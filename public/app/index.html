SDE UNIVERSES

把爱思乐园装到手机桌面

装好之后，桌面上会多一个图标；点开是全屏的，没有地址栏，和从应用商店下的 App 用起来一样。 它不占应用商店那份空间，正文也一律实时取自站上——站上改了什么，你下次打开就是新的。

你现在就是从桌面图标打开的，已经装好了。

安卓：Chrome / Edge / 三星浏览器

  1. 若上面没有出现安装按钮，点浏览器右上角的 ⋮ 菜单。
  2. 选 安装应用 或 添加到主屏幕。
  3. 确认名称「爱思乐园」，点安装——桌面上就有了。

从微信、QQ、微博里打开这一页是装不了的，那是它们自带的浏览器。 请点右上角菜单选「在浏览器打开」，再回到这一页。

iPhone / iPad：必须用 Safari

  1. 用 Safari 打开 sdeuniverses.com/app/（微信、Chrome 都不行，苹果只允许 Safari 添加）。
  2. 点屏幕下方正中的分享按钮（方框里一支向上的箭头）。
  3. 在菜单里往下翻，选 添加到主屏幕。
  4. 右上角点添加——桌面上就有了那个三角图标。

苹果不给网页「一键安装」的权限，这四步是它唯一的路子，别处也一样。

电脑：Chrome / Edge

  1. 看地址栏右侧，有一个安装图标（显示器带下箭头，或 ⊕）。
  2. 点它，再点安装。
  3. 没有这个图标就走 ⋮ 菜单 → 投放、保存和共享 → 安装页面为应用。

装好后它有自己的窗口和任务栏图标，和别的软件并排放。

装好之后

  • 长按桌面图标可以直接跳四个地方：SDE 浏览 · SDE 对话 · SDE 社区 · 全站检索。
  • 不必再管「强刷」——App 里读到的永远是站上最新那一版。
  • 断网时打开会看到一张离线提示页，联网后自动恢复。
  • 要卸载：长按图标 → 卸载 / 移除，和普通 App 一样。
