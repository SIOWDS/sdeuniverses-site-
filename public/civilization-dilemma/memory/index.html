一张也想不起

一个人整理云盘，翻出十年前的一个相册，二百多张照片，都是他自己拍的。他一张一张看，想不起任何一张是在哪里拍的、那天发生了什么。云盘很贴心，每张照片下面标着日期、地点、天气，有几张还自动生成了说明："与朋友在海边"。他看着"朋友"那两个字，认不出那是谁。

十年前的那趟旅行，他记得自己去过。别的，全在云盘里，不在他这里。

他试了一件事：找出一张没有任何标注的老照片——上大学时同学用胶片相机拍的，没有日期，没有地点——他看了一眼就想起来了：那天是期末最后一门考完，几个人翻墙去了后山，一个人的鞋掉进了水里。这张照片他十几年没看过。

这本书是为这两张照片写的：当记忆可以被完整地外置——照片、聊天记录、日程、语音、每一次搜索——存下来是不是就等于记住了？如果不是，记住是什么？

一百年的账：记忆是存储与提取

记忆心理学的基本画像，从艾宾浩斯的遗忘曲线到现代的编码—存储—提取模型，都建在一个比喻上：记忆像一个仓库，经验被编码后存进去，需要时提取出来；遗忘是存储衰减或提取失败。这套画像功劳很大，它让记忆可以被测量、被训练、被临床评估。它背后有一个从来没被认真检查过的假设：记住一件事，就是把它存下来；存得越全、提取越方便，记得越好。外部存储——笔记、照片、云盘、聊天记录——只是把仓库搬到了体外。

这个假设九十年前就被一位心理学家正面质疑过。巴特利特一九三二年的《记忆》做了一个著名的实验：让人读一个陌生文化的民间故事，隔一段时间复述，再隔一段时间再复述。复述一次比一次短，一次比一次"合理"——陌生的细节被删掉，不合逻辑的情节被改成合逻辑的，故事被改写成复述者自己文化里的样子。他的结论是：记忆不是再现，是重构——每一次回忆都是按当下的图式重新建造过去，不是从仓库里取出原件。本书完全接受这个判断。但要指出：他讲的重构是每一次回忆时发生的事，本书要问的是，当仓库被搬到体外、每一次"回忆"都变成一次查询之后，重构还发不发生。

那一层已经被占了

先看能核的现象，不给未核的数字。

十多年前有一项被广泛引用的实验：当人们知道一条信息可以随时在网上查到时，他们对信息本身的记忆变差，对"在哪里能查到"的记忆变好——记忆从内容转向了索引。此后关于导航工具与空间记忆的研究方向一致：长期依赖导航的人，对走过的路线的记忆更差。近两年关于"认知卸载"的研究把这条线推进到了对话工具：把思考与记忆交给工具的程度越高，某些独立认知能力的测评越低。这些研究本书第二卷会完整读。这里只取一件事：在"存下来、随时能查"这一层，工具已经做得比任何人的记忆都全都准；而这一层做得越好，人自己那一层越空。

那二百张照片正是这条线的个人版：存得很全，一张也想不起；没存的那一张，一眼就回来了。

为什么是现在

记忆不是第一次遇到外置。文字、印刷、笔记本、相机，每一种都把一部分记忆搬到了体外，柏拉图早就担心过文字会让人不再用心记，人类每一次都调整，然后稳定下来。这一次为什么不一样？

第一，存储不再稀缺。一个人一生的照片、对话、行程、搜索，全部可以被无成本地存下，且随时可查、自动标注、自动总结。围绕"记不记得住"设计的一切——背诵、笔记、记忆术——都失去了定价对象。

第二，价值结算的地方挪了。从前"记得"的价值在"能不能想起来"这一格结算；现在这一格工具填得比人满——它不但能想起来，还能替你总结"那天你和朋友在海边"——价值只能往别处走：往"不看记录，我自己能不能把那天走一遍"那一格走。教育还在考记得多少，生活已经在按谁能不看手机讲出自己的过去来分辨谁在场。

第三，工具从条件变成了变量。相机是条件，拍下什么就是什么；云盘是变量，它自动标注、自动分类、自动生成说明、自动推送"三年前的今天"，你的过去在它那里每天被重新组织一次，且半年一换版。当"你的记录"本身成了一个被算法反复重排的东西，"存下来了"就不再能说明你记得。

把三条放在一起：不是外置更全了，是它把"存与取"整个从人手里拿走了，而记忆的观念还在把存与取当作记忆的全部。

死的是什么，没死的是什么

死的不是记忆，不是过去，是一个位置："我存下来了所以我记得"这个位置。

它早该死了。云盘给那张照片配上"与朋友在海边"时，它做的不是从他的记忆里把那天取出来——那天在他的记忆里已经没有了。它是当场造的：从日期、地点、人脸识别、几百万张类似照片的说明里，生成一句最像的。这件事暴露了一个事实：他自己的记忆从前也是这么"想起"的——巴特利特九十年前就证明了，每一次回忆都是按当下的图式重新建造。云盘只是把这个重建做得比他更快、更"合理"、更不像他。工具让人看清了：记住从来不是取回，是重建——所以它可以被一台更会重建的机器替代。

那么没死的是什么？是工具没做、也做不了的那一件：翻墙去后山，那只掉进水里的鞋。那张照片没有任何标注，工具生成不出那天——不是因为数据不够，是因为那天的要紧处不在任何可被拍下的东西里：鞋掉进水里之后几个人笑成什么样，翻墙时谁先上的，考完最后一门那种松下来的感觉。这些东西不在照片里，在他身上——他能不看任何记录把那天从头走一遍。这叫重走。重走不是提取，是一个人以自己此刻的身体，把过去的一段路再走一次。工具可以存路的照片，不能替他走。

有一门行当早就把这两件事分开了。飞行员训练里有一项叫"航位推算"：不用任何导航设备，凭速度、航向、时间，推算自己在哪里。全球定位系统普及之后，这项训练没有取消，反而被强调——不是因为定位系统不准，是因为一位完全依赖定位的飞行员，在设备失效的那一刻不知道自己在哪，而且平时也不知道，他只知道屏幕上那个点。航空早就知道，"知道自己在哪"和"屏幕上显示我在哪"是两件事，前者只能靠自己走出来。

最强的反方

本书必须正面回答一个反方，它是当代心灵哲学里最有影响的论证之一。

延展心智论说：心灵不止于颅骨之内——一个记事本，如果一个人始终随身携带、随时查阅、无条件信任其内容，那么记事本里的信息在功能上就是他的记忆，与脑内的记忆没有本质区别；外置不是记忆的替代，是记忆的延展；担心云盘让人"不再记得"，就像担心笔记本让人不再记得一样，是一种怀旧。

这个反方对本书的一半是对的：在"能不能找到这条信息"这一层，云盘确实就是他的记忆，本书不主张卸载云盘。它错在另一半：它只看"能不能找到"，不看"找到之后是不是他的"。那二百张照片在功能上完全是他的记忆——随身、可查、可信——但他看着"朋友"两个字认不出那是谁。延展的是索引，不是那段路。本书的赌注在这里：如果长期完全依赖外置记忆的人，十年后不看任何记录讲出的自传，在连贯性上不低于对照人群，本书作废。

往上走的四级台阶

本书把一个人和自己记忆的关系分成四层。

第零层：存。拍、记、录、备份。这一层已经被工具占了，占得比人全。谁把记忆放在这一层，谁就在等那二百张认不出的照片。

第一层：检索。搜、标注、自动总结、"三年前的今天"。这一层撑不了多久：工具的检索比人的回忆快，而检索仍是在同一堆记录里打转，它不生产任何一次重走——它生产的是"与朋友在海边"。

第二层：判断哪些事必须能重走。一个人的过去里，哪些是存下来就够了的——发票、日程、地址——哪些是必须能不看记录走一遍的——第一次离家、父亲住院的那周、那次翻墙？这一层的活是粗粒度的：不再管每一条记录怎么存，管的是这一生里，有几段路是必须留在自己身上的。工具给记录、给时间线、给"你可能想回顾"，但"这一段我要自己走"由人定——不是工具能力不够，是它不在这个位置上：它没有身体可以把那条路再走一遍。

第三层：不看记录，把它讲出来，并为讲出来的认账。这一层的人不再回答"我存了什么"，而是回答"这一段我不看任何东西能讲，讲的和记录不一样的地方是我的，错了也是我的"。这是一个人在自己记忆上能站的最高一层，也是工具绝对到不了的一层，因为它需要一个会讲错、会讲得和照片不一样、会在讲到那只鞋的时候笑出来的人。

在第二、三层上，工具是必要的：没有它把第零层穷尽——把能存的都存了——第二层不存在：正因为一切可存的都已经在云盘里，"哪些是我必须自己走的"才显出来是另一个问题；从前人以为记住就是存住，因为存不全，存下来的就显得珍贵。人也是必要的：没有人走那段路，云盘里就只有"与朋友在海边"。谁也替不了谁。本书把人与工具在第二、三层上的搭配叫作人机协同的重走单元——在第零层工具是仓库，到第二层它是这个单元不可拆的一半：正是它把该存的存尽了，该走的才看得见。

回到那个人。他后来做的事是这样的：他没有关云盘。他给自己定了一条规矩——每年挑五段过去，不看任何记录，讲给一个人听，讲完再对照云盘。第一年他讲了父亲住院的那周，讲完对照，日期错了两天，有一个细节云盘里没有：父亲在病房里教他叠一种纸船。云盘里有那周的三十四张照片，没有一张是纸船。他把这一段记在了照片之外的一个地方，标注只有一句：云盘没有。第二年他的孩子问他小时候的事，他讲的是翻墙那天。这一上一认，就是第二、三层。

一把尺：不看记录能讲出几成

主张说完了，得给一把尺。

本书提出的尺叫自由回忆率：一个人对自己存下的记录，不借助任何记录，能连贯讲出的比例——以及讲出的内容里，记录之外的细节占几成。它借的是记忆研究里"自由回忆"这个经典范式，区别在于本书的材料不是实验室的词表，是一个人自己的过去；而且本书不只计回忆得对不对，更计记录里没有的那部分。取值材料是本人的讲述录音与其外置记录的对照，一次取值约一个月。

有了尺，就能写下这本书什么时候算错。如果长期完全依赖外置记忆的人，十年后不看记录讲出的自传在连贯性上不低于对照人群，那么本书作废。

还有一个更硬的检验，本书没做，但把设计写出来了：一年前的一段经历，三个组各自复原——第一组只有工具从记录里生成，第二组只有本人不看任何记录复述，第三组是重走单元、本人先复述再与工具对照——由第三方核连贯性、准确度，以及记录外细节的数量。本书的主张成立，当且仅当前两组都不如第三组：工具生成的没有纸船，本人单独讲的日期错两天，两者合起来才是那一周。这个实验没有人做过，本书作者也没有。书里所有的尺都停在取法上，一个值也没取过。

举一个数法。同一个人，同一趟十年前的旅行。第一次：看着云盘的二百张照片讲，讲出的全部内容与照片标注一致，没有一条照片之外的细节；自由回忆率记零——因为他讲的全是看来的。第二次，一年后：不看云盘讲，讲出的内容对照记录，事件的顺序对了七成，日期错了，有四条细节记录里没有——一个人晕船、一家关了门的面馆、下雨那天在屋檐下打的牌、回程车上有人丢了钱包；自由回忆率记七成，记录外细节记四条。本书要问的是：把一批人排开，自由回忆率与记录外细节数，和十年后自传的连贯性是不是一起动。这个问题此前没有人这样问过，因为此前记忆测量的是"记得对不对"，没有人测过"记得的里面有多少是记录里没有的"。

这把尺会怎样被做假

自由回忆率一旦成了指标，会发生什么，不难预见：先看记录，背下来，再"不看记录"讲一遍，率记满分，没有一条是走出来的。本书事先写了升级条款：只计含记录外细节的复述——纸船、面馆、屋檐下的牌；与记录完全一致的复述按背诵处理，不计。若在这个口径下自由回忆率与自传连贯性无关，这把尺已被驯化，尺子那一节须重写。

一本主张"记住是重走而非存取"的书，若自己立的尺被人用一次背诵填上了，它就在自己身上犯了它要批评的错。

本书不做什么

本书不讲知识的归属——本社此前有专书讲"被使用而仍是他的"，本书讲"存下来而仍不是他的"。本书不讲历史：本丛书另有一本，管集体的过去能被追问几层，本书管个人的过去能不能重走。本书不讲老年：那本管别人来不来走老人那段路，本书管一个人自己走不走自己的。本书不讲阅读：那本管走过什么，本书管留下什么。本书也不反对任何外置工具，它只需要一个不再需要论证的事实：云盘里有三十四张照片，没有纸船。

各卷概览

第一卷 列一张表：仓库、编码、存储、提取、备份——记忆观念史上历代被当作"存住"的东西，逐条写明它存住的过去是怎样在每一次回忆时被当场重建过一次。

第二卷 是实证：从网络效应到导航依赖到认知卸载的那条研究线，巴特利特的复述实验，航位推算为什么没有被取消，延展心智论证的边界。

第三卷 写四级台阶与重走单元：哪些事必须能重走、怎么走、怎么与记录对照，机器供什么、人供什么。

第四卷 写制度：教育与个人档案从鼓励全存转向保留重走——每一段重要的记录附一次不借助记录的复述；家庭与老年恢复口述与重讲的场合；附学校、家庭、个人三个层级的重走练习与判据。

第五卷 写尺与判据：自由回忆率的取法、三组对照的设计、作废条件。

第六卷 写这本书自己的死法。

给读者的话

三种人，是这本书的读者。第一种是那个整理云盘的人，他需要知道认不出"朋友"不是他的记忆坏了，是那二百张从来就不在他身上——而那只掉进水里的鞋一直在。第二种是做记忆研究与教育设计的人，他们手里握着"记忆怎么测"的范式，第四卷为他们而写：在"记得对不对"旁边加一栏"记录里没有的有多少"。第三种是正在做个人记忆产品的人，他们需要知道自己的产品在第零层是真正的礼物——它替所有人存住了从前存不住的——在第二层是必要件——正是它把该存的存尽了，该走的才看得见——而在第三层什么也不是：那一层没有产品，只有一个不看手机讲父亲叠纸船的人。

作者对本书的态度写在第五卷：它可能是错的，错的条件已经写明。若有一天十年的追踪告诉我，全靠云盘的人讲自己的一生并不比别人零碎，那一天本书便可以退场了——它被一个真正延展了的心灵推翻了，而在那之前，纸船只在他身上。

立题大纲 病灶 · 承重命题 · 卷目 · 出路 · 读数与作废 · 边界

病灶

记忆被当成可外置的存储，存下来就等于记住了——手机记电话号码，云盘记照片，AI 记你说过的每句话。一个人翻出十年前的照片，一张也想不起是在哪拍的。存下来的东西越多，一个人能不看记录讲出来的自己越少；到最后自传只能由云盘代写。

承重命题

记忆不是存下的信息，是能被本人重新走一遍的差异序列。外置的是显露，走不回去的是那段路；存得越全，走回去的越少。

卷目

卷一 外置记忆史（从文字到云端）；卷二 全存之后（记得更少的实证：导航、通讯录、照片）；卷三 记忆的发生学（重走：哪些事只有本人能走回去）；卷四 教育、老年与个人档案的重建；卷五 读数与判据。

出路

第一步换读法：把「存下来了没有」改问成「能不能走回去」——存下来的是显露，走回去的才是记忆。第二步立读数：以重走率记账，一个人对自己存下的记录，不看记录能复述几成。第三步改制度：教育与个人档案从鼓励全存转向保留重走——每一段重要的记录附一次不借助记录的复述；老年与家庭相应恢复口述与重讲的场合。卷四给出学校、家庭、个人三个层级的重走练习与判据。

读数与作废

本行叫法（见上文前言）：自由回忆率

旗舰读数：重走率——一个人对自己存下的记录，不借助记录能复述的比例。作废条件：若全外置记忆者十年后的自传连贯性不低于对照组，本书作废。

边界

让开 #109《AI 时代的个人知识》（知识归属）。与本丛书《历史》分界：历史管集体的过去，这本管个人的；与《阅读》分界：阅读管走过什么，记忆管留下什么。

本书要交的三项成果

一、这一行里那个旧哲学假设的具体失效机制；二、一套由三方程、六路径、三原理展开的重建方案；三、一组能检验这条出路是否有效的现实判据。三项缺一不成书。全书五卷：卷一病灶史、卷二 AI 之后的实证、卷三发生学重建、卷四制度与实践、卷五读数与判据；日常案例主讲，学术案例只做旁证。
