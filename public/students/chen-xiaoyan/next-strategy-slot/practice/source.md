## 下一步存在性检查：三个集合、一个窗口，以及本次行动改写了什么

## 母文的续策位判据用在非医疗的多阶段决策上；医学部分只转述母文自己的限制

## SDE 编辑部  ·  2026年8月

### 先写死两条

**第一，这不是医疗工具。**母文自己写明：该概念**未经临床验证，不得用于患者分层、保险授权、法律能力判断或绩效考核**；它目前是一项**待验证的研究假说**；它的公开注册审计得到的是一个**对它自己不利**的结果。本文因此不提供任何临床用法，也不提供任何诊断、治疗或用药参考。

**第二，本文把这套判据用在非医疗的多阶段决策上。**母文的结构是通用的：任何"这一步会改写下一步能不能成立"的场合——系统迁移、技术债、长期项目、设备维护、组织变革——都适用。医学那一侧，本文只在最后一节原样转达母文自己的限制。

### 这套检查做什么，不做什么

**做**：判断你计划里的"下一步"是真的存在，还是只是路线图上画的一个箭头；并把本次行动对下一步的四项条件的改写记录下来。

**不做**：不比较方案优劣，不产生推荐，不打分。它产生的是一个**存在性判断**和一份**改写记录**。

**不适用**：单步决策；以及"这一步做完就结束了"的事——那种事不需要这套东西。

### 安全边界

- **不用它当作拖延的理由。**母文写死了七条反向约束，第一条的精神就是：这个概念不得成为**延缓有效行动**的语言。判出 Q=0 是要求换一类行动，不是要求什么都不做。
- **不用它给人打分或考核。**
- **不用缺记录推断人的态度。**母文的原话是：把公开字段的缺失当作质量缺陷去惩罚团队，等于**把记录能力误当成照护能力**。
- **不让检查本身占用被检查者的时间。**母文的处置是：最小记录要**嵌进已有的评估**，以**触发变化**为重点，稳定时简化、有重大变化时才完整重开。

### 第一步：先划定 Ω，别把"世界上存在"当成"你能用"

Ω 是这一轮所有候选行动的全集。母文对它有一条硬限制：**不能把"理论上存在于世界某地的东西"直接收进来**，必须先明确适用范围、可及性、资格和时间窗。

翻成日常：不能把"业界有这个方案""开源社区有个库能做"直接写进候选集。要先问：在我们这个环境里、以我们能拿到的资源、在这个时间窗内，它能不能到位。

划不清 Ω，后面三个集合全是空谈。

### 第二步：三个集合，每项都要具名

对 Ω 里的每个候选，判它属于哪几个集合。母文要求**零情态词**——"大概能""应该可以""估计他们会同意"都不满足编码。**每一项至少要有一个具名行动、时间戳、证据来源和排除理由。**

| 集合 | 判据 | 常见的松掉方式 |
|---|---|---|
| **B** 说得通的 | 能说明为什么这个做法对当前局面有合理依据 | 把"清单上有"当成 B（母文：B 不等于目录） |
| **P** 进得去的 | 在有效窗口内，人力、时间、预算、权限、依赖都能真的到位 | 写"原则上可以协调"（母文：没有可完成路径就不算 P） |
| **N** 能授权的 | 到那时候，有权拍板的人在了解更新后的信息与代价之后，还能授权 | 拿一年前的立项批复当永久授权（母文：一次概括同意不能收编未来所有行动） |
| **W** 窗口开着 | 所需信息能在行动失去意义之前拿到，且局面没有把选择压成一个来不及商量的默认动作 | 把"事后补决议"当成决策发生过 |

第三行最容易被跳过，也最容易出事。**"当时那批人同意过"不等于"现在这批人能授权"**——人换了、条件变了、代价变了。

### 第三步：判 Q，并记下缺的是哪一个

判据只有一行：

**Q = 1，当且仅当 W=1 且 B∩P∩N 非空。**

真正有用的不是这个 0 或 1，而是**缺的是哪一个**——四种缺法对应四种完全不同的下一步：

- **B 空**：缺的是说得通的做法。要去找新做法，或者承认这条路走完了。
- **P 空**：缺的是入口。要去补资源、权限、依赖——**这是最常被误诊成"没人愿意做"的一种**。
- **N 空**：缺的是当时的授权。母文这句话直接可用：**缺的是当前授权，不是由谁去替别人推测意愿。**
- **W = 0**：行动即使事后被写进记录，也没有在有效时间内成为一个决定。

母文这里有一句非常实用的话：如果 P 空，**不能把它写成"对方没有选择"**；如果批准晚于窗口，那是 P 或 W 的失败，不能在事后列为"依从性问题"。

### 第四步：记录本次行动改写了什么

这是整套方法真正的重点，也是它区别于普通"下一步规划"的地方。

母文把它写成一个记录约束：本次行动 a 不只改变了状态，它同时决定了下一时点的 (B, P, N, W)。**任何声称"我为下一步保留了空间"的方案，都必须说明它怎样改变这四项，而不能只展示当前指标。**

做法是在每次行动结束时填四行：

1. **这一步让哪些做法从 B 里退出了？**（不可逆的改动、烧掉的兼容性、失去的可选路径）
2. **这一步让 P 变宽了还是变窄了？**（消耗的预算与人力、新增的依赖、透支的信任）
3. **这一步之后，还能拍板的是谁，他的目标变了吗？**
4. **判断下一步所依赖的那些信号，还能不能用？**——这一项来自母文的第二条机制：策略一变，原来的信号可能失真，**必须检验旧阈值在新分布上还成不成立，而不是机械搬过去**。

四行里第四行最容易漏。母文举的那个例子很硬：某些防御让常规攻击失效、看起来很稳健，换一种针对性攻法之后大多被打穿——**"标准测试没打穿"不等于"机制稳健"。**

### 第五步：填双未来表

不要把三个集合压成一个总分。母文用一张 2×2 表分开两种未来：

| | 人／组织进得去且能授权 | 进不去或不能授权 |
|---|---|---|
| **还有说得通的做法** | **双续**：下一步真实存在 | **有方案没人能上**：最常被漏掉的一格 |
| **已无说得通的做法** | **有人没方案**：能力和意愿都在，路走完了 | **双断**：两边同时消失 |

三条读法照抄母文：

- **右上格最容易被传统的路线图漏掉**——方案还在表上，也说得出道理，但实际已经进不去。
- **左下格防止"只要大家有决心就行"这种夸张**——愿望不能创造不存在的做法。
- **右下格不能被写成"什么都不能做"**——这一类行动的失败，不等于整件事的失败；这一格里要做的是另一类安排，而且它同样需要被认真做。

母文还提醒：这是一个**带时间戳的状态**，不是永久标签。同一个项目可以先在双续，因为迟发的代价移到右上，又因为条件恢复或目标重谈回到双续。**所以要报的是 Q 形成的时间、持续多久、怎么退出的、能不能恢复**，而不是在事情结束时回头下一个判语。

### 五条机制当检查表

母文列了五条机制说明"本次行动怎么改写下一次"，直接当检查表用：

1. **选择机制**：这一步是否只清掉了最容易的那部分，反而让难的那部分失去了竞争约束？
2. **信号机制**：判断"该不该走下一步"所依赖的指标，会不会正好被这一步弄失真？
3. **消耗机制**：不只看有没有出大事，**低强度但持续的消耗**（疲劳、返工、值班、维护负担）会通过累计使下一步做不完。
4. **时窗机制**：审批、采购、排期、外部依赖，能不能在窗口内到达。
5. **授权机制**：目标本身会不会因为这一步而改变——**而这种改变不能先验判为理性或不理性**，它只需要被看见并获得一个正式位置。

### 走完一遍：一次系统迁移

某团队要把一个老系统迁到新平台，路线图上写着三期：先双写、再切读、最后下线老库。

- **第一步 Ω**：三期各自的具体动作，加上"回滚""暂停一个季度""换一条迁移路径"。排除"业界有种一步到位的方案"——本环境拿不到，不进 Ω。
- **第二步三个集合（判第二期"切读"）**：
  - **B**：切读有明确依据（双写已跑三个月、数据一致率可查）。B 非空。
  - **P**：需要 DBA 两周窗口＋一次停机审批。查下来，DBA 两周内被另一个项目占满，停机窗口本季度只剩一个且已被预定。**P 空。**
  - **N**：一年前的立项批复覆盖"完成迁移"，但**没有覆盖"为此停机四小时"**；现在的业务负责人换了人。**N 存疑。**
  - **W**：老库的支持服务在两个季度后到期。窗口还开着，但在收窄。
- **第三步判 Q**：**Q = 0，缺的是 P（还有一个存疑的 N）。**
- **这一步的价值**：路线图上"第二期"看起来一直在，团队三个月来一直在讨论"要不要现在切"。判完才发现，**这个讨论本身没有对象**——不管讨论出什么结论，这一步都进不去。真正该做的是去补 P（申请窗口、协调 DBA）和重新拿 N（向现任负责人重开授权），而不是继续论证切读的技术优劣。
- **第四步改写记录**：这三个月的双写让一致率数据更漂亮了（B 变宽），但也让老库多扛了三个月的双倍写入，磁盘余量从 40% 降到 12%（**P 变窄了**）——**同一步同时让一项变宽、另一项变窄，这正是母文说的"本轮效果与下一轮能力不必同向"**。
- **第五步双未来**：当前落在**右上格**——方案在、说得通，但进不去。
- **结论怎么用**：产出不是"该不该切读"的建议，是"这一步现在不存在，缺的是 P 和 N"这个事实，以及一份改写记录。**要不要为此调整整体计划，是另一层的决定。**

这个例子里最值钱的是第三步：它把一场持续三个月的技术辩论，还原成了一个资源与授权问题。

### 最小记录怎么做

母文对记录负担有明确要求，照抄：

- **嵌进已有的评估**，不新开一套流程。
- **以触发变化为重点**：稳定的时候简化确认，出现重大变化（大的成果、大的代价、外部条件变动、目标变化）时才完整重开。
- **频率由实际窗口和被记录者的负担共同决定**，不由记录者的日历单方面决定。

一份能用的最小记录只有五行：Q 是 1 还是 0；缺的是哪一个；本次行动对四项的改写；当前落在双未来表的哪一格；下次重新判的时间点。

### 一条容易被漏掉的记录：把「从未形成」和「跟丢了」分开

母文提了一个很实在的研究要求，搬到实务里同样成立：**要把"下一节点从未形成"从"失访"里分离出来。**

这两件事在记录上看起来一模一样——都是"后来没有下文了"。但它们是两件完全不同的事：

- **跟丢了**：那个位置本来成立，只是没人跟进。处置是补跟进。
- **从未形成**：那个位置根本没有出现过。处置是补 B、P、N 或 W 里缺的那一项。

如果一份记录把这两种都写成"未推进"，那么所有的复盘都会指向同一个错误结论——"我们跟进不力"——而真正的缺口一次都不会被看见。

做法很简单：在你的状态字段里，把"未推进"拆成两个值，并要求填的人写出缺的是哪一项。**多这一个字段，比多开三次复盘会管用。**

### 一张自检表：每一行都要预先写好「我输了是什么样」

母文列十个近邻时定了一条规矩，可以直接搬用：**每一行都要写明"这个已有的解释若成立，我会看到什么"**，不给自己优待。

搬到你的场合，就是在动手判之前先填这张表：

| 已有的解释 | 若它对，我会看到 | 若这套判据对，我会看到 |
|---|---|---|
| 「就是资源不够」 | 补足资源后，下一步立刻成立 | 资源补足后 N 或 W 仍然空着 |
| 「就是没人跟进」 | 加强跟进后就推进了 | 跟进再紧，缺的那一项也不会自己出现 |
| 「计划做得不细」 | 计划细化后路径清晰 | 计划再细，P 里那条依赖仍然拿不到 |

第一行最有用：**"补足资源之后还缺不缺"是一个能做的实验**，而且它一次就能把"资源问题"和"授权问题"分开。

### 读数与代价

- **代价一：要具名。**"资源不足"不算，要写"DBA 两周窗口被占"。不具名的判断没法被别人推翻。
- **代价二：N 要重开，会得罪人。**"这个不是一年前批过了吗"是最常见的回应。母文的立场很清楚：一次概括同意不能自动收编未来所有行动。
- **代价三：结论常常是"这一步不存在"，而不是"该怎么选"。**很多场合的人不接受这种产出。
- **一条读数**：如果你每一轮判出来的都是 Q=1，那多半是判据松了——回去看 P 那一栏是不是写了"原则上可以协调"。

### 三种典型事故

**事故一：把 Q=0 当成"没救了"。**母文写死：那一格里仍有另一类行动要做，而且要认真做。把它写成"什么都不能做"，才是真的什么都不做。

**事故二：把 Q=0 当成谁的失职。**母文：交集为空可能来自快速变化、不可逆代价、资源排斥和目标改变，**责任要另行分析**。

**事故三：拿它当延缓的理由。**这是母文七条反向约束直接点名的一条。

### 停手线

- 一旦这套判据被用来给人分层、排名或做考核，停手。
- 一旦有人用"下一步反正不存在"来阻止本来就该做的事，停手。
- 一旦记录本身开始占用被记录者的时间，停手，回去做最小记录那三条。
- 一旦要往医疗上引，停手——见下一节。

### 什么时候该怀疑这套说法

母文自己给了可翻案的线，这里是你能执行的三条：

1. **如果"下一步能不能成立"已经被现有的状态变量充分解释**——也就是说，只看进展和资源就能预测下一步存不存在，重复授权这一项没有增量——那么这套东西应当退回普通的可行性模型。这是母文自己写的。
2. **如果逐格翻案成立**：任何人在完整材料里找到了那些被判为缺失的字段，相应编码就该从 0 改为 1。母文的原话是：**新概念必须接受逐格翻案，不能用"广义上都相关"保护自己。**
3. **如果整套审计被系统推翻**——完整文件显示那些条件早已进入规则、只是公开页面压缩显示——那么"记录架构存在盲区"这个概括就该撤回。母文把自己被推翻的样子也写下来了。

### 四种常见反对

**「路线图上明明有下一步啊。」**这正是母文要拆的那句。路线图给的是 B 的候选，不保证 P、N、W。

**「这不就是可行性评估吗？」**区别在第四步。可行性评估问"现在能不能做"；这套东西还要问"这一步做完之后，下一步的四项会变成什么样"，并要求把它记下来。

**「N 太主观了。」**N 不是问"他情不情愿"，是问"在了解更新后的信息与代价之后，他还能不能授权"——这件事是可核对的：有没有重开过一次讨论，有没有一个具名的人在具名的时间点确认过。

**「判出 Q=0 之后我该干嘛？」**看缺的是哪一个。缺 P 就去补入口，缺 N 就去重开授权，缺 B 就去找新做法或承认这条路走完，W=0 就去改时间安排。**四种缺法，四条完全不同的下一步。**

### 关于医学那一侧：只转达母文自己的三句话

本文不提供任何临床用法。以下三句取自母文，转达在此以免读者去别处误用：

**第一句（定位）**：这个概念**未经临床验证**，**不得用于患者分层、保险授权、法律能力判断或绩效考核**；它目前是**一项待验证的研究假说**。

**第二句（审计的界限）**：那次公开注册审计**只评价公开记录架构，不评价未被观察的临床关系**；它的结论是"公开注册架构尚不能识别这个对象"，**不是"临床团队忽视患者价值"**。

**第三句（不归罪）**：**Q=0 不是对团队或患者的道德归罪**；治愈使后续选项归零**不编码为失败**——"没有下一次治疗"可以是最佳结局。

### 一个人的自查版

手上有一件分阶段的事，问四句：

1. 下一步在纸上叫什么？它有没有一个具名的做法？
2. 到那时候，我实际进得去吗？（时间、钱、人、依赖，逐个具名）
