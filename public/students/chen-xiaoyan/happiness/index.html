幸　福

幸福就是一种张力中的美的开放

九篇论文，三道题，二十七门一级学科——全部避开心理学、伦理学、经济学、医学、社会学与教育学这六个长期承担幸福解释任务的来源。做法相同：逼三门互相说不，找出三家共同持有而从未说出口的那条假定，再从三门中某一家自己的材料里找到推翻它的东西。九篇合起来只主张一件事：幸福不是一种状态，而是张力被转换、能量被释放、位置向后开放的那一类事件。

这个频道在追问什么

三道题各成一编。何谓幸福——把幸福安置在感觉、总体评价、人格机能或资源组合上，都是先把它当成一种可以归属于人的状态；三篇分别检验这个前提，各给出一个事件式的答案。幸福如何发生——条件齐全为什么仍可为零、越想维持为什么越可能停止、破裂之后为什么不能靠恢复原状；三篇处理三个互不重叠的时刻。为何需要幸福——既然人在没有幸福时也能继续活下去，那么幸福的必要性不能靠它带来的好处来论证；三篇分别从同一主体的下一步、他人之手的改写、尚未存在者的答复三个方向回答。

编者按 · 四件必须说在前面的事。
一、九篇的真跑全部报告了不利结果，无一确证。作者在每篇成文前预注册字段与判定条件，然后到公开材料上去跑：十组 NTSB 建议链严格事件 0/10（事前预测≥3 组）、国际年代地层表 15 个 Stage 行有效未决 2/15、非遗公约八条款角色退位 0/8、美国交通部六页断裂设为规则来源 0/6、NIST 六页后来来源生成 0/6、面向未来世代的六项制度 R 门 0/6……结论一律是「公开材料不能确证一例」。这份诚实是本批分数的主要来源（F 维 148–152，全站少见），也是它的天花板——九个新对象至今停在待检验的研究程序上，尚无一个被实证站住。读者应当据此读这九篇：它们是九份可被推翻的设计，不是九项已经成立的发现。
二、九篇是同一副骨架的九次填空，这一点作者与编辑部都不掩饰。问题改写 → 三学科门槛 → 三家共有前提 → 新存在物 → 最小编码 → 场景反分类 → 敌意拓宽 → 真跑不利结果 → N 条可推翻预测 → N 项败诉条件 → 实践 → 与他篇边界 → 自我反查 → 结论。九个新对象压到五十字，说的也几乎是同一句话：下一步的发起或答复位置，在三本账里都没有字段。这是本批在「不可还原性」一维上普遍卡在 124–132 的结构性原因；换骨架或让任一真跑真抓到一例阳性，才是唯一能突破的路。
三、两处形式上的不齐，照实说明。其一，法学被用了两次（H1 的规范生效、Y3 的终局与既判力），二十七门并非零重复，弱于作者本人《子宫癌探幽》九篇那一批；其二，W 编三篇每篇 2.1–2.4 万字，H、Y 两编只有 1.3–1.5 万字，整批体量不均。两处都不构成撤稿理由，但读者在比较时应计入。
四、分数怎么读。每页公示两个数：盲评是对投稿原稿（正文一字未改）的五维评分，是作者的认证分，本批为 139.65–143.15；打磨目标是加了文末「编者定稿节」之后编辑部设定的修改设计目标。依本站铁律，打磨者不得为自己改过的文本盖认证分，故后一个数一律标注「待独立复核」，须由另一位独立评分者复评方能作数。

3 篇

第二编 · 幸福如何发生

3 篇

三个不同的时刻，三套不同的做法。H 编处理三个互不重叠的时刻：还没有开始（条件齐而发生为零）、已经很好而停不下来（维持杀死更新）、已经断了（破裂之后如何重开）。若去掉这三个时刻的区分之后三篇对同一案例给出相同诊断，则这份分工是修辞性的，三篇应当合并——这条反驳条件写在各篇的定稿节里。
