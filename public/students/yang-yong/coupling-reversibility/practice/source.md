## 切换损失怎么测：四类扰动、一份清点手册与不许事后改的阈值

## 把母文的测量协议做成一份能在自己的团队里跑完的迁移演练流程

## SDE 编辑部  ·  2026年8月

导语　母文给了一整套测量协议，但它是按论文的顺序写的。这一篇把它重排成动手的顺序：先判断该不该测，再设计扰动，最后算数与写结论。

### 这套方法做什么，不做什么

**做**：测出一个流程在工具被撤走、被替换、出错或换题之后，能不能在规定时间与质量内重新拼出一条路；并把这件事变成一个能记账的数。

**不做**：**不给个人打分。**母文写死了这一条——个体的切换损失受任务、界面、权限和辅助资源影响，拿它排名会导致隐藏工具使用、故意制造人工步骤、在测试中表演独立性。**合适的单位是流程位置，不是人。**

**不做**：不主张少用工具。母文的四格里，"自主冗余"没有比"增能型协作"更高。

**适用**：任何"工具会变"的场合——模型或供应商会换、系统会升级、法规会改、人员会流动、接口会关闭。

**不适用**（母文明写的三条）：无法保持必要辅助技术的场合；真实扰动会危及安全的场合；任务找不到等值条件的场合。

### 安全边界：先写死不做什么

- **不撤辅助技术。**屏幕阅读器、辅助沟通设备、翻译系统可能是一个人稳定行动的组成部分，不得为了测试而强制拿走。要测就换用"替换"或"模拟"这两类扰动。
- **不在真实业务里制造中断。**医疗、飞行、能源、金融这类场合，用数字孪生、历史回放、沙盒案例、影子运行、等能力备份系统。母文的原话是：可逆性的伦理底线是**降低**真实变化造成的风险，不是通过**制造**风险来证明某个人不够独立。
- **不做个人 KPI。**单一综合分只用于群体比较，不用于个人的高风险决策。
- **不把速度恢复等同于完整恢复。**结果要同时测质量、时间和安全。
- **不在看到结果之后挑扰动。**扰动必须事先定义。

### 第一步：判断你手上的指标是不是"稳定条件下读的"

| 问 | 答"是"意味着 |
|---|---|
| 这个指标是在工具正常可用的条件下测的吗？ | 它测不到切换后的任何事 |
| 过去一年里，工具（模型、供应商、系统、接口）变过吗？ | 变化频率越高，这套方法越值 |
| 工具变的那几天，有没有留下任何记录？ | 有就是现成的自然实验，别浪费 |
| 如果明天换一家供应商，你说得出"哪些判断会没人接"吗？ | 说不出，就是母文说的"没有定位的依赖" |

第一问为"是"且第四问为"说不出"，这套方法对你有用。

### 第二步：设计四类扰动

母文规定了四类，各有各的用处和各的坑：

**撤除**——在限定时间内停掉原工具，但**保留完成任务所必需、且不是研究对象的辅助技术**。优点：最直接地看出哪些步骤只存在于原系统里。缺点：最容易把无障碍差异和资源差异混进来。

**替换**——换成一个**能力大致相当、界面或交互逻辑不同**的工具，任务、时间、可用资料都不变。这是四类里最有价值的一类，因为它不要求"纯人类独立"，却能测出可迁移性。母文的多条分离线都押在这一类上。

**错误暴露**——在安全的模拟环境里预先植入可识别的错误、遗漏或冲突证据，看参与者能不能发现、定位、修复。注意：**发现错误不等于修得了错误。**

**结构迁移**——给一个表面材料不同、但关系结构相同的新任务，看原来那套问题分解和验证顺序还能不能重建。

**设计纪律三条**：其一，参与者必须已经熟悉原配置（否则测到的是初学期波动，不是脆弱）；其二，扰动事先定义、不许事后挑；其三，能力等值的依据要写下来——"换了个更差的工具"测出来的不是可逆性。

### 第三步：算切换损失 L

定义固定：**稳定配置下的标准化表现，减去扰动配置下的标准化表现。**正值是损失，负值是切换后反而变好。

两个必须做对的地方：

**标准化必须用同期、同难度层级的对照或锚题。**如果扰动前后的任务难度不同，直接相减会把题目难度差当成切换损失。母文自己的做法是用同一轮的对照组分别标准化两个阶段。更严格的研究应该用等值题、锚题或项目反应模型。

**四类扰动不要过早压成一个数。**母文要求保留一个四维剖面（撤除、替换、错误、迁移）。如果量纲不同，**先在各类内部标准化，再取中位数**——并且写死一条禁令：**不许把一次严重的安全错误和若干秒的时间差直接相加。**

### 第四步：判断这是"损失"还是"极化"——四条判据同时成立

这是全篇最该照抄的一节。母文给了四条，**必须同时成立**：

1. **先在稳定产出上匹配**：主分析样本限定在均值附近的窄带（默认中位数 ±0.25 个标准差）或用倾向／精确匹配。不匹配就比，比出来的是"本来就有的差距"。
2. **两成分模型显著优于一成分**：ΔBIC ≥ 10。
3. **两个成分的均值至少相距 0.5 个该样本标准差。**
4. **每个成分至少占 15% 的样本，并且在四类扰动中的至少两类上重复出现。**

母文还写死了一句反面清单：**均值差、方差增加、长尾、分位数扩大、单次双峰，都不足以单独判定极化。**

第四条里"至少两类扰动"这一款，是母文被自己的数据逼出来的——它原本可以把明显的右移写成"隐藏的两极化"，真实复算不允许它这么写。**单一次撤除实验，最多证明脆弱，不能证明两极结构。**

### 第五步：清点手册必须在分析之前写死

母文列了一份必须提前写明的清单，照抄：

- 匹配窗口怎么设；
- 什么算一次有效恢复；
- 任务完成、验证、修复分别怎么编码；
- 超时与放弃怎么处理；
- 哪些辅助工具始终保留；
- 工具能力等值的依据是什么；
- 用哪个信息准则比较一成分与二成分；
- 成分权重与间距的阈值；
- 跨扰动的复制条件。

然后是最狠的一句，直接引用其意：**正文、证伪条款和预测里必须用同一套阈值。任何在结果出来之后把匹配窗口从 ±0.25 改成 ±0.5、把 ΔBIC 门槛从 10 改成 2 的做法，都会把一个可裁决的读数退化成叙事。**

这一句可以贴在墙上。它适用范围远远超出这篇文章。

### 第六步：记过程，不只记分数

母文说，光有分数会把三种完全不同的情况混成同一个"低分"：

- **知道缺了什么，但做得慢**；
- **不知道缺了什么**；
- **知道缺口在哪，但没有权限去补。**

第三种是制度问题，把它记到个人头上是错的。所以要记一张最小过程表：

| 过程字段 | 记什么 |
|---|---|
| 目标与约束 | 参与者能不能独立写出来 |
| 待验证主张 | 能不能列出哪些说法需要核 |
| 缺失识别 | 有没有意识到"原工具给过我而我没保存"的信息 |
| 首次发现错误 | 在第几分钟 |
| 首次换路 | 在第几分钟 |
| 恢复构成 | 最终答案里，哪些来自新系统／旧记录／同事／自己重建 |
| 未恢复部分 | 谁负责 |

最后一行最容易被跳过，也最重要——它是把"个人能力问题"和"没人负责"分开的唯一办法。

### 走完一遍：一次供应商迁移演练

某团队用某家的工具做客户资料整理，效率指标半年来一路走高。

- **第一步定位**：指标全部在工具可用时读的；过去一年换过一次版本，没留记录；"换一家会有哪些判断没人接"——说不出。进入流程。
- **第二步设计扰动**：真实业务不停机，所以不用撤除。改用**替换**——在影子环境里换一家能力相当的工具，任务、时限、资料都不变；再加一次**错误暴露**——在沙盒案例里预埋三处可识别的事实错误。两类扰动，正好够第四步第四条的复制要求。
- **第三步算 L**：同一批案例，两套环境各跑一遍，用同期对照案例分别标准化质量分与用时，相减。质量与时间**分开报**，不加总。
- **第四步判定**：先在原环境的产出上做窄带匹配（中位数 ±0.25 SD），落在窄带里的有 11 个人。样本太小，**不做混合模型，不谈极化**——只报切换损失的分布与四分位。这是正确处置：母文的判据在小样本上跑不了，硬跑就是把叙事当读数。
- **第六步过程表**：三个人在替换环境里第一时间写得出目标与约束，五个人写不出；两个人指得出"原工具替我做了字段归并"，其余指不出。错误暴露那一轮，发现三处的有 2 人，发现一处的有 6 人，而**能说清错在哪一层的只有 1 人**。
- **结论怎么用**：不给任何人打分。落到流程位置上——"字段归并"这一步没有第二条路，也没有导出格式；"事实核验"这一步没有责任人。处置是两条：把字段归并规则写成与厂商无关的文档；给核验环节指定责任人和一份可核清单。
- **一年后的读数**：下次真换供应商时，恢复用了几天。这个数比任何演练分数都硬。

这个例子里最值钱的是那句"样本太小就不做混合模型"。**放弃一个漂亮结论，比凑出一个漂亮结论有用得多**——这正是母文自己做过的事。

### 把母文的可裁决预测，变成你的验收项

母文按行业给了一批可裁决预测。它们的形状都一样——**某个现成的省事指标，解释力弱于某个麻烦的过程指标**。直接拿来当验收项即可：

| 场合 | 别只看 | 要看 |
|---|---|---|
| 软件 | 代码采纳率、生成行数 | 接受之前有没有写测试；关键逻辑有没有手改；设计决策有没有留下来 |
| 法律与公文 | 文本评分、交付速度 | **可核验主张的来源覆盖率**；不确定项有没有单列 |
| 科研与分析 | 代码是否开放 | 变量定义、排除标准、**失败的模型**、阈值理由有没有记录 |
| 组织 | 生产率提升幅度 | 与厂商无关的任务分类、数据接口能否导出、人工责任链、有没有备份供应商 |
| 教学 | 作业分数 | 学生能不能写出目标、验证关键步骤、说明改动理由 |
| 客服 | 结案量、建议采纳率 | 建议与结果的反馈是否可见；员工有没有修改权 |

每一行右栏都比左栏麻烦。母文的判断是：**左栏在工具稳定时足够，在工具会变时不够。**它也给了自己的败局——比如"如果来源链完备却仍然无助于迁移，那本文对验证结构的强调就过强了"。

### 读数与代价

- **代价一：影子环境是真花钱的。**替换扰动要维护第二套系统。这笔钱要不要花，取决于工具的变化频率和失败后果，不取决于口号。
- **代价二：过程记录会拖慢演练。**七个字段每人每次都要填。可以先只填三个（目标与约束、缺失识别、未恢复部分负责人）。
- **代价三：多数团队的样本量撑不起极化判据。**这不是失败，报切换损失的分布就够用了。
- **一条读数**：如果所有人的切换损失都差不多且都很大，那是**普遍脆弱**，不是两极——处置是补流程，不是找人。母文专门写了这一条：整体均值大幅下降不必然意味着极化。

### 三种典型事故

**事故一：把一次撤除测试的结果写成"两极分化"。**母文用自己的数据示范了这个诱惑有多大，也示范了正确的处置：把判据调严，不是把结论写松。

**事故二：把切换损失大的那一组读成"这个工具伤害更大"。**母文的复算里，带护栏那一组损失最大，恰恰因为它在稳定阶段的增益最高。**这个指标算的是增益保留比例，不是净伤害。**任何可通约的读数，都必须跟价值判断分开。

**事故三：为了"锻炼能力"而在真实业务里制造中断。**这是本方法最危险的误用，直接违反安全边界。

### 停手线

- 一旦有人提出把切换损失写进绩效考核，停手。
- 一旦扰动要求拿走某人的辅助技术，停手，改用替换或模拟。
- 一旦发现自己在结果出来之后调阈值，停手，把原阈值和原结论一起写出来。

### 什么时候该怀疑这套理论本身

母文给了十条分离线，这里挑三条你能自己执行的：

1. **控制了"工具替你省掉了多少认知步骤"这个量之后，重建过程与恢复表现不再相关**——那么"认知卸载"这个更简单的概念就够了，本方法没有独立内容。
2. **只有在工具出错时才有效应，而单纯替换（能力相当、只是交互不同）没有任何额外效应**——那么"自动化偏误"更简约。
3. **所有切换损失都能由接入、素养量表和当前产出解释掉**——那么它可以被数字鸿沟吸收。

母文自己写下了最后那句话：如果未来研究反复找不到"产出相同、技能没降、接入与素养匹配、工具没出错，但替换后出现两种恢复轨迹"这种案例，**这个概念就应该被相邻理论吸收掉。**

### 四种常见反对

**「这不就是说别太依赖工具吗？」**不是。母文明确写着不能把所有步骤都强制留给人——如果工具在某个环节远比人可靠，硬要人重做只会增加错误和负担。目标是保留**最小可恢复结构**。

**「我们从来没换过供应商，测这个干嘛？」**那就先不测。母文说得很清楚：低风险、规则稳定的任务可以接受较低的可逆性。这套方法的价值随变化频率上升。

**「测出来低可逆，然后呢？」**然后落到流程位置上：哪些环节没有第二条路，哪些证据导不出来，哪些职责在工具失效时没人接。这三句话都是可以直接改的。

**「过程记录太主观了。」**过程表里的字段大多是可核对的事实（第几分钟发现、最终答案的哪些部分来自哪里），不是评价。真正主观的是"他是不是真的懂"，那一栏本方法里没有。

### 三个岗位怎么跑

- **做技术架构的**：重点是"系统提示、工具调用、数据接口能不能导出"。这三样导不出来，可逆性在个人层面再高也没用。
- **做教学的**：不要简单恢复全面禁用工具的考试。更有效的是安排一次条件切换——同一主题先在熟悉工具里做完，再换一个工具、或加一条错误解释、或给一个同构任务，评价学生能不能写出目标、验证关键步骤、说明改动理由。
- **带团队的**：把演练结果**只**落到流程位置，绝不落到人名。这一条如果守不住，第二次演练所有人都会开始表演。

### 一个人的自查版

挑一件你每周都借助工具完成的事，问三句：

1. 如果换一个界面完全不同的同类工具，我今天这件事要多花多久？
2. 我说得出这个工具替我做掉了哪一步吗？
3. 我最后交出去的东西里，有哪些部分是可以带走的（来源、算法、用例），哪些只是流畅的成品？

第三问答不出来，那就是母文说的"没有定位的依赖"。

### 两周最小实验

第一天：选一件常规任务，写下你对"换个工具会多花多少时间"的预测，封存。

第二到第十三天：照常工作，但每完成一次，多花两分钟记三个字段——目标与约束、这次工具替我做掉的那一步、我保留下来的可带走的东西。

第十四天：用另一个同类工具做一次同样的任务，计时，然后打开封存的预测。**你预测得越不准，说明你此前越不知道那个工具替你做了什么——这本身就是一个读数。**

### 本文用到的母文词，各在哪一步

| 母文词 | 用在第几步 |
|---|---|
| 耦合可逆性（配置的关系属性，不是人的属性） | 贯穿；尤其安全边界"不做个人 KPI" |
| 四类扰动（撤除／替换／错误暴露／结构迁移） | 第二步 |
| 切换损失 L 与同期标准化 | 第三步 |
| 四维可逆性剖面、禁止跨量纲相加 | 第三步末 |
| 极化四判据（匹配窗／ΔBIC≥10／0.5 SD／15% 且跨两类扰动） | 第四步 |
| 清点手册、禁止事后改阈值 | 第五步 |
| 过程字段与三种相同低分 | 第六步 |
