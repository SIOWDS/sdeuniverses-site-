01这一篇解决什么问题，谁该用它

母文的结论对个人有一个直接后果：你最需要盘查的，恰恰是你最不觉得需要盘查的地方。但“盘查自己”这句话本身没有操作性——它太容易变成一次情绪化的自我怀疑，或者一次开完就忘的务虚会。这一篇的任务是把它变成一件有输入、有输出、有判据、有截止时间的具体工作。适用条件有三条，缺一条就不必做：

  • 你手上有一套成熟且好用的判断办法（用了三年以上，且带过别人）。
  • 这套办法所面对的对象，在过去若干年里发生过结构性变动（政策、技术、人口、渠道、病种构成、学生来源，任一即可）。
  • 你的领域里很少出现公开的失败记录——大家的产出都还算顺利。

第三条最要紧。如果失败记录很多，你面对的是普通的能力问题，直接补课即可。只有在“一切顺利”的地方，才需要查账。

02第一步：划定支架，说清楚「当年它靠什么成立」

先做一件比想象中难的事：写下你那套办法在成立之初，所依赖的现实条件是什么。不是写它的原理，是写它的地基。地图靠的不是印刷技术，是“这座城市当时长这样”。做法：把办法拆成三到五条核心判断，每条后面强制补一句“这条之所以准，是因为当时＿＿”。

  • 例：教研组的“课堂抬头率高＝听懂了”——之所以准，是因为当时学生获取讲解的唯一渠道是课堂。
  • 例：科室的“这个指标不高就先观察”——之所以准，是因为当时该指标的检测时机集中在发病中期。
  • 例：审稿的“综述做得全＝作者读得多”——之所以准，是因为当时检索工具还筛不动。

输出物：一张两列表，左列“核心判断”，右列“当年的支撑条件”。验收标准：右列每一格都能写出具体的年代、制度或技术条件；写不出来的，说明这条判断你其实从没审查过，先标一个问号。

03第二步：盘点你最顺手的那几个名字

逆循环的运转靠的是名字。所以第二步是把你的“名字库”摊在桌面上。做法：抽取你近半年的工作记录（会诊记录、评课记录、审稿意见、复盘纪要、田野笔记均可），统计出现频率最高的结论性名字——不是描述词，是那种一说出来事情就结束了的词。典型的名字长这样：态度问题、不典型、个例、执行不到位、意识不够、样本特殊、暂时的、还在磨合、疫情影响、市场波动。把出现次数排前八的名字列出来，每个后面回答两个问题：

  • 说出这个名字之后，还有没有下一个动作？（没有 → 高风险）
  • 这个名字是不是任何情况都能套？（是 → 高风险）

判据：两问都命中高风险的名字，就是你的候选钝感通道。一个健康的名字应该带着下一步动作（“缺铁 → 查铁四项”）；一个钝感名字则自带终止符（“体质问题 → 无”）。

04第三步：抓复发别扭，而不是抓错误

这是全套流程里最关键、也最容易被跳过的一步。错误是找不到的——逆循环的特征就是不产生公开的错误。可以找到的是复发别扭：反复出现、每次都被顺手解释掉、从来没进入正式记录的那种小磕绊。它的四个识别特征：

  • 反复：半年内出现三次以上。
  • 同型：每次的场景不同，但让你不舒服的那一点是同一个。
  • 被吸收：每次都有一句现成的话把它解释过去，而且解释完你就不再想它。
  • 不留痕：从来没写进正式文件，只出现在私下的抱怨、笔记边角、群里的一句吐槽。

采集办法：让每个人各自翻自己的私人记录（不是共享文档），把这类“当时觉得有点怪、后来没再管”的片段抄下来，匿名汇总。关键纪律：这一步只许记录，不许命名。一旦有人说“这不就是XX嘛”，那句话本身就是钝感在现场发作。主持人要把它拦下来，记成“待定 A、待定 B”。

05第四步：算绕路成本，把债务变成数字

到这一步，你手上有一堆“待定”。它们看起来都不重要——这正是它们能存活多年的原因。所以必须给它们标价。对每一条待定，回答三个量化问题：

  • 单次成本：每次遇到它，多花了多少时间、多做了几次返工、多请了几次会诊、多改了几稿？给一个粗略数字即可。
  • 频次：一年发生多少次？
  • 累计：两者相乘。

这一乘往往非常刺眼。一件“就多花二十分钟”的小事，一年六十次，就是二十个小时；一条“再确认一下”的流程，一年两百次，可能是团队最大的隐性支出。这就是解释债务的具体形态：它从来不以一笔大额出现，只以两万笔小额出现。输出物：待定清单按累计成本排序。排在前三的，就是你这一年真正要查的东西——不是因为它们最可疑，而是因为它们最贵。

06第五步：开一个不许命名的窗口

最后一步是给排名第一的那条待定，安排一次禁止命名的观察。规格如下：

  • 时长：一次完整的现场，不少于两小时；或连续五个同类事件。
  • 人数：至少两人，各自独立记录，事后再对。
  • 唯一纪律：全程只许写“发生了什么”，不许写“这是什么”。禁止使用第二步列出的那八个名字。
  • 产出：两份独立的白描记录 + 一份差异清单。

收口判据（三选一）：

  • 两份记录高度一致，且都能被旧名字完整覆盖 → 这条待定是假警报，销案。
  • 两份记录一致，但旧名字只能盖住一部分，剩下的部分说不出来 → 命中。这里需要一个新名字，进入正式研究/改进流程。
  • 两份记录彼此矛盾 → 观察方法有问题，重做一次，换现场。

注意：命中之后不要急着起名。新名字起早了，会立刻变成新的钝感通道。先用“暂称一”这样的编号，让它带着不适感存活至少一个季度。

07三张判据表（可直接抄用）

表一 · 名字健康度

  • 健康：带下一步动作 / 只适用于特定条件 / 说出来之后有人会追问。
  • 可疑：带下一步动作但从没执行过 / 适用范围在悄悄扩大。
  • 钝感：不带动作 / 万能 / 说出来之后全场点头结束。

表二 · 别扭成熟度

  • 一级：偶发，一次。→ 记下，不处理。
  • 二级：半年内三次以上，同型。→ 进待定清单。
  • 三级：三次以上，且已经形成一句固定的解释话术。→ 优先级最高，因为话术的存在说明它已经被吸收很久了。

表三 · 支架松动度

  • 未动：支撑条件与当年一致。
  • 半松：条件变了，但你的判断仍然全对。→ 可疑，因为不该这么顺。
  • 已断：条件变了，判断的准确率却“感觉”没下降。→ 最高危信号。准确率不下降往往不是因为判断准，而是因为评价标准也是你自己定的。

08四种失败模式与拆解办法

失败一：变成批斗会。盘查一开始就指向某个人的水平问题，于是所有人都开始防守，别扭一条也交不上来。拆解：全程匿名收集；主持人开场先交自己的三条；明确宣布“这次不查对错，只查绕路”。失败二：一步到位起了新名字。团队非常兴奋地发明了一个词，写进纪要，从此这个词成了新的万能解释。拆解：新名字必须先经过一个季度的编号期；期满后由没参加过盘查的人来判断它是否真的比旧名字多切开了东西。失败三：只查别人不查自己那套。盘查对象选成了“下面执行得不好”，绕开了自己最拿手的判断办法。拆解：第一步的两列表必须由资历最深的人先做，并且当众念一遍右列。失败四：查完就归档。报告写得很漂亮，第二年一切照旧。拆解：把第五步的“禁止命名观察”写进例行日程（每季度一次，两小时），并指定与产出考核脱钩——这项工作一旦被计入绩效，就会立刻产出漂亮的假别扭。

09两个跨行业演练

演练一 · 医院科室。第一步：写下“腹痛先看这三项”的当年支撑条件（当年该人群的病种构成、当年的影像可及性）。第二步：盘点结论性名字，发现“功能性”三个月出现四十一次，且说完没有下一步。第三步：抓到复发别扭——某类患者复诊时总说“上次那个药吃了没感觉”，每次都被“依从性差”吸收。第四步：算成本，每次多一轮复诊，一年约七十次。第五步：连续观察五例，禁止使用“功能性”与“依从性差”，两名医生独立记录。结果：白描里反复出现同一个此前没被记录的时间点。命中。演练二 · 中学教研组。第一步：写下“作业正确率＝掌握程度”的当年条件（当年作业只能独立完成）。第二步：名字库里“粗心”高居第一，说完无动作，万能。第三步：别扭是“考得好的学生讲不出思路”，每次被“表达能力差”吸收。第四步：成本＝每次讲评多花的重复讲解时间。第五步：抽五名学生做禁止命名的口述观察。若白描显示他们的解题路径与所教路径系统性不同，则旧判断的支架已断。

10一页纸自检卡

把下面九行抄在一张纸上，季度例会时对着念一遍即可，不需要任何工具。

  • 一、我这套办法当年靠什么成立？那些条件今天还在吗？
  • 二、我最近半年说得最多的三个结论性名字是什么？
  • 三、这三个名字后面，有没有下一个动作？
  • 四、有没有哪种小别扭，我半年里遇到了三次以上、每次都用同一句话解释过去？
  • 五、那句解释话术，我是什么时候开始用的？
  • 六、这条别扭一年让我多花多少时间？（写一个数字，不许写“不好说”）
  • 七、如果不许我用那三个名字，我还能不能描述现场发生了什么？
  • 八、我最近一次说“我不知道那是什么”，是什么时候？
  • 九、我这一行里，有没有哪件事顺利得有点可疑？

第七条和第九条是硬核。第七条答不上来，说明名字已经替代了观察；第九条如果想不起任何一件事，请把整套流程从第一步重跑一遍——想不起来本身就是最强的信号。

11什么时候应该停手

这套流程有明确的边界，越界就会伤到正常工作。不要对新手用。没有成熟判断办法的人不存在逆循环问题，他们需要的是老老实实学那套办法。对新手做钝感盘查，只会摧毁他建立标准的过程。不要在危机期用。逆循环盘查需要一个不出事的安静期。正在救火的时候要的是果断命名、快速处置，此时禁止命名等于自废武功。不要连续做超过一个季度。长期悬置命名会让团队失去行动力。合理的节奏是：一个季度盘一次，其余时间照常用你那套熟练办法——它绝大部分时候仍然是对的，这一点不能因为盘查而被忘记。最后一条边界最重要：这套流程查得出“哪里有债”，查不出“新东西是什么”。它只负责把你带到那个你一直绕开的地方，然后停下。之后要做的事——长时间待在那里，忍受说不出名字的难受——不属于流程，属于人。

12这套流程与既有做法的分工

很多组织已经有一些看起来相近的机制，先说清楚它们各管什么，免得重复劳动或互相顶撞。

  • 复盘 / 事故分析：处理的是已经出错的事。逆循环自检处理的是没出错但一直多花钱的事。两者输入不同，不能互相替代——复盘会里永远不会自动冒出本流程要找的东西，因为它们从未被登记为事故。
  • 满意度调查 / 意见征集：收的是别人对你的不满。本流程收的是你自己对现场的不适，而且专收那些被你自己解释掉的。方向相反。
  • 同行评议 / 交叉检查：查的是你有没有按规矩做对。本流程查的是那套规矩本身当年靠什么成立。层级不同。
  • 创新提案 / 新技术调研：往前看，找新东西。本流程往后看，查旧账。母文的核心判断正是：后者才是前者真正的入口。

一句话分工：出错了用复盘，没出错但总觉得别扭，用这一套。

13主持人的六条现场纪律

这套流程失败与否，八成取决于主持人在现场拦不拦得住那几句话。

  • 不许接“这不就是”。任何以“这不就是……嘛”开头的发言，一律记为“待定”，不许写进纪要的结论栏。
  • 不许比惨，也不许表功。发言只描述发生了什么，不评价谁做得好或差。
  • 不许当场归因。“因为人手不够”“因为上面要求”这类归因全部推迟到第四步之后。
  • 不许用统计口径替代白描。“这类情况占比不高”不是对现场的描述。
  • 不许让最资深的人最后发言。必须让他第一个交自己的三条别扭，否则全场都会等着对齐他的口径。
  • 不许延长会议。两小时到点必停。这套东西越拖越像务虚，短促才有压强。

14记录模板（照抄即可）

别扭记录卡（每条一张，匿名）

  • 时间与场景：＿＿
  • 当时发生了什么（只写动作与话，不写判断）：＿＿
  • 我当时心里那句一闪而过的话：＿＿
  • 我后来是怎么解释过去的（原话）：＿＿
  • 这半年这种事大概发生过几次：＿＿
  • 每次大概多花：＿＿分钟／次返工／次沟通

观察白描页（第五步专用，两人各一份）

  • 现场编号、时长、在场人：＿＿
  • 逐条动作与原话（不少于二十条）：＿＿
  • 我想用却被禁止使用的名字（诚实写下）：＿＿
  • 我说不出名字的那部分是什么样子（尽量描述，允许语无伦次）：＿＿

最后一栏最有价值。能写满最后一栏的记录，才是这次盘查真正的产出；其余都是过程材料。

15收尾：把结果交给谁

盘查结束后最容易发生的事，是一份报告在抽屉里躺一年。所以收尾必须指定去向。

  • 销案的待定：写一行原因，归档，明年不再重复讨论（避免每年重开同一个话题）。
  • 命中的待定：交给一个具体的人，给一个季度的编号期，期满时做一次十五分钟的口头汇报——只汇报“这个季度里它又出现了几次、每次长什么样”，不许汇报“我认为它是什么”。
  • 支架已断的核心判断：这是最重的一类。处理方式不是废除它，而是给它加一条使用边界——写清楚“在什么条件下它仍然可靠”。废除一条老判断的代价通常远大于给它划边界。
  • 整个流程本身：每年做一次元检查，问一个问题——本流程有没有开始产出漂亮的、可预期的、每次都差不多的结论？如果有，它自己已经进入逆循环，需要换主持人、换记录格式、换场地。

16为什么“多绕二十分钟”从来不会被记账

还有一个问题值得单独回答：既然绕路是可测量的，为什么它可以攒十几年都没人算？因为没有任何一个岗位负责记这笔账。出错有人管：出了事故要写报告，写错了要改，漏诊了要复核。整个系统对“错”是有接口的。但“没出错，只是多花了点力气”这件事，在所有报表里都不存在对应的字段。它落在两张表的缝里：产出表说你完成了，成本表说你没超支。更麻烦的是，绕路的时间往往被算成了别的东西的成绩。多花的二十分钟被记成“认真负责”；多做的一次沟通被记成“服务态度好”；多改的三稿被记成“精益求精”。这笔债不但没被记账，还被记成了资产。所以第四步那个“给一个数字”的要求，看着粗糙，实际上是整套流程里唯一一次让这笔债现形的机会。答“不好说”就等于让它继续隐身。哪怕数字是拍脑袋估的，只要它被写下来、被乘以频次、被排进一张有序清单，性质就变了。

17三个可以立刻做的小动作

如果暂时组织不起一场完整的盘查，下面三件事可以今天就做，每件不超过十分钟。第一，翻一次自己的私人记录。打开你最近半年的笔记、备忘录或聊天记录，搜索“有意思的是”“奇怪的是”“不知道为什么”这几个词。这些词是别扭留下的原始收据。把命中的条目抄到一张纸上，什么也不做，只是放着。第二，给自己的口头禅计一次数。下一次开会，让一个人帮你数：你说了几次“这就是典型的……”。数字本身就够说明问题。第三，做一次十分钟的白描。随便挑一个你天天见的场景，用十分钟把它写下来，禁止使用任何你的行话。写不下去的地方就是你的名字已经长进眼睛里的地方——那个卡壳的位置，比任何一份报告都准确。

18一句话收束

这套流程从头到尾只在做一件事：把“顺利”重新变回一个需要解释的现象。在一个成熟的领域里，顺利被默认为好消息，因此不需要解释。母文的判断把这个默认反转过来：在支架已经变动的场合，顺利首先是一个需要被解释的现象——它可能意味着你真的很强，也可能意味着你的名字库把所有意外都提前吸收了。两种可能长得一模一样，唯一能把它们分开的办法，就是关掉名字，去现场看一次。
