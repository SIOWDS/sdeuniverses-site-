兑位审计：查清楚你的力气落在关口的哪一侧

一套六步流程，把「验收单上写的那一项」找出来、定位、并搬到第一处可判定的位置

这篇要交付什么

《离峰》给出的不是一句评论，是一个可以动手查的东西：一个领域用来判断成败的那个物件，落在不可返工关口的哪一侧。落在前面，每一轮投入改写下一轮的起点；落在后面，每一轮投入只改变这一批对象的结局。

本文把它落成一套六步流程。它不需要新数据，只需要两样本来就存在的文书：你们的验收标准，和十年前的验收标准。适用对象是任何分阶段推进、且存在不可逆节点的工作——产品研发、教学、工程、公共项目、内部流程治理都可以。

先守住边界，这一节不能跳

一，这套流程不能用在个人身上。 它读的是一个领域、一个团队、一条产线的位置，不是某个人的能力或品格。把它变成对个人的评价，是最常见也最有害的用错方式。

二，涉及医疗的场景，它不构成任何临床判断。 说一个领域的着力点落在关口之后，不等于说某位患者接受的治疗是徒劳的，也不等于说这样的治疗不值得做。治疗决定取决于当事人的处境、意愿与医生的判断。

三，它不构成对任何筛查或早期干预政策的支持或反对。 把结算物件搬到关口之前，在群体层面产生收益的同时，在个体层面会产生真实的伤害——被发现并被处理的、那些永远不会造成危害的病变，是真实的过度治疗。《离峰》第十三节明确承认它给不出最优位置在哪里。

四，观察窗不短于十年。 判据搬动到走法改变需要三到七年，到组织形式改变需要五到十年。用五年以内的数据判定，会把正在发生的变化读成没有发生。

这套流程里的六个词

动手之前，先把《离峰》的六个词各钉在流程的一步上，避免用着用着变成别的东西。

词 在这套流程里指什么 在第几步用
结算物件 你们的验收标准里，被用来判断「这次算不算成」的那个实体 第二步
不可返工关口 过去之后前面的工作只能被替换、不能被修改的那个节点 第一步
兑位 同一笔力气落在不同位置上，买回来的「下一轮入口」不一样多 第三步
离峰 着力点被自己最严格的正式判据钉在低兑位一侧，而形式审查全过 第五步
创新方向的位置依赖 你们往哪儿走，取决于力气落在轨迹的哪一段，不只取决于想解决什么 第六步
癌症死亡率的长期分化 母文的原始对象：同期同制度下，有的癌种降了七成，有的五十年没动 全程作参照

第一步：画出这条轨迹，把关口标出来

在一张纸上按时间顺序列出这项工作从开始到交付的全部阶段，一行一个。然后逐行问一句：过了这一行，前面做的东西还能不能改，只能不能被整个替换掉？

只要答案是「只能替换」，这一行就是一道关口。装修里是封墙与贴砖；晶圆上是离子注入退火与封装；专利里是申请日与公开日；临床上是可完整切除、是黏膜下浸润这一类由处理方式的可逆性定义的位置。

三条纪律：

  • 关口由可逆性定义，不由难度定义，也不由分期或职级定义。结直肠癌的关口不是分期系统里的任何一道线，是黏膜下浸润这一处——过了它，摘除不再是一次完整的处理。
  • 一条轨迹可以有多道关口，全部标出来，不要只标最显眼的那一道。
  • 找不出任何关口，就在这里停手，不要往下做。没有关口的工作（连续可调、随时可回滚），位置效应会被摊平，投入量重新占主导。

第二步：把结算物件找出来，去文书里找，不要问人

结算物件不是问出来的，是抄出来的。去下面这几类文书里找，抄下原话：

  • 验收单、结项报告的评分表
  • 立项书里「主要指标」那一栏
  • 绩效考核表里权重最高的那一项
  • 对外通报时被引用的那个数字

抄完之后追问一句：这一栏所指的实体，到底是什么东西？ 不是指标名，是指标背后那个可以被指着的实体。「总生存」指的是这个人；「转录本对数下降」指的是血里的一段序列；「期末成绩」指的是那张卷子；「事故起数」指的是已经发生的那件事。

一个领域通常只有一个结算物件——就是那个在争议时被搬出来终结争论的东西。写不下第二个，说明找对了。

第三步：判定落在哪一侧

把第二步抄下的实体，摆到第一步画的轨迹上，标出它出现在第几行，再看它在关口的哪一侧。

输出只有两种形态，两种都要写：二值（前／后）加指名（挨着哪一道关口）。

不要试图给它打分或排序。《离峰》在这里做过一次被迫的收缩，值得直接抄走：兑位的峰值在哪里，事前算不出来，只能事后指认，所以读数最终定成了「落在哪一侧」加上关口的名字，而不是一个连续量。这意味着这套流程回答不了「离峰值有多远」，只回答「在不在同一侧」。

第四步：查十年前后是不是同一个物件

这一步是全套流程里最便宜、也最硬的一步。

找出十年前的同类文书（旧版验收单、旧版考核表、旧的立项模板），比对第二步那一栏：主要判据所指的那个实体，与今天是不是同一个。

  • 换过：记下换了几轮、每一轮换成了什么、发生在哪一年。
  • 没换：直接记「未更换」，并记下这十年间该栏位的措辞改动——措辞改动不算更换。胶质母细胞瘤的影像评价标准修订过，改的是怎么读，不是读哪一个，因此记作未更换。

三条不算更换，逐条写死，防止自己糊弄自己：

  1. 只在综述、倡议、内部讨论里出现过新物件，而没有进入正式文书的，不算。
  2. 只在个别分支、个别小组内部使用的，不算。
  3. 改的是读法、口径、统计方式而所指实体未变的，不算。

第五步：填四格表，看自己在不在第三格

两根轴。横轴：着力点在关口之前还是之后。纵轴：关口的位置有没有被写进正式判据（指南、验收标准、终点清单、评分表）。

着力点在关口之前 着力点在关口之后
已写进正式判据 第一格：搬过去了，而且写进了文书 第三格：钉死在后面，且由最严格的判据钉死
未写进正式判据 第二格：实际搬过去了，账本上没有这一栏 第四格：既没搬动，也没有正式判据

要找的是第三格。它的辨认特征不是「做得差」，恰恰相反：

  • 它的终点最硬，不容争议
  • 它的设计最严
  • 它最容易通过评审
  • 它的对象最容易招募或获取
  • 它每年产出大量真实信号，而信号的读法只有一种：换一个方案再试

如果你查出来的那一格「一眼可见地坏」——该做的没做、该记的没记——说明纵轴选错了。第三格的每一项形式指标都优于第一格：第一格的判据更软、周期更长、审批更麻烦、更难说服人。按形式审查排序，第三格永远排在第一格前面。

第六步：搬到第一处可判定位置，不是最早位置

确认落在第三格之后，唯一的动作是：在关口之前找一个可判定的物件，把它写进正式文书。

「可判定」有三条硬要求，缺一条就不要动：

  1. 它是一个可以被指着的实体，不是一个形容词。
  2. 它在关口之前就能读出来，不需要等到关口之后的结果才能反推。
  3. 它的读数在不同读者之间是稳的，或者至少有一套可写下的判读规则。

三条都满足的物件通常只有一两个，选那个离关口最近的。位置依赖在这一步变成一个具体动作：不问「哪个指标更重要」，只问「哪个物件落在这道关口之前」。

不要搬到最早的位置。 半导体那一侧有一条反向的成本：量测越往前推，中间参数与最终结果的关联越弱，假阳性越多，为一个不存在的问题停线的代价越高。存在一个最优插入位置，逐条产线算，没有通用解。卵巢癌那一行从另一侧证实了同一件事——搬得更早而没跨过关口，不产生任何东西。

搬完之后必须做一件收尾：把新物件写进入组／立项／验收的条件里。只在报告里提到它，不算搬动。

读数 怎么采 代价

最后一项值得单独说：回写率是这套流程里唯一能在几年内看到结果的读数。《离峰》把最大的期待放在它身上，理由是数据现成、成本接近于零、无论结果如何都改变下一轮的起点。

一个从头到尾的算例

一家做工业设备的公司，客户验收总是拖，返工率高。管理层的判断是「测试投入不够」，连续两年加测试人手，返工率没动。

第一步，画轨迹：需求确认 → 方案设计 → 结构定型 → 开模 → 试制 → 整机测试 → 客户验收。逐行问「过了这一行前面还能不能改」，标出两道关口：开模（模具一开，结构改动等于重开模）与整机装配（装完之后单个部件的更换要拆解整机）。

第二步，抄文书：项目结项评分表里权重最高的一项是「整机测试一次通过率」，所指实体是已经装好的那台机器。

第三步，定位：那台机器出现在「整机测试」这一行，落在两道关口之后。二值：后。指名：整机装配之后。

第四步，比对十年前的结项模板：主要指标同样是整机测试一次通过率，措辞从「一次通过率」改成「一次通过率（含复测）」——按第四步的第三条，措辞改动不算更换。记：未更换，十年。

第五步，填表：这一项写在正式评分表里，落在关口之后 → 第三格。核对特征：整机测试的数据最硬（机器要么跑起来要么跑不起来）、争议最少、老板最认、每年产出大量失效报告，而报告的读法只有一种——改这一处、再测一次。全部对上。

第六步，找关口之前的第一处可判定物件。备选三个：需求确认阶段的「客户现场工况参数是否与设计输入一致」、方案设计阶段的「关键接口尺寸链是否闭环」、开模之前的「结构评审遗留问题是否清零」。按三条硬要求筛：第一个可指着（一份参数表）、开模前可读、判读规则可写——选它。写进立项条件：参数表未与客户现场核对签字，不进入开模。

一年之后看回写率：新立项里把这份参数表写进开模前置条件的比例，从零升到多少。升不上去，说明搬动没有回写，这一轮白做。

什么时候应该停，什么时候说明这套读法不对

四条停手线，任意一条命中就停：

  1. 第一步找不出任何关口——工作是连续可调的，位置效应被摊平。
  2. 第二步找出两个以上并列的结算物件，且争议时谁都不能终结争论——先解决判据不唯一的问题，再回来。
  3. 观察窗不足十年，或旧版文书已不可考。
  4. 有人打算把这个读数写进对个人的考核——立刻停，理由见下一节。

三条证伪条件，用来判这套读法本身对不对：

  1. 在把对象复杂度、有没有可及的前置阶段、有没有明确外因这三项配平之后，结算物件的位置与长期分化之间不再有关联——核心判断不成立。《离峰》为医学场景已指定四组配对：慢性髓性白血病与急性髓性白血病、宫颈癌与卵巢癌、霍奇金淋巴瘤与弥漫大B细胞淋巴瘤、结直肠癌与胰腺癌。
  2. 四格表在预测「此后十年起点是否移动」上没有区分力——那张表只是一个描述性分类。
  3. 物件更换之后三到七年，新立项引用它作为条件的比例不上升——关于「搬动会回写」的那一段不成立。

《离峰》还留了一个它自己解释不了的例子：黑色素瘤的结算物件近十五年没有搬到关口之前，而死亡率明显下降了。遇到同形的反例，如实记下来，不要替它圆。

三种最容易把它做坏的方式

第一种，把它变成考核指标。 一个读数一旦进入考核，最省事的达标方式是在文书上更换措辞而不改变实际着力点——这恰恰是《离峰》说的那种病相的更隐蔽形态。防法只有一条：更换结算物件的同时，必须能指出至少一处实际做法的改变（谁在哪一步多做了什么、少做了什么）。指不出来，就是换词。

第二种，把它读成「越早越好」，一路往前推。 结果是假阳性泛滥、为不存在的问题停线。第六步那三条硬要求就是拦这个的。

第三种，用它给人定性。 说一个领域落在第三格，不是说这个领域的人不够努力；一次失败，不是谁没扛住。《离峰》全篇避免把结局道德化的语言，这套流程照办。若已有机构据此做出不利于某个方向的资源安排，应当公开判定规则并提供复核通道。

与三类相邻做法的分工

与「测试左移」（博姆一九八一年那条成本曲线：缺陷越晚发现越贵）：左移讲的是同一个缺陷在不同时点被发现的成本，是一条成本函数；这里讲的是同一笔投入在不同位置买到的下一轮入口，是一条兑换函数。差别可判：左移主张越早越好，这里主张的是关口的哪一侧，而关口之前的最优点不一定是最早点。

与指标治理（古德哈特、坎贝尔）：那两条说的是指标被针对之后失效。这里处理的情形相反——指标完全没有失效，数据完全诚实，而学习仍然不发生。若你查到的是终点被系统性操纵（换终点、挑亚组、截断随访），那是指标治理的事，这套流程说不上话。

与复盘和事故调查：复盘处理的是「这一件事为什么没成」，产出是这一件事的归因；这套流程处理的是「我们的判据钉在哪一侧」，产出是下一批事的起点。两者不冲突，次序是先做这一套再做复盘——否则复盘会一遍遍地在关口之后归因，而报告格式里根本没有「位置选错了」这一栏。

五个实操疑问

问：验收单上权重最高的那一项，和大家实际在乎的那一项不是同一个，抄哪一个？ 抄验收单上的。实际在乎的那个若没有进入正式文书，它就没有约束力，也没有人为它花钱——这本身正是第五格里「未写进正式判据」那一列要记的东西。两个都记下来，标明哪个在文书里、哪个不在。

问：找出来的关口在别人手里（上游供应商、上级单位、客户），怎么办？ 照样标出来，并在第三步把侧别写成「后（关口不在我方）」。这一行不改变判定，只改变第六步能做什么：关口不在自己手里时，可搬动的物件只能在自己那一段轨迹的关口之前找，找不到就如实写「本层无可搬位置」，把它上报，不要在自己这一侧硬造一个。

问：新物件和旧物件并存，算不算搬动？ 并存不算完成，算在途。判定看一条：争议发生时，谁被搬出来终结争论。旧物件仍然是终结者，就记未更换。

问：第四步找不到十年前的旧版文书怎么办？ 退到能找到的最早一版，并把实际跨度写进结论（如「可比跨度六年」）。跨度不足十年的结论只能当线索，不能当判定——判据搬动到组织形式改变需要五到十年，短窗会把正在发生的循环读成没有发生。

问：查完发现在第一格，还需要做什么吗？ 需要。第一格只说明位置对，不说明维持得住。着力点已经在关口之前而进展仍然停滞的，问题多半在维护与退役一侧——谁来养这套判据、什么时候让它退休——那是另一件事，不在本流程范围内。

用法有一条纪律：这张表给的是起点，不是答案。关口必须在自己的流程图上按可逆性重新判一遍——照抄别人的关口，是这套流程最容易失效的地方。

最便宜的第一步

今天就能做完的，只有一件事：把你们现在的验收标准和十年前的那一版并排放在一起，找出权重最高的那一栏，看它所指的实体是不是同一个。

一小时之内会有答案。答案是「同一个」的话，接着做第一步，把关口画出来——十有八九，那个实体正躺在关口之后。
