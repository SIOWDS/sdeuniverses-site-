专著母题 · 德麦国际专著第 367 号

《从马力到 Token》

能源史是三号位被逐出的历史；Token 是第一种把三号位带回可计量之力里的力，所以同价不同值。

副题
力的属性纠缠文明史
作者
王德生著
分类
人工智能
题域
人工智能·能源与经济
题型
What

一、它推翻的默认看法

默认看法是把 token 当作又一种能源：算力像电，按量计价，账单上一个数、一个单价、一个总额，所以 token 与电同类，只是更新的计量单位。能源经济学认为使用者是中性的、能量是同质的，不许问谁在用、用来做什么；规模派认为谁来用都差不多，能力在模型里随规模长；提示派认为差别在会操作的手艺。三家各认一个号位，却在同一处签了字：「我的」那个位置没有格子。书的回答是：像，但不是一种力。两百年来力被做成「谁来都一样」，是靠一颗颗钉子钉出来的公共成立，稳定是真的，也是做出来的；token 的一号位钉得和电一样牢，但它的场在使用中回写，分布落给谁、美被谁选中，都改变它是哪一种力。

二、母题怎样立起来

起点是两张账单：杜长林抄了三十年电表，电表不问你熬药还是看电视；孙女杜禾的 token 账单格式相同，但其中有她离不开的那一小部分。账单上的数，说的是不是同一种力？

第一步，立力的九格：一号位客体性（对比、粒子、真，「那儿有」），二号位互动性（变化、波、善，「正在」），三号位主体性（分布、场、美，「我的」）。总式：号位侧重 × 维 × 界。

第二步，读四段史。人力畜力时三号位都在，但一号位立不起来，没有「一度人力」；马力、标准煤、原油的桶与基准价、电压与频率、插座与电表，把各格依次钉住，三号位无处安放，被逐出；计算力放开二号位，同样的运算跑不同程序是不同的力，但别人的三号位被封装进参数；token 让三号位回来。

第三步，证明回来的是三号位：以作者本人对 token 的一段话为头号案例，逐句拆进九格；再分别论场（语料、Skill、记忆三层，在使用里长出）、分布（落点）、美（被选中、被复用）。规模只长一号位，三号位只能养。

第四步，落到经济学：价格是一号位的读数，价值是三号位的纠缠，两层并列、互相回写，于是一价定律、需求曲线、边际成本定价、剩余与 GDP、杰文斯悖论五道题同时松动。

三、核心构念

  • 号位与九格：一号位对比·粒子·真，二号位变化·波·善，三号位分布·场·美；号位只说属性在哪里显出来，不说归谁所有。
  • 钉住与被逐出：标准化把某一格固定，使读数谁来都一样；被挤掉的格叫被逐出或缺。
  • 三号位之场：围着显影成形的那片联系；「懂 SDE」是一片场，不是一项功能。
  • 两本账与回写对称度：所得进土（慢），名字进号位（快）；一次共同经历后双方各被改写多少，分零写、单写、双写。
  • 地板 token 与纠缠 token：前者只在一号位被读，用完就走；后者落进场、会回写；账单同价，分开的是号位侧重。
  • 价格与价值：价格是一号位的读数，价值是九格的纠缠。
  • 出生证：范式的主体预设乘客体预设，加意义权重与不许问的问题；旧范式靠免检、改名、先验吸收三号位异象。

四、全书骨架

八编四十一章，另有十分钟读完这本书、前言、导读、导言、结语与六件附录。第一编立底盘与九格；第二至五编是力的四段史：三号位尚在，一号位立起而三号位被逐出的工业钉住史，二号位放开的计算力，三号位回来的 token；第六编讲旧范式如何消化三号位；第七编讲三号位之力的文明：地板与纠缠 token、一个 token 有几个价、大装置与发生器、养出自己那份力；第八编转刀向本书自己，给出预注册检验与自认最弱处。

五、关键案例与证据

  • 头号案例：作者本人关于 token 与「懂 SDE 的 Claude」的话，五块拆进九格；「最好」亮两次，一号位是比出来的排名，三号位是被选中的那一下。
  • 钉子年表：马力、标准煤与热值、原油基准价、电网电压与频率、插座与电表；千克原器 1889，以普朗克常数重新定义 2019。
  • 公平秤：把「谁来称」「怎么称」固定，一斤才处处一斤。
  • 杜禾的两个下午：统一四十条文献格式是地板，带着方法文件与导师批注来回十几轮是纠缠。
  • 两张桌子：同一个月、同一个基底、同样一百万个 token，杜禾一桌改论文留下五百字离不开的段落，网店一桌批量回客服消息，账单一样，亮的号位不同。
  • 五道难题：一价定律失效，需求曲线画不出，边际成本定价失灵，剩余与 GDP 计不进，杰文斯悖论在一号位重演。
  • 杜家四口、网店店主等均为虚构；年份多标〔待核〕。

六、碰撞接口

  • 可抽出的命题：①凡显得谁来都一样的力，皆是另两角被标准化钉住的结果。②规模长一号位，三号位只能养。③价格是一号位的读数，价值是三号位的纠缠。
  • 可相撞的方向：经济学价值论（劳动、交换、效用三家各押一个号位）、标准化与计量学、平台经济与按席位计价、AI 评测。可撞点在「同一个基底、同一个版本号，差出来的那一块不在模型里」。
  • 站内邻书：第396号《属性纠缠论》是底本，本书为其应用卷；第368号《关系发生学导论》借其回写对称度；第363号《中国 AI for Science 的困境》同向，同处理 Token 与产业，但取科研体制一面；第391号（AI 第一次坐上主体位）讲经济主体，与本书讲力方向相反。

七、边界：什么情况下算错

致命条款：同一批使用者、若干基底、两类任务交叉，若放开轮里思想创新任务上含使用者的搭配份额不高于标准编程，或差值低于登记线，第五编收窄，「懂 SDE」退回二号位的用法；两类都低且复现，判词后一半划掉，只剩一部钉住史。另有六条分号位的预注册预言，阈值开跑前登记。书自认最弱：思想创新与标准编程无现成分尺，场与封装分不干净，三号位的「我」测起来绕不开「我」，引站内专著多近于自证。写作时检验一条都还没有真跑。
