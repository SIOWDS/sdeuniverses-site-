# 预注册 · 第二次真跑（改革前后同一批对象的两套读数）

冻结时间：2026-08-10。写在运行任何脚本之前，未看过任何结果。

## 为什么是这份数据

原稿第十节自陈：本文最想跑的那一条没跑成，因为公开数据里几乎没有「同一批对象在一次改革前后的两套读数」。
本次找到一例：Open LLM Leaderboard 于 2024-06-26 由 v1 换为 v2。

- 旧读法 A（v1，六项）：ARC / HellaSwag / MMLU / TruthfulQA / Winogrande / GSM8K
- 新读法 B（v2，六项）：IFEval / BBH / MATH Lvl 5 / GPQA / MUSR / MMLU-PRO
- 对象：同一批模型（按 fullname 匹配两版都跑过的）
- 这是一次有日期、有公开理由（旧集饱和与污染）、由专业团队执行的口径更换，且**不要求新旧可比**——与教育里的等值改革正好相反。

## 数据处理规则（先写死）

1. 两版各按 `fullname` 去重，保留 `Average ⬆️` 最高的一条。
2. 两版都剔除 `Flagged == True`。
3. 取两版 fullname 的交集为分析样本。
4. 六列各自标准化后回归；λ 取各列决定系数均值；同时报 λ(B|A) 与 λ(A|B)。
5. 样本量须 ≥ 10×6＝60，否则判为不可用。
6. v2 用榜面归一化列（非 Raw 列）。

## 假设与阈值

**Q1（主件，阈值取自原稿 F4，未改）**：λ(B|A)。
- 若 **λ < 0.30**，则原稿「评测集大多落在既有张成之内」这一推论**为伪**，正文第十一节第十条与 F4 必须改写。
- 若 λ ≥ 0.60，则这次改革在结构上没有张成新方向。
- 0.30–0.60 之间判为不确定，如实报告，不作有利解释。

**Q2（分配后果，触及 F1）**：取共同模型，按 v1 平均分与 v2 平均分各取前 20%，报两份名单的重合度 J。
- 原稿第十一节第十条预测：λ 高 → 排名不变。
- 若 **λ ≥ 0.60 而 J ≤ 0.40**，则 λ 与分配后果脱钩，原稿关于 λ 携带分配信息的主张受损，须写进正文。

**Q3（量表两端标定）**：报同口径内部 λ（v1 六项互重构的留一均值、v2 同）。跨版 λ 必须与它并排给出，否则一个孤立的比率读不出大小。

**Q4（方向性预测，可失败）**：逐项报 λ(新单项|旧六项)。
- 预测：**MMLU-PRO 最高**（它是 MMLU 的加难版，属同口径精修），**GPQA 与 MUSR 最低**（新方向）。
- 若 MMLU-PRO 不是新六项里最高的一项，则原稿「加难不等于扩口径」这一说法失去本处支撑，须在正文写明。

## 事后不得做的事

不换阈值、不换匹配键、不剔除不利模型、不改 λ 定义、不做变量筛选（遵原稿清点手册编码规则三）。
