SDE 学科通融

给一个问题，再给三个学科——机器从站内库与联网两路，找出三家在这道题上互相顶撞的理论，撞出一条三家都不会同意、而三家的证据合起来只能得出的判断，写成一篇两万字的学术论文，最后再打磨一遍。
这是顶栏「学科通融」栏目背后的那道工序。

② 你要解决的问题，和撞它的三个学科

问题决定这篇文章要交出什么形状的答案——一个东西（What）／一条路（How）／一个驱动（Why）。第二格先把它判出来。判错不会报错，只会答得很通顺而答非所问。
自己组合的好处是材料厚（每块都带真出处与八字段供料层）；坏处是可能撞不起来——三门站在同一个位置上就撞不出东西。撞不起来会自动转成基底自由组合，不会停在那儿。
不选「只用站内」的话，基底会自动去站外找——那正是默认行为。闭库跑的代价要先知道：敌意拓宽的经典层与专著两个方向在库内常常取不到，产出的不可还原性会结构性偏低（站内六次实测，闭库与开库的分差每次都全部落在这一维）。
三格都留空 → 由基底按这道问题自己定三门（它要挑离得远、又都真能回答这道题的）。填了几个就锁几个，其余由基底补齐。
自测句：把「__ 与 __ 的矛盾驱动了 __ 改变」填实——填得进去就是 Why 题。
⚠ 联网搜来的材料只有摘要级，发表前务必自己点开每个链接核对。取材那一步每一路都有 30–45 秒的闸，超时按空处理并如实标出，不会无限期转圈；站内那一路是串行跑的（每查一次都要把全站语料读一遍），三门大约 20–60 秒。本站检索通道要管理端配过智谱 Key 才通；不通时上面那一格会自动露出来。
A · 一人三篇只选一位学员——哪三篇由基底挑，它要挑互相打架的，不是挑最好的
B · 三人各一篇三位学员各一篇——三人三篇全由基底挑（硬约束：必须三个不同作者）
C · 站上三长文站上长文——三篇全由基底挑（硬约束：必须三个不同栏目）
D · 站外三领域给一个议题——三个领域的对立理论由基底联网去找（撞站外理论，成品走学科通融）
F · 自由投喂你自己粘三篇进来（手上已有站外理论时用这个，材料比检索到的厚）
随机抽定一篇 A（固定不换）→ 找与 A 对立的 B：对立度不够就逐级放宽范围——本人栏 → 其他学员 → 全站长文 → 基底知识库。立住对子后，再找同时顶住 A 和 B 的 C（同样逐级放宽，最后才知识库、再自造）。
内化那一格走快速档（压缩活，快而稳）；碰撞与成文全程满功率。
每一轮只读标题与摘要，很便宜；只有定标的那一组才去取全文
勾三篇（勾第四篇会把最早的一篇顶掉）
留空 → 基底先自己定一个议题（强制避开站上已经撞过的那些）；然后把议题拆成三个不同领域的检索词，各搜一轮，再从搜到的东西里挑三家斜着对立的理论。
本站通道要管理端配过智谱 Key 才通；不通时下面这一格会自动露出来，填一把自己的智谱 Key 即可。
⚠ 这一路的源在站外：材料只有摘要级，抽脊会比站内薄；发表前务必自己点开每个链接核对。手上已有全文就改用 F 模式。
三个源各粘一段：第一行当标题，其余当正文（每篇建议 2000 字以上；站外理论可粘论文摘要＋核心论证）。

③ 撞的是这三家（每家：一个主题观点 ＋ 三个支撑观点）

这一块是中间产物：给你看清撞的是什么、底盘硬不硬。三家本身会正面写进成品的文献综述（那是论文该做的事），但这些卡片上的抽脊不会进正文。三家的位置要各不相同——两家站在同一个位置就是撞车，学科离得再远也撞不出东西。
