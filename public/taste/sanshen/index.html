CHATSDE · SDE三审

一部书稿进来，三份审读报告出去

出版社的稿子要过三关：责任编辑初审、编辑室主任复审、总编终审。今天很多出版社把稿件处理交给传媒公司，传媒公司要做的，就是让稿子三关都过得去。SDE三审把三关一次走完：初审查字词、标点、体例、引文和前后矛盾；复审问这部稿子到底是书，还是库存；终审看读者会不会被卷进去、它在领域里站在哪里、该怎样出版。交给你一份三审意见书 Word；选「审＋改」，它还会照意见把稿子逐章改好，另附一份修改稿。

只审 →审＋改 →怎么用

三审，各看一样东西

初审 · 责任编辑规范与概念

错别字与误用；标点、数字按国标；术语、人名前后统一；概念先用后定义；引文与数据有没有出处；写给作者的批注留在正文、删了一半的残句、同一段重复两遍；前后矛盾。每条分 A 必改、B 应改、C 可改。

复审 · 编辑室主任洪流体检：是书，还是库存

构成洪流的才叫书，否则只是库存——内容都在，却不流动，像一冰箱食材而不是一桌饭。逐章问四件事，画出全书的洪流图，把库存段落一处处标出来，并写清怎样改成流动的。

终审 · 总编读者、领域与出版决定

写给谁、读者会在哪一处被抓住、在哪一处放下书；同类书怎么写、这部有没有别人没有的东西，适合走国际出版立理论，还是国内出版做应用；导向与合规风险；出版形态；终审决定与必改清单，附致作者信。

复审的四问

起手开头有没有一个问题、缝隙或处境，把读者拉进来
接力每一段是不是接住上一段往前推，而不是原地堆量
结算读完这一章，读者得到了什么开头没有的东西
出口结尾有没有把新的问题递给下一章、递给读者

教材、专著、小说各有一套四问的判法：教材看学生能不能做成开头做不成的事；专著看能不能得出一句「不是……而是……」的新判断；小说看人物的局面有没有被改变。四问四个都答不上的段落，就是库存。

两种做法，开始前选

只审

机检全稿 → 逐章三审（每批 5 章，自动审完）→ 复审报告 → 终审报告 → 三审意见书 Word。审完还想改，点「按三审意见改稿」接着做。

进入只审 →

审＋改

三审走完后，按终审的必改清单、复审的库存改法和初审的逐条意见，逐章改稿（每批 3 章，自动改完）：清掉残留、补出处标记、把库存段落改成流动的。作者的观点、亲历与口吻保留；没把握的地方标〔待核〕，缺材料标〔待作者补〕，不替作者编。另出一份修改稿 Word，意见书里附逐章修改说明。

进入审＋改 →

进了 ChatSDE，模式条上的 ⚖ SDE三审 每点一次在「只审 → 审＋改 → 关」之间切换。

结论怎么定

初审通过初审／修改后复审／退回修改复审通过复审／修改后终审／退回修改终审同意出版／修改后出版／退回修改／不予出版

字数、单元数、A 级条数、库存章的比例、风险项都由程序数出来，再据此定出每一审「最宽允许的结论」：有 A 级必改，初审就不能是通过；库存章占到两成，复审就不能是通过；有提请人工的风险项或还有章没审，终审就不能直接同意出版。人工智能给的结论只能维持或从严，不能放宽——放宽的会在意见书里注明「已按底线从严」。

怎么用

  1. 点上面「只审」或「审＋改」进入 ChatSDE。第一次用要先在设置里选基底、填你自己的 API Key。
  2. 用输入框下的 📎 附件 载入书稿：Word、PDF、文本都行。
  3. 在输入框写稿件信息，例如：书名：老城新生　作者：某某　类型：专著　出版社：某某出版社，下面可以接着贴出版社的要求或编辑的退改意见。都可以留空，类型会从正文推断。
  4. 发送后先出机检，接着逐章三审，再出复审、终审报告；选了「审＋改」会接着逐章改稿。中途可以停，再点「接着三审」「现在出复审与终审」或「接着改稿」。
  5. 随时点 ⤓ 三审意见书 Word；改过的，还有 ⤓ 修改稿 Word。

用之前要知道

  • 它出的是审读意见。政治性与意识形态把关、事实与引文的最终核定、图片画面，必须由责任编辑完成；出版决定以出版社三审为准。意见书不构成「符合出版要求」的结论。
  • 数由程序算。字数、修订残留、重复段落、标点类问题、A 级条数与库存比例都是程序数的，不靠模型估。
  • 改稿不编造。事实、数据、引文、人名没把握的保留原样并标〔待核〕；风险项只标〔提请人工〕，不替作者改观点；小说不改情节走向与人物命运。
  • 报告用平常话。写给编辑和作者看，不出现学派术语。
  • 一人一把 Key。审读用的是你自己的 Key，一部 20 万字的书约 25–40 次调用；限流按 Key 计。
  • 稿子不离开你的电脑。文件在你自己的浏览器里解析，只有切好的单元文字随提问发给你选的基底。载入未出版稿件前请征得作者同意。
