CHATSDE · 教材审校

先查概念和结构，再核字词和标点

教材最怕的不是错别字，而是学生读不懂的地方：概念没讲就用、同一个术语前后两个叫法、例题跳了一步、前一章埋的伏笔后面没人接。教材审校把重点放在这两层，逐单元给出带原文位置的分级意见；字词、标点、数字、量和单位、参考文献格式等表层问题按国家标准顺带核对。最后汇总成全书审校报告。

开始教材审校 →怎么用

审什么

概念层（重点）

先用后定义、术语前后不一、定义与例子对不上、同一符号两种含义、与前序章节的概念冲突。

结构层（重点）

单元内部的讲解顺序、例题梯度、练习是否覆盖所讲内容、章节之间是否断档，每个单元给出「有／弱／缺」的体检结论并引原文为证。

表层

字词、标点、数字用法、量和单位、外文与公式、参考文献格式、图表引用、语病。每条标明规则编号和级别（必改／统一／裁决／提示）。

合规提示

比较性断言无来源、疑似未标注出处的引用等，只提请人工核对，不下结论。

怎么用

  1. 点「开始教材审校」进入 ChatSDE，模式条上的 🔎 教材审校 已点亮。第一次用要先在设置里选基底、填你自己的 API Key。
  2. 用输入框下的 📎 附件 载入教材稿：Word、PDF、文本都可以，在你自己的浏览器里解析。
  3. 发送后按单元逐个审，每批 4 个；前面单元的术语、图表、公式编号会记入台账，带给后面的单元对照。
  4. 点「↻ 继续审」审完余下单元，审完自动生成全书汇总；也可以随时点「现在生成全书汇总」。
  5. 随时可下载 ⤓ 导出审校报告 Word：汇总、逐单元审校意见和全书台账。

用之前要知道

  • 它只出审校意见。不替代人工终审，也不构成「符合出版要求」的结论；重大修改与取舍由责任编辑裁决。
  • 纯文本会丢字体信息。正斜体、粗体、上下标在粘贴或转文本时已经丢失，相关检查会在报告里标「未检」。
  • 没有社内体例。本模式按通行国家标准核对，不知道你社的内部体例；与社内规定不一致处请以社内为准。
  • 一人一把 Key。限流按 Key 计，审校用的是你自己的 Key。
  • 事实要人核。书名、引文、数据、人名和标准的现行状态，交出版前请逐条核对。
  • 稿子是作者的。载入未出版稿件前请征得作者同意。
