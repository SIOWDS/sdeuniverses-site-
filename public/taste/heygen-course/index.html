⬇ 下载声音样本（WAV）
录好下载后：自拍视频拿去 HeyGen 训练 Avatar V 分身；声音样本拿去 AI Studio → Voice → Instant Voice Cloning 克隆你的声音。详细步骤见下一步。

1 连接你的 HeyGen 账户

本工具用你自己的 HeyGen 密钥出片（BYOK，密钥只在你浏览器与 HeyGen 之间转发，本站不存储）。出片前，先在 HeyGen 官网准备好三样东西：

① 训练你的数字分身（形象）
登录 HeyGen → Avatars（头像）→ Create → Avatar V，对着摄像头录一段约 15 秒的自拍（正脸、光线充足、背景干净——背景会保留在视频里，不满意要手动删）。等它训练好，就有了你的形象分身。

② 克隆你的声音（让分身用你自己的嗓音讲课）
进 AI Studio → Voice（声音）→ + New Voice → Create New Voice → Instant Voice Cloning：勾选那句授权协议（同意用你的录音生成合成声音）→ 上传一段你自己说话的清晰录音（安静房间、好一点的麦克风，约 30 秒到 2 分钟，说得越自然越像；中文课就用中文录、内容尽量贴近讲课口吻）→ 处理几秒即得你的声音克隆。不满意可点「Improve this voice」调相似度/风格/稳定度。
小贴士：声音质量决定成片质量——录得清楚、内容贴近真实讲课，克隆才像你本人。若中文效果不理想，可在 voice 设置里选 multilingual v2 模型。

③ 复制 API Key
去 设置 → API 复制 API Key，填入下面，点「载入我的分身与声音」——你训好的形象和克隆声音都会出现在下面的下拉里，选你自己的那份即可。

计费由 HeyGen 按视频分钟数从你的额度扣：标准约 $1/分钟，最逼真的 Avatar IV 约 $4/分钟（$5 起充，用多少扣多少）。
