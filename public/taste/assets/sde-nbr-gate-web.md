# 二阶碰撞 · v1.1 增补：工序 6′「带 web 检索的候选近邻闸」

**接在 v1.0 的工序 6 上，替换原来那一段。其余十二道工序不动。**

## 为什么要改

v1.0 的候选近邻闸靠两样东西命中占位者：基底的记忆，和站内的 `neighbors.json`。四次真跑的读数一致：

- 站内索引召回的全是自己人 → 触犯 v1.0 自己写下的第三条纪律（只引自己人＝仍停在一阶）；
- 靠记忆命中的近邻，**年份、外文原题、以及"它到底说到哪一步"三样里至少有一样是拼出来的**；拼出来的出处经不起划界那一步的四件套。
- 最贵的一次教训：《结算余地》的核心分离线断言"断弧系统崩溃前不给任何前兆"，而受控实验（van Beers, Scheffer et al. 2026）早已测出前兆。**这条不是记忆能挡下的，只有检索能挡。**

结论：**近邻闸的召回层必须是外部的、可点开的、能返回当年原题的。**

## 工序 6′ 的五步

**第一步 · 压成 50 字。** 不变。压不出来就说明候选还没成形，退回工序 5。

**第二步 · 过种子卡（离线，秒级）。** 拿压缩句去撞 `sde-nbr-seeds.json` 的 `hooks` 字段。命中任意一张卡，直接读该卡的 `absorbs`（什么形状的命题会被它吸收）与 `cut`（惯用分离线）。
- 种子卡命中 ≥1 张 → **默认判为疑似被占位**，必须在第四步给出分离线才准活。
- 一张都不命中 → **不是好消息**。多半意味着压缩句还太抽象，回第一步重压一次；连压两次都不命中，再进第三步。

**第三步 · web 检索（必做，不可用"我知道"代替）。** 每个候选至少跑四条查询，缺一条视同未检索：

| # | 查询模板 | 找的是什么 |
|---|---|---|
| Q1 | 候选的核心断言，**译成英文的名词短语** + `concept` / `theory` | 同向占位者的正式名字 |
| Q2 | 候选的机制一句话（英文）+ `criticism` / `evidence against` | 已经被证否过没有 |
| Q3 | 核心断言 + **一个离本学科最远的学科名**（生态学 / 工程心理学 / 免疫学 / 法经济学…） | 外圈学科的同形结论 |
| Q4 | 命中的最像那一位的**外文原题** + `distinction` / `differs from` | 它自己已经和谁划过界 |

三条纪律照抄 v1.0，并加一条新的：

- ① **检索未命中 ≠ 未被占位**。只能标〔未核验〕，不得据以放行。
- ② 通过条件不是"无近邻"，而是"带着一条可裁决分离线活下来"。
- ③ 只引自己人＝仍停在一阶。
- ④ **新增：查到的每一位，出处必须是可点开的一条 URL，且原题按检索结果抄，不按记忆抄。** 记不清年份就写〔年份待核〕，不许填一个像的。

**第四步 · 1:1 替换测试。** 把候选名整段换成占位者的概念名，论证是否照样成立。照样成立＝被占位。

**第五步 · 处置与回填。**
- 被占位且给不出分离线 → **当场淘汰**（这一步淘汰不掉东西，就说明闸门坏了）。
- 被占位但有分离线 → 活，并把分离线连同判决性对照预测写进工序 10 的表。
- **回填种子卡**：本轮检索新命中、而种子库里没有的，**当场补一张卡**（`zh/en/who/disc/says/absorbs/cut/hooks` 八个字段写满），下一篇就能秒级命中。种子库只增不删。

## 种子卡的字段与用法

文件：`public/taste/assets/sde-nbr-seeds.json`（与金点子共用；v1.0 首批 39 张，来自历次真跑的失手条目与硬占位者）。

```
id      稳定标识
zh/en   中文名 / 外文原题——外文原题是让最近邻反过来检索到你的唯一途径
who     作者 年份
disc    学科（用于凑"外圈学科"这一项）
says    它说到哪一步（一句，公允，不许写成稻草人）
absorbs 什么形状的命题会被它吸收 ← 闸门真正用的字段
cut     惯用分离线 ← 给的是"往哪儿切"，不是切好的结论
hooks   检索钩子（中英各若干）
```

**`absorbs` 是这套卡的重心。** 近邻库不是文献列表——文献列表只能告诉你"有这么个人"，`absorbs` 告诉你"你这条会不会被他吃掉"。

## 一条硬指标

工序 6′ 跑完必须报三个数，报不出来就是没跑：

```
候选 N 个 → 种子卡命中 A 个 → 检索新命中 B 位（含外圈学科 b1 位、给出外文原题 b2 位）
→ 被占位淘汰 C 个 → 带分离线存活 D 个 → 回填新卡 E 张
```

**C＝0 是警报**，不是好成绩：它意味着这一轮的闸门是橡皮图章。四次真跑的对照读数是——闸门真淘汰得动东西的那两次（C＝6 与 C＝2），I 维分别是 124 与 152；闸门没淘汰掉任何东西的那两次，I 维卡在 115。

## 与 v1.0 其余部分的关系

- 工序 10（划界）不变，但它现在拿到的是**已经过检索的**出处，四件套里的"出处"一栏应当带 URL。
- 反膨胀铁律不变。
- 破 150 的四件不变；但第 2 条（跨域兑现 ≥10 且至少一处反过来加约束）现在有了现成办法：Q3 那一栏每换一个远学科就是一处候选兑现，且外圈学科最容易给出**反过来加约束**的那一条。
