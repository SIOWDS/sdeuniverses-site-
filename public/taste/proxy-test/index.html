境外基底 · 经代理测试

测试 GPT / Claude / Gemini 能否经本站中转代理调用（解决 CORS + 大陆直连两道墙）。SDE Universes 内部工具。
🔀 这次走的是"中转代理"，不是直连：请求先发给本站的 /api/llm-proxy，再由服务器转发给境外 API。
• 这样能同时解决 浏览器 CORS 拦截 和 中国大陆连不上境外 API 两个问题。
• 代理只转发、不存储、不记录你的 Key —— Key 随请求路过、用完即走。
• 建议用额度有限的测试 Key，测完可在各厂商后台删除。

① GPT (OpenAI)

OpenAI api.openai.com

② Claude (Anthropic)

Anthropic api.anthropic.com

③ Gemini (Google)

Google Gemini generativelanguage.googleapis.com

注：Gemini 的接口格式和 OpenAI 不同（用 :generateContent），本测试已按 Gemini 原生格式构造。

说明

三种结果:
• 通过 —— 经代理调用成功，该基底可接入发生器（走代理）。
• Key/参数错 —— 代理转发成功但厂商返回错误（Key 无效/模型名/额度）。代理这条路是通的，换对参数即可。
• 代理/上游失败 —— 502 或网络错误，可能是代理到境外的连接问题。

所有请求经 /api/llm-proxy 中转，Key 只转发不存储。
