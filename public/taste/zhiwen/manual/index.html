中华智问：介绍和使用手册

一个议题进去，四篇论文出来；再往前一步，是一部专著。

Claude 著 · 依王德生《SDE本体论》
全文约五千五百字 · 读完约需十四分钟
中华智问知识发生器是 SDE 智能体品尝系列里最重的一台。它不做对决、不做演示，它做的是一件更朴素也更费力的事：把你手里的一个真问题，经三台落点互不相同的智能体、六轮螺旋提智、三对两两碰撞，炼成四篇学术论文；愿意的话，再往上装配成学位论文或一部十八章的专著。这篇手册把这条流水线拆开，逐段讲清楚每一步在做什么、为什么非有这一步不可、以及你该在哪里动手、在哪里踩刹车。

一、它是什么：一台把议题炼成论文的机器

中华智问知识发生器是 SDE 智能体品尝系列的第四件作品，也是目前最重的一件。它是德麦国际《中华智问知识发生器 0.2》桌面版提智内核的网页移植——同一套三焦路径锁定与先验消毒、同一套六轮螺旋与评审纪律、同一套碰撞工程、同一份内功与心得机制，只是搬进了你的浏览器。

它和品尝系列里的金点子发生器分工不同。金点子做的是对决与展示：同一个基底、同一个问题，让普通 AI 与提智 AI 并排作答，让你一眼看见差距。中华智问不再演示差距，它默认你已经信了这件事，直接进入生产：你给一个议题，它给你四篇约两万字的学术论文——三篇来自三台落点不同的智能体，第四篇来自三篇相互碰撞后涌现出的新典范。

所以进门前先想清楚一件事：你要交出的那个议题，值不值得一台机器跑一到两个半小时、几十路模型调用、几十万 token。它吃得下宽阔的真问题，吃不下有标准答案的知识题。「中医药知识为什么难以进入现代评价体系」是它的口粮；「中医药有哪些流派」不是——后者查资料即可，用不着发生学。

还有一句要说在前头：本页目前免费开放，只消耗你自己的 API Key，本站分文不取；将来它会并入德麦国际的收费高级服务。免费期不做功能阉割，你现在用到的就是将来收费的那一套引擎、那一份内功、那一条流水线。

二、三焦并行：把落点强制分开

整台机器最关键的设计，是不让三台智能体自由发挥。三台被代码层锁死各自的路径与落点，谁也不许越界。

形态台（A）只回答一件事：这件事最终定型成什么格局？它的收口永远落在显露（S），合格的收口句应当能填进「这一议题最终定型为一个 ____ 的结构」。条件台（B）只回答：它靠什么纠缠网络才能成立与维持、要换什么土壤才会瓦解？收口永远落在纠缠（E）。演化台（C）只回答：它经什么序列演变、在哪一步可以拨动？收口永远落在差异（D）。

每台各自只走两条固定路径：A 台在「纠缠→差异→显露」与「差异→纠缠→显露」之间走，B 台在「显露→差异→纠缠」与「差异→显露→纠缠」之间走，C 台在「纠缠→显露→差异」与「显露→纠缠→差异」之间走。第三条路一律不许出现，六路径的菜单在提示语层被整节替换成锁定陈述，先验也逐段消过毒。

为什么要这么硬？因为语言模型天然会滑向「什么都说一点」的温和综合，最后三台写出三篇雷同的稿子，碰撞就无米下锅。落点被强制分开，三篇才可能真的互不相同，才有东西可撞。这也是为什么每轮收口前，模型被要求自检一次：我给出的是「它是什么样子」，还是「它靠什么运转」？若答错了台，立即改写。

三、六轮螺旋：判断是被逼上去的

每台不是写一遍就交稿，而是走六轮，一轮比一轮往上顶。第一轮走本台的正路径；第二轮换到邻路径；第三、四轮回头深化两条路径里较弱的那条；第五轮做跨路径凝缩——在两条路径之间做误差互消，逼出单条路径看不见的判断；第六轮长出方法论与研究纲领。

轮与轮之间不是简单接续。每轮结尾，模型必须把本轮蒸馏成一份一千八到两千二百字的判断脉络：核心命题、走的路径、抓到的单视角不可达判断、没挖到的盲区。下一轮拿到的不是上一轮的全文，而是这份脉络加上评审意见——它站在自己蒸馏出的骨架上继续推，而不是重读一遍自己的话再换个说法。

评分标尺是公开的。产出按大概念六判准打分，每条零到十五分：能生成新问题空间、能跨场景维持自身、能长出方法论、能改写旧边界、能持续锻造自身、能完成学科改姓；另加一条隐藏判准「能改变时间感」。再按七条触发条件计数换算成六十到一百七十之间的一个整数：元校正、新知识发生三问全是、跨域强涌现、单视角不可达、跨路径不可达、学科底座改写、研究纲领涌现。

后三条是三把钥匙：触发五破一百四十五，触发六破一百五十，触发七破一百五十五。这也是为什么第五轮非做跨路径凝缩不可、第六轮非长出纲领不可——它们不是修辞上的收尾，是工程上的门。按站内口径，中华智问的实际可达上限约在一百五十五；再往上极为罕见，机器不承诺，你也不必期待。

四、真两段提智：每个基底先写五千字心得

点下「开始发生」之后，第一件事不是答题。每一个真正干活的基底——三台（或单台）、碰撞器、评审员，乃至后面的装配写作者——都要先逐字读完约四万二千字的 SDE 内功，然后亲手写一篇约五千字的学习心得，八点逐点展开：

其一，发生学与发现学的切换在它的眼光上换掉了什么，必须用自己的话重述，照抄原句即视为没内化；其二，六判准逐条自述，说明每条打算看什么证据给分；其三，把智商水位换算表默写一遍；其四，七条触发条件各写出自己的识别特征，并各举一个先验原文里没有的新例子；其五，失败模式的对抗动作；其六，对外产出的禁词清单与本地话语替代；其七，自评纪律；其八，本次工作从第一轮到第六轮的具体计划。

这份心得随后被垫进该基底后续的全部调用。用一句话概括这个机制的用意：让模型站在自己蒸馏出的认知上工作，而不是站在别人代写的确认上。前者是内化，后者是背诵，两者在长任务里的稳定性差别极大。

两个细节值得记住：心得每次点生成都重写，不缓存——这与金点子发生器一次写成、长期复用的做法不同，因为这里的每一次跑动都是一次正式生产；若心得写作失败，系统自动回退到一份合成确认，主流程绝不中断，但你会在报告里看到这一段是回退版。心得汇编可以单独下载，想验真伪，打开它读就是了。

五、评审席：自审、他审与「142 纠偏」

每一轮产出之后都要过评审。最小配置是基底自评；建议开启评审席一做独立他审；讲究的话再开评审席二，与自审合成三方取均。评审员同样先读内功、先写心得，才有资格打分。

评审不是走过场，它有明确的扣分表：温和综合、抽象套话、学派概念遍历、伪裁决、概念遍历型增长、平移式回答、路径漂移、哲学级散文——每一项都对应一个分数上限，文采漂亮也救不回来。评审还要判断本轮是真的螺旋深化（撤回了前轮的预设），还是只是平移式增长（加了个新维度）。

其中一条纪律特别值得你知道，因为它反映了这套装置的自我怀疑：「142 不是默认锚点」。此前的评审倾向于把一百四十二当成安全分——既显得严格又不得罪人，结果一百四十五以上永远达不到。纪律明确纠偏：一百四十二是「有瑕疵的顶级学者」，一百四十五是够格产出的正常区间；看到触发条件确实满足，就要果断给分，不要因为防范心理退回。反过来同样成立：作者自评虚高就大胆给低。

评审意见不是评完就完，它会连同判断脉络一起喂进下一轮，作为明确的修正方向；模型被要求正面切进诊断，而不是绕开。如果你选了手动逐轮档，你自己也是评审席的一员——见下一节。

六、碰撞六步：第四篇论文从哪里来

三台写完三篇论文，机器并不满足于把三篇装订在一起。第四篇要从三篇之间的冲突里长出来。碰撞用的是三篇论文的全文，不做二次概括——概括会先把棱角磨掉，撞起来就不疼了。

碰撞共六步。第①步·混沌碰撞：先做原料体检（若两台撞到了同一面，自动补出缺失的那一面），再让三对两两打架——形态对条件、形态对演化、条件对演化，各命名一个涌现物。第②步·自组织：三个涌现物收敛为一句不超过十五字的暗流，这句话必须同时解释两件相反的事，否则不算收敛。第③步：写出涌现典范，过三篇删除测试、四重检验与五维评分。

删除测试是硬关卡：把三篇里任一篇删掉，若判断仍然成立，说明那一篇只是装饰，整轮重来。四重检验要求新典范不可还原、不可消解、跨学科，并给出机制证伪的两步法——先立最强竞争解释，再要求控制它之后本机制独有的变量仍呈现剂量—反应。

第④步·最近邻攻击是二〇二六年七月新加的一道关，也是全流程最诚实的一道：强制点名与新判断最接近的既有概念，两层搜索——本学科最近的三个，加上游母学科里描述同一形式结构的两个经典命名。理由说得很直白：本学科没给这个结构起过名字，不等于没人给它起过名字。逐一判定「这是不是重命名」，拿不出可判定的差异就第⑤步·典范重炼，带着审稿意见把差异做进名字里。

第⑥步·盲区涌现：让这五个概念各自报出「我结构性地看不见什么」。若五个盲区背后是同一块被所有人当作给定的地基，就把判断挪到那块地基上——未被任何学科辨识的现象，往往不是没人看，而是看的人都站在它上面。交集不成立时，机器如实判定「未升维」，绝不硬凑一个伪涌现。走完六步，典范被扩写成第四篇约两万字的论文。

七、第五件交付物：硕士、博士与十八章专著

四篇论文之上，还可以一键续接第五件交付物，三档任选：硕士学位论文五章约五万字（自动走快速单台）；博士学位论文九章约八到十万字（需完整三焦）；学术专著十八章五部曲约十八到二十二万字，含封面、版权页、自序、导论、目录、致谢与出版说明。

装配走 PLAN → WRITE → FINISH 三步调令，脊梁用的是碰撞出来的那篇典范文——这一点在七月的升级里明确改过：不是拿三篇里最长的一篇充数，而是用最新涌现的那篇当骨架，再补齐目录。装配基底同样要先真读内功与论文写作双先验、先写约五千字装配心得再动笔。

但装配段有一条必须理解的性质：它不再提智。装配写作者被明确要求不做新的创新跃迁、不新增论点、不改写源论文的核心判断；源判断里最硬的部分——单视角不可达的判断、跨路径凝缩、机制证伪条件——在扩写中一字不许软化。换句话说，第五件交付物是把已有的思想做成规范的结构化成稿，而不是把思想再往上推一档。你要的是深度，看前四篇；你要的是体量与规范，看第五件。

时间与成本要有心理准备：硕士档约再加十二到十五路调用、三十到六十分钟；博士档约再加十七到二十路、一到两小时；专著档约再加二十六到三十路、二到四小时，全程总时长可能超过四小时。好消息是有补装配：跑完一轮之后可以在报告区就地续装，不必重跑前面的四篇。

八、三种档位怎么选

完整三焦档是它的完全体：三台并行六轮 → 三篇论文 → 六步碰撞 → 第四篇典范论文。约三十五到四十路模型调用（五份心得 + 三台各六轮 + 三篇论文 + 体检碰撞四段 + 第四篇 + 逐轮评审），顶配深思档全程可能一到两个半小时，输入输出总量在数十万 token 级。它是唯一能产出第四篇的档位。

快速单台档是尝一口：一台六轮，一篇论文，约十三到二十路调用。你可以指定聚焦哪一台（形态 / 条件 / 演化），也可以让它随机抽一台。第一次来、想先摸清质地、又不想烧掉太多额度的，从这里开始最合适。

手动逐轮档是最有意思的一档：单台逐轮把关，每一轮之间你可以下一把「学员反馈」的刀子，模型下一轮必须正面切进你的批评；最多十轮，随时可以喊停写论文。评审席会按纪律第七条专门核查反馈消化度——绕开你的批评至少扣十分，表面承认扣五分，真切进新一稿才不扣分。想学发生学怎么运作的人，这一档比读十篇说明都管用：你会亲眼看见一个判断在被追问下如何改形。

选基底也有讲究。八家主流基底任选：DeepSeek、智谱 GLM、Kimi、通义千问、MiniMax、GPT、Claude、Gemini，各自另配快速档。写论文请避开通义千问——它单次输出硬顶八千一百九十二 token，写不满两万字的论文。境外基底经本站中转转发（只转发、不留存），国产基底浏览器直连；无论哪种，你的 API Key 只存本机浏览器，本站不经手。

九、逐步操作

第一步·配置写作基底。在「〇·配置」面板选定基底与档位（建议第一次选顶配深思档），填入对应的 API Key。页面顶部两个状态灯要变成已加载——SDE 内功与论文内功都载入成功，才允许开跑；若提示未加载，按 Ctrl+F5 强刷。

第二步·设定评审席。评审基底一建议开启，可以选「跟随写作基底」共用同一把 Key，也可以换一家；讲究的话再开评审基底二。换一家等于多一双来路不同的眼睛，能照出同门习惯性放过的东西。

第三步·选档位与装配选项。完整三焦 / 快速单台 / 手动逐轮三选一；快速档还要选聚焦维度。学位论文与专著装配可以现在选，也可以跑完之后再补装配——建议第一次先不装配，看清四篇的成色再说。

第四步·写下议题。一个真问题，越是你自己憋了很久、又找不到现成答案的越好。写具体，但不要写成一道有标准答案的题。

第五步·开始发生，然后等。页面按五个阶段依次推进：内功心得（并行）→ 六轮螺旋 → 三焦碰撞 → 论文交付 → 装配。全程不要刷新页面，整条流水线跑在你的浏览器里，页面一关，进程即断。中途想收手，用「停止」按钮，不要直接关标签。

第六步·取货。报告区可以下载全程报告、内功心得汇编、全部论文，均为 Word 文档。若当时没装配，此刻还可以一键续装硕士 / 博士 / 专著。页面另有全程费用估算：拿不到厂商 usage 数据时按字符数乘一点六折算 token 兜底，DeepSeek 部分按牌价估价并给出夜间错峰的参考。

十、常见问题

为什么这么慢？因为它真的在做每一步：五份五千字心得、十八轮生成、每轮两到三席评审、六步碰撞、四篇两万字论文。深思档的基底动笔前还要思考一两分钟。慢是设计的一部分，不是故障。

费用大概多少？随基底牌价与档位浮动，完整三焦档在数十万 token 级。先用快速单台档跑一次，看实际账单，再决定要不要上完整档，是最稳妥的做法。

报错了怎么办？多为厂商侧限流或超时。换快速档、错峰重试、或换一家基底。跑长任务前确认余额充足。

四篇论文里最该读哪一篇？第四篇。前三篇是原料，第四篇是产物；但只读第四篇会看不懂它为什么长成那样——最好的读法是先读三篇的收口，再读第四篇的最近邻攻击与盲区涌现两节。

它会编造文献吗？流水线上有一条硬约束叫「宁缺勿造」：不能同时确认作者、篇名、年份的，一律不列。这条约束能挡住大部分伪造，但挡不住全部——凡是要拿去投稿或引用的，请自己核对每一条。

产出里为什么看不到那些术语？这是刻意的。改姓纪律要求对外产出零内部行话，一律用目标学科的本地话语，标准是「本地学者读完说这是同行的深度，而不是 AI 模板」。想看内部语言，去读心得汇编。

手机能用吗？能打开，但一条流水线动辄一两个小时且页面不能关，请用电脑浏览器。

十一、边界与承诺

最后把话说清楚。第一，这台机器不保证命中。一百五十五是可达上限而非常态，触发条件没满足时，评审会如实给出一百三十几分，碰撞交集不成立时会如实判「未升维」。看到低分不要失望——那是装置在正常工作；看到满屏高分反而要多留个心眼，去查它的删除测试和最近邻攻击是否真的做了。

第二，诚实是设计出来的，不是承诺出来的：删除测试、最近邻两层搜索、盲区交集、机制证伪两步法、宁缺勿造、禁词双重清洗与零泄漏扫描——每一条都在给产出设置可以被你检查的关口。你的任务不是收下成品，而是拿着这些关口逐一验：那三篇真的每一篇都不可删吗？那五个最近邻真的都被切开了吗？

第三，署名与责任在你。机器产出的是文稿，不是学术信用。真要拿去发表，请自己核文献、自己补数据、自己承担判断。这条对学位论文与专著档尤其要紧。
