## 第一部分 · 论文的本体论地位

### 1.1 论文不是判断的扩写,是判断的工程化

一个经得起反驳的判断(如"教育系统对变革有语义免疫机制")是【核心】,
但它不能直接作为论文发表。论文必须把判断【包装进学术工程体】:

  · 文献定位(把判断放进现有研究的实际位置)
  · 理论框架(为判断提供可被检验的概念结构)
  · 方法论(说明判断如何被推演出来 / 可被验证)
  · 经验材料(给判断锚定具体数据 / 案例 / 观察)
  · 反驳预期(显式回应可能的批评)
  · 局限自陈(承认判断的边界)
  · 政策含义 / 实践指引(把判断翻译成可操作的指导)

判断是骨架,论文是完整生命体。

### 1.2 学术写作的零内部行话纪律(硬规则)

**严禁出现的术语**(SDE 母体话语):
  · SDE / 三视角 / 纠缠 / 三界 / 介生态 / Q1-Q4
  · 改姓爪 / 龙爪手 / 抓核 / 抓裂缝 / 武器锻造
  · 经得起反驳的 / 跨路径凝缩 / 路径轮跑 / 触发条件
  · 中华智问 / DeepSeek / GLM / 提智 / R1-R6 / 元校正
  · 任何"学派内特有"术语

**所有这些必须翻译成目标学科的本地话语**:
  · "三视角误差互消" → "通过多视角分析的交叉验证"
  · "跨路径凝缩" → "通过对比性概念分析获得"
  · "学科底座改写" → "对学科核心假设的重新审视"
  · "判断" → "命题 / 主张 / 假设"
  · "凝缩" → "归纳 / 综合 / 凝练"
  · "本体论位移" → "范式转移"

### 1.3 跨学科调用的实质概念咬合

SDE 提智里得到的跨域强涌现(比如借用免疫学的"免疫机制"看教育系统),
在论文中必须显式说明【为什么这个跨学科类比有效】:
  · 不能"借用免疫学的概念" ── 这是装饰性引用
  · 必须"教育系统与免疫系统在 X、Y、Z 三个结构性维度上同构,
        因此免疫学的核心机制可作为分析教育系统语义防御机制的理论资源"
  · 类比有效的边界必须显式说明

## 第二部分 · 论文的标准结构

### 2.1 完整结构(IMRaD 扩展版)

```
扉页(Title Page)
├─ 论文标题(中英文)
├─ 作者署名 + 单位
└─ 通讯邮箱 / 投稿信息

摘要(Abstract,300-500 字)
├─ 研究背景与问题
├─ 理论框架
├─ 方法论
├─ 核心发现
└─ 理论与实践贡献

关键词(Keywords,5-7 个)
└─ 优先选可被检索的标准术语

正文
├─ 引言(Introduction,1500-2500 字)
├─ 文献综述(Literature Review,2500-4000 字)
├─ 理论框架(Theoretical Framework,2000-3000 字)
├─ 方法论(Methodology,1500-2500 字)
├─ 分析与讨论(Analysis & Discussion,5000-7000 字)
└─ 结论(Conclusion,1500-2500 字)

参考文献(References,40-60 条)
└─ 按 APA 7th 格式
```

### 2.2 字数分配(2 万字总目标)

  · 标题 + 摘要 + 关键词:500 字
  · 引言:2000 字
  · 文献综述:3500 字
  · 理论框架:2500 字
  · 方法论:2000 字
  · 分析与讨论:6500 字
  · 结论:2000 字
  · 致谢 + 利益冲突声明:200 字
  · 总计:~ 19,200 字(留 800 字弹性)
  · 参考文献单独列(不计入字数)

## 第三部分 · 各章节的写作纪律

### 3.1 标题(Title)

**纪律**:
  · 长度 12-25 字
  · 体现核心命题 + 议题
  · 用"主标题:副标题"结构
  · 避免"研究""探讨""分析"等空洞动词

**好例子**:
  · "语义免疫机制:AI 时代教育系统变革困境的再审视"
  · "评价制度的结构锁定:中国教育变革的政治经济学诊断"
  · "改革者困境:论制度变革中外部设计者预设的瓦解"

**坏例子**:
  · "关于 AI 时代教育变革的探讨"(空洞)
  · "教育研究"(过宽)
  · "AI 教育"(无判断)

### 3.2 摘要(Abstract)

**结构(必须严格按此 5 段)**:
1. 研究背景:1-2 句,议题的当前重要性
2. 理论框架:1 句,本文采用的理论视角
3. 方法论:1 句,论证方法
4. 核心发现:2-3 句,本文的新判断(必须有具体内容)
5. 贡献:1-2 句,理论 / 实践贡献

**纪律**:
  · 300-500 字
  · 必须能独立读懂
  · 核心发现必须包含可被引用的关键判断
  · 不出现"本文将探讨..."这种预告式语言,直接陈述发现

### 3.3 引言(Introduction)

**漏斗结构**:
1. **议题的现实重要性**(300-500 字)
   · 从具体的现实事件 / 矛盾 / 转折点切入
   · 不要从"自人类历史以来"开始
   
2. **现有研究的概要**(400-600 字)
   · 主要研究路径 2-3 个
   · 每个路径的核心贡献和盲区

3. **本文的研究问题**(300-500 字)
   · 显式陈述 1-3 个具体问题
   · 解释为什么这些问题重要

4. **本文的贡献预告**(400-600 字)
   · 理论贡献(对现有理论的修正 / 补充 / 颠覆)
   · 经验贡献(新材料 / 新案例 / 新数据)
   · 方法贡献(新分析方法)

5. **论文结构概览**(150-200 字)

### 3.4 文献综述(Literature Review)

**不是文献清单,是文献对话**:
  · 按"理论传统"或"研究问题"组织,不要按时间线
  · 每个段落必须有作者自己的判断
  · 文献缺口必须精确定位

**结构(按理论传统组织)**:
  · 学派一:核心观点 + 经典文献 + 内部进展 + 局限
  · 学派二:核心观点 + 经典文献 + 内部进展 + 局限
  · 学派三:核心观点 + 经典文献 + 内部进展 + 局限
  · 跨学派对话与张力
  · 文献缺口的精确诊断
  · 本文的理论定位

**纪律**:
  · 引用 30-50 篇文献,优先国际期刊
  · 不要"许多学者认为..."(空洞)
  · 要"Smith (2020) 认为...,但 Jones (2022) 提出..."(具体)
  · 每个判断都要可被追溯到具体文献
  · 参考文献的作者名 + 年份要写得像真的(可以略虚构,但必须看起来真实可信)

### 3.5 理论框架(Theoretical Framework)

**核心概念的明确定义**:
  · 每个核心概念给出操作化定义
  · 与已有概念的区分

**概念之间的关系**:
  · 用命题形式(P1, P2, ...)或假设形式(H1, H2, ...)
  · 命题之间的逻辑关系要清晰

**跨学科理论调用**:
  · 调用 2-3 个远端学科的理论资源
  · 必须做实质概念咬合,显式说明为什么有效
  · 类比的有效边界要写清楚

### 3.6 方法论(Methodology)

**对于概念分析型论文**:
  · 说明分析的逻辑工具
  · 说明推演步骤
  · 说明跨学科类比的选择标准
  · 说明对反驳预期的处理方式

**关键**:**说清楚自己的判断是怎么来的,而不是从天而降**

**纪律**:
  · 预先承认方法的局限
  · 解释为什么这个方法适合这个问题

### 3.7 分析与讨论(Analysis & Discussion)

**这是论文的核心,字数最多(5000-7000 字)**

**结构(分论点逐一展开)**:
  · 分论点 1:展开(800-1200 字)+ 跨学科锚定 + 反驳预期
  · 分论点 2:展开 + 跨学科锚定 + 反驳预期
  · 分论点 3:展开 + 跨学科锚定 + 反驳预期
  · 综合讨论:与现有理论对话 + 新理论的形成

**通用纪律**:
  · 每个判断都要锚定具体证据
  · 主动给出反驳并回应
  · 与文献综述中的现有理论对话
  · 跨学科类比要谨慎,显式说明有效边界
  · 段落之间要有清晰的逻辑过渡

### 3.8 结论(Conclusion)

**绝不要重复摘要**!结论是核心贡献的最终凝缩。

**结构(必须按此 5 段)**:
1. **核心发现的简明陈述**(300-500 字)
   · 用 1-2 句话凝缩论文的中心判断
   · 这一句话应该可被作为引用

2. **理论贡献**(300-500 字)
   · 对现有理论的具体修正 / 补充 / 挑战

3. **实践 / 政策含义**(400-600 字)
   · 给出 2-3 条具体的实践指导
   · 必须可操作,不要"应该改进"这种空话

4. **研究局限的诚实自陈**(200-300 字)
   · 主动承认论文的实际局限
   · 这反而增加学术可信度

5. **未来研究方向**(300-500 字)
   · 给出 3-5 个具体可做的后续研究
   · 这是 SDE 提智中"研究纲领涌现"的兑现

### 3.9 参考文献(References)

**纪律**:
  · 40-60 条,优先英文国际期刊 + 经典著作
  · 按 APA 7th 格式
  · 引用格式示例:
    Smith, J. (2020). The architecture of educational reform. *Journal of Education Policy*, 35(4), 521-540.
    Wang, D. (2019). *Structural transformation in Chinese education*. Oxford University Press.
  · 中文文献按引用学科惯例处理(教育学常用中英混排)

## 第四部分 · 从 SDE 提智判断到论文的工程映射

### 4.1 6 轮提智产出的论文映射

```
R1 正路径凝缩  →  引言 + 文献综述
                  把 R1 看到的"评价制度结构锁定"判断
                  作为引言的核心问题切入点
                  
R2 邻路径凝缩  →  理论框架(部分) + 分析章节 1
                  把 R2 看到的"差异演化路径"
                  作为理论框架的第二支柱

R3-R4 深化     →  分析章节 2-3
                  把深化后的判断展开为论证主体

R5 跨路径凝缩  →  分析章节 4(核心) + 结论
                  R5 的"单路径不可达判断"
                  必须作为论文的中心论点

R6 方法论 + 研究纲领  →  结论 + 未来研究方向
                          R6 给出的具体方法论
                          扩写为 5+ 个未来研究方向
```

### 4.2 跨学科调用的论文处理

R5 / R6 中调用的跨学科概念(免疫学 / 演化经济学 / 政治哲学 / ...),
在论文中必须:
  · 单独成段说明类比的有效性
  · 引用该学科 2-3 篇权威文献
  · 明确指出类比的边界

### 4.3 反驳预期的处理

SDE 提智过程中,GLM 评审员给出的扣分理由(失败模式诊断),
在论文中应作为"反驳预期"段落,显式回应:
  · "针对本文论证可能的反驳之一是..."
  · "我们认为这一反驳虽具说服力,但..."
  · 这种自我反驳显著提高论文严谨度

## 第六部分 · 写作风格细则

### 6.1 句式纪律

**短句优先**:
  · 优先用 15-25 字的句子
  · 复杂判断分两句说,不要塞进一个长句

**避免空洞修饰**:
  · 不要"非常重要""极其关键""至关重要"
  · 要"这一判断改写了 X 学派的核心假设"

**主动语态优先**:
  · 中文:"本文论证..."而不是"本文中,X 被论证为..."
  · 英文:Active voice over passive

### 6.2 段落纪律

每段必须有**主题句**(段首)+ **展开** + **小结句**(段尾):
  · 主题句:这一段的核心判断
  · 展开:论证 / 例子 / 反驳预期
  · 小结句:把这段连接到下一段

### 6.3 章节间过渡

每章末尾必须有"过渡段"(80-150 字):
  · 总结本章核心发现
  · 引出下一章要解决的问题
