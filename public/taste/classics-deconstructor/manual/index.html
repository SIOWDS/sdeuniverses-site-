SDE 经典解构器：介绍和使用手册

同一段经典，一篇传统读法作对照，三件工具各解一遍，最后让三篇相撞。

Claude 著 · 依王德生《SDE本体论》
全文约五千字 · 读完约需十三分钟
经典解构器不问「这句话是什么意思」。它问的是另一个问题：这段被反复引用了千百年的文字，是哪一场发生留下的断面？为回答它，工具一次生成五篇论文——一篇走传统经学路数作对照，三篇分别只用三大方程、六路径、123 原理这一件工具各自解构同一段经典，最后三篇终稿相撞，看能不能涌现出任何一篇单独到不了的新判断。这篇手册把这五篇的来路、关卡与读法逐段讲清楚。

一、它是什么：一场四对一的解读对照

SDE 经典解构器是智能体品尝系列的第三件作品。你贴进去一段经典——《道德经》的一句、《论语》的一段、一节圣经、一偈佛经，最长五百字——它同时开出四条生产线，各写一篇学术论文，最后再加一篇碰撞篇，共五篇。

四篇的分工是这样的：传统经学那篇走训诂、思想脉络、注疏史的老路，是对照组；SDE 1 只用三大方程，SDE 2 只用六路径，SDE 3 只用 123 原理。三篇 SDE 论文不问这段话说了什么，而问：这段文字是哪一场发生留下的断面，并且指认传统读法在哪一步把「发生」错读成了「发现」。

四篇同时并行生成、互不依赖，各自独立走完两轮自审自改。它们不是同一篇稿子改出来的三个版本——这一点很要紧，因为只有各自独立成篇，最后的并排对读才有意义：同一段经典，换一件工具会显出什么不同的断面，你一眼就能比出来。

输入限五百字，一句到一段最好。太长会稀释解构的锋利——五百字的上限不是技术限制，是方法上的取舍。页面另附中西二十本经典的原文入口（ctext、CBETA、BibleGateway、Quran.com、古腾堡计划），方便你去那边挑段落复制回来。

二、四篇论文，不是四段随笔

四栏产出的都是正经学术论文，规格统一：标题、摘要、关键词、六节分节正文、参考文献，各约四千五百字。不是四段随笔，也不是四份提要。

六节里最值得注意的是最后一节：应用。四篇的末节都要落到一个具体领域的具体难题上——传统经学那篇接教育，SDE 1（三大方程）接商业，SDE 2（六路径）接健康，SDE 3（123 原理）接商业。领域是固定分配的，不让模型临场自选，否则三篇容易撞车、也容易集体漏掉某个领域。

这一节的要求写得很硬：不许说「这个视角对某某领域很有启发」这种话，必须写清楚具体难题是什么、论文里哪个判断对上了它、对上之后该怎么做。审稿环节有一条专门盯它，只贴标签、给不出可操作建议的，一律点名打回。

还有一条贯穿四篇的铁律：绝不杜撰。记不准的原文、注家、著作、页码、文献，宁可写「待考」也不许编。审稿的第八条把杜撰列为最致命的问题——一经发现，必须写成审稿意见里的头一条。

四篇的摘要值得单独看一眼。审稿第八条要求摘要必须概括出真正的判断，不许写成「本文探讨了某某问题」式的空话——所以四份摘要并排读，本身就是一份最省时间的对照：对照组的摘要通常在交代这段文字的义理归属，三篇 SDE 的摘要则应当各交出一个可以被反驳的判断。哪一篇的摘要读完你说不清它主张了什么，哪一篇多半就是这轮里最弱的一篇。

三、对照组：传统经学那一篇为什么不注入内功

很多人第一眼会问：既然是 SDE 的工具，为什么还要花一整条生产线去写一篇传统经学的论文？答案是——没有对照，差距就无从谈起。

所以这一篇被刻意保持「素」：写作时既不注入内功、也不注入心得。它就用它自己的本事，按经学与文献学的路数写：训诂先下功夫，思想脉络理清楚，注疏史要具体。它的审稿标准也换成经学审慎性检查，不套用 SDE 那套工具检查——用错标尺去审对照组，对照就不成立了。

读结果的时候，请先读这一篇。如果它本身写得稀烂，那么后面三篇的领先未必是提智之功，可能只是模型在这一题上状态好。只有当对照组中规中矩、三篇仍然拉开身位时，那道差距才真正归功于那双看世界的眼。

另外一个常被忽略的用处：传统经学那篇往往写得最稳，可以拿来核对三篇 SDE 论文有没有在训诂层面出硬伤。发生学不豁免文献常识，读法可以新，字义不能错。

还有一层用意在设计里没写明，但值得说破：对照组也是给你自己设的一面镜子。多数人读经典，读的正是这一路——义理、脉络、注疏。先看清楚这一路能走到哪里，你才判断得出后面三篇是真的走出去了，还是只是换了一套词把同一件事重说一遍。这也正是审稿第一条要查的：有没有滑回传统注疏。

四、三件工具，各执一件，不许串味

三篇 SDE 论文的差别不在措辞，在工具，而且每篇只许用一件。

SDE 1 · 三大方程：把 S=F(D,E)、D=G(S,E)、E=H(S,D) 当解剖刀，具体指认这段经典里哪个字句是显露态、哪个是差异序列、哪个是纠缠土壤，三者如何像三脚架的三条腿一样同时互生、拆掉一条就全塌。SDE 2 · 六路径：先读这段经典的任务 DNA，再按六条路径中恰当的一条展开——从哪一端切入、为什么是这一端。SDE 3 · 123 原理：走「差异与纠缠的矛盾 → 显露改变 → 回写」这条链，看这段文字记录的是哪一次回写。

「不许串味」是被当成硬检查写进审稿条目的：审稿第二条专门查有没有偷偷夹带另外两件工具充数——工具用混了，比只用一件用得浅还糟。因为一旦混用，三篇就重新趋同，整个对照设计就白做了。

审稿第三条同样值得你自己记住，因为你读稿时也该这么读：这件工具有没有落到这段经典的具体字句上？如果整节文字换一段经典也照样说得通，那就是空转。这条判据你不需要懂 SDE 也能用——把论文里的经典原文替换成另一段，看它还成不成立即可。

五、先写心得再动手：每个基底各写各的

点下生成后，第一步不是写论文，是写心得。每个真正干活的基底都要先把 SDE 内功读进去，用自己的话完整想一遍，写出一篇约七千字的《从发现到发生》，含三大方程、六路径、123 原理的学习心得，再带着这份已内化的认知上阵。

关键在「各写各的」：审稿基底、评估基底若换了别家，各写各的那一份。让审稿基底去读写作基底的心得，那是读别人的读后感，不叫它自己提智。评估基底尤其不能裸评——它要判的是差异锐度与不可还原性，没读过内功、没自己想过一遍发生学，凭什么判？

心得每次点生成都重写，不缓存、不复用。同一份内功，基底每次想过的角度会有细微差异，这份差异顺着心得传导进三篇论文，让同一段经典每次解构出来的味道也不尽相同。想看它是不是敷衍，直接打开心得读——这是本工具的主功能之一，不是幕后铺垫。

心得还有一道结构性校验：不只看总字数够不够，还要逐节核查，任何一节明显过短或整节缺失，都不许被当成合格心得。这道校验的来历值得一提——早先版本只有一道「总长过关」的闸门，一篇前几节草草几句、总字数却达标的浅层心得照样能混过去，于是补上了逐节核查。

六、两轮自审自改与九条硬检查

每篇论文内部走五步，顺序进行、一步等一步：初稿 → 审稿一 → 改稿一 → 审稿二 → 改稿二（终稿）。四篇之间并行，每篇内部串行。

审稿的角色设定是「调转刀口审自己刚写的那篇」，规矩写得很明确：审稿不是夸奖、不是复述、更不是打分，要逐条挑出可指认的问题，每条引用论文原话作证据，并给出可操作的改法。九条硬检查依次是：有没有滑回传统注疏、是否真的只用了指定的那一件工具、这件工具是否落到具体字句、「错读成发现」那一刀是否真的落下、有没有把传统读法稻草人化、改写是不是真的换了眼睛、证伪条件是否真能被证伪、学术规范与杜撰、第六节应用是否落到实处。

其中第五条特别值得你留意：有没有把传统读法写得比实际更蠢，好让自己的解构显得高明？如果有，这篇论文就是在打假靶子。一套解构工具最容易堕落的方向就是这个，工具把它写进了自查清单。

改稿由写作基底自己完成——审稿人挑毛病，作者自己动笔改，这符合真实的审稿流程。你可以把审稿一、审稿二指定给别家基底，让另一双眼睛来挑。页面明确提示：审稿意见往往比终稿更能暴露基底的真实水平——看它敢不敢承认自己刚才在说套话。

七、创新智商：五维评分与「不许自评」

四篇终稿定稿后各自独立送评一次，用的是站内的 SDE 创新智商评分标尺，五个维度独立打分，不许直觉给综合分：

S 结构精确度（权重 0.20）看论证是否严密可重现；D 差异锐度（0.25，最高权重）看是否切开了旧概念切不开的辨别面、是否命名了一个之前「看见但说不出」的现象；E 纠缠深度（0.20）看跨域之间是结构性咬合还是单纯类比；I 不可还原性（0.20）看把核心命题压到五十字以内能否被已有命题一比一替换；F 可证伪性（0.15）——这一维最容易掉分，找不到证伪条件一律不超过一百分。综合分按权重加权算出，层级标尺上一百三十上下是资深学者，一百五十是提智达标线，一百六十是典范级。

评分纪律里有几条是为了防止分数注水：每个维度必须给出直接引用原文的证据句；必须给出至少一处扣分句，精确引用让分数掉下去的那一句；综合分必须能用公式重算出来；不因为看到内部术语就高估，也不因为通俗易懂就低估；还要给出从当前层级提升到下一层级的具体动作，不许说「写得再深入一点」。

最重要的一条是硬闸：不许自评。评估基底若与写作基底同厂同型，直接拒绝运行，要求换一家来评。理由说得很朴素——量尺一旦由被量的人自己拿着，分数就不可读。所以跑之前请准备第二家基底的 Key，哪怕只用于评估。

八、碰撞篇：四道涌现闸与词频删除检验

三条 SDE 链全部定稿之后，工具才发起第五篇：碰撞篇。它拿三篇终稿当原料，试着涌现一个任何一篇单独都到不了的新判断。

碰撞分三阶：先找出三处接缝（两两相撞暴露的冲突与互补），再从接缝里找出那条三篇都在绕、却都没点破的暗流并给它命名——名字必须用这段经典自己语域里的词，不许用招牌话。然后过四道硬闸：其一不可还原，压到五十字以内看能否被任一篇的核心命题一比一替换，能替换即为假涌现；其二三链全承重（删除检验），逐条写清方程贡献了什么、路径贡献了什么、原理贡献了什么、删掉任一条会塌哪里；其三不是拼接，读起来必须是一个东西，有单一的、一句话能说清的内核；其四可证伪，带可观察落点、必要时带时间窗。

第二道闸之外，工具还加了一层机器判定：词频删除检验。它不去问模型「你用上三条链了吗」（问了它总说用上了），而是数三条链各自的特征词在碰撞篇里出现了几次——某条链的特征词一次都没出现，就是删除检验没过，页面会直接标红提示这次碰撞更像加法而非化合，建议重跑。这道闸只能查「有没有用」，查不了「用得深不深」；后者看创新智商评分。

如果四道闸过不了，工具被要求诚实报「未涌现」：在正文里说清为什么这次没有产生不可还原的新结构、三篇为什么更像并列而非化合。一次诚实的未涌现，比一个装饰性的假典范有价值得多——看到这个结果不要以为工具坏了，那恰恰是它在正常工作。

九、逐步操作

第一步·填 Key、等内功。选写作基底并填入对应的 API Key。八家任选，档位已锁定为各家顶配旗舰，不提供快速档——这台工具的设计前提就是让模型慢慢想。页面顶部内功加载状态变绿才可开跑。境外基底（GPT / Claude / Gemini，以及出于浏览器兼容的 MiniMax）经本站中转转发，只转发、不存储、不记录；Key 无论哪种都只存本机浏览器。

第二步·贴经典。最长五百字，一句到一段最好。旁边的「出处」栏建议填上书名与篇章——它帮两边的解读都对准位置，尤其能减少传统经学那篇的走偏。

第三步·设审稿与评估。审稿一、审稿二可以跟随写作基底（自己审自己），也可以各指定别家。评估基底必须换一家，同基底自评会被强制拦截。换了厂商，上方会多出一个该厂商的 Key 输入框。

第四步·点生成，然后耐心等。全程约二十七路模型调用（一次心得 + 每篇五步 + 各送评一次 + 碰撞 + 碰撞篇送评）。篇幅预算已大幅放开、不设紧张上限，顶配深思档想思考多久就思考多久——单步可能十几分钟，每篇论文全程可能一小时以上。这是排除掉「预算不够被砍」这个故障模式之后必然的代价。中途不要刷新页面。

第五步·取货。「分批导出 PDF」共十二份（四篇初稿 + 四篇改稿一 + 四篇终稿），碰撞篇完成后升为十五份。无论某篇某阶段成功与否都会导出——失败或未进行的阶段会生成一份写明原因的 PDF，不静默跳过。浏览器可能弹出「允许多个下载」，请允许。

十、常见问题

为什么这么慢？顶配档、不砍预算、每篇内部五步串行，这三条加在一起就是慢。慢是这台工具的设计选择，不是故障。想快请去金点子发生器。

可以只跑一段很长的文本吗？不行，五百字是硬上限。想解构整章，请自己切成几段分别跑，然后对读——这样反而更能看出章内的层次。

四篇分数都不高怎么办？先看扣分句。评分纪律要求评估基底精确引用让分数掉下去的那一句，那一句往往就是这段经典最难解构的地方，也是最值得你自己接着想的地方。

碰撞篇报了「未涌现」，是不是白跑了？不是。你仍然拿到四篇论文和一份诚实的失败诊断。可以重跑碰撞，也可以先看看三篇终稿里是不是有一篇本身就弱——弱的那条链撑不起化合。

它会编造注家和文献吗？有「绝不杜撰」的硬约束，审稿把杜撰列为最致命的问题。但这挡不住全部——凡要引用的，请自己核。

同一段经典跑两次，结果会一样吗？不会。心得每次重写，角度的细微差异会顺着传导进三篇论文；两次结果并排读，能看出这段文字有多少种可能的切法。

解构宗教经典会不会冒犯？工具解构的是文本被理解的方式，不是信仰本身；产出里也被要求用这段经典自己的语域说话、不许出现学派招牌词。真要用于公开场合，请自行斟酌语境。

能用手机吗？能打开，但全程可能几小时且不能刷新页面，请用电脑浏览器。

十一、边界与承诺

第一，这是解读，不是定论。五篇论文给的是五个断面，不是这段经典的正确答案。经学有它自己积累千年的审慎，工具专门留了一条传统经学的生产线来提醒这一点。

第二，诚实是被做成关卡的：不许自评的硬闸、词频删除检验、四道涌现闸、九条审稿硬检查、绝不杜撰、失败阶段也要导出一份写明原因的 PDF——每一条都在给产出设置一个你能亲手检查的关口。你的活儿不是收下五篇论文，而是拿着这些关口逐一验。

第三，费用与责任在你。全程用你自己的 Key、烧你自己的额度；产出若要引用或发表，文献自己核、判断自己担。

补一句关于分数的：一百五十是标尺上的提智达标线，不是每次都该拿到的成绩。多数轮次会落在一百三十几到一百四十几，这说明评估基底守住了纪律。看到四篇齐刷刷高分，反而应当去翻它的扣分句与证据句——查不出扣分句的评分卡，本身就不合格。

第四，一个读法上的建议：先读传统经学那篇，再读三篇 SDE，最后读碰撞篇。顺序反过来，你会被最花哨的那篇带着走，而看不见它是从哪一步开始与传统读法分道的。
