🔬 DeepSeek 浏览器直连测试

这个页面会用你的 Key 发一个最小的测试请求给 DeepSeek，判断"浏览器能否直接调用 DeepSeek API"。结果决定我们要不要加代理服务器。
点一下，等几秒。测试只花极少 token（约 1 个字），几乎不耗钱。
这个测试在看什么？

情况① 如果返回 ✓ 成功 → DeepSeek 允许浏览器直连，金点子发生器可以零服务器运行。

情况② 如果报 CORS / 跨域 / Failed to fetch → 浏览器被拦截，需要加一个轻量代理服务器。

情况③ 如果报 401 / 402 / 模型不存在 → 能连通（CORS没问题！），只是 Key 或模型名的问题，换正确的再试。
