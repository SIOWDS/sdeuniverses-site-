能力是长出来的：
一套按成熟度分阶的培养序列

Ⅰ一、「我教了，他就该会了」——为什么这个期待总落空

很多老师和家长，心里都藏着一个隐秘的期待：我把这个能力教给他了、讲清楚了、示范过了，他就该会了。可现实一次次地打脸——你明明教过了，他还是不会;你明明讲清楚了，他还是做不到。于是你困惑、着急，甚至怀疑他是不是不用心。

问题的根，往往不在孩子不用心，而在这个期待本身错了：能力，从来不是「教一次就会」的东西——它不是一个可以「一步到位」地安装进去的软件，而是一株需要从原初、经过成长、才慢慢长到成熟的「苗」。你「教」的那一次，最多是播了一粒种、或浇了一次水，而一株苗从破土到长成，中间要经过许多个阶段，急不得。

SDE 有一个判断：任何一种成熟的能力，都是「成熟态」，而不是「原初态」——它是长出来的结果，不是一开始就有的样子。指望一个还在「原初态」的能力，一教就跳到「成熟态」，就像指望一粒刚播下的种子，明天就结果——违背了它生长的规律。这一篇，就给你一套「把能力当苗来养、按成熟阶段一阶一阶扶着长」的培养方法。

Ⅱ二、能力不是一步到位的，是一阶一阶长出来的

先把这个根本视角说透。我们常常把「会一个能力」，看成一个非黑即白的开关——要么会，要么不会。可真实的能力，从来不是开关，而是一条从「完全不会」到「炉火纯青」的、连续生长的光谱。

一种能力，要从它最初的、笨拙的、需要处处扶持的「原初态」，经过一段跌跌撞撞、时好时坏的「成长态」，才慢慢长到那个稳定、自如、甚至能教别人的「成熟态」。这中间的每一阶，都是必经的，跳不过去。你看到的高手那种行云流水的「成熟态」，是他从原初态一阶一阶长上来的结果，而不是他一开始就有的样子。

这个视角一换，教学的心态就变了。你不再指望「教一次就会」（指望苗一夜长成），而是接受「能力要一阶一阶地长」（陪着苗慢慢长大）;你的任务，也从「把知识灌进去」，变成了「判断他此刻长到了哪一阶，然后给这一阶该有的扶持」。这才是尊重能力生长规律的教法——不拔苗助长，而是按苗此刻的阶段，扶它往上长。

Ⅲ三、把一种能力，拆成从原初到成熟的生长台阶

要「按阶扶苗」，第一步是把你要培养的那种能力，拆成清晰的生长台阶。任何能力，大体都能拆成三个大阶（每个大阶里还可以再分小阶）。

把一种能力拆成生长台阶（以任何能力为例）
  1. 原初阶（笨拙·依赖扶持）：刚接触，处处不会、处处别扭，做每一步都要人手把手地扶、时时提醒。能勉强模仿着做，但离开扶持就散架。
  2. 成长阶（跌撞·时好时坏）：开始有点感觉了，能自己做一些，但不稳定——有时做得不错，有时又退回去，会犯错、会反复。这一阶最长、也最关键。
  3. 成熟阶（自如·能教人）：稳定、自如、不用刻意想就能做对，甚至能灵活变通、能把它讲给、教给别人。这才是能力真正长成的样子。
  4. 再把每大阶切成小台阶：把「原初→成长→成熟」这条大路，再切成学生一步跨得上去的一个个小台阶——每个小台阶，都是他努力一下够得着的下一步。

拆台阶的意义，是让你手里有一张「这株苗要怎么长」的生长地图。有了这张地图，你就不会再用「会/不会」这种粗糙的眼光看学生，而能精确地判断：他此刻长到了哪一阶、下一个该扶他上的台阶是哪个。教学的精准，就藏在这张台阶地图里。

Ⅳ四、诊断：这个学生，此刻在哪一阶

有了台阶地图，第二步是诊断：这个学生，此刻这株苗，长到了哪一阶?诊断准了，才能给对扶持。

诊断学生此刻在哪一阶
  1. 看「离开扶持行不行」：一撤掉提示、示范、帮助，他就完全散架 → 还在原初阶;能自己做一些但不稳 → 成长阶;稳定自如 → 成熟阶。
  2. 看「错误的性质」：错得毫无头绪、方向都不对 → 原初阶;方向对、但细节反复出错、时对时错 → 成长阶;基本不错、偶有失误能自己纠 → 成熟阶。
  3. 看「能不能变通」：只能照着一模一样地做 → 原初/成长阶;能在新情境里灵活运用、甚至讲给别人听 → 成熟阶。
  4. 分能力、分点地诊断：一个学生在不同的能力上，可能处在不同的阶——别笼统地判「这孩子行不行」，而要具体到「这个能力，他在哪一阶」。

诊断最忌讳的，是用一个笼统的、贴标签式的判断（「这孩子聪明/笨」），代替具体的、分阶的诊断（「这个能力，他此刻在成长阶的哪一步」）。贴标签，既不准，也伤人，还没法指导教学;而分阶诊断，才能告诉你「下一步该扶他上哪个台阶」。诊断得越具体、越对准某一阶，后面的扶持就越有的放矢。

Ⅴ五、原初阶：先「扶着走」，别撒手

诊断出学生在某个能力的「原初阶」（笨拙、处处依赖扶持），这一阶的教法核心是——大胆地「扶着走」，别过早撒手。

原初阶的扶持
  1. 手把手示范，拆到最细：把动作拆到最小的一步，清清楚楚地示范给他看，让他先能照着模仿。这一阶，充分的示范和引导是必需的，不是「惯着」。
  2. 给足脚手架：提供模板、步骤清单、提示、范例——这些「脚手架」帮他在还站不稳时，先把动作做出来。
  3. 降低难度，保证他能成功一次：把任务简化到他扶着能完成的程度，让他先尝到「我做到了」的成功——原初阶的信心，比什么都重要。
  4. 别急着撒手：这一阶最忌讳的，是看他做了两下，就以为他会了、马上撒手放他自己去——他会立刻散架、受挫。扶稳了，再谈放手。

原初阶的要害，是接受「他现在就是需要扶」，并大方地扶。有些老师觉得「一直扶着是惯坏他、不利于独立」，于是过早撒手——结果苗还没扎根就被放倒了。原初阶的充分扶持，不是溺爱，而是一株幼苗必需的支架;等它长壮了，支架自然会撤。此刻，扶稳，是为了将来能放手。

Ⅵ六、成长阶：慢慢「放手」，容许他跌

诊断出学生进入了「成长阶」（能自己做一些，但不稳、会反复），这一阶——通常是最长、也最关键的一阶——的教法核心是：慢慢地、有节奏地「放手」，并容许他跌倒、反复。

成长阶的扶持
  1. 逐步撤掉脚手架：不是一下全撤，而是一根一根地、随着他越来越稳，慢慢撤掉提示、模板、帮助，把「自己做」的空间一点点还给他。
  2. 容许试错和反复，别慌：成长阶时好时坏、进两步退一步是常态，不是退步。别一见他犯错、退步就慌、就否定，那恰恰是成长的正常样子。
  3. 把犯错变成台阶：他犯错时，别直接给答案，引导他自己发现「错在哪、为什么」——理解，恰恰常在「我原来错在这」的那一刻，最深地长出来。
  4. 难度跟着他涨：随着他变稳，一点点提高难度，始终让任务落在他「跳一跳够得着」的地方，让能力在恰当的挑战中持续长。

成长阶的要害，是耐心，和对「反复」的宽容。这一阶又长又颠簸，学生会一次次地「明明会了又不会了」，最考验老师的定力。此时最伤人的，是用成熟阶的标准去要求还在成长阶的他——一看他反复、出错，就急、就否定、就说他「怎么又不会」。请记住：反复，是成长阶的常态，不是失败;稳住，容许他跌、扶他再起，这株苗才能穿过这段颠簸，长向成熟。

Ⅶ七、成熟阶：让他「自己走」，并教会别人

诊断出学生进入了「成熟阶」（稳定、自如），这一阶的教法核心是：彻底放手，让他独立地走，并把能力用出去、教出去。

成熟阶的扶持
  1. 彻底放手，给真实的舞台：撤掉一切脚手架，给他真实的、有挑战的任务，让他独立地完成——成熟的能力，要在独立的实战中，才能真正巩固。
  2. 引向「变通与创造」：鼓励他在新情境里灵活运用、甚至创造性地发挥，把能力从「会做」推向「会用、会变」。
  3. 让他「教别人」：让他把这个能力，讲给、教给还在前面阶段的同学——「教」是最深的「学」，能教明白，说明他真正长到了成熟态。
  4. 别再过度指导：这一阶如果老师还处处指点、不肯放手，反而会束缚他、让他长不到真正独立自如。此时，退后，信任，放手。

成熟阶的要害，是老师要舍得、也敢于「退场」。一株苗长成了，就该让它独立地经风雨、见世面;老师若还紧紧扶着、处处指点，反而挡了它长成参天大树。教育的一个深意，正在于此：好的扶持，最终指向「不再需要扶持」——让他自己走、走得比你远。能放手让他独立、甚至让他去教别人，是这株苗真正长成的标志，也是老师功成身退的时刻。

Ⅷ八、按阶扶苗，别拔苗

把全文收成一句可以带走的话：能力是长出来的——按它此刻的阶段扶苗，别指望一步到位、更别拔苗助长。

「我教了他就该会」的期待，之所以总落空，是因为它把能力当成了可以一步安装的软件，而能力其实是一株要一阶一阶长的苗。而这一篇给你的，是一套「按阶扶苗」的方法：把能力拆成从原初到成熟的生长台阶，诊断学生此刻在哪一阶，然后给这一阶该有的扶持——原初阶扶着走、成长阶慢慢放手容他跌、成熟阶彻底放手让他自己走并教人。

这套方法最能救人的一点，是它让你不再因为「教了还不会」而焦虑、而错怪孩子——因为你明白了，那不是他不用心，而是苗正在它该在的那一阶，慢慢地长。你要做的，不是催它、逼它、拔它，而是耐心地判断它长到了哪、给它这一阶该有的水和光，然后信任它，会一阶一阶地，长向成熟。按阶扶苗，别拔苗——这，是尊重生长规律的教育，也是最终能真正把能力养成的教育。

成熟的能力，是「长出来的结果」，不是「一开始就有的样子」——它要从原初态，经过成长态，才长到成熟态。
别指望「教一次就会」（拔苗），也别用成熟阶的标准要求还在成长阶的他。诊断他在哪一阶，给这一阶该有的扶持——按阶扶苗，苗自会长向成熟。
