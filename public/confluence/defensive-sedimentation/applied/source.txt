TITLE: 查补丁，不听口号：建立理论边界的版本与使用账
SUB: 一套识别收缩、扩张、公开收益和新增承诺的争议审计流程
ABS: 本文把“理论边界在挑战中重划”的判断落成可执行审计。流程按时间保存主张版本、挑战类型、回应方向和公开使用记录，区分正常进步与只解除当前反例的防守，并规定何时应停止追责或收回判断。

== 这套方法做什么、不做什么
这套方法不裁决某个医学、经济学或心理学理论在事实层面最终正确与否，也不把学术修订当作道德污点。它处理一个更窄的问题：某项主张面对挑战后，是否只改变“自己原来覆盖什么”，从而让本次反例失效，却没有增加可由未来事实检查的新承诺。最小动作是选一场持续三年以上的争议，建立按日期排序的四栏账：挑战、挑战前主张、回应后的范围、新增可检验承诺。若最后一栏长期为空而范围反复移动，再进入深入审计。

先做一个案例，不建立评判整个学科的排行榜。启动卡还要写明审计服务的决策：更新教材、评估政策引用、澄清研究史，还是判断是否继续投入检验。没有现实用途就不扩大检索。指定材料管理员与独立复核者，设置结束日期和最多文献量。任何结论分成“事实真伪未裁决”“范围动作观察”“责任关联强弱”三栏，防止读者把边界审计误当最终科学裁判。被审计方在发布前有核对材料的机会。范围卡由委托方和审计负责人共同签字，新增目的必须另开项目，不能在检索中途悄悄扩权。

- 不负责判断理论总体真假。
- 不负责推测维护者内心动机。
- 不负责用审计处罚学者或学生。

== 先守住边界
审计只处理公开主张和可核版本，不调取私人通信，不把未发表草稿当承诺。作者可拒绝提供超出公开范围的材料，也可要求更正错误引述；编辑收到更正后要通知用过旧编码的复核者并删除无保留理由的副本。涉及名誉、师生权力或组织惩罚时，审计员暂停个人归责，升级给独立伦理或申诉渠道。旧文本引用须保留上下文，不能截句制造强版本。学生、下属和年轻研究者不因加入同一学科自动继承前辈责任；只有继续使用、代表或受益的连接才进入公开使用记录。

档案访问分原件、编码和公开三层，作者同意复核不等于同意人身评价。学生、下属或少数意见者可匿名提交版本证据、撤回身份关联并退出审计。若审计可能影响聘用、课程或资助，结果只针对主张版本，且给当事人查看上下文与纠错期限；无法保证不报复时，只做去身份的历史分析。

这套方法不裁决某个医学、经济学或心理学理论在事实层面最终正确与否，也不把学术修订当作道德污点。它处理一个更窄的问题：某项主张面对挑战后，是否只改变“自己原来覆盖什么”，从而让本次反例失效，却没有增加可由未来事实检查的新承诺。

== 先定位：问题究竟卡在哪一环
选一场确实逼出理论修订的挑战，把修订前后的公开文本并排。审读者只在这里逐一回答：挑战以前公开主张的范围是什么？ 回应究竟改了内容还是只改了范围？ 这次收缩或扩张新增了什么失败条件？ 强版本过去是否被维护者公开使用？ 所有重划叠加后还剩多少未来风险？

答案不能来自维护者事后的口头概括，要能回到页码、发布日期、演讲录音或实际预测。某个时期查不到材料，就在版本链上留缺口；缺口本身不是收缩，也不能替理论补一条从未说过的限定。

先以防守性重划账登记每次改边界的日期和触发反例，再用收缩—扩张比区分退守与兼并。防守沉积厚度看的是多轮修补累计拿走了多少风险，公开使用责任率则核查强版本是否真被拿去解释或预测，而非只存在于批评者笔下。

复核人抽取一次看似合理的修订，尝试用修订前规则处理同一案例，并写出两个版本各自会输在哪里。若新版本没有新增失败条件，只有更灵活的措辞，这次重划不能结案；定位结果还须落到下一次公开承诺，而不是停在历史评价。

== 一张不下结论的事实底稿
事实底稿按日期排四栏：挑战原文、挑战前理论边界、回应后的边界、回应新增的预测或失败条件。事实栏保存页码、版本和实际公开使用；推断栏才标“收缩”“扩张”或“只解围”。防守性重划账逐次登记，收缩—扩张比不合成好坏分，防守沉积厚度记录累计删除的风险，公开使用责任率只纳入维护者真实采用的强版本。每个字段必须改变一次版本判定或责任连接，答不出即删；历史缺口写未知，不推定从未使用。

防守性重划账保存版本先后，收缩—扩张比只做方向分布，防守沉积厚度衡量多轮修补拿走的失败风险。公开使用责任率把历史强版本接回说过它、用过它的人，防止维护者把批评对象改写成无人主张的稻草人。一次扩张可能增加风险，一次收缩也可能澄清对象；只有逐条查看新失败条件，数字才有意义。复核者应从账上任抽一条，找出挑战文本、回应文本和公开使用痕迹。任一环找不到，这条记录退回“待证”，不得用估值补齐。账中还要保留维护者当时为何改动的说明，使合理修订与纯粹卸责可被后人区分。

== 建立防守性重划账
每个版本记录原句、出处、日期、受众、主张强度、适用对象和失败条件。原句保留上下文，另加一栏用普通语言概括，但概括必须由另一人复核。强度不靠主观评分，而看它排除了多少可能、允许多大范围的现实后果。版本表按时间排序，不覆盖旧行。

遇到相同概念不同表述时，先列为两项，再用边界案例判断是否等价。表的目的不是收集金句，而是回答挑战发生以前，维护者愿意让哪些观察算作对自己不利，以及公众被允许据此做了什么。版本表附三个代表性例子：明确在范围内、明确在范围外、原文未说明。

让被审计方核对这些边界例比争论抽象强弱更有效。若公共版本为简化表达，记录简化目的与附近限制语，不能截句。每次合并版本都保留映射关系，避免把异议磨平。完成后随机抽取十分之一由第三人重新编码，一致性不足就先修说明，不发布频率结论。原始截图与可搜索文本同时保存，便于后来核对转录、断句和上下文是否改变了意思。抽查发现语境不完整时，先补材料再编码，不能靠推断填满空栏。

动作甲：并排挑战前后原句；动作乙：标出新增与删除的覆盖范围。版本管理员负责，异议方复核，时限为三日；禁止用今日摘要替旧文本，单条记录可撤回待证。

== 计算收缩—扩张比
收缩型回应常出现“我们从未主张如此强”“这只是大众说法”“该理论只适用于某些条件”。操作上比较挑战前后适用对象、时间和因果力度，标出被移出范围的部分。

随后查被移出版本是否由责任单位公开使用，并记录产生的资源、临床、教育或政策后果。有公开使用不等于实质理论必错，只表示不能用“从未属于我们”完全解除责任。

若维护者早已持续澄清，媒体仍自行夸张，则收缩可以成立。审计结论必须把事实正确性与范围责任分栏，避免越权裁决。

对每次收缩做一次“删除测试”：把新增限制从回应中拿掉，原挑战是否重新命中。答案为是，说明限制承担了防守功能；答案为否，可能只是文字澄清。

再检查限制是否在挑战前的同类场景中一贯使用，避免误把早有边界当临时退守。公开使用记录按维护者直接使用、授权使用、知情未纠正、外部误读四级标记，不用单一有无覆盖复杂责任。两名审计者分别完成删除测试，再比较边界判断；不同意见不得被一个总标签覆盖。

动作甲：把重划分为向内收与向外包；动作乙：保留同时发生的混合案。编码员执行，第二编码员复核，时限为一轮阅读；禁止强塞单类，分歧时撤销比率只报案例。

== 计算防守沉积厚度
用月或日为单位建立事件轴，把挑战发表、公众传播、正式回应、教材改版和政策更新放在同一图上。关键不是谁先有想法，而是哪一版本在挑战前已可查。

若范围限制早于反例并稳定存在，不能说是被撞后才退；若限制恰在挑战后出现且无新承诺，防守解释更有力。时间轴还要标出响应延迟，避免把多年后正常发展误判为即时防守。

所有日期链接到原材料，无法确定时用区间，不凭记忆填空。时间轴至少加入一个挑战前等长窗口和一个挑战后窗口，比较范围词语与失败条件的变化。自动文本检索只能帮助找词，最终仍由人读语境。

多篇材料同日发布时，按提交或预印本日期判断，避免把出版延迟当响应。若关键草稿无法取得，降低因果措辞，只说“时间上相随”。图上用不同颜色分事实新证据、范围声明和公共使用，防止三类事件混成一条线。时间无法确定的节点用区间和虚线表示，不得为了图形整齐而伪造事件先后。图表发布时附原始事件表，使读者能够从节点返回材料，而不只接受颜色暗示。

动作甲：累计被拿走的失败条件；动作乙：新增一条未来可输观察作对照。理论审计员负责，领域同行复核，时限为版本结项前；禁止把篇幅变短当沉积，定义可回滚。

== 计算公开使用责任率
对每项强版本建立“收益—责任”表：谁说、对谁说、带来何种行动、维护者是否获益、何时知道误读、有没有公开纠正。收益可包括资金、使用量、政策地位和公众信任，不只算金钱。产业独立营销若无学者参与，不能直接归责；但若维护者反复引用营销成果、提供背书或长期不纠正明确误解，关联增强。纠正必须在相近受众和传播强度上进行，学术脚注不自动抵消大众广告。表格只判断范围责任，不推断个人动机。每项关联附证据等级：直接署名、正式授权、可查合作、推定知情、无关联。只有前三类可支持较强责任判断，推定知情必须写不确定性。收益后果也要具体到行动，不把一般声誉自动换算成获利。若维护者后来公开纠正，记录纠正覆盖面和延迟，不要求抹去全部旧后果。审计语言使用“版本责任连续”而不是“欺骗”，坚持对结构作判断。纠正若只到达专业读者，而强版本仍面向公众流通，就只能记为部分完成，不能冲销旧影响。收益不确定时写成范围，不以一个精确数掩盖证据不足；责任判断也随证据等级降低。

动作甲：查强版本是否真被教材、政策或传播采用；动作乙：核对维护者纠正机会。资料员执行，作者或代表复核，时限为五日；禁止按学科标签归责，错误连接立即删除。

== 区分正常修订与只解围
为每次范围变化做“三问”：是否说明新条件从何而来；是否交出挑战发生前未知的预测；是否规定下一次什么结果会失败。三问至少一项实质成立，才有资格进一步判断为进步；三项全空而当前反例刚好失效，记为只解围。正常修订也应承认旧版在哪一处失败，而不是把历史版本悄悄删除。

审计者不得以“改变就是逃避”下结论，也不得因新文本更精确就自动判进步。真正分界是新版本是否承担了未来风险。三问之后加一项兑现跟踪：到复核日，新预测是否真正测试，失败条件是否被遵守。只写承诺不执行，也可能成为装饰。

若预测失败而理论明确再修，记录为学习；若失败后再次移动范围，形成连续防守链。审计报告把“提出新承诺”和“承诺兑现结果”分开，不用承诺数量代替质量。对尚未到期的版本只做暂定分类。尚未到期的承诺不进入兑现比例，避免把写下一句未来计划提前算成理论进步。兑现失败若被诚实记录，同样算作可检验承诺发挥作用，不能只奖励预测命中。

动作甲：写明修订新增的预测；动作乙：用下一宗案例尝试让新版失败。修订者负责，未参与修订者复核，时限为下一测试前；禁止只提高措辞弹性，可撤销“进步修订”标签。

== 角色与权限分开
执行者负责找版本、对原句和编码重划，不评价人格。决策者决定某条记录进入待证、正常修订或防守性重划，并承担公开说明。复核者须能查看上下文、听取异议方和撤销错误连接；原决策者不得独自复核自己。对象是被审查的主张版本及受归责影响的人，不是整个学科。作者或代表拥有纠错入口，却不能删除真实公开使用。资料保管者单独控制原件，防止编码者覆盖历史。若审计用于课程或机构治理，再增加权利代表，确保学生和下属不会因提出反例受罚。 发布审计前，把材料清单、排除理由和初步编码交给被审计方核对事实，给出固定期限补充记录。对方有权指出遗漏和语境错误，但不能删除不利公开材料。审计报告逐条回应主要异议，未解决部分标为不确定。另请一名不了解双方立场的复核者抽查至少十分之一记录。若新材料推翻原分类，应公开更正，而不是把审计权威置于同一套无法失败的保护中。审计团队在开始时写下自身失败条件，例如关键分类一致性低于约定值、挑战方向不能预测回应方向、公开使用与收缩无关联。

== 读数、采集办法与代价
一条主张在连续挑战中的版本链先定材料边界，各项读数分别报告，不生成总分：
- 防守性重划账｜来源：挑战、旧版、新版和使用记录；频率：每次公开修订一次；缺失：表示版本链有缺口；反向优化：少存旧版美化历史；改善上限：能重放一次边界移动即够。
- 收缩—扩张比｜来源：已编码的范围变化；频率：一个版本周期一次；缺失：表示混合案不能分型；反向优化：把混合案塞入有利方向；改善上限：只显示方向分布，不设最佳值。
- 防守沉积厚度｜来源：累计删除与新增的失败条件；频率：每轮挑战后；缺失：表示风险空间不可比；反向优化：拆小措辞制造厚度；改善上限：能指出可输空间是否收窄即够。
- 公开使用责任率｜来源：维护者真实采用与纠正材料；频率：档案补齐时更新；缺失：表示历史材料不足；反向优化：只保留澄清、删除获益使用；改善上限：只连接可核责任，不追求高低。

防守性重划账以一次公开修订为记录单位，必须同时含挑战、旧边界和新边界。收缩—扩张比只报告两个方向各有多少次；防守沉积厚度按累积删除的失败条件描述，不换算成优劣分。

== 最容易把方法做坏的三种方式
防守性重划账一旦脱离自己的材料，最先出现以下三种坏法：
- 坏法：只检索批评者引用，制造无人真正主张的强版本。保护：保护措施是核对维护者公开使用与纠正记录。
- 坏法：把任何反例后修订都判作防守。保护：保护措施是检查新版是否新增预测与失败条件。
- 坏法：审计变成人员诚信排名，年轻成员继承全部责任。保护：保护措施是只评主张版本，并写清受益与代表连接。

发布审计前，把材料清单、排除理由和初步编码交给被审计方核对事实，给出固定期限补充记录。对方有权指出遗漏和语境错误，但不能删除不利公开材料。审计报告逐条回应主要异议，未解决部分标为不确定。另请一名不了解双方立场的复核者抽查至少十分之一记录。若新材料推翻原分类，应公开更正，而不是把审计权威置于同一套无法失败的保护中。审计团队在开始时写下自身失败条件，例如关键分类一致性低于约定值、挑战方向不能预测回应方向、公开使用与收缩无关联。结果不利时必须保留这些检验，不能把研究改写成纯案例随笔。

== 什么时候应该停，什么时候说明理论可能不对
操作停手线：审计转成人员惩罚、引用脱离上下文、历史材料不足却被强行编码时停；撤销标签并开放更正。

理论撤回线：边界变化持续新增预测与可失败条件，风险空间未收窄，公开强版本也无维护者使用证据时，撤回防守沉积判断。

当检索无法覆盖关键时期、责任单位无法合理界定、材料涉及个人隐私或临床保密、争议已转为骚扰具体研究者时，应停止或缩小审计。不得用版本表发动人肉搜索、要求个人为整个领域负责，也不得把诚实改口当作失信。若事实争议尚未解决，范围审计只能并行，不能宣布理论真伪。项目达到预定材料量且连续两轮没有新类型时结束，不能为寻找预设模式无限扩搜。若多数范围限制在挑战前已清楚公开，范围变化普遍伴随独立新预测，并且公开强版本记录不能预测后来的收缩方向；或不同审计者无法可靠区分内容修改与范围重划，那么母文核心判断在该样本中不成立。此时应撤回“防守沉积”诊断，只保留描述性历史。失败报告同样上线，避免这套方法把任何理论史都画成一堵被撞出来的墙。
