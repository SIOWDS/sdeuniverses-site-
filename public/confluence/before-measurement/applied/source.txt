TITLE: 先把球门线画清，再去增加摄像机
SUB: 面向研究、医疗讨论和人工智能评估的对象资格对齐流程
ABS: 本文提供一套“先认定、后测量”的操作方法：把争议拆成对象资格与事实测量，要求各方事前写出判决条件，用关键分歧案例比较不同口径，并规定何时停止争论。它不替代专业诊断，也不允许借口标准差异回避已有安全规则。

== 这套方法做什么、不做什么
这套方法不负责判断意识、疾病机制或人工智能能力的最终本质，也不替代临床指南、伦理审查、法规与专业人员。它处理一个更窄的工作：当各方不断增加证据却仍得出相反结论时，检查他们是否把不同可观察事件当成“对象真正出现”的门槛。最小动作是建立一张对齐表，每方各写一句“观察到什么，我就承认它在场”和一句“观察到什么，我就收回主张”，再找出两句第一次分开的地方。若门槛相同，转去修测量；若门槛不同，停止堆数据，先比较口径。

全流程只在一项具体争议上试跑，不建立包办所有概念的总词典。启动人先写明争议产生的实际后果：它是否阻挡研究决策、造成重复检查、影响服务，还是只是理论兴趣。没有现实决策点的争论可保留，不必强行收敛。选择一个已有三次以上重复争论、资料可取得且修改可撤回的案例，指定主持人与记录者各一人。方法不产出“谁对”的总分，只产出卡点位置、临时工作口径、待检验分歧和结束日期。若参与者期待一次会议解决本质问题，应先调整预期再开始。

- 不负责替任何一方宣布对象的终极本质。
- 不负责处理设备故障和统计误差。
- 不负责用多数票压掉高风险专业异议。

== 先守住边界
医疗、公共安全和法律决定先沿原有程序运行，本方法不得延迟必要处置。资料对象可拒绝把个人材料用于规则校准，并能从比较页退出；退出后，管理员删除非必要副本并通知曾接收者。双方在开始前分别确认可公开范围、在场标志和可能的不利结果，未取得同意的敏感材料只做去身份摘要。若资格争议引发即时伤害、歧视或服务中断，主持人停止讨论并升级给有法定职责的专业人员。任何一方无权借“先认后测”取消另一方申诉，也不能把未同意者标成缺乏理性。

争议双方分别保存原话，不把人的身份、疾病或群体资格交给试验重新命名。共同判据若会改变治疗、惩罚或权利，必须由有资格者走正式程序。协调者只主持交换，不能替任何一方同意；发现一方受雇佣、师生或照护关系压迫，暂停对称测试，先提供独立申诉和必要支持。

这套方法不负责判断意识、疾病机制或人工智能能力的最终本质，也不替代临床指南、伦理审查、法规与专业人员。它处理一个更窄的工作：当各方不断增加证据却仍得出相反结论时，检查他们是否把不同可观察事件当成“对象真正出现”的门槛。

== 先定位：问题究竟卡在哪一环
先把争议双方各自指向的对象写在纸面两栏，五个诊断句只在本节出现：双方说的是不是同一个对象？ 什么可见事件算对象已经在场？ 什么结果会让各方承认自己错了？ 分歧发生在判别、测量还是解释？ 新数据进入后对象资格有没有被悄悄改写？

每个回答旁放一件可共同查看的材料，例如原始样本、拍摄时间、判定规则旧版和操作日志。数据精度再高，也不能替代“对象何时算在场”的约定；无法确认的格子保持空白，尤其不能用后来出现的结果倒填先前资格。

在场标志对齐表负责显示双方到底共用了哪些标志，对象资格分歧率只统计确实评过同一材料的判断。出现争执时先查万能退路次数：若一方每遇反例便改称对象不同，争论已经不再可裁决。可裁决性读数须附那条可能使本方认错的观察。

请第三人随机拿走一个案例名称，只凭证据重做判别。重做结果若随叙述立场而变，就暂停测量，返回资格定义；若结果稳定，再指定下一位收料者、复核日期和终止条件。

== 一张不下结论的事实底稿
底稿一案一页：争议对象、各方原句、共同看到的材料、各自的在场标志、对象资格、测量读数和事后解释分栏。事实栏只放录像、样本、规则版本与实际判定；推断栏才写“双方认的不是同一对象”。在场标志对齐表保存原话，对象资格分歧率只数共同评过的案例，万能退路次数登记资格被改写的时点，可裁决性读数写明哪项观察会让谁认错。每个字段必须能改变下一步校准、测量或暂停决定，否则删去；不把精度高当作资格已统一。

在场标志对齐表属于判别之前，对象资格分歧率发生在多方判别以后；万能退路次数追踪失败条件是否被撤走，可裁决性读数则回答争论还剩不存在自说自话的出口。四者不是线性得分，而是四个可能卡住讨论的位置。实际案例要能从名称退回原句。例如一条记录被标为万能退路，复核者必须找到哪次反例之后资格标准改变；找不到，就只能记作普通修订。任何部门不得拿对象资格分歧率评价个人，也不能把在场标志的多少解释成对象更真实。

== 建立在场标志对齐表
对齐表只设六列：争议对象、提出方、在场判据、不在场判据、所需观察窗口、允许推翻的结果。每格必须写成能由第三人辨认的事件，例如“在无提示的新任务中连续完成三次”，不能写“真正理解”“明显改善”或“表现自然”。各方独立填写后再交换，防止先看对方答案再调整。

主持人把用词不同但事件相同的行合并，把名称相同但事件不同的行标红。表格不评谁高明，只揭示证据会进入哪扇门。若某方拒绝提供不在场判据，记录为当前不可裁决，不再用新增样本制造虚假进展。填写后做一次“陌生人测试”：请未参加争论但了解基本任务的人依据表格判断三个旧案例。

若其结果与原作者大幅不同，判据还不够可操作，应补充边界例和例外处理。每次修改保留版本，禁止覆盖。表格中的观察窗口尤其重要，同一行为在一分钟、一天和三个月上可能含义不同。若各方窗口不同，把时间差标成独立争点，不用更长数据自动压过短期安全判断。完成表格后，各方各用一句普通话复述对方判据，由对方确认无误。

动作甲：双方各写三个可见标志；动作乙：交换标志重判一宗边界案。主持人负责，未参争议者复核，时限为会前一日；禁止把立场摘要当原句，整表可退回重填。

== 计算对象资格分歧率
从真实或可构造案例中找一个双方判决相反、其他条件尽量相同的最小案例。例如模型停止回答时，一方判能力不足，一方判风险控制；接着保持题目、输入和资源不变，只改变能区分两种解释的一项条件。每方事前写下预期，不能事后换理由。好案例不是极端轶事，而是只跨过一条判据的边界事件。若需要改变五六个条件才能制造分歧，说明口径还太模糊，应继续拆小。最小案例会把漫长理论争论压成一个能观察的分叉，也能暴露双方其实没有在回答同一个问题。为最小案例准备配对案例：只差一个关键条件，其他材料尽可能相同。由不知道各方立场的第三人随机排列，减少期待影响。每方在查看结果前提交预测和允许误差。若结果同时支持两种解释，不宣布平局，而记录为当前设计不可区分，下一轮只改一个条件。最多迭代两轮，仍不可区分就停止，把资源转向更有判决力的任务，不能无限追逐一个也许没有可观察差异的争论。案例材料、预测和判决应一并归档，便于后来复查是否移动门槛。

动作甲：只纳入共同看过的材料；动作乙：把无法判定单列。记录员执行，方法复核者抽查，时限为两次会议内；禁止用估计补分母，发现对象不同即可撤销本轮比率。

== 形成可裁决性读数
对象资格对齐后，另开一张测量表，记录仪器或评分者读的是什么、重复测量是否一致、盲评是否可行、误差范围和缺失数据怎样处理。

不要把“工具可靠”写成“对象真实”，也不要因对象复杂就忽略工具误差。

选取同一批材料让两名不知道立场的评估者独立判读，计算一致案例与分歧案例，并回看分歧来自阈值还是读数。

若工具连约定表现都不能稳定读取，先修测量，不讨论更大理论。若工具可靠而判决仍相反，回到资格表检查是否有人在事后移动了门槛。

测量审计至少包含一次重复、一次换评估者和一次已知样本校准。报告原始不确定范围，不把连续数值强行切成确定标签。缺失值单列，禁止自动归为“不在场”。若某工具由支持某立场的团队开发，邀请另一方复现操作或审查评分规则。工具修订后用新材料复测，不能反复在同一数据上优化到一致。完成这些动作，才能说争议不再主要来自读数本身。每项校准都记录设备、软件版本、操作者和时间；任何一项缺失就暂缓强结论。

动作甲：各方事先写一项认错观察；动作乙：确认该观察现实可取得。项目负责人执行，外部同行复核，时限为测量前；禁止结果出来后改条件，条件不可得则暂停而非假装可裁决。

== 研究项目中的预登记动作
在收集新数据前，把对象资格表、最小分歧案例、主要结果和收回条件写入带日期版本。预登记不必公开全部研究创意，但至少让团队无法在看到结果后悄悄换线。若研究中确需修改判据，保留旧版，把修改标为探索性，并说明新判据将在哪一批独立数据上接受检验。论文或报告同时给出哪些结果支持、哪些结果不利、哪些因测量不足不能判断。

不要把“更多研究需要”当作统一结尾；明确下一项研究究竟是修仪器、比较口径还是检验因果。三类任务预算和成功条件完全不同。项目负责人还应登记停止规则：样本达到多少、效果进入什么范围或资源消耗到何程度就结束。每次中期查看结果都留痕，避免只在有利时停下。若研究发现原对象资格无法操作，允许把原假设判为未检验，而不是换一个门槛继续声称验证成功。最终材料附上版本差异表，让读者看到哪些决定发生在数据之前、哪些发生在之后。这个时间顺序比一段“我们保持客观”的声明更有证据力。

动作甲：冻结对象资格和在场标志版本；动作乙：预写新材料进入后的改版规则。研究者负责，登记保管人复核，时限为采集前；禁止删掉旧版，发现安全风险可撤销登记并转原程序。

== 记录万能退路次数并设置日落
每个临时口径都写版本号、生效日期、适用任务、负责人和复核日期。复核不问“大家习惯了吗”，而看误判案例、漏判后果以及新证据能否区分竞争口径。修改只对之后的判断生效，历史数据若需重算必须保留原结果和理由。工作口径到期只有三种去向：继续、修改、撤回；不能无限以“暂行”逃避评估。若某口径被用于资源、诊断或资格决定，还要提供申诉与人工复核。

版本制度的目的，是让球门线可改但不能在射门之后移动，使协作既能结束当前比赛，也能学习下一轮如何画线。负责人在复核前汇总五个最接近边界的案例，而不是只报总体正确率。受影响者可以提交一个遗漏案例，委员会须书面回应是否在适用范围内。修改理由区分新证据、任务改变和价值取舍，三者不能混写。旧版资料保存到规定期限，访问权限按敏感程度控制。若新口径使历史结果不可比，明确断点，不制造一条虚假的连续曲线。版本治理成功的标志是每次变化可追溯，而不是标准永远不变。

动作甲：每次改称对象不同便登记理由；动作乙：到日落日检查是否新增失败条件。理论维护者负责，争议另一方复核，时限为一次完整测试；禁止无限延期，未增加可输位置即关闭该解释。

== 角色与权限分开
执行者负责保存双方原话、交换标志和重判材料，不决定哪一方本质正确。决策者只选择当前任务采用哪条工作口径，并写明期限。复核者检查共同材料、资格分母和认错条件，原决策者不得独自复核自己。对象既包括被判定的样本，也包括判定会影响到的人；后者拥有拒绝二次使用、退出和申诉入口。医疗或高风险场景另设专业责任人，他可越过试验直接升级处置。记录员不能兼任争议一方发言人；若角色无法分开，就暂停比率，只保留并排事实。 拥有定义权的人可能借流程把自己的球门线写成唯一标准。为此要求三项制衡：受后果影响者能提交边界案例；少数口径与采用理由同时公开；工作标准有复核日期和申诉通道。不能用“大家已同意”压过未参与会议的人，也不能要求患者、下属或普通用户掌握专业语言才有资格指出错判。主持人负责把日常叙述翻成可观察事件，再让当事人确认没有失真。若标准改变资源分配，决策者必须说明误判成本由谁承担。

== 读数、采集办法与代价
一场双方看过同一观察却判法不同的争议先定材料边界，各项读数分别报告，不生成总分：
- 在场标志对齐表｜来源：各方原句、规则与共同材料；频率：每次争议一次；缺失：表示尚无共同入口；反向优化：抄同义词制造一致；改善上限：能支持一次交换重判即够。
- 对象资格分歧率｜来源：共同评过的同一案例；频率：每轮校准一次；缺失：表示对象或样本未对齐；反向优化：删掉难例压低分歧；改善上限：只用于找关键分叉，不追求零。
- 万能退路次数｜来源：带日期的资格改写；频率：一次完整测试后；缺失：表示版本史不足；反向优化：少留书面改口压低次数；改善上限：出现一次无新失败条件即触发审查。
- 可裁决性读数｜来源：预写认错条件和实际结果；频率：条件触发时更新；缺失：表示条件不可取得；反向优化：把容易发生的结果写成认错线；改善上限：只需一条真实可能的不利观察。

在场标志对齐表逐案保存各方原话，不先翻成统一标签；对象资格分歧率只以共同看过同一材料的人次为分母。

== 最容易把方法做坏的三种方式
在场标志对齐表一旦脱离自己的材料，最先出现以下三种坏法：
- 坏法：主持人先替双方选好在场标志，协调变成权力独占。保护：保护措施是各方先写原句，再由第三人主持交换。
- 坏法：用更多小数位遮住对象资格仍不同。保护：保护措施是设备误差与资格分歧分栏发布。
- 坏法：每遇反例就改称对象不同，比较永不到期。保护：保护措施是预写认错条件和资格版本日落日。

拥有定义权的人可能借流程把自己的球门线写成唯一标准。为此要求三项制衡：受后果影响者能提交边界案例；少数口径与采用理由同时公开；工作标准有复核日期和申诉通道。不能用“大家已同意”压过未参与会议的人，也不能要求患者、下属或普通用户掌握专业语言才有资格指出错判。主持人负责把日常叙述翻成可观察事件，再让当事人确认没有失真。若标准改变资源分配，决策者必须说明误判成本由谁承担。对齐的目标是让证据能约束各方，不是让强者更早占住名字。抽样复核应包含最容易被现行线漏掉的人群与场景，而不是只找典型案例。

== 什么时候应该停，什么时候说明理论可能不对
操作停手线：资格讨论延误必要处置、引发歧视或任何一方无法安全表达时停；转回原专业程序，冻结比较数据。

理论撤回线：共同在场标志与对象资格已稳定一致，分歧却只随精度或推理改变；交换规则也不移动结论时，撤回先认后测作为主要解释。

出现急迫安全风险、参与者无法自由表达、标准讨论被用来延迟必要行动、或一方不断移动失败条件时，应停止对齐流程。医疗与公共安全场景立即转入专业处置；研究场景把该主张标为不可裁决；组织场景由更高一级独立复核。若最小分歧案例会给个人造成不可接受风险，不做真实试验，可用历史材料、模拟或直接承认未知。任何时候都不能拿这套方法要求他人证明自己的痛苦、身份或经历“达到门槛”，它只用于共同判断任务，不用于取消人的陈述资格。若在对象资格已经不同的多组案例中，单纯增加测量精度仍持续提高一致率并最终结束争议；或在对象资格完全一致的情况下，证据再多也从不改变判决，那么母文关于“先认后测”的解释力就要下降。
