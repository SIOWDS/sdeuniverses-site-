TITLE: 先找承重气孔，再决定哪条缝该补
SUB: 一套识别存活落差、测试缝合动作并保护再生能力的系统体检
ABS: 本文把“系统可能被成功、标准化和复制缝死”转成实践流程：区分缺陷与承重差异，追踪度量和复制怎样关闭回路，用撤援、新情境和接手测试观察再生，并明确禁止把“保留落差”做成新指标。

== 这套方法做什么、不做什么
这套方法不反对质量控制、标准化、绩效记录、知识库和规模复制，也不允许以“保留差异”为由放松安全、隐私、基本能力和公平底线。它处理一个更窄的问题：某项持续成功的改进是否让系统短期更整齐，却失去在新情境中自行生成回应的能力。最小动作是选一个连续高分流程，列出过去一年消失的例外和判断位置，再做一次低风险新情境测试。先体检，不先宣布系统正在死亡。启动卡写明主系统、当前成功标准、不可触碰底线、可能的再生任务、试点负责人和结束日。

选择可撤回、非安全关键场景，避免拿真实事故检验。所有结论针对流程，不评价员工“有没有生命力”。若系统正在明显失败，先处理故障，不能用本方法把资源从急迫修复移走。输出只包括候选落差、缝合链、测试结果和是否继续。开始前再找一名不受该流程考核的人复核启动卡，确认试点不是为了证明负责人预设的结论。把现行流程当作基线完整保留，任何改动都留下版本与恢复办法。若无法说明失败后怎样退回，暂不启动；可恢复性是这套体检获得行动资格的前提。

- 不负责保护所有差异和低效率。
- 不负责撤掉必要的安全或无障碍支持。
- 不负责用试验降低基本服务质量。

== 先守住边界
先写不可撤的安全、健康、无障碍和基本质量底线；任何测试都不能拿对象的必要支持作外援。参与者可拒绝接手、盲测或撤援，并随时退出；退出后删除测试副本并通知复核者。出现服务下降、身体或心理伤害、关键故障时立即恢复原支持，随后升级给既有安全责任人。结果不进入个人绩效，也不把“缺乏再生”归罪给新人或弱势者。试验只选低风险、可恢复任务，恢复按钮和责任人在开始前写明；无法即时恢复，就不做撤援测试。

必要支持、无障碍安排和安全步骤列为不可撤项，不能被叫作外援后拿走。对象可拒绝交接测试，退出后恢复原服务并删除非必要表现记录。若新情境会把失败成本落到患者、学生或下属，改用模拟任务；任何“再生”收益都必须同时说明由谁承担试错。

这套方法不反对质量控制、标准化、绩效记录、知识库和规模复制，也不允许以“保留差异”为由放松安全、隐私、基本能力和公平底线。它处理一个更窄的问题：某项持续成功的改进是否让系统短期更整齐，却失去在新情境中自行生成回应的能力。

== 先定位：问题究竟卡在哪一环
取一次指标改善却让系统更依赖外援的变化作为入口。五个问题在本节一次问完：这项差别只制造缺陷还是会产生新回应？ 消除它后短期指标是否变好？ 换情境后系统能否自行改写动作？ 新人接手时是否拥有重新判断的位置？ 撤去外援后系统还能不能继续发起？

回答必须比较改变前后的返工、求助、转岗、异常处置和新情境表现。漂亮的平均分不能替代一次真实接手；短期没有故障也不能证明再生能力仍在。观察不到的阶段留白，不把没有事故写成具备韧性。

存活落差清单把承重差别与纯缺陷分开，缝合链沿度量、标准化和复制追踪判断位置怎样被逐步封住。度量式缝合率看差别有多少被同一刻度抹平，复制式缝合率看做法有多少只能照搬；再生读数专查系统能否在陌生条件下重新发起。

找一位没有参加优化的人接手一件边界任务，只给必要底线，不给标准答案。若他只能召回原设计者，存活表面的整齐需要重新解释；若能提出新动作并承担后果，则保留该差别。诊断结论还要指定下一轮删掉哪项外援，防止把持续托管误报为已经存活。

== 一张不下结论的事实底稿
底稿按一次变化列旧做法、被消除的差别、使用的量规或模板、短期结果、换人表现、换境表现、撤援结果与新动作来源。事实栏放版本、求助和异常处置；推断栏才写“系统被缝合”。存活落差清单只收能产生新回应的差别，缝合链追度量和复制怎样关闭判断，度量式缝合率与复制式缝合率各守分母，再生读数只取撤去非必要外援后的表现。字段若不改变保留、恢复或关闭决定便删去；普通裂缝不美化。

存活落差清单决定哪些差别值得追，缝合链显示这些差别怎样被关闭。度量式缝合率只数同一刻度造成的关闭，复制式缝合率只数照搬造成的关闭；再生读数须来自新情境中的自行发起，不能由原设计者持续代劳。清单项目可能最终证明只是缺陷，那是允许的结论。名称的用途是把“整齐了”与“还能生长”分开，不是替差异加冕。随机抽一项交给陌生接手者复述，他若无法指出哪项外援被撤去、何种新动作由系统产生，该项只能记为短期改善，不能计入再生。两种缝合率必须保留造成关闭的具体装置：量规、模板、交接脚本或复制要求。

== 建立存活落差清单
为每项不一致做四问：它是否产生新回应；消除后短期指标是否改善；换情境后能力是否下降；成本与伤害由谁承担。

只造成事故、返工和不公平而不产生再生的，按缺陷处理；短期看似低效却稳定支持适应、接手或纠错的，列为候选存活落差。答案不明就小规模测试，不凭理念保护。候选表附正反案例和责任人，最多保留五项。

涉及安全与权利的差异不进入试验，直接按规范修复。受影响者可以指出所谓“活力”是否只是把不确定转嫁给他们。若落差只让下属额外劳动、没有修改主流程的权力，删除候选。

区分成功的标志是能解释保留与关闭条件，而不是发现差异越多越好。涉及未成年人、健康支持、亲密关系或明显权力不对称时，不撤除已有保护，不把人当试验材料，也不依据本文自行诊断。先取得适当监护、专业与伦理意见，并给当事人真实拒绝权；一旦试验收益归强者、风险落在弱者身上，即使数据好看也应停止。可操作对象优先选流程、文档与非关键产品入口。

动作甲：列一项能产生新回应的差别；动作乙：列一项只制造返工的反例。现场负责人执行，新情境使用者复核，时限为当日；禁止按外观选差别，清单项可删除。

== 画出度量式缝合链
从主指标倒追：哪些事件被翻成字段，字段怎样排名，排名如何移动资源，下一轮参与者何时看见。标出没有字段的成果、为了得分被改形的动作和指标从不被结果修改的位置。再做暂停反事实：若一周期不显示排名，下一步选择会不会变化。变化大说明度量已成为导航，不只是记录。

选择一个非安全指标做短期遮蔽或延迟，保留原始工作与后续结果。若多样路径增加且质量底线不降，缝合链得到支持；若只增加混乱，恢复指标。不要同时更换指标和流程，否则无法判断。所有实验事前写恢复条件，参与者知情，结果不入个人绩效。

指标暂停不是反管理仪式，只是检查固定动作是否占据唯一入口。链图至少画出一条被指标接住的材料和一条被遗漏的材料，并在每个箭头旁写负责角色与处理时限。若遗漏材料后来证实无关，应从候选删除；若与结果有关却长期无入口，新增临时接收者。下一周期检查接收是否真的触发决策，而不是多了一只无人阅读的信箱。所有改动都须保留回退版本。

动作甲：从量规倒追被删动作；动作乙：暂时遮掉一个非安全评分看选择是否回来。流程设计者负责，安全人员复核，时限为一次低风险任务；禁止动底线，遮蔽可立即撤销。

== 画出复制式缝合链
列出知识从经验到教程、模板、培训、验收的转换，标出每一步哪些判断被删、哪些异常被归一。让新人按文档处理一个标准案例和一个未见边界案例，比较是否能说明偏离理由。若标准案例很好、边界案例只能等待原作者，复制可能保留外壳却未交接能力。接着让原作者暂时退出，由新人负责一次低风险变体，记录求助点、修改权和结果。退出可随时恢复，不用“独立测试”羞辱新人。若失败来自基础知识不足，补教学；若来自任何偏离都无权限，修传承结构。知识库继续保留，但新增“为什么、何时例外、谁可改版”，而不只是更多步骤。为避免把任务难度误当传承失败，先由两名熟手在同一边界案例上独立作答，确认案例确实存在合理调整空间。新人完成后，不只比答案，还比较能否察觉条件变化、提出理由和请求恰当支持。若熟手也只能猜测，就应修任务与资料，不能据此宣判复制链已封闭。复盘结论分为知识缺口、权限缺口、经验缺口和任务含混，分别补课、授权、练习或重写案例。四类原因不能用一份更长的操作手册统一处理。

动作甲：标出模板拿走重新判断的位置；动作乙：让接手者改一处并说明后果。传承者负责，陌生接手者复核，时限为一次交接；禁止把偏离当创新，模板可恢复。

== 计算复制式缝合率并做撤援
撤去一项持续外部启动、模板或专家支持，时间短、范围小、可随时恢复；同时给一个主流程未训练的新问题。观察系统是否能发起、提出多条路线、解释选择并在失败后修正。只看结果正确率不够，还要看下一步由谁产生。测试前匹配任务难度和资源，避免把突然断粮当能力检验。出现安全风险、明显焦虑或服务质量下降即恢复支持。对照组保留原安排，比较差异。

若撤援组短期下降后恢复并产生新路线，可能存在再生；若持续崩溃，说明能力尚未形成或落差已被缝；若两组无差异，候选机制可能不重要。结果不用于个体淘汰，只改系统支持与传承。测试日志按事件而非按人记录：何时遇到障碍、谁发起下一步、使用了哪种材料、何时请求恢复。开始前写明最长测试时段和质量下限，由现场负责人拥有立即终止权。结束后先恢复正常服务，再复盘机制，不能为了补齐样本延长不适合的撤援。若没有匹配对照，就与同一团队过去的相似任务比较，并把环境变化写入限制。测试只支持本次流程判断，不把一次独立完成解释成普遍能力，也不把一次求助解释成系统失活。

动作甲：两种关闭分别确定分母；动作乙：抽一宗边界案复算。记录员执行，独立统计者复核，时限为两日；禁止合成总分，未知项不进入两类缝合率。

== 读取再生读数
对通过测试的候选，只提供最小条件：少量时间、有限预算、独立接收者、修改主流程的明确入口和失败后关闭权。不设数量配额，不要求每团队制造差异。保护期写开始、结束和要观察的后续作用。

落差若长期没有任何生成后果，按期关闭，不让“活力”成为永久豁免。保护同时设置成本上限和权益底线，不能让少数实验消耗基础服务。接收者轮换但需交接，防止保护依赖个人。

主系统必须至少有一次机会被候选结果修改，否则保护区只是展示橱窗。每次修改记录触发事件与适用范围，不把局部例外无条件扩张。

建立一张简短保护卡，列出它承担的再生任务、需要的最低资源、可能伤害、接回主流程的接口和下一次复核日期。复核只依据真实任务中的作用，不按提案数或新颖度续期。若接收者离岗、接口关闭或成本越界，先暂停而非自动追加资源。保护对象若连续两个复核期只重复旧方案、不再接受新材料，也应退出。退出前保存有效知识并通知依赖者，随后把资源归还基础服务；保护落差不是建立第二套永不结束的机构。

动作甲：撤去一项非必要外援；动作乙：记录系统是否自行提出并承担新动作。试点负责人执行，服务对象代表复核，时限为一个短周期；禁止硬撑到伤害发生，恢复键常开。

== 角色与权限分开
执行者运行低风险交接、撤援和记录新动作，不得移动安全底线。决策者选择保留、恢复或关闭哪项差别，并承担服务成本。复核者由陌生接手者、服务对象代表或安全人员共同组成；原决策者不得独自复核自己。对象是承受标准化后果的人和系统成果，不是供管理者打分的“再生能力”。原设计者只能在预写的紧急条件下介入，介入必须留痕。必要支持的提供者与可撤外援的提供者分开标明。任何失败先恢复服务，再讨论理论，不能为了完成试验延迟保护。 制度明确禁止“每月必须产生几处落差”“偏离率越高越好”和个人创新配额。检查报告只围绕具体事件与后续作用，不制作红绿榜。若管理者要求一个总数，提供成功、失败各一条案例和剩余未知，而非合成分数。保护区负责人不能同时因项目数量获得奖励。每次复盘问：这项记录是否正在让参与者表演不规则；若是，暂停读数，保留真实任务观察。落差名称也不进入品牌宣传，防止团队为了形象长期供养无用项目。

== 读数、采集办法与代价
一个连续高分却越来越依赖原设计者的流程先定材料边界，各项读数分别报告，不生成总分：
- 存活落差清单｜来源：异常处置、改版和新回应；频率：真实事件发生时；缺失：表示差别尚未承重；反向优化：制造可展示例外冲高清单；改善上限：保留能触发一次新动作的差别即可。
- 缝合链｜来源：量规、模板、交接与版本；频率：流程改变时更新；缺失：表示关闭装置未知；反向优化：把所有标准都画成缝合；改善上限：只追出一条关闭判断位置的链。
- 度量式缝合率｜来源：评分前后可选动作；频率：一个低风险周期一次；缺失：表示分母不完整；反向优化：拆细指标制造更多关闭；改善上限：用于触发撤表测试，不追求零。
- 复制式缝合率｜来源：交接版本与改动权限；频率：每次交接一次；缺失：表示接手者未获真实任务；反向优化：要求表面改动冲低比率；改善上限：只检查是否还有重新判断位置。
- 再生读数｜来源：换人、换境和撤援结果；频率：每个完整测试一次；缺失：表示尚未测试，不等于失败；反向优化：预先提示答案冲高表现；改善上限：能确认自行发起一项动作即可。

存活落差清单按一次新回应登记，必须说明它为何不是普通误差；缝合链逐节点记录差别被度量、标准化或照搬关闭的过程。

== 最容易把方法做坏的三种方式
存活落差清单一旦脱离自己的材料，最先出现以下三种坏法：
- 坏法：把所有不规则命名为存活落差，缺陷获得永久保护。保护：保护措施是要求新情境中的可追踪回应和反例。
- 坏法：撤掉无障碍或安全支持做再生测试。保护：保护措施是预写不可撤底线，由安全人员握恢复权。
- 坏法：把再生读数变成团队排名，大家表演改法。保护：保护措施是低频事件复核，不公开个人或部门总分。

制度明确禁止“每月必须产生几处落差”“偏离率越高越好”和个人创新配额。检查报告只围绕具体事件与后续作用，不制作红绿榜。若管理者要求一个总数，提供成功、失败各一条案例和剩余未知，而非合成分数。保护区负责人不能同时因项目数量获得奖励。每次复盘问：这项记录是否正在让参与者表演不规则；若是，暂停读数，保留真实任务观察。落差名称也不进入品牌宣传，防止团队为了形象长期供养无用项目。允许结论是“本期没有需要保护的新差异”。只有能被关闭的保护，才不会成为另一种不可触碰的标准。

== 什么时候应该停，什么时候说明理论可能不对
操作停手线：撤援引起服务下降、健康安全风险、必要支持被误删或接手者要求退出时停；立即恢复支持。

理论撤回线：标准化后换人、换境、撤援表现持续改善，被删除差别只制造缺陷且从不产生新回应时，撤回缝合致死在该系统中的判断。

出现安全、合规、隐私、严重服务下降或权力者把不稳定成本转给弱者时，立即停止测试并恢复支持。候选落差若只增加错误、不产生任何新回应，按缺陷修复。撤援涉及医疗、无障碍支持、急救或法定保护时，不执行，除非相应专业人员明确批准。参与者可退出，不因退出受罚。若标准化、度量和复制增强后，多个系统的新情境适应、撤援迁移和接手能力同步提高；保留差异的匹配对照没有更强再生；暂停固定度量动作也不改变结果，那么母文判断在该场景不成立。停止报告保留有效质量改进，撤销无效保护和多余采集，不把失败解释成“落差还藏得更深”。还应预设阶段停止线：连续两轮没有候选材料改变行动，或试点成本达到上限，即结束而不是扩大搜寻。
