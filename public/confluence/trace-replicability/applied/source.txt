TITLE: 先画传递通道，再决定相似能推出多远
SUB: 一套用于研究、审计和数字取证的痕迹复制性检查法
ABS: 本文把痕迹的复制能力、接触强度、可辨差异和传递方向做成四问流程。实践中先写待证结论的通道，再检查证据是否同路、盲区是否互补，并用独立证据和停止规则控制过度推断与过度采集。

== 这套方法做什么、不做什么
这套方法不替代法定取证、专业鉴定、考古分析或隐私审查，也不允许未经授权收集生物与门禁数据。它处理一个更窄的问题：看到两地相似痕迹时，如何避免从“形式相同”直接跳到“同一人、同一群体或同一来源移动”，同时不把不可复制痕迹的强证据无端削弱。最小动作是给一项关键证据写通道卡：复制难度、传递过程、系统性盲区、与待证结论是否同路。先用于已有资料复核，不为测试主动制造敏感痕迹。项目开始由专业负责人、数据权益负责人和领域使用者确认范围。

通道卡只支持推断力度，不裁决法律责任或身份。涉及个人数据时遵守目的限定、最小收集、访问控制和删除期限；无法授权就用去身份或公开材料。所有“不可复制”必须带时间、技术和场景条件，禁止写成绝对本质。若发现现实安全事件，立即转现有处置，不等待研究流程。启动卡写明待审结论、现实用途、不可采集材料、责任人和结束日。若只想证明既有故事，不启动。每张卡由领域专家和数据权益人员共同签字，确保推断问题与采集边界同时明确。方法输出是结论范围和证据缺口，不是一个来源真实性总分，也不用于给人或群体贴标签。

- 不负责给材料作真假总鉴定。
- 不负责替历史共同体宣布身份。
- 不负责用盲区为没有证据的故事背书。

== 先守住边界
涉及人体、遗骸、原住民知识、私人通信或数字取证时，先取得现有授权，不因比较通道扩大采样。材料提供者可拒绝二次用途并退出，保管人随后删除未经法定留存的副本并通知接收方。任何破坏性取样、隐私识别或现实指控都由原有专业与法律程序决定；出现损伤、污名或安全风险立即停止并升级。通道卡只写研究所需层级，不公开可帮助伪造痕迹的操作细节。证据沉默既不能定罪，也不能免责；受结论影响的群体有查看说明、指出遗漏和要求更正的入口。

取样权、保管权和解释权分开登记。原件所有者或相关社群可拒绝破坏性复作，退出后停止新增分析并删除未经授权副本。涉及遗骸、基因、地理敏感点或可被滥用的取证细节，先由伦理与法律责任人决定能否继续；复制便利从不自动构成公开许可。

这套方法不替代法定取证、专业鉴定、考古分析或隐私审查，也不允许未经授权收集生物与门禁数据。它处理一个更窄的问题：看到两地相似痕迹时，如何避免从“形式相同”直接跳到“同一人、同一群体或同一来源移动”，同时不把不可复制痕迹的强证据无端削弱。

== 先定位：问题究竟卡在哪一环
先锁定一组相似痕迹，再暂时搁置“它们必经同一路径”的结论。五项排查句只在这里完整出现：这种痕迹能否脱离携带者被复制？ 复制需要一次观察还是长期接触？ 复制品会留下哪些可辨差异？ 当前证据能看见哪条传递通道？ 相似之外还有什么竞争路径？

逐项附上载体、制作步骤、接触时长、年代范围与采样缺口。看不见某条通道不等于通道不存在；能复制外形也不等于复制了形成机制。记录者须把观察事实与因果推断分栏，避免同一句话两头兼任。

痕迹复制性分档先判断痕迹脱离携带者的难易，默认因果偏移再比较换一种证据后首选故事是否移动。证据通道盲区用于登记当前材料天然看不见的传递方式，相似—迁移越界率只数那些从“相像”直接跳到“发生迁移”的论证。

复核时挑一条主张，构造一条不经迁移也能留下同类痕迹的竞争路径，并列出两条路径会产生的不同残留。若现有材料分不开，就保留并立解释；若五问未改变采样或比对动作，说明研究对象仍太宽，应缩到一个遗址、一类器物或一段语言形式。

== 一张不下结论的事实底稿
底稿一项痕迹一页：载体、形成步骤、复制所需接触、年代、保管链、相似特征、可行传递路径与当前不可见事件分栏。事实栏只记观察和实验复作；推断栏写迁移、来源或意图。痕迹复制性分档描述机制，默认因果偏移保存新增证据前后的排序，证据通道盲区登记材料天然看不见什么，相似—迁移越界率只数缺机制桥梁的跳步。字段必须改变采样、竞争路径或结论强度，答不出就删；沉默不补成反证。

痕迹复制性分档描述机制难度，不判断文化价值；默认因果偏移比较证据更换前后的首选解释；证据通道盲区提醒研究者哪些传递方式没有留下当前材料；相似—迁移越界率则专记从形态相似直接跳到人口或语言迁移的步子。分档不能自动推出因果，盲区也不是随意想象的许可证。一次合格记录必须同时给出痕迹、可行复制过程和竞争路径。把案例交给另一研究者，若他只能看见相似却无法复述复制机制，这条越界记录成立；若竞争路径已有区分证据，就转入检验而非继续累计读数。

== 写清待证结论的通道
先把结论改写为事件链，例如“某人身体到场”“某种做法被教学复制”“某段文字由共同文件传播”“某项影响改变后续行动”。为链条写出必须发生的物理或社会过程：移动、接触、学习、复制、生殖、交换、执行。

结论若包含多个过程，拆开，不用一项证据包办。每条链还写出时间与空间尺度，因为复制能力可能随尺度改变。请未参加研究的人根据事件链说出他认为需要什么痕迹，检查描述是否可理解。

若链条只能用结论自身重述，如“影响通过影响发生”，继续拆到可观察动作。结论卡在看数据前冻结，避免结果出现后改路。后续若改变，保留旧版并说明新问题。没有清楚结论通道，不进入证据强弱讨论。

事件链还要写竞争路径，至少一条不需要目标结论也能生成现有痕迹。没有竞争路径时，团队容易把故事当过程。链条由不同专业人员互换复述，任何模糊动词继续拆。对社会影响这类长链，可只处理其中一段，不能因总问题重要就让一项材料承担全部跨度。事件链通过后由责任人签字，后续任何跨越新环节的结论都必须重新开卡。

动作甲：把结论拆成必须发生的传递步骤；动作乙：为每步找一种残留。论证作者负责，异领域同行复核，时限为采样前；禁止用相似替机制，整条通道可退回待证。

== 建立痕迹复制性分档
对每类痕迹连续判断：陌生人通过观察能否复制；复制需要一次接触还是长期学习；复制后是否留下系统可辨差异。用现实边界案例校准，不凭“看起来复杂”判断。可一次复制者不能单独证明实体移动；需长期接触者可支持强接触但未必支持方向；难以复制者更能排除形式传播。

结论写成条件句，不给痕迹永久标签。复制测试只在合法、安全材料上进行，不能仿造证件、生物记录或攻击系统。可查已有研究、历史事件和公开样本替代实作。两名编码者分档并保留分歧，必要时给区间。发现技术使复制成本变化，立即更新通道卡并复核旧结论。

若无法判断，按多路径保守处理，不把未知自动归为不可复制。复制分档保存证据依据，例如公开演示、历史案例或技术说明，不能只写专家感觉。对“长期接触”说明大致时间和必要条件。若复制品可在某些细节上辨认，记录哪些细节与哪种工具相关。每次技术升级触发抽样复测，不把旧分档自动继承到新版本。未知项单列，不强行三选一。

动作甲：用观察、长期学习、难脱离载体三档复作；动作乙：记录复制品差异。实验员执行，材料保管者复核，时限为一次低损测试；禁止损伤原件，分档可随技术更新。

== 计算默认因果偏移
问痕迹能否说明谁先谁后、谁传给谁。共同格式通常只显示关联，除非有独立时间；共同错字可能帮助建立复制关系，仍需版本日期判断方向；身体谱系类记录可能带方向，却未必覆盖文化影响。把方向证据与相似证据分栏，禁止用相似度高代替先后。建立最小时间轴，列出痕迹首次出现、可传播窗口和对象到达时间。日期不确定就用区间，区间重叠时承认方向未知。数字文件时间戳需检查是否可修改、复制是否保留旧时间。方向结论至少由一项独立时间证据支持；没有就只报告联系，不写源头。时间轴随新材料更新，旧方向结论保留版本。还要记录传递后的反向修改有没有发生。若接收方只能照单执行，任何新发现都回不到源流程，那么表面上的双向沟通仍是单向复制。只有接收方的材料能够改变源头规则，传递方向才真正打开。方向判断还需防止循环：先根据理论认定谁早，再用“早者是来源”支持理论。时间证据应尽量独立，且报告可能被复制保留或篡改。若只有相对先后，没有传播接触，仍不能直接证明影响。

动作甲：保存增加新证据前的因果排序；动作乙：加入证据后重排并说明移动。分析者负责，盲态同行复核，时限为同一轮分析；禁止删旧排序，偏移结论可撤回。

== 列出证据通道盲区
对每条通道问“哪些事件即使发生也不会留下这种痕迹”。

生物链可能漏掉未留后代者，器物链漏掉不制作或材料未保存者，数字日志漏掉离线与未记录动作，门禁漏掉借卡或未触门者。

盲区必须来自传递机制，不是泛泛说数据不全。另列偶然缺失，二者用不同修理：偶然缺失可扩样，通道盲区需换证据。

请受影响领域人员补充一项分析者容易忽略的无痕事件，防止只从数据库视角作答。盲区按结论后果排序，选择最关键者进入后续互补设计，不追求全列。

报告明确“没看见”是采样不足还是通道不记录。若无法区分，给两种解释范围。任何盲区不得被用来凭空断言事件发生，它只限制缺席证据的力度。盲区清单加入“谁因此不可见”，检查数据库是否系统遗漏特定角色、地域或行为。若遗漏关系重大，报告结论不得泛化到全体。可寻找低侵入替代材料，而不是直接扩大监控。盲区若无法修复，就写进适用边界，并让决策者知道未覆盖风险。清单每次采集方案变更后更新。

动作甲：每类材料列一项看不见的事件；动作乙：指定另一条可能看见的通道。资料员执行，通道专家复核，时限为报告前；禁止把盲区填成猜测，未经授权不新增采集。

== 计算相似—迁移越界率
把结论链与证据链并排，标出共同过程和跳跃。证据记录生殖而结论关于语言，或证据记录文件复制而结论关于人员到场，都存在跨通道跳跃。此时证据可支持共变、接触或某个中间环节，但不能直接完成整个结论。要求研究者为每个跳跃提供独立桥梁，否则降低措辞。桥梁必须是新材料或明确机制，不是把结论换句话说。逐句审查报告中的“因此、说明、证明”，回链到通道对照。若结论可拆成两段，先发布有支持部分，把其余标为假设。

审阅者从反方向问：若结论不成立，这类痕迹是否仍可能出现；答案为是，证据不是判决性。对照表附于高后果报告，方便复核。对照完成后给每个跳跃分级：已桥接、仅相关、无证据。正文措辞与级别绑定，已桥接可用“支持”，仅相关用“相伴”，无证据不写因果。审稿或验收抽查五个因果词，必须回到表格。若业务必须行动，可按风险采用保守决策，但明确那是治理选择，不把它写成事实已经证明。每个未桥接跳跃都进入摘要边界，不能只藏在技术附录。

动作甲：圈出从相似直接跳到迁移的句子；动作乙：补一条不经迁移的竞争路径。写作者负责，反方复核，时限为定稿前；禁止用多数票消除竞争路径，可降低结论强度。

== 角色与权限分开
执行者描述痕迹、复作与通道，不先写迁移结论。决策者决定采什么、结论写到多强，并说明剩余盲区。复核者从竞争路径出发检查越界；原决策者不得独自复核自己。对象包括材料、材料所属群体和受来源判断影响的人，授权与纠错入口不能被研究便利取消。保管者控制原件和破坏性取样，通道专家只对自己熟悉的机制负责。数字取证另设法律责任人，历史研究另设社群代表。新增证据改变结论时，版本管理员通知引用过旧通道卡的人。 管理者可能把“不可复制”自动排在最高级，忽略它只对特定问题强。规则禁止总分和永久排序，每张卡必须同时写优势与盲区。评审意见若只说某证据更硬，要求指出待证结论和排除的竞争路径。不同材料可以在同一项目中分别主导不同子问题。另一种反噬是为证明互补而收集更多敏感数据。新增通道前做必要性评估：现有盲区是否真的影响决策，新数据能否看见它，收集风险是否可接受。成功的通道设计是在有限材料下把能说与不能说分开，不是把世界变成无遗漏日志。

== 读数、采集办法与代价
一条从材料痕迹跳到来源判断的论证先定材料边界，各项读数分别报告，不生成总分：
- 痕迹复制性分档｜来源：材料细节与低损复作；频率：技术或材料变化时；缺失：表示机制未测试；反向优化：挑容易样本压低难度；改善上限：足以区分竞争路径即可。
- 默认因果偏移｜来源：新证据加入前后排序；频率：每次关键证据新增时；缺失：表示旧排序未保存；反向优化：先看结果再补旧排序；改善上限：只判断证据是否移动入口。
- 证据通道盲区｜来源：生成机制和保存条件；频率：通道说明更新时；缺失：表示尚不知道可见范围；反向优化：罗列无限盲区阻断结论；改善上限：指出一项会改变采样的盲区即可。
- 相似—迁移越界率｜来源：论证文本与机制桥梁；频率：稿件定稿前一次；缺失：表示句子不能稳定编码；反向优化：拆句稀释越界数量；改善上限：用于找跳步，不追求归零。

痕迹复制性分档以完成一种痕迹所需的接触和学习过程为依据；默认因果偏移比较增加不同证据前后的首选解释。证据通道盲区按证据类型登记不可见路径，相似—迁移越界率只统计论证文本中缺少机制桥梁的跳跃。

== 最容易把方法做坏的三种方式
痕迹复制性分档一旦脱离自己的材料，最先出现以下三种坏法：
- 坏法：通道卡变成证据等级，难复制便自动更真实。保护：保护措施是分档只描述机制，不直接决定真假。
- 坏法：盲区越列越多，任何结论都无法成立。保护：保护措施是每个盲区必须改变一次采样或竞争路径。
- 坏法：多位评审重复同一材料却宣称独立互证。保护：保护措施是核查生成、保管与失败方式是否独立。

管理者可能把“不可复制”自动排在最高级，忽略它只对特定问题强。规则禁止总分和永久排序，每张卡必须同时写优势与盲区。评审意见若只说某证据更硬，要求指出待证结论和排除的竞争路径。不同材料可以在同一项目中分别主导不同子问题。另一种反噬是为证明互补而收集更多敏感数据。新增通道前做必要性评估：现有盲区是否真的影响决策，新数据能否看见它，收集风险是否可接受。成功的通道设计是在有限材料下把能说与不能说分开，不是把世界变成无遗漏日志。评审模板加入一问：“换成另一个问题，这项证据的强弱会不会反转？

== 什么时候应该停，什么时候说明理论可能不对
操作停手线：取样可能损伤原件、授权不足、来源判断造成现实污名或通道卡暴露伪造方法时停；撤销发布并通知受影响者。

理论撤回线：控制复制性与盲区后因果排序不变，竞争路径持续被独立残留排除，通道说明也不能预测新证据的影响时，撤回复制机制主解释。

发现证据涉及未经授权的个人信息、取证链破坏、结论可能直接伤害群体且尚无复核、或测试要求制造违法仿造时，立即停止并转专业程序。通道无法明确、技术条件变化太快或关键材料不可得时，报告不确定。团队不能拿“系统性盲区”要求当事人提供更多敏感资料，也不能用缺席痕迹否定个人陈述。若同一研究者在其他条件相同下，对复制能力差异巨大的痕迹仍给出相同默认；通道卡不能预测推断错误；共享盲区的多证据与真正互补证据同样提高外部准确性；或增加同类样本持续消除所谓系统盲区，那么母文推论不成立。停止后撤回过度结论、删除无必要数据，并记录更好的解释，如训练传统或任务激励。
