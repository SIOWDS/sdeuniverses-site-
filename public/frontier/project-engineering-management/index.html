项目与工程项目管理

近二十年 · 两幕 · 20 个新思想 · 约 25,717 字 · 王德生 亲撰 · 2026 年 8 月

过去二十年，项目与工程项目管理的重心从进度、成本和范围三角移向项目交付、治理与全寿命价值。第一幕由“巨型项目的成本低估是系统性而非偶然误差 Megaproject Cost Underestimation”展开，经过“项目复杂性需要区分结构、技术与社会政治维度 Dimensions of Project Complexity”与“敏捷方法的成功取决于迭代是否产生真实反馈 Agile Project Success”，说明旧框架为什么无法只靠中心指标解释差异；第二幕从“收益实现把“按时完工”改写为使用后的价值 Benefits Realization Management”推进到“供应链地缘风险把项目计划改写为可替代网络 Geopolitical Risk in Projects”，把数字化、危机与制度回写纳入同一分析。二十条并非平均陈列流派，而是分别追问谁进入分母、哪条路径产生结果、什么条件使方向反转。这样处理后，交付价值、系统韧性与社会许可不再是一个静态总分，而成为可核对、可争议、也可与相邻领域对撞的责任链。

甲、巨型项目的成本低估是系统性而非偶然误差Megaproject Cost Underestimation

提出Flyvbjerg、Skamris Holm 与 Buhl，2002，《Journal of the American Planning Association》68(3):279–295，DOI 10.1080/01944360208976273。　争议Morris，2013，《Reconstructing Project Management》，Wiley-Blackwell。　最新OECD，2025，《OECD Supply Chain Resilience Review: Navigating Risks》，DOI 10.1787/94e3a8ea-en。　关键大型基础设施成本低估来自激励与政治选择，不能用普通预测误差解释

从大型基础机制的材料看，项目与工程项目管理早期讨论“巨型项目的成本低估是系统性而非偶然误差 Megaproject Cost Underestimation”多从进度、成本和范围三角出发，Flyvbjerg、Skamris Holm 与 Buhl在2002年的工作把被结算的对象与汇总读数提升为需要单独识别的层次。Morris（2013）并未否定问题本身，却证明样本以欧洲和北美为主，项目会计口径与价格基准并不完全一致，从而让“未获批准的诚实方案、取消项目和预算外配套成本”进入收益实现台账的核对范围。

Flyvbjerg、Skamris Holm 与 Buhl于2002年给出的立场可以直接接受反证：大型基础设施成本低估来自激励与政治选择，不能用普通预测误差解释。Morris（2013）迫使Flyvbjerg、Skamris Holm 与 Buhl的命题在OECD的新场景中把解释焦点落到对象或读数“巨型项目的成本低估是系统性而非偶然误差”，因此，判断标准被明确为：决定成本偏差的只有预测是否受战略性失真约束。

经验判断的锚点来自Flyvbjerg、Skamris Holm 与 Buhl（2002）：对258个交通基础设施项目的研究发现成本超支普遍且长期未改善，铁路平均超支高于公路和固定连接。为检验Morris（2013）针对Flyvbjerg、Skamris Holm 与 Buhl所指出的选择问题，并接续OECD的更新，不能只展示“最终成本超支额”，而要在风险登记册中按“最终成本超支额／决策时批准预算”重算。为复核Flyvbjerg、Skamris Holm 与 Buhl提出而Morris质疑的命题，按照OECD（2025）的更新口径，第三方至少要获得原始分母、事件定义和“该未登记群体”清单，不能只接收汇总图表。

“巨型项目的成本低估是系统性而非偶然误差 Megaproject Cost Underestimation”的适用边界由Morris（2013）集中提出：样本以欧洲和北美为主，项目会计口径与价格基准并不完全一致。Morris对Flyvbjerg、Skamris Holm 与 Buhl的压力测试不是简单缩小范围，而是要求直接观察：当独立审查者对预测者承担追责时，方向反过来：政治关注越高估算越保守。核查大型基础机制时，Flyvbjerg2002—Morris2013的争议已暴露明确的自我限制。在大型基础机制这条证据链上，就Flyvbjerg、Skamris Holm 与 Buhl提出、Morris质疑的命题而言，OECD到2025年的材料仍不能替代预先登记的失效检验。

对大型基础机制做反向检验，按照Flyvbjerg、Skamris Holm 与 Buhl在2002年建立的口径，业主团队处理交付验收不能只引用“这一比率”，还要让风险登记册保存分子、分母与口径变更。OECD到2025年的材料说明，交付验收实施后参与者会适应，业主团队因而必须沿Flyvbjerg、Skamris Holm 与 Buhl、Morris之间的争议线观察指标使用前后交付价值、系统韧性与社会许可是否仍同义。

乙、参考类预测用外部基准压制内部乐观Reference Class Forecasting

提出Flyvbjerg，2006，《Project Management Journal》37(3):5–15。　争议Flyvbjerg 与 Gardner，2023，《How Big Things Get Done》，Currency。　最新Reja、Varghese 与 Haavaldsen，2024，《Digital Twins for Construction Project Management》，Cambridge Centre for Smart Infrastructure and Construction。　关键项目预测应从“这个项目为何不同”转向“同类项目通常怎样”

Flyvbjerg在2006年提出“参考类预测用外部基准压制内部乐观 Reference Class Forecasting”时，面对的旧框架仍以进度、成本和范围三角为主，行动次序、反馈和转折点只在结果异常后才被追问。Flyvbjerg 与 Gardner在2023年的异议把难点落到变更令：参考类划分可被操纵，新技术项目也常缺足够近邻，而“因不符合参考类而被排除的失败项目、未进入数据库的取消案”正是旧账本没有位置的那部分。核查项目预测机制时，Reja、Varghese 与 Haavaldsen（2024）由此把“该转向 Reference Class Forecasting”从经验标签改成责任链，要求变更令同时保存进入、退出与未分类事件。

Flyvbjerg于2006年给出的立场可以直接接受反证：项目预测应从“这个项目为何不同”转向“同类项目通常怎样”。Flyvbjerg 与 Gardner（2023）迫使Flyvbjerg的命题在Reja、Varghese 与 Haavaldsen的新场景中把解释焦点落到行动路径“参考类预测用外部基准压制内部乐观”，因此，判断标准被明确为：决定预测校准的只有是否使用相似项目的实际分布。

Flyvbjerg在2006年提供的主证据是：英国交通部等采用参考类预测，把成本与工期提升额按历史分布设置，减少只依赖项目团队内部情景。项目预测机制的结构读数拆成2项：主命题、替代机制、缺失对象与时间窗分别核对，任一项都不由总均值代填。

Flyvbjerg 与 Gardner在2023年的争议材料没有简单否定“参考类预测用外部基准压制内部乐观 Reference Class Forecasting”，而是指出：参考类划分可被操纵，新技术项目也常缺足够近邻。沿Flyvbjerg、Flyvbjerg 与 Gardner之间的证据分歧线，原方向必须在以下条件下重新判定：当团队选择过窄且有利的参考类时，方向反过来：外部基准越精细乐观偏差越隐蔽。

在项目预测机制这条证据链上，在项目交付、治理与全寿命价值的现场，Flyvbjerg（2006）所给读数必须由项目控制办公室写入基线版本，并说明“全部预测项目数”如何形成。对项目预测机制做反向检验，Flyvbjerg 与 Gardner（2023）对Flyvbjerg的边界批评、以及Reja、Varghese 与 Haavaldsen的后续检验，要求“这些漏记对象、未进入数据库的取消案”拥有独立状态，若它被并入一般缺失，交付价值、系统韧性与社会许可就可能因分母收缩而显得改善。

把Flyvbjerg（2006）和Cicmil、Williams、Thomas 与 Hodgson（2006）并读，可以看到“本项证据 Reference Class Forecasting”追问行动次序与反馈路径，“重新思考项目管理把交付对象从计划移到实践 Rethinking Project Management”追问制度、技术与关系条件，两条命题共享的未言明条件是“有限样本与有限指标足以控制“这一制度安排”的全部可能状态，这组账外材料、未进入数据库的取消案只是尾部误差”。把项目预测机制放到另见第 244 号第 9 条『Wasserstein 分布鲁棒性』旁核验：先对齐对象、时间窗和责任人，再检查项目预测机制的核心判断在另一套分母中是否仍同向。

丙、重新思考项目管理把交付对象从计划移到实践Rethinking Project Management

提出Cicmil、Williams、Thomas 与 Hodgson，2006，《International Journal of Project Management》24(8):675–686，DOI 10.1016/j.ijproman.2006.08.002。　争议Love、Ahiaga-Dagbui 与 Irani，2016，《Production Planning & Control》27(4):321–336，DOI 10.1080/09537287.2015.1129461。　最新PMI，2024，《Pulse of the Profession 2024》。　关键项目不能只被看成目标明确的临时组织，而要研究权力、意义和日常调整

就重新思考项目管理研究的材料边界而言，进入、退出与未登记对象必须分开留痕。对照Love、Ahiaga-Dagbui 与 Irani（2016）的反例可见，批判议程难形成统一绩效指标，也可能低估工程约束的必要性，若业主团队删去“临场修补、非正式协调、未写入基线的利益冲突”，表面稳定很可能只是样本边界被改写。PMI在2024年的材料把Cicmil、Williams、Thomas 与 Hodgson、Love、Ahiaga-Dagbui 与 Irani之间的分歧带入风险登记册：同名结果若经历不同交付验收，就不能被视为同一事实。

Cicmil、Williams、Thomas 与 Hodgson于2006年给出的立场可以直接接受反证：项目不能只被看成目标明确的临时组织，而要研究权力、意义和日常调整。在重新思考项目管理研究这条证据链上，Love、Ahiaga-Dagbui 与 Irani（2016）迫使Cicmil、Williams、Thomas 与 Hodgson的命题在PMI的新场景中把解释焦点落到制度条件“重新思考项目管理把交付对象从计划移到实践”，因此，判断标准被明确为：决定项目理解的只有现场实践如何处理不确定性。

Cicmil、Williams、Thomas 与 Hodgson在2006年提供的主证据是：英国“Rethinking Project Management”网络提出五个方向，推动研究从工具理性转向复杂性、社会过程和实践知识。重新思考项目管理研究的结构读数拆成3项：主命题、替代机制、缺失对象与时间窗分别核对，任一项都不由总均值代填。

Love、Ahiaga-Dagbui 与 Irani在2016年的争议材料没有简单否定“重新思考项目管理把交付对象从计划移到实践 Rethinking Project Management”，而是指出：批判议程难形成统一绩效指标，也可能低估工程约束的必要性。沿Cicmil、Williams、Thomas 与 Hodgson、Love、Ahiaga-Dagbui 与 Irani之间的证据分歧线，原方向必须在以下条件下重新判定：当“灵活实践”被用来免除基线责任时，方向反过来：现场自由越大可追责性越弱。

按照Cicmil、Williams、Thomas 与 Hodgson在2006年建立的口径，业主团队处理交付验收不能只引用“上述分子—分母”，还要让风险登记册保存分子、分母与口径变更。Love、Ahiaga-Dagbui 与 Irani（2016）提醒，业主团队必须为Cicmil、Williams、Thomas 与 Hodgson提出而PMI继续检验的“这些漏记对象”提供查询位置，在Love、Ahiaga-Dagbui 与 Irani所划定的责任边界里，它若没有位置，责任便会在部门之间消失。重新思考项目管理研究的复核表还保留退出日期、原记录者和未纳入理由，不用零值代替缺失。

Cicmil、Williams、Thomas 与 Hodgson、Flyvbjerg、Skamris Holm 与 Buhl的两组证据可以在本块内部对读：“重新思考项目管理把交付对象从计划移到实践 Rethinking Project Management”把解释焦点放在制度、技术与关系条件，“巨型项目的成本低估是系统性而非偶然误差 Megaproject Cost Underestimation”则放在被结算的对象与读数，二者都默认“有限样本与有限指标足以控制“上述机制”的全部可能状态，这组账外材料只是尾部误差”。把重新思考项目管理研究放到另见第 542 号第 4 条『Materials Project』旁核验：先对齐对象、时间窗和责任人，再检查重新思考项目管理研究的核心判断在另一套分母中是否仍同向。

丁、项目复杂性需要区分结构、技术与社会政治维度Dimensions of Project Complexity

提出Geraldi、Maylor 与 Williams，2011，《International Journal of Operations & Production Management》31(9):966–990，DOI 10.1108/01443571111165848。　争议Morris，2013，《Reconstructing Project Management》，Wiley-Blackwell。　最新OECD，2025，《OECD Supply Chain Resilience Review: Navigating Risks》，DOI 10.1787/94e3a8ea-en。　关键复杂项目必须按结构、社会政治、涌现、步速与不确定性分类

Morris在2013年的异议把难点落到变更令：维度之间重叠，管理者自评也可能把失败归因于“复杂”以逃避责任，而“未能发声的地方利益、跨接口小故障和累积返工”正是旧账本没有位置的那部分。对项目复杂性社会政治做反向检验，OECD（2025）由此把“该转向 Dimensions of Project Complexity”从经验标签改成责任链，要求变更令同时保存进入、退出与未分类事件。

在Geraldi、Maylor 与 Williams的2011年论证中，“项目复杂性需要区分结构、技术与社会政治维度 Dimensions of Project Complexity”不再只是相关性标签，而明确主张：复杂项目必须按结构、社会政治、涌现、步速与不确定性分类。把项目复杂性社会政治放回原窗口，按Morris（2013）给出的反例压力并对照Geraldi、Maylor 与 Williams、OECD两组材料，若对象或读数“本项证据”不起决定作用，那么“决定管理策略的只有复杂性类型而非项目规模”就应被判错。

就项目复杂性社会政治的外推边界看，Morris（2013）对Geraldi、Maylor 与 Williams的批评、以及OECD的后续材料，使证据责任落到分母“全部重大扰动来源数”：只有“被正确识别的复杂性来源数／全部重大扰动来源数”能区分普遍变化与选择性结果。项目复杂性社会政治的结构读数拆成3项：主命题、替代机制、缺失对象与时间窗分别核对，任一项都不由总均值代填。

◎ 三个常见误解

误解一：把项目与工程项目管理等同于增加数据或工具。之所以容易误读，是因为“重新思考项目管理把交付对象从计划移到实践 Rethinking Project Management”确实提供了操作方法；但方法只有在说明“被正式计划覆盖的关键决策数／全部关键决策数”的分母、失效条件与账外对象后，才构成可检验转向。

误解二：认为平均改善自动适用于所有对象。“混合敏捷承认不同工作包需要不同节奏 Hybrid Project Management”提醒，群体结果可能掩盖选择、异质性或制度适应；正确表述应当同时给出谁进入样本、谁被排除，以及何时方向会反过来。

误解三：把透明、合规或参与当作终点。“人工智能项目管理需要把建议与决策责任分开 AI-Augmented Project Management”显示，程序被采用后仍可能产生新盲区；通过形式审查并不等于交付价值、系统韧性与社会许可已经得到实质保障。

◎ 争议现场

第1场争论围绕“项目复杂性需要区分结构、技术与社会政治维度 Dimensions of Project Complexity”：维度之间重叠，管理者自评也可能把失败归因于“复杂”以逃避责任。要使争论收敛，需要开展跨机构预注册比较，固定“被正确识别的复杂性来源数／全部重大扰动来源数”的口径，并把“未能发声的地方利益、跨接口小故障和累积返工”列入结果；当复杂性标签取代可分解责任时，方向反过来：复杂度评分越高纠错越少，就应承认原命题只在限定条件下成立。

第2场争论围绕“项目化扩张把永久组织问题转移给临时团队 Projectification of Organizations”：跨国定义仍不统一，工作时间比例不能反映权力与不稳定性。要使争论收敛，需要开展纵向部署前后追踪，固定“项目工作时间／组织全部工作时间”的口径，并把“项目间等待期、无家可归的知识、连续加班后的恢复成本”列入结果；当永久岗位被拆成连续项目时，方向反过来：灵活性越高组织学习越弱，就应承认原命题只在限定条件下成立。

第3场争论围绕“项目风险分析开始由静态登记表转向动态数据 Data-Driven Project Risk”：可见数据偏向已数字化工作，异常报警可能造成注意过载。要使争论收敛，需要开展边界样本与反例样本并列试验，固定“在决策前被识别的风险数／全部实际发生风险数”的口径，并把“没有传感器的小承包环节、未被编码的关系冲突和近失”列入结果；当报警数量成为风险管理绩效时，方向反过来：监测越密真实弱信号越难被看见，就应承认原命题只在限定条件下成立。

◎ 十条可做的研究命题

命题：把“未获批准的诚实方案、取消项目和预算外配套成本”纳入“最终成本超支额／决策时批准预算”后，“巨型项目的成本低估是系统性而非偶然误差 Megaproject Cost Underestimation”的效应将显著缩小。设计：在两类组织中预注册分母并重算三个周期。证伪：纳入后方向和效应量均不变。

命题：“参考类预测用外部基准压制内部乐观 Reference Class Forecasting”与“数字孪生把项目控制改为物理—虚拟闭环 Digital Twins in Construction”之间存在由“有限近似控制无限对象”调节的反号关系。设计：构造支持条件与失效条件的成对样本。证伪：两种条件下“落入参考分布置信区间的项目数／全部预测项目数”保持同一方向。

命题：当“被正式计划覆盖的关键决策数／全部关键决策数”被用于设计冻结，参与者会把成本转移到“运输损伤、工厂返工、被标准模块排除的特殊需求”。设计：比较考核前后记录、访谈与结果分布。证伪：账外对象规模和成本均未变化。

命题：“项目复杂性需要区分结构、技术与社会政治维度 Dimensions of Project Complexity”的跨机构迁移取决于是否同时保留“项目韧性要求管理吸收、适应与恢复三种能力 Project Resilience”所要求的条件。设计：在两个制度环境中复制同一流程。证伪：移除该条件后，交付价值、系统韧性与社会许可仍稳定改善。

命题：独立复核会降低“敏捷方法的成功取决于迭代是否产生真实反馈 Agile Project Success”的表面绩效，却提高一年后的交付价值、系统韧性与社会许可。设计：分离指标定义者与评价者并做纵向跟踪。证伪：短期和长期结果均无变化。

命题：将“混合敏捷承认不同工作包需要不同节奏 Hybrid Project Management”与“供应链地缘风险把项目计划改写为可替代网络 Geopolitical Risk in Projects”组合，会产生现有总分无法识别的新对象。设计：联合记录两条中未入账对象与可比较读数，进行聚类和机制访谈。证伪：新增类别不提高解释或预测。
