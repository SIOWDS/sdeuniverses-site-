教育领导与学校治理

近二十年 · 两幕 · 20 个新思想 · 约 30,059 字 · 王德生 亲撰 · 2026 年 8 月

教育领导与学校治理近二十年的变化，可以概括为把“结果是什么”改写成“结果由谁、沿哪条路径、在何种条件下生成”。2006—2016年从“教学领导对学生结果的影响大于一般变革领导 Leadership Dimensions and Student Outcomes”到“学校转型需要按阶段组合领导行动 Successful School Leadership”，研究逐步拆开校长个人能力、考试结果和制度授权所遮蔽的对象与过程；2016—2026年从“文化回应型领导把制度性种族与社区知识纳入治理 Culturally Responsive School Leadership”到“人工智能学校治理需要可审计采购与退出机制 AI Governance for School Systems”，又把平台、算法、公共风险和治理后果写回模型。本块以学校领导、治理能力与改进网络为共同场景，每条都保留提出、争议、最新材料和带分母读数，并把账外对象单独登记。最终要检验的是：当指标进入教师配置与问责后，学习改进、组织信任与学校公平是否仍保持原来的含义。

【第一幕】上一个十年 · 约 2006—2016

第一幕处理基础概念的改写：从“教学领导对学生结果的影响大于一般变革领导 Leadership Dimensions and Student Outcomes”到“学校转型需要按阶段组合领导行动 Successful School Leadership”，研究逐步证明校长个人能力、考试结果和制度授权不能独立代表学校领导、治理能力与改进网络，失败与排除也必须进入证据。

甲、教学领导对学生结果的影响大于一般变革领导Leadership Dimensions and Student Outcomes

提出Robinson、Lloyd 与 Rowe，2008，《Educational Administration Quarterly》44(5):635–674，DOI 10.1177/0013161X08321509。　争议Leithwood、Harris 与 Hopkins，2020，《School Leadership & Management》40(1):5–22，DOI 10.1080/13632434.2019.1596077。　最新UNESCO Global Education Monitoring Report Team，2025，《Lead for Technology: 2025 East Asia Report on Leadership and Digital Transformation in Education》。　关键领导影响学生结果主要通过设定教学目标、参与教师学习和保障教学质量

Robinson、Lloyd 与 Rowe在2008年提出“教学领导对学生结果的影响大于一般变革领导 Leadership Dimensions and Student Outcomes”时，面对的旧框架仍以校长个人能力、考试结果和制度授权为主，被结算的对象与汇总读数只在结果异常后才被追问。Leithwood、Harris 与 Hopkins在2020年的异议把难点落到数据团队纪要：纳入研究多为观察性，领导实践与学校既有能力可能互为因果，而“没有被校长观察的课堂、非正式教师领导和学生自组织”正是旧账本没有位置的那部分。

“教学领导对学生结果的影响大于一般变革领导 Leadership Dimensions and Student Outcomes”的核心判断由Robinson、Lloyd 与 Rowe（2008）写明：领导影响学生结果主要通过设定教学目标、参与教师学习和保障教学质量。为了回应Leithwood、Harris 与 Hopkins（2020）对Robinson、Lloyd 与 Rowe主张的异议，并接受UNESCO Global Education Monitoring Report Team的新场景检验，解释焦点被放在对象或读数“教学领导对学生结果的影响大于一般变革领导”上，本条只保留一个决定因素：决定领导影响的只有是否直接进入教学与教师学习。

Robinson、Lloyd 与 Rowe（2008）给出的关键读数为：元分析比较五类领导维度，参与和促进教师学习的平均效应明显高于一般转型领导。针对Leithwood、Harris 与 Hopkins（2020）对Robinson、Lloyd 与 Rowe证据的可比性质疑，并承接UNESCO Global Education Monitoring Report Team的更新，学校改进计划必须把“与教学直接相关的领导行动数”与“全部领导行动数”同时保存，复核量纲为“与教学直接相关的领导行动数／全部领导行动数”。

“教学领导对学生结果的影响大于一般变革领导 Leadership Dimensions and Student Outcomes”的适用边界由Leithwood、Harris 与 Hopkins（2020）集中提出：纳入研究多为观察性，领导实践与学校既有能力可能互为因果。Leithwood、Harris 与 Hopkins对Robinson、Lloyd 与 Rowe的压力测试不是简单缩小范围，而是要求直接观察：当校长过度直接控制教学时，方向反过来：教学领导越强教师专业自主越弱。Robinson2008—Leithwood2020的争议已暴露明确的自我限制。就Robinson、Lloyd 与 Rowe提出、Leithwood、Harris 与 Hopkins质疑的命题而言，UNESCO Global Education Monitoring Report Team到2025年的材料仍不能替代预先登记的失效检验。

把Robinson、Lloyd 与 Rowe（2008）的证据带入学校问责时，学校董事会应在数据团队纪要中分别登记“与教学直接相关的领导行动数”与“全部领导行动数”，而不是只留下最终比率。依据Leithwood、Harris 与 Hopkins在2020年对Robinson、Lloyd 与 Rowe的反例，并承接UNESCO Global Education Monitoring Report Team的新场景，数据团队纪要还要显示“没有被校长观察的课堂、非正式教师领导和学生自组织”的规模与去向，否则未被结算的代价会被误读为没有发生。为避免Robinson、Lloyd 与 Rowe所述指标在Leithwood、Harris 与 Hopkins的边界情形中反客为主，UNESCO Global Education Monitoring Report Team（2025）所对应的制度设计不是再加总分，而是公开口径变更、例外批准与账外成本。

把Robinson、Lloyd 与 Rowe（2008）和Harris（2008）并读，可以看到“教学领导对学生结果的影响大于一般变革领导 Leadership Dimensions and Student Outcomes”追问被结算的对象与读数，“分布式领导把领导从职位改写为互动实践 Distributed Leadership”追问行动次序与反馈路径，两条命题共享的未言明条件是“只有进入“教学领导对学生结果的影响大于一般变革领导”正式记录的对象才影响总体结论，没有被校长观察的课堂、非正式教师领导和学生自组织可以留在分母之外”。跨领域联系由Leithwood、Harris 与 Hopkins、Grissom、Egalite 与 Lindsay的反例来定位，而不是泛称相关，二者给出的回查入口是另见第129号第12条与第434号第6条。

乙、分布式领导把领导从职位改写为互动实践Distributed Leadership

提出Harris，2008，《Distributed School Leadership》，Routledge。　争议Grissom、Egalite 与 Lindsay，2021，《How Principals Affect Students and Schools》，Wallace Foundation。　最新UNESCO Global Education Monitoring Report Team，2024，《Global Education Monitoring Report 2024/5: Leadership in Education—Lead for Learning》。　关键领导不是校长个人风格，而是多人、工具与情境共同形成的实践

围绕“分布式领导把领导从职位改写为互动实践 Distributed Leadership”，Harris（2008）首先指出，若继续用校长个人能力、考试结果和制度授权作总解释，行动次序、反馈和转折点就会被压成未说明的残差。对照Grissom、Egalite 与 Lindsay（2021）的反例可见，“分布”可能只是责任下放而无权力和资源，非正式领袖也可能形成小圈子，若校长团队删去“无头衔却承担协调者、被分责但无决策权者”，表面稳定很可能只是样本边界被改写。UNESCO Global Education Monitoring Report Team在2024年的材料把Harris、Grissom、Egalite 与 Lindsay之间的分歧带入教师流动表：同名结果若经历不同技术采购，就不能被视为同一事实。

在Harris的2008年论证中，“分布式领导把领导从职位改写为互动实践 Distributed Leadership”不再只是相关性标签，而明确主张：领导不是校长个人风格，而是多人、工具与情境共同形成的实践。按Grissom、Egalite 与 Lindsay（2021）给出的反例压力并对照Harris、UNESCO Global Education Monitoring Report Team两组材料，若行动路径“分布式领导把领导从职位改写为互动实践”不起决定作用，那么“决定领导能力的只有任务是否在有专长者之间真实分布”就应被判错。

经验判断的锚点来自Harris（2008）：学校案例显示，教师团队、中层与网络可承担课程、评估和改进领导，分布形式影响信任与执行。为检验Grissom、Egalite 与 Lindsay（2021）针对Harris所指出的选择问题，并接续UNESCO Global Education Monitoring Report Team的更新，不能只展示“由非正式领导者承担的关键任务数”，而要在教师流动表中按“由非正式领导者承担的关键任务数／全部领导任务数”重算。为复核Harris提出而Grissom、Egalite 与 Lindsay质疑的命题，按照UNESCO Global Education Monitoring Report Team（2024）的更新口径，第三方至少要获得原始分母、事件定义和“无头衔却承担协调者、被分责但无决策权者”清单，不能只接收汇总图表。

“分布式领导把领导从职位改写为互动实践 Distributed Leadership”的适用边界由Grissom、Egalite 与 Lindsay（2021）集中提出：“分布”可能只是责任下放而无权力和资源，非正式领袖也可能形成小圈子。Grissom、Egalite 与 Lindsay对Harris的压力测试不是简单缩小范围，而是要求直接观察：当任务下放而问责仍向下集中时，方向反过来：分布越广倦怠越重。Harris2008—Grissom2021的争议已暴露明确的自我限制。就Harris提出、Grissom、Egalite 与 Lindsay质疑的命题而言，UNESCO Global Education Monitoring Report Team到2024年的材料仍不能替代预先登记的失效检验。

按照Harris在2008年建立的口径，校长团队处理技术采购不能只引用“由非正式领导者承担的关键任务数／全部领导任务数”，还要让教师流动表保存分子、分母与口径变更。Grissom、Egalite 与 Lindsay（2021）提醒，校长团队必须为Harris提出而UNESCO Global Education Monitoring Report Team继续检验的“无头衔却承担协调者、被分责但无决策权者”提供查询位置，在Grissom、Egalite 与 Lindsay所划定的责任边界里，它若没有位置，责任便会在部门之间消失。

Harris、Branch、Hanushek 与 Rivkin的两组证据可以在本块内部对读：“分布式领导把领导从职位改写为互动实践 Distributed Leadership”把解释焦点放在行动次序与反馈路径，“校长效应必须从教师配置与学校改进路径识别 The Effect of Principals on School Performance”则放在制度、技术与关系条件，二者都默认“只有进入“分布式领导把领导从职位改写为互动实践”正式记录的对象才影响总体结论，无头衔却承担协调者、被分责但无决策权者可以留在分母之外”。为了避免只凭词语相似配对，Grissom、Egalite 与 Lindsay（2021）与Day、Gu 与 Sammons（2016）给出了具体回查路径：另见第152号第13条与第434号第8条。

丙、校长效应必须从教师配置与学校改进路径识别The Effect of Principals on School Performance

提出Branch、Hanushek 与 Rivkin，2013，《School Leaders Matter》，Education Next 13(1):62–69。　争议Day、Gu 与 Sammons，2016，《Educational Administration Quarterly》52(2):221–258，DOI 10.1177/0013161X15616863。　最新OECD，2025，《Policies for the Digital Transformation of School Education》，OECD Publishing。　关键校长对学生结果的影响主要通过教师招聘、保留、文化与资源配置累积

Branch、Hanushek 与 Rivkin在2013年提出“校长效应必须从教师配置与学校改进路径识别 The Effect of Principals on School Performance”时，面对的旧框架仍以校长个人能力、考试结果和制度授权为主，制度、技术与关系条件只在结果异常后才被追问。Day、Gu 与 Sammons在2016年的异议把难点落到数据团队纪要：校长分配并非随机，增值指标会混入学生流动和地区政策，而“离开学校的教师、未参加测试学生和短任校长的长期影响”正是旧账本没有位置的那部分。

在Branch、Hanushek 与 Rivkin的2013年论证中，“校长效应必须从教师配置与学校改进路径识别 The Effect of Principals on School Performance”不再只是相关性标签，而明确主张：校长对学生结果的影响主要通过教师招聘、保留、文化与资源配置累积。按Day、Gu 与 Sammons（2016）给出的反例压力并对照Branch、Hanushek 与 Rivkin、OECD两组材料，若制度条件“校长效应必须从教师配置与学校改进路径识别”不起决定作用，那么“决定校长影响的只有其能否改变教师与组织条件”就应被判错。

经验判断的锚点来自Branch、Hanushek 与 Rivkin（2013）：美国行政数据研究估计校长质量差异与学校增值相关，低绩效校长在高贫困学校的代价更大。为检验Day、Gu 与 Sammons（2016）针对Branch、Hanushek 与 Rivkin所指出的选择问题，并接续OECD的更新，不能只展示“校长任期内学生增值”，而要在教师流动表中按“校长任期内学生增值／同校历史增值”重算。为复核Branch、Hanushek 与 Rivkin提出而Day、Gu 与 Sammons质疑的命题，按照OECD（2025）的更新口径，第三方至少要获得原始分母、事件定义和“离开学校的教师、未参加测试学生和短任校长的长期影响”清单，不能只接收汇总图表。

“校长效应必须从教师配置与学校改进路径识别 The Effect of Principals on School Performance”的适用边界由Day、Gu 与 Sammons（2016）集中提出：校长分配并非随机，增值指标会混入学生流动和地区政策。Day、Gu 与 Sammons对Branch、Hanushek 与 Rivkin的压力测试不是简单缩小范围，而是要求直接观察：当校长为提高增值而筛选学生或教师时，方向反过来：估计效应越高组织稳定越低。Branch2013—Day2016的争议已暴露明确的自我限制。就Branch、Hanushek 与 Rivkin提出、Day、Gu 与 Sammons质疑的命题而言，OECD到2025年的材料仍不能替代预先登记的失效检验。

Branch、Hanushek 与 Rivkin（2013）的主张若进入实践，第一项治理动作应是改造学生申诉记录：由教师领导小组把“校长任期内学生增值／同校历史增值”拆开留痕。对Day、Gu 与 Sammons（2016）针对Branch、Hanushek 与 Rivkin所指出、并由OECD继续检验的盲区，最低治理要求是让“离开学校的教师、未参加测试学生和短任校长的长期影响”可追溯，而不是在汇总时静默删除。回应Branch、Hanushek 与 Rivkin的证据与Day、Gu 与 Sammons的边界批评，OECD（2025）的更新进一步要求分离指标定义者、教师配置批准者与复核者，并在部署后再次测量行为回写。

Branch、Hanushek 与 Rivkin提出的“校长效应必须从教师配置与学校改进路径识别 The Effect of Principals on School Performance”并非孤立条目，Robinson、Lloyd 与 Rowe处理“教学领导对学生结果的影响大于一般变革领导 Leadership Dimensions and Student Outcomes”时从被结算的对象与读数解释同类结果，正好检验前者对制度、技术与关系条件的强调是否过强。Day、Gu 与 Sammons、Leithwood、Harris 与 Hopkins构成的边界证据说明，同一机制在别处已有不同名称与分母，具体入口为另见第130号第13条与第152号第11条。

丁、学校自治只有与问责和能力配套才有效School Autonomy and Accountability

提出Hanushek、Link 与 Woessmann，2013，《Journal of Development Economics》104:212–232，DOI 10.1016/j.jdeveco.2012.08.004。　争议Leithwood、Harris 与 Hopkins，2020，《School Leadership & Management》40(1):5–22，DOI 10.1080/13632434.2019.1596077。　最新UNESCO Global Education Monitoring Report Team，2025，《Lead for Technology: 2025 East Asia Report on Leadership and Digital Transformation in Education》。　关键学校自治在制度成熟地区可能改善表现，在弱问责系统中可能加剧差异

在Hanushek、Link 与 Woessmann（2013）之前，“学校自治只有与问责和能力配套才有效 School Autonomy and Accountability”常由校长个人能力、考试结果和制度授权直接结算，研究很少说明被结算的对象与汇总读数怎样改变同一指标的含义。Leithwood、Harris 与 Hopkins（2020）随后用边界材料指出：国家层面共变和自选择限制因果推断，自治维度也不完全可比，这使学校改进计划中的“被自治学校拒绝的学生、地方能力不足地区和家长信息成本”不能继续按普通缺失处理。

Maier、Daniel、Oakes 与 Lam于2017年给出的立场可以直接接受反证：学校改进必须同时处理学习、健康、家庭和社区条件，而非把校外困难当背景。Leithwood、Harris 与 Hopkins（2020）迫使Maier、Daniel、Oakes 与 Lam的命题在UNESCO Global Education Monitoring Report Team的新场景中把解释焦点落到对象或读数“社区学校把教育治理扩展到健康与社会服务”，因此，判断标准被明确为：决定社区学校效果的只有服务整合能否以学生与家庭需求为中心。

把“社区学校把教育治理扩展到健康与社会服务 Community Schools as an Evidence-Based Strategy”从观点推进到可核对事实的是Maier、Daniel、Oakes 与 Lam在2017年的材料：研究综述总结综合学生支持、扩展学习、家庭参与和协作领导四大支柱，多项案例显示出勤与学业改善。Leithwood、Harris 与 Hopkins（2020）对Maier、Daniel、Oakes 与 Lam的批评、以及UNESCO Global Education Monitoring Report Team的后续材料，使证据责任落到分母“全部有需要学生数”：只有“实际使用综合服务学生数／全部有需要学生数”能区分普遍变化与选择性结果。

Leithwood、Harris 与 Hopkins（2020）把争论从有没有效应转向何时可识别，其核心异议为：项目异质、资源密集，选择高能力社区可能夸大效果。把Maier、Daniel、Oakes 与 Lam的主张放到Leithwood、Harris 与 Hopkins的边界样本中，最关键的反向情形是：当学校用合作名义替代稳定公共服务时，方向反过来：项目越多家庭导航负担越重。既然文献已经把这项限制说清，为检验Maier、Daniel、Oakes 与 Lam、Leithwood、Harris 与 Hopkins之间的分歧，UNESCO Global Education Monitoring Report Team在2025年之后的研究就必须公开反向结果，否则争论仍不会收敛。

九、系统领导把学校改进从单校竞争转向横向协作System Leadership

在Boylan（2016）之前，“系统领导把学校改进从单校竞争转向横向协作 System Leadership”常由校长个人能力、考试结果和制度授权直接结算，研究很少说明行动次序、反馈和转折点怎样改变同一指标的含义。Grissom、Egalite 与 Lindsay（2021）随后用边界材料指出：协作常在竞争性问责环境中运行，强校也可能只输出表面方案，这使学校改进计划中的“没有被伙伴关系接纳的学校、借调教师的本校成本”不能继续按普通缺失处理。

Boylan（2016）把命题收紧为可反驳的一句：学校领导应同时对本校与更广教育系统负责，通过联盟、网络和伙伴关系扩散能力。Grissom、Egalite 与 Lindsay在2021年对Boylan的边界批评、以及UNESCO Global Education Monitoring Report Team的后续场景，使责任不能分散到笼统因素，必须检验行动路径“系统领导把学校改进从单校竞争转向横向协作”，判断标准是决定系统改进的只有高能力学校是否承担跨校公共责任。

◎ 二十年连起来看

第一条线索：比较单位从中心值转向生成结构。“教学领导对学生结果的影响大于一般变革领导 Leadership Dimensions and Student Outcomes”先拆开校长个人能力、考试结果和制度授权，到“文化回应型领导把制度性种族与社区知识纳入治理 Culturally Responsive School Leadership”时，研究已经要求同时观察对象、路径和条件；这使学习改进、组织信任与学校公平不能再由单一平均数代表。

第二条线索：技术进入制度后会回写被测对象。“专业学习共同体的价值取决于是否改变课堂实践 Professional Learning Communities”说明测量与行动并不分离，“校长福祉是学校治理能力的约束条件 Principal Well-Being”进一步把激励、适应和申诉写进学校领导、治理能力与改进网络；指标越接近考核，越需要二次测量。

第三条线索：账外对象成为新的解释入口。从“系统领导把学校改进从单校竞争转向横向协作 System Leadership”到“人工智能学校治理需要可审计采购与退出机制 AI Governance for School Systems”，二十年积累把失败、退出与未分类事件从附注移到分母。第442号最重要的收获，不是多一个总分，而是知道哪些对象原本根本不算对象。

◎ 三个常见误解

误解一：把教育领导与学校治理等同于增加数据或工具。之所以容易误读，是因为“校长效应必须从教师配置与学校改进路径识别 The Effect of Principals on School Performance”确实提供了操作方法；但方法只有在说明“校长任期内学生增值／同校历史增值”的分母、失效条件与账外对象后，才构成可检验转向。

误解二：认为平均改善自动适用于所有对象。“改进科学用小规模连续试验替代一次性改革 Improvement Science in Education”提醒，群体结果可能掩盖选择、异质性或制度适应；正确表述应当同时给出谁进入样本、谁被排除，以及何时方向会反过来。

误解三：把透明、合规或参与当作终点。“数字领导的对象是制度转型而非设备采用 Digital Transformation Leadership in Schools”显示，程序被采用后仍可能产生新盲区；通过形式审查并不等于学习改进、组织信任与学校公平已经得到实质保障。

◎ 争议现场

第1场争论围绕“学校自治只有与问责和能力配套才有效 School Autonomy and Accountability”：国家层面共变和自选择限制因果推断，自治维度也不完全可比。要使争论收敛，需要开展跨机构预注册比较，固定“自治决策中被公开评估的事项数／全部自治事项数”的口径，并把“被自治学校拒绝的学生、地方能力不足地区和家长信息成本”列入结果；当学校可控制招生但无公平约束时，方向反过来：自治越大分层越深，就应承认原命题只在限定条件下成立。

第2场争论围绕“教师领导从角色授权推进到组织条件 Teacher Leadership Review”：学生结果证据有限，教师领导者常由校长选择而非同伴授权。要使争论收敛，需要开展纵向部署前后追踪，固定“拥有决策权的教师领导者数／全部教师领导者数”的口径，并把“无正式头衔领导者、被额外工作挤压的教学时间”列入结果；当教师领导成为无薪行政外包时，方向反过来：参与越高专业倦怠越重，就应承认原命题只在限定条件下成立。

第3场争论围绕“社区学校把教育治理扩展到健康与社会服务 Community Schools as an Evidence-Based Strategy”：项目异质、资源密集，选择高能力社区可能夸大效果。要使争论收敛，需要开展边界样本与反例样本并列试验，固定“实际使用综合服务学生数／全部有需要学生数”的口径，并把“无证家庭、非正式照护者和服务转介后未抵达者”列入结果；当学校用合作名义替代稳定公共服务时，方向反过来：项目越多家庭导航负担越重，就应承认原命题只在限定条件下成立。

◎ 可与哪些领域对撞

本块“教学领导对学生结果的影响大于一般变革领导 Leadership Dimensions and Student Outcomes”的跨领域对手可沿以下路径查找：另见第129号第12条与第434号第6条。两边共享的未言明条件是“只有进入“教学领导对学生结果的影响大于一般变革领导”正式记录的对象才影响总体结论，没有被校长观察的课堂、非正式教师领导和学生自组织可以留在分母之外”，但本条把责任落在被结算的对象与读数，相关研究则从行动次序与反馈路径设置纠错。若校长过度直接控制教学，教学领导越强教师专业自主越弱，就必须把“没有被校长观察的课堂、非正式教师领导和学生自组织”承认为独立对象，用它解释为何同一动作在两种制度中出现相反方向。

本块“校长福祉是学校治理能力的约束条件 Principal Well-Being”的跨领域对手可沿以下路径查找：另见第142号第16条与第152号第12条。两边共享的未言明条件是“校长福祉是学校治理能力的约束条件”一旦被制度采用仍测量原来那件事，离职前未报告者、代理校长与家庭照护成本不因考核而扩大”，但本条把责任落在被结算的对象与读数，相关研究则从行动次序与反馈路径设置纠错。若系统用“使命”解释过载，承诺越高退出越快，就必须把“离职前未报告者、代理校长与家庭照护成本”承认为独立对象，用它解释为何同一动作在两种制度中出现相反方向。

◎ 十条可做的研究命题

命题：把“没有被校长观察的课堂、非正式教师领导和学生自组织”纳入“与教学直接相关的领导行动数／全部领导行动数”后，“教学领导对学生结果的影响大于一般变革领导 Leadership Dimensions and Student Outcomes”的效应将显著缩小。设计：在两类组织中预注册分母并重算三个周期。证伪：纳入后方向和效应量均不变。

命题：“分布式领导把领导从职位改写为互动实践 Distributed Leadership”与“疫情领导要求在不确定性下维持信任与学习连续 School Leadership in Disruptive Times”之间存在由“谁进入分母”调节的反号关系。设计：构造支持条件与失效条件的成对样本。证伪：两种条件下“由非正式领导者承担的关键任务数／全部领导任务数”保持同一方向。

命题：当“校长任期内学生增值／同校历史增值”被用于教师配置，参与者会把成本转移到“离职前未报告者、代理校长与家庭照护成本”。设计：比较考核前后记录、访谈与结果分布。证伪：账外对象规模和成本均未变化。

命题：“学校自治只有与问责和能力配套才有效 School Autonomy and Accountability”的跨机构迁移取决于是否同时保留“学生声音只有进入决策权才不沦为咨询表演 Student Voice and Agency”所要求的条件。设计：在两个制度环境中复制同一流程。证伪：移除该条件后，学习改进、组织信任与学校公平仍稳定改善。

命题：只优化“引发课堂改变的协作议题数／全部共同体议题数”的分子会恶化长期结果。设计：随机比较只报分子、完整报告和不考核三组。证伪：三组在长期学习改进、组织信任与学校公平上无差异。

命题：“未进入信息系统的课堂观察、学生声音和退出者”不是随机缺失，而与“社区学校把教育治理扩展到健康与社会服务 Community Schools as an Evidence-Based Strategy”的路径系统相关。设计：建立退出与未分类事件追踪队列。证伪：其发生概率与路径变量独立。

命题：在边界样本中，当领导只强化高绩效核心网络时，方向反过来：协作密度越高边缘隔离越深。设计：预先锁定失效阈值，比较阈值两侧的“跨群体有效联系数／全部专业联系数”。证伪：方向没有反转且差异落在最小效应以下。

命题：独立复核会降低“学校转型需要按阶段组合领导行动 Successful School Leadership”的表面绩效，却提高一年后的学习改进、组织信任与学校公平。设计：分离指标定义者与评价者并做纵向跟踪。证伪：短期和长期结果均无变化。

命题：“文化回应型领导把制度性种族与社区知识纳入治理 Culturally Responsive School Leadership”的平均效应由少数高暴露对象驱动。设计：报告完整分布，并按“教育领导全球报告把领导定义扩展到系统各层 Leadership in Education”所界定的条件分层。证伪：分层后各组效应同质。

命题：将“改进科学用小规模连续试验替代一次性改革 Improvement Science in Education”与“人工智能学校治理需要可审计采购与退出机制 AI Governance for School Systems”组合，会产生现有总分无法识别的新对象。设计：联合记录两条中未入账对象与可比较读数，进行聚类和机制访谈。证伪：新增类别不提高解释或预测。
