第三十八章　实验一与实验二

实验一：对话形态与撤机读数

目的：检验第二编的读数面板对撤机成绩的预测力，特别是 k 与 ρ。

设计：自然观察加事后编码，不设干预。招募单一学科（建议高中数学的某一章）的学习者 N≈300，全部使用统一的对话平台完成三个知识点的自学，平台记录完整转写与时间戳。两周后进行撤机延迟考（无预告，覆盖三个知识点并含迁移题）。

编码：两名独立编码者对转写编码 ρ、k、τ、G/V，报告一致性系数；Δc 由学习结束时的自评量表与延迟考成绩标准化后求差。

预注册预测：

  • E1-1：控制总学习时长后，ρ 对延迟考成绩的回归系数显著为负。
  • E1-2：k 对延迟考成绩的回归系数显著为正，且在纳入 ρ 之后仍显著——即否决可见性是独立于代走量的保护因子。
  • E1-3：τ 与延迟考成绩正相关；τ→0 的子样本中，延迟考成绩与对照基线无差异。
  • E1-4：G/V 对延迟考成绩的预测力强于”对话轮数”与”总学习时长”。
  • E1-5：Δc 随 ρ 单调增大。
  • E1-6（次级结局）：对错卷做盲编码，高 ρ 组的错误更多属于识别失败型（完整、流畅、在未标记的分叉处整体偏离），低 ρ 组更多属于回忆失败型（空白、中断、计算错误）。

判负：E1-1 与 E1-2 任一方向相反且显著，第二编作废。

实验二：讲解质量的反向预测

目的：检验本书最反直觉、也最易被打掉的一条预测。

设计：同一知识点，三臂随机，学习时长严格等长。

  • A 臂（高清晰）：AI 讲解经过优化，路径最短、表述最清楚、无冗余分支。k≈0。
  • B 臂（含否决）：AI 在每一个实质推进步骤上，必须先列出至少两个候选下一步并说明为何排除其中之一，然后再走。k≥0.5。其余条件与 A 臂相同，因此 B 臂的讲解更长、更啰嗦、主观清晰度更低。
  • C 臂（逼走型）：AI 只提问、只给反馈、不给下一步；下一步必须由学生说出，学生说不出时 AI 只缩小范围而不代答。ρ≈0。

两周后撤机延迟考，主结局为迁移题得分。

预注册预测：

  • E2-1（主预测）：延迟考成绩 C > B > A，而学习结束时的主观清晰度与满意度评分 A > B > C。即主观教学质量与客观学习结果反向。
  • E2-2：若 C ≈ B，则否决显影足以替代亲自生成——这是本书所能给出的最有价值的教学规格，因为 B 臂的成本远低于 C 臂，且不牺牲进度。
  • E2-3：若 B ≈ A，则否决可见性无效，第十三、十四节作废，本书退回到位置论。

判负：E2-1 主方向相反（A 臂延迟考成绩最高）则本书核心机制被推翻。

这一组实验的份量在于：它把”AI 讲得越好学得越差”这句听上去像是反技术姿态的话，变成一个有明确方向、明确样本量、明确判负条件的经验命题。本书愿意在这一条上被打掉。
