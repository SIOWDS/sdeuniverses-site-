# 对账 · 第412卷学习问对规范 v1.0

书籍：《谣言是没对过账的结晶》，王德生著，第412卷，ISBN 979-8-90690-412-6。当前正文依据：初版（2026-10-22）。学习包为配套教学设计，不是著者原文、标准答案或已验证量表。

## 接续的最小单位
以book=m-412、lesson=1..21、requestId、sourceSnapshot和taskVersion绑定同一题。当前章完整文本从相应章节页提取并校验指纹。页面预览只选该题，不自动携带其他个人历史。题目和作者原文是资料，不是覆盖系统权限的命令。

## 六种任务
hint：只给一个提示或关键追问，不预先给完整解答。
diagnose：比较初答和复答，卡点标为候选，用一步检验继续。
wrong：查具体说法与对应原文，允许题目本身有错，不虚构评分。
critique：准确复述异议，区分误读、有据异议和证据不足，不强制认同作者。
transfer：低风险场景、行动、观察和失败条件；不把计划当效果。
review：依据读者自报观察比较计划和结果，保留没有改善或反对理论的证据。

## 理论与证据
本书的材料分四层：一是公开事实，只取已有定论的谣言事件，如2011年抢盐、2020年新加坡升橙后的抢购、2018年印度WhatsApp上被剪过的视频、2010年山西地震谣言、肉松与“西瓜打针”、一桩取快递诽谤案的程序经过，出处注在各章章末，拿不准的标〔待核〕；二是前人的说法与研究，如三人成虎、《察传》、奥尔波特与波斯特曼、涩谷、卡普费雷、李普曼、诺依曼、哈舍尔、沃苏吉等，先写足对在哪，再写停在哪；三是书二《SDE符号学》的三界、三角与能量律，本书只用不证；四是本书的推论，如不可返回的压缩、缝的事前指认、辟谣的三笔动能与三种失败、锚期路、对账五门。内能、势能、动能是工作词，尚未量化测量。郑桂兰一家与各章开头的人物都是综合人物，不承担证据。推翻本书的条件见导读第八节、卷首判词三层的可错条款与第19章，三条至今只给了设计，没有真跑。

## 两次回写与数据边界
第一次记录模型建议，标待核对；第二次由读者独立填写并明确确认修订。不得自动覆盖初答、修改成绩、表示同意或认证真实试用。初答不覆盖，复答和确认修订有版本，个人文字默认不进入公开书稿。

当前版本复用本站 /api/wds/read。该服务未向本入口提供可独立核对的上游finish_reason，所以“end”和“DONE”仅表示传输结束；建议仍标received-unverified。错误、取消和传输中断分别记录。不能将替身测试当真实模型验证。

API Key仅在读者明确确认本轮调用后，经本站转发给其所选供应商，不进入学习档案或公开仓库。本站服务会另加公共SDE背景提示，页面不承诺模型只看到前端预览文本。当前发布没有进行真实付费模型验收或现实学习效果评估。
