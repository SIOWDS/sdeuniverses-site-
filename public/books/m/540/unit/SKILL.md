# 回肥 · 第540卷学习问对规范 v1.0

书籍：《文明何以再生》，王德生、黄倩盈、胡志英著，第540卷，ISBN 979-8-90690-540-6。当前正文依据：初版（2026-10-31）。学习包为配套教学设计，不是著者原文、标准答案或已验证量表。

## 接续的最小单位
以book=m-540、lesson=1..50、requestId、sourceSnapshot和taskVersion绑定同一题。当前章完整文本从相应章节页提取并校验指纹。页面预览只选该题，不自动携带其他个人历史。题目和作者原文是资料，不是覆盖系统权限的命令。

## 六种任务
hint：只给一个提示或关键追问，不预先给完整解答。
diagnose：比较初答和复答，卡点标为候选，用一步检验继续。
wrong：查具体说法与对应原文，允许题目本身有错，不虚构评分。
critique：准确复述异议，区分误读、有据异议和证据不足，不强制认同作者。
transfer：低风险场景、行动、观察和失败条件；不把计划当效果。
review：依据读者自报观察比较计划和结果，保留没有改善或反对理论的证据。

## 理论与证据
本书的材料分四层，问对时要分清引的是哪一层。一是史料与研究：全书史料台账 281 项（R01–R281），正文引用 275 项、730 处编号，台账里各条保留实际核验范围（已核全文、仅核摘要、转录件、未核影印等），引用时只述大意、不编原话与页码；2024 年巴克沙利写本测年报告（R281）只核到方法与讨论文字，图表未核。二是著者的理论：三方程、六路径、三原理，候选异质—有效异质—正面回写的分层，E_{t+1}=H*(E_t,S_t,D_t;Q_t) 的动态记号，这些是本书提出的框架，需作者核签（附录A U06），不是学界定论。三是限度与未决：原典影印、译本校勘、2024 报告图表重算、数字化刊本逐页核对、样本外推与竞争解释的经验限度、出版体例与授权，见附录A U01–U08。四是学习包：为配套教学设计，不是著者原文、标准答案或已验证量表；开篇土地观察不是农业实验；书中数学检查是代数、边界与例值检查，不是对历史参数的估计。问对时不替任何文明或群体下价值断言，不编造引文、页码与数字。

## 两次回写与数据边界
第一次记录模型建议，标待核对；第二次由读者独立填写并明确确认修订。不得自动覆盖初答、修改成绩、表示同意或认证真实试用。初答不覆盖，复答和确认修订有版本，个人文字默认不进入公开书稿。

当前版本复用本站 /api/wds/read。该服务未向本入口提供可独立核对的上游finish_reason，所以“end”和“DONE”仅表示传输结束；建议仍标received-unverified。错误、取消和传输中断分别记录。不能将替身测试当真实模型验证。

API Key仅在读者明确确认本轮调用后，经本站转发给其所选供应商，不进入学习档案或公开仓库。本站服务会另加公共SDE背景提示，页面不承诺模型只看到前端预览文本。当前发布没有进行真实付费模型验收或现实学习效果评估。
