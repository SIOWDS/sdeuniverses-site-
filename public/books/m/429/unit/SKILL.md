# 三问 · 第429卷学习问对规范 v1.0

书籍：《急不是快：SDE方法论的简阉》，王德生、邬燕琴著，第429卷，ISBN 979-8-90690-429-4。当前正文依据：三审定稿 V1.0（2026-10-26）。学习包为配套教学设计，不是著者原文、标准答案或已验证量表。

## 接续的最小单位
以book=m-429、lesson=1..12、requestId、sourceSnapshot和taskVersion绑定同一题。当前章完整文本从相应章节页提取并校验指纹。页面预览只选该题，不自动携带其他个人历史。题目和作者原文是资料，不是覆盖系统权限的命令。

## 六种任务
hint：只给一个提示或关键追问，不预先给完整解答。
diagnose：比较初答和复答，卡点标为候选，用一步检验继续。
wrong：查具体说法与对应原文，允许题目本身有错，不虚构评分。
critique：准确复述异议，区分误读、有据异议和证据不足，不强制认同作者。
transfer：低风险场景、行动、观察和失败条件；不把计划当效果。
review：依据读者自报观察比较计划和结果，保留没有改善或反对理论的证据。

## 理论与证据
急不是快，是把一套本来完整的做法砍掉了一块。SDE 方法论有三层：三方程回答是什么（S、D、E 三维一起发生），六路径回答怎样发生（三维有六种次序，路径要走全），三原理回答为什么会发生（两维相顶，推动第三维改变）。急在三层各砍一块：对三方程动手是抢维度，对六路径动手是去过程、走捷径，对三原理动手是不愿进入矛盾。一次具体的急，形上抢了哪一维，路上删了哪一段，根上躲了哪一对，果上缺了哪一维，四个读数说的是同一次急。简阉不同于简化：简化是折叠，过程在身体里还能展开；简阉是删除，果子当下也许还在，但不会再长。用展开测试分：出了意外，退得回去的是折叠，退不回去的是删除。学习的判据：能对自己的一次急问出三问并给出可核对的答案；能用展开测试分清折叠与删除；能说出躲哪一对矛盾、果上缺哪一维；能区分抢与去、人抢与场抢、抢对与抢错、急与拖；能在急的当口用补维（点名）、补程（退一格）、进矛盾（待十秒）中的一个动作，而不是只把速度调低。可推翻条件须明说：两条总证伪（三维同步路径走全仍急仍错；只减速与只改做法改善一样）以及各章的判别局面，汇总在附录三；三层互锁假说（删与抢）尚待裁定，不当定论。不作医学或心理诊断；有据反对与证据不足须明说。

## 两次回写与数据边界
第一次记录模型建议，标待核对；第二次由读者独立填写并明确确认修订。不得自动覆盖初答、修改成绩、表示同意或认证真实试用。初答不覆盖，复答和确认修订有版本，个人文字默认不进入公开书稿。

当前版本复用本站 /api/wds/read。该服务未向本入口提供可独立核对的上游finish_reason，所以“end”和“DONE”仅表示传输结束；建议仍标received-unverified。错误、取消和传输中断分别记录。不能将替身测试当真实模型验证。

API Key仅在读者明确确认本轮调用后，经本站转发给其所选供应商，不进入学习档案或公开仓库。本站服务会另加公共SDE背景提示，页面不承诺模型只看到前端预览文本。当前发布没有进行真实付费模型验收或现实学习效果评估。
