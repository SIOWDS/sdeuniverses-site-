# 不算 · 第450卷学习问对规范 v1.0

书籍：《为什么人人都想重开？》，阳涌著，第450卷，ISBN 979-8-90690-598-7。当前正文依据：初版（2026-10-19）。学习包为配套教学设计，不是著者原文、标准答案或已验证量表。

## 接续的最小单位
以book=m-450、lesson=1..38、requestId、sourceSnapshot和taskVersion绑定同一题。当前章完整文本从相应章节页提取并校验指纹。页面预览只选该题，不自动携带其他个人历史。题目和作者原文是资料，不是覆盖系统权限的命令。

## 六种任务
hint：只给一个提示或关键追问，不预先给完整解答。
diagnose：比较初答和复答，卡点标为候选，用一步检验继续。
wrong：查具体说法与对应原文，允许题目本身有错，不虚构评分。
critique：准确复述异议，区分误读、有据异议和证据不足，不强制认同作者。
transfer：低风险场景、行动、观察和失败条件；不把计划当效果。
review：依据读者自报观察比较计划和结果，保留没有改善或反对理论的证据。

## 理论与证据
本书是阳涌在王德生指导下写成的游戏发生学，写给家长、老师和普通读者。底盘：游戏不是规则加玩家，也不是失败的艺术，而是人类特意造出来、可以一次次再来的地方；日子里的回写常失败，所以留业，游戏是特意搭起来的无业回写场。论证走法：先把前人讲到最有道理的样子，再按“现成、不是推出的、没有公开声明”三项记欠条，然后立本书自己的话，最后写清怎样算错。六编三十八章：第一编三家各押一头（第1—6章），规则派、体验派、文化派、讲故事派与程序派，结算三家共享的前提；第二编三家的欠条（第7—13章），最强对手、最近的前人、三个最强反例、全景缝隙表、欠条定理与三号位的空缺；第三编游戏的三大特征（第14—21章），定义、再来、停顿与起点的稀缺、意义升级、三律转一圈、回写、悬念与业、三根柱子与八格表；第四编重开在日子里（第22—27章），童年、学习、牌桌、沉迷、工作与日子里的一处重开；第五编 AI 坐上主体位（第28—33章），机器赢棋、无限关卡、代练与陪玩、抽卡、设计原则、一角独大与真实增益；第六编三本账与致命条款（第34—38章），读数账、价值账、意义账、致命条款与撤推试验、本书最弱的一点与承认的边界。每章的走法：周家一件小事开头，请前人讲到最强，再给本书的说法，正面接最强的反驳，最后放回日子里给一件明天能试的事，章末一句不超过三十字的带走的话。随身三问：能不能回到同一个起点再来；再来以后手里多了一样“我的”没有；账当场结清了没有。体系术语（SDE、三律、回写、业、三号位）只在第三编、各编结算章与附录系统使用，首次出现配一句日常话。证据边界：陪读的周家人物（外公、周明、林老师、小树）及其邻居、同学均为虚构，故事不是证据；学术研究只当证据不当主角，多为转述大意并标〔待核〕；站上同一学派的文献只算借来的说法，不算外部证据；五条致命条款、一条局部条款和四组撤推试验均尚未实施，阈值留空待登记；书中谈沉迷不替代医生或心理咨询；不宣称已验证学习效果。

## 两次回写与数据边界
第一次记录模型建议，标待核对；第二次由读者独立填写并明确确认修订。不得自动覆盖初答、修改成绩、表示同意或认证真实试用。初答不覆盖，复答和确认修订有版本，个人文字默认不进入公开书稿。

当前版本复用本站 /api/wds/read。该服务未向本入口提供可独立核对的上游finish_reason，所以“end”和“DONE”仅表示传输结束；建议仍标received-unverified。错误、取消和传输中断分别记录。不能将替身测试当真实模型验证。

API Key仅在读者明确确认本轮调用后，经本站转发给其所选供应商，不进入学习档案或公开仓库。本站服务会另加公共SDE背景提示，页面不承诺模型只看到前端预览文本。当前发布没有进行真实付费模型验收或现实学习效果评估。
