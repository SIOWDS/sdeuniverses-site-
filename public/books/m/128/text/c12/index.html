第十二章　应收与存货：期末那一天的“魔术”

上市公司会计造假的SDE神探——三张报表的系统解构 · 王德生 著 · 德麦国际专著第 128 号

只在拍照那一天好看

资产负债表是一张照片，只拍某一天——年末的12月31日，或者半年末的6月30日。

照片有一个弱点：它只管拍照那一刻，不管前后。

你家客厅平时乱七八糟，但拍照那天收拾得干干净净，照片上就是一个整洁的家。照片没有撒谎——拍照那一刻确实整洁；可它也没有告诉你真相。

有一类造假，专门利用照片的这个弱点：只在拍照那一天，把家底收拾得好看；拍完照，再恢复原样。

案发：一家变压器企业的上市之路

辽宁丹东有一家做输变电设备的企业，叫欣泰电气。2014年，它在深圳证券交易所创业板上市。

2015年5月，辽宁证监局按照常规对辖区内的这家公司进行现场检查，发现它可能存在财务数据不真实的问题。证监会随即立案，由两地近三十人组成的联合调查组，进公司、跑银行、访客户，历时约四个月，查清了问题。

证监会认定的手法是这样的：欣泰电气通过外部借款、使用自有资金或伪造银行单据的方式，虚构应收账款的收回，在年末、半年末等会计期末冲减应收款项。

翻译成大白话：

欣泰电气有大量的应收账款——客户欠它的钱，收不回来。应收账款太多，报表就不好看：一来说明公司的生意“赚了利润却收不到钱”，二来按规定要计提坏账准备，会减少利润。这会影响它上市。

于是，在每个会计期末拍照之前，它从外面借一笔钱，或者拿出自己的钱，或者干脆伪造一份银行单据，假装是客户付了款。照片上，应收账款一下子少了，现金多了，坏账准备也少提了。

拍完照，到了下一个期间，这笔钱再还回去、转回去。应收账款悄悄恢复原样。

它就这样带着一张“收拾干净”的照片，通过了上市审核。

结局：退市第一股

2016年7月，证监会对欣泰电气作出行政处罚，认定其欺诈发行。欣泰电气由此成为A股第一家因欺诈发行而被强制退市的上市公司，公司实际控制人被处以罚款，并被采取终身证券市场禁入措施。

保荐机构兴业证券出资5.5亿元设立先行赔付专项基金，先行赔偿受损的投资者。

值得一提的是公司实际控制人当时对媒体说的一番话。他辩称自己连营业收入都没有造假，只是“在流水上造了点假”。

这句话，恰恰道出了这类造假的本质：收入可能是真的，但家底照片是假的。而一张假的家底照片，同样足以骗取上市资格、误导所有的投资者。

用老王算一遍：期末那一天

我们用老王再演一遍。

老王一年卖包子30万元，隔壁食堂和几家小卖部一共欠了他8万元，其中有好几万已经拖了大半年，很可能收不回来了。

年底，老王要拿着账本去找亲戚借钱开分店。他担心亲戚看到“别人欠了8万”会觉得他的生意不靠谱。

于是12月30日，他找表哥临时借了6万元，存进自己卡里，在账上写：“收到食堂和小卖部还款6万元。”

12月31日拍照：

  • 别人欠我的钱：8万 → 2万，漂亮；
  • 卡里的钱：多了6万，漂亮；
  • 按规矩要为可能收不回来的钱计提的坏账：几乎不用提了，利润也漂亮。

1月2日，老王把6万元还给表哥，在账上把那笔“收款”改回去。别人欠他的钱，又变回8万。

亲戚看到的，是12月31日那张照片。

疑点：照片怎么露馅

第一只眼（看显露）：

  • 应收账款在期末特别低，而在季度报告、半年报之间的某些时点却很高？把一年里能看到的所有报表时点排出来，看应收账款是不是只在“拍照日”好看。

第二只眼（看差异）：

  • 这是期末魔术最大的破绽：它会在“期初”留下反弹。年末应收账款骤降，第二年一季度末又骤升；年末现金骤增，第二年一季度又骤降。一次两次可以解释为季节性，年年如此、只在期末发生，就是信号。

第三只眼（看纠缠）：

  • 现金流量表会作证。临时借来的钱，要么表现为筹资活动的现金流入（借款），要么被伪装成经营活动的“销售回款”。如果一家公司期末突然收到大量回款，而这些回款对应的客户、账龄说不清楚，或者期末借款突然增加、期初又突然还掉——两张表放在一起，就能看出一个“借了又还”的圈。
  • 应收账款的“账龄”会作证。附注里有应收账款的账龄分析：一年以内的多少，一到两年的多少，两到三年的多少。如果公司说客户都按时付了款，可账龄结构里却一直有大量的陈年旧账，前后就矛盾了。
  • 坏账准备会作证。同行都在为应收账款计提相当比例的坏账，这家公司却提得很少，要问问它凭什么这么有把握。

存货：看不见的另一半

和应收账款一样，存货也是家底照片上最容易“收拾”的一项。

存货的麻烦在于：它是实物，堆在仓库里、田地里、海底下。外人看不到，只能依靠公司的盘点。于是：

  • 期末可以通过“账实不符”虚增存货：账上有，仓库里没有。还记得康美药业吗？它在2019年的“会计差错更正”里，除了现金少了近三百亿元，存货却一下子多出了一百九十多亿元——同一家公司、同一个年份，家底照片上两大项同时出现了巨额的“差错”，照片的可信度可想而知。
  • 存货的价值依赖估计：会不会过期？会不会跌价？该不该计提跌价准备？估计得乐观一点，利润就多一点。
  • 存货最难核实的，是那些自然生长的资产：海里的扇贝、山上的林木、池塘里的鱼、地里的药材。第三章的獐子岛，就是最典型的例子。

看存货，神探用的仍然是第四章的那几对证人：收入和存货是不是配套地长？存货周转天数是不是越拉越长？存货跌价准备和同行比怎么样？以及，对于那些“自然生长”的存货，有没有任何报表之外的证据——航迹、卫星图像、第三方检测——可以作证。

神探的判断清单：应收与存货

  1. 只在拍照日好看吗？把年报、半年报、季报的应收账款和存货排成一列，看期末和期初的“反弹”。
  2. 期末有没有突击回款、突击借款？第二年初有没有相应的反向流动？
  3. 账龄结构和回款故事对得上吗？
  4. 坏账准备、存货跌价准备，和同行比是不是提得太少？
  5. 存货能被独立核实吗？对自然生长的资产，要格外小心。

本章小结

  1. 资产负债表只拍某一天，期末魔术就是只在拍照那天把家底收拾好看。
  2. 欣泰电气在会计期末用借款、自有资金或伪造单据虚构应收账款收回，成为A股首家因欺诈发行被强制退市的公司。
  3. 期末魔术的破绽在“期初反弹”，以及现金流量表、账龄、坏账准备这些邻居。
  4. 存货是实物，外人看不见，最需要报表之外的证人。

动手练习

找你关心的公司最近两年的四份季报（一季报、半年报、三季报、年报），把“应收账款”排成一行：

时点一季度末二季度末三季度末年末次年一季度末
应收账款

如果年末明显偏低、次年一季度末又明显反弹，就去看同期的现金流量表和短期借款，找一找那个“借了又还”的圈。
