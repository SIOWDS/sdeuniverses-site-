第十八章　三表合一：一套完整的破案流程

上市公司会计造假的SDE神探——三张报表的系统解构 · 王德生 著 · 德麦国际专著第 128 号

为什么需要流程

一个新手看年报，最常见的毛病是东看一眼、西看一眼：看到利润增长就高兴，看到一个奇怪的数字就紧张，看完了也说不清这家公司到底怎么样。

一个老练的神探，不一定比新手懂得更多，但他有顺序。他知道先看什么、后看什么，知道每一步要回答什么问题，知道什么时候该停下来、什么时候该继续往下挖。

下面这套流程分成五步。前两步只用十分钟，就能筛掉大部分不值得深究的公司；后三步用来对付那些真正让你起疑的公司。

第一步：定位——这是一门什么生意？（五分钟）

在看任何数字之前，先回答三个问题：

  1. 它靠什么赚钱？卖产品、卖服务、收租金、放贷款、做贸易？
  2. 钱是怎么流的？先收钱后交货（像预售），还是先交货后收钱（像赊销）？需要大量设备吗？需要大量存货吗？
  3. 同行是谁？找两三家做同样生意的公司，作为后面比较的参照。

这一步看起来和财务无关，却是整个流程的地基。不知道一门生意“应该”是什么样子，就看不出它“不像”什么样子。

一个做软件的公司，存货很少、设备很少，是正常的；一个做钢铁的公司，如果存货很少、设备很少，就不正常了。一个卖水的公司，应收账款很少，是正常的；一个给政府修路的公司，应收账款很多，也是正常的。

第二步：看脸——快速扫一遍“显露”（五分钟）

第二章教过的五条线索，在这里快速过一遍：

  • 审计意见：是不是标准无保留？有没有关键审计事项提到收入、现金、存货、商誉？
  • 会计师事务所：最近几年有没有换？
  • 重大事项：年报前面的“重要提示”和“重大事项”，有没有提到资金占用、违规担保、诉讼、立案调查？
  • 大股东：股权质押的比例高不高？
  • 业绩承诺：有没有对赌？对赌期是哪几年？

这一步的产出，是一张“圈重点”的清单：哪些年份、哪些科目，需要在后面重点看。

如果这两步走完，你没有发现任何值得圈出来的东西，这家公司大概率不需要你当神探。如果圈出了东西，进入第三步。

第三步：拉时间线——看“差异”（二十分钟）

把公司最近五到八年的关键数字排成一张表。不需要很多项，下面这些就够：

科目第1年第2年……
营业收入
毛利率
净利润
经营活动现金流量净额
货币资金
有息负债
应收账款
存货
在建工程＋固定资产
商誉
其他应收款＋预付款项

然后，对这张表问第三章的四个问题：

  1. 有没有急转弯？哪一年、哪一项突然变了方向？
  2. 有没有过线年份？要紧的年份，数字是不是“刚好”？
  3. 有没有太平滑？利润和毛利率是不是整齐得像尺子画的？
  4. 和同行比呢？把第一步找的同行的数字也放进来。

这一步的产出，是几个可疑的年份和几个可疑的科目。

第四步：对口供——看“纠缠”（三十分钟）

现在，拿着第三步找出的可疑年份和科目，让证人对口供。先问报表里面的五对证人（第四章）：

证人对应该怎样可疑的样子
净利润 / 经营现金流长期大体同步利润年年涨，现金流年年跌
营业收入 / 应收账款同步增长应收涨得比收入快得多
营业收入 / 存货同步增长存货越堆越高，或和收入毫不相干
货币资金 / 利息收入、有息负债钱多利息多、借款少钱多、利息少、借款多
固定资产＋在建工程 / 营业收入资产带来产出资产猛涨，产出不动

再补上后面几部学到的几对：

证人对可疑的样子出处
期末 / 期初年末好看，次年一季度反弹第十二章
经营现金流 / 资本支出自由现金流常年为负，投资不见产出第十六章
新业务收入 / 毛利率、员工、资产收入暴增、毛利极低、别的都不动第十七章
对赌期内 / 对赌期后期内刚好达标，期后断崖第六章、第十四章
公司 / 大股东大股东缺钱，公司“有钱”第十章、第十五章

最后，问报表外面的证人：产能、产量、员工、用电、纳税、物流、行业总量，以及媒体调查、监管问询和交易所的问询函。

这一步的产出，是断口：哪一根线接不上，接不上在哪里。

第五步：追问——把断口变成问题（十分钟）

神探不是法官。你手里只有公开资料，下不了“造假”的结论。你能做的，是把每一个断口，变成一个具体的、公司必须回答的问题。

两场破案演练里，我们都是这样结尾的：

  • 为什么利润年年创新高，经营现金流却年年下降？
  • 为什么账上的钱足以还清全部借款，却不还？
  • 那个进度三年停在85%的工程，款项付给了谁？

好的问题有三个特点：具体（指向一个科目、一个年份），可以回答（真实的公司一定能给出答案），答不好就说明问题（含糊其辞本身就是信号）。

然后，去找答案：公司的年报说明、交易所的问询函和公司的回复、业绩说明会的记录。读公司怎样回答问题，往往比读报表本身更有收获。一个说得清的公司，会用数据和事实回答；一个说不清的公司，会用形容词和套话回答。

流程的一张图

把五步连起来，就是：

定位（它应该是什么样）→ 看脸（它说自己是什么样）→ 拉时间线（它这些年是怎么变过来的）→ 对口供（它和它的邻居对得上吗）→ 追问（接不上的地方，它怎么解释）

这五步，正好对应本书的三只眼睛：看脸是“显露”，拉时间线是“差异”，对口供是“纠缠”。定位是地基，追问是收尾。

一个提醒：流程的边界

最后必须说清楚这套流程不能做什么。

它不能证明一家公司造假。它只能告诉你，哪里接不上。接不上的原因，可能是造假，也可能是一门你不熟悉的生意、一个特殊的年份、一次真实的意外。

它也不能保证抓住所有的造假。一个准备极其充分的造假者，可能让报表里的每一根线都暂时对上——这时，只有报表外面的证人、监管机构的调查权力，才能揭开真相。

但它能做到一件非常有价值的事：让你在大多数人之前，问出那个对的问题；让你在不确定的时候，有理由离一家公司远一点。对一个普通投资者来说，这已经足够保护自己了。

本章小结

  1. 破案流程五步：定位、看脸、拉时间线、对口供、追问。
  2. 前两步十分钟，筛掉大部分不需要深究的公司；后三步用于真正可疑的公司。
  3. 神探不是法官，他的产出不是结论，而是具体、可回答、答不好就说明问题的追问。
  4. 流程不能证明造假，但足以让普通人保护自己。

动手练习

用本章的五步，把你一直在跟踪的那家公司完整走一遍。最后写下三个你想问这家公司的问题。然后去交易所网站，搜一搜它有没有收到过问询函——看看监管机构问的，和你问的，是不是同一个方向。
