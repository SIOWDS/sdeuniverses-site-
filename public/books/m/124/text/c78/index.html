第九编　反击与边界

第七十八章　第三记·语境内的临时程序只是激活——本书接不住的那一记

一、先说明这一章为什么单独存在

本书在这一章里没有赢，也不打算装作赢了。

一本论辩的书通常这样处理接不住的反击：略过、降格为脚注、或者用一句”这超出了本书的范围”打发掉。本书不这样做，理由与第五十八章那四条败绩条件是同一个——一本不承认自己哪里薄的书，它说自己哪里厚也不可信。

因此本章的写法与本编其余各章相反。其余各章的结构是”反击—回答”；本章的结构是”反击—为什么接不住—本书做了什么补救—补救为什么不够”。

二、这一记的形式

先回到它攻击的对象。

第五十七章的条款三列了三类性质候选，其中候选三是：语境内临时形成的程序。 模型在推理时可以在语境中形成一个训练时并不存在的、针对当前任务的临时程序。

这是最诱人的猎场，理由显而易见：那个程序不在语料里——语料里没有这道题；也不在权重的任何固定位置上——权重在推理时没有改变。它看起来是一个在推理那一刻被造出来的东西。

反击是这样的：

所谓”形成”，只是把权重里已有的能力按语境组合起来激活了一次。组合的规则本身是训练出来的；能力本身是训练出来的；语境只是触发器。因此那个临时程序仍然先在——它先在于权重之中，只是以一种被压缩的、待触发的形态。

三、为什么本书接不住

本书接不住这一记，原因不是修辞上的，是结构上的。要把它说准。

问题在于”组合”与”形成”之间没有一条本书能画出来的界线。

设有一个模型，它在权重里有能力 a、能力 b，而在某个语境中表现出了能力 c，且 c 在训练中从未被单独要求过。反方说：c 是 a 与 b 的组合，组合规则也在权重里。

本书要反驳这句话，必须能说明：c 不只是 a 与 b 的组合。 而这需要回答”什么叫只是组合”。

试几种回答，逐一看它们为什么不成立。

回答一：若 c 在权重中没有对应的固定结构，则 c 不是先在的。 这个回答看起来最有力，但它把举证责任放到了一个极难完成的位置上——要证明一个结构不存在于权重中。第五十七章第二节讲过绝对不可达不可证，这里是同一个困难的另一个实例：“权重里没有 c”这句话，与”我们还没找到 c 在哪里”无法区分。

回答二：若 c 的出现依赖于语境，则 c 是被语境造成的。 这个回答失败得更快。依赖于触发条件的东西，不因此就不是先在的——钥匙依赖于锁孔才起作用，钥匙仍然是先做好的。

回答三：组合的数量是组合爆炸的，因此不能说每一个组合都先在。 这个回答有直觉上的吸引力，但它恰好落进第七十六章第四节那个地址三里：说”所有组合都先在”，与说”所有小说都在字符串集合里”，是同一句话。而本书已经论证过那个地址是无内容的——问题在于这一次，无内容的是本书自己需要的那一侧。 若”组合的先在是免费的因而无内容”，那么反方的”c 是组合”这句话也无内容；可无内容不等于假，它只是不能判案。于是这一记打成了平手，而平手在本案里等于本书拿不到读数。

三条都不成立。本书没有第四条。

四、这一记有它自己的代价，但代价不构成回答

要把话说完整：这一记不是没有代价。

若”组合的激活”可以算作先在，那么任何造成都可以被同样地重述为”某个更大空间里已有元素的组合被激活了一次”。作曲是音符组合的激活，写作是词语组合的激活，发明是零件组合的激活。第七十五章第二节那个”证明得太多”的诊断，在这里同样适用。

因此，要让这一记站得住，反方必须给出一个非平凡的界限：

哪些组合算激活，哪些组合算形成？

给不出这个界限，这一记就与”所有小说都在字符串集合里”是同一句话。

但这不是一个回答，只是一次对等的索取。

本书向反方要一个界限，反方同样可以向本书要一个界限——而本书上一节已经承认，本书给不出。双方都欠着同一笔账。在一个双方都欠账的位置上，谁也拿不到判决。

这就是为什么本书把这一处标记为尚未解决的争点，而不是标记为”本书的回答有待展开”。两者的差别不是措辞：前者承认没有回答，后者暗示回答存在只是没写。

五、本书实际做了什么补救

承认接不住之后，本书在工序上做了三件事。三件都是减法，没有一件解决了问题。

其一，把候选三降为第三顺位。 条款三的三类性质候选中，候选一（算法性内部结构的出现）排第一，候选二（次序造成的不可达）排第二，候选三排最后。排序的依据在第五十七章写着是可跑性，而这里要补一个更实在的依据：候选三是唯一一个本书在哲学上守不住的。

其二，给它附加了一条额外的证据要求。 候选三必须配上”该组合在权重中不存在对应结构”的证据，才被计入条款三。

这条要求是本书为自己设的障碍，而且是一道几乎过不去的障碍——上一节回答一已经说明，证明一个结构不存在极其困难。本书明知如此仍然设它，理由是：一个守不住的候选，若不设一道几乎过不去的门槛，就会变成本书的软肋。

其三，在条款三未跑之前，候选三在本书中只有启发意义，没有判决意义。 这一条写在第五十七章第四节，本章重申。

六、补救为什么不够

三件补救加起来，做到的只有一件事：它们使本书不会因为这一记而输掉。

它们没有做到的是：使本书能够在这个方向上赢。

这个区别要说清楚。把候选三降级、加门槛、限制其判决意义，等于本书主动把这条路封了。封路之后，反方那一记打在空处——它攻击的是一个本书已经不再倚重的候选。从防守上说，这是有效的。

但条款三本来就是本书三条条款里最强的一条，而候选三本来是它最诱人的一个实例。封掉它之后，条款三只剩候选一与候选二，而这两条都需要新的实验，其中候选二还需要大规模新训练。

所以补救的实质是：本书用放弃一条进攻路线的代价，换来了不在这条路线上被反击。 这是一笔亏本的交易，本书接受它，因为没有更好的选择。

七、这个争点不是模型特有的

在写”怎样才算解决”之前，先指出一件对本章的处境有帮助、但对本书的论证没有帮助的事。

同一个争点在人身上有一个同构的版本。

一个人解决了一个他此前从未遇到过的问题。问：他是形成了一套新的做法，还是组合了他已有的若干种做法？

这个问题在关于创造的讨论里已经存在了很久，而且从来没有被判掉。一方说：所谓创造，无非是已有元素的新组合；元素是学来的，组合的能力也是学来的。另一方说：若一切都是组合，那么”新”这个词就没有指称了，而我们明明能区分一次真正的突破与一次熟练的拼装。

两方所用的论证，与本章第三节、第四节所写的两方论证，形状完全相同。

这件事有两个作用，一个对本书有利，一个对本书不利，两个都要写。

对本书有利的那个：它说明本书接不住这一记，不是因为本书的现场特别弱，也不是因为本书的判据不够好。这是一个更一般的困难，它在任何一个讨论”新东西如何出现”的地方都会出现。 一本在这里承认接不住的书，与一个在这里含混过去的传统，前者更诚实。

对本书不利的那个，而且更重：既然这个争点在人身上也没有被判掉，那么本书原本指望从这个方向上取得的东西——一个可重跑、可缩放的现场所带来的判别力——在这里失效了。换现场没有帮到本书。

第五十三章论证过换现场的理由是可重跑与可缩放；第七十五章又补了第三个理由——在这个现场，先在者是可以被要求出示的对象。而这一记正好绕开了三个理由中的每一个：它不需要重跑（组合与形成的区别不随重跑次数改变），不需要缩放（它在任何规模上都同样成立），也不需要出示地址（权重就在那里，只是不知道该往里面找什么）。

一记同时绕开本书换现场的全部三个理由——这是本章那句”接不住”的完整分量。

八、这一处需要什么才能被解决

最后写清这一处将来可能怎么被解决，因为一个只说”接不住”而不说”怎样才算解决”的承认，是廉价的。

要让这一记被判掉，需要的是一个非平凡的、可操作的激活与形成的界限。它至少要满足三条：

其一，它不能以”在不在权重里”为唯一判据。 因为那个判据落在一个不可证的否定命题上。

其二，它必须对两侧同样适用。 一个只判得出”这是激活”而判不出”这是形成”的界限，不是界限，是一个立场的重述。

其三，它必须给出一个可测的量。 按本书全书的标准，一个不带量与判负条件的界限，不能进入判决。

本书没有这样的界限，也不知道它长什么样。这是本书留给后来者的一个具体的问题，而不是一句谦辞。

有一点可以说：这个问题的形式与第七十一章第五节那个”变换群的三个层级”高度相似——那里问的是哪些变换算标号，这里问的是哪些组合算激活。两者都是在问一条约定的边界该划在哪里。若那一处的框架能被推广到这一处，也许是一条路。本书只能提示到这里，提示不是解决。
