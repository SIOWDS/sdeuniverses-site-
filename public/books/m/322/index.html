AI时代的商场风云与SDE智慧应对

风云比战场更快，对策只能从发生里来

旧商场多次性，经验管用；新商场一次性，经验失灵——对手一夜冒出、地形月月在变、价值正在改道，应对之道只有预案：What If 预判，How If 应对，Why If 接住。

从前商场像一条宽阔的河，河道大体不变，老船夫凭经验就能撑过去；战场才是一次性的，所以兵家讲「因敌制胜」。今天这个对比反过来了：几个人加一个模型，几周就能做出一个对手，平台规则、算法分发、模型能力月月在变，价值又在从物的生产流向「我的知识」。这本书从一句口述出发：最为重要的是 AI 时代的新经济，战场的风云突变更快。

全书把《胜算》里作战参谋的总方法论搬进商场：用 What If 的三方程预判突变，用 How If 的六条路径选起手，用 Why If 的三原理接住突变，每章一张预案卡，三十六章三十六张。长沙奶茶店的林晓、东莞家具厂的老周、杭州独立设计的阿雅，陪读者一路走过。不给「赚钱十个秘诀」，只给一副看局面的眼睛和一套生预案的方法。

三句判词与三层预案

判词一 · 多次与一次旧商场是多次性的，经验管用；新商场是一次性的，经验失灵
判词二 · 更快的风云对手一夜冒出、地形月月在变、价值正在改道——这是比战场更快的风云
判词三 · 预案应对之道是预案：What If 用三方程预判，How If 用六路径应对，Why If 用三原理接住
What If · 预判（三方程）S＝F(D,E)、D＝G(S,E)、E＝H(S,D)：显露、差异、纠缠，哪个先断；哪个方程从没想过，哪里就是缝隙
How If · 应对（六路径）S、D、E 三维的六种次序，同一局面起手不同、结局不同；真实的路往往是几条路径的接续与组合
Why If · 接住（三原理）任何两维相争，会推动第三维改变：张力积累、形状改变、回写；看懂哪两维在争，就知道力往哪里去

一个根、三根梁与三件替换

旧商场的做法本书的替换保留的那一半
靠经验：同样的事会反复发生换成预案：几套方案，加一套方案失效时还能现场生出新方案的方法经验退为「后勤部」，记账、库存、工序、待人接物仍然托底
靠计划：押一种未来，沿线走换成预案：未来是一把扇子，每个方向备一步计划可以作为预案里的一条
商战是两家大公司的攻守换成新商场：几个人加一个模型的一夜对手、月月在变的地形传统商战作慢镜头对照（柯达、诺基亚、王老吉与加多宝）
盼一场最后一战换成留在局里、一直在发生在自己那块局里，规模与位置仍有用

适用范围与边界

本书讲的是一次性、回写剧烈的新商场：对手可以一夜冒出，平台、模型与成本月月在变。在这样的局面里，经验退到后勤，预案才跟得上。在地形几年不变、对手看得见、打法可以重复的局面里，经验仍然管用，本书的方法退为补充。书中真实案例只讲公开事实，核对状态汇总于附录三，尚未核毕处标〔待核〕；全书不做投资与法律建议，不对政策表态，不预言任何一家具体公司的成败。
