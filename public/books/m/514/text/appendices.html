附录一 概念及使用边界

下表统一本书用语，便于回查各章的判断范围。它不是诊断标准，也不是经过验证的量表。一个过程可以涉及多个概念，选用哪一种记录方式，应由正在追问的问题决定。

| 概念 | 本书中的含义 | 不能直接推出的结论 |
| --- | --- | --- |
| 显露 S | 感受、表现或其他可辨认的呈现 | 表现相同便具有同一原因 |
| 差异序列 D | 行动、状态和条件变化的可追踪次序 | 先后关系已经证明因果 |
| 特征纠缠 E | 特征在具体情境中互相限定并随操作改变 | 列出个人和环境因素就完成解释 |
| 收尾 | 为活动建立可接受的结束或后续边界，包括完成、暂停、移交、终止 | 必须做完全部任务才可休息 |
| 可信暂停 | 未完成事项已有足以支持暂时离开的处理安排 | 每件事情都必须重新启动 |
| 回写 | 当前结果进入后续判断、操作、资源或关系条件 | 得到回应或表扬便发生了建设性改变 |
| 限制性回写 | 结果进入后续过程，却压缩了表达、选择或修正机会 | 所有规则和约束都具有伤害性 |
| 经手 | 保有与活动目的和责任相适应的判断与修正机会 | 凡事亲手完成或不可替代才有价值 |
| 反向守门 | 将自身避险经验用于提前关闭他人的问题 | 沉默者属于固定人格类型 |
| 命名锁死 | 状态被过早归类并绑定不容修订的处理路径 | 语言是疲劳的唯一来源 |
| 指标替代 | 记录逐渐取代原本目的，并改变活动的实际排序 | 任何记录和计数必然有害 |
| 受阻性疲惫 | 对部分持续悬置或参与受阻经验的工作性称谓 | 它是独立临床诊断或已验证类型 |
| 无产出权 | 人可以拥有不以成果证明其正当性的休闲时间 | 它是本书已核定的某一地区法律条文 |

上述概念属于不同层次。S、D、E组织解释责任；收尾、回写与经手描述活动关系；无产出权涉及共同生活的规范判断。把它们放在一张表中，是为了便于辨认，不能将它们当成同一套互斥分类。人的疲惫也不需要先被归入其中一个概念，才有资格得到倾听与帮助。

材料承接与署名说明

前三份材料追问经验如何被辨认，分别以活动边界、中断与觉察、命名与回应为入口。中间三份追问疲惫怎样形成，分别进入组织中的差异消退、成功交付与参与退出、疲劳和幸福的关系。最后三份追问解释的边界与实践方向，涉及身体及工具、经手资格、生活与共同关系的重建。

本书的六十章并非六十份独立原稿。每章从相应对话中提取问题线索，经概念拆分、过程推演、反例检验和跨章衔接重新写成。相邻章节共享材料，但承担不同任务。例如第七章区分身体变化与被报告的状态，第八章分析中断打开的比较位置，第九章研究整夜报废的评价，第十章转向测量的作用。这些问题在原对话中交织，本书把它们展开为可以分别讨论又能相互修正的论证。

第54至60章尤其依靠Y3中可见的完整问答，并结合前八部重新组织。由于Y3的末尾论文只保留摘要与部分引言，这些章节的完整论证属于本次扩写，不能被说成原文件中已经存在的成稿。其他截断论文同样如此：缺失部分没有被猜测还原，所补充的收束与研究设计均由本书重新提出。

文件中“我”和“WDS”等标签保留了导出对话的形式。其中WDS是回答者标签，不能据此把所有回答归为王德生本人直接说过的话。指导老师署名按本书作者安排列示，标签与个人发言之间的对应不由本书补造。对话承担思想形成材料的作用，不作为经过招募、同意与编码的访谈样本。

附录三 对话进入论证的方法

一 保留追问怎样改变问题

从对话取材，首先要保留追问的方向。有的追问将“做了多少”转为“事情怎样结束”，有的把“已经看到提醒”进一步追到“为什么仍然继续”，还有的指出“每次都有结果”与“结果改变下一次条件”并非同一件事。如果只摘录最后一次回答，这些转折容易消失，原本需要区别的条件就可能再次被压成一句结论。

本书把转折转化为章内的判别问题。例如，对话描述调姿以后继续观看，便需要同时考虑身体不适得到了局部处理，以及停止整段活动的判断仍未发生。该细节既不能证明此前没有疲劳，也不能证明舒适支持有害。它要求比较局部调整在不同活动安排中所承担的作用，进而说明同一物件为什么可能支持休闲，也可能延续一个当事人已不愿继续的过程。

二 将断言还原为可比较的条件

对话常用鲜明句式推进思考，扩写则需要逐项查明适用条件。“必须做完才能休息”被改为对完成、暂停、移交和终止的区分；“中断才使疲劳存在”被改为对状态、觉察、命名和报告的区分；“计入即毁”被改为记录何时支持目的、何时取代目的的问题。修订并未取消原来的疑问，而是使疑问有机会接触不符合预想的材料。

涉及恢复、幸福与创造时，还需要防止理论重新给人分派任务。半句话、一项小制作或一次散步可以是某人的可用入口，也可以是另一个人的新负担。其有效性不能由动作小就保证。书中因此把建议者、资源条件、拒绝机会和失败后果一并纳入推演，不以当事人是否配合建议作为理论成立的证据。

三 区分例子与观察结果

构造情境用于说明两个概念为何不同，或展示某种解释怎样可能成立。它没有实际样本、发生率和效应大小，不能独自证明现实中的主导机制。对话中的三次、三周、六个月等数字，若无可核来源，就不被转写为经验规律。提出对照条件、时间记录或模型比较，也不等于这些研究已经实施。

相反的情境同样需要认真展开。可靠委托可以支持参与，记录可以减轻记忆负担，标准化可以保护安全，重复维护可以具有价值。这些反例要求“经手”“回写”等概念说明自己的判据，不能只在令人满意的结果出现后给它贴上相应名称。一个判断如果无论观察到什么都成立，就很难承担检验任务。

四 让来源记录接受复查

随书分章源稿保留各章的对话线索与原PDF页码，记录线索如何展开、哪些过强断言被修订、外部来源实际查阅到什么范围。来源台账服务于编辑复查，不计入正文目标。页码指原始PDF页面，不是本书版面页码，两者不可混用。

同一来源可能支持多个章节，但不能因此把其证据强度重复累加。多位写作者对同一文本的内部互读，也不能被称为独立外部同行评审。论证的可信程度取决于可检查的理由、材料和失败条件，而不是参与整理的人数或生成文字的次数。
