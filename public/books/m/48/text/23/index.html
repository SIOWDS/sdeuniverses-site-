第四编 · 人格与心理编

编序

约 778 字 · 纸书第 439 页起 · 王德生 著

如果说意识是心理学的入口，那么人格就是心理学的核心。

然而，过去一个世纪里，人格研究充满了标签化、碎片化与工具化的倾向。

心理学家热衷于创造各种指标：智商、情商、意志力，大五人格，MBTI 类型……

它们似乎能够给人下定义，能够把复杂的生命用几个分数、几个维度、几个

字母来概括。

这些指标确实在应用层面上提供了某些便利，但从本体论角度看，它们都有

一个共同的根本错误：把人格当作主体固有的属性，而不是生成的过程。

  • 智商（IQ）把认知简化为静态的“能力水平”；
  • 情商（EQ）把情绪关系化为“管理技巧”；
  • 意志力（WQ）被当作某种与生俱来的品质；
  • 各类人格分类测试更是把人僵化为某些“类型”。

结果，人格研究丧失了动态性和生成性，心理学陷入了测量学的窠臼，而忽

视了人格背后真正的发生机制。

在三律心理学的框架下，人格必须被彻底重写。人格不是“人自带的属性”，而

是 SIO 整体在三律运行中长期沉淀的产物。

  • 在特征律的运行中，认知习惯和秩序感不断生成，形成知格；
  • 在自由律的运行中，选择方式和意志风格不断沉淀，形成意格；
  • 在幸福律的运行中，情感体验和意义取向不断稳定，形成情格。

人格的核心，不是 IQ、EQ、WQ，而是知格、意格、情格。人格生成史，

就是三律在生命历程中持续作用的历史。

本编的任务，就是从根本上重构“人格与心理学”。文章安排如下：

1. 《颠覆心理学：人没有智商情商意商》 → 先彻底清算旧心理学的幻象。

2. 《三律心理学的内核解码》 → 提出知格、意格、情格作为心理的三大内

核。

3. 《感觉情感情境的生成性根源》 → 说明心理现象如何在三律中发生，而

非主体的独立机能。

4. 《心理健康、疾病与治疗的三律解构入门》 → 重释心理健康与病理，提

出三律平衡作为根本标准。

5–6. 《三律人格发生学：理论与应用（上、下）》 → 系统展开人格生成的

理论框架与教育、社会、临床应用。

5. 《兴趣发生学与成瘾治疗》 → 从幸福律的角度，揭示兴趣与成瘾的发生

机制，展示心理学对现实生活的深度解释力。

这套结构，既有哲学批判的锐度，也有心理机制的深度，更有临床与教育的

实践落点。

通过本编，我们将看到一个全新的心理学：它不再是“测量人的学问”，而是“理

解人格如何生成的学问”。

人格与心理的重构，是通往学习心理学的必由之路。因为学习，本质上就是

人格生成的过程。
