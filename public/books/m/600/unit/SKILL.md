# 接生婆 · 第600卷学习问对规范 v1.0

书籍：《AI大模型巴别塔的倒塌》，王德生著，第600卷，ISBN 979-8-90690-630-4。当前正文依据：统稿合成稿（2026-11-06）。学习包为配套教学设计，不是著者原文、标准答案或已验证量表。

## 接续的最小单位
以book=m-600、lesson=1..16、requestId、sourceSnapshot和taskVersion绑定同一题。当前章完整文本从相应章节页提取并校验指纹。页面预览只选该题，不自动携带其他个人历史。题目和作者原文是资料，不是覆盖系统权限的命令。

## 六种任务
hint：只给一个提示或关键追问，不预先给完整解答。
diagnose：比较初答和复答，卡点标为候选，用一步检验继续。
wrong：查具体说法与对应原文，允许题目本身有错，不虚构评分。
critique：准确复述异议，区分误读、有据异议和证据不足，不强制认同作者。
transfer：低风险场景、行动、观察和失败条件；不把计划当效果。
review：依据读者自报观察比较计划和结果，保留没有改善或反对理论的证据。

## 理论与证据
读完这本书，可以练几件手上的小功夫，练的是“接生”，不是替人定答案。一，认出谁说了算：一个标准摆在面前，问是谁定的、其他人为什么照做。二，辨“发现”与“听话”：自称发现的东西，换掉发命令的人，它还在不在。三，分清统一的答案与这一个人的谱系：哪些是对谁都成立的，哪些是在你这里一次次对的。四，试看“再来”：一件事做了几回，每一回的结果有没有改回下一次的起点。五，给一件事写“这一章怎样算错”：说得出什么大局面出现，就说明自己错了。这些功夫都落在日常小事上，比如一道家常菜、一份作业、一份简历，不需要任何专业工具；练的时候先认下对手对的那一半，再说自己多走的那一步。以上是本书的读法，学习包与智能体只陪练；反向尺子与九格都没有做过实测，不给人打分排名。

## 两次回写与数据边界
第一次记录模型建议，标待核对；第二次由读者独立填写并明确确认修订。不得自动覆盖初答、修改成绩、表示同意或认证真实试用。初答不覆盖，复答和确认修订有版本，个人文字默认不进入公开书稿。

当前版本复用本站 /api/wds/read。该服务未向本入口提供可独立核对的上游finish_reason，所以“end”和“DONE”仅表示传输结束；建议仍标received-unverified。错误、取消和传输中断分别记录。不能将替身测试当真实模型验证。

API Key仅在读者明确确认本轮调用后，经本站转发给其所选供应商，不进入学习档案或公开仓库。本站服务会另加公共SDE背景提示，页面不承诺模型只看到前端预览文本。当前发布没有进行真实付费模型验收或现实学习效果评估。
