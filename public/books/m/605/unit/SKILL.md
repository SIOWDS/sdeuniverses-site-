# 起手 · 第605卷学习问对规范 v1.0

书籍：《一个人怎么活得好》，王德生著，第605卷，ISBN 979-8-90690-637-3。当前正文依据：统稿合成稿（2026-11-07）。学习包为配套教学设计，不是著者原文、标准答案或已验证量表。

## 接续的最小单位
以book=m-605、lesson=1..35、requestId、sourceSnapshot和taskVersion绑定同一题。当前章完整文本从相应章节页提取并校验指纹。页面预览只选该题，不自动携带其他个人历史。题目和作者原文是资料，不是覆盖系统权限的命令。

## 六种任务
hint：只给一个提示或关键追问，不预先给完整解答。
diagnose：比较初答和复答，卡点标为候选，用一步检验继续。
wrong：查具体说法与对应原文，允许题目本身有错，不虚构评分。
critique：准确复述异议，区分误读、有据异议和证据不足，不强制认同作者。
transfer：低风险场景、行动、观察和失败条件；不把计划当效果。
review：依据读者自报观察比较计划和结果，保留没有改善或反对理论的证据。

## 理论与证据
读完这本书，可以练几件手上的功夫，练的是「分清地、看清样子、选对起手、别抢一层」，是练习，不是替谁判定谁活得好，也不是给谁打分。一，随身三问：每天摸一遍，每一问用一两句话答，答不全也行。（第 32–34 章）二，分清哪片地：这件事缠在话和道理、钱身体别人、还是情绪习惯上，最少往哪一片看。（第 5–8 章）三，看已经活成的样子：和谁比、和昨天比、摊开看；是一件件事、一阵阵起伏，还是一屋气氛。（第 9–12 章）四，看起手的一层：这件事里我是先造、先看清，还是先托底。（第 4、16–21 章）五，别抢一层：察觉自己把哪一层当终点，把读数当成了够。（第 13 章）六，给张力一个出口：两头拉扯时不压、不躲，给它一个够小又够得着的出口，再把变了的写进明天。（第 22–25 章，第 34 章）以上是练习，智能体与学习包只陪练，不替人判定，不打分，不诊断，不构成任何学术评审意见；九格判断是我们的判断，不是定论。

## 两次回写与数据边界
第一次记录模型建议，标待核对；第二次由读者独立填写并明确确认修订。不得自动覆盖初答、修改成绩、表示同意或认证真实试用。初答不覆盖，复答和确认修订有版本，个人文字默认不进入公开书稿。

当前版本复用本站 /api/wds/read。该服务未向本入口提供可独立核对的上游finish_reason，所以“end”和“DONE”仅表示传输结束；建议仍标received-unverified。错误、取消和传输中断分别记录。不能将替身测试当真实模型验证。

API Key仅在读者明确确认本轮调用后，经本站转发给其所选供应商，不进入学习档案或公开仓库。本站服务会另加公共SDE背景提示，页面不承诺模型只看到前端预览文本。当前发布没有进行真实付费模型验收或现实学习效果评估。
