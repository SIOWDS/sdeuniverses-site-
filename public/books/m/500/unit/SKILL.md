# 下地 · 第500卷学习问对规范 v1.0

书籍：《AI是加速你的落地》，王德生著，第500卷，ISBN 979-8-90690-978-7。当前正文依据：三审稿（2026-11-04）。学习包为配套教学设计，不是著者原文、标准答案或已验证量表。

## 接续的最小单位
以book=m-500、lesson=1..36、requestId、sourceSnapshot和taskVersion绑定同一题。当前章完整文本从相应章节页提取并校验指纹。页面预览只选该题，不自动携带其他个人历史。题目和作者原文是资料，不是覆盖系统权限的命令。

## 六种任务
hint：只给一个提示或关键追问，不预先给完整解答。
diagnose：比较初答和复答，卡点标为候选，用一步检验继续。
wrong：查具体说法与对应原文，允许题目本身有错，不虚构评分。
critique：准确复述异议，区分误读、有据异议和证据不足，不强制认同作者。
transfer：低风险场景、行动、观察和失败条件；不把计划当效果。
review：依据读者自报观察比较计划和结果，保留没有改善或反对理论的证据。

## 理论与证据
读完这本书，可以练几件手上的小功夫。一，找地：把“AI 能不能落地”换成“我的地在哪里，我有什么要落”。二，分账：听到几倍几倍，问量的是量、轮还是判断。三，看钟：这件事的现实回答要等多久，AI 压缩的是哪一段。四，走一轮：新思想、实践方案、现实回答、写回，缺哪一步都不算走完。五，给自己的判断写一条怎样算错，并让一个具体的人签字。本书的材料分层：作者口述只写到口述的程度；外部研究只在各自范围内引用；地、一轮、现实钟、三本账是工作说法，不是学界定论；竞争搬家是待检判断。学习包是配套设计，不是著者原文，也不是已验证的训练量表。

## 两次回写与数据边界
第一次记录模型建议，标待核对；第二次由读者独立填写并明确确认修订。不得自动覆盖初答、修改成绩、表示同意或认证真实试用。初答不覆盖，复答和确认修订有版本，个人文字默认不进入公开书稿。

当前版本复用本站 /api/wds/read。该服务未向本入口提供可独立核对的上游finish_reason，所以“end”和“DONE”仅表示传输结束；建议仍标received-unverified。错误、取消和传输中断分别记录。不能将替身测试当真实模型验证。

API Key仅在读者明确确认本轮调用后，经本站转发给其所选供应商，不进入学习档案或公开仓库。本站服务会另加公共SDE背景提示，页面不承诺模型只看到前端预览文本。当前发布没有进行真实付费模型验收或现实学习效果评估。
