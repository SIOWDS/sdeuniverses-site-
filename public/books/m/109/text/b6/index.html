# 第六部　边界

全书最后一章，做的是减法。

前十一章都在论证这套东西成立。第十四章说清楚它对谁不适用——六类，每一类配一个自检问题和一条出路。

为什么这一章必须存在，第十节写了理由：

一个不说明自己对谁不适用的方法，是无法被判断的。 因为它对任何失败都有一个解释——你没做对、你不够坚持、你还没到时候。

所以这一章的真实功能不是给读者省时间，是给前十一章装上一个可以判负的接口。

它还做了两件本书别处没做的事：

· 逐章列出它撤销了前十一章的哪些部分（那张表在第十一之二节）；

· 把刀转向本书自己——按第一章那七件核一遍，这十二章目前是一批"半条"：有主张、有条件、有作废条件，缺的是来源事件与失败记录，也就是缺实践。

而按第九章的判据，一个高度互相牵连、却几乎没被外部攻击过的结构，正是最该被送去挨打的那一种。

这本书自己就是这样一个结构。
