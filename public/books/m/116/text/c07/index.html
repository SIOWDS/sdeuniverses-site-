第七章　大众化的是享受，不是杰作

理念艺术的诞生与实践 · 三界的最后一门艺术，与理念世界发生器 · 王德生 著 · 德麦国际专著第 116 号

一　卡拉 OK 的账

一九七一年，神户一个给酒吧伴奏的乐手做了一台机器：投币，放伴奏带，客人自己唱。他没有申请专利。此后五十年，这台机器长成了一个产业，从酒吧的角落长到了每一座城市的包房。

这个产业有一笔账值得算清楚。它卖的是什么？不是歌——歌是别人写的、别人唱红的，包房里唱的每一首都不是原创，而且绝大多数唱得走调。它也不是卖歌唱家——五十年里卡拉 OK 没有多造出一个歌唱家，倒是让歌唱家的门槛显得更高了。它卖的是一种人：晚上会去唱歌的人。一个人进包房之前是一个白天上班的人，唱完两个小时出来，歌没了，那个人还在，而且和进门时不一样——他唱过了。产业的钱不在歌里，在包房里：包房卖的是那两个小时，和那两个小时在一个人身上留下的东西。

理念艺术的大众化，形状和这笔账一模一样。它不会多造出一个哈代，也不会让卡斯塔利亚的游戏大师失业；它造出的是一种人：塑过一个概念的人。奶奶那道菜进不了菜谱史，但奶奶从此是一个会拿别人家的做法和自己的手艺撞一撞的人——这是她身上新长出来的东西，是主体性，第八章讲它长在哪里。

二　健身房

第二笔账是健身房。

健身房也不生产奥运冠军。跑步机上的人绝大多数跑得不快，姿势不标准，练一年也进不了任何一场比赛。健身房卖的是把一个人变成"跑步的人"：他从此是一个早上六点会出门的人，一个饭桌上会看一眼热量的人，一个知道自己膝盖什么时候会疼的人。健身房收的是他回来的那间屋子和那个教练，不是他练出来的肌肉——肌肉是他的，屋子是健身房的。

这两笔账合起来，大众化的准确形状就出来了：大众化的是享受，不是杰作。享受不是消费——消费是花掉一样东西，享受是做了一件事之后自己不一样了。卡拉 OK 和健身房都不承诺作品，它们承诺的是那个人；它们的产业规模不由作品的水平决定，由多少人被留下了一样东西决定。

三　享受是什么：传导的体温

"享受"这个词要说准，不然它会被读成娱乐。

享受是传导的体温。第十二章讲传导时会说，一件作品从理念界扛到自我界和现实界，靠两个动作：想做，做了。这两个动作是有温度的——想做那一下的高兴，做成那一下的高兴。享受就是这两下，不多不少。奶奶星期天下午把那道菜端上桌那一下，孙子问"还有那个吗"那一下，就是她的享受；它不是看菜谱的时候来的，是做的时候来的。

所以享受和作品的高低无关，和传导有关。一个人把一个平平的概念做出来、认领了、因此改了一个做法，他享受到了；一个人让模型撞出一个极深的概念、读完点头、从此没想起过，他没有享受到，他消费了。围墙里的思想家享受的正是前一种，哈代说别人享受不到的那种；本书说，现在人人可以——可以的是传导，不是杰作。

四　杰作会不会因此更少

一个常见的担心：人人做理念艺术，杰作会不会被淹没，水平会不会整体下降。

先说事实：卡拉 OK 普及五十年，歌唱家没有减少；相机进了每一部手机，摄影大师也没有减少——恰恰相反，两门艺术的底座都比从前宽了几个数量级，尖也就更高。杰作从来是从一个宽底座上长出来的，围墙的作用是把底座切窄，切窄的结果不是尖更高，是尖更少。

再说本书的立场：杰作不是本书的目标，也不是大众化的目标。大众化的目标是让主体性的发生总量高出几个数量级——一亿人各塑一个平平的概念，比一百个人各塑一个深的概念，发生的主体性多得多。围墙里的人会说前者的作品平均水平低，这是对的，也是无关的：包房里的歌平均水平也低，包房照样是包房。杰作会从这个底座上长出来，长出来最好，不长也不是本书的失败。

五　风口在人身上，不在作品上

于是"理念艺术是风口"这句话有了它准确的版本。

风口不在理念艺术品上。一件理念艺术品的物形态是一段文字，复制成本为零，它作为物品一文不值——第九章证明这一点。风口在理念艺术这件事在大众身上发生的主体性上：多少人塑过一个概念，多少人因此改了一个做法，多少人回来做第二件。卡拉 OK 的钱不在歌里，在包房里；理念艺术的钱不在概念里，在塑概念的那个人身上。

这一条对产业的后果是直接的：凡是想靠卖理念艺术品本身赚钱的——卖生成的文本、卖概念、卖论文——都在和它的成本结构作对，越做水价越低；顺着它成本结构的生意只有一种，第六卷叫它包房经济：为发生收费，按人计，不承诺结果。

六　享受的灭火器：刷

大众化的享受有它自己的灭火器，形状和"享受"长得几乎一样，叫刷。

刷是无传导的享受：看一段就换一段，每一段都有点意思，每一段都不留下东西。短视频是它今天的样子，理念艺术大众化之后它会长出自己的样子——刷概念：让模型撞一个，看完点头，再撞一个，再点头，一晚上撞了三十个，一个都没有认领，一个做法都没有改。刷和享受的分别只有一样：有没有传导。刷不留下人的变化，享受留下。

这一条比签收更危险，因为签收是一件一件的，刷是一片一片的。一个理念艺术的产品若把用户留在刷里——不断供新概念、从不逼人认领——它就是一台灭火器，而且是最舒服的那种：用户觉得自己整晚都在思考，其实一个念头都没有出过屏幕。分辨的办法是看它的账本记什么：记观看数的，是刷的账；记认领和改做法的，才是享受的账。

七　乐器普及的三段

大众化不是一次到位的，它有三段，前两门艺术的普及史已经走过一遍，理念艺术会照着走。

第一段是工具进门：缝纫机进家，钢琴进客厅，相机进口袋。这一段只是工具可得，还没有发生什么——很多家庭的钢琴一年不响一次。

第二段是形态出现：有了钢琴才有家庭合奏，有了相机才有摄影俱乐部，有了卡拉 OK 机才有包房。工具进门之后要有一种形态，让人在里面用它——形态是工具的用法在社会里长出来的样子。理念艺术的形态本书第三卷讲：造型的、表演的、乐器的，其中表演支——思想剧场——就是理念艺术的包房。

第三段是享受成为常态：唱歌不再是歌手的事，拍照不再是摄影师的事，晚上去包房、周末去健身房成了普通人的一天的一部分。这一段到了，大众化才算完成：它不是很多人会了，是很多人的生活里多了一件事。

理念艺术现在在第一段：工具进门了，大模型在每一部手机里。第二段刚开始：思想剧场、短剧、群碰这些形态正在长。第三段还没有：塑一个概念还不是普通人一天里的一件事。本书的实践各卷，写的就是怎么从第一段走到第三段。

八　给产业的一条判据

本章最后给产业一条判据，第六卷会把它展开。

看一个理念艺术的产品，别看它出的东西多好，看它的账本记什么。记生成了多少件、被看了多少次的，是板材厂加刷；记多少人认领了、改了做法、回来了的，是包房。前者的价值随生成成本一起归零，后者的价值随人的发生一起长。卡拉 OK 产业五十年没有一天靠卖歌活着，它靠包房活着；理念艺术的产业也不会有一天靠卖概念活着。

卖包房，不卖歌。这一条判据在本书后面每一卷都会回来。

九　第三笔账：家庭相机

卡拉 OK 和健身房之外还有一笔账，离理念艺术更近：家庭相机。

一八八八年柯达的盒子进了家门之后，照片没有变得更好——相反，人类照片的平均水平从那一年起一路下降，因为绝大多数照片是普通人在自家院子里、生日蛋糕前、火车站台上拍的，构图不对，曝光不准。可是摄影产业从那一年起长大了一千倍。它卖的是什么？不是杰作，是相册：一个家从此有了一本自己的相册，有了"我们家的样子"。柯达的广告从来不说"拍出杰作"，它说：留住这一刻。

家庭相机造出的那种人，是"有相册的家"。这种人和"塑过一个概念的人"是同一种人：他们做的东西进不了美术馆，但他们因为做过而不一样了——一个家有了相册和没有相册，看自己的方式不同。

三笔账合在一起，形状全一样：产业卖的都不是作品的高低，是作品在人身上留下的那样东西；产业的规模都和杰作无关，和多少人被留下了东西有关。

十　享受的三个记号

享受不是一种感觉，它有三个可查的记号，和传导的记号是同一套。

想做。看到一样东西，手痒。不是"觉得有意思"，是"我要试一下"。这是认领的前身：一件作品在你想做它的那一刻，已经有一半是你的了。

做了。真做了一次，哪怕做坏了。做坏的菜也是做了，它进了锅、进了手、进了那个晚上。这是改做法：你的一天里多了一个从前没有的动作。

回来了。过几天自己又想做，不是被叫回来的。这是回访：作品对你有拉力。

三个记号一个都不需要作品好。它们查的是人，不是作品，这正是享受和杰作的分别：杰作要看作品，享受只看人。第七卷的读数——τ、α——量的就是这三个记号在人群里的比例。

十一　杰作从哪里来

第四节说杰作从宽底座上长出来，这里给一点历史，因为围墙里的人会说这是空话。

十九世纪是业余科学家的黄金时代。法拉第是装订工的学徒，靠听公开讲座进了实验室；孟德尔是修道院里的修士，在菜园里种豌豆；达尔文没有在任何大学任教，他是一个住在乡下、有钱有闲的绅士，养鸽子、看藤壶。那个世纪科学的底座宽——公开讲座、博物学会、通信网络让围墙外的人第一次能拿到材料——尖也就高。二十世纪科学专业化，围墙重新砌高，底座收窄，杰作没有变多，变的是每一件杰作要更多的人、更多的钱。

宽底座不保证杰作，但窄底座保证杰作少。大众化把底座放宽，杰作会不会从上面长出来本书不预言；本书只说，围墙的担心方向反了——该担心的是底座窄，不是底座宽。

十二　第三段怎么量

第七节说大众化有三段，第三段是"很多人的生活里多了一件事"。这一段可以量，量法叫日常化率：一段时间里，把塑一个概念、打一集、下一次场当作自己一周里的一件事的人，占用过发生器的人的比例。

它和产品数、用户数、生成件数都不同：一个人一年用发生器一次，做了一件很好的作品，他在日常化率里读零——那一件是一次事件，不是他生活里的一件事；一个人每周三晚上都来打一集，做的都平平，他读一。日常化率量的是包房有没有成为"晚上去的地方"，是大众化到没到第三段的唯一读数。卡拉 OK 的日常化率五十年前是零，今天在很多城市接近一半；理念艺术的日常化率今天是零，本书的实践各卷写的就是怎么让它不是零。

承重句　理念艺术大众化的产品不是杰作，是人：量产的是"塑过一个概念的人"，风口在做作品的人身上，不在作品上；享受是传导的体温，与作品的高低无关，与有没有出界有关。

分离线　相对"创造力民主化"一派（把大众化理解为让更多人做出更好的作品）：他们量作品，本书量人；分离处在"享受不是杰作"——他们要的是底座上长出更多的尖，本书要的是底座本身。可反驳处：若大众化后作品水平的下降伴随着主体性发生总量的下降（塑过概念的人并没有多），本书的"底座"论作废，他们的担心成立。

作废条件　若一批以刷为形态（不断供新概念、不逼认领）的产品，其用户的传导率与包房形态（逼认领、查改做法）的产品无差别，则"刷是灭火器"作废，本章第六节撤回，享受与刷的分别退回口味之分。

留下的一件东西　一个区分：享受与消费——做了一件事之后自己不一样了，是享受；花掉一样东西自己没变，是消费。看一晚上的账，哪一种多。
