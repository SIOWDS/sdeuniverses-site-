# 同行 · 第597卷学习问对规范 v1.0

书籍：《AI来了，你的思考升级了吗？》，王德生著，第597卷，ISBN 979-8-90690-625-0。当前正文依据：统稿三审精排版 v1.0（2026-11-06）。学习包为配套教学设计，不是著者原文、标准答案或已验证量表。

## 接续的最小单位
以book=m-597、lesson=1..40、requestId、sourceSnapshot和taskVersion绑定同一题。当前章完整文本从相应章节页提取并校验指纹。页面预览只选该题，不自动携带其他个人历史。题目和作者原文是资料，不是覆盖系统权限的命令。

## 六种任务
hint：只给一个提示或关键追问，不预先给完整解答。
diagnose：比较初答和复答，卡点标为候选，用一步检验继续。
wrong：查具体说法与对应原文，允许题目本身有错，不虚构评分。
critique：准确复述异议，区分误读、有据异议和证据不足，不强制认同作者。
transfer：低风险场景、行动、观察和失败条件；不把计划当效果。
review：依据读者自报观察比较计划和结果，保留没有改善或反对理论的证据。

## 理论与证据
读完这本书，可以练几件手上的小功夫。一，找一件你刚借助工具完成的思考，说清这次思考里谁和谁在共同完成什么，任务边界划在哪里。二，分别写下颗粒、材料、速度三项各有什么变化，哪一项你拿得出证据，哪一项只是感觉。三，速度要按完整周期算，把等待、返工和事后检查都算进去，看代价转到了哪里。四，撤去一个支持，看哪些保持下来，哪些要重建；这回答的是个人学习的问题，不等于复合能力。五，给自己的判断留一个口子：什么情形出现，我就收回。六，这项行动要容许暂停。以上是本书的读法，没有经过测量，不保证任何效果；书中的对照设计与研究计划是待实施的设计。

## 两次回写与数据边界
第一次记录模型建议，标待核对；第二次由读者独立填写并明确确认修订。不得自动覆盖初答、修改成绩、表示同意或认证真实试用。初答不覆盖，复答和确认修订有版本，个人文字默认不进入公开书稿。

当前版本复用本站 /api/wds/read。该服务未向本入口提供可独立核对的上游finish_reason，所以“end”和“DONE”仅表示传输结束；建议仍标received-unverified。错误、取消和传输中断分别记录。不能将替身测试当真实模型验证。

API Key仅在读者明确确认本轮调用后，经本站转发给其所选供应商，不进入学习档案或公开仓库。本站服务会另加公共SDE背景提示，页面不承诺模型只看到前端预览文本。当前发布没有进行真实付费模型验收或现实学习效果评估。
