空白不是零

乳腺癌里九个没有被登记的位置

母 题 · CORE THESIS

一位女性的影像读数连续三次稳定，报告写着「较前无明显变化」，随访周期因此拉长。可是没有人问过：这个读数当初绑定的那个靶点，最近一次确认是什么时候？如果绑定早已不成立，读数仍会稳定输出——它稳定，是因为它已经不指向任何东西。

一位工作者上了三年夜班。她用周末补觉、推掉家庭活动、削减了锻炼，把负荷补上了，工作产出一直照常。排班表上于是写着：这个人能承受。可是「她补了多少」这一栏，排班系统里根本没有位置。中心判断因此是：在乳腺癌里，「没有记录」一路被读成「没有发生」；这个空白反过来签发了下一轮的判断、干预与暴露，而代价落在没有记账权的那一边。

三段结构：缺一段就不是本书讨论的现象

中心判断有三段，三段必须同时成立。① 位置缺席——一个在结局未知时就能依预先规则识别的事项，没有被登记；② 空白被读成实质——「没有看见」被改写成「没有发生」；③ 空白反过来签发——这个空白成为下一步判断、干预或暴露的输入。

只有①，是缺失数据——已有成熟方法处理，本书不与之竞争。①加②，是认知偏差——诊断推理里叫过早闭合，也有大量文献。三段俱全，才是本书的对象：那个空白不再只是被误读，它取得了它本来不该有的权力——它进入了决策链，签发了本轮之后的判断。缺席从一个待补的洞，变成了一个正在工作的行动者。

这条要求同时是本书的准入规则：三闸有一闸不过，该案例记为不可判，不得折算为零。这条纪律与全书主题同构——把不可判算成零，正是本书要查的那件事。

四种零必须分开

观测零位置存在、测量执行、结果为零。这是信息，而且是好信息。
缺测零位置存在、规则要求登记，这一次没记。缺失数据方法的对象，可插补、可加权。
失位零连登记位置都不存在，因而任何缺失率统计都发现不了——数据集看上去是完整的。本书的主要对象。
合并零形式上有值，实质上两类事项被同一字段收编、被平均、被折算进一条单调轴，差别在数据中不再存在。本书的第二类对象。

由此得到一条对本书自己不利的检验要求：任何一次「发现空白」的报告，都必须先排除前两种。若某章标记的空白多数属于缺测零，该章应并入缺失数据处理，而不是继续声称发现了新对象。

九个位置

编次不按原稿的「是什么／怎样／为何」排，而按中心判断的三个环节排——这是本书比九篇论文多出来的第一样东西。

第一编
取得事实资格		一 异层改判对象：跨层候选与病灶的连接没有登记位置 → 没有这层关系 → 终值表冒充完整对象。
二 靶定闭合：靶点绑定是否仍成立没有登记 → 读数稳定即靶稳定 → 取得诊断事实资格。
三 基线无继：解释规则的到期与继任没有登记 → 器官连续可照旧 → 签发不可逆决定。
共同靶格：一份看上去完整的记录，其完整性本身就是那个空白造成的。
第二编
关掉退路		四 路径早闭：被关闭分支的历史—行动格消失 → 两条路没差别 → 合并两类本不该合并的人。
五 返轨灭失：三张分账未挂在同一路线身份上 → 分账都还有路 → 加大干预强度。
六 能力抵押式复行：这次恢复由谁付款没有记 → 行为回来＝预防成功 → 继续按同一标准要求。
共同靶格：关闭发生在任何结局信息到达之前，因而此后无论收集多少数据，那一支都不会出现。
第三编
签发下一轮		七 补偿转许可：负荷与补偿未进入排班决定 → 工作照常＝身体耐受 → 签发下一轮夜班。
八 异锚生育效应：断乳钟的相位未登记 → 生育没有独立作用 → 统一按分娩时距分析。
九 未承接因果单：因果承接授权未被承接 → 风险清单解释了你 → 责任与自责落回个人。
共同靶格：签发者与代价承担者不是同一方。

九处真跑，九次都输

这是本书唯一真正硬的部分，也是最容易被跳过的部分。九章各执行一次公开数据的真跑或结构审计，九处全部产出对作者原主张不利的结果，并全部原样写进正文。

第一章TCGA／METABRIC／SEER 结构审计 → SEER 的患者拒绝手术编码推翻作者「公共库没有关系边」的强命题；作者另声明预注册针对旧模型，不为新模型冒领时间优先权
第二章CBIS-DDSM（四表 SHA-256，1993 病灶）→ 条件熵仍留 64.82%，主读数根本算不出来；增补的置换检验自标为非盲
第三章cBioPortal → 预注册的数据地址返回 403，严格可重建率 0%；事后扫描发现某字段覆盖 78.92%，反过来推翻自己「公共数据不记录生命阶段」的说法
第四章GSE145850 → 主判据与宽松判据在四个时点全部阴性，换主成分数复算仍阴性；作者拒绝把一处 |Δ|=0.0027 的差别拿来当阳性
第五章类器官八 CSV → 预设的相关性闸没过（ρ=−0.812）；主结果六条路线可评价数 0/6
第六章HeartSteps V1（冻结 commit）→ 149 个恢复事件全部落进同一格，无假设边界 0≤θ≤1完全无信息
第七章NHANES 三周期 8861 人 → 第二条判据置信下界 −9.11，只是窄幅未被推翻；作者拒绝用 P=0.348 宣称相等
第八章GSE285005／GSE12247 → 作者用识别性论证自证强制断乳使两钟在原理上不可分，据此废掉自己的数据，并声明这是识别问题不是样本量问题
第九章BCRAT 移植 → 因自设 1e-10 误差阈主动停机，查出官方源码与文档相差 2.206888 个百分点；随后撤回「风险模型制造患者自责」这句最好卖的话——理由是倒算下游误用给源模型，正是本书批评的越权归因

九比零这个比例不是谦虚。它是一个信号：这本书离能被检验还差一步，而这一步不是再写一章能补上的。

装书时补的那一样东西

九篇原稿的敌意拓宽做得很足，但方向错了——做在认识论与方法论的邻域（诊断认识论、疾病本体论、数据溯源三片覆盖得极好），没做在肿瘤学本身的邻域。乳腺癌本行的正主几乎全部缺席。

装书时逐章补入了这些占位者，每一处写法相同：先承认对方已经占住了什么，再给一对判决性反例，最后写一条撤名条件。原有的判断一字未动——补的是「它不能占用哪块地」，不是「它还能多说什么」。

第一章肿瘤内异质性 · 多区域取样 —— 分离线：同层空间分辨率不足 vs 跨层证据有无登记位置
第二章过度诊断 · 惰性病变 —— 分离线：真病变、假威胁 vs 稳定读数、无靶；另自设一条比外部批评更严的自查
第三章正常组织体细胞突变 · 小叶退化 —— 分离线：组织基线生物学真的变了 vs 解释规则的继任没有安装
第四章克隆演化 · 平行演化 · 适应性治疗 —— 分离线：已走过并留下证据的路径 vs 从未被执行、因而永不产生比较证据的那一条
第五章动态网络标志物 · 吸引子景观 —— 分离线：单账本的动力学读数 vs 三张分账交集为空
第六章复发预防 · 阶段模型 —— 分离线：因变量是目标行为本身 vs 这次回来由谁付款
第七章光照假说 · 夜班队列证据 —— 分离线：剂量与机制 vs 下一轮暴露凭什么被签发；并自设硬边界「剂量—结局证据的不一致不是本章的论据」
第八章产后乳腺退化 · 首次活产年龄 · 组织年龄模型 —— 最要紧的一条：组织年龄模型本身就是多事件模型，但它把多事件折算进一条单调轴；本章的判决性对照是折算重算后四项判决是否有一项改变
第九章随机复制错误 —— 它表面上支持本章，正因如此才必须划清：随机性说「原理上不可确定」，本章说「某个位置的授权没跟着后果走，可记录、可定位、可修复」

第十章不为九章辩护

第十章把九章并排，做了七件事：读出九次失败长得一样（三栏表九行零例外）；把三段结构写成准入规则；区分四种零；说明每章三门学科分别负责三段中的哪一段（并给出可检验的消融方法）；写死一条会把九章压成一章的规则；给出五条整体撤销条件；最后查出本书自己的两处失载。

压缩规则：在同一批病例上取到九个读数之后，若它们两两相关普遍高于 0.8，或第一主成分解释方差高于 70%，九章应合并为一章「失位零的签发」，四编结构不予保留。作者预期最可能先聚成一簇的是第一、二、三章，其次是第六、七章——若聚类出现在未预期的位置，作者必须公开说明预期为何落空，不得事后重述。

五条撤销条件中最要紧的是第五条：把缺失的登记补上之后，若下游判断没有任何改变，那么本书指出的空白就不重要——这条如果不成立，前面四条成立也没有意义。

本书自己的两处失载

一本讲「没有被登记的位置」的书，必须先查自己。第十章第七节写下两处，作者目前都没有解决方案。

第一处：九章的分母都要求「已经有记录」。九个读数无一例外都在已经进入医疗系统的人身上取值——有过就诊、有过筛查、有过随访。从未进入系统的人，不出现在任何一章的任何一个分母里。这意味着本书批评的那件事，本书自己正在做。因此本书声明：全部结论只在「已被登记的人群」内成立，不得外推。

第二处：签发者弥散时本书失效。三段结构要求第三段有一个可定位的签发者。当签发者是弥散的——一整套无人负责的默认做法、一条从未被写下来的科室惯例——本书取不到值，只能记为不可判。而恰恰是这一类签发最难被修复。本书的方法在最需要它的地方最没有力气。

怎么读这本书

临床与研究人员
约五万字		导论 → 第十章 → 附录一（九个位置速查）→ 附录三（学科入口与消融检查）→ 与自己题域最近的二三章。第十章是全书唯一一处把九章合起来看的地方，也是判断这本书值不值得检验的最短路径。
关心决策与责任
约三万字		前言 → 第六章（恢复由谁付款）→ 第七章（补偿被读成能力）→ 第九章（承接授权落回个人）→ 第十章第七节。这四处与「代价落在谁身上」关系最直接。
审稿人与批评者
约两万字		写作与证据声明 → 各章的「补节·本章不能占用的地」→ 第十章第五、六节 → 附录二（四种零对照）。本书在这几处集中承认了自己的边界与最可能被合并的地方。

九章结构统一。时间有限时每章只读三处：章首提要（这一章要分开的是哪两种「表面同样合理」的判断）、真跑那一节（本书的诚实程度全在这里）、补节·本章不能占用的地（与本行最近的占位者之间的分离线与撤名条件）。

使用禁令与写作声明

本书没有任何一章拥有可用于临床的验证数据。本书全部读数均未经信效度验证，且九个读数中没有一个曾在真实病例上被完整取到过。本书明确反对在第十章第五、六节所述条件被检验之前，把其中任何一个读数用于临床分诊、治疗决策、职业健康评定、保险核保或患者责任判定。

九章的问题设定与三门学科的选择约束由著者给定；文献线索检索、数据审计脚本、初稿组织由语言模型协助执行；全部概念判断、引文核对与最终主张由著者负责。凡本书未能直接核验原文的，一律写明「在本书检索到的范围内未见」。

⚠ 关于文献：九章中只有第八、九两章附有独立的编号文献表，其余七章采用正文内叙述式引证，因而本书参考文献页所列的 122 条不能代表全书的引用总量——这是原稿体例不统一留下的缺口，装书时未能补全，据实说明。其中标 [装] 的十八条是装书时为处理九处缺席的本行占位者而补入的。
