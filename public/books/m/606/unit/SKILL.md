# 接谱 · 第606卷学习问对规范 v1.0

书籍：《AI时代新教育的三大典范》，王德生著，第606卷，ISBN 979-8-90690-638-0。当前正文依据：统稿合成稿（2026-11-07）。学习包为配套教学设计，不是著者原文、标准答案或已验证量表。

## 接续的最小单位
以book=m-606、lesson=1..30、requestId、sourceSnapshot和taskVersion绑定同一题。当前章完整文本从相应章节页提取并校验指纹。页面预览只选该题，不自动携带其他个人历史。题目和作者原文是资料，不是覆盖系统权限的命令。

## 六种任务
hint：只给一个提示或关键追问，不预先给完整解答。
diagnose：比较初答和复答，卡点标为候选，用一步检验继续。
wrong：查具体说法与对应原文，允许题目本身有错，不虚构评分。
critique：准确复述异议，区分误读、有据异议和证据不足，不强制认同作者。
transfer：低风险场景、行动、观察和失败条件；不把计划当效果。
review：依据读者自报观察比较计划和结果，保留没有改善或反对理论的证据。

## 理论与证据
读完这本书，可以练几件手上的功夫，练的是“分清水电与谱系、认出自己代表哪条谱系、把课例走完九步、立好安全与隐私边界”，是练习，不是替谁评价谁，也不是给谁打分。一，分清哪些是统一性知识，哪些是同一性谱系知识（第1、2章）。二，认出我代表哪条谱系，看哪些特征成了团（第5、6章）。三，在对不上的地方碰撞，让此前没有的东西长出来（第7章）。四，把课例走完前行、回写、跃层九步，每步写清老师做什么、学生做什么、留下什么（第12至26章）。五，课前先立安全与隐私的硬规则，涉及火、热水、工具、身体、家里病人，由大人把关，不交给智能体判断（附录B）。六，把留下的东西收进“我的平台”，并分清名次与成绩是一本账、谱系是另一本账（第27至29章）。以上是练习，智能体与学习包只陪练，不替人判定，不打分，不诊断，不给医疗、法律或投资建议，不构成任何学术评审意见；九格判断是作者的判断，不是定论。

## 两次回写与数据边界
第一次记录模型建议，标待核对；第二次由读者独立填写并明确确认修订。不得自动覆盖初答、修改成绩、表示同意或认证真实试用。初答不覆盖，复答和确认修订有版本，个人文字默认不进入公开书稿。

当前版本复用本站 /api/wds/read。该服务未向本入口提供可独立核对的上游finish_reason，所以“end”和“DONE”仅表示传输结束；建议仍标received-unverified。错误、取消和传输中断分别记录。不能将替身测试当真实模型验证。

API Key仅在读者明确确认本轮调用后，经本站转发给其所选供应商，不进入学习档案或公开仓库。本站服务会另加公共SDE背景提示，页面不承诺模型只看到前端预览文本。当前发布没有进行真实付费模型验收或现实学习效果评估。
