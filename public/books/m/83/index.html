九个在记录与记录之间掉下去的位置

书名里的「幽」不是玄。它有确切所指：那些既不被任何一份记录判为错误、也不被任何一份记录判为缺失的位置。它只在把几本账按同一条时间轴重排之后，才作为一个空位露出来。
母 题 · CORE THESIS

这本书要问的九个问题，都不是"子宫癌是什么病"。它们是：病名成立之后还剩下什么；两个病人共有一个病名，这个"相同"能带到哪儿为止；一个人"患有子宫癌"是不是只指病灶；它如何从周期性的更新变成恶性的持续；为什么已经发出的信号没有把病灶纠正过来；为什么预防写成提醒之后仍然完不成；同样的风险为何只有一部分人发病；危险为何有时没能及时转化为诊断行动；以及——得了这个病，能不能归结为一个人没管好自己。

九章各用三门与医学无关的学问互相撞出一个余数。而九个余数长得几乎一样：几本记录各自完整，一个本该有持有者的东西在记录之间掉了下去。本书没有把这一点藏起来，而是把它提为承重主张——总论为它规定单位、形态、合并规则与整体失败的条件。

单位：持格

全书九章共用一个最小单位，称为持格：⟨谁 · 在哪一格 · 持有多久⟩，其中"格"由五个字段定位——⟨对象，问题，时间，范围，后果⟩。

三个"必须"：必须是同一个五字段元组被各账同时指向，不是各自都有一个自己的元组；必须包含范围，否则无法判越界；必须包含后果，否则那只是知识缺口，不是本书的对象。准入条件因此写得很硬：一个空位只有在"后果已经运行"时才进入本书——尚未生成任何输出的不确定性、未完成的检查、未回答的科学问题，都是研究议程，不是制度事实。

初稿曾把这个单位称作"见证格"。成书前的一次机检显示，"见证／担保"这组语汇只在第一章密集出现（每万汉字 60 次），其余五章逐字为零；而"格／位"九章全覆盖。用一章的私有语汇统辖全书是不诚实的，故改称持格，"见证"退回第一章作局部术语。这次更名与它的证据一并印在书里（总论第三节、附录 A）。

三态，与九章的位置

给定一个持格与它已经运行的输出，持有关系的失配只有三种形态，本书主张三态互斥且穷尽：

形态是什么特征
0 持（无声删除）该格应有持有者而没有：上一个已退出，下一个未取得资格，而前者造成的状态差仍在约束后续账上根本不生成事件——不是记了一笔错账，是这一笔从未被要求记
错持（越权继承）有持有者，但其证明力来自另一个格：另一个对象、问题、时段或范围每一栏都能找到依据，而没有一个元组同时为该输出作证
双持（合法并持）同一格被两个持有者同时、各自合法地持有，且两者判定可以相反不是病理。它证明本框架并非只能生产"缺失"

九章由此长成一棵每一级都有分枝规则的树，而分枝依据全部取自单位本身——一级取持有者的计数与来源，二级取持格的三个槽加持有资格，三级取"本应持有它的是谁"：

支 / 维章新对象本维读数三学科

两处结构事实：H2 是全书唯一写出两态之间因果的一章——一次越权继承如何产生一次无声删除（旧回执被继承之后，新事件所要求的待证对象根本不再被生成）；Y3 是唯一两态同时发生的一章——可执行控制向上游移位（0 持），而控制资格仍登记在患者名下（错持），两件事必须同时成立，它的对象才存在。

关联系统：九章之间二十一条可检验的关系

一部由九篇论文合成的书，最容易犯的错误是：九章各自完整，合起来只是一个文件夹。本书为此单写一章（结章《持格网络》），规定两章之间可能存在的关系只有五种，每一种自带"什么情况下这条关系不成立"：

关系成立要求不成立的判据
①前置 →甲先发生，乙才可能发生，且存在甲发生而乙不发生的情形乙在甲发生与未发生两层的发生率相同，则删掉这条边
②同格异命 ⇔两章处理同一个持格，只是结局不同主键无法对齐，则不是同格，只是同题
③兄弟需分 ∥同支同维、有被误合并的真实风险，必须给出可观察的分界判据给不出判据，或只能靠作者意图区分，则两章应当合并
④换层 ↕层级差能被指认为某个具体量的改变（单位、主键或授权来源）两层用同一套读数即可描述，则没有换层，只有重复
⑤共主键 ≡可在同一份日志、用同一个主键一次清点清点甲必须额外采集乙不需要的字段，则不共主键

三十六对逐对判定，判出二十一条边（前置 7 / 需分 4 / 换层 5 / 共主键 5），其余十九对判"无关系"并写在表里——如果每一对都被说成有关系，那张表就不含信息。"互相呼应""形成对话""共同揭示"这类说法本书明确拒收，因为它们没有不成立的条件。

由前置边串成的主链是全书最想让人记住的一句话：

W2 → W1 → H2 → H3 → W3：一项关系被搬到不该去的问题上 → 输出失去共同担保 → 旧回执跨时段继承、待证对象不再生成 → 结案规则连失败分支一并删除 → 患者的下一个选项在判定完成前关闭。从"分类被搬错了问题"，一路走到"一个人失去一次选择"。

那一刀：删章检验，与本书自曝的薄弱环节

判断一个关联系统是真是假，最干净的办法是逐章删除，看网络损失什么。本书把这张表印在结章里：W1（五字段主键出自该章）、H2（唯一的形态转化路径）、Y3（三条换层边的换乘站）、H3 不可删；W2 与 H1 可降为附论。

而Y1 是唯一一章，在初版判定里删掉它网络仍然连通、七条链无一断裂、零前置边损失——它与其余各章的关系全是并列性的，前置边为零：既不是任何一章的成因，也没有任何一章是它的成因。

成书时按持格的槽位重分，浮现出一条降级序列：删「谁」→ 删「资格」→ 删「格」→ 删「多久」（一个格长期无人持有，就没有人为它生成记录；无记录则无法比较，于是退出可估空间）。据此新增一条前置边 Y1 → H1，Y1 才不再孤立。

但这条边的性质，书里在三处写明：它是从分类结构导出的推论，不是从数据得到的发现。因此结章的删章检验保留两行——按新边算 Y1 不宜删，按旧状态算 Y1 删掉不影响结构；下一版的首要任务即是去两个独立队列里检验它，不成立就把 Y1 降为附论。一个从不指认自己薄弱环节的关系图，只是一张装饰画。

怎么读这本书

按结构读（推荐）：总论 → W1（错持的原型，五字段在此定义）→ H2（错持如何转成 0 持）→ Y1、Y2（0 持的两种时间形态）→ W3、H1、H3（0 持的三种对象与后果形态）→ W2（唯一的问题字段越权）→ Y3（两态同时发生）→ 附论一 → 附录 A。

按主链读（约五章）：W2 → W1 → H2 → H3 → W3，五章连成一个从分类到一个人失去一次选择的完整通路。

给评阅者：不必逐章找漏洞。取主链最弱的一环（H2 → H3），或取三对兄弟章的任一条分界判据，若能证明它在真实数据上不成立，本书的相应部分即须改写。

给做研究的人：按结章"采集链"读。一张带持格主键的事件表 ＋ 一份纵向三账日志，可同时检验五章的对象——不必为九个概念建九套系统。

怎样最快地推翻这本书

一、合并。按结章的三条合并规则，证明任意两章其实是同一个对象的两次命名——本书自报最危险的一对是 Y1 与 Y2（同为 0 持、同落时间侧）。

二、第四态。在真实日志上找到既非 0 持、非错持、非双持、又已生成输出的失配形态——三态不穷尽，分类框架失败。

三、可还原（最便宜的一条）。若一份普通的数据库完整性约束（外键、时效约束、访问控制）无需任何领域判准即可自动识别全部九类事件，那么本书的三门学科结构是多余的，九章应降为一份数据治理规范。

四、无后果（最狠的一条）。若在带主键的日志上，0 持与错持格的发生与任何独立评分的结局（规则错误、预测损失、延迟、可避免伤害）均无关联，则本书识别的是记账形式而非医学事实。作者写明：若这一条在两个独立队列中均不成立，本书不再主张三态具有临床意义，只保留其作为记录规范的价值。

本书没有做到什么

九章都做了成文前锁定的公开数据检验。它们一致地否定了若干听起来天经地义的强命题——分类改变通常内含行动改变；跨尺度整体守恒；最早可见克隆永久持有发起权；生物可识别性自动同步行动时钟；有保险或有入口即可完成接力；提醒到达即可转化为行动；州级肥胖率垄断地理分布解释。

也一致地承认：现有公开资料没有选项级、格级、事件级的时间戳与授权字段，因此没有确证任何一例本书命名的事件。九个对象目前都停在"可定义、可清点、尚未观察到"的位置上。

把它们从可定义推到可观察，需要的不是更多论证，而是一次很小的数据结构改动——总论第七节写了它的最小形式。一本书如果只在概念上完成，它就还没有完成。这一本自认属于此列，因此它把自己写成一份可以输掉的纲领，而不是一套已经赢了的说法。

与作者另一部专著《空白不是零》的分界

作者另有一部同型专著——《空白不是零——乳腺癌里九个没有被登记的位置》（专著第 75 号）。两书相似到足以让任何读者提出同一个问题：这不就是把同一件事换一种癌症再写一遍吗？本书在结章第七节正面回答，此处摘其要。

先承认相似的部分：都以"九个位置"为骨架；都要求位置缺席必须产生下游后果才算数；都执行预注册的公开数据真跑并原样报告不利结果；都在书末做了一次"九章会不会其实是一章"的自我攻击。这四条不是巧合，是同一位作者的同一套工作方式。

分界只有一条，但它是硬的：前书查的是"记没记"，本书查的是"谁在持有"。前书的对象是登记位置在不在（四种零的分类）；本书的对象是持有关系的形态。空白在本书里只是三态中的一态（0 持）；另外两态是前书没有的——错持：格上有持有者、记录完整、每一栏都合规，只是他的证明力来自另一个格，记全了照样成立；双持：两个持有者同时合法在场，它不是缺陷，而且是前书全部九个位置的"之前"。此外前书九章的章际关系未被形式化，本书有二十一条边。

判决性分离：取一份记录完备、缺失率为零、按前书四种零逐项排查全部通过的数据集。前书的九个位置在其上应当全部取不到值；本书的错持格在同一份数据集上照常成立。若错持与双持在缺失率为零的数据集上也取不到值，则本书相对于第 75 号没有新增任何形态，应当并入前书作为其"子宫癌篇"。

还要说明一处不利于本书的事实：前书九章的真跑九处全部产出不利结果并原样写入，其中一处直接导致该书最好卖的一句话被撤回；本书九章的真跑同样一致地报告"不能确证一例"。两书在这一点上没有分别——这既是同一种诚实，也说明本书在"从可定义推到可观察"这件事上，比前书没有前进。这条分界是成书付印前扫出的：九篇原稿与成书稿此前零处提及前书。
