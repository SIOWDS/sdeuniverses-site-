结　章　持格网络

九章如何互相支撑

一、为什么这一章必须单写

一部由九篇论文合成的书，最容易犯的错误是：九章各自完整，合起来却只是一个文件夹。编者按能列出九个题目，目录能排出三大编，但读者读完仍会问一句——它们凭什么在一起？这个问题不能靠"都关于子宫癌"来回答。九章用了二十七门与医学无关的学问，若它们之间只有主题的共同，那么删掉其中任何一章，全书不会少任何东西；而一个删掉任一部分都不会有损失的整体，本来就不是整体。

所以本章的任务是把九章之间的关系写成一个可以检验的系统，而不是写一段"综上所述"。具体地说，本章要做四件事：

1. 规定关联的种类——两章之间可能存在的关系只有有限几种，每一种都有它自己的成立条件；

2. 对三十六对逐对判定——是哪一种关系，或者干脆没有关系；

3. 由此得到一张网络，并读出它的形状（谁是枢纽、谁最孤立、有没有断开的部分）；4. 给出这个关联系统自己的证伪——什么情况下说明本书的九章其实不该在一起。

并且：本章使用的单位是「持格」，不是总论初版所用的"见证格"。 机检显示，"见证／担保"这一组语汇实际上只在 W1 密集出现，其余各章零星或为零；用一章的私有语汇去统辖全书，是初版的一处失误。全书统一的单位应当是九章都在使用的那个：

持格 〈谁 · 在哪一格 · 持有多久〉，其中"格"由 〈对象，问题，时间，范围，后果〉 五字段定位。

W1 的"见证"自本版起退回 W1，作为该章处理"担保"这一特殊持有关系时的局部术语。

二、五种关联，及每一种的不成立条件

两章之间的关系，本书只承认以下五种。承认得越少越好——种类多了，任何两篇文章都能被说成"有关系"。

① 前置（甲 → 乙）：甲章的事件是乙章事件的发生条件之一。

成立要求：能写出一个时序——甲先发生，乙才可能发生；且存在甲发生而乙未发生的情形（否则两者是同一件事）。

不成立的判据：若在真实日志上，乙的发生率在甲发生与未发生两层中相同，则这条前置边应当删除。

② 同格异命（甲 ⇔ 乙）：两章处理同一个持格，只是这个格的结局不同。

成立要求：两章的对象共用同一个主键，能在一张表里互为对方的补集。

不成立的判据：若两者的主键无法对齐（一方以患者为单位、另一方以标本为单位），则不是同格，只是同题。

③ 兄弟需分（甲 ∥ 乙）：两章属同一支、落在同一字段上，有被合并的真实风险，必须靠一条判据分开。

成立要求：必须给出那条判据，并且它是可观察的。

不成立的判据：给不出判据，或判据只能靠作者的意图区分——那么两章应当合并，本书少一章。

④ 换层（甲 ↕ 乙）：同一个问题在不同层级上出现（个体与群体、本地与跨账、生物与制度）。

成立要求：层级差必须能被指认为某个具体量的改变（单位变了、主键变了、或授权来源变了）。

不成立的判据：若两层用同一套读数即可完整描述，则没有换层，只有重复。

⑤ 共主键（甲 ≡ 乙）：两章的事件可以在同一份日志、用同一个主键一次清点出来。成立要求：字段可以对齐，无需为其中一方另建表。

不成立的判据：若清点甲必须额外采集乙不需要的字段，则不共主键。

这五种之外的一切说法——"互相呼应""形成对话""共同揭示"——本书不采用，因为它们没有不成立的条件。

三条读数：

（一）W1 是枢纽，而且是结构性的枢纽。 它连出七条边，其中四条是共主键——因为全书的五字段主键就出自这一章。这解释了它篇幅最长（压缩前近其余各章两倍），也说明它不能被移到后面：读者不先读 W1，其余八章的"格"就没有坐标。

（二）网络是连通的。 任取两章，都能沿边走到；不存在与全书断开的孤岛。这是"九章确实是一本书"的第一个硬证据——而它不是靠主题相同得到的，是靠十七条具体关系连起来的。

（三）Y1 曾是全书最弱的一环，本版补了一条边，但那条边还没有数据。 初版判定时，Y1 只有三条边且前置边为零——它既不是任何一章的成因，也没有任何一章是它的成因，与其余各章的关系全是并列性的。本版按乙支的槽位重分（总论第五节）导出了一条降级序列，并据此新增前置边 Y1 → H1：空窗时长越长的格，越可能随后退出可估空间。

这条边使 Y1 的连边升到四条、前置边升到一条，网络因此不再有"只并列、不参与因果"的章。但必须写清楚它的性质：它是从分类结构导出的推论，不是从数据得到的发现。 若它被证伪（空窗时长与退出可估率无关联，或关联可由随访强度完全解释），Y1 立刻退回原状——本章第六节的删章检验因此保留了两行，一行按新边算，一行按旧状态算。

五、六条判决链

网络里的前置边串起来，得到七条可以按顺序读、也可以按顺序检验的链。每条链的意义在于：链上任何一环被证伪，其下游全部要改写。

链一 · 成因链（全书主链）

W2 → W1 → H2 → H3 → W3

一项关系被搬到不该去的问题上 → 输出失去共同担保 → 旧回执跨时段继承、待证对象不再生成 → 结案规则连失败分支一并删除 → 患者的下一个选项在判定完成前关闭。这条链把全书五章串成一个从"分类"到"一个人失去一次选择"的完整通路，是本书最想让读者记住的一句话。证伪点在最弱的一环 H2 → H3：若在回执被标注证明范围的机构里，失托行动位的发生率不变，链条即在此断开。

链二 · 时间链

Y2 → H3

年龄失去进入决策规则的资格 → 责任刚被激活后的近端交接失败。 H3 的公开数据（同日与十二个月的差距收窄六个百分点）正落在这一段，是全书唯一一条已有数据形状支持的前置边。

链三 · 责任链

W1 → Y3 → W3

担保已变而登记继续运行 → 控制资格错记在患者名下 → 与之对应的选项在她那里早已关闭。 这条链的价值在于它把一个伦理判断（不该归责于患者）改写成了两个可清点的事件。链四 · 兄弟链（不是前置，是分界）

Y1 ∥ Y2 · W3 ∥ H1 · W2 ∥ H2

三对最容易被误合并的兄弟，各由一条可观察判据分开：持有者 vs 资格、患者 vs 证据系统、跨问题 vs 跨时段。若其中任何一条判据在实测中不能把两类事件分开，对应的两章应当合并——这正是总论第六节合并规则的落地形式。

链五 · 层级链

Y1 ↕ Y3 · H1 ↕ Y3 · H3 ↕ Y3

三条换层边全部通向 Y3，说明 Y3 是全书的"层级换乘站"：病程内的发起权、证据层的可估性、前瞻的托底，在它这里都被换算成同一个问题——某个具名的人此刻还能执行什么。链七 · 降级链（本版新增，待检验）

Y1 → H1，并以 Y2 为加速器

无人持有 →（有人在场却不得使用已知信息，加速）→ 格从可估空间退出。 这条链把乙支四维从并列改成有方向，是本版对结构最实质的一次改动；它同时是全书最容易被推翻的一条——只需在两个独立队列里显示空窗时长与退出可估率无关。

链六 · 采集链（给做研究的人）

W1（五字段主键）≡ W3、H1、H3、Y2 · Y1 ≡ H1

一次采集，五章可算。 这条链不是理论关系而是工程关系：它说明本书提出的九个对象，在数据上并不需要九套系统，只需要一张带持格主键的事件表，加一份纵向三账日志。

七、书外的一条边：与《空白不是零》的分界

本书的关联系统若只画到书内，会漏掉最该画的一条边。作者另有一部专著《空白不是零——乳腺癌里九个没有被登记的位置》（德麦国际专著第 75 号）。两书的相似程度足以让任何一位读者提出同一个问题：这不就是把同一件事换一种癌症再写一遍吗？

这个问题必须由本书自己回答，而且要用与前七节相同的规格来答——给判据，给不成立的条件。

先如实承认相似的部分。 两书都以"九个位置"为骨架；都要求"位置缺席"必须产生下游后果才算数；都执行了预注册的公开数据真跑并原样报告不利结果；都在书末做了一次"九章会不会其实是一章"的自我攻击。这四条不是巧合，是同一位作者的同一套工作方式。分界只有一条，但它是硬的：前书查的是"记没记"，本书查的是"谁在持有"。

判决性分离：取一份记录完备、缺失率为零、按前书四种零逐项排查全部通过的数据集。前书的九个位置在其上应当全部取不到值——因为没有空白可查。本书的错持格在同一份数据集上照常成立：每一栏都有值、每一栏都合规，而没有一个五字段元组同时为该输出作证。若在一份缺失率为零的数据集上，本书的错持格与双持格也都取不到值，则本书相对于第 75 号没有新增任何形态，应当并入前书作为其"子宫癌篇"。 这条检验成本很低，作者请读者代为执行 。还要说明一处不利于本书的事实：前书九章的真跑九处全部产出不利结果并原样写入，其中一处直接导致该书最好卖的一句话被撤回；本书九章的真跑同样一致地报告"不能确证一例"。两书在这一点上没有分别——这既是同一种诚实，也说明本书在"从可定义推到可观察"这件事上，比前书没有前进。

八、这套关联系统怎么用

・给读者：不必按目录顺序读。按链一读，五章连成一个故事；按链四读，三对兄弟的分界就是本书全部精细度之所在。

・给评阅者：不必逐章找漏洞。取链一最弱的一环（H2 → H3），或取链四任一条判据，若能证明它在真实数据上不成立，本书的相应部分即须改写——比逐章挑剔省力得多。

・给做研究的人：按链六采集。一张带持格主键的事件表 ＋ 一份纵向三账日志，可同时检验五章的对象；不必为九个概念建九套系统。

・给本书自己：初版由网络指出的首要任务（为 Y1 找一条真实前置边）已在本版尝试完成（链七），但这条边目前只是结构推论。下一版的首要任务因此变成：去两个独立队列里检验链七；若不成立，把 Y1 降为附论。
