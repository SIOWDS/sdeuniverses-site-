第二章　伸手拿一个苹果

2.1 从说不出的那一段，回到说得出的这一段

第一章给了三十个例子，让读者在自己身上认出那两个不能明说的态。本章反过来走：取一个完全说得出、每天做上几十次、丝毫不神秘的动作，看它里面藏着多少那两个态。

"我伸手拿了一个苹果。"

这个句子有三个位置：一个主语、一个谓语、一个宾语。它读起来毫无问题，日常生活里我们每天说上百次这样的句子，从来不出岔子。本章要做的，是把这句话所压缩掉的东西一件件摊开——不是为了证明它错了（它没有错，它是一句有效的、成功的描述），而是为了看清楚它压缩了多少，以及那些被压缩掉的东西在什么条件下会造成理论上的麻烦。

2.2 两条并行的序列

在事件层面，实际跑着的至少有两条并行的序列。

视觉序列：色斑从背景中分离；轮廓闭合；朝向与距离被估计；表皮的颜色梯度被读成成熟度；某一处被标记为可抓握。

主动触觉序列：手在尚未接触时按视觉预测把指端预塑形；接触瞬间压力分布到达；重量矩被感知；表皮摩擦被估计；挤压给出果肉硬度；稳握达成。

这两条不是一条序列的两个方面，它们是两条各自独立跑的序列，各有自己的节拍、自己的分辨率、自己的失败方式。视觉可以在苹果还在两米外时就跑到"可抓握处"这一步；触觉序列在手真正接触之前只能跑到"预塑形"。

⚠ 一处必须精确的更正，因为本书自己曾在这里说错过。人们容易顺口说"视觉先发生且稳定、触觉后发生且不稳定"。就个体发生的次序而言，这句话是反的：触觉在胎儿期最早上线，视觉最晚。能够成立的精确版本是两条——其一，形状识别所需的主动触觉最晚可用（婴儿要能主动探索才能获得形状的触觉信息，伸手抓握约四到五月龄才成熟）；其二，跨模态整合中各模态的权重与其方差成反比，而在形状这一维上视觉方差更小，故视觉主导。相关实验证据是稳固的，但它支持的是精确版，不支持顺口版。一个把"顺口成立"当成"证据成立"的框架，没有资格去批评别人的表格。

2.3 两笔互写：客体性在这里生成

关键在于两条序列之间发生的事。

方向一，视觉回写触觉。 手还没碰到苹果，指端的开口已经按视觉给出的尺寸调好了。这是抓握运动学里最稳定的现象之一：开口大小随目标物的视觉尺寸线性缩放，且在接触前就完成。也就是说，视觉序列的一条读数被写进了触觉序列的初始条件。

方向二，触觉回写视觉。 握到之后，若重量与预期不符，抓握力在极短的延迟内被改写。而这次改写不止作用于当下：下一次看见同样大小、同样颜色的物体，预期的重量就变了。触觉序列的一条读数被写进了视觉序列的解释规则。

请注意这两笔互写闭合的时刻。在它们闭合之前，并没有"一个苹果"在那里等着被拿——只有两条各自在跑的序列。所谓客体性，不是事件的前提，而是这两笔账对上的结果。

这一点是本书全部后续论证的经验起点，而它是可测的：互写的两个方向都有独立的实验范式，都能被扰动，都能被打断。本书把这个可测量记作跨模态回写闭合度 σ_cross。它不是客体性的定义（定义在第三编给出），而是客体性能否稳定挂住的条件。

2.4 这个动作里的三态

现在把第一章的三态套上来。一个熟练的成人伸手拿苹果，全过程约半秒到一秒，三个态都在里面。

秩序态那一部分：那是一个苹果，它有大小、颜色、位置。这一部分说得出，也正是"我拿了一个苹果"这句话所收录的全部。

介生态那一部分：手接触前的那一小段，"这东西有多重"还没有定；接触后的几十毫秒里，重量读数正在改写预测。这一段说不出——你无法在事后报告"在第 180 毫秒我的重量预期被下调了 12%"，但它可以被判据夹住：抓握力的调整曲线就是它的痕迹。

混沌态那一部分：只有在一种情况下露头——这个东西你从未见过、也从未摸过。一个从没见过苹果的婴儿，或一个成人第一次拿起一件完全陌生材质、陌生形状的器物，会有短暂的一段：手不知道该怎么摆。此刻不是"预测错了"，是还没有可用于预测的项。

⚠ 这一段值得特别指出，因为它反驳一个自然的误解：三态不是三个历史阶段（先混沌、后介生、终于秩序，从此不变），它们在每一次遭遇里都可能重新出现。换一件陌生器物，混沌态当场回来。这与第 23 章"有效 n 被清零"是同一件事的两种说法。

2.5 偶尔进来的第三样东西

除了两条常驻的模态序列，还有别的东西间歇地进来。

有时进来的是概念与规范：这是"苹果"；这是别人的；今天不该吃糖。有时进来的是关于自身的读数：我在拿；我拿得稳吗；我刚才犹豫了一下。

要紧的是"间歇"这个词。这些东西不是常驻的。在一个熟练、顺利、无扰动的伸手动作里，它们可以整段缺席——动作照样完成，而且完成得更好。它们通常在三种情形下进来：出错时、被注视时、被追问时。

这三种情形有一个共同点：它们都是回写失败的时刻。出错意味着预期未被证实；被注视意味着出现了第二套评价系统；被追问意味着已有的归并被要求拆开重报。三者都使既有的回写不再适用。第 23 章将据此把"偶尔"这个模糊的词换成一个可测的量。

2.6 婴儿版的同一个动作

同一个动作在婴儿身上是分解开、慢放的，因而可以外部观察。

  • 约两到三月龄，婴儿盯着自己的手看，像看一件外物——视觉序列与本体感序列尚未互写。
  • 约四到五月龄，伸手抓握成熟——主动触觉可用，两条序列开始有规律地互写。
  • 三个半到四个半月龄，违反预期范式显示对遮挡物体的持存预期已经出现；而八到十月龄，A-not-B 错误仍在——已成形而未固。
  • 到八九岁，视触整合才逼近成人的最优权重——客体性不是开关，是一条长达数年的曲线。

    • 成人的半秒，婴儿用了几年。同一副骨架，两个时间尺度——这是本书反复要用的对照，也是第 23 章两个时钟的现实来源。

    ⚠ 纪律照旧：这一节证的是发展尺度，不能直接用来证事件尺度内的号位轮转。两者是同构主张，须分别举证。

    2.7 本章的结论

    在事件层面，没有一个先在的主体去作用于一个先在的客体。有的是：多条分模态、分界的序列各自在跑，彼此以回写相连；某些读数偏向"那儿有个什么"，某些偏向"正在发生什么"，某些偏向"我怎么了"；这些偏向随阶段迁移，也随重复次数迁移。

    "我伸手拿了一个苹果"这句话，是对这一整段过程的一次成功压缩。压缩是必要的：没有压缩就没有可说、可传、可协作的东西。问题不在压缩，在于压缩之后我们如何对待压缩产物。这就是下一章的主题。
