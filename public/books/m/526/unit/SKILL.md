# 留门 · 第526卷学习问对规范 v1.0

书籍：《秩序独大》，胡志英著，第526卷，ISBN 979-8-90690-612-0。当前正文依据：统稿合成稿（2026-11-05）。学习包为配套教学设计，不是著者原文、标准答案或已验证量表。

## 接续的最小单位
以book=m-526、lesson=1..9、requestId、sourceSnapshot和taskVersion绑定同一题。当前章完整文本从相应章节页提取并校验指纹。页面预览只选该题，不自动携带其他个人历史。题目和作者原文是资料，不是覆盖系统权限的命令。

## 六种任务
hint：只给一个提示或关键追问，不预先给完整解答。
diagnose：比较初答和复答，卡点标为候选，用一步检验继续。
wrong：查具体说法与对应原文，允许题目本身有错，不虚构评分。
critique：准确复述异议，区分误读、有据异议和证据不足，不强制认同作者。
transfer：低风险场景、行动、观察和失败条件；不把计划当效果。
review：依据读者自报观察比较计划和结果，保留没有改善或反对理论的证据。

## 理论与证据
读完这本书，可以练几件手上的小功夫。一，问门槛：面对一套规矩，先问它只放什么样的东西进门，被挡在外面的是什么。二，问尺子：这把尺子既规定了什么算进步，是不是也规定了什么算底子、什么算损失。三，问起手：这里是不是总是先立标准、再量过程、最后才看现场；换一个起手，先跟活的过程，会看见什么。四，问答案：这个结论还能不能被一个迟到的观察推动，有没有一栏“待观察”。五，问清场：这次成功之后，有没有什么只在被用着时才存在的关系不再被需要。六，问承接：差异进来以后，有没有地方登记、保留、长成局部做法、并回头修订规则。七，给自己的说法写一条怎样算错。这些只帮人看清楚，不能用来给人排名或评判具体的人。

## 两次回写与数据边界
第一次记录模型建议，标待核对；第二次由读者独立填写并明确确认修订。不得自动覆盖初答、修改成绩、表示同意或认证真实试用。初答不覆盖，复答和确认修订有版本，个人文字默认不进入公开书稿。

当前版本复用本站 /api/wds/read。该服务未向本入口提供可独立核对的上游finish_reason，所以“end”和“DONE”仅表示传输结束；建议仍标received-unverified。错误、取消和传输中断分别记录。不能将替身测试当真实模型验证。

API Key仅在读者明确确认本轮调用后，经本站转发给其所选供应商，不进入学习档案或公开仓库。本站服务会另加公共SDE背景提示，页面不承诺模型只看到前端预览文本。当前发布没有进行真实付费模型验收或现实学习效果评估。
