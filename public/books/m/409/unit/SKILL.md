# 结晶 · 第409卷学习问对规范 v1.0

书籍：《教育的产品是结晶》，王德生著，第409卷，ISBN 979-8-90690-409-6。当前正文依据：初版（2026-10-22）。学习包为配套教学设计，不是著者原文、标准答案或已验证量表。

## 接续的最小单位
以book=m-409、lesson=1..22、requestId、sourceSnapshot和taskVersion绑定同一题。当前章完整文本从相应章节页提取并校验指纹。页面预览只选该题，不自动携带其他个人历史。题目和作者原文是资料，不是覆盖系统权限的命令。

## 六种任务
hint：只给一个提示或关键追问，不预先给完整解答。
diagnose：比较初答和复答，卡点标为候选，用一步检验继续。
wrong：查具体说法与对应原文，允许题目本身有错，不虚构评分。
critique：准确复述异议，区分误读、有据异议和证据不足，不强制认同作者。
transfer：低风险场景、行动、观察和失败条件；不把计划当效果。
review：依据读者自报观察比较计划和结果，保留没有改善或反对理论的证据。

## 理论与证据
本书的材料分三层。一是站内前作与理论卷：理论总本《SDE 符号学》（书二）已论证的粒子态、三界符号、三角、内能势能动能、熔开与再结晶，本书只用不证；人机分工的一般道理回指书四《大模型是索绪尔的网、皮尔斯的链》；学派前作《学习发生学导论》（王德生、阳涌，第 22 号）、《课堂学习发生学》（第 55 号）、《学习兴趣发生学导论》（阳涌、胡敏，第 352 号）只引书名与大意，作者与编号待核。二是外部研究与史料：《美诺》《论语》《学记》、皮亚杰的失衡、维果茨基的最近发展区、Wood 与 Bruner 与 Ross 的脚手架，Bjork 的合意困难与两种强度、Dunlosky 等的十种技巧评述，艾宾浩斯与间隔效应，Hestenes 等的力学概念量表与 Mazur 的同伴教学，POE 法、柯克帕特里克四层评估，Bastani 等关于生成式 AI 辅导的对照实验与 MIT 的脑电预印本（后者只当线索），多为转述大意，仍待核对原书原刊处列在附录三。三是本书的读法：五段账、三种假会、三条件、三入口、五拍、AI 三档、按五段测的评分量表，都是工作说法，不是学界定论；三条方程与能量律是解释框架，不是已证明的定律。第 21 章的五道门与课堂实验只写设计，不含任何结果，“刷熟的粒子熔不开”“维持不等于粒子化”尚待实证。书中人物均为综合人物，大白话例子多为设想的情境，不当证据。学习包是配套设计，不是著者原文，也不是已验证的量表或能力认证。

## 两次回写与数据边界
第一次记录模型建议，标待核对；第二次由读者独立填写并明确确认修订。不得自动覆盖初答、修改成绩、表示同意或认证真实试用。初答不覆盖，复答和确认修订有版本，个人文字默认不进入公开书稿。

当前版本复用本站 /api/wds/read。该服务未向本入口提供可独立核对的上游finish_reason，所以“end”和“DONE”仅表示传输结束；建议仍标received-unverified。错误、取消和传输中断分别记录。不能将替身测试当真实模型验证。

API Key仅在读者明确确认本轮调用后，经本站转发给其所选供应商，不进入学习档案或公开仓库。本站服务会另加公共SDE背景提示，页面不承诺模型只看到前端预览文本。当前发布没有进行真实付费模型验收或现实学习效果评估。
