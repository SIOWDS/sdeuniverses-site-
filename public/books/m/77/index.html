记到谁的账上

语言习得的九本账

全书零学习者级数据。九章各带一条写死日期的撤回条件；第十章另写死一条会把九章压成两章的合并规则；第十三章事先承认哪一个理论家族最可能整体吞掉本书
母 题 · CORE THESIS

一个学生答对了一道题。所有人都同意他答对了：老师看见了，分数记下了，家长知道了。可是没有人问过一个更前面的问题——这一次答对，该记在谁的账上？

如果老师刚刚说出了句首，这一分里有多少是老师的？如果他是靠母语翻了一道弯才说出来的，这条路径算不算已经通了？如果他其实分别会说这两个句式、只是从没被要求同时用上，这次成功证明的是什么？这些追问指向同一个空缺：我们的测量把一次成功记为 1，而 1 的内部不再有结构。中心判断因此是：语言习得不是做对的次数变多，而是每一次经验被记到正确的账上。

九章，九个「该记在谁头上」

正确率、词汇量、流利度、保持时间、迁移距离、加工速度、显隐知识的分离度——这一族因变量回答的都是「会不会」。语言习得研究因此有一份很长的收入表，却没有一张科目表：每一笔进账都记下了金额，没有记下户头。九章补的就是这张表。

第一章无定载续态——承载账。撤掉那位老师、那句提示、那个熟悉的搭档，这句话还能不能重新说出来？关键不是判断「还能不能」，而是把需要某个特定的人与需要有个人分开：前者随习得解除，后者可能本来就是语言能力的组成部分。
第二章伪直连成功——路径账。两个子系统之间那条唯一的桥，扰动掉它，跨层任务还成不成立？成功可以被一条中介垄断，而端点成绩看不出这件事。成熟不是所有中介消失，而是任何单一中介都不再不可替代。
第三章双熟互斥——配对账。两项能力分别都达标，放进同一个语言事件却稳定坍塌。这不是任一单项的属性，是「这一对」的属性——而能力清单从不为「一对」留一栏。
第四章成元余备——单位账。当时没被选中的那种切法，后来还调得出来吗？关键检验必须在不重新呈现材料的条件下做：若只能靠重新看、重新听才出现，那只是一次普通的重新分析。
第五章承诺守恒域——同一性账。一句话经过语序、语态、时态、语体、情态的变化之后，还在承担同一件交际责任吗？真正危险的不是分不清，是分得太少——把一切变体都判为「差不多一样」，会让迁移率非常好看。
第六章空缺举证资格——空缺账。一个说法长期不出现，可能是它不合法，也可能只是这份语料太窄。零不能自己给自己当分母。
第七章决前因果资格——时点账。学习者确实拥有这条知识——讲得出规则、订正得对、不限时成绩很好——但它每次都在选择关闭之后才抵达。这样的学生最容易被判为「粗心」，而增加规则讲解只会让库存更大，不改变到场时间。
第八章语言更新寻址——层级账。同一个表面偏差，可以被记到词项、语法、说话人、通道、任务上。当场适应得快，不等于写对了地方；而眼前越成功，越不容易意识到地址错了。
第九章语言写域——范围账。一次局部经验该改写哪些未来情境？学得快而串得远，源任务成绩上涨与真实语境适配下降，可以同时发生。本书不奖励「少泛化」，只奖励「泛化范围与证据的实际适用范围匹配」。

并排之后才看见的三件事

九章是分别写成的。装成一本书时并排放在一起，出现了三件写作时没有预料到的事。

其一，九种记错无一例外都会让传统指标上升。靠一个人托着的流利、只有一条路的正确、每一项都达标的清单、焊死了的熟练、压平了边界的迁移、看起来很规范的谨慎、讲得出规则的懂、当场适应得很好的快、学得飞快的进步——九格全部是奖励结构会挑出来表扬的样子。这不是巧合：记账错误只有在存在一个「本该记到别处」的对照条件时才可见，而我们的测量几乎从不提供这样的对照。由此还得到一条不舒服的推论：课堂越统一、考试越标准，这九格越牢固——标准化的本质正是消除条件对照。

其二，九个读数的分母没有一个是「人」。分别是扰动事件、试次、能力对、探针、变形边、配对、语言事件、偏差事件对、输入事件。九章各自为了避开同一个陷阱独立走到了同一处：只要把分母写成人，任何一次成功都可以被记进这个人的账上，而这正是本书要问的问题本身。后果很硬——任何以学习者为单位、单一条件下取值的成绩单，都产不出这九个读数中的任何一个，本书因此不能靠二次分析既有数据验证自己，必须做新实验。

其三，九章从九个完全不重叠的地方出发。九章共引 213 条次，去重后 205 条，被两章共引的只有 8 条，被三章以上共同引用的一条也没有。这个数字只支持「输入不同」，不支持「产出不同」——九章完全可以从九个不重叠的书架出发最后说同一句话。但它也说明：上面两条共同签名不是从共同传统里继承来的，因为九章根本没有共同的传统。

八次真跑，八次不利结果

九章各做过一次公开数据复算或语料检查，其中八次产出的是对本书不利的结果，并当场删掉或收窄了原有条款：

第二章复算公开双语切换数据（stay 764.20ms／switch 805.35ms，成本 5.38%）→ 删掉「反应时残余成本＝桥依赖」原始条款
第三章查三项最新公开研究，均不满足四字段 → 删掉「现有证据已证明双熟互斥广泛存在」
第四章复算 2024 年二语程式语数据（高水平修改份额 43.17% vs 低水平 30.55%）→ 被迫退出「整体→分析」单向发展轴
第一章复算 2026 年社会网络与语用能力数据（Welch t≈7.66，d≈0.92）→ 推翻「外部支持退出后语言生成转入个体」
第六章在一个公开树库上查 a-adjective，可编码事件为 0 → 删掉「零频率阈值」
第九章2025 年说话人可靠性复制研究（条件主效应不显著）→ 打掉「可信来源过滤器」初版
第八章2025 年五项多说话人语音实验字段审计 0/5 → 只能给出缺口结论，不能计算读数
第七章两条公开统计压力测试 → 推翻「离线知识高即接近实时可用」

第九次——第五章那次——用的是一份内部清单查内部构念，本书在改写时把它降级为方法示例，因为拿自家的清单查自家的新词，零覆盖几乎是必然的。八比一这个比例不是谦虚，它是一个警告信号：一个每次真跑都被打回来的理论，通常意味着它离能被检验还差一步。

第四编不为九章辩护

第十章《九本账，是不是同一本账》把九个读数拆成形式、分母、条件、时间四项并排，找出三条共同签名，点出三对最可能其实是同一件事的读数（第八章与第九章最危险），并写死一条会把九章压成两章的合并规则：七个比例型读数若两两相关普遍高于 0.8，或第一主成分高于 70%，全书重编，现行三编不保留。

第十一章《九种记错了也不报警的样子》并排九个靶格，抽出三条共同签名，推出全书最硬也最容易被推翻的一条：凡只在单一条件、单一时点、以学习者为单位取值的指标，都无法把九个靶格与其对照格分开。本章同时给本书自己设了一条目前答不上来的反证——九读数全是事件量、没有一个是分布量，一个班可以九项全部合格而合格事件集中在少数几名学习者身上，其余的人不是记错了账，是根本没有开过账。

第十二章《一份共同的实验》给出让九个读数在同一批学习者身上同时取值的四臂设计，并在看数据之前写死三种结果的处置——其中一种直接执行第十章的合并规则。另附一个最小可行版：一个班、一个语言目标、八周、四个读数。

第十三章《这套理论共同的对手》补章级划界挡不住的五个理论家族，逐家给出分离线、判决性预测与合并规则，并事先承认：潜在成因推断与理性适应器那一家，一家就能覆盖本书的第八、九、六三章，若再加上「层是异质的」这一条假设，还能覆盖第五章。

第十四章：答克拉申

末章让对手直接说话。三条规矩先写清楚：对方的话由本书代拟，因此必须拟到最狠；答不了就明说；末节逐场结账。八场：克拉申五问、乔姆斯基、托马塞洛、维果茨基、斯温、一位测评专家、一位中学英语教师。

明确输三处。输给克拉申的问三——九章一个字也没处理输入，而书名叫《语言习得的本质》，这是范围与题目不相称，不是分工。输给斯温——学习者在本书里只是记账者，不是新证据的制造者，九个账户里没有「谁发起了下一条证据」这一维度。输给乔姆斯基——在第十二章那份数据出现之前，「实验地址空间」与「描述性范畴」没有区别。

明确赢一处。赢在使用禁令：九个靶格全是传统指标会打高分的那一格，这意味着任何把本书读数用于评价个人的做法，都会在制度上奖励一件本书刚刚证明为危险的事。一个关于「看起来最好的那一格最危险」的理论，如果自己被做成一个分数，它就是自己理论的第十个靶格。

克拉申问五击中自反缺口——你自己这本书，是不是也在一个高度稳定的条件下反复练同一套话术？本书当场接受三条承诺：保存被拒绝的批评并说明未采纳的理由；若实验跑出不利结果，公开原始相关矩阵；写下一件会让作者放弃本书的事——若数据显示九读数的高值系统性伴随低参与率，作者放弃本书在教育情境中的全部主张。

这本书打算怎样被推翻

三层撤回条件，层层向上，执行都不需要著者同意。

章级：九章各有一条撤回主张、一个期限（多为 2031 年）、一份「以下情况不算命中」的否定清单，汇总在附录一。

书级：第十章那条合并规则——七个比例型读数高度共变则全书重编为两章。

家族级：第十三章那条——五个家族中任一家的既有编码方案若能算出本书六个以上读数且相关高于 0.8，全书并入那一家，九章降级为该家族在语言材料上的九个应用案例。

导读第六节另给了三条最省力的推翻路径，从最便宜到最致命。最便宜的一条是：按第十二章第七节的最小可行版做——若那四个读数已经两两相关高于 0.8，完整实验不必再做，本书应当直接进入重编。

怎么读这本书

导读给了四条路径，读者按自己的位置选一条。

研究者
约六万字		导论 → 第十章 → 第十二章 → 第十三章 → 附录二 → 附录一。读完这一路已经掌握推翻本书所需的全部材料，甚至不必读九章正文。若目的是判断这本书值不值得检验，这条最短。
教师
约三万字		前言 → 第十一章 → 第十四章第七节 → 九章中任选二三章的第一节与二维辨别格。第十一章是全书对教学最直接的一章。
审稿人
约两万字		写作与证据声明 → 第十三章 → 第十四章结账 → 附录一 → 附录四。本书在这几处集中承认了自己的输处、缺口与最可能被合并的地方。找弱点从这里开始比从正文快。
通读按印次读。建议读完第九章之后停一停，先看第十章第一节那张九读数并排表，再回头看自己对九章的印象有没有变化——九章分别读时像九件事，并排看时很像一件事。

九章结构统一，时间有限的读者每章只读三节即可掌握承重内容：第一节（问题重置）、二维辨别格那一节、单一主读数那一节。

姊妹卷：《语言的智慧》处理一次表达完成之后，被删掉、偏转或沉积的那一部分如何返回并改变下一轮；本书处理另一半——一次语言事件发生之后，它被记到了哪一个账户上。两书的分界与判决性预测写在本书第十三章。另见同一作者的 《一花一世界》 与 《知行合一》。

写作与证据声明

本书没有任何一章拥有学习者级的验证数据。九章各自报告过一次基于已发表汇总统计的复算或一次公开语料检查，其中八次产出的是对本书不利的结果，并已导致相应章节删除或收窄原有条款。这些复算不是独立再分析，不构成对本书构念的经验支持。

第五章（承诺守恒域）在最初写作时限定了检索范围，因此它的外部文献基础明显薄于其余八章。本书在改写时为该章补入了四位占位理论与三项测量工具文献，但它仍不足以与其余八章等量齐观。读者应把第五章视为本书中证据基础最弱的一章。

本书全部读数均未经信效度验证。本书明确反对在第十二章所述实验完成、且第十一章第五节所述参与率盲区解决之前，把其中任何一个读数用于人员评价、教育分流、儿童能力标签或临床判断。

九章的问题设定、三源选择约束与产出要求由著者给定；候选组合的随机生成、来源阅读、候选淘汰、概念操作化、公开数据复算、正文组织与文稿生成由语言模型协助执行；全部判断、取舍与本书的最终主张由著者负责。凡本书未能直接核验原文的，一律写明「在本书检索到的范围内未见」，而不写「尚无人处理」。
