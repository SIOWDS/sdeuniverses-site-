# 松结 · 第270卷学习问对规范 v1.0

书籍：《敌人发生学》，王德生著，第270卷，ISBN 979-8-90690-784-4。当前正文依据：初版（2026-10-12）。学习包为配套教学设计，不是著者原文、标准答案或已验证量表。

## 接续的最小单位
以book=m-270、lesson=1..40、requestId、sourceSnapshot和taskVersion绑定同一题。当前章完整文本从相应章节页提取并校验指纹。页面预览只选该题，不自动携带其他个人历史。题目和作者原文是资料，不是覆盖系统权限的命令。

## 六种任务
hint：只给一个提示或关键追问，不预先给完整解答。
diagnose：比较初答和复答，卡点标为候选，用一步检验继续。
wrong：查具体说法与对应原文，允许题目本身有错，不虚构评分。
critique：准确复述异议，区分误读、有据异议和证据不足，不强制认同作者。
transfer：低风险场景、行动、观察和失败条件；不把计划当效果。
review：依据读者自报观察比较计划和结果，保留没有改善或反对理论的证据。

## 理论与证据
本书判词：敌人不是一个人，而是一种发生。王德生口述（2026-10-12）：他和我，即主体，都是发生的，都不具备先验独立存在性；敌人是对当下的SDE，一些负面和阻力特征纠缠聚合体的粒子性（整体、稳定、独立）发生；类似物体发生学——三种感官特征纠缠聚合体的发生；在这件事上是敌人，在另一件事上是朋友；没有永远的敌人，就是阻抗特征纠缠聚合体的解散；最大的敌人既不是自己，也不是他人，这也解构了萨特的“他人即地狱”。全书以春秋战国（吴越同舟、合纵连横、远交近攻、管仲与齐桓公、卧薪尝胆）与二战（绥靖、苏德条约、国共两场发生的叠加、同盟瓦解、法德美日的解散）作大尺度论证。

## 两次回写与数据边界
第一次记录模型建议，标待核对；第二次由读者独立填写并明确确认修订。不得自动覆盖初答、修改成绩、表示同意或认证真实试用。初答不覆盖，复答和确认修订有版本，个人文字默认不进入公开书稿。

当前版本复用本站 /api/wds/read。该服务未向本入口提供可独立核对的上游finish_reason，所以“end”和“DONE”仅表示传输结束；建议仍标received-unverified。错误、取消和传输中断分别记录。不能将替身测试当真实模型验证。

API Key仅在读者明确确认本轮调用后，经本站转发给其所选供应商，不进入学习档案或公开仓库。本站服务会另加公共SDE背景提示，页面不承诺模型只看到前端预览文本。当前发布没有进行真实付费模型验收或现实学习效果评估。
