# 换档 · 第451卷学习问对规范 v1.0

书籍：《发生的时差》，王德生著，第451卷，ISBN 979-8-90690-451-5。当前正文依据：三审定稿 v1.0（2026-10-22）。学习包为配套教学设计，不是著者原文、标准答案或已验证量表。

## 接续的最小单位
以book=m-451、lesson=1..30、requestId、sourceSnapshot和taskVersion绑定同一题。当前章完整文本从相应章节页提取并校验指纹。页面预览只选该题，不自动携带其他个人历史。题目和作者原文是资料，不是覆盖系统权限的命令。

## 六种任务
hint：只给一个提示或关键追问，不预先给完整解答。
diagnose：比较初答和复答，卡点标为候选，用一步检验继续。
wrong：查具体说法与对应原文，允许题目本身有错，不虚构评分。
critique：准确复述异议，区分误读、有据异议和证据不足，不强制认同作者。
transfer：低风险场景、行动、观察和失败条件；不把计划当效果。
review：依据读者自报观察比较计划和结果，保留没有改善或反对理论的证据。

## 理论与证据
本书的材料分四层：一是德麦国际 2026 年 10 月 19—20 日上架的二十种专著（书号见附录四），凡引其原话处注明书号与章节，三审时逐条回原书核过；二是站内近邻（第 282、336、396 号，《轮空》《初次对表》），转述处写明「换成本书的白话」；三是外部文献，以参考书目所列为限（Ogburn、Braudel、Koselleck、Brand、Gunderson 与 Holling、Scheffer 等、Rosa、Gould、Hairston 等、Lipsitz 与 Goldberger、Earn 等、Haldane 与 May、Ancona 与 Chong、Lupu 与 Liu、Serhan 与 Savill、Wever、Lefebvre、Little），本书不把他们已说过的三件事（快慢不同、不同步与太同步、次序改变生出新东西）当作自己的发现；四是本书自己的推论：缓劲、先手、当家三分，档位、换档、卡档（锁死／拧死），两快顶一慢，换档力。六路径读作六种档位、123原理读作两快顶一慢，是本书提出的读法，不是 SDE 的定论，只当地图用。卢家一家、各章配角和书中的日子都是虚构的，只作说明，不当调查结果。身体、法律、理财的内容只讲道理，不构成医学、法律或投资建议。三条「怎样才算错」见导读，最便宜的三种跑法与自认最弱的五处见附录二，至今均未用真实数据跑过。

## 两次回写与数据边界
第一次记录模型建议，标待核对；第二次由读者独立填写并明确确认修订。不得自动覆盖初答、修改成绩、表示同意或认证真实试用。初答不覆盖，复答和确认修订有版本，个人文字默认不进入公开书稿。

当前版本复用本站 /api/wds/read。该服务未向本入口提供可独立核对的上游finish_reason，所以“end”和“DONE”仅表示传输结束；建议仍标received-unverified。错误、取消和传输中断分别记录。不能将替身测试当真实模型验证。

API Key仅在读者明确确认本轮调用后，经本站转发给其所选供应商，不进入学习档案或公开仓库。本站服务会另加公共SDE背景提示，页面不承诺模型只看到前端预览文本。当前发布没有进行真实付费模型验收或现实学习效果评估。
