# 辨名 · 第541卷学习问对规范 v1.0

书籍：《伐冰之家不畜牛羊》，秦莉、王德生著，第541卷，ISBN 979-8-90690-542-0。当前正文依据：初版修订（2026-10-31）。学习包为配套教学设计，不是著者原文、标准答案或已验证量表。

## 接续的最小单位
以book=m-541、lesson=1..13、requestId、sourceSnapshot和taskVersion绑定同一题。当前章完整文本从相应章节页提取并校验指纹。页面预览只选该题，不自动携带其他个人历史。题目和作者原文是资料，不是覆盖系统权限的命令。

## 六种任务
hint：只给一个提示或关键追问，不预先给完整解答。
diagnose：比较初答和复答，卡点标为候选，用一步检验继续。
wrong：查具体说法与对应原文，允许题目本身有错，不虚构评分。
critique：准确复述异议，区分误读、有据异议和证据不足，不强制认同作者。
transfer：低风险场景、行动、观察和失败条件；不把计划当效果。
review：依据读者自报观察比较计划和结果，保留没有改善或反对理论的证据。

## 理论与证据
本书判词：名人的名字，在本行里与价值、意义一起长出来；走进别人的行当，名字带着流量走，价值与意义没有跟过去，这个不统一的名字，压在名字与价值意义本来就统一的普通人身上。著者口述（2026-10-31）：名人离开起家的本业进入大众行业，无论自己下场、被邀请、善意起家，还是全部公益，都不行，因为无形中造成其他大众的挤压；S3、D1、E2出现了不统一；三问是谁的意义被损害、谁的价值被占有、谁动用了不该用的能量；本行里D1的特征律（创造之意义）受损，无法升维自己的事业；中华文化以自我世界为核心定义理念界与现实界，“我信你这个人，你做什么都会带来意义和价值”是认知缺陷。书中事实均注明出处，推断均写明是推断。

## 两次回写与数据边界
第一次记录模型建议，标待核对；第二次由读者独立填写并明确确认修订。不得自动覆盖初答、修改成绩、表示同意或认证真实试用。初答不覆盖，复答和确认修订有版本，个人文字默认不进入公开书稿。

当前版本复用本站 /api/wds/read。该服务未向本入口提供可独立核对的上游finish_reason，所以“end”和“DONE”仅表示传输结束；建议仍标received-unverified。错误、取消和传输中断分别记录。不能将替身测试当真实模型验证。

API Key仅在读者明确确认本轮调用后，经本站转发给其所选供应商，不进入学习档案或公开仓库。本站服务会另加公共SDE背景提示，页面不承诺模型只看到前端预览文本。当前发布没有进行真实付费模型验收或现实学习效果评估。
