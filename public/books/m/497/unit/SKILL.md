# 开场 · 第497卷学习问对规范 v1.0

书籍：《释经学的典范革命》，王德生著，第497卷，ISBN 979-8-90690-497-3。当前正文依据：三审定稿（2026-10-22）。学习包为配套教学设计，不是著者原文、标准答案或已验证量表。

## 接续的最小单位
以book=m-497、lesson=1..74、requestId、sourceSnapshot和taskVersion绑定同一题。当前章完整文本从相应章节页提取并校验指纹。页面预览只选该题，不自动携带其他个人历史。题目和作者原文是资料，不是覆盖系统权限的命令。

## 六种任务
hint：只给一个提示或关键追问，不预先给完整解答。
diagnose：比较初答和复答，卡点标为候选，用一步检验继续。
wrong：查具体说法与对应原文，允许题目本身有错，不虚构评分。
critique：准确复述异议，区分误读、有据异议和证据不足，不强制认同作者。
transfer：低风险场景、行动、观察和失败条件；不把计划当效果。
review：依据读者自报观察比较计划和结果，保留没有改善或反对理论的证据。

## 理论与证据
本书的材料分四层：一是经文，一律据中文和合本（1919 年版），统稿时与和合本文本逐条比对；二是释经史与学术观点，教父、拉比、改教家与现代学者只转述大意，凡未逐页核对处标〔待核〕并汇总于附录三；三是 SDE 口径，母题、判词、符号学底座与全部承重命题来自王德生口述；四是本书自己的读法，如六十六卷各自的缝、结晶与类型（入口一、入口二、入口三、固化、迁移），以第 72 章总表为准。各章开头的家常人物与故事是为说明而设的示范情境，人名、情节皆属虚构，不当证据。防“怎么读都行”的三道闸与五条可推翻条件见第 3、66、73 章。

## 两次回写与数据边界
第一次记录模型建议，标待核对；第二次由读者独立填写并明确确认修订。不得自动覆盖初答、修改成绩、表示同意或认证真实试用。初答不覆盖，复答和确认修订有版本，个人文字默认不进入公开书稿。

当前版本复用本站 /api/wds/read。该服务未向本入口提供可独立核对的上游finish_reason，所以“end”和“DONE”仅表示传输结束；建议仍标received-unverified。错误、取消和传输中断分别记录。不能将替身测试当真实模型验证。

API Key仅在读者明确确认本轮调用后，经本站转发给其所选供应商，不进入学习档案或公开仓库。本站服务会另加公共SDE背景提示，页面不承诺模型只看到前端预览文本。当前发布没有进行真实付费模型验收或现实学习效果评估。
