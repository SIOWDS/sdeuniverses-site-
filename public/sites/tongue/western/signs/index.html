西医临床舌征图谱

良性变异、营养缺乏、感染、系统病、神经病变与八条警示信号。

本编有 3 处标着「待核」：编写时没在检索结果里直接见到原文。它们照原样标出，没有补核前请不要当定论引用。

按类别整理西医临床上常见、常考、常被误认的舌部表现。每条写「表现｜机制｜意义」。

主要依据：美国家庭医师杂志两篇综述（Reamy BV 等 2010；Straub L 等 2024）A，以及口腔医学、皮肤科、神经科通行内容C。

本编涉及的任何病变，都必须由医生面诊判断，不能据此自我诊断。

零、先看两个总数A

  • 据美国国家健康与营养调查的数据，美国成人舌部病变的时点患病率约为 15.5%；戴假牙者与吸烟者患病率更高。
  • 最常见的三种是地图舌、裂纹舌、毛舌（黑毛舌），三者通常不需要治疗。

也就是说，一个普通人对着镜子看到舌头「不太一样」，最可能的是良性变异，而不是病。但也正因为常见的多是良性的，少数真正需要警惕的表现（见本编末「警示信号」）才更要单独记牢。

一、常见良性变异

1. 地图舌（良性游走性舌炎）

  • 表现：舌背出现一块或多块边界清楚、光滑发红的斑片，周围有略隆起的白色或黄色边缘，形如地图；斑片的位置、形状在数天到数周内不断变化，此消彼长。
  • 机制：病变区丝状乳头脱失，边缘区上皮内有中性粒细胞浸润。确切病因不明，与遗传、银屑病、特应性体质、裂纹舌等相关。
  • 意义：良性，多数无症状，少数对酸辣食物敏感。一般不需治疗，有症状时可对症处理。A
  • 参考：Jainkittivong A, Langlais RP. 188 例地图舌的临床特征，J Contemp Dent Pract 2005;6:123–135；Ogueta C 等，地图舌：皮肤科医生应知道的，Actas Dermosifiliogr 2019。A
  • 两套机制对照：中医把地图舌归入剥落苔，读为胃气、胃阴不足或气血两虚；小儿多见时，常与脾胃虚弱、食积相联系。这是两套机制判断分歧最大的地方之一（见第 10 编）。

2. 裂纹舌

  • 表现：舌背上有深浅不一的沟裂，常以正中沟为主干向两侧分支。
  • 机制：多为发育性，随年龄增长更常见；常与地图舌并存。
  • 意义：良性。沟内易积食物与细菌，可致异味与刺激，建议轻刷舌面。可见于唐氏综合征、梅尔克松—罗森塔尔综合征（反复面瘫、唇肿、裂纹舌三联）、银屑病。A

3. 毛舌与黑毛舌

  • 表现：舌背中后部出现一层毛发样外观，多为黑色，也可为褐、黄、绿、白。
  • 机制：丝状乳头角化物脱落受阻而异常伸长，被色素菌、真菌、食物、烟草着色。
  • 诱因：吸烟、口腔卫生差、软食或流质、口干、广谱抗生素及其他药物、放疗等。
  • 意义：良性。处理为去除诱因、刷舌或刮舌。【A：Schlager E 等，Am J Clin Dermatol 2017;18(4):563–569；Thompson DF, Kessler TL. 药物诱发的黑毛舌，Pharmacotherapy 2010;30(6):585–593】
  • 鉴别：含铋制剂可使舌面变黑（假性黑毛舌），停药可退；中医的灰黑苔须结合润燥与全身状况判读。

4. 正中菱形舌炎

  • 表现：舌背中线、界沟前方一块边界清楚、光滑发红的菱形或卵圆形斑片，通常无症状，偶有烧灼感。
  • 机制：多与局部念珠菌感染相关；吸烟、吸入激素、义齿等为危险因素。
  • 意义：有症状时抗真菌治疗通常有效。A

5. 容易被误认为「肿物」的正常结构

  • 轮廓乳头：舌根前方一排较大的圆形突起，8—12 个。
  • 叶状乳头：舌侧缘后部的竖向皱襞，发炎时肿大。
  • 舌扁桃体：舌根部的淋巴组织。
  • 舌下静脉：舌下面两侧蓝紫色的静脉，老年人常迂曲扩张。

这些都是正常结构。第一次认真自查舌头的人，常常因此焦虑。

二、营养缺乏

1. 萎缩性舌炎（光滑舌）

  • 表现：舌面光滑、发红、发亮，乳头消失，可有烧灼痛。
  • 机制：上皮增殖所需原料缺乏。
  • 常见原因：铁、叶酸、维生素 B12、核黄素、烟酸等缺乏；也见于念珠菌感染、干燥综合征、乳糜泻、营养不良。
  • 意义：病因治疗后可恢复。这是舌头作为全身营养指示灯最可靠的一类表现。A

2. 几种有名字的营养性舌炎C

  • Hunter 舌炎：维生素 B12 缺乏（恶性贫血）所致，舌面光滑鲜红，常伴疼痛。
  • 核黄素缺乏：舌色可呈紫红（品红色），常伴口角炎、唇炎。
  • 烟酸缺乏（糙皮病）：舌红肿、光滑，常伴皮炎、腹泻、痴呆。
  • 缺铁：舌面光滑，可伴口角炎、吞咽困难（普卢默—文森综合征，伴食管蹼）。

三、感染

1. 口腔念珠菌病

  • 假膜型：舌背、颊黏膜上白色凝乳样斑片，可以擦掉，擦后留下红色创面。
  • 红斑型（萎缩型）：舌背光滑发红，常见于抗生素、吸入激素之后，或义齿下方。
  • 危险因素：婴幼儿、老年、义齿、糖尿病、广谱抗生素、吸入或全身糖皮质激素、免疫抑制（包括艾滋病）、口干。
  • 两套机制对照：假膜型念珠菌病的白色斑块，外观上可能被误读为「白苔」，但它能被擦掉、擦后出血，与中医的「无根苔」在操作上有相似处，意义完全不同。

2. 口腔毛状白斑A

  • 表现：舌侧缘白色、带竖向皱褶的斑块，擦不掉。
  • 机制：EB 病毒感染上皮。
  • 意义：多见于严重免疫低下者（尤其是艾滋病），可用口服抗病毒药治疗。出现时应评估免疫状况。

3. 草莓舌C

  • 猩红热：病初舌覆白苔、菌状乳头红肿凸出（白草莓舌），数日后白苔脱落、舌面鲜红而乳头凸起（红草莓舌）。
  • 川崎病：美国心脏协会 2017 年科学声明中的主要诊断标准之一，「口唇与口腔改变」包括口唇红、干裂，草莓舌，口咽黏膜弥漫充血。川崎病的延误诊断可导致冠状动脉瘤，所以儿童持续高热伴草莓舌、眼红、皮疹、手足红肿、颈淋巴结肿大时，要立即就医。
  • 中毒性休克综合征等也可出现。

4. 梅毒C

一期可在舌上出现无痛性硬下疳；二期可有口腔黏膜斑；三期可出现树胶肿、间质性舌炎（后者有癌变风险）。

5. 其他病毒C

单纯疱疹（多在唇与硬腭）、手足口病（口腔疱疹与溃疡）、人乳头瘤病毒相关的乳头状瘤等。新冠感染后舌部改变（乳头炎、舌炎、味觉改变等）有较多病例报告待核：系统综述；舌苔菌群与新冠严重程度相关的研究见第 05 编A。

五、神经系统

1. 舌下神经麻痹

  • 表现：伸舌偏向患侧，患侧舌肌萎缩，可见肌束颤动；构音、吞咽可受影响。
  • 常见原因：颅底肿瘤、颈内动脉夹层、外伤、颈部手术、延髓病变。
  • 意义：突然出现的单侧舌下神经麻痹，尤其伴颈痛、头痛，要警惕颈内动脉夹层。

2. 脑卒中

  • 表现：伸舌偏向肢体瘫痪一侧，言语含糊，常伴口角歪斜、肢体无力。
  • 意义：急症。时间就是脑组织，应立即就医。
  • 中医对照：歪斜舌、强硬舌被中医读为中风或中风先兆，在「看到就要警惕」这一点上，两套机制完全一致。

3. 肌萎缩侧索硬化（渐冻症）

  • 表现：舌肌萎缩、肌束颤动（舌面上细小不规则的蠕动），构音不清、吞咽困难；延髓起病型以舌与咽喉症状首发。
  • 意义：舌肌束颤动是神经科查体的重要体征，需与震颤、生理性细颤鉴别。

4. 重症肌无力

  • 表现：说话、咀嚼、吞咽越久越费力，休息后好转；严重者舌面可见纵向三条沟（「三沟舌」）。C

5. 运动障碍类

  • 震颤：甲亢、焦虑、酒精戒断、原发性震颤、帕金森病等。
  • 迟发性运动障碍：长期服用抗精神病药等之后出现的舌、唇、面部不自主动作，如舌反复伸缩、舔唇、咀嚼样动作。

6. 灼口综合征

  • 表现：舌与口腔持续烧灼感，而黏膜外观正常，多见于围绝经期及绝经后女性。
  • 机制：多认为与神经病理性机制有关。
  • 意义：先排除营养缺乏、念珠菌、口干、义齿刺激、糖尿病、药物等继发原因。

六、睡眠与气道

1. 舌与阻塞性睡眠呼吸暂停

  • 睡眠时舌肌张力下降，舌根后坠，是上气道阻塞的重要机制之一。
  • 肥胖者舌内脂肪增多、舌体增大，与呼吸暂停严重程度相关A：Kim AM 等，Sleep 2014；减重后呼吸暂停改善，与舌脂肪减少关系密切A：后续研究，卷期待核。
  • 齿痕舌与睡眠呼吸暂停的关联有研究报道待核。

2. 麻醉与睡眠医学里的「看舌」C

  • Mallampati 分级：让患者坐位张口伸舌，按能看到的咽部结构分级，用来预测气管插管难度，也用于评估睡眠呼吸暂停风险。
  • 这是西医里「看舌」的一种特殊读法：读的不是舌的颜色和苔，而是舌与口腔、咽腔之间的空间比例。

3. 舌下神经刺激治疗C

对部分不能耐受持续正压通气的中重度阻塞性睡眠呼吸暂停患者，可植入舌下神经刺激器，在吸气时刺激颏舌肌使舌前伸、打开气道。这是「让舌头往前动一动」被做成治疗手段的例子。

七、口腔潜在恶性病变与肿瘤

1. 白斑

  • 表现：擦不掉、又不能被诊断为其他已知疾病的白色斑块。
  • 意义：属口腔潜在恶性病变，需要活检评估。舌腹、口底的白斑风险相对较高。

2. 红斑

  • 表现：鲜红色、天鹅绒样的斑块，不能归因于其他疾病。
  • 意义：虽比白斑少见，但癌变风险更高，必须活检。

3. 口腔扁平苔藓

  • 表现：白色网纹（Wickham 纹），可有糜烂、萎缩。
  • 意义：多为慢性病程，少数有恶变可能，需定期随访。

4. 口腔黏膜下纤维化

  • 表现：口腔黏膜苍白、变硬、出现纤维条索，张口逐渐受限；舌可变僵、乳头萎缩。
  • 机制：与咀嚼槟榔密切相关。
  • 意义：属口腔潜在恶性病变。槟榔（槟榔果）已被国际癌症研究机构列为一类致癌物。C在我国，湖南、海南、台湾等嚼槟榔习俗较盛的地区，这一问题尤其值得公众知晓。

5. 舌鳞状细胞癌

  • 好发部位：舌侧缘与舌腹，是口腔癌最常见的部位之一。舌根癌属口咽癌范畴，与人乳头瘤病毒感染的关系更为密切。
  • 危险因素：吸烟、饮酒（二者协同）、嚼槟榔、慢性创伤（残冠、不良修复体长期摩擦）、人乳头瘤病毒（舌根与口咽）。
  • 表现：两周以上不愈的溃疡，边缘隆起、质硬，或白斑、红斑、肿块；可伴疼痛、出血、耳痛、颈部淋巴结肿大、伸舌受限。
  • 意义：早发现、早活检是改善预后的关键。【A：美国家庭医师杂志综述指出舌部新生物通常需要活检，以区分良性病变与白斑、鳞癌】

九、警示信号（子站须醒目呈现）

出现以下任一情况，应尽快就医，而不是自行观察或按舌象调理：

  1. 舌部溃疡、白斑、红斑、肿块，两周以上不愈，或质地变硬、出血。
  2. 舌体突然肿大，伴呼吸、吞咽困难。
  3. 伸舌偏斜，尤其伴言语含糊、口角歪斜、肢体无力或麻木（脑卒中）。
  4. 单侧舌肌萎缩或伸舌偏斜，伴颈痛、头痛。
  5. 舌肌持续萎缩、肌束颤动，伴说话、吞咽逐渐困难。
  6. 儿童持续高热五天以上，伴草莓舌、眼红、皮疹、手足红肿（川崎病）。
  7. 舌与唇明显青紫，伴气促（低氧）。
  8. 舌面光滑发红伴乏力、面色苍白、手脚麻木（贫血或维生素 B12 缺乏）。

十、给子站的一句提要

西医的舌征图谱有一个很清楚的形状：大多数舌头上的「不一样」是良性变异，不必治；少数是营养、感染、系统病、神经病的指示灯，要顺藤摸瓜；极少数是肿瘤和急症，必须立刻处理。西医读舌的本事，在于把每一种表现精确地挂到一条具体的通路上。
