本编回答：从生理学、病理学看，舌头「看起来是什么样」由哪些过程决定？

这是和第 02 编（中医理论机制）平行的一编。整编标C，另注者除外。

编排方式是按「显露」的几个维度（颜色、苔、表面、大小与边缘、润燥、运动）逐一拆出背后的差异路径。

一、舌色：光、上皮、血三层的合成

肉眼看到的舌色，是光线穿过舌面上皮、被下方组织与血液吸收和散射之后，再反射回来的结果。它至少由三层叠加：

  1. 表层覆盖：舌苔的厚薄与颜色。苔厚则舌色被遮，看起来发白或发黄。
  2. 上皮层：上皮的厚度与角化程度。上皮厚、角化多，像磨砂玻璃，舌色偏淡偏白；上皮薄、乳头萎缩，像擦干净的玻璃，下方的血色透出来，舌色偏红偏亮。
  3. 血液层：黏膜固有层里毛细血管的密度、扩张程度、血流量，以及血中血红蛋白的浓度与氧合状态。

据此，西医对几类舌色的解释：

1. 偏淡偏白

  • 血红蛋白低（贫血）：透出的红色少。
  • 血管收缩：寒冷、休克、失血早期。
  • 上皮水肿增厚：透光性下降。

2. 偏红

  • 血管扩张、血流增加：发热、局部炎症、饮酒后。
  • 上皮变薄、乳头萎缩：萎缩性舌炎时，舌面光滑鲜红（牛肉样舌），这里的「红」不是血多，而是遮挡少。
  • 红细胞增多症：舌色可偏暗红。

3. 偏紫偏青

  • 去氧血红蛋白增多：中心性发绀。临床教学的一个经典要点是：看舌头能区分中心性发绀与周围性发绀。周围性发绀（手脚冰凉、局部循环慢）通常不累及舌；中心性发绀（心肺疾病致动脉血氧不足）舌与唇都发紫。
  • 静脉回流受阻、淤血：右心衰竭、上腔静脉阻塞等。
  • 某些药物或中毒（如高铁血红蛋白血症）也可使黏膜呈青灰色。

4. 偏黄

  • 黄疸时，胆红素沉积于组织，在舌下面、口底、软腭等黏膜较薄处最易看出，往往早于皮肤。
  • 舌背的黄多是苔色，与黄疸无直接关系。

小结：同一个「红」，可以是血多了，也可以是遮挡少了；同一个「白」，可以是血少了，也可以是遮挡多了。这就是为什么单凭舌色很难下结论，必须同时看表面有没有乳头、有没有苔。中医要求「舌色与舌形、舌苔合看」，在光学层面上正好对得上。

二、舌苔：生成与清除之差

1. 舌苔是什么A／C

现代口腔医学对舌苔成分的描述比较一致：丝状乳头间隙中堆积的脱落角化上皮细胞、细菌（以及少量真菌）、白细胞、食物残渣、唾液蛋白与黏液。C舌苔的菌群主要属于拟杆菌、梭杆菌、放线菌、厚壁菌等门类，其组成受宿主上皮提供的营养、唾液以及二者之间相互作用的塑造。A

2. 舌苔厚薄＝生成速度减去清除速度

这是理解一切舌苔变化的总公式。

生成的一侧：

  • 丝状乳头的角化物与上皮细胞不断脱落。
  • 细菌在乳头间隙这片「粗糙、潮湿、低氧」的环境里附着、繁殖，形成生物膜。
  • 唾液与龈沟液带来白细胞与蛋白质。
  • 进食留下残渣。

清除的一侧：

  • 咀嚼、说话、吞咽时，舌背与硬腭、食物之间的摩擦。
  • 唾液的冲刷。
  • 主动刷舌、刮舌。

凡是让清除变慢、或让生成变快的因素，都会使舌苔变厚：

因素作用方向例子
进食减少、流质饮食、鼻饲摩擦清除减少发热病人、术后病人、住院老人苔厚
唾液减少冲刷减少夜间睡眠、发热、脱水、张口呼吸、抗胆碱药、干燥综合征、头颈部放疗后
口腔卫生差、牙周病细菌负荷增加牙周炎患者舌苔量明显较大A：综述转述
吸烟角化与色素沉积、菌群改变苔偏厚偏黄灰
戴假牙、老年摩擦与唾液均减
广谱抗生素菌群失衡，真菌与产色菌过度生长黑毛舌、念珠菌感染

有研究专门考察了舌苔的相关因素（Van Tornout M 等，J Clin Periodontol 2013;40(2):180–185），也有研究测定过年轻人刮除舌苔后舌苔重新形成的速度（Chérel F 等，Int J Dent Hyg 2008;6(4):371–375）。A：题名与出处已见

日常生活里最贴切的比方是窗户上的雾。冬天早上擦掉窗户上的雾，过一会儿又起来了，因为屋里屋外的温差没变、屋里的水汽没变。刮舌苔也是这样：刮掉的只是「这一层」，生成和清除之间的那个差没变，一天之内苔就长回来。想让苔长期变薄，得改的是那个差——多咀嚼、多喝水、治牙周、戒烟——而不是一遍遍擦。

3. 为什么早上的苔最厚

一夜之间，人不进食、不说话，唾液分泌大幅减少，舌背与上腭的摩擦几乎停止，而上皮照常脱落、细菌照常繁殖。于是生成照旧、清除几乎为零，早晨舌苔最厚，口气也最重。早饭之后苔就薄了。中医教材里「晨起苔厚、食后苔薄」的生理变异，在这里得到了直截了当的机械解释。

4. 舌苔与口臭A

舌背，尤其是舌后部，被公认为口腔内源性口臭最主要的来源。厌氧菌分解舌苔中的含硫氨基酸（半胱氨酸、甲硫氨酸），产生硫化氢、甲硫醇等挥发性硫化物。代表性文献：

  • Yaegaki K, Sanada K. J Periodontal Res 1992;27(4 Pt 1):233–238：比较临床健康者与牙周病患者口气中的挥发性硫化物。
  • Seerangaiyan K, Juch F, Winkel EG. J Breath Res 2018;12(3):034001：综述舌苔的特征及其在口内源性口臭与全身健康中的作用。
  • 以数字舌诊系统比较口臭与非口臭患者的舌苔量：口臭组舌苔评分显著较高，舌后部差异更明显（韩国东医学杂志研究，65 例）。
  • 评估舌苔量的常用指数有 Winkel 舌苔指数（WTCI）、Shimizu 等提出的舌苔状态评价法（J Oral Rehabil 2007;34(6):442–447）。

5. 舌苔与老年吸入性肺炎A／待核

养老机构的口腔护理（包括清洁舌背）可以降低老年人肺炎的发生，这一结论最早的高影响证据来自日本的研究（Yoneyama T 等，Lancet 1999）。C也有研究把舌苔量作为无牙老年人吸入性肺炎的风险指标待核：具体文献。这条线说明：西医也在「读」舌苔，只不过读的是菌量与吸入风险，而不是证型。

三、舌面：乳头的萎缩、增生与伸长

1. 萎缩：舌面变光

舌上皮更新快，对制造新细胞所需的原料特别敏感。铁、维生素 B12、叶酸、核黄素（B2）、烟酸（B3）等缺乏时，上皮增殖受阻，先是丝状乳头变短消失，继而菌状乳头也萎缩，舌面变得光滑、发红、发亮，常伴烧灼感或疼痛。这就是萎缩性舌炎。A：美国家庭医师杂志综述列出上述营养素

其他原因：念珠菌感染、口干（干燥综合征）、乳糜泻、蛋白质能量营养不良、某些药物。

中医所说的「镜面舌」「光剥舌」，显露层面基本对应这里的乳头萎缩。

2. 增生：草莓舌

菌状乳头充血肿大，在白色苔或红色舌面上凸起如草莓籽。见于猩红热（先白草莓、后红草莓）、川崎病、中毒性休克综合征等。C

3. 伸长：毛舌

丝状乳头的角化物正常情况下不断脱落。若脱落受阻（软食、口干、口腔卫生差、吸烟、抗生素、某些药物），角化物堆积，乳头异常伸长，形如毛发，再被细菌、真菌、食物、烟草着色，呈黑、褐、黄、绿等色，即毛舌，最常见的是黑毛舌。【A：Schlager E 等 2017 年综述；药物诱发见 Thompson DF、Kessler TL 2010 年综述】

4. 游走性剥脱：地图舌

地图舌表现为舌背上一块块边界清楚的红色光滑区，周围绕以白色或黄色的微隆边缘，形如地图，位置和形状在数天到数周内不断变化。组织学上，红色区是丝状乳头脱失，边缘区是上皮内的中性粒细胞浸润与角化异常。确切病因不明，与遗传、银屑病、特应性体质、裂纹舌等有关联。C

四、舌体大小与边缘

1. 巨舌

  • 真性巨舌：肌肉肥大（肢端肥大症、Beckwith–Wiedemann 综合征），组织浸润（淀粉样变性、甲状腺功能减退时黏多糖沉积），血管淋巴管畸形。
  • 相对性巨舌：舌体大小正常而口腔容积小（如唐氏综合征）。
  • 急性肿大：血管性水肿（包括血管紧张素转换酶抑制剂相关的舌部血管性水肿）、外伤、感染、过敏。急性舌肿大可堵塞气道，属急症。

2. 舌内脂肪A

Kim AM 等（Sleep 2014;37(10):1639–1648）用磁共振三点 Dixon 成像比较了 31 名无睡眠呼吸暂停的肥胖对照与 90 名肥胖的阻塞性睡眠呼吸暂停患者，发现后者舌体更大、舌内脂肪比例更高，舌脂肪量与呼吸暂停严重程度及体重指数相关。同一团队后续研究发现，肥胖患者减重后呼吸暂停改善，与舌脂肪减少的关系最为密切。A：后续研究发表于《美国呼吸与危重症医学杂志》，具体卷期待核

3. 齿痕

舌边的齿痕是舌体被牙齿压出来的印子。它出现的条件是：舌体相对于牙弓内空间偏大，或舌体持续向外顶压。原因包括巨舌、舌体水肿、舌内脂肪增多、紧咬牙或磨牙、习惯性伸舌，以及睡眠中为保持气道通畅而舌体前顶等。齿痕舌与阻塞性睡眠呼吸暂停之间的关联已有研究报道【待核：Weiss TM 等 2005 年耳鼻喉头颈外科杂志论文】。

中医读齿痕为脾虚湿盛；西医读齿痕为「舌与牙弓的空间矛盾」的显露。两种读法并不互相排斥：一个讲整体水湿代谢，一个讲局部的空间与压力。

4. 裂纹

裂纹舌多数是发育性的良性变异，随年龄增长而更常见；可与地图舌并存，在唐氏综合征、梅尔克松—罗森塔尔综合征、银屑病中较多见；口干也会让舌面出现裂纹。裂纹深处易积食物与细菌，可引起异味与刺激。A：美国家庭医师杂志综述

五、润燥

舌面润燥主要取决于唾液的量与质，以及口腔水分的蒸发：

  • 唾液减少：脱水、发热、高血糖渗透性利尿、抗胆碱能药物、抗抑郁药、抗组胺药、利尿剂、干燥综合征、头颈部放疗。
  • 蒸发增加：张口呼吸、鼻塞、睡眠时张口、吸氧。

舌干在西医里是脱水的体征之一，但单独用它判断脱水，可靠性有限，需要与其他体征和化验一起看。C

六、运动

舌的运动由舌下神经、皮质脑干束、锥体外系与小脑共同调控，出问题时各有特征：

显露西医读法
伸舌偏向一侧，伴同侧舌肌萎缩、肌束颤动同侧舌下神经或其核的下运动神经元病变（颅底肿瘤、颈内动脉夹层、外伤、延髓病变等）
伸舌偏向一侧，无萎缩，伴对侧肢体瘫对侧皮质或皮质脑干束的上运动神经元病变（脑卒中等）
舌肌萎缩、肌束颤动，双侧延髓麻痹，典型见于肌萎缩侧索硬化（渐冻症）
舌体震颤（伸舌时细颤）甲状腺功能亢进、焦虑、酒精戒断、原发性震颤、帕金森病等
舌不自主蠕动、伸缩、舔唇迟发性运动障碍（长期服用抗精神病药等）、舞蹈症
舌无力、说话吃饭越来越费劲，休息后好转重症肌无力
舌体活动受限、说话含糊、吞咽难假性延髓麻痹、舌系带过短（儿童）

七、从全身到舌的七条通路（编者归纳）

把上面这些拆开来看，西医意义上「全身状况上显于舌」，大致走七条通路：

  1. 血液通路：血红蛋白量、氧合、血流 → 舌色。
  2. 营养通路：造血与上皮更新的原料 → 乳头的存亡、舌面的光与糙。
  3. 体液通路：唾液与水分 → 舌的润燥、苔的厚薄。
  4. 微生物通路：菌群的组成与负荷 → 苔的厚薄、颜色、气味。
  5. 神经通路：运动神经与中枢 → 伸舌方向、震颤、萎缩。
  6. 内分泌与沉积通路：激素、黏多糖、淀粉样物、脂肪 → 舌体大小、齿痕。
  7. 免疫与炎症通路：感染、自身免疫、过敏 → 草莓舌、地图舌、血管性水肿、扁平苔藓等。

这七条通路，每一条都是一条具体的、可以单独测量的差异路径。西医的长处是能把显露拆回到具体通路上；它的局限是，一旦显露同时由几条通路纠缠而成（比如「苔厚而黄腻、舌边齿痕、舌色偏暗」），就很难只用其中一条去解释。

八、给子站的一句提要

西医看舌象的形成，是拆开来看：颜色拆成光、上皮、血三层，舌苔拆成生成与清除之差，舌面拆成乳头的萎缩、增生与伸长，舌体拆成肌肉、浸润、脂肪、水肿，运动拆成神经通路的哪一段。拆得开的时候，它非常准；拆不开的时候，它往往就不再看了。
