总框架

`` 舌诊 ├─ 舌质（舌体） │ ├─ 舌神：荣／枯 │ ├─ 舌色：淡红／淡白／红／绛／青紫 │ ├─ 舌形：老嫩／胖瘦／肿胀／点刺／裂纹／齿痕／光滑 │ ├─ 舌态：痿软／强硬／歪斜／颤动／吐弄／短缩 │ └─ 舌下络脉：长度／粗细／颜色／分支 └─ 舌苔 ├─ 苔质：厚薄／润燥／腐腻／剥落／偏全／真假（有根无根） └─ 苔色：白／黄／灰黑（及少见的绿、霉酱等） ``

正常舌象的教材口径：淡红舌，薄白苔。展开说，就是舌色淡红而鲜明润泽，舌体柔软、大小适中、运动灵活，舌苔薄白、颗粒均匀、干湿适中、紧贴舌面、揩之不去。C

一、舌色

1. 淡红舌

  • 表现：舌色淡红，红中带白，润泽。
  • 形成：气血充足，上荣于舌。
  • 意义：正常舌色；也见于外感表证初起、病情轻浅者。
  • 辨析：淡红舌不等于「没病」，只说明气血尚未受到明显影响。

2. 淡白舌

  • 表现：比正常舌色浅淡，白多红少。舌色白而几乎无血色者，称「枯白舌」。
  • 形成：气血不足，舌失充养；或阳气虚衰，运血无力、寒凝血脉。
  • 意义：主气血两虚、阳虚。
  • 辨析：
  • 淡白而瘦薄：偏气血两虚。
  • 淡白而胖嫩、边有齿痕、润滑：偏阳虚水湿内停。
  • 枯白无华：脱血夺气，病情危重。

3. 红舌

  • 表现：比正常舌色红，甚至鲜红。
  • 形成：热盛致气血沸涌，舌体脉络充盈；或阴虚火旺，虚火上炎。
  • 意义：主热证，包括实热与虚热。
  • 辨析：
  • 舌鲜红而起芒刺，或兼黄厚苔：实热。
  • 舌红而少苔、有裂纹，或光红无苔：阴虚内热。
  • 舌尖红：心火上炎。
  • 舌边红：肝胆有热。

4. 绛舌

  • 表现：较红舌颜色更深，或略带暗红。
  • 形成：热入营血，耗伤营阴，血液浓缩而瘀滞；或阴虚火旺日久。
  • 意义：外感热病中主热入营血；内伤杂病中主阴虚火旺。
  • 辨析：
  • 绛而有苔：多属温热病热入营血或气营两燔。
  • 绛而少苔或无苔，或有裂纹：阴虚火旺。
  • 绛而晦暗，或有瘀点：兼血瘀。
  • 经典依据：「热传营，舌色必绛」（叶天士）。B

5. 青紫舌

  • 表现：全舌呈均匀青色或紫色，或局部现青紫斑点。淡紫、绛紫、青紫、紫斑紫点等。
  • 形成：气血运行不畅，血脉瘀滞。
  • 意义：主气血瘀滞。
  • 辨析：
  • 淡紫或青紫而湿润：阴寒内盛，阳气不宣，血行凝滞；或阳虚。
  • 绛紫而干枯少津：热毒炽盛，津液受伤，血行壅滞。
  • 舌有紫斑紫点：瘀血阻滞于局部，或局部血络损伤。
  • 舌淡紫暗：气虚血瘀或阳虚寒凝。

二、舌形

1. 老舌与嫩舌

  • 老舌：舌质纹理粗糙或皱缩，坚敛而不柔软，舌色较暗。主实证。
  • 嫩舌：舌质纹理细腻，浮胖娇嫩，舌色浅淡。主虚证。
  • 辨析：老嫩是判断虚实的首要形态指标。邪气亢盛，正气未衰，邪正交争，舌多坚敛苍老；气血不足，舌体脉络不充，或阳气亏虚，运血无力、水湿不化，舌多浮胖娇嫩。

2. 胖大舌

  • 表现：舌体比正常舌大而厚，伸舌满口。
  • 形成：水湿内停，痰湿热毒上泛。
  • 意义：主水湿、痰饮。
  • 辨析：
  • 淡白胖大：脾肾阳虚，津液不化。
  • 红胖大而苔黄腻：脾胃湿热或痰热内蕴。

3. 肿胀舌

  • 表现：舌体肿大，甚者塞满口腔，不能闭口，缩回困难。
  • 意义：多属热毒、酒毒上壅，或中毒致血液凝滞。
  • 辨析：与胖大舌不同，肿胀舌多见于急症，舌色多鲜红或青紫。临床上须警惕血管性水肿、过敏、中毒等急症（见第 08 编）。

4. 瘦薄舌

  • 表现：舌体比正常舌瘦小而薄。
  • 形成：气血阴液不足，不能充养舌体。
  • 意义：主气血两虚、阴虚火旺。
  • 辨析：
  • 瘦薄而色淡：气血两虚。
  • 瘦薄而色红绛干燥：阴虚火旺，津液耗伤。

5. 点刺舌

  • 表现：点，指蕈状乳头肿胀或高突，呈红色、白色或黑色星点；刺，指舌乳头增生、肥大，高起如刺，摸之棘手，又称「芒刺」。
  • 意义：主脏腑热极，或血分热盛。
  • 辨析：
  • 点刺多见于舌尖：心火亢盛。
  • 舌中见点刺：胃肠热盛。
  • 舌边见点刺：肝胆火盛。
  • 点刺颜色越深、越密，热越重。

6. 裂纹舌

  • 表现：舌面上出现各种形状的裂纹、裂沟，深浅不一，多少不等，形如「人」「川」「爻」「井」字等。
  • 形成：阴血亏损，不能荣润舌面；或脾虚湿侵。
  • 意义：主阴血亏虚、热盛伤津、脾虚湿侵。
  • 辨析：
  • 舌红绛而有裂纹：热盛伤津，或阴虚液涸。
  • 舌淡白而有裂纹：血虚不润。
  • 舌淡白胖嫩、边有齿痕而有裂纹：脾虚湿侵。
  • 先天性裂纹：健康人也可见，裂纹中多有舌苔覆盖，身体无其他不适。中医教材明确把它排除在病理舌象之外。这一点与西医「裂纹舌属良性变异」的判断一致（见第 08 编）。

7. 齿痕舌

  • 表现：舌体边缘见牙齿压迫的痕迹。
  • 形成：舌体胖大而受齿缘压迫；或舌体不胖而有齿痕，属舌质嫩、气血不足。
  • 意义：主脾虚、水湿内盛。
  • 辨析：
  • 舌淡胖大而润、有齿痕：寒湿壅盛，或阳虚水湿内停。
  • 舌淡红而有齿痕：脾虚或气虚。
  • 舌红而肿胀满口、有齿痕：湿热痰浊壅滞。
  • 舌体不胖而有轻微齿痕：可见于正常人，或属先天。
  • 西医对照：齿痕舌（scalloped tongue）在西医里与巨舌、磨牙、夜间舌体后坠、阻塞性睡眠呼吸暂停等有研究关联（见第 07、08 编）。

8. 光滑舌（镜面舌）

  • 表现：舌面光洁如镜，无苔，甚至舌乳头萎缩。
  • 意义：胃气将绝、胃阴枯竭。
  • 辨析：
  • 淡白而光莹：脾胃损伤，气血两亏。
  • 红绛而光莹：水涸火炎，胃肾阴液枯竭。
  • 西医对照：舌乳头萎缩、舌面光滑，西医称萎缩性舌炎，常与铁、维生素 B12、叶酸、核黄素、烟酸缺乏等相关（见第 08 编）。这是两套机制在「显露」层面对得最整齐的一处。

三、舌态

1. 痿软舌

  • 表现：舌体软弱，无力屈伸，痿废不灵。
  • 意义：气血俱虚、阴液亏损，筋脉失养。
  • 辨析：
  • 久病舌淡而痿：气血俱虚。
  • 新病舌干红而痿：热灼津伤。
  • 久病舌绛少苔而痿：阴亏已极。

2. 强硬舌

  • 表现：舌失柔和，屈伸不利，或板硬强直，不能转动，常伴语言謇涩。
  • 意义：热入心包、高热伤津、风痰阻络。
  • 西医对照：舌强、言语不清在西医里需要首先排除脑卒中等中枢神经急症（见第 08 编）。

3. 歪斜舌

  • 表现：伸舌时舌体偏向一侧。
  • 意义：多见于中风或中风先兆，属肝风夹痰或痰瘀阻滞经络。
  • 西医对照：伸舌偏斜是神经科查体的标准项目，偏向的方向可以帮助区分上、下运动神经元病变（见第 06、08 编）。

4. 颤动舌

  • 表现：舌体震颤抖动，不能自主。
  • 意义：肝风内动。可因热盛、阳亢、阴亏、血虚所致。
  • 辨析：
  • 久病舌淡白而颤动：血虚动风。
  • 新病舌绛而颤动：热极生风。
  • 舌红少津而颤动：阴虚动风、肝阳化风。
  • 西医对照：舌震颤可见于甲亢、帕金森病、酒精戒断、焦虑等；舌肌束颤动（细小不规则的肌纤维抽动）是下运动神经元病变的体征，与震颤不同（见第 08 编）。

5. 吐弄舌

  • 表现：舌伸于口外，不即回缩，称吐舌；伸舌即回缩，或反复舐唇，称弄舌。
  • 意义：心脾有热。吐舌可见于疫毒攻心或正气已绝；弄舌多为动风先兆，或见于小儿智能发育不全。

6. 短缩舌

  • 表现：舌体卷短、紧缩，不能伸长，严重者舌不抵齿。
  • 意义：多属危重证候。可因寒凝筋脉、痰浊内阻、热盛伤津或气血俱虚。

四、舌下络脉

  • 观察方法：患者张口，舌尖上卷抵上腭，舌体自然放松，使舌下络脉充分显露。先看络脉的长短、粗细、颜色，有无怒张、弯曲、分支，再看周围细小络脉的颜色、形态，有无紫暗的珠状结节和紫色血络。C
  • 正常：络脉颜色淡紫，隐现于舌下，管径不粗，长度一般不超过舌尖至舌下肉阜连线的五分之三，多为单支、少分支。C：教材亦有给出管径参考值者，具体数值待核
  • 异常：
  • 络脉细而短、周围小络脉不明显、舌色偏淡：气血不足。
  • 络脉粗胀，或呈青紫、紫红、绛紫、紫黑色，或周围小络脉曲张如网、呈紫色珠状结节：血瘀。
  • 西医对照：舌下静脉曲张（sublingual varices）在老年人中常见，研究者探讨过它与年龄、吸烟、心血管疾病的关联待核：具体研究。

五、苔质

1. 薄苔与厚苔

  • 判断标准：透过舌苔能隐约见到舌体的为薄苔（「见底」）；不能透过舌苔见到舌体的为厚苔（「不见底」）。
  • 意义：
  • 薄苔：正常，或外感表证初起、病邪轻浅。
  • 厚苔：邪气入里，或内有痰饮、湿浊、食积。
  • 动态：苔由薄转厚，病邪由表入里、病情由轻转重；由厚转薄，正气渐复、病邪渐退。

2. 润苔与燥苔

  • 润苔：舌面润泽，干湿适中。正常，或病中津液未伤。
  • 滑苔：舌面水分过多，扪之湿滑，甚至伸舌欲滴。主寒、主湿。
  • 燥苔：舌面干燥，扪之无津，甚至干裂。主津液已伤。
  • 糙苔：苔质粗糙如砂石，扪之糙手。多为热盛伤津之重症。
  • 辨析：燥苔也可见于阳气被阴邪所遏、不能上蒸津液者，这时燥苔并非津亏，需结合其他征象。

3. 腻苔与腐苔

  • 腻苔：苔质颗粒细腻致密，融合成片，如涂有油腻之状，中间厚、边周薄，紧贴舌面，揩之不去，刮之不脱。主湿浊、痰饮、食积。
  • 腐苔：苔质颗粒疏松，粗大而厚，形如豆腐渣堆积舌面，边中皆厚，揩之易去。主食积胃肠，或痰浊内蕴；也见于内痈。
  • 脓腐苔：舌上黏厚一层，有如疮脓。多见于内痈或邪盛病重。
  • 辨析：腻苔是阳气被阴邪所遏，湿浊内蕴；腐苔多是阳热有余，蒸腾胃中秽浊之邪上泛。

4. 剥落苔

  • 表现：舌苔全部或部分脱落，脱落处光滑无苔。
  • 分型：
  • 花剥苔：舌苔多处剥落，剥落处光滑无苔，余处残存舌苔。
  • 地图舌：舌苔不规则大片剥落，边缘凸起，界限清楚，形似地图，部位时有转移。
  • 类剥苔：剥落处并不光滑，似有新生颗粒。
  • 镜面舌：舌苔全部剥落，舌面光滑如镜（同上文光滑舌）。
  • 意义：胃气不足、胃阴枯竭或气血两虚。
  • 西医对照：地图舌在西医里是良性游走性舌炎，属最常见的舌部良性变异之一（见第 08 编）。这是两套机制在同一个显露上判断分歧最大的一处，值得在第 10 编专门讨论。

5. 偏苔与全苔

  • 全苔：舌苔遍布舌面。主邪气散漫，多为湿痰阻滞中焦。
  • 偏苔：舌苔仅布于舌的某一局部。依所在部位推断病位（参照舌面分区）。

6. 真苔与假苔（有根苔与无根苔）

  • 真苔：舌苔紧贴舌面，似从舌里长出，刮之难去，刮后仍留苔迹，不露舌质。为有根苔，说明胃气尚存。
  • 假苔：舌苔不紧贴舌面，似涂在舌上，刮之易去，刮后无垢而舌质光洁。为无根苔，说明胃气已衰。
  • 意义：辨苔之真假，以判断病情轻重与预后。

六、苔色

1. 白苔

  • 意义：常见，主表证、寒证、湿证。正常舌苔亦为薄白苔。
  • 辨析：
  • 薄白而润：正常，或表证初起。
  • 薄白而干：表证而津液已伤。
  • 白厚腻：湿浊内困，或痰饮、食积。
  • 白厚而干：湿浊中阻，津液不布，或痰浊化热伤津。
  • 苔白如积粉，扪之不燥（积粉苔）：多见于瘟疫或内痈，为秽浊湿邪与热毒相结。
  • 苔白燥裂如砂石，扪之粗糙（糙裂苔）：热极津伤，湿病化燥。

2. 黄苔

  • 意义：主热证、里证。苔色越黄，热邪越重。淡黄为热轻，深黄为热重，焦黄为热结。
  • 辨析：
  • 薄黄苔：邪热未甚，或风热表证，或风寒化热入里。
  • 黄滑苔：阳虚寒湿之体，痰饮聚久化热；或气血亏虚，复感湿热。
  • 黄腻苔：湿热蕴结，痰饮化热，或食积热腐。
  • 黄燥苔、黄焦苔、黄糙苔：邪热伤津，燥结腑实。
  • 白黄相兼：外感表证处于化热入里、表里相兼阶段。

3. 灰黑苔

  • 灰苔与黑苔同类，灰苔即浅黑苔。多由白苔或黄苔转化而来。
  • 意义：主阴寒内盛，或里热炽盛。
  • 辨析关键在润燥：
  • 灰黑而润滑：阳虚阴寒内盛，或痰饮内停。
  • 灰黑而干燥甚至焦裂起刺：热极伤阴。
  • 苔色越黑，病情一般越重。
  • 西医对照：黑苔需与黑毛舌（抗生素、吸烟、口腔卫生、某些药物诱发的丝状乳头延长与色素沉积）以及食物、药物染色鉴别（见第 04、08 编）。

4. 少见苔色C

  • 绿苔：多由白苔转化而来，主湿热或瘟疫。
  • 霉酱苔：红中发黑，又带黄色，似霉酱。多见于宿食湿浊积久化热，或湿热夹秽浊。《舌鉴辨正》中专列「霉酱舌」三条。A

七、舌质与舌苔的综合判读C

单项舌象只是字母，临床判读靠的是拼写。教材给出的几条综合原则：

  1. 舌质与舌苔变化一致：提示病机单纯，判断比较容易。比如舌红苔黄而干，是实热；舌淡苔白而润，是虚寒。
  2. 舌质与舌苔变化不一致：提示病机复杂，需要分别分析。比如舌淡白而苔黄腻，常见于脾胃虚寒而湿热内蕴，或阳虚之体复感湿热；舌红绛而苔白滑腻，常见于外感热病营分有热而气分有湿。
  3. 舌质偏重反映正气与脏腑，舌苔偏重反映邪气与胃气。二者合看，才能兼顾标本。

八、给子站的一句提要

中医舌象分类的骨架很清楚：舌质分神、色、形、态，舌苔分质、色，再加舌下络脉。真正难的不在骨架，而在拼读：同一个颜色要和形态、润燥一起读，同一个形态要看它是新病还是久病。这套分类本身就预设了「组合读法」——单个舌象几乎从不单独说话。
