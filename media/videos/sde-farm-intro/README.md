## 旁白脚本

**开场**（0.6s 起）  
世界不是被发现的，而是发生的。今天，我们走进一座农场，讲SDE本体论入门。

**E · 土壤**（8.8s 起）  
先看土壤。泥土、雨水、阳光、种子、农人的经验，彼此缠绕。这就是E，纠缠网络，一切发生的土壤。

**D · 农时**（18.1s 起）  
再看农时。翻地、播种、浇水、除草，看长势，再调整。一次次比较、试探、修正，这就是D，差异序列。

**S · 麦浪**（27.0s 起）  
到了秋天，田里显露出一片金黄的麦浪。这就是S，显露。注意，S是显露，不是一个现成的结构。

**公式**（35.4s 起）  
合起来一句话：在E中，经D，成S。

**123原理 · 大旱**（38.6s 起）  
可大旱一来，土壤和老办法起了矛盾。农人改种耐旱的谷子，新庄稼又反过来养了土壤、改了农时。矛盾推动显露，显露回写土壤和路径，循环不止。

**收尾**（52.8s 起）  
所以，麦子不是从地里被发现的，是在土里发生的。这，就是SDE本体论的第一课。

## 说明

旁白是离线 AI 合成的标准普通话女声（标贝 Baker 播音员语料训练的 Matcha-TTS 模型，经 sherpa-onnx 运行；字母读作 S=艾斯、D=低、E=伊），并非王德生本人声音。重新生成配音：`python3 src/build_audio.py 1.0`（需下载 matcha-icefall-zh-baker 与 vocos-22khz-univ 模型）。若换成本人录音：按上面脚本录一条约 60 秒音频，替换音轨即可（`ffmpeg -i sde-farm-intro.mp4 -i 本人录音.wav -map 0:v -map 1:a -c:v copy -c:a aac out.mp4`），字幕时间可能需微调。
