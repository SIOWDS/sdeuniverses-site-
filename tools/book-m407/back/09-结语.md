# 结语　每一个公式都是一道被刻进世界的痕

又是一个夜里。

林晓雯在长沙的家里，把那支电子体温计从抽屉里拿出来，擦了擦，放回原处。额温枪还躺在旁边。朵朵早就退了烧，这会儿睡得很沉，一只脚伸在被子外面。陈屹在客厅收拾白天没洗完的碗。

这本书是从那支体温计开始的。那天夜里，女儿额头发烫，陈屹的额温枪先说了 37.4。她把电子体温计夹进孩子腋下，一分多钟后“嘀嘀嘀”，屏幕上跳出 38.6。两个数摆在灯下，差了一度多。

本书在前言里问过两句：到底哪个是真的？那个 38.6，是谁的符号？

走完二十二章，可以回答得完整一点了。

屏幕上停住的那个数，是现实自己沉下来的痕。感温元件被体热改变了电阻，读数停在一个位置，不需要任何人去解释，它就立在那里。额温枪的 37.4 也是这样立住的，只是它够到的是额头皮肤的热，孩子打寒战、皮肤血管收紧的时候，就偏低。两个读数都是真的痕，回答的不是同一个问题。

她读出那个数字，说出“发烧了”，这是理念那一边的事。“体温”“摄氏度”“正常值”，这些都不是感温元件自己长出来的。它们背后，是华伦海特、摄尔修斯那一代人的温标之争，是一代代医生把千百次测量整理成的“正常范围”，是一套把冷热刻进数字的约定（见第 8 章）。

还有第三样东西。她手一摸孩子额头，就知道“不对”。那是做了五年母亲、做了十来年药剂师，身上沉下来的东西，比两台仪器都快一步。这是一个自我符号。

那天夜里，三样东西在一块小小的屏幕上相会了。

本书说的“科学”，就是让这三样东西反复对账的一套办法。

手的感觉说“烫”，额温枪说 37.4，腋下说 38.6，书上说“正常是多少”。几样对得上，人就踏实，什么也不用想。那天夜里偏偏对不上，林晓雯才开始问：是额温枪坏了，是量的位置不对，还是这次的病不一样？她没有扔掉哪一个数，想通了额温为什么偏低，四点四十又量了一遍：腋下 37.5，额温 37.3，两个数挨近了。那一度多的差，是在一次次重量里被收住的。

科学也是这样走过来的，只是把这一问做成了一种制度。

实验，是有意把一个想法推到读数面前，让它有机会对不上（第二编）。

仪器，是把看不见、摸不着的东西变成可读的痕：望远镜里的卫星，温度计里的那个读数，探测器里的一道闪光（第三编）。

记号与单位，是把想法刻进现实：一个等号，一个公式，一根米尺，一个用自然常数定下来的千克（第四编）。共同体，是托住这些痕的网：期刊、评审、复现、学派（第五编）。这一切都要付能量（第六编）。忘了它们是怎么来的，就会把它们供起来（第七编）。

所以，书名里的“被刻进世界的公式”，说的不是一个比喻。

一个公式，最初是某一次对不上逼出来的。它在一个人的草稿纸上成形，在一群人的争论里站稳，被写进教科书，被造进仪器，被做成桥梁、卫星和药片。到了这一步，它已经不只在人的脑子里。它刻在了钢筋的截面上，刻在了导航卫星的时钟修正里，刻在了一片退烧药的剂量里。

这就是本书说的回写：一个理念上结晶出来的东西，反过来改写了现实的样子。

林晓雯自己就天天站在这样的痕旁边。她在社区医院的药房里配药，药盒上印着“按体重每公斤多少毫克”，说明书上写着“每次间隔不少于几小时”。这些数字背后，是一次次临床试验、一回回不良反应的报告、一版版修订的指南。每一个数字，都是某一次对不上被收住以后留下来的。

她给病人发药时，那些数字已经不需要她再去推导。它们稳定、整体、能带走，从实验室一路走到了长沙一个社区药房的柜台上。可她也知道，说明书隔几年就会改一次，有的剂量调了，有的禁忌加了。数字站得稳，不等于它不会再动。

那支体温计本身，也是一道痕。几百年前，冷和热只是手上的感觉，每个人说的“烫”都不一样。后来有人把液体封进玻璃管，有人在管上刻下刻度，有人争论零度该定在哪里，一百度又该定在哪里。今天她手里那支几十块钱、一分钟出结果的电子体温计，是那根玻璃管的后代，装着好几代人的对不上与争吵。林晓雯那天夜里不需要知道这些，它就在她手里稳稳地工作。

每一个公式，都是一道这样的痕。

痕是实的。踩出来的小路能走人，刻进现实的公式能造桥、能治病、能把人送上天。本书从来不说科学是“随便怎么说都行”。结晶有三条判据：稳定、整体、独立。科学事实是经过千百次对账、付了巨大代价才站住的东西，它值得尊重。

痕也不是终点。河道会改，小路会荒，公式也会在新的对不上面前熔开，再结晶一次。牛顿的公式没有被丢掉，它在新的框架里找到了更准确的位置。科学的可贵，不在于它的每一道痕都永远不变，而在于它肯让自己的痕被重新检验。

本书对自己也是这样要求的。第 22 章写下了它在什么情况下会错。三条是：若重大科学概念的诞生找不到任何可事前指认的反常，若仪器与记号的革新与理论变化无关，若无共同体之场的结晶能长期稳定。这本书本身，也只是一道等着被重新检验的痕。

全书的判词，到这里可以再念一遍：科学的力量不在于它找到了现成的真理，而在于它把“对不上”变成了一种制度。

林晓雯不是科学家。可是那天夜里，她做的事和科学家没有两样：她不只信自己的手，也不只信那个数字，她让两样东西互相对一对。对得上，她就照着做；对不上，她就再量一次，或者带孩子去医院。

这份不肯只信一边的习惯，就是科学留给普通人最好的东西。

它不要求你懂麦克斯韦方程组，也不要求你去过大科学装置。它只要求一件小事：当手上的感觉和纸上的数字合不拢时，别急着把其中一样扔掉。先让它们对一对，再看是谁该改。

下一次你拿起一支体温计、一张化验单、一个手机里跳出来的数字，可以停一秒想一想：这道痕是怎么被刻下来的？它和你身上的感觉对得上吗？对不上的时候，你愿意多问一句吗？

那一问，就是科学在你身上又发生了一次。
