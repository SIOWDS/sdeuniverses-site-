# 前言

这本书起于一个反复出现、却总被归错了因的经验：伤痛往往不出在秩序失灵的时候，而出在秩序最尽职的时候。一位治疗师翻开病历，诊断书上的那行字替他完成了对来访者的全部认识；一位药企副总裁坐在评审桌前，用自己亲手设计的、最合理的流程，投票终止了一个他由衷看好的研究方向；一所学校把误差、冗余与亏损一项项压到最低，三十年后发现教师已经不会偏离教案半步。没有人做错什么，每一个环节都在正确地运转，可那个被服务的活物——病人、项目、学生、手艺、判断——却在这种正确里一点一点地挨饿。

2026 年夏天，我在 SDE Universes 学员专栏陆续写下了一批论文，分别处理诊断、审计、排名、司法、饮食知识、农耕文明、因果认知、语言学习、社会修复与算法时代的选择。写的时候，每一篇都在为一种具体的失效命名，并逼自己写出能让这个命名失效的条件。直到把其中十五篇放在一起重读，我才看清它们其实在追同一个东西：不是秩序太多，而是秩序独大——它独占了“什么算数”的裁量权，把尚未成形的差异与活的关系关在了门外。这个判断的形成，得益于王德生老师的指导。他读完这十五篇后指出，诸篇所写的伤痛，根子在于秩序被当成唯一正当的状态，混沌与承接被压了下去，差异与关系因此失去了进入的能力。这一句话成了全书的脊梁。

因此，这本书不是论文汇编。十五篇旧作在这里被拆开、重写、重新排列，按照秩序独大在一个活的过程中掐断的三处位置组织起来：第一编写差异怎样进不来，第二编写结论怎样被封口，第三编写成功怎样反过来清走了底子里的关系。第四编转向另一面：先写秩序失手的破口处，新东西怎样挤进来；再写一个旧作里没有回答的问题——门是否只能等崩溃来撞开，还是秩序可以自己留下一道承接之门。最后这一章是新写的，也是全书试图往前多走的一步。

全书不反对秩序，也不反对效率。没有秩序，任何差异都无法被保存、被比较、被传下去；书中每一处诊断都预先写明了它在什么经验情形下应当被放弃。我希望读者把这本书当作一把需要被检验的刀，而不是一张已经画好的地图。若有一天，人们在秩序很强的地方照样看见差异自由出入、活物安然生长，那正是这本书最乐于接受的反驳。

胡志英
2026年11月
