# 第18章　关为什么撤不掉

## 梯子没有往上搬

例会过去一个星期，老卢在走廊里叫住秦岚，说他想了一晚上，觉得还是该把要求提一提：硕士优先，项目经历和量化成果写成必备项。他说这是老办法了，水涨了，船就得高，行业里都这么干。秦岚没有立刻反驳。老卢说得对，这确实是老办法，而且在很长一段时间里管用。上一代人本科就够了，后来要硕士，再后来要名校硕士，每往上加一级，总有一批人上不去，分辨就在这一级上发生了。

这个办法为什么管用，要想一想。同一张证书，有人拿起来轻松，有人拿起来吃力；肯下苦功、基础好的人，付的代价小，别人付的代价大，甚至付了也拿不到。证书本身不说明什么，它们背后那个“代价不一样”，才让一张证书有了分辨的力气。所以一个信号用滥了，大家就去找一个更贵的，把代价的差距重新拉开，梯子就又往上接了一节。

今天的难处在于，这一回降下去的不是某一种证书的难度，是弄出一份像样的证据这件事本身。写一份对得上岗位的简历，做一份看着专业的方案，把经历整理成带数字的成果，这些工夫对所有人一起降到了很低，而且差不多是同一个比例。小禾和她那个基础更好的同学，改简历花的时间都是几分钟，谁也没比谁轻松多少。代价的差距没有了，新加的任何一级，都还没站上去就被踩平了。秦岚没有拿老卢的建议去试。她估计，规则写进岗位说明没几天，论坛上就会有人把它拆成一句话，工具里就会多一个选项，她女儿那几十版简历就是这么来的。

老卢不服气，说那硬条件里的学历，不也是一年一年往上提的吗，那一道不是还好好地拦着人？秦岚想了想，说那一道拦得住，是因为学历是别的机构发的，不是申请人自己写得出来的，发它的学校要为它担着名声。你要加的项目经历和量化成果，是申请人自己写上去的，写的人不用担任何人的名声。同样是往上提一级，一个别人写不出来，一个自己就能写。老卢没有再说什么，他回办公室，过了一会儿又走回来，说你这话我得想想。

我们可以用梯子来想。以前加一级，像是在梯子上多接一截，爬不上去的人会在这一截掉下来，梯子还是梯子。现在的情形是，每一截木头在你踩上去以前，已经被人踩成了平地。设一道新的、申请人自己就能写出来的关，它从设下的那一天起，就走在饱和的路上。这是这本书对资格越抬越高那种常见说法的一处不同意见：那种说法认为分辨会往上搬一级，这本书的推断是，在这类关口上没有梯子可搬，分辨是整个离开了。

分辨没有消失。岗位还是只有一两个，总要从两千份里选出一两个人，选的办法总是有的。秦岚那天晚上翻了去年她手上这七个岗位录用的十二个人的面试记录，翻着翻着发现了一件事：最后一轮拍板的那几句话，十二份里有七份提到了某个认识的人，“他以前的老板我知道”“老贾说这个人在车间待得住”“内部同事推荐的”。这些话没有写进任何一道关，没有一道关为它留过栏位。起作用的那一下分辨，发生在一个不留记录的地方。这是我们给她编的数，用来说明方向。搬去了哪里、要付什么代价，第20章细说。这里先记住一件事：分辨没有往上搬一级，它整个离开了那些可以写下来、别人拿起来就能读的地方。这样的关口，学名叫可读门槛，它们整体失去了分辨力，是这一编要讲的判断。

## 谁加的，谁能撤

第二天秦岚做了一件她以前没做过的事，她想把关键词那一道关掉看看。她问小范能不能关，小范说技术上点一下就行，可是这是集团统一的配置，要走变更单。变更单要六个人会签：集团信息部门、信息安全、法务、合规审计、人力总监，还有用人部门。她把单子填了。第三天，法务回了一句话，问取消筛选之后，将来如果有人问起公司为什么不对简历做任何筛选，由谁来答复。合规审计要她补充这道关设立的依据。

她翻出来才发现，这道关最早是五年前系统上线时，供应商留下的默认设置，没有人专门批过；一年半以前，她自己申请加严过一次，理由写了三行：申请量上升，需提高筛选效率，一个星期就批下来了。加严要一个理由，一个星期。撤掉要六个人签字，而这张单子的理由栏里，她只能如实写：这一道关最近一年几乎没有区分过任何人。写下这句话，等于承认这道关过去几年一直在空转，而每个会签的人都要在这句话下面签上自己的名字。没有人反对她，法务和审计问的都是该问的问题，可是每个人都有理由先放一放。变更单在合规那里停了三个星期，她没有再催。

这样的关，我们叫它没有作者。作者不是定标准的人。标准是有人定的，岗位说明有人写，系统配置有人批。作者是另一个位置：一个有权宣布这道关作废或者改写，并且要为这个决定担后果的具体的人。加一道关只需要一个理由，废一道关需要一个授权，而不少单位只有前一半的办法，从来没有造过后一半。所以关越积越多，没有一道是谁的错。

这样的事不止发生在秦岚的公司。一份招聘公告上的资格要求，几年前有人写了“三年以上相关经验”，现在谁能站出来说，这一条已经不分出任何人了，删掉？写这一条的人也许早已调走，当年批它的人也许换了岗位，今天的人事部门只是照着去年的公告改个日期。要加一条，只要说得出一个理由，别人听了点头就行。要删一条，得有人担得起“万一删错了”的后果，而没有人愿意担，因为这一条留着的时候，从来没有出过事。留着的代价是分散的，每个人都付一点点，没有人看得见；撤掉的风险是集中的，一旦出了岔子，名字就写在单子上。

要看清作者是什么，不妨看一个有作者的例子。小舟他们月考，数学卷子里有一道选择题，全班都做对了，数学老师改完卷子在备课组会上说，这道题不分人，下回换掉。这件事轻轻松松就办成了，因为这张卷子有一个人对它负责：出题的老师有权换，也得为题目好不好担着。心理测量里早就有这个办法，一道所有人都答对的题，区分度是零，该从题库里剔掉，总有一个考务方来做这件事。秦岚公司的关键词关和这道月考题，在账上长得一模一样，都是人人通过，区别只在于一个有人管，一个没人管。

## 四种关，和最危险的一种

把关放在两根轴上看，会清楚一点，这是这一章用来讲清楚空关的一张工具。一根轴是这道关还拦不拦人，另一根轴是有没有一个位置有权宣布它作废，并为此负责。交叉起来是四种：

| | 有人管 | 没人管 |
|---|---|---|
| 还在拦人 | 正常的关：拦得对不对有人负责，错了有人改 | 没人管的老规矩：还在拦人，也许拦错了，可是没人能改它 |
| 已经不拦人 | 已发现失灵的关：有人量出来了，正在换或者撤，月考那道全对的题就在这里 | 空关：不拦任何人，也没有谁有权撤它 |

第二格也是个麻烦，比如一条几年前定下的年限要求，还在挡掉不少人，可是谁也不记得它当初为什么定，也没有人敢动。你可以拿手边的一道关，自己放进这张格子里试试。孩子学校门口查校牌，保安天天查，出了岔子有人担责，大概在第一格。单位里一条“报销必须附三张发票”的老规定，有人嫌烦有人嫌重复，可是问起来，谁也不知道能找谁改，它多半在第二格。至于填表时那些必填却谁也不看的栏目，有人看着觉得多余，却又不知道自己算不算有资格说它多余，那往往在第四格，只是没人去数过。放进去以后你会发现，第四格里的东西最难认，因为它不惹麻烦，你甚至会觉得它是个好制度。这也是为什么这一章不急着给办法。办法要等你先看清楚自己手里这道关站在哪一格，站错了格子，用对的办法也会白用，比如把一道空关当成正常的关去“加强管理”，只会让它更精细地继续空着。

但这一章要打的是第四格，空关。它不是最难看的一格，恰恰相反，它是看起来最没有问题的一格。第一个原因，它在短期的指标上看起来是改善。一道从不拒绝的关，在报表上只会留下几个数：通过率高，处理得快，退回重做的少，没有人投诉。这几个数放在任何一套流程评价里都是好数，通常被读成“来的人质量提高了”“流程很顺畅”。秦岚的季度报表上就是这样写的，老卢在例会上说的“现在的孩子都会包装”，也是同一种读法。第二个原因，它失灵的时候没有声音。一道错拦了人的关，会马上有动静：被拦的人要申诉，要发帖，要打电话。一道什么人也不拦的关，在日志里只有一串“通过”“通过”“通过”，跟一个一直没响过的火警铃，和一栋从来没起过火的楼，是分不开的。没有哪个机制会去问一句，怎么全是通过。

第三个原因，它会自己越长越牢。一个单位越正规，关口越多；关口越多，每一道的责任越分散；责任越分散，越没有哪个位置有权撤其中任何一道。这跟人们的直觉正好相反，人们总以为规范化会把没用的环节淘汰掉。可规范化的单位更擅长写出理由、走完流程、加上一道新的关，却常常没有一张表格叫“我要宣布这道关作废”。所以这一格不会被它自己发现，只能从外面去数。小范看了秦岚画的这张格子，沉默了一会儿，说他们每个月交的那张报表，每一项都是这第四格的样子：通过得快，退回得少，没有人投诉。他本来是引以为傲的。秦岚说，我也是。两个人都没有再说下去，因为谁也不能说对方有错：报表是照着要求做的，要求是照着当年的目的定的，目的在当年也是对的。顺便提一句，有一类关口例外，它们本来就希望人人通过，比如安全检查，不在这一章说的范围里，第19章会专门讲。

## 一句问话，一个比例

要把这件事从纸上落到地上，需要一句可以拿去问记录、不用问意见的话，这样不同的人问出来的答案才会一样。这本书选的是这一句：这道关，最近一百次判定里，拦下过几次？这句话里没有“合理”“充分”“应当”，它问的是日志。任何一个有记录的流程，都可以拿它去问一遍，而多数流程从来没有被这样问过。

秦岚把这句话拿去问了自己的七道关：简历上的三道自动关，新同事扫一遍，她自己挑一遍，再加初面和终面。形式审查，一百次里拦下一次；关键词，拦下二次；硬条件，拦下六十二次；同事扫一遍这一道，拦下九十五次；她自己挑选这一道，拦下七十多次；初面和终面，各拦下四十次和六十次上下。这些数都是我们替她编的。七道关里，通过率在百分之九十五以上的，是头两道，七分之二，不到三成。把这个比例叫饱和关占比：一套流程所有的关里，最近一百次以上判定中通过率不低于百分之九十五的关口，占多大一份。百分之九十五只是一个操作上的选择，换成百分之九十或者百分之九十九，各单位的数会变，不能说明什么的地方不会变。

这个比例有几样好处。它没有单位，招聘的二分之一和一本期刊的二分之一，说的是同一件事：十道关里，有五道谁也拦不住。它可以事后去数，数据多半是日志里现成的，不用造新系统。它还把一句人人都抱怨过的“这道关形同虚设”，变成了一个可以对的数字。有一点容易被误读，所以也要说：它跟平常用来看一个流程好不好的数是两码事。一家录用率只有千分之三的公司，看着筛得极严，可是它公开的每一道关都可以人人通过，最后的取舍发生在一次不公开、不留记录的碰头里，饱和关占比照样是百分之百。录用得少，不等于分辨得准。

这个数也有不能做的事。它说的是位置，不是人：一道空关，不能算到某一位审核员头上，一个尽心尽力的人站在空关上，也只能一路放行。它不能拿去给单位或者个人排名，也不能为了把它做好看，故意去拦几个人，那样的结果只会更坏，第19章会说为什么。再有，书里的这些数，包括秦岚那七道，都是我们编的，没有常模，也没有检验。有的流程连这个数也查不出来，因为日志里压根没有把这一道关单独记过，一道从来没有被单独记过的关，是不会有人为它负责的。

这一句问话换到别的地方，答案各不相同，所以值得多问几遍。软件团队的一条检查流水线，最近一百次运行里每一道检查红过几次，一个下午就能数完，是最容易查的一个。行业的调查说，团队用了人工智能以后，交付的稳定性下降，评审队列里等待的时间变长，有相当一部分改动没有经过评审就被合进去，这几件事放在一起，提示评审这一道关的答案可能在往下走，但光凭这些还下不了结论。杂志的形式审查就难查一些，多数编辑部只记“编辑直接退稿”的总数，并不分是在形式这一关退的，还是在内容那一关退的。能查，是一种答案；查不出来，也是一种答案。

那个周末，小禾听秦岚讲完这七道关，问了一句：那要是前面两道哪天撤了，我是不是就不用对着岗位说明改那么多版了？秦岚说，也许吧。可是别人没撤的时候，你还得改。小禾点点头，没有再问。窗外有人在楼下喊孩子回家吃饭。你单位门口的关，你能说出是谁加的吗？如果它今天不再拦任何人了，你知道该去找谁，才能让它停下来？
