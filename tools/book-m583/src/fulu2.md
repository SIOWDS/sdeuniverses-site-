# 附录二　这本书核对了什么、没有核对什么

**做过的核对。** 全书写完后，我们抽查了约三十个最承重的外部事实，渠道是公开网页，其中论文库和部分期刊的页面打不开，有几条只读到转述。约十四条属实，例如那项生成式辅导的实验、那项开发者试验、研究人员十八倍的估算。约七条有出入，已经改正，例如伦勃朗名下作品的数目、会议投稿上限的起始年份、那家期刊评审意见里机器文字的比例。这些出入有几处是九篇原文本身的错，这里按核对的结果写，与原文不同。

**查不到、已改成不具体说法的。** 那家管理学期刊的直接退稿比例和邀请评审的数字，一项行业调查里无人评审的合并请求比例，求职者用工具和多投的比例，人工智能会议投稿量的具体数字，一项绩效评分研究的比例，这些找不到可靠来源，书里只留了大意，不写数字。那项辅导实验的论文，据原文，二〇二五年八月有过更正，我们没能查实，也没能核到更正改了什么。

**只凭常识没有联网逐条核的。** 位次竞赛、变异度定义、康威的观察、约束理论、信号理论，这些是常见的文献，我们认为没有大错，请以原著为准。书中其余提到的研究，也没有逐一回到原始文献。

**没有做的。** 九处账的所有问话和比率，都没有在任何人群中检验过，没有常模。全书没有做过访谈、问卷或数据分析。邵家人物和书中那些数字都是编的。这本书没有经过独立的学术评审。写和审都出自同一类 AI，能查出前后矛盾，查不出共有的盲点，全书的一致性统稿也只逐字读了一部分章节，其余靠检索核对。
