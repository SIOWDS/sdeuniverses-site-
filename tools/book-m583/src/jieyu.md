# 结语　包子大赛的第二年

## 老支书多问了一句

青石村后来怎么样了？这个村子本来就是我们编的，它的结局也只能是编的。我们不想编一个好结局。

第二年腊月，蒸笼还是摆了半条街。规矩没有少，个头那一条还立着，视频也还要拍。猪还是一头。老支书的嘴还是那张嘴，比去年更老了一点。只有一件事变了：比赛前开会，他问了一句，去年我到底尝了几笼？村委会的会计翻了半天，账上没有。他们只好挨家去问，问出来的数不大准，大约两百来笼。他又问，那八百笼的人知道吗？没有人说话。

这一问没有让包子变好吃。可是那天晚上，有人在会上说，个头那条规矩能不能撤了，反正谁也没拦住。另一个人说不行，撤了会有人闹。又有人说，要不就明说，今年老支书只尝三百笼，抽签定，抽到的他都尝完，都写一句话。这个办法吵了一晚上，有人说抽签不公道，有人说总比揭都不揭强。王婶说，我那个新馅怎么算？没有人答得上来。最后定下来的只有一条：通知上写清楚，你这一笼有没有人尝过。

第二年的通知发下去，村里骂得更凶了。以前落选的人还可以想，是老支书尝了不喜欢；现在明明白白写着“未尝”，他们气得要去村委会拍桌子。小顺也收到了一张“未尝”，他拿着看了半天，第二天早上没有开机器，去师傅家问，头三个月揉面，现在还来得及吗？王婶说，来不来得及我不知道，你先把手洗了。

这就是我们能编到的最好的样子了。猪还是只有一头，老支书明年还会更老。没有人因此多得到什么，只是多知道了一点，有人因为知道了而更难受，有人因为知道了换了一个方向。

## 小禾后来

小禾四月的时候还在投，她把每周投出去的数量压到了原来的一半。她不再改第四十几版简历，把另一半时间拿去学数据分析。她不敢说这样对。那张一百三十七行的表还在她电脑里，后面多了一列，她自己加的，写着“有没有人看过”，大部分格子是空的，因为她不知道。

她也没有等来一个转折。我们不打算告诉你她后来找到了什么工作，因为这件事取决于太多这本书管不了的东西。她所在城市的行情，那一年的名额，也许还有一个肯替她打电话的人。这些都比这本书有力。如果你读这本书是想知道怎样才能找到工作，我们要向你道歉，它没有这个本事。

秦岚那边，她请人在拒信记录上加了一栏，这个数第一次报上去，人力总监老卢看了一眼，说这个先不要往上报。她回家以后，晚饭吃得比平时慢。她知道自己明天还要筛，七个岗位，一周四十个小时，这个算术没有变。可是她不再每天问女儿今天投了几份，有一天她问的是：“今天有人回你一句人话吗？”

这家人的饭桌上，现在还是有人说卷。这个词不会因为一本书就退休。只是小舟有一回说他们班卷的时候，老邵放下筷子，问了一句：“卷什么？谁在看？”问完他自己也愣了一下，因为他想起组里那块看板，它到现在还挂在墙上。

## 留给你的那一小块

这本书写了二十万字，翻来覆去说的是一件事：东西越交越多，看的人还是那几个。最后能留给你的东西其实很小。它不能给你多一个名额，不能让你的老板多看你一眼，也不能让这个世界慢下来。它只想帮你把一句话换掉。下次你想说“都怪我不够努力”的时候，或者想对孩子、对下属说“你怎么就不够努力”的时候，你可以先问一句：这份东西交上去以后，有谁看过？

如果你是那个看的人，这句话对你要难一点。你也许知道答案，只是从来没有去数。我们不怪你，换了我们也一样，你的时间就那么多。可是如果你手上有一份记录，记着上一轮的“不”是怎样作出的，你也许可以挑一个不太忙的下午翻一翻。翻完不一定要做什么。这份记录里写着的，是别人的半年。

这本书自己也是一份交上来的东西。它由 AI 协作写成，写得很快，比一个人写快得多。它的前言里说，它没有经过独立的评审，也没有经过实证的检验。按它自己说的道理，它正好是那种做起来几乎不要钱、看起来又很费工夫的东西，它也在往老支书面前那条街上再添一笼。你手上这本书，有多少是为了证明它不是别人说过的话？你读到了第几页？它要是不值得你这几个小时，那这本书就是它所说的那件事的又一个例子。我们留着这个问题，不替自己答。

你读完以后，如果觉得它有哪一处说得不对，请告诉我们。如果你能告诉我们，你看过了，看到第几章，觉得哪里不对，那就是这本书最想收到的回信。
