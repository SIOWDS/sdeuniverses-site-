# 写在前面

这本书从一场讨论而来，题目就是副题里的那句话：人力资源管理为何如此挑战。常见的回答有两种，一种说人复杂，一种说人和人的关系复杂，近些年又多了一种，说这是知识经济的难处。我的判断不在这三种里。难在工具是按单一洪流造的，却要去管多元洪流。一个人拧螺丝，对一条序列负责，对错由质检一种办法判，统一的工具在那里是灵的；一位研究员的一天里同时缠着手上的项目、半成形的想法、要带的新人和家里的事，把这样一个人读成一个常数，差额就大到无法忽略。这个差别不看他处在哪个经济里，看这份工作要接入几股洪流。

沿着这根总轴，书里立了四个挑战，也就是四道错配。第一道是对象错配：用统一性去管控同一性谱系，像抓泥鳅，手里握住的只是一个截面，抓得越紧，滑得越快。第二道是状态错配：人很多时候处在混沌态和介生态，管理总想用秩序态去控制。第三道是层次错配：管理管的是已经长成的果子，诚信、责任、质量，多元工作却更走向价值的发生源头，也就是创造、自由、幸福这三条路，而意义运行的土壤已经在人与人之间分化。第四道是位置错配：前三道都默认岸上站着一个管理者，其实没有岸，抓泥鳅的手也是泥鳅，只是两条泥鳅都在水里，只有一条手里有网，所以这句话不替任何人开脱。今天被称为“有效”的策略，大多是抓泥鳅的老办法，先给它抹一层灰，让它滑不动。指标确实好看了，人力却停在那里。

答案是不抓，推。管理不是去深刻理解什么人性、人格、文化，那还是在给泥鳅找一个实体。管理是基于对同一性谱系的体验和感知，让一条洪流序列去促进和推动另外一条或几条洪流序列的意义之路、价值之路；方向由被推的人判，他有权说这不是我的路，也有权停。这件事靠一个人的大脑做不到，靠一位好经理也跟不上，所以书里说它要建在人—AI 复合智能体的知识发生平台上。这个平台如果只握在公司手里，就成了最大的一层灰，第 43 章专门写这一点。书的前七编讲难在哪里、为什么一百年没有开工，第八编给答案，第九、十编才谈做法，每一种新做法都和旧做法对账，写明多预测了什么、多花了什么。

有几件事要先交代清楚，读者可以据此决定这本书的分量。第一，书中凡未注明来源的化名人物与情境，张三、小王、老李、陈明、那位研究员，以及各章里的公司与经理，都是为了说明机制而构造的，不是对某家公司或某个人的记录，也不带任何调查数据。带数字的地方都有出处，写在每章末尾的参考文献里，全书的文献汇总在书末。第二，本书的写作与审校借助 AI（Claude）协作，经统稿与三审。同一底座的执笔者与审稿者不能互作独立证据，三审能查出矛盾和错漏，查不出这个底座共有的盲点。第三，本书没有经过独立的学术评审。第四，书里写下了十条“怎样算错”的条款，这十条都还没有被直接检验过，其中四条有强弱不同的旁证，六条还缺直接证据，结语逐条交代了它们现在的状态。在这些检验做完之前，这本书应该读作一个有明确失败条件的假说，不应读作一套已经证明的方法。第五，本书与书中讨论的知识发生平台出自同一学派，平台的好处不能由本书自己证明，要由外人来检；平台的效果在书里一律写作待检。

还要说明两条边界。评分者效应是书里用得最多的一组研究，它的大小取决于研究设计，有的设计得出很高的比例，能把评分者的一贯倾向和他与被评者之间的特殊关系分开的设计，得出的比例要低得多，本书只取它们共同支持的那一点：这一块不是零，有结构，有后果。书里讲的“推”，和发展型关系、辅导、发展性对话这些研究有大面积的重合，本书不称首创，多说的只是把它放回了洪流与谱系的读法，并连着它会怎样变质一起写。书也不是诊断工具。读完以后，没有人应当拿它去给同事、下属或自己归类；心理状态不在本书的诊断范围之内，持续的困扰需要专业的支持。
