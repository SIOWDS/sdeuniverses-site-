# 第二编　总轴：单一洪流与多元洪流

第一编摆开了六个现场，每一处的账都算不准，而且算不准的样子相似：一个人身上缠着不止一条线，管理手里只有一条。读到这里，一个自然的反问会冒出来：这些工具是百年里一代代管理者用出来的，它们在工厂里是灵的，难道工厂里的账不也是人在记？为什么到了办公室、实验室、研发部，就一路失灵？

通行的回答有现成的名字：知识经济来了，工业时代的管理跟不上了。这个回答听起来顺，细看却站不稳。同一个时代里，同一家公司的楼下是分拣线，楼上是算法组；同一个行业里，有人整天对着一套固定流程录入，有人整天处理没人见过的故障。如果难处出在“处于什么经济”，这两层楼的人就该一样难管，实际上他们不一样。本编提出的总轴是另一把尺：难不难，不看处在什么经济，看这份工作要接入的洪流是单一的，还是多元的。

“洪流”在本书里指一个人的 SDE 序列：差异怎样累积、纠缠怎样缠绕、显露怎样结算，又怎样回写，一环接一环地流下去。工作把一部分洪流接进来，变成产出。接进来的部分窄而单一，还是宽而多股，决定了拿一条常数去管它，账会差多少。本编四章先后讲单一洪流、多元洪流、两者在同一时代的并存，最后画出多元度的地图。本章先从最容易被误会的一头讲起：流水线。

## 第 7 章　单一洪流：流水线上

### 泰勒的生铁，和一个值得保留怀疑的故事

1911 年，Frederick Taylor 在《科学管理原理》里讲了一个后来被引用了一百多年的故事。伯利恒钢铁公司的厂区里，一批工人把生铁块装上火车，每人每天平均装十二吨半。泰勒挑出一位他在书里叫施密特的工人，有人在旁计时，告诉他什么时候搬、什么时候歇。按泰勒的记述，施密特那天装了四十七吨半，工资从以前最多每天一块一毛五，涨到一块八毛五左右。

这个故事要先放一个保险。Wrege 与 Perroni 1974 年在《管理学会杂志》上，对泰勒的生铁实验做了史料核查，结论是这个故事“与其说是事实，不如说是虚构”，泰勒的记述与档案对不上。本书不靠施密特的数字立论。数字可以存疑，故事的结构却是真实的，因为它被后来的工厂反复照做：这就是泰勒整个方法的缩影。

这个结构有三个动作。第一，把一件工作拆成最小的动作，用秒表量出每个动作的最短时间，得出“一天应当做多少”。第二，把想的人和做的人分开：泰勒的原话是，需要一类人来事先计划，另一类完全不同的人来执行；车间里安排动作的是“计划室”里的人。第三，把规定写成指令交到工人手里，对照执行，按完成的程度发钱。他还有一句总纲，说得清清楚楚：过去是人排第一，将来必须是制度排第一。

泰勒书里另一句话要专门引。他谈到装生铁这类工作时说，适合长期做这种活的人，头脑必须迟钝、麻木到近乎一头牛。这句话冒犯，后来也成了批评泰勒的常用靶子。本书的读法不同，先不评价他的为人。放在他的设计里看，这句话说的其实是岗位的规格：要让一个人日复一日，在一条完全由别人规定的动作序列里毫无差错地做下去，这个岗位就不能接入这个人的判断、他对活计的好奇、他对自己手艺的想法。接进来的越窄，越不会出岔。泰勒的错在后半步：他把岗位的规格写成了人的属性，仿佛有一种“适合”这活的人，天生如此。这笔账从此记在了人头上。

### 单一是岗位切出来的

单一性是什么意思，先给一个检验。第 395 卷与本书一起用三个问题来看一份工作的多元程度：这份工作要同时对几条序列负责？出了错由谁来判，判法有几种？把这个人的理论与自我投入拿掉，产出还是不是同一个东西？

把装生铁的岗位放进三问。第一问，对几条序列负责：一条，就是眼前这批铁装得对不对、快不快。第二问，错了谁来判：计划室定下的标准，判法只有一种，有没有按指令动作，有没有达到当天吨数。第三问，去掉这个人的想法和自我，产出变不变：不变，换一个人照指令做，铁还是那些铁。三问的答案都指向同一个方向，这个岗位接入的洪流是窄的、单一的。

关键在于这个单一是怎样来的。它不是装铁的人天生简单，是泰勒的方法一刀一刀切出来的：切掉计划，计划归了别人；切掉判断，判断变成指令；切掉动作的多样，动作只剩一条最短路径。同一个人在家里用扳手修自行车，要同时想链条的松紧、车座的高低、孩子够不够得着，那一刻他接入的东西比岗位上多得多。岗位没有要，所以在岗位上，这些差异进不来。

差异进不来的时候，它在工厂的账上就变成噪声。泰勒把一种现象叫作“磨洋工”，意思是故意放慢，不肯做满一天的活。从管理者的位置看，同一批人做同一件事，有人快有人慢，慢的就是偏差，要纠正。这个读法在单一段站得住：工序已经标准化，快慢差异里确实没有太多值得保留的信息。不过后面会看到，噪声这个名字里也埋着一些别的东西。

还有一件事是容易漏掉的：工厂不只切动作，还给所有人发同一套符号、逻辑和数学。E. P. Thompson 1967 年在《过去与现在》杂志发表的长文，讲的就是这个。他的材料是英国工业化时期。在此之前，农民和手艺人干活按“活计”安排，潮水涨了就去，庄稼熟了就收，活干完了才歇，一个星期里有强度很高的几天，也有近乎闲着的几天，不少行业的人惯于过“圣星期一”，也就是周一也不上工。时间是在活里面过的。工业化把这一切改成了计时的劳动：雇主买的是钟点，时间不再是“过”的，是“花”的：Thompson 的说法是，时间成了通货。工厂用考勤表、罚款、计时员、教堂的钟和后来的怀表教会了人守时，学校和主日学校也在教孩子进入有纪律的时间。

把 Thompson 的观察换成本书的话：工厂对所有进门的人，提供了同一套符号（工牌、工号、工票上的名目）、同一种逻辑（对错由指令和考勤判）、同一种数学（秒表、钟点、计件率）。符号、逻辑、数学这三种信息形态，本书后面称信息三元，记作 E2，是意义发生的土壤。在流水线上，这个土壤是同一块的，大家用同一种钟，算同一本账。所以在这里谈“什么叫一天的活”，大家说的是同一件事。Thompson 还指出，这套纪律是被教会的、被内化的，也一路被争夺过：工人争的往往不是要不要计时，而是时间怎么算、工时多长、加班怎么付。这一层，即工业统一性有一部分正是工业制度自己造出来的，第三编讲测量如何造人时会回到它，这里先记下一个伏笔。

### 在这里，统一的工具为什么灵

接下来要把对方的道理讲足，因为它站得住。流水线上，统一的工具和对果子的管理，效果很显著。

先说管果子。工序把动作切得很窄，产量这个果子与动作之间几乎是一根直线：多搬几块铁，吨数就多；动作更省力，吨数就更多。这时拿产量奖惩，就是直接作用在果子与动作的这根线上。第 395 卷里价值关系有两条主路，其中一条是优化约束与能量状态共同决定显露出来的价值，奖惩、效率、节奏走的主要是这一路。在窄的洪流上，这一路有力，管果子管得到根。泰勒自己记的数字，施密特从十二吨半到四十七吨半，工资涨到一块八毛五，哪怕有史料质疑，方向是一个多世纪里无数工厂复述的：产量和工资同升。

再说统一的工具。Raff 与 Summers 1987 年在《劳动经济学杂志》上研究了福特公司 1914 年著名的五美元日薪。他们的结论是，这次大幅提薪最合理的解释，是对效率工资理论所强调的那一类劳工问题的回应，提薪之后，福特的职位出现了明显的排队，生产率和利润都上升了。这个研究要读准：它检验的是效率工资理论，不是给福特的一生作评价。它说明的是，在标准化程度很高的装配线上，一套统一的薪酬安排，加上统一的考勤和工序，可以带来可见的产能提升，并且让工人拿到比从前高的收入。这是统一性的真实红利。

本书因此不批评流水线管理。它回答的是一类问题，用的是适配这类问题的工具，而且在工资和效率上有目共睹地兑现过。批评要放在下面：当这套工具被原样搬到别的洪流上，会发生什么。这是第二编后几章的事。

### 账记在了工人身上

回头看“单一”这个词，容易落进一个陷阱：既然岗位是单一的，做这个岗位的人是不是也就简单一些？这一章要明确地说，不是。单一性描述的是岗位接入了什么，不评价人，也不描述人。

最直接的证据是工厂自己的观察。1930 年代初，Hawthorne 工厂的研究者在西方电气公司的“接线观察室”里，观察了十四位装配电话交换设备的男工。工资与产量挂钩，按理说，每个人都有动力做得更多。结果是产量被压住了：据二手的转述，工人担心做多了公司会降低计件的基础率，于是小圈子自己立了规矩，谁超了就被提醒，向上司汇报时大家的口径也一致，甚至说得不符合事实。这里要分清几件事。Hawthorne 研究中流传最广的“关注让人更努力”的说法，主要来自照明实验，Levitt 与 List 2011 年在《美国经济杂志：应用经济学》上，找回了当年的原始数据重新分析，发现流传多年的讲法，也就是每一次改变照明、产量都上升，站不住，他们评价此前的说法是“完全虚构的”，只在原始数据里找到更微弱的迹象。继电器装配室的实验在方法上也受到批评。本书用的是接线观察室那一阶段的观察，它是另一回事，但同样是二手转述，需要读 Roethlisberger 与 Dickson 1939 年的原书才能确认细节。

即便如此，它所展示的这一点是清楚的：岗位把工人的序列切成了一条，人带着其余序列来上班。他们对失业的担心，对同伴的责任，对什么是“公平的一天”的看法，一样接进了车间，只是工厂的账上没有这几栏。泰勒把这类现象记作磨洋工，Hawthorne 的研究者把它叫作非正式群体。名字不同，被切掉的东西是同一批。

账的另一半记在岗位之外。一个人在岗位上被要求单一，下了班他不单一。想象一位在电子厂做焊接工序的女工，姑且叫她阿芬，白天一条线上同一道工序，一天几千次相同的动作。下班后，邻居的收音机坏了，她拿过来，拆开，闻了闻，说是电容的问题，没有仪器，凭手感和一点点听来的经验，三下就修好了。这件事用到的东西，也就是对故障的判断、对零件的熟悉、不怕出错的试探，岗位一点也没要。阿芬不是“只会焊接”的人，是岗位只接入了焊接。两者的差别，在管理的账里默默消失：岗位上的阿芬被记作“操作工，熟练度三级”，另外那些东西没有科目可记。这是前面说的“账记在人身上”的最朴素的样子：切出来的余数，被当成人本身就剩这么多。

流水线工作的苦，也很早就被艺术家看到。Charlie Chaplin 1936 年的电影《摩登时代》，开场就是一个流浪汉在装配线上承受重复的节奏，被推去试验一台自动喂饭机，最后在压力下神经崩溃，把工厂搅乱，被送进医院。影片是艺术，不是调查，不能当作数据。但它画出了岗位单一时人那一头的代价：岗位只要一条序列，人的其他序列没有出口，在某处就要以别的方式漏出来。

这笔账在福特的提薪里也有一点痕迹。五美元日薪的背景是工人对这种工作的反应，如流动、怠工，这些通常被称作“劳工问题”。企业用更高的工资应对了，补偿了岗位，没有改变岗位。从管理一侧看，这是合理的：单一段上，用工资买下单一，成本可以算清，账能平。账平在企业这一头，工人那一头是否平了，要看他怎样用岗位之外的那些序列去消化，这些消化多半发生在厂门之外，不在任何报表里。

### 单一里也有手艺，也有人造出来的多元

读者有理由问：流水线上难道没有手艺吗？有的，而且很多。老师傅的手感，对设备声音的分辨，对一批材料脾气的判断，这些在许多制造业岗位上仍然存在。Michael Burawoy 的《制造同意》（1979 年，芝加哥大学出版社）是一项在芝加哥一家工厂里做了十个月机床操作工的民族志研究，他描述工人们在计件工资之下自己玩起一种赶产量的游戏，在规则里找窍门、争面子、赢同伴；这本书的主旨是解释工人为何会在这种游戏里自愿使出力气，本书这里只取一点：在最单一的岗位上，人也会自己造出多元来，游戏、窍门、小圈子，都是被切掉的序列在缝隙里的新芽。这些东西，管理者常常或者当它噪声去压，或者当它文化去引导，很少有人把它记作一条序列。

因此要把话说准：单一不是说工人没有判断，没有手艺。有两点必须区分。第一，一个岗位要求的是什么，和一个人拥有什么，是两件事，本书只谈前者。第二，同一个岗位，不同的工序切法，可以让接入的东西宽一些或窄一些，这是设计的选择，不是自然的事实。老钳工的岗位可以非常多元，只会写增删改查的程序员的岗位可以非常单一，第 10 章画地图时要回到这一点。

### 对手与边界

第一个对手来自统一管理的功绩。科学管理和随之而来的装配线带来了巨大的效率和工资增长，这个说法本书接受，不愿用批评的口气带过。本章只给了福特一例，并且是通过一项以效率工资为题的研究间接得来的，更大范围的数据本章没有核，也没有用。泰勒自述的数字受到 Wrege 与 Perroni 的质疑，故本章只取其结构，不取其数字。

第二个对手是“流水线上也有手艺”。Burawoy 一书本章只读到出版社的简介和章目（第五章题为《作为游戏的劳动过程》，第四章谈三十年间的“赶产量”），对游戏玩法的描述没有在原书里逐页核对，这里只用它说明岗位之内有人造的游戏，并不代表他对全部制造业工作的判断。关于技能被拆走的更大争论，如去技能化的主张，本章没有展开，也没有读原文。

第三，Thompson 的论文讲的是英国工业化时期的时间观念，它不是在论证岗位的单一性。本章把它用来说明工厂如何发出同一套钟，再把钟转写为符号、逻辑、数学的统一发放，这一步是本书的解释，属于哲学解释层面，不是 Thompson 的结论，也不是经验命题，读者应当分开看。

第四，Hawthorne 研究的各阶段方法上都有争议，照明实验的流传讲法已被 Levitt 与 List 推翻，继电器装配室被批评缺乏对照，接线观察室的细节本章来自二手转述。这些材料在这里只用来佐证一个很弱的主张：单一岗位上的人并不单一，且会以非正式的方式把其余序列带入。不能依据它们断言某个具体的管理做法有多大效果。

第五，三问判据需要数据。本章把装生铁、焊接工序放进三问，是推理，不是测量。一个流水线岗位的三问答案实际上多元，那么它就不该被归入单一段。总轴要能成立，必须有可复核的多元度测量，这是第 10 章要回答的。

第六，可错条件。总轴判断写在全书的证伪里：如果同一公司内，工作接入的纠缠种类并不比行业、年代更能预测统一工具失效的程度，总轴不成立。流水线一章只立了一端，另一端和对比要靠后面的章节。

第七，本章不评价任何职业和任何人。单一性描述的是岗位接入了什么，多元度不贴在人头上。阿芬是构造的说明人物，不是任何真实的人。下一章要问的是：如果单一是岗位切出来的，那么知识工作者的岗位，接入了什么？
