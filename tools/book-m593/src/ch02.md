## 第 2 章　绩效表评的是谁

### 同一个张三，两张表

回到导论里的张三。他在一家做企业服务的公司负责几个重点客户，前四年的直属领导是老周，第五年换成了何总。老周的评语年年相近：客户信得过，交代的事不用盯。何总的评语是另一种：反应偏慢，主动汇报少，对跨部门协作的推动不足。表上的分数从 A 掉到了 C。

人事部门拿到这个结果，通常有三种走法。第一种，把 C 当作事实，启动绩效改进：约谈、写计划、三个月后复评。第二种，把 A 当作事实，怀疑新领导要求过苛，找何总“校准”一下。第三种，两张表都不信，说评分本来就有主观性，下次再多收几个人的意见。这三种走法各有道理，也都有一个没有说出口的前提：存在一个“张三的真实绩效”，分数是对它的近似，近似得好不好，是打分的人的责任。

但先别急着挑一个。设想一下，这件事如果发生在你身边，最自然的解释是什么？多半是这样一些话：老周和张三合得来，老周看到的是张三擅长的那一面；何总的风格不同，他要的东西张三以前没人要过。这些话里藏着一个朴素的认识：分数不只关于张三，也关于打分的人和他们之间的关系。问题是，这个朴素的认识在人事制度里没有位置，表格只有一栏，写的是被评者的名字。本章要做的，是把这个朴素的认识称一称，看它在证据里占多大的分量，以及这个分量有多靠得住。

### 62%，来自哪里，后来缩到多少

最常被引来说明这一点的，是 Scullen、Mount 和 Goff 在 2000 年发表于《应用心理学杂志》的一项研究。因为这个数字太容易被误用，先把它的出处说清楚。

这项研究用了两套大规模的数据，被评者都是管理者，人数分别是 2,350 和 2,142。每位管理者收到的是发展性评价，也就是一种多源反馈：由 7 位评价者对他的 3 个绩效维度打分，这 7 位是两位上司、两位同事、两位下属，外加他自己。研究者的目的，是把这些评分里的方差拆开，看有多少来自被评者的总体水平，有多少来自他在具体维度上的表现，有多少来自评分者自己的特异评分倾向，有多少来自评分者所处的组织视角，还有多少是随机误差。

结果在两套数据里相当一致。评分者的特异效应分别占 62% 和 53%，超过了一半；被评者的总体表现与维度表现合起来，分别只占 21% 和 25%，不到特异评分者效应的一半；随机误差分别是 11% 和 18%；与评价者来源（上司、同事、下属）相关的效应较小，在上司和下属的评分里能看到一点，同事的评分里则没有。

白话说就是：在这两批管理者的多源评价里，按当年的模型，一份评分的波动，大部分跟“是谁在打分”有关，跟“被打分的人表现如何”有关的部分只有四分之一上下。评分揭示的更多是评分者而不是被评者，这句流传很广的话，就出自对这个结果的概括。下面会看到，这个概括后来被证明说得太满。

这些数字的使用范围要说清楚。第一，被评者是管理者，不是一般员工；第二，评价是发展性的，用于反馈和培养，不是用于决定薪酬和去留的行政考核，评价者在后者里可能更谨慎，也可能更有策略；第三，每一份分数的方差被分到了几个来源上，是一种统计模型下的分解，不等于说“张三的 C 里有 62% 属于何总”。把它当作某一张具体表的分摊比例，是一种常见的误读。这个结果能说明的，只是在当年那种设计和估计方法下，评分者因素显得很大。

后来的研究把这个数字压小了许多，必须并排放在这里。Jackson 等 2020 指出，包括 Scullen 等在内的不少早期分析，把评分者的效应和来源（上司、同事、下属）的效应混在一起估计，并对 Scullen 等所用的相关唯一性验证性因素分析提出了质疑。他们改用能把评分者与来源分开的贝叶斯概化理论设计，在两个英国样本里重新估计：样本一是 392 位管理者被评者、1,495 位评分者，样本二是 342 位管理者被评者、2,636 位评分者。评分者相关效应在样本一里占 16.91%（聚合到各绩效维度时）和 9.16%（再把来源内的评分者取平均时），在样本二里占 6.35% 和 4.23%。作者的结论是，把评分者与来源分开之后，评分者相关效应对聚合评分的影响很小。也就是说，62% 和 53% 不能当作常数使用，在更完整的设计下，这一块只有几个到十几个百分点。本章对这个数字的用法因此收窄：评分者因素不是分数里的大头，本书主张的只是它非零、有结构、有后果。这一截里有多少是评分者的一贯倾向，有多少是这一对人的关系，现有设计仍然分不开。

### 评分者的那一块里装着什么

那么，所谓“评分者的特异效应”里面装着什么？研究者的模型把它们叫作特异的评分倾向，直白的理解是有人普遍宽、有人普遍严，有人爱看沟通、有人爱看结果。这样理解，评分者就像一把有刻度偏差的尺子，调一调就好，办法是校准会议、强制分布、统一培训。

本书想多问一步。这把尺子偏差的来源是什么？至少有三类东西装在里面。第一类是评分者看得到什么。老周和张三在一个办公室坐了四年，客户来电话、突发情况、张三怎样把事压下来，老周都在场；何总是新来的，他看到的是周报、会议里的发言和几件他亲自过问的事。两个人各自评的，是各自看见的那一段，没有谁看错，但被看见的不是同一批显露。

第二类是评分者拿什么当好。老周管客户关系出身，把“客户信得过”当最高标准；何总来自一个讲流程和同步的团队，把“让我随时知道进展”当底线。同样是“工作做得好”，两个人心里对“好”的定义不一样，谁说了算，是命名的权力，这件事第 26 章再谈。要点是：这个定义不是误差，是评分者的一部分，它和他过去的序列、他现在被什么压着有关。

第三类是评分者和被评者之间的关系本身。老周信任张三，信任使他对不确定的事给予善意解读；何总还没有建立这种信任，对同样的行为做了保守的解读。这一类最难与前两类分开。在这类多源评价的模型里，“评分者的一贯倾向”和“这位评分者与这位被评者之间的特殊关系”在数据里很可能是混在一起的，没有办法分开。这是本书对其设计的推断，Scullen 等的分析没有替它做过拆分，Jackson 等的设计也没有把评分者与被评者的这一对关系单独拿出来，写在这里是为了提醒：“特异评分者效应”这个标签下面，很可能已经包含了关系。

这三类东西，没有一类是传统意义上的“偏差”，它们都是评分这件事本身自带的构成。一次评分，是评分者的一条序列与被评者的一条序列相遇，在一次特定的缠绕里结算出来的一个读数。读数写在被评者那一栏，但它的原料来自两边。这一截在数量上也许只有几个百分点，下面的读法并不依赖它很大，而依赖它不是零、不是随机的，并且会带来后果，比如一次调岗或一次不予晋升。

这样读，评分者效应就不只是一种偏差。偏差的说法默认评分者站在岸上，手里拿着一把或准或不准的尺子。可老周和何总同样是各自带着一串序列的人：老周那几年要对客户负责，何总刚接手团队，自己的表上也有要交的数字。他们打分的那一刻，是两条洪流相缠，分数是这次相缠的显露，写进了张三那一栏。同时要留个口子：评分者那一块里，有噪声，有偏差，也可能有被评者在这段关系里确实发生的东西，现有数据分不开，本章不替它断案。

日常里的例子到处都是。同一篇作文，语文老师甲打 85 分，老师乙打 72 分，没有人会说这篇作文的“真实分数”是多少，大家知道甲看重立意，乙看重文字。同一位租客，房东甲评价他“爱干净、好说话”，房东乙评价他“事多”，我们不会去问这位租客“本质”上是什么人，而是想到：两个房东对“事”的容忍度不同，租客对两位房东提出诉求的方式也可能不同。绩效表上的 A 与 C 的差距，如果换成作文和租客，读者立刻明白；一进入人事语境，大家反倒觉得分数应该有个客观的“本值”。

### 校准能解决吗

人事部门当然知道评分者有偏差，所以有一整套对付它的办法。校准会议让各部门经理坐在一起，对着同一批人对齐标准；强制分布限制每个等级的人数，防止有人宽有人严；多源评价让几个人同时打分，取平均；评分者培训教人识别晕轮效应、近因效应。

这些办法有效，本书不否认。多收几个人的意见，取平均，评分里属于个别评分者的那一块会被稀释，剩下的稳定部分更接近多数人的共识。Viswesvaran、Ones 和 Schmidt 1996 年的一项元分析发现，上司对整体工作绩效的评分，评分者之间的信度均值为 0.52，同事评分的信度更低；也就是说，两位上司对同一个人的评分，大约一半是一致的，另一半各说各话。这个数字既说明评分里确有可被共同认出的部分，也说明不一致的部分很大。

但注意这些办法共同做了什么：它们把评分者的那一块当作要从读数里减去的噪声，目标是还原一个“去掉评分者之后的人”。这个目标成立的前提，正是那个未被说出的假定：减去之后剩下的东西是稳定的、属于被评者的。校准会议本身也是一次相缠：经理们坐在一起对齐标准，各自背着自己的指标和排名，对齐的结果常常是大家同时朝最稳妥的方向挪。这可能只是在分数上再抹一层灰，灰也会抹在经理自己身上，他们同样被考核抓着。如果情况是另一种，也就是张三在老周手下和在何总手下，确实各自在不同的缠绕里显露了不同的东西，那么取平均得到的是一个谁手下都没有出现过的张三，校准会议对齐的是一个谁都没见过的张三。

换个说法：校准处理的是评分者之间的分歧，它默认分歧是看法的分歧。而在张三这件事上，分歧可能是事实的分歧，两位领导各自看到了真实发生过的、不同的张三。把这个差异平均掉，等于把最有用的信息扔了：张三在什么样的搭配里发挥得好，在什么样的搭配里发挥不出来。这恰恰是下一个管理动作，比如调岗、分组、配领导，最需要知道的东西。

### 两张表都对，然后呢

如果这样读张三，两张表就都不必推翻。老周的 A 记录了一次顺畅的缠绕：信任、默契、客户关系，张三在其中的长处被接住并放大了。何总的 C 记录了另一次缠绕：新领导要的是同步和可见，张三的做法没有被读出价值，他自己也没有意识到要换一种方式。两张表是同一条序列在两张网里各结算一次的结果，两个结果对不上，不构成矛盾。

这个读法要多做的事并不神秘。拿到两张不同的表，HR 的第一反应不是问“哪张是对的”，而是问两条线：张三在两个领导手下，做的是不是同样的事？两位领导各自看重什么、各自看得到什么？这两个问题问完，很可能发现一些可以操作的东西，比如何总需要一份每周同步，张三需要知道这在新团队里算一项成绩。这些东西会在 C 的背后，也在 A 的背后，但从没有出现在表格里，因为表格只有被评者那一栏。

还要承认这个读法的代价：它比“张三是 C”或“何总太严”都麻烦，需要多问几个人，需要承认有一部分问题无法归给任何一个人。这是第 46、53 章要处理的事。这一章先停在较前面的一步：分数里有一块属于评分的人与这段关系，这一块也许不大，但不是零，它不是一个只靠培训就能消除的缺陷，而更像对象本身的性质。

还有一点不能含糊。评分的人也被洪流裹着，并不等于责任被摊平。经理能决定张三的去留，张三决定不了经理的；两边都被缠着，权力却不对称。能力和处境的分布不等于责任的分布，说管理者也是泥鳅，是为了让工具看清自己，不是替谁开脱。这一层第 33 章再展开。

### 对手与边界

有四处要老实交代。第一，证据的限度，也是本章最需要收窄的地方。Scullen 等 2000 的被评者是管理者，评价是发展性的多源评价，评价者包含被评者自己，分解依据的是研究者设定的统计模型，它的 62% 和 53% 把评分者倾向与别的效应混在一起。Jackson 等 2020 在能把两者分开的设计里得到的评分者相关效应只有约 4% 到 17%，样本同样是管理者评价。因此本章不再把评分者因素说成“大头”：它在不同设计下从一半以上缩到几个百分点，大小取决于怎样估计，这一点现有文献没有定论。这些研究也都不能直接外推到一线员工的年度考核，不能说明上司单独打分的行政考核里评分者效应占多少。本章把它们都当作旁证，主张的只是这一截不是零。

第二，最强的对手：上司评分仍有效度。绩效评分与客观指标有相关，上司评分在选拔验证里长期被用作标准，用了这么多年还没有崩，说明里面确有稳定的信号。Viswesvaran 等 1996 的 0.52 也是这样一个数：它高于零，意味着两位上司的看法有一半是重合的。本书不否认这个信号。本书的补充是，重合的这一半不能自动读成“被评者的属性”，它也可能是两位上司共享的组织标准、共享的信息渠道和共享的盲区。重合不等于属于对方。

第三，“评分者因素”究竟是噪声、是偏差、还是真实差异，这个问题在研究文献里并没有定论。如果说它是噪声，校准是对的；如果说它是偏差，培训是对的；本书认为其中有一部分是真实的差异，即被评者在不同评分者面前确实显露得不同。这部分的比例，现有数据没有告诉我们，是这个读法目前最薄弱的地方。要检验它，需要追踪同一批人在换上司前后的绩效，和不换上司的人比较，看变动有多大，是否可由任务变化解释。这是全书对象判断那条证伪要看的：如果同一批员工跨上司、跨任务的绩效变异很小，个人稳定的部分解释了绝大部分差异，“把洪流读成常数”就不是难的主要根源。这条检验在本书里尚未有自己的数据，第 53 章和结语会写出设计。

第四，这一章读评分者效应的方式有一个相邻的、更保守的读法，应当并排放着。保守读法认为，评分者因素是需要被压低的测量误差，改进评分工具就够了；本书的读法认为其中有一块是关系的显露，哪怕这一块只有几个百分点。两种读法对同一组数据都说得通，区别要到后果里去看：若换上司后被评者的客观产出（销量、交付、缺陷率）跟着变，关系的读法得到支持；若客观产出不变而分数大变，保守读法更占上风。这个对照本书尚无自己的数据，写在这里，是为了让读者知道该拿什么来判本书错。

另一个边界：本章没有说评分不可信，也没有说绩效考核应当取消。它说的是，在把分数挂到一个人名下之前，这个分数里有一块属于别人，这一块有多大，要看怎样估计。

### 留给后面的问题

如果评分的人和被评的人缠在一起，那么给人发钱，是不是也会遇到同样的事：同一笔钱，落在不同的人身上，不会是同一个结果。下一章看奖金。
