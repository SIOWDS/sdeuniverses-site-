# 第二编　那一半：学校接走秩序，AI加速秩序，家里留混沌与介生

这一编是全书的题眼。女儿读的是传统高中，学校教得认真，但关系、赚钱、学习这三样，学校碰到的只是定型的那一头：有标准答案的题，有章程的社团，有分数的作业。AI来了以后，这一头来得更快、更顺，连从前夹在笨功夫里的那一点没想清、没定下的东西，也一并被端走了。孩子没交给学校的那一半，是这三样的混沌与介生，学校接不走，AI替不了，只能在家里长。

第4章讲学校只接了秩序，家并不是第二所学校。第5章把一张头像订单摊开，讲读懂客户是关系，客户付钱是价值，为画到满意去学新画法是学习，三样本来是一件事，拆开教，三样都会变形。第6章是全书最容易被误读的一章：不能都是秩序，不等于不要秩序。作息、安全、健康、诚信这类可靠的秩序要稳稳给；要防的是封闭的秩序。混沌要有底，介生要有人接，这一章我写得最慢，也改得最多。

## 第 4 章　学校只接了秩序

### ◆ 一句“不考，不用管”

〔示例性情境〕一个周四的晚上，小满进门放下书包，一边脱外套一边说：“今天物理老师讲到一半，说这个不考，不用管。”我正在盛汤，问她是哪一个。她说是讲电路的时候顺带提到的一个现象，同样的元件，换一种接法，灯会先亮一下再慢慢暗下去。有同学问为什么，老师笑了笑，说这个不考，感兴趣的课后自己看。她转述这句话的口气很平，没有委屈，也没有不服，倒像是在转告我一条交通规则：前面路口限速，知道就行。

她接着又说起另一件事。这几天她在画订单的时候冒出一个问题：同一个红色，放在深色底上和浅色底上，看起来为什么不一样？客户说“再柔一点”，她拿不准客户要的“柔”，究竟是颜色的事，还是别的什么事。她说她想在课上问一问光和颜色的关系，可翻了翻课表，没有哪一节课是放这种问题的。订单怎么来的、怎么画的，这里不展开，第2章和第5章会细讲；我只取她随口说的这半句：课表上没有地方放它。

我当时脑子里先后跳出两个念头，都是好心。第一个是顺着老师说：“老师说得对，先把要考的学好。”第二个是掏出手机，让AI把先亮后暗的道理给她讲一遍，讲得又快又清楚。过了很久我才看明白，这两个念头其实指着同一件事：一个问题冒出来，我的本能不是让它在她手里多待一会儿，而是尽快把它归档，一个归进“不考”，一个归进“已解决”。前一个是学校账本的做法，后一个是AI账本的做法。两本账都很体面，都没有恶意，可那个问题在两本账里都没有待着的地方。

本章要立的判断只有一句：我曾经对指导我的老师说“学校不教三样”，现在要把这句话改准。学校并非没有碰到这三样，它碰了，只是只接住了它们的秩序那一头；三样里没有定型的部分，和接住那些没定型的部分的人，学校的账上没有名分，这一半只能在家里长。AI接管秩序以后，连原先搭在笨功夫里顺带传下来的那一点，也被一并端走了。写到这里先把话说在前面：这一章不是在责怪学校，更不是在责怪那位笑着说“不考”的老师。他守着一节课的进度，守着全班的公平，做的是他该做的事。秩序本身不是病，病在秩序独占了整本账。

### ◆ 前人说到哪里

我最早提出这个说法，是在给指导我的老师写的一条微信里，原话是：“学校不教3样：如何学习-思考，如何关系-人与人的关系，如何赚钱-提前学习。”写的时候我是认真的，也是顺手的，凭的是二十多年人力资源工作加上十几年做母亲的体感：课表上没有“关系课”，没有“赚钱课”，也没有哪一门课教人怎样面对一个不知道怎么学的问题。后来我自己回头想，“不教”两个字其实要拆开看：是没碰，还是碰了没有接住？这一问把我问住了，因为只要翻一翻小满的书包，就知道学校碰得其实不少。

教育学里有“隐性课程”这样的说法，大意是学校在明文课程之外，还通过班级的规矩、座位、评价和气氛，向孩子传递着对人、对知识、对权威的态度（杰克逊，《课堂生活》，1968）。这个说法帮我承认了一件事：关系也好，学习的方式也好，对钱和劳动的看法也好，学校天天都在传，只是没有把它们当作课程来对待。所以“不教”不准确，“没有当作一本账来管”才准确。

更近的一块材料，来自站内的第537号《AI接管秩序之后》。它把全书收成一句判词：“学校只为秩序立了账，未定与承接从无份额。”书里的三个词我转述如下。秩序，是沿着给定的方向，走向可预期、可证明、可比较的结果的学习与劳动，像照着菜谱做菜，做对了有分。未定，是新鲜的东西已经出现、还没有收敛、没人替你兜底、后果自己担着，像冰箱里只剩几样东西，没有菜谱。承接，是这个新鲜的东西被接住：做砸的那道菜你记住了，下次改成拿手菜。第537号还说，只有未定没有承接，只是一次受惊；只有承接没有未定，只是一次背诵。这几句话我读到的时候停了一下，因为它把我一直说不清的那种“明明学了很多，却像缺了一块”的感觉，一下子说成了账本上的两栏。

第537号还回答了一个我一直想不通的问题：学校为什么偏偏只肯给秩序立账？它的解释是监护的证明焦虑。社会把孩子的成长托付给学校，就必须向自己、也向不在场的陌生人不断证明这份托付没有落空；而要让不在场的人也读得懂，就得有事先划定的方向和能排出先后的结果，这样的东西只有秩序。于是考试成了一台只认收敛的机器，不是谁存心压制好奇，而是好奇在账本上没有栏目。读到这里，我对那位物理老师的看法彻底变了：他说“不考”，不是在贬低那个现象，而是在老老实实地告诉学生，账本上哪一栏收什么。

最后是我自己上一本书的材料。第586号《你没交给企业的那一半》里有三个词：秩序，是可以被指挥、被交接、被替换的做法；混沌，是没处安放的判断、说不清的差别感，是原料；介生，是正在成形、被半接住的尝试，给混沌搭一个接得住的地方。当时我用一个土办法来分：设想明天离开，把交接清单交给接替的人，照着清单就能做下去的是秩序，写不进清单却一再冒出来的是混沌，已经在一个不归企业管的地方试过、被记下来的才是介生。三个词是分析用语，不是好坏排名，更不是“企业坏、个人好”。这一本书把同一组词从企业搬到学校和家里，搬法很简单：把“交接清单”换成“教学大纲加考试范围”，把“企业”换成“学校”，剩下的话几乎不用改。

### ◆ 学校碰了，碰到的是秩序那一头

先看“如何学习—思考”。学校在这件事上做了大量扎实的工作：听讲、笔记、刷题、纠错本，一套把陌生知识变成可检验结果的办法。我们这一代人，多半就是靠这套办法一路读过来的，不敢小看。这是学习的秩序态，也是任何一个孩子必须先有的底盘，第6章会专门讲，可靠的秩序必须稳稳给。可是学习里还有另外两头。一头是混沌：一个问题冒出来，不知道该归哪一科，老师也未必有现成答案；或者一种别扭，明明做对了题，心里清楚自己其实没懂。另一头是介生：把这个冒出来的问题带回去试一试，记下来，过两周再回头改一改。小满那句“这个不考”，说的正是这条线上的第二头和第三头：混沌出现了，没有人接。

再看“如何关系—人与人的关系”。学校在这里同样做了很多：班规、座位、值日、小组分工、同学守则，教的是关系里可以规格化的那一部分，比如礼貌、合作、不欺负人，这些都是关系的秩序态，缺了它们，一个班四五十个孩子根本转不起来。〔示例性情境〕可是想一想，一个平时一起吃饭的朋友，忽然有一周不再叫她了，这件事该放进哪一栏？它不违反任何班规，不影响任何分数，当事人自己也说不清是怎么回事，这是关系的混沌。一位班主任带着几十个孩子，这样的别扭每周都有许多件，她接不过来，也没有人要求她接，因为账本上没有这一栏。我在这里想说得公道一点：这不是班主任的失职，是一个人的时间和一本账的栏目，本来就装不下这么多事。

第三样“如何赚钱—提前学习”，学校碰得最少，却恰恰最能看清账本的逻辑。学校不是完全没有这类东西：劳动课、社会实践、财商讲座，偶尔还有模拟创业比赛，这些大多是有方案、有评分、有展示的活动，属于赚钱的秩序态。可是完整的“赚钱”里最有分量的几样，学校给不了：有人愿意为你的东西付钱，有人觉得不值，你得把这件事的后果自己担着。道理很直接，学校很难让后果实际落到孩子身上，一旦落了，出了安全问题、纠纷问题，它就难以向社会证明“托付没有落空”。所以不是学校不愿意，而是监护这件事本身，要求学校把后果挡在孩子前面。第537号管这个叫守护过剩，我转述它的大意：铺路替学生走了路，贴签替他打了分，外部的确定性在每个分叉点之前先到。而承接的四个条件里，有一条正是“后果能留在她身上”，学校恰好很难给。

把三样并排放，会发现同一个形状。每一样都有一头是学校接得住的：听讲、班规、活动方案，可以排进课表，可以量，可以交代；每一样都有一头是学校接不住的：一个无处归类的问题，一种说不清的别扭，一笔后果归己的钱。接得住的那一头，我叫它秩序；接不住的两头，叫混沌与介生。孩子每天带着这三样的后两头来上学、回家，学校的账上收不了，只能留给下班后的人。我的话要说得严谨一点：同伴圈子、网络、打工，也是这两头会出现的地方，但那些地方不一定有人接。所以“只能在家里长”，我的意思不是只有家里才有，而是只有家里有机会同时具备承接所需要的那几样：认得她、陪得久、后果又能被她和家人一起消化。


再往下问一步，为什么偏偏是这三样？三样放在一起看，有一个共同点，我是在整理这一章的时候才看出来的：每一样都是孩子和另一个会自己发生变化的东西相遇。学习与思考，遇到的是一个她还没有见过的问题，问题不会按教案长；关系，遇到的是另一个人，对方也有自己的想法、情绪和打算，不会照着剧本回应；赚钱，遇到的是一个陌生人和他的需要，对方愿不愿意付钱，不由她一个人说了算。这三种相遇，前面的路都是事先画不出来的，只能走了才知道。

而账本是怎么运转的呢？账本靠的是事先划定的方向和能排先后的结果。一个东西如果前路本来就画不出来，它在账本里自然只能接到靠近起点的那一小段：相遇之前的准备，比如背熟公式、背熟礼貌用语、背熟报价的算法。到了相遇的那一刻，账本的笔就停了。所以学校并不是随手挑了三样不教，而是这三样天生就站在账本的边上，它们最重要的部分，恰好是账本最没法写的部分。这样看，三样在孩子成长里的分量，和它们在学校账上的分量，常常是倒着的，越要紧的部分，账上越少，这也是它们在家里值得被专门看着的原因。

### ◆ 夹带：笨功夫里搭车的那一点

写到这里，一个反问会冒出来：既然学校的账一直如此，为什么我们这一代人读完书，好像并没有觉得缺了混沌和介生？第537号给了一个解释，我觉得是全书最扎实的一处，叫夹带。它的意思是，过去未定与承接多半不是被教出来的，而是搭在笨拙的秩序劳动上，由制度强制一并传下去。书里的例子是手推积分：卡了半个小时，发现中间符号写反了，回头重来。那半个小时里，没有人在教“未定”或者“承接”，可你被迫待在一个没有答案的地方，自己找到哪里错了，自己改。有效的夹带需要三个条件：后果归己，批评者和你共享可以逐行审查的材料，这条路对你的身体来说是必经的。

我在自己的成长里能找到同样的东西。〔示例性情境〕设想一个孩子在抄错题的时候，抄了三遍都对不上，直到发现是自己把一个数字看岔了；或者一篇作文改到第三遍，才发觉第一段根本不是她想说的。这两件事都不是任何老师设计的教学环节，却把“卡住、悬着、回头、认账”这一整套动作，刻进了孩子身上。它们搭在“必须做完”这件秩序劳动上，不用另外立账，免费送到每个孩子手里。

AI来了以后，这趟顺风车的车厢被整个换掉了。第537号对这一点说得很干脆：AI接管劳动的时候，没有人撤销夹带，夹带随着载体一起落空，而账本上也不出现任何缺口，考分可能一分都不降。书里还有一个词叫封口，大意是善意的现成答案赶在孩子自己的回应长出来之前，就把它焊死了。回到小满那个先亮后暗的灯：如果我当晚掏出手机，AI十秒钟就能讲得头头是道，作业里的同类题她也许会做得更好，可是那半个小时的卡住、悬着、自己猜一猜，就没有了。这并不是在说AI不该用，而是在说，从前免费送的那一点，现在要有人专门留。第12章会讲“先猜后问”怎样在家里做。

这里还有一个容易混淆的地方，也借第537号来分清。我们很容易把眼前的现象说成退化：孩子不会在没有答案的地方待着了，是不是以前会、现在被AI惯坏了？第537号的说法更窄，也更硬。它认为这不是能力先有后失，而是未定被抢先抵达、承接被提前结算，那份能力从来没有被允许发生过。两种说法给出的预期不同：如果是退化，撤去压制，应该恢复得比较快；如果是无份，恢复就慢，而且需要特定的序列，不能指望撤了AI，孩子自己就会长出来。这一点对家庭很实际。它意味着，我不能只是把AI收走、把手机关掉，然后等着孩子“恢复”，那样等来的多半是一个更焦虑的孩子；我得陪她把“卡住、悬着、回头”这几步，第一次、一小截一小截地走出来。这不是修复，是让它第一次发生，所以要慢，也要有人在旁边。

这一节还有一层意思，是我最想让家长读到的。第537号特别提醒，单把苦活补回来也收不回来：让孩子多做点手算，不等于夹带回来了，因为夹带需要的三个条件是一起起作用的。所以我不主张“回到从前”。我主张的是：既然搭车的路被拆掉了，这条路本身要有人修，修路的地方只能是家里。

夹带落空，在三样上的样子各不相同。先说学习。从前，把一道题写出规整的解法，是一件慢而苦的事，苦里夹着卡住与回头；如今整理笔记、生成解题步骤、列出纠错清单，AI几秒钟就能做完，而且做得比孩子自己整齐。秩序这一头越发顺滑，混沌那一头反而更容易被盖住，因为孩子“看起来什么都会了”。第12章要讲的看懂、做对、学会，就是从这里长出来的问题。

再说关系。从前，一句话说不出口，要在心里转几圈，转着转着自己就明白了几分；现在可以让AI给出几个得体的版本，挑一个发出去。话说得更体面了，转几圈的那一段没有了。那一段是什么呢？是她和自己的别扭待在一起的时间，是她第一次发现“我其实不是生气，我是难过”的时间。第9章会专门讲只会肯定的陪伴，这里先记一笔：关系的秩序态是话术，话术越好，越容易让人忘记话术背后还有一团没理清的东西。

最后是赚钱。从前，一个孩子要接订单，得自己琢磨怎么报价、怎么回客户、怎么写说明，琢磨错了，客户走了，下次就记住了；现在这些都有现成的模板，AI可以代写，可以代算。孩子能更快地把事做成，可是“后果归己”的那一段不一定变少，变少的是做之前的那一阵手足无措，那阵手足无措，其实是她最快长出判断的地方。第11章会给出一个办法，让孩子在用工具的同时，仍然是那个拿主意的人。

三样合起来，是同一个形状：AI把秩序那一头做得更快、更好，同时也让那一头更容易独占孩子的注意。孩子不是被AI变懒了，而是她面前的每一个卡点，都有人（不论是老师、是AI，还是焦虑的妈妈）准备好了一条顺路，顺路走多了，她自己的路就不容易长出来。这和学校的监护逻辑不一样，没有人要证明什么，却产生了相同的效果。更要紧的是，妈妈自己也被AI带着走，会很自然地用同样的快节奏去回应她，结果是两股洪流都在把混沌变成秩序，这是第3章要讲的同源回声，这里先点到为止。

### ◆ 三问看清这句“不用管”

按我这本书一章一章的写法，要先问她这一次显出来的那件事：小满说的“老师说这个不考，不用管”，是从哪里长出来的？我把它拆开看，里面有三层。第一层，是她的好奇，灯为什么先亮后暗，这个问题在她手里是新鲜的。第二层，是老师的善意，他不想占用全班的时间，也不想让没听懂的同学更乱。第三层最要紧：是她自己学会了账本的规则。她已经知道，不考的东西不进账，进账的东西才值得花力气。这一层是学校教得很成功的地方，我不该为此遗憾，而该看清它：这是她用了十几年学会的一项本事，一项适应制度的本事。

第二问，凭她已经显出来的和手边的条件，下一步能试什么，多大一步？手边有的是：她那台iPad，一个晚上，家里有人愿意陪她多待一会儿，还有现成的AI。可以试的最小一步，不是把灯的问题彻底弄明白，而是让这个问题在她手里多留一晚，比如让她先写下她自己的三种猜法，哪怕猜得很不像样。多大一步？一个问题，一晚上，不要超过。步子大了，就变成我给她布置的另一份作业了。

第三问，这一次之后，她的现实、她的想法、她对自己的看法，哪里被改写了？现实一层：她又验证了一次“有些问题在学校没地方放”。想法一层：如果没人拦着，这句话会慢慢长成“不考的不重要”。对自己的看法一层：更悄悄的一句，“我的好奇是课外的事，是不太体面的事”。这三处现在都还软着，改得动，可也正是在这个年纪，最容易被一句句“不考”钉实。这一问，我不是替她回答，是替自己看着。

复合主体的时代，还多一问是给妈妈自己的：我对这句话的第一反应，是从哪里来的？“先把要考的学好”，是我上学时那本账在替我说话；“马上让AI讲清楚”，是我这几年养成的习惯，妈妈加上她的AI，把一件事处理妥当。两个反应都不是错，但都不是为了她，是为了我自己心里那点不安。看清这一点，我才有可能把手放下来。

起手也要看对。她来讲学校的事，我的起手是先跟着经过走，问一句“后来呢？”老师怎么说的，同学们什么反应，她自己是什么感觉。不要抢在她前面评价老师，也不要抢在她前面解释物理。她讲完，我才知道她是想让我听一听，还是想让我陪她把这个问题弄出来。读不准，就直接问：“你想让我先听你讲完，还是一起想办法？”

再把这件事里的矛盾点出来。她在推进的，是想把一个冒出来的问题弄明白；学校稳着的，是一节课的进度和全班的公平。两边都有道理，这是家里的发动机，不是故障。这一类矛盾，是她的价值和校规打架，按我在这本书里的办法，改的是做法，不是改学校，也不是改她。具体的做法是：课上放不下的问题，回家有一页纸能放。这一页，不评分，不转成作业，不要求当晚有结论。至于最后她拿它怎么办，是继续琢磨、放下，还是去问老师，由她自己定。

三种回应摆在一起，会清楚一些。第一种：“老师说得对，先把要考的学好。”她留下的感受是妈妈和老师站在一边；认识是好奇要收好；行动空间是把问题放回心里，下次不说了。第二种：马上让AI讲电容。她留下的感受是妈妈对我有求必应；认识是问题就是用来被秒解的；行动空间是下次直接问AI，不用经过妈妈，也不用自己猜。第三种：“后来呢？你自己觉得它为什么先亮后暗？”她可能一脸不耐烦地说“我怎么知道”，但那个问题留在了她手里，而且妈妈站在旁边，没拿走。三种回应里，没有一种是坏人做的，区别只在问题最后落在谁的手上。


三问之外，还有一件很小、却容易做坏的事：当孩子带回一句“这个不考”，家长对那位老师说什么、对孩子怎样转述这件事。

最容易出现的偏差有两个。一个是替老师辩护，“老师也是为你们好，时间有限”，这话没有错，可孩子听出来的是“你的问题让大人为难了，不要再提”。另一个是借机批评，“你们学校就是只管考试”，这话也有几分对，可是孩子会因此多出一层夹心的难受：既觉得自己的问题不被接住，又觉得妈妈在背后说老师，她的好奇变成了一场大人之间的争论。两种说法都把她的问题从她手里拿走了，一个交给了老师，一个交给了批评。

我更愿意说的一句是：“老师那句话是在说账本，不是在说那个现象值不值得好奇。”这句话里有三个意思：老师没有否定你，那个现象是有意思的，账本有它的规矩。孩子听到这样的话，既不用对老师生气，也不用把好奇收起来，她会明白，原来“不考”只是一个关于分数的说法，并不是关于她的问题的说法。

对老师本人，如果有机会，我也不会去提意见，而是问一个小问题：“您讲到的那个现象，您觉得她要是想自己去看，从哪里起步比较好？”这是在请老师把秩序账本里省掉的那一小步，用一句话送回给她。老师多半很乐意，因为他们并不反对好奇，只是账本没给他们留出时间。〔示例性情境〕设想一位老师在“不考”之后，补一句“想看的话，可以从某某那一节开始”，或者课后留五分钟。这是老师在秩序之内悄悄留下的小份，值得家长看见，也值得家长接住。

### ◆ 家庭的位置：不是第二所学校

回到我自己在问题清单里写下的那个核心问题，前半句是：在传统高中教育与AI带来的实践机会同时存在的成长阶段，父母的位置在哪里。写这一章之前，我以为家庭的位置在两者之间，像一个裁判，一边盯着学校的成绩，一边盯着AI的使用，两头都不落下。现在看，这个想法也要改。

传统高中是秩序的稳定供应者，这一点不用质疑，也不必抱怨，社会就是这样托付它的。AI带来的实践机会，则是另一种情形：实践本身会带来混沌，客户的一句话、一笔订单、一次出错，都是没有菜谱的地方；可是AI又擅长在每一个卡点上立刻给出一个顺滑的说法，把混沌转眼变成秩序。所以孩子的处境是：一头有学校，把她收进账本；一头有AI，把她的卡点秒平。两头都在加速秩序。家庭的位置，就不是在这两头之间当裁判，也不是当第三个供应秩序的人，而是另开一本小账，记两本大账都不记的东西。

这本小账家里能开，还有一个简单的原因：家里不必向陌生人证明什么。学校的账要给不在场的人读，所以必须排得出先后；家里的账只给她自己和我们几个人读，读不懂的地方，直接问她就行。比如一页纸上写着“颜色的柔”，在学校的账里这几个字没有位置，在家里却可以是一个周末的话题。当然这不等于家里就没有压力：做父母的都难免有把孩子拿去和别人家对照的念头，那一刻家就成了一个小型的证明场，账外的东西最先被挤掉。所以这本小账要开得住，先得我自己愿意少交一点“证明”。

具体说是三件事。第一，不抢学校的活。作息、安全、健康、诚信这类可靠的秩序，家里稳稳地给；但不要把家变成第二所学校，晚上再加一轮督促、测验和排名，那只会把仅剩的一点空地也变成秩序。第二，不替她把冒出来的问题秒解，不管是我自己动手，还是让AI动手。第三，做那个承接的人，承接有四个条件：她的差异能进来，后果能留在她身上，她自己的小规矩能成形，这些小规矩以后还能改。这四条第6章会逐条细讲，这里只提一点：它们没有一条需要家长懂物理或者懂绘画，只需要家长在场，并且不抢。

这个位置在十六岁这一年尤其要紧，我的理由有两条。第一条，高中越往后，账本收得越紧，孩子也越熟悉账本的规则，她会越来越自觉地把“不考”的东西挪到视线之外，不需要任何人提醒。到那时，家里的那块空地如果还没有开出来，就会被时间表一点点吃掉。第二条，她已经有了一条自己的路：正月初六亲戚聚会时，她说过一句“要赚到认知以外的钱”。我当时没有急着夸她，后来越想越觉得，这句话说的正是账外的东西。认知以内的，是账本认得的、有菜谱的；认知以外的，是还没有名字、没人替你兜底的。她自己已经隐约知道，值钱的东西多半在账外，只是不知道怎样在账外站稳。站稳这件事，学校的账帮不上，AI的账也帮不上，只剩下家里那一点连续的在场。

有人会问，既然她自己已经能在订单里碰到未定，家里还要不要特意留？我的回答是要，原因恰好在订单本身。订单里的未定确实存在，可订单里也有太多现成的顺路：模板、AI、同行的经验，处处都能帮她把混沌转成秩序。她赚到了钱，说明她已经走通了一条路；可是走通了，不等于每一个冒出来的问题都有人接，更不等于那些问题里属于她自己的判断，被留下来了。这一点第2章会从“三千元是谁赚的”开始细讲，这里只提醒一句：成绩好看，与账外的东西有人接，是两件事。

我的问题清单里还有一句，我一直放在心上：“这些问题在学校教育中较少得到系统、连续的讨论。”我原来把它读成对学校的一点遗憾，以为是学校疏忽了。现在换一个读法：“系统”和“连续”，恰恰是账本的两个特征。系统，意思是能排进课表；连续，意思是能按期计量。而混沌与介生，既排不进课表，也无法按期计量，它们总是在某个意想不到的晚上冒出来，冒出来以后又可能隔很久才有下文。所以“较少”并不是巧合，是这本账的结构必然留下的缺口。也由此可以反过来看家庭：家里不能“系统”，因为没有课表；但家里可以“连续”，每天都在，同一个人一直在。零散而持续，正好是混沌与介生需要的节奏。

### ◆ 三个容易走偏的读法

这一章的说法，有三种常见的读偏，我先替读者把它们挡一挡。第一种读偏，是把它读成对抗学校：既然学校只给秩序，那家里就要反着来，少管作业、多去玩、多折腾。这样读，就把“不能都是秩序”读成了“不要秩序”。可是前面讲过，秩序本身不是病，听讲、刷题、作息、安全，这些可靠的秩序必须稳稳给。家里要做的不是和学校唱反调，而是把学校没记的那一栏，另外记上。

第二种读偏，是把它读成补课：既然学校不教关系、不教赚钱、不教思考，那家里就开一门关系课、一门财商课、一门思维课，每周讲一讲。这样做，混沌与介生又被做成了秩序。一门课可以教“同伴冲突的五个步骤”，可是那个说不清的别扭，是在某个晚上冒出来的，不会等到周六下午的课。这种读偏的危险在于，它让家长很有成就感，因为家里也终于“有体系了”，而孩子身上那一半反而更没有地方长。

第三种读偏，是把混沌读成放任：既然要留混沌，那就什么都别管。混沌是要有底的，作息、安全、诚信这些底线不让渡；介生是要有人接的，不是有人看着就行，要有人愿意在她把事情搞砸之后，陪她看清是哪一步，再试一次。只留不接，混沌就退化成一次受惊，用第537号的话说，只有未定没有承接，只是一次受惊。这和任其自流不是一回事。

三个读偏，其实都是把“另开一本小账”读成了“换一本大账”，读的人并没有恶意，只是秩序的习惯太深，一听到“要做点什么”，手就自动去拿课表和尺子。小账之所以是小账，是因为它小而窄、不排课、不打分，才躲得过被收编。

### ◆ 工具：一页“不考的账”

做法很小，我打算这样用。准备一个本子，或者iPad上的一页，名字叫“不考的账”。每周她从学校带回来的话里，只留意一类：冒出来了、但学校账上没有位置的问题，不管是物理的、关系的，还是和钱有关的。留意到了就记一条，用她自己的话记，不改写，不润色。周末找十分钟，只问三句：这一条你想怎么办，试一下、先留着、还是不要了？需要我陪你做哪一步，还是都不需要？上周留着的那条，现在怎么样了？我自己守三条：不当场给答案，不当场问AI，不把它转成作业或排名。下面是这张小表的样子，三栏。〔示例性情境〕

| 学校账上有的 | 学校账上没有的 | 这周家里接的一件 |
| --- | --- | --- |
| 电路的计算题，会做 | 灯为什么先亮后暗 | 她写了三种猜法，周日再看 |
| 小组汇报的分工 | 同伴为什么忽然不叫她了 | 她决定先不说，观察一周 |
| 劳动课的活动方案 | 颜色“柔”到底指什么 | 她想去问问客户的意思 |

〔示例性情境〕为了看清这一页怎样落到时间、评价、关系三处，设想某个周日晚上的十分钟。时间上，她说灯的那条还没猜完，我就让它晚一周再说，不催，也不记成拖延；第537号讲留份时提到容许“晚五分钟”的晚来一步，在家里大约就是这样一种不记迟到的让步。评价上，她写下的第一种猜法后来看来站不住，我不说“错了”，也不说“差一点”，只问她当时为什么这样猜，因为猜错的那条路里常常有她真正在想的东西，一旦折算成负数，下次她就只写稳妥的。关系上，我只做两件事：把她的话原样复述一遍，再问一句“这一步你是怎么想到的”，不替她答，也不顺手让AI补全。十分钟里，我说的话加起来，最好不超过她说的一半。这三处怎样一起松，第6章会细讲。

还有一种情形要提前想好：一周下来，她什么也没带回来，右边一栏空着。我的做法是让它空着。空白也是一种读数，它可能说明这周没有冒出新问题，也可能说明她已经不信这一页能装东西，后一种比前一种更需要我留意。这时我不追问，不提醒，不把空白补成一句“你再想想”，只在下一周的十分钟里，老老实实多听她讲一件学校里的事，用“后来呢”往下走。她愿意讲，说明路还通，账外的东西迟早会再冒出来；她不愿意讲，我就先去看自己上周是不是抢了她的收尾。

几点说明。第一，右边一栏每周只写一件，多了又成作业。第二，“先不说”“放下”也是合格的答案，这一页记的是她的处置，不是我的验收。第三，两周以后翻回去看，哪一条是她自己动过的，哪一条是我替她动的，这个区分比任何答案都重要。第四，这一页是留份卡的一个小前身，第6章会给出完整的家庭留份卡，把时间、评价、关系三处一起松开。

### ◆ 撤回条件

这一章的核心是一个很强的说法：三样的混沌与介生，在学校的账上没有份额，所以只能在家里长。如果下面的情形成立，这一章就是错的，或者至少“只能”两个字要拿掉。

第一，学校已经为这三样的未定与承接立了账。可以观察的样子是：一个不在考纲上的问题冒出来，在她所在的班里有固定的时间、固定的地方和固定的人去接；接的结果被记入她的评价，而且不是折成负数；她的后果有一部分留在她自己身上。设想去问几所不同的传统高中里的学生与家长，若大多数家庭说“有，而且常用”，那么家里这一半就不再是“只能”，本章要改成“学校和家庭分担”。

第二，没有任何家庭留份，孩子仍然长出了自己的小规矩，并且能自己改。如果在一批没有这类留份的孩子身上，我们稳定地看到她们能带着问题回来、能自己试、也能自己推翻，那说明承接不止发生在家里，这一章对家庭独占性的判断就要收窄。

第三，若“不考的账”做了两个月，她带回来的问题和提法没有任何变化，也没有一条是她自己动过的，那要先怀疑是不是我在其中又替她收了尾；排除了这一点以后仍然没有变化，说明这一页纸没有起到承接的作用，这一章给出的家里的位置，就要重新找。

## 第 5 章　三样其实是一件事

### ◆ 一张订单，摊在饭桌上

〔示例性情境〕那天晚饭后，小满把iPad推到我面前，说：“妈，你看这个，客户又来了。”屏幕上是一张刚交完的头像，一个背着书包的女生站在路灯下，裙角有一点被风吹起来的意思。客户的原话留在对话框里：“想要放学遇到下雨天的感觉，但不要太甜。”小满指着“不要太甜”那四个字，说：“我昨天想了一晚上，这四个字到底是什么意思。”

我先忍住了。做了二十多年人力，我对“把事情拆成几块、各块分给不同部门”这套动作太熟了。看见这张图，我脑子里立刻自动分了三格：画画是兴趣，收钱是理财，客户沟通是情商，回头再看看周末的作业排得下排不下。三格摆好，每格各配一段话，我已经可以开讲了。幸好那天她话多，我没来得及开口，她自己就往下说了：客户第一稿看完说“好看，但是太甜了”，她才明白“不要太甜”不是指颜色，是指表情；她把女生的嘴角往下压了两毫米，眼神改成看向别处，客户回了一个“就是这个”。她说到这儿，笑得有点得意。

我后来一直在想那个晚上。她那十分钟里讲的东西，我若按自己的三格去归档，会撕成三截：读懂“不要太甜”，归关系；客户说“就是这个”之后付了款，归赚钱；她为了压那两毫米的嘴角去查了半天笔刷和图层，归学习。可是她自己讲的时候，这三截是连着的，没有任何一处能让人说：到这里，上一件事结束，下一件事开始。她不是先学会了才去读客户，也不是读懂了才去收钱。读不懂，就不知道该学什么；学得不够，就压不出那个表情；表情没压对，客户不会说“就是这个”，钱也就不会按“就是这个”的价格到账。

这一章要说的，就是这个连着的东西。前面第2章已经把这笔钱里工具的部分和她自己的部分分过，钱最终归谁的账也算过一遍，这里只一句话带过：账要分，是为了看清哪一截是她的，不是为了把她的日子切成块。接下来要问的是另一个方向的问题：既然她的日子本来是连着的，我们大人为什么总习惯拆开教？拆开以后，三样各自会变成什么样子？

我的判断先放在这里，后面再一步步摊开：关系、赚钱、学习，不是三门课，是同一次发生的三种显露。所谓“发生”，我在这本书里的用法很朴素，指的是一件事在具体的条件里，从无到有、从有到变，一步一步长出来的过程。拆开教，三样都会变形：只盯着钱，家里会冒出一套看不见的KPI；只盯着学习，一切又滑回考试；只盯着关系，聊天就成了陪聊。这三种变形，都是做父母的人最容易犯的，后面会一样一样讲。

这个想法不是我的新发明，先把前人说到的地方交代清楚。第一块，是我自己的老本行。我写过一篇讲工作经验的文章，《从原子习惯Workbook说起：别让工作经验，只剩下聊天记录》，里面有一句话我自己很喜欢：“聊天记录保存的是发生过什么，经验要留下的是下次怎么做。”当时我是对着HR同行说的，说做过很多事不等于下次会更快，中间隔着一道工序：把过程里有用的东西留下来。文章里给的办法很小，关键任务结束，留三行：这次卡在哪里，哪一步有效，下次提前做什么。那时我只是想让同行别在聊天记录里考古。现在回头看，同样三行，放到小满的一张订单后面居然也成立。区别只是，对她来说，“经验”不是工作经验，是她这个年纪在世界里一次次试出来的东西，而这些东西，今天在学校里几乎没有地方存放。

第二块，是学教育的人早就说过的“从经历中学习”。科尔布把学习看成一个圈：先有一次体验，然后回头想一想，从中形成一点概念，再带着它去试下一次（科尔布，《经验学习》，1984）。我在《认知以外的钱：一个雨夜里，孩子给我上的一课》里提到过这个模型，意思很清楚：经历过，不等于学到了，中间要有回头看的一步。这个圈对本章有用，我要借它，但也要看见它的边：它讲的是一个人的学习怎样转圈，没有讲到这个圈旁边，还有一个客户在回应她，一个妈妈站在厨房门口看着她，一个班级的周测在周五等着她。她的圈不是一个人在转。

第三块，是第324号讲的“互相生成”。那本书的第2章里有一个我反复读的说法：显出来的样子，取决于差异的接续和被缠住的处境；差异怎样发动，又取决于已经显出来的样子和被缠住的处境；处境本身也不是静止的背景，会因为前两者的矛盾而被重新改写。三样东西，谁也不是起点。书里特别提醒读者，别把它们读成三个名词盒子，判断自己有没有用对，只看一条：你是否在谈“它们如何互相改变”。我把这条标准搬到家里，就得到了本章的问法：关系、赚钱、学习，这三样，我是不是在把它们当三个盒子？还是在看它们怎样互相改变？

这三块合起来，就是这一章“站在前人肩上”的位置。本书押的新，只有一处：三样是同一次发生，所以三样的秩序、混沌、介生要放在一起看，教的时候也不能只动其中一块。这一点我会给出判死条款，写在本章末尾。

### ◆ 把这一单摊开，再用三问连着走一遍

下面把那张订单从头再走一遍。能当真实经历写的，只有这些：她用一支五块钱的触控笔，在iPad上画二次元人物头像和卡片接单；一个假期画了几十张，她自己算过，时薪大约四十元；开始赚了一千多元，后来累计约三千元；最近开始用AI。至于这一单的客户怎么说话、她怎么改的、改了几稿，是我为了讲清道理搭的示例，不是纪实，读的时候请当示例看。

〔示例性情境〕客户发来的需求只有一句：“放学遇到下雨天的感觉，但不要太甜。”小满第一稿交出去的是一个撑着透明伞、脸颊微红、嘴角上扬的少女，背景是粉紫色的雨幕。她自己觉得很满意，因为这是她最熟的画法，圈子里的人看了都会点头。客户的反馈是：“好看，但是太甜了。”

这里先看第一处连着的地方。客户说“太甜”，她要读懂的是：这个人心里想要的，到底是一个什么样的人物？同样是“太甜”，可以是画风太幼，可以是配色太糖，也可以是表情太讨好。她问了客户一句：“是颜色太甜，还是人看起来太甜？”客户说：“人。她不用对我笑。”到这一步，她读到的已经不只是一条修改意见，而是一个陌生人对“好看”的理解：他要的是一个有自己心事的人，而不是一个对着观众微笑的人。这是关系，读人，读一个她从没见过面的人的需要。

第二处连着的地方。读懂以后她发现，自己熟悉的画法画不出“不对我笑”。她习惯的嘴角和眼睛的组合，一出手就是在笑。要让一个人看起来有心事，需要换眼睛的画法，换阴影落在脸上的方式，甚至换整张图的光。这是学习，但这个学习不是老师布置的，是这一单逼出来的，目标非常具体：画出一个“不对我笑”的女生。她去查，去看别人的画，去问AI某种光线下脸部的阴影一般怎么处理。

第三处，付钱。客户说“就是这个”，款项到账。这一步的意义，我觉得常被大人看窄了，以为是“她赚到了钱”。其实钱在这里更像一个回执：它告诉她，她刚才读人的那一步读对了，学的那一步学到位了，交出去的东西被一个与她无关的陌生人认可到愿意掏钱。这个回执的分量，比我在饭桌上说一百句“你画得好”都重。我在《认知以外的钱：一个雨夜里，孩子给我上的一课》里写过，这类事情里要紧的是：“看见需求，把手边资源重新组合，拿到反馈，再把经验变成下一次更好的判断。”现在摊开看，这句话里其实有三样：看见需求是关系，重新组合是学习，拿到反馈是钱和人一起给的。

第四处，也是最容易被忽略的一处：这一单结束以后，家里变了什么（仍是示例）。她知道了“不要太甜”可以被问清楚，下一次再有模糊的要求，她会先问一句；她多了一种画法，原来单子上能接的类型多了一类；她对自己的定价也松动了，因为这类“有心事”的人物比她从前接的批量头像费工，她得重新算时薪；在家里，她不再把我推过来的“要不要先把作业写完”当成压力，而是当成一个排期问题，因为她手里有了一个确实在等着交付的东西。这一串变化，没有一条是我设计的，它们是这一单自己长出来的。

把这四处连起来看，就能回答那个朴素的问题：三样为什么说是“一次发生”。因为每一样的发动，都靠另外两样；每一样的结果，都改写另外两样。读不懂客户，没法决定学什么；不学新画法，钱不会到账；钱到账的方式（满意、不满意、愿意再来），又反过来改变她下一次怎样读人、学什么。三样不是三条平行的线，是三股绕在一起的绳。

接下来用三个问题把这一单再走一遍，仍沿用上面的示例。每一问，我都先问小满，再问我自己。第一问：她显出来的这个东西，是从哪来的？那张“不对我笑”的图，是她这一单交出来的东西。它从哪里来？我顺着“后来呢”往回听：先是一稿太甜，然后问了客户，然后查了画法，然后试了三四次眼睛，然后才有最后这个版本。这条路里，有她从小喜欢动漫积下来的审美，有五块钱笔和iPad这套现成的条件，有二次元圈子里人人都懂的“甜”和“不甜”的暗号，有客户一句追问之后的纠偏，也有她最近开始用的AI，在她问到阴影处理的时候给过她一个方向。

要紧的是，这里每一样，我都不用替她判断哪个更重要，只需要在她讲的时候，听一听哪一截是她自己试出来的，哪一截是别人给的。第2章讲过怎样分这一截，这里只提醒一点：问的时候别问“你怎么这么会画”，问“你是怎么发现他要的是这个的”。前一句是夸，后一句是让她回头把路走一遍。

第二问：凭她已经显出来的和手边的条件，下一步能试什么，多大一步？这一问在家里最容易走偏，因为我的职业习惯是“一步到位”：既然她读客户读得不错，是不是可以做个固定的客户沟通模板？既然有人愿意为“有心事”的人物多付钱，是不是可以把价目表做一张，分档位？这些想法都不算错，但都太大了。她的现实是：周测排着，一单要画几个小时，她手里的画法这周刚多了一种。凭这些，她下一步能试的，大约是一个再小一点的东西：下一次遇到模糊的要求，先问一句“你想要的感觉里，最不想要的是什么”。这是一个能用现有条件走出去的一步。我在心里问自己，如果我把这一步放大成“做模板、定档位”，那是她自己的下一步，还是我的下一步？

第三问：这一次之后，她的现实、理念、自我，还有这个家，哪里被改写了？我把这一问拆成三个小问，因为三样各改了一处。她的现实里多了一类可接的订单（现实）；她对“好看”的理解里多了一条：好看不等于讨喜（理念）；她看自己时，多了一句“我能把不会的画法逼出来”（自我）。而这个家，也在悄悄变：晚饭后推到我面前的iPad，意味着她愿意把“做成了一件事”带回来给我看，我在饭桌上的位置，从“检查作业的人”挪了半步，成了“听她讲这一单的人”。这个半步是她给的，我只是接住。

另外还有一问是对我自己问的：我对这一单的看法，是从哪来的？那天晚上她一边讲，我一边在心里已经有了几个“结论”，比如“她这次沟通得不错”“这类单价应该能提”。我停了一下，问自己：这些话是我听她讲出来的，还是我昨晚问AI“十几岁孩子接单怎么引导”的时候，AI给我的现成说法？这个问题不舒服，但很有用。如果是后者，那我是带着一个别人的答案来听她的，我听到的就是我想听的。第3章讲的“同源回声”就是这个，我在这里只借它的一个小动作：每次开口之前，先问一句，这是我听出来的，还是我提前带来的。

三问走完，你会发现一个事情：它们不是三个独立的环节，每一问的答案，都是下一问的材料。第一问查出她手里有什么，第二问才知道下一步多大；第二问试出来的结果，又是第三问改写的对象；第三问改写出的新现实、新理念、新自我，又是下一轮第一问要往回看的起点。三问也是连着转的。

### ◆ 只问其一会怎样，矛盾又该怎么放

现在要做一件事：把三问里的一问单独拿出来用，看这一单会变成什么样子。这不是吓人，这三种变形，做父母的都容易犯，下面各写一遍。

先看只盯着钱。〔示例性情境〕假设那天晚上，我听她讲完，只问了一句：“那这单赚了多少？时薪比上次高了吗？”她会如实回答，因为她本来就算过时薪。可是你想想后面会发生什么：她这一单读客户、学新画法的过程，在我这里变成了“用了多长时间”和“收了多少钱”两个数字。下一次她再接单，会本能地算：值不值得读这么久的客户，值不值得学这个新画法。按时薪算，“不要太甜”这类需要反复沟通的单子，往往不如批量头像划算。她会慢慢往批量单子倾斜，因为那样数字更好看。几个月以后，她的“关系”那一块会萎缩：不再有耐心去读一个人想要什么；“学习”那一块也会变窄：不再为了一个没把握的表情去学新东西。我设了一个KPI，什么也没说，她自己就学会了遵守。这就是我说的“家庭KPI”：不是我下令的，是我的追问方式让它长出来的。

再看只盯着学习。〔示例性情境〕换一种我：听完她讲，我立刻说：“你查的那个阴影画法，是美术里的什么知识？是不是跟物理里光的反射有关？我们要不要借这个把这周的光学复习一遍？”听上去很有水平，是不是？但她会怎样接？她这次是为了让一个陌生人说“就是这个”才去学阴影的，那是她自己的学习，有出处，有对象。我一句话把它接进周测的复习里，这个学习的出处就被换掉了：从“为了一个人”换成“为了一个考试”。她的反应不会是反驳，而是悄悄把下一次的订单细节少讲一点。因为她知道，讲得越多，越会被我拿去“转化”。学习又回到了考试的轨道上，而订单里原本活着的那一团，被我自己的好意压没了。

最后看只盯着关系。〔示例性情境〕第三种我：听完她讲，只说：“客户这么挑剔，你是不是很委屈？要不要妈妈陪你聊聊？”她当然可以说几句，也许还会感谢我。但这样的聊天里没有东西落地：客户到底要什么、她怎样学会的、下一步试什么，都没有被问到。关系被抽出来单独养，就成了陪聊。陪聊不是坏事，它让人觉得被接住了，但这里的接住是空的：没有后果落在她身上，也没有她自己的做法长出来。久了，她会觉得跟我聊天是一个情绪出口，而不是一个想事情的地方。

这三种变形，换个角度看，就是三种好心。盯着钱的，是想让她认真对待现实的回报；盯着学习的，是想让她不要耽误正事；盯着关系的，是想让她被人心疼。每一种好心，都是单拎一样出来，所以每一种好心，最后都让另外两样的活气被抽走。做人力资源的人对这样的反例不会陌生。设想一个部门做招聘，只盯着“到岗周期”这一个指标，三个月后周期是下来了，用人部门和候选人之间的关系却越来越薄，新人上手也越来越慢。到那时候才发现，周期这一个数，把“读懂岗位”“学会新人上手”这两件事一起压扁了。家里不是公司，但道理相通：一个单独被拿出来看的指标，会安静地改造它周围的一切。

三问之外，还有一个我以前总绕过去的地方：这一单放进她的日子里，是有矛盾的。〔示例性情境〕那周她为了压那两毫米的嘴角，连着三个晚上画到十一点多，周五有一个小测，周四晚上她坐在桌前却说：“我先把客户这张收个尾。”我的第一反应，大概每个做母亲的人都有：“小测不要了吗？”这个时候，我提醒自己先在心里写一句话：她在推进的是一个她很想做成的东西，学校和家里稳着的是周五的小测和作息。这是两件各有道理的事，不是一个对、一个错。矛盾是家里的发动机，不是故障。把它认成故障，我就会去“解决”它：要么禁掉这一单，要么给她一个排得满满的完美时间表。这两样，都是在替她把第三项改掉。

这里的第三项，指的是两件打架的事之外，还有一样东西可以动。她的尝试和她的处境打架，可以动的是“处境里的某一样”：一个晚上的时间怎么分，客户的交稿期限能不能往后推半天，周四的小测复习能不能挪到周三。这些，只有她自己能改，因为只有她知道客户的脾气、自己的手速、周五的小测到底有多要紧。

我能做的，是把条件摊开：“周四你有几个小时，周五要考什么，客户什么时候要？”她算了一遍，自己说：“那我跟他说周六早上给。”客户回了一个“可以”。这个“可以”，是她自己谈出来的新做法。我若替她谈，她就没有了这一次“和一个陌生人商量时间”的经历，而那恰好是关系，也是赚钱，也是学习，三样一起。

起手也要选对。她那天是主动来讲的，所以我要做的是先跟着经过走，问“后来呢”，而不是先拿主意。她若是说“妈，我这周到底先写什么”，那是她请我拿主意，我才用我职场里那一套：先明靶子（这周最要紧的是什么），再盘家底（你有几个晚上，各是什么状态），后定路线（怎么排）。起手错了不报错，只会让我越认真，离她越远。读不准的时候，我就直接问：“你想让我先听你讲完，还是一起想办法？”

最后是留份。这一单里，混沌是她的：为什么“不要太甜”会让她想一晚上？这个想一晚上，我不能用一句“其实客户的意思是……”替她省掉。时间上，我留给她的是周四晚上一段不被盘问的画画时间；评价上，我不把这一单的成败拿去跟小测比；关系上，我不在她面前评论客户“事儿多”。三处一起松，那团混沌才有地方变成她的东西。

### ◆ 一个月以后：回写

〔示例性情境〕大约一个月以后，有天她放学回来，进门第一句话不是订单，是：“妈，今天物理老师讲光的反射，我突然明白我的阴影为什么老画不对了。”她用手比划着：光从左上方来，脸右下方的阴影不是随便涂的，角度是有规矩的。她拿起笔在草稿纸上画了一个三角形，说：“原来我一直在凭感觉，现在知道它是个几何。”

这个场景我想放在这里，是因为它给了一个反向的牵连：学校里一个原本是秩序的东西（光的反射），因为订单里先冒出了一团说不清的疑问（那个“我老算不对”的角度），才长出了意思。这一回，学习没有被我“转化”进考试，而是自己从订单走回了课堂。后来她在周测的光学题上错没错，我不知道，也没问；但她那天在饭桌上讲这个的神情，让我知道，那一团混沌正在被承接。

她这一单的后续，还有另一条线。〔示例性情境〕过了几天，她又接了一个单子，这回客户的要求是“有点忧伤，但不要哭”。她没有再想一晚上，而是先问了一句：“你说的忧伤，是想让看的人心疼，还是想让看的人陪着？”客户沉默了一会儿，回：“陪着。”小满回来跟我说：“我现在知道要先问那个了。”这是上一单的回写：关系里那一次“试着说一次再调整”，已经变成了她自己的小规矩。

把这两条线并排放，就是一次回写：关系里的一个动作，改写了她接单的做法；订单里的一团疑问，改写了她听物理课的方式；而物理课上明白的一件事，又改写了她下一次画阴影的手。三样的变化互相牵连，而且牵连的方向不止一个。我之所以敢在本章末尾写撤回条件，是因为这类牵连是能被看见、被记下来的：只要每一单之后留三行，三个月以后翻回去，就能看有没有这样的连线。

回写这件事，在职场里也常见。设想一个新人，因为一次客户投诉学会了读人，读人又让他开始学产品，产品懂了，他再面对下一个客户时，投诉的方式都变了。没有哪个培训部门设计过这条路，它是在一个个具体的单里连起来的。我们大人能做的，是别在它连起来之前，先把它切开。

### ◆ 三样各自的秩序、混沌、介生

到这里，有必要把全书的三个分析用语请回来。秩序，指已经有现成答案、有人管、可以照着办的东西；混沌，指还说不清、对不上、没有现成答案的东西；介生，指混沌被某个人接住，在后果落在她身上的前提下，慢慢长出她自己的小规矩。三样都有这三种状态，下面这张表是我对着小满的这一单，给三样各填的一行（都是示例，不是她的纪实）。

| | 秩序 | 混沌 | 介生 |
|---|---|---|---|
| 关系 | 校规、礼貌：见了老师问好，同学之间不起冲突 | 说不清的别扭：客户一句“太甜”，她读不懂、有点烦，又不知道该怎样问 | 试着说一次，再调整：问客户“是颜色太甜还是人太甜”，听到回答后再改 |
| 赚钱 | 平台规则、市面价目：接单的流程、行情的价格 | 不明白为什么有人愿付钱：同一个头像，为什么这个人肯出这个价 | 自己慢慢定下的底价与规矩：哪类单子接、哪类不接、怎样收定金 |
| 学习 | 作业、考试：布置好的题，有标准答案 | 订单里冒出的叫不出名字的数学疑问：阴影的角度、图像放大后的比例，她说“这个我老算不对”，却说不清是哪一门的东西 | 自己定的用AI规矩与疑问本：先自己猜一遍再问AI；把没弄懂的记下来 |

这张表最该看的，不是每一格，是它的纵向。先看秩序那一列：三样里的秩序，学校和平台、市面其实都给了，而且给得不坏。校规礼貌、平台规则、作业考试，都是可靠的东西，该有，我从不主张拆掉。

再看混沌那一列：这一列的三个格子，是一件事的三个面。她读不懂客户那种别扭，是关系的混沌；她不明白为什么有人愿为这个付钱，是赚钱的混沌；她说不出那是哪门数学，是学习的混沌。我把它们并排放，是因为它们在她心里本来就是同一团：“我不明白这个人为什么要这个、为什么愿意付这个钱、我又为什么画不出来。”

最后看介生那一列：试着说一次，是关系里长出来的；底价规矩，是赚钱里长出来的；疑问本和用AI规矩，是学习里长出来的。三个规矩互相咬合：她问客户的那一句，让她有了想学的东西；她学的东西，让她有了可以定价的新画法；她定下的价，又影响她愿意接什么样的客户。

这里要把第6章的一个提醒提前说一句：三态是分析用语，不是排名。我没有说混沌比秩序好，介生比混沌高级。表里的秩序一列，家里该稳稳给的就要稳稳给，作息、安全、诚信，这些都不是介生可以替代的。

我要提醒的只有一点：如果三样的混沌和介生都被秩序抢先填满了，比如客户一说“太甜”，我就递过去一套标准话术，她问AI，AI又给一套标准流程，那一团“我不明白”还没来得及长成她自己的东西，就已经被一个现成的答案盖上了。这就是为什么我说，孩子没交给学校的那一半，是三样的混沌与介生。它们是同一次发生里最活的部分。

### ◆ 一个更完整的成长框架：看、懂、选、做、改

回到我最初写给老师的那个问题：关系、赚钱、学习这三方面，能不能放进一个更完整的成长框架里理解？孩子怎样通过一次次具体的经历，逐渐学会观察现实、理解问题、作出选择、采取行动，并根据结果修正自己的认识？我的回答是：能，而且这个框架不需要另外搭，就在这一单里。

把小满这一单里发生的动作，按先后排一排。她先是看：看客户的话，看第一稿给人的感觉；然后是懂：弄清“太甜”指的是人而不是颜色；然后是选：用什么画法，要不要接这一类单子，花多少时间；然后是做：画，交稿；最后是改：根据客户的“就是这个”，也根据自己事后的感觉，改掉自己原来的做法。看、懂、选、做、改，五个字，就是我当时问的“观察现实、理解问题、作出选择、采取行动、根据结果修正”。

这五步在三样里各有各的味道。在关系里，看是看一个人的表情和话语，懂是弄清他在意什么，选是选说什么、让不让，做是开口，改是看对方反应再调。在赚钱里，看是看一个需求，懂是弄清为什么有人愿付钱，选是定价和接单，做是交付，改是用收到的回执修正下一次。在学习里，看是看到自己不会，懂是弄清自己缺的是什么，选是选哪种方法和资料，做是练，改是用结果去检验学没学会。同样五步，只是材料不同。

孩子的“成长框架”，说到底就是这五步在三类材料上，一次一次地转。转得多了，不同材料上的五步就开始互相借力：读人时练出的“弄清他在意什么”，用到了学习里的“弄清自己缺什么”；赚钱里练出的“用回执修正”，用到了关系里的“看对方反应再调”。这种互相借力，才是我理解的“零散经历变成能用的能力”。

那零散的经历，怎样才能变成能用的东西呢？这里要借我在那篇谈工作经验的文章里的办法。那篇文章里说，经验若没有地方留下，就会跟着聊天记录一起往下沉；“经验有地方留下，才有机会在下一次关键时刻，重新回到现场”。对小满来说，这个“地方”不必是一本漂亮的笔记，三行就够，而且是她自己写：这一单卡在哪里，哪一步让事情往前走了，下次可以提前做什么。她若愿意给我看，我就看；她不愿意，那三行也依然在她手上。我要做的只是在她愿意讲的时候，用三问陪她走一遍，而不是替她把三行写完。

还有一个界线要划清：我说的是“框架”，不是“流程”。框架不是规定她必须按看、懂、选、做、改的顺序一步一步过。实际接单时，常常是做到一半又回去看，改到一半发现没懂，这五步不能当作单向的流水线来读。我拿五个字，只是为了让大人有个地方可以放眼睛，不至于盯着一个点（钱、分数、情绪）失焦。至于这些经历共同指向什么，第16章会专门谈，这里只先放一个朴素的说法：判断力，从看和懂里来；行动力，从选和做里来；对自己选择的责任感，从改里来；合作能力，在每一步里都要碰到另一个人。这四样在一单里全都有，所以我才说，三样其实是一件事。

### ◆ 一件家里马上能用的工具：一单三栏

最后给一个很小的做法，我叫它“一单三栏”。不用买什么，一张纸或者手机备忘录就行，哪怕只记在脑子里。她讲完一件事（订单也好，一次作业也好，一次和同学的别扭也好），我在心里分三栏，不记给她看，也不让她填。第一栏，关系：这件事里，她读了谁、读到了什么，哪里没读懂？第二栏，价值：这件事里，有没有人因此得到了什么，或者没得到什么？回执是什么形式（一句话、一笔钱、一个分数、一个沉默）？第三栏，学习：为了把这件事做成，她去学了什么、用了什么？还有什么说不清的东西？

三栏填完，我只做一件事：看哪一栏空着。如果她讲了半天，关系栏很满，价值栏是空的，那下一次我可以问：“那这个人后来怎么说？”如果价值栏有钱，学习栏空着，我可以问：“为了做成这个，有没有你以前没用过的东西？”空栏不是缺点，是下一次可以顺着问的入口。我从不把三栏拿给她打分，也不要求三栏必须均衡。均衡是我的秩序，她的单子有自己的重心。

举个用法的例子。〔示例性情境〕假设她哪天回来，只讲了一件事：同桌借了她的画册，翻的时候说“你这个人物怎么都不笑”，她当时有点不高兴，没接话。我在心里一过：关系栏有东西，她读到了同桌的一句评价，却没读懂那句话是夸是损；价值栏是空的，没有回执；学习栏也是空的。这时我不去解释同桌的意思，只问一句：“那你自己觉得，她是在说什么？”她若答不上来，那一栏就先空着；她若答上来了，说不定就是下一单“不要太甜”的前身。要点是，这张卡不替我下结论，只替我挑出下一句该问什么。

三栏的目的，只是帮我不要只听见一样。我这个人，职业病重，一听见“钱”就想谈规则，一听见“学习”就想谈计划，一听见“别扭”就想谈沟通技巧。这张小卡是给我自己用的，防止我一路滑进某一格里去。偶尔，也可以倒过来：隔几天让她自己讲讲“这个月三样里，哪一样最近动得最多”。她若讲得出来，我就知道她心里有这个框架；她讲不出来，也没关系，说明还没到那一步。

还有一个小提醒，是给用AI的家长的。如果你问AI“我女儿接单怎么引导”，AI多半会给你三条整齐的建议：沟通、定价、学习，各一条。那三条每一条都对，合起来恰好是把三样拆开教的样子。拿它们当材料可以，拿它们当听她讲话时的起手，就晚了半步。

### ◆ 这个看法的适用边界

最后交代这个看法用在哪里、不该用在哪里。第一，它是对着一个已经有一件具体事做的孩子说的。若她手里还没有任何一单、一个项目、一次自己主动要做成的事，三样就没有可以互相生成的材料，这时候硬谈“三样是一件事”，只会变成一套新的说教。先帮她有一件事可做，比先讲道理要紧。

第二，三样互相生成，不等于每一件事都要凑齐三样。她只是喜欢画一张画，没有客户，没有钱，也没有要学的东西，那就让它只是喜欢。我在《认知以外的钱：一个雨夜里，孩子给我上的一课》里就写过，要允许孩子保留一部分不变现的爱好，不要把每个爱好都推向赚钱。

第三，年龄和性格会改变三样的比重：话多的孩子，关系一栏会很满；闷头做事的孩子，学习一栏会很满。我不拿一个均衡的样子去量她，只看三栏之间有没有线连着。线若长期连不上，也不必着急认定是她的问题，先看是不是我自己的听法把线剪断了。

### ◆ 撤回条件

这一章的核心判断是：关系、赚钱、学习是同一次发生的三种显露，三样互相生成，拆开教都会变形。如果出现下面的情况，我认为这一章错了，或者只剩比喻的价值：

第一，如果在小满（或任何一个孩子）较长时间的真实记录里，三样的变化彼此毫不牵连——关系上的进步，从来不伴随赚钱或学习上的任何动静；订单里学到的新东西，从不改变她读人的方式或家里的安排；钱的变化，从不影响另外两样——那么“互相生成”就只是一个好听的比喻，不是描述。这个记录不难做：每一单之后，用“一单三栏”记几个月，看三栏之间有没有可见的前后牵连。

第二，如果把三样拆开分别教的家庭，孩子在三样上的长进，与合在一起看的家庭相比，没有任何可观察的差别，那么“拆开教会变形”的说法也要收回。

第三，如果家里用了“一单三栏”之后，孩子反而更不愿意讲订单，说明我的三栏正在变成她眼里的另一种检查，这时要先停下工具，回到听她讲。

## 第 6 章　混沌要有底，介生要有人接

### ◆ 周末的那张纸

〔示例性情境〕下面这一幕是我为了讲清道理拟的，不是某个周末的纪实。周日上午，小满把iPad架在餐桌上，笔尖悬着，说今天想画一整天。我正在厨房切水果，脑子里已经有了一套回应：作业写完了吗？下周有没有小测？画画可以，但得有个时间表。这套回应不是我当场想的。前一晚我睡前问过AI，问法大致是“高中生周末想花大量时间画画，怎样平衡学习”，它给了我一份很得体的方案：上午学习三小时，下午画画两小时，晚上复盘。条理清楚，语气温和，还提醒我“要尊重孩子的兴趣”。我当时甚至有点得意，觉得自己这次不会吵了。

我端着果盘走到桌边，话已经到了嘴边，是那份方案的第一句。就在这时我听见自己心里冒出另一句，很小，不太体面：这个方案，是我的，还是它的？我在公司做了二十多年人力资源，太熟悉这种感觉了。有人把一份做得很漂亮的制度文本递到你手上，你读完觉得句句在理，却说不出哪一句是自己的判断。我把话咽了回去，放下果盘，问了一句不在方案里的话：“今天想画什么？”

小满头也没抬，说：“不知道，画到哪儿算哪儿。”然后她又补了一句，让我在桌边站了很久：“你们是不是又觉得这不算正事？”这句话里有试探，也有一点早就准备好的防备。我一下子明白，我心里那份方案，她隔着桌子就闻到了味道。周末画画算不算正事，这个问题在我们家从来没有被正面讨论过，它一直以“作业写完了没有”“时间表”“有什么用”的形式，在各种缝隙里渗出来。

这一章就从这张桌子讲起。上一编讲了学校接走的是秩序，AI让秩序来得更快；这一编要回答一个更实际的问题：家里到底要留出什么，留到什么程度，留了以后谁来管。我先把判断说在前面：不能都是秩序态，不等于不要秩序。家要给的，是有底的混沌，加上有人承接的介生。底是什么，人怎样接，这两样说不清，“给孩子留空间”就会滑向两种坏结果，一种是什么都管，一种是什么都不管。

### ◆ 前人说到哪里，三态不是排名

先把前人的好答案摆出来，免得我把别人早就说过的东西当成新发现。说“管与放”的人很多。有一类研究讲的是教养方式：要求与回应兼备，是一种值得单独命名的教养（鲍姆林德关于权威型教养的研究，1966）。有一类讲的是独处：孩子在可信赖的人在场时，能安然独处（温尼科特，《独处的能力》，1958）。这两类说法我都信，它们说的是同一件事的两面：底要稳，空要留。我自己做人力资源时用的是另一套话，叫“授权不授责”，把任务交出去，把责任的边界讲清楚。放在家里，它也有用，但有一个我后来才看明白的缺口：它默认被授权的人已经有了自己的判断，而十六岁的小满正在长这个判断，长的过程中恰恰需要一个“不被当场评估”的地方。

本书给这件事的说法，是三个词：秩序、混沌、介生。我在第一本书里用它们看过职场，在这里要用它们看家，所以第一件事是把话说死：这三个词是分析用语，不是好坏排名。秩序，是可以照着做、可以交接、可以事先说清楚的那部分，像作息表、菜谱、考试大纲。混沌，是还没有成形的东西：一个说不清的偏好，一阵无缘无故的热情，一笔画了又擦、擦了又画的线。介生，是混沌里开始有形状、有人在半接着的那一段：她试了一种新画法，有一个人看见了，没有评分，只说“这里和上一张不一样”，下次她又改了一点。

我要强调“不是排名”，是因为一不小心，读者会把它读成“秩序低级，混沌高级”，然后回家把家规全撤了，等着孩子“自由生长”。那不是本书的意思，书里也没有任何一处说过存在一个“最佳比例”，三态各占多少才对，没有可测的答案，谁给你一个数字，谁就是在编。三态的用处，只在于帮你认出：这一刻，这件事，它在哪个状态，我现在的回应是在服务它，还是在压它。同一个周末下午，同样是画画，它可能是混沌（她只是想画点什么），可能是介生（她在试一个新的上色办法，并且打算让朋友看），也可能是秩序（她在赶一个答应了别人的交稿日）。三种状态各有各的对待方式，对待错了，不报错，只是越认真离孩子越远。

“不能都是秩序态”这句话，最容易被误读成“不要秩序”。我在这里把一条线画清楚，因为这是全章的地基：有一类秩序，家里必须稳稳地给，不让渡，不商量。它们是作息、安全、健康、诚信。睡够觉，晚上几点之前回家，出远门要报个平安，生病了去看医生，答应了别人的事要做到，不骗人也不被骗。这些事不是“妈妈的偏好”，是一个人能够安心去混沌的前提。我管它们叫可靠的秩序：可靠，是说它稳定、可预期、对孩子说得清理由、违反了后果由规则而不是由妈妈的心情来决定。

另一类秩序我叫封闭的秩序。它的外形和前一类很像，也是规则、安排、要求，区别在于它有两个特征。一是成功归大人，失败归孩子：考好了是“我们的安排对”，画砸了是“都怪你不专心”。二是每一处空白都被填满：周末要有计划，计划要有产出，产出要能说得出“有什么用”，孩子刚做完一件事，回答之前先得准备好那句“今天做了什么”。封闭的秩序不见得严厉，很多时候它是温柔的，甚至是充满爱意的，正因为这样，它最难被家长自己认出来。第537号把这件事讲成账本问题：学校只为秩序立了账，而未定与承接从无份额。放在家里，同样的情形是：家里的账本上，只有“完成”这一栏，没有“试过”那一栏。

分辨两类秩序，我有一个土办法，是向自己提三个问题。第一，这条规矩的理由，我能不能在十五秒里说给她听，并且允许她追问？“十一点前睡觉，因为你周一早上五点五十就要起”，能；“你就该这样”，不能。第二，这条规矩出了问题，后果由谁承担？睡晚了第二天犯困，是她自己的后果，那就让它落在她身上；如果每次她犯了错，我都要替她挡一下再批评她一顿，那这条规矩就在偷偷把后果转移走。第三，这条规矩有没有时效？可靠的秩序可以有变化，十六岁的睡觉时间和十岁的就不一样，它随着她长大被重新谈；封闭的秩序则几乎不改，因为它从来不是为她定的，是为我的安心定的。

这三问在周日那张桌子边帮了我一把。“作业写完了没有”是一条可靠的秩序吗？如果我愿意在十五秒里讲出“因为周一的数学课要交，错过了你自己会难受”，并且允许她说“我周六晚上已经写完了”，那它是。如果它只是一个条件反射，是我焦虑时的呼吸，那它就是封闭秩序里一个漏气的阀门。我那天问的是前者，她答的是：“写完了，周五晚上就写完了，你没检查。”我愣了一下，才想起周五晚上我加班，确实没有检查。可靠的秩序和封闭的秩序，有时候差的只是我有没有认认真真听她回答。

### ◆ 自由为什么变成了手机

讲有底，最好的反面教材，是没有底的自由。第324号《SDE教育发生学导论》里有一个例子，我读了好几遍。一所中学的年级主任对家长说，高一给学生“充分的自由”：作业自选，座位自选，社团自选。头两个月，一部分学生如鱼得水，另一部分不知所措，有几个直接把自由用成了睡觉和手机。主任于是得出结论：现在的孩子不适合自由。第324号对这个结论的回应，我愿意原样引一句：“缺的并不是自由，是自由所需要的善的结构。”

这句话的价值，在于它把“放”拆开了。那几个学生不是自由过多，是自由里缺了三样东西：没有人帮他们看清选择的后果；没有同伴共同体来承接选择；也没有足够的现实体验去知道自己喜欢什么。换成家里的话说：你对孩子说“周末你自己安排”，如果这句话背后没有底（睡觉、安全、健康这些不让渡的东西没有说清），没有人（她做出的选择，没有一个人愿意认真看一眼、问一句），也没有她自己的东西（她从未有过一次让“我想要”被认真对待的经历），那这句“自由”不过是把她从一台秩序机器里拎出来，丢进一个没有任何东西接着的空房间。她去睡觉、去刷手机，不是她堕落，是房间里除了这个，没有别的东西在回应她。

职场里也有同样的事。设想一位新来的年轻人，主管说“你放手去做，有问题找我”，三个月过去，他做得小心翼翼，只做那些肯定不会错的事。主管的“自由”是诚恳的，缺的是一件事：他没说过出了错会怎样，也没说过做对了会有谁看见。自由放下去，没有后果，没有人看，就退成了谨慎，谨慎又退成了应付。

那么有底、有人接，具体是什么样子？第586号讲企业里的混沌时，给过承接的四个条件，我借来用在家里，一条一条对着看。第一条，她的差异能进来。差异，指的是她和我们、和同学、和昨天的自己不一样的那一点：她偏爱某种线条，她对某个角色有自己的解读，她觉得这个科目“没意思”。能进来，意思是这个差异可以被说出口，被听见，而不是一出现就被翻译成“态度问题”或“小孩子想法”。第二条，后果能留在她身上。她答应了别人的稿子晚交，那份尴尬是她的；她把整个周末给了一幅画，周一的小测没复习好，那份后果也是她的。后果留在她身上，不等于我袖手旁观，而是我不抢在前面把后果消掉，也不在后果之后补一刀“早就跟你说了”。



第三条，她自己的小规矩能成形。这是最容易被忽略的一条。孩子在混沌里摸索，慢慢会长出一些自己的办法：画画前先听同一张歌单，每张图收工要放三个小时再回头看，不接超过三天的急单。这些规矩粗糙、局部、有点怪，家长常常的反应是“这不科学”。可是它们是她判断的雏形，要给它们一点“成形”的空间，哪怕只是不去嘲笑。第四条，这些规矩以后还能改。这一条是把前三条护住的保险：小规矩一旦被当成不可动摇的“原则”，就硬化成另一套秩序了；她今年定的“不接急单”，明年也许发现急单是练速度的好机会，这时她改规矩，不是出尔反尔，是长大。承接的四个条件，少了任何一条，混沌要么退回原样，要么变成一套新的封闭秩序。

少了哪一条，会长成什么样，我也举几个家里的例子，免得四个条件读起来只是一份漂亮的清单。少了第一条，差异进不来：她说“我觉得这个科目没有意思”，我回一句“高中就是要把每科学好”，她下次就不说了，混沌退回肚子里，变成沉默。少了第二条，后果留不住：我每次都在她出错前替她补好，她得到的是顺滑的日子和一个始终没有长出来的“我”。少了第三条，小规矩成不了形：她刚说“我想每天画前先热手十分钟”，我笑一句“还挺讲究”，这条规矩就被笑回了混沌。少了第四条，规矩不能改：她定的规矩被我夸成“这才是自律”，从此成了她不敢动的标杆，混沌硬化成了另一套秩序，只是这一次，是她自己替我们守的。

这也是我对“混沌不是放任”的理解：放任，是四个条件一个都没有；留份，是四个条件都在，只是它们看起来很轻，轻到旁人以为家里什么也没发生。

### ◆ 三问，和一个起手

把这些放回周日的桌子上，我对自己做了一遍书里一再讲的三问，只是换成了大白话。第一问，她这次显出来的东西，是从哪里长出来的？“今天想画一整天”是一句很小的话，往回看，它背后是她用那支五块钱的触控笔在一个假期里画下的几十张头像，是她算过自己大约四十元时薪的那种清醒，是她每周在学校里被分数和排名覆盖的那一部分自己，终于有一个出口。它不是心血来潮。看清这一点，我对“算不算正事”的态度就变了：我不再是在评估一个爱好，而是在面对一条已经有来历的线。

第二问，凭她已经显出来的和手边的条件，下一步能试什么，多大一步？她今天不需要我给她一个宏大的计划，她需要的是一个下午；下一步不是“画画变成事业”，也不是“画画必须换算成成绩”，而是“今天画一整天，晚上我们看一眼画成什么样”。一步要小，小到她失败了也不丢脸，成功了也不必立刻变现。第三问，这一次之后，她的现实、她对世界的看法、她对自己的看法，还有这个家，哪里被改写了？这一问当天答不出来，要在后来的几天里才慢慢浮出来（这仍是拟想的情境）：她也许第一次得到“妈妈没有问有什么用”的体验，我们家那条不成文的规矩（画画是下班后的奖励，不是正事）开始松了一个角。

复合主体的时代，还有一问是对我自己的：我的看法从哪来的？那天我拿着的方案，是前一晚AI给的，我若直接念出去，就成了典型的同源回声：妈妈问了AI，拿到一个看法；小满回头也会去问AI，大概率拿到相似的看法，然后我们两个人在饭桌上“谈得很顺”，彼此赞同，彼此理解，可我们的共同点并没有进入彼此，只是我们各自进入了同一个AI。共同点越多，关系越少，这是一种负向的发生，它也是发生，不是什么都没发生。所以我给自己立了一条规矩：妈妈的AI，只在她请我拿主意的时候才上场，而且上场时先摆材料，不先摆结论。那天她没有请我拿主意，所以我的AI应当留在口袋里。

这就牵到一个读事的起手问题。同一件事，起手不同，走的路完全不同：她来讲一件同学的事，我先跟着经过走，问“后来呢”；她卡住了，我先看卡在哪一步，再调条件；她谈钱、谈家规，我先把材料摊开，结论最后由她自己得出；她明确地说“妈你帮我拿个主意”，这时才轮到我用职场里那套先明靶子、再盘家底、后定路线的本行。周日那一幕，她没有请我拿主意，所以我什么也没拿，先问了“想画什么”。读不准的时候，我就直接问她一句：“你想让我先听你讲，还是一起想办法？”这一句看起来笨，其实是在保护那段混沌，因为它让主动权停在她手里。

接着要点名这件事里的矛盾，因为矛盾是家里的发动机，不是故障。这一天的矛盾，一句话说：她在推进“我想用一整天去做一件没有答案的事”，家里和学校稳着“时间要换成可以说得出的东西”。这两股力打架，有三种常见的改法，要改的永远是第三项，也就是那个把两边的力连起来的东西。

如果打架的是“她已经显出来的”和“她想试的”（比如她擅长画头像，却想试风景），要改的是条件：给她一个不必立刻有成果的试验场。如果打架的是“她的价值”和“家规校规”（比如她认为画画重要，家规认为作业重要），要改的是做法：把作息和作业的底先稳住，再把画画的时段明确划出来，不拿来讨价还价。

如果打架的是“她的尝试”和“环境”（比如她想把画拿给同学看，同学却只关心她的成绩），这一项只能她自己改出新的样子，妈妈和AI都不代改。

最后还要问一句回写：这个变化，又反过来改了什么？一场对话如果聊过就算了，没有回到她的现实、她的想法、她和我的关系里，就是白聊。

回到周日那句“今天想画一整天”，我把当时可能出现的三种回应并排放一下，看它们各自给小满留下什么。第一种，方案式回应：“可以，但上午先学三小时，下午再画。”这句话的善意是明显的，它甚至没有拒绝。小满得到的感受是：我想要的东西，要经过批准才算数；她得到的认识是：画画是学习之外挤出来的余量，它的正当性要靠学习来兑换；她的行动空间是，在三小时和两小时之间讨价还价。她不会反抗，大概会应一声“好吧”，然后在上午的三小时里心不在焉，下午的两小时里匆匆赶工。我们都按方案走了，没有一个人出错，可是那一天里小满的混沌，在她开口之前就被翻译成了日程。

第二种，放任式回应：“随你，你自己安排。”然后我回屋刷手机。这一句听上去像尊重，小满得到的感受却可能是：她做什么，我无所谓。她得到的认识是：画画是个人私事，与家无关，没有人在意；行动空间看似很大，实际上空无一物，因为没有一个人会看她的画，没有人问她手画得怎么样。这正是第324号年级主任那个故事里的“充分的自由”，她大概率会画一阵，然后转去刷手机，不是因为她不爱画，而是因为无人回应的自由，很快就变成了无聊。

第三种，承接式回应，也就是我那天做的：先问“想画什么”，不给方案，不置可否，把底在另外的时机讲一次（睡觉时间、周一要交的东西），晚上请她把画给我看，只反射和追问。小满得到的感受是：这个下午是她的，而且有人在旁边；得到的认识是：画画可以不需要先被证明有用；行动空间是，她可以画坏、可以改、可以决定要不要给我看。三种回应之间的差别，不在于哪一句话更温柔，而在于她的差异有没有进来、后果有没有留在她身上、她自己的小规矩有没有位置。

### ◆ 留份三处，要一起松

三问、起手、点矛盾，说的是怎样“看”；留份说的是怎样“让”。第537号在处方里提了一个词，叫留份，大意是：不是在秩序之外再加一种守护，而是在时间、评价、关系三处，各让出一块地方。我把它改写成家里的话。

时间上，留一些不被安排、不被追问“今天做了什么”的时段。比如周日下午两点到五点，不是“自由学习时间”，也不是“兴趣培养时间”，就是没有名字的时间。她可以画，可以躺着，可以对着窗外发呆，可以把一幅画画到一半丢掉。要紧的不是这三个小时的用法，而是三小时之后我不问那一句“今天做了什么”。这一句问话听起来平常，但它背后的意思是：时间需要被说明。孩子一旦知道每段时间都要被说明，她就会开始在做之前先想“怎么说”，混沌于是在发生之前被预先翻译成秩序。

评价上，留一些不打分、不比较、不问“有什么用”的草稿与尝试。她画了一张随手的涂鸦，我不说“不错”，也不说“这个比上次差”，更不问“这能接单吗”。我只能说看见了什么：“这条线收得挺狠。”或者“这里你没有描边。”这类话的好处在于，它不下判断，却让她知道有人看过。草稿的意义，是它可以失败，一旦草稿被评价，它就不再是草稿，而成了作品，作品就要对得起观众。留一类东西永远是草稿，孩子才敢在上面长新东西。

关系上，妈妈在场，但只反射、只追问，不替答，也不替她问AI。反射，是把她说的话换个说法放回去：“你是说，这一张你想让它看起来冷一点？”追问，是顺着她的话往下一步：“冷的话，你打算用什么色？”不替答，是她说“我不知道这里怎么办”的时候，我不立刻给方案，哪怕我手上就有一个。不替她问AI，是更新的一条：她卡住了，我也不顺手打开手机，把她的难题转手问一遍AI再把答案递给她。我这样做，等于把她的混沌在她自己动手之前，换成了一份来自AI的秩序。

这三处必须一起松。只松时间，不松评价：她有了整个周末，却知道周一要交一份“周末成果汇报”，那个周末就是一场表演。只松评价，不松关系：我不打分，但整个下午站在她身后，每隔十分钟问一句“画得怎么样了”，她一样画不下去。只松关系，不松时间：我安静坐在旁边，她的日程却被补习班塞得满满，坐再久也没有空隙。三处只要有一处是紧的，另外两处的松就会被它抵消，第537号说“留份要小而窄，自带抵抗被收编的结构，事先写明失效条件，三处同时松动”，小而窄这三个字尤其重要：不要一上来就想给她一整个暑假的混沌，从每周三个小时开始，做稳了再说。

另外有两条，我把它们放在三处留份的外面，因为它们是留份的前提，不属于留份。第一条，底不让渡。作息、安全、健康、诚信，这四件事无论她多投入、多有灵感、多“正在状态里”，都不退。她画得入迷，凌晨两点还不睡，我会敲门，理由十五秒讲完，不吵，也不让。这不是对混沌的压制，恰恰是混沌能长久的保险：一个身体垮了、睡眠崩了、信用丢了的孩子，是没有力气去混沌的。

第二条，女儿的混沌不拿去问妈妈的AI。这一条我写得很重，因为它是我们这个时代才有的新诱惑。比如她某天跟我说了一个模糊的想法，说得断断续续，我会忍不住想“让AI帮我分析一下她这是怎么回事”，这样做，等于把一个孩子半成形的东西，不经她同意，送进一个会立刻把它整理成标准话术的机器里。分析出来的东西往往很对，对到她自己的那个“不对”（那个说不清的、才是她的部分）被磨平。她的混沌，由她自己决定要不要给AI看。

那天晚上的事，我也记在这里，因为它说明留份之后会发生什么，也说明不会发生什么。〔示例性情境〕她画了一整天，晚饭后把iPad推到我面前，说：“你看吧，随便看。”我没有说“不错”，也没有说“你一天才画这么点”。我问：“这张你最不满意的是哪里？”她指了左手，说手总是画不好，今天画了六七遍。我顺着问：“六七遍里，哪一遍最接近你要的？”她翻了翻，指了第四遍，说：“其实第四遍对了，我后来又改坏了。”我说：“那第四遍为什么对？”她停了一会儿，说：“因为那时候我没想着要它好看，只想着它在抓东西。”这句话我没有追，我怕一追，它就从她嘴里变成我嘴里的结论。我只是点了点头，起身去洗碗。

这一幕里没有一句教育，也没有一句夸奖，可是四个条件都在：她的差异（手画不好，第四遍对了）进来了；后果（改坏了第四遍）留在她身上，我没有安慰她，也没有替她惋惜；她那一句“抓东西”，就是一条正在成形的小规矩，关于画手的；至于这条规矩以后改不改，是她的事。我所做的，只是在三个地方没有抢：没有抢着评价，没有抢着总结，没有抢着去问AI“画手有什么技巧”。不过这样的晚上并不总是有。也可以设想另一种：她画完把iPad一合，说“没什么好说的”，我就什么也不说，这同样是留份的一部分：承接的人要接得住“没什么好说”，不能每次都要回报。

留份是有代价的，我不想把它写成只赚不赔的买卖。第一个代价是成绩。她把一个下午给了画画，周一那个小测，复习得就不如以前细，分数也许会掉几分。这几分是留份的价钱，要由她自己看见，我不替她买单，也不拿它做“你看吧”的证据。

第二个代价是家里的声音。亲戚聚会上总会有人问“最近成绩怎么样”，学校群里也有“周末要不要去补课”的讨论，我会感觉到压力，有时候甚至会怀疑自己是不是在耽误她。这时我提醒自己的，是那个年级主任的故事：放手本身没有错，错在放手以后没有底、没有人。我既然守住了底，也站在这里承接，那么暂时看不见的东西，就让它暂时看不见。第三个代价是我自己的不安。留份最难受的地方，是我不再是“正在做点什么”的那个人，我只是在场。二十年职场里练出来的“推进感”，在家里必须收起来，这对我是一个很具体的修行。

### ◆ 讲到什么程度

问题清单里有两个问题，落在这一章。一个是：父母怎样把握引导的程度，让孩子既能享受探索的兴趣，也有机会逐渐理解事情背后的条件与责任？另一个是：这些认识，父母应该讲到什么程度？我的回答是三条，都不新，但放在“有底的混沌”这个框里，才有了位置。

第一条，分类讲：底线类的事讲全，探索类的事讲到她接得住。底线类，指作息、安全、健康、诚信，还有“答应了别人的事”。这类事，一次讲清楚，理由讲透，允许追问，之后不再每天重复。比如她接了一个单，答应了周五交稿，这个“答应”的分量，我会一次讲完：答应了就是答应了，做不到要提前说，不能等到对方来问。探索类，指的是画什么、怎么画、值不值得、要不要往这个方向走，这类事我只讲到她下一步够用，不讲到我自己放心。我放心不放心，是我的事，不是她下一步需要的东西。

第二条，讲条件不讲结论。〔示例性情境〕设想她刚赚到第一笔钱，我不会马上给她一整套“需求、劳动、成本、信用、责任”的框架，那是成人世界的要求，扣在一个刚有点实践的孩子身上，会把她的兴趣压成义务。我会在她提到某位客户的时候，问一句“他为什么愿意再找你”，她答得出就答，答不出就搁着。条件，是她自己遇到之后才有感觉的东西，我能做的是在她遇到的那一刻，递一个问句，而不是在她遇到之前递一份讲义。至于“这笔钱说明什么”这样的结论，由她自己得出，哪怕得出的和我想的不一样。

第三条，讲到她能自己问出下一个问题为止。这是我判断“讲够了”的信号：如果我讲完，她只是点头说“哦”，说明我讲过头了，她收下的是我的结论；如果我讲完，她追了一句“那如果对方不付钱呢”，说明我讲到了刚好。这个信号很朴素，却很管用，它把判断“讲多少”的权利，从我的焦虑转到了她的好奇。

再举一个〔示例性情境〕，不是小满的，是我拟的另一个家，用来看同一套办法在别处怎么走。一位母亲，孩子喜欢拆旧电器，某个周末把家里的闹钟拆成一堆零件，装不回去了。母亲心里有三种声音：骂他浪费，教他怎么装，或者“看他自己怎么办”。按本章的办法，她先分类：闹钟拆了，是后果，留在孩子身上，不替他装；晚上睡觉前把零件收到盒子里，是作息与整洁的底，不让渡；至于这堆零件算什么、值不值得再拆下一件，是探索，只问一句“你拆的时候，发现里面有什么你没想到的”。孩子说了一个，母亲就听着，没有再多讲。过两周，孩子自己说，下次想先画一张图再拆，这是他自己的小规矩，在成形。又过一阵，他说画图太慢了，不想画了，这条规矩被他自己改掉了。四个条件走完一圈，母亲没有讲什么大道理，她只是没有抢。

如果有人问：那么从哪里开始？我的建议是小而窄地开始，不要宣布。不必开家庭会议告诉孩子“从今天起我们家要留份”，那样做，留份本身又变成了一套新的要求。我打算这样开头：第一个月只做一件事，每周挑一个很小的时段，大约一个小时，在这一个小时里，我不问、不评、不评估，只是在场。第二个月，把“评价”这一栏加进来：她给我看什么，我只说看见了什么，不说好坏。第三个月，才把底的几条重新梳一遍，把那些我自己都说不清理由的规矩，要么补上理由，要么撤掉。顺序是先松后立，因为底的重新梳理需要建立在她已经觉得“家里有一块地方是安全的”之上，否则她会把每一条被重新讲出来的规矩，听成新一轮的收紧。

这里也要说一说我自己最容易犯的错。我是一个习惯了“把事情推进下去”的人，职场里这是美德，在家里它常常变成急着收口。她话说了一半，我已经把话接完了；她停顿了三秒，我已经给出了方案。留份对我来说，最具体的练习，就是数到五：她说完一句话以后，先数五个数，再决定我要不要开口。我猜多数时候，五个数里她自己会再补一句，那一句往往才是她想说的。

另一个容易犯的错，是把“底”扩大。底是四条，作息、安全、健康、诚信，一旦我开始说“学习态度也是底”“礼貌也是底”，这个词就会像气球一样越吹越大，最后把所有的混沌都装进去。我给自己的纪律是，凡是我想把一件事列入底，先问自己：不这样做，她的身体、安全或信用，会不会在一个月内受到可见的伤害？不会，就不是底。

### ◆ 为什么这一半只能在家里长

读到这里，有人会问：这些事学校做不到吗？学校里也有社团，也有选修课，也有老师愿意听学生说话。我的看法是，学校当然可以做，也有很多老师在做，但它的结构决定了做不完整。第537号讲学校的账本，说它只能承认被翻译成可比较量值的东西，这不是谁的错，是它要对全社会证明托付没有落空，而证明就必须有事先划定的方向和能排序的结果。一个社团再自由，最后也要出一份活动记录；一门选修课再开放，最后也要给一个等第。学校留不出一块“永远不用说明”的地方，因为它没有这样的账可以立。

家不一样。家的账本是自己写的，没有陌生人要来核对。一个下午画了什么、画坏了什么、有没有画，不需要对任何人说明，只对这个家里的两个人。这就是为什么我在书的开头说，孩子没交给学校的那一半，只能在家里长。可是也正因为家的账本是自己写的，它也最容易被自己写成学校的样子：我把学校的作息表、评价口径、问话方式，原样搬回了家。那样，学校接走了秩序，家里又替学校加了一遍班，孩子从早到晚，没有一寸地方是不用说明的。

AI的出现，让这件事变得更紧迫。AI会把任何一团模糊的东西很快整理成通顺的话，妈妈的AI如此，孩子的AI也如此。孩子随口问一句“我想画点不一样的，怎么办”，得到的是一份有条理的建议清单；她照着做了，画得不错，却没有经历过那一段“不知道画什么”的混沌。那一段混沌正是她判断长出来的地方。所以在AI的时代，家里的留份不能只是“少管”，还要有意识地给孩子留几个不绕开AI也不被AI填满的节点：比如先自己画三笔再去问，先说出自己的想法再看别人的；这一类“先猜后问”的小入口，我会在后面讲学习的章节里细讲。

### ◆ 家庭留份卡

下面是我拟的一张小卡，写成大白话，可以抄在便签上，也可以贴在冰箱门里。它不是给孩子看的，是给妈妈自己对一遍的。

| 栏目 | 要问自己的话 | 我这个月的做法 |
| --- | --- | --- |
| 底（不让渡） | 作息、安全、健康、诚信，哪几条我能十五秒讲清理由？有没有哪一条我其实是在拿它当借口管别的？ | |
| 时间 | 这周有没有至少一段没有名字的时间？我有没有在那段时间之后问“今天做了什么”？ | |
| 评价 | 这周她有没有一样东西，从头到尾没有被我打分、比较、问用处？ | |
| 关系 | 她开口时，我是在反射和追问，还是在替答？我有没有顺手把她的难题转给我的AI？ | |
| 后果 | 这周有没有一个后果，原本该落在她身上，被我悄悄挡掉了？ | |
| 小规矩 | 她有没有一条自己的小规矩？我是嘲笑它、无视它，还是给了它一点位置？ | |
| 可改 | 她有没有改过一条自己的规矩？我是当成“出尔反尔”，还是当成长大？ | |
| 回写 | 这一周留份以后，家里哪一条旧规矩变了？ | |

用法有三条。每周日晚上花五分钟，自己填，不要和孩子一起填，更不要拿它去“检查孩子”。填不出的格子，不是失败，是这一周还没有这件事发生，空着就好。每个月翻一遍前几周，看哪一栏总是空，空得最久的那一栏，大概就是你家那块最紧的地方。比如我家，我猜空得最久的会是“评价”这一栏，我很容易不自觉地说“还可以”，她一听就知道我在打分。

用这张卡，要防两个毛病。一是把它当成清单去打钩，变成一件新的“要完成的事”，那就又长出一套封闭的秩序。二是把它当成对孩子的诊断表，孩子没有变化，就怪孩子。卡片里问的每一句，都是在问妈妈自己，孩子没有出现在“我这个月的做法”那一栏的主语里。

### ◆ 撤回条件

这一章立的判断，是家要给有底的混沌和有人承接的介生。如果它是对的，留出了这些空间的家庭，孩子应当多出一点自己的东西：她会开始说“我觉得”而不只是“随便”；她会在做一件事之前有自己的理由，也会在做完之后给出自己的判断，哪怕这个判断和家长的不同；她改规矩的时候，能说得出为什么改。

反过来，如果在认真留出时间、评价、关系三处空间、守住了底、也有人在承接的家庭里，观察到孩子只是更焦虑、更散，经过一个学期以上，仍然说不出任何一条自己的判断，不能解释自己的选择，那么这一章就要改写。它不能再被读成“留份就够了”，而要改写为：留份需要更多前提。到那时我要回头去查的是，孩子的焦虑是不是来自别处（比如睡眠、人际、学校里的压力），空白是不是被她理解成了被放弃，承接的人是不是并不在场。

另外，只有一两周的混沌、一次周末的放松、一个孩子偶尔变散，都不算数；一个孩子本来就更焦虑，也不能直接算作反例。要算数的，是在底稳、三处一起松、有人承接的条件下，持续一个学期以上的、可以观察到的没有变化或变差。那一天到来，我会把这一章里的“要给”改成“要先查”。
