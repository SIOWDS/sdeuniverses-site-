## 第 6 章　混沌要有底，介生要有人接

### 周末的那张纸

〔示例性情境〕下面这一幕是我为了讲清道理拟的，不是某个周末的纪实。周日上午，小满把iPad架在餐桌上，笔尖悬着，说今天想画一整天。我正在厨房切水果，脑子里已经有了一套回应：作业写完了吗？下周有没有小测？画画可以，但得有个时间表。这套回应不是我当场想的。前一晚我睡前问过AI，问法大致是“高中生周末想花大量时间画画，怎样平衡学习”，它给了我一份很得体的方案：上午学习三小时，下午画画两小时，晚上复盘。条理清楚，语气温和，还提醒我“要尊重孩子的兴趣”。我当时甚至有点得意，觉得自己这次不会吵了。

我端着果盘走到桌边，话已经到了嘴边，是那份方案的第一句。就在这时我听见自己心里冒出另一句，很小，不太体面：这个方案，是我的，还是它的？我在公司做了二十多年人力资源，太熟悉这种感觉了。有人把一份做得很漂亮的制度文本递到你手上，你读完觉得句句在理，却说不出哪一句是自己的判断。我把话咽了回去，放下果盘，问了一句不在方案里的话：“今天想画什么？”

小满头也没抬，说：“不知道，画到哪儿算哪儿。”然后她又补了一句，让我在桌边站了很久：“你们是不是又觉得这不算正事？”这句话里有试探，也有一点早就准备好的防备。我一下子明白，我心里那份方案，她隔着桌子就闻到了味道。周末画画算不算正事，这个问题在我们家从来没有被正面讨论过，它一直以“作业写完了没有”“时间表”“有什么用”的形式，在各种缝隙里渗出来。

这一章就从这张桌子讲起。上一编讲了学校接走的是秩序，AI让秩序来得更快；这一编要回答一个更实际的问题：家里到底要留出什么，留到什么程度，留了以后谁来管。我先把判断说在前面：不能都是秩序态，不等于不要秩序。家要给的，是有底的混沌，加上有人承接的介生。底是什么，人怎样接，这两样说不清，“给孩子留空间”就会滑向两种坏结果，一种是什么都管，一种是什么都不管。

### 前人说到哪里，三态不是排名

先把前人的好答案摆出来，免得我把别人早就说过的东西当成新发现。说“管与放”的人很多。有一类研究讲的是教养方式：要求与回应兼备，是一种值得单独命名的教养（鲍姆林德关于权威型教养的研究，1966）。有一类讲的是独处：孩子在可信赖的人在场时，能安然独处（温尼科特，《独处的能力》，1958）。这两类说法我都信，它们说的是同一件事的两面：底要稳，空要留。我自己做人力资源时用的是另一套话，叫“授权不授责”，把任务交出去，把责任的边界讲清楚。放在家里，它也有用，但有一个我后来才看明白的缺口：它默认被授权的人已经有了自己的判断，而十六岁的小满正在长这个判断，长的过程中恰恰需要一个“不被当场评估”的地方。

本书给这件事的说法，是三个词：秩序、混沌、介生。我在第一本书里用它们看过职场，在这里要用它们看家，所以第一件事是把话说死：这三个词是分析用语，不是好坏排名。秩序，是可以照着做、可以交接、可以事先说清楚的那部分，像作息表、菜谱、考试大纲。混沌，是还没有成形的东西：一个说不清的偏好，一阵无缘无故的热情，一笔画了又擦、擦了又画的线。介生，是混沌里开始有形状、有人在半接着的那一段：她试了一种新画法，有一个人看见了，没有评分，只说“这里和上一张不一样”，下次她又改了一点。

我要强调“不是排名”，是因为一不小心，读者会把它读成“秩序低级，混沌高级”，然后回家把家规全撤了，等着孩子“自由生长”。那不是本书的意思，书里也没有任何一处说过存在一个“最佳比例”，三态各占多少才对，没有可测的答案，谁给你一个数字，谁就是在编。三态的用处，只在于帮你认出：这一刻，这件事，它在哪个状态，我现在的回应是在服务它，还是在压它。同一个周末下午，同样是画画，它可能是混沌（她只是想画点什么），可能是介生（她在试一个新的上色办法，并且打算让朋友看），也可能是秩序（她在赶一个答应了别人的交稿日）。三种状态各有各的对待方式，对待错了，不报错，只是越认真离孩子越远。

“不能都是秩序态”这句话，最容易被误读成“不要秩序”。我在这里把一条线画清楚，因为这是全章的地基：有一类秩序，家里必须稳稳地给，不让渡，不商量。它们是作息、安全、健康、诚信。睡够觉，晚上几点之前回家，出远门要报个平安，生病了去看医生，答应了别人的事要做到，不骗人也不被骗。这些事不是“妈妈的偏好”，是一个人能够安心去混沌的前提。我管它们叫可靠的秩序：可靠，是说它稳定、可预期、对孩子说得清理由、违反了后果由规则而不是由妈妈的心情来决定。

另一类秩序我叫封闭的秩序。它的外形和前一类很像，也是规则、安排、要求，区别在于它有两个特征。一是成功归大人，失败归孩子：考好了是“我们的安排对”，画砸了是“都怪你不专心”。二是每一处空白都被填满：周末要有计划，计划要有产出，产出要能说得出“有什么用”，孩子刚做完一件事，回答之前先得准备好那句“今天做了什么”。封闭的秩序不见得严厉，很多时候它是温柔的，甚至是充满爱意的，正因为这样，它最难被家长自己认出来。第537号把这件事讲成账本问题：学校只为秩序立了账，而未定与承接从无份额。放在家里，同样的情形是：家里的账本上，只有“完成”这一栏，没有“试过”那一栏。

分辨两类秩序，我有一个土办法，是向自己提三个问题。第一，这条规矩的理由，我能不能在十五秒里说给她听，并且允许她追问？“十一点前睡觉，因为你周一早上五点五十就要起”，能；“你就该这样”，不能。第二，这条规矩出了问题，后果由谁承担？睡晚了第二天犯困，是她自己的后果，那就让它落在她身上；如果每次她犯了错，我都要替她挡一下再批评她一顿，那这条规矩就在偷偷把后果转移走。第三，这条规矩有没有时效？可靠的秩序可以有变化，十六岁的睡觉时间和十岁的就不一样，它随着她长大被重新谈；封闭的秩序则几乎不改，因为它从来不是为她定的，是为我的安心定的。

这三问在周日那张桌子边帮了我一把。“作业写完了没有”是一条可靠的秩序吗？如果我愿意在十五秒里讲出“因为周一的数学课要交，错过了你自己会难受”，并且允许她说“我周六晚上已经写完了”，那它是。如果它只是一个条件反射，是我焦虑时的呼吸，那它就是封闭秩序里一个漏气的阀门。我那天问的是前者，她答的是：“写完了，周五晚上就写完了，你没检查。”我愣了一下，才想起周五晚上我加班，确实没有检查。可靠的秩序和封闭的秩序，有时候差的只是我有没有认认真真听她回答。

### 自由为什么变成了手机

讲有底，最好的反面教材，是没有底的自由。第324号《SDE教育发生学导论》里有一个例子，我读了好几遍。一所中学的年级主任对家长说，高一给学生“充分的自由”：作业自选，座位自选，社团自选。头两个月，一部分学生如鱼得水，另一部分不知所措，有几个直接把自由用成了睡觉和手机。主任于是得出结论：现在的孩子不适合自由。第324号对这个结论的回应，我愿意原样引一句：“缺的并不是自由，是自由所需要的善的结构。”

这句话的价值，在于它把“放”拆开了。那几个学生不是自由过多，是自由里缺了三样东西：没有人帮他们看清选择的后果；没有同伴共同体来承接选择；也没有足够的现实体验去知道自己喜欢什么。换成家里的话说：你对孩子说“周末你自己安排”，如果这句话背后没有底（睡觉、安全、健康这些不让渡的东西没有说清），没有人（她做出的选择，没有一个人愿意认真看一眼、问一句），也没有她自己的东西（她从未有过一次让“我想要”被认真对待的经历），那这句“自由”不过是把她从一台秩序机器里拎出来，丢进一个没有任何东西接着的空房间。她去睡觉、去刷手机，不是她堕落，是房间里除了这个，没有别的东西在回应她。

职场里也有同样的事。设想一位新来的年轻人，主管说“你放手去做，有问题找我”，三个月过去，他做得小心翼翼，只做那些肯定不会错的事。主管的“自由”是诚恳的，缺的是一件事：他没说过出了错会怎样，也没说过做对了会有谁看见。自由放下去，没有后果，没有人看，就退成了谨慎，谨慎又退成了应付。

那么有底、有人接，具体是什么样子？第586号讲企业里的混沌时，给过承接的四个条件，我借来用在家里，一条一条对着看。第一条，她的差异能进来。差异，指的是她和我们、和同学、和昨天的自己不一样的那一点：她偏爱某种线条，她对某个角色有自己的解读，她觉得这个科目“没意思”。能进来，意思是这个差异可以被说出口，被听见，而不是一出现就被翻译成“态度问题”或“小孩子想法”。第二条，后果能留在她身上。她答应了别人的稿子晚交，那份尴尬是她的；她把整个周末给了一幅画，周一的小测没复习好，那份后果也是她的。后果留在她身上，不等于我袖手旁观，而是我不抢在前面把后果消掉，也不在后果之后补一刀“早就跟你说了”。



第三条，她自己的小规矩能成形。这是最容易被忽略的一条。孩子在混沌里摸索，慢慢会长出一些自己的办法：画画前先听同一张歌单，每张图收工要放三个小时再回头看，不接超过三天的急单。这些规矩粗糙、局部、有点怪，家长常常的反应是“这不科学”。可是它们是她判断的雏形，要给它们一点“成形”的空间，哪怕只是不去嘲笑。第四条，这些规矩以后还能改。这一条是把前三条护住的保险：小规矩一旦被当成不可动摇的“原则”，就硬化成另一套秩序了；她今年定的“不接急单”，明年也许发现急单是练速度的好机会，这时她改规矩，不是出尔反尔，是长大。承接的四个条件，少了任何一条，混沌要么退回原样，要么变成一套新的封闭秩序。

少了哪一条，会长成什么样，我也举几个家里的例子，免得四个条件读起来只是一份漂亮的清单。少了第一条，差异进不来：她说“我觉得这个科目没有意思”，我回一句“高中就是要把每科学好”，她下次就不说了，混沌退回肚子里，变成沉默。少了第二条，后果留不住：我每次都在她出错前替她补好，她得到的是顺滑的日子和一个始终没有长出来的“我”。少了第三条，小规矩成不了形：她刚说“我想每天画前先热手十分钟”，我笑一句“还挺讲究”，这条规矩就被笑回了混沌。少了第四条，规矩不能改：她定的规矩被我夸成“这才是自律”，从此成了她不敢动的标杆，混沌硬化成了另一套秩序，只是这一次，是她自己替我们守的。

这也是我对“混沌不是放任”的理解：放任，是四个条件一个都没有；留份，是四个条件都在，只是它们看起来很轻，轻到旁人以为家里什么也没发生。

### 三问，和一个起手

把这些放回周日的桌子上，我对自己做了一遍书里一再讲的三问，只是换成了大白话。第一问，她这次显出来的东西，是从哪里长出来的？“今天想画一整天”是一句很小的话，往回看，它背后是她用那支五块钱的触控笔在一个假期里画下的几十张头像，是她算过自己大约四十元时薪的那种清醒，是她每周在学校里被分数和排名覆盖的那一部分自己，终于有一个出口。它不是心血来潮。看清这一点，我对“算不算正事”的态度就变了：我不再是在评估一个爱好，而是在面对一条已经有来历的线。

第二问，凭她已经显出来的和手边的条件，下一步能试什么，多大一步？她今天不需要我给她一个宏大的计划，她需要的是一个下午；下一步不是“画画变成事业”，也不是“画画必须换算成成绩”，而是“今天画一整天，晚上我们看一眼画成什么样”。一步要小，小到她失败了也不丢脸，成功了也不必立刻变现。第三问，这一次之后，她的现实、她对世界的看法、她对自己的看法，还有这个家，哪里被改写了？这一问当天答不出来，要在后来的几天里才慢慢浮出来（这仍是拟想的情境）：她也许第一次得到“妈妈没有问有什么用”的体验，我们家那条不成文的规矩（画画是下班后的奖励，不是正事）开始松了一个角。

复合主体的时代，还有一问是对我自己的：我的看法从哪来的？那天我拿着的方案，是前一晚AI给的，我若直接念出去，就成了典型的同源回声：妈妈问了AI，拿到一个看法；小满回头也会去问AI，大概率拿到相似的看法，然后我们两个人在饭桌上“谈得很顺”，彼此赞同，彼此理解，可我们的共同点并没有进入彼此，只是我们各自进入了同一个AI。共同点越多，关系越少，这是一种负向的发生，它也是发生，不是什么都没发生。所以我给自己立了一条规矩：妈妈的AI，只在她请我拿主意的时候才上场，而且上场时先摆材料，不先摆结论。那天她没有请我拿主意，所以我的AI应当留在口袋里。

这就牵到一个读事的起手问题。同一件事，起手不同，走的路完全不同：她来讲一件同学的事，我先跟着经过走，问“后来呢”；她卡住了，我先看卡在哪一步，再调条件；她谈钱、谈家规，我先把材料摊开，结论最后由她自己得出；她明确地说“妈你帮我拿个主意”，这时才轮到我用职场里那套先明靶子、再盘家底、后定路线的本行。周日那一幕，她没有请我拿主意，所以我什么也没拿，先问了“想画什么”。读不准的时候，我就直接问她一句：“你想让我先听你讲，还是一起想办法？”这一句看起来笨，其实是在保护那段混沌，因为它让主动权停在她手里。

接着要点名这件事里的矛盾，因为矛盾是家里的发动机，不是故障。这一天的矛盾，一句话说：她在推进“我想用一整天去做一件没有答案的事”，家里和学校稳着“时间要换成可以说得出的东西”。这两股力打架，有三种常见的改法，要改的永远是第三项，也就是那个把两边的力连起来的东西。

如果打架的是“她已经显出来的”和“她想试的”（比如她擅长画头像，却想试风景），要改的是条件：给她一个不必立刻有成果的试验场。如果打架的是“她的价值”和“家规校规”（比如她认为画画重要，家规认为作业重要），要改的是做法：把作息和作业的底先稳住，再把画画的时段明确划出来，不拿来讨价还价。

如果打架的是“她的尝试”和“环境”（比如她想把画拿给同学看，同学却只关心她的成绩），这一项只能她自己改出新的样子，妈妈和AI都不代改。

最后还要问一句回写：这个变化，又反过来改了什么？一场对话如果聊过就算了，没有回到她的现实、她的想法、她和我的关系里，就是白聊。

回到周日那句“今天想画一整天”，我把当时可能出现的三种回应并排放一下，看它们各自给小满留下什么。第一种，方案式回应：“可以，但上午先学三小时，下午再画。”这句话的善意是明显的，它甚至没有拒绝。小满得到的感受是：我想要的东西，要经过批准才算数；她得到的认识是：画画是学习之外挤出来的余量，它的正当性要靠学习来兑换；她的行动空间是，在三小时和两小时之间讨价还价。她不会反抗，大概会应一声“好吧”，然后在上午的三小时里心不在焉，下午的两小时里匆匆赶工。我们都按方案走了，没有一个人出错，可是那一天里小满的混沌，在她开口之前就被翻译成了日程。

第二种，放任式回应：“随你，你自己安排。”然后我回屋刷手机。这一句听上去像尊重，小满得到的感受却可能是：她做什么，我无所谓。她得到的认识是：画画是个人私事，与家无关，没有人在意；行动空间看似很大，实际上空无一物，因为没有一个人会看她的画，没有人问她手画得怎么样。这正是第324号年级主任那个故事里的“充分的自由”，她大概率会画一阵，然后转去刷手机，不是因为她不爱画，而是因为无人回应的自由，很快就变成了无聊。

第三种，承接式回应，也就是我那天做的：先问“想画什么”，不给方案，不置可否，把底在另外的时机讲一次（睡觉时间、周一要交的东西），晚上请她把画给我看，只反射和追问。小满得到的感受是：这个下午是她的，而且有人在旁边；得到的认识是：画画可以不需要先被证明有用；行动空间是，她可以画坏、可以改、可以决定要不要给我看。三种回应之间的差别，不在于哪一句话更温柔，而在于她的差异有没有进来、后果有没有留在她身上、她自己的小规矩有没有位置。

### 留份三处，要一起松

三问、起手、点矛盾，说的是怎样“看”；留份说的是怎样“让”。第537号在处方里提了一个词，叫留份，大意是：不是在秩序之外再加一种守护，而是在时间、评价、关系三处，各让出一块地方。我把它改写成家里的话。

时间上，留一些不被安排、不被追问“今天做了什么”的时段。比如周日下午两点到五点，不是“自由学习时间”，也不是“兴趣培养时间”，就是没有名字的时间。她可以画，可以躺着，可以对着窗外发呆，可以把一幅画画到一半丢掉。要紧的不是这三个小时的用法，而是三小时之后我不问那一句“今天做了什么”。这一句问话听起来平常，但它背后的意思是：时间需要被说明。孩子一旦知道每段时间都要被说明，她就会开始在做之前先想“怎么说”，混沌于是在发生之前被预先翻译成秩序。

评价上，留一些不打分、不比较、不问“有什么用”的草稿与尝试。她画了一张随手的涂鸦，我不说“不错”，也不说“这个比上次差”，更不问“这能接单吗”。我只能说看见了什么：“这条线收得挺狠。”或者“这里你没有描边。”这类话的好处在于，它不下判断，却让她知道有人看过。草稿的意义，是它可以失败，一旦草稿被评价，它就不再是草稿，而成了作品，作品就要对得起观众。留一类东西永远是草稿，孩子才敢在上面长新东西。

关系上，妈妈在场，但只反射、只追问，不替答，也不替她问AI。反射，是把她说的话换个说法放回去：“你是说，这一张你想让它看起来冷一点？”追问，是顺着她的话往下一步：“冷的话，你打算用什么色？”不替答，是她说“我不知道这里怎么办”的时候，我不立刻给方案，哪怕我手上就有一个。不替她问AI，是更新的一条：她卡住了，我也不顺手打开手机，把她的难题转手问一遍AI再把答案递给她。我这样做，等于把她的混沌在她自己动手之前，换成了一份来自AI的秩序。

这三处必须一起松。只松时间，不松评价：她有了整个周末，却知道周一要交一份“周末成果汇报”，那个周末就是一场表演。只松评价，不松关系：我不打分，但整个下午站在她身后，每隔十分钟问一句“画得怎么样了”，她一样画不下去。只松关系，不松时间：我安静坐在旁边，她的日程却被补习班塞得满满，坐再久也没有空隙。三处只要有一处是紧的，另外两处的松就会被它抵消，第537号说“留份要小而窄，自带抵抗被收编的结构，事先写明失效条件，三处同时松动”，小而窄这三个字尤其重要：不要一上来就想给她一整个暑假的混沌，从每周三个小时开始，做稳了再说。

另外有两条，我把它们放在三处留份的外面，因为它们是留份的前提，不属于留份。第一条，底不让渡。作息、安全、健康、诚信，这四件事无论她多投入、多有灵感、多“正在状态里”，都不退。她画得入迷，凌晨两点还不睡，我会敲门，理由十五秒讲完，不吵，也不让。这不是对混沌的压制，恰恰是混沌能长久的保险：一个身体垮了、睡眠崩了、信用丢了的孩子，是没有力气去混沌的。

第二条，女儿的混沌不拿去问妈妈的AI。这一条我写得很重，因为它是我们这个时代才有的新诱惑。比如她某天跟我说了一个模糊的想法，说得断断续续，我会忍不住想“让AI帮我分析一下她这是怎么回事”，这样做，等于把一个孩子半成形的东西，不经她同意，送进一个会立刻把它整理成标准话术的机器里。分析出来的东西往往很对，对到她自己的那个“不对”（那个说不清的、才是她的部分）被磨平。她的混沌，由她自己决定要不要给AI看。

那天晚上的事，我也记在这里，因为它说明留份之后会发生什么，也说明不会发生什么。〔示例性情境〕她画了一整天，晚饭后把iPad推到我面前，说：“你看吧，随便看。”我没有说“不错”，也没有说“你一天才画这么点”。我问：“这张你最不满意的是哪里？”她指了左手，说手总是画不好，今天画了六七遍。我顺着问：“六七遍里，哪一遍最接近你要的？”她翻了翻，指了第四遍，说：“其实第四遍对了，我后来又改坏了。”我说：“那第四遍为什么对？”她停了一会儿，说：“因为那时候我没想着要它好看，只想着它在抓东西。”这句话我没有追，我怕一追，它就从她嘴里变成我嘴里的结论。我只是点了点头，起身去洗碗。

这一幕里没有一句教育，也没有一句夸奖，可是四个条件都在：她的差异（手画不好，第四遍对了）进来了；后果（改坏了第四遍）留在她身上，我没有安慰她，也没有替她惋惜；她那一句“抓东西”，就是一条正在成形的小规矩，关于画手的；至于这条规矩以后改不改，是她的事。我所做的，只是在三个地方没有抢：没有抢着评价，没有抢着总结，没有抢着去问AI“画手有什么技巧”。不过这样的晚上并不总是有。也可以设想另一种：她画完把iPad一合，说“没什么好说的”，我就什么也不说，这同样是留份的一部分：承接的人要接得住“没什么好说”，不能每次都要回报。

留份是有代价的，我不想把它写成只赚不赔的买卖。第一个代价是成绩。她把一个下午给了画画，周一那个小测，复习得就不如以前细，分数也许会掉几分。这几分是留份的价钱，要由她自己看见，我不替她买单，也不拿它做“你看吧”的证据。

第二个代价是家里的声音。亲戚聚会上总会有人问“最近成绩怎么样”，学校群里也有“周末要不要去补课”的讨论，我会感觉到压力，有时候甚至会怀疑自己是不是在耽误她。这时我提醒自己的，是那个年级主任的故事：放手本身没有错，错在放手以后没有底、没有人。我既然守住了底，也站在这里承接，那么暂时看不见的东西，就让它暂时看不见。第三个代价是我自己的不安。留份最难受的地方，是我不再是“正在做点什么”的那个人，我只是在场。二十年职场里练出来的“推进感”，在家里必须收起来，这对我是一个很具体的修行。

### 讲到什么程度

问题清单里有两个问题，落在这一章。一个是：父母怎样把握引导的程度，让孩子既能享受探索的兴趣，也有机会逐渐理解事情背后的条件与责任？另一个是：这些认识，父母应该讲到什么程度？我的回答是三条，都不新，但放在“有底的混沌”这个框里，才有了位置。

第一条，分类讲：底线类的事讲全，探索类的事讲到她接得住。底线类，指作息、安全、健康、诚信，还有“答应了别人的事”。这类事，一次讲清楚，理由讲透，允许追问，之后不再每天重复。比如她接了一个单，答应了周五交稿，这个“答应”的分量，我会一次讲完：答应了就是答应了，做不到要提前说，不能等到对方来问。探索类，指的是画什么、怎么画、值不值得、要不要往这个方向走，这类事我只讲到她下一步够用，不讲到我自己放心。我放心不放心，是我的事，不是她下一步需要的东西。

第二条，讲条件不讲结论。〔示例性情境〕设想她刚赚到第一笔钱，我不会马上给她一整套“需求、劳动、成本、信用、责任”的框架，那是成人世界的要求，扣在一个刚有点实践的孩子身上，会把她的兴趣压成义务。我会在她提到某位客户的时候，问一句“他为什么愿意再找你”，她答得出就答，答不出就搁着。条件，是她自己遇到之后才有感觉的东西，我能做的是在她遇到的那一刻，递一个问句，而不是在她遇到之前递一份讲义。至于“这笔钱说明什么”这样的结论，由她自己得出，哪怕得出的和我想的不一样。

第三条，讲到她能自己问出下一个问题为止。这是我判断“讲够了”的信号：如果我讲完，她只是点头说“哦”，说明我讲过头了，她收下的是我的结论；如果我讲完，她追了一句“那如果对方不付钱呢”，说明我讲到了刚好。这个信号很朴素，却很管用，它把判断“讲多少”的权利，从我的焦虑转到了她的好奇。

再举一个〔示例性情境〕，不是小满的，是我拟的另一个家，用来看同一套办法在别处怎么走。一位母亲，孩子喜欢拆旧电器，某个周末把家里的闹钟拆成一堆零件，装不回去了。母亲心里有三种声音：骂他浪费，教他怎么装，或者“看他自己怎么办”。按本章的办法，她先分类：闹钟拆了，是后果，留在孩子身上，不替他装；晚上睡觉前把零件收到盒子里，是作息与整洁的底，不让渡；至于这堆零件算什么、值不值得再拆下一件，是探索，只问一句“你拆的时候，发现里面有什么你没想到的”。孩子说了一个，母亲就听着，没有再多讲。过两周，孩子自己说，下次想先画一张图再拆，这是他自己的小规矩，在成形。又过一阵，他说画图太慢了，不想画了，这条规矩被他自己改掉了。四个条件走完一圈，母亲没有讲什么大道理，她只是没有抢。

如果有人问：那么从哪里开始？我的建议是小而窄地开始，不要宣布。不必开家庭会议告诉孩子“从今天起我们家要留份”，那样做，留份本身又变成了一套新的要求。我打算这样开头：第一个月只做一件事，每周挑一个很小的时段，大约一个小时，在这一个小时里，我不问、不评、不评估，只是在场。第二个月，把“评价”这一栏加进来：她给我看什么，我只说看见了什么，不说好坏。第三个月，才把底的几条重新梳一遍，把那些我自己都说不清理由的规矩，要么补上理由，要么撤掉。顺序是先松后立，因为底的重新梳理需要建立在她已经觉得“家里有一块地方是安全的”之上，否则她会把每一条被重新讲出来的规矩，听成新一轮的收紧。

这里也要说一说我自己最容易犯的错。我是一个习惯了“把事情推进下去”的人，职场里这是美德，在家里它常常变成急着收口。她话说了一半，我已经把话接完了；她停顿了三秒，我已经给出了方案。留份对我来说，最具体的练习，就是数到五：她说完一句话以后，先数五个数，再决定我要不要开口。我猜多数时候，五个数里她自己会再补一句，那一句往往才是她想说的。

另一个容易犯的错，是把“底”扩大。底是四条，作息、安全、健康、诚信，一旦我开始说“学习态度也是底”“礼貌也是底”，这个词就会像气球一样越吹越大，最后把所有的混沌都装进去。我给自己的纪律是，凡是我想把一件事列入底，先问自己：不这样做，她的身体、安全或信用，会不会在一个月内受到可见的伤害？不会，就不是底。

### 为什么这一半只能在家里长

读到这里，有人会问：这些事学校做不到吗？学校里也有社团，也有选修课，也有老师愿意听学生说话。我的看法是，学校当然可以做，也有很多老师在做，但它的结构决定了做不完整。第537号讲学校的账本，说它只能承认被翻译成可比较量值的东西，这不是谁的错，是它要对全社会证明托付没有落空，而证明就必须有事先划定的方向和能排序的结果。一个社团再自由，最后也要出一份活动记录；一门选修课再开放，最后也要给一个等第。学校留不出一块“永远不用说明”的地方，因为它没有这样的账可以立。

家不一样。家的账本是自己写的，没有陌生人要来核对。一个下午画了什么、画坏了什么、有没有画，不需要对任何人说明，只对这个家里的两个人。这就是为什么我在书的开头说，孩子没交给学校的那一半，只能在家里长。可是也正因为家的账本是自己写的，它也最容易被自己写成学校的样子：我把学校的作息表、评价口径、问话方式，原样搬回了家。那样，学校接走了秩序，家里又替学校加了一遍班，孩子从早到晚，没有一寸地方是不用说明的。

AI的出现，让这件事变得更紧迫。AI会把任何一团模糊的东西很快整理成通顺的话，妈妈的AI如此，孩子的AI也如此。孩子随口问一句“我想画点不一样的，怎么办”，得到的是一份有条理的建议清单；她照着做了，画得不错，却没有经历过那一段“不知道画什么”的混沌。那一段混沌正是她判断长出来的地方。所以在AI的时代，家里的留份不能只是“少管”，还要有意识地给孩子留几个不绕开AI也不被AI填满的节点：比如先自己画三笔再去问，先说出自己的想法再看别人的；这一类“先猜后问”的小入口，我会在后面讲学习的章节里细讲。

### 家庭留份卡

下面是我拟的一张小卡，写成大白话，可以抄在便签上，也可以贴在冰箱门里。它不是给孩子看的，是给妈妈自己对一遍的。

| 栏目 | 要问自己的话 | 我这个月的做法 |
| --- | --- | --- |
| 底（不让渡） | 作息、安全、健康、诚信，哪几条我能十五秒讲清理由？有没有哪一条我其实是在拿它当借口管别的？ | |
| 时间 | 这周有没有至少一段没有名字的时间？我有没有在那段时间之后问“今天做了什么”？ | |
| 评价 | 这周她有没有一样东西，从头到尾没有被我打分、比较、问用处？ | |
| 关系 | 她开口时，我是在反射和追问，还是在替答？我有没有顺手把她的难题转给我的AI？ | |
| 后果 | 这周有没有一个后果，原本该落在她身上，被我悄悄挡掉了？ | |
| 小规矩 | 她有没有一条自己的小规矩？我是嘲笑它、无视它，还是给了它一点位置？ | |
| 可改 | 她有没有改过一条自己的规矩？我是当成“出尔反尔”，还是当成长大？ | |
| 回写 | 这一周留份以后，家里哪一条旧规矩变了？ | |

用法有三条。每周日晚上花五分钟，自己填，不要和孩子一起填，更不要拿它去“检查孩子”。填不出的格子，不是失败，是这一周还没有这件事发生，空着就好。每个月翻一遍前几周，看哪一栏总是空，空得最久的那一栏，大概就是你家那块最紧的地方。比如我家，我猜空得最久的会是“评价”这一栏，我很容易不自觉地说“还可以”，她一听就知道我在打分。

用这张卡，要防两个毛病。一是把它当成清单去打钩，变成一件新的“要完成的事”，那就又长出一套封闭的秩序。二是把它当成对孩子的诊断表，孩子没有变化，就怪孩子。卡片里问的每一句，都是在问妈妈自己，孩子没有出现在“我这个月的做法”那一栏的主语里。

### 撤回条件

这一章立的判断，是家要给有底的混沌和有人承接的介生。如果它是对的，留出了这些空间的家庭，孩子应当多出一点自己的东西：她会开始说“我觉得”而不只是“随便”；她会在做一件事之前有自己的理由，也会在做完之后给出自己的判断，哪怕这个判断和家长的不同；她改规矩的时候，能说得出为什么改。

反过来，如果在认真留出时间、评价、关系三处空间、守住了底、也有人在承接的家庭里，观察到孩子只是更焦虑、更散，经过一个学期以上，仍然说不出任何一条自己的判断，不能解释自己的选择，那么这一章就要改写。它不能再被读成“留份就够了”，而要改写为：留份需要更多前提。到那时我要回头去查的是，孩子的焦虑是不是来自别处（比如睡眠、人际、学校里的压力），空白是不是被她理解成了被放弃，承接的人是不是并不在场。

另外，只有一两周的混沌、一次周末的放松、一个孩子偶尔变散，都不算数；一个孩子本来就更焦虑，也不能直接算作反例。要算数的，是在底稳、三处一起松、有人承接的条件下，持续一个学期以上的、可以观察到的没有变化或变差。那一天到来，我会把这一章里的“要给”改成“要先查”。
