## 口径纪律（吃过亏的）

1. **只判「承重构念名＋副标题＋标题」这一层，不判全文。** 全文层不具判别力——两万字的稿子里「账／记／悬／在场」这类字必然出现，实测全文判法对通融产线与站内其余都给出 ~100%，等于没判。
2. **判型有先后**：先 E 再 D 最后 S。S 的词表最宽，放最后才不会把 D／E 吃掉。
3. **「—」不等于合格**，只等于「从名字上判不出来」。它里面既有真的另辟蹊径，也有名字起得太抽象而看不出取的哪一型——**这一栏必须人工过一遍**，不能当成通过。
4. 罚则见 Skill v4.1 附二：S 型在三型中 >70% → 产线告警；连续三篇同型 → D 减 4、I 减 4；同一条地基用满 5 次 → 第 6 篇起 I 封顶 136；形式句跨批同形 ≥3 篇 → I 封顶 136。

- **空位型**：S 792（29.2%）／D 47（1.7%）／**E 2（0.1%）**／— 1,868（69.0%）。**在三型之内 S 占 94.2%，告警成立；E 型实际为零。**

## ⚠ 一处必须记下的更正

复查之初的判断是「全站母题只有一个」。**按名字层的实测，这一条在全站尺度上不成立**（S 型在全部文章里只有 29.2%）。它成立的范围要小得多也准得多：

| 样本 | 摘要层命中「记账／缺席」词族 |
|---|---|
| 已上站·学科通融产线（n=109，关键词层） | 22.0% |
| 已上站·站内其余（n=617，关键词层） | 12.2% |
| **收件箱·胡敏 47 篇（跨五个题域，标题层 66.0%）** | **95.7%** |
| 收件箱·孔凡鹤 9 篇 | 100% |
| 收件箱·陈晓艳 9 篇 | 66.7% |

**结论**：母题单一性不是历史积累的问题，是**最近这一版产线的问题**——越新的批次越严重。这与 v4.0 题闸把「无字段者」写成唯一放行判据的时间点对得上。
