# 导言　一张体检单上的箭头

### ◆ 引子

**一张单子，两种说不通**

下面是两个构造的例子，不是真实调查，只为把问题摆出来。汪先生四十八岁，单位体检时，血脂一栏有一个向上的箭头。医生开了药，他遵医嘱按时服用，三个月后复查，箭头回正了。单子干干净净，可他自己知道，人还是那个人：下午三四点就乏，晚上躺下要翻很久，周末睡一整天也缓不过来。

他拿着复查单问医生：“指标都正常了，我怎么还是累？”医生把单子又看了一遍，说各项都在参考范围里，建议注意休息。这句话没有错，却也没有回答他。他的累在单子上找不到地方写，于是只能以“注意休息”的形式被带回家。

陶阿姨六十五岁，体检单上常年挂着几个箭头：血压偏低，血红蛋白略低于参考值，胆固醇在边缘上下。每年拿到单子，家里人都替她紧张。可她走路比儿女快，晚上沾枕头就睡，早上去菜场、下午带孙子、晚上跳一会儿舞，日子过得有劲。轻度贫血当然要查原因、遵医嘱处理，这里不是说箭头可以不管；这里要问的是另一件事：单子上的样子和她过日子的样子，为什么对不上。

**如果健康就是“各项指标正常”**

如果健康就是各项指标正常，这两个人都说不通。汪先生应该已经健康了，可他自己不认；陶阿姨应该一直不太健康，可她的日子不认。两个人的反常方向相反，卡住的却是同一个默认：体检单上的箭头，被当成了健康本身。

这个默认并不愚蠢。指标可测、可比、可追踪，医生靠它发现了无数早期的病，很多人因为一个箭头及时得到了治疗。问题不在指标，而在把指标当成“健康”这个词的全部意思。汪先生的累、陶阿姨的劲，都是真实发生着的东西，可它们在单子上没有位置。

**这本书要追问的**

这本书从这张单子出发，问九个关于健康的问题：健康到底是什么在显露；道理全懂为什么养不好；病好了是复原还是重组；面对一个不舒服第一眼往哪里看；反复发作的毛病怎样看清；伤身的习惯怎样才改得动；不舒服是故障还是引擎；转变为什么偏偏在那个时候发生；改变怎样才留得住。九个问题各成一章，合起来是一条线。

回答它们用的是一套叫 SDE 的思想框架：S 是显露，D 是差异序列，E 是特征纠缠。它出自王德生的《SDE思想体系入门》（德麦国际专著第395号），本书称它为“母本”。导言要做的，是把母本的基本框架用健康的例子讲清楚，只讲到够用为止；再交代本书守什么证据纪律、为什么这样写、可以怎样读。

导言的题目叫“一张体检单上的箭头”。箭头本身没有错，它是一次真实的显露；本书要问的是，这个箭头在怎样的条件里、经过怎样的序列被显露出来，它显露了什么，又漏掉了什么。这样问，就是从“发现”换到“发生”的第一步。

### ◆ 0.1　发现与发生：体检是在揭开，还是在生成

**发现范式的三条默认**

日常说“去查一查”，背后有一幅很自然的图景：身体的真相早就完整地放在那里，仪器和医生把它揭开，查得越多，知道得越全。母本第1章把这幅图景归成“发现范式”，由三条默认合成：对象先在、方法中立、知识累积。母本特意说明，这是为了比较而选定的一种思想类型，不是对几百年科学史的总判决。

对象先在，在医学里的样子是：体检单被当成“揭开身体的真相”，好像汪先生的健康早已写在血里，抽出来读一下就行。方法中立的样子是：血压计被当成一面透明的镜子。可同一个人在诊室里和在家里量出的血压可以不一样，临床上把这叫“白大衣高血压”；量的时间、袖带的位置、刚才有没有爬楼、旁边坐着谁，都是那个数字的一部分。

知识累积的样子是：查得越多，离真相越近。可检查越多，偶然查出的、意义不明的小结节也越多，医学上有“偶发瘤”这个说法。它带来的有时不是更接近真相，而是一串新的不确定、新的复查和新的担心。三条默认各有道理，合在一起，就让人以为健康是一件等着被揭开的东西。

**发现范式说中了什么**

发现范式不是错的。对于无意图、相对稳定、可以测量的对象，它几乎无可替代：血型不会因为谁来验而改变，骨折对没对位，片子上看得清清楚楚。母本说得很明白，看清它的边界，不等于要抛弃它。本书对检查和西医的态度也是这样：不贬低，只问它在哪里够用、在哪里不够用。

它不够用的地方，是对象怎样被划分、方法怎样形成、认识的人自己的能力本身成了问题的时候。汪先生的累不在单子上，不是因为累不存在，而是因为这张单子所依托的那套条件，没有给累留出位置。要回答“指标都正常了，我怎么还累”，光把单子再读一遍没有用，得问单子是怎样被生成的。

**发生范式的总命题**

母本第4章给发生范式写了一个总命题：任何可被认识、表达、维持的存在形态，都不是预先完整摆好等人观看的，而是在一定的条件、差异路径与纠缠土壤中被发生、稳定、表达出来的。这句话的主语是“存在形态”，不是“存在”本身。它不说血压是人想出来的，只说“高血压”作为一个可被认识的形态，是被发生出来的。

拿“高血压”来看。它需要血压计和量法，需要大量人群数据慢慢积累出的界值，还需要医院、病历、指南把这个界值固定下来。界值本身也会改：2017年美国心脏病学会与美国心脏协会的指南把成人高血压的起点下调到130/80毫米汞柱，各国指南的界值至今并不完全一致。一个人的血管一夜之间并没有变化，可按这一套指南，同样是130多的读数，他就从过去的“高血压前期”被划进了“1期高血压”，变的是显露它的条件。

**两道防线**

发生范式容易被误读成两样东西，母本为此立了两道防线。第一道：它不是唯心论。存在与存在形态的显露要分开说，没有人量，血也照样在血管里推着走；可“血压偏高”这个可以写进病历、可以讨论的形态，需要条件才显露得出来。

第二道：它不是任意建构。母本给了三重约束：土壤约束、现实顶撞、路径收敛。没有血压计的年代不会显露出“高血压1级”，这是土壤约束；把胸口压榨样的痛说成“最近太累”，心肌缺血不会因此不发生，这是现实顶撞，胸痛要立即就医；不同医院用不同设备反复测量，结果会收敛到一个可以互相核对的范围，这是路径收敛。用母本的话说，发生比发现更承认创造，比发明更承认约束。

**用词纪律：发生不等于产生**

本书里“发生”是一个术语，不是“产生”“出现”的同义词。母本第4章把四个词摆在一起对比：发现否认生成，产生取消过程，发明夸大意志，发生则同时守住生成、过程、约束与回写。“熬夜产生了黑眼圈”可以这样说，因为这里只要一条单向的因果；“健康的发生”却不能换成“健康的产生”，因为它还包括新显露反过来改写生成它的条件。

所以本书说“一次调理有没有真的发生”，问的不是“有没有出现好的结果”，而是结果有没有回过头去改动那些生成它的条件。汪先生的箭头回正了，这是一次真实的显露；至于他的健康有没有因此发生变化，要到他的日子、他的身体感受、他对自己的说法里去看。这件事要到第一章和第九章才能讲透，导言先把问题立住。

### ◆ 0.2　在E中，经D，成S

**一句话，三个短语**

母本把发生范式压成一句话：“在E中，经D，成S。”它的意思是：一个显露（S），是在特征纠缠的土壤（E）里，经过差异序列（D），才结成形的。母本第5章特意提醒，这句话是三维互生的最简句式，是一种组织方式，不是操作顺序，也不是已经完成证明的普遍定律。

所谓“不是操作顺序”，就是不能把它用成“先看环境、再看过程、最后看结果”的三步操。母本的说法是“公式一句，路径六条”：同一句话，从哪一维切入，要看问题自己的性质（这一点在0.4节讲六路径时展开）。下面逐个短语，用健康的例子讲。

**在E中：伤口长在什么里**

“在E中”说的是，发生总在一个先于你、厚于你、大于你的沉淀层里进行。母本用“浸没”来形容这种关系：鱼在水中，不是鱼在“使用”水。一个人身上的伤口，就浸没在他的血供、营养、年龄、血糖、睡眠，以及有没有人帮他按时换药之中。

同样大小的伤口，长在血糖控制不好的糖尿病人脚上，往往愈合得慢得多，这是临床上很熟悉的事。伤口的形状一样，它所浸没的那一束条件不一样，长出来的结果就不一样。所以 E 不是伤口外面的一个“背景”，抽掉它，伤口就根本不会以那样的方式愈合。

**经D：伤口愈合不能速成**

“经D”说的是，显露要经过一段由试探、失败、修正、收敛构成的路径。伤口愈合要经过止血、炎症、增生、重塑几个阶段，每一段都要走，哪一段被跳过或者卡住，愈合就会出问题。母本说这条路径有三个不可压缩的要素：必须试探，必须承接，必须收敛。

学会在家里量血压，也是一段“经D”。第一次量，袖带绑歪了，刚爬完楼就量，读数忽高忽低，人也跟着心慌。慢慢地学会先坐下休息几分钟、手臂和心脏放在同一高度、每天同一时间量，读数才稳下来。这段路别人替不了，想跳过它直接拿到“准确的血压”，就是母本说的“把产生冒充发生”。

**成S：一个指标的三个“可”**

“成S”说的是结晶成形，不是“拿到”或“找到”。母本给 S 立了三个“可”，缺一不可：可识别、可维持、可表达。拿一个指标来说：两次测出来能认出是同一个“偏高”，这是可识别；隔几周再测仍在这个范围，不是一次偶然波动，这是可维持；能写进病历、能讲给家人听、医生能据此说话，这是可表达。

只量过一次的高血压读数，可识别，却还谈不上可维持，所以医生通常要求复测。汪先生的累正好相反：三个月来一直在，是可维持的；他自己也认得出来，是可识别的；可它在体检单上无栏可写，是不可表达的。导言开场那个问题，用三个“可”一看，就落到了“可表达”这一格上。

因此本书凡说某样东西“显露”了，都要交代清楚：向谁显露，通过什么显露，在哪一类任务里显露，稳定到什么程度。说“汪先生的累显露了”，要接着说：它向他自己显露，通过下午的乏和夜里的翻身显露，在“体检合格”这类任务里不显露，稳定到已经持续三个月。

**结算点也是下一轮的起点**

母本说，成S是这一轮的结算点，也是下一轮的起点。血压读数一旦稳定地显露为“偏高”，它就会反过来改变这个人以后怎么吃饭、多久复查一次，也会慢慢改变家里的盐罐和饭桌。这种“新显露反过来重置生成它的 D 与 E”，就是母本所说的回写。

回写这个词本书会反复用，它不是“反馈”，也不是“复盘”。反馈是信息回到原处，复盘是事后回顾；回写说的是条件本身被改动了。量血压的人如果只是“知道自己血压高了”，而饭桌、作息、对自己的说法都没变，那就只有反馈，没有回写。

### ◆ 0.3　三维各是什么

**先立一条规矩：三维是问题，不是标签**

讲三维之前，先立一条规矩。母本第29章明令：三维是问题，不是身体部件的标签。不能说“器官是E、生理活动是D、检查数字是S”，也不能做一张“什么东西属于哪一维”的对照表。S、D、E 是追问同一场发生的三个方向，同一件事可以从三个方向分别去问。

拿汪先生的累来说，从 S 去问：这份累显露到了什么程度，向谁显露、稳不稳。从 D 去问：哪些差异一次次推进、被放大或被压下，才走到今天这样。从 E 去问：哪些特征缠在一起，使这份累既持续得下去，又写不进单子。三问问的是同一件事，不是把累拆成三块。下面每一维都只讲到够用，例子全用健康。

**S：显露，是一个连续谱**

S 是英文 Show 的缩写，意思是显露，不是“结构”。结构只是显露的一种：一张 CT 片显露的是结构，一个人“还愿不愿意做下一件事”也是一种显露，却不是结构。母本把 S 说成有程度、可进可退的连续谱。

一个人的累，可以从“说不清的不得劲”，显露到“下午四点那阵最沉”，再显露到写在本子上、拿给医生看。这是 S 在往前走。病好了一阵，又回到“说不清”，是 S 退回去了。母本还说，S 不自亮、不自撑：D 推进到哪里，S 显露到哪里；E 撑得多牢，S 维持得多久。没有人连续记上一周，“四点”就显不出来；没有家人看着，早睡的样子三天就散了。

**D：差异序列，分三层**

D 是差异序列，不是“步骤”，也不是笼统的“变化”。它关心的是：哪些差异能继续推进，哪些被压住，哪些被放大，最后收敛成一条走得通的路。母本把 D 分成三层：意义目标（D1）、路径组织（D2）、优化约束（D3）。

意义目标是创造、自由、幸福三者的配比，它定方向和风格，不定细节。设想一位膝关节置换后的老人练走路，他要的是自己能去菜场（自由），能去学校接孙子（幸福）；这两样一定，他练走路的样子就和“为了复查时数据好看”不一样。路径组织的通用引擎是母本说的六步法：猜想、执行、评估、反馈、修正、迭代。一个总在晚上胃胀的人，猜是晚饭太晚，试一周七点前吃完，看胀不胀，再修正下一周的安排，这就是在走六步。

优化约束是要把误差、冗余、损耗压小，让发生经济一些，但它是一把双刃剑。门诊为了省时间，只看单子、不问“最近是多久”，省掉的那一句恰恰可能是关键。母本把这种过度优化叫“高效而贫血”：效率上去了，创造和辨认所需要的那点冗余却被砍掉了。

**E：特征纠缠，不是环境**

E 是特征纠缠，不是“环境”或“背景”。背景是被动的、可以换掉的；E 主动参与，决定性地塑造发生。母本第9、10章把 E 展开成三组：E1 三界、E2 信息三态、E3 能量三态。

三界是理念界、现实界、自我界。理念界是概念、规则、制度和说法：参考值、诊疗指南、医保目录，以及家里那句“我们家的人胃都虚”。现实界是身体、器具、土地和城市：胃和饭碗、厨房和血压计、住在没有电梯的四楼。自我界是记忆、身份、情绪和意志，包括身体的内感与时间连续感中被本人认领的那一面——“这还是我的腿”，“我已经不是那个能熬夜的人了”。本书统一的口径是：身体属现实界；身体的内感、体感、时间连续感，作为被本人认领的那一面，属自我界。用到时说清是哪一面。

信息三态在每一界里都有：符号态、逻辑态、数学态。“胃不好”三个字是符号态；“一累就犯，所以是胃不好”这一条推进是逻辑态；一个人一周里饭点、睡点、发作点之间的连接与次序，是数学态。母本特意说明，三态是三个方向，不构成从低到高的等级。

能量三态是内能、动能、势能。内能是已经积下的储备，比如一个人还剩多少余量；动能是正在推进的力气，比如此刻还撑着把活干完的那股劲；势能是尚未释放的张力，比如心里那句“这样下去不行”。母本对这一组也有限定：它们是组织比喻，不是可以测量的物理量。

**名是指针**

母本第10章还说了一句对健康尤其要紧的话：名是指针。“胃不好”这个名字，指向的是一束缠在一起的东西：饭点、压力、睡眠、家族说法、药房里的“养胃”货架。它不是胃里藏着的一个东西，而是指向那一束纠缠的一个记号。

名字一旦立住，观察就会往名字上凑。每次胃胀，人都会说“又犯了”，却很少去记“这是第几晚、前一天发生了什么”。第五章会专门讨论这件事：病名怎样变成链条上焊死的一环，又怎样握住了“从哪里算起”的权力。

**三维不可拆**

最后要说的是，三维不能拆开单独存在。母本说 S、D、E 是同一场发生的三个方向，不是三个对象。不能先把 E 准备好，再去走 D，最后收 S；也不能只盯一维，把另两维当作背景。

汪先生如果只从 S 去问，他会去做更多的检查；只从 D 去问，他会给自己排更严的作息；只从 E 去问，他会想换个工作、换个城市。这三条都可能有用，但单拿任何一条，都会把另两维压成背景。后面九章的做法，是每一章都三维齐问，只是起手的那一维不同。

### ◆ 0.4　三件工具，外加两把刀

母本第12章把框架分成三个不可混淆的层次：三大方程说三维是什么关系，123原理说这种关系怎样自己推进，“在E中经D成S”加上六路径说从哪里切入。本书据此用三件工具：三大方程管关系，六路径管起手，三原理管动力。另外再用两把刀：发生＝底盘＋回写，以及成熟态、退化与重组。下面逐一讲，每一件配一个健康的例子。

**三大方程：关系**

三大方程是：S＝F(D,E)，D＝G(S,E)，E＝H(S,D)。意思是，显露由差异序列与特征纠缠共同生成；差异序列由显露与特征纠缠共同生成；特征纠缠由显露与差异序列共同生成。三式同时成立，没有哪一维能先于另两维被单独抽出来。

设想一位刚被诊断为高血压的人。两年后，他的复查单写着“控制良好”，这个显露是由他遵医嘱服药、少盐少酒的那一串差异，加上家里谁做饭、单位食堂怎样、他怎样看待“病”这一束纠缠共同生成的，这是第一式。“控制良好”一旦显露出来，又反过来重塑他的路径：复查间隔拉长了，偶尔也会放松一下，而食堂的饭菜还在规定着他能怎样放松，这是第二式。再过两年，家里的盐罐换小了，他开始自称“我是控制得好的人”，这是显露与路径沉淀成了新的土壤，也就是第三式。

必须说清楚的是：F、G、H 只是生成关系的占位记号，不是可以计算的函数。母本没有给出变量、函数形式和时间尺度，本书也不会写出任何“代入算出”的样子。三大方程在本书里的用处，是逼人每次都问全三个方向，而不是只问一个。

**六路径：起手**

三维同时互生，但人思考问题总得有个起点。六路径就是 S、D、E 三者的六种起手排列：S→D→E、S→E→D、D→S→E、D→E→S、E→S→D、E→D→S。选哪一种，看母本说的“任务DNA”，也就是这个问题此刻最吃紧的那一维。六路径不是六条有向的因果箭头，而是起点的纪律。

健康里的例子很多。要向家里老人讲清“什么是糖尿病”，宜从 S 起手，先立骨架再讲来路，走 S→D→E。术后要决定回不回原岗位，是达成一个目标结构，宜走 S→E→D：先明靶子，再盘家底，后定路线。一个人反复胃痛，想看清是怎么回事，宜先跟他正在推进的序列，不先贴标签，走 D→S→E（第五章）。

要干预一个正在进行的习惯，母本给的是 D→E→S：先看卡点，再调土壤，后成新构；第六章落到吃饭太快这样的具体习惯，就照这条路径排三步：先在那一拍逼出一个停顿（看卡点，属 D），再让饭桌多出一个可以停的地方（调土壤，属 E），最后才让停顿—放下成为稳定的新拍子（成新构，属 S）。想弄明白一个小区的老人为什么都不下楼，要先铺开这个场域，走 E→S→D。要为一份家庭照护方案写出理由，宜先厚底料、再走链条、结论最后到场，走 E→D→S。

母本说，起点错误代价最高：中途的错误会被评估和反馈捕捉到，起点的错误不会，越往深处走越牢固。第四章会讲到，“最近总是累”如果从“我就是体质差”起手，此后每一张正常的报告都会把这个起点加固一层，一路不报错。母本也给六路径设了限：它是提问的助手，不穷尽所有方法，也不必每个问题都走六遍。

**三原理：动力**

三大方程是静态的关系，还需要一个引擎说明它怎样推进。本书统一把这个引擎写成三条原理：原理一，D×E 矛盾→S 改变；原理二，S×E 矛盾→D 改变；原理三，S×D 矛盾→E 改变。每一条都以“改变回写前两维”闭合，回写之后，下一轮由谁先动，就由这次回写决定。

这里要注明来历。原理一就是母本第12章的“123原理”：D 与 E 相互矛盾，矛盾推动 S 改变，S 的改变回写 D 与 E。母本全书没有“三原理”这个独立概念，与三大方程、六路径并列的就是123原理。原理二、原理三，是学派在碰撞与判杀工具中补齐的另两种矛盾入口，本书沿用这个三条的写法，以便九章能从不同的两维相顶处进入问题。

原理一的例子：一个人定下每晚饭后走四十分钟（D），可他的日子是晚上九点才到家、楼下没有路灯（E），两者长期咬不上。矛盾显露为“总觉得不对劲”，体重也还在涨（S 改变）。这个显露如果被认下来，它会回写：他改成早上走，是改 D；和邻居约着一起走，是改 E。

原理二的例子：体检单上血糖一栏的箭头（S），与一家人多年的饭桌习惯（E）相顶，饭桌不改，单子不认。被逼出来的是路径改道：先吃菜后吃饭，晚饭提前一小时（D 改变）。新的路径再回写，下一次的单子变了，家里的饭点也跟着挪了。

原理三的例子：一位已经能走五公里的人，“我是能走的人”这个显露（S）已经立住了，可他每天的序列仍是出门就上车（D），两者相顶。被逼出来的是土壤改变：运动鞋放到了门口，上班换了一条要穿过公园的路，家里人开始叫他“走路的那位”（E 改变）。土壤一变，又回写他的显露和路径。

母本给123原理配了三笔纪律，本书三条原理一体遵守。第一笔，矛盾是引擎，不是故障；但失控的矛盾也会撕裂系统，长期严重缺觉就不是“引擎”，而是需要处理的损耗。第二笔，S 是结算点，不是起点；不能绕过相顶直接颁布一个新显露，“从明天起我就是早睡的人”之所以挂不住，第二章和第八章会讲。第三笔，回写那一步是命门，最容易被漏掉，第九章专门讲它。

**第一把刀：发生＝底盘＋回写**

母本第19章说，这是最锋利的诊断刀。底盘是一次发生所依托的、已经沉淀下来的 S—D—E 整体，包括既有的显露、走惯了的路径和土壤，所以底盘比 E 宽。回写是发生的下半场：新发生出的东西反过来改写底盘本身。

设想一位糖尿病人听完一堂健康教育课，能复述“少吃精米白面”，这叫入库。如果此后他点菜的手变了，家里的米缸换了，他说起自己时多了一句“我是要管住嘴的人”，这才叫回写。母本的口诀是：入库不算发生，回写才算；要回写，先相撞；底盘每天都在被写，看好你的笔。

母本还列了两种假发生。一种是无底盘的发生：出院时带回一份精美的康复计划，家里却没有会帮忙的人、没有合用的器具、没有空出来的时间，像雨落在玻璃上，挂不住。另一种是无回写的发生：计划贴在冰箱门上，日子照旧，像图书馆添了一本书，图书馆还是那个图书馆。还要记住，回写是中性的：每晚刷手机到一点，也在一笔一笔地被写进底盘。母本后来又加了一条修订：回写要被观察，不能被宣布。

**第二把刀：成熟态、退化与重组**

母本第4、12、13章说，完整的三元互生是成熟态，不是起点。设想一个人在生病之前，身体给出的凭证、他判断“我行不行”的标准、“我是谁”的认领，三者大致对得上，这就是一种成熟态。一场大病把这些判据打回去重新审查，可以看作退化；旧的判据被注销、新的判据立起来，三界重新对上，才算重组。

母本对这一组概念收得很紧，本书照办。原初、成长、成熟、退化、重组这五个阶段，不是每个系统都必经的周期；重组需要条件，不是每一次崩溃都会迎来重组，不能把每次垮掉都浪漫化成“破茧重生”。第三章讨论病好了是复原还是重组，就是在这个限度之内展开的。

### ◆ 0.5　证据纪律：一个整体视角，要背更多的证据责任

**五类主张不能互相豁免**

母本导言立了一条规矩：概念规定、哲学解释、数学命题、经验判断、实践建议，这五类主张的证明责任各不相同，不能互相豁免。哲学上说得通，不等于经验上成立；一个人照着做有效，也不等于证明了一套本体论。本书每说一句话，都尽量让读者看得出它属于哪一类。

举本书自己的例子。“健康显露在维持付出那本账还付不付得起上”，这是一个哲学解释，它帮你换一个方向看问题，但它本身不是实验结果。“改记事件账的人，主观恢复时间会缩短”，这是一个经验判断，必须拿数据来检验，第一章为它设计了比较的办法。“每天做一笔三分钟结算”，这是一个实践建议，它可以试，但试了有效，也只说明它在你身上有效。

**在健康领域，SDE 只是提问的视角**

母本第29章说得很清楚：SDE 在健康领域只提供组织研究问题的视角，也就是问当前的显露状态怎样形成、靠什么维持、怎样影响后续；它不提供疾病定义、诊断、治疗原则或统一公式。用 SDE 的术语，不会产生新的治疗原则。本书所有章节都在这个限度里写。

所以本书不会说“这个药推动了 S”，也不会说“整体调理改了 E”。母本已经明确撤回了“药物只作用于S”这类说法。一个人如果读完本书，觉得可以用“读数”“账”来代替看病，那是误读了本书。

几条医学安全的底线，在这里先说一遍，各章都照此执行。红旗症状一律立即就医，不当作转变的细节来写：长期吸烟者痰中带血，胸痛，便血或黑便，体重不明原因地下降，突然出现的一侧肢体无力、言语不清。涉及用药的情节，一律遵医嘱，不暗示自行停药、减药或换药。情绪和心理上的困扰，本书只用母本第30章的“工作性提问”去问，持续的困扰请寻求专业支持。

**每一章都写“怎样算错”**

母本还有一句话，本书把它当作写作的底线：整体视角是增加证据责任，不是减轻证据责任。越是说“要整体地看”，越要说清楚：什么样的观察会让我这个判断站不住。一个解释如果在任何结果出来之后都能把 S、D、E 的位置随意调换，那它就没有经受过任何检验。

所以每一章都专设一节“怎样算错”，写出能推翻本章判断的观察、读数与阈值，并把最强的竞争解释写出来，说明怎样排除。例如第二章的判断如果成立，那么让人写一篇“早睡的好处”，不会让他当晚更早入睡；如果写好处的那一组反而睡得更早，第二章的判断就作废。九章的判别局面与作废条件，汇总在附录二，阈值还说不清的，直接标“待定”。

**不换名，不称首创**

已有成熟名称的机制，本书不换一个新名字再说一遍，也不宣称首创。与近邻相似的地方，坦白承认；只在真正多出来的那一层上分叉。例如第六章讲的“半咽点”，与行为治疗里的习惯逆转训练几乎同形，那一章会先承认这一点，再说本章多看到的是什么。

跨领域的类比，本书只用它帮助提问，不用它证明任何事。记账、水文、流体，都只是借来的眼镜。比如第三章借水文里“初损”的说法，说河道一时干了，不等于没下过雨；这能帮人想到自我界的承兑不留记号，却不能证明病人一定还没好。

**已撤回的旧说，本书不再用**

母本在修订中撤回了一批健康和心灵方面的旧说，本书一律不当结论用。例如：慢性病等于“D流程失能加E产能缺陷”；药物只作用于S；抑郁是“E3受压”或“真善美同时熄火”；焦虑是“美的机制被劫持”；把“D短路”当作成瘾的定义；把“回写覆盖旧沟”当作唯一的恢复路径；把心理问题归咎于早期教育；用“发生性年轻”解释衰老；把检查贬为“机械性的年轻”；说癌症是“D2-9病”。完整的清单和理由，见附录四。

### ◆ 0.6　为什么用九个问题来写

**这是一本子本**

这本书不是母本的通俗译本，也不是九篇文章的合订本。它是一本“子本”：母本，加上一位读者的画像，加上这位读者自己提出的问题和由此展开的问对，三者合起来重写成的一本新书。母本是现成的知识，子本是这份知识在一个具体的人、具体的问题上重新发生一遍。

打个健康上的比方。同一份高血压诊疗指南，落到一位退休教师身上和落到一位跑长途的司机身上，需要回答的问题不一样：一个关心晨练时要注意什么，一个关心在车上怎样按时服药。指南不变，可每一次落地，都要在这个人的日子里重新走一遍。子本做的就是这件事，只不过它落地的对象是一套思想框架，落到的是健康这一块。

**三方各管什么**

子本的发生有三方参与，分工是清楚的。母本是总原则：术语、三大方程、六路径、三原理、底盘与回写、三界、成熟态、证据责任，一律以母本为准。九问是总纲：每一章回答一问，章序就是问序。问对是材料：新的想法、例子和判别局面从问对里来，不够的，用母本和真实的文献来补。

九个问题是我在 ChatSDE 上提出的，问对的过程把每一问推进了好几轮。问对里有走得很远的想法，也有走得太快的地方：引错的文献、过强的断言、自相矛盾的定义。本书对后者一律改正或收窄，例如无证据支持的全称断言一律收窄，涉及红旗症状的情节一律写成立即就医。问对本身不作为文献引用，其中站得住的观点，直接写成本书的论述。

**为什么从问题出发**

母本有一条方法顺序：先把问题逼出来，再让答案指向 S、D、E。它的写作法也是这样：从一个困惑开场，最后打开一个新问题。用健康的话说，就是先有“指标正常了我怎么还累”这个卡住的地方，才有必要动用框架；没有卡住，就不必硬套。

所以本书每一章都从一个门诊或家常的场景开场：体检单、门诊里那句“我都懂”、术后家人说“恢复得不错”、“最近总是累”、“我就是胃不好”、新作息表撑不过两周、“忍一忍就过去了”、拖了三年才去做的肠镜、戒了半年又捡起来的烟。每一章都附原题的必答项，章末逐项收口。读者自己的问题，也可以照这个格式来提。

**为什么分三编**

九问分成三编，每编以母本的一个层次为主导。第一编“显露与纠缠”，以三大方程层为主，问健康在三界里怎样被看见：健康是什么在显露，为什么懂了还养不好，病好了是复原还是重组。第二编“起手与序列”，以六路径层为主，问从哪里看、跟什么走、在哪一拍动手。第三编“矛盾与回写”，以三原理层为主，问转变怎样发生、怎样留下。

这样分，是写作上的次序：先要知道看的是什么，才谈得上从哪里起手；起手对了，才谈得上矛盾怎样推动转变、转变怎样留下。它不是说健康本身按“先显露、后路径、再矛盾”的次序发生，母本明确反对把三维写成先后三步。所以每一编虽有主导的一层，每一章仍然同时用三大方程、六路径、三原理去追问它的问题，并专设一节说明三者在这一问里的关系。

### ◆ 0.7　记账这条线

**为什么借“记账”来看健康**

全书有一条贯穿的线：一个人的不舒服、病、好与不好，都可以看作一笔账怎样被记、被销、由谁来销。这是本书借来帮助提问的类比，不是会计学的定律。每一章第一次用到它时，都会点明“借记账来看”。

借它，是因为它能把几件平时混在一起的事分开。一个人“知道了”，算不算“做了”？医生写下“已教育”，病人说出“我下周就开始”，这一笔算谁结了？家里人说“他已经好了”，本人还不认，这一笔是谁销的？这些问题，用“健康”“意志”“心态”这类大词很难问清楚，换成“账、栏、收据、勾销权”，就有了可以追的线头。

**两本账：指标账与付出账**

先回到汪先生和陶阿姨。可以设想每个人身上同时记着两本账：一本是指标账，就是体检单上那些可测、可比的数；另一本是维持付出账，记的是为了让日子照常运转、让指标好看，人实际付出了什么。早饭吃的一片面包是一笔支付；为了明天抽血空腹，前一夜紧张得没睡好，也是一笔支付，可抽血室记不下它。

汪先生的指标账结清了，付出账却一直在透支；陶阿姨的指标账有几笔欠着，付出账却还付得起。第一章的判断是：健康显露在“维持付出那本账还付不付得起”上；两本账对不上的那条缝，是读数的位置，不是健康本身；本人认领一句“这一回是我经手的”，是闭合这一笔的动作。

**栏、凭证、收据**

账里有几个词，全书统一用法。“栏”是一本账里预留的记录位置，没有栏，事情就记不进来：体检单上没有“累”这一栏，汪先生的累就无处可记。“凭证”是能当场出示的原始证据，比如一项指标、一张检查单、一个身体信号。

“收据”是替一件事开出的“已处理”证明。本书特别留意一种零成本收据：没花代价、也没有人验收的收据，比如收藏一篇养生文章、给病友群里的打卡点个赞、听完讲座说一句“这些我都知道”。第二章会讲，懂得越多，这种收据就越多，推迟反而越久。

**结算、假销与勾销权**

“结算”是有了付或收的动作之后，把这一笔了结。“假销”是没有付或收的动作，却把这一笔当作了结。“勾销权”问的是谁有资格把一笔账销掉，本书的判据只有一条：本人在付或收之后销，是结算；靠一个名分、一张凭据，或者别人替他销，是假销。

例子在各章里都有。“我就是体质差”一句话，把“最近总是累”整笔销掉，是名分替人销账（第四章）。门诊里医生记“已教育”，病人记“已表态”，双方各自开了一张收据，谁也没有付或收（第二章）。家人说“他已经好了”，本人还没有承兑，是别人替他销（第三章）。

**赊与借，见证人**

欠账也分两种。“赊”是没有到期日、也找不到借主的欠：今晚不睡，说“明天早点睡”，明天又说“明天”，这是病。“借”是有到期日、借主就是本人、可查可追的欠：在手机充电处的小本子上写下“借明晚十一点前躺下”，到点可查，这是药。第二章会讲怎样把赊改成借。

“见证人”是能看见这本账的人，比如家人、医生。本书有一条统一的口径：见证人不当债主，讨债的永远是本人自己。家人可以看见本子上那一行“借明晚十一点”，却不该在十一点零一分去敲门讨债；讨债一旦交给别人，这笔借就又变回了别人替他销的假销。

**回写与“只增不改”**

账的最后一个词，是母本的术语“回写”：新显露反过来重置生成它的差异序列与特征纠缠。放在记账这条线上，它说的是：一笔账结清之后，账本本身的格式、栏位和记账人，有没有因此改变。只把这一笔划掉、账本照旧，就还没有回写。

第一章和第九章都会用到“只增不改”的事件账：记下何时、对什么负荷、撑了多久、隔多久缓过来，写下去就不再涂改。它的意思不是要人记一辈子流水账，而是不让后来的说法把当时的凭证改掉。本书的结语题为“一本只增不改的账”，也是这个意思。

**这个类比的边界**

记账是借来的眼镜，只帮助提问，不证明任何事。本书不借用会计学里自己并不确知的术语，也不说“会计学里有一个词叫什么”来给论述撑腰。一个健康上的判断成不成立，要看它的判别局面和作废条件，不看它的记账说法顺不顺。

### ◆ 0.8　全书地图与读法

**三编九章**

下面这张表是全书的地图。每一章回答一问，“判断”一栏只写一句话的方向，展开、例子、近邻和作废条件都在各章里。

| 编 | 章 | 问题 | 判断的方向 |
|---|---|---|---|
| 第一编　显露与纠缠 | 第一章 | 健康到底是什么在显露 | 指标是健康的一次低像素显影；健康显露在维持付出那本账还付不付得起上，本人认领是闭合动作 |
| | 第二章 | 道理全懂，为什么养不好 | 卡在自我界：懂被当成收据替行动假销，“明天”被当成接单人，今晚的执行被赊出去 |
| | 第三章 | 病好了，是复原还是重组 | 是重组；第一道工序是销旧，而且是一场跨主体、三界错时的结算 |
| 第二编　起手与序列 | 第四章 | 一个不舒服，第一眼往哪里看 | 先看症状跟什么同拍、“最近”按哪本账划出；正常报告在两本账里反向记账，所以判错一路不报错 |
| | 第五章 | 反复发作的毛病，怎样看清 | 先跟序列：病名是链上焊死的一环，握着划定起止的权；跟序列多看到的是“位置” |
| | 第六章 | 伤身的习惯，怎样改得动 | 习惯运行在“节拍”上；干预点是半咽点；次序是先在那一拍逼出停顿、再让土壤多出可以停的地方、后让新拍子稳定下来 |
| 第三编　矛盾与回写 | 第七章 | 不舒服是故障还是引擎 | 不舒服是路与土咬不上时、账面平衡却没结清的读数；结清之后才转成引擎；压平改写勾销权 |
| | 第八章 | 转变为什么偏偏在那时发生 | 决心是长期相顶走到不可逆之后补签的收据；替旧行为平账的那几栏在三界同时失效 |
| | 第九章 | 改变怎样才留得住 | 看旧状态回来时是自动接管，还是要穿过本人可指认的“批准口子”；回写起于现实界、成于自我界 |

**三编各自在做什么**

第一编管“看见”。第一章给全书立下健康的定义口径，第二章说明知道了为什么还是动不了，第三章说明真正好起来时三本账怎样先后结清。三章合起来，回答的是“健康这本账在三界里怎样被看见、被假销、被真结”。

第二编管“起手”。第四章讲面对一个不舒服时，第一眼该落在哪里；第五章讲反复发作时，记录应该从哪一环起算；第六章讲改一个进行中的习惯，笔应该落在哪一拍。三章合起来，是母本“起点的功夫”在健康里的三次落地。

第三编管“转变与留下”。第七章讲不舒服本身是读数还是引擎，第八章讲结账日为什么偏偏是那一天，第九章讲结了账之后怎样才算真的写进了底盘。三章合起来，是三原理在健康里走完一整圈：矛盾、结算、回写。

**每一章的骨架**

为了方便读者对照，九章大体用同一副骨架：一个场景开场；先承认四位题定的近邻和几位现代研究者说中了什么；写出本章的判断，分节展开。接着专设一节用三大方程、六路径、三原理把本问走一遍；看它在理念界、现实界、自我界各显露为什么，落到一个普通人的一天；与近邻分叉，给出一个只有本章推得出的判别局面；写“怎样算错”；回到原题逐项收口；最后把留下的问题交给下一章。

章与章之间还有几组接口，读的时候可以留意。第二章与第八章成对：假决心是平账的工具，真决心是闭账的收据。第五章与第七章互指：换一个说法是必要条件，付或收的动作才是充分条件。第六章的那一拍停顿，是第九章“批准口子”最早的样子。

**读者每章三问**

母本建议读者读每一章都问三个问题，本书照用：我看见了什么？此前我是怎样解释它的？什么情况会让这一章的解释失效？第三问最要紧，它让读者不只是被说服，而是自己握着推翻它的那把尺子。

拿导言自己试一下。看见了什么：汪先生的累在单子上无栏可写。此前怎样解释：多半是“心理作用”或“还没查出来”。什么会让本书的解释失效：如果给汪先生这样的人加一本只增不改的事件账，与只写普通日记相比毫无差别，第一章“格式先于账”的主张就要撤回。

**几种读法**

顺着读，是最完整的读法，九问一步一步搭起来。也可以从自己最卡的那一问读起：戒了又复吸的人，可以先读第八、第九章；总说“我都懂”的人，可以先读第二章；家里有人刚做完大手术的，可以先读第三章。

还有一种读法，是只读每章的“怎样算错”和附录二，先看本书愿意在哪里认输，再决定信它多少。无论怎样读，都可以在读完一章之后，给自己的事件账添一笔。下面从第一章开始，回到那张体检单，问健康到底是什么在显露。第一章会换两位构造的人物（老许和顾大姐）把这个问题重新摆一遍，他们的处境与汪先生、陶阿姨同类，只是为了让第一章可以独立读。
