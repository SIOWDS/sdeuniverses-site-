# 附录二　引文与史实核验说明

先交代这本书的核验程序：全书经过通读和逐章的史料复核，每章都有一份台账，记着用了哪些外部事实、来源是什么、核到哪一步。写作与复核都由协作的智能体完成，同类基底不能互作独立证据；这本书没有经过独立的学术评审，也没有做统计调查。书中构想的场景（老陆、陆青、叶川和他们的厂子等），都在文中注明了“这是我构想的场景”，请不要当作事实引用。

**一、已回到原文或权威来源核过的主要内容（举要）。** 站内第267、305、461、503号中被引的句子，对原文逐字核过；《约翰福音》《希伯来书》对和合本核过；《晋书·律历志》中杜预的话、《几何原本》诸序跋、《孙子》《计篇》等句，对古籍原文核过；国发〔2025〕11号、2011年信用卡监管办法第38、42、43条、《禁止传销条例》第二条，对政府网站原文核过；信用卡数量对人民银行各期原文核过。研究类中，Dana 等人的面谈研究、Bond 与 DePaulo 的测谎元分析、Reber 与 Schwarz、Oak 与 Shafiq、Sharma 等、Cheng 等，以及 OpenAI 说明、Arup 案报道，回到了论文页或官方页面。
