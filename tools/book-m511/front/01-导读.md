# 导读　三种信，一条链：全书地图

### ◆ 一、三种信，各凭什么

全书只有一张最要紧的地图，由两部分组成：三种信，和信的一生。先说三种信，再说一生。

第一种叫见面之信。它的依据是图像和场：对方的脸，说话的腔调，饭桌上的气氛，介绍人的面子，还有您自己那天缺什么。隔着屏幕也算，只要您信的依据还是头像、声音、视频里的那股亲近感。它快，一顿饭就能放心；它不准，因为您看到的是一幅图像，图像要靠您自己的经验去解释，解释又被当时的场推着走，常常发生很大的偏离。

第二种叫实践之信。它的依据是见过的结果，走通了的路：别人已经用了三年，没出事；老乡去了那边，混出个样子。它准，可是迟。更要紧的是，我在书里要反复讲的一点：实践之后的那一步，其实叫验收，它结的是账，生不出信。实践不生信，只结算信。见面之信，则是实践之信最便宜的版本：没有结果可看，先拿一眼印象，当成了结果。

第三种叫理念之信，也就是未见面之信。它的依据是一个理念的运行：这个主意的假设有没有根据，机制走不走得通，推演推不推得出，说错了的话怎样算错。它快，因为不必等结果；它可以当下核对，因为运行的每一步摆在纸面上，谁都能顺着走一遍。这是科学得以发生的那种信，也是本书的母题：科学需要未见面之信。

用一个日常的例子把三种信放在一起。我构想一位老陆，五十八岁，浙南县城一家机加工厂的老板，规矩是“不见面不签单”。这是我构想的场景。有一天，他女儿转来一份从没谋面的年轻人叶川的方案，说用大模型改造他们的质检。老陆要是按见面之信，就约叶川来喝茶，看他“像不像靠谱的人”；按实践之信，就等同行用满三年再说；按理念之信，就是把方案读两遍，看它写了什么假设，推出什么结果，什么情形算它错了。这位老陆会在书里同我们走完第一章到第四十一章。

三种信还各有各的冒险样子和各的毛病。见面之信的冒险，是被亲近感带着押，骗子的主场就在这里。实践之信的冒险，是老乡带老乡，下南洋，亲友托底，它有功劳，常常押得很稳，毛病是只认得过去，也永远是后一步。理念之信的冒险，是爱因斯坦、杨振宁与李政道、玄奘、哥伦布这一类人，他们押的是没人走过的东西，只有一个理念在前面。这一类也有毛病：笃信，投机，理念闯祸。哥伦布算错了，碰巧撞上美洲，后果沉重。所以我不把理念之信写成一个好词，它是一把要用刀口对着自己的刀，第 17 章专门写它怎样算错。

三种信的来处也不同。见面之信多半来自从小养成的“亲眼见到才算数”；实践之信来自行业、乡土、试点的成败；理念之信来自读书、论文，来自同理念相撞。最后一个来处，是后天的，这就是第六编能够存在的理由。

### ◆ 二、信的一生

信不是一个静止的状态，它有一生，有生有长，也有死。我把它画成一条链：

所望 → 右端（猜加许）→ 理念运行（走过粘性）→ 实底（信）→ 四层判别 → 押 → 路标 → 放心（分期）→ 付账 → 结算 → 沉底（基础设施）→ 裂。

我逐段用大白话解释。所望，是您想要的那件还没有的事，比如老陆希望废品率降下来。右端，指一份预案的前半截：一半是猜，一半是许。猜，是对世界的判断；许，是您自己愿意担的承诺，比如“我把这条线交出来试三个月”。理念运行，是这半截东西在理念里被推演、被撞击的过程，推演会遇到粘性：矛盾、反例、算不下去的地方，走过去，才算数。我借用物理的说法作类比，只是类比，不当测量。

走过了粘性，落下来的一层叫实底。《希伯来书》说，信是所望之事的实底，是未见之事的确据。我借这句话作思想资源，不作神学论证：望的东西要有底，底要靠运行走出来。有望无底是画饼，有底无望是存货。

实底有了，要过四层判别。这四层是我在《预案科学》（德麦国际专著第 267 号）里写的：假设有没有根据，机制走不走得通，推演推不推得出，路标清不清楚。过了，就押，押一笔，不是押全部。押的时候同时立路标，说出现什么局面就改。押出去以后，您会逐渐放心，放心可以分期，一点点增加额度。放心到了，就是付账：真金白银地交出去。付了账，接着是结算，结果出来，对了，这个理念沉下去成了基础设施，沉到没人觉得它在那里；错了，或者条件变了，它就裂开，裂缝里又长出新的所望。整条链，就是一个理念从猜想到教科书，再到被替换的一生。

在这条链上，三种信站在不同的位置。见面之信从“见了”一步跳到“放心”和“付账”，中间的运行、判别、路标统统省掉；这就是第二承重句：放心是信结的账，见一面，是没信先付账。实践之信，则要等到结算才开始。理念之信，守着链条的中段，在押之前就生出来。

### ◆ 三、三个位置

读书时，请记住三个位置，它们在书里会反复出现。共享的底，是放心：它是已经结算过的、大家不再追问的东西，比如桥能走，药量有上限。实底，是信：它是走过粘性才落下来的一层，里面包括右端“许”的那一半，所以信里天然有您自己的担当。叉，是预案：同一件事，您手里不止一条路，每一条都不是定论。

这三个位置，让我们能够回答一个常见的反问：你说多做几手准备，不就是不信吗？不是。信是实底，押的那一条是认真押的；叉是留着，万一路标亮了，您知道往哪里转。信和叉并不打架，一个管深，一个管宽。

### ◆ 四、两条轴

全书还有两条轴，第 37 章才正式立起来，这里先打个招呼。一条轴是回写的强弱：您做的事，反过来改变世界的程度。桥梁、药量，回写弱，世界不因您的想法而改；职业选择、癌症治疗线、AI 路线，回写强，您怎样做，局面就跟着变。另一条是证据的时差：证据已经到了，还是还没到。两条轴交叉成四格。证据未到的两格加在一起，就是“还未见面的科学”，是我在《预案科学》里立的定义，这一本把它扩展了。回写弱的地方，可以押一条，相对论就是这样；回写强的地方，必须留叉。

今天人们说“AI 时代没有确定性”，我同意一半。变得不确定的是发生的那一层，桥还得算得对，剂量还得守得住。

### ◆ 五、七编怎么走

第一编写见面的账：它为什么吸引人，为什么被偷换，为什么中国式的那一面特别厚，以及见面有哪四件本事。第二编把三种信摊开，并讲放心、战机、实底。第三编写理念之信怎样发生：理念的创造、自由、幸福，三者缺一就偏瘫；笃信不算信；信用卡和版本史是两个落地的例子；最后是我的学员。第四编是科学：爱因斯坦、哈代与拉马努金、开普勒，到论文这一发明，到科学的两张脸。第五编是冒险与文明，李约瑟之问就在这里。第六编写出路：信可以学会，从摇篮到国情。第七编写还没发生的事：两条轴，AI，和大模型见一面，最后一章，是怎样见一面。

前六编主要写已经发生的，判对错；第七编写未发生的，判值不值得押。

### ◆ 六、三个提醒

第一，书里的“发生”是个关键词。我不说信是“产生”的，信是一次次发生的，发生就意味着可以重来，可以学会。我同时用三个关系记号作笔，写作 S=F(D,E)、D=G(S,E)、E=H(S,D)：所见的显露，来自看的人的差异序列，和当时的场；而新的显露，又会反过来重置这个人的差异和场，这叫回写。回写要被观察，不能被宣布，它也可能是负向的。

第二，书里每个观点我都配了日常的例子，史实我都要求查证；凡是构想的人物和场景，都会注明。

第三，请带着质疑读。每章的“路标”，就是我给您留下的检验口。

读完全书，您手里应当多出三样东西：一张分清三种信的地图，一套在押注之前判别的办法，和一个可以随时拿来对着自己用的路标习惯。这三样东西，不靠任何人的脸来担保。
