# 前言

这本书是在王德生老师的指导下写成的。第 586 号《你没交给企业的那一半》写完以后，我又给老师发了一组更贴近处境的问题，想把三件事连起来：我怎样理解人力资源工作里的人和关系，我为什么在这些年里产生了较大的消耗，以及未来怎样为自己建立更多收入来源。那组问题收成一句话是：我怎样在理解人和组织的复杂性、减少无效消耗的同时，把已有积累发展成能够独立创造价值、获得收入的能力？

王老师读完，先说这其实是前一本书的应用。接着他一层一层往下说：回答这个问题，就是在工作中建立意义三律运行的能力；实现的办法，是让复杂的信息和意义三律联合变换，显露出真善美的价值；我不能再单独依靠自己的大脑来处理这些事；解决方案，是建立自己的知识创造平台，也就是一家人事管理慧店；这家店要面对的老板、人事同行、想离开岗位的中年职场人，是三个市场细分，也是三条同一性谱系。这本书就是把这几句话放回我的处境，一句一句试着走通。

书里凡是写我自己的地方，都依据我已经写下的材料和第 586 号里交代过的事实：做过的写做过，还没有发生的就写还没有。本职之外第一次被人付费、第一位回头客，到这本书出版时都还没有。书里的产品、智能体、部落和交易都是设计，还没有真实付费；凡是涉及别人的场景，都标为〔设想〕，人物用虚构的名字，不指认任何公司和个人，有几处为了演示做法用了“我”，只要标着〔设想〕，也不是我经历过的事。

全书在写作与审校中借助了 AI 协作，经统稿与三审。同一底座的执笔者和审校者只能查错，不算独立评审，这本书也没有经过独立的学术评审。书里要紧的判断，章末都写了怎样算错，第 29 章又把它们收在一起。这是一个可以检验的回答，不是已经被证明的结论。
