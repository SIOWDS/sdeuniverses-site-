# 《伐冰之家不畜牛羊》合并初稿审稿报告

（行号指 全稿_合并初稿.md 的行号。覆盖说明：前言、序章、1.2、1.4、2.1-2.4、4.4、5.3、6.4-6.5、7.2、9.3末至9.4、11.2-11.3、11.8-11.10、12.2与12.3首部、结语、附录B 逐字读过；其余章节以检索、抽读与各章稿末汇总对照，未逐字通读，漏网处请统稿时补查。）

## 总评
1. 承重墙大体在位，但“压在普通人身上”在0.2、2.4、7.2、11.3、11.9、结语六处被写成“可收回的待验证命题”，已超出口径“写成推断并说明无数据”的要求，实质削弱核心命题，须王德生裁定。
2. 事实纪律总体守住：数字与出处各章一致，无点名真人、医院、平台，无注家原话，被罩多处标〔待核实〕。但有数处把未核实内容写成事实或暗含动机，编辑口吻（“王德生/统稿/写手”）大量漏进正文，结语还有一处引文拼接错乱。
3. 读者体验：茶叶数字十余次整段重述、三条路讲三遍、1.2与3.1重叠、结语五千余字多半重复；人名与案例撞车严重。

## 一、必须改

**A. 承重墙**
- A1 挤压降级。2.4、7.2、11.9标“结构性推断，没有查到具体数据”合规。越界的是：0.2:269“这一节的判断就是错的”；2.4:978“要从论证里收回”；11.3:3948、11.9:4164“‘压在普通人身上’这一环，要收回或者改写”；11.9:4166“这一环现在是待验证的命题”；小结4216；结语5048“‘压在普通人身上’这一半，就站不住了”。同时序章0.3:315、6章小结2465“不统一是原因，挤压是后果”又写得很实。改法：保留“推断+未查到数据”，删各处“收回”条件句，只在11.9留一处且限于“程度与数量”；“待验证命题”字样是否可用由王德生定。
- A2 9.4“公益也不行”在位（3322、3360），但出口过多：3364“梅姐若问过夫妻一声，事情就变了”；3401“所有受影响的人事先都被问到并点头……就没有成立”；11.2:3912同；2.1:813“一次性的……义卖……先不拆开”。读者会读成“征得同意就可进”。改法：补一句“在大众行业里不可能事先问到所有受影响者，故结论不变”；删2.1:813的例外。
- A3 6.4特征律只照那一句写，未自造定义，合规。要改：(a)2259-2263“王德生对这件事有一句话”“留待他本人来定”、2463“口径来自王德生，待他最终确认”是编辑口吻，改作者口吻或删；(b)2299把真实案例的粉丝数与“本行没停”并置，易读成暗指真人本行停摆，建议删对该名人的指涉；(c)“增量”在6.4指本行自己的新东西，在12.2指行业新增需求，附录C合并两义，易混。
- A4 6.5先立命题后讲SDE，无比较句，合规；2413“几乎是一种常态”可留，建议加“在我们的日常说话里”限定。
- A5 “民为贵”均注《孟子》，合规。但1.3标题与565-571说“民为重”是后人概括，而3908、3944、3980、4016、4054、4100、4124把“民为重”当本书原则用，未交代。须在1.3或前言明说：“民为重”是本书自己的概括，不是引文。
- A6 1.4“类比而非原意”在位。699-703“声望含众人托付”是论证前提，正文未标为推断（稿末自承），须加“这是我们的论证”。1.2:529“原文管的是位置，旧读法把它翻成品行”、541-543“经文字面是朝外的”，与1.2自己承认的“义、利、臣、盗讲品行”相抵，也冲淡1.4的“类比”自限，改为“我们读出的一层”。

**B. 事实与点名**
- B1 对真实案例断言先后或动机：0.2:215“起点是善意，然后……慢慢长出了长期经营的可能”；2.2:858“起点是一桩善意的事，后面又有长期品牌的打算”。品牌起意、捐款兑现均〔待核〕，且2.2:824自称不谈。改为并列三件已报道之事。
- B2 0.2:245“钱是真的进了医院”、267“直播的钱进了医院”预设捐款已兑现；249“从一张桌子上分走的”把挤压写成事实。改为“若兑现”“可能”。
- B3 8.2:2932“观众一半是来买茶的，一半是来表示‘我也出一份力’的”“善……成为一层亮色”，无据且近动机断言，删。6.1:2017“撑起这个数字的，是演艺那一行的多年积累”是因果断言，改“我们读作”。10.2:3648“874样货，对应的是许多家商家”无据，且2.2:836已声明不假定都是茶。
- B4 2.2:890“这几篇报道里没有一处提到有人违规”，写手只见口径摘要，不可如此断言；2.2:856“直播之前这些人并不是普洱茶的客人”无据。
- B5 结语4944把“成交额1.6亿”当“利”，与2.2:832“成交额不等于利润”相抵，删；结语4994、4996、5068把“被压”写成事实，与推断纪律不一致。
- B6 序章0.1:141“商家……卖的是合格的货”对未核实的被罩案断言事实，改“设想”。191、489、1274三处提被罩名人未带〔待核实〕。
- B7 编辑口吻漏入正文：943（“日后王德生博士核实了……”）、1528、4236、4324、4474、4494-4496、4588、4628、4632；附录A 5100-5127；附录B 5147、5168、5180-5204（“写手不自行补入”等）；附录C 5208-5225。公开稿须删或移作附注。
- B8 结语4938-4940引文被拼接破坏（“此谓还有一句，要对着这本书自己说……国不以利为利”），必须修复。
- B9 未核的断言：1.1:385法官/医生/校长三例（“医生不能给亲人开处方换回扣”），6.2的平台流程“一般理解”，3.3的行会史、超市史，4.3:1506“有研究说”。标〔待核〕或改为设想。

## 待王德生裁定
1. “压在普通人身上”能否写成“待验证命题”，各处“收回”条款是否保留（A1）。
2. 全部公益是否留“事先被问并同意”的出口（A2）；一次性义卖是否在讨论范围内。
3. S3·D1·E2对应；E2是否整体等于“名字”，还是名字只是符号一形态。
4. “能量”指向；是否要对到E3。
5. 特征律的准确表述；6.4能否在正文署名引用他那句话；“存量/增量”的口径。
6. 第12章12.3通融创新口径（现为占位，须整节重写）。
7. 被罩一例：核实后点名，还是整节撤换或并入2.1/9.2（2.3）。
8. 其他行业案例名单（6.4、附录B目前为空）。
9. 6.5“中华文化日常里的‘我的’圈子”的写法是否合其本意。
10. “民为重”作为本书概括的地位；“分量/托付”论证与“声望有公共性”（11.10）是否采用。
11. 凤凰网报道日期；捐款是否兑现；品牌何时起意（均待核）。
12. 书名、副题、署名，以及正文是否出现“王德生”字样。
