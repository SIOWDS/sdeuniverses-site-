# 结语　大学最后要读的，不是一个已经完成的人

AI时代，大学毕业生并没有因为模型能够生成答案而失去价值。真正失效的是一种旧的读取方式：从漂亮产物直接回推个人，从一次考试永久确认能力，从一张技能清单想象未来，从一个团队成绩拆出每个人的全部价值，从过去的署名推断今天仍然有效。

当知识、技能构件、表达形式和一般问题解法不断公共化，核心竞争力不会消失，却会改变存在方式。它越来越少地表现为一个人静态占有的稀缺物，越来越多地表现为：在相近工具与相近资源条件下，这个人能否使新的判断、结构、关系和价值发生；这种发生能否在答案没有先行时形成，在不可重来的关口承担，在长期辅助中保持底流，在自己的作品上继续向前，在不同任务和伙伴中重新出现；又能否诚实地区分哪些差属于他，哪些属于复合体，哪些来自机会与环境。

所以，本书的答案只有一句：

> AI时代大学毕业生的核心竞争力，是发生学能力的差异度。

这句话不是第十一项技能。它要求大学放弃这样一种理解：学生是能力容器，教育是把知识和技能装入容器，再用考试检查装入程度。学生不是等待完成的产品，而是能够进入主客互动、改变互动并被互动改变的发生主体。真正的教育，不是使他最终拥有一套永不过期的答案，而是使他在答案极其丰裕的世界里仍然保有发生的能力。

“大学如何读？”也不能再回答为“用更严格的考试”。大学要读的是一件尚未完成的事情：这个人怎样面对未知，怎样在工具与他人之间形成自己的判断，怎样在真实责任中持续执行，怎样跨场再发生，怎样与别人共同产生没有单一所有者的新价值，怎样在记录与制度中保住发生的证据和正当归属。

大学最后不可替代的，不是它拥有最多答案。模型可以比大学提供更多、更快、更便宜的答案。

大学不可替代之处，在于它能够设计一种环境：答案不垄断发生，工具不代走主体，互动不抹除个人，个人不侵占共同体，评价不把复杂生命压成单一数字，记录不扩张成无边监控；学生在这里一次次亲自形成、真实承担、共同创造、重新续签，并最终学会为自己的发生负责。

大学读到的，不应是一个已经完成的人。

大学应当读到：

> 一个仍然能够发生未来的人。
