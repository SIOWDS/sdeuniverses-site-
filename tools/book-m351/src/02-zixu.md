# 自序　不是再发明一张更长的能力清单

“AI时代大学毕业生的核心竞争力是什么？”

这个问题已经被回答了无数次。答案通常是一张不断更新的清单：批判性思维、创造力、沟通、协作、领导力、同理心、韧性、终身学习、数字素养、AI素养、提示词能力、复杂问题解决。技术每进步一轮，清单便向上移动一格。机器会计算，人就强调判断；机器会写作，人就强调创造；机器会生成方案，人就强调提问；机器会参与决策，人就强调伦理与责任。

这些答案并非错误。问题在于，它们的形式几乎从未改变：核心竞争力被想象成一个人可以储存、持有、展示和认证的“东西”。知识是一种存量，技能是一种存量，批判性思维是一种更高级的存量，AI素养是一种新加入的存量，终身学习则被理解为不断增加存量的元能力。于是教育改革的基本动作始终是：在清单上增加条目，在课程里配置条目，在量表中测量条目，在证书上确认条目。

生成式人工智能真正改变的，恰恰不是清单里的某一个条目，而是“列入清单”这一动作的制度后果。一种能力只要被稳定命名，就会被写入课程；一旦写入课程，就会被拆成目标、步骤、范例和评分细则；一旦被拆成这些东西，就会成为人工智能可以学习、教师可以批量讲授、学生可以模板化展示的对象。它仍然重要，却越来越难以构成人与人之间的差。呼吸极其重要，但没有人依靠“会呼吸”获得竞争优势。AI时代大量被称为核心竞争力的能力，正在经历同样的变化：它们作为社会运行的地板越来越重要，作为个人差异的来源却可能越来越弱。

我最初面对这个问题时，也试图寻找一个更好的名词。后来形成了十篇专题研究，它们分别提出“零判份”“峰兑”“他手无事账”“盲遍”“单遍段”“底流”“脱稿步”“常席差”“现配优势”和“前账阶段”。如果把这些研究并排摆放，很容易产生一种错觉：这是一组彼此竞争的答案，好像要争的只是核心竞争力究竟应当叫盲遍、单遍力、常席差，还是现配优势。

本书的写作，就是为了取消这种错觉。

十个概念所指向的并不是十种能力，而是同一件事情的不同截面。盲遍回答发生之前答案是否已经到场；单遍段回答尝试是否耗散了重来条件；底流回答发生能力是否仍在被真实执行供养；脱稿步回答过去的发生能否在今天继续向前；常席差回答换掉任务、伙伴与工具后，什么差仍然稳定地跟随此人；现配优势回答什么价值并不跟随任何人，而只在特定互动中现场长出；零判份回答已经完成的产出还有多少能够区分生产者；峰兑回答有些价值为什么只在稀发关口整笔显露；他手无事账回答谁选择读取时刻、谁执行取样以及记录归谁；前账阶段回答发生出来的技能一旦进入社会账本，其价值与归属怎样被重新裁定。

把它们放在一起，真正的答案才显露出来：

> 核心竞争力不是某种已发生的结果，而是持续发生出差异的能力；不是发生能力本身，而是这种发生相对于共同基线所形成的差异度。

这句话包含两个必须同时成立的部分。

第一，竞争力是发生学的。一个人拥有多少知识，并不能直接推出他能否在新的条件中形成判断；一个人过去做出过什么，也不能直接推出他今天还能否沿着那件作品继续走；一个团队的产出很好，也不能直接推出其中任何一个人独立拥有同等价值。竞争力只有在一次具体发生中才存在，而这次发生总是由主体、客体、互动以及环境共同构成。

第二，竞争力是差异性的。一个人能够完成一件事，不等于这件事构成竞争力。只有当这一发生相对于社会现存能力、人工智能基线、同侪水平或既有样本形成可辨差异时，它才具有竞争意义。使用价值与差异价值必须分开。一个标准化流程可以拯救生命，价值极高，却因为人人都必须执行而不再构成个人竞争差；一个极其精美的报告也可能有很高的使用价值，却因为模型可以迅速生成同类产物而几乎不再提供识别人本人的信息。

因此，本书不是反对技能，不是反对AI素养，不是反对人机协作，也不是主张大学回到闭卷、断网和工具禁用的旧世界。它要改变的是大学的核算单位。大学过去主要以个人拥有的知识和产物为单位，未来必须学会以“发生”作为单位，以“差异度”作为竞争力的读数，以“主客互动复合体”作为发生的真实载体。

在主客互动知识论中，认识的对象不是孤立主体，也不是孤立客体，而是主体—互动—客体形成的复合存在物。这个判断在AI进入教育之后获得了新的现实重量。一篇论文不再只是学生的属性，也不是模型的属性，而是学生、模型、资料、任务、教师要求、时间限制以及评价制度共同作用的复合产物。若仍把全部产出直接记到学生名下，大学读到的是组合，却误以为读到了个人；若反过来因为组合复杂而放弃读人，大学又失去了教育与认证的基本责任。真正的出路不是回到单一主体，而是在承认复合体的前提下，重新设计能够分别读取个人差、互动差、环境差和发生过程的账本。

本书因此有两个目标。

第一个目标是理论性的：把十篇专题研究提升为一套统一的“发生学能力差异度理论”。这套理论要能够说明，为什么当代六大核心竞争力理论各自抓住了一部分真相，却仍不能完整回答大学如何读人；也要说明十个概念之间不是简单并列，而是形成一条从发生条件、形成过程、持续供给、互动显露、跨场识别、证据取得到社会记账的连续链。

第二个目标是制度性的：回答副标题中的问题——大学如何读？本书最后不会停在“大学应该重视创新、判断与实践”这样的原则性口号上，而要提出一套可以讨论、试验和反驳的制度构造：如何记录答案到达与承诺落定的先后，如何识别单遍段，如何给无辅助且有真实后果的亲手执行留出位置，如何在本人作品延长线上发起可核的脱稿追问，如何轮换任务、同伴和模型以读取常席差，如何避免把互动优势错误归给个人，如何建立自愿而非强迫的他择读取机制，如何在不制造危险的前提下积累关键事件记录，以及如何让成绩单从结果清单转变为发生结构的有限映射。

这里必须预先声明一个边界。任何新的读数一旦成为强制考核指标，就可能被表演、优化和操纵。发生学能力尤其如此：若学校把“盲遍率”做成排名，学生会表演性地延迟查看答案；若把“他择率”做成门槛，机构可能把不预告观察扩展成不受约束的监控；若把“峰兑”做成履历要求，年轻人可能被推向人为制造的危险；若把“常席差”用于单一排序，组织可能为了取数而拆散本来稳定的高风险团队。因此，本书提出的多数读数，首先描述的是任务、位置、互动与记录结构，而不应直接成为给人贴永久标签的量具。

大学如何读？正确答案不会是一把更锋利的尺子，而是一套知道自己读到了什么、没有读到什么，并允许不同层级读数相互约束的制度。

这本书从这里开始。
