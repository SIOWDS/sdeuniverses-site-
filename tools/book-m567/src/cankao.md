# 参考书目

只列正文确实引到或转述到的著作。三部名著与古代经典标明本书所读的版本；现代著作正文大多只转述大意、不长引，这里列出处以便查考，书名后的年份为初版或首次发表之年。正文没有点出书名、只转述一路研究的，列该路研究最常被引的那一篇。
