# 附录

本书的承重判断不是先拟好再去找论据的，而是在动笔之前的一次问对里一句一句长出来的；大纲是在这些判断定下之后才列出的。下面按原来的次序登记 WDS博士在那次问对中的原话，只校正明显的错字，不改措辞。正文里每一个口径，都能在这里找到它最初的样子；读者也可以把这一页当作第十一章所说的“收口”的一个实例来读。

## 附录　本书的来路：WDS博士口述原话

**一、起问。**“如何打造真正解决个人问题的知识智能系统呢？你需要有两个东西：1. My books system，作为个人智能体的 RAG 和 Skill 基础文库；2. 你的个人理念世界的代表系统：各种专著和论文，知识系统；3. 一个知识发生系统：你的 SDE 智能体系统。”

**二、问对是 D。**“第三个就是用户与你的 ChatYou（SDE 内功）进行互动问对，这是一个具体的思考问对 D 差异过程，获得答案。”“前面三个是 S 和 E。”“或者说 ChatYou 代表着 D，其他两个代表 S 和 E。”

**三、理念世界是 S。**“专著，论文，知识系统，这些是最为重要的 RAG 大数据。”“就像我的 SDE 浏览，里面都是‘我的理念世界的展示 S’。”

**四、化为 Skill 的是 E。**“其中的一部分，比如 SDE 思想系统，和很多 Skill 系统，被用来做 Skill 系统和系统 prompt，他们就是 E。”“E 在推动着 ChatSDE 与我或者其他用户的 D。”

**五、成形为作品。**“个人解决方案，也就是用论文或者其他形式来代表，比如小说，报告，专著。”“比如，我每天写的很多专著，都是解决我提出的‘宏大问题’，也是我的‘个人想解决的问题’，比如‘博士的出路’。”“都是‘我的问题’。”

**六、思想体系系列。**“这样，My books，在我这里就有一个非常重要的部分，就是 SDE 思想体系专著系列。”

**七、同一性谱系。**“而这个系统必须打破从前的‘知识＝统一性认知’的定义，进入‘同一性谱系’。”

**八、E 的三维。**“社区是 E，但是社区是 E 的三界，不是信息和能量分量。”“E3，就是问对的那股劲。”

**九、立题。**“现在可以写一个专著：如何产生解决个性化问题的知识？20 万字。”
