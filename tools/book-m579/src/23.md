# 第23章　三方程、六路径、三原理

这一章的问题：这家面馆天天坐满，老板放下的那些事在底下怎样推着事情走？

## 三个字母，先说白话

假设巷口有家面馆，开了十几年。早上六点老板娘拉开卷帘门，灶上的汤已经滚了。七点上客，八点坐满。老主顾说，这碗面十年一个味。老板盯两样东西：汤的咸淡，出面的快慢。差一点，他立刻调。灶台后面的油垢他看见了，心想忙完再说。老师傅弯腰时捶了一下后腰，他也看见了，没说话。房东提过一句明年的房租，他只当没听见。这家面馆是假设的，这一章我们从头用到尾。

这是全书唯一用字母的一章。字母来自王德生的一套说法，叫 SDE。前面二十二章没用，是不想让您先背词。三本书的作者都没这么说过，下面的读法都归我们。为什么还要讲它？因为前面讲的差、接、不接、余量，都是一样一样讲的，讲的是去处。这一章要讲它们怎样互相推着走。这套说法本来就是讲这个的。字母记不住也不要紧，记住面馆就行。

S 是 Show，显露，白话就是“样子”。它指此刻显出来的那一面：向谁显，认得出，明天还在，说得出来。面馆向客人显出来的样子，是坐满了，十年一个味。D 是 Difference，差异。前面说一笔一笔的差流过来，D 说的是这些差怎样排队：谁先接，谁放下，谁压根排不上。白话叫“挑法”。老板的挑法就是汤和快。E 是 Entanglement，纠缠，白话叫“底下”。灶、师傅的腰、房租、老主顾的习惯、手里的现金，全搅在一起，动一样，别的跟着动。余量就在这里头。这三个字母不是三样东西摆在三个地方。一碗面端上来，三个都在。

## 三个式子：谁也不是老大

第一个式子写作 S=F(D,E)，意思是样子由挑法和底下一起定。今天客人看到的这碗面，是老板接住的那些差，在这副灶、这位师傅身上显出来的。油垢没有接，所以油垢不在这碗面里。样子只由接住的那些差显露。这句话很要紧。它说明看样子看不出放下了什么。您看一个人穿得整齐、话说得好，看不出他这几年把什么事放下了。您看这家店坐满了，也一样。样子再好，也只替接住的那部分说话。

第二个式子写作 D=G(S,E)，意思是挑法由样子和底下一起定。坐满了，师傅的腰还撑得住，老板就接着只盯汤和快。哪天客人少了一半，或者师傅请了假，他的挑法当天就换。接谁不接谁，看着像老板的主意，其实是样子和底下逼出来的。您家也是这样。孩子中考这一年，全家只盯分数，别的话都不提。等考完了，样子变了，大家才想起老人该去看牙。第13章说的“暂时不轮到”，就长在这个式子里。

第三个式子写作 E=H(S,D)，意思是底下由样子和挑法一起改。这样的挑法走两年，灶更油了，腰更坏了，房东那句话也没人接。不接和没接并没有白白待着，它们就在这里改写条件，余量也在这里走。这一条最容易被漏掉，因为它不出声。您每天晚睡一小时，今天的样子还是好好的，挑法也说这样划算，可是身体底下的条件在变。到底变了多少，式子不说。有不舒服还是要去问医生。

底下的改写，有两种来路要分开。老师傅的腰是不接，老板看见过，这一笔还有人记得，下一轮还可能排上。隔壁要修路是没接，这时候谁也读不到。两样都在改底下，分别在于有没有人看见过、记着。余量也可以这样看。余量是离那道线还有多远：手里的钱够撑几个月，师傅的腰还能撑几年，灶还能烧多久不出事。线多半不动，灶起火的那个温度就是那么高。动的是离线的距离。上一章说的沉底，放到这里就是前一种走成了后一种：有人记得的那一笔，到后来和没人读得到的那一笔没有分别了。

这里说三句老实话。第一，F、G、H 不是能算数的公式，只是记号，表示“这一样由那两样生成”，往里代不进数字。第二，这三个式子没有谁在先。王德生爱打一个比方，三脚架的三条腿互相靠着，一起才立得住，这只是打比方。第三，式子画的是互相的关系，看不出谁先动。可是日子是一步一步过的，总有一刻是某一样先动。所以光有式子不够，还得有路径和原理。

## 六条路：这一段谁先动

三个字母排队，一共有六种次序，这就是六路径。这套说法原本用它来问，一个问题该从哪一头下手。我们这里借来问一段事情里谁先动。这是借用，它也不穷尽世上所有的事。先看最常见的一条，E→D→S。下暴雨，客人不来，这是底下先变。老板一看，马上改挑法，先做外卖。过两天样子回来了。条件先变，差被读到，调一下，样子回到原来那样。《工程控制论》大半走这条，书讲稳定就是「即使出现内部的或外来的干扰时，系统也将会达到设计中所要求的性能」（§16.6）。戈夫曼也走这条。有人当众打嗝，桌上的人圆通一下，场面回来了。

再看 S→E→D。老板觉得这家店就是这个味，这是样子先站在那儿。有一天他往下想：汤靠骨头，骨头靠肉铺，味靠老师傅那双手，没有一样是自己定死的。这就是往底下看。看清了，他对这个味就不那么抓着了，挑法跟着变。《中论》的偈说「未曾有一法，不從因緣生」（[0033b13]，偈），就是把人从样子带到底下，再改他抓什么。修行的事比开面馆大得多，这只是帮您记次序。说《中论》走这条，是我们的读法，龙树没有这样分过。

第三条，S→D→E，就是沉底走的路。样子说没事：坐满了，一个味。于是挑法放过：油垢先放着，腰先撑着。然后底下悄悄地变。这条路的落点在 E，落在谁也看不见的地方。我们说三家都缺这个落点，就是这个意思。第一条路落在样子上，事情回来了，人人看得见。第二条路落在挑法上，人自己知道变了。只有这一条，走完以后面上什么也没有，所以没人觉得该管。上一章那只桶走的也是这条。主任看到楼好好的，就说先放只桶，下面的接头一年年烂。

三家为什么都不走到这个落点？看它们要什么就明白了。您家来客人，地上脏了，赶紧扫一下，屋子回到待客的样子，这件事就算办完。机器要回到指标，一场戏要回到定义，它们的落点本来就该在样子上，走到这儿就可以收工。修行要的是人不再抓着，落点就在挑法上。放下的差后来把底下改成什么样，不在它们要办的事里。这也是我们替它们说的理由，不是它们自己交代的。可是日子不收工，第二天还要接着过，底下改掉的东西第二天还在。

另外三条也说一下，都带例子。D→S→E 是先改挑法，样子跟着变，底下再变。老板立规矩，只卖一种面，店看着专了，备料少了，客人慢慢换了一拨。D→E→S 是先改挑法，底下慢慢变，样子最后才露。老板每晚多花二十分钟擦灶，半年没人看得出，一年后灶火稳了。E→S→D 是条件先变，样子先破，才改挑法。师傅腰坏请假，当天面就不对味，客人说了，老板才开始想徒弟的事。一段日子可以几条路连着走。没有哪条更高级，走错了也不报错，您只会觉得很忙，事情还是摸不到门。

这里有个毛病要先防。街上算命的，什么结果都能说圆。这六条路也一样，事后怎么都能挑出一条来讲。店垮了，可以说是 E 先动；店没垮，可以说是 D 先动。一个说法如果事情出来以后随便换字母都讲得通，它就什么也没说。这套说法自己也这样提醒。所以用这六条路有个规矩：事情出来之前，先说这段事走的是哪一条，下一步该看到什么，看不到算错。第24章的判死条款，就是照这个规矩写的。您要是听见有人张口就拿字母解释一切，可以问他一句，什么结果算你错。

## 三个原理：对不上就调，说没事，突变

路径说谁先动，原理说为什么动。一句话：一样东西要动，是因为另外两样对不上。原理有三条，都是两样对不上、第三样动，只是配法不同。编号不按日子走，先讲原理二。S×E→D，样子和底下对不上，挑法就动。今天这批骨头差，汤淡了，样子和底下对不上，老板多放骨头，加点盐。这就是对不上就调。

原理二，两家写满了，《中论》也可以算。您家的恒温热水器水凉了就加热，走的是这个。一个人当众失礼，大家圆通，走的是这个。《中论》按听的人配说法（[0025a16–17]，释），听的人不同，说法就换，勉强也走这个。前面第一编、第二编讲的，差不多都在这里。它太常见了，所以人们以为稳定就只有这一种。对不上就调，调回来，事情就算过去了。可是它有个前提，得有样子和底下对不上，并且被看见。要是样子一直说没事呢？

那就是原理三，S×D→E，样子和挑法把底下改了。坐满了，这是样子。只盯汤和快，这是挑法。两样都说没事，两样都很满意，彼此配得严严实实。差还在流，油垢还在厚，腰还在坏，条件被一点点改掉。这种时候没有人对不上，所以没有人调。比如一个班只看分数，分数年年好，老师满意，家长满意，可是孩子的觉一年比一年少。线多半没有动，熬夜该伤人还是伤人，走的是余量。三家对这一条都写得少。这是本书最想补上的一块，补得对不对还要查。

原理一，D×E→S，挑法和底下顶到头了，样子突变。老板还在只盯汤，那边灶上的油垢烧起来了。或者老师傅早上弯下腰，直不起来了。头天还坐满的店，第二天卷帘门没开。挑法要它这样，底下撑不住了，余量吃尽，矛盾只能从样子上出来。大家这时才看见。所以突变常常不是那一天的事，它是原理三走了很久以后的一下。当然，不是每次都走到这一步。很多差走着走着就过去了，这三个原理也不是必经的三步。

把它们连起来，就看得见转了。平常的日子走原理二，对不上就调。调不到、也不想调的差放下来，样子和挑法都说没事，就走原理三，底下在变。余量走完了，走到原理一，样子突变。突变以后又对不上了，又回到调。全书前面讲的每一个去处都在这个转里，它们不是分开摆着的三堆东西。同一笔差今天被接，明天被放下，后年被人当意外，走的就是这样一圈。

就拿灶上那层油垢，跟它走一遍。第一年，它只是灶台后面有点腻，老板看见了，够得着，放下，这是不接。样子说没事，挑法说先忙，走的是原理三。第二年，老板娘有回擦了一下，说这得好好刷一次，老板说等淡季。这算提起，没有轮到。第三年，当初说这话的老板娘回了娘家帮忙，老师傅也懒得提了，油垢成了灶台本来的样子，没人再把它当一笔差。第五年，一点火星落上去，样子突变，走的是原理一。一笔差在这几年里没有挪过地方，换的是它的去处。

## 回写：下一轮谁先动

卷帘门关了三天。下面才是这一章最要紧的一段。一次样子变了，它会反过来改写挑法和底下，这就叫回写。回写决定下一轮谁先动。假设有两位老板。甲老板清灶的时候，老师傅说，这油垢我看了好几年了。他认出来了，这场火是一笔旧差。他改了挑法，每周查灶，徒弟也开始带。下一轮，是挑法先动。乙老板说，倒霉，电线老化，谁也想不到。保险赔了钱，灶换了新的，重新开张。底下也改了，也算回写。可是写进去的是“这是意外”。下一轮还是样子先动：坐满了，油垢先放着。

这就是沉底律在这套说法里的位置。沉底的差回来了，人们认不出，回写就落不到它身上。火是真的烧了，灶是真的换了，可是当初放过的那个动作没有人碰。回写不一定是好事，也不是发生了就有改善，这位老板的回写把一句“谁也想不到”写进了店里。您家也是这样。一件事吵过以后，有的家说“以后这事得提前说”，有的家说“那天他心情不好”。两句话都是回写，下一轮谁先动就不一样了。回写要看得见痕迹才算，光说“我们吸取教训了”不算。

甲老板是怎样认出来的？他走的路，正好和沉底相反。沉底是从样子到挑法再到底下，一路往下沉。查的时候就要倒过来走：从底下露出来的事起手，问当初的挑法放过了什么，再问当初的样子为什么让人觉得没事。这恰好是 E→D→S 的次序，可是它不急着把样子调回去，它要先把来路找出来。假设您家老人摔了一跤，一条路是买个防滑垫，事情就过去。另一条路是坐下来问，这半年他走路是不是已经不稳了，谁看见过，当时为什么没当回事。第二条路慢，也不一定问得出，问不出就是沉透了。

## 洪流和四种结局

还有一层要说。这套说法把这些差合起来叫洪流，里头三种状态混着：秩序、介生、混沌。这是看事情用的说法，不是仪器能读出来的东西。面馆这个早上，汤的咸淡有读数，有人调，这是秩序。老师傅和小徒弟这几天说话的口气有点不一样，说不上是什么，这是介生，半显未显。隔壁要修路，菜价要涨，明年街上人多人少，这时还没形状，谁也读不到，这是混沌。一笔差可以在中间走。徒弟的口气明天可能变成一句辞职，也可能散了。隔壁的路真开了工，就成了老板要接的一笔差。油垢沉久了，反倒退到谁也读不到的地方去。三种状态不是三个格子，差在里面来回走，今天在哪儿，明天不一定。

老板盯的那两样，只是其中被接住的一小部分。人容易把这一小部分当成全部，因为只有它有读数。面上的秩序是真的，汤确实好。它只是不大。您家的日程表、孩子的成绩单、单位的报表也一样，它们都是真的，也都只记着被接住的那一点。这句话不是劝您去盯全部，那做不到，也用不着。第二编、第三编都说过，挑是要挑的。我们只是说，别把挑剩下的当成没有。

一段事情走下去，这套说法列了四种结局。耗散，是先崩掉身体、关系或者钱。老师傅腰废了，老板两口子吵散了，店也赔光了。内卷，是挑法越挑越细，底下不换。老板把汤调到一克不差，出面快到四十秒，油垢和腰一点没变，加的力气全被旧条件吃了。您家孩子从九十五分往九十八分逼，觉更少了，别的什么也没变，也是这个样子。轮回，这里和第22章的轮回来不是一个意思，是改了没站住，又被旧样子拉回去。出事后定了每周查灶，查了半年，生意一好就放了，三年后又来一回。

跃迁，是认出了那笔差，挑法和底下都换了，下一轮还站得住。甲老板两年后灶是干净的，徒弟能上手了，老师傅歇了，味道也还在，他也知道什么时候该再问一句。四种结局不是排名，也不是每家都得落进其中一种，能一直开下去也不等于就该这样开下去。比例是多少，我们不知道，没人数过。这套说法自己定过一条规矩：加上这几个字母，要是多不出能查的区分，式子就只是在整理语言。这一章多出来的，是沉底的落点在底下，和回写落没落到那笔差上。这两条怎样查、查到了多少，下一章照实说，查到的只是一小角。

**这一章说了什么。** 样子只由接住的差显露，挑法由样子和底下一起定，不接和没接在底下改条件，余量也在那里走。沉底走的是样子先说没事、挑法放过、底下悄悄变的路，落点正是三本书都缺的。回写决定下一轮谁先动，认不出的差，回写落不到它身上，事情就可能再走一圈，这些都是本书的读法，能不能查，下一章说。

**回家看一眼。** 找一件家里最近“挺好”的事，比如孩子成绩稳，或者生意不错，或者老人最近没喊哪儿疼，都算。问一句，因为它挺好，我们这阵子放下了什么？再问一句，这个放下的东西，底下有没有在变？要是答不上来，也不算什么毛病。您只是知道了，样子说没事的时候，这条路上的第一步已经走了，下一轮谁先动，还可以由您来定。
