# 附录一　词语小表

**差**：实际和预定、和上一刻、和别人之间的那点不一样。比如体温高了半度，这一场有人说错一句话。

**接**：差符合意义预定，进了回路、这一场或这件事，人和机器照它动。比如老师听见孩子读错字，马上纠正。在《中论》那里，把东西当实去接，本书说这个接本身是病，这是本书的转译。

**错接**：不该进的进了，把噪声当信号，把不实的当实。比如烟雾报警器把油烟当火。

**不接**：够得着，却不接。分两种。不符合：不合这一回的预定，比如老师看见零食不停课。在《中论》那里理由不同，贤圣放下不是不合预定，是不可得。暂时不轮到：这一轮不在侧重里，下一轮可能轮到，比如今年先顾孩子中考。

**没接**：还没到能接的份上。分两种。混沌碰撞：差在碰，一笔一笔没有形状，回路读不到它本身，比如教室里一阵一阵的杂响。介生：场面上半显未显，还说不上是什么，比如一句能全然否认的玩笑。这两个词是本书的。

**轮回来**：不接的差在后来某一轮重新进入动作。光提起不算。

**沉底**：不接的差一直轮不回来，知情的人走了或忘了，记录也查不到，它就沉成了没接。三条要同时够。

**认不出**：沉了的差回来时，人们把它当意外。

**余量**：系统离那道线还有多远。线多半不动，走的是余量。

**料**：没接的差可能成为下一轮的材料。这一面证据薄。

这些词说的不是几类差，是同一笔差先后可能经过的去处。

# 后记

这本书的说法来得很晚。我们起初想从三本书的共同毛病入手，试了很久，那条路走不通。后来换了一个问法：三本书讲的，也许是一样东西稳得住的三个面。沿着这个问法，才把作者原有的那套想法落到接、不接、没接，又走到沉底。走的路上，很多漂亮的话被顶了回来，第25章记了其中几件。

这本书写作时用了人工智能。Claude 协助读原文、查文献、写初稿和跑两次查验。三本书的内行意见是用只读原文的人工智能模拟的，不是真人，还没有请真人内行看过。书中的判断由署名作者负责。

书里说得最满的那句大白话，“放下的，会沉底”，超过了我们手上的证据。您转述的时候，请说小一号：放下的，有些可能沉底，有多少我们还没有数到。

王德生　黄倩盈
