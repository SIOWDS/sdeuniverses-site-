# 前言　一个放下去就没再拿起来的问题

## 一、从一句“没事”说起

一家人吃饭，您问老人最近身体怎么样，老人说没事。单位开总结会，主任说今年运转平稳，没事。工程师看着仪表说，读数都在范围内，没事。这句话我们一天能听好几回，也说好几回。这本书问的就是这句话：说“没事”的时候，事到哪里去了？

您多半有过这样的经历。一件事当时说先放一放，说的人也不是不负责任，当时确实顾不过来。后来忙别的，这件事就再没人提。过了几年，它以一件“谁也想不到”的事回来了。您这才隐约记起，好像很早以前有人说过一句。这种事太常见，常见到大家不觉得它值得写一本书。我们觉得值得，因为它不只是记性不好。一样东西能稳稳当当地运转，本来就要放下一些差；放下的那些后来怎样，却少有人跟到底。

## 二、三本不搭界的书

我们从三本书入手：讲机器的《工程控制论》，讲人和人的《日常生活中的自我呈现》，还有《中论》。《中论》问的是一切东西有没有定死的自己。这三本书放在一张桌子上，看着很奇怪。我们最初也不是为了证明什么，只是发现它们都碰到同一个问题：一样东西怎么立得住。一本说，先指定要什么，差了就调回来。一本说，大家合力把这一场的定义演住。一本说，正因为没有定死的自己，事情才成得了。三个回答都站得住，而且都写到了“放”：工程上有放过去的小量，饭桌上有当没看见的一下，《中论》里有明白了以后的照用不受。放了以后呢？三本书都写得很少。

这个地方就是这本书落脚的地方。我们把一笔差可能去的地方分成接、不接、没接。接，是符合意义预定，进了动作。不接，是不符合，或者暂时不在轮换的侧重里。没接，是还在混沌碰撞里，或者还在介生里。然后再问一句：不接的差轮不回来，会怎样？我们的回答叫沉底律。它的大白话就两句：稳住的，都是挑着接的。放下的，会沉底。这条律是我们自己的，三位作者都没这么说过，可能对，也可能错。

## 三、这本书不那样写

这本书不教您多管，也不教您放下。放下是日子必需的，什么都接的人上不完一节课，也过不好一顿饭。这本书也不把三本书写成三份整齐的答卷。它们在很多地方根本不对称，有的一格很厚，有的一格是空的，我们照实写。工程书里几乎找不到半显未显的东西，《中论》不许人把“不断不常”读成半成形，这些都写在书里。

这本书还写了自己可能怎样输。第24章列了判死条款，也摆了两回用公开代码做的查验：一回没有支持我们事先的猜想，一回判不了。第25章列了我们解决不了的事。我们宁可您读完说这本书哪里不对，也不愿您只记住一句顺口的话。书是写给普通人的。您不用读过这三本书。每讲一个意思，我们都先讲一件家常事，那些都是举例，不是谁家的真事。您读完一章，能拿自己家的事讲给家里人听，这一章就算读成了。
