# 导读　这本书怎么读

**全书一句话。** 稳住的，都是挑着接的。放下的，会沉底。这句话比我们手里的证据要满，第24章和后记都写明了。

**想先看全貌：** 读导论，再读第22章沉底律，再读结语。

**想先看三位作者：** 读第一编四章。这一编主要讲他们三位，我们自己的读法到第4章才多起来。

**想拿去用：** 读第14章的判别问句，再读第六编您最关心的一章，家、身体、单位，或者代码与 AI。

**想挑毛病：** 读第24章和第25章，那里写明了这本书怎样算输，也写了它解决不了什么。第23章是全书唯一用字母的一章，讲的是这本书背后的那套想法，不读也不影响读别的章。

**引文怎么看。** 《工程控制论》和《中论》的原文放在直角引号里，后面跟出处。§16.6 就是《工程控制论》第 16.6 节。[0033a22] 是大正藏的页码、栏和行。“偈”是龙树的诗句，“释”是青目的解释，两层不是一个人写的；提问人的话是书要反驳的，我们会标明。戈夫曼的引文放在普通引号里，p.13 指中译本第 13 页。

**章号怎么看。** 本书自己的章用阿拉伯数字，比如第22章；原著的章用汉字，比如《工程控制论》第十六章。

**每章的样子。** 开头有一句“这一章的问题”，接着是一个场面。正文分几节，各有小标题，节前有 ◆。末尾两段：“这一章说了什么”三句话收住，“回家看一眼”留一个可以马上做的小问题。
