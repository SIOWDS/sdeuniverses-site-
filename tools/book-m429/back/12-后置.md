# 附录

本书附四件：急的谱系决策树（拿来给一次急归类）、九问原题与九篇成文要点、全书判别局面与证伪条件汇总、参考文献。

## 附录一　急的谱系决策树

这棵树是给第一章 1.4 的三层判据配的工具。它的用法很简单：碰到一次你想叫它「急」的事，照着三个问题往下问，问到底，就得到这次急的一张「三层卡」。

先交代一句。S（显露）、D（差异序列）、E（特征纠缠）本是一起发生、不可分割的，下面把它们分开问，是理念界的假想性切割，只是为了让判据好用。请记得：S 是随 D 不停显露的谱系，不是一张固定的样子。

三层判据先摆在这里，后面都按它的意思用：

- **抢**：三维都在，只是次序乱了。事后能找到被抢在后面的那一维。
- **去**：有一维事后找不到痕迹。用展开测试检验：出了意外，退不回慢的过程。
- **避**：两维都在，但在相顶的那一刻退出。能观察到三种躲法：放弃、换方法、找人代。

### 一、树

提问顺序是：先问躲了哪对矛盾（Why，根），再问删了哪一段（How，路），最后问抢了哪一维（What，形）。顺序这样定，是因为按互锁假说，根决定路，路决定形（假说本身待裁定，这里的顺序只是约定）。这是第一章 1.4 里的「三层互锁假说」，尚待裁定，裁定前先这样用；后面第二节会说它错在哪里算错。三问答完，还有一个「缺」的读数：由第一问按三原理直接推出，不是假说，树的末尾单列。互锁预测只保留删与抢两样。

```
【第一问】相顶的那一刻，有没有人退出？（找「退出点」：话题换了、手松开了、事交给别人了）
│
├─ 有：两维在相顶的那一刻退出了。问：是哪一对？
│   ├─ A  S 与 D 没顶起来（想要的样子 vs 过程里的差异）
│   │      缺 E：缺的是「会」。三种躲法各看一眼：
│   │        放弃（不学了）／换方法（换一本字帖、换一个技巧）／找人代（交给别人）
│   │      互锁预测（尚待裁定）→ 第二问多半落在「去 D」，第三问多半落在「抢 S」
│      （观察上也见「抢 D」，如 7.3 读半拍被挤没、8.4 翻抽屉的小满，所以只说「多半」）
│   ├─ B  D 与 E 没顶起来（自己的下一步 vs 周围的场）
│   │      缺 S：缺的是判断，这一步该不该走，显露不出来
│   │      互锁预测只保留删与抢，且只有观察、没有定论（尚待裁定）：
│   │        第二问路上删了哪一段，读不出，记「读不出」，不写「去 S」；
│   │        第三问观察到「抢 D」（不称就做、嘴先动）
│   │                  或「抢 E」（先收场、被场带着走）
│   └─ C  S 与 E 没顶起来（想要的样子 vs 眼前的处境）
│          缺 D：缺的是新路，D 迟迟不出
│          删与抢只有观察、没有定论（尚待裁定）：多见【拖支】；或者改掉一头来消除别扭，然后走捷径；
│          也见过一边躲一边赶的，如抢 S、去 D（1.4 回到厨房），抢 D（3.4 的演员），抢 E（10.3 拖的阶段）
│
└─ 没有：相顶发生了，人在里面，或者根本没有相顶的机会
    └─ 不算「避」，直接进第二问（常常是「抢」，也可能是「抢对」）
       （场替人把相顶收走的「被动的避」，见 4.3、11.1：先撤场再答；只记作场抢，尚待裁定）

【第二问】他删了哪一段？
│
├─ 第一问答了 B 格的，先查 S：该显露的判断，事后找得到吗？
│   ├─ 找不到（掐断了的争论、手先伸出去、被人群替答的「同意」）
│   │      → 缺 S（判断没有显露过，果上的读数）。展开测试：隔一阵再来一次，
│   │        你们能不能指着说「上次就是在这里停的」？指不出，就是缺 S。
│   │        路上具体删了哪一段，这棵树读不出，记「读不出」
│   └─ 找得到 → 往下，照常问
│
├─ 否则先看果子有没有拿到。果子拿到了
│   │  做展开测试：出了意外，能不能退回慢的过程？
│   ├─ 能退回 → 没删。再分三种：
│   │     没出错，也找不到被抢在后面的那一维 → 折叠（老师傅的三下）。不算急，到此为止，只记一笔「快」
│   │     场真的不等、动作又是事前备好的（见附注②）→ 抢对。记「抢对」，进第三问
│   │     出了错，或事后找得到被抢在后面的那一维 → 不是去，是抢。进第三问
│   └─ 退不回
│       ├─ 找不到 D 的痕迹 → 去 D（去过程）
│       └─ D 在，但路径中间缺了一维 → 走捷径，看缺的是：
│             缺 E（只在脑子里成形，没入过场）    签名：一到新场就崩
│             缺 S（还没成形就入场，或被场一推）  签名：拿出去总被要求返工
│             缺 D（拿别人的结果直接换）          签名：结果在，说不出怎么来的
│
├─ 果子还没到，但人正朝它赶（事在途中，如赶着出门、赶着交）
│       展开测试用不上，改问：该走的那一段 D，现在有没有痕迹？
│       没有痕迹 → 去 D，进第三问；有痕迹 → 没删，进第三问
│
└─ 果子没拿到，该出的那一维也没出，而且人没有朝果子赶（忙别的、布场、往后挪都算没赶）→ 走【拖支】
       记「让维度」。展开测试用不上，因为没有果子可退。
       拖和急常在同一个人身上轮流出现（见例三）

【第三问】他抢了哪一维？（找被抢先的那一维和被抢在后面的那一维；第二问答了「去」的，那一维另记，不要求三维都在；走拖支的可以不问，要问时 10.3 观察到拖的阶段多是抢 E，即先布场）
│
├─ 抢 S：先拎出结果的样子，倒过来催 D。被抢在后面的是 D、E
├─ 抢 D：差异一冒头就非动不可。被抢在后面的是 S、E（还没显露完就动）
└─ 抢 E：事和结果都还没有，先把关系和场绑定。被抢在后面的是 S、D

【缺的读数】由第一问按三原理直接推出，不是假说
│   A 格（躲 S 与 D）→ 缺 E（「会」）
│   B 格（躲 D 与 E）→ 缺 S（判断没显露）
│   C 格（躲 S 与 E）→ 缺 D（新路没走出来）
│   第一问答「没有」的，没有这一栏

【三个附注，每次都要标】
① 人抢还是场抢？  把场撤掉（截止期、排名、催促、危险），同一个人还抢吗？
                  还抢：人抢；不抢了：场抢；撤了之后弱了一半：两者各占一些
② 抢对还是抢错？  场真的不等，还是人以为它不等？真的不等：抢对，这种急救命
                  场其实等得起：抢错
③ 急还是拖？      走【拖支】的，在附注里写「拖」，并写明躲的是哪一对（多半是 C）
```

### 二、读这棵树的四条规矩

第一，三问的答案要互相合得上，合不上的格子才有信息。比如第一问答「躲 S 与 D」，第二问却答「没删」，第三问答「抢 E」，那就说明要么判错了某一问，要么互锁假说在这个格子不成立。后一种情形是整本书最该被看见的东西，请记入附录三第一章一条的读数里。注意，合不合得上，只比第二问、第三问的删与抢；「缺」的读数由第一问直接给出，不参加这一比。

第二，「避」靠观察，不靠猜心思。只有看到了退出点（放弃、换方法、找人代三种之一），才能答「有」。看不到，就答「没有」，不必替人补一个躲法。这也是本书不作心理诊断的原因：树问的是做了什么，不问为什么这样的人。

第三，「抢」与「去」分不清的时候，回到展开测试。事后能不能找到那一维的痕迹，找不到，就是去。

第四，一次急可以同时落在几个格里，但必须每层只答一个主答案，不许写「抢 S 兼抢 E 兼去 D 兼躲三对」。写成这样，等于没有归类。

### 三、三个日常例子走一遍

下面三个都是我构想的场景，只为演示这棵树怎么用，不作为各章的主案例。

**例一：周日晚上的教案。**（这是我构想的场景）林晓周一第一节有课。周日下午她有三个小时，但到晚上 9:00，她把网上一份现成教案原样拿来，改了几个例句就定稿。

第一问：她心里想要的是「一节课的样子」，手里却对这个班这周的差异还没摸出来，两者没顶起来。她退出的方式是「找人代」，让现成教案替她摸。所以是 A 格，躲 S 与 D，果上缺 E，也就是她自己那点「会」。第二问：果子拿到了，做展开测试：如果有个学生在课上问了一个教案里没有的问题，她能不能退回到「这个班这周卡在哪」？退不回，D 没有痕迹，所以是去 D。第三问：被抢在前面的是 S，也就是课的样子，D 和 E 都排在后面，抢 S。附注：周一早上是场，但周日下午三个小时是空的，撤掉截止期她仍然会这样做吗？大概率会，所以人抢的成分重；场其实等得起，抢错。结果：A 格（缺 E）、去 D、抢 S，三层合得上，互锁假说在这里成立（尚待裁定）。

**例二：卷子的第一题。**（这是我构想的场景）小满拿到数学卷子，看见第一题就动了笔，题干最后有三个字「不正确的是」，她没读到。

第一问：有没有人退出？没有。她没有躲什么矛盾，这里相顶根本没有机会发生，因为动作比相顶来得早。所以树把我们直接送到第二问。第二问：果子是错的，但事后她能退回去：老师一提醒，她重读题干，能把整道题重新做一遍，D 的痕迹在，只是路上少了「读完」那一步。不是去，是抢。第三问：被抢在后面的是 S（题干的意思还没显露完）。抢 D。附注：考试有倒计时，场在催；但同一份卷子，同桌在场里却读完了题，说明场撤不掉，人也有份，各占一些；场并非不等，抢错。这个例子说明：第一问可以答「没有」，那就不必硬编一个躲法，直接用第三问把它归类。它是 B 格的近亲吗？不是，因为没有退出点，也就没有「缺」的读数可读。B 格读出的是缺 S，删与抢只观察到抢 D 或抢 E，这是单向的，反过来「抢 D 一定来自 B 格」并不成立，请别倒推。

**例三：一直没开口的那次谈话。**（这是我构想的场景）林晓想把班里收作业的方式改一改，需要先和年级组长说一声。她想了一学期，每次都觉得「再等等，等考完试」，直到期末最后三天，一口气把方案写完、材料全交上去。

第一问：有退出点。每次走到该开口的时候，她把它挪到了「以后」。想要的样子（改方式）与眼前的处境（组长不喜欢动静）没顶起来，所以是 C 格，躲 S 与 E，果上缺 D，也就是那条新路，躲法是「换方法」中的一种：把「去谈」换成「等时机」。第二问：果子没拿到，而且该她出的那一维（去谈这一步）一直没出，走拖支，记「让维度」。第三问：拖支里不再问抢哪一维，但要标一句：期末最后三天狂赶，是同一个人在同一件事上从拖转成了急，这时可以补问一次，答案是抢 D。附注：学期中没人催，场没有在抢她，是人在躲；最后三天截止期压下来，场开始抢，所以先是人拖，后是场逼的急。抢对抢错：最后三天的狂赶没有错，是迟到的补救，但它补不回一学期里本该长出来的那条新路。

三个例子分别落在 A、没有退出点、C 三个入口，说明这棵树不是只会给一种急贴标签。

### 四、三种感觉里各走一遍

树不只用在大事上。下面用触、听、看各举一个小例子，每一个都含完整的 S·D·E，看看三问怎么问。三个都是我构想的场景。

触觉：穿针。线头在指尖一点点探出去（D），针眼的小、屋里的光、手指的微微发抖（E），线头一点点对准针眼的那个显露过程（S）是一起发生的。赶着缝一颗扣子的人，眼睛盯着「穿过去」的结果，手先去戳，线头散开成一团。第一问：没有退出点；第二问：D 在，没删；第三问：抢 D，被抢在后面的是 S 的显露，线头还没对准，手就戳了。

听觉：装修师傅蹲在地上给你讲方案，讲到一半，你已经点头说「行，就这么办」。师傅的语调起伏、哪一句加了重音（D），满屋的灰、报价单、一蹲一站的两个人（E），方案的意思一点点显露（S），都还在途中，你拿着前半句就应了。第三问：抢 S，答案的样子先到了。若这时并非你没听完，而是有一句疑问已经到了嘴边，怕问出来显得外行，又咽了回去，第一问就该答「有」，躲的是 D 与 E，果上缺 S，即「这话该不该问」的判断没有显露，躲法是「放弃」，把疑问咽回去；第三问也随之变成抢 E，和气先到。同一个场面，有没有退出点，要看嘴边那句疑问有没有出现过。

视觉：照菜谱炒一道番茄炒蛋。眼睛一行行扫过菜谱上的字（D），灶台、油温、手边的碗和锅（E），这道菜怎样一步步成形（S）本该一起显露。急着开饭的人，只扫了第一行的菜名和配料就下了锅，漏掉第三行「蛋先炒到半熟盛出」。第一问：没有退出点；第二问：字就在纸上，事后找得到被漏的那一行，不是去；第三问：抢 S，并且属于吞拍，不是无拍：那一行就在眼前，是被「快开饭了」顶替了，所以回头对一遍真的能修。

这三个例子都说明一件事：同一个动作，可以在第一问有退出点，也可以没有；两种答案会走到不同的补法，不要混。

## 附录二　九问原题与九篇成文要点

读这张表有三点要说。

一是九篇每一篇切中的都是真东西，但只切到一层：《急的两种死法》《提前发动与看回来》《拍位归属论》切的是「抢哪一维」，《一句劝告的两本账》《离开的餐桌》《读半拍》切的是「删哪一段」，《拍子归谁》《节拍计权错误》《门缝上的换手》切的是「躲哪一对矛盾」。三个三篇，正好各占三层中的一层。这是回头用三层去读九篇时看到的，不是写九篇时安排的〔待核：尚待确认〕。这个发现本身就是本书的起点：九刀不是九件事，是同一次简阉的九个切口。

二是分数卡在 129 至 138 的原因，前言里写得很清楚：每篇只抓住了一层，而且漏了最近的邻居。这些邻居，本书放进了各章的交锋节：指差确认、卡尼曼的回归错觉、心流、单纯紧迫效应、话轮转换与执行意图。

三是本书吸收九篇，不是照搬，是把每一刀放回它所在的那一层。九刀的锋利度和判别预测保留，具体见附录三。

## 附录三　全书判别局面与证伪条件汇总

本附录把全书的判别局面汇在一处：两条总证伪，加第一章到第十一章各一条，另附第十二章的一周自检。每条都写明：两组人是谁，可清点的读数是什么，本书预测什么，对手预测什么，以及出现什么就是本书错了。

先说明三件事。其一，这些都是预测，写在做之前，不是事后解释。其二，这里的读数是用来「清点」的，比如次数、对错、能不能退回去，书里的读数不进任何人的考核。其三，我没有做过这些实验，下面写的两组人和读数，是按各章正文里的判别局面汇总的，人数、阈值等数字以各章正文为准；个别由我另行拟定的条目，已标〔待核〕。

### 总证伪

**总一：完整执行者仍急仍错。**两组人：一组在一件事里三维同步、路径走全、也进入了矛盾（由两位旁观者按附录一的树独立确认，三问的答案都是「没有」，也可按 1.5 的做法，由不知分组的评阅者对着记录纸，认定「三条都做到」）；对照组是同一类事里按树归类后有明确简阉的人。读数：出错次数、返工次数、变形题上的出错次数、事后自述「急」的次数。本书预测：前一组的急与出错应明显少于对照组。对手（急只是快慢与耐心问题）：两组没有明显差别。出现什么本书错：前一组到了变形题上照样出错、展开测试也退不回，本书总命题作废。

**总二：只减速组与只改抢删躲组。**这一条在 1.5 里写成了具体的局面，也就是第一章那一条（见下）。两组人：80 位志愿者随机分两组，每组 40 人，一周，每天 15 分钟，同一套题。甲组只减速：每道题用时至少是自己平时的两倍，其余一概不管。乙组只改做法，不限时：动手前把条件圈出来（补维）、每一步写出中间结果（补程）、卡住时写下「我卡在哪」并待住（进矛盾）。读数：常规题出错次数；第七天变形题出错次数；对每个错做展开测试，看能不能退回去讲出来；两位不知分组的评阅者认定乙组是否真做到三条；两组各自用时。本书预测：乙组降幅明显大于甲组，尤其在变形题上，且降幅与记录纸上「三条做得全不全」挂钩，不与用时挂钩。对手（速度—耐心观）：甲组降幅不低于乙组。出现什么本书错：甲组与乙组降幅一样大或更大；乙组的降幅只发生在用时最长的人身上，与三条做得全不全无关。

### 逐章

**第一章（1.5 本书怎样会错；1.4 三层可判别）。**两组人：就是总二的甲、乙两组，这是 1.5 里给出的局面。另附一条检验 1.4 的判据本身：两位互不相识的评分者，不看书中答案，只拿一批日常的急的例子，按附录一的树独立归类。读数：两人在三层各自的主答案上一致的比例，以及三问答案「合得上」的比例。本书预测：一致率明显高于随机，且合得上的比例高。对手（「急于求成会跳步」这句老话）：只能贴出一个标签，两人的归类零散。出现什么本书错：一致率不比随机高，三层就退回成了三个名字；合不上的格子占多数，互锁假说作废。〔后一条检验为我据 1.4 拟定，待核〕

**第二章（2.4 抢 S；并入《急的两种死法》）。**共三组局面。

- 局面一（对孔子）。两组人：校对同一类文件（比如一份社区义卖的账目）的人，一组为他人无偿做、目标大到整个社区，一组为自己、拿一点小奖金；每组再分两种条件，给一张「做完应当是什么样」的成品样图，或不给样图、只要求每步写下「这一步该露出什么」。读数：每份文件被跳过的核对项数；过程中「目标描述」被改写的次数。本书预测：给样图时两组跳过数相近，且都多于不给样图时；利的大小没有主要影响，S 有没有被切出才有。对手（孔子的「见小利」）：无偿大目标组的跳过数应明显更低。若出现这些，本书就错了：无偿大目标组在给样图的条件下，跳过数显著低于小利组，差距接近不给样图时两组的差距。
- 局面二（对速度—准确率权衡与「早计」的读法）。有两个版本。写作者版，两组人：一组期限延长一倍、仍按「成稿的样子」打分，一组期限不变、每写一段先写下「这一段应当让读者看到什么」；读数：初稿里前后矛盾或漏掉的要点有几处、在稿子的什么位置。外科医生版，两组人：一组时限放宽、但心仍盯着「下台的样子」，一组时限不变、但把验证拍装回去；读数：漏掉的核对项数，以及漏在第几项。本书预测：两个版本同向，都是第二组更少，第一组的错集中在末端。对手（速度—准确率权衡、「早计」）：放宽时限的第一组更少。若出现这些，本书就错了：放宽时限但不改结构的一组，比不放宽但改了结构的一组漏得少，而且漏的位置分散。
- 局面三（并入吞拍与无拍）。两类局面，各是加了动作的一组与没加的一组。吞拍局面（填身份证号、找钥匙）：在原位加一个很小的强制动作，填完把号码念一遍、翻完一处说「这里排除了」；读数：被退回的表格份数，同一个角落被翻的遍数。无拍局面（车冲到面前、油锅起火）：事先对人说「请你慢一点」；读数：结果有没有变好。本书预测：吞拍局面明显减少；无拍局面不会变好，只有事前装进去的东西有用。对手（把急看成快慢游标）：两类局面放慢都有益。若出现这些，本书就错了：吞拍局面加了「念一遍」并不减少错误；无拍局面只凭「放慢」的指令就明显改善。

**第三章（3.4 抢 D；并入《提前发动与看回来》《拍位归属论》）。**共五组局面。

- 局面一（3.4 主局面）。两组人：都是做过同类表演、两人一组对台词的人；甲组心定而工作记忆充裕，乙组被安排成心浮而记忆被占（告知当场评分，并让他们默记一串数字）。每组再分两个条件：同步条件下，起手提示灯在搭档说完末字落音时才亮；提前条件下，灯在末字之前半拍就亮。读数：抢拍次数（开口早于搭档末字）；卡壳次数（忘词或停住超过 2 秒）。本书预测：抢拍随提示灯走，提前条件下甲组的抢拍明显多于同步条件，且与心率、工作记忆分数无关；卡壳随心和容量走，乙组多于甲组；乙组在同步条件下抢拍并不比甲组多。对手（掉举、窒息研究、担忧占容量、话轮转换，四家大体一致）：甲组不论灯早晚都少抢拍、少卡壳，乙组都多。若出现这些，本书就错了：提前条件下甲组的抢拍没有增加；乙组在同步条件下抢拍也明显多于甲组。
- 局面二（《提前发动与看回来》之一）。两组人：煮同一锅面，一组被要求「水重新滚起来之前不许掀盖」，一组随意。读数：掀盖次数；从下锅到出锅的分钟数。本书预测：随意组掀盖更多、出锅更晚。对手（心浮说）：掀盖多少只是性子急，与出锅时间无关〔待核：这一句对手预测是我据局面补的〕。若出现这个，本书就错了：随意组出锅并不更晚。
- 局面三（《提前发动与看回来》之二）。两组人：做同一件 40 分钟的活，一组在做到一半时写下一句对自己这个人的评价，一组做完以后写同样的一句。读数：自评的沉重感（零到十）；接下来 10 分钟里反复改动同一处的次数。本书预测：事中写的一组两样都更高。对手：两样只随内容轻重变，与写在事中还是事后无关。若出现这个，本书就错了：事中写与事后写没有区别。
- 局面四（《拍位归属论》之一）。两组人：每组 8 人，甲组语速快、但总在对方说完后才开口，乙组语速慢、却常插入。读数：每小时抢拍次数；同伴投票选出的「谁让人觉得被催」的票数。本书预测：票数随抢拍走，不随语速走。对手（快就是催）：票数随语速走。若出现这个，本书就错了：票数只随语速走。
- 局面五（《拍位归属论》之二）。同一批 8 个人，开 5 次会，看每个人的两个读数：每人的抢拍次数；「轮到后超过 3 秒没出声、会后问他其实有话」的次数。本书预测：两个读数在同一个人身上同升同降。对手（性格论）：此消彼长。若出现这个，本书就错了：两种读数在会上此消彼长。

**第四章（4.4 抢 E）。**两组人：同一批项目组里匹配了职级、工作量和工时的人，分组靠事前读数，与那封邮件无关：入组头两周，没有外压的日常里，「绑场动作」（先表态、先认领显眼的事、先问「上面怎么想」）出现在第一份可给人看的草稿之前的为 A 组，之后的为 B 组。读数一：邮件到达后第一小时里，绑场动作与起手动作各多少次；读数二：交付后由第三人审阅，把错分成对接性错误（口径、对象、版本与场里的真实需要不合）和内容性错误（算错、漏项、抄错）；读数三：换一轮邮件、截止期延后一周的撤场轮，看前两个读数还剩什么。本书预测：A 组绑场动作多于起手动作，B 组相反；A 组的错以对接性为主，B 组以内容性为主；撤场轮里 B 组回到平常，A 组的绑场与错的类型基本不变；每一格压力下两组斜率相似、截距不同。对手（罗萨的加速、汤普森的钟表）：匹配之后两组读数没有系统差别，撤场轮里一起回到平常。出现什么本书错：匹配后两组在读数一和读数二上没有差别；撤场轮里 A 组的绑场与对接性错误和 B 组的急一起消失；A 组在长期无加速压力的环境里读数衰减到与 B 组无差别（那就是场的残影，罗萨和汤普森对）。

**第五章（5.4 交锋，删与折；并入《一句劝告的两本账》《离开的餐桌》）。**共四组局面。

- 局面一（5.4 主局面）。两组人：每组 20 位司机，在这段路上走过的次数、日常车速、到达时间的平稳度都一样，只在头几次是不是自己找过路上分开；在隧道里让导航断掉。再加子条件：依赖导航的一组，一半被提醒「别慌，认真想想」。读数：从断到重新确认方位用了多久；不借手机能不能说出「我现在在哪个已知地标的哪一侧」；接下来的错拐次数。本书预测：自己找过路的一组三个读数明显更好；依赖组被不被提醒几乎没有差别，要补上一小段 D 才改善。对手（卡尼曼加练习时数）：两组表现相近，且提醒会让依赖组改善。若出现这些，本书就错了：两组读数没有差别，或一句提醒就让依赖组追平。
- 局面二（《一句劝告的两本账》）。两组人：带新人的两组，一组说「别急，慢慢来」、不给日期，一组说同样的话、并写明自己哪天出场看什么。读数：第一版出现在开工后第几天；最后 48 小时里返工的次数和集中程度；交付后双方对「这件事谁欠谁一次什么」的回答是否一致。本书预测：无日期组第一版更晚、返工更集中、回答对不上；日期写了而说的人缺席，则退回无日期组。对手（给人自主、减少压力有益）：无日期组至少不比有日期组差。若出现这个，本书就错了：无日期组第一版并不更晚、返工也不更集中。
- 局面三（《离开的餐桌》）。两组人：早晨总有人被点名的家庭，甲组把账翻开、全家在冰箱贴上记一周，并把「快点」的对象改成自己，乙组只被告知「要少催一点」。读数：被点名者是不是同一个人；赶上校车的天数；被点名的孩子自己先开口报「我还要几分钟」的次数。本书预测：甲组催的次数下降而赶上天数不降、先开口的次数上升；乙组催的次数很快回到原样。对手（催是有效的外部提示）：不催，赶上天数就会下降。若出现这些，本书就错了：甲组赶上天数明显下降且一周内没有回升，或乙组与甲组催的次数一样下降。
- 局面四（5.4 回归课）。两组人：一组家长上一堂讲清回归平均的课，另一组家长翻账、并明确由谁认领出门这串事。读数：一个月后，各家早晨催的次数。本书预测：只上课的一组很快回到原水平，翻账认领的一组下降。对手（回归错觉论）：讲清回归之后，催应明显下降。若出现这个，本书就错了：只上课的一组降得和另一组一样多。

**第六章（6.5 交锋，局面落在缺 E 一条）。**两组人：40 个学琴一年左右的 10 岁孩子，随机分 A、B 两组，每组 20 人，同一位老师，同样的曲目、同样的反馈，一学期累计练习 60 小时；A 组全是独奏，B 组每周有 20 分钟与同龄人合奏（算在 60 小时之内）。读数：独奏测试的出错次数（确认基本功没有差别）；新场合奏里每 100 小节的「抢拍、漏拍、中断重来」总次数；陌生琴独奏的出错次数；合奏前一天的预估停顿次数减去实际次数。本书预测：独奏测试 A 组不比 B 组差；新场合奏 A 组明显更高，先定的阈值是中位数至少为 B 组的 1.5 倍（倍数尚待裁定）；陌生琴独奏 A 组也更高；预感差上 A 组低估得更多。对手：时数论、反馈论预测新场合奏两组一样，或只有 B 组因独奏时间少而略差；练习专一性预测新场合奏 A 组更差（与本书同向），但陌生琴独奏两组一样，所以只有陌生琴独奏这一项能把本书和它分开。出现什么本书错：A 组的出错次数不超过 B 组的 1.2 倍，或反而更低；合奏上 A 组更差而陌生琴独奏两组差别落在自然波动之内（缺 E 被练习专一性吸收，「E 是一般能力」就错了）。另有副预测：给 A 组补 4 周合奏后再测，追平为「抢」，仍明显落后则含「去」，区分要改动。其余五条，6.5 末只点了读数：缺 D 的一组与不缺 D 的一组换成变形题通过率；缺 S 的一组与不缺 S 的一组换成「同一件东西被不同场要求返工的次数是否一致」。具体设计正文没有给〔待核：尚待裁定〕。

**第七章（7.4 交锋，折叠与删除；并入《读半拍》）。**共三组局面。

- 局面一（7.4 主局面）。两组人：初中一年级同一个单元的两组学生，一组是练出来的（拼剪、推导、试错，自己走到公式），一组是抄来的（只给公式、例题、口诀，刷题到熟）；两组用三道关配平：标准题的正确率与用时、「说出公式为什么成立」的口头测验、单元考分数。读数：变形题（每道只改一处条件）的首次解出率；做不出时草稿纸上有没有「退回」的痕迹（两位不知分组的评分者独立计数，取较少的一个）；一周后新一套变形题的用时与出错有没有递减。本书预测：配平的项目上两组无区别，练出来的一组在三个读数上明显更好。对手（常规专长理论、知识编译）：配平之后两组落在同一类，对变形题没有系统差别。若出现这些，本书就错了：配平之后两组在三个读数上没有区别；抄来的一组草稿纸上显出同样多的退回痕迹；练出来的一组同样在变形题前退不回去。
- 局面二（《读半拍》之一，对指差确认）。两组人：做同一个漂移任务，屏幕上连续几百次把光标拖到目标点，目标点每隔若干次悄悄偏移；一组每次先做指差式的固定动作，一组每次先读半拍、让视线扫过上一次落点偏在哪。读数：漂移出现后，到发现并修正之间的操作次数；「动作做了但下一次没有任何修正」的比例；总操作数。本书预测：目标不漂移时，指差组不差；漂移出现后，读半拍组发现更快，且指差组的空动作比例随练习升高。对手（指差确认）：两组发现漂移的速度差不多。若出现这些，本书就错了：指差组的空动作比例并不升高，发现漂移也不比读半拍组慢。
- 局面三（《读半拍》之二）。三组人：不回读、整拍回读、半拍回读。读数：连续 10 次出手里偏差方向相同的最长串；出手总数。本书预测：三组分得开，整拍组与半拍组不同。对手：正文没有单列〔待核〕。若出现这个，本书就错了：整拍组与半拍组没有区别。

**第八章（8.4 交锋，不肯相顶）。**共三组局面，第一组另有堵漏的对照。

- 局面一（耗能）。两组人：每位受试者前一天亲手把 10 件东西放进 20 个格子，次日随机抽一件让他找；甲组被指令「马上找」，乙组被指令「先坐下想 1 分钟再找」。读数：开合格子的总次数；重复开同一格的次数；总用时（乙组含那 1 分钟）；停顿次数；一周后换房间、换物品，不给指令，看各自自然选择的做法。本书预测：甲组动作数和重复数更高、停顿更少，20 格以上时总用时不短于乙组。对手（省力的朴素读法）：甲组总耗费不高于乙组。若出现这个，本书就错了：20 格以上的搜索里，甲组的动作数、重复数和总用时都不高于乙组。堵漏的对照：另加第三组，同样坐 1 分钟，但被要求做无关的心算、不许回想；它若和乙组一样好，好处来自停下而非对顶，本书要改写。读数里再加一项：事后请受试者说出自己翻过哪几格，说不出的，停顿是空的。
- 局面二（困难要对顶）。两组人：随机分组，同样难、同样久、同样的失败次数；甲组失败后，把自己的解与规范解并排，写出「哪一步分开、为什么分开」；乙组继续做同样难的新题，只告知对错。读数：一周后变形题的正确数；能指出自己错在哪一步的人数。本书预测：甲组两样都更多。对手（只要难就有益）：两组一样。若出现这个，本书就错了：两组变形题正确数与指出错处的人数没有差别。
- 局面三（动机系在哪）。两组人：同学一个有难点的小技能；甲组的奖励系在最终结果，乙组的奖励系在每次练习后写下「这次与上次不同在哪」。读数：难点前停手、换手、求助的次数，以及这些出现得比难点早多少。本书预测：甲组更早、更多地退出。对手（有动机则肯多想）：甲组躲得更少。若出现这个，本书就错了：甲组在难点前退出的次数不多于乙组，也并未更早。

**第九章（9.1、9.2、9.3、9.4）。**共四组局面，其中一组另设对照。

- 局面一（9.4 正念）。两组人，外加一个对照组：一组是有半年以上日常练习、正念量表得分高的人（量表和分数线由实验者在看数据前登记），一组是没有训练的同龄人，对照组是没有正念训练、但练过一个月「当场签收下一步归谁」的人。大家专注做一件手上的活，被人打断；打断分两类场：静场（没有催、没有期限）和催场（带着「快点，来不及了」），催场里再分催有据和催无据。读数：从催开始到停下手上的事用了几秒；催无据时被带走（立即放下手上的事跟着走）的人数比例；催有据时该走没走或走得迟的人数比例。本书预测：正念好的一组在静场里明显更稳，到了催场优势大幅缩小甚至消失，错落在两头；签收组在静场里不比对照强，在催场里最能分开有据与无据。对手（一行禅师、卡巴金）：正念好的一组在两类场里都更稳，优势相近。若出现这些，本书就错了：正念组在催场里的优势和静场里一样大；签收组在催场里分不开有据与无据。
- 局面二（9.2 不称就做）。三组人：面前摆着一件紧迫但回报低的事和一件不紧迫但回报高的事。校准秤组在选择前得到一张清楚的回报对照；启动称组不给信息，只要求伸手之前用一句话把冲动和处境放在一起；等待组只等 30 秒。读数：每组选了低回报紧迫项的人数比例；同一批人在不同处境下反应的变化幅度；30 秒里目光一直停在紧迫项上的人数。本书预测：校准秤组降得很少，启动称组降得最多，等待组几乎不降；死排序的人，反应在不同处境里是平的。对手（单纯紧迫效应，是称错）：校准秤组明显下降，启动称组下降不比校准秤组多。若出现这些，本书就错了：校准秤组的下降和启动称组一样多，或等待组也明显下降。
- 局面三（9.3 换手）。两组人：一组事先练习执行意图（「如果孩子又犯那个错，我就提醒一次」），一组练习当场签收（「这一步归我／归他／先不动」）。两类场：场和预案一模一样，或场是变形的（同一个错误，同时多了预案没有的东西，如电话响了、对方明显累了）。读数：「越位出手」的次数；「错过起手」的次数。本书预测：一模一样的场里两组差不多，执行意图组可能略好；变形的场里，执行意图组的两种读数明显上升，签收组上升很少。对手（执行意图）：两类场里执行意图组都稳。若出现这些，本书就错了：变形的场里两组一样稳；一模一样的场里签收组也比执行意图组明显差。
- 局面四（9.1 掐断与暂停）。两组人：一组是被「好了好了，不说了」掐断的争论，一组是双方说好暂停、约了时间再谈的争论。读数：同一个话题隔一段时间再出现时，两个人手里有没有多出一样上次没有的东西。本书预测：暂停的一组两边新增的东西更多，没有新增的上次是掐断，有的是暂停。对手：正文没有单列〔待核〕。若出现这个，本书就错了：掐断了的争论隔一段时间再来时，两边新增的东西不比暂停了的更少。

**第十章（10.2、10.3、10.4；并入《拍子归谁》）。**共四组局面。

- 局面一（10.2 末拍无主）。两组人：同一批受训者做模拟抢救演练，分四组，改变两个条件，一是外部喊拍密还是疏，二是演练结束时有没有人当场点名「下一步归谁」。读数：演练中的漏项数；演练结束后十分钟内的返工次数、重复核对已核对过的东西的次数、互相问「刚才是不是我……」的次数。本书预测：演练中的读数只跟喊拍疏密走，结束后的读数只跟末拍有没有主走，「密而无主」那一格收尾后最乱。对手（心流：进入流的程度相同，则收尾后读数相同；过度监控说：执行中回头看得少的人，事后乱得少）：都不预测「密而无主」这一格会收尾乱。若出现这些，本书就错了：「密而无主」的一组收尾后并不比末拍有主的更乱；或末拍有主的组收尾后的乱度仍随喊拍疏密而变；或几乎没有回头看的人，收尾无主也不乱。
- 局面二（10.3 拖）。同一个人当自己的对照，各做两类任务：一类里想要的样子和眼前的处境撞得很具体（比如写一份自己看得出材料不够的申请书），一类里两头没什么可撞（按现成表格录入数据）。读数：从拿到任务到第一个触到矛盾的动作之间隔了几天；总共做了多少动作。本书预测：同一个人，第一类任务上隔的天数明显长，第二类上很短，总动作量相差不大。对手（拖是性格）：隔的天数跟着人走，拖得多的人两类任务上都拖。若出现这个，本书就错了：同一个人在两类任务上隔的天数高度一致，与两头撞得具不具体无关。
- 局面三（10.4 之一）。两组人：面对同一个临近的截止期，价值与期望测得一致。一组按斯蒂尔式的办法办，拆成每周一个小截止期，再加奖励；一组在最初两周先把想要的样子和眼前的处境各写成具体的话，再各做一个能退回来的小试探。读数：总工作量；交付物里「事先清单上没有、后来才出现的做法」的数目；变形题上谁能展开。本书预测：总工作量相当，甚至拆小截止期的更高；新做法的数目，先顶后做的一组明显更多。对手（斯蒂尔的算式）：期望、价值、冲动性、延迟都相当，两组行为没有差别。若出现这个，本书就错了：先顶的一组新做法并不比拆小截止期的一组多。
- 局面四（10.4 之二）。两组人：面对同一类矛盾（想换工作又怕家里反对，或想转专业又怕耽误时间），一组在头几周里就改掉了一头（说「其实没那么想」，或赌气一走了之），一组把两头都保留了至少八周，并做过至少一次能退回来的小试探。读数：半年后事先清单上没有的新做法有几个；被问起时能说出两头各自具体内容的有几条；对这件事的自评舒服程度；一年后这件事被自己重新提起的次数。本书预测：自评舒服程度，改掉一头的一组不低于顶住的一组；新做法和能说出的条数，改掉一头的一组近乎为零；一年后重新提起的次数并不为零。对手（费斯廷格的失调消除）：失调已消除，改掉一头的一组满意度更高，这件事不会再来。若出现这些，本书就错了：改掉一头的一组半年内的新做法并不比顶住的一组少；或这一组一年内没有再提起过、顶住的一组反倒提起得更多。

**第十一章（11.3 带着问题追问 AI）。**两组人：五、六年级学生，随机分组，每组 30 人，读同一本书、写同一篇读后感，总时长和可用机器的轮数相同。A 组直接要答案、自己誊写；B 组带着追问，先在纸上写下自己的一句，请机器问自己而不替自己写，请机器反驳自己的一句并待住。另设两个对照：C 组轮数与 B 组一样多，但每轮都是「再长一点」「换个开头」，不先写、不接受反驳；D 组和 A 组一样直接要答案，只是拿到后放一晚上再誊写。读数：一周后关掉机器，换一道变形题（写给不喜欢这本书的同桌的一封信，限时 40 分钟）：一，交出至少 150 字且含一个自己的理由的人数；二，稿子里「理由—例子—转折」成链的条数，由两位互不知道分组的人清点；三，拿出一周前的旧稿、指定一句，能说出同意还是不同意、为什么的人数；四，起手前 5 分钟纸上有没有先写下一句自己的判断。本书预测：B 组在第一、第三个读数上各比 A 组至少多 10 人，A 组第三项能答出的不超过 10 人；C 组、D 组与 A 组相近，差不超过 5 人。对手（「AI 只是工具，用得好就行」与认知卸载）：A 组不比 B 组差，省下的力气可以用在别处；或 A 组更差，但差的程度只跟省了多少时间成正比，推不出 B 与 C 会分开。出现什么本书错：B 组与 A 组在第一和第三项上都差不超过 3 人；C 组与 B 组相当；D 组与 B 组相当（同时撞上 1.5 的总证伪条件）；A 组反而高于 B 组。

**第十二章（12.1 一周自检，不是交锋节）。**两类事：同一个人把难度相近的事分成两类，或找同伴各做一类。一类只减速，一类只在着急时问三句并按答案去补。读数：每天晚上清点返工几次、漏几项、被打断后重来几次，七天后比。本书预测：只减速的一类改善有限，时间紧的日子甚至没有改善；补三层的一类明显下降，换到不熟的场合时降得更多。对手（速度—耐心观）：只减速的一类不比另一类差。出现什么本书错：只减速的一类好得多，或两类一样好；做到三维同步、路径走全、进了矛盾，仍又急又错（见总一）。这是总二的自助版，一个人分两类会掺进顺序和疲劳，找同伴分组更好。

# 后记　从一个问题到一本书

这本书是从一个问题长起来的：什么是急？

起点是 ChatSDE 上的九个问题。九问，各问了一个角度，九篇成文各切中了急的一层：有人切在「验证那一拍被吞掉」，有人切在「一句劝告里的账」，有人切在「家里总得点名一个慢人」。九篇都写得有锋，可创新智商都卡在 129 到 138 之间，没有一篇到 145。问题不在写得不够好，在每一篇都只抓住一层，而且漏了离自己最近的邻居。

转折是前言里那句原话。在读这些成文时，有人说：「你的急，只是某一种，还有更多急，你就是'急于吃果子，不经过D和E，直取果子'」。这句话的好处是：它不只是批评，它本身就是一次急的样本。急着给「急」下一个定义，也是急。顺着这条线往下追，就有了后面的三句：「急的定义：就是'抢维度'」；「急还有'去过程，走捷径'」；「还有一种：从三原理就是：不想花力气，即不愿意进入矛盾」。三句合起来，才有了总命题：「实际上急，就是：SDE方法论的'简阉'」。九刀从此收成一把刀。

有了这把刀，才发现前面的九篇不是九件事。它们分别落在抢维度、去过程、不愿进入矛盾三个层上，每一层各有三刀。这本书做的事，就是把这九刀放回它们所在的层，再补上它们各自漏掉的近邻。

书写成之前，先请一位不知道出处的评分者，盖住署名，评了大纲：137 分，资深学者级，没有跨过 150。失分主要在「I」这一项：每一层单拿出来，都有近邻能覆盖七成左右。所以这本书不是靠把话说得更满去过那条线，而是靠几件具体的事：给三层配上了可判别的判据；写了互锁假说，让三层不只是三个名字；每个交锋节都找最近的邻居打；每一条判别局面都写成两组人、可清点的读数，写明「若出现什么，本书就错了」。要不要真的过 150，不由这本书自己说，要等全稿写完，再请一位没有参与推导和写作的评分者盲评一次，D 和 I 都在 150 以上，才算认证。在那之前，这本书的分数是 137 分的大纲，加一个目标 150。

最后说一句这本书背后的愿望。「让每个人都有自己的思想和知识工厂。」〔待核：这句话的归属与出处〕一个人怎样把一个问题长成一篇文章，再把几篇文章长成一本书，靠的不是快，也不是慢，是三维一起发生、路径走全、肯在矛盾里待一会儿。这本书由王德生、邬燕琴共同写成。书里标明「构想」的场景和人物，都是为讲清结构设的，不是真人真事；书里的判别设计，也都没有做过实验，等着读者和研究者去检验，错了，就照书里写的认错。这本书写急，也是在写这件事本身。如果你读完，下一次想问一个问题时，肯把它走一遍，不抢、不删、不躲，那么这本书的用处，就在你手里长起来了。读完以后，不妨回头把那三句判词再对着自己的一天读一遍。
