# 参考资料与使用范围

本书核心命题来自王德生在2026年11月6日提出的论述：人—AI复合体是思考升级的主体；升级包含颗粒度增大、材料广度与深度扩大、速度增加；教育应促进这种升级，而不以人与AI的思考能力胜负为中心。正文中的具体解释、案例和研究设计由这一命题展开，不以所列文献替代验证。网页复核日期为2026年11月6日；来源台账区分本轮成功读取、书页缓存与初稿既有核读记录。部分站内章节本轮未能重新取得，未据此扩大引用范围。
