# 导论　一本书怎样生出一本书

## 第 1 章　白板上的一个圆

你手里有一本书，读了三遍。书页上画满了线，页边写满了小字，有的地方打了问号，有的地方写着「妙」。合上书，你问自己：然后呢？多数人的下一步是写点什么。写一篇书评，写一篇读书笔记，或者写一篇综述，把这本书放进一排前人的名字里。这些都是「关于这本书的话」。写得再好，它们的身份也没变：它们是这本书的客人。

你想要的不是做客人。你想要的是另外一本书，一本别人没有写过、而且离不开你这一路读法的书。可是从「读完一本书」到「写出另一本书」之间，隔着一大片空地。空地上没有路标，大家各凭手感走。有人走成了，说不清怎么走的；有人走丢了，也说不清丢在哪里。设想有一回，几个人围着一块白板讨论这件事。白板上先是什么都没有，后来画上了一个圆，圆里写了几个名字。这张图，就是这本书的白板图。

### ◆ 白板上的图

图很简单，三样东西。中心写着：**SDE 思想创新法**。从中心引出三条箭头，指向三个名字：**缝隙创新法**、**二阶碰撞法**、**九宫透镜法**。最外面，一个大圆，把中心和三个名字一起围住。

```
   （外圈：一个大圆，围住下面所有）

                 缝隙创新法
                     ▲
                     │
   二阶碰撞法 ◄── SDE思想创新法 ──► 九宫透镜法
```

要紧的是三件事。第一，中间那一格不是一个新方法，是一个名字，管着下面三个方法。三个方法各自能单独用，合起来用，才是这本书讲的东西。第二，三条箭头是并排的，没有谁在谁上面。哪一个先用，哪一个后用，后面再说。第三，外面有一个圆。这是整张图里最容易被看漏的一笔。它的意思是：三个方法走完，你手里有一本新书；这本新书写成以后，又可以成为下一轮的「一本书」，重新从头走。线是首尾相接的，所以是圆，不是一条直线。

### ◆ 一条线：从一本书出发，找到几本书，造一本书

把这张图拉直，变成一句话，就是全书的主线：**从一本书出发，找到几本书，造一本书。**这句话里有三个动作，每个动作配一个方法，各管一段。**从一本书出发，用缝隙创新法。**你不从空白出发，从一本具体的书出发。选一本被很多人读过、很多人引用的名著，读透它，找出它里面「本来如此」的地方。这些地方是书的承重墙，作者觉得不必交代，所以一字不提。这一段的产物是一张缝隙卡：哪一句话被当成了起点，它的来历是什么。

**找到几本书，用二阶碰撞法。**一条缝如果只有一本书有，它多半是这位作者的个人习惯。可是如果你发现，别的几本书、别的几家，也踩在同一块地上，那这块地就不是个人的习惯，而是一群人共同默认的前提。二阶碰撞要做的，就是召集五家立场不同的人，找出他们公共默认、从没说出口的那一句，再用其中一家自己的材料把它推开，让一个新的说法发生出来。这一段的产物是：五家的名单，一句被推开的话，一句新的话。

**造一本书，用九宫透镜法。**新的说法有了，怎样变成一本书？九宫透镜把一个领域画成一张九格的地图，再把这个领域里已有的名著、学派一个个放上去，看哪些位置有人占着，哪些位置空着。空着的位置，才是值得写一本书的地方。这一段的产物是：一张占位图，一个空位，一份由空位压出来的编章骨架。库恩的《科学革命的结构》是这本书贯穿始终的实例。它是怎样被三种方法一路带到一本新书上的，第四编会逐步做给你看。这里只先说一句：这条线上每一站的产物，都是下一站的原料。缝隙卡喂给碰撞，碰撞出来的新说法喂给透镜，透镜压出的骨架成为新书的目录。

### ◆ 为什么说是「发生」

三个方法为什么放在一起？因为它们背后是同一个口径：**新思想不是被发现的，是发生的。**先把两个词分开。「发现」是说东西原来就在那里，你走过去，把它找到了。「发生」是说东西原来不在，在某些条件下，经过某些过程，它才有了。

日常说话里，我们总爱说「发现了一个新思想」，仿佛思想是埋在地下的矿，谁先挖到算谁的。可是你回头看任何一本好书，它的核心想法都不是平地冒出来的。它是在一场争论里、一批材料里、一次又一次的碰撞里，一点点显出来的。写书的人很少说得清是哪一天、哪一句，想法就有了。这样看，创新方法要做的事就清楚了：不是教你去「挖」，而是让一个新想法在合适的条件下「发生」。条件是什么，工序是什么，什么时候算发生了，什么时候只是拼出来的，全书都在回答这几个问题。三个方法，各有一件被当成「发现」的东西，要放回「发生」里：

| 方法 | 被当成发现的东西 | 放回发生 |
|---|---|---|
| 缝隙创新法 | 一句「本来如此」 | 它是在某些条件下、经某些过程，一次次沉积出来的 |
| 二阶碰撞法 | 一个「典范」，也就是一个领域里人人默认的共同底子 | 它是旧的一个「1」，要被新的一个「1」顶替，顶替是可以走工序的 |
| 九宫透镜法 | 一个领域里「没人写过」的空位 | 空位不是自然空着的，要问它是被什么封着的 |

这三行里，第二行要多说两句。「典范」这个词是库恩带进来的。他讲科学怎样从一个典范换到另一个典范，讲得极好，可是他讲的是已经发生了的转换，是从外面描述它。他没有给出「怎样让一次转换发生」的工序。这不是疏漏：库恩并不认可把「发现」和「辩护」截然分成两件事的讲法（据斯坦福哲学百科的库恩条目），所以他不替发现立工序，是他的立场。本书第二编要做的，就是把这件事写成一套能照着走的步骤。第三行也要留一句。空位为什么空着，有好几种可能：没人想到，没人想要，或者想了但被什么挡住了。只有最后一种，才值得立一本书。这是第26章的内容，这里先记住：空，不等于值得写。

写到这里，要先挡住一个误会：既然说新想法是「发生」的，是不是只能等它自己长出来？不是。等，是把发生当成了天意。发生有条件，条件可以备。你备得越好，它发生的机会越大。这本书里的每一道闸，都是在备条件，或者在检查条件有没有备齐。

还有一个常见的混淆，要提前分开：**拼出来的**和**发生出来的**。把三家的说法各取一点，合成一个看上去更全面的说法，这是拼。拼出来的东西，拆开以后，每一块都能在原来的地方找到。发生出来的东西不同：它的核心句，在五家的任何一家的账本上都没有对应的字段，五家的语言也说不出它。第17章和第20章会把这一条写成可以检查的标准。读到那里请回头看这一段。

### ◆ 三个方法，各管一段

把三个方法并排摆出来，看它们各自的入口问题、手里的东西、交出的东西，以及最怕的那一种假做法。

| | 缝隙创新法 | 二阶碰撞法 | 九宫透镜法 |
|---|---|---|---|
| 入口问题 | 这本书里哪一句是「本来如此」？ | 这句话是几家共同默认的吗？撞开以后长出什么？ | 这个领域里哪一块位置空着？ |
| 手里拿的 | 一本读透的书 | 五家立场不同的人 | 一张九格地图 |
| 交出来的 | 缝隙卡与判语 | 旧1、新1、一条判死条款 | 占位图、空位、编章骨架 |
| 最怕的假做法 | 把遗漏当缝，把批评当缝 | 把综述当碰撞 | 把画格子当找空位 |

这三个方法在这本书里各占一编：第一编讲缝隙法，第二编讲二阶碰撞法，第三编讲九宫透镜法。每编十章，每章讲一道工序。有一点要提醒。三个方法里，没有哪一个是「主力」，另外两个是「配角」。有的人读完第一编，觉得缝隙法就够了；有的人读完第二编，觉得碰撞才是核心；有的人喜欢第三编的地图。每一种偏爱都说得通，也都是偏了。三个方法各管一段，缺了哪一段，线就断在哪里。缺了缝隙法，碰撞没有题眼；缺了碰撞，缝隙成不了一个能站住的新说法；缺了透镜，新说法落不成一本书，只能停在一篇文章里。

方法要能用，先要说得出它怎样算失败。三个方法各留了一个口子，全书后面会逐一写成判死条款，这里先摆出最短的样子。缝隙法的口子：补过以后，原书里同一句话没有换意思，后面的推论也没有跟着变。那就是只在旁边添了一块，没有改写那句「本来」。碰撞法的口子：新说法拆开以后，每一块都能在五家的某一家账本上找到对应的字段。那就是拼出来的，不是撞出来的。透镜法的口子：那个空位空着，是因为没人想问，或者问了也没用，而不是被什么挡住了。那就不值得立一本书。三个口子都是同一类东西：一个可以拿去查的结果。查出来是这样，就说明这一段没有做成，退回上一站重来。能这样挨个查，是这本书敢叫它「方法」的底气。

### ◆ 先后可以换：六套路径

「从一本书出发，找到几本书，造一本书」是一种次序：缝、碰、镜。可是三个东西排先后，不止这一种。3 个东西全排列是 3×2×1＝6，所以一共有六套打造路径：

1. 缝→碰→镜
2. 缝→镜→碰
3. 碰→缝→镜
4. 碰→镜→缝
5. 镜→缝→碰
6. 镜→碰→缝

同一个方法排在不同位置，干的活不一样。排第一，是入口：它决定你从哪里进。排第二，是展开：它拿前一步的产物做原料。排第三，是收束：它负责把东西收成书，并且检查有没有走偏。比如缝隙法：排第一，是从一本书的预设入手；排第二，是检查前面撞出来的新说法，有没有偷偷带进了另一个「本来如此」；排第三，是对最后的母题再做一次解构，写出它自己的判死条款。同一个方法，三种用法。

那么该选哪一套？看你手里有什么。手里有一本书，缝隙法排第一最顺手。手里是一场吵了很多年没有结果的争论，从碰撞入手。手里只有一个领域、没有一本具体的书，从九宫透镜入手。第四编把六套路径各走了一遍，每一套都从一个具体的起点出发，走到一份新书的创新大纲为止。哪一套更好，不能凭想象，要看走出来的东西。

### ◆ 新书回到起点

最后说那个圆。一本新书写成以后，它自己也是一本书：有自己的名著式的地位（也许没有，但它有自己的论证），有自己「本来如此」的地方。它写进去了一些起点，它自己并不觉得需要交代。这样，新书就可以成为下一轮的起点：从它出发，找它的缝，找站在同一块地上的几家，再造另一本书。

这不是文字游戏。它说明了两件事。其一，方法对自己也适用。缝隙法要拿来拆别人的起点，也要拿来拆自己的。这本书最后一章专门做这件事（第42章），把本书自己的「本来如此」摆出来，写上判死条款。其二，思想创新是一个接力。你从前人的书出发，造出的新书又交给后人。每一棒都在上一棒的缝里起跑，在自己的缝里交棒。没有谁跑完全程，也没有谁的一棒是白跑的。

### ◆ 用库恩走一遍，大致是这样

库恩的《科学革命的结构》初版在1962年。书里的故事大家熟：一门科学平常的日子是「常规科学」，大家在一个共同接受的「范式」里解谜；解不开的谜越攒越多，成了「反常」；反常攒到一定程度，出现「危机」；危机里有人换了一副眼睛，一场「革命」发生，新的范式站住，新的常规科学开始（以上是对全书主线的转述）。拿这本书当第一棒，三个方法大致这样接：

缝隙法先上。读透以后，你会发现书里有几个地方一直是「顺口」的：共同体怎么就「都认」了一个范式；一个解不开的谜，怎么就成了「反常」；教科书怎么就把过去的历史写成了一条直路。这些地方，库恩讲得很顺，几乎没有停顿。顺，就是信号。这三处只是候选。过了第一编的各道闸，它们收窄成三道缝：认同没有账，起点和终点都有，中间没有；反常前面是认出来的，后面是攒出来的，链条上没有接；教科书的重写没有算进「变化完成」。另有一层，也就是变化靠什么原理发生的那一层，四个候选全部出局，不立缝。三道缝有一个共同的出口：这个东西凭什么还是它？

碰撞法接着上。你问：科学变化这个题目上，还有哪些立场不同的人？证伪论的，研究纲领的，反方法的，问题解决的，社会学的。他们彼此吵了几十年，吵的是科学为什么变、怎样变才合理。你去找他们都没问过的一句话。模拟里找到的是一句看上去很不起眼的话：你们在谈科学怎样变的时候，都先给「变的东西」立了一个单位，这个单位在变化之前就已经有了边界。把它推开以后，问题就成了：这个东西凭什么算是「同一个」在变？

透镜法最后上。你把库恩和那五家放到九格地图上，看哪些位置已经被占满（反常怎样处理，是闹市区），哪些位置冷清（变化的每一步在不同层面上是否站得住）。新书落在冷清的位置：科学变化的每一步，在现实、理念、自我三个世界上是否都站得住。这是九格地图上的一个异位组，它怎么记、怎么读，第23章再讲。判它是空位，用的材料里没有用到新书的核心词，这一点算勉强过关，仍须另一个人拿同一张图再落一遍。书名叫《谁说它还是它》。以上是第34章模拟出来的样子，不是定论，也没有真人验收。放在这里，只为让你看见：三个方法的接口是通的，前一个的产物，正好是后一个要的原料。

### ◆ 这张图常被读错的三处

第一处，把中心当成第四个方法。中心那一格写的是「SDE 思想创新法」，容易让人以为它是一个比三个方法更高的方法，用它就不必用下面三个。不是的。中心只是一个名字，等于说：这三个方法合在一起，共用同一套语言、同一个口径、同一组闸。你不会拿着「中心」去创新，你拿着三个方法里的某一个，去做某一段活。

第二处，把三条箭头读成三选一。看到三个名字，人容易问：我该选哪一个？这个问法本身就有点偏。三个方法回答的是三个不同的问题：缝隙法回答「这本书的起点是什么」，碰撞法回答「这个起点是不是一群人共有的，推开以后长出什么」，透镜法回答「长出来的东西在哪里落脚」。三个问题缺一个，书都出不来。选的不是方法，是先后。

第三处，把外圈当装饰。圆画在最外面，像一个边框。可是它是整张图里唯一说「这件事是循环的」的地方。把它当边框，就会把新书看成终点；把它当圆，新书才会被放回下一轮的起点。还有一层。圆里的每一站，都要留下一份别人看得懂的东西：缝隙卡、五敌表、占位图、判死条款。只有留下了，下一棒才接得住。靠记忆和手感传的东西，传一次就走样。所以这本书不厌其烦地要求「每章至少一张工作卡」，要的就是让每一步的产物落在纸上，可以交给别人，也可以交给半年以后的自己。

### ◆ 工作卡：你自己的白板

拿一张纸，把白板图画一遍，填上你自己的项目。每一栏只用一句话填，不要写成段落，写成段落的栏，多半是还没想清楚。

| 栏目 | 填什么 | 你的填写 |
|---|---|---|
| 起点 | 一本书，或一场争论，或一个领域 | |
| 手里有什么 | 书？五家的名单？一张地图？ | |
| 排哪一套路径 | 六套里选一套，并写一句理由 | |
| 第一步的产物 | 缝隙卡？五敌表？占位图？ | |
| 圆的另一头 | 你想写成的新书，一句话说它是什么 | |
| 下一轮的起点 | 这本新书交出去以后，别人会从哪一句开始拆它 | |

填不满没有关系。填不满的栏，正是你读后面各章的理由。填满了的栏也留着，读到第四编再对一遍，看当初选的路径对不对。

### ◆ 这样写＝没做

下面这几种情形，看上去在用这套方法，其实没有。读的时候对照自己手里的东西，看有没有哪一条沾边。

1. **只画了图，没有走工序。**白板上画了三个圆圈、五条箭头，嘴里说着「缝隙、碰撞、透镜」，手里没有一张缝隙卡、一份五敌表、一张占位图。图不是产物。
2. **把三个方法当成三个标签。**给一篇已经写好的文章贴上「这是缝隙」「这是碰撞」的标签，以为这样就用了方法。方法是动作，不是标签。
3. **只用一个方法，却说是三法合用。**找了几句「本来如此」，写成一篇感想，没有召集第二家，没有画第二张图，仍然自称走完了全程。
4. **把「发生」当成一个新的口号。**说「新思想是发生的」，说完就算完，没有说出它在什么条件下发生，在什么条件下不发生。口号换了名字，仍然是「本来如此」。
5. **把圆画成直线。**新书写完就扔，没有给自己的书留一个被拆的口子。

> **带走的话**
>
> - 全书一句话：从一本书出发，找到几本书，造一本书。
>
> - 三个方法各管一段：缝隙法起头，二阶碰撞法展开，九宫透镜法收成书。
>
> - 新思想不是被发现的，是发生的；三个方法都是把被当成发现的东西放回发生。
>
> - 三法排先后有六套路径；同一个方法排第一是入口，排第二是展开，排第三是收束。
>
> - 外面那个圆的意思：新书写成，又是下一轮的「一本书」。

## 第 2 章　这本书怎样读

买过组装柜子的人，都有过这样的经历。打开纸箱，里面有一张说明书。说明书上有三样东西：一张零件清单，一串步骤图，最后一页画着装好的样子。聪明的人不会从头到尾读一遍说明书再动手，他们边装边翻。装到第四步，对一下零件，看一眼最后一页，确认自己没有装反。装反了的人，通常是因为跳了一步，或者没数清螺丝。这本书也是一份说明书，只是要组装的东西是一本书。它也有三样东西：一串工序，若干道检查，一些装好的样子。读它的办法，和读说明书差不多：不用一口气读完，但每一步都要对着产物看。

### ◆ 三条线：工序、闸、实例

全书四十二章，看上去分成许多章节，其实是三条线交织着往前走。**工序**是第一条线。每一章讲一道工序，也就是一个具体的动作：怎样选一本书，怎样读透，怎样写一张缝隙卡，怎样划出五个对手，怎样给占位图计分。每道工序有输入，有步骤，有产物。读完一章，你应该能说出：我手里多了一件什么东西。**闸**是第二条线。闸是一道检查，过不了就不许往下走。书里的闸很多，常见的有这几种：

- 选书的时候，有隔离闸、可数对象闸、盲选闸（第4章）；
- 补缝的时候，有来历闸、新意闸、外部验收闸（第10章）；
- 撞之前，有题闸（第14章）；
- 撞完以后，有命名闸、族闸（第20、21章）。

闸的作用是挡住「看上去做了」。很多方法书只讲怎么做，不讲怎么检查，结果读者做出一堆东西，自己也不知道对不对。这本书里，一道闸的写法是固定的：问什么，怎样算过，怎样算不过，不过怎么办。

**实例**是第三条线。方法光讲不演，读者记不住。本书用两批实例。一批是贯穿全书的库恩《科学革命的结构》，从第1章露头，在第一编里一直是演示的对象，第四编第34章把它一路走到一本新书的大纲。另一批是六次完整的模拟，也就是第四编的主体：六个不同的起点，六套不同的路径，每一套走到一份创新大纲为止。三条线怎么用？一个办法是：先抓住工序，知道每章手里多了什么；再看闸，知道哪里会被挡住；最后看实例，知道做出来的东西大概是什么样子。读到某一章觉得抽象，就翻到第四编找对应的那一步，看模拟里是怎么做的。

### ◆ 一章里有什么，一道闸长什么样

每章的装置是固定的，读熟一次，后面就轻松了。先是一个家常的开头：一个具体的场景或例子，引出本章的问题。然后是用「◆」起头的几个小节，一节一件事。每章至少有一张工作卡或一张表，可以直接拿去填。接着是「这样写＝没做」，列出几种常见的假做法，每一种看上去都像在做，其实没有做。最后是「带走的话」，几句，要是你只想记住这一章的东西，记这几句。闸的写法也是固定的。拿第一编里的**来历闸**做个样子：

| 栏目 | 内容 |
|---|---|
| 问什么 | 这一句话，作者交代过它的来历没有？ |
| 怎样算过 | 翻回前文，找不到来历；并且拿掉这一句，后面的论证接不下去 |
| 怎样算不过 | 前文已经交代了来历；或者拿掉这一句，论证照样成立 |
| 不过怎么办 | 这一句不记入缝隙卡，回到原文，找下一个候选 |

表很短，但每一栏都不能空。写不出「怎样算不过」的闸，等于没有闸。闸还有一个特点：它们挡的常常是你最得意的东西。一条缝找了三天，在来历闸上被翻出一段交代，作者早就讲过了。这很难受，可是闸就是为这个时候准备的。被闸挡下来的候选，也不要扔，写进卡的背面，注明挡在了哪一道。这些「被挡的缝」往往是方法书里最有用的教材。

### ◆ 四项方法检查

一本讲方法的书，怎么判断它好不好？小说可以评文笔，论文可以评新意，讲方法的书，最该评的是：照着做，能不能做出来。所以这本书不拿「创新智商」给自己打分。道理很朴素：讲方法、讲工序的书，里面有很多技术动作，在书里讲不完整，也讲不到位；拿一个单一的分数去衡量它，不公平，也不准。本书改用四项方法检查，对自己，也请读者对它：

| 检查项 | 问什么 | 本书怎么做 |
|---|---|---|
| 可执行 | 一个没有读过全书的人，照着一章的内容，能不能把那一步做出来？ | 每章给出输入、步骤、产物，并附一张可以直接填写的工作卡 |
| 步骤完整 | 从起点到产物，中间有没有跳步？ | 全书按「选、读、找缝、集缝、解构、碰撞、落格、占位、压母题、成书」的次序排，每步的产物是下一步的输入 |
| 可证伪 | 方法说它有用，那么看到什么结果，就说明它没用？ | 每种方法都写判死条款；末章（第42章）把整套方法的判死条款一并写出 |
| 事实干净 | 引的书、引的话、引的数，核过没有？标了没有？ | 站内的书注书号，外部名著只转述大意，核过的才写出处，拿不准的不写 |

这四项里，最容易被轻视的是最后一项。一本方法书如果在事实上含糊，读者没法分清：是方法不灵，还是例子编的。所以本书的引文纪律是写死的：不编造原文，不编造页码、年份和数据；外部的名著与学者，一律写大意，直接引的话不超过一句；站内专著，写书号；拿不准的人名和年份，宁可不写。四项之间互相牵制。只有可执行，没有可证伪，会变成一份很顺手、但说不清有没有用的流程；只有可证伪，没有步骤完整，会变成一堆挑剔的条款，没人知道从哪里下手；事实不干净，前三项都是空中楼阁。所以四项要一起看，缺哪一项，就在哪一项上补，不要拿别的项来抵。

还有一个要事先说明的限制。本书的正文由人加 AI 协作完成。执笔的和核查的出自同一个基底（本书泛指大模型为「基底」），不能互相当作独立的证据；书里的方法没有经过独立的学术评审，大部分示范是模拟，不是实测。六次模拟没有一次打分，也没有一次由真人读原著做验收，书里凡是「验收」，都会标明是桌面模拟还是真人。读者读到「已验证」三个字的时候，请看它后面跟着的是什么。

### ◆ 全书地图

全书有导论、五编和合论，共四十二章，四十一万字上下。下面这张表把每一部分干什么、交出什么摆在一起，动手之前先扫一眼。

| 部分 | 章 | 干什么 | 产物 |
|---|---|---|---|
| 导论 | 1–2 | 画出白板图；说清怎样读 | 一张自己的白板 |
| 第一编　缝隙创新法 | 3–12 | 从一本书出发：什么是缝，选哪本书，怎样读透，怎样找缝，怎样集缝，怎样解构，缝指向谁 | 缝隙卡、缝隙集、一句判语 |
| 第二编　二阶碰撞法 | 13–22 | 找到几本书：旧1与新1，题型，五个对手，根1，推翻，新1，真跑 | 五敌表、根1、新1、判死条款 |
| 第三编　九宫透镜法 | 23–32 | 造一本书：九格，落格，占位，空位的四种，压母题，回落，成书 | 占位图、空位、编章骨架 |
| 第四编　六套打造路径 | 33–39 | 三法排先后的六套路径，各做一次模拟 | 六份新书创新大纲 |
| 合论　一个圆 | 40–42 | 六次模拟的总账；专著、专业、领域；方法自己的缝 | 总账、判死条款 |

为什么第一编讲缝隙法，第二编讲碰撞法，第三编讲透镜法？因为这是主线的次序：先有一本书，再有几本书，最后造一本书。可是请注意，这只是讲解的次序，不是唯一的用法次序。第四编才会告诉你，另外五种次序同样走得通，只是各自的入口、风险和适用的场合不同。所以读完前三编，你手里有三件工具；读完第四编，你知道怎样根据手里的材料，选一件先拿起来。

先说篇幅。导论一万字，第一到第三编各十万字，每章约一万字；第四编八万五千字，开头一章短，后面六章各一万三千字上下；合论一万五千字。每章一万字，认真读一遍，要花一个多小时。建议一次只读一章，读完当场做那一章的工作卡，不要攒到最后补。攒着补的卡，多半是照着书抄一遍，没有经过手。

读法有三种。**从头读**。适合第一次接触的人。三个方法依次读下来，到第四编看它们怎样合起来。**带一本书读**。适合手里已经有一本书想拆的人。先读导论，然后跳到第4章（选书）、第5章（读透），照着做一遍，再回头读第3章（什么是缝）和第6到9章（四种缝）。你拆自己的书，比读这本书更要紧。**先看成品再看工序**。适合想先知道有没有用的人。先读第四编的任意一章，看那一章的模拟走到了哪里，再决定要不要学前面的方法。第四编每章分四节：路径、模拟、新书创新大纲、复盘，其中「复盘」一节专讲哪里卡住了。

### ◆ 六套路径预告

第四编的六章，各走一套路径，各从一个不同的起点出发。起点列在这里，先让读者有个印象。表里「母题」一栏，是每次模拟走到最后得到的一句话结论。

| 章 | 路径 | 起点 | 走到的新书（模拟） | 一句话母题 |
|---|---|---|---|---|
| 34 | 缝→碰→镜 | 库恩《科学革命的结构》 | 《谁说它还是它》 | 科学变化里的「同一个」不是先在的承载单位，是接续判决沉出来的 |
| 35 | 缝→镜→碰 | 皮亚杰的发生认识论 | 《同一是怎样沉出来的》 | 同一不是孩子带进每个场合的东西，是在三界之间来回走、损耗被认下以后沉出来的 |
| 36 | 碰→缝→镜 | 「先天还是后天」的百年争论 | 《接住》 | 性状不是先天给的，也不是后天塑的；被后一步接住的差异沉成性状 |
| 37 | 碰→镜→缝 | 站内典范文《账本记不下的那样东西》 | 《承担位》 | 账本杀死承担的方式，是把它发生所需要的那块不被看的地方一寸寸看没了 |
| 38 | 镜→缝→碰 | 管理学这个领域 | 《合拍》 | 劲头不是水平，是拍合 |
| 39 | 镜→碰→缝 | 「躺平」这个现实问题 | 《躺平不是没劲》 | 躺平不是人把劲收回去了，是路上三本账不再同步，牵引就停了 |

六次模拟都不打分，原因有两个。一是模拟是同一批执笔者在同一次推演里把三步走完的，后一步对前一步有预知，这本身就污染了结果；二是方法书要检查的是工序，不是新书的高低。哪里有预知，哪里需要换人盲做，书里会逐处标出来，第40章再汇总成一条规则。表里的书名和母题，是模拟走出来的结果，不是已经写成的书，更不是定论。读者有一个任务：读第四编的时候，不要只看新书大纲漂亮不漂亮，要看每一步是怎样走过来的、哪一步靠不住、哪一步被闸挡下过。第40章会把六次模拟放在一起算总账，有些地方，六次的结果指向同一个方向，那只是一个待检验的假设，不是结论。

### ◆ 字母怎么读

书里有三个字母，S、D、E，是 SDE 这个思想体系的底。它们第一次出现的时候都先说人话，这里提前交代一遍，读者心里有数。

- **S，显露**。东西显出来的样子。不是「结构」，是它此刻摆在眼前的样子。
- **D，差异序列**。变化、路径和过程。一件事一步一步是怎么走过来的。
- **E，特征纠缠**。条件、关系和场。一件事周围的东西怎样互相牵着。

三个字母之间有三条方程：S＝F(D,E)，D＝G(S,E)，E＝H(S,D)。用大白话说：东西显出来的样子，取决于它走过的路和它所处的条件；它走过的路，取决于它的样子和条件；它所处的条件，取决于它的样子和它走过的路。三者互相决定，没有哪一个天生是出发点。三条方程之上，有两样东西：三原理和六路径。三原理说的是：三个里面任何两个的矛盾累积起来，会逼着第三个改变，改变了的又回头写进另外两个。六路径说的是：三个东西排先后，有 3×2×1＝6 种次序，没有第七种。

这些东西，在第一编的前半不会出现。第3到5章讲缝隙是什么、怎样选书、怎样读透，用的都是大白话。第6到9章才逐个请出来，那时每一个都会先讲人话。另外还有一套九宫格，是透镜法的主体：S、D、E 各分三格，共九格，第23章再讲。读者只需要现在知道：九格是九个问题的位置，不是九个答案。

### ◆ 三条纪律

读这本书，也请读者遵守三条纪律。它们同时是本书自己遵守的。**第一条，不编引文。**这一条在前面说过。多说一句：在方法书里，编一个好例子比引一个实有的例子容易得多，也省事得多。可是一旦例子是编的，方法对不对就无从检查。所以书里凡是设想出来的场景，都会写明是设想；每章开头的小场景，大多是构想，不是实有其事。凡是真人真书，会写出处；核不到的，不写。

**第二条，不拿「一个人」做主语去看穿、去决定。**用 SDE 讲任何现象，不写成「某人看穿了什么」「某人决定了什么」，那还是旧的讲法，把人当成发动一切的起点。本书写成发生的样子：某种条件下，某件事发生了，「人」是这件事显出来的一个结果，不是它的发动者。读者会在书里看到很多这样的句子：「想法发生了」「一道缝显出来了」，而不是「他发现了一道缝」。这不是文字上的怪癖，这是这个体系自己的口径。两种写法放在一起，一眼就分得出来：

| 旧写法（把人当发动者） | 本书的写法（写成发生） |
|---|---|
| 他看穿了这个预设 | 在读到这一页的时候，这个预设显出来了 |
| 作者决定把它当作起点 | 在这门学问的条件下，它被放在了起点的位置上 |
| 研究者选择了第二条路径 | 这套做法实际沿着第二条次序展开 |

右边的写法有时拗口，读者要多一点耐心。它换来的是：句子里每一个动作，都能回到条件和过程上去问。**第三条，字母纪律。**在演示找缝的时候，找到「扎手处」之前，不出现 S、D、E 这三个字母。扎手处是原文里卡住、绕不过去的地方。为什么这样定？因为一旦先把字母摆上桌，你看到的就是字母的形状，而不是书本身的形状。你会拿格子去套材料，套得严丝合缝，却不知道是格子在说话，还是材料在说话。从扎手处进，字母是后来涌现出来的，这才是找。第5章把这一条讲成一道完整的操作。

### ◆ 读到卡住的时候

方法书读到卡住，是常事。卡住有三种样子，各有各的退法。第一种，工作卡填不出来。多半是上一章的产物没有落在纸上。退回去，把上一张卡补齐，再填这一张。填不出的栏不要编，空着，写上缺什么。第二种，闸总是过不了。一道闸连着三次挡下你的候选，先别怀疑闸。看一看是不是选的书不对：太新，没有子孙，缝还没有长出来；或者太薄，起点就那么几个，挑不出承重的。换一本，比在原地硬磨有用。第三种，读得下去，却不知道用在哪里。这时候别再往下读。翻到第四编，挑与你手头材料最近的一条路径，看那一章每一步的产物长什么样，再回头对自己的卡。

还有一种不算卡住，却比卡住更糟：一路顺畅，所有闸都过了，所有卡都满了，心里却没有任何一处觉得别扭。这几乎总是说明闸被当成了表格，填了，没有问。顺畅的时候，请随机挑一道闸，把「怎样算不过」那一栏大声读一遍，再问自己：我这一次，有没有确实试过让它不过？

### ◆ 工作卡：读书进度卡

| 项目 | 你的填写 |
|---|---|
| 我读这本书，是为了 | 拆一本具体的书 ／ 学方法 ／ 写自己的专著 |
| 我选的读法 | 从头读 ／ 带书读 ／ 先看成品 |
| 我手里的那本书 | 书名、作者、读过几遍 |
| 读完每章以后手里多了什么 | 第3章：　第4章：　…… |
| 被哪一道闸挡过 | 哪一章、哪一问、怎么退回去的 |
| 我对这本书的一处不同意 | 写在这里，第42章再回头看 |

最后一行请认真填。不同意的地方，是你与这本书之间的第一道缝。卡片每读完一编更新一次，到合论时翻出来对一对，看哪些不同意被后面的章回答了，哪些还悬着，悬着的那几条，值得你自己写成一章。

### ◆ 这样写＝没做

1. **读完所有章，没有做过一次。**方法书的读法是做，不是读。一章读完，工作卡是空的，等于没读。
2. **跳过闸，直奔产物。**觉得闸太啰嗦，直接写缝隙卡、五敌表，写出来的东西没人检查，看上去很像，实际站不住。
3. **把模拟当成定论。**第四编的六份大纲，不是六本已经成立的书。拿它们去做引用、做宣传，是把模拟当成了实测。
4. **把「四项检查」只用在别人身上。**对书里的方法一条条挑剔，对自己的稿子一条也不查。
5. **跳过纪律。**觉得「字母纪律」「不拿一个人做主语」是形式，随手写成「我发现了一个缝」，却又自以为在用这套方法。
