# 第一篇　缺口篇：一句老话为什么不够用

“意料之外，情理之中”，看戏的人会说，写戏的人会说，教编剧的课堂也会说。可只要追问一句，这八个字就站不住了：既然合理，观众为什么没推出来？推不出来，他又凭什么说合理？这一篇先把这道缺口摊开。第 1 章看前人怎样说这句话，又在哪里停了步；第 2 章拆开三种烂戏，平的、假的、只剩一惊的，看它们各自坏在哪一步；第 3 章停在观众说“合理”的那一刻，给出本书的第一个回答：观众手里有两本账，推理一直有效，变的是账上的前提。

# 第二篇　底盘篇：好戏的四个条件

缺口摊开了，就要立起底盘。这一篇把好戏拆成四个条件，一章讲一个，最后一章把它们装回一部完整的戏里。合理，是因为故事走的是发生的语法，三大方程、123原理、六路径在戏里一起运转；意外，是因为土壤会突变，而且常常没有预兆；意义，是因为一部戏的完成不在落幕，而在观众身上又发生了一次；缺口，是因为这份意义必须正中观众此刻的心坎。第 8 章用李安的《饮食男女》从头到尾走一遍，看四条怎样在同一刻咬合。

# 第三篇　方法篇：E 的突变序列设计——好戏是怎样做出来的

知道好戏是什么样，不等于做得出好戏。这一篇讲一门手艺：好戏的设计智慧，核心是土壤（E）的突变序列设计，在恰当的地方安排一次突然的改变。一部戏里的突变不止一次，而是一串，编剧要回答六个问题，一章答一个：落在哪一刻，有多大，打在谁身上、哪条路上，怎样扩散成一张网，世界的突变与认知的突变怎样交错，突变之后怎样走得有理。每章末尾都留下几条设计纪律和自检问题，写戏的人可以拿去用，看戏的人可以拿去看懂。

# 第四篇　激活篇：跨门类，跨时代

一套说法要算数，得换几块地方试一试。这一篇把前三篇的眼光带到别处：中国戏曲里那些超自然的情节，什么时候合理，什么时候作弊；长篇小说和长剧，怎样一轮接一轮地发生；相声的包袱为什么是最短的一次前提发生；一部戏为什么会老，又为什么会在下一代人那里复活；最后回到一个躲不开的问题：回写得深，不等于回写得好，一部戏要对它在观众身上发生的方向负什么责。

# 第五篇　新缺口篇：补上一个，再打开一个

最好的戏不只补上观众的缺口，还会替他照出一个他自己不知道的缺口。观众带着新的问题离场，戏的生命就在他身上继续。这一篇只有一章，它把全书的四个条件和突变序列收拢成一个圈，再把这个圈交还给读者。
