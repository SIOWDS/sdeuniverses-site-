# 附录

附录六件，供查、供对、供练、供读。正文里的每一个判断，都能在这里找到它的位置、它的边界和它的推翻条件。读正文时想一眼看清四种转法，翻附录一；想给自己或身边的人对一对是哪一种怠速，翻附录二；碰到一个说法想知道它在 SDE 里叫什么，翻附录三；碰到一句标了〔待核〕的引文或年份想查，翻附录四；想知道这本书可能错在哪里，翻附录五；想接着往下读，翻附录六。

## 附录二　三种怠速诊断卡

三张卡各对一型。每张卡上的五个问题，答「是」的越多，越接近这一型。三张都答一遍，常会发现自己身上叠着不止一种。这几张卡只看运行态，不看品性，也不作医学诊断；身体或心里的难处真的大了，请找医生或心理咨询师。

**诊断卡一　第一种怠速：油门踩死之后**（第 20 章、第 39 章）

| 问题 | 是／否 |
|---|---|
| 1. 我在一件事上拼过很长时间，加班、加量，可是位置、排名或结果一直不动 | |
| 2. 后来我收了，只做分内，不再多推一下 | |
| 3. 我心里常冒出的话是「卷也没用」「做多做少一个样」 | |
| 4. 我推出去的劲，要隔很久、穿过很多人，才看得见一点回应 | |
| 5. 我最先没有的，是「愿意多推一把」的那股劲 | |

挂法：换一片推一下就会回一下的地，不在原赛道加量。明天能试：找一件一周内能看见它动的小事，不用原来那把尺子量。

**诊断卡二　第二种怠速：挂不上挡**（第 21 章、第 40 章）

| 问题 | 是／否 |
|---|---|
| 1. 我想要的样子还在，可眼前这片地方对不上，觉得「没路了」 | |
| 2. 我这一阵主要在观望，「先看看」，连做都少了 | |
| 3. 我常说「我是某某的，所以不做那个」 | |
| 4. 很多新的选项，没细想就被我划掉了 | |
| 5. 我最先没有的，是被一样新东西吸过去的那股劲 | |

挂法：拆掉身份那颗粒子，重写能走的路。明天能试：把「我是某某的」改写成三句「我某某，所以能某某」，挑最小的一件去做。

**诊断卡三　第三种怠速：方向盘和油门打架**（第 22 章、第 41 章）

| 问题 | 是／否 |
|---|---|
| 1. 我心里有一个想成为的样子，可每天走的路和它对不上 | |
| 2. 那个样子被我收起来了，降成「以后再说」「活着就行」 | |
| 3. 我有一样东西收在抽屉里，不扔，也不用 | |
| 4. 我的日子里，没有一个人、一个时段、一个地方是给那件事的 | |
| 5. 我最先没有的，是天天守着一件事的那股劲 | |

挂法：让想要的样子和每天的路，在新土里落地成习惯、关系、手上的接触。明天能试：把抽屉里那样东西摆上桌，在日历里占两个钟头，给一个人发一句「你能不能当第一个听众」。

**三张卡之后，再问自己一句**：这一次停下来，是在止损、保住还剩的劲，还是在踩刹车？写下了「什么时候、什么样子，我再挂挡」没有（第 44 章）？

## 附录五　本书自认最弱的几处与推翻条件

判词能被推翻，才配站在第一页。下面五处，是本书自己觉得最站不稳的地方，各写一条推翻条件。

**一、「怠速是唯一不断环的病态」。** 这是全书最要紧的新判断，也是最可能被打穿的一处。推翻条件：如果有人能找到一大批长期躺平的人，他们的回写在很长一段时间里完全停止，一句话也不再沉下来，土里也不再留任何东西，而且后来挂挡比熄火重打的人更难，那么「不断环」就要改判为「在一段时间里不断环」，第 25 章、第 38 章要收窄。

**二、三型分得那么清。** 本书把怠速分成三种，一型对一种较劲、一种先熄的律、一种先失的劲。真实的日子里，三种常常缠在一起，老林、林舟、苏晴身上都叠着不止一种。推翻条件：如果拿附录二的三张卡去问一大批人，多数人三张卡的得分差不多，分不出主型，那么三型就只是三个侧面，不是三种类型，第 20—22 章的总表要改成「三个侧面」的写法。

**三、「先有新的缠，后有新的我」。** 本书坚持解冻的主语不是那个下决心的人。可是在一些人身上，确实像是先有一个晚上的决心，后有一连串新东西进来。推翻条件：如果有可靠的追踪研究表明，在没有任何新的人、新的地方、新的事进来的情况下，单靠一次决心，就能让长期怠速的人稳定地挂上挡，那么第 37、38 章的「劝说无效」要收窄为「劝说多数时候无效」。

**四、车的比喻。** 车总有一个驾驶座。这个比喻用久了，会把司机悄悄请回来，和本书最硬的那条口径打架。推翻条件谈不上，这是一处要读者帮着守的地方：凡读到「挂挡」「给油」，请记得手不是先坐在那里的司机的手，是土里新进来的那一样东西。

**五、陪读人物太顺。** 老林有一单生意送上门，苏晴有一条街和一位顾师傅，林舟有一个父亲的店。真实的土里，这些常常都没有。本书在第 38、39、41、43 章都写了「也可能就停在这里」，可是三个人的故事读下来，仍然比真实的日子顺。请把他们当作三台车的示意图，不当作承诺。

# 后记

这本书，是一个词引出来的。

在「普通人都能懂」这个系列里，多数卷拆的是一个人：一位哲学家，一对论敌，一段谱系。这一卷拆的不是人，是一个词，以及这个词底下那一种转法。它和第 157 号《哲学的使命是什么？》、第 158 号《普通人都懂的逻辑学》一样，是一卷主题卷：没有一位要还公道的大师，要还公道的，是千千万万台停在路边的车。

「躺平」流行开来那几年，王德生博士身边常有人问他：这个词，SDE 怎么看？是懒，是累，是看穿了，还是一种新的活法？他没有急着答。他先口述了这本书的题，又在一连串口述里，裁定了几件承重的事。

第一件，是那个比喻。躺平不是熄火，是怠速：车停在路边，发动机还在低低地响。这一下，把躺平和死、和懒、和无为，全分开了。后面每一章，都是从这辆车开出来的。

第二件，是三型。躺平不是一种，是从三种消耗战场退下来的三种怠速：油门踩死之后，挂不上挡，方向盘和油门打架。哪一头被堵，就从哪一头引进新的缠。第三编和第五编的骨架，都在这一句里。

第三件，是一正三病。挂挡前进是一正，空转、熄火重打、怠速是三病；而怠速是三病里唯一不断环的那一种。这一句，是全书最要紧的新判断，也是附录五第一条推翻条件对着的地方。

还有一件，贯穿全书，被他反复叮嘱：躺平不是「一个人」的选择，是一种 SDE 运行态。不许写「他看穿了，于是选择躺平」；主语要落在引擎、路、土上。这一条，比任何一个比喻都难守。写的时候，好几次，句子自己就滑回了「他决定」「她想通了」，又一句一句改回来。

这本书是复合主体写成的：全部判断、口径与承重命题由王德生博士口述给出；文字在他的指令下，由五位 AI 执笔（Claude）分编并行写成，各写一段，再由一位统稿合成一本。五个人写一本书，最难的不是写，是写成一个声音：同一辆车、同一张转速表、同一家人、同一套词。为此，动笔之前先立了一份总纲，判词、比喻、人物、章号章题，一律照它，一字不改。如果你在书里读到哪一处口气不齐、哪一个细节前后对不上，那是统稿没有做到家，请告诉我们。

这本书也有几件没有做的事，一并写在这里。

它没有做调查。书里没有一份问卷、一组统计，凡是数字和年份，拿不准的都标了〔待核〕，汇在附录四。它讲的是一台引擎怎样转，不是有多少台车停在路边。

它没有评政策。场变了、可预期度下降，书里只描述这件事怎样落进一片土，不说谁对谁错。

它没有给诊断。附录二的三张卡，只看运行态，不看病；身体或心里的难处真的大了，请找医生或心理咨询师。

它也没有替任何人做决定。从头到尾，本书不说「应该躺」，也不说「不许躺」。它只想放一张转速表在你手边，让你自己看一看：这台车，此刻转在哪一格。

再说一说这本书是怎样搭起来的。

五位执笔分了五段：前置与第一编一段，第二编一段，第三编一段，第四编一段，第五编连同结语、附录、后记一段。五段同时动笔，彼此看不见对方的稿子，靠的只有那一份总纲。总纲里定死了几样东西：判词一字不差，一句话定义一字不差；车的部件对照只有一套，油门就是往路上送的劲，路面就是土；三位陪读人物的年龄、职业、经历不许改；四十四章的章号章题不许动。

这样写，好处是快，难处是缝。五段之间，难免有一处说早了、一处说重了、一处两个人各用了一个不同的例子。统稿时一条条对：交叉引用的章号对不对得上，同一件事前后口径一不一致，同一个比喻有没有用到腻。对得上的，留下；对不上的，改。

这件事本身，也像书里讲的那台引擎。五段稿子是五股劲，总纲是那片土，统稿是回写。回写改动了哪几处，这本书就在哪几处，比五段各自写完时多长出了一点东西。

还要感谢那些在网上、在饭桌上、在深夜的聊天框里，说过「躺平」两个字的人。这本书里的每一辆车，都不是谁，可每一辆车，都像很多人。

一本讲「回写」的书，最希望的，是被读者回写。

你要是觉得哪一处判错了，比如你身上的怠速，三型都对不上；你要是查到哪一条引文不对、哪一个年份记错了；你要是在自己的日子里，试过书里的某一件明天能试的小事，发现它不灵，或者灵得出乎意料——请告诉我们。这本书，会因此改。

本系列的下一本，还会接着用这一套词往下走。车停在路边的时候，我们在；车挂上挡的时候，我们也想在。

最后，把全书的那一点意思，再说一遍。

怠速的车，保住了不熄火，这是它的功劳。可是不熄火，从来不是为了停着。发动机一直低低地响，是为了有一天，挡挂上了，离合松开了，油给上了，它还能往前走。

不熄火，是为了在走路。这本书，也是。
