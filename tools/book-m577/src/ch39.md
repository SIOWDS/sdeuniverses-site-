# 第39章　画家的独生子：继承他的为什么是画家

◆一、黑板上的两个字

周三下午，一所社区老年大学的国画班。老师是位退休的美术教师，进门先在黑板上写了两个字，“虚静”，转过身说：画山水要有庄子的味道，心里不空，笔下就挤。台下十几位学员，有退休的会计，有从工厂下来的钳工，都点头，没有一个人觉得这里出现《庄子》有什么奇怪。下课前拿起毛笔试了一笔，退休的钳工发现自己手有点抖，三十年在车间里稳稳握着锉刀的手，到了笔杆上不听使唤。老师走过来，没有说“你心不够静”，她把他的手指往下挪了半寸，说：握这里。这半寸是一件可以教、可以纠错的东西，在黑板上的那两个字之外。

现在换一间教室。设想同一所学校开了一门水利常识课，讲堤坝怎样防汛；再开一门小本经营课，教人怎样进货、记账。如果老师进门先在黑板上写“虚静”，说修堤坝要有庄子的味道，学员大约会笑。这个笑声里有一个值得掂量的东西：两千三百年来，读过《庄子》的人遍布各行各业，可是把他当作自己行当的祖师爷，认认真真接过去的，似乎总是画家。治水的人，似乎没有这样接的；开店的、管账的，也没听说过。这一章要问的就是这个。

◆二、一个读法，和一个反驳

先说一个有名的读法，只转述。徐复观在《中国艺术精神》里，把庄子读成中国艺术精神的源头。他的意思大致是：庄子本来没有打算谈艺术，他追求的是人生的某种境界，可是这个境界一旦落下来，它的样子就是艺术的样子；而在所有门类里，把这份精神落成作品的，主要是绘画。据章启群引述，徐复观把绘画称作庄学的“独生子”，意思是中国艺术精神的自觉主要表现在绘画和文学两方面，而绘画又是庄学最亲的那一个。独生子的意思很清楚，别的行当也许沾过光，可是接家业的只有这一个。

章启群不同意这个读法的一半。他的反驳，大意是：汉代以前的绘画，基本不具有徐复观所说的朴素、恬淡那种性质，庄子对艺术的影响，是通过魏晋玄学才直接发生的；同时他也承认，这种影响不容置疑。下面几样东西，可以拿来对照他的说法，它们是本书另外补的，不是章启群的原话。西汉马王堆一号墓里的T形帛画，一般认为画的是引魂升天的天上、人间、地下，是为丧礼画的，不是为一个人看山看水画的。唐代张彦远在《历代名画记》里还留着一种老说法，大意是画画为的是成教化，助人伦。山水成为画家愿意认真画的题目，要到东晋和南朝，顾恺之之后，宗炳写《画山水序》，里头有“澄怀味象”四个字。从战国中期的庄子到这些人，隔了好几百年。书躺了好几百年，画家才伸手去拿。

这个反驳没有推翻徐复观，它改了他的故事。继承不是一条从祖师爷到嫡子的血脉，它是一次又一次的伸手，每一回都是某一批人，在某一种需要里，翻开了这部书。魏晋的士人活在乱世里，要给自己找一个看山看水的理由，这部书里有现成的东西。书先在那里，需要来了，手就伸过去。本书接住徐复观看见的那件事，画家的确是这部书最干净的继承者；不接的是“独生子”三个字背后的那条血脉，因为血脉要有人连着传，而这里的传，每一次都隔着几百年的空白。

◆三、画家拿走了什么

接下来看画家究竟拿走了哪一部分，这要贴着原文看。《田子方》里有一个画家，只出场不到一百字：“宋元君将画图，众史皆至，受揖而立；舐笔和墨，在外者半。有一史后至者，儃儃然不趋，受揖不立，因之舍。公使人视之，则解衣槃礴臝。君曰：‘可矣，是真画者也。’”第 25 章把这一段的镜头细读过一遍，这里只取与继承有关的两点。一点是故事从头到尾没有画一幅画：众史舐笔和墨，站满了厅，那位后到的人“不趋”“不立”，只用脚步和姿势出场；国君派人去看，看到的是一个解衣盘腿的人，便说“可矣”。验的是画家的姿势，图根本没有拿出来。另一点是这句“可矣”出现的位置，在任何一笔落下之前，作品把重量全压在“人先空下来”上，动笔以后的事留在了片外。画家最爱这一段，原因就在这里：它给出的是一个动笔之前的人，没有给动笔之后的做法。

苏轼写文与可画竹，用了同一个姿势。《书晁补之所藏与可画竹》里说：“与可画竹时，见竹不见人。岂独不见人，嗒然遗其身。其身与竹化，无穷出清新。庄周世无有，谁知此凝神。”这几句里有两个词是借的。“嗒然”来自《齐物论》开篇的“嗒焉似丧其耦”，南郭子綦隐几而坐、仿佛把自己丢了的样子；“凝神”来自《达生》，孔子看着那位粘蝉的驼背老人，叹一句“用志不分，乃凝于神”。苏轼把两处合在一首诗里，等于说：文与可画竹的那一刻，就是子綦隐几，就是驼背人粘蝉。最后一句更有意思，“庄周世无有，谁知此凝神”，这世上要是没有庄周，谁还知道这是凝神？他承认，这个词、这个姿势，是庄周给的。

可是苏轼在同一位朋友身上，还写下了另一段话，意思完全不同。他说文与可画竹，“必先得成竹于胸中”，看熟了，看清了，提笔急追，不让它跑掉，这是《文与可画筼筜谷偃竹记》里的话。写到后面，他自己承认：我做不到，只是心里知道为什么那样做；知道了为什么而做不到的人，是内外不一，心和手不相应，毛病出在没有学。这就是整个故事的关键。“嗒然遗其身”是看的方法，庄周给了；“成竹在胸”是画的方法，要靠一遍一遍地学，庄周没有给。苏轼自己，心里明白，手里不会，是眼睛有了，办法没有。画家从《庄子》那里领到的，是一双眼睛。画笔怎么握、墨怎么破、山石怎么皴，是画室里师徒几代自己攒出来的。

再回到国画班。那位老师教这一课的次序，大概也是这一行的通例：头一个月只让学员临，临得不像就再临，几节课下来不提一个哲学字眼；“虚静”两个字留到学员的手稳了、纸上开始透气的时候才用，用来给一种已经出现的状态起名，不用来发动它。设想一位学员问：我心总静不下来，怎么办？老师多半不会讲心，她会说：先把这一笔的水分控好。在她手里，《庄子》是看画时用的话，握笔的时候，用的是另一套。

◆四、治水的和开店的

现在回到黑板。治水的人为什么不拿《庄子》当祖师爷？《庄子》里恰恰有一位和水打交道的人。《达生》里吕梁的那位游泳者，在三十仞的瀑布下面出没，孔子问他蹈水有没有道，他先答一句：“亡，吾无道。”没有。接着才说：“吾始乎故，长乎性，成乎命。与齐俱入，与汩偕出，从水之道而不为私焉。”随着水的旋涡进去，随着水的涌浪出来，顺着水的路，不加一点自己的主意。开头那句“没有”很要紧，他是说，这里没有一套可以教给别人的工序。故、性、命三个词，一个比一个远，想学游泳的人听了，不知道先动哪一块肌肉。这段话谁听了都觉得好，可是管堤坝的人听了，只能放在心里，不能放到图纸上，因为“顺水之道”这个词，搬到水闸和堤线上，没有定义，也没有人知道它的尺寸。洪水来了，堤坝撑得住还是撑不住，洪水不看意境。治水的这本账，记在现实界里，记在汛期过后有没有人被淹，有没有一季的粮食保下来。游泳者的“从水之道”，管的是一个人怎样不被水吞掉，管不到一座城。

开店的人也是一样。设想一位开小饭馆的老板，晚上收了摊，躺在沙发上翻《庄子》，读到“人皆知有用之用，而莫知无用之用也”，觉得舒服极了。第二天早上，他仍然要核对昨天的流水，要想想上头两家馆子的价钱，要给供货的人打电话。“无用之用”在晚上给了他一口气，到了早上，这口气折算不成一笔进货款。他的账是现金的账。书里没有哪一句，替他说清楚怎样把明天的米钱凑够。

把这三个行当放在一起看，差别在一个地方。画家的工作，从头到尾是让人看见。画家这一行的账，大半记在美的名下，画得好不好，是看的人说了算；读不读庄子，改变的是怎么看，这正好是庄子能给的东西。治水和开店的账，记在回写名下，记在做完以后现实里留下了什么，而这恰恰是这部书把它判得比较轻的地方。所以这是全书判词的一次回落：作品只管让你看见，不管替你结算，那么最容易接得住它的，就是那些本来就以“让人看见”为业的人；而职业就是“结算”的人，多半接不住。

当然，说独生子也说过头了。陶渊明是诗人，禅宗的和尚读《庄子》，养生的道士也读，下一章就有两位读者，一个种地，一个开荒。继承的并不只有画家。但是画家的情形，的确是这个读法最干净的一个例子：他领走的是眼睛，没领办法，也没有因此少画一笔。

◆五、擦掉的那两个字

最后说一句三重关系，因为这件事用它说得最准。先看一幅山水摆在人面前的样子（显露，S），它由画一笔接一笔的次序（差异序列，D）和它落在谁手里、谁出钱、谁来看、挂在哪面墙上（特征纠缠，E）一起顶出来。魏晋以后的山水画变了样，是 S 变了：“澄怀味象”进来了。可是 D 没有从《庄子》那里得到什么，怎样一笔一笔把山画出来，是画室里的东西。E 倒是变得多：魏晋士人的处境，让一种看山水的眼光有了需要。这里有 123 原理说的那一幕：士人的处境（E）要一个可以安放自己的看法，而此前的绘画（D）只会为教化和丧礼服务，两边的矛盾累积起来，逼着显露改变，改变以后留下的东西又回写给后面的画室，画论里的“澄怀味象”“见竹不见人”就是看得见的回写。看不见的是：《庄子》的哪一句，变成了哪一种皴法。这个空白，恰好是眼睛能留下、办法留不下的另一种说法。六路径的角度，画家走的是 E→S→D：先有处境，再有看法，最后才是手上怎样画，从处境到手艺，中间的 D 要自己补。

黑板上那两个字，老师大概也明白。第二节课她擦掉“虚静”，写上一行小字：先临十遍。台下的退休会计，认认真真抄了下来。
