# 前言　一条刷到的短视频

这本书从一条短视频开始。二〇二六年十一月的一个晚上，我刷到它：舷窗外一片云海，机翼斜斜地伸进画面，太阳在右上角，配乐是一支老歌，字幕是黄色的大字：“飞机飞到一定高度，就没有阴天了。其实人也一样，一切烦恼都是因为高度不够。”底下的数字是五万多个赞，五万多颗红心，八万多次转发，三千多条评论。

转发比评论多二十多倍。这个比例当然证明不了什么，一条视频算不上证据，可它让我多看了一眼。一句话被这么多人递给别人，却很少有人停下来问一句“然后呢”。这种话好像生来就是用来转的，它不等人回答。

我接着想下去，一层一层地往外翻。第一层，这句话是一个类比，前半句是物理，后半句是人生，中间只靠“人也一样”四个字把证明的责任免掉了。这样的话太多了，我管它们叫虚幻的类比智慧。第二层，你不能总是在云上，人一生大部分时间都在低处，云上的智慧管的是千分之几的时间，却拿来判决其余的全部。第三层，处高处是要消耗能量的，不可长久，没有哪架飞机能靠境界留在天上。第四层，这句话把人活在其中的三个世界切掉了两个，现实界和自我界都不见了，只剩一个理念界，而且是缩了水的。

翻到这里，一个人的名字浮了上来，他就是庄子。“以道观之，物无贵贱”，蜗牛角上两国交战，大鹏飞上九万里，这些话比那条视频高明得多，骨子里却有同样的动作。我于是想到一个判断：《齐物论》只能是一种艺术境界；庄子是艺术家，不是哲学家，因为他的类比经不起理性的拷问；他的智慧很有用，道理也很好，可是不能经常用。

这个判断听上去是在贬低庄子，其实是在替他卸担子。一幅画不会因为不能挡雨就成了坏画。把《庄子》当人生操作手册，错不在《庄子》，错在拿它当手册的人。这部书自己就说过，它的话是“谬悠之说，荒唐之言，无端崖之辞”，世道太浑，“不可与庄语”。作者早就把合同写在门口了，是后来的人把合同撕了，拿着戏文上了街。

所以这本书要做的事很简单：把《庄子》三十三篇，内篇七、外篇十五、杂篇十一，一篇一篇当作品来读。每一篇问五件事：它是一件什么样的作品，手艺在哪里，读者身上发生了什么，拿理性一拷问断在哪里，最后替它写一张说明书，说清楚什么时候用，什么时候别用，用完回去做什么。

这里要交代几件事。

第一，本书的判断是能错的。动笔之前我写下了四个读数和各自的撤回条件，比如全书所有带着难处来求教的场景里，如果过半的答复给了具体做法，全书的判词就作废。结果写在导论里，有的支持我，有的不支持，《人间世》那一关差点把判词推翻，判词也因此改了两个地方。这些读数是写作过程中自己数的，属于自查，算不上独立验证，读者可以自己再数一遍。

第二，站上已有两本读庄子的书。第 486 号《浑沌的七窍》问的是他靠什么长出来，判语是“他教的是不凿，他靠的是凿”；第 274 号《逍遥是怎样长出来的》问的是逍遥怎样在生活里一点点练成。本书问的是另一件事：这件作品管什么，管多久。三本书的判断并不一致，尤其第 274 号倾向于“可练”，本书说“不能常用”。我的处理是，练得成的是手艺，住不进去的是境界，详见正文，附录列有对照。第 116 号《理念艺术的诞生与实践》讲的理念艺术也要在这里划开：理念艺术是做椅子，打榫，留读数，可以坐；本书说的哲学艺术是画椅子，不留读数，只让你看。

第三，书里有一家人，机务老陆一家。他们全是设想出来的人物，用他们，是因为一本谈云和高度的书，总得有几个站在地面上的人替它作证。

第四，凡涉及死亡、丧亲、病痛的地方，都只当作品来读。作品不替代医生，也不替代任何专业的帮助。

最后说一句分寸。读完这本书，我希望您更佩服庄子的手艺，也希望您知道，读完以后，那通电话还得您自己去打。
