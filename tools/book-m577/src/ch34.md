# 第34章　盗跖：编虎须的人

◆一、被道理压得喘不过气

陆远这一年听过的道理，数得出来。年夜饭上，亲戚说年轻人要上进，要成家，要懂得感恩；陆晴一条接一条转来励志短视频，字幕写着“别人都在拼”；母亲在电话里说，你要体谅你爸。每一条都对，没有一条驳得回去，对到陆远只想把筷子放下。有一回他把手机扣在桌上，说：“你们说的我都懂，别说了。”屋里安静下来，他自己也分不清，那一刻是痛快还是难受。

这种时候翻到《盗跖》，会有久违的舒坦。前半篇整整一场，是一个满嘴狠话的强盗，把天下最体面的说教人骂得一句也还不上。

◆二、虎须是怎么编的

故事先铺垫，再登场。孔子对柳下季说：“为人兄者，必能教其弟。”柳下季是盗跖的哥哥，这话的意思是：你管不住你弟弟，我替你去。柳下季只回一句：“先生必无往。”孔子不听，颜回驾车，子贡护右，往太山之阳去。到了，盗跖正歇着人马，“脍人肝而餔之”，一句话交了他的底色：午饭吃的是肝。孔子下车，向通报的人报名：“鲁人孔丘，闻将军高义，敬再拜谒者。”“再拜”加“高义”，客气得像求人办事。

通报传进去，盗跖“大怒，目如明星，发上指冠”，人还没见到，先骂了一套衣裳：“冠枝木之冠，带死牛之胁”，戴着树枝做的帽子，扎着死牛的肋骨，孔子的礼服被当成戏服嘲笑。接着是四字一句的急雨，“作言造语”“妄称文武”“多辞谬说”“摇唇鼓舌”，句子短，不换气，落脚在肝上：“我将以子肝益昼餔之膳”。两个人见面，身体先把座次排好了：孔子“趋而进，避席反走，再拜”，小跑、后退、又拜，三个动作都在矮下去；盗跖“两展其足，案剑瞋目，声如乳虎”，腿岔开，手按剑，声音像带崽的母虎。没有一个字的论辩，输赢已经摆在地上。孔子带来的两个最得意的学生，颜回驾车，子贡护右，全程没有一句台词，他们只是坐在车上，看着老师一路矮下去。

孔子的开场是一套推销。他夸盗跖有三德，样貌夸到牙齿和嗓子，“唇如激丹，齿如齐贝，音中黄钟”，然后许诺：我去替你游说诸侯，给你造方圆数百里的大城，让你做诸侯。他挑了最差的一件货，对一个手下九千人、靠刀吃饭的人，许一个更大的饭碗。盗跖的回话带着内行人的不耐烦：“夫可规以利而可谏以言者，皆愚陋恒民之谓耳。”能用利哄、用话劝的，都是老实人。

◆三、骂声忽然安静的一处

接下来是历史大段。有巢氏的人住在树上，神农时的人“与麋鹿共处，耕而食，织而衣，无有相害之心”，到黄帝开始打仗，“自是之后，以强陵弱，以众暴寡”。然后他把箭转回孔子：“天下何故不谓子为盗丘，而乃谓我为盗跖？”这是全篇最漂亮的一句，只换了一个字，整场对话翻了面。再往下他点名一串圣贤，说他们“无异于磔犬流豕操瓢而乞者”，英雄被一律打成牲口和乞丐，骂得有画面。

而最好的是转折。他说孔子那些，“皆吾所闻知也”，随后换了声调：“今吾告子以人之情，目欲视色，耳欲听声，口欲察味，志气欲盈。”人活得再长，“开口而笑者，一月之中不过四五日而已矣”。再然后：“天与地无穷，人死者有时，操有时之具而托于无穷之闲，勿然无异骐骥之驰过隙也。”一匹好马掠过墙缝，一闪就没了。整场骂战里，只有这里像诗，叫骂忽然轻下来，露出一个怕时间的人。

◆四、执辔三失

孔子这一边，在盗跖面前没有回一句话。败写在身体上，而且由外向里：“执辔三失”，手先不听使唤，缰绳掉了三回；“目芒然无见”，眼睛睁着，看不见；“色若死灰”，脸先灭了；“据轼低头”，脖子撑不住；“不能出气”，最后连气也出不来。从手、眼、脸、颈写到呼吸，像一盏灯一格一格往里熄。回到鲁国东门外，正碰上柳下季，他问：“跖得无逆汝意若前乎？”孔子只应一个字：“然。”这个字本可以引出一篇辩解，他却自己笑了：“丘所谓无病而自灸也，疾走料虎头，编虎须，几不免虎口哉！”没病给自己灸，跑去摸老虎的头、编老虎的须。败的人亲手把败写成一出笑话，这是整场对手戏里最体面的收法，也是它的喜剧所在：说教的人被说教了，而且自己笑出声。

读的人在这里发生的事，和陆远扣下手机那一刻很像，又更干净。前面压了一路的气，从孔子开口教训柳下季起就攒着，到“目芒然无见”那一格，才有了出口。读的人可以安心笑，因为败的是孔子，不是自己；那些压在陆远身上的道理，背后站着的恰是孔子这一类人。这场笑里有个细节：开篇柳下季劝过“先生必无往”，结尾他又在东门外迎面碰上，一头一尾，把整场败仗框成了一件早有人预告的事。预告过的败仗最好笑，因为败的人是自己走进去的，没有人推他。笑到这里，压力换了方向：原来讲道理的人，也有被道理收拾的时候。

◆五、骂得好，不等于说得对

苏轼疑这篇和《渔父》“若真诋孔子者”，要把它从庄子名下去掉。他是在替庄子辩护，评的不是手艺。当论读，这篇确实不强；当戏读，这是杂篇里最大的一场对手戏，价值在这里。可戏看完了，论还得拷问。抽掉脍人肝、乳虎、执辔三失，剩下三条主张。一，圣王贤臣都为利所惑，所以不足贵，动机的断言，没有办法验。二，忠臣贤士多半死了，所以不值，可死的人多，推不出事不值得，他自己的九千人也在死。三，人生短，所以该悦其志意，“不能悦其志意，养其寿命者，皆非通道者也”。第三条是承重件，而它推不出来：“人寿短”可以推出别把一生耗在不值的事上，也可以推出更要把一件事做完，也可以推出今晚把薪水花光。同一个“短”，推向哪里，看的是账。设想有人知道人只活一回，便把一个月的工资一晚上花完，月底房租没着落，这一步不是从“人生短”走出来的，是从“我现在就想”走出来的。吵架时也是这样：对方一句话骂得极准，当场把你噎住，噎住你的是准，不是对；等气消了回头算，那句话里能认领的，往往只有一半。盗跖算账只写了收入一栏：一月笑四五天；他扣掉的病、死、丧、忧里，有一部分正是他的九千人制造的。

骂也有骂歪的地方。他说子路“欲杀卫君而事不成，身菹于卫东门之上”，拿子路的死证明孔子教得不好，可史书记子路死在卫国孔悝之乱里，他是赶回去救孔悝的，并非谋杀卫君，与此说不同。连证据也顺着话头弯了一下。“盗丘”那一句，揭出了对方的伪，却没有减少自己的账：说你也是强盗，强盗不会因此不是强盗。类比四问里，“盗”这个词只搬了字，没搬条件：拿刀拿走的人，和收学费讲学的人，共用一个“拿”，一个被拿的人丢了东西，一个交学费的人自愿。把方向倒过来，说“强盗是另一种老师”，听着就不顺耳了，可见“盗丘”靠的是单向借字。再问它敢不敢说自己断在哪，盗跖的回答是“丘之所言，皆吾之所弃也”，一处也不让步。

◆六、后半篇替前半篇补的账

篇没有在“自灸”处收尾，又接了两场谈话。第一场里满苟得说“无耻者富”，可结尾他自己落在“无为小人，反殉而天；无为君子，从天之理”，两头都不要。第二场里知和把财富的坏处一条一条数下去：“可谓乱矣”“可谓苦矣”“可谓疾矣”“可谓辱矣”“可谓忧矣”“可谓畏矣”，六个“可谓”排下来，收在“此六者，天下之至害也”。前面强盗说该悦其志意，最后一场里，说富过了头是六样害。这篇自己不同意纵欲，不同意的人，是后来接着写的那只手。

两场谈话为什么偏偏接在后面，这样想就说得通了。一场对手戏收在孔子的笑话上，笑完，账没有结：强盗要人悦其志意，那么志意该悦到哪里止，欲望的账由谁来算，孔子没答，强盗没讲。后来的手觉得不对，便一场一场补，补成了劝世文的口吻，节奏也松了，没有肝，没有乳虎，没有掉在地上的缰绳。这里的荃和鱼各有下场：前半篇的荃编得最漂亮，补的人却想把鱼再塞回去，塞进去的那几句，作品里最不好看，说得最像道理。

◆七、一把尺子转了手

显露（S，眼前的这一幕）是孔子被骂垮。差异序列（D，次序一步一步怎样排）是同一把尺子的转手：孔子开场用的是“为人兄者必能教其弟”，盗跖收场用的是“子教子路菹此患”，教者的责任这把尺，从孔子手里转到盗跖手里，量的是孔子自己。特征纠缠（E，一个人被哪些人和事牵着）是孔子与柳下季、子路的牵连：他的账里有这些人，盗跖的账里只有九千人和自己。按123原理，D与E的矛盾累积，逼着S改变：孔子的手脚先垮。回写能被观察到的，是孔子把这趟出门的名字从“说之”改成了“自灸”。回写只落在孔子一个人身上，“该不该管弟弟、怎样管”这件事，篇里再没有提。想判这篇，起手不能是S，那会被场面带着走；先把论点拆成可判的几条（D），再问谁在说、替谁说（E），最后才让场面出来。

**说明书**
适用：被道理压得喘不过气时，读孔子登门那一幕，笑一场，把气放出来。
不适用：拿盗跖的话当行事依据，尤其是把“人生短”当成花钱、欠账、撒手不管的理由；也不适用于判断某一条具体劝告对不对。
回程：压在身上的那几条道理，当晚逐条抄下来，挑最重的一条，查清是谁的，对不对，自己做不做得到。
