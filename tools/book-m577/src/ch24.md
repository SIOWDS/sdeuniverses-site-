# 第24章　山木：栗林里的弹弓

◆一、厨房门口的那个问题

庄子出了山，借宿在老朋友家里。主人高兴，吩咐小童杀一只雁来烹。小童站在厨房门口，问了一个很周到的问题：“其一能鸣，其一不能鸣，请奚杀？”两只雁，一只会叫，一只不会，杀哪只。主人想都没想：“杀不能鸣者。”五个字。这一问一答不到二十个字，是整篇最快的一场戏，因为头天山里那棵树刚被庄子夸过，“此木以不材得终其天年”，这句话还在读者耳朵里，小童一开口，读者已经知道要出事了。

第二天弟子来问，把两件事拼成一副对子：“昨日山中之木，以不材得终其天年；今主人之鴈，以不材死。”同一个“以不材”，后面一个跟着“得终其天年”，一个跟着“死”。对仗到这个份上，几乎不用再问，那句“先生将何处”只是替读者补上最后一槌。庄子笑了。他先说自己大概要站在材与不材之间，话音未落就自己撤回：“似之而非也，故未免乎累。”刚摆好的位置，当场拿掉。随后他又给出第二个位置，乘着道德而浮游，“一龙一蛇，与时俱化”，说完立刻又堵上：合则离，成则毁，廉则挫，尊则议，有为则亏，贤则谋，不肖则欺，一连七组“某则某”，把能站的位置挨个走了一遍，没有一个是安全的。最后用一声叹息收住：“胡可得而必乎哉”，再补两个字，“悲夫”。

这是门人给《人间世》补的漏。《人间世》里的栎社树靠无用保命，说得太顺，这里派一只不会叫的雁出来，把话戳破。本书开头那条短视频说的是人到了一定的高度就没有阴天，这一篇的回答是，没有哪一层楼高到不会被人从下面看见。让一个刚立住的说法当着弟子的面，当场被自己拆台，这份诚实在整部书里不多见。弟子最后得到的只有一个去处，不是办法：“其唯道德之乡乎”。

◆二、一件补过的粗布衣

“庄子衣大布而补之，正緳系履而过魏王。”这一句里没有一个字在说话，先让人看见一件打着补丁的粗布衣和一双靠带子系住才没散的鞋。魏王开口，问的是：“何先生之惫邪？”庄子的回答只有五个字：“贫也，非惫也。”紧跟着他下了定义：“士有道德不能行，惫也；衣弊履穿，贫也，非惫也；此所谓非遭时也。”穷是衣服破了，惫是有道而不能行，两样东西本来被人叠在一起看，他一刀分开。这一刀分得有骨气。

再往下读，这一句有意思的地方出来了。他举腾猿为例：猿猴得了楠梓豫章，攀枝称王，连羿和蓬蒙也不敢正眼看它；换到柘棘枳枸之间，就只能危行侧视，浑身发抖，“此筋骨非有加急而不柔也，处势不便”，筋骨没变，处的地方变了。然后他收口：“而欲无惫，奚可得邪？”开头五个字替自己撇清，结尾却说在这样的世道里想不惫是办不到的。按他自己的定义，有道而不能行就是惫，这个世道恰好让人不能行。两头并读，他其实没有把魏王的话推回去，只是把账从自己身上，挪到了世道头上。这一笔挪得漂亮，也留了个口子。

◆三、一环扣一环

雕陵这一段，是外篇里最好的连续镜头。庄周在雕陵的栗园边，头一个画面不是蝉，是鸟：“覩一异鹊自南方来者，翼广七尺，目大运寸。”先拿尺子量，翅膀七尺，眼珠一寸，大得有些不对劲。紧接着：“感周之颡而集于栗林”，鸟从他的额头擦过去，落进树林。第一下碰触是鸟碰的他，他还没有出手，就已经被擦了一下。他开口是笑那只鸟：“翼殷不逝，目大不覩”，翅膀这么大却飞不远，眼睛这么大却看不见。笑别人的盲点，是整段的引信。然后四个动作：“蹇裳躩步，执弹而留之”，提衣，快步，端弹弓，等着。镜头到这里，已经从他身边挪到了他的身体里，他成了猎人。

接下来是三句同样的句式：“覩一蝉，方得美荫而忘其身；螳蜋执翳而搏之，见得而忘其形；异鹊从而利之，见利而忘其真。”眼睛是顺着弹弓的准星往下找的：先是蝉，再是螳螂，再是刚才那只鸟。三句各自推一环，动词是得、搏、利，被忘掉的东西是身、形、真，从身体到样子再到本来的自己，一环比一环深。这三句里每个人都只看着前面一个，没有人回头。镜头推进得整整齐齐，像一台摄像机顺着一根线往前走，观众以为这是庄周在看别人。

“庄周怵然曰：噫。”镜头在这里切了，拉远了。“物固相累，二类相召也。”他忽然意识到，自己端着弹弓，是链子上的第四环。“捐弹而反走”，扔了弹弓，掉头就跑。可是镜头继续往后拉，又进来一个人：“虞人逐而谇之”，管栗林的人追着他骂，把他当作闯了林子、该受罚的人。逃出链子的那个动作，立刻把他放进了另一个链子里。这是全段最狠的一笔，作者没有给他一个干净的醒悟。

接着是一个收尾的安静镜头：“反入，三月不庭。”回去闭门三个月，旧注一般把“不庭”解作不出门庭。弟子蔺且追问，庄周的自我检讨很短：“吾守形而忘身，观于浊水而迷于清渊。”我只顾盯着猎物的影子，丢了自己。他还补了一句从老师那里听来的话，“入其俗，从其俗”，到了人家的林子，就得守人家林子的规矩。门人让书里的庄周做了自己寓言里最傻的那一环。一部书肯这样写自己的主人公，边框是自己撤回来的。

◆四、读者被挂在弹弓后面

读这一段，人是站在庄周的位置上，眼睛随着准星走的。先是好奇，鸟这么大，会被什么吃？然后是一点小小的得意，看穿了鸟的盲点。然后顺着往下看，蝉、螳螂、鸟，每看一环，猎人的快意就多一分。切镜头的那声“噫”把人从准星后面拽出来，满身是汗，这个动作快得读者来不及反应。通常的寓言到这里该松一口气了，这一篇偏不，扔了弹弓以后紧跟着是追骂，再跟着是三个月。紧张没有被放掉，被拖长了。读完的人没有得到一个答案，得到的是一个姿势：不要忘了脖子后面。

◆五、超市里的连环账

设想秀兰的超市里有这样一环扣一环的事。街坊里一位老主顾，赊着一个月的食用油和挂面，他心里很安稳，反正月底发了钱就还，这是躲在荫凉里的蝉。秀兰夜里对着赊账本，一页一页盯着，盘算明天怎么开口，怎么在不得罪人的前提下把钱要回来，这是执翳的螳螂。可是十五号，进货商的车会准时到门口，货款不能拖，拖了下次就不给赊，价钱也要往上涨，这是在后面等着的异鹊。再往后还有：进货商背后有厂家压他的账期，对街新开的连锁店盯着这条街的生意。每一环都忘了自己后面有人。

设想秀兰有一个夜里看到了整条线，怵然一下。她的“噫”不是装的，可是她没法“捐弹”：赊账本扔了，十五号的货款不会少一分。《山木》让庄周三个月不出门，这是他的账；它没有告诉秀兰，那一笔欠着的货款怎么在醒悟之后按先后还。这里要停一下，拿尺子量一量。做减法检验，把蝉、螳螂、鸟的画面抽掉，剩下的主张是“追逐者自己也被追逐”，这是一条观察，有时对，有时不对：有的螳螂背后没有鸟，有的链子只有两环。作者选的是三环，选到第四环正好是观察者自己为止，链子的长短由作者定，判错不容易。类比四问里，“物固相累”这个词的条件交代了吗？没有，只有“忘”一个条件。它敢不敢说自己断在哪？敢，开头那句“胡可得而必乎哉”已经说了。这是它的好处，也是它能管的范围。

◆六、一个人在三式里只动了一式

这一节才让本书自己的词出场。三大方程：显露（S，能被看见的样子）、差异序列（D，一级一级拉开的次序）、特征纠缠（E，缠在一起的条件）三者互相牵着，S=F(D,E)，D=G(S,E)，E=H(S,D)，F、G、H只是占位记号。蝉、螳螂、鸟三环的“忘其身”“忘其形”“忘其真”是显露，这显露是由它们在链子里的位置（E）和忘掉的东西一环比一环深的次序（D）共同定的。庄周的“捐弹而反走”，只动了显露一式，扔了弹弓，掉头跑，但缠着他的那条链没动，于是第三式立刻有了回应：虞人冲出来。这是这件作品自己演给你看的：只动一式，另外两式会替你补上。

123原理指的是：差异与纠缠之间的矛盾累积，逼得显露改变，显露的改变再回写到差异与纠缠里。“怵然”就是矛盾累积到逼出显露改变的那一下。回写要看是不是被观察到：庄周回写到了自我这一层，“吾守形而忘身”“入其俗，从其俗”，他认了错，改了口；蝉还在荫下，螳螂还在扑，链子没有动一环。

起手的次序也有讲究。庄周的路是从纠缠起手，一眼看见缠，立刻掉头，整个过程不经过任何次序。秀兰要走的是另一条：先把哪天欠谁、哪天谁欠她，按先后排出来，再看这些账缠着谁，最后才轮到要不要换个活法。起手错配不会报错，它让人觉得透亮，账却还是原来的账。

◆七、黄雀从哪里来

最后看一件事：这么扎手的故事，为什么留在后世嘴里的，竟是一句看起来很聪明的话？成语词典里的“螳螂捕蝉，黄雀在后”，出处标的是《山木》，并另引汉代《韩诗外传》里螳螂欲食蝉、不知黄雀在后的说法。原文是异鹊，今天是黄雀；原文里有第四个人拿着弹弓，成语里没有。成语把庄周剪掉了，只剩三环，意思也跟着变了：它成了一句提防背后有人的话，更常被拿来说谁在算计谁。原文那一声“噫”，“捐弹而反走”，三个月的不庭，都没有被带走。这一篇的别的成语，“直木先伐，甘井先竭”“君子之交淡如水”，方向基本没有翻。这是反面的证据，也说明：至少在这几条上，判语长在话里的句子，像直木先伐、君子之交，方向没有翻；判语放在画面后面的，判语常被剪掉，只剩画面。

**说明书**
适用：正在追人、盯人、算计人的时候，读雕陵那一段；以为换个位置就能躲祸的时候，读树与雁。
不适用：账期已到、有人已经上门的时候；那时要的是排先后，不是顿悟。
回程：回去把手上正盯着的一件事写在纸上，顺着往后看一环，谁在盯着你盯的这件事，把名字写下来，再想下一笔账怎么排。
