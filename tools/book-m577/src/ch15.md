# 第15章　在宥：一篇政论，和一个拍着大腿的人

比如有一位新上任的部门主管，上班第一周，满腔想法，手里捏着一份写满条款的方案，跑去请教退休的老前辈。老前辈正在院子里，一边晃着两条胳膊，一边拍大腿，嘴里哼着不成调的东西。主管把方案讲了十分钟，老前辈只回了一个字。《在宥》里有一场戏，和这个场面几乎是一个模子，只是主管换成了云，老前辈换成了一团叫鸿蒙的东西。

这一篇开头是政论，中间一段崔瞿问老聃，接着是黄帝求广成子和云将遇鸿蒙两个故事，最后又回到议论。作品的看点集中在云将与鸿蒙那一段，本章把力气花在那一段上，政论部分点到为止。

◆一、长问，短答

“云将东游，过扶摇之枝，而适遭鸿蒙。鸿蒙方将拊脾雀跃而游。”云将、鸿蒙二名，从字面读像一个玩笑，旧注多把云将解作云的主帅，把鸿蒙解作未分的元气：一个管云的，撞上了一团还没分开的混沌。云将的反应是“倘然止，贽然立”，两个叠词，先愣住，再站定，像一个习惯了被人让路的人突然被路挡住。他问“叟何人邪？叟何为此？”，对面“拊脾雀跃不辍”，只答一个字：“游！”

这个段子的喜剧节奏，来自问和答的比例失衡。云将接着问，问得很大：“天气不和，地气郁结，六气不调，四时不节。今我愿合六气之精以育群生，为之柰何？”四个四字句铺陈灾情，再接一个宏愿，问了一整个天下。鸿蒙“拊脾雀跃掉头”，回答是：“吾弗知！吾弗知！”连说两遍，掉头不看。然后作者只补了一句：“云将不得问。”问的越长，答的越短，这条反比，贯穿整场戏。

◆二、称谓和动作，倒过来

过了三年，云将又遇见鸿蒙，“大喜，行趋而进”，“天忘朕邪？天忘朕邪？”再拜稽首。这几个动作要放在一起读。“朕”在先秦是通用的自称，到秦始皇才归皇帝专用，这里不能一听就当帝王口气；可云将紧接着自报家门，说的是“民随予所往”“朕也不得已于民”，他是个管着民的人，口气是当家人的口气。身子却在“行趋”，小步快走，是下属见上级的步态，随后“再拜稽首”，磕头。口气往上，动作往下，全在同一个人身上。作者没有一句评语，让两个信号撞在一起，读者自己看到这位管着民的云将，在一个拍大腿的人面前怎样一点点矮下去。

◆三、一个叹词，三次出场

这一次见面，鸿蒙才多说了几句，先是“浮游，不知所求……朕又何知”，仍然推开。再往下，他的话里三次出现同一个叹词：“意，治人之过也！”收在一段话的尾上，“意，毒哉！僊僊乎归矣。”“意！心养。”站在话头，像一个人叹了三口气，后面才接实话。这一声叹，把说理变成了人声，一个老者在对着不开窍的人叹气，嘴里说的是道理，气里带着不耐烦。云将问“然则吾柰何”，问的是怎么办，得到的先是“僊僊乎归矣”，回去吧，再是“心养”，养心。到了第三声叹息之后，话才有了做法的样子，而这做法是一串减法：“汝徒处无为，而物自化。堕尔形体，吐尔聪明，伦与物忘。”云将听完说：“天降朕以德，示朕以默；躬身求之，乃今也得。”再拜，辞行。一幕戏到这里收住，没有再多送一步。

◆四、读者身上

这一段读起来的张力，是熬出来的。云将问了又问，鸿蒙推了又推，读者夹在两个人之间，先替云将着急，再替他难堪，等到三年过去、云将“行趋而进”的那一刻，难堪变成了一点怜惜。放松来自“游！”和“吾弗知！”，这两个说法太干脆了，干脆到读者发笑。笑的时候，手里攥着的想把一切安排好的那口气，也跟着松了。

◆五、一千二百岁的广告

篇里另一个故事，黄帝求广成子，读起来就没有这份轻松。广成子说：“我守其一以处其和，故我修身千二百岁矣，吾形未常衰。”又说：“人其尽死，而我独存乎！”这几句已经近乎保健品讲座上的口气：我这么多年了，身板一直没衰过。一千二百岁不能被查验，“未常衰”也没有检验的办法，故事里黄帝先被骂走，回去“捐天下，筑特室”，闲居三个月，再来跪着膝行求教，先拒后授，门槛立得很高。

再用减法检验量一量。鸿蒙一段，抽掉“拊脾雀跃”，只剩“汝徒处无为，而物自化”这样一句话，它是可以判错的，你可以找一个地方，真的处无为，看物化不化。可是这一段承重的不是这句话，是画面，把画面抽掉，整段塌掉。政论部分的“举天下以赏其善者不足，举天下以罚其恶者不给”，反倒是一条可以数的论证，赏罚的规模赶不上人的数目。这一段有自己的力气，只是读完往往记不住。

再用类比的问法问“物自化”。这个词在目标域里的定义是什么？“云气不待族而雨，草木不待黄而落”是物的自行变化，可是人“处无为”的时候，物化要凭什么条件，篇里没有说。设想一块菜地，主人撒了种就彻底不管，不浇水，不除草，“物自化”之后，长出来的多半是草。这个类比只搬了“自化”的结果，没有搬种子、土和雨水这些条件，也没有搬无人照看的代价。反过来说“汝徒处有为，而物自乱”，同样顺耳，同样没人能验。至于它敢不敢说自己断在哪，鸿蒙那句“朕又何知”，还有前面两声“吾弗知”，是这件作品自己先说了不知道，这是它诚实的地方，只是诚实到这里为止。

◆六、问题怎样一格一格缩小

云将与鸿蒙这一段，是全篇里差异序列（D，一步一步变化的次序）写得最清楚的地方：问，不答，三年，再问，答一半，再问，叹，再问，终于有了做法。云将的问题也一格一格缩小，从“合六气之精以育群生”，缩到“吾遇天难”，从天下缩到自己。特征纠缠（E，几样特性缠在一起拆不开）是云将身上的：“朕”与“民之放也”缠着他的问题，他想问的是天下，该改的是他自己。显露（S，眼前摆出来的那一幕）是鸿蒙的跳。D 与 E 的矛盾这样累积，云将的问法才被逼得改。然而回写要被观察，不能被宣布：云将说“乃今也得”，作品没有再给一个镜头，让你看到他回去之后云气怎样。第486号已判这一篇写的是一个人怎样熬到肯放手。这里再量一量它的有效长度：管到云将转身为止。熬写出来了，放手之后的账没有。

◆七、翻转：吾弗知

后来的人把“吾弗知”用反了。它在作品里是一个不肯给答案的人，对一个想替天下拿主意的人的拒绝；到了会议室，成了“这事我不清楚”。

**说明书**
适用：想替别人把一切安排好、手伸得太长的时候，读鸿蒙那一段。
不适用：政论部分，可略；也不能当治理方案，堤要决了不能学鸿蒙。
回程：读完，把手上一件想替别人定下来的事，留到对方自己开口来问的时候再说。
