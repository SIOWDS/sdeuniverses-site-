# 第13章　马蹄：一幅田园画和一纸控诉

秀兰的超市门边贴着一排表：消防巡查表，冷柜温度记录表，食品留样表，价签核对表。每个月都有一拨人拿着另一张表来检查那几张表。贴得整整齐齐，没有一格空着。秀兰签字签到手腕发酸，有一回对着冷柜说：“你要是会说话，你来签。”老陆家的这个设想，放在这一篇旁边正合适，因为《马蹄》骂的就是这种整齐。

◆一、先画马，再画刀

《庄子》三十三篇里最短的一篇，开头是一幅画。“马，蹄可以践霜雪，毛可以御风寒，龁草饮水，翘足而陆，此马之真性也。”四个动作，一句一个，没有一个形容词，马只是在做它平常做的事。画还没有看够，镜头往外拉了一步：“虽有义台路寝，无所用之。”高台和大屋摆在马旁边，马不看它们，这一笔先把人类的堂皇摆到了马的对面。然后换人上场：“及至伯乐，曰：「我善治马。」”被告亲口说话，作者不替他辩，也不替他骂，只让他自夸这一句。

接下来的节奏全变了。前面是从容的长句，现在是一串短促的动词：“烧之，剔之，刻之，雒之，连之以羁馽，编之以皂栈”，每个字下去就是一刀，四个动作之后才转到“连”和“编”，从伤身转到了圈养。紧跟着是数字：“马之死者十二三矣”，再往下，“已过半矣”。数字出来的口气像验尸报告，一个寓言里突然冒出统计，冷得人不舒服。

◆二、三个行当，同一句话

下一步，作者把伯乐摆进一排人里。陶者说“我善治埴，圆者中规，方者中矩”，匠人说“我善治木，曲者中钩，直者应绳”，句子套的是同一个模子：我善治某，某被治成什么形。三行并排，读者自己看出来，“善治”原来是一句通用的自夸。然后一个反问把台下的人拎出来：“夫埴木之性，岂欲中规矩钩绳哉？然且世世称之曰：「伯乐善治马，而陶匠善治埴木。」”鼓掌的主语换成了世人。批评从伯乐转到了喝彩的那一排观众身上，这一转，把一桩驯马的案子转成了一桩制度的案子。

◆三、一幅没有人干活的画

篇的中段是第二幅画，至德之世。“山无蹊隧，泽无舟梁；万物群生，连属其乡；禽兽成群，草木遂长。”开头两句全是“无”，路没有，桥没有，后面才一件一件长出来。画里的人很少：“同与禽兽居，族与万物并”，人被画成了景的一部分，混在鸟兽之间，连“君子小人”也分不出来。这幅画的美，一半来自它什么都不做。随后六个反问连发：“纯朴不残，孰为牺樽！白玉不毁，孰为珪璋！道德不废，安取仁义！性情不离，安用礼乐！五色不乱，孰为文采！五声不乱，孰应六律！”从器物到仁义，再到文采六律，一路推倒，最后推到的是艺术本身。作者手里正握着最漂亮的排比，却在排比里把“文采”也算成了残朴的产物，这个自相矛盾，他自己没有回头看。

◆四、从马背上睡到被叫醒

读者先在马的画面里放松，在动词里被打了一下，在三个行当里点头，在田园画里睡了一觉，最后被首尾呼应的句子叫醒：开头是“此亦治天下者之过也”，结尾是“此亦圣人之过也”。控诉的力气，是靠这样一层层给被告加名号攒出来的。那一觉是整篇释放的地方，“含哺而熙，鼓腹而游”，嘴里含着饭笑，拍着肚子逛，是读者可以带回去的画。

◆五、画里没有瘟疫

现在抽掉马。抽掉以后剩下两条主张：治理要付出代价，世人却拿整齐当功劳；人本有“常性”，“织而衣，耕而食”，圣人的礼乐才把人弄坏。第一条站得住，而且可判错：你可以去数，一张表多花了多少人的工时，换回了什么。第二条就站不住了，因为“织而衣”这件事，本身是代代教出来的，马不会织布。类比的第二问，只搬结果，不搬条件，在这里最清楚：马的蹄毛是给定的，人的织耕是学来的，把学来的本事也算作“本性”，等于把后来者的功劳记到了天上。第四问，作品敢不敢说自己断在哪，这幅画没有回答，因为至德之世的画里，没有瘟疫，没有饥荒，也没有一条能把粮食运过山口的路，“山无蹊隧”的另一面，正是灾年里粮食进不来。

大白话一点，设想秀兰的冷柜温度记录表。她嫌烦，每天抄一遍，抄得像在勒自己。有一天冷柜坏了，翻开表，三天前的温度已经开始往上爬，这张表就是她最早的警报。这张表既是勒马的嚼子，也是账本。《马蹄》只让你看见嚼子。

◆六、嚼子和账本

画面是两幅：勒马的画和田园的画（显露，S）。篇里只有一串差异序列（D）是写足的，伤害的序列：“十二三”到“已过半”；好处的序列，一张表怎样一年年挡掉了几次事故，没有。最好的一笔其实是特征纠缠（E）那一句：“夫加之以衡扼，齐之以月题，而马知介倪𬮱扼鸷曼诡衔窃辔。故马之知而能至盗者，伯乐之罪也”，训练把马改成了会使坏的马，这一环是作品写下来的回写，写得极准；使坏的马会不会又成为再训的理由，原文没有说，那是读出来的。可是回写只被用在一个方向上。123 原理讲 D 与 E 的矛盾累积，逼 S 改变，S 的改变再回写，篇里只肯让它朝坏处转。

◆七、孤零零的一句“吾意”

篇里正面的方案只有一句“吾意善治天下者不然”，后面立刻转去画画，这个比例本身就是答案。“吾”是全篇唯一露面的“我”，作者在这里把自己的名字写得很轻，一带而过。控诉可以画满，方案必须结算，作品只管让你看见，不管替你结算。后人把它用反，是把“都是形式主义”当成口头禅，连冷柜那一张也不抄了。控诉的痛快被当成了免抄的许可，这是画被读成了令。

**说明书**
适用：被流程、表格、检查管得透不过气的时候，读开头那匹马。
不适用：冷柜真坏了，别拿它当不抄表的理由。
回程：挑一条具体的规章去改，比如把一张每天抄三遍的表并成一张，别去拆整个制度。
