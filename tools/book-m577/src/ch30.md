# 第30章　外物：车辙里的鲋鱼，和一只编给自己的笼

◆一、年底的三十万

有这样一个星期三。秀兰在机场附近开着一家小超市，周五要结一笔货款，账上差了一截，她硬着头皮给一位做生意的亲戚打了电话。亲戚在那头答得很痛快：“这个好说，等年底分红下来，我借你三十万。”她说了两声好，挂了电话，在货架中间站了一小会儿。亲戚这话并没有说谎，年底有分红，三十万也不是客套，他甚至是诚心的。问题只在于，这份诚心走的是一条要等到十二月的路。三十万比她缺的那一截大出许多倍，可是周五用不上，周六也用不上。她没有发火，也没有道谢，回到柜台后面，翻出那本赊账本，挑了欠得最久的三户，各打了一个电话。这样的电话，多数人接过，也打出去过。两千多年前，有人把同一场电话写了下来，放进《外物》，写得又短又狠。

◆二、两个“诺”，两张发怒的脸

原文交代难处只用一句：“庄周家贫，故往贷粟于监河侯。”监河侯的回答分两截：“诺。我将得邑金，将贷子三百金，可乎？”头一个字是应允，后面接连两个“将”，话从眼前一路滑进将来。借粮的人在第一个字上得到了答复，在其余的字上什么也没有得到。

庄周的反击不是驳论，是讲了一个故事。他说来的路上听见有人喊，回头看，车辙里躺着一条鲋鱼，求他：“君岂有升斗之水而活我哉？”接下来的一句要停一下：“周曰：‘诺。我且南游吴越之王，激西江之水而迎子，可乎？’”把它和监河侯的话并排放着看，一个“诺”开头，一个远大的打算居中（“将得邑金”对“且南游吴越之王”），一个“可乎”收尾，句型一模一样。怒气冲冲讲这个故事的人，在故事里借了监河侯的嘴，自己做了那个许诺的人。鲋鱼那张脸也是现成的：“鲋鱼忿然作色”，和讲故事的人开口之前的“庄周忿然作色”，是同样四个字，怒气从放贷的人传到讲故事的人，再传到车辙里的鱼，一层套着一层。鱼要的只是“斗升之水”，语言里能找到的最小的量，而且要在现在。最后一句“曾不如早索我于枯鱼之肆”，是一个干巴巴的笑话：与其听你说西江，不如早点到卖干鱼的铺子里来找我。故事到这里就停了，粟借到没有，一个字也没提。还有一个细节：开口说的是“周昨来”，昨天才碰上的事，带着刚出锅的热气。讲故事的人要的就是这点热气，好让听的人当成亲眼所见。

◆三、笑完以后手里剩了什么

读的人先笑。监河侯那两个“将”叠起来，谁都不陌生，笑得很顺，监河侯一共说了十几个字，庄周回敬的故事比它长出好几倍，用一个长故事拆开一句客气话，替庄周出的那口气，在鲋鱼开口时有了出口。等你听出“我且南游吴越之王”的口气和监河侯是一个模子，第二波才上来：笑的人被拉进了故事，自己也许过这样的诺。这一下没有出口，篇里也没有哪句话来收拾你。顺带交代一句取证上的本分：这是杂篇，出自门人与同人之手，写的是书里的庄子，监河侯有没有其人，庄周穷到什么份上，原文之外一概无从知道，故事只对读它的人负责。

再退一步看，“激西江之水而迎子”这种句子，和《逍遥游》里“抟扶摇而上者九万里”是同一路的语言，大，远，漂亮。写这篇的人懂这一点，所以把它放进许诺者的嘴里，让车辙里的鱼回敬一句。云上的话，这部书自己写下了它的反面，用的还是同一支笔。

◆四、五十头牛才下得一次钩

这口气还没喘匀，就接上了任公子。“任公子为大钩巨缁，五十犗以为饵，蹲乎会稽，投竿东海，旦旦而钓，期年不得鱼。”六拍，前四拍是器物和地理，钩大，饵大，山大，海大；后两拍转到时间，“旦旦”把一天叠成每一天，然后用“期年不得鱼”一刀切断，一整年，空手，五个字，不加评语。大鱼上钩以后，镜头不给鱼身，只给海：“牵巨钩錎没而下，骛扬而奋鬐，白波若山，海水震荡，声侔鬼神，惮赫千里。”写鱼大，是写海被它弄成了什么样。最后的账算在地图上：“自制河以东，苍梧已北，莫不厌若鱼者。”腌成鱼干，一块地方的人吃腻了。

随后一句是嘲讽：拿细竿守在水沟边，看着小鱼，再“饰小说以干县令”，离通达还远得很。今天的对应物不难找：把一点小成绩包装成漂亮的故事，递到能批预算的人面前，故事未必假，笼里却没有鱼。“小说”在这里是把小话修饰一番，去求县令的青眼，鲁迅在《中国小说史略》里就把它当作这个词的较早用例，只是当时指的是琐碎的小话。有意思的是，骂小说的这几行，自己就长在一个故事后面，故事里写的是钓一条鱼要花多少。第486号读出任公子是篇里最勤的人，本书接着问的是，这只钩是谁编的：它不在海里，在那六拍的节奏里。

◆五、嘴里含珠的人

再往下是“儒以《诗》、《礼》发冢”。这一则全靠传话撑起来：大儒在上面“胪传”，小儒在下面报告。大儒问：“东方作矣，事之何若？”天快亮了，手脚怎么样。小儒答：“未解裙襦，口中有珠。”然后他背了一句诗：“青青之麦，生于陵陂。生不布施，死何含珠为！”原文说“《诗》固有之曰”，这两句不见于今本《诗经》，一般视作逸诗。这是一句责备富人的诗，嫌他活着不肯舍，死了还含着珠子。小儒把它当成开工令来背。后面的指令细得像手术：“接其鬓，擪其顪，儒以金椎控其颐，徐别其颊，无伤口中珠！”一排人只管传话，每个人只对自己那一句负责，没有人对整件事负责。按住鬓角，压住下巴，金锤轻轻敲开下颌，慢慢分开两颊，别伤了嘴里的珠。“徐”字最毒，动作越轻，越像在行礼。诗和礼在这里都做得到位，用处是撬开一张嘴。黑色喜剧的笑点在于，那句责备贪婪的诗，被用来合法地拿走贪婪的那一份。

◆六、三块一样大的砖

紧挨在前面的一则，是演门那个守丧守出了官位的人：“演门有亲死者，以善毁爵为官师，其党人毁而死者半。”哀毁得过分的人被封了官，同乡便学他，学到一半的人把命学没了。他们学的是形，丢的是哀，这是“得荃而忘鱼”的现成样本。接下来压轴的三句，排得像三块同样大小的砖：“荃者所以在鱼，得鱼而忘荃；蹄者所以在兔，得兔而忘蹄；言者所以在意，得意而忘言。”荃是捕鱼的竹笼，蹄是兔套。前两块是看得见摸得着的东西，读者点头；第三块的句式纹丝不动，里面的东西却换成了他此刻正在使用的这一样。接着是一个叹出来的问句：“吾安得夫忘言之人而与之言哉！”

先做减法检验。把荃和蹄这两个比方抽掉，剩下的主张是：话是为意而设，意到手，话可以放下。这个主张立得住，但立在一个没有说出口的前提上：话和意可以像笼子和鱼那样分开。再问类比四问里的第二问，只搬结果，还是连条件和代价一起搬。笼子和鱼，一个有形，一个可吃，吃鱼的时候用不着笼子。意在没有话的时候是不是还在，原文没有交代，搬过来的只有“笼子可以放下”这个结果。第三问，反过来说顺不顺耳。“得荃而忘鱼”同样顺耳，因为这正是后来发生的事。设想看一场电影，哭得稀里哗啦，走出影院，剧本、镜头、台词一概模糊，只剩一口气。哭是鱼，几分钟就吃完了。可是下个月你还会想再看一遍，因为荃还在，鱼要靠它再来一次。第四问，它敢不敢说自己断在哪。这一问，恰好由最后那个叹词替它答了：说“忘言”的人，仍然在说话，还想找一个忘言的人来听。比起那条鱼，这个叹词是更诚实的边框。

◆七、一斗一升隔着几道“将”

到这里，才让三大方程进场。它们是三个互相牵着的式子，S=F(D,E)，D=G(S,E)，E=H(S,D)。S 是显露，就是摆出来让人看见的那一下；D 是差异序列，一步一步分出来的先后；E 是特征纠缠，一个人和周围人事拉扯成的那张网；F、G、H 只表示彼此牵着，不能拿来算数。监河侯那个“诺”是一个漂亮的显露，可是从“将得邑金”到“将贷子三百金”，中间的先后他一步也没有走，他自己的邑金也还系在别人手里，三个式子，他只动了第一个。鲋鱼要的是另外两个先站住：一个零步的序列，水就在车辙里；一张没有散的网，它说“吾失我常与”，平日靠着的那些没了，所以“我无所处”。这里要把话说准：监河侯未必是骗子，他的邑金说不定年底就到。三个式子没有同时站住，用不着坏心，一个答应得太轻的人就够了。

123 原理说的是，D 和 E 之间的矛盾累积起来，逼 S 改变，S 的改变再回写 D 和 E。鲋鱼这一边，矛盾到了顶，显露改了，从求水变成了发怒，这是原文看得见的。回写应当是有人舀来一瓢水，原文没有写。秀兰的电话倒是留下了痕迹：设想她放下电话，翻开赊账本，显露从指望三十万改成催小数目，账本上的先后也跟着排过了，回写落在了纸上。

再看起手的次序。秀兰这件事的卡点在差异序列：哪天缺多少，谁的钱哪天到。该从 D 起手，再看 E，这家铺子欠谁、谁欠它，最后才轮到 S，打哪个电话。亲戚的答复是从 S 起手的，先给一个宽厚的姿态，序列和网都没碰。这个错位没有提示音，只让人越听越觉得有面子。

◆八、三只笼子，一条鱼

回头看这一排。任公子的笼：钩和饵就是为了那条鱼，“荃者所以在鱼”。“饰小说以干县令”的笼：拎着去见县令，笼里没有鱼。儒的笼：诗和礼拿去撬一张嘴，笼里装的是别人的珠子。三个故事挨在一起，不是凑巧，是同一只笼的三种用法，区别只在笼子是为哪条鱼编的。再往后还有一只编得更精的：宋元君的龟甲，“七十二钻而无遗䇲”，七十二次没有一次落空。那是这一篇里难得给了人下一步动作的答复，元君拿不定主意要杀要放，占卜的回话是“杀龟以卜吉”，于是龟被剖了，孔子在旁边评一句：“知能七十二钻而无遗䇲，不能避刳肠之患。”最灵的笼子，替编笼子的人办完了事，也把鱼办掉了。

这样读，全书判语在这一篇里找到了落脚处。他教的是得鱼忘荃，他靠的是编荃。两千年过去，鱼吃完了，荃还在。鲋鱼的句子能被一代代人背下来，靠的是两个“诺”对着的句型和叠着传下去的“忿然作色”，这些都是编出来的篾条；而背它的人大多拿它去敲别人的门。庄周借粮借没借到，早已无人关心，那只笼子却结实得很。秀兰那三个电话也是这个尺寸，打出去的是最小的几笔，三十万留在了十二月。书里的话同样，到手的只有斗升之水，其余的归了云。

**说明书**
适用：被一个“将来”打发了的时候，读涸辙之鲋，读到“斗升之水”停下来。
不适用：不能拿它当对亲戚、对放贷人说话的底气，笼子替你出了气，没有替你借到粟。
回程：翻出一件别人答应了你、至今还只是答应的事，换成一个这周内能到手的最小数目，去问一句。
