# 第19章　刻意：五个“而已矣”，和一把没出鞘的剑

◆一、一人一句，五个“而已矣”

篇首五句，句式一模一样：“刻意尚行，离世异俗，高论怨诽，为亢而已矣；此山谷之士，非世之人，枯槁赴渊者之所好也。”后面四句只换内容，句尾轮流是“为修而已矣”“为治而已矣”“无为而已矣”“为寿而已矣”。五种体面的活法，被一个“而已”各削成一个目的，削得很干净，看得出作者眼力。日子里也常见：饭局是为了谈事，菜上得再好，桌上谁也没吃出味道，饭成了一块垫板。接下来是回答：“若夫不刻意而高，无仁义而修，无功名而治，无江海而闲，不道引而寿”，五个“不”和“无”，一一对折前面的五句。理想的人，是五个减号。再往后，“无不忘也，无不有也，澹然无极而众美从之”，画面就没有了。全篇像样的东西只有一件：“夫有干越之剑者，柙而藏之，不敢用也，宝之至也。”一把关在匣子里的剑，赞的是不出鞘。

◆二、读完手里什么也没有

这一篇里没有一个人开口。《天地》里的丈人至少会又怒又笑，这里的五种人只被列举，没有被碰撞过。读的人每一句都点头：“光矣而不耀，信矣而不期”，“其寝不梦，其觉无忧”，句子漂亮，贴在任何一面墙上都合适。设想有人把“光矣而不耀”打印出来贴在工位上，同事路过，谁也看不出这是谁的座位。能贴在任何墙上的话，不属于任何一面墙，这正是它读来像今天的鸡汤的原因。用减法检验，这篇没有东西可抽，水和剑两个比喻抽掉，论点照样站着，因为论点本来就不靠它们站，坏处不在比喻，在整篇找不到一个人、一件事可以拿来对证。画面在的那一处，作品还能自己撤回：“水之性，不杂则清，莫动则平；郁闭而不流，亦不能清”，下一行却写“静一而不变”。有水在，它还能给自己打补丁，水一走，就没有人拦它。

◆三、五个减号怎么算账

字母在这篇里好认，因为只有一个字母在干活。显露（S，画出来的那幅像）堆得很满，“恬惔寂漠虚无无为”，差异序列（D，一步一步差在哪）里一步也没有，特征纠缠（E，缠着它的人和事）被自己宣布取消，“不与物交，淡之至也”，三式里于是只有第一式在说话。123 原理要靠 D 与 E 的矛盾逼 S 改变，这里悲乐、喜怒、好恶这些矛盾发出的信号，被逐个判成“德之邪”“道之过”“德之失”，等于取走了第二拍的燃料，回写无从观察。路径上，起手是画像，终点还是画像；五种人的毛病明明是目的压过了手段，该从 D 起手去看，这一篇没有走。它把病看得准，药方是一幅看不出怎么走进去的像。

**说明书**
适用：可略。只在想认出自己或身边“为……而已”的姿态时，读头一段。
不适用：把后面那幅画像当作要做到的状态。
回程：对照那五句，找出自己做得最久的一件事，写下一句“我是为了什么在做它”。
