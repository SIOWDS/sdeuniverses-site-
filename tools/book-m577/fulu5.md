# 附录五　参考书目与核验说明

## 核验说明

《庄子》引文据 Kanripo 汉籍库本（KR5c0126）用程序逐条核过，个别用字依通行写法（如“般礴”，此本作“槃礴”；《天运》此本作“吾始闻之而惧”）。《墨子》据 Kanripo 本（KR3j0002）核过《小取》与《经下》。苏轼《庄子祠堂记》、《赤壁赋》和《宋史》本传那句话，据 Kanripo《东坡全集》（KR4d0076）核过。《庄子祠堂记》原文是：“然余尝疑《盗跖》《渔父》，则若真诋孔子者；至于《让王》《说剑》，皆浅陋不入于道。”

其他古籍（《论语》《史记》《天工开物》、陶渊明诗文等）按通行本录入，部分未对照外部原本。现代学者一律转述。下面几位读得不够，书里已写明：周国平的书只读到报道；Hansen 的路线多来自二手概述；肖鹰读到论文与摘要；Moeller 与 D’Ambrosio 只读了出版说明和目录；Eno 只核到书目；闻一多的说法据通行转述；徐复观“独生子”一语据章启群文章的引述。
