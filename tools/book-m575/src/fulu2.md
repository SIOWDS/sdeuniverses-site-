# 附录二　两句话的原文、上下文与版本

说明：下列古文和经文都按本书所据的原文库逐字抄出，经文用和合本；个别条目按通行本录入，引用时请对照自己所用的版本。每条后的小注只说它在书里的位置，不替原文加解释。

## 一、《论语》（章号按杨伯峻本）

第一句话在《论语》里出现两次，一次在仲弓问仁，一次在子贡问一言。先看仲弓问仁，请连着前后两句一起读，因为书里的读法正是从这句话被砍掉的头和尾开始的。

**12.2**

仲弓问仁。子曰：“出门如见大宾，使民如承大祭。己所不欲，勿施于人。在邦无怨，在家无怨。”仲弓曰：“雍虽不敏，请事斯语矣。”

第一句话的出处之一。前一句把使唤别人的人放到“大宾”“大祭”的位置，后一句看对方有没有怨。

**6.1　雍也可使南面**

子曰：“雍也可使南面。”

仲弓是将要管人的人。

**6.6**

子谓仲弓曰：“犁牛之子骍且角，虽欲勿用，山川其舍诸？”

孔子谈到仲弓，字句按通行本录入。

**15.24**

子贡问曰：“有一言而可以终身行之者乎？”子曰：“其恕乎！己所不欲，勿施于人。”

同一句话，这里被子贡问成“一言而可以终身行之”。

**5.12**

子贡曰：“我不欲人之加诸我也，吾亦欲无加诸人。”子曰：“赐也，非尔所及也。”

子贡自己说出几乎同样的话，孔子的回答是“非尔所及”。

**6.30**

子贡曰：“如有博施于民而能济众，何如？可谓仁乎？”子曰：“何事于仁！必也圣乎！尧舜其犹病诸！夫仁者，己欲立而立人，己欲达而达人。能近取譬，可谓仁之方也已。”

孔子称它是“仁之方”，打比方，指方向。

**12.1**

颜渊问仁。子曰：“克己复礼为仁。一日克己复礼，天下归仁焉。为仁由己，而由人乎哉？”颜渊曰：“请问其目。”子曰：“非礼勿视，非礼勿听，非礼勿言，非礼勿动。”颜渊曰：“回虽不敏，请事斯语矣。”

同一组问仁，颜渊得到的回答。

**12.3**

司马牛问仁。子曰：“仁者，其言也讱。”曰：“其言也讱，斯谓之仁已乎？”子曰：“为之难，言之得无讱乎？”

同一组问仁，司马牛得到的回答。

**3.15**

子入太庙，每事问。或曰：“孰谓鄹人之子知礼乎？入太庙，每事问。”子闻之，曰：“是礼也。”

孔子自己入太庙，每事问。

**11.22**

子路问：“闻斯行诸？”子曰：“有父兄在，如之何其闻斯行之？”冉有问：“闻斯行诸？”子曰：“闻斯行之。”公西华曰：“由也问闻斯行诸，子曰‘有父兄在’；求也问闻斯行诸，子曰‘闻斯行之’。赤也惑，敢问。”子曰：“求也退，故进之；由也兼人，故退之。”

同一个问题，两个人，两个答案。

**4.15**

子曰：“参乎！吾道一以贯之。”曾子曰：“唯。”子出，门人问曰：“何谓也？”曾子曰：“夫子之道，忠恕而已矣。”

曾子对门人讲“忠恕”。

**9.4**

子绝四：毋意，毋必，毋固，毋我。

弟子记下的孔子四个“毋”。

**11.19**

赐不受命，而货殖焉，亿则屡中。

记子贡善于揣度。

**14.29**

子贡方人。子曰：“赐也贤乎哉？夫我则不暇。”

记子贡“方人”，字句按通行本录入。

**14.43**

原壤夷俟。子曰：“幼而不孙弟，长而无述焉，老而不死，是为贼。”以杖叩其胫。

孔子对原壤，言语之外还动了手杖。

**2.5—2.8　问孝**

孟懿子问孝，子曰“无违”；子游问孝，子曰：“今之孝者，是谓能养。至于犬马，皆能有养；不敬，何以别乎？”子夏问孝，子曰：“色难。”

同一个“孝”字，三个人，三种回答，书里用它说明信息的三个维度可以不同步：字很稳，答案各不相同。

**朱熹《论语集注》5.12 章**

程子曰：“我不欲人之加诸我，吾亦欲无加诸人，仁也；施诸己而不愿，亦勿施于人，恕也。恕则子贡或能勉之，仁则非所及矣。”愚谓无者自然而然，勿者禁止之谓，此所以为仁恕之别。

这是后世对“无”与“勿”之别的读法，书里先接住，再多走一步。

**子贡庐墓**

《史记·孔子世家》：“唯子赣庐于冢上，凡六年，然后去。”《孟子·滕文公上》：子贡“筑室于场，独居三年，然后归”。

两处记载的年数不同（六年、三年），这里并列照录，不替它们定论。

**仲弓出身**

《史记·仲尼弟子列传》：“仲弓父，贱人。”只作“旧说”。

这只是旧说，不作定论。

## 二、《中庸》《大学》

**《中庸》第十三章**

忠恕违道不远，施诸己而不愿，亦勿施于人。君子之道四，丘未能一焉：所求乎子，以事父，未能也；所求乎臣，以事君，未能也；所求乎弟，以事兄，未能也；所求乎朋友，先施之，未能也。

第一句话在这里的样子是“施诸己而不愿，亦勿施于人”，后面紧跟着孔子的四个“未能”。

**《大学》传十章**

所恶于上，毋以使下；所恶于下，毋以事上；所恶于前，毋以先后；所恶于后，毋以从前；所恶于右，毋以交于左；所恶于左，毋以交于右：此之谓絜矩之道。

六个“所恶于”，每一个都是一个位置。

## 三、圣经（和合本）

这里只读语言处境和做法，不作神学判断。

**利未记 19:18**

不可报仇，也不可埋怨你本国的子民，却要爱人如己。我是耶和华。

“爱人如己”的出处，上下文是邻舍之间的相处。

**利未记 19:34**

和你们同居的外人，你们要看他如本地人一样，并要爱他如己，因为你们在埃及地也作过寄居的。我是耶和华你们的神。

对外人的理由是“你们在埃及地也作过寄居的”，理由是位置。

**出埃及记 23:9**

不可欺压寄居的，因为你们在埃及地作过寄居的，知道寄居的心。

同一类理由。和合本修订版作“知道寄居者的心情”，两版的字句略有出入，书里两版都可提。

**申命记 24:18**

要记念你在埃及作过奴仆。耶和华你的神从那里将你救赎，所以我吩咐你这样行。

“要记念”，因为轮过位的人会忘。

**马太福音 5:17**

莫想我来要废掉律法和先知。我来不是要废掉，乃是要成全。

马太 7:12 句尾“律法和先知的道理”与这一节呼应。

**马太福音 7:1**

你们不要论断人，免得你们被论断。

同一章开头的话。

**马太福音 7:7—14**

你们祈求，就给你们；寻找，就寻见；叩门，就给你们开门。因为凡祈求的，就得着；寻找的，就寻见；叩门的，就给他开门。你们中间谁有儿子求饼，反给他石头呢？求鱼，反给他蛇呢？你们虽然不好，尚且知道拿好东西给儿女，何况你们在天上的父，岂不更把好东西给求他的人吗？所以，无论何事，你们愿意人怎样待你们，你们也要怎样待人，因为这就是律法和先知的道理。你们要进窄门。因为引到灭亡，那门是宽的，路是大的，进去的人也多；引到永生，那门是窄的，路是小的，找着的人也少。

第二句话在马太里的位置：前面是祈求、寻找、叩门和天父给好东西，后面紧接窄门。“你们”是复数。通常把 7:13 以下划入下一段，这里连着抄，以便看出“所以”前后。

**路加福音 6:20、6:22　听众**

耶稣举目看着门徒，说：“你们贫穷的人有福了！”“人为人子恨恶你们，拒绝你们……你们就有福了！”

路加里这句话的听众。

**路加福音 6:27—38**

只是我告诉你们这听道的人，你们的仇敌，要爱他！恨你们的，要待他好！咒诅你们的，要为他祝福！凌辱你们的，要为他祷告！有人打你这边的脸，连那边的脸也由他打；有人夺你的外衣，连里衣也由他拿去。凡求你的，就给他；有人夺你的东西去，不用再要回来。你们愿意人怎样待你们，你们也要怎样待人。你们若单爱那爱你们的人，有什么可酬谢的呢？就是罪人也爱那爱他们的人。你们若善待那善待你们的人，有什么可酬谢的呢？就是罪人也是这样行。你们若借给人，指望从他收回，有什么可酬谢的呢？就是罪人也借给罪人，要如数收回。你们倒要爱仇敌，也要善待他们，并要借给人不指望偿还，你们的赏赐就必大了，你们也必作至高者的儿子；因为他恩待那忘恩的和作恶的。你们要慈悲，像你们的父慈悲一样。你们不要论断人，就不被论断；你们不要定人的罪，就不被定罪；你们要饶恕人，就必蒙饶恕。你们要给人，就必有给你们的，并且用十足的升斗，连摇带按，上尖下流地倒在你们怀里；因为你们用什么量器量给人，也必用什么量器量给你们。

第二句话在路加里的位置是 6:31，夹在爱仇敌、被打脸、被夺衣与“就是罪人也……”之间，后面是“不要论断人”。这句是肯定，还是将被超越，解经有争议（利科讨论过），本书不当作已定论。

**马可福音 10:51**

耶稣说：“要我为你做什么？”

耶稣问瞎子。

**路加福音 18:41**

“你要我为你做什么？”

同一件事在路加里的说法。

**约翰福音 5:5—7**

在那里有一个人，病了三十八年。耶稣看见他躺着，知道他病了许久，就问他说：“你要痊愈吗？”病人回答说：“先生，水动的时候，没有人把我放在池子里；我正去的时候，就有别人比我先下去。”

耶稣问病了三十八年的人。

**约翰福音 13:6—9、14**

挨到西门彼得，彼得对他说：“主啊，你洗我的脚吗？”耶稣回答说：“我所做的，你如今不知道，后来必明白。”彼得说：“你永不可洗我的脚！”耶稣说：“我若不洗你，你就与我无分了。”西门彼得说：“主啊，不但我的脚，连手和头也要洗。”……“我是你们的主，你们的夫子，尚且洗你们的脚，你们也当彼此洗脚。”

彼得的“不欲”在相遇里翻转。

**马太福音 26:39**

我父啊，倘若可行，求你叫这杯离开我；然而，不要照我的意思，只要照你的意思。

在“我的意思”和“你的意思”之间。

**创世记 3:5**

你们便如神能知道善恶。

“如神能知道善恶”。

## 四、两句话的两个样子

第一句，否定式，在本书里叫“勿施”：《论语》12.2 和 15.24 作“己所不欲，勿施于人”，《中庸》第十三章作“施诸己而不愿，亦勿施于人”。第二句，肯定式，在本书里叫“要待”：马太 7:12 和路加 6:31 作“你们愿意人怎样待你们，你们也要怎样待人”，两处的上下文、听众和紧邻的话都不同，上面已逐一列出。《论语》5.12 里子贡说的“我不欲人之加诸我也，吾亦欲无加诸人”，字句与第一句又有差别，书里分开对待。
