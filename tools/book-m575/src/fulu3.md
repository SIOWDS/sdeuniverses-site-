# 附录三　近邻与撞车账

一本书不是从空地上长出来的。这一份账登记两类邻居：站内前作，站外学者。每家写两件事：它看对了什么，本书多走了哪一步。写法的规矩是先接住，再说多走的那一步。站内的每一本，转述都以它的母题卡和正文为据（第549号没有母题卡，依据的是书的序、目录和正文），不超出那里写的内容，细节以原书为准。“撞车”的意思是：有几处，别人的话和本书的话几乎是同一句，本书要认账，不能装作是自己最先说的。

## 一、站内

| 号与书名 | 它看对了什么 | 本书多走哪一步 |
|---|---|---|
| 第255号《SDE价值发生学》 | 价值不是一个数，是一次发生。它把一件东西切成四刀（显出的样子、组织的分量、缺与接住缺的信息、走出来的路），四家价值学说各切对了一刀，错在把一刀当成整根萝卜。它还说意义是母，名字、道理、样式三态的信息是接生。 | 本书取第三刀，也就是意义与信息，作主刀，拿它去问一对具体的话：这两句话只查“愿不愿”，不查“为了什么”。其余两刀，位置和力气，在第三编末尾牵回来。第255号里关于文明的那段读法，本书不引。 |
| 第217号《价值发生论》（王德生、付自文） | 真善美不是早就摆在那里、等人去发现的标准，而是意义三律运行结出的三种力之果；价值是意义的局部定型，意义才是源头；把价值果当成意义果，就是伊甸园里的错认。 | 本书把这个判断用到一对每个人都会背的话上，并加了两件事：一是意义不清时价值没有显露，善恶不能判（定义域）；二是句子一字不改，只动一个变量，善就翻成恶（翻转）。第217号用的是较早的口径，本书只转述它的大意，不照搬它的术语。 |
| 第549号《今天的善为何很难发生了？》 | 善是发生，不是现成的善心或良知；今天的技术世界里，善难以发生，因为有三道堵：逻辑把自由律吃掉了，人人只算自己的最小亏损，事事先评估再动手。书里一再强调它的人物和场景是构想的，也说明没有独立评审。 | 第549号问的是善为什么发生不了，本书问的是好心的善为什么会变成恶，而且是同一个动作、同一句话。两本书的碰面处在第五编的公共几章：那里的算法和“事前评估”，是第549号三道堵的近亲。 |
| 第271号《耶稣之善》 | 善不是藏在一个人身上的固有属性，是在具体关系、自由回应和实际苦难里显露出来的；“他本来就善”这句话方便交往，也遮住了善赖以成立的过程。 | 本书把这个提醒的另一头也拿下来：一句话本身无善无恶，所以“这句话是黄金”同样是一个遮住过程的称谓。读耶稣只读语言处境和做法，不作神学判断；第271号和下面的第301号都用过这些经文，本书接着它们读，不改它们的读法。 |
| 第514号《累的发生学》 | 有一类累不是力气用完，而是一轮活动的结果进不了可理解、可调整的后续关系；觉察、报告、疲劳存在是三个时点；它自己声明不是独立的诊断。 | 本书借它“累不一定是力气用完”这一点，用到孩子嘴里的一个“累”字：拆开看里面是困、卡、烦、怕中的哪一束，再决定接什么。本书同样不作诊断；连续几周都累，要找医生。 |
| 第452号《谁在给善记账》 | 善在人与人之间显露，学校的账法只给名次留页，不让被记的人改账法，善就被折成了名次；缺的是一页账，和一支被记的人也能拿起来的笔。 | 本书把“笔在谁手里”搬到家里和两句话上：施方记的是自己的欲，受方的读数没有地方记。第51章因此要在饭桌上给受方留一页。 |
| 第433号《情绪价值发生学》 | 安慰透支，不是因为不够用心，而是它把自己的舒适写进了衡量舒适的尺子，又没有留下改回的口子；区分增值与透支的是回写能不能返回。 | 本书只取它“要留改回口子”的意思，用到“别难过了”这一类安慰，以及整本书最后的几条用法；它的数量化构念，本书没有搬。 |
| 第508号《何谓公平？》 | 公平不是统一性，是同一性谱系：统一的是到达，不是输入；谱系是一串随差异显露又彼此牵连的形态；谁在整串谱系里始终被关在意义门外，就是不公平（铁门）。 | 本书把这条谱系拆成符号、逻辑、数学三条，拿去量“己所不欲”：同字不同指，同理不同推，同到达不同量。第20章还要登记一个问题：对称算子与不对称关系，谱系是否都装得下。 |
| 第245号《何谓中华，中国，中庸？》 | “中”是命中，不是居中，是一辈子练出来的；一次偏差是消息，它改变下一次的起手。它读《中庸》“施诸己而不愿，亦勿施于人”时，指出这句话藏着一个前提，我的心和你的心大体相同，日子里常常不成立，于是给忠恕补了一小步：先替对方站一站，再当面问一句“你是怎么想的”，并自己写明这一步文本里没有。 | 本书接这一小步，多走三处：问什么（不问结论，问序列和账，因为孩子的欲常和大人的欲一致）；问之前先判他的意义清不清；问到的话是读数不是判决。偏差这条消息由谁来读，也是本书追问的：施方自己读，读到的永远是“我是为你好”，要由受方的读数送回来，这就是书里反复回到“在邦无怨”的原因。 |
| 第312号《一的原材料库》 | 《论语》是随提问者变化的现场记录，同问异答是调参，不是矛盾；它把仁读成互认和位置互换，把“己所不欲”读成换位的第一次演练。 | 本书把调参律用回这一句：仲弓、子贡、颜渊各得到不同的回应。本书多说一步：换位只在轮过位的人那里有料，而且只靠想象换位不够，读数要由对方给。 |
| 第313号《一的宪章》 | 《中庸》是立法文件，不只是教诲；它把忠恕当作输送既定之一的传输办法，发展做到极致。 | 本书只取第十三章里“丘未能一焉”的四个“未能”，读成四个位置（子、臣、弟、朋友），问：传输一路送下去，受方那一头有没有读数。 |
| 第314号《一的总装线》 | 《大学》是总工艺文件，不只是修身励志；絜矩一章被它读成一把尺子的两种命运。 | 本书把“所恶于上”到“所恶于左”六个向度读成六个位置，并问：尺子本身没错，没轮过那个位置的人拿它去量，量出来的是什么。 |
| 第301号《我是道路、真理、生命》 | 福音书里读起来互相矛盾的地方，多半不在耶稣身上，在量他的尺子只有一个刻度；它的判语是无缺、无偏、无中心。 | 本书只读与两句话相关的几处经文，不作神学判断。多走的一步是把耶稣的问法摆出来：问瞎子“你要我为你做什么”，问病人“你要痊愈吗”，他教的是“你愿意”，靠的却是“你要什么”。 |

## 二、站外

| 学者与文献 | 它看对了什么 | 本书多走哪一步 |
|---|---|---|
| 赵汀阳《论道德金规则的最佳可能方案》（《中国社会科学》2005年第3期） | 传统金规则要成立，需要人际共识和价值共识，里头藏着“主体观点霸权”；他改成“人所不欲，勿施于人”，把立足点从自己换到他人。 | “人所不欲”仍然是欲。孩子此刻很可能就想要：“妈，你帮我写吧。”他的欲和妈妈的欲一致，问他也白问。本书把靶子从欲挪到意义，并且把读数由问一次变成看一段序列。 |
| 王庆节《道德金律的“主体观点”与“他人观点”》 | 对等互惠不保证道德（两个腐败官员互相行贿）；“所有人的观点”近乎上帝之眼，人做不到。 | 本书同意互惠不够，再问一步：就算互惠成立，对着什么判善恶。答案是对着意义，创造、自由、幸福，这是书里明写的设定，不是从推导里得来的。 |
| 邓晓芒《全球伦理的可能性——金规则的三个模式》 | 金规则把“所欲相同”当作未经思考的前提，在血缘共同体内有效，范围一扩大就难以适用；他把它分成儒家犹太教、基督教、康德三个模式。 | 本书把“范围一大就难用”落成一条可看的东西：窄段和宽段。不想被杀被抢，人人差不多；穿什么、怎样面对死亡，差别很大。本书没有走向康德那种高度抽象的方案。 |
| 柯华庆《“己所不欲，勿施于人”是普世准则吗？》 | 它预设人人相同，不适用于市场社会，反映的是家长制伦理；他提出“己所不欲，慎施于人”。 | “慎”还是施方的谨慎。本书补的是受方一侧的读数，让“在邦无怨，在家无怨”那一句回来。 |
| 韩东屏《为“金规则”辨》（《伦理学研究》2003年第1期） | 许多批评打在误读上，他辨析了四类误读，为金规则辩护。 | 本书不为它辩护，也不否定它：先认它的四样功劳（止手、开手、借条、兜底），再问它在哪一段上翻。 |
| Robert Allinson, “Hillel and Confucius”, *Dao* 2003 | 否定式比肯定式谦逊，防好心伤人，尊重自主；他不认为两式等价（例：给素食者端肉）。 | 本书同意两式不等价，并补一点：否定式也能作恶，“勿施”可以把别人的路关上（瞒病，袖手）。两式翻转的方向不同。 |
| Paul Ricoeur, “The Golden Rule: Exegetical and Theological Perplexities”, *New Testament Studies* 36(3), 1990 | 路加 6:31 有两种读法：肯定，或引来待驳；金律与“礼物的经济”也有关联。 | 本书接他的争议，登记在案，不装作已有定论；多补一件事：这句话夹在爱仇敌与“罪人也是这样”之间，听的人是穷人和被恨恶的人。 |
| Eyal, Steffel, Epley, “Perspective Mistaking”, *JPSP* 2018 | 25个实验：要求人“设身处地”并不能普遍提高准确度，总体甚至略降，有时还提高了信心；直接通过对话得到对方的想法才提高准确度。 | 这是本书“换位不够”的最重一块砖。本书多走的是：把对话的结果变成一份读数，由受方给，施方事后才能据此调整；而且要留下改回的口子。本书自己没有做任何实验。 |
| Ruttan, McDonnell, Nordgren, “Having ‘Been There’ Doesn’t Mean I Care”, *JPSP* 2015 | 经历过某种困境并扛过来的人，对另一个没扛住的人判断更严苛，比没经历过的和正在经历的人都严，自己还预料不到。 | 本书用它拆“人轮此位”：轮过位不等于仁慈，还要有记念和回写。“我当年也这么熬过来的”的苦，就在这里。 |
| Ken Binmore, “How and Why Did Fairness Norms Evolve?”, *Proceedings of the British Academy* 110, 2001 | 公平习惯在演化中扎得很深，我们常常照做而不知其故；当自己也可能落在队尾时，先到先得就不那么吸引人了。 | 这是“人轮此位”的一个旁证，本书把位置当作两句话灵验的第二层解释。多走的是：位置轮过，记念和回写丢掉，灵验就没了。 |

## 三、顺带点到的

下面几家在书里只点名，不引字句：康德（脚注里批评金律，举罪犯可据此要求法官释放他的例子）、莱布尼茨（更早回应过囚犯这种反驳，法官要站到所有相关者的位置上）、萧伯纳（别人怎样待你，你愿意，别照样待人，他们的口味可能不同）、黄玉顺（金规则是规范不是原则，可损益）、王钧林（否定式是最低限度的道德要求，肯定式容易变成“己所欲，施于人”）、Harry Gensler 与 Jeffrey Wattles（为金律辩护）、Dan Flores（准确想象他人的位置做不到）。他们每一位都看对了一块，本书读完他们，更相信这句话值得认真对待。
