# 第5章　一块焊死的金

◆一、摆得好看的那盘菜

县城里新开了一家简餐店，这是构想的场景。门口立着一块灯箱，上面是招牌菜的照片：一尾鲈鱼卧在盘子正中，葱丝细细地沿着鱼身左右铺开，两边各摆一朵西兰花，盘沿一圈酱汁画得像个整整齐齐的圆。路过的人看一眼，心里立刻有了三句话：这个好看，这个一定好吃，这个吃了对身体好。三句话几乎是一起到的，连先后都分不出来，像一句话的三个字。

可是把这三句话慢下来，就会发现它们问的是三件不同的事，要用三种不同的办法去查。好看，用眼睛查，照片就够了。好吃，要用舌头查，得有人把鱼夹进嘴里，咸淡、火候、鱼新不新鲜，灯箱上一样也看不出来。吃了对身体好不好，又是另一回事：同一盘鱼，端给正在控盐的老人，端给刚打完球的少年，端给胃里不舒服、只想喝口热粥的孩子，答案各不相同，要对着吃的人和他吃这顿饭的缘由才能查。摆盘摆得再整齐，对第二个问题只是轻轻地暗示，对第三个问题一个字也没说。

馆子老板比许多人更清楚这一点：他把盘子摆正，不是为了让鱼更好吃，是知道客人会替他把好看算成好吃。会做饭的人家倒常常反过来，端上桌的红烧肉黑乎乎，一点不上相，吃的人却一口接一口。好看和好吃分得开，开店的和做饭的都知道，只是谈起道理来，我们常常忘了。

人心有个省力的习惯，愿意把三件事当一件事。好看的东西让人放松警惕，觉得它不会骗人；不会骗人的东西，我们又顺手认定它对我们有益。这个习惯并不坏。平常赶时间选馆子，靠它省了不少工夫，因为在吃饭这件事上，好看和好吃确实有几分相关。麻烦出在把它搬到别处：搬到一句话上，搬到一条人人都要遵守的规矩上，而这条规矩管的往往是一个人几年的日子，远不止一顿饭。

人们把“己所不欲，勿施于人”和“你们愿意人怎样待你们，你们也要怎样待人”合称“黄金定律”。“金”这个字用得很准，金子是一整块，看不出里面有接缝。本章要做的，是找到这块金里的三个焊点。

◆二、对称怎样变成了美

这两句话先打动人的，是它的样子。“己所不欲，勿施于人”，八个字，四个字一半，前半说自己，后半说别人，中间那个“勿”字像一扇合页，把两边折过来，正好重合。把“己”和“人”对调一下，句子照样成立：我不想要的，不给别人；别人不想要的，也不该塞给我。你和我可以互换位置，一个字不用改，这就是对称。第二句“你们愿意人怎样待你们，你们也要怎样待人”，前一半是别人待你们，后一半是你们待别人，左右各占一半，像一架摆平了的天平。

对称有一种不动声色的魅力。凡是能一句话说尽、左右又整齐的东西，人听了觉得舒服，觉得既没有多余，也没有缺。这份舒服不是假的，那盘鱼的摆盘也是这个道理：葱丝左右各一缕，西兰花两边各一朵，眼睛一扫就觉得稳。这种稳当，是人对秩序的喜欢，没有什么可笑话的。

本书检查一样东西美不美，用三个检查点：完全，看它是不是什么都不缺；纯一，看它是不是只有一个意思，没有杂质；活力，看它放进新的场合还能不能动，还有没有生气。这两句话在前两项上都交了漂亮的卷子：八个字之内没有缺口，意思单一得几乎透明。第三项就要打个问号。一句话要做到纯一，通常是把许多不同的情形压成了一种，压得越平，越纯，越整齐；可压平的代价，是它走进新场合时没有可以弯一弯的地方。就像那盘按同一套规矩摆出来的菜，鲈鱼大小不一，客人口味不一，摆法却一模一样。纯一有了，活力就悄悄少了。所以美的这一笔账，本书这样记：两项高分，一项存疑。它确实美，本书不会否认这一点。

第一个焊点就在这里：对称让人觉得美，这没有错；麻烦在于，美不肯停在自己的格子里，它有一股往外溢的力量。一件东西美，人们就想替它做更多的证明，好像它美到这个份上，如果不对，就太可惜了。

◆三、美怎样变成了真

从美到真，没有一道门，是顺着坡滑过去的。记得住、说得出、传得开的话，我们天然觉得它离事实近。八个字，小孩背得下来，老人说得出口，隔着几千年、几万里的人，也认得出这是同一个样子。再加上“这么多人都这么说”，一个念头就悄悄冒出来：这样整齐的话，怕就是世界本来的样子。

要先接住它的另一面：这句话在一个地段上，确实差不多是对的。不想被杀，不想被抢，不想被骗，几乎每个人都不想。你不想，我不想，他也不想，“人同此不欲”在这一段上差不多成立。拿这一段的例子去检验，句子一次次过关，一次次添足人们的信心。所以不能说它是假话，这样说既不准确，也对不起那些靠它避开了伤害的人。该说的是：它在这一段上的读数很高，人们却把这个读数说成了整条路上的读数。到了穿什么、学什么、走什么路、怎样面对死亡，“你不想的我也不想”就没人能担保了。前两章提过的萧伯纳的俏皮话和邓晓芒的“所欲相同”之说，指的是这个地方，一个用笑，一个用论证。

这就是第二个焊点。举例总是从窄段举，窄段里句子灵验，灵验带来信心，信心把句子抬成了“真理”：从某一段上的真，抬成了各处的真。那盘鱼也是如此。灯箱上的照片，让人把“好看”当成了“好吃”，因为好看和好吃在多数饭馆里确实常常同行，一次次对上了，就忘了它们不是同一件事。哪天碰上一家只会摆盘的店，才发现这两件事本来可以分开。

还有一层不容易觉察。句子越整齐，我们越不愿意拿它去碰那些难看的例子。一个例子如果让这句话显得笨拙，人们会倾向于说“这个例子不典型”，而不是回头想“是不是这句话管不到这里”。美给自己建了一道防线，用整齐把不整齐的东西挡在门外。

◆四、真怎样变成了善

第三个焊点最隐蔽。一件事如果是对的，它是不是就是好的？日常里我们常常这样接着想：既然这句话多数时候说得对，照它做就不会错；既然大家都承认它对，没做到的人就是不对。“真”的东西自带一种让人服从的分量，我们把这份分量叫作“该”。人说“你该这样”的时候，有不少次只是在说“大家都这样说”。

但“真”回答的是“是不是这样”，“善”回答的是“对谁、为了什么算好”。本书对善恶有一个明白写下的前提：善恶要对着意义来判，意义有三样，创造，自由，幸福。这是一个设定，不是从什么方程里推出来的，不接受这个设定的人，可以不接受后面的结论。这个前提第15章再细讲，这里只取它最直白的一面：一句话再对，也不能自己宣布自己是善，要看它落到具体的人身上，这个人的路走得通走不通。

回到那盘鱼。“这条鱼新鲜”是句实话，“摆得好看”也是句实话，可是它是不是善，得看端给谁。端给想把血压降下来的老人，咸鲜重口的做法对他是添乱；端给没胃口的孩子，这一大条鱼是负担。鱼没有变，摆盘没有变，新鲜程度也没有变，变的是吃的人和他为什么吃。

再换一个场景，同样是构想的。一位在车间干了二十年的老员工，信奉“己所不欲，勿施于人”，他最不喜欢别人手把手地教他怎么做事，于是对新来的实习生也一概不指点，只说一句“有事你问我”。他自己觉得，这是对人家最大的尊重。句子是真的，他的用心是真的，他自己的经验也是真的：当年他就是这样被放着自己摸索、才练出一手本事的。可实习生是那种不敢开口的孩子，三个月里一次也没问过，只是对着机器干着急。后来实习生调去了别的班组，临走时对同伴说，那三个月他一直以为师傅不喜欢他。老员工的话没有一个字是错的，实习生那条路却一直没有走通。这里“真”和“善”分开了：话是真的，落到这个人身上，不是善。

第二句话也逃不开同样的处境。“你们愿意人怎样待你们，你们也要怎样待人”，一个人愿意被人悉心照顾，就悉心去照顾别人，这股热心是实实在在的，说它美、说它对，都没有错。可一个人愿意被照顾到什么程度，和另一个人愿意被照顾到什么程度，是两个数。有人病了喜欢身边围着人，有人病了只想关起门睡一觉，两个人都是好心，各自把自己愿意的递给对方，递过去的东西都是真的，递到谁手里，却要看谁在接。

反过来也有。有的话看起来不整齐，说得拖泥带水，甚至没头没尾，却在某个人那里是善。这样的话不会被写成格言，也不会被刻在墙上，但它有时就是那一个人当时最需要的。善是对着一个具体的人才算得出来的，不是对着一句话。

◆五、拆开，分别算

焊在一起的坏处，不在于每一块都是假的，而在于任何一块被问到的时候，另外两块出来作保。有人说“这句话未必适用于所有人”，回答是“可它多美啊，放在哪里都那么妥帖”；有人说“它说不尽”，回答是“这么多人都信”；有人说“它可能伤人”，回答是“它本来就是为了不伤人”。这样一圈下来，没有一块需要自己站住。美护着真，真护着善，善又转过来护着美，三块金子互相垫背，拆哪一块都拆不动。

所以本书的做法是拆。拆不是砸，拆是把一个整体分成三个格子，每个格子各记一笔账。美这一格，前面记过了：对称整齐，完全和纯一两项高分，活力一项存疑。这笔账认下，不赖账。

真这一格，不能用一个数字了事。在不想被杀、被抢、被骗的那一段上，“人同此不欲”差不多成立，读数很高；在穿什么、学什么、走什么路、怎样面对死亡的那一段上，读数很低。句子没有说假话，只是一段上的值，被说成了整条路上的值。

善这一格，先空着。因为它不能凭句子的样子去填，也不能凭句子的真假去填，要对着意义，一个人一个人、一件事一件事地看。第三编会讲怎样看。

拆开以后，该留的都还在。就像把那盘鱼的照片、味道和对身体的好处分开评分，照片仍旧可以挂在灯箱上，只是不再替另外两样说话。八个字仍然好看，窄段里那份灵验仍然灵验，我们仍然可以放心地对一个伸手拿别人东西的孩子说这句话。拆掉的只是焊点，那个让三块东西互相作保、谁也不必单独接受检查的焊点。读者不用担心这样做是在糟蹋一句老话。老话经得起分开算，被分开算过之后留下来的东西，才是它真正站得住的部分。

可是在往下拆之前，有一件事该先做，不然这本书就成了单方面的挑剔。这两句话为什么能活几千年，为什么人人愿意背它，总有它的缘故。下一章先认账，一笔一笔认。

**带走的话**：好看、可信、该做，是三件事，要用三种办法各查一遍。整齐只能证明它好看。

**这一章怎样算错**：若能证明，人们信服这两句话，是先逐项查过它在不同情形里的后果才信的，而不是先被它的整齐打动，“焊”的说法就不成立。或者，若有一句既不对称又不好记的话，也同样被几乎所有人奉为真理，那么美就未必是信的入口。
