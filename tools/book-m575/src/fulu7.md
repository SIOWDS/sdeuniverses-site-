# 附录七　参考书目

这份书目只列两类材料：一是本书《原文库》里列为“可引材料”的文献，二是德麦国际出版社的站内前作。正文里没有用到的，不列；没有核对过卷期页码的，不补。条目的卷期页码一律照原文库所录，没有的就是没有。

## 一、原典与古注

《论语》，章号按杨伯峻本。《中庸》，《大学》。朱熹《论语集注》，所引为 5.12 章下的程子语与朱熹按语。《史记·孔子世家》；《史记·仲尼弟子列传》；《孟子·滕文公上》。《圣经》和合本。《巴比伦塔木德·安息日》31a（希勒尔的故事，只写大意）。《多比传》4:15（只写大意）。埃及中王国《能言善辩的农夫》（只写大意）。上列原文的逐字出处，见附录二。

## 二、名字与建造史

“Golden Rule”一名，17 世纪初在英国通行，最早的用例据一般记载归于 1604 年的 Charles Gibbon 与 Thomas Jackson。法国 1793 年《人权和公民权宣言》第六条。1993 年世界宗教议会《全球伦理宣言》，孔汉思起草。
