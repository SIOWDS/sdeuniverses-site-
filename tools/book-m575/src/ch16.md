# 第16章　欲不是意义

◆一、想玩是真的，为了什么却说不清

晚上八点半，段一鸣把作业本推到一边，说：“我想玩一会儿游戏。”这是构想的场景。妈妈苏晓红问：“作业呢？”“明天早上再写。”“你想玩，那你为了什么要玩？”一鸣被问住了，挠了挠头：“就是想玩啊。”再追问一句，他的脸沉下来：“你怎么什么都要问为什么。”

这个孩子没有撒谎。想玩，是真的，而且是此刻最清楚、最有力的一样东西。问他为了什么，他答不上来，也不是因为笨，是因为这个问题他从来没人问过，他自己也没问过。十一岁的人，嘴里能说出来的，是“想”“不想”“累”“烦”，说不出来的，是“我这样过日子，是为了什么”。这两样东西，一样读数很大，一样读数几乎是空白。

换成大人，也是一样。爸爸段建军下班回来，瘫在沙发上说“我想安静一会儿”，这个“想”也是真的，清清楚楚；可要是问他“你这样过日子，为了什么”，他多半要沉默很久，然后说一句“养家呗”，这句话也不是答案，是一个现成的词。成年人的欲不比孩子少，说得清意义的也不比孩子多多少，只是大人更会用现成的词盖住这个空白。

后面要讲的，就从这个差别出发：想要的东西，和为了什么，不是一回事。前者叫欲，后者叫意义。上一章立了一把尺子，说善恶对着意义判，不对着任何人的欲判。这一章要把这半句话讲透，并且用它去查那两句人人会背的话，看它们究竟问了什么，又没问什么。

◆二、两句话问的是同一件事

先看两句话怎样用。一鸣的妈妈有两种想法可以用。第一种，用“己所不欲，勿施于人”。她想：我要是被人天天收走手机，我愿意吗？不愿意。那我就不收他的。这句话让她放下了手，一鸣可以玩了。第二种，用“你们愿意人怎样待你们，你们也要怎样待人”。她想：我要是孩子，我愿不愿意有人管我、提醒我？我愿意，因为我小时候没人管，吃过亏。那我就要管他。这一句让她伸出了手，手机被收走了。同一个妈妈，同一个孩子，同一晚上，两句话得出相反的结论。爸爸段建军这边也一样。他脾气急，可小时候挨过父亲当面的数落，最不愿被人这样对待，所以对一鸣的作业，急归急，话到嘴边总咽回去，看一眼，说一句“行”。这是“勿施”，同样出自他自己的“不愿”，一鸣那一页写歪的字，就这样没人提过。

请注意两句话的起点是同一个：我愿不愿意。前一句问我愿不愿意被这样对待，后一句问我愿不愿意被那样对待。两句话问的都是“愿不愿”，也就是施方自己的欲。一鸣妈妈的欲里，有“不愿被收手机”，也有“愿意被管”，两条都是真的，都是她身上沉淀下来的，两句话各取了其中一条，结论就分了岔。可见这两句话自己并不给方向，方向是提问的人手里本来就有的那一份欲，借着话的口说出来。

想一想看，日常里我们对别人说这两句话的时候，几乎从来不会先问一句“你这件事是为了什么”，因为问了显得生分，也耽误事。口诀的好处就在于快，快的代价，是把最需要慢下来想的那一格省掉了。

这并不是这两句话的错处。它们是口诀，口诀短，必须短。但短，也就意味着有的东西省掉了。省掉的，是什么？

◆三、缺的那一样：方向

拿开车做个比方。一辆车要开得好，大概有三样东西：往哪儿去，怎么走，走得稳不稳。往哪儿去是目的地，怎么走是路线，稳不稳是刹车和误差的控制。这三样，本书的术语里依次叫D1、D2、D3：D1是意义目标，一个人“为了什么”；D2是路径组织，事情怎样一步一步做；D3是优化和约束，怎样少出错、少伤人。

把这个比方放到两句话上，看它们占了哪几样。施与不施，是路径：伸手还是缩手，这是D2。“勿施”两个字，把伤害的误差压到最小，宁可不做，也不要做错，这是D3。两样都有，而且做得相当漂亮，一个老师傅给学徒的第一课往往就是这个：拿不准的时候，不要动。可是目的地呢？为了什么要施，为了什么不施，没有说。两句话的刹车很灵，方向盘很顺，油门也好使，车上没有人问：我们是去哪里？

没有目的地的车，不会停在原地。它会往司机身上本来就有的方向开。这就是上一节看到的：妈妈从自己的欲里，找出一个方向来。欲便是在这里顶上去的。第28章会专门讲这个空档怎样一下子被填满。这里只记一句：两句话缺的，是D1；缺了以后，空出来的位置被欲占了。

再换个角度看：如果一句话既不给目的地，又被当作一切行为的总纲，那么它在实际生活里就成了一面镜子，谁拿着，照出来的都是谁自己。

这里要接住这两句话的好处。缺D1，并不是它们疏忽。口诀说的是“怎么对人”，不是“为了什么活”，它本来就不打算回答目的地的问题。问题出在后来：人们把它们当成整个的道德，当成“普遍真理”，于是缺掉的东西没人再去找。

◆四、欲是什么

欲不是坏东西，也不是假东西。人没有欲，什么也干不成，一个孩子对一样东西的“想”，是他最早的路标。本书不劝人去欲，也不说欲是低级的。要说的只是：欲不是意义。

一个人的欲，常常是他自己最先相信、最后怀疑的东西，因为它来得最快，最像“我自己”。正因如此，它最容易被误认成方向。

欲是什么？是旧土壤沉淀出来的惯性。小时候经历过什么，被什么喂过，被什么吓过，身边的人怎样活，这些东西一层一层沉下去，成了今天“想要什么”“不想要什么”的底子。举个例子：郑桂英奶奶的柜子里，总是囤着一袋米，家里明明天天有新米。这是构想的场景。她说：“有米心里踏实。”那只放米的柜子她从不让人动，一鸣想把空出来的一格放球鞋，她说放什么都行，米不能动。这份踏实是真的，欲也是真的。可是它是从哪里沉下来的？是她小时候饿过。那个年代过去了，惯性还在。她的欲忠实地记着过去，对今天的日子并不一定对得上。

所以欲有三个特点，恰恰是意义所没有的。第一，欲向后看：它是从过去沉淀来的，哪怕指向未来，用的也是过去的尺寸。第二，欲会被喂：广告、气氛、同伴、一整套算法，都能把一样东西喂成“我很想要”；第42章会讲。第三，欲不问为什么：它只管有没有，不管有了以后一个人的路通不通。意义则要回答一个问题：这件事对我走创造、自由、幸福这三条路，有没有帮助？

欲和意义当然有重合的时候。退休语文老师苏德厚，一辈子想教书，教了一辈子，欲和意义几乎是一回事：他想教，教的过程里他在创造，在选择，在把绷着的劲转成一堂堂课，幸福律也走得通。碰上这样的人，“你愿意人怎样待你们”大概会很灵：他愿意被人好好教，也愿意好好教人。但我们要看清，这是碰巧重合，不是保证重合。两句话在重合的人身上灵验，在不重合的人身上翻车，而它们自己看不见这个差别，因为它们量的只是愿不愿。

◆五、别把这一章读歪

“欲不是意义”这句话，有两种读歪的办法，要先堵上。第一种读歪，是以为这句话在说“欲不重要”，于是对方的想要可以不理。恰恰相反。上一章阿娟改方子，是先听了客人嫌腻；第14章里大夫开方之前先问病人要什么，也是这样。都是先把对方的读数收下，才有了往下走的地方。欲是读数，读数要看，只是不能把读数当成尺子。一个人说“我想玩”，这是一条要紧的信息：他此刻的劲在哪里，哪里堵着，哪里有出口。大人要做的，是把这条信息接住，再往下问：这个“想”背后绷着的劲是什么？是累了想松一松，是在学校里受了气想躲一躲，还是游戏里有一件事他做成了、很得意？每一种背后，要接的东西都不一样。他要是说，刚才那局他带着两个同学翻了盘，想再来一把，这股劲就是做成一件事的得意，要接的是这份得意，不是那台手机。要接的东西各不相同，这一点第32章、第50章会细讲。

第二种读歪，是反过来，施方认定“我知道你的意义是什么”，于是替他把意义定下来。妈妈说：“你的意义就是好好读书，别的都是胡闹。”这听上去像在补D1，补得很结实，其实是另一种顶替：她用自己清楚的欲，顶掉了孩子还没清楚的意义。意义不是别人能递过来的东西，它是一个人自己在创造、自由、幸福这三条路上一步一步走出来的，大人最多能替他开路、点灯，不能替他写目的地。所以补上D1，不能靠施方“把方向装进两句话”。要靠的，是留出孩子自己走出方向的时间和余地。这一条，第四编还会反复回到。

还有一个常见的追问：那孩子说不清为了什么，是不是就该一直由大人替他定？这是个正当的疑问，答案在第四编里，先留一个预告：意义没清楚的时候，不是大人说了算，也不是孩子说了算，是还没有定义，这时候大人的活，是陪着、问着、守住该守的底线，而不是替他把意义填满。

◆六、于是，两句话本身无善无恶

接着往前推一步，这是本书的推论，要标明。既然善恶对着意义判，而这两句话里没有意义这一格，那么这两句话自己，就无善无恶。它们是一件还没有装上方向的工具。装上什么方向，就帮什么忙。妈妈带着“让孩子走通自己的路”的方向用它，“勿施”替孩子挡掉了无谓的消耗，“要待”替孩子接住了真的接不住的东西，是善；妈妈带着“我怕被人说我不是好母亲”的方向用它，同样的两句话，伸出去的手可能是在替自己结账。

由此，“普遍真理”这个说法也站不住了。一句话要成为普遍真理，至少要自带方向，不管谁用、对谁用，都指向同一个“为了什么”。这两句话不自带方向，方向是用的人带来的，用的人变了，方向就变了。这是本书对“普遍真理”的拆法，它不是在说这两句话是谎话，也不是说它们没用，它们的功劳，第6章已经认过账：止手、开手、借条、兜底，每一样都真有用。只是这些功劳，都是在有人带着合适的方向用它们的时候发生的。

要不要补一个方向呢？本书不打算给这两句话补上一个固定的方向，这样做就会变成另一句口诀，还是替人安排。本书的做法是：每次用的时候，查一查那个方向是谁的，对着什么。这就是第三编后面几章要铺的路：先把“信息”的三张脸讲清，再看三张脸怎样各有各的谱系，最后才是那个总式。

回到那个晚上。一鸣说“想玩一会儿”，妈妈问“为了什么”，孩子答不上，这个“答不上”并不是坏消息。它说明在这个时刻，孩子的意义还没有清楚，这个状态本身，是第四编要专门讲的。眼下记住一条：欲是清楚的，意义是空的；谁的欲清楚，谁就最容易把自己的欲当成方向填进去。妈妈填的是“考好”，孩子填的是“玩”，两个都是欲。下一章，我们转到信息这一头：一句话怎样靠名字、道理、样式这三张脸，才接得住一个人的意义。

**带走的话**：两句话只问“愿不愿”，不问“为了什么”；缺了意义这一格，位置就被欲占了。

**这一章怎样算错**：如果能证明人们用这两句话时，总会先问清“为了什么”，或欲与意义在绝大多数情形里本来就是重合的，本章说它们缺方向、被欲顶替，就不成立。
