# 第13章　挨打的人听到的

一幢写字楼里（这件事是构想的），物业公司请了个培训师，给全体员工讲“服务意识”。大屏幕上打着一行字：“你愿意别人怎样对待你，你就怎样对待别人。”保洁组的秦大姐坐在后排，使劲点头。前排的康经理也点头，他是物业的负责人，上个月刚把保洁组的夜班津贴砍了一半。散会以后，秦大姐想的是：我对每层楼的人都客客气气，可从来没有人这样待过我。康经理想的是：我待员工不薄，大家都看得到。一块屏幕，一行字，两个点头的人。他们点头的是同一个意思吗？

上一章我们读了马太福音里这句话的前后：它前面是祈求被听见，后面是窄门。这一章读路加福音第六章，同一句话在那里的位置，几乎完全不同。它不在祈求与窄门之间，而在一连串让人喘不过气来的命令中间：爱仇敌，被打脸，被夺衣，之后是“就是罪人也是这样行”。界限同上一章：只读语言处境，不作神学判断，不评判信仰。第301号《我是道路、真理、生命》读过福音书里“爱你们的仇敌”（太5:44）和“不要论断人”（太7:1）这样的话，是用另一把尺子去读耶稣；本书借的是它读经时的态度，对这一处的具体读法，由本书自己负责。

◆一、这些话是对谁说的

先看这一段的开头。在路加福音里，第六章二十节有一句：“耶稣举目看着门徒，说：‘你们贫穷的人有福了！’”第二十二节说：“人为人子恨恶你们，拒绝你们……你们就有福了！”再往下，就到了我们要读的二十七节。

这一处最先要看清的是说话的对象：耶稣是对门徒说的，被称作有福的，是贫穷的人，是被恨恶、被拒绝的人。二十七节的开头，“只是我告诉你们这听道的人”，一个“只是”把前面的福分转了过来，转向对这些听道的人的一连串要求：

“你们的仇敌，要爱他！恨你们的，要待他好！咒诅你们的，要为他祝福！凌辱你们的，要为他祷告！有人打你这边的脸，连那边的脸也由他打；有人夺你的外衣，连里衣也由他拿去。凡求你的，就给他；有人夺你的东西去，不用再要回来。”（路6:27—30）

这一串话里，碰到事情的都是承受的一方：被恨的，被咒诅的，被凌辱的，被打的，被夺的，被求的。这些多半是没有权柄的人才会碰到的事。接下来才是我们熟悉的那一句：“你们愿意人怎样待你们，你们也要怎样待人。”（路6:31）

读到这里，要停一下。我们今天引用这句话的时候，脑子里的场景往往是一个有选择的人，坐在桌边，掂量该怎样待别人。可是在路加的上下文里，这句话夹在“被打脸”和“被夺衣”的后面，说给一群生活里没有多少选择的人听。这是本书的读法，依据只有一条语言上的观察：上下文里的大半动词，是别人对他们做的。

◆二、句子的后面：“罪人也是这样”

这句话后面接的是什么？路加紧接着写的是：“你们若单爱那爱你们的人，有什么可酬谢的呢？就是罪人也爱那爱他们的人。你们若善待那善待你们的人，有什么可酬谢的呢？就是罪人也是这样行。你们若借给人，指望从他收回，有什么可酬谢的呢？就是罪人也借给罪人，要如数收回。”（路6:32—34）

这三个问句排成一列：爱那爱你的，善待那善待你的，借给指望收回的。每一问的答案都是：连罪人也这样做。也就是说，在这一段里，“以对方对我的方式对他”，是一件连罪人都做得到的事，没有什么可酬谢的。随后是转折：“你们倒要爱仇敌，也要善待他们，并要借给人不指望偿还。”（路6:35）

把这几句放在一起读，可以看出一个明显的结构：第三十一节那句话，上面连着一串讲被伤害的人要怎样的话，下面连着一串说只是互惠、连罪人也会的话。夹在这两串话中间，它处在一个有张力的位置上：向前看，它是对挨打的人说的；向后看，它所代表的那种对等往来（你怎样待我，我怎样待你），被指出是不够的。

◆三、解经上的分歧，和利科

那么，这句话在路加里到底是什么地位？是一句被肯定的准则，还是一句被引来、然后被超越的话？这个问题，解经的人是有争议的，不能装作已有定论。法国哲学家保罗·利科1990年在《新约研究》上发表过一篇文章，题目译成中文大致是《金律：释经与神学上的困惑》。本书只取原文库里列出的内容：他讨论了路加6:31的两种读法，一种是肯定的读法，一种是把它当作“引来待驳”的读法；他还讨论了金律与“礼物的经济”的关系。除此之外，他的论证细节，本书不转述，因为我们没有核对。

两种读法，用大白话说，是这样的。肯定的读法，把这句话看作说话人自己立下的准则。它夹在前后的命令之间，是对那一串要求的一个概括，或者一个落脚：爱仇敌，不是别的，就是你们希望人怎样待你，你们也这样待人。这样读，三十一节与前后文是顺着走的。

引来待驳的读法，则把它看作当时听众耳熟的一句互惠之言，被引到这里，随后就遇到了三个“有什么可酬谢的呢”：你们说的这句话，罪人也做得到，所以不够，要超过它。这样读，三十一节与后文是拧着的，它是被指出不足的那个起点。

两种读法都有道理，各有各的难处。肯定的读法要面对“罪人也是这样”的追问，为什么紧接着对这一类对等往来的做法有所保留；引来待驳的读法要面对这句话自己的措辞，为什么它写得如此肯定，没有一个“你们听见有话说”之类的引导。以上两处难点是本书自己的观察，不是利科的原话。本书不裁定。本书要拿走的只有一点，也是对两种读法都成立的一点：不管取哪一种，这句话在路加的上下文里，都与“回报”这件事绑在一起。它前面是不要回报的受害，后面是不指望偿还的借贷；它自己说的，是那种你给什么、我给什么的往来。它所在的地方，是一个互惠与超过互惠的张力点。在路加这里，这句话不是一个平静的、人人皆知的底线，而是一个被放在显微镜下的东西，既被引用，又被追问。

这一段的收尾，还有一笔值得带走：“你们要慈悲，像你们的父慈悲一样。你们不要论断人，就不被论断；你们不要定人的罪，就不被定罪；你们要饶恕人，就必蒙饶恕。……因为你们用什么量器量给人，也必用什么量器量给你们。”（路6:36—38）末了一句说到“量器”，量给人的，也量给自己。这与第11章《大学》的那把尺子有一点遥遥相对：量别人用的是什么尺，别人量你用的也是什么尺。本书只记下这个相似，不推论二者同源。

◆四、两个位置，两个方向

现在可以回到本书一直在找的东西：位置。在第7章里我们读了仲弓问仁：孔子说“己所不欲，勿施于人”，听的人是仲弓，旧说他出身微贱，孔子说他“可使南面”，一个将要管人的人。那句话是对一个手里即将握有权柄的人说的，意思是：你将要使唤别人，在伸手之前，先查一查，你自己愿不愿意被这样使唤。这是一个对将要管人的人说的“勿”。

路加这里，听的人是穷人，是被恨恶、被拒绝的人，是被打脸、被夺衣的人。耶稣对他们说的，是“你们也要”：你们愿意人怎样待你们，你们也要怎样待人。这是一个对挨打的人说的“要”。

两句话的方向，正好相反。孔子在仲弓章里的话，是让手里有权的人先收一收手；路加这里的话，是让手里没有权的人先伸一伸手。前者拦住的是“施”，后者推出的是“待”：一个是已经握在手里的力气，要不要使出去，一个是眼看被人拿走的东西，还肯不肯给。

然后回到写字楼里那两个点头的人。同一行字，落在两个耳朵里。秦大姐听到的，是一句她早就在做、却从来没有得到过回报的话；康经理听到的，是一句他已经做到了的话。如果这句话是对秦大姐这样的人说的，那么它的意思，是请一个受了委屈的人，仍然先把手伸出去，这需要极大的分量，也需要极大的自由。如果这句话从康经理的嘴里说出来，对着秦大姐，那就是另一回事了：一个手里有权的人，要求一个受气的人“你要怎样待人”，这句话的重量就整个翻了过来。

这是本章最想让人看见的一点，也是本书对“位置”的一条守则：句子可以一个字不动，说话的人站在哪个位置，听话的人站在哪个位置，句子的意思就跟着变。在路加里，这句话是对挨打的人说的，被打的人听到它，可以听出一个邀请，从只能承受的人，变成先动手的人；而当有权柄的一方把它引到被打的人面前，要对方继续忍受，这就变成了反方向的使用。本书不判断哪一种使用是经文的本意，那是神学的事，本书只读语言：这句话的语法里，并没有写明“谁对谁说”，是上下文告诉我们的；而上下文，把听众放在了穷人与被恨恶者的位置上。回到写字楼：培训师若在屏幕上多打一行，写明这句话是讲给谁的功课，两个人点头的意思就不会混在一起；可屏幕上没有这一行，康经理和秦大姐各按各的位置去听。

◆五、受气的人和有权的人

这一章的题目说的就是这件事。同一句话，有权的人听到的是自己的功课，受气的人听到的是别人的要求。这两种听法，都不是对这句话的曲解，是它在两种位置上的两个回声。可是做成一块屏幕上的标语，对全体人员一起放映，两种位置的差别就被抹平了。

抹平的后果，在秦大姐身上看得最清楚。她不缺“待人好”的意愿，也不缺这方面的功夫，每一层楼的人她都客客气气。她缺的是另一半：有人待她好。这句话在她那里，既不能证明她做得不够，也不能证明别人做得够。把它不加区分地同时发给秦大姐和康经理，等于告诉两个人，你们是平等的，你们都该照这一行字办。而事实是，他们站的位置不一样。一个管着津贴表，一个领着津贴；一个说话有人记，一个说话常被当作牢骚。津贴砍掉的那个月，康经理在例会上用的是“公司统一调整”，秦大姐在楼梯间对同组的人说的是“这样不对”，两句话里，只有前一句进了会议记录。同一行字要算作两份功课：对康经理，功课在他抽屉里那张津贴表上；对秦大姐，功课是她愿不愿意、能不能在没有人待她好的时候，仍然开这个头，这件事要不要做、做到哪一步，应当由她自己说了算，旁人不能替她定，更不能拿这行字来催她。仲弓章里那个“无怨”，放到康经理身上，就是一件很具体的事：砍津贴的那天，到保洁组的楼梯间站一站，听一听她们怎么说，查一查这笔钱砍掉以后，谁的夜班接不上孩子放学。

这位说话的人自己是怎样做的？他对瞎眼的人，对病了三十八年的人，都问过一句话。那一问里藏着一件事：连答案谁都猜得到的时候，他还是先问一句。

**带走的话**：同一句话，对将要管人的人是“收手”，对挨打的人是“先伸手”；有权的人拿它去要求受气的人，方向就整个翻过来了。

**这一章怎样算错**：如果能证明路加这一段的“你们”主要是有权者，或六章二十至三十八节的听众与受害者无关，本章“挨打的人听到的”这一对照就要重写。
