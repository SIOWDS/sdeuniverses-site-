# 附录一　这本书在什么情况下算错

这本书立了不少判断，却没有做过一次调查，也没有做过一次试验。核心判断由著者口述，正文由会说话的机器协助写成，几位执笔者共用同一个底座，互相校对不算彼此独立的证据。所以每一条判断都应当附上一句话：在什么情形下，它就算错了。下面是五条，每条都是未检验的。第一条可以真跑，办法写得最细；其余四条先写出算错的情形，留给愿意做的人。

## 一、谱系宽窄：窄段灵验，宽段失灵

本书的说法是：不想被杀、被抢、被骗，人和人的差异很小，近乎统一，“己所不欲，勿施于人”在这一段上灵验；穿什么、学什么、走什么路、怎样面对死亡，人和人的差异很大，同一句话到了这一段，就成了替人命名、替人推理、替人算账。人们举例总举杀偷骗，是把窄段的灵验外推到了全谱。这条说法可以做成一个小实验，办法如下，没有哪一步是本书替你跑过的。

第一步，列场景。编三四十个场景，每个场景是一件具体的事，写成“如果……你想要还是不想要”的样子。从最窄的一头排起：被人抢走东西、被人骗钱、被人当众打；中间有：别人替你拿主意换工作、别人不跟你商量就替你交钱；最宽的一头有：别人替你选学什么、别人替你决定要不要知道自己的病、别人替你安排老了以后怎样过。数量由做的人定，但要够多，每个宽窄档位都不能只有一两个。

第二步，事先排宽窄，排完锁死。找一批与本书无关的人，由人来评，不用同一个底座的机器，也不告诉他们本书的假说，只让他们各自给每个场景打分：你觉得，换一百个不同的人，想要同一样东西的有多少？先把打分规则和评分者间一致性的及格线写在纸上。窄宽的等级只能由这一步定，不许在看到后面的结果以后再调。

第三步，招对子。三类对子：十岁以上的孩子和一位家长，成年子女和一位老人，同事和同事。另招一组互不认识的陌生人对子，当基线。每一对里，施方和受方分开作答，彼此看不到。

第四步，各答各的。受方回答：这件事，我自己想要还是不想要，想要什么。施方回答两件事：一是这件事换成我自己，我想要什么；二是我猜对方想要什么。顺序固定，先答自己，后猜对方。

第五步，计分。命中，是施方猜的和受方答的一致。另记一项：施方自己的欲和受方的欲是否一致。两项都按场景所属的宽窄档位汇总。

第六步，三个对照。其一，陌生人对子的命中率，作基线。其二，同一个施方在受方作答以后，被允许直接问受方一次，再答，看命中有没有提高，这一组对应本书引用的一项研究结论：直接通过对话得到对方的想法，准确度提高，单靠设身处地不一定。其三，让受方隔两周把同一份场景再答一遍，看他自己前后一致不一致；一致性太低的场景，不能拿来检验任何人猜得准不准，要剔除。

第七步，看趋势。把命中率按宽窄档位画出来，分三类对子各画一条。书里的预测是：越往宽的一头，命中率越低，施方自己的欲和受方的欲越不一致；窄的一头，命中率明显高于陌生人基线。

什么结果算这条作废，事先写好：

第一，命中率不随档位变宽而下降，趋势线是平的，或者宽的一头反而更高，那么“窄段灵验、宽段失灵”这个说法就算错了。第二，窄的一头的命中率并不比陌生人基线高，那么“窄段近乎统一”也不成立，两句话连窄段上的灵验都没有说清楚。第三，施方自己的欲和受方的欲在宽段上仍然高度一致，那么“同一句话在宽段上成了替人算账”就没有依据，因为替人算账的前提是两个人的账本不同。第四，第二步里评分者之间的一致性达不到事先定的线，说明窄宽的分法本身说不清；这时候不能说书对，也不能说书错，只能说量具作废，要换场景、换评分者重来。

做的时候要守几条规矩：孩子的答案不能让家长看到，也不能因为答案受任何责罚；成年人的自我报告会带社会期许，要在报告里写明；涉及重病和死亡的场景，要经过伦理审查，并让参加者随时可以不答；结果无论好坏，都要把场景、规则、原始数据一起公开。本书没有跑过这个实验，所以对结果没有任何话可说。

## 二、欲与意义：空档里欲顶替了意义

本书的说法是：这两句话查的是“愿不愿”，不查“为了什么”；意义不清的时候，欲照样有读数，于是欲顶上去，施方替受方提前结算。

下列情形出现，这条就算错：第一，两句话的使用者在日常实际使用时，多半先问了对方“这是为了什么”，然后才问愿不愿，而且这是常态，不是个别好人的做法；第二，在受方意义已经清楚的情形里，截断发生的频率和意义不清时一样高，那么起作用的就不是空档，是别的东西；第三，被问到的人，回答“想要什么”和回答“为了什么”总是同一个答案，欲和意义在他们那里根本分不开。这条可以靠访谈和日记去查，本书没有查过。

## 三、作恶的结构：施方走通，受方截断

本书的说法是：恶，是施方借这次施受走通自己的意义，受方的意义却被截断；而且要说清是谁的意义、哪一律、哪一步、多长的时间窗，说不清就不用“恶”字。

下列情形出现，这条就算错：第一，找到大量人们一致称为恶的事，施方并没有走通自己的任何意义，受方的截断也写不出来；第二，找到大量受方的意义走得通、人们却一致称为恶的事；第三，请几位互相独立的评判者，用同一份材料各自填“谁、哪一律、哪一步、多长时间窗”这四项，填出来的东西彼此对不上，那么这个定义读不出来，不能算一个能用的定义。

## 四、定义域：意义未清时不判

本书的说法是：意义不清，真善美没有显露，这时候判善恶是果当因；事中只问他的意义清楚了吗，事后结算已发生才能回头判；三道闸防止它变成免罪牌。

下列情形出现，这条就算错：第一，在意义未清的阶段做出的善恶判断，事后回看几乎总是稳定不变，提前判并没有造成任何截断，那么“果当因”不成问题；第二，三道闸在实际使用中，常常被人用来无限拖延制止或回避责任，闸门变成了免罪牌；第三，请独立的评判者去判断“他的意义清楚了吗”（他说得出为了什么，过几天还认，能据此取舍），他们彼此的判断对不上，那么定义域画不出来，“不判”就无从操作。

## 五、方法层：同一底座互校，没有独立证据

本书的说法是：核心判断出自著者口述，正文由机器协助写成，互校不算独立。

下列情形出现，这一层的说法就要收窄：第一，独立的人类读者，不同来路，各自照本书的办法去拆同一个案例，得出的判断和书里的相反，或者彼此对不上；第二，把书中的字母和学名统统删掉，论证丝毫不受影响，说明那些字母只是贴上去的标签；第三，有人证明总式里的 F 永远填不进任何可检验的内容，那么总式只是一个修辞，不是方法；第四，书里引的原文、出处、文献有误，任何一处，都应当更正，并写明更正了什么。
