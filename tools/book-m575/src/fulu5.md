# 附录五　大白话与学名对照

书里第一次出现一个术语，先说大白话，再在括号里写学名。这一页把它们收在一处，方便回头查。学名带字母的，字母第三编才出场；前两编正文不用。表里每条只给一句话，详细的说法在正文各章。“S”写作显露，不是结构。

| 大白话 | 学名（记号） | 一句话 |
|---|---|---|
| 一件事露出来的样子 | 显露（S） | 矛盾累积到一个点，结算出来的东西，是看得见的结果。 |
| 事情里分得出来的差别 | 差异（D） | 要往哪去、怎么走、受什么约束，都是差别在起作用。 |
| 缠在一起的东西 | 纠缠（E，特征纠缠） | 事情缠在哪一界、哪一种信息上、哪一种力气上。 |
| 真、善、美 | 价值显露（S3） | 价值是意义被信息接住的样子；意义不清，它就不显露。 |
| 为了什么 | 意义目标（D1） | 方向。两句话里缺的就是它。 |
| 怎么走 | 路径组织（D2） | 施与不施，先后次序，是路。 |
| 怎样少出错 | 优化约束（D3） | 把伤害的误差压到最小，“勿施”主要做的事。 |
| 名字、道理、样式 | 信息的三维（E2）：符号、逻辑、数学 | 一句话在三种信息上各有一条来路。 |
| 同字不同指 | 符号的同一性谱系 | 名字是指针，同名不等于同心。 |
| 同理不同推 | 逻辑的同一性谱系 | 没有通用法庭，本地逻辑里仍有对错。 |
| 同到达不同量 | 数学的同一性谱系 | 要统一的是到达，不是件数。这里的“数学”指连接、次序、结构和算账的办法。 |
| 乱成一团，自己理出头绪，长出新东西 | 创造：混沌—自组织—涌现 | 三条意义里的第一条。 |
| 在缠住自己的东西里自己选，选了又激发出新路 | 自由：纠缠—选择—激发 | 自由的量度是能不能长出新路，不是选项多少。 |
| 一股绷着的劲，转成别的样子，走通那一下 | 幸福：张力—转换—释放 | 幸福不是舒服，不是没事。 |
| 三个设定的意义 | 意义三律（创造律、自由律、幸福律） | 本书明写的规范前提：善恶相对于它们。是设定，不是推出来的。 |
| 三界 | 理念界、现实界、自我界（E1） | 想法在哪里，事在哪里，“我”在哪里。 |
| 三种力气 | 内能、动能、势能（E3） | 第23章里的“力气”一刀。 |
| 统一的是输入 | 统一性 | 同价、同卷、同份，看不见到达。 |
| 统一的是到达 | 同一性谱系 | 一串随差异显露又彼此牵连的形态，把差异保留在一个整体里。 |
| 不想被杀被抢被骗 | 谱系的窄段 | 人和人的差别小，近乎统一，两句话在这里灵验。 |
| 穿什么学什么怎么面对死亡 | 谱系的宽段 | 人和人的差别大，同一句话成了替人命名、替人推理、替人算账。 |
| 还没想清楚的时候 | 混沌 | 差异极强，还没成序。 |
| 正在成形的时候 | 介生 | 局部结构已经能形成、能修订，要害是承接。 |
| 欲一下子顶上去的那个位置 | 空档 | 意义不清时，欲照样有读数，于是顶替了意义。 |
| 替人把账提前算了 | 提前结算 | 矛盾还在累积，结算没到，就先给出结论。 |
| 三道闸 | 态相对于人、时间窗先说、不可逆者不享暂缓 | 防止“意义未清”变成免罪牌。第三条是另设的规范承诺。 |
| 子会当父，媳会当婆 | 人轮此位 | 位置会轮到每个人。轮过位不等于仁慈，还要有记念和回写。 |
| 谁始终到不了意义，谁被关在门外 | 铁门 | 第508号的判语：偶尔吃亏是谱系，始终吃亏是铁门。 |
| 他的反应能不能回到我这里 | 回写 | 结果回头改写起点。单向，或丢失，是引擎熄火的一种样子。 |
| 引擎熄火的三种样子 | 123 原理的三种熄火 | 矛盾被压平，判决先于相遇，回写单向或丢失。 |
| 六种起手的排法 | 六路径 | 显露、差异、纠缠三个要素的六种先后次序；两句话自带的是先定我要不要，再盘自己，再动手；其余五条用来多问一个问题。 |
| 把别人的愿望当成孩子的 | 冒名显露 | 父母未竟之愿，成了孩子的愿望。 |
| 经手但不替他走完 | 经手 | 保有判断与修正机会，不等于亲手完成（第514号）。 |
| 改回的口子 | 回写的可返回性 | 复核点、修订权、重开通道（第433号的意思）。 |
| 总式 | S3＝F(D1, E2) | 价值是意义目标和信息的函数；F是占位记号，不是能算的公式。 |
