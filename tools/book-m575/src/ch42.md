# 第42章　按你要的给：算法的黄金定律

◆一、睡前的那一划

这是构想的场景。小彭二十三岁，是段建军的徒弟，在模具厂干了快两年。下班回到合租的屋子，洗完澡躺到床上，手机拿起来，拇指一划。第一条是车间里的加工视频，铣刀从一块钢上走过去，铁屑卷成一条银色的小弹簧，他看得入神。第二条还是加工，第三条是个老师傅讲怎样装夹，一个小窍门，他当场点了赞。从这个赞起，屏幕上的东西就越来越像他刚点过的东西。

先说明一句：本书不指任何一家平台，也不知道哪一家怎样做，这里讲的是一种按“你要什么就给什么”的想法造出来的系统，是构想的。它的做法用一句话就能说完：记下你停在哪里、点了什么、看了多久，算出你大概还会爱看什么，下一条就给你这个。你的每一次停留，等于投了一票。

起头的几个月，这套办法对小彭是好事。他那阵子正想弄明白一种夹具怎么用，书上讲得绕，车间里师傅忙得顾不上细讲，是屏幕里一个陌生人用三分钟给他演示清楚的。第二天他照着做，省了小半个钟头，还顺手把那张夹具的草图画在了工作本的背面，留着下回用。这是“你们愿意人怎样待你们，你们也要怎样待人”最顺手的样子：我知道你想要什么，我就把它递过来，一点不绕。第6章讲过的“开手”，就是这个：对一个素不相识的人先动一步，不等他开口求。

这样的好处不该被抹掉。一个在小县城里干活的年轻人，身边没有那个陌生人，要不是有这样的办法，他一辈子也碰不到那三分钟。按欲来给，在意义已经清楚的时候，是极好的接生手：他心里有个缺，系统就把名字、道理、样式递到手边，缺怎样补，是他自己一眼认出来的。

◆二、三个月以后，句子没变

三个月后，小彭自己说不清是哪一天开始的，他发现已经很久没在屏幕上看到过一条他事先不认得的东西了。每一条都对胃口，每一条的开头他都能猜到结尾。他在车间里这个月学了不少新东西，睡前的屏幕却一个新东西也没有，给他看的永远是昨天那个小彭会点的东西。他越刷，越像昨天的自己。有一回同屋的人问他最近看了什么好东西，他张了张嘴，发现说出来的，还是上个月就讲过的那一类。

系统的原则一个字没改，还是“按你要的给”。他也没有被谁强迫，每一条都是他自己停下来的，每一个赞都是他亲手点的。要是他去抱怨，这套办法有一句现成的回答：这些全是你自己选的，没有人按着你的手。这句回答不能说是假话，难处就在这里：欲是他的，一点没有冒名顶替，所以连白金律、连“再问他一句”也帮不上忙：问出来的，仍是欲。这里问小彭：你想不想看？他说想。他想看，是确确实实的。

有天夜里他想找一种他自己也叫不出名字的东西，大概是“怎样把一件活儿的次序排得不容易出错”。他躺着打开搜索框，换了三个词，都搜不到合心意的。那天他最后什么也没搜到，把手机扣在枕边，对着天花板想了一会儿，才睡。搜索框和睡前的那一划是两回事：在搜索框里，他得先有个想法，哪怕是模糊的；在那一划里，想法是不需要的，只要手指在。越是后者占去他的晚上，他越少有机会练习把一个模糊的念头说成一句话。

白金律就是“照别人希望的方式待别人”。批评它的人说，它可能带来刻板印象：我以为你们这类人都希望什么，就照着给。算法把这条做到了头，而且刻板得更彻底：它不再按“这一类人”给，它按“这一个人的过去”给，把小彭钉在他自己的昨天上。这样说并不贬低谁，造这套办法的人想的可能就是让人省心、让人得到想要的东西，这个愿望本身没有错。要看的是它落到小彭身上的样子。

◆三、只动一格：给来做什么

现在把系统放在桌上，只动一处。机器、数据、那句“按你要的给”，全不变，只问一件事：给他这些，是拿来做什么的？一种答案是：帮他把想学的学到。那么这套东西的尺子就是：他后来会了什么，他用上了没有。另一种答案是：让他留下来。那么尺子就是：他停了多久，明天回不回来。两套尺子下面用的是同一批读数，同一个“按你要的给”。小彭看不出差别，他的手指也看不出，只有放长了看，才分得开。拿同一个夜晚演一遍：尺子若是前一种，他连看三条加工视频之后，系统在第四条里放一条他没看过的，比如怎样把工序排得不容易出错，看完还问他一句，这条用上了没有；尺子若是后一种，第四条还是加工，第五条还是加工，因为那最能把他留住。后台看到的读数几乎一样，都是他又停了、又看了。

这里要紧的一点是：小彭自己并不知道他想拿这些视频做什么。他要学夹具的时候是清楚的，睡前那半个钟头，他说不清是为了放松、为了不想白天的事，还是单纯舍不得放下手机。意义没有说清，欲却读得一清二楚：停了几秒、划走了几次、看完了没有，样样都有数。第28章讲过这个空档：意义不清的地方，欲照样有读数，于是它一下就顶了上来。算法在这里做的事很朴素，它是读得最勤的那个读数员，读到什么就按什么给，读不到的东西它不会替你想起来。

这里要防一个反面的想法：既然它读不到意义，是不是该由平台来替小彭定，他“应该”看什么？也不行。那是换一个人来写方向，从读他的欲变成替他定他的意义，和给孩子代写作业是同一个反面：妈妈认定“这道题对你就是创造，必须自己扛”，也是替孩子写了方向。小彭二十三岁，早成年了，判错的权利在他自己手里，任何一方替他拿走，都是又一次截断。要的是他的方向能被写进去，写的人是他自己，不是平台，也不是哪一位替他操心的长辈。

所以“人所欲”这个说法，到了算法手里成了一个数。赵汀阳把“己所欲”改成“人所不欲”，意思是别从自己出发，去看他人的观点，这是个很重要的转身。可是在这里，他人的观点就摆在那里，数得清清楚楚，数出来的全是欲。从欲数出来的“他人的观点”，也只是他昨天的观点。

◆四、只动一处：信息的三张脸

再换一个办法。方向不动，只看这套东西怎样处理信息的三张脸。第一张是名字。屏幕上，小彭的一个赞、一次停留，统统叫作“感兴趣”。可他停下来的缘故多得很：因为好看，因为生气，因为没看懂想再看一遍，因为累得没力气划走。这些在他心里是五种东西，到了系统里只有一个名字。同名不同指，第18章说过，名只是个指针。

第二张是道理。系统的推法只有一步：他看过这个，所以他要这个。可小彭自己的推法很可能是另一条：我今天看了一晚上加工，明天想看点别的。他有他的本地道理，这个道理里是带着“换换口味”的，而系统的道理里没有这一环，因为换口味这件事在他过去的读数里还没有出现。

第三张是样式，也就是怎样算账。系统把“像”算成了一个距离：离他已点过的东西越近，就越先给他。人往前长，常常要跳到一个离现在很远的地方去，从木工跳到电路，从厂里跳到一个他自己也说不出名字的念头。距离这把尺，天生只管近处。

这三处合在一起，可以拿一个朋友作比。有人隔几年见你一面，每次都按他上次记住的你来招呼：你爱吃辣，就端辣的；你爱聊球，就开口聊球。这个朋友很体贴，可你这几年已经不爱吃辣了，也开始想聊些别的，你又不好意思拂他的意，只好陪着再吃一回。一个朋友这样，是一顿饭的事；一个天天陪你的系统这样，就是一年的事。三张脸上，每一张都挤掉了一点点，挤掉的偏偏是他还没有的东西，也就是他明天会成为的那个人。

◆五、谁走通了，谁被截断了

小彭的三条路，在这套东西里各断在哪一步？创造那条路，起点是一团乱麻，自己理出头绪，长出新东西。可是给他的东西永远是理好了的、他认得的，乱麻进不来。自由那条路，要看的是能不能长出新路，不是选项多少。屏幕上的选项多得数不完，一划就换，可是每一条都是同一条路的分叉，新路长不出来。幸福那条路，是一股绷着的劲转成别的样子，走通那一下的畅快。小彭下班后的疲惫、无聊、说不出的烦，是一股劲；一划，换成下一条，这股劲在转换之前就被泄掉了，第二天早晨它还在原地。

有一天，段建军路过休息室，瞥见徒弟低着头划屏幕，什么也没说。他带徒弟的办法是话少，让人自己去碰壁。这回碰壁的地方没有墙，也没有疼，他想说也没有说的理由。小彭自己更觉不出：每一条都是好玩的，哪一条也不比前一条差。

施方这一边呢？在这套构想里，账本上每天都有读数：他又看了一条，他又回来了。每一条读数都在说这个做法行得通，不会有哪一条读数说“这个人这三个月没有长”。变量变了，没有警报。这一点与前面各章一样：句子没变，用的人也许是好心，读数全是好的，而被截下来的东西，不在任何一个读数里。

这并不是说，一个太会给的系统就该一律拿掉。一个目标清楚的人，比如小彭决定这个月把夹具彻底弄通，用它就是用一把顺手的锥子，刺到哪里是他定的。翻转出现在另一种晚上：他没有目标，手指替他定了方向，而手指只认昨天。

能不能翻回来？能，办法也很朴素：让“要的”由他写。小彭可以给自己立个小规矩，每个礼拜先想好一样自己想学的东西，自己去搜，看完问自己用上没有；碰到系统给的，隔三条主动点一次“不看这类”，让它多出一个它读不到的读数。同一句“按你要的给”，只要“要的”里有他自己放进去的方向，就从钉在昨天变成了接他往前走。反过来，这套东西若肯让他看到“为什么给我这一条”，又留一个“给我换点没看过的”的口子，也是在退一步，把判错权的一部分还给他，第51章会细讲。

第二天早上闹钟响，小彭伸手去按，指尖先碰到的是手机，屏幕上还停着昨夜最后一条。他没觉得哪里不对，只觉得睡得不够。这是这类翻转最难的地方：受方没有哭，没有喊，甚至没有不满，他只是比三个月前少了一点点长出新东西的机会，而这一点点，谁也没有拿走，是他和系统一天一天、一划一划，一起省掉的。

用本书第三编的话收一句：这套做法里，意义那一格（D1）被换成了他昨天的读数，信息那一格（E2）的三张脸被压成了一个距离，所以它走得极顺，也极稳。可是还有一种情形和它正相反：不是太会给，是一点也不给。下一章，我们听一听隔壁的哭声。

**带走的话**：算法是“人所欲”的数学态：欲读得最准，意义读不到，于是越按你要的给，你越像昨天的自己。

**这一章怎样算错**：如果追踪一个人几个月，发现他在这样的系统里接触的东西并没有变窄，反而不断长出他过去从未点过的新方向，本章的判断就不成立。
