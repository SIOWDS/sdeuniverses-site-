# 第6章　先认账：这两句话的四样功劳

◆一、操场上的一句话

课间操场上，一个男孩把同学推倒了，同学的膝盖蹭破一块皮，哇的一声哭起来。这是构想的场景。老师赶过来，没有吼，也没有讲“同学之间要团结友爱”，只是蹲下来，让自己的眼睛和男孩一般高，问了一句：“你愿意被人这样推吗？”男孩的手还悬在半空，嘴张着，愣了几秒钟，脸一点一点红起来，低声说了句“对不起”。

这一句话做了不少事。它先让那只手停住了，没有再推第二下。它又把一个十岁孩子从来没认真想过的东西递到他面前：被推倒是什么滋味。这个滋味他不是完全没尝过，也许去年被谁推过一下，早忘了，一句话把它从记忆里翻了出来。老师没有讲道理，因为讲道理需要孩子听得进，而一个刚动过手的孩子，这时候什么道理都听不进。一句话，八九个字，比十分钟的训话管用。

上一章拆了这两句话的焊点，接下来的几编还要继续拆，拆之前必须先把家底点清楚。一本书如果只会挑毛病，读者有理由怀疑它没看见对方的好处。这两句话几千年来被无数父母、老师、掌柜、师傅挂在嘴边，不是因为大家糊涂，是因为它们在一些具体的地方，确实干成了事，别的话干不成。本章逐一认账，认出四样。每一样都是它实实在在干过的活。

◆二、止手：把冲动拦在半空

第一样功劳，是止手。人在气头上，手比脑子快。孩子推人，大人也一样：一个司机被别的车别了一下，手已经按在喇叭上；一个人收到一条气人的消息，一大段话已经敲了一半，拇指悬在发送键上方。这时候不需要大道理，需要一个短而硬的东西，在手落下去之前把它拦住。“己所不欲，勿施于人”正是这样的东西：开头一个“己”字，把目光从对方身上拽回自己，只要拽回来那么一两秒，这一两秒里，也许就够让火降下去一点。

设想社区卫生服务中心的候诊椅上有人插了队，排在后面的人不吵，只问一句：“换成你在后面等，愿意被人插到前头吗？”插队的人多半不好意思，往后退一步。这也是止手，不用讲理，只用一个问句。

它能干这个活，有几个原因。第一，它短。八个字，孩子背得下来，吵架吵到一半的大人也想得起来。第二，它用的是否定式，“勿”。禁止的话比要求的话容易执行，因为要求你“怎样去做”，得先想办法，禁止你“别这样做”，只需要停下。有学者把否定式称作最低限度的道德要求，说的正是这一层：这是一道最低的线，低到几乎每个人都做得到。第三，它不需要你懂得对方。刹车不需要懂地形，只要你愿意踩。一个暴怒的人、一个刚冲动完的孩子，没法一下子理解对方的处境，可他想象一下“如果是我”，通常还办得到。

想想这件事的分量。一个社会里有多少暴力，是在冲动的那几秒里发生，又有多少暴力，是因为恰好在那几秒里有人想起了这句话而没有发生，没有人统计过，这里也不敢报数。可以说的只是：这一样功劳最扎实，因为它向人要的东西最少。

◆三、开手：对陌生人先动一步

第二样功劳，是开手，也就是第二句话“你们愿意人怎样待你们，你们也要怎样待人”所做的事。止手管的是别伸手去伤人，开手管的是主动伸手去帮人。两件事方向相反，缺一不可。

想一个车站的场景，同样是构想的。一个提着两只大箱子的年轻女人站在天桥楼梯下面，箱子沉，楼梯陡，她仰头看了看，有点犯愁。一个路过的中年人没有认识她，也没有人托他，他放下手里的包，说了句“我帮你抬一头”，两个人一人一边，把箱子抬了上去，道一声谢，各奔东西。这件事里没有任何亲缘，没有任何交情，也没有任何人要求。他凭什么动？凭的是心里那个朴素的念头：要是我提着两只箱子站在那儿，我多盼着有人搭把手。

没有这个念头的世界，会是另一个样子。大家只管着别伤害别人，各自守着自己的一寸，谁也不犯谁，同时谁也不理谁。“勿施”可以让人做到互不相害，做不到互相伸手。陌生人之间的好意，需要一个由头，而肯定式的这一句，给了这个由头：你自己盼的，就是别人盼的。《利未记》19:34里有一句话，针对的恰是陌生人：“和你们同居的外人，你们要看他如本地人一样，并要爱他如己，因为你们在埃及地也作过寄居的。”对外来的人，理由很清楚，你曾经就是那个外来的人，你知道那是什么滋味。这是读经文的语言处境，只讲这句话怎么给陌生人开路，不作别的判断。

宾默尔在2001年的一篇文章里说过，“己所欲施于人”一类的公平习惯，在人类的演化中已经牢牢扎根，我们常常照做而不知其故。他的文章里有一句：“当你自己也可能落在队尾时，先到先得就不那么吸引人了。”这话说得很实在，放在排队上尤其好懂。人们愿意把方便让给后来的人，不一定因为人人都是圣徒，也可能因为每个人都想过，自己有一天可能是那个站在队尾的人。这一句话在日常里，几乎时时刻刻都在干活，只是它干得太自然，我们不觉得是它。

◆四、借条：把前人的经历借给没经历过的人

第三样功劳最容易被忽略，可也许最了不起。操场上那位老师的问话，其实是在做一件事：把别人的经历借给孩子。

一个人的经历是用日子换来的。被人欺负是什么滋味，被冤枉是什么滋味，被冷落、被抢走东西、被当众羞辱是什么滋味，这些滋味要一一亲身尝过才知道，学费很贵。可人类有一个办法，把许多人许多代尝过的滋味，压缩成一句话，提前借给还没尝过的人。“你愿意被打吗”就是这样一张借条：出借的是无数个被打过的人，借条的内容是被打的滋味，借的人是一个只想着“他先惹我”的十岁孩子。他不必真被打一回，就能提前知道，那一下落在别人身上是什么分量。

第3章提到过希勒尔的故事，这里把它讲全（据一般记载，只取大意）：一个外邦人对希勒尔说，你能不能在我用一只脚站着的这点工夫里，把全部律法讲给我听？希勒尔的回答，大意是：你所憎恶的，不要施于你的同伴，这就是全部律法，其余都是注释，去学吧。这个故事妙在两处。一处是，它承认有人没有工夫、也没有机会把所有经历都过一遍，要一条能立刻拿走的东西。另一处是，故事的最后一句不是“你已经学完了”，是“去学吧”。借条是个开头，不是全部本钱。孩子常常记不住道理，却记得住一个问句，因为问句要他自己去答。

借条的好处，是让没经历的人少走弯路。借条也有一个小小的条件：借的人心里得有一点相应的本钱，才能把借来的话兑成真东西。孩子被问“你愿意被打吗”，能够触动他，是因为他自己多少挨过一点推搡，哪怕早已忘记；一个从未体会过任何疼的人，听这句话也是一句空话。所以借条最好用得及时，也最好有一天换成自己的经历。后面几编会讲到借条什么时候借多了，这里先不说，这里只认账：它借出去的，在大多数时候，是实打实的好东西。

◆五、兜底：对方开不了口的时候

第四样功劳，是兜底。有些时候，对方没法告诉你他要什么。构想一个场景：菜市场口，一位老人突然倒在地上，不省人事。围上来的人七嘴八舌，有人喊叫救护车，一个年轻人已经跪下来，开始做胸外按压。没有人问老人一句“你愿意我按你的胸口吗”，也没法问。按压会很用力，可能压断肋骨，也许他醒来会疼得骂人。可是没有人犹豫，因为每个人心里的回答是一样的：要是倒在地上的是我，我一定盼着有人这样做。昏迷的人、刚出生的婴儿、高烧说胡话的病人，都属于这一类。他们开不了口，旁边的人又不能无动于衷，那就只好问自己：我若在他的处境，会要什么？

这时候“你们愿意人怎样待你们”这句话，成了一个替身，替那个无法被提出的问题作答。婴儿哭了，我们喂、换、抱，凭的是“若是我这样哭，我盼着什么”；急救现场，凭的是“若是我躺在那里”。在危急又无从问起的时刻，这条路最可靠，也最人道。把它称作兜底，是因为它是一张网，兜住了其他办法都够不着的地方。

还要说一句边界，免得这一样功劳被说过了头：兜底是替身，替身有个本分，等对方睁开眼、能开口了，替身就该退场。这一点留到后面细讲，这里只记一笔：兜底的功劳不假，它的有效期，却是从对方开不了口，到对方能开口为止。

◆六、四样功劳有什么共同点

把四样放在一起看，它们有一个共同点，不那么明显，却很重要。

止手，发生在对方还没来得及说话的时候，手已经要落下去了。开手，发生在对方是个陌生人的时候，你对他一无所知，也没法先问一问。借条，发生在孩子还没有这份经历的时候。兜底，发生在对方根本说不了话的时候。四种情形都有一个共同的背景：关于对方，你来不及知道，或者没法知道。在这样的背景下，一句简短的话，让你以自己为尺，先动一步，先停一步，这是一个聪明、体面、有效的起手。

所以这两句话的功劳是实打实的，不需要依赖它“放之四海而皆准”的名声才站得住。它在止手、开手、借条、兜底这四个具体的岗位上，每天都在干活，干得很好。一个东西能不能被敬重，要看它做了什么，不看它被封了什么头衔。本书之所以要把它从“普遍真理”的位置上请下来，是因为那个位置对它不公平：站在那里，它被要求做所有它做不了的事，而这四样它本来做得最好的活，反倒被遮住了。

那么，对方能开口、能解释、能自己讲出他要什么的时候，这两句话还一样灵吗？孩子长大了，爸妈老了，徒弟出师了，这时候再用“以我为尺”，会怎样？这是接下来要问的问题。

**带走的话**：止手、开手、借条、兜底，是这两句话实打实的四样功劳，都发生在对方来不及开口或无法开口的时候。

**这一章怎样算错**：若有人能证明，被问“你愿意被打吗”的孩子，并没有更少动手，或者这四样事不靠这两句话也一样做得成，这里的认账就要重算。

**本编收口**：这一编从一句话的名字讲起，问它怎样成了“普遍真理”：“黄金”这个名号很晚才有，一路被抬进宣言和全球伦理；各家说法相似，却不是同一句话；人们举例总举杀、偷、骗，那是谱系最窄、差异最小的一段，句子在那里灵验，便把灵验说成了处处灵验；美、真、善三样又焊在一起，互相作保，谁也不用单独接受检查。同时，它的功劳实打实：止手、开手、借条、兜底，每一样都救过人，值得敬重。它在原处从来不是什么普遍真理，普遍性是一段上的值被说成了全谱的值。这是一个错觉，没有人在骗谁，错觉本身也有它的来路和好处。要弄清错觉从哪里来，只能把句子放回当年的处境，看是谁对谁、在什么争执里说的。它当年是对一个具体的人说的，说的时候还带着前后的话，后来才被剪成了单独的一句。下一编，我们去原处看。
