# 第50章　接累，不接关口，帮他长出词

◆一、进门那一声“累”

这是构想的场景。晚上七点多，段建军下班进门，鞋还没换好，就靠在门框上说了一个字：“累。”苏晓红正在盛饭，听见了。这个字在一个家里每天都会响起，大人说，孩子也说，说得太多，就没人再追问它是什么了。

第32章讲过孩子说累的情形，这一章不重讲。换到大人身上，换到夫妻之间、同事之间，同样的事照样发生，而且更难，因为大人的“累”后面常常没有人敢追问。孩子说累，大人还会问一句；丈夫说累，妻子往往只会递一杯水，或者说一句“那你歇着吧”。这两个反应都出于好心，都没有错，但是这一章要讲：好心在这里分了岔，岔路口的两边，一边把他的累接住了，一边把他的关口也一并接走了。

建军这一声“累”说得很轻，鞋带还没解开，眼睛也没有看谁，更像是对着门框说的。这样的字最容易漏过去，因为它不是对谁说的，听的人可以当没听见。当没听见的那一秒，就是这个晚上第一个岔路口：晓红回不回头，决定了这个字落在地上，还是被捡起来。

先说“关口”。这里用它指的是一件事里正好卡住的那一步，是矛盾累积到最紧的那一处，也是人最可能长出新东西的那一处。累和关口常常缠在一起，从外面看不出来。接累的意思，是接那份身体上的消耗、心里的怕、被磨掉的耐心；不接关口的意思，是这一步仍然要他自己过。两样分开，才谈得上帮忙；分不开，帮忙就成了代走。

◆二、累里捆着什么

建军这一声“累”，里面可能捆着好几样东西。站了十个小时的腿和腰，这是身体的报告。一个孔位怎么都对不上，对了三遍还是不对，这是卡住。下午被人当着徒弟的面说了一句，心里一直压着，这是烦，也可能是委屈。下个月订单少了，不知道奖金还有没有，这是怕。四样东西挤在一起，压成一个字，出口就是“累”。

为什么偏偏说“累”？第32章讲过孩子的原因：词不够用，而且这个词最安全。大人的原因多一层。说“我卡住了”，可能被问一句“你怎么连这个也弄不好”；说“我怕下个月没奖金”，要把一家人的心都吊起来；说“累”，没有人会追究，还自带几分功劳的意思：我累，是因为我撑着这个家。所以大人的“累”有时兼着另一件事，是想被看见。这时候他要的不全是被拆开，先要的是一句“看见了”。看见之后再问，才不显得是盘问。

结果就是，同样歇十分钟，有的累好了，有的没有好。腿和腰歇一歇就缓过来；孔位还是对不上，歇完以后第二天又摆在那里。词切得太粗，歇和不歇都对不准那一块。第32章的拿走测试，在大人身上照样用得上：假如这个孔位现在对上了，还累吗？换成他喜欢的事，比如周末到河边钓鱼，还累吗？拿走孔位就不累，钓鱼也不累，累缠在孔位上；什么都累，累就在身体里。

外面那两套话，“别累坏了”和“吃得苦中苦”，在大人这里同样在抢这个字。一套看见了身体的代价，一套看见了磨炼的价值，各有看对的地方。累本身没有善恶，它只是一个压缩的字，谁抢到了它，谁就替他决定了它是什么意思。

◆三、接的三种样子

晓红听见这个字的时候，大概会有三种接法，外加一种接过头的接法。先说三种。

第一种叫顶回去。晓红手里端着饭碗，随口说：“你累什么，我今天一天不也跑了三家？”这句话在夫妻之间极常见，它甚至不带恶意，是一种比较：你累，我也累。可是顶回去的效果是，“累”这个字变成了不能说的字。建军下次进门，会改说“没事”。累没有消失，只是被压回去了，压成一个更小的、更硬的东西，在以后某个更糟的时候冒出来。

第二种叫沉默。晓红“嗯”了一声，端着碗转身，建军换了鞋，坐到沙发上刷手机，一顿饭谁也没有再提。这种接法最难看出是接法，因为它看上去什么都没做。可是建军从中学到了一件事：说了也没用。这个“没用”会一直沉在他的底下，下一次他连这个字也不说了。

第三种叫接住。晓红把碗放下，问了一句：“从哪一下开始觉得累的？”这一句不是安慰，也不是反驳，是把那个压成一团的字递回给他，让他自己拆开。接住的意思是接住这个字，不是接过这件事。字被接住，它能还原成它原来的样子。

还有一种，是接过头的接住，最容易被当成体贴。晓红说：“那你歇着，碗我洗，孩子我管，明天厂里的事你也别想了。”这一整串话没有一句不暖心。可是“累”就此变成一张免做券，凡是令他不舒服的东西，他都可以凭这张券不去碰，包括那个对不上的孔位，包括那句没有回应的话。他的累被接走了，连同关口一起。好心越周到，关口被接得越干净。

再换一个场景，看同事之间。这同样是构想的，小冉是为这个例子另起的名字：晓红的同事小冉，二十五岁，在卫生服务中心刚满半年，这天要第一次一个人去给一位独居老人做上门随访。回来以后，她坐在休息室里说：“累死了。”晓红如果是个热心的前辈，最容易的办法是说：“下次我去，你在中心整理资料。”小冉松一口气，这个老人的门，她再也不用去敲。关口是那扇门后面的第一句话，被前辈接走了。

◆四、问序列，不递答案

接住的办法是问序列。序列是一个人经过的先后，问他“怎么走过来的”，不问“结论是什么”。上面那句“从哪一下开始觉得累的”就是这一类。继续往下问，还可以问：这一天里最重的是哪一段？那一下之前你在做什么？之后呢？回来路上是什么时候松下来的？如果这个孔位现在对上了，你还觉得累吗？

这里有一个纪律：只问序列，不递候选答案。“你是不是又被谁说了？”“是不是下个月奖金的事？”这样问，看起来是关心，实际上是把一个答案放到了他手里。他累了一天，很可能顺手接过来说：“嗯，是。”问题就此结束，缠着他的东西没有出来，却已经有了一个被承认的名字。夫妻之间尤其如此，一方给的答案，另一方往往不愿意反驳，因为反驳要多费一口气。

序列问下去，词就慢慢长出来。建军也许说：“不是人累，是那个孔位，我对了三遍，每次差一点点，我心里发虚。”这就比一个“累”多出了很多：孔位，三遍，差一点点，发虚。这里面的“发虚”就是他自己长出来的词，它不是妻子递的，是他的。下一回，他有可能不再说“累”，而是说：“我今天卡在一个孔位上。”这个词出来了，他自己的路就看得见了，那条路上要接什么，也就清楚了。

接什么，要看拆出来的是哪一样。困了，接人：先睡，早点起，明天再说。卡在一步上，接一步：问他卡在哪儿，听他讲，必要时一起把问题说清楚，然后把问题还回去。要害在还回去，别替他对孔位。烦，且确实是纯消耗的那一类，比如反复填没有人看的表格，接那份消耗：陪他想一想跟谁商量减一减。怕，接那份怕：陪着，让他知道不如意也不会塌。小冉的事就是后一类：晓红可以陪她在休息室里把上门的第一句话演练一遍，甚至问问她敲门时怕的是什么，然后让她自己去敲。那次演练只花了十分钟，小冉把第一句话改了三遍，从“我是中心的小冉”改成“大爷，我来看看您的药够不够吃”。第二天她敲了门，老人问她是不是新来的，她说是，老人让她进了屋。她回到休息室，这回没有说“累死了”，说的是：“那个大爷的茶太浓，我喝了半杯。”同一个人，同一个下午，那个压成一团的字散开成了一件具体的事。手受了伤、人生了病，替他做是该做的，那是另一回事。

不妨把接住的那一晚完整走一遍。晓红放下碗，没有急着坐下，只是靠在灶台边问：“从哪一下开始觉得累的？”建军愣了一下，说：“下午吧。”“下午哪一会儿？”“三点多，那个孔位。”“对了几遍？”“三遍。”到这里他自己停了一下，说：“其实人也还行，就是那个尺寸，我老觉得它在笑我。”晓红没有说“那你明天再弄”，也没有说“徒弟都看着呢”，她问了最后一句：“要是现在它对上了，你还累吗？”建军想了想，说：“不累。去河边坐坐都行。”

这一晚的收获，不在孔位有没有对上，孔位明天还是要他自己去对。收获是：他知道了自己累的是哪一块，而且是用自己的词说出来的。晓红接走的，是这一块之外的东西：她把饭热了，让他先吃，让他早点睡，孩子的作业她来看。关口留在他手里，累被接走一部分，他明天早上站在那台机器前面，是有力气的。

再说回写。三种接法给对方留下的是三样不同的东西。顶回去，留下的是“这个字不能说”；沉默，留下的是“说了没用”；接住，留下的是“说出来有人听，而且我还能把它说得更清楚”。每一次接，都在改写下一次他开口的方式。同事之间也一样：小冉被前辈接走了那扇门，学到的是“难的事会有人替我”；被陪着演练了第一句话，学到的是“难的事我能走过去”。夫妻之间的日子很长，一次的接法不算什么，一年的接法就成了这个家里“累”这个字的用法。

◆五、边界：不是审问，也不是万能

最后要说几条边界。第一，不要把这套问法当成审问。进门第一秒、刚坐下、饭还没吃的时候，是不适合问的。要等他松下来，要看他有没有话想说。他说不想说，就停，留一句“你想说的时候我在”。门别关，是这个办法里最要紧的东西。

第二，累不总是藏着什么。有时候就是累，一个人站了十个小时，累就是累，这时候最好的接法是让他睡。把一个简单的累拆成五样，是另一种折腾。拿走测试就是为了判断这一点：什么都不累的时候，也许只是身体要歇。

第三，累也可能不属于这套办法。如果一个人连续好几周都说累，睡不好，对什么都提不起兴致，情绪一直低落，不想上班，这时候要找医生或者专业人士看一看，不要自己在家里拆词。本书不作诊断，也不提供治疗建议。

第四，问法也带着问的人的神色。同一个“从哪一下开始”，由一个平时爱评判的人问出来，对方只会觉得是在盘问。接累不接关口，不止是一句话，是整个人的神色：愿意等，愿意听完，听完不急着说“那你应该”。

回头看，整套做法有一个很小的核。一个人的矛盾在某处累积到了该逼出一点改变的地步，那个地方就是关口；接累的人把消耗接走，让他有力气站在关口前面；接关口的人则把这个改变替他做掉，矛盾被压平，回写也跟着丢了。这是第45章讲的第一种熄火在大人身上的样子。善的接法让压缩的字能还原回去，由他自己说出下一个词。下一章要讲的，是怎样把这些读数留下来，把退路也留下。

**带走的话**：活和累分开：困了接人，卡了接一步再把题还回去，烦的纯消耗接消耗，怕了接怕；问序列，不递答案，让词自己长出来。

**这一章怎样算错**：如果追问本身成了新的压力，对方为了应付而编出一个词，或者他其实只是困了而被拆成五样折腾一晚，本章的判断就不成立。
