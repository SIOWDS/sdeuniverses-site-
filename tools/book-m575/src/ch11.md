# 第11章　四个“未能”和一把尺子

谢文海四十一岁（构想的人物），在县城一家五金店当店长，儿子上初二，晚自习后总要磨蹭到九点半才到家。那天九点四十还没见人，他站在楼下的路灯底下，手机攥在手里，心里把要说的话过了三遍：你知不知道几点了，你知道我们多担心，你自己说，要是换了你等一个人等到这个点，你什么滋味？话刚在嘴里排好，他忽然愣住了。三十年前，他的父亲也是这样站在老屋门口，他也是这样晚归，也被这样问过一遍，当时他在心里回的是：你们管得也太宽了。

三十年过去，他站到了父亲站过的地方，同一句话几乎一个字不差地涌了上来，只是这一回，他知道那句话里装的是什么了。当儿子的时候他听到的是管，当爹的时候他说出的是怕。两个人说的是同一句话，位置换了，话的分量也换了。这件事每个人都有过，常被说成一句老话：养儿方知父母恩。

这样一种“换了位置才懂”的经历，和“己所不欲，勿施于人”有什么关系？前面几章把这句话从仲弓、子贡那里请回了原处，这一章翻开它的两个近邻：《中庸》里紧挨着它的那几句话，《大学》里把它展开成六条的那一段。两处都没有让这句话更响，只让它有了地址：上下前后左右，子臣弟友。位置是怎样进入这句话的，两本书各自走了一步。

◆一、紧挨着的那几句话

《中庸》第十三章里，这句话的出处是这样的：“忠恕违道不远，施诸己而不愿，亦勿施于人。君子之道四，丘未能一焉：所求乎子，以事父，未能也；所求乎臣，以事君，未能也；所求乎弟，以事兄，未能也；所求乎朋友，先施之，未能也。”

先看开头这一句，它和《论语》里的写法几乎一样，只是换了说法：不是“己所不欲”，而是“施诸己而不愿”，加在自己身上而自己不情愿的，不要加给别人。第313号《一的宪章》（解构《中庸》）读到这里，抓住的是它的否定式。这本书的说法是：否定式在设计上像一条防火墙规则，不像一条服务规则。服务规则要满足对方，就得知道对方要什么，信息需求高，猜错的风险也高；防火墙规则只承诺不伤害，只需要知道自己不要什么，信息需求低，稳健得多。在对方的情形永远不能完全知道的现实里，否定式的误伤率远低于肯定式：“不知道你要什么，但至少不把我不要的塞给你。”这是我们要先接住的一笔。《中庸》在这里没有写“你要为别人做什么”，只写“不要把我不愿的加给你”，它选的是最谨慎的那一种说法，这份谨慎该得到敬重。

同一本书也记下了这种谨慎的残余风险，这里只转述它的原意：否定式仍然靠“我所不欲，就是人所不欲”这个支点在推理，那个“人同此心”的假设，只是从“欲的全集”降到了“不欲的子集”，被降了维，没有被拿掉。假设什么时候出问题？该书举的情形是：我不愿受约束，所以不约束你，可你恰好需要约束；我不愿被直言，所以不对你直言，可你恰好需要听一句直话。到这一步，这条规则自己是察觉不出的。

这一段读下来，有一点值得停一停。防火墙规则不问对方是谁，它只检查“我不要什么”。可是紧跟着这条规则的，却是孔子的四个“未能”。《中庸》把一条看上去不问位置的规则，和四句明明白白写着位置的话，放在了一起。

◆二、四个“未能”：孔子的自报

“君子之道四，丘未能一焉。”君子的路有四条，我孔丘一条也没有做到。这句话本身就够叫人停下来：立法的人，亲口报自己不及格。

四条是这样的：“所求乎子，以事父”，我要求儿子怎样对待我，我就该怎样事奉自己的父亲，我没做到；“所求乎臣，以事君”，我要求臣下怎样对待我，我就该怎样事奉自己的君主，没做到；“所求乎弟，以事兄”，我要求弟弟怎样对我，我就该怎样事奉哥哥，没做到；“所求乎朋友，先施之”，我希望朋友怎样待我，就该先这样待朋友，没做到。

第313号对这四句有一段细读，我们照着它的意思走一遍。它先指出，四句用的是同一个句式，“所求乎甲以事乙”：我希望处在甲位置的人怎样对我，我就拿同样的方式去对待处在乙位置的人。甲和乙是一对一对的角色：子和父，臣和君，弟和兄，朋友和朋友。所以这四句话是在演示“恕”这个算法怎么在五伦的网络里运转：沿着角色的对偶做换位，把我在这一头的期待，翻成我在那一头的义务。

接着是该书读出来的一个方向。四句话里，换位的箭头一律指向尊者：求于子，事于父；求于臣，事于君；求于弟，事于兄。明文上，恕是对称的，己和人互换；落到具体的伦理网络里，它却是单向跑的，期待放在下位的人身上，履行放在上位的人面前。该书的解释是：网络本身不对称，对称的算法跑在不对称的结构上，结果自然不对称。第四句不一样。朋友是五伦里唯一对称的一伦，而它的措辞也独独不同：“先施之”，先手做。该书因此说，只有这一点跑出了最初的设计。以上是前作已经说过的，本书接住它，不再往前加。

◆三、位置在这四句里是怎么进来的

下面一段是本书自己的读法，要标明。请看四句话里每一个人的处境。说“所求乎子，以事父”的孔子，同时站在两个位置上：他对自己的儿子是父亲，对自己的父亲是儿子。这一句话的整个重量，落在这两个位置之间的那道落差上：做父亲的时候，我清清楚楚知道自己希望儿子怎样；做儿子的时候，我没有照着这个标准对待我的父亲。落差不在道理上，道理他明白，落差在位置上：站在这头的时候，我所求的东西才看得见；站到那头去，它就不再那么显眼了。

这就是谢文海站在路灯底下的处境。他当儿子的那些年，不是不懂道理，他懂：父母关心我，我该体谅。可是“该体谅”三个字是从道理里推出来的，“怕”这个东西是从位置里长出来的。直到站到楼下，他才知道一句“你知不知道几点了”的底下压着多少说不出口的东西。孔子的“未能”，说的也是这件事：换位这种事，知道它的算法，和真的挪到那个位置上去，是两回事。

所以我们可以这样读：《论语》里的那句话，在仲弓那里虽然是对一个将要管人的人说的，句子里的“人”却仍是笼统的“人”，没有分出上下前后。到了《中庸》，这句话被摆进了四对具体的角色里，位置第一次一对一对地写了出来，同时写出来的还有一件事，就是连说话的人也没有做到。位置进来了，带来的是落差，而不是保证。这四句话没有一句在教人“换位就能懂”，它们说的是：换位是一件要走一辈子的事，创立者自己也没走完。

◆四、一把尺子：絜矩

《大学》传十章把同一件事换了一种写法：“所恶于上，毋以使下；所恶于下，毋以事上；所恶于前，毋以先后；所恶于后，毋以从前；所恶于右，毋以交于左；所恶于左，毋以交于右：此之谓絜矩之道。”

絜是度量，矩是画方的曲尺。六条，一条一个方向：上下，前后，左右。拿第一条来说：我不喜欢上头怎样对待我，我就不要这样去使唤下头。第二条是反过来：我不喜欢下头怎样对待我，我就不要这样去事奉上头。第一条“所恶于上，毋以使下”，正对着仲弓那样一个将要管人的人：他在上面受过什么气，就别拿同样的气去撒给下面。

第314号《一的总装线》（解构《大学》）对这一段有几处细读，本书照着它的意思转述。头一处，是它指出这六条和《中庸》四个“未能”在写法上的分工。四个“未能”按名分列项，子、父、臣、君，是社会上的位置；絜矩按方位列项，上、下、前、后、左、右，是几何上的位置。名分表里站着具体的人，方位表里只有“上”“前”“右”，不问上面站的是谁。该书因此说，方位化意味着去人格化，这是向“可以度量”迈出的一步。它还指出，《论语》给的是一条原则，《大学》给的是格式：把单句展开成六条，加上坐标。

第二处，是前后两条。“前”和“后”在这里不指空间，只指次序：走在我前面的人，跟在我后面的人。该书的读法是，絜矩在这里给次序加了一道对称的规程：先到者所受的恶，不许转嫁给后到者。本书借一个家常的例子来说：新来的学徒被老师傅呵斥过，轮到他带下一个学徒的时候，不要把那份呵斥原样搬过去。

第三处，是朱熹的注，该书特地指出，朱注自己讲这六条的时候，就是拿度量的话在讲：不愿上头怎样待我，就用这个去量下头的心，不敢这样使唤他；上下四旁，长短广狭，都要平均方正。所以把絜矩读作“一套尺度”，不是后来的人强加的，朱子先这样读了。

接住这几处，要说一句公道话：把一条泛泛的箴言，变成上下前后左右六个方向、条条可查的规程，是中国伦理思想里很了不起的一步。它让“推己及人”从一种心意，变成一把可以拿在手里的尺子。

◆五、尺子上的刻度是谁的

尺子拿在手里，要问的是刻度从哪里来。第314号在这个问题上说得很直：絜矩度量的基准是“所恶”，也就是量的人自己的好恶。公尺不属于任何人的手臂，絜矩这把尺子却是长在每个人自己身上的，各人的刻度各不相同，彼此不能直接对照。该书称之为基准的“不可公度”，并且把《中庸》四个“未能”和《大学》的这把尺子并在一起，说它们是同一个原则的两半：一半是宪法，给原则；一半是工艺，给仪器。

该书也替絜矩做了辩护，本书一并转述，因为这样才公平。辩护说：基准虽然各人自带，但约束是交叉的，我的所恶约束我下头的人，下头人的所恶约束我，一张网上的基准互相咬合，也就有了某种事实上的公度。而且人所恶的东西，比人所好的东西更趋同：痛、饥、辱、被欺，各人的清单重叠得多。该书承认这是一个有分量的辩护，同时指出它依赖三个前提：每个节点都在做翻转；邻位之间有通道知道对方所恶；位与位之间的落差有汇率。三个前提，文本都没有明文保证。所以该书的结论是，絜矩有走向公度的方向，它还不是一把已经造成了的公度的尺。

最后还有一条登记：六个方向之外缺一轴，内外。边界之外的人，絜矩的坐标系里没有位置；该书找过反例，在《大学》本段和邻近文本里，没有找到格式同型的跨界条款。

◆六、位置给了什么，没有给什么

把两本书并在一起读，可以得到一个清楚而有限的结论。位置给了这句话地址。在仲弓那里，它是对一个人说的；在《中庸》里，它被写进子臣弟友四对角色，说话的人还承认自己没走完；在《大学》里，它被写成六个方向，成了一把可用的尺子。越往后，位置写得越明白。这是有价值的：一个人站在“上”的位置，翻开絜矩的第一条，立刻知道这句话在对他说什么。

可是位置没有给的东西也很清楚。无论是四个“未能”还是六向的尺，量的仍然是“我所不愿”。第一节记下的那个残余，在这里原样还在。我在上头受过的气，我不让下头受，这当然是对的；但下头那个人此刻怕的是什么、要的是什么、怎样算账，这把尺子没有安排去问。谢文海站在路灯下，他知道了父亲当年的怕，这是位置教给他的；可他的儿子此刻为什么磨蹭到九点半，是赌气，是球没打完，是在班上受了冷落，他靠“我当过儿子”是推不出来的。位置让他知道有一种怕，没有告诉他这一回儿子是哪一种。

当过那个位置的人是不是就一定更懂、更宽厚，第23章会专门来看，现在先不抢。本章只留一个判断：位置让这句话从泛泛的“人”落到了具体的上下前后左右，这是它在原处境里实在的一步；而量尺上的刻度始终是量的人自己的，从《中庸》到《大学》没有变。

儒家的经典读到这里。山上还有另一个“所以”：同样是一句人人皆知的话，在福音书里，它的前面有什么，后面有什么，说话的对象是谁，留给下一章。

**带走的话**：位置给这句话装上了地址，子臣弟友、上下前后左右；可尺子的刻度仍是量的人自己的，位置让人知道有一种怕，不告诉他这一回是哪一种。

**这一章怎样算错**：如果《中庸》四个“未能”的读法、絜矩以己心好恶为基准的读法被前作原文推翻，或者能举出絜矩本段里有一处要求先去问对方所恶的明文，本章“位置进来了，询问并没有进来”的判断就不成立。
