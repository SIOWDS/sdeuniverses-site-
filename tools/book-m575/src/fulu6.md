# 附录六　陪读人物小传

先说一件要紧的事：这一页的所有人，全部是构想的。沅安这座南方县城是构想的，茶厂老宿舍是构想的，下面每一个人，连同他们说的每一句话、做的每一件事，都是为了说明机制而设，不是真人真事，也不是任何真实人物的影子。构想的案例只作说明，不当证据。书里偶尔另起名字的配角，同样是构想：第46章的汤阿姨和对门的小宋，第50章晓红的同事小冉，第52章的谭校长，都是为各自一章另起的名字，不在上面的陪读人物之列，只出现一次。

**段一鸣**　十一岁，五年级，爱打球，语文一般，数学卡在分数。他是全书的中心陪读：作业、“累”，以及饭桌上的几场争执，大半是围着他展开的。他不是一个有问题的孩子，只是一个正在长的孩子，他的“累”和“没事”，常常压着一束话。

**苏晓红**　一鸣的妈妈，四十二岁，社区卫生服务中心的护士，心疼孩子，干脆利落。她做事快，下手准，护士的本事让她习惯了“看见就处理”。她是全书里最典型的好心人：每一次翻转里，她的心疼都是真的。

**段建军**　一鸣的爸爸，四十五岁，模具厂技师，带徒弟，话少，脾气急。他在厂里教徒弟，在家里不太会教儿子。他的一句“写个作业哪有那么累”，既是老交情，也是一道关门的声音。

**郑桂英**　奶奶，七十二岁，同住，年轻时受过婆婆的气，腿脚还行，爱进厨房。她是书里“人轮此位”的活例子：当过媳妇，现在是婆婆，位置轮过了，她记得多少，又丢了多少，要看具体的事。

**苏德厚**　外公，六十八岁，退休语文老师，住城东。第35章他刚确诊，瞒不瞒他，由家里争。他是书里“事实”与“善恶”要分开讲的那个人；这本书只用他的处境说明问题，不写他的医疗细节。

**苏晓青**　小姨，三十八岁，在深圳，常往家寄保健品，深夜常跟手机上的机器说话（第36章、第44章）。她的好心隔着千里，用的是包裹和转账，她的焦虑也一同寄了出去。

**小彭**　二十三岁，段建军的徒弟，第一副模（第39章），下班刷短视频（第42章）。他是新人，第一副模是他的关口，下班刷的短视频也在书里出现；被师傅“接过去”的活，和被平台“推荐”的内容，都落在他身上。

**姚师傅**　六十岁，厂里老师傅，“我当年也这么熬过来的”（第40章）。他的苦是实在的，他的善意也是实在的，问题只在：他把自己那一份苦，原样递给了别人。

**贾厂长**　模具厂老板，“为你好”的加班和年终考核（第41章）。他不是反派，他有一本账，账里的每一栏都合理，只是被记账的人没有笔。

**钟老师**　一鸣的班主任，三十八岁，语文老师，不当众批评学生（第34章）。她把“不批评”当作保护，有的学生把它读成“老师不管我了”。

**田姐与田田**　田姐是苏晓红的同事，田田是她的女儿，两人出现在琴行门口（第33章）。田姐小时候没学成的琴，在田田身上被重新想了一遍。

**小罗夫妇**　隔壁302的一对夫妻，楼道里偶尔传出哭声（第43章）。他们是“勿施”变成袖手的那个场景里，被隔着一堵墙听见的人。

最后，一个提醒：这些人物的名字和性格，是为了让机制看得见而设。书里的每个选择都有别的写法，读者完全可以把他们换成自己家的人，换成自己的同事，再检查一遍。
