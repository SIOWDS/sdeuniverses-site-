# 第18章　同一个字：符号的谱系

十一月初，沅安下了第一场冷雨。晚饭后，十一岁的段一鸣在客厅里打完了一场楼下的篮球，一身汗，头发贴在额头上，T 恤后背湿了一片，正站在窗边拿冷水冲脸。妈妈苏晓红下班回来，在门口换鞋，一眼看到这个场面，说了一句：“这么冷的天，你就穿这个？去把秋裤穿上。”一鸣头也不回：“不冷。”妈妈提高声音：“怎么会不冷！”一鸣说：“我不冷！”两个人在同一个房间里，说着同一个字，一个说有，一个说没有，各自都觉得对方不讲理。（这是构想的场景，人物也是构想的。）

这一幕看着像一个小争吵，其实是一个符号学的小事故。妈妈说的“冷”和一鸣说的“冷”，字是一个字，指的却不是一个东西。这一章就拿这条裤子说话，说清一件事：同一个字，可以指向很不一样的东西，两句话假定它指向同一个。

◆一、妈妈的“冷”和孩子的“冷”

先听妈妈的。她在社区卫生服务中心上班，每年一进十一月，门诊里就排满了咳嗽流涕的孩子，有的家长一边抱着孩子一边念叨“早知道就多穿一件”。降温的这个晚上，她下楼的时候风灌进领口，打了个寒战，回到家看见孩子湿着头发站在窗边，一句“冷”脱口而出。这个“冷”里装的是什么？是她自己的寒战，是门诊里那些孩子，是“万一感冒了怎么办”，是一个当妈的人对孩子身体的一团放不下的心。换成更准确的话，她说的“冷”，是担心。

再听一鸣的。他刚跑了四十分钟，心跳还没缓下来，后背在冒热气，脸上的水是他自己冲上去的，因为热。他说的“不冷”，是体感，是皮肤和身体此刻报给他的一个读数。他一点也没撒谎，那个读数是真的。

所以这场争吵里，其实没有人说错。妈妈的担心是真的，一鸣的体感也是真的，两个真东西，被同一个字拖到了一起。字一样，两个人就以为在谈同一件事，谈不拢，就各自认定对方不讲理：妈妈觉得孩子不听话、不懂事，一鸣觉得妈妈不看人、乱管。

◆二、名是个指针

第17章说过，名字是把一束东西叫成“一个”。现在要往前走一步：名字不是那束东西，是一个指针，指向一束东西。指针指到哪里，要看是谁在指、在什么时候指、指给谁看。

这一点其实人人都知道，只是写进句子里就容易忘。“好”这个字，是最典型的。妈妈说“你要做个好孩子”，老师说“这个同学很好”，一鸣的同桌说“他人挺好的”，三个“好”字，一个指听话，一个指成绩和纪律，一个指愿意把橡皮借给别人。同一个孩子，在三双眼睛里，被同一个字指向三个不同的东西。“累”也是这样，孩子说“累了”，有时指身体困，有时指一道题卡住了，有时指不想面对爸爸的脸色，这一条第32章会专门拆开来看。

再小一点的字也是这样。奶奶问晚饭吃什么，一鸣说“随便”，意思是你做什么我都吃；爸爸段建军下班回来，被问同一句，也答“随便”，意思是别再问我了。奶奶要是把两个“随便”都听成“不挑”，给爸爸端上一桌她以为随便的菜，爸爸多半吃得心里不是滋味。

所以说同名不等于同心。同名只是说，两个人嘴里出来的音一样。这个音后面连着什么，要问，要看，不能默认。默认的结果，便是上面那条秋裤：妈妈递过去的，是她自己的“冷”，一鸣收到手里的，是一件他此刻不需要的衣服。

◆三、秋裤归谁

再把这条秋裤细看一遍。妈妈的整个过程是怎么走的？先是一股劲在她心里绷起来，看见孩子湿着头发站在窗边，她担心，这是一股张力。接着她做了一个动作，开口说“去穿秋裤”，这是转换，把担心变成一个具体的行动。最后，一鸣如果听话穿上了，她心里那块石头落了地，松了一口气，这是释放。

这三步，从头到尾都是妈妈的。张力是她的担心，转换是她递出去的话，释放是她自己的踏实。一鸣呢？他只是在中间被经过了一下。他此刻没有张力，反而正在享受一场运动之后的轻松；如果他听话穿上，他得到的是一条闷出汗来的秋裤；如果他不穿，他得到的是一顿不被理解的埋怨。三步里，他一步也没有走。

这里要看清一个对施方不太友好的事实：妈妈越真诚，这件事越沉。如果妈妈只是随口说说，一鸣顶一句也就过了。偏偏她是真担心，所以一鸣的“不冷”在她听来，就成了“你不把自己的身体当回事”，她的声音自然提上去，话也越来越重。好心的人一旦把自己心里的读数当成了对方身上的读数，就会觉得自己在帮忙，所以心安，所以不肯退。这一条后面第46章会专门讲，这里先点出：这一幕里没有坏人，只有一个字被当成了一件事。

按本书的用法，这里还够不上叫“恶”。这个字要带定位：谁的意义，哪一律，哪一步，多长时间窗。一条秋裤，一个晚上，一鸣在这一晚上顶多是不痛快，三律里没有哪一律被长期截断。但同一个动作，换一个更长的时间窗，换一个更重的事，比如天天替孩子判断“你是不是饿”“你是不是累”“你是不是喜欢”，孩子慢慢就会丢掉自己判断的那份本事。这是后面几编要讲的。

◆四、“同一性谱系”是个什么东西

讲到这里，需要把本书的一个词请出来，叫“同一性谱系”。它听着拗口，意思其实很家常：一串彼此牵连、又各不相同的样子。

先说“各不相同”。妈妈那个“冷”是担心，一鸣这个“冷”是体感，爷爷坐在阳台上说的“冷”，也许是膝盖里的一阵酸，一个从北方来的人说“这算什么冷”，是拿零下二十度比的。这些“冷”，字相同，样子各异。

再说“彼此牵连”。这些“冷”并不是各说各话。妈妈的担心，是从她自己的体感里长出来的，她小时候发过烧，也见过门诊里孩子的鼻涕；一鸣长到她这个岁数，他的体感里也会带上担心。两种“冷”，一头连着身体，一头连着对别人的关心，一条线把它们穿起来。所以它是一串，一条线上的不同位置，不是一堆毫无关系的东西，也不是同一个东西的拷贝。

这个词的用法，本书是从第 508 号《何谓公平？》借来的。那本书用一个合唱的比方来讲：大家一起齐唱，是统一性，每个人唱一模一样的调；各人唱各人的，是多样性，谁也不碰谁；和声是另一回事，各声部唱的不一样，却合在一首歌里。同一性谱系，更像和声。它既不要求大家的“冷”相同，也不允许各人的“冷”彼此隔断。

于是，“符号的谱系”这个说法就清楚了：一个字，在不同的人、不同的时刻、不同的处境里，指向一串彼此牵连、各不相同的东西。要知道此刻这个字指的是这串里的哪一个，只能去问、去看，不能靠字面。

有两句话要补在这里，免得把“谱系”听成别的意思。第一，它不是各说各话。如果每个人的“冷”都只属于自己，互相谁也不必理会，那一家人晚饭后就各过各的了，这正是第 508 号批评过的那种各点各的外卖，吃得下去，线却断了。谱系的意思，是承认差异的同时，把牵连留着：妈妈的担心要有地方落脚，一鸣的体感也要有地方被听见。第二，它不是随你怎么说。一个人说“我不冷”，别人可以去摸一摸他的手，可以问他刚做了什么，字所指的东西不是任凭谁一说就算，里面有可以对照的地方。本地的对错，还是在的。

第 508 号还留下一道很重的判语，叫铁门：谁在整串谱系里始终到不了意义，那才是不公平。放到符号这一层，意思是这样：一鸣这一次被误解，是谱系里常有的事，说两句就开了；可如果这个家里，他说出来的“冷”“累”“不想”，总是被改写成别的东西，“你那不叫冷，你那是懒”，说久了，他自己的字就进不了这条线。字在，路断了。这一点第32章讲“累”的时候还会用到，这里只作一个提醒：字的差异本身是常态，字的差异被抹掉，才是要警惕的事。

◆五、两句话为什么偏偏在这里出事

现在回头看那两句话。“己所不欲，勿施于人”，开头是“己所不欲”，这个“欲”字，就是一个名字。“你们愿意人怎样待你们”，“愿意”也是一个名字。两句话的运行方式，都是先查自己心里有什么，再把它当作对方心里的东西。查自己，就是用自己的“冷”去代替别人的“冷”。

妈妈这一晚上的运算过程，大致是：我不愿意孩子冷着，我也不愿意被人看着受冻，所以我给孩子穿秋裤。每一步都符合那两句话，每一步都没有违背良心。问题只有一个，她在第一步用的那个“冷”，和一鸣身上的那个“冷”，已经不是同一个东西了，而这两句话的写法里没有任何一个位置，能让她发现这一点。句子没有变，她的好心也没有变，她甚至会觉得自己比平常更讲道理，因为这条规矩简单、清楚、人人都认。

好在，这件事并不总是出事。想想这样一个场合：零下十度，一鸣站在室外，身上只有一件单衣。这时候妈妈说“冷”，一鸣自己也哆嗦，两个“冷”几乎重合了。再比如一个人被推下水，不想被淹，所有人的“不想”都差不多。字所指的那一串，在这些场合里压得很窄，两个人的“冷”相差不远，那两句话在这里很灵验。因为这样的例子太容易想到，人们便容易以为所有的“冷”都是这样。秋裤这类事，指向的那一串很宽，从担心到体感，距离大得很，同一句话到了这里，就把“替人命名”悄悄带了进来。

◆六、怎样回到那一个字

那么，妈妈那一晚上可以怎样走一步，才会把这条线接起来？最省事的做法，是问，而且要问得让对方有话可说。如果问“你是不是不冷”，一鸣只能回答“是”或者“不是”，这是把妈妈自己的候选答案递过去了。问“你觉得现在怎么样”，他会说“还行”。问“你刚才跑了多久”，他会说“四十分钟”，然后妈妈自己就听出来：他是热的。再问一句“等一下汗干了，风这么大，你打算怎么办”，这时候一鸣自己会想到，也许要披件外套，也许要先洗个热水澡。这件事上，妈妈没有收回她的担心，她把担心换了个说法放进了问题里，让一鸣有机会用自己的体感来回答。

反过来，一鸣也有一步可走：他可以说“我现在是热的，一会儿凉了我自己加”，而不只是回一句“不冷”。这样一句话，就是把自己那个“冷”的位置说清楚了。孩子能说出这句话，不是天生的，是在无数个这样的夜晚里，被问出来的。

问之前还有一道很小的工序，叫先停一下。妈妈在门口换着鞋，话已经到嘴边，这时候只要多等三五秒，看一眼孩子的头发、后背和呼吸，信息就已经比刚才多了一层。很多时候，答案不用问，是看出来的。问是在看不出来的时候才用。

这一步走完，两个“冷”被放到了同一条线上，妈妈看见了一鸣的，一鸣看见了妈妈的，这个字才有了两个人共同认的意思。不过，两个人就算对准了“冷”指的是什么，下一步还有一个问题：同样是担心天凉，该怎么办？妈妈的办法是加衣，一鸣刚打完球，他的办法是先散热。这是下一章要走的路，也就是道理的谱系。

**带走的话**：同一个字，在不同人嘴里连着不同的东西；名字只是指针，指到哪里，要问，不能默认。

**这一章怎样算错**：如果能证明，在宽段的日常事上，两个人用同一个词时，所指的东西几乎总是相同，那么“同字不同指”这一章就不成立。
