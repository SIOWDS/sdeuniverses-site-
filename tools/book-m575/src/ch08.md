# 第8章　“其恕乎”：老师说的是“大概”

◆一、抄方的人把“大概”写成了“必是”

这是一个构想的场景，只作说明。南方小县城里有一位老中医，给病人号了脉，看了舌苔，沉吟一会儿，对身边跟诊抄方的年轻人说：“大概是这个方子。先吃三剂，下回来我再看。”年轻人低头抄方，在脉案末尾顺手添了四个字：“此证必是。”几年后，这本脉案被另一个年轻人借去当作成法，遇到相似的脉象，他不再沉吟，也不再约“下回来我再看”，三剂药写下去，人就打发走了。

老中医那句话里，“大概”和“下回再看”是方子的一半。有这一半，药方是一次试探，吃下去有什么反应，下回来就能改；没有这一半，药方成了命令，病人好不好，都只能怪他体质不对。抄方的人没有存心改什么，他只是觉得“大概”两个字不像医书，不够硬，替老师补了一笔。补完之后，口气没了，方子上的字一个没错。

《论语》里有一句话的遭遇与此相似。它在后世被抄、被背、被刻在匾上，通常被当作一条断语：定了，不用再问了。可是回到它当年出口的那个场合，老师说的是“大概”，学生问的是一条要走一辈子的路，两样东西后来都从句子里掉了出去。这一章就是把它们捡回来。

◆二、一个想要口诀的学生

事情记在《论语》里，原文是：子贡问曰：“有一言而可以终身行之者乎？”子曰：“其恕乎！己所不欲，勿施于人。”（《论语》15.24）

先看提问的人要什么。他要“一言”，一句话，最好是一个字；他还要这句话“可以终身行之”，一辈子都能照着做。这是一个想要口诀的人的问法。门里有那么多规矩，礼有礼的，乐有乐的，事君事父各有各的，他想知道有没有一把总钥匙，拿在手里，不必每次翻册子。子贡在孔子的学生里以口才和机敏出名，第9章会细讲他，这里只记一笔：这样的人问出这样的话，一点也不意外。

再看孔子怎样答。他先说了一个字，“恕”，前面加了一个“其”，后面缀了一个“乎”。然后才补上那句人人会背的话，当作这个字的说明。把顺序摆清楚：先是一个带着商量口气的词，再是一句话，做它的注脚。后世的人往往只背后半句，把前半句当成了开场白。

“其……乎”的格式，在古汉语里常带推测和商量的口气，近于现在说的“大概是……吧”。这是语法上的一般读法，不是本书的发明。第484号《儒家发展之道总纲》引这一章，大意也译作：大概是恕吧，自己不愿意的，不要加给别人。古书原来没有标点，那个感叹号是后人加的，加得合不合老师的口气，谁也说不准；有人读成斩钉截铁，有人读成沉吟，两种读法放在同一行字上，都排得下。

可是只要拿孔子在别处答问的口气对一对，差别就出来了。颜渊问仁，他说“克己复礼为仁”，是一句断语，下得干脆；仲弓问仁，他一路说下去，出门如何，使民如何，在邦如何，一条一条交代，没有一个“大概”。唯独子贡问“一言”，他用了揣度的口气。同一位老师，对不同的学生，有时斩钉截铁，有时沉吟，这本身就是信息。当年在场的学生，听口气大概比听内容还准，因为口气里有老师对这个人、这个问题有几分把握；可口气恰恰是写下来之后最先丢的东西。

沉吟的原因，原文没有说，我们只能推。一种推法在孔子自己那里找得到依据：他的学生记下过他的四种戒备，叫“子绝四”：子绝四：毋意，毋必，毋固，毋我。（《论语》9.4）

大意是，老师杜绝四样毛病，不凭空揣测，不说死，不固执，不执着于自己。“毋必”是其中一条，就是不下“必定如此”的断语。这是本书的读法：一位不肯说“必”的老师，被学生逼着要一个管一辈子的字，答的是“大概是恕吧”，口气与他平日的戒备合得上。读法只是一种推测，没有哪一页写着“他在这里是有意为之”。

◆三、“终身行之”：要的是路，给的也是路

口气之外还有一个词，更容易被略过：终身。子贡问的不是“哪一句话最对”，不是“哪一句话能说服所有人”，也不是“哪一句话可以写进规章”。他问的是：哪一句话可以让我一辈子照着走。“终身”是时间词，它把这句话从“一次判断”改成了“一个过程”。判断是一次的，对就是对，错就是错；过程是长的，今天做得不好，明天再来，三十岁和六十岁做出来的样子可以不一样。孔子没有纠正这个问法，顺着答下去，等于认了：这个字，是要走一辈子的。

走一辈子的东西，和背一辈子的东西，是两回事。背下来的条文，二十岁和六十岁是同一条，字字不差；要走的路，是随着人老、事杂、位置变，一遍遍重新走。拿学做饭来比，“盐要适量”是一句背得下来的话，“适量”到底多少，却要在灶台边站一辈子，每回换了锅、换了人口、换了季节，手上的分寸都要重新找。恕这个字被放在“终身”之下，就是这个意思：它是一门手艺，不是一道公式。

这一点和上一章的仲弓章可以互相印证。仲弓那里，孔子把话分成前后几段，“如见大宾”在先，“在邦无怨”在后，中间夹着这半句，整体是一个有来有去的动作：先端正自己的态度，再查自己的欲，最后看对方有没有怨。到了子贡这里，话缩成了一个字、一句话，可是“终身行之”四个字仍然留着。本书的读法是：仲弓章里那条来回的链子，在这里被折叠进了“终身”这个时间词。链子没有断，只是叠起来了。

还有一处可以对照。《中庸》第十三章也提到这几个字，说“忠恕违道不远，施诸己而不愿，亦勿施于人”。“违道不远”四个字很要紧：离道不远，不等于就是道。这一句也在说，这条路是靠近大道的，是一个近处的入口，不是终点本身。把《论语》的“大概”和《中庸》的“违道不远”放在一起，两处的分寸一致：它好，它有用，它走得近，它不是全部。至于《中庸》紧接着的“丘未能一焉”是怎么回事，第11章再讲。

◆四、曾子的那一译，和“口令”的来历

“其恕乎”的另一半遭遇，发生在另一章里，而且发生得很早，在孔子的学生里。《论语》里仁篇记着一幕：子曰：“参乎！吾道一以贯之。”曾子曰：“唯。”子出，门人问曰：“何谓也？”曾子曰：“夫子之道，忠恕而已矣。”（《论语》4.15）

孔子只对曾参一个人说，说得很短：我的道，有一根线穿着。曾子答一个“唯”，便是应了，懂了。孔子走出去，别的学生没听明白，围上来问，曾子才开口：老师的道，忠恕罢了。

这一译，站内的两本前作都认真对待过，而且都有话说。第484号《儒家发展之道总纲》讲，孔子没有说那根线是什么，是曾子替他说成了忠恕，并且承认这一译有它的公道：忠恕是孔子自己说过的，忠恕做得出来，忠恕传得下去。同时它转述第312号《一的原材料库》的判断：曾子把“一”译成忠恕，得了它的用，漏了它的体。第312号还把“一以贯之”后来的遭遇概括为“架构变口令”：原义是邀请人把它展开，后来的用途却是不许再展开。本书接住这两个判断，不重判。曾子面对一屋子没有听懂的同学，手里只有一堂课的工夫，他要让话站得住，选了最好带的两个字，这是一位负责的师兄会做的事。曾子没有错，后来的麻烦是人们只留下了他那两个字，没有同时留下孔子那一句的口气。

本书只补一点，这一点和本章的主题直接相连。曾子的忠恕，和子贡面前的“其恕乎”，在口气上差了一格。孔子对子贡说的是“大概是恕吧”，是一个正被追问的老师勉强给出的一个近处的入口；曾子对同学说的是“夫子之道，忠恕而已矣”，用了“而已矣”，是一句收口的话，一句把整条线压成两个字的话。这两句话先后相差不远，位置却不同：前一句是老师在路上给学生指的一个方向，后一句是学生在课间替老师定的一个结论。一个把结论当作方向用，问题不大；一个把方向当作结论背，路就停了。这是本书的读法。第312号用的词是“口令”，本书借用这个词，因为它准确地说出了那个变化：口令只管喊出来，不管走得通走不通。

◆五、口气是怎样一层层掉光的

把前面几处合起来，可以看出一句话怎样丢掉自己的口气。大致有三步，每一步都不坏，连起来就变了味。第一步，压缩。路太长，口诀要短，于是“大概是恕吧，己所不欲，勿施于人”变成了“己所不欲，勿施于人”，前半句的商量没了。压缩是教学的需要，没有谁能把老师的沉吟都背下来。这一步无可指责，跟老中医的徒弟一样，是为了方便。

第二步，定格。短句背熟了，大家开始引它，写在教室后墙、家规、校训、宣言里。引的人只引句子，不带场合：谁问的，在哪问的，老师当时是什么口气，都不带。一句话离开了场合，就只剩字面，字面是硬的，“勿”就是勿，“不欲”就是不欲，没有一个“大概”可以挂住它。到这一步，它已经从提议变成条文。比如走廊墙上刷着这八个字，天天有学生走过，没有哪个学生知道它是一位老师在被追问之后说的，更没有哪个老师想过，它后面还跟着一个“乎”。

第三步，升格。条文被用得久了，成了常识，成了人人都懂、不必再想的东西；一句话到了“不必再想”的地步，就从“方向”升成了“底线”，从“好像可以走”升成了“必须这样”。这时若有人说一句“且慢，这句话要看是对谁说、在什么情形下”，听着反倒像是在抬杠。口气掉光了，连“口气曾经存在过”这件事，也被忘了。

这三步，每一步都有它的好处：压缩使话好记，定格使话稳固，升格使话有分量。第6章讲过这句话的四样功劳，止手、开手、借条、兜底，多半也要靠这三步才做得到。功劳是真的，代价也是真的：它让后来的人，包括今天想把这句话用在孩子、病人、下属身上的人，以为自己握着的是一个定论，而当年递过来的，是一个“大概”。

回头看开头的老中医：他说“大概是这个方子，下回我再看”，处置是两半，方子加复诊。徒弟抄下来的“必是”，丢掉的不只是一个语气，是整个处置里改错的余地。

再把这个“大概”放进今天的饭桌。设想一位爸爸要孩子周末去上补习班，他可以说“我小时候就是这么过来的，你也一样”，听着像重复一句老话；也可以说“我大概是这样想的，你看合不合适”。两句话里的道理可能一模一样，孩子能不能把“不对”说出口，却因此不同：前一种说法里，孩子要插话，得先推翻一条定论；后一种说法里，插话本来就是这句话的一部分。“恕乎”后面那个“乎”，留的就是这个口子。

回到子贡。他问的是一条可以走一辈子的路，孔子给的也是一条要走一辈子的路，口气是商量的。那么，当这位学生自己把差不多的话说出来的时候，老师又是怎样回应的？《论语》公冶长篇里有另一幕，几乎同样的一句话，换成子贡自己的嘴说出来，老师的回答短得多，口气也完全不同。那一句，就是下一章的题目。

**带走的话**：孔子答子贡的是“大概是恕吧”，问的是“终身”，给的是一条路，不是一道断语；口气和时间一掉，路就成了条文。

**这一章怎样算错**：若能证明“其……乎”在这一章里只是普通的断定口气，没有商量和揣度的意思，或者“终身行之”在当时只是“一直照做”的套话，本章对口气的读法就不成立；曾子那一译的评价，则以第484号和第312号所说为限，不能因本章而加重。
