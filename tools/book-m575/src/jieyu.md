# 结语　下一次孩子喊累

◆一、又是一个周三

这是构想的场景，沅安茶厂老宿舍，段家，一个普通的周三夜里九点四十。苏晓红到家二十分钟，社区卫生服务中心今天下班晚，鞋是蹬掉的，没摆正。奶奶郑桂英在厨房里炖一锅什么，汤气顺着门缝出来。段建军在客厅沙发上，膝盖上摊着一张模具图，铅笔夹在耳朵上。一鸣坐在饭桌边，面前是数学作业，分数的除法，写了大半页，后面三道题一个字没动。他把笔放下，往椅背上一靠，说：“妈，我累了。”

这句话，这本书从头到尾一直在拆。拆之前，先交代一件事：这一晚不是第一次，也不会是最后一次。一鸣十一岁，分数是他这学期的坎，累字会一周喊上几回。前面五十二章里写过的那些夜晚，有的接得好，有的接坏了，坏的那几次里没有一个坏人，每个人都是好心。今晚没有什么新的东西发生，同一个孩子，同一张桌子，同一个字。要看的只是：这一回，手伸出去之前，多了点什么。

苏晓红没有立刻伸手。她站在门口，外套还没脱。这个“没有立刻”，她自己并不觉得是什么功夫，只是在护士站干了二十年，学会了一件事：病人喊疼，先别急着给药，先问疼在哪里、什么时候开始的、像什么。疼是一个字，底下是一团东西。她没有把这个本事带回家过，因为家里没有人是病人，家里只有孩子，孩子累了，你就心疼。心疼来得比问话快，这是她四十二年的习惯。今晚她让心疼先站了一会儿。站的时间不长，大概就是脱外套的工夫，可这一会儿，足够她看清桌上的东西：写完的半页，没动的后三道，一支搁在本子边上、笔帽还没盖的笔。

◆二、同一个字，重走一遍

她把外套搭在椅背上，在一鸣对面坐下，没有看作业，先看他的脸。眼皮没有打架，眼睛是醒的，手指在桌沿上敲。她问：“刚才哪一下开始不想写的？”一鸣愣了一下，说：“就是累。”她没有追，也没有替他说“是不是不会做”。她把那本作业翻过来，指着写完的那半页，说：“这几道你写得挺快的。”一鸣看了看，说：“这几道是分数乘，简单。”她说：“后面是除。”他不吭声了。过了一会儿，他说：“除的时候，我不知道到底是除哪个，翻过来的是哪个。”

累这个字，底下露出了一小块东西，是卡，眼皮并没有沉。可她心里清楚，这一小块不是全部。一个孩子说“不知道翻哪个”的时候，旁边坐着妈妈，他还可能在说：我怕你看见我不会。也可能在说：我今天在学校打球输了，不想再输一次。这些她没有问，也没有猜，因为书里反复讲过，递候选答案是最快的错路，“你是不是不会”一出口，他点头点得比谁都快。她只讲了一道例题，用的是他自己写错的那道，讲完把笔递回去：“你来做下一道，我在这儿。”

她还问了一句，语气很随便：“要是现在手边是球，还累吗？”一鸣想了想，老实说：“球不累。”这一句不是用来抓他的，她没有接一句“那就是偷懒”。书里讲过，这种问法只是看累缠在哪里：缠在这张卷子上，缠在分数上，还是缠在这一整晚上。一鸣的答案是球不累，累不在身上，在这道除法上，这就够她用了。她要的只是知道该往哪里递一只手，不是要给孩子定一个性。

书里最难守的一条，就在这一步。讲例题容易，递笔难。笔递回去，孩子可能算错，可能又喊累，可能磨到十一点，明天交不出完整的作业。苏晓红的手在桌面上停了一下，心里那股劲是实在的：她想把后面三道快快讲完，让他早点睡。这股劲一点也不坏，是为他好。她把手收回来，放在膝盖上。这时候，那两句老话反倒帮了她一下：“我自己写到一半被人把笔抢走，会是什么滋味”，这念头一闪，手就停住了。这是它们最老实的一份功劳，止手，在冲动落下去之前拦一下。拦住之后该往哪里走，它们不管，那是桌边另外几件事的活。这一晚她多走了这一步，缘故很简单：坐在对面的是她儿子，她想看他自己把笔拿起来。

◆三、父亲的一句话

客厅里，段建军听了几句，没抬头，说了一声：“写个作业哪有那么累。”他并非存心。他十四岁进厂，学徒三年没喊过一声累，这句话在他嘴里是一份老交情，是把自己的日子递给儿子，等儿子接。一鸣的笔停在半空，肩膀往下塌了一寸，说：“没累。”然后低头，一个字一个字地写，写得很慢，很规矩，不再看任何人。

苏晓红听见了，也看见了。这一刻，书里讲过的东西都在场，却没有一样帮得上她。道理她都懂，闸门她也知道，可是眼前这句话已经出口了，孩子的字已经被关上了，关上的方式很安静，没有吵，没有哭，只是“没累”两个字，比“累”还重。她可以起身去客厅，跟丈夫说一句话，可当着孩子说，等于告诉孩子爸爸错了；不说，这句话就留在桌上。她选了不说，在桌下碰了碰一鸣的脚，没有碰到回应。

后来她跟自己说，这一晚她只做对了一半，另一半没做对，而且不知道怎样才算做对。她不会因此睡不着，只是在洗碗的时候又想了一遍。要补，也只能明天补，补的办法是找个不在桌上的时候，问一句“昨晚爸爸那句话，你听着什么感觉”，看孩子肯不肯说。孩子肯不肯，她没有把握。这一页没有结局，这件事今晚没有闭合。

◆四、一锅汤，一通电话

十点二十，一鸣把后三道题做完了，做对了一道，另外两道还是翻错了。苏晓红没有改，也没有说“差不多”，只说：“这两道明天早上带去问钟老师，你自己问。”他点点头。奶奶端着碗从厨房出来，是一碗热的冰糖梨水，放到桌上，说：“喝了再睡，润一润。”一鸣捧着喝，没有说谢，也没有说不要。奶奶站着看他喝完，把碗收走，一个字没提作业。她年轻时在婆婆手下，凡事轮不到她说话，如今这点分寸，是她自己一点点摸出来的。

碗刚洗完，晓红的手机响，是城东的外公。苏德厚当了一辈子语文老师，打电话从来不绕弯：“一鸣今天的作业写完了？”她看了一眼那边收拾书包的儿子，说：“写完了，有两道还要再看。”外公在那边嗯了一声，说周末想让孩子过去，他有几道题想看看孩子的字有没有进步。外公自己的事，家里还在商量，怎么说、说多少、什么时候说，一家人没有议定。这一页不替它翻到后头，也不在这里下任何结论。她只说了“周末带他去”，挂了电话，站在阳台上没有马上进屋。

屋里，一鸣在刷牙。段建军把模具图收起来，经过孩子房间门口，停了一下，进去，站在床边，说：“数学，爸爸不会。你妈说的那个，翻过来……我也不会。”这是他一天里说得最长的一句话。一鸣没回头，含着牙膏泡沫，嗯了一声。这一声里有什么，没有人知道，包括这个父亲。

◆五、判词，和这本书会错在哪里

这一晚结束时，没有人被治好，没有什么被解决。分数还得再练，父子之间那一句“没累”还悬着，外公的事还在商量，一鸣明天可能依旧喊累。如果有什么不同，只是桌边多了一个迟到的动作：先问一句，再决定接什么。那个动作不保证结果，只保证下手的时候，孩子的那一边也有一个位置。

有人会问：这样慢慢问、慢慢递，万一孩子就是偷懒呢？万一他学会了拿“累”换时间呢？这种可能存在，书里没有否认，苏晓红自己也没有答案。她只知道，今晚的两道错题留了下来，没有被她悄悄改对；孩子也没有因为喊了累就少写一道。如果过几周发现，问了又问，他的字还是越来越少，书里的闸就该用上了：时间窗要说出来，不可逆的事不等，该去找老师，该去找医生，也要去。慢，不等于永远慢，问，也不等于永远只问。

这本书从头到尾讲的，压成一句，只有这一句：

> 这两句话量的是欲，善恶却要对着意义判；欲一旦顶替了意义，施者走通的那一刻，就是受者被截断的那一刻。

这句话没有变。变的是读它的人：同一个母亲，坐在同一张桌子对面，句子里的每一个字她都认识，认识了几十年，今晚才第一次看见句子里缺了一个人。“己所不欲”问的是我，“你们愿意”问的是我的愿意，孩子的那一边，在句子里没有座位。她没有比从前更善良，也没有变成更好的母亲，只是在伸手之前，多留了几秒，让那个座位空着，看孩子自己走进来坐。

这本书可能错。它没有做过调查，也没有做过试验；核心判断出自著者的口述，正文由会说话的机器协助写成，几位执笔者用的是同一个底座，互相校对不算彼此独立的证据。附录一写了五处，说明在什么情形下，这些话应当被放下。其中第一处可以真跑：找一批真实的家庭、真实的同事，把窄段和宽段的场景摆出来，看双方的读数是不是像书里说的那样分开。结果如果相反，第三编以后立着的东西要整体重判。一本讲“别替人结算”的书，也不该替读者提前结算：它是否成立，要留给读者去问，留给日子去验。

下一次孩子喊累的时候，你会在哪里？厨房，客厅，加班的路上，还是电话那头？你手里会是笔、汤碗，还是一句话？这本书不知道。喊的人和听的人隔着一个字，字底下是一团东西，只有喊的人自己能一点点打开。你能做的，是先别急着替他打开，也别急着把它关上，然后听他怎么说。听完以后接什么，今晚的苏晓红有今晚的接法，你有你的。
