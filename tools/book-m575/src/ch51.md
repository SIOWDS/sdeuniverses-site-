# 第51章　留下读数，留下退路

这是构想的场景。沅安茶厂老宿舍的段家，周日晚饭多了一个小习惯。汤端上桌，苏晓红盛完第一碗，只问一句：“上回那样，你觉得呢？”她问的“上回”从来不含糊，总先把事说出来：上周三晚上我坐在你旁边看你写分数，你觉得呢？上周六我把你的球鞋收进了柜子，你觉得呢？一鸣头几回答的都是“还行”，她不追问，点点头，把汤勺递过去。到第四个周日，一鸣一边扒饭一边说：“你坐旁边，我反倒写不出来，感觉你在等我错。”苏晓红愣了一下，没有解释，也没有说“妈妈是怕你……”，只说了一句：“那下回我坐到客厅去，你要的话喊我。”

这一章讲的就是这一句话的分量。前面几章把话拆开了，拆完要问的是：手里还剩什么能用。这一章先留下两样东西，一样是读数，一样是退路。

◆一、被砍掉的那一截

第7章讲过仲弓问仁，孔子的回答有三段：“出门如见大宾，使民如承大祭。己所不欲，勿施于人。在邦无怨，在家无怨。”（《论语》12.2）后世传诵的只有中间一句，头一段是把被使唤的人抬到大宾、大祭的位置，末一段是“无怨”。这两段其实是一前一后的框：前面先把对方放高，中间才查自己，最后回头看对方有没有怨。

“在邦无怨，在家无怨”常被读成一个愿望，意思是你这样做了，天下自然没有怨。本书的读法有点不同，这是解释性的展开，不是定论：这一句也可以读成一个读数。做完之后，别人那边有没有怨，这是要去看的，不是靠自己心里有数就算数。施的人觉得自己没有恶意，不能替换掉受的人有没有怨。药方只剩下“吃药”，望闻问切和复诊都没了，等于只留下了动手的那一步，没有留下看结果的那一步。

要补回来的东西，说穿了朴素：受方那边的读数。读数在这里指的是，这件事落到他身上之后，他自己怎么说、怎么看。注意是他自己的话。施者推测的“他应该是高兴的”，不算读数。第46章引过的实验和那篇代理人系统综述，说的是同一件事：设身处地不能保证看准，亲近、用心、甚至被病人事先指定，也不能；能提高准确度的，是直接拿到对方的话。这并不是说施者不用心，只是说想得再诚恳，也代替不了问一句。

还要防一种假的“无怨”。一个人不敢怨，也是没有怨。下属在老板面前不吭声，孩子在爸爸面前说“没事”，读出来都是零。所以读数得连着前面的“如见大宾”一起读：先把对方放到可以开口的位置上，才轮得到问他有没有怨。零读数分两种，一种是确实顺，一种是不敢说，两种单看数字分不出来。能看的是旁的地方：他平时敢不敢提别的小意见；同一件事换一个人来问，他的答案变不变；话到嘴边又咽回去的时候，有没有留下一个欲言又止的表情。三样里有一样亮了，这个零就要打个问号，先回头查那个位置有没有放得够高、够安全。

◆二、一句话，怎样才算读数

回到饭桌上。“上回那样，你觉得呢”看着随便，里面有几条讲究，缺了哪一条，这句话都可能变质。

第一，问的是一件具体的事，不是一个人。“你觉得妈妈对你怎么样”答不出来，也不敢答；“上周三我坐在旁边”，一鸣能回头看见那个晚上。具体，对方才有东西可以说，说错了也只错在一件事上。

第二，问完不递候选答案。不要问“你是不是觉得妈妈管太多”，那是把答案塞进他嘴里，他顺着认了，读数就读成了施者自己。前一章讲“累”的时候已经讲过，问序列、不递选项。这里同理。

第三，允许他说“不知道”，允许他过两天再说。孩子十一岁，很多感觉当场说不出来，等打完球回来才浮上来。苏晓红后来补了一条规矩，周日没想好，周三也行，在厨房门口说一句就算。

第四，也是最容易被忽略的一条：他说了，要有后果。后果不是马上照办，是让他看得见这句话进了账。苏晓红说了“那下回我坐到客厅去”，一鸣隔周回答“这样行”，或者“也不行，我想你偶尔看一眼”，不管哪个回答，下一个周日都有人接着问。这就是退路的雏形，下一节展开。

还有一个细节值得写下来：时机。苏晓红试过饭后马上问，也试过睡前问，发现都不如汤端上来的那几分钟。那时人手里有事做，眼睛不必对着眼睛，话说出来的压力小。同样的问题放在“坐下来谈谈”的郑重场合，一鸣只会答“没什么”。读数拿得到拿不到，常常取决于问的地方有没有给对方留一点轻松。这大约和人手里有事做时更容易开口是一个道理：不觉得是在受审，说出来的反而更接近实话。

读数这个词有一个危险：它太像仪表盘。一旦读数变成每周一次、人人要答、答完要有分数，它就成了新的评价体系。后面专门有一节防这件事。

◆三、退路：尺子还能不能改回来

第433号《情绪价值发生学》（秦莉著，王德生指导）提出过一个想法，可以借来说明为什么只有读数不够。这本书讨论的是安慰越说越不管用：它的看法是，安慰的好坏不只看它让人此刻好受多少，因为一次安慰会把它带来的舒适，回头写进衡量“够不够”的那把尺子里；三个月后同一句“辛苦了”托不住了，变的是尺子，话没变。书里把区分“增值”和“透支”的关键叫作回写的可返回性，大意是：一次回写之后，有没有路径让它被复核、被修订、被重开。它的意思是，好意满格，这个可返回性仍然可以是空的。

这里要老实交代它的身份：这是第433号自己标明的待检验命题，那本书说明全书没有数据，场景是构想。本书不借它的结论，只借它的一个想法，放进饭桌上说：每一次“我是为你好”，都会改变孩子判断“什么叫好”的尺子；而这把尺子被改写之后，如果没有一个口子让它改回去，同样的好意只会越来越重。口子由三样东西组成，换成大白话就是：能回头看一眼（复核），能说“这样不行”并且被听见（修订），能把已经翻篇的事重新拿出来讲（重开）。

苏晓红的饭桌上这三样都有了：“上回那样”是回头看，一鸣说“你在等我错”、妈妈答“那下回我坐到客厅去”是说了不行并且被听见，周三补一句、隔周再问，是把翻篇的事重新拿出来。反过来看一个没有口子的例子：另一家的爸爸每次发脾气后都买一只冰淇淋回来，孩子吃了，事情就算完。三个月后，冰淇淋成了“事情已经过去”的信号，孩子再也没有机会说“你那天吼我吼得我很怕”，因为冰淇淋已经把话堵上了。冰淇淋是好意，口子是空的。

◆四、读数怎样不变成新的指标

读数最怕的是变成考核，有几个办法防它。一是不打分，不汇总，不比较。“你觉得呢”换成“打几分”，当场就是考试；孩子很快学会说“挺好”，因为说“挺好”最安全，这和“累”是同一类事，一个字被压得最安全，里面的东西就不再出来。更要紧的是，读数不能在家庭里公开比较，不能出现“哥哥上周说挺好，你怎么说不好”。

二是读数只用来改下一次，不用来给上一次定罪。妈妈听到“你在等我错”，第一反应若是“我辛辛苦苦”，读数立刻死掉，因为孩子学到了：说真话会让妈妈难过。这时候接住的办法，是把那句话先收下，什么也不辩，过一会儿再想。苏晓红那天夜里在厨房洗碗，自己对自己说了一遍：他说我在等他错，我坐在那里的时候，脑子里确实在数他错了几个。这句话是对的，对在她没法否认。收下以后才谈得上改，当场辩解，下周就没有人再说了。第433号区分过几种“没事了”：有的是事情确实转完了，有的是暂缓但留着口子，有的是话被封死了，还有的是原来的问题已经变了。孩子说“还行”，要分清是哪一种，不能默认是第一种。分辨靠什么？靠下一周他有没有还愿意讲，不靠这一周他讲得多好听。

三是问的人也在被问。这句话得是双向的：一鸣有时反问妈妈：“你那天吼我，你自己觉得呢？”苏晓红的回答是：“我觉得我吼早了。”一家人里只有一个方向的读数，就是审问；双向的才是复盘。

还有第四个办法，听上去反常：隔一阵子，有意识地问一句“上回你说的那件事，后来我改了没有”。问的是施者自己的兑现。读数只收不改，孩子很快看穿，知道说了没用，再往后就不说了。收到的读数里至少要有一两条确实变成了行动，让对方看见这条路通。第433号说好意再足也不等于有口子，这里换成家常话：口子要用过，才算口子；挂在墙上的“欢迎提意见”，不算。

◆五、事后复盘：给已经发生的事一个出口

事中不判，事后可以回头算账，这是第四编定下的规矩。读数和退路合起来，就是事后的那个出口。所谓复盘，不是开会，是每隔一段时间，把已经走过的某一件事拿出来，问三个问题：当时他那边是怎么走的；我那一步，他看见的是什么；下一次，哪一处可以改。

复盘有一个边界要守住：它不是翻旧账找罪人。复盘的对象也要挑。段建军有一次想复盘三个月前他拍桌子的那回，一鸣早忘了，爸爸硬要问，孩子被问得浑身不自在。过去很久、对方已经不在意的事，不必为了形式拿出来；留给复盘的，是还在影响他的事，也就是他提起来时眼神会动一下的那种。苏晓红在社区卫生服务中心上班，出院病人回访是她熟悉的程序：不是回头追究当时谁对谁错，是问病人回家后这几天怎么样，有没有哪一步没跟上。这是同一个动作搬到了饭桌上。再进一步，复盘要有时间上限：一件事复盘一两次，三次还没有改，就该换办法，而不是继续问。

退路还要给自己留。苏晓红说出“我吼早了”以后，家里也得允许她下次仍然会吼早，允许改得慢。要求施者一次改干净，等于又立了一把新尺子，改不干净的人就不再来问了。读数的用处是让方向一点点校，不是一次判定谁及格。

退路也有代价。口子留着，意味着施者要接受自己的做法可能被改，意味着权威要降一点。这对有些人是难的，老人尤其如此。奶奶郑桂英起初很不习惯：“吃饭还要评理？”后来她发现，孙子在这张桌上讲的话，比在客厅里多。有一回，一鸣当着奶奶的面说：“奶奶你夹菜夹得我碗里堆成山，我吃不完又不敢说。”桌上安静了一下，奶奶说：“那你吃多少，自己夹。”以后碗里的山就矮了。这个口子没有改变奶奶疼孙子的心，它只改了一个动作：从替他夹，到他自己夹。

读数留下了，退路也留下了，但还有一处没解决：读数总是从下往上递的。孩子说，学徒说，病人说，这些话递到上面，上面愿不愿意走下来，是另一回事。这一章能做的，是让话递得上去；递上去以后上面听不听，要看上面的人肯不肯自己先动。下一章讲的就是这个方向：上位者能不能自己先走下去。

**带走的话**：把“在邦无怨”当成要去读的数，不当成自己心里的把握；每一次好意之后，留一个能回头、能改、能重开的口子。

**这一章怎样算错**：若家里坚持了半年的“上回那样，你觉得呢”，孩子越答越少、越答越空，说明读数已经成了新的评分，本章的做法在这个家里不成立，该撤的是问法，不是孩子。
