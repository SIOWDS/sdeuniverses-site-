# 第30章　三道闸：这不是免罪牌

◆一、一个在摸索，一个在流鼻血

课间十分钟（这是构想的场景），四年级的教室后排，阿凯被同桌小宇碰掉了铅笔盒，里面的笔滚了一地。小宇说了句“活该你放那么边上”，阿凯没有说话，站起来，一拳打在小宇脸上。小宇捂着鼻子蹲下去，血从指缝里渗出来。班主任赶到的时候，阿凯站在原地，拳头还攥着，肩膀一耸一耸，像是要再来一下，眼睛红得厉害，嘴里什么也说不出来。

这个孩子，几个月来一直是这样。他脾气上来的时候，身体先动，话说不出口。班主任私下和家长聊过，家长说他在家也是摔门，已经在慢慢试着学：憋着，数数，去阳台吹风。前一阵他有两次硬是忍住了，转身走开。老师看在眼里，心里有数：这孩子正在摸索怎样处理愤怒，摸索的路上，难免有摔跤的时候。

读过前面几章的人，这时候心里会冒出一个顾虑。前面讲过，意义还没清楚的时候，事中不判善恶；孩子在摸索，处于混沌和介生之间，这一拳，按那个讲法，是不能急着判的。那么，老师该怎么办？看着，不管，等他自己想明白？小宇的鼻子还在流血。

这个顾虑是对的，也是危险的。对，是因为它确实顺着前面的逻辑推下来了。危险，是因为如果顺着推到底，“他还在摸索”就变成了一块牌子，谁举着，谁就可以免于被追问。这一章讲的三道闸，正是为了让前面那条原则不至于变成这样的牌子。三道闸缺一道，不判善恶的主张就会变成纵容；三道闸齐了，它才守得住。

◆二、第一闸：态是相对于人的

先讲头一道。阿凯那一拳，到底处在哪一种态里？对阿凯来说，也许还在混沌里。他自己都说不清那一刻是怎么回事，一团热的东西涌上来，手就出去了。他还没有一套“遇到这种事我怎么办”的东西，那个东西正在慢慢长，现在长到一半。他的意义没有清楚，这一拳之于他，是摸索路上的一个事件。

对小宇呢？小宇的鼻子在流血，嘴里一股铁锈味，脸上又烫又疼，周围的同学都在看。这件事对他不是混沌，是已经结算完了的事：他被打了，疼了，丢了脸，也许从此对阿凯有了一份怕。他的这一页，已经翻过去，写满了。小宇的意义，在这个课间被截断了一小段，这是一个已经发生的事实。

可见同一件事，对两个人，处在两种态里。这是第一道闸：态是相对于人的。不能说“这件事还没定义，所以大家都不判”，那等于拿打人的人的态，去盖住挨打的人的态。电车难题那一章讲过一个类似的边界：同一道题，对扳道的人处于混沌，对坐在办公室里预先写好规则的工程师就不是，他们的意义是清楚的。态跟着人走，不跟着事走。

这一闸一立起来，就挡掉一种常见的滑法：“孩子还小，他不懂，这事不算什么。”孩子不懂，是对孩子说的；这事算不算什么，要问被打的孩子。一个旁观者或者老师，如果只看到阿凯这一边的混沌，就会在不知不觉间，把小宇从屋子里抹掉。第一闸的作用，就是让小宇的位置始终留在画面里。

反过来也成立。小宇这边是已结算的，不等于阿凯那边也可以立刻判成“坏孩子”。前面说过，“恶”这个字要带定位：谁的意义，哪一律，哪一步，多长的窗。小宇被打这一件，算是他的意义被截断了一段，这一点站得住；至于阿凯是个什么样的孩子，是不是“恶”，那要放到他的序列里看，要看这几个月，看他怎么走。一拳不够。第一闸管的是两边各按各的态来对待，不是把一边的态强加到另一边。

◆三、第二闸：时间窗要先说

第二道闸，上一章已经讲了：时间窗要先说。放到阿凯身上，意思是：老师和家长可以说“我们再看这个孩子一学期，看他学着处理”，可以说，但要说定。说定了，窗有头有尾，学期末坐下来回头看，那时候阿凯学得怎样，小宇有没有好转，说清楚。不能对阿凯说“你以后就懂了”，也不能对小宇家长说“孩子之间的事，长大就好了”。这样说的话，窗没有期限，也没有人负责回头。

这里要多看一点，窗是对谁开的。对阿凯，窗是他摸索的时间，他有一个学期来试着做得更好；对小宇，窗是什么？小宇不能因为阿凯在窗里，就一直等下去，让这件事悬着。所以窗要连着另一样东西：小宇这一边的处理不用等窗。他被打，要有人看他的伤，要有人问他怎么样，要有人认下这件事是发生过的。窗是给摸索的人的，不是给受了伤的人的。把两者混起来，就是把一个人的缓冲时间，变成了另一个人的无限期等待。

◆四、第三闸：不可逆的，不享受暂缓

现在讲第三道，也是最容易被误解的一道。阿凯攥着拳头要再动手的时候，老师冲上去拦住了第二拳，把两个孩子隔开，先带小宇去处理鼻子。这个动作，没有任何人会觉得需要等一等再说，等阿凯的意义清楚了再动手。为什么？因为鼻子流血、眼睛旁边挨一拳，这类事情做出去就收不回来了，下一拳可能打在更要紧的地方。

这就是第三闸：不可逆的事，不享受暂缓。伤害身体的，不能挽回的决定，不能以“态未定”为由推迟制止。

必须在这里把一件事明明白白地写出来：这一条不是从前面的方程推出来的。方程只说到一件事：意义未清的时候，善恶无从判定。从这句话推不出“所以该制止”，也推不出“所以不该制止”。方程在这个问题上保持沉默。第三闸是本书另外设下的一条规范承诺：我们决定，不让不可挽回的事在“再等等看”里发生。这个承诺从哪里来？从我们愿意怎样一起生活来。它和本书开头那个设定一脉相承，善恶要对着创造、自由、幸福去判，这是设定，不是推出来的；第三闸也是设定。不接受这个设定的人，可以不接受，但他要明白自己接受的是什么：一个允许不可挽回的事在“他还在摸索”的名义下发生的世界。

这样写，是要防两种偷换。一种是说“方程已经证明了该制止”，那是把承诺伪装成了定理。另一种是说“方程没有说该制止，所以制止没有根据”，那是把沉默当成了许可。两种都不对。第三闸站在方程之外，它自己说明自己的来路，谁都看得见。

第三闸还有一个紧紧跟着的句子：制止不等于判善恶。老师拦下第二拳，拦的是手，没有给阿凯定性。她不必在拦的那一刻就想清楚“这孩子是不是坏”，也不应该一边拦一边说“你怎么这么坏”。拦住了，事态停下来，接下来才是另一道工序：先顾小宇，再去问阿凯。问什么？问序列，第50章会细讲，这里只提一句，大概是“刚才哪一下开始，你觉得不对劲的？”这类问题。要是拦的同时就判，那就把制止和判决焊成一块，介生的孩子就被扣上了定论，这又回到了第27章讲的提前结算。

也许有人反问：拦住阿凯的手，难道不也是替他结算？老师凭自己的清楚，断了他的一次出手，他的摸索不就被打断了？这个问题问得好，要正面答。拦手和结算不是一回事。结算，是把他的矛盾盖上一个结论：你这样做是错的，你是这样的孩子，这件事到此为止。拦手只是让一个动作停在半空，矛盾还原样留着，阿凯心里那团热，一分没少，仍旧要他自己去消化。被拦下的手，事后甚至可以成为他摸索的材料：我刚才差点打第二拳，是什么让我停不下来？只要拦的时候不盖章，拦就是给摸索留了命，而不是替摸索交了卷。打个比方，孩子学骑车，车头一歪，大人伸手扶住后座，这是扶，扶住了，骑车还是孩子自己的事；要是大人顺手把车推走，说以后别学了，那才是结算。

同样的道理，第25章说过：介生状态不享有道德优先（第395卷有一节说的是同一个方向，措辞是本书的）。介生是正在成形，要害在承接，它值得被好好接住，但它不能拿“我还在成形”去压过别人的现实。阿凯正在学，值得耐心；可他的学习不能以小宇的鼻子为学费，还要小宇认下这笔账。

◆五、三道闸怎样防“免罪牌”

把三道闸放在一起看，它们防的是同一个东西——免罪牌，但防的方向有两个。第一个方向，是行动的人拿它当牌子：“我还在摸索，所以我做的事不算数。”第一闸挡住这句话，因为受方有自己的态，他那边已经结算；第三闸挡住这句话，因为伤害不可挽回时，摸索不是理由。

第二个方向，更隐蔽，是施方拿它当牌子：“他还没想清楚，所以我替他定。”这是前一章空档的老路，换了一个说法。第二闸挡住它，因为替他定也要有期限，要先说，要到日子回头，他到时说了算。第三闸在这里反过来起作用：它只给不可逆的事开了口子，范围很窄，不能让“我怕他将来后悔”也混进来。

这一点必须说清楚，否则第三闸本身会变成新的免罪牌。做父母的都有一个体会：几乎每一件事，都可以被说成是“不可逆”的。选哪所学校，不是不可逆吗？今天不练琴，不是不可逆吗？这个年纪错过了，永远错过了。照这个讲法，所有的“为你好”都有资格越过时间窗，直接动手。所以不可逆要卡得很窄：能被事后修补的，不算；能再来一次的，不算；“将来可能遗憾”的，不算。算的是身体的伤害，不能挽回的决定，比如不戴头盔骑车上了大马路，比如把一个人不可恢复的东西拿走。拿不准的时候，可以问自己一句：如果他明天换了主意，还有路走回来吗？有，就不算；没有，才算。

再举一个窄的例子，帮助把这条线看得更清楚。十二岁的孩子想自己骑车去学校，大人担心，但路是熟的，车是好的，这件事就在可修补的一边：先试一周，大人远远跟着看，不行再商量。可要是他想不戴头盔，骑上有大货车的国道，这件事不在窗里排队。头盔要戴，路要换，这一条先做，不用等他想明白，理由可以边走边讲。两件事听上去都是“怕他出事”，分界只有一条：出了事，还有没有回头的路。

阿凯这件事里，两头的分寸大体是这样：拦下第二拳，不等；把小宇送去处理，不等；让阿凯学会处理愤怒，要等，而且要按窗来等；对阿凯是什么样的孩子，不急着判；对小宇被打这件事，认下它发生过，不让它悬着。三件事，三种速度，各管各的。

◆六、留给下一步的问题

有人读到这里，也许觉得三道闸太细，生活里哪能这么拆。其实每个做过老师、做过父母、做过班组长的人，都在这么拆，只是没有说出来。他们拦下孩子的手，同时没有骂；他们答应给时间，同时说了到哪天；他们守着摸索中的孩子，同时没有忘记旁边那个流血的。三道闸只是把这套看不见的手艺写成了字，好让它在手忙脚乱的时候，也有地方可以对照。

再往后，我们就要离开“不能判的时候”，走进“已经翻了的现场”：同一句话，句子一个字没变，怎样从善变成恶。到那里，闸门的作用会一次次出现。

**带走的话**：态跟着人走，窗要先说定；不可逆的事不等，这是另设的承诺，不是推出来的；拦住手，不等于给人定了性。

**这一章怎样算错**：如果让一批老师和家长按这三道闸去用半年，发现多数人还是把“将来可能后悔”的事也当成不可逆，或者拦手时总顺带给孩子定了性，那就说明这三道闸写得守不住，本章要重写。

**本编收口**：第四编问的是，什么时候善恶还没有定义。回答是：意义没有清楚，真善美还没有显露，这时判善恶，是把结果当成了原因。电车难题的三十秒，孩子涂出的第一团颜色，学游泳第一天的怕，都在这个区间里，不判，不是中性，也不是相对，是尚未定义。可是尚未定义有三个出口：欲在空档里总是有读数，于是顶上去替人结算；“以后”如果没有期限，就成了永远不会跳票的支票；态相对于人，同一件事，对一个人是混沌，对另一个人已经结算。所以不判不等于不管：事中只陪、只问、只守闸，守住三道闸；等结算已发生，再回头算账，算清是谁的意义、哪一律、哪一步、多长时间。下一编把这些落到现场：十几个具体的情境里，同一句话一个字不改，怎样一步步从善翻成恶。
