# 附录四　动手前五句话随身卡

这一页可以剪下来，折好，放进钱包，或者贴在厨房门背后。五句话不是咒语，也不是审问，是手伸出去之前，在心里过一遍的五个问题。过一遍，用不了半分钟。过完以后，你可能还是伸手，也可能不伸；这张卡不替你定，只保证那只手伸出去的时候，你知道它伸向哪里。

**第一句　现在能判吗？**　也就是：他的意义清楚了吗？他说得出这件事是为了什么吗？过几天他还认不认？他能不能据此取舍？说不出来的时候，别忙着判对错，也别忙着替他定；先陪着，问着，守着闸。事实另算：病在不在、火有没有着，不等他想清楚。

**第二句　对他此刻要紧的是创造、自由，还是幸福？**　是他要在一团乱麻里自己理出头绪（创造），是他要在缠住自己的东西里自己选一回（自由），还是他心里绷着一股劲，要走通那一下（幸福）？同样一句“我来帮你”，对着这三样，结果可以完全相反。

**第三句　这个词，他指的是什么？**　“累”“冷”“好”“没事”“随便”，同一个字，到了他嘴里，可能是另一件东西。别拿自己的意思去填。可以问：刚才哪一下开始的？像什么？问序列，不递候选答案。

**第四句　他会怎么推？**　我的道理是“天凉加衣”，他的道理可能是“打完球先散热”。两条路都有各自的对错，不用一条去审另一条。先听他的推法，再说我的。

**第五句　这件事，他那边怎么算账？**　我在算我的安心，他在算他的面子、他的时间、他的下一步。我觉得合算的，他那边未必合算。合算不合算，由账本的主人说了算，我只负责问。

用的时候记住三件事。第一，来不及问的事不用问：有人要掉下去、孩子要冲出马路、对方昏迷了，先拦，先救，事后再过这五句。拦住不等于判了善恶。第二，五句话过完，你还是可能错。错了没关系，要紧的是留一个口子：过几天再问一句，“上回那样，你觉得呢”，让他有机会改你的账。第三，这五句话也会用歪。有人拿它当借口，一直问，一直等，迟迟不动手，这就用成了另一种提前结算，替别人把时间耗掉了。有时间窗，先说出来，别无限期延下去。

遇到连续几周的累、睡不好、不想上学、情绪低落，这张卡帮不上忙，请找医生或专业人士。
