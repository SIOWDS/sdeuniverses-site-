## 附录一　术语表：把专门话放回日常

| 术语             | 本书中的通俗解释                                                                                          | 必须避免的误读                                             |
|------------------|-----------------------------------------------------------------------------------------------------------|------------------------------------------------------------|
| 现实刻痕         | 在具体采样和测量条件下留下的记录                                                                          | 数字就等于人的全部状况                                     |
| 理念符号         | 医学共同使用的分类、指南和判断规则                                                                        | 标准只是任意约定、可以不理                                 |
| 自我符号         | 对身体经历、生活影响与自身处境的理解                                                                      | 个人感觉就是临床诊断                                       |
| 三界对账         | 核对三类信息的范围、差异和下一步责任                                                                      | 三栏相互投票决定疾病                                       |
| 参考区间         | 依据规定人群和方法建立的统计区间                                                                          | 区间内必然健康、区间外必然有病                             |
| 临床决策限值     | 用于某种专业判断的阈值，依据与目的可能不同                                                                | 与参考区间永远相同                                         |
| 解释缝隙         | 信息或理解尚未对齐、可以事前登记的差异                                                                    | 一定隐藏了未知疾病                                         |
| 标签固化         | 用既有名称过度覆盖新信息或个人身份                                                                        | 诊断标签本身都没有价值                                     |
| 结晶             | 有条件地形成相对稳定的理解和行动习惯                                                                      | 一个人依靠意志力即可成功                                   |
| 连接度           | 对关系连续性和相互理解的理论描述                                                                          | 已有统一量纲的医学测量                                     |
| 动能／势能／内能 | SDE符号学正式工作词：动能是沿差异序列拆接的方向与速率；势能是纠缠网络的吸引、拉扯；内能是连接度与断裂难度 | 不可直接当作医学仪器读数，但也不能降为随意比喻             |
| 共同决策         | 结合证据、专业判断和病人价值共同商议                                                                      | 医生和病人的责任完全对等                                   |
| 复述确认         | 通过重新说明要点检查沟通是否清楚                                                                          | 考核病人记忆好不好                                         |
| 待核             | 引文或事实仍须查证原始材料                                                                                | 可以不核实直接出版                                         |
| 待对账的问题     | 有来源、有边界、状态与责任记录的候选沟通事项；可重开，关闭只表示本条任务按规则处理                        | 不是疾病、不是诊断不确定性的同义词，也不代表临床问题已解决 |

## 附录二　三栏对账单模板（研究与沟通原型）

使用声明： 以下模板用于研究医疗信息的表达与承接，不是疾病筛查、诊断、分诊或治疗工具；个体病情请遵医嘱。仅记录必要信息，注意隐私和授权。

### A　医生版

| 记录字段     | 现实刻痕：检查／观察           | 理念符号：专业解释／标准   | 自我符号：体验／价值           |
|--------------|--------------------------------|----------------------------|--------------------------------|
| 目前知道什么 | 来源、日期、测量条件、已知局限 | 适用的解释范围与尚不确定处 | 病人的主要问题、担忧与生活影响 |
| 哪些不一致   | 客观记录中未回答的疑问         | 标准可能未覆盖的处境       | 病人理解与专业解释的差异       |
| 下一步谁负责 | 待核对资料及责任人             | 解释／转介等由合格人员决定 | 需要再次确认的理解和偏好       |

对账记录：差异类别〔S来源／B解释边界／T时间／V意义价值／A行动可行性／H责任交接；或X-INS／X-NONE／X-OUT出口状态〕；发现日期；责任角色；预定核对节点；患者是否理解此次沟通重点。所有医疗决定遵循当地法律与临床规范。

### B　护士版

| 问题                       | 记录                         | 后续承接                   |
|----------------------------|------------------------------|----------------------------|
| 病人如何复述专业说明？     | 只记关键差异，不替病人作答   | 必要时向负责的专业人员反馈 |
| 哪些实际执行条件受到限制？ | 生活条件、资源与理解障碍     | 明确交接对象及时间         |
| 哪个问题还没有回答？       | 使用病人的原话，注明不确定性 | 记录何时回访及责任岗位     |

### C　病人和家属版

| 我已经听明白的               | 我自己的生活和感受             | 我还想问的                           |
|------------------------------|--------------------------------|--------------------------------------|
| 医生解释的内容，我的理解是…… | 对日常有什么影响，最担心什么…… | 哪些问题暂时不能确定、下次向谁询问…… |

# 后记　让未说完的问题有去处

这本书从一张全在参考范围内的体检单开始，以同一张纸结束。中间经历的所有理论、研究和表格，只想使一种常见的处境得到认真对待：医学已经说出许多重要的事实，而人的生活可能还有尚未进入共同语言的问题。

医疗工作并不轻松。专业人员承担安全、准确与时间上的责任；病人和家属承担不确定与生活变化的压力；管理者还要为制度运行、隐私和资源公平负责。彼此理解需要条件，而不能只靠道德要求。这正是继续研究医疗符号学的原因。

本书不给诊断和治疗建议，不替代任何临床规范。书中说明性人物和对话均为虚构；理论模型与工具仍需经验检验。若读者面临具体病情，请向合格医疗专业人员寻求帮助。具体病情请遵医嘱。
