# 结语　还是那张饭桌

## 又一个周六

周六晚上七点二十，岳岚家的饭桌上又摆好了菜，热气还没散。晚饭还是比平时早四十分钟，因为她八点要赶去医院接夜班，桌上的钟，一直是按她的排班拨的。这一点没有变。变的是桌上多了两个人，墙上多了一样东西。

墙上的东西不在屋里，在楼道里。十二号楼的电梯里，现在贴着一张纸，每个季度换一次，上面写着电梯维保花了多少钱，修了什么，谁签的字。邵伯每天下楼晒太阳，进电梯的第一件事，是把那张纸从头看一遍，看得比报纸还认真。有一回他对老邵说，你们现在能看到账了，我们那会儿，账是厂长的，工人只能看到工资条。老邵说，那你看出什么了？邵伯说，看不出什么，就是看着踏实。

舅舅提着两盒牛奶进门，这回舅妈跟在他后面，手里拎着一袋橘子。舅舅的电话照例在门口响了，他看了一眼屏幕，接起来，说了句什么，全家人又照例停下筷子等着。可是这一回，他只说了半分钟。“我吃完饭回你，十点以前。”他说完把手机放进了外套口袋，外套挂在了门边的钩子上，他走回桌边坐下。岳岚看了他一眼，没有说话，把汤碗往他那边推了推。

这半分钟的变化，要搁在一年前，没有人会注意到。舅舅自己也没有想过要特意做什么。是舅妈的事。舅妈从前每周三晚上上一节陶艺课，她很喜欢，后来舅舅的事业忙起来，周三晚上总有应酬，总有加班，接孩子要有人去，于是那节课先是缺席，再是退了。她从来没有抱怨过，她的日程永远可以改，这是这个家里谁都没说出口的规矩。前不久的某个晚上，舅舅在书房里坐到凌晨，出来以后对舅妈说，周三晚上我来，你去上课。舅妈愣了一下，说你那么忙。他说，周三我不排事情。

老邵坐在靠门的位置，他的手机放在了碗柜上。这是小禾定的规矩，饭桌上不许拿手机，她说得很简单：一个钟头，你手机里的单子又不会跑掉。老邵一开始说不行，平台看接单率的，一个钟头不接，系统会少派给你。小禾说那你少赚多少？他算了半天，说一个月大概三百来块。小禾说，那就三百块，换一顿饭。他没再争，大概是因为说这话的是自己十四岁的女儿，看他的眼神，像在看一个她得负责说服的人。

饭吃到一半，小禾从书包里翻出一张纸，是那篇河的作业，发下来了，老师在上面打了个优。她把纸递给邵伯，说爷爷你看。邵伯戴上老花镜，看到老师在那句话底下划的线，念了出来：“我们车间的废水，也有一份。”他念完，把纸折好，放在了桌角，没有说话。过了一会儿，他说，这句话我在心里说了二十多年，没跟谁说过，没想到是跟孙女说的。岳岚在桌下碰了碰他的手背，他没有躲。

这一晚上的细节，一点一点说出来，不是要讲什么大事。这一桌饭，依然没有人吵架，没有人下命令，也没有人欺负谁。排班表还是那张排班表，算式还是那道算式，舅舅明天一早还是要回到那个二十个人一咳嗽就安静的会议室。只是如果你像书的开头那样，拿一个小本子，坐在这张桌子旁边，记下每个人这四十分钟是跟着什么在动，你会发现，有几格，跟一年前不一样了。

## 小本子上的那几格

我们一格一格地读，仍然从岳岚开始。岳岚的夜班，这个月仍然是九个。她和三个同事整理出来的那份半年排班的数据，递上去以后的事，第44章已经讲过，这里不重复。书里说过，这件事很小，也不一定成，我们没有写大。她自己的变化是另一种。那个绿本子在抽屉底下放了二十年，被小禾翻出来读过以后，又回到了抽屉里。她没有这个心力去整理那些旧稿，只是在一个夜班的后半夜，值班室里没有人，她在交班本最后一页的背面，写了四行字。四行，没有题目，写完把本子合上，没有给任何人看。第二天回到家，她睡觉前想起来，那四行字没有写给谁，也不为什么用处，就是为了写，这一点连她自己都有点吃惊。这一格很小，小到在外人眼里根本不是一格。可是在她的日程里，这是二十年里头一回，有了一块完全属于她自己的空白，哪怕只有十分钟。

邵伯这一格更小，小得要靠旁人才看得见。中风之后，他的右手一直不太听使唤，吃饭用左手，慢，饭菜还要岳岚替他拌好，鱼刺要先挑净，汤要等人有空才端到面前。这个周六，他自己把汤碗拉到面前，用勺子舀，手抖，汤洒了半勺在桌布上，一勺送到嘴边，又洒了一点。岳岚的手已经伸到了半空，停住了。她想起来，医院里的康复师说过，让他自己来，慢一点，洒了就洒了。这是她这些年最难的一件事：手放下去。邵伯喝完了这口汤，没有看任何人，说了一句，“有点咸”。桌上的人都低头吃饭，没有一个人笑，也没有一个人说话。这一勺汤，岳岚学了很久，才学会不替他喝。那天晚上她洗碗的时候，嘴里哼了半句什么，老邵没听清，问她，她说没什么。

小禾的一格，不在她自己身上。她要的，是饭桌上这一个钟头，老邵不要看手机。这是她这个年纪的一个孩子，能从一个家里挪出来的最大的一块东西，她挪得动，不靠吵，靠的是一个她事先想好了的数字：三百块。书里说过，小禾是家里能反过来改变大人的那一格，这一回我们亲眼看见了。她自己还有一格，只有她自己知道。那天下午她从河边回来，发了一条朋友圈，一张河的照片，配了一句话，她写了三遍，没有删，发出去了。只有七个赞，她看了一会儿，觉得够了。这是她发朋友圈这件事上，第一次没有先替别人把自己管好。

舅舅的周三，前面已经说了，他在这个家里让出来一个晚上。也是书里讲的“替动”的反面：他的日程，从常量变成了一点变量。没有人逼他。舅妈那堂课，现在每个周三晚上准时开始。她回来的时候手上沾着泥，指甲缝里是灰白色的，舅舅有时候会问一句，今天做了什么，她拿出来，一个歪歪扭扭的杯子，釉还没有上。他看了看，说杯口有点斜，舅妈说，你不懂，这叫手作。两个人都笑了。舅舅那封辞职信，现在还躺在他电脑里，没有发，也没有删。这封信的事，我们不知道结局。那份名单后面附的一页纸也一样，上面的人有没有读，读了怎么想，他到现在也不知道，没有人回过一个字。

老邵的一格，是三百块买来的这一个钟头，还有另外一样。他在一家面馆门口站着等单的时候，有一个问题没走，书里讲过。他现在也还没有答案。上个月的一个周日上午，他骑车去了城东那条河，在步道上坐了一个钟头，什么也没有做。他对岳岚说，不知道为什么想去，去了也没有想到什么。岳岚说，没想到什么也好。他又说了一句，“我想学着做点吃的”，说完自己觉得好笑，岳岚没笑，说，学。这件事到现在也还没有开始，可是“学”这个字说出来过，是这一年里他第一次说出一句不是为了谁的话。站点后面那三个人的纸，倒是写出来了，三条，一页，现在还在他们的口袋里，没有递出去。这一头怎么收场，我们和第46章一样，不替他编。

梁老师没有来吃饭，但这家人在楼道里常常遇见她。她卸了业委会主任的担子以后，每个周二下午在小区的活动室里支一个画架，画窗外那棵老香樟，画得慢，常常一个下午只画半边树。有人路过问她，梁老师你怎么不管事了？她说，管过了。她的那一格，是别人接手以后空出来的。接手的人，是那个四十多岁的新主任，他的晚上从此不属于自己了，这一点梁老师比谁都清楚，所以每次见到他，都要问一句，吃饭了没有。业主大会如今都开在周日上午，上班的人来得了，新主任自己的周日上午，就是这样被换走的。

韩律师也来了，坐在邵伯旁边，带来一盒糕点。她和邵伯聊起他那份申诉，还在走，她说，法律的路慢，别指望哪天一早起来就有个结果，但每一步我们都是在往前走。邵伯说，我等了一辈子了，不差这一年。她笑了。

吃饭的时候，小禾隔着桌子问韩律师，当律师是不是就是帮别人把话说成规矩认的样子。韩律师夹着菜想了想，说，差不多，有时候还要帮规矩把话说得更像人话。小禾笑了，没有再问。她低头扒了一口饭，心里大概在把这句话和爷爷那页纸上的线放在一起。桌那头，邵伯正在和舅舅争一个橘子的甜不甜，两个人都不肯让步，谁也没有下令，谁也没有让谁。

## 什么也没有变

读到这里，你也许要问，这一家人，是不是日子好起来了？这个问题，我们得回答得小心。有几样事情是没有变的。岳岚每个月的九个夜班没有变，八个的那条线也没有人答应，医院的人手、考核、医保额度，都还是原来的样子。老邵的平台、那道算式，没有变，他每个月少了三百块，是实打实的。舅舅的公司，下一季度的报表，还是要交。邵伯的右手，不会好起来。小禾的月考，下周一照样来。

水没有换。这是这本书从开头一直在讲的：权力是盐水里长出来的结晶，砸碎它，水没换，它又长回来。这一年没有人砸碎什么结晶，也没有换过哪一整碗水。如果有谁看到这里，期待着写一个“他们把一切都改好了”的结局，我们要老实告诉你，没有。

那变的是什么？先说一件容易漏掉的。舅舅还是那个一咳嗽全场安静的人，他在会议室里的位置，一寸也没动。书里讲过，权力和弄权要分开，他是坐在结晶上的冲浪者，浪不是他造的，但骑哪一道浪、骑上去以后撞不撞别人，他可以选。这一年里他选了几次，有一次他在名单后面多附了一页纸，有一次他让出了一个周三。这些选择，没有一次动摇过那个会议室，但每一次，都让坐在会议室里的人，多留了一点自己。

变的是几个很小的地方。舅舅让出了一个周三，这个周三是他的日程让位，舅妈的课才排得进去。老邵让出了一个钟头，代价是三百块。岳岚学会了把手放下，代价是邵伯洒了半勺汤。每一格都要付点什么，书里第8章讲过，不动要有人替它撑着，反过来，动也有它的价钱。一格被挪出来，总有一个地方要付出点什么。我们不想把这件事说得轻松。

这样看，这一家人身上发生的，和书里讲过的那些办法，是一个路数。不是对着某一个人用力，不是去攻哪座城堡。是在各自的地方，改了一点让结晶长出来的条件：舅舅改了自己的周三，老邵改了自己的接单率，岳岚改了自己的手。条件一点一点在动，局面没有塌，也没有长回原样，只是松了一点。松多少，往哪边松，这本书不敢说。

导读和附录二里立过几条规矩，说出现什么情况，就说明这本书错了。我们拿这一家人对一遍，对不上的地方不遮着。第一条，换掉最上面的那个人，局面很快整个消失，并且不再长回来。梁老师卸了任，新主任上来，账还是每个季度贴，这是章程里那几根刺的功劳；可是没有人敢说，换了人，那块结晶就没有了，新主任的晚上，也已经被它占去了。这一条，在这家人眼前没有出现反例。第二条，替动的人全都不再替，那一处影响别人的能力并没有下降。这一条我们没有机会试，没有一个地方的人是一起停下来的，只有舅舅的一个周三，老邵的一个钟头，每回只停一小格。停下来的那一格，对面确实松了一点，舅妈的课上起来了，但这太小了，当不了证据，我们只算它一点侧面的消息。

第三条落在最后一句上，也最难。岳岚的同事方姐照护失智的母亲六年，替母亲动了六年，说不上不幸福，别人也不会这样说她。这个反例，第36章没有绕开，我们的办法是把话收窄：替动的人排不上日程，这句话会随条件变强，替的是一个盼着自己不再被需要的人，还是一个越收越紧的局面，结论是不一样的。岳岚自己也在这条缝里。她替孩子、替老人动的那些钟头，带着倒计时；她替排班表补缝的那些夜里，没有倒计时。她手里那四行字，是从后一种夜里挤出来的。这个分法站不站得住，请你自己去判。

还有一件事要承认。这几格里，有几格，是靠别人替它动换来的：舅妈的陶艺课，是用舅舅的周三换的；小禾的一个钟头，是用老邵的三百块换的。换来的格子，比起没有换，当然好。但如果你仔细看，哪一格是白得的？没有。这是这本书里最诚实的一句话：这个世界上没有哪一个人，可以完全不替别的什么在动，也没有哪一格，是不要钱的。能做的，只是看清自己手里的几格，在哪里，为什么而动。

## 这本书走过的路

这一本书很长，我们在这里把走过的路收一收。第一编讲的是“析出的局面”。我们从舅舅那间十一层的会议室开始，看一声咳嗽怎样让二十个人安静，看一个人的头衔和他说了算的那些事为什么常常不是一回事；然后用一杯盐水，讲权力是结果，不是谁在操作的过程，你砸碎结晶，水没换，它又长回来。第7章讲的权力和弄权，也在这里：权力是结晶，没有主人，弄权是有人骑在上面；冲浪的人可以选浪，造不了浪。第8章讲到有权力的标志是不必动，别人替它动。

第二编讲的是“别处怎样替它动”，六种做法：替它等，替它跟，替它撑着不变，替它补缝，替它翻译，替它先管好自己。我们一样一样地看，看岳岚怎样用自己去补制度的缝，看老邵怎样跟着一道算式改自己的睡眠，看小禾怎样在发出去之前先把自己删干净。后面几章讲了几种特殊的局面：从不发令的咽喉，找不到主人的网，模型不动、人替它动。

第三编讲的是“为什么排不上日程”。这一编是全书最沉的一块，我们从看得见的动作，一层一层往下，走到选项、想要，走到世界，走到一个人把局面叫作自己的性格和运气。岳岚的抽屉，老邵凌晨两点的手机，就是这一编的两个样子。它很少直接压你，只是让你的创造、自由、幸福一直排不上日程，不必回答错，只要“我究竟要什么”这个问题问不出来。

第四编讲的是“那怎么办”。先讲家里的权力，爱和不对称并不互斥，家里最弱的那个人叫不叫得开门，要紧得很；讲“管不住自己”是谁管不住谁，那是身体里一场不对等的较量，靠喊口号是赢不了的。再分清好坏：好的权力盼着自己失业，判据是方向盘最后还不还给人；说服和操纵，差在通道你看不看得见。然后讲改条件：对着冲浪的人用力没有用，要去疏通河道，权利是要年年维护的河道，法律也要学会有的地方不看。最后讲弱者的第一课是盘点，不是变强，讲命名、判错、计算三件小工具，讲四种结局，讲一群人怎样一起，讲替还没出生的人想一想，讲为什么谁也封不死你。

四编加起来，不过一件事：看清楚，那个局面里，谁在替谁动，替动的人，自己的日程还剩没剩一格。书后的附录里放了几样东西，都是给用得着的人备的：一张给一段关系做体检的六步表，一页“出现什么情况，说明本书错了”的汇总，一张近邻表，把我们在书里请过的那些前人和他们各自说对了什么放在一起，还有一张白话和术语的对照。最后这张表，是给想接着读理论专著的人留的。其余的人可以不看，书里的话，没有一句靠它才能读懂。读到哪里读不懂，那是我们没有写明白，不是你的错。

## 读完以后

书到这里，该放下了。放下之前，我们想说几句不算建议的话，因为一本讲权力的书，不该再给你布置作业。我们知道你的晚上多半只有半个钟头，读一章就到点了，这本书写得长，也是因为想让你每次只读一章，读完能放下，第二天想一想，隔两天再翻。你不必把这本书里的办法都用一遍。大多数日子，大多数关系，你就是在里面过着，不去体检，也不去整理成三条。这些办法放在那里，像一个工具箱，用得着的时候再翻。要挑一件最小的事，我们觉得是这一件：下一次你说“我这周很忙”的时候，留意一下，是谁的周跟着调。下一次你听到“我就是这样的人”，不管是别人说的还是你自己说的，顿一下，问一句这话是谁先说的。不需要答案，只要问一句。如果你还想再带走一样，就是第40章那张体检单里最小的一步：下次对谁生气的时候，先问一句，这个位子上换一个人，事情会不会变。会变的，是人的事；不会变的，去找条件。这一问用不了一分钟，却能省下很多本来要花在墙上的力气。

如果你想往深处读，站上有一本理论专著《权力为何物：SDE权力发生学》，里头用的是另一套更硬的话，公式也多，它是这本书的底子。这本书把里面的机制，用这家人的饭桌重新讲了一遍，讲错的地方，由我们负责。你要是在自己家的饭桌上、自己单位的会议室里，发现书里有哪一句对不上，请你记下来。每一章末尾我们都写过，出现什么情况，就说明这一章错了。一本讲权力的书，如果不许人反驳，它自己就成了一块结晶。

## 一句话

回到开头，回到那一页。书的开头说，这本书只说一句话，现在我们可以把它再说一遍。这句话里的每一个词，现在都有了一个人，一张桌子。“众多因素联合析出的一种局面”，是岳岚的排班表，是十二号楼里三千户人家的电梯，是邵伯那条城东的河。“一处不必动，别处替它动”，是舅舅的一声咳嗽，是老邵跟着的那道算式，是舅妈那个永远可以改的周三。“替动的人，自己的创造、自由、幸福排不上日程”，是抽屉里的诗，是凌晨两点床沿上的手机，是小禾删了又删的那条朋友圈。你可以把它们一个一个对过去，对得上，这本书就算讲清楚了；对不上，请把对不上的地方记下来。

我们讲这些，不是为了让你去恨什么，也不是为了让你去怕什么。恨一座结晶没有用，怕它也没有用，它是水浓到那一步长出来的，要改，得去改那碗水。我们是想请你回到自己的饭桌旁边，拿一个小本子，看一看那四十分钟里，每一个人是跟着什么在动，再看一看，这张单子上，有没有哪一格，是他自己想动才动的。有的话，请替它守住；没有的话，请想想，哪一处的条件可以松一点，松哪一寸，让谁先松。

七点五十，邵伯的药，小禾记着，端水过去，差了两分钟。老邵在水池边洗碗，舅妈在擦桌子，舅舅走到阳台上接那个电话，说好的十点以前回，这回说得很快，一分钟就回到了桌边。岳岚穿好外套，走到门口，回头看了一眼这张桌子：碗筷还没收完，橘子皮摊在盘子里，邵伯的汤碗里剩着小半口汤，是他自己没喝完的。她关上门，下了楼。桌上的钟走到八点整。这本书讲了这么久，说到底还是那一句话，权力是众多因素联合析出的一种局面：一处不必动，别处替它动，替动的人，自己的创造、自由、幸福排不上日程。
