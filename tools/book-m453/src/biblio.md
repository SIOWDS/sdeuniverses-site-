# 参考书目

本书的参考书目很短，只列确实核实过的：本书所用的经文版本，和站内与本书有明写关系的几本专著。本书对他人看法的转述一律只取大意，不作逐字引文，故不另列学者著作。

### 一、经文版本

1. 《圣经》和合本，1919。本书全部经文引文所据；已逐处对照核对，附录一为经文索引。

### 二、站内同源与相关专著

2. 王德生：《爱的箴言新解——信是内能，望是动能，爱是势能》，德麦国际专著第 503 号，德麦国际出版社，2026。同读林前 13 章，纵向的读法；本书第 2 章用到其“忍耐即粘性”。
3. 王德生：《我是道路、真理、生命——普通人都能明白的耶稣的 SDE 智慧》，德麦国际专著第 301 号，德麦国际出版社，2026。第六部借其三个主例和“无中心”一说。
4. 王德生：《耶稣之善——从固有属性论到SDE三律丰满运行的价值发生学》，德麦国际专著第 271 号，德麦国际出版社，2026。第 46 章取其一条界线。
5. 王德生：《新文明诞生——同一性谱系化》，德麦国际专著第 402 号，德麦国际出版社，2026。相关阅读，正文未引用其文字。
6. 王德生：《化冲突——谱系社会的新知识发生器》，德麦国际专著第 496 号，德麦国际出版社，2026。相关阅读，正文未引用其文字。

读书建议：先读和合本林前 13 章三遍，再读本书导论，然后按手头的事选章。各书与本书的关系，见附录四。
