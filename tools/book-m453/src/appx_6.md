## 附录六　术语白话对照

全书用到的几个术语，先说白话，再标出处。（SDE 是显露 Show—差异 Difference—纠缠 Entanglement 的头一个字母。）

| 术语 | 白话 | 首见 |
|---|---|---|
| 统一性 | “大家都一样才算一家人”的想法：口味一样，看法一样，做法一样 | 导论 |
| 同一性谱系 | 同一段时间里，有的层必须同，有的层可以异；必须同的那一层尽量薄，可以异的层尽量放开，像一条光谱。它是“横着”的线，不同于尼采、福柯所说的纵向的谱系 | 导论 |
| 最薄的核心 | 必须同的那一层，薄到只剩最要紧的；薄，不等于最少，也不能薄到零 | 导论，第 10 章 |
| 三种走法 | 强求同一、部落化、创造 | 导论 |
| 机械的忍耐 / 创造中的忍耐 | 前者把力气耗掉，后者把力气存起来，存成新的东西；外面看几乎一样，分别在忍了以后有没有东西在长 | 导论，第 2 章 |
| 虚幻解法 | 用“爱”只求暂时平息的做法：暂时平息，很快复发，级别升高；原因是泄了压，没改形状 | 第 1 章 |
| 张力 | 两股力道的拉扯：我想要的和你想要的不一样，我认为对的和你认为对的不一样 | 第 1 章 |
| 双亏 | 机械的忍耐里，受苦的一方亏了自己，受益的一方亏了成长和真实 | 第 2 章 |
| 两种放弃 | 放弃自己的多样性（被推进对方的中心），放弃共同的同一性（跳到反向的中心） | 第 3 章 |
| 三句判别 | 在不在真理里；有没有生出新东西；守没守住最薄的核心 | 第 4 章 |
| 同一性知识的创造力 | 化解冲突的三步手艺：分层、生成、回流 | 导论，第 10 至 12 章 |
| 分层 | 和对方一起找出必须同的那一层，和可以不同的那些层 | 第 10 章 |
| 生成 | 在可以放开的层上造出新做法，让对方在乎的东西在我这里出现；不是折中 | 第 11 章 |
| 回流 | 新做法反过来使最薄的核心更厚；爱在这时成形 | 第 12 章 |
| 作账 | 不记账，不等于不作账：把旧账说清、处理，再开一个新账本 | 第 23 章 |
| 显露 | SDE 的 S：差异和需要被摆到桌面上 | 导论小账 |
| 差异 | SDE 的 D：真实的不同，口味、看法、需要、做法的不同 | 导论小账 |
| 纠缠 | SDE 的 E：人与人彼此牵连、绕不开的关系 | 导论小账 |
| 三方程 | S=F(D,E)，显露由差异与纠缠生成；D=G(S,E)，差异由显露与纠缠生成；E=H(S,D)，纠缠由显露与差异生成 | 各章小账 |
| 三拍 | 张力积累、形状改变、回写 | 各章小账 |
| 九步中的“分化、重组、升维” | 本书取其一般意义；第六部借第 301 号时，按 301 号的专指 | 第 29 章，第 44 章 |
| 单中心的尺子 | 只拿一个人或一个立场做标准去量所有人，会量错 | 各章小账 |
| 反向中心 | 被推进对方的中心的反面：跳到对面去。反中心不等于反向中心 | 第 3 章，第 43 章 |
| （本书的读法，待验） | 经文没有明说、是本书推出来的动作、动机、因果和先后；请当作有待检验的读法 | 导论 |
