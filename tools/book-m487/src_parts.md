# 第一编　粥的统一性：母题

这一编回答书上为什么没有路。它从恩格斯的批评起步，先替他把话说足：把事物看成孤立、静止、一次定终身，这种想法确实该反对。然后一步一步看，反对的范围怎样扩大，直到凡是想把某一块东西固定下来单独看的做法，都有被判错的危险。

第1章看恩格斯反对的究竟是什么。第2章立全书第一个关键区分：统一性和同一性，并追问“正当甚至必要”那句话后来去了哪里。第3、4、5章各拆一层：联系怎样从方法话变成世界话，发展怎样成了唯一不发展的句子，否定静态怎样反过来改写了判错的标准。第6章把三层合起来，正面陈述粥的统一性，四格在这里全面展开。

第7、8、9章各查一个特征：无独立、无稳定、无整体，看缺了隔开、留住和能数，判错为什么难。第10章找粒子掉在哪一步，从恩格斯手里的边界，经普列汉诺夫，到1938年的那一章。第11章回到马克思本人：他手上有粒子，却没有给它正式的名分，这就留下一个新问题，师傅不在场的时候，谁来说他说过什么。

# 第二编　粒子从外面补

粥里捞不出立得住的东西，可一门学说总得开课、结队、分对错，于是粒子只好从外面来。这一编看外补的三样东西，也看它们为什么没有消解问题。第12章讲招牌：一个名字能让一堆说法“算一块”，而 1881年抽屉里的草稿显示，名字的主人也可能说这些人他不认识。第13章讲定本：稳定掉了以后，只剩纸还留得住，于是开箱与封箱同时进行。第14章讲裁决：检验能在别处重做，裁决只能在原处重说。

第15章把三样东西放回时间里。写的、印的、官定的，三条线错开了半个多世纪，每次新材料露面，名额都被重新打开一次。也是在这一章，本书最强的对手正式上场：安德森一路的局势说解释的东西比公式多。本书只说局势决定何时捞、往哪边捞，公式决定为什么总要捞；这句话还不能检验，对手没有被排除。

# 第三编　各家捞米：一个名额，多粒米

这一编一家一家看。每一家都先问三件事：他觉得粥里缺什么，他捞上来的是哪一粒，这粒米靠什么立住。道理先给足，再看缝。第16章考茨基捞规律，第17章列宁捞党，第18章卢卡奇捞方法，第20章阿多诺捞单个者，第21章阿尔都塞从结构走到原子，第23章文献派捞手稿，第24章毛泽东捞主要矛盾，第25章中国这一路捞实践。

有两章专门处理不合模式的情形。第19章写没捞的人：葛兰西和布洛赫是反例，它们逼得“每一家”改成“多数家”。第22章写出锅的人：伯恩施坦、分析马克思主义、拉克劳与墨菲捞到较硬的东西之后，名字要承受压力；可是三家逐一查下来，比初判弱，不能单独承重。

第26章做清点，十四家数下来，符合七，半家四，反例二，存疑一。这次清点由写作者自判，没有独立编码，也没有真跑，只算一份可以被重数的底稿。它要说的只是：争的如果是同一把椅子，这些米就并不成一桌菜。

# 第四编　于是只好摸

理论里捞不出路，人还是要过河。这一编回到书名。第27章查这句话的来历：1950年到1988年，一句稳当话怎样走成一个方法，以及它里面没人讲的第四样东西。第28章收窄本书自己的说法：粥只是摸的条件，不是唯一原因，林德布洛姆、波普尔、伊莎贝拉·韦伯都不靠粥也走通了各自的路。第29章看试点：嘴上说都连着，手上先隔开一块，这是偷用的形而上学，石头的三条也在这里定下，并交代它们早有主人。

第30、31、32章分三种情形：有石头的河，看分田到户、特区、双轨制怎样隔得开、留得住；摸到的未必是石头，样板好看，推广后常常缩水；没有石头的河，隔不开、留不住、数不清，只好另想办法。第33章把“淹”字说死：淹的意思是退不回来，失败不等于淹。这一编只做类型分析，现实案例以已有研究基础的年代为主，不评判政策功过。

# 第五编　静态的同一性谱系：石头怎样发生

诊断之后说出路，并让出路接受同一把尺子。第34章借中观这面镜子：它连“空”也空，却先把粒子的名分留下了，同样一个口径，可以有两种安排。第35章正面立论：不是一锅粥，是一桌菜，反静态的统一性，不反静态的同一性谱系；它先把这个“静态”与站内第402、508 号两书所反的“静态”对齐，再用三个方程读四格，并说明这是一个“应该”，不是一个必然。

第36章讲垫石头：边走边让粒子发生，写回制度，并且能撤；也接住阿多诺会有的质问，把世界切成一格一格，这本身是不是暴力；再与科林里奇的可逆、可纠正对照，问撤回键该由谁来按。第37章最难写：医生也要给自己量一次血压。本书拿同一把尺子量作者所属的 SDE 这一派，列出它已经撤回的和还挂着的账，并把自己倒掉的条件写在那里。
