## 附录一　班级谱系诊断卡

**用法**：每月一次，班主任和两三个孩子（轮流）一起填，用时不超过二十分钟。填完贴在谱系墙背面，下个月对照。读数只给班级自看，不进考核。

**第一部分：四个读数（第 29 章）**

| 读数 | 怎样数 | 本月 | 上月 | 白话提醒 |
|---|---|---|---|---|
| 谱系事件率 | 每两周一期：四关都过、两人签字、有定理册或词典编号的事件次数 | | | 一期连一次都没有，先别急着下结论，看是不是底座太厚 |
| 「我的知识」指认率 | 每月最后一个周五，每个孩子在墙上或册子里找一处自己的一枝，借用的同学点头确认；找得到的人占全班的比例 | | | 说「好像有」不算，要能指出是哪一条、变在哪里 |
| 互相查错率 | 每两周一期：定理册草稿和作业里被指出的错，同学先指出的占几成 | | | 老师自己的错被孩子先查出，也算进同学那一堆；指错不指人 |
| 分歧化解匹配度 | 每两周一期：化成谱系事件的分歧数，除以「吵得有内容」的分歧数 | | | 太低是化不过来（第 16 章两个速度）；太高也要看分歧本身是不是少得可疑 |

**第二部分：阈值四信号（第 6 章）**

| 信号 | 本周有没有 | 已连续几周 |
|---|---|---|
| 作业抄成一片（同一题十份以上同一个错法） | □有 □无 | |
| 班干部没人愿意当（改选时冷场、推辞） | □有 □无 | |
| 按统一步骤教的题型，错误率不降反升 | □有 □无 | |
| 家长群深夜爆发争吵 | □有 □无 | |

判读：第 6 章的推荐值是四个里同时亮三个、连续三周，才算越过阈值；一个信号、一周的波动都不算。越过了，就说明统一的那套「同的方式」撑不住了。这时候先别急着开班会摆平（第 6.1 节），也别放任：底座照常零容忍。各班可以按自己的情况调这个数，但要在动手之前写在卡上，不要亮了以后再临时改。

**第三部分：饱和三判据（第 28 章）**

| 判据 | 怎样看 | 是否出现 |
|---|---|---|
| 谱系事件率连续下降 | 每两周一期的事件数连成折线，连续几期往下走（考试周那一期掉下来不算） | □是 □否 |
| 新枝集中来自少数孩子 | 新条目的第一作者，越来越总是那几个名字 | □是 □否 |
| 新条目与旧条目越来越像 | 每条新条目后面写「最像第几条、差在哪里」，「差在哪里」越来越多地只能写「换了图形」 | □是 □否 |

判读：三条同时亮，连续两到三个统计期（每两周一期，就是一个月到一个半月）没有回落，就是这一轮谱系长满了，该准备合谱仪式与换根（第 28 章）。只亮一两条，多半是别的事：只有事件率下降，可能是考试周或根不够好；事件率降、新枝集中而新条目并不相似，往往是小圈子，要看连通度、要搭桥，不是换根。

**饱和以后：合谱仪式四步（第 28 章）**

第一步，最后一轮认出。每个孩子去墙上或册子里找一条：我的哪一枝在别人那里长着，长成了什么样；借用的人站在旁边说一句从哪里拿的、改了哪一处。找不到的，请全班帮着找；最后仍找不到的名字，不贴出来、不点名，只记成全班的一个数，作为下一轮最先搭桥的地方。第二步，压实。全班问每一条：下一轮还要不要人人都一样地用它？绝大多数不用，好好存着；只有极少几条压进下一轮最薄的底座。第三步，选根。从这一轮最意外的一枝里选下一轮的根，选的人要说得出这一枝来自哪个孩子、经过了谁；说不出来路的「新主题」不能做根。第四步，揭墙。墙上的纸条按顺序装进活页夹，先拍一张全景照片；后墙只留新压实的底座和下一轮的根。仪式不要放在期末考试那一周。

**第四部分：发生失败的判定**

统一性死亡（标准崩塌、统一作业取消等）之后，开始计周。若在事先定下的 N 周内（第 7 章推荐 N 等于六），班里没有出现第一次四关都过的谱系事件，即判这一轮发生失败，回头查预备 E 够不够（读书角、旧作品、友谊、孩子带来的经验）。中途恢复统一的，也记作失败，原因写「中途恢复统一」。失败记录只给班级和老师自己看，写五样：死亡日；这几周记下几条「借」、其中几条有原主认出、几条有来源标出；失败原因（没有线可接、没有东西可长、中途恢复统一）；底座有没有破、怎么处理；下一轮先补什么。不用任何看不见、数不出的说法去解释失败。

**一张填好的示例（构想）**

初二（3）班第二学期四月的那张卡，大致是这样填的：谱系事件率，每两周六七次，三月还是十来次，往下走了一期；指认率，月底那次三十多个孩子找得到，有一个说「好像那个接力的有我」，追问之后说不出变在哪里，不算；互相查错率，定理册草稿上十个错里有六个是同学先指出来的；分歧化解匹配度，两周七八次分歧，化开五次上下，是全年最好的一段。阈值四信号，一个也没有。饱和三判据，事件率只降了一期，还不算亮；新条目的第一作者开始老是那几个名字。

几个孩子看完这张卡，自己得出的结论是：分歧化得还算快，可新条目老是那几个人的。他们没有要求换根，而是提议下一单元请几个很少出现在册子上的同学先起音。一个月后，三条信号还是一起亮了，那是另一回事（第 28 章）。这就是这张卡最好的用法：读数不给谁打分，只给全班一个往哪里使劲的方向。

## 附录二　谱系事件四关速查卡

**用法**：一张卡片大小，可以发给记谱员，也可以贴在讲台上。四关都过，才算一次谱系事件，才写进定理册。只过三关的，写在谱系墙的「待合」栏，不进册。记下的次数只给班级自看，不进考核。

| 关 | 问一句 | 过 | 不过的样子 |
|---|---|---|---|
| 一、在场 | 别人的知识有没有在我这里出现？ | 一诺的新解法里，确实用到了林朵的算法 | 两人各做各的，碰巧相似 |
| 二、有差 | 它在我这里有没有被改写？ | 一诺把乘法改成了减法 | 原样背下、原样抄、原样复述（变形收受律：原样接过去，等于没有收下） |
| 三、双向认得 | 原主能不能指出被改在哪里？借用者能不能指出原形在哪里？ | 林朵说「这里是我的损耗，可你把它从乘法改成了减法」；一诺说「这一步是从林朵那里来的」 | 只有老师说「这是林朵的方法」（单向署名）；或只有借用者自己说、原主认不出 |
| 四、回流 | 改出来的东西有没有写回全班？ | 写进《班级定理册》，标根、标来路、标经过谁 | 下课就散在各自草稿纸上 |

**三个常见误判**

1. 把「承认」当认出。说「你很棒」「你的想法很好」，对的是人，不是这一枝知识怎样变了形，不算第三关。
2. 把「复述确认」当认出。老师问「你是这个意思吗」，要的是原意不走样；认出要的是变形看得懂。两件事方向相反。
3. 把「想法改进」当谱系事件。一个想法可以被一轮轮改得越来越好，可是谁也说不清它从哪里来、原主也认不出它了。按本书的口径，这不算美。

**过不了关怎么办**

第一关不过，多半是根没立住：孩子们各做各的，彼此的知识没有在对方那里出现。办法是搭桥，让两组互讲，而不是直接宣布「你们其实想的是一样的」。第二关不过，多半是在抄、在背：一诺原样背下林朵的算法，就停在这里。不批评，请借用者回去在原形上改出一步，改了再来。第三关不过最常见，又分两种：原主认不出，常常是借用者改得太远，或者原主根本没看过对方的作品，办法是请两人当面对着草稿各指一次；借用者说不出来源，常常是他真的忘了，或者不愿意承认借过，办法是把「标出来源」变成班里的习惯动作，而不是道德要求，谁借了谁写在草稿角上，就像引号一样平常。第四关不过，往往是老师忙忘了，或者没人当记谱员。设一个轮值记谱员，下课前十分钟专门做这件事。

前言里那堂全等三角形的课，前三关当堂就过了；第四关，是许老师下课后把「杜可的线，邱田延长」和两个人的原话记下来才过的（见结语）。回流常常只差一个人顺手记一笔，最好当场记。

**记谱格式（每条都写这四项）**

做法（孩子自己的话或图）／根（来自课本哪一条）／来路（原主—借用者—经过谁）／两句原话（原主一句，借用者一句）。

## 附录三　两张工作单

### 工作单甲：一堂课的谱系发生（第 11、18 章）

**用法**：备课时填前两栏，下课前十分钟和记谱员一起填后两栏。一节 45 分钟的课按「立根 10 分钟、分枝 25 分钟、搭桥记谱 10 分钟」分段，是参考，不是硬规定。单上记下的事件次数只给班级自看，不进考核，也不作为评课依据。

| 环节 | 要填的 | 本课填写 |
|---|---|---|
| 分层·底座 | 这节课必须全班一样的是什么（定义、符号、必须用到的定理） | |
| 分层·根 | 本课复活哪一块化石？它当初回答的「对不上」是什么？用一句孩子听得懂的话写 | |
| 立根（起音） | 谁来起音？（老师或一个孩子）起完音退到哪里 | |
| 分枝·生成 | 预计会有几条路？留给哪几组？有没有平时很少开口的孩子可能有一条 | |
| 搭桥 | 让哪两组互讲？互讲后要求每组在对方的方法上改出一步 | |
| 记谱 | 本课出现的谱系事件：四关逐一打勾 | □在场 □有差 □双向认得 □回流 |
| 回流·结晶 | 写进定理册的条目名、根、来路 | |
| 三种假会自查 | 本课有没有只是看懂、背住、刷熟而没有结晶的地方 | |
| 下一课的根 | 本课最意外的一枝是什么？能不能做下一课或下一单元的根 | |

**填写示例（构想）：「赵苏旋转对称法」那一节课**

底座一栏，许老师写的是黑板竖线左边那三行定理：「这节课照用，谁用错了我要管。」根一栏写的是「截长补短」这块老化石当初回答的对不上：「分开的两段，怎么跟一整段比。」起音由许老师自己来，说完这一句就退到一边，给各组十二分钟。分枝一栏，她事先只猜到会有人用截长补短的标准做法，没有猜到赵磊组会用齿轮转动的想法把一个三角形转过去，也没有猜到苏小禾组会用画图找到对称。搭桥时让赵磊组和苏小禾组互讲，各自在对方方法上改出新的一步。记谱一栏四关都打了勾，回流一栏写的是「第八条，赵苏旋转对称法；根：截长补短；来路：赵磊组齿轮转动→苏小禾组画图对称→两组互改」。最后一栏「下一课的根」，她写了一个问号：赵磊说的齿轮转一圈和转半圈，能不能接到别的课上去。这个问号后来接上了物理课的传动比（第 19 章）。

这张单的空白比填满的地方更有用。分枝一栏猜错的那一格，就是下一次备课最该留余地的地方。

### 工作单乙：跨谱再现（第 15 章）

**用法**：班里出现「对不上」——两个答案、两种做法、两派吵起来——时用。可以在课上用，也可以在班会（生成会）上用。

| 步 | 做什么 | 填写 |
|---|---|---|
| 0 先挡住三种假接住 | 不由老师直接裁定；不说「两种都对」草草收场；不靠「这次听你的、下次听他的」轮流 | □已挡住 |
| 一 拆 | 把分歧拆开：两边各自算进了什么、没算进什么？（36 与 38：一边算了损耗，一边没算；值日吵架：扫地与擦黑板的辛苦不对等） | |
| 二 筛 | 哪些部分属于底座，不讨论（概念、诚信、安全）？哪些部分可以重做？ | |
| 三 重做 | 双方一起做出一个新东西（新解法、新规则、新记法，如「辛苦点数」） | |
| 四 认 | 每一方指出新东西里哪一部分是自己那一份、被改成了什么样 | 甲方说：　　乙方说： |
| 退回条款 | 有任何一方认不出自己那一份，退回第三步重做 | □通过 □退回 |

## 附录四　谱系式试卷模板与三本账模板

### 谱系式试卷模板（第 20 章）

**说明**：用于班内单元测验，不替代统一考试。中考、高考照常准备（第 20.4 节），根题部分本来就是为它们打底的。成绩里属于本附录新增的部分，只给班级自看，不进考核。

占比只是起步的参考，没有标准数：初一、初二桥题和枝题可以多一些，初三下学期桥题可以少到一个月一次（第 20.4 节）。

| 题型 | 起步参考 | 考什么 | 示例写法 |
|---|---|---|---|
| 根题 | 约六成 | 底座与根：定义、符号、关键定理、基本运算，必须全班一样 | 按课本标准题型出，评分标准与平时一致 |
| 枝题 | 约三成 | 同一个根上，你自己的一条路 | 「用至少一种课本上没有讲过的方法证明……，并写出你的方法从哪条定理长出来」 |
| 桥题 | 约一成 | 借用并回应一位同学的作品 | 「从《班级定理册》中选一条不是你自己的条目，在它上面改出一步，注明借了谁、改在哪里」 |

**桥题评分要点**：注明出处（借了谁、哪一条）；改动处清楚（改在哪里、为什么改）；改后仍成立。阅卷后，把桥题答卷交给被借用的同学看一遍，请他写一句「认得出／认不出，改在了哪里」。这一句不计分，但能补上第三关。

**不同学科怎样出根题、枝题、桥题**：语文的根题考字词、文体常识与基本理解；枝题请孩子对同一篇课文写出自己的一种读法，注明从原文哪一处长出；桥题请他选一位同学的读法续写或反驳，注明借了谁、改在哪里。英语的根题考词汇与语法底座；枝题请他用同一组句型讲一件自己的事；桥题请他改写同学的一段话。体育与艺术不必出卷，可以把「桥题」换成作品接力：一个孩子的动作、构图或旋律被另一个孩子改出一处，原主当场说出改在哪里。不同学段与学科的差别，第 29 章还有细说。

**错题汇集**：每次测验后，把全班的典型错误汇成一页「对不上集」，挑一两条作为下一课的根（第 20.3 节）。

**桥题示例（构想）**：「《班级词典》里有一条『辛苦点数』，原主是第四值日组。请把这套记法用到一件别的事上（比如小组分工、运动会后勤），说出你改了哪一处，为什么要改，并注明借自哪一条。」阅卷后，这道题的答卷交给第四值日组的同学看，他们在每份答卷下写一句：「认得出，你把扫地换成了搬器材，点数也跟着改了」，或者「认不出，这和我们原来那套已经没关系了」。后一种情况不扣分，但它说明那份答卷其实是另起了一套，而不是在桥上走。

### 三本账模板（第 21 章）

**说明**：三本账代替单一积分榜，每月合一次。账只给班级自看，不进考核。被记的人有权提议改账法，每学期至少开一次「改账会」。

| 账 | 记什么 | 怎样记 | 对应 |
|---|---|---|---|
| 底座账 | 底座有没有守住：概念、诚信、安全、不欺凌 | 只记全班层面的事件数，不在墙上点名；涉及个人的事私下处理 | 真（在轨） |
| 生成账 | 本月班里长出了什么：新条目、新枝、新词 | 按条目记，每条带根与来路 | 善（效率：长出的枝被别人用上、替别人省下力气） |
| 咬合账 | 谁的一枝被谁接上了，谁帮谁搭了桥 | 记连线，不记分数；一根线两端的人都确认才记 | 美（吸引：每一根两端认过的线，都是一次闭环合上） |

三个指标有先后：真先于善、善先于美（第 21.3 节）。线再多，若建在出轨的东西上，错得越整齐。

**个人谱系档案（给家长看的那一张）**

| 栏目 | 写什么 |
|---|---|
| 这一年我在树上的位置 | 我的枝主要长在哪几个根上 |
| 我的一枝被谁接过 | 条目名／接的人／改成了什么样／我认出时说的一句话 |
| 我从谁那里接过什么 | 条目名／原主／我改了哪里 |
| 我还没有被接上的那一份 | 我带来的、还没进册的知识（老师与孩子一起写，不写缺点） |

不写名次，不写和别的孩子比多比少。线少的孩子，档案的最后一栏往往最值得写。

**三本账月度示例（构想）**：底座账，本月全班层面事件两起（一次作业互抄、一次课间推搡），均已私下处理，墙上只写「两起，已处理」。生成账，本月新条目六条，新词三条，每条带根与来路。咬合账，本月新画上的线二十三根，其中九根连着上个月还一根线都没有的四个孩子。改账会上，有孩子提出「帮人讲题讲了三次对方都没改过来，算不算咬合」，全班讨论后定下：不算咬合，但记进生成账的「待合」一栏。这一条改账，本身也写进了班级词典，注明是谁提的。

## 附录五　同一性知识谱系发生智能体：功能清单与数据底座

**说明**：本附录写的是第 24 章那个智能体应当做什么、不做什么，不对应任何一个现成的产品。它算出的所有读数只给班级自看，不进考核。

### 功能清单

| 工作 | 对应 | 它做什么 | 它不做什么 |
|---|---|---|---|
| 守根 | 真 | 提醒本课的底座与根；孩子的枝偏离底座（概念错、数据错）时提示 | 不替孩子给出标准解法 |
| 分枝 | 自由 | 对一个根，提示还可能有哪些不同的路，供老师起音参考 | 不替孩子走路；提示给老师，不直接塞给孩子 |
| 搭桥 | 善 | 看出谁的枝和谁的枝可能接得上，建议互讲、换座、组队；每周给座位建议（第 17 章） | 不强行分组；建议由老师和孩子决定用不用 |

### 它算的几个量

1. **认出图的连通度**：每根线两端都确认才算；全班有多「同」，看这张图连得有多匀、多紧：最少剪几根线能把全班分成两半，叫边连通度，剪一两根就分开，「同」就弱；更细的一把叫代数连通度，网里一出现细颈口它就掉，所以用作小圈子的预警（这里不写公式）。
2. **小圈子预警**：连通度下滑、某一团越来越密而与外面不连，提示老师在小圈子成型之前搭桥（第 30 章第 8 条预言检验它）。
3. **饱和读数**：新条目与旧条目的相似度、新枝原主的集中程度、谱系事件率的走势。
4. **变形收受比**：原样接过与变形接过的比例。原样接过的越多，越说明班里在抄、在背，不在收。
5. **四个读数**（附录一）由以上记录自动汇出。

### 数据底座（全部零容忍，归入班级底座）

| 条款 | 内容 |
|---|---|
| 不替孩子创造 | 枝必须是孩子自己长出来的；智能体只预备 E（第 24.1 节），孩子—AI 复合主体是「我」的延伸，不是替身 |
| 不公开排名 | 不生成任何个人排行；不向班外输出个人读数 |
| 最少采集 | 只记与谱系有关的条目、连线、确认记录；不采集与学习无关的个人信息，不做心理或医学判断 |
| 孩子有权看、有权改 | 孩子能看到自己的每一根线，能撤回自己的确认，能对记错的来路提出更正 |

### 一周里它出现在哪几个时刻（构想）

周一早上，它给许老师一张座位建议：哪几张桥座这周值得换人，理由写的是「这两组上周的枝接近，还没互讲过」。备课时，它列出本单元的根可能对应的几个「对不上」，供老师挑一个起音。课上它不出声。下课前十分钟，记谱员把本课的新条目录进去，它给原主和借用者各发一条确认：「你认得出这一处改动吗？」「你记得这一步来自哪里吗？」两人都点了确认，墙上才多一根线。周五，它把一周的连线汇成一张小图，交给班主任和轮值的孩子看；如果某一团连续三周只在内部连线，它会在小图边上标一个提醒。月末，它把四个读数填进附录一那张诊断卡，填完就停。至于怎么读、往哪里使劲，是全班的事。

### 老师常问的五个问题

**一、没有这个智能体，能不能做？** 能做，但做不全。二三十人的小班，班主任和记谱员靠一本定理册、一面谱系墙，大致记得过来。四十八人的班，一年下来几百根线，靠人力只能记下最显眼的那些，安静的孩子那几根线最容易漏。第 30 章第 6 条预言说的就是这件事：如果全靠人力的 48 人班，谱系可读度和用智能体的一样高，第 25 章就错了。

**二、孩子会不会为了多画线而互相「认」？** 会有，尤其是在读数被拿去比较的班里。所以本附录反复写「只给班级自看，不进考核」。线多不加分，线少不扣分，造假的动力就小了很多。第三关要两个人都说得出改在哪里、来自哪里，空口说「我认得」是过不了的。

**三、智能体会不会替孩子写？** 按本附录的数据底座，它不替孩子创造。分枝的提示给老师看，不直接塞给孩子；孩子用别的 AI 写了作业，那是原样接过，过不了第二关「有差」。第 25 章说四十八份 AI 答案几乎一样，正是这个意思：化石免费了，谱系还得孩子自己长。

**四、家长要看全班的图怎么办？** 不给。家长只看自家孩子的个人谱系档案。全班的认出图只在教室里贴，学年末随合谱仪式取下。

**五、学校要把读数拿去评优怎么办？** 这是本书最担心的事。读数一进考核，老师就会去追读数，孩子就会去凑连线，这套东西会变成另一张积分榜。遇到这种要求，宁可停用读数，只保留定理册和谱系墙。没有读数，闭环照样能合上；读数被拿去排名，闭环就会被假线淹没。

| 扩展性学习（Engeström） | 矛盾推出集体新工具 | 每一方要认出自己那一份，没有「认」不算化开 |
| 胡塞尔「沉积—重新激活」；怀特海「惰性观念」；库恩「教科书抹去历史」；弗赖登塔尔「引导再创造」 | 原初意义再现；诊断知识僵死；诊断来路被抹；重走老路到同一终点 | 复活要到不同终点，并写回底座 |
| 巴赫金、沃茨「挪用」；皮亚杰同化与顺应 | 接的人有没有化为己有 | 变形收受律还要求原主认出变形 |
| 莫斯「礼物」 | 印记附着在物上 | 班级知识的印记不在形上，在双向认出里 |
| 霍耐特「相互承认」 | 人与人之间的承认 | 认出对的是一枝知识怎样变了形，不是对人 |

### 附表　三律到读数

| 意义律 | 它要什么 | 在班里留下的痕迹 | 读数 | 只讲这一律的课堂缺什么 |
|---|---|---|---|---|
| 创造律（王德生老师口述时也称特征律） | 众人聚焦同一个问题，把力气拧进同一个解 | 互相改写 | 类我率：共同问题上互相改写的组数 | 只讲创造律：人人都朝一个解使劲，容易又挤回一个标准答案 |
| 自由律 | 各走各的路 | 同一根上分出不同的枝 | 枝分化数 | 只讲自由律：各学各的，像隔壁班的「自由日」，没有接力 |
| 幸福律 | 一个人的自由在共同创造里恰恰被用上 | 原主认出、借用者标出 | 双向认得率 | 前两律都在、缺幸福律：有合作、有分枝，却没有人认得出自己那一枝长在了哪里 |

三律在「积累—死亡—混沌—涌现」链上的分工，本书这样处理：创造律管积累，自由律管混沌，幸福律管涌现收场。

这张表里的三个读数和附录一的四个读数一样，只给班级自看，不进考核。
