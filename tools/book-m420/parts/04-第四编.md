# 第四编　改变句子的焦点、责任和语气

同一件事，可以说成不同的样子：谁来负责，要不要把那个人藏起来；是直接要，还是客气地借；是真的可能，还是一个不存在的世界。这一编的三章，讲句子怎样改变焦点、责任和语气。打碎的窗户，借不到的笔，没复习就考完的试，都会在这里出现。

## 第 11 章　谁来负责：主动与被动


> **这一章的问题**：同一件事，为什么有时候说「我打碎了窗户」，有时候只说「窗户碎了」？英语里那个 was broken，到底是在讲语法，还是在讲谁来负责？我做错了事不想说出自己，英语能帮我「藏」起来吗？

### ◆11.1　窗户被打碎了

「哗啦——」

十二月的一个星期六下午，老小区楼下的空地上传来一声玻璃碎响，清脆得像有人把一摞盘子摔在了水泥地上。小雨站在原地，脚边那只足球还在慢慢滚，一直滚到一楼张阿姨家的窗台底下才停住。窗户上破了一个碗口大的洞，裂纹像蜘蛛网一样往四周爬，几片碎玻璃落在窗台的花盆里。和她一起踢球的两个小男孩愣了一秒，撒腿就跑，跑得比球还快，转眼就没影了。

小雨没跑，可她也没去敲张阿姨的门。她听见屋里好像有动静，心一下提到了嗓子眼，抱起球就往楼道里钻。从一楼到三楼，平时蹦两步就上去了，那天她觉得楼梯特别长，每一级都在响。

她一边爬一边在心里排练：要不要说？怎么说？说了会不会挨骂？排练到三楼门口，一句也没排好。

开门的时候她手心全是汗。林姐正在厨房择菜，听见动静探出头来问：「这么快就回来了？不是说踢到五点吗？」小雨把球塞进鞋柜旁边，又拿脚往里踢了踢，憋了半天，只挤出一句：「楼下……窗户碎了。」

林姐手里的芹菜停在半空。她当了十几年妈，这句话的味道她一听就懂。「窗户碎了」，好像窗户是自己想不开碎的，好像这件事里没有人，只有一块玻璃和一阵风。她没急着发火，把芹菜放下，擦了擦手走出来，看看女儿通红的脸，又看看鞋柜边露出半截的足球，问：「窗户自己碎的？」

小雨的脸一下红到耳根。她知道妈妈看穿了，也知道自己刚才说了一句很「滑」的话——每个字都是真的，合起来却把最要紧的那个人藏了起来。她嘟囔一句「我去写作业」，钻进了自己房间，把门轻轻带上。

林姐站在客厅里叹了口气，没跟进去。她想，先让孩子自己待一会儿吧。她自己小时候也打碎过邻居家的咸菜坛子，当时撒了个谎说是猫碰的，结果被她妈——也就是小雨的外婆——拎着耳朵去赔了不是，那种又羞又怕的滋味，她到现在还记得。逼得太紧，孩子只会把那句「窗户碎了」说得更圆；等她自己想明白，那句真话才会从她嘴里出来。

那天晚上，小雨翻开 Mr. Brown 布置的周末日记，题目恰好是「这个周末发生的一件事」。真是巧得让人头疼。她先写了一句 I broke a window（我打碎了一扇窗户），写完盯着那个 I 看了半天，越看越扎眼，拿橡皮擦掉了。她又写：

The window broke.（窗户碎了。）

写完她觉得这句太干，像天气预报，而且有点假——窗户哪会自己碎呢？她想起课本上刚学过的一个句型，改成了：

The window was broken.（窗户被打碎了。）

这一句写下去，她心里竟然松了一口气。句子里没有 I，没有她，只有那扇窗户站在最前面。可是「被」字又提醒着读的人：这里有一个人，只是没露面。她盯着这行字看了好一会儿，忽然有点明白：原来英语里也有一种句子，可以把「谁干的」先放到看不见的地方去。

我想在这里停一下，跟你说说这个「松一口气」。小雨不是在学语法，她是在办一件事——办一件「不想说出自己」的事。正是这件事，逼着她从课本里把这个句型翻了出来。课本上它叫「被动语态」，名字听着很吓人，可在小雨这里，它只是一个很朴素的用处：让窗户站到前面，让自己退到后面。课本上的例句她背过好几个，那时候它们像抽屉里的旧钥匙；今天这把钥匙第一次被她拿出来，插进了一把真锁。

你也许注意到了，小雨前后写了三句，三句其实各有各的意思。The window broke 是「窗户碎了」，听起来像是它自己碎的，也许是冻裂的，也许是风刮的，句子里根本没给人留位置。The window was broken 是「窗户被打碎了」，句子里留着一个空座位，大家都知道有人坐过，只是没写名字。I broke the window 是「我打碎了窗户」，人就坐在座位上，谁都看得见。三句话，像同一个舞台换了三种打光。

这种打光的事，其实我们天天都在做，只是没注意。过年拍全家福，谁站中间？一般是外婆，因为这张照片是为她拍的；要是给小雨拍升学照，站中间的就是小雨，爸妈退到两边。照片里的人都是那几个，换的只是谁站中间。说话也是这样：同一件事里的人和东西都在那儿，你把谁放到最前面，就等于告诉听的人「这一回，我要你先看他」。

你可以把一句话想象成舞台。舞台上有一盏追光灯，灯打在谁身上，谁就是这句话最先让人看见的东西。说 I broke the window，灯打在「我」身上，我是做事的人，我站在台中央。说 The window was broken，灯挪到了窗户身上，窗户是受了影响的东西，它站在台中央，做事的人退到了幕后，甚至干脆没上台。

灯亮了：**主动句和被动句讲的是同一件事，区别在于追光灯打在谁身上。**主动句，灯照着做事的人；被动句，灯照着被这件事影响到的东西。被动句不是一种「更高级」的句子，也不是一种「更难」的句子，它只是把焦点挪了个位置。

> I broke the window.（我打碎了窗户。——灯照着「我」）
> The window was broken.（窗户被打碎了。——灯照着「窗户」，做事的人在幕后）
> The window broke.（窗户碎了。——只说窗户自己怎么了，不提人）

小雨这一晚的日记就停在了这一句上。她没写是谁打碎的，也没写后来怎么办。可是那块破玻璃一直在她脑子里晃，楼下张阿姨家的灯亮到很晚，她躺在床上翻来覆去，觉得本子上那句英文好像也睁着眼睛在看她。

### ◆11.2　不知道是谁、不想说是谁

第二天早上吃饭的时候，老陈刷着手机，忽然放下筷子，叹了口气。他在物流公司做调度，天天跟快递打交道，管着几十辆车几千个包裹，没想到自己的快递在小区门口的快递架上不见了。「给你外婆买的护膝，」他说，「显示签收了，人没了。」林姐问是谁拿的，老陈摇摇头：「门口那个监控上个月就坏了，谁知道。」

小雨正好满脑子都是英语日记，脱口而出：「爸，这个用英语怎么说？」老陈想了想，用他那点在公司系统里看来的物流英语，慢吞吞地说：

My package was stolen.（我的快递被偷了。）

说完他自己愣了一下，好像没想到这句还在脑子里。小雨眼睛一亮，这不就是昨天那个句型吗？她马上追问：「那为什么不说 Someone stole my package（有人偷了我的快递）？」老陈喝了一口粥，冒出一句：「因为我不知道那个 someone 是谁，说了也白说。」

这句冷幽默把林姐逗笑了，也把一个道理说透了。偷快递的人是谁，老陈不知道，就算硬塞一个 someone 进去，这个 someone 也是一团雾，什么信息都没有。真正要紧的是快递——它没了，这才是要告诉别人的事。所以灯自然就打到了快递身上，这一点也不「滑」，反倒很老实：我只说我知道的。

林姐顺着这个话头往下想。她说：「那咱们小区门口那块牌子上写的『垃圾每天早上七点清运』，要是写成英语，是不是也这么说？」小雨拿手机查了查，写出来是：

The rubbish is collected at seven every morning.（垃圾每天早上七点被收走。）

这一句里也没有做事的人，可这回不是因为不知道。大家都知道是环卫工人收的，说出来反倒啰嗦，就像你跟邻居说「菜市场八点开门」，没人会补一句「是菜市场管理员开的门」。做事的人太明显了，或者根本不重要，说话的人就把他省掉，把灯留给真正要说的东西——垃圾什么时候被收走。

小雨越查越来劲，又翻出几个例子念给爸妈听：English is spoken in many countries（很多国家都说英语）。这句让林姐皱起了眉：「中文可不这么说，谁会说『英语在很多国家被说』？听着别扭死了。」这话说到点子上了。中文的「被」字，平时多半用在倒霉的事情上——被偷了、被骂了、被罚了、被雨淋了；好事、平常事，中文很少用「被」，直接说「很多国家说英语」就行。英语的被动却没有这个脾气，好事坏事、平常事，只要想把灯打在东西上，它都能用。

所以很多中国学生学英语时有一个小误会：以为被动句就是「倒霉句」，只在出事的时候用。其实不然。This bridge was built in 1998（这座桥建于 1998 年），没有谁倒霉；Breakfast is served from seven to nine（早餐七点到九点供应），这是酒店电梯里一句很客气的提示。英语的被动，更像一个中性的转台，转一下，台中央就换了人；中文的「被」，常常带着一点皱眉的表情。

说到这里，饭桌上安静了一下。林姐看着小雨，慢慢地说：「那昨天你那句『窗户碎了』，属于哪一种？是不知道是谁，还是谁都知道不用说？」小雨低头扒饭，扒了两口，小声说：「是……不想说。」

你看，一顿早饭，一家三口把被动句的三种用处都碰了一遍。第一种，不知道是谁做的，比如快递被偷了；第二种，做事的人太明显或者不重要，说了也是多余，比如垃圾被收走、桥建于哪一年；第三种，知道是谁，但不想说，或者不好说，比如小雨的窗户。前两种是老老实实的省略，第三种就有点「藏」的意思了。

我得替被动句说句公道话：它本身没有好坏。新闻里、说明书里、告示牌上，被动句用得到处都是，因为那些场合关心的是事情本身，而不是哪个人。可是同一个句型，放进「我闯了祸」的场合里，就会变成一块挡箭牌。语法这把工具，是护航用的，不是躲闪用的。这话不是我在讲大道理，你往下看就知道，小雨自己慢慢也觉出来了。

这时候老陈的手机「叮」地响了一声。快递软件推送了一条消息，他把屏幕转过来给小雨看，上面有一行英文：Your parcel has been delivered.（您的包裹已送达。）老陈苦笑：「看见没？人家说送到了，可没说送到谁手里。」小雨凑过去一看，乐了，这一句里又是被动，而且前头那个 has 她上个月刚碰到过——has 管的是「到现在为止」，been delivered 管的是「被送了」。

快递公司为什么这么写？因为送货的是哪个快递员，收件人根本不关心；收件人只关心一件事：我的包裹现在在不在了。所以灯照着包裹，has 把这件事拉到眼前。小雨把这一句抄进了本子里，在旁边写：「被动＋已经＝事情办完了，现在就是这个样子。」这个心得记得很粗，却一点不错。

老陈收回手机，又冒了一句：「我们公司系统里天天这么写，The goods have been loaded（货已装车），The order has been cancelled（订单已取消）。我以前只当是机器话，原来是这个道理。」说完他有点不好意思，好像不习惯在饭桌上讲这么多话。林姐朝小雨挤挤眼睛，意思是：你爸今天话多，是被你那句英语勾出来的。

灯亮了：**被动句常在三种时候出场——不知道是谁做的；做事的人不重要或者谁都知道；不想说出是谁。**前两种让话更干净，第三种让话更「滑」。用哪一种，取决于你要办的事是什么。

> My package was stolen.（我的快递被偷了。——不知道是谁）
> The rubbish is collected every morning.（垃圾每天早上被收走。——谁都知道，不必说）
> The window was broken.（窗户被打碎了。——不想说是谁）

中午，林姐给外婆打电话，说护膝的事要晚几天，快递被人拿走了，重新买了一副。外婆在电话那头连声说不碍事不碍事，又说：「我们村里也有，晒在外头的腊肉，一夜就被人拎走了两条，狗都不叫一声。」林姐笑着把手机开了免提，让小雨也听。小雨在一旁小声嘀咕：「外婆这句，翻成英语就是 Two pieces of bacon were taken。」林姐瞪她一眼：「外婆在跟你说话，你在那儿做翻译题。」

可小雨这一嘀咕，倒让我想到一件值得说的事。外婆说「腊肉被人拎走了」，也没说是谁，因为她不知道；她把腊肉放在句子最前头，因为那两条腊肉是她熏了一冬天的，心疼的是腊肉。全世界的人说话，在这一点上都差不多：心里最惦记的那样东西，会自己跑到句子最前面。英语只是把这个习惯，做成了一个固定的样子。

吃完饭，老陈下楼去物业问快递的事。走到一楼，他看见张阿姨正拿胶带往破窗户上贴纸板，一边贴一边回头朝楼上望了一眼。那一眼，小雨躲在三楼的窗帘后面，全看见了。

### ◆11.3　卡住点：be＋done 两件套

那天下午，小雨决定先把日记写完，别的事待会再说——她自己也知道这是在拖。她想多写几句，把快递的事也加进去，结果一写就卡住了。本子上出现了这样两行：

The window broken.（错）

The package was steal.（错）

她自己读了一遍，总觉得哪里不对劲，可又说不清。拿去给林姐看，林姐的英语早就还给了老师，盯了半天也只能说：「好像……少了点什么，又好像多了点什么。」母女俩对着两行字发愣，橘子跳上桌子，在本子上踩了两个梅花印，好像在替她们打分。

小雨这两个错，其实是一个错的两张脸。被动句在英语里不是一个词，而是两件东西搭在一起：一个是 be（is、are、was、were 这一家），一个是动词的「做完了的样子」，也就是第 9 章说过的「第三个样子」（done 那种形式），课本上叫过去分词，比如 broken、stolen、collected、cleaned。第一句只放了 broken，丢了 be；第二句放了 was，可后面的动词没换成「做完了的样子」。两件套，各丢一件。

为什么偏偏要两件？我们来看看它们各自在干什么：broken、stolen 这一类词，管的是「这东西被做成了什么样」——窗户成了碎的，快递成了被拿走的。可光有这个样子，句子还站不起来，因为它没交代这是什么时候的事、说的是几样东西。这时候 be 就上场了：was 说的是「过去，一样东西」，were 说的是「过去，好几样东西」，is 说的是「现在，一样东西」。它像一根扁担，一头挑着时间，一头挑着数量。

你还记得第 5 章吗？英语句子不能缺那根「中轴」，She very nice 不行，得是 She is very nice。被动句里的 be，就是同一根中轴又一次出场。中文说「窗户被打碎了」，一个「被」字加一个「碎了」，事情就说完了；英语却非得先立起一根 was，再把 broken 挂上去。这就是小雨卡住的地方：中文的「被」是贴在动词前面的一个小字，英语的 be 却是整句话的承重墙。

我喜欢拿包饺子来比。一盘饺子端上桌，英语说 The dumplings were made this morning（饺子是今天早上包的）。were 是那个盘子，made 是饺子包好了的样子。没有盘子，饺子撒一桌，没法端；只有盘子，里面装的却是没包的面团和馅儿，也不叫一盘饺子。两样都得有，这道菜才算上了桌。

林姐听小雨讲完这个比方，自己先笑了：「那 The window broken 就是饺子没盘子，The package was steal 就是端了个盘子，里面是一团没包的面。」小雨拍着桌子说对对对。两人把句子改了过来：

> The window was broken.（窗户被打碎了。）
> The package was stolen.（快递被偷了。）

改完，小雨又往前走了一步。她发现扁担那一头挑的「时间」可以换。窗户明天要请师傅来修，那就是 The window will be fixed tomorrow（窗户明天会被修好）；张阿姨家的窗户现在就碎着，那就说 The window is broken（窗户是破的）。

was broken 说的是「那一下」被打碎的事，is broken 说的是此刻它破着的样子。一根扁担，前后一挪，说的就是不同时候的事。这跟第 10 章的 will 也接上了：will 照样可以挑着被动往前走。

扁担还能翻个面。小雨想问妈妈「窗户修好了吗」，这时候不用另找什么 do，直接把 be 提到最前面就行：Is the window fixed?（窗户修好了吗？）要说「还没修」，就在 is 后面加个 not：The window isn't fixed yet（窗户还没修好）。你看，be 这根扁担一身兼了好几样活：管时间，管数量，提到前面就是在问，后面跟个 not 就是在否定。它真是被动句的主心骨。

林姐这时候插了一句很实在的话：「那要是我非要说出是谁干的呢？」这一问问得好。英语给了一个小门，就是句尾加 by。比如 The window was broken by a football（窗户被一只足球打碎了），by 后面把那个「做事的」请回来，但是放在最后面，像散场时才报出的演员名单。大多数时候，英语的被动句都不带 by；真要把人说出来，往往直接用主动句更干脆。这正好说明，被动句本来就是为了「不把人放在前面」而存在的。

还有一个卡住点，几乎每个中国学生都踩过，我顺手提一下。有的动词根本没有「被」的说法，比如 happen（发生）。事情就是自己发生的，没有谁去「发生」它，所以不能说 The accident was happened（错），要说 The accident happened（事故发生了）。这跟 The window broke 有点像：有些事，英语只让它自己出场，不给它安排「被谁」。

日记写到一半，小雨想起这学期开学时闹过的一个笑话。她在开学交的自我介绍作业里写了一句 I born in 2012（错），周老师在本子上画了个红圈，旁边写了一个 was。当时她只当是记错了一个词，抄了三遍就过去了，现在才明白那个 was 是从哪里来的。「出生」这件事，英语看作是「被生下来」：孩子是被妈妈生的，不是自己生的自己。所以要说 I was born in 2012（我生于 2012 年），一根 was，一个 born，又是那副两件套。

她把这事讲给林姐听，林姐乐了：「那可不，你是我生的，当然是被生的。生你那天下大雨，你爸在医院走廊里来回走了一夜。」小雨嫌她又要讲老故事，可还是听完了。听完她在本子上写：I was born on a rainy night（我出生在一个下雨的夜里）。这是她第一次没背课本、自己造出来的一个被动句，写完还挺得意，拿红笔在旁边画了一颗小星星。

你看，一个曾经被画了红圈的错句，隔了三个月才真正「长」出来。那时候 was 是老师给的，是一个要记住的零件；现在 was 是她自己需要的，是一根撑起「被生下来」这件事的扁担。同样一个词，从别人塞进来，到自己找出来，这中间隔着的，就是一件真想说的事。

林姐那天也撞上了一个。她收拾厨房，把一口新买的炒锅翻过来，锅底印着两个词：Made in China。她举着锅跑来问：「这不也是被动吗？怎么没有 was？」小雨一看，还真是。这是把 This pot was made in China（这口锅是在中国制造的）压短了：贴在商品上的小标签，地方就那么一点，大家又都知道说的是这口锅，于是 This pot was 统统省掉，只留下最要紧的「在哪儿造的」。

这跟我们家里写便条差不多。你在冰箱上贴一张「饭已热好」，不会写「妈妈已经把饭热好了，饭在锅里」，因为看便条的人一眼就懂。标签、标题、便条这些地方，英语常常把 be 省掉；可一旦写成完整的一句话，比如日记、邮件、作文，be 这根扁担就得老老实实地挑回来。林姐听完点点头：「明白了，便条可以偷懒，作文不行。」这话总结得比我还好。

这里我再提醒一句，免得你走岔。stolen、broken 这种「做完了的样子」，有的动词有自己的长相，不能一律往后加 -ed，比如 steal 变 stolen、break 变 broken、write 变 written、eat 变 eaten。这些不用一口气背完，你会在一句一句真话里慢慢碰到它们，碰到一个，记一个，像认识楼里的邻居一样，见多了自然叫得出名字。

灯亮了：**被动句是「be＋做完了的样子」两件套。be 管时间、数量，还管问和否定；后面那个词管「东西被做成了什么样」。缺了哪一件，句子都站不住。**

> The window was broken.（窗户被打碎了。）
> Is the window fixed?（窗户修好了吗？）
> The window will be fixed tomorrow.（窗户明天会被修好。）

小雨把这几条写在了日记本的边上。写完，她看着那句 The window was broken，忽然不想再把它当挡箭牌了。规则她弄明白了，句子也写对了，可是这件事还没办完——窗户还破着，楼下的纸板在风里哗啦哗啦地响，一声一声，像在敲她的门。

### ◆11.4　句子家族：同一件事的三种写法

傍晚，林姐没有再追问，只是从冰箱里拿出一袋刚买的橘子，放在了门口的鞋柜上。小雨从房间出来，看见那袋橘子，在门口站了很久，终于说：「妈，你陪我下去一趟吧。」林姐点点头，什么也没说，换了鞋。

张阿姨开门的时候，小雨深吸一口气，说：「阿姨，对不起，窗户是我踢球打碎的。」话一出口，她发现自己声音在抖，可心里那块压了一天一夜的石头，一下子就挪开了。张阿姨愣了愣，接过橘子，反倒笑了：「我还以为是隔壁那两个小子呢，跑得那么快。你这孩子，敢认，好。」林姐在旁边赶紧说修窗户的钱我们出，两家大人站在门口又聊了半天，从玻璃聊到了菜价。

回到家，小雨把那篇英语日记重新打开。她决定不只写一句，而是把这件事换几种人的口气，各写一遍。这是 Mr. Brown 上课时带大家玩过的一个小游戏，叫「句子家族」：同一件事，换一个说话的人，换一件要办的事，句子就长成不同的样子。

第一种，她假装自己是小区公告栏上的通知，写成一则小新闻：

> A window was broken in Building 3 on Saturday afternoon. It will be repaired on Monday.（周六下午，3 号楼一扇窗户被打碎。该窗户将于周一修好。）

新闻不关心是哪个孩子踢的球，它只关心哪儿出了事、什么时候修好。所以它用被动句，用得理直气壮，一点也不「滑」。灯照着窗户，因为读通知的人要知道的就是窗户——住在这栋楼里的人关心的是「我家窗户会不会也遭殃」「周一会不会有师傅来敲门」。

第二种，她想象如果张阿姨气呼呼地去找家长告状，会怎么说：

> A girl from the third floor broke my window!（三楼那个女孩打碎了我的窗户！）

告状的人最想让人看见的是「谁干的」，所以她一定用主动句，把做事的人推到台前，追光灯死死打在那个女孩身上。小雨写完这句，自己先吐了吐舌头。同一件事，换了要办的事，句子立刻换了一身衣服，连口气都跟着变了。

第三种，是小雨自己的道歉。她写了好几遍，划掉，重写，最后定下来是这样：

> I'm sorry. I broke your window. It was my fault, and we will pay for it.（对不起。是我打碎了您的窗户。这是我的错，我们会赔的。）

写到 I broke your window 的时候，她特意停了一下笔。这一句，就是昨天那句 The window was broken 的另一面——同样的窗户，同样的碎，可这一回追光灯照回到了她自己身上。道歉就是这样一件事：把自己从幕后请出来，站到灯底下。用被动句道歉，就像嘴上说对不起、人却躲在门后面，对方一听就听得出来。

写完这三段，小雨起了个坏心眼，想试试用被动句道歉会是什么样子。她写下：Your window was broken by me（您的窗户被我打碎了）。念出来，母女俩都笑了。这句话语法上没毛病，be 有了，broken 有了，连 by 都把人请回来了，可听着就是怪，像一个人鞠躬的时候屁股朝着对方。林姐说：「这哪是道歉，这是念判决书。」

怪在哪儿？怪就怪在，它费了好大劲把「我」挪到了句尾，又费劲用 by 把「我」请回来。既然最后还是要说出「我」，何必绕这一大圈？

这一绕，听的人就会觉得你不太情愿。你看，一个句子对不对，不只看零件装得齐不齐，还要看它跟要办的事合不合拍。零件全对、场合不对，句子照样办不成事，甚至会把事办砸。

这也是我想让你记住的一点：语法书会告诉你「主动句可以改成被动句」，这话没错，就像一件衣服可以反过来穿，可你不会穿着反面的衣服去见客人。能改，不等于该改。哪一种说法，是由那一刻的人和事来挑的，不是由练习册上的箭头来挑的。

三段写完，小雨拿去给老陈看。老陈拿着本子看了半天，说了一句让她意外的话：「我们公司写事故报告，最爱用你这第一种。」他说，每次货车晚点、货物摔坏，报上去的单子上常常写 The goods were damaged（货物受损）、The delivery was delayed（配送延误），看上去很专业，可经理每次都要打电话追问：「到底是哪个环节出的问题？谁来负责？」

「被动句写报告是好写，」老陈把本子还给她说，「可报告是要拿来解决问题的。光写『货坏了』，下回还会坏。」小雨很少听爸爸一口气说这么长的话，愣了一下。老陈这番话，其实讲的就是这一章的题目：谁来负责。被动句把人藏进幕后，在通知里是体贴，在报告里有时就成了推脱。一句话里有没有人，往往就是这件事有没有人管。

三种写法摆在一起，小雨看明白了一件事。主动和被动，没有哪个高哪个低，它们是同一个家族里的兄弟，各自在不同的场合干不同的活。新闻要的是事情本身，被动句最合适；告状要的是揪出那个人，主动句最有力；道歉要的是自己站出来负责，那就非得是 I 不可。选哪一种，看的是你那一刻要办成什么事。

星期一，Mr. Brown 在课上批完日记，把小雨叫到讲台边。他指着那三段，笑眯眯地说：Your news report is very good. And your apology is even better.（你的新闻写得很好，道歉写得更好。）小雨问他为什么道歉比新闻好，他想了想，说道歉那一段最难写，因为句子的开头是 I。然后他轻轻补了一句：Everyone breaks a window at least once.（谁都至少打碎过一次窗户。）小雨不知道他是不是在说他自己，但她一下子就不那么难为情了。

那天课后，小雨还碰到一件小事。她把日记本放进书包时，后排的一个男生凑过来问：「你那道歉写得那么好，窗户真是你打的？」换作以前，小雨大概会说「谁知道是谁打的」，然后岔开话题。这一回她耸了耸肩，干脆地说：「是我。周六踢球踢的。」那男生「哦」了一声就走了，什么事也没发生。

小雨后来跟林姐说，她那一刻才发现，承认一件事原来没有想象中那么难。难的是前面那一天一夜，心里一直在找一句能把自己藏起来的话。我觉得这是本章最好的一课，它不在课本上：句子帮我们办事，办得好不好，有时候看的不是句子写得对不对，而是我们敢不敢把自己放进句子里去。

其实周日那天晚上，林姐也看了这三段。她看不太懂 repaired，但看懂了 I broke 和 my fault。她没说什么，在日记本最后画了一个笑脸，写了一句刚跟小雨学会的英语：I'm proud of you（我为你骄傲）。小雨看着那行歪歪扭扭的字，嘴上嘟囔一句「妈你写得好丑」，眼睛却有点热。老陈从门口路过，探头看了一眼，冒出一句：「这本子要是交上去，Mr. Brown 得先表扬你妈的英语。」母女俩同时朝他扔了一个抱枕。

星期一傍晚，修窗户的师傅来了。小雨放学回家，正好看见张阿姨家的新玻璃亮堂堂地装上了，纸板被卷起来扔进了垃圾桶。张阿姨隔着窗户朝她挥手。小雨上楼以后，在日记最后补了一句：The window has been fixed. Everything is fine now.（窗户已经修好了，现在一切都好了。）她发现这一回用被动，心里一点也不虚了——事情已经认了、赔了、修了，灯照着窗户，就只是在说窗户。

灯亮了：**同一件事可以长成一家子句子。要说清事情本身，用被动；要指出是谁，用主动；要为自己负责，就让「我」站到句子最前面。**语法在这里不是规矩，是一面镜子——你想不想负责，句子都照得出来。

### ◆给老师的一页


本章用 S／D／E 看主动与被动。S（句子的样子）：被动结构 be＋过去分词，be 承担时、数、疑问与否定，分词承担「受事所处的结果状态」；课堂上常把它当作「主动句的变换」来教，学生于是把它学成一道改写题，会把 Tom cleaned the room 改成 The room was cleaned by Tom，却不知道何时该说哪一句。D（说话的过程）：谁对谁说、说话人想把什么推到前景、想把什么留在背景——这才是被动句出场的真正原因。E（要办的事）：报告事故、抱怨失窃、发布通知、告状、道歉，场合不同，焦点的选择随之不同。

本章主路径仍是 E→D→S：小雨先有一件「不想说出自己」的事（E），在跟妈妈、跟日记本的来往中（D），从课本里翻出被动句（S）。123 原理在 11.3 体现得最清楚：中文「被＋动词」的旧句型装不下英语的时数要求，「被」与「be」之间的张力逼出了两件套；中文「被」偏向不如意、英语被动语义中性，这一层差异也值得讲给学生，它解释了为什么学生很少主动写 English is spoken… 这类句子。The accident was happened 这一高频错误，可以借 The window broke 一并讲清：有些事件英语只给「自己发生」的说法。

11.4 的「句子家族」是一个可直接搬进课堂的活动：给一件事，让学生分别以新闻、告状、道歉三种身份写，学生自己就能说出主被动的分工，这比讲十遍「被动语态的用法」更牢。还请留意一层意味：同一个 S，在不同的 E 里，可以是护航，也可以是遮掩。我们不必替学生下道德结论，只需让他们看见句子的选择本身就是一种态度。这正是三证据里的「迁移」：同一结构换到新场合，学生能说出它在那里为什么合适、为什么不合适，才算真会了。

> **带走的话**
> 被动句把灯从人身上挪到事情上；想负责的时候，记得把灯挪回自己身上。

> **小账**
> 本章句子：I broke the window. / The window was broken. / My package was stolen. / The window will be fixed tomorrow. / It was my fault.
> 本章卡住点：The window broken.（错）→ The window was broken.（对）


## 第 12 章　可能、必须、客气


> **这一章的问题**：明明每个词都对，为什么我一开口，人家就不高兴？英语里的 can、could、must、should 是在讲「能不能」，还是在讲别的什么？我想客气一点，是不是只要加个 please 就够了？

### ◆12.1　借一支笔

「Give me your pen.」

「……Excuse me?」

说这话的是 Emma，小雨的新同桌，从加拿大来的交换生，到班上才第二天。十二月的早上，教室的窗缝里钻着冷风，大家都缩着脖子。英语课刚开始，周老师说要默写单词，小雨一摸笔袋，才发现那支常用的黑笔落在家里了。她扭头看见 Emma 笔袋里插着三四支笔，想也没想，就说出了开头那一句。

Emma 是星期一跟着班主任走进教室的。她个子高高的，头发扎成一个蓬松的马尾，用带点口音的中文说「大家好，我叫 Emma」，全班哄地一下鼓起掌来。班主任把她安排在小雨旁边，小雨心里又高兴又紧张：高兴的是终于有一个真正说英语的同桌，紧张的是怕自己一开口就露馅。头一天她几乎不敢说话，只是点头、微笑、递一递课本。直到第二天早上，她总算开了口，开口就是那一句 Give me your pen。

Emma 愣了一下，眉毛往上挑，那个 Excuse me 的尾音拖得长长的，往上一扬。然后她还是抽出一支笔递了过来，只是脸上没了笑，转回头去，一整节课都没再跟小雨说话。小雨捏着那支笔，心里直犯嘀咕：我说错什么了？Give 是「给」，me 是「我」，your pen 是「你的笔」，哪个词都没错啊。

她越想越委屈。下课的时候她憋不住，跑去问前排的同学，那个同学也说不上来，只说：「可能人家外国人比较讲究吧。」这句话让小雨更不服气了——讲究什么？难道借支笔还要先鞠个躬？那天她在本子上用力写下一行字，写得笔尖都快戳破纸：「我又没说脏话！」

晚上回到家，她把这事讲给林姐听，一边讲一边吸鼻子，那几天她正好有点着凉，声音闷闷的。林姐听完，没急着站队，想了想问她：「你在家跟我说『把酱油给我』，我不生气。可你要是在楼下跟张阿姨说『把酱油给我』，张阿姨会怎么样？」小雨不吭声了。

小雨被问住了，委屈却还没消。她抱着靠枕缩在沙发角上，说：「可我又不是故意的。我就是着急，一着急，脑子里就只剩这几个词。」林姐挨着她坐下，把她额前的头发拨开，摸了摸，有点烫。「我知道你不是故意的，」林姐说，「人家 Emma 也不知道你着急。她只听得见你说了什么。」这话说得很轻，小雨却一下子安静了。

林姐这一问，问到了根上。「把酱油给我」这句话，在自家厨房里是很自然的，因为母女俩天天在一起，关系近，不用客套。可同样一句话，说给一个刚认识没两天的人，意思就变了：它听上去像是在下命令，好像对方本来就该给你，好像你是在使唤人。词一个没变，变的是说话的人和听话的人之间的距离。

小雨还嘴硬：「那我加个 please 总行了吧？Give me your pen, please.」林姐让她自己念两遍听听。小雨念完，自己也泄了气。

加了 please，听起来是软了一点点，可骨架还是那个命令句——「给我」两个字还是直直地杵在最前头。这就像饭店服务员把盘子往桌上一摔，嘴里说一声「请慢用」，那个「请」字救不回那一摔。please 是一层糖衣，句子的骨头要是硬的，糖衣裹得再厚，咬下去还是硌牙。

老陈在旁边看电视，这时候冒了一句：「我在调度室，对司机喊『三号车，马上去二号仓』，没人觉得我凶。可我给客户打电话，从来都是『麻烦您看一下，货能不能下午再收』。」他说完又低头看电视去了。林姐朝小雨眨眨眼：你爸一天要换两种嘴，他自己都没觉得。小雨想了想，好像还真是：爸爸跟司机说话像在下口令，跟客户说话像在商量，跟外婆说话像在哄小孩。

我在这里要说一句可能和你想的不一样的话：Give me your pen 这句英语，语法上完全正确，可是它办事办砸了。它没把「借」这件事办成，反倒办成了另一件事——让 Emma 觉得自己被使唤了。语法书里很少讲这一层，可是在生活里，这一层常常比单词拼写更要紧。

第二天上学前，小雨问林姐：「那我该怎么说？」林姐自己也说不清，母女俩翻手机查了半天，查出好几种说法。小雨挑了一句，在路上嘴里念了一路：

Could I borrow your pen, please?（我能借一下你的笔吗？）

英语课前，她鼓起勇气，转过身把这句话说了一遍。Emma 先是一愣，然后笑了，眼睛弯成两个月牙，说：Sure! Here you go.（当然，给你。）递笔的时候还顺手多给了一块橡皮。那节课，两个人传了三次小纸条，下课一起去打了热水。小雨后来跟林姐说，就差了几个词，Emma 简直像换了个人。

过了几天，两人熟了，小雨忍不住问 Emma 那天为什么不高兴。Emma 用很慢的英语加上手势跟她解释：在她们那儿，Give me… 是妈妈对小孩、或者老板对员工才会说的话；同学之间这么说，好像在说「你得听我的」。她还笑着补了一句：My little brother says that to me. I don't like it.（我弟弟就这么跟我说话，我可不喜欢。）小雨这才明白，那天自己在 Emma 耳朵里，大概就像一个没礼貌的小弟弟。

其实换了的不是 Emma，是那句话。Give me your pen 是一个命令句，它把「给」这个动作直接塞到对方手里；Could I borrow your pen 却是一个问句，它把决定权递给了对方：你可以说好，也可以说不行。中间那个 could，像是说话时往后退了一小步，给对方让出一块地方。

那天下午还有一个小插曲。第二节课下课，周老师让小雨和 Emma 去办公室抱作业本。走到门口，小雨伸手就要推门，Emma 一把拉住她，先轻轻敲了两下，探头说：May I come in?（我可以进来吗？）里面的老师笑着说 Come in。小雨跟在后面，心里又记下一笔：对同学说 Can I…?，对老师说 May I…?，同一个「我可以吗」，换了人，就换了个词。

你可能会想起第 7 章，母女俩在香港学过 Could you…? 是请别人帮忙做事。这一回小雨碰到的是它的另一半：不是请别人做，而是问「我可不可以」。借笔、进门、坐一坐、看一眼，这些都是「我想做一件事，但这件事碰到了你」。碰到了别人的东西、别人的地方，英语就要先问一声，把那一点决定权留给对方。

问句还有一个好处，小雨是后来才想明白的。命令句只给对方一条路：照做。问句却给了两条：可以答应，也可以拒绝。

要是 Emma 那天只有一支笔，她完全可以说 Sorry, I only have one（不好意思，我只有一支），而小雨也不会觉得丢脸，因为这本来就是一个问题，问题就可以有两种答案。把拒绝的路留给对方，对方反倒更愿意走那条答应的路。这跟去菜市场买菜一样，你问一句「这把葱能便宜点吗」，摊主笑着说不行，大家都不伤和气；你要是说「便宜点卖给我」，摊主就算让了价，脸色也不好看。

灯亮了：**can、could、must、should 这一家词，表面上在说「能不能」「该不该」，骨子里是在照顾对方。**说话的人用它们来调节自己和对方之间的距离：退一步，是客气；往前一步，是要求。

> Give me your pen.（把你的笔给我。——命令，太冲）
> Can I borrow your pen?（我能借你的笔吗？——熟人之间，可以）
> Could I borrow your pen, please?（我能借一下你的笔吗？——对不太熟的人，更稳妥）

### ◆12.2　医生的叮嘱

改口借笔的那天夜里，小雨的感冒加重了，半夜开始发烧，嗓子疼得咽口水都皱眉头。林姐摸摸她的额头，二话不说，第二天一早打电话替小雨请了假，带她去了社区医院。社区医院新来了一位医生，说话慢条斯理。

林姐那天突然起了个念头：回去以后，要让小雨把医生的话用英语讲一遍，就当是练口语。小雨烧得迷迷糊糊，还是答应了。于是诊室里，医生每说一句，母女俩就在心里默默记一句。

候诊的时候，走廊里坐满了人，咳嗽声此起彼伏。护士拿着一叠单子出来叫号，对每个人说的都是：「请把衣服拉开，量个体温。」「请到二号诊室，稍等一下。」小雨烧得昏昏沉沉，心里还在想英语：护士一句「请」一句「稍等」，换成英语，大概就是 Could you…? 和 Would you…? 吧。她忽然觉得，医院就是一个说话很讲分寸的地方：护士对病人软声细语，可轮到医生交代病情，话又一下子硬了起来，一句是一句，没有商量。

医生量完体温，看了看喉咙，说：「问题不大，就是病毒性感冒。药按时吃，这个必须的。多喝水，最好在家休息两天，别去学校，免得传染同学。」他顿了顿，又补了一句：「对了，退烧以前，千万不能洗冷水澡。」

回到家，小雨裹着被子靠在床头，林姐端来一杯热水，坐在床边：「来，医生说了什么？用英语。」小雨清清嗓子，试着说：

> You should take medicine. You must drink water. You must stay at home.（你最好吃药。你必须喝水。你必须待在家里。——单看每句都不算错，可轻重全放反了）

林姐虽然英语不好，可她听出了一点意思：「你这么说，好像吃药是『最好吃』，喝水倒是『非喝不可』？医生可不是这个意思。」她让小雨把手机词典打开，母女俩一个词一个词地对。查到最后，小雨发现，她把医生那几句话的「分量」全弄乱了。

医生的话里，其实有三种轻重。「药必须按时吃」，这是最重的，没有商量的余地，不吃病就好不了；「多喝水、最好在家休息」，这是一种劝告，你照着做会好得快，不照做也不会出大事；「千万不能洗冷水澡」，这是一个禁止，跟「必须」一样重，只是方向反过来。把这三种轻重摆清楚，句子就重新排好了：

> You must take the medicine on time.（你必须按时吃药。——最重，没商量）
> You should drink more water.（你应该多喝水。——劝告，为你好）
> You should stay at home for two days.（你最好在家休息两天。——劝告）
> You mustn't take a cold shower.（你千万不能洗冷水澡。——禁止）

改完以后，林姐拿过本子念了一遍，点点头说：「这回像医生了。」她又说，你想想，我平时叮嘱你，是不是也分这几种？「作业必须写完」，是 must；「早点睡」，是 should；「过马路不准看手机」，是 mustn't。小雨一听就乐了：「妈，你天天都在用情态动词，自己还不知道。」

我很喜欢林姐这个联想，因为它把 must 和 should 从课本里拉回了厨房。我们说话的时候，心里本来就有一杆秤：这件事有多重要，我要用多大的力气说出来。说「必须」，是把秤砣压到底；说「应该」，是把秤砣放在中间，留一点给对方自己拿主意。英语只是给这杆秤上的刻度起了名字，叫 must、should。

医生开完药，又说了一句让林姐心里一紧的话：「今天晚上可能还会再烧一次，不用太担心，超过三十九度再来。」小雨回家翻译到这一句，又卡住了。「可能」该怎么说？她第一反应是 can，写成 You can have a fever again tonight（错），越读越别扭，好像医生在「允许」她再发一次烧。

林姐也觉得好笑：「人家医生是在提醒你，不是批准你。」母女俩一查，说「可能会」最常用的是 may 和 might：You may have a fever again tonight（你今晚可能还会再发烧）。如果医生的意思是「说不定会，概率不太大」，就用 might：You might feel a bit tired tomorrow（你明天可能会有点累）。may 和 might 都不是在下命令，也不是在给许可，它们是在说「我估计」，像天气预报说「明天可能有雨」。

这下，那杆秤上又多了一种刻度。must 说的是「一定得」，should 说的是「最好」，may 和 might 说的是「可能会」。前两种管的是你该做什么，后一种管的是会发生什么。医生一次门诊，把这几种刻度都用上了：他告诉你哪些事非做不可，哪些事做了更好，还有哪些事可能会来，让你心里有个准备。原来「可能、必须、客气」这三样，在一个医生嘴里就能凑齐。

> You may have a fever again tonight.（你今晚可能还会发烧。）
> You might feel a bit tired tomorrow.（你明天可能会有点累。）

这里还有一个小地方容易卡住。小雨后来问：「那医生说的『别去学校』，是 must 还是 should？」这个问题很好。医生说的是「免得传染同学」，这是一个有道理的劝告，不是法律规定，所以用 should 最贴切：You shouldn't go to school this week（这周你最好别去学校）。要是换成 You mustn't go to school，就有点像学校发了禁令一样，太重了。

从医院出来，母女俩顺路去了趟菜市场。林姐一边挑青菜一边念叨：「明天一早我还得去给你外婆送药，七点那班车，不能晚。」小雨灵机一动，说这句也能用英语：I have to get up early tomorrow（我明天得早起）。林姐问：「怎么不是 must？刚才医生那句不就是 must 吗？」

这个问题，小雨一时也答不上来，回家查了才弄清楚。must 和 have to 都很重，可秤砣是谁压上去的不一样。must 常常是说话的人自己觉得非这样不可，像医生凭他的判断告诉你「必须吃药」；have to 常常是外面的事情逼着你，像公交车七点发车，你不早起就赶不上，这不是你想不想的问题。林姐听了，点点头：「那我明天是 have to，车不等人。」这说法虽然粗，方向是对的；平常说话里两个词常常能换着用，你只要先记住这一层就够了。

你看，情态词用得对不对，不是查字典能完全查出来的，要看这句话在什么场合、谁对谁说、到底有多严重。一个医生对病人说 must，是在交代一件要命的事；一个同学对同学说 must，可能就显得太凶了。轻重是从场合里来的，不是从词典里来的。

临走前，小雨还替自己问了医生一句：「我下周一能去上学吗？」医生说：「烧退了，不咳得那么厉害了，就可以。」回家翻译的时候，小雨发现这一问一答里又藏着一个 can。她写下：Can I go back to school on Monday? — Yes, you can, if your fever is gone.（我周一能回学校吗？——烧退了就可以。）这里的 can 不是「有没有本事」，而是「允不允许」；医生不是在夸她身体好，是在给她放行。

林姐看了说：「这个 can 跟借笔那个 can 是一家的吧？」小雨点点头。借笔是问同学允不允许，上学是问医生允不允许，问的人都把自己放在请求的一方，把「行不行」交给对方去说。只不过对同学，她后来学会了退一步用 could；对医生，用 can 就足够诚恳，因为这是一个实打实的问题，不是一个要别人帮忙的请求。

灯亮了：**must 是秤砣压到底，没得商量；should 是秤砣放在中间，是劝告，留一点余地给对方；mustn't 是「千万不能」。**选哪一个，取决于这件事有多重、你跟对方是什么关系。

吃药前，林姐拿着药盒看了半天说明书。盒子侧面有一行小小的英文，她叫小雨帮她念：Children under 12 should not take this medicine.（12 岁以下儿童不宜服用此药。）林姐松了口气：「还好你十四了。」小雨却注意到，药盒上用的是 should not，不是 must not。她琢磨了一下：说明书大概是在说「不建议」，可如果真到了要命的地步，它就会换成更重的词。原来连药盒子都在用这杆秤，一字一字地掂分量。

小雨那天晚上睡得很早。她把本子放在枕头边，在最后一行写了一句自己的话：Mom says I should sleep now.（妈说我现在该睡了。）写完，她果然很快就睡着了。

### ◆12.3　卡住点：could 不是「过去能」

从医院回来那天下午，小雨吃了药，躺得无聊，翻出了周老师发的语法练习册。翻到情态动词那一页，有一道题让她又卡住了：

「could 是 can 的过去式，表示『过去能够』。请用 could 造句。」

她照着写了一句 When I was five, I could swim（我五岁的时候就会游泳了），这句对。可她越想越不对劲：前两天借笔说的 Could I borrow your pen? 明明是在说「现在」，现在就要借，怎么会是「过去」呢？难道她借笔的时候，其实是在问 Emma「我昨天能不能借你的笔」？

她拿着练习册去问林姐，林姐一听也犯迷糊：「是啊，人家现在就要借，你用个过去的词干什么？」母女俩又卡住了。这一回卡得比上回还厉害，因为练习册白纸黑字写着「过去式」，可她们的经验又明明告诉她们，Could I…? 说的就是眼下这一刻的事。

这个卡住点，其实是语法书留下的一个缝。说 could 是 can 的过去式，这话只说了一半。could 确实可以讲过去的能力，可它还有另一份更常用的工作：把话往后退一步，让语气变软。在英语里，「往过去退」常常就等于「往客气退」。时间上往回退了一步，说话的人跟眼前这件事之间就隔出了一点距离；有了这点距离，话就不那么硬，不那么逼人。

我常拿递东西来比。你把一杯热茶递给长辈，不会伸直胳膊怼到人家鼻子前，而是稍微收一点手，弯一点腰，让对方自己来接。手往回收的那一点点，就是 could 里那个「退」。它不是真的回到过去，而是在说：我不想逼你，你可以自己决定。

这么一想，小雨一下子通了。Can I borrow your pen? 是直直地伸出手；Could I borrow your pen? 是把手往回收了一点。两句都能借到笔，可后一句给 Emma 留的空间更大。所以对刚认识的人、对老师、对长辈，could 更稳妥；对好朋友、对家人，can 就够了，太客气反倒显得生分。这一点，小雨当天晚饭就亲身领教了。

这个「往后退一步」的道理，不只 could 有。英语里还有好几个词也是这样，同一个家族，往后退就变软。小雨在练习册后面找到了一张小表，她看着觉得挺有意思，抄了下来：

| 直接一点 | 退一步，更客气 | 意思 |
| --- | --- | --- |
| Can you help me? | Could you help me? | 你能帮帮我吗？ |
| Will you open the window? | Would you open the window? | 你能开一下窗吗？ |
| I want a cup of tea. | I'd like a cup of tea. | 我想要一杯茶。 |

你看最后一行，I want 和 I'd like。I'd like 是 I would like 的缩写，would 也是往后退了一步的那个词。在餐馆里说 I want a coffee，服务员不会生气，但听着有点像小孩子伸手要糖；说 I'd like a coffee，就像一个大人在点单。还记得第 7 章林姐在香港不敢点菜吗？要是那时候她会这一句，大概就没那么紧张了。

正说着，外婆打来视频电话，问小雨感冒好些没有。小雨一时兴起，要考考外婆：「外婆，你想跟我说『你能不能多穿件衣服』，英语里有三种说法，你猜哪种最客气？」外婆在那头笑得直摆手：「我哪懂这个。我只晓得，跟你说话要大声，跟隔壁王婆婆说话要慢声，跟村长说话要先递根烟。」

小雨被外婆这句话逗得咳嗽了半天，可笑完一想，外婆说的不就是这一节的事吗？大声、慢声、先递根烟，就是外婆的 can、could、would。外婆一个英语单词也不会，可她心里那套「看人说话」的分寸，比练习册上那张表还细。语言不一样，这杆秤每个人心里都有，英语只是把它刻进了几个小词里。

那天晚饭，小雨决定把新学的本事在家里试一试。她清清嗓子，对老陈说：Could you possibly pass me the salt, please?（您能否把盐递给我？）老陈夹菜的手停住了，看了她三秒，慢悠悠地把盐罐推过去，说：「说吧，又闯什么祸了？」林姐笑得差点把汤洒了。

这一出闹剧，正好把「退一步」的另一面演了出来。小雨的话一个词都没错，can 退成了 could，还加了 possibly 和 please，客气到了顶，可是用错了地方：餐桌对面坐的是她爸，不是校长。客气是有方向的：对远的人退一步，是尊重；对近的人退三步，就成了见外，甚至让人起疑心。一家人围着一张桌子吃饭，说 Can you pass me the salt? 或者干脆 Pass me the salt, please 就很好，那种随便本身就是亲近。分寸不是越客气越好，而是跟人的远近对得上。

我想再多说一层。为什么英语偏偏用「过去」来表示「客气」？中文其实也有类似的感觉。

你去邻居家借东西，会说「我想问一下，能不能借个梯子用用」，那个「想问一下」就是在绕，绕一点，话就软一点。英语没有「一下」这种小词，就用时间往回退一格，来做同样的事。不同的语言，用不同的零件，办的是同一件事：别让对方觉得被逼着。

灯亮了：**could、would 不只是 can、will 的「过去式」，它们更常用来把话往后退一步。往后退，话就变软；话变软，就是客气。**时间上的距离，换成了人和人之间的分寸。

> When I was five, I could swim.（我五岁的时候就会游泳了。——真的是过去）
> Could you help me, please?（您能帮帮我吗？——是现在，退一步更客气）
> I'd like a cup of tea.（我想要一杯茶。——比 I want 更得体）

这里顺便说一个很多人会踩的小坑，小雨也踩了。那天她用 could 问 Emma 借笔，Emma 回答的是 Sure!，要是 Emma 回答得完整一点，会说 Yes, of course you can（当然可以）。注意，回答里用的是 can，不是 could。小雨一开始很想回一句 Yes, you could，觉得这样才「对得上」。可那样一说，意思就变了，听上去像「你本来是可以的（不过现在不行）」，或者像是在给建议。

为什么问的时候用 could，答的时候反倒回到 can？因为 could 那一步是问的人往后退的，是问话的人在客气；答的人不需要跟着退，他只要痛痛快快地给出许可就好。就像别人弯着腰递茶给你，你不必也弯着腰去接，你点个头、双手接过来，说声谢谢，就是最好的回应。一个人退一步，另一个人往前迎一步，话才对得上。

> Could I borrow your pen?（我能借一下你的笔吗？）
> Yes, of course you can.（当然可以。——回答用 can）

小雨把练习册上那句「could 是 can 的过去式」用铅笔轻轻划了一道，在旁边写了几个字：「还会退一步，变客气。」写完她又有点担心周老师看到会不会不高兴，想了想，没擦。她觉得这几个字是自己从借笔、看病一路撞出来的，擦了可惜。

### ◆12.4　写一封请假邮件给周老师

那天傍晚，小雨的烧退了一些，人也精神了，只是还在咳嗽。医生说要在家休息两天，林姐说，明天周五就别去了，跟周老师请个假。以往请假都是林姐打电话，这一回林姐突然说：「你给周老师写封邮件吧，用英语写，就当练习。」

小雨一听就头大。她打开邮箱，第一稿写得飞快：

Teacher Zhou, I am sick. I can't go to school tomorrow. Give me the homework.（这一稿意思都到了，但太冲，像在下通知。）

写完她自己读了一遍，忽然想起了 Emma 那个挑上去的眉毛。Give me the homework——这不就是 Give me your pen 的翻版吗？周老师是老师，又不是她的同桌，这句话要是发出去，周老师大概会在电脑前面也挑一下眉毛。还有开头那个 Teacher Zhou，Mr. Brown 上课说过，英语里一般不这么称呼老师，要用 Ms. 或 Mr. 加姓。

她又删掉，换了第二稿：Dear Ms. Zhou, I am very very very sorry, I am so sick, I can't come, please please give me the homework.（这一稿也不妥）这回轮到林姐皱眉了：「你这是请假还是哭诉？连写三个 very，两个 please，周老师还以为你得了什么大病。」小雨也笑了。原来客气也有个度：不够了显得冲，过了又显得慌，像一个人一进门就连鞠十个躬，主人反倒手足无措。

她叫林姐过来，母女俩先从最上面的邮件标题改起。小雨原来空着没写，林姐说：「老师一天收那么多邮件，你不写标题，她都不知道要不要先点开。」两人想了一会儿，写上 Absence on Friday（周五请假）。几个词，老师扫一眼就知道是什么事。这也是一种体贴：替读信的人省一点力气。

接着，母女俩一句一句地改。小雨一边改一边嘟囔：「写封请假条比考试还累。」林姐说：「考试是写给分数看的，这封信是写给一个人看的，当然累。」改的不是单词，而是每一句话和周老师之间的距离。「我病了」，要说清楚，但不用说得像在抱怨；「明天去不了」，要讲明原因；「给我作业」，是最该改的，要变成一个请求，而且要把决定权留给老师。改了三四遍，最后的邮件是这样的：

> Dear Ms. Zhou,
> I'm sorry, but I have a bad cold and I'm still coughing. The doctor said I should stay at home, so I can't come to school on Friday.
> Could you tell me what the homework is? I'll finish it at home.
> Thank you very much.
> Best wishes,
> Chen Xiaoyu

（亲爱的周老师：很抱歉，我得了重感冒，还在咳嗽。医生说我应该在家休息，所以周五我不能去学校了。您能告诉我作业是什么吗？我会在家完成的。非常感谢。祝好！陈小雨）

这封邮件不长，可是这一章的东西几乎全在里面了。The doctor said I should stay at home，是用 should 转述医生的劝告，分量刚刚好；I can't come to school，是用 can't 说一件实在做不到的事，不客套也不夸张；Could you tell me…? 是把「给我作业」那一句往后退了一步，从命令变成了请求；I'll finish it at home 又接上了第 10 章的 will——这是她当场做出的一个承诺。

邮件里还有一处，母女俩争了一会儿。小雨本来想写 Could you send me the homework?（您能把作业发给我吗？），林姐觉得这是让老师替她跑腿。最后她们改成 Could you tell me what the homework is?——只请老师告诉她作业是什么，剩下的她自己来。同一个 could，请求的事情小一点，对方就更容易答应。客气不只是在词上退一步，有时候也是在要求上退一步。

林姐看完，说了一句很中肯的话：「这封信，周老师看了会放心。」她说，周老师放心的不是你英语多好，而是你懂事：你病了，你知道自己该干什么，你也知道怎么跟老师说话。小雨听了有点不好意思，又有点得意，点了发送键，手指在键盘上停了一秒。

周五下午，周老师回了邮件，不长：

> Dear Xiaoyu,
> Thank you for your email. You should get plenty of rest and drink more water. The homework is on page 45. Don't worry about it if you are too tired.
> Get well soon!
> Ms. Zhou

（亲爱的小雨：谢谢你的邮件。你要好好休息，多喝水。作业是第 45 页。要是太累了，就别担心作业。早日康复！周老师）

小雨把这封回信读了三遍。平时在作业本上画红圈的周老师，原来也会说 Don't worry（别担心）。她发现，周老师用的也是 should，用的也是那种给人留余地的语气——Don't worry about it if you are too tired，这句话简直比医生还温柔。那天晚上，她跟林姐说：「我以前以为周老师很凶。」林姐笑着说：「你以前给她的话，也没这么好听啊。」

那个周末，林姐也悄悄改了一样东西。她以前叮嘱小雨，开口闭口都是「必须」：必须九点前写完作业，必须把房间收拾干净，必须喝完这杯牛奶。看了这一个星期的 must 和 should，她忽然觉得自己的秤砣压得太狠了，好像家里每件事都是医生的医嘱。周六晚上，小雨还在看手机，林姐没像往常那样喊「必须睡了」，而是靠在门口，用她那口不太标准的英语说：You should go to bed now.（你该睡觉了。）

小雨抬起头，愣了一下，然后笑着放下了手机，说了一句：OK, Mom.（好的，妈。）林姐说，她那一刻觉得，自己不是在管孩子，是在跟孩子商量。一个 should，把「你给我去睡」变成了「为你好，去睡吧」。从「妈妈监督我」到「我们一起学」，原来有时候只隔着一个小词。

周一回到学校，小雨还在本子里夹着那封回信。Emma 看见她来了，指了指她的喉咙，问：Are you feeling better?（你好些了吗？）小雨笑着说：Much better, thanks. Could I borrow your notes from Friday?（好多了，谢谢。我能借你周五的笔记看看吗？）Emma 二话不说，把本子推了过来。

中午吃饭的时候，Emma 打开饭盒，里面是她寄宿家庭的阿姨做的饺子。她夹起一个，问小雨：Would you like one?（你要不要来一个？）小雨刚想摆手，又觉得这一句好听极了。Would you like…? 不是在问「你想不想要」，那样太直；它是把一份好意轻轻放在你面前，你接也行，不接也不尴尬。小雨接过饺子，说：Yes, please. Thank you!（好呀，谢谢！）

她后来跟林姐说，原来 would 不光能用来求人，还能用来请人。求人的时候退一步，是不想逼对方答应；请人的时候退一步，是不想逼对方接受。林姐想了想说：「这跟我去你外婆家，你外婆非要往我包里塞菜不一样。你外婆是往前冲三步。」母女俩都笑了。不同的人家，客气的方向也不一样，可心里想着对方，这一点是一样的。

小雨这一借，借得自然极了。没有人提醒她，她自己就用上了 could；她也没背任何句型，这一句是她在那一刻自己想出来的。从 Give me your pen 到 Could I borrow your notes，中间隔着一个白眼、一场感冒、一封邮件，还有一个陪她查了好几回词典的妈妈。

灯亮了：**一封得体的信，是把每一句话都放在合适的距离上：说明的地方说清楚，劝告的地方用 should，做不到的地方用 can't，请求的地方退一步用 could。**客气不是多加几个 please，而是让对方觉得被尊重。

### ◆给老师的一页


本章的核心是：情态动词首先是 D（说话的过程）的语法，其次才是 S（句子的样子）的语法。传统教法把 can/could、will/would 当作「现在式/过去式」配对来教，这是在 S 层上切分；学生会填「could 是 can 的过去式」，却在 E（要办的事）里频频失礼，因为他们没学到这些词真正在调节的东西——说话人与听话人之间的距离、请求的强度、义务的轻重。Give me your pen 一句，S 层完全合格，D 层却失败了：它把「请求」办成了「命令」。

123 原理在 12.3 最清楚：「could＝过去能」这一旧规则装不下 Could I borrow…? 的现在用法，张力逼出新理解：英语以「时间上的后退」表达「人际上的后退」。教学上可以把这一点讲成一条贯穿的线，后面第 13 章 If I were you 的「往后退一步＝不是真的」正好是它的姊妹，可提前埋下伏笔。12.2 的 must/should/mustn't，建议用「秤」的比喻让学生自己排轻重，再放进家长叮嘱、医生医嘱、校规三种场合里对照，学生会发现同一个 must 在不同场合分量不同。

三证据方面：小雨在 12.4 末尾对 Emma 说出 Could I borrow your notes from Friday?，这是没有人提示、换了对象和物件的自发使用，既是迁移，也带有创造；邮件的修改过程则是修正证据。请留意，本章错句里有两类：一类是 S 层错（本章较少），一类是 S 对而 D 错。后一类在课堂评分中最容易被漏掉，却最影响学生出门说话。

> **带走的话**
> 情态词是说话的分寸；往后退一步，对方就往前走一步。

> **小账**
> 本章句子：Could I borrow your pen, please? / You must take the medicine on time. / You should drink more water. / I'd like a cup of tea. / Could you tell me what the homework is?
> 本章卡住点：Give me your pen.（语法不错，但对不熟的人太冲）→ Could I borrow your pen, please?（对）


## 第 13 章　假如


> **这一章的问题**：明天会不会下雨，谁也说不准，可我们总得提前把话说好。有些事根本不可能，比如「我要是你」；有些事已经过去了，比如「要是早点复习就好了」。英语是怎么把「还没发生的」「根本不是真的」「已经来不及的」这三种「假如」分开说的？

### ◆13.1　明天下雨怎么办

一月中旬的一个星期四，晚上九点四十分，离学校的冬季长跑还有不到十二个小时。小雨趴在窗台上，手机屏幕亮着天气预报：明天，小雨，降水概率百分之六十。她盯着那个小雨点图标看了好久，心里一半盼着它真下，一半又怕它真下。盼它下，是因为十二月那几次课后练跑，她全都找理由溜了；怕它下，是因为一旦推迟，这件事就要像一块没咽下去的馒头，在嗓子眼里多卡几天。

班级群里早就炸开了锅。体育老师发了一条通知：「明早若下雨，长跑顺延至下周一。」底下一溜「收到」，夹着几句哀嚎。同桌 Emma 是加拿大来的交换生，中文还磕磕绊绊，她单独给小雨发来一句英文：「Will the race be cancelled if it rains?」小雨看了一眼，觉得这正是露一手的机会，手指飞快地敲了一句回过去。

> If it will rain tomorrow, the race will move to Monday.（错）

发出去她还挺得意，句子不短，「明天」「下雨」「推到星期一」一样没落下。林姐端着一杯热水从房门口路过，探头看了一眼屏幕。这一学期林姐跟着小雨一起学，别的不敢说，眼睛倒是越来越尖了。她没吭声，只是指了指 Emma 刚回过来的那一句。

> Oh, if it rains, we'll have more time to practise!

小雨把两句话上下对着看，脸慢慢有点热。Emma 的 if 后面，干干净净一个 rains，没有 will；自己的 if 后面，规规矩矩地塞了个 will。「明天的事，不就该用将来时吗？」她嘟囔着，「课本上说 will 表示将来，我又没用错。」林姐把杯子放下，在床沿上坐下来，说：「那咱俩想想，人家为什么偏不加。」

林姐想了一会儿，用的是她最熟的办法——拿厨房说事。她说，你看菜谱上写「水开了，就下面条」，没人写成「水将要开了，就下面条」。前半句「水开了」不是在预告未来，是在摆一个前提：等这个前提成了，后面的事就跟着来。小雨愣了一下，说：「对哦，中文那半句也没加『将要』。」

这就是第一种「假如」，最老实的一种。说话的人真心觉得这件事可能发生，下不下雨各有几成把握，于是先把条件摆上桌，再说条件成了会怎样。英语的习惯是：条件那半句用一般现在时，像是把它当成一张已经摊开的牌；「将来」这个意思，放在后半句的 will 里说一次就够了。一句话里两个 will 挤在一起，就像炒菜时盐放了两遍，意思没多，反而齁了。

小雨还是不太服气。她说：「可是我脑子里想的就是『明天会下雨』，那个『会』字不加，我总觉得少了点什么。」林姐说，那你换个角度想，if 本身已经把这件事推到了「还没定」的地方，就像你跟卖菜的说「你要是便宜点，我就多买两斤」，「便宜点」是你提的条件，不是你在预报。条件只管摆出来，结果才需要往前看。

林姐又举了个例子。她说她每天早上都跟小雨说「你要是迟到了，周老师会说你」，这句话在中文里也不会说成「你要是将会迟到」。说到这里，小雨自己先笑了，这句话她听了一个学期，耳朵都快起茧了，可从来没想过它里面藏着一条英语语法。

小雨把手机拿回来，重新打了一遍，又补了一句给 Emma 打气。这一回她没急着按发送，先自己小声念了念，觉得顺多了。她心里有点怕，怕又在 Emma 面前出一回丑。

> If it rains tomorrow, the race will be put off till Monday.
> 如果明天下雨，长跑就推迟到星期一。

> If it doesn't rain, I'll just have to run.
> 要是不下雨，我就只好跑了。

第二句是她自己加的，带着一点认命的味道。林姐笑了，说这句话说得比第一句还像真人在说话，「只好」两个字全在 just have to 里了。小雨没笑，她心里清楚，「只好跑」三个字背后，是十二月那四次溜掉的练习。

这时外婆的视频电话打了进来。外婆在城郊种菜，一到冬天就盯着天，她一开口就是：「明天要落雨哦，下雨天菜长得快，我那几垄菠菜正好喝水。」小雨顺嘴给外婆「翻译」成英文，逗她玩：「If it rains, the spinach grows fast.」外婆听不懂，只听出了「菠菜」那个调子，在屏幕那头乐得直点头。

挂了电话，林姐指着小雨刚才那句说，这句跟长跑那句有点不一样。长跑那句讲的是明天这一回，后半句用 will；外婆这句讲的是年年冬天都这样，下雨就长，是个老规律，前后两半都用一般现在时就行。就像「牛奶放在外面就会坏」，说的不是今天这一瓶，是所有牛奶的脾气。

> If you leave the milk out, it goes bad.
> 牛奶放在外面，就会坏。

小雨又想起 Emma 那句 we'll have more time to practise。她把这句话翻来覆去看了几遍，发现人家这么一说，下雨就不是坏消息了，而是「多出几天练习」。同一个条件，后半句接什么，全看说话的人想办成什么事。体育老师的通知是在安排日程，Emma 的回复是在给自己打气，外婆的那句是在惦记菜地，三个人都说「要是下雨」，各有各的心思。

她想了想，给 Emma 回了一句：「If we have more time, will you run with me after school?」我们要是多出时间，你放学陪我跑跑好吗？发出去以后她有点不好意思，这是她第一次主动约人练跑。Emma 回了一个大拇指，又加了一句「Deal!」。小雨看着那个词，猜了半天，林姐说大概是「一言为定」，两人一查，果然。

这一问一答，让小雨发现 if 句不光能说天气，还能拿来约人、讲条件、讨价还价。妈妈平时说「你写完作业，就可以看半小时电视」，翻成英语也是一句真条件：If you finish your homework, you can watch TV for half an hour. 后半句不一定是 will，也可以是 can、may 这类词，只要那件事是真有可能的，就都算这一家的。林姐一听就乐了，说这句话她天天挂在嘴边，原来早就会了一半。

正说着，老陈下班回来了。他在门口换鞋，听见母女俩在念 if，就冒出一句：「明天要是下雨，我开车送你。」小雨眼睛一亮，问他这句用英语怎么说。老陈摆摆手说他不会，小雨就自己替他说了：「If it rains, Dad will drive me.」说完又换了个顺序：「Dad will drive me if it rains.」两句意思一样，一句先摆条件，一句先说结果。

林姐问，这两种有什么不一样。小雨想了想说，第一种像先看天再出门，第二种像先把好消息说出来，再补一句「前提是下雨」。英语的 if 那半句放前放后都行，放前面的时候，中间习惯加一个逗号，像在条件和结果之间喘一口气；放后面的时候，一般就不加了。老陈在一旁听完，只说了一句：「反正下雨我都得早起。」

小雨这时又想起一个问题。班级通知里写的是「若下雨」，那要是写「等雨停了，再开始跑」呢？她试着说了一句 If the rain stops, we'll start，又觉得不对劲。雨总是会停的，这件事不是「可能」，是「早晚」。林姐也觉得别扭，两人翻了半天书，才弄明白这里该用 when。

> When the rain stops, we'll start.
> 等雨停了，我们就开始。

> If the rain stops, we'll start.
> 雨要是停了，我们就开始。

这两句放在一起，差别一下就出来了。用 when，说话的人心里有底：雨一定会停，只是时间早晚；用 if，说话的人心里没底：雨停不停还两说。这跟买菜一个道理，「等菜贩来了我就买」和「菜贩要是来了我就买」，前一句是天天来的老摊子，后一句是有一天没一天的流动摊。if 那半句里装的，正是说话的人心里那一点「不一定」。

灯亮了：真条件说的是「真有可能」的事。if 那半句用一般现在时，把条件当成摆在桌上的前提；后半句如果说这一回会怎样，就用 will（也可以用 can、may）；如果说的是向来如此的规律，就也用一般现在时。「将来」只在一个地方说一次，不在 if 后面再塞 will。

那天晚上小雨很早就关了灯，可是睡不着。她一会儿听窗外有没有雨声，一会儿想起十二月那几个溜掉的下午。她在被窝里默默念了一遍「If it rains」，念着念着发现自己最想要的，其实不是下雨，而是一个能重新来过的十二月。

### ◆13.2　如果我是你

星期五早上，天没下雨。不但没下，还出了个惨白的太阳，冷风吹得操场边的旗杆嗡嗡响。检录的时候，小雨听见旁边两个女生在小声嘀咕，一个说「要是下雨就好了」，另一个说「要是我昨天没吃那么多就好了」。小雨心里一紧，这两句「要是」，一句盼的是没来的天气，一句悔的是已经吃下去的晚饭，都不是她能改变的了。

发令枪一响，她跟着人群冲了出去。三千米，小雨跑到第五圈就岔了气，最后一圈是捂着肚子走完的。冲线的时候，她看见 Emma 早就跑完了，正披着外套朝她挥手，那一刻她恨不得地上有个缝能钻进去。

晚上回到家，她整个人瘫在沙发上，腿酸得像灌了铅。手机举在脸上方，短视频一条接一条地往上划，橘子蜷在她肚子上打呼噜。下星期一就是期末考试的第一门英语，书包从进门起就扔在玄关，拉链都没拉开。

林姐从厨房出来，围裙还没解，看了她足足有半分钟。照她平时的脾气，这时候一句「你还有心思玩手机」已经冲到嘴边了。可她深吸了一口气，把那句话咽了回去。这学期她跟小雨学英语，最大的收获之一，是发现换一种语言说话，人会不自觉地慢下来半拍。她在沙发扶手上坐下，想了想，说了一句前几天在剧里听来、又专门查过的话。

> If I were you, I'd put the phone down and go over my notes.
> 我要是你，就把手机放下，去翻翻笔记。

小雨把手机从脸上挪开一点，斜着眼睛看她妈：「可你又不是我。」话一出口，她自己先愣了一下。林姐也愣了，然后两个人同时笑出了声。小雨这句顶嘴，恰好把这个句子的要害说穿了——林姐不是小雨，永远也成不了小雨，这句话说的本来就是一个不存在的世界。

小雨不服输，想用英语顶回去。她说：「If you are me, you will also play.」（错）意思是：你要是我，你也会玩。林姐没听出哪儿不对，可小雨自己说完，总觉得哪里别扭。刚才妈妈说的是 were，是 I'd，自己说的是 are，是 will，两句话放在一块儿，明明是同一种意思，穿的却不是一套衣服。

她爬起来翻英语书，翻到条件句那一页，嘴里念念有词。原来上一节讲的那种「假如」，是真有可能的事，明天可能下雨，也可能不下，所以用 rains、用 will。可「我是你」不一样，它没有一丝一毫成真的可能，谁也变不成谁。英语碰到这种「根本不是真的」，就换一套说法：if 那半句往过去时退一步，后半句用 would 代替 will。

> If you were me, you'd play too.
> 你要是我，你也会玩的。

改完这句，小雨才觉得顺了。她又不甘心地补了一句：「If I had a car, I'd drive Grandma to the market every day.」我要是有辆车，就天天开车送外婆去赶集。她当然没有车，她才十四岁，这又是一个不存在的世界。林姐说，我听懂了，你这是变着法儿夸自己孝顺。

我在这里多说两句。这种句子，课本上叫「虚拟语气」，名字听着玄，其实我们天天在用。中文里「要是……就好了」「我要是你」「假如我有一百万」，都是在说一个不存在的世界，只不过中文靠「要是」两个字撑着，动词本身不变。英语多了一道手续：它要在动词上做个记号，提醒听的人「这是假的，别当真」。

你可以把它想成家里的两种笔。钢笔写的是账本，买了几斤菜、花了多少钱，一笔一笔都是真的；铅笔写的是草稿，画个设想，随时可以擦掉。真条件用的是钢笔，虚拟用的是铅笔，退回过去时、换上 would，就是英语换笔的那个动作。

> If I were you, I'd take a break.
> 我要是你，就歇一会儿。

> If I had more time, I'd learn to cook.
> 要是我有更多时间，我就学做饭。

这时候橘子从小雨肚子上跳下来，伸了个懒腰，慢吞吞地走到取暖器旁边，又躺倒了。老陈正好从卫生间出来，看了一眼橘子，难得地接了一句：「我要是猫，也天天这么躺着。」小雨一下子坐直了，说：「爸，你这句我会说！」她掰着手指头说：「If I were a cat, I'd sleep all day.」老陈点点头，说了声「嗯」，回房间去了，大家都分不清他是在夸小雨，还是在羡慕橘子。

小雨又想起外婆。上次去外婆家，外婆坐在门槛上剥豆子，说过一句：「我要是年轻二十岁，也跟你们一起学洋文。」那时候她只当是一句闲话，现在才发现这也是一个不存在的世界。外婆不会再年轻二十岁了，这句话说出口，本身就带着一点点心酸。她在本子上试着写下来，写得很慢。

> If I were twenty years younger, I'd learn English with you.
> 我要是年轻二十岁，就跟你们一起学英语。

林姐凑过来看，眼圈有点红，说下回去外婆家，念给她听。小雨说外婆听不懂。林姐说，听不懂也没关系，她听得出来你在说她。这句话让小雨想起，一个句子要办的事，有时候根本不在字面上。

虚拟还有一个近亲，叫 I wish，专门用来说「真希望」。小雨长跑落在最后，心里想的就是这个：I wish I were faster. 我真希望自己跑得快一点。wish 后面也往后退了一步，用的是过去时，因为那个「跑得快的自己」，现在还不存在。林姐听了，补了一句自己的：I wish I had more time to study. 我真希望有更多时间学习。两个人都没说透，可都知道对方说的是真心话。

后半句也不是只能用 would。林姐查书的时候发现，would 说的是「我会」，could 说的是「我能」，might 说的是「我也许会」。比如：If I had a bigger kitchen, I could bake bread. 要是厨房再大点，我就能烤面包了。这一句是林姐自己造的，她念完叹了口气，说老小区的厨房转个身都难，这句话怕是只能一直待在虚拟里了。

灯亮了：说一个不存在的世界，英语会把动词往后退一步——if 那半句用过去时，后半句用 would（或 could）。它说的不是过去的事，而是「不是真的」。真条件和虚拟，差的不是语法难度，是说话的人心里到底觉得这件事有没有可能。

后来小雨问过林姐，那天为什么不直接说「快去复习」。林姐说，直接说的话她也会，You should study now，上个月看医生的时候刚学过 should。可 should 是站在对面说话，像隔着桌子递一张单子；If I were you 是假装走到你这边来，跟你站在同一个位置上看事情。一个是「你应该」，一个是「我要是你」，话里的意思差不多，可听的人心里的滋味完全不一样。

小雨想了想，觉得妈妈说得对。要是那天林姐冲进来说「你还玩手机」，她八成会把门一关，手机照玩；偏偏是那句「我要是你」，让她连顶嘴都顶得有点心虚。原来虚拟不光是语法书上的一个章节，它还是大人劝孩子、朋友劝朋友时，给对方留面子的一种办法。

那天晚上，小雨嘴上没服软，手机却真的放下了。她把书包从玄关拖回房间，拉链拉开的声音特别响，好像是故意给客厅里的人听的。林姐在客厅里假装看电视，嘴角翘了一下，什么也没说。

### ◆13.3　卡住点：为什么是 were

星期六早上，小雨一边啃包子一边复习，复习着复习着，又绕回了昨晚那句话。她拿铅笔在本子上写了三行：I were you（错）、He were here（错）、It were cheap（错）。写完自己都觉得刺眼——单拎出来，这三行都不对。

平时 I 后面跟的是 am 和 was，从来没跟过 were，这就好比一直穿三十六码鞋的脚，忽然被塞进了一双三十八码的。可昨晚妈妈那句 If I were you，偏偏就是这么穿的，而且穿得理直气壮。她越看越糊涂，包子都忘了往嘴里送。

她给 Emma 发微信问这件事，想听听「本地人」怎么说。Emma 回得飞快，还带着一个大笑的表情：「Haha, if I was you I'd just sleep in today.」小雨盯着屏幕傻了眼——Emma 用的是 was，不是 were。课本说 were，林姐说 were，土生土长讲英语的同桌却说 was，到底听谁的？

星期一考完英语，她带着这个问题去办公室找 Mr. Brown。Mr. Brown 正在泡茶，听完笑眯眯地说：「Both are fine when you talk with friends. But in writing, and in exams, If I were you is safer.」意思是：跟朋友聊天，两种都行；可写东西、考试，用 If I were you 更稳妥。小雨把这句话记在了手心里，生怕一转身就忘。

小雨又问，那他平时自己怎么说。Mr. Brown 想了想说，跟老朋友喝茶聊天，他多半随口说 was；给学生写评语、给学校写报告，他会写 were。他说英语里有不少这样的地方，一种说法松一点，一种说法正式一点，就像你在家穿拖鞋，出门换球鞋，脚还是那双脚。

小雨这下松了口气，可心里那个「为什么」还没解开。Mr. Brown 拿起一支笔，在纸上画了一条线，左边写 past，右边写 now。他说，过去时本来是用来说「离现在远」的事，昨天、去年、小时候；虚拟借用了它，表示「离现实远」。时间上往后退一步，借来当作现实上往后退一步——说话的人往后站一站，意思就是：「我说的这件事，不在眼前，不在真的世界里。」

小雨忽然想起上个月借笔的事。那时候她发现，Could I borrow your pen? 里的 could 也不是「过去能」，而是往后退了一步，退出来的那一点距离，变成了客气。现在这个 were 也是退一步，只不过退出来的距离，变成了「这不是真的」。同一个后退的动作，一个用来照顾对方，一个用来标明假设，原来英语里「往后退」这个习惯，到处都在用。

那为什么偏偏是 were，而不是 was 呢？这件事你可以这样记：一旦进了「不是真的」这个世界，英语就不太在乎主语是谁了，I、he、she、it 统统穿同一件衣服，就像学校运动会上不管哪个班，一律发同一款运动服。were 就是这件统一的运动服。日常聊天的时候，很多人懒得换衣服，还穿着平时的 was 出门，大家也都听得懂；可到了正式场合，统一着装更体面。

不过小雨真正栽的跟头，不是 was 还是 were，而是另一处。那是考前一个星期的一篇练笔作文，题目叫「假如我是老师」。她写得很投入，一口气列了好几条「我要是老师就怎样」。其中有这么一句：

> If I were a teacher, I will give fewer tests.（错）

前半句穿的是铅笔衣服，后半句却又换回了钢笔衣服——were 已经说了「这是假的」，will 却又说「我一定会」。两半句一个在梦里，一个在现实里，听的人就糊涂了：你到底是在做梦，还是在许诺？就好比一个人嘴上说「我要是中了五百万」，下一句接的却是「明天我就去交首付」，听的人不知道该陪他笑，还是该替他担心。

> If I were a teacher, I would give fewer tests.
> 我要是当老师，就少考几次试。

正确的做法是两半句一起退：前面退到过去时，后面退到 would。虚拟不是哪一个词的事，是整句话一起换了一个世界。小雨把这一句改好，又顺手造了一句：「If I knew the answer, I would tell you.」我要是知道答案，就告诉你了——她其实是写给自己的，因为考试那天有一道阅读题，她真的不知道答案。

说到这里，你也许会问：中文怎么就不用这么麻烦？「要是明天下雨」「要是我是你」「要是我早点复习」，三句话用的都是同一个「要是」，动词一个字没改。这正是中国学生容易在这里卡住的原因。中文把「有几成真」交给语境和语气去管，听的人自己掂量；英语却要求说话人在动词上亲手做个记号，把自己的判断明明白白地交代出来。

这不是谁好谁坏的问题，而是分工不同。中文像一桌家常菜，咸淡由吃的人自己就着米饭调；英语像一份菜单，辣不辣要在菜名旁边标一个小辣椒。我们说惯了中文，到了英语里就常常忘了标那个小辣椒，于是一句明明是假想的话，被人当成了真的打算。

小雨在作文里还写过这么一句：「If I am a bird, I will fly to Canada to see Emma's home.」（错）她自己是知道人不能变成鸟的，可动词照样用了 am 和 will，读起来就像她真打算明天长出翅膀。周老师在这句旁边画了个红圈，又在边上写了一个小小的笑脸。改成虚拟以后，这句话就变得又老实又可爱了。

> If I were a bird, I would fly to Canada to see Emma's home.
> 我要是一只鸟，就飞到加拿大去看 Emma 的家。

还有一种卡法也常见，就是把虚拟和真条件搞混了。比如明天真可能下雨，你却说 If it rained tomorrow, the race would be put off. 这句话本身没错，可它的意思变了：说话的人觉得明天下雨不太可能，只是随便设想一下。所以选哪一套，不看课本第几页，看你心里那杆秤，觉得这件事有几成可能。

> If it rains tomorrow, we'll stay in.（真有可能下）
> 明天要是下雨，我们就待在家里。

> If it rained tomorrow, we'd stay in.（觉得不大会下）
> 万一明天下雨，我们就待在家里。

从办公室出来，小雨在走廊里碰到了周老师。周老师问她英语考得怎么样，她说有一道题拿不准，就是 if 后面填 was 还是 were。周老师说，卷子上那道题考的就是 were，课本上教的是 were，你写 were 不会错。小雨又把 Mr. Brown 和 Emma 的话学了一遍，周老师听完笑了，说：「那你现在比课本知道得还多一点。」

这一句话让小雨挺高兴。原来周老师和 Mr. Brown 说的并不打架：一个告诉她卷子上怎么写稳妥，一个告诉她生活里大家怎么说。语法书上的规则，像是一张写给陌生人的说明书，要写得最规整、最不会出错；而真实的说话，像是熟人之间的家常话，松一些、随便一些。两样都知道，人才不会在考场上丢分，也不会在聊天时紧张。

灯亮了：were 不是乱来，是「往后退一步」的记号——借用过去时离现在远，表示离现实远。进了「不是真的」世界，前后两半句要一起退：if 后面用过去时（be 动词常用 were），主句用 would。口语里常有人说 If I was you，写作和考试用 were 更稳妥。

### ◆13.4　后悔的话

期末成绩是一月底出来的。英语考了八十一分，比期中掉了九分；数学更惨，最后两道大题几乎是空着交上去的。小雨把成绩单塞在书包最底下，晚饭吃得很少，老陈问了一句「考得怎么样」，她说「还行」，老陈就没再问，只是给她夹了一块排骨。

那天夜里，她打开日记本。这学期她开始试着用英语写日记，不为别的，就为林姐说过一句「你写，我看不懂，正好保密」。她咬着笔头想了很久，写下一句话。

> If I studied earlier, I would get a better score.（错，用错了地方）

写完她自己看了看，觉得哪里不对劲。这句话的意思好像是「我要是现在早点学，就会考得好一点」，可考试已经考完了，成绩单已经塞在书包里了，「早点复习」这件事，是一个已经错过的过去。她想说的不是一个不存在的现在，而是一个回不去的过去。

第二天她犹豫了好久，还是把日记本拿给了林姐。这是她第一次主动把英语日记给妈妈看。林姐看了半天，说她也看不太懂，但她看出来这句话里装的是后悔。她们一起翻书，翻到条件句的最后一种，林姐念出声来，念得磕磕巴巴，可意思一下子就对上了。

林姐先问了一个问题：「你这句话，说的是哪一天的事？」小雨说是考试前那一个月。林姐又问：「那一个月，你早点复习了没有？」小雨说没有。林姐说：「那你这句话，就是在说一件过去没发生的事。」

这三问问下来，小雨自己就明白了，她卡住的地方不在单词，而在时间：她用说「假的现在」的那一套，去说了一个「假的过去」。上一节说，假的现在，要往后退一步；那假的过去呢？过去本来就已经在后面了，要说「过去其实没有发生过的事」，英语就再往后退一步：if 那半句用 had 加过去分词（过去分词就是第 9 章说的动词「第三个样子」），后半句用 would have 加过去分词。退了两步，意思就是：那件事已经过去，而且它当初没有那样发生。

> If I had started reviewing earlier, I would have done better.
> 我要是早点开始复习，就会考得更好了。

这里还有一个小坑，小雨第二天就踩了进去。她写：If I had started earlier, I would get a better score.（错）前半句退了两步，后半句只退了一步，就像下楼梯时一只脚踩到了二楼，另一只脚还留在三楼。成绩是考试那天定下来的，也是过去的事，后半句也得跟着退到 would have got。要是后半句说的真是现在，比如「我现在就不会这么难受了」，那才可以只退一步：If I had started earlier, I wouldn't feel so bad now.

林姐听小雨讲完这一层，琢磨了一会儿，说这就像炖汤：先放什么后放什么，看的是每样东西本身要炖多久，而不是一股脑儿全扔进锅里。前半句看那件事发生在什么时候，后半句看那个结果落在什么时候，两边各管各的时间。小雨说，妈你这个比喻比书上的还好懂。

小雨看着这句话，觉得它比自己写的那句沉得多。那两个 have 像两块小石头，把这句话压在了过去，再也挪不动。她又想起星期五的长跑，想起最后那一圈捂着肚子走的样子，就又写了一句。

> If I had run more in December, I wouldn't have been so slow.
> 我要是十二月多跑跑，就不会那么慢了。

林姐看了，没说什么，过了一会儿才开口：「我也有一句。」她说，她要是当年在学校把英语学好，现在就能多帮帮小雨，不用跟着从头学。她让小雨帮她翻成英文，小雨想了想，写下了 If I had studied harder at school, I could have helped you more. 林姐盯着那句话，又笑了，说：「不过要是那样，我也就不会陪你一起学了。」

小雨也笑了，这一笑，后悔的味道就淡了一点。她想起老陈讲过的一件事。有一年冬天，老陈在物流公司排班，图省事把一批货排在了老路线上，结果那条路修桥封了一半，三辆车在路上堵了四个钟头。老陈回家那天一句话没说，后来才讲起来：「早知道走环城路就好了。」

小雨把这件事也翻成了英语，算是替爸爸说一回后悔的话：If I had sent the trucks the other way, they wouldn't have got stuck. 林姐说，你爸要是知道你拿他当例句，肯定又要冷冷地来一句「我那是工作失误，不是语法练习」。果然，晚饭时小雨念给老陈听，老陈嚼着饭说：「嗯，后来我都先看路况。」说完他又低头吃饭，好像这件事早就翻篇了。

这一句「后来我都先看路况」，让小雨愣了一下。爸爸的后悔没有停在「早知道」上，而是变成了一个新习惯。她忽然明白，后悔的句子最有用的地方，不在于说得多准确，而在于说完之后人往哪里走。

其实说后悔，英语还有一个更短的说法，上个月学过的 should，往后退一步加上 have，就是「本来应该」：I should have started earlier. 我本来应该早点开始的。一句话就把后悔说完了，像一声叹气。林姐听了说这句她用得上，买菜回来发现忘了买葱，就该叹一句 I should have bought some spring onions.（我本来该买点葱的。）

我想在这里停一下，说说这三种「假如」到底差在哪儿。它们不是三条要背的公式，而是说话的人站在三个不同的地方往外看。站在「真有可能」的地方，说的是还没来的明天；站在「不是真的」的地方，说的是一个假想的现在；站在「来不及了」的地方，说的是一个回不去的过去。动词往后退几步，就是说话的人离现实有几步远。

| 心里的「假如」 | if 那半句 | 后半句 | 例句 |
| --- | --- | --- | --- |
| 真有可能 | 一般现在时 | will／一般现在时 | If it rains, the race will be put off. |
| 不是真的（现在） | 过去时（were） | would | If I were you, I'd go over my notes. |
| 来不及了（过去） | had＋过去分词 | would have＋过去分词 | If I had started earlier, I would have done better. |

表里三行，最容易被人忽略的，其实是第一行。人一后悔，心思就全跑到第三行去了，「要是当初」「早知道」，越想越往回走。可第三行说的那个世界，已经没有门可以进去了；只有第一行说的那个世界，门还开着，明天还没有来。

那个周末，一家人去城郊看外婆。外婆在菜地里拔菠菜，听说小雨长跑落在最后、考试也没考好，没有说一句重话，只是把一捆菠菜塞进她怀里，说：「菜晚种了一茬，下一茬早点下种就是了。」小雨抱着那捆菠菜，带着泥土的凉气，鼻子忽然有点酸。

回家的车上，她在手机备忘录里把外婆这句话写成了英语。她想了很久，没有用 had done，而是用了最简单的那一种：If you plant early, you get more. 早点种，就收得多。林姐问她为什么不用后悔的那一套，小雨说：「外婆说的不是后悔，是规律。」

那天晚上，小雨在日记的最后又写了一句。写之前她想了很久该用哪一套，最后用的是最老实的那一种——真条件。因为下学期还没开始，这件事还真有可能发生。

> If I start now, I'll be ready next term.
> 我要是现在就开始，下学期就能准备好。

灯亮了：说后悔，就是说一个没有发生的过去。英语把动词再往后退一步：if 后面用 had 加过去分词，后半句用 would have 加过去分词；短一点，可以说 should have 加过去分词。后悔的话说完了，别忘了还有一套真条件，留给还来得及的明天。

### ◆给老师的一页


条件句在课本里通常是三张公式卡：第一类、第二类、第三类，学生背得出，却分不清什么时候用哪一张。本章把它还原为说话人对现实的判断：先有要办的事（E）——明天可能下雨的长跑、一个劝不动的孩子、一张已经出来的成绩单；再有说话的过程（D）——跟同桌商量、母亲忍住火劝、夜里写日记的自言自语；最后才显露出句子的样子（S）——rains/will、were/would、had done/would have done。路径是 E→D→S。

本章的承重概念是「往后退一步」。过去时形态在这里不承担时间，而承担与现实的距离；这与第 12 章 could 的礼貌距离是同一种机制，可以引导学生把两章连起来看，体会英语形态在不同场合被借用的方式。123 原理在本章三处可见：一是「明天的事要用将来时」与「条件只摆前提」的矛盾，逼出 if 从句不用 will；二是「我说的是现在」与「这不是真的」的矛盾，逼出过去时形态加 would；三是「我在说过去」与「过去没那样发生」的矛盾，逼出 had done。每一处都是旧句子装不下新意思，新结构才长出来。

课堂建议：不要先发三张公式卡。给学生同一个场合（比如周末出游），让他们分别从「真有可能」「不是真的」「来不及了」三种心态各说一句，再让同伴判断说话人心里有几成把握。检查三证据时，尤其看「迁移」：学生能否在自己的后悔里，而不是课本例句里，说出 had done 的句子。关于 If I was you，宜如实告诉学生口语中常见，书面与考试用 were 更稳妥，不必当成错误去扣。

> **带走的话**
> 动词往后退几步，就是你心里离现实有几步远。后悔说完，记得换回真条件，给明天留一句。

> **小账**
> 本章句子：If it rains tomorrow, the race will be put off till Monday. / If I were you, I'd put the phone down. / If I were a teacher, I would give fewer tests. / If I had started reviewing earlier, I would have done better. / If I start now, I'll be ready next term.
> 本章卡住点：If it will rain tomorrow, the race will move to Monday.（错）→ If it rains tomorrow, the race will be put off till Monday.（对）
