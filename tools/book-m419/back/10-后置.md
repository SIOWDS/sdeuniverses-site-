# 附录

## 附录一　两周小本子

这本书里，好几章的「你可以试试」都是一件很小的事。如果你想把它们串起来，看一看自己家这本账到底长什么样，可以试试这个小本子。

它不是考卷，也不是证据。它只是让你在两周里，每天停下来半分钟，看一眼今天的一件事。

### 怎么用

准备一个小本子，或者就用手机备忘录。每天晚上睡前，挑一件今天和孩子、和家里有关的事，记一行。

挑哪一件都行。可以是接送、做饭、看病、开家长会这种大事，也可以是记得给孩子剪指甲、发现牙膏快用完了、回了老师一句「收到」这种小事。挑那件你今天印象最深的就好。

每一行，记六样东西：

| 日期 | 今天的一件事 | 谁做的 | 有没有人问过「这次谁去」 | 有没有人说谢谢 | 我当时的感觉 |
| --- | --- | --- | --- | --- | --- |
| 10月8日 | 孩子咳嗽，半夜起来喂水 | 我 | 没有 | 没有 | 困，有点烦 |
| 10月9日 | 外婆下午来接孩子 | 外婆 | 我提前问的 | 我谢了外婆 | 松了口气 |
| 10月10日 | 老师打电话说要交照片 | 我 | 没有，电话直接打给我 | 没有 | 习惯了 |
| 10月11日 | 周末带孩子去打疫苗 | 他 | 他自己说他去 | 我说了谢谢 | 有点高兴，又有点不放心 |
| | | | | | |
| | | | | | |

上面几行，只是写给你看个样子。你自己的那一页，一格一格往下填就行。

几点小提醒：

「谁做的」，照实写。是你就写你，是他就写他，是老人就写老人，两个人一起做的就写「一起」。

「有没有人问过『这次谁去』」，指的是事情开始之前，有没有人开口商量过。如果是你自己默默就去了，写「没有」。如果是你开口问的，写「我问的」。如果是他主动说的，写「他说的」。

「有没有人说谢谢」，谁谢谁都算。你谢了他，他谢了你，你谢了老人，都写上。

「我当时的感觉」，写两三个字就够。累、烦、心慌、无所谓、高兴、委屈，都可以。不用写得好看，也不用想很久。想不起来，就写「没感觉」。没感觉，也是一种感觉。

有一天忘了记，也没关系。第二天想起来就补一行，补不上就空着。空着的那一行，也是一天。

记的时候，你可能会犹豫：这件事算不算「一件事」？比如顺手把孩子的水杯洗了，比如在群里回了一句「收到」。算。越是顺手的事，越值得记一行，因为它们最容易被你自己忘掉。

你也可能记着记着，心里有点堵。看见一列一列的「我」和「没有」，会觉得委屈。如果是这样，就停两天，不用硬撑。这个小本子是让你看清楚，不是让你更难受。

### 两周以后怎么翻看

两周以后，找一个你不太累的晚上，把这十几行从头到尾看一遍。

先不用想什么道理，就看看这几样：

第一，「谁做的」那一列，写「我」的有几行？

第二，「有没有人问过」那一列，写「没有」的有几行？这几行里，又有几行，「谁做的」写的是你？

第三，「有没有人说谢谢」那一列，有「谢谢」的那几行，做事的是谁？

第四，「我当时的感觉」那一列，写「累」「烦」「委屈」的那几天，是什么事？是可以等一等的事，比如洗碗、晾衣服？还是等不了的事，比如接孩子、孩子生病、老师打电话？

你可能会发现一些你早就隐约知道、但从来没看清楚过的东西。比如，没人问过「谁去」的事，大多落在你身上。比如，被说谢谢的，常常是外婆、是他，很少是你。比如，你最累的那几天，往往是两件事撞在一起、哪一件都不能等的那几天。

你也可能什么都没发现。你可能会觉得，自己家还挺好的，事情分得也算均匀。那也很好。这个小本子不是要证明你家出了问题，它只是让你看一眼。

### 看完以后

看完了，你可以把它收起来，只自己知道。

如果你愿意，也可以挑一个两个人心情都还不错的时候，拿给孩子爸爸看。不要整本甩给他，也不要一条一条念给他听。你可以只挑其中一行，跟他说：「你看，这件事，我们俩好像从来没商量过。下次要不要先问一句？」

只挑一行。一行就够了。

如果你不想给任何人看，那就不给。这本子是你的，它记下的这两周，也是你的。

## 附录二　给研究者的说明

本附录面向希望了解本书理论来源的研究者与专业读者。正文为面向母亲读者的通俗写作，刻意回避了学术术语；本附录则简要交代本书所依据的母本论文《无人安排的照料：母亲劳动如何被预记为本分》的核心命题、判定方法、可证伪条件与后续研究设计，并说明其与既有文献的分界。以下所述均为母本论文的理论主张与研究设想，尚待系统的经验检验。

### 一、核心命题

**命题一：本分不产生债权，失误产生债务。**母本论文将家庭照料中被默认归属于母亲、且未经明确分配即已由其承担的那部分劳动称为「本分」。其关键特征在于记账上的不对称：本分范围内的劳动，完成时不在家庭成员的互惠记账中形成任何可主张的债权（即不构成「你欠我一次」）；而一旦出现疏漏，则立即形成可被追究、可被长期记忆的债务。正文以「做了不算，错了算」表述这一不对称。

**命题二：三条生成路径。**本分并非由某一次明示的分工决定形成，而是在无人安排的情形下，沿以下三条路径逐步「顺」给某一位家庭成员：（1）身体在场，即在照料需求出现时谁在现场；（2）响应速度，即谁对信号反应最快；（3）信息获取，即谁掌握与照料相关的信息最多。三者相互强化：在场者更早响应，更早响应者积累更多信息，信息优势又进一步提高下次被期待在场与响应的概率。正文分别以「谁先在」「谁先醒」「谁记得」表述。

**命题三：倒签。**当某项照料经由上述路径稳定归属于母亲之后，家庭成员及外部环境倾向于将这一归属追溯性地解释为母亲的天性、性格或能力（如「天生会带孩子」「更细心」）。母本论文借用票据上的「倒签」一语，指这种把事后形成的归属改写为事前既定属性的过程。倒签的后果是使归属脱离其生成史，从而难以被重新协商。本书第14章即围绕这一命题展开。

**命题四：不可错峰任务先裂。**照料任务可按其时间弹性区分为可错峰任务（洗碗、晾晒、整理等可延后完成者）与不可错峰任务（接送、患病照护、学校临时通知、请假等必须在特定时刻由特定的人完成者）。母本论文主张，本分结构所掩盖的分配不公，在可错峰任务上可以被个人的时间调度长期消化；而当两项不可错峰任务在同一时刻到期（例如放学时间与工作会议重叠）时，个人调度失效，原本不可见的归属首次显露为冲突。故本分结构最先裂开之处，是不可错峰任务的同刻到期。

**命题五：报到期。**在干预层面，母本论文提出「报到期」作为最小单位的行动：照料者提前、明确地声明自己在某一具体时点无法承担某项不可错峰任务，并且不自行安排替代方案（即「不补位」）。其作用不在于争辩或求助，而在于使一项此前从未被提问的任务，第一次需要有人回答「由谁来做」。

### 二、判定方法

**（一）分配句与偿还句的拆分。**既有研究常将「是否被感谢」作为照料是否被承认的指标。母本论文主张将两个变量拆开处理：其一为「有无分配句」，即在任务发生之前，是否出现过「这次谁去」一类的显性分配话语；其二为「有无偿还句」，即在任务完成之后，是否出现过感谢、补偿或互惠承诺等话语。本分的识别标准是：无分配句；而偿还句的有无，并不改变该任务的归属。这一拆分使研究者可以区分「被感谢但仍属本分」与「未被感谢但经过分配」两种在既有框架中容易混同的情形。

**（二）本分覆盖率。**在一个家庭的照料任务清单中，计算无分配句的任务数占全部任务数的比例，称为本分覆盖率；并可进一步分别计算可错峰与不可错峰任务的覆盖率，以及各家庭成员名下的覆盖率。附录一所列「两周小本子」即为该方法面向普通读者的简化记录工具，其中「有没有人问过『这次谁去』」一列对应分配句，「有没有人说谢谢」一列对应偿还句。

**（三）三把锁。**母本论文以「三把锁」指认使本分得以维持、且难以通过日常协商解除的三种机制：第一，问句省略之锁，即「谁去」的问题不再被提出，归属因而无从被重新讨论；第二，倒签之锁，即归属被解释为天性，协商被视为违背本性；第三，感激之锁，即感谢话语确认了劳动的存在，却同时确认了劳动的既有归属，使照料者难以在被感谢之后再主张调整。研究者可据此检验具体家庭中何者为主要的锁定机制。需要指出，三把锁是分析上的区分，在具体家庭中往往同时出现、相互加固，经验研究中宜分别编码而非择一归类。

### 三、本分 × 可见性四格

母本论文将「是否属于本分」与「是否被看见」视为两个独立维度，交叉得出四种情形：

1. 本分且可见：劳动被公开称赞，但称赞本身将其确认为应尽之责，如被公开赞誉为「伟大的母亲」。可见性在此不产生债权，反而加重不可抱怨的约束。
2. 本分且不可见：劳动既未被分配，也未被注意，如夜间照护、记忆与规划类劳动。这是照料劳动中最为常见、也最难被测量的部分。
3. 非本分且可见：经过分配或被视为「额外」的劳动，如父亲偶尔承担的接送、祖辈的帮忙，往往获得显著的称赞与记忆。
4. 非本分且不可见：经过分配但未被注意的劳动。母本论文预期此格在经验资料中占比较低，可作为检验框架稳健性的对照格；该预期本身亦有待检验。

这一划分意在说明：增加照料劳动的可见性，本身并不足以改变其记账方式；被看见与被记账是两回事。

### 四、证伪条件

母本论文明确提出以下三条条件，若经验研究证实其中任一条，则相应命题应被修正或放弃：

1. 若发现相较于照料需求出现初期的身体在场、响应速度与信息获取，婚前的性别观念与分工意向对后来的照料归属具有更强、且独立的预测力，则「三条生成路径」命题不成立或须降级为次要解释。
2. 若发现夫妻冲突在任务类型上随机分布，或主要集中于可错峰任务（如洗碗、晾晒），而非不可错峰任务（如接送、患病照护、请假），则「不可错峰任务先裂」命题不成立。
3. 若发现仅增加感谢、称赞等偿还性话语，而任务的实际归属保持不变，照料者的主观疲惫与不公平感即显著下降，则「感激不能改变归属」的判断须被修正，本书关于感谢之局限的论述亦随之失效。

### 五、后续研究设计

**设计一：任务日志研究。**招募有学龄前或小学阶段子女的双职工家庭，由夫妻双方各自独立填写为期两周的照料任务日志，逐项记录任务内容、执行者、事前有无分配句、事后有无偿还句及主观感受。据此计算本分覆盖率，并比较夫妻双方记录之间的差异，以检验本分任务是否在非承担方的记录中系统性缺失。

**设计二：同刻到期的冲突事件研究。**以夫妻冲突事件为分析单位，采用事件回溯访谈或日记法收集冲突发生的情境，按可错峰与不可错峰两类任务编码，检验冲突是否集中于不可错峰任务的同刻到期时点，从而直接回应第二条证伪条件。

**设计三：报到期干预研究。**设计小规模的家庭干预：请照料者在若干周内，就若干项不可错峰任务提前声明无法承担并不补位；比较干预前后该任务的分配句出现频率、任务归属的变化以及双方的主观感受，同时追踪可能出现的副作用，例如家庭关系的过度清算化。本书第23章所讨论的「别把家过成法庭」，即对应这一副作用的观察。

### 七、与既有文献的关系

本书讨论的问题与家庭劳动分工、性别与时间使用、母职意识形态等领域的大量研究相关（参见Coltrane 2000；Sayer 2005；England 2010；Thurer 1994）。在性别如何在日常互动中被持续「做出来」这一点上，本书受益于互动论取向的研究（West & Zimmerman 1987；Ridgeway 2011）；在记忆、规划与预判类劳动的识别上，与关于家务劳动认知维度的研究相呼应（Daminger 2019）。

需要特别说明的是本书与Hochschild关于「感激经济」论述（Hochschild & Machung 1989）之间的分界。该论述强调，夫妻之间对彼此付出的感激存在落差，一方的劳动未能得到对方所期待的感激，由此产生怨怼。本书的判断与此不同：问题并不在于感激的缺位。在本书所描述的许多情形中，感谢是在场的，甚至是真诚而频繁的；然而照料者的劳动依然「不算数」。原因在于，这些劳动在发生之前即已被预先归入本分，其可能形成的债权在劳动发生前已被注销。感谢所确认的，正是这一既有归属。因此，单纯补足感激，并不能改变以后由谁来做。

# 后记　这本书是怎么想出来的

这本书不是从一个故事开始的，是从一篇论文开始的。

论文的题目很长，读起来也很硬，叫《无人安排的照料：母亲劳动如何被预记为本分》。它写给做研究的人看，里面有很多你在这本书里没见过的词。我把那些词一个一个拿掉，换成家里的话，再把它想说的事，放进李静、许慧、韩雪这些人的日子里。所以你读到的每一章，底下都压着那篇论文的一个判断。

那篇论文想回答的问题，其实很简单：为什么一个妈妈做了那么多，却总觉得什么都没做；而她一旦出一次错，全家都记得？

它给出的答案，就是这本书反复在说的那一句：做了不算，错了算。

不是因为哪个丈夫不讲理，也不是因为哪个婆婆偏心。是因为那些事，在她伸手去做之前，就已经被记成了「应该的」。应该的事，做了，账上不添一笔；没做好，账上就是一个窟窿。

把一篇论文改成一本给妈妈读的书，最难的不是把词换掉，是把它的口气换掉。

论文的口气，是站在外面往里看。它说「这种劳动」「这一类家庭」，它要把很多家放在一起，找出一个共同的样子。可一个妈妈翻开书，她不想被放在「一类」里。她想看见的是一个具体的晚上，一个具体的抽屉，一句具体的「那就好」。

所以我定了一个办法：论文里的每一个判断，都要先找到一个家里的时刻，能把它装下。装不下的判断，就先不写。装得下的，就让它藏在故事底下，只在「说破那件事」那一节，用家常话露一个头。

论文还说了另一件事，这件事让我觉得这本书值得写出来：这本账不是铁板一块。它有地方会先裂开。

◆

我想用一个夜晚，把这本书背后的想法讲一讲。

这一段会讲得稍微抽象一点。如果你只想读故事，可以跳过去，不影响什么。

就是第1章里那样的一个夜晚。孩子半夜发烧，咳了一声，妈妈醒了，爸爸翻了个身。

你看这个夜晚，好像什么都没发生。没有人吵架，没有人分工，没有人说「你去」。可是到了第二天早上，一件事已经定了：孩子生病，是妈妈的事。

这件事是怎么定下来的？

这本书背后，有一套专门看一件事是怎么一天一天「发生」出来的看法，叫SDE发生学。它把一件事的来路分成三层：先有一张缠在一起的网，再有一次一次的小差别，最后显露出一个大家都当真的样子。这三层，各对着一个英文字母，E、D、S。下面一层一层说。

第一层，是家里那张缠在一起的网。

孩子的身体，挨着谁睡；夜里谁的耳朵离小床近；体温计放在哪个抽屉，谁知道；明天早上谁要开会，谁可以晚一点到；婆婆住得远不远，能不能来；幼儿园几点开门，生病了能不能去。这些东西，一样一样，都缠在一起。它们不是谁安排的，是日子过着过着，自己缠起来的。

这张网，就是SDE里的E（特征纠缠）。名字听起来很玄，其实就是「家里所有的东西都连着，动一样，别的都跟着动」。

第二层，是一次又一次没有问出口的「谁去」。

那天夜里，本来可以有一句话：「你去还是我去？」可是没有。妈妈先醒了一步，她已经下床了，这句话就没了用处。

第二次发烧，也没有人问。第三次，更不会有人问了。第一次不问，是因为她快；第二次不问，是因为上次是她；第三次不问，是因为大家都知道是她。

每一次没问，都和上一次有一点点不同：上一次还差一点就问了，这一次连想都没想。这些一次比一次少的「差一点」，排成一串，就是SDE里的D（差异序列）。说白了，就是一件事每天被重复一遍，每一遍都比上一遍更像「本来如此」。

第三层，是最后显露出来的那个样子：「应该的」。

到了某一天，你回头去看，会发现家里已经有了一条谁都没写下来、谁都在遵守的规矩。孩子病了找妈妈，老师的电话打给妈妈，鞋码妈妈记得，作业妈妈签字。大家都说，她天生就细心，天生就会带。

这个显露出来的样子，就是SDE里的S（显露）。它看上去像一块石头，一直在那里，好像生来就是这样。

所以把这三层连起来，就是一句话：在家里那张缠在一起的网里，经过一次又一次没问出口的「谁去」，「应该的」就显露出来了。

◆

发烧的夜晚只是一个例子。换成接孩子，也是一样的三层。

许慧的女儿上幼儿园那两年，接孩子的那张网是这样缠的：幼儿园五点放学；她在药房，班可以换；丈夫在单位，走不开；她妈妈还没退休。网里每一根线都不是谁故意拉的，可它们合在一起，就把五点钟校门口那个位置，留给了她。

第一天，也许两个人还说过一句「我能换班，我去吧」。第二个月，已经不用说了。有一回下大雨，她骑车赶到幼儿园，头发全湿了，门口只剩女儿一个人。回到家，丈夫在客厅看手机，听见门响，抬头问了一句「今天怎么这么晚」。那句「谁去」，就是在这两年里一点一点没掉的。

等外婆退休接过去，大家开始说「谢谢妈」。到这时候，那个样子才露了出来：外婆接，是帮忙；妈妈接，是应该。没有人这样说过，可每个人都这样记着。

再换成家长群。

一个班几十个家长，群主是老师。最开始，群里爸爸妈妈都有。老师发通知，谁先回「收到」，谁就会被记住。妈妈手机看得勤一些，回得快一些，老师下一次有事，就先@她。被@了几次，她就更常盯着群。盯得越常，回得越快，老师就越找她。

过了一个学期，你去看那个群：爸爸们都还在，头像都亮着，可说话的、交钱的、报名的、接龙的，几乎全是妈妈。老师打电话，也直接打给妈妈。没有一个人规定过这件事，学校也没发过文件。可它就成了。

再过一阵，连妈妈自己都会说：「群里的事，还是我来吧，他看不懂。」

你看，三个例子，是同一个样子。一张缠在一起的网，一串一次比一次少的「谁去」，最后长出一个人人都当真的「应该的」。

◆

还有一个地方，我想多说一句，就是「天生」这两个字。

到了最后那一层，大家会回过头来说：她天生就会，她天生细心，孩子天生跟妈妈亲。

这话听上去像是在讲来由，好像先有了天生，才有了后来她做的这些。可你要是把日子一天一天倒回去看，次序其实是反的。是她先在那里，先醒了，先记住了，做了几百遍，然后大家才说她「天生」。

第14章里曾琳的故事讲的就是这个。她以前是真的丢三落四。大学宿舍里，室友给她起了个外号，叫「丢丢」；饭卡、雨伞、借来的笔记，她都丢过。后来进了出版社，校稿的毛病是被侯老师一个字一个字骂出来的，可一离开办公桌，她还是那个出门要回去三次的人：回去拿钥匙，回去关燃气，回去拿手机。是有了孩子以后，一年一年，她才成了亲戚嘴里那个「细心的妈妈」。丈夫记得她从前丢三落四，也看见她现在什么都记得，中间那几年是怎么过来的，他不在场。

「天生」这两个字，是事情发生以后，才补签到前面去的。它一签上去，前面那几百遍，就都变得好像不用做也会了。

我觉得，把这个次序摆正，对一个妈妈很重要。它不会让你少做一件事。可它会让你知道，你那份「会」，是一遍一遍练出来的，是算数的。

◆

这个想法里，我觉得最要紧的，是最后那一点：「应该的」看上去是一块石头，其实不是。

它是每天都在重新发生一次的。

今天晚上孩子再咳一声，那张网还在，妈妈的耳朵还是离小床近，体温计还在那个抽屉里。如果今晚她又先醒了，又没有人问，那「应该的」就又发生了一次，又牢靠了一点。

可是反过来说，既然它是每天发生的，它就也可以换一条路发生。

今晚如果有人问了一句「这次谁去」，那条一次比一次少的「差一点」，就断了一下。哪怕最后还是她去，这一次也和以前不一样了：这一次，是有人问过的。

换一条路，不一定要很大的事。还拿那个家长群说。有一天老师发了通知，妈妈看见了，没有先回「收到」。过了一个钟头，爸爸回了。第二天要交的钱，也是他转的。下一次老师有事，也许@的就是两个人。网还是那张网，只是有一根线，换了一个走法。

这就是为什么，这本书没有教你吵架，也没有教你列分工表。第21章里方颖的故事你读过，那张贴在冰箱上的表，三个月以后还在，日子却回去了。因为表上写的，都是已经被看见的事；那些「应该的」，从来没上过表。

这本书最后想给你的，只是一句很小的话：提前说一声「这次我去不了」，然后不要自己去补。

这句话不是在跟谁算账。它只是让一件从来没被问过的事，第一次需要有人回答「谁去」。那张网里，就多了一个以前没有的结。

◆

论文还说，这本账最先裂开的地方，不在洗碗、晾衣服这种事情上。

洗碗可以明天洗，衣服可以晚上晾。这些事可以等，所以再累，也藏得住。它最先裂开的地方，是那种不能等的事：四点半放学，六点下班；孩子烧到三十九度，明天上午有一个躲不开的会；老人病了，孩子也病了，都是今天。

两头在同一分钟等你的时候，你没法用「我晚一点做」把它圆过去。这时候你最撑不住，而你最撑不住的那一刻，其实也是这本账终于撑不住了。

还是拿那个发烧的夜晚来说。下面是一个假设，不是第1章里发生的事。第1章里那天早上，婆婆坐八点那趟车赶过来带孩子，妈妈撑着去开了十点的会，那一分钟就这样被圆过去了。

如果孩子烧退了，第二天是周末，那一夜再累，也就过去了。白天补一觉，谁也不会知道。账还是那本账，可它没露出来。

可是假如第二天上午十点，她有一个必须到的会；假如婆婆那天来不了，幼儿园不收发烧的孩子，丈夫也是九点要到岗。早上七点，三个人站在客厅里，孩子在沙发上裹着毯子。

这时候，「谁去」这句话，就自己回来了。不是谁想起来要问，是那一分钟逼着它回来。以前它可以被省掉，是因为她总有办法把事情挪一挪；现在挪不动了，空位就摆在那里，要有人回答。

那一刻往往很难看。有人着急，有人嗓门大了，有人摔了一下杯子。可是你仔细看，吵的不是这一次谁去，是这几年来，这句话为什么一直没人问。

所以如果你在那样的时刻崩溃过，在车里哭过，在单位的厕所里蹲过，那不是你不行。那是一本记错了的账，在那一分钟露了底。

我写第四辑的时候，心里想的就是这些时刻。

◆

我还得诚实地说一说：这本书可能在哪里错了。

一本书说了这么多「是这样的」，如果不说它在什么情况下不是这样，那它就和那些「当妈就是这样」的话没有分别了。

我想到了三种情况。如果你在自己家里，或者在你认识的很多家里，看见了这三种情况，那这本书就说错了。

第一种：如果大家发现，比起谁先在场，婚前怎么想更能决定谁带孩子。

这本书说的是，谁先在场、谁先醒、谁记得，事情就顺给了谁。如果实际上，那些婚前就说好「我们俩一起带」的夫妻，不管后来谁在家、谁先醒，孩子的事都分得很匀；而那些婚前没想过的，才一路顺给了妈妈——那就是说，真正起作用的是两个人早先的想法，不是这张网。那这本书就把重点放错了地方。

第二种：如果吵架总是随机落在洗碗、晾衣这些可以等的事上，而不是接送、生病、请假这些不能等的事上。

这本书说，账最先在不能等的地方裂开。如果事实上，家里的矛盾和那一分钟的两头等待没什么关系，哪件事都一样会吵，那「最先裂开的地方」这个说法，就站不住了。

第三种：如果光是多说几句谢谢、谁做事不变，妈妈就明显不累了。

这本书在第8章说过，谢谢只是确认你在做，改不了下周的事还是你的；第9章又从另一面看了一次：同一件事，谁做，记法不一样。如果事实上，一个家里丈夫每天真心说几句谢谢，事情一件没挪，妈妈却真的觉得轻松多了，心里那块硌也没了——那这本书就是把谢谢看得太轻了。

如果是这样，那就好了。那说明事情比我想的简单，一个妈妈可以少受很多罪。

◆

还有一件事，是写的时候我一直担心的。

一个人一旦看见了这本账，很容易走到另一头去：什么都要算，什么都要说，今天谁洗碗、明天谁拖地、上周谁接了几次，全都摆到桌面上来。第23章里谭莉走过这段路，后来她儿子问了一句：「你们为什么老在算？」

我不想让这本书变成一本记账的书。

把那句「这次谁去」重新问出来，是为了让该被问的事被问到，不是为了让家里每一件事都过一遍秤。有些事，永远不用算。你半夜给孩子掖被角，他在你生病的时候给你倒一杯热水，这些就让它们在那张网里缠着，挺好的。

账要摊开，是因为它记错了。不是因为一个家，本来就该是一本账。

◆

最后说一说这本书里的人。

李静、周敏、许慧、韩雪、谭莉，还有其他人，她们都不是某一个真实的人。她们是许多母亲合在一起的样子。她们的城市、工作、孩子的年纪，都是为了让故事站得住才定下来的。

她们的故事里，没有坏人。这是我动笔之前就定好的规矩。丈夫、婆婆、外婆、老师、同事，每一个人都有他的道理。因为这本账，本来就不是哪一个人记的。你要是把它怪到某一个人头上，就看不见它了。

第20章写了一个爸爸，高建华。他单位离学校近，妻子常出差，他接了三年孩子，也累，也说不出口。我把这一章放进来，是因为论文里有一个判断很要紧：这本账不是专门对着女人的。谁最近、谁最快、谁知道得最多，谁就会被顺进去。只是在大多数家里，那个人恰好是妈妈。

这本书是写给妈妈的。可如果有一位爸爸读到这里，我也想跟他说一句：你不是她的帮手。你们是同一本账上的两个人。

◆

写这本书的时候，我一直记着一个画面：一个妈妈晚上十点，孩子终于睡了，她靠在床头，拿起这本书，翻开一页。

她很累。她不需要被教育，也不需要被鼓励。她需要的，也许只是有人把她心里那块说不出来的硌，用她自己的话说出来。

如果这本书做到了一点点，那就够了。

如果没做到，也没关系。你把它放下，去睡觉。

明天，那张网还在。可明天的事，还没有发生。
