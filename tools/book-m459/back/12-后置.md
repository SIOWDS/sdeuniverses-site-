## 附录一　术语表（大白话对照）

本表收本卷常用的工作词，每条一句大白话。理论来源见本系列理论总本《SDE符号学：超越皮尔斯的三元与索绪尔的二元》。

### ◆ 一、一张单子上的三种东西

| 本卷用词 | 大白话 |
|---|---|
| 三界符号 | 世界上的痕迹、脑子里的约定、身上的自我认识，三处都会长出符号。 |
| 刻痕（现实符号） | 身体留在仪器上的痕迹，比如一个检验数字、一次测量值。 |
| 标准（理念符号） | 医学约定出来的尺子：参考范围、指南阈值、诊断的名字。 |
| 日子（自我符号） | 病人怎样过、怎样感受，以及"我病了"或"我没病"那份对自己的认识。 |

### ◆ 二、对不上与对账

| 本卷用词 | 大白话 |
|---|---|
| 对不上 | 两栏说的话合不上，比如单子全绿，日子却不对劲；对得上就没有解释，对不上才开始问诊。 |
| 缝 | 两栏对不上的那个地方；本卷的典型缝是病历里同时有"检查未见异常"和"症状持续"两行。 |
| 住在缝里的人 | 指标正常却很难受、落在两栏之间没人接住的人。 |
| 各守一角 | 检验科守数字、指南守标准、病人守感受，没有人专门负责对账。 |
| 对账 | 把三栏摆上同一张桌子，让它们各自说话，把对不上的地方找出来、记下来。 |
| 附闸 | 缝必须事前就能在病历里指出来；事后说"其实早就对不上"不算。 |
| 三栏单 | 一张分三栏的纸：左栏「刻痕」（检查与测量显示什么）／中栏「标准」（指南怎么说）／右栏「日子」（病人怎样过）。 |
| 三问 | ①哪两栏对不上？②这条缝能不能事前指出？③这次谈话谁来付动能？ |
| 对不上登记簿 | 把一时解释不了的缝记下来的本子，下次见面先看它。 |

### ◆ 三、符号怎样成形、怎样凝住、怎样化开

| 本卷用词 | 大白话 |
|---|---|
| 粒子态 | 符号站稳以后的样子：能被反复认出、拆开就不是它、能带去别处。 |
| 三判据 | 稳定、整体、独立：检查一个东西算不算站稳了的三把尺子。 |
| 结晶 | 一堆零散的东西压成一个站得住的符号，比如一条医嘱终于长成了日子里的习惯。 |
| 熔开 | 站稳的符号被新的对不上化开，比如一个诊断被一次认真的谈话重新打开。 |
| 先托住 | 熔开以后不急着马上给出新说法，先让人站得住。 |
| 偶像 | 凝在对象那一端的符号：病人只剩床号加病名，不再被新的情况改写。 |
| 石心 | 凝在自我那一端的符号："我就这样了"或"我没病"，新的话进不来。 |
| 回写 | 新长成的东西反过来改写原来的条件，比如一次对账改了下次门诊的谈法。 |
| 免费衍义 | 再查一项、再加一个说法，看着不要钱，账却转给了病人的焦虑与医保。 |

## 附录二　三栏单模板（医生版、护士版、病人版）

三栏单是一张沟通用的纸，不是病历，不是检查单，也不是诊断工具。它只做一件事：让刻痕、标准、日子三样东西在同一张纸上各自说话，把对不上的地方记下来。用法见第19章，团队用法见第20章。

三栏的名字与三问，三个版本一律相同：

- 左栏「刻痕」：检查与测量显示什么
- 中栏「标准」：指南怎么说
- 右栏「日子」：病人怎样过
- 三问：①哪两栏对不上？②这条缝能不能事前指出？③这次谈话谁来付动能？

# 后记

这本书是王德生"SDE 符号学"系列应用卷的第五本，在全系列里是第十五卷。理论卷讲的是符号怎样发生：世界上的痕迹、脑子里的约定、身上的自我认识，三处都有符号；三者对不上，新的理解才会发生；发生要付力气，会凝住，也会化开。应用卷把这套道理一卷一卷带进日子里：学校、舆论、手机、气候、钱、法律、组织、两代人、城乡、品牌、跨文化的交谈。这一卷带进的是诊室。

书名用的是"病人"，不是"患者"。"患者"常常是表格里的一格，"病人"是一个正在病着的人。全书的判词也只有一句：病人不是一张化验单，也不是一份指南的例外。这句话不是给医学下判语，是给每一张纸提一个醒：纸上的东西再准，也只是一个人的一部分。

诊室是最难写的一处。难不在道理，在分寸。这本书写的是检验单、指南和身体为什么总对不上，可是它从第一页起就给自己划了一条线：只谈医疗沟通与医疗制度，不谈任何一种病。书里出现的检查数字、参考范围、指南阈值，只讲它们作为符号的身份：谁定的，怎么来的，说的是一群人还是一个人。它们准不准，该不该查，查出来怎么办，本书一个字也不碰。所以要在书的最后，再说一遍：**本书不给任何诊断与治疗建议。具体病情请遵医嘱。**

书里的蔡淑贞、杜明哲，以及每一章开头的那些人，都是为了说明而虚构的，不对号入座。他们的下午、他们的门诊、他们手里的单子，是许多人都经历过的样子，却不是任何一个人的病历。书里提到的研究、指南与历史事件，都只转述大意，拿不准的地方标了〔待核〕，留待核验。

写这一卷时，本书一直提醒自己一件事：先把医学对在哪里写足。标准化的检验，循证的指南，知情同意，家庭医生，团队照护，每一样都是许多代医者与病人用代价换来的。本书说"它停下的地方，正好是接着要走的一步"，说的是一步，不是一场推翻。本书不否定循证医学，不替代任何指南，不比较任何医学传统的高下，也不评判任何一国的医疗体制。

本系列的书四《大模型是索绪尔的网、皮尔斯的链：符号在对话中才发生》说过，免费得来的符号结晶不了：别人替你说出的答案，在你身上只是信息。这一条也落在本书自己身上。读完二十二章，读者手里多了一些说法：刻痕、标准、日子，对账，缝，石心。可是如果它们从没在你自己的一次门诊、一次陪诊、一次写病历的时候被用过，它们就还只是这本书的话，不是你的。

所以本书真正想留下的，只是一张纸和三个问题。纸分三栏：刻痕、标准、日子。问题是：哪两栏对不上？这条缝能不能事前指出？这次谈话谁来付动能？附录二把这张纸做成了三个版本：医生的，护士的，病人的。栏名和三问，三个版本一字不差，因为对账要三方说同一种话。三个版本又各有各的提示，因为三个座位看到的东西本来就不一样。它们都只用于沟通，不构成诊断与治疗建议。

这张纸也可能是错的。第21章写下了它怎样才算错：三条可推翻条件，一道必须守住的闸。如果有一天，有人认真做了那些研究，结果对不上，本书愿意按那一章去改。一套说法肯在事前写下自己怎样会输，这是本书从医学那里学来的规矩，也是本书对医学的一点敬意。

这本书的读者，大概会从三个门进来。为自己或家人来的读者，也许最想读的是住在缝里的人、石心、慢病那几章；为医护来的读者，也许会停在问诊的三十秒、坏消息怎么说、三栏单那几章；为医疗制度与管理来的读者，也许会翻家庭医生、病历与知情同意、慢病小组那几章。不管从哪一个门进来，本书都盼着你最后走到同一张桌子前：三栏摊开，各说各的，对不上的地方有人画一条线。

读这本书，也可以用它自己的三问来读。哪一章和你的日子对不上？那条缝，你能不能在读之前就说出来？读完它，谁来付动能？最后一问的答案，只能是你自己。

最后，给每一位拿着单子、日子却和它对不上的读者：你的下午是真的。把它用你自己的话写下来，带去，交给面对面的医生。身体或心里的难处真的大了，请找医生或心理咨询师。具体病情请遵医嘱。
