# 结语　读数之后

## 一、那张账结算的是什么

回到江城那张账。

“本学年实际结余-705.52万元，实际与预算相比多亏损412.14万元。”〔P05·第4页〕

这行字我在导言里放过一次。现在，书写到尽头，我想再认真问一遍：它到底结算了什么？

账面上的算式很简单。收入比预算少得多，费用也比预算少，两头一减，多亏412.14万元。这里有一个结论我当年没有细算：费用省下的部分，只补上了收入缺口的不到六成（第18章算过）。省钱这件事，我们做得很用力，也只填了一半多一点的窟窿。

可是这还不是我真正想说的。我想说的是，这张表从头到尾，结算的是一种账：价格账。学费收进来多少，房租、人力、折旧、经营花出去多少，减一减，得出一个数。

它忠实、精确、不会撒谎，也只能回答这一个问题。这一年孩子们在这里长出了什么，家长凭什么相信，老师的力气花在了哪里，那些账页上没有一格。

所以我才会在表的下面写下那句“总体是节约成本费用的”〔P05·第4页〕。那句话是真的，也是我当时能写出的全部真话，因为我手里只有这一本账。

上一学年的对照让这一点更清楚〔P05·第5页〕：收入涨了，人力和经营费用降了，亏损却从上一年加深到705.52万元。一本只看价格的账，对这种事没有解释，它只能再催一遍：多招，再省。

一本账，只能看见一种亏空。看不见的那几种，就在底下慢慢亏。

账本的盲区不是错误，是它的边界：价格账只认能标价的东西，标不了价的，就从它的视野里整个滑过去。补账的意思，就是为那些滑过去的东西另开一页。

## 二、如果当年有三本账，哪一条先报警

这本书写到这里，我可以回答一个让我睡不踏实的问题：如果2022年我手里有三本账（招生账、清单账、兑现账），有三条方程的读数，哪一条会最先报警？

我的判断是：**那一年亮着绿灯的，恰恰是唯一一条一直在转的方程。**

如果当年有读数，效能再生那一栏几乎会是绿的。成本控制在预算之内，最小亏损，我们做到了。这条方程转得最勤，读数也最好看，可是它告诉不了我们学校是不是在变好。它只会说：账管住了。

如果当年有这些读数，我推想最先报警的会是意义再生。而且它报警的时间，会比财务表早将近一年。

2022年8月，我在江城的另一次汇报里，记录过家长的一个统一感受：和公立孩子对比没有竞争力。我当时的分析，第3章引过：进步和改变在家长看来是应该的，并没有超越期待。

这几句话，用本书的话翻译，就是意义再生的读数：家长复述学校价值的准确度，低；家长感受到的“质的差异”，没有。它比财务表早了将近一年亮起红灯，可惜那时我没有这个词，只能把它当作“口碑问题”去处理。再往下一句我写的是：

“我们不能道德式的自我感动！”〔P10·第19页〕

那一句，我今天依然当作对自己的提醒。道德式的自我感动，就是读数当家的另一副面孔：我们进步了，所以应当被看见。家长不欠学校这个“应当”。

第二个报警的是实践再生。老师的时间被招生、检查、材料占去，孩子卡住的地方没有人长期持有。追踪记录数、无推销续读占比这样的读数如果当年有，我推想它们会在直升率之前先松动。直升率那两个数，在当年被我写成“创校以来最好记录”〔P05·第25页〕，可是它们是读数，不是证据。

最后才轮到招生账，它是最后一个报警的，也是最响的一个。因为它是整条链的末端：意义没有被兑现，实践没有留住人，招生的数字才掉下来。我们那一年把全部力气放在了末端，去拉一个已经松掉了的读数。

如果三本账当年就摆在我桌上，我这一年的力气大概会换一个去处。120家招生合作单位、24场幼儿园活动、三百多条短视频，我不会全撤，招生账照记；但我会把其中一部分时间，换成老师和家长坐下来的一对一，换成每个孩子的那一页来路。

因为意义再生的红灯亮着，实践再生的读数在松，再往末端加力，只会让我们跑得更累。

这就是“读数当家”的代价。体温计显示发烧的时候，病已经在身上好几天了。

书名里说“读数之后”，我要把这四个字交代清楚。读数之后，并不是不要读数。体温计还要放在桌上，招生数、学费、续读率，一个都不撤。读数之后，是读数回到它该在的位置：它告诉我们哪里在发烧，却不替我们决定怎么退烧；它可以报警，却不该当家。当家的是学校对一个孩子的那份持有，是它说出口的话有人取样、有人认账。

有人会问，这样做，招生就不重要了吗？我的回答是，招生很重要，只是它不再是学校唯一醒着的那一部分。一所学校的其他部分都睡着，只有招生办醒着，这所学校就在拿力气换时间，换到时间用完为止。

## 三、下一张账，从哪里写起

书写到这里，该说说我自己下一步怎么做。

我不打算先写一个新的战略。战略的话，导言里那精、亮、硬三件事〔P05·第44页〕，一个字都不必改。要改的，是这三件事靠什么做成，这个答案我当年说不清楚，现在说得清：靠三条方程一起转。

育人质量靠实践再生里的持史，课程特色靠意义再生里的证据，社会口碑靠效能再生里的内能，也就是老师干得有劲、家长信得过。

下一张账，我想从最小的地方写起：一个孩子的一页。

这一页上，没有排名，没有招生数，没有预算。只写三行：这个孩子在哪里卡住过；怎样走出来的，谁在场；下一步往哪里去。一页纸，一位老师写，家长和孩子可以读、可以改。

一个班四十页，一个年级几百页，一所学校几千页。几年以后，这些页攒起来，就是学校真正拥有的东西。招生账会涨落，价格账会吃紧，这些页不会因为一个招生季就没有。

第一个学期，我不会铺开。选两个班，每位老师先给自己带的孩子写一页，一个学期写完，期末坐下来互相读：哪一页写得出来龙去脉，哪一页只有形容词。写不出来的地方，就是学校真正的卡点，那是下一学期的功课。小事从这里做起，账也从这里长出来。

然后才轮到三本账。招生账照记，不撤，它仍是体温计；清单账另列，每一项精细化要求，写明来路、护什么、谁定、哪天复审；兑现账放最后，每学期一页，写学校对家长说过的话，哪几句兑现了，证据在哪，谁取的样。

三本账并排放，不加总，不排名，不拿去考核老师。它们的用处是让下一次的我，不再只握着一本账坐在年终汇报会上。

导言里我写过，那个学期我心里冒出五个念头，从停办初中到立军令状。今天我愿意把它们看成同一个念头的五种说法：我想要一条出路，却只有一本账。

账换成三本以后，这些念头里的大多数，就变成了可以一条一条讨论的事：哪里该停，哪里该留，哪里该请别人接手。不再是一个人在深夜里的“申请”。

写到这里，我想起导言里那个坐下来写汇报的夏天。那时我把财务表原样放在第一页，没有修饰。今天我还是这个做法，只是多了两个动作：把另外两本账也放在旁边，把“怎样算错”写在每一个判断的后面。一个讲兑现的人，自己先把承诺写成能被检验的样子，这是我给自己定的第一条规矩。

这本书读到这里，不同的人手里该留下不同的东西。举办者，留下三条路和那张预案纸；校长，留下三本账；老师，留下每个孩子的一页；家长，留下一个问题：这一句话是谁看见的？每一样都小，每一样都能在这个学期动手。

生源还会继续减少，这是地势，不是谁的错。有的学校会撑住，有的会转型，有的会体面地收场。我没有资格替任何一所学校选路，我只能说我自己的选择：我愿意做那种，孩子毕业很多年以后，还能从学校手里要回一页纸的校长。

那份规划里我还写过一句：

“初心是有力量的！”〔P05·第45页〕

我今天依然这么想，只是要补半句：初心要有账托着。账不替初心说话，却能让初心在下一个招生季、下一次年终汇报、下一个深夜里站得住。三本账，三条方程，一页一页的来路，加在一起，就是我给这半句话找到的托底。

那一页纸，就是我对705万元的回答。

我现在合上这本书，去写新账的第一行。
