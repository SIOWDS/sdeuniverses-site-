# 版本后记

数字重编版 v1.0由全部16项原始材料重新组织而成。正文、长文网页和PDF共用同一份章节文本；网页目录与翻页目录按实际生成结果建立。第220号仅作为出版视觉与阅读体验的参照，本书不借用其卷号、ISBN、署名或出版日期。

本版的医学证据校订，并不表示所有理论命题已经被验证，也不表示已取得外部临床审稿或正式新版登记。它完成的是一次有记录的结构重编、文字统稿与来源核查。读者发现实质错误时，可按书名、版本与章节反馈；后续修订应留下可比较的记录，而不悄悄把旧结论改写成仿佛从未存在。
