# 参考书目　凡引必查

本书谈到的研究，大都来自下面这些书和文章。按作者姓氏的字母排列，每条写作者、年份、题目和出处。本书只引大意，不照抄原文；书页、版次和译本，一律以〔待核〕对待，使用前请对照原书。书里没有引用的，不列进来。
