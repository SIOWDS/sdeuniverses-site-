## 附录 A　预案卡模板

这个附录给两张空白的卡，各配一张用周家填好的示例。四栏版来自 267 附录三，八栏版在 339 第 23 章六栏预案卡的基础上，加了“小账”和“小预言”两栏。两张卡的用途不同：四栏版适合还在想的时候，先把一件事的骨架立起来，缺的栏用问号占着；八栏版适合已经要拿去用、拿去验的时候。周家的示例都是设想，阿乐嗜辣、小满不吃辣是本书新增的设想，外婆的低盐是医生的叮嘱，卡里一律不写盐量、不写任何剂量，饮食上的医疗决定听医生的。

### ◆一、四栏版

**空白模板**

| 栏目 | 填什么 |
|---|---|
| 右端假设 | 先分清哪些是猜的（自己管不着：别人的反应、天气），哪些是许的（自己能定：这一次只试一小份、先问一句）。猜的要写来处，许的要写做不做得到。条件太多时，挑两三个“旋钮”，其余写成一句明说的默认。 |
| 发明机制 | 事情是怎样一步步发生的。对象层写：先动哪一维，后动哪一维，是哪一对矛盾在推。方法层写：选了哪个方程、哪个原理，收窄出哪一两条路径，一冲程还是两冲程。 |
| 左端显露 | 写成一束，至少三种：最可能的（做主方案），最不想要的（设底线），最意外的（别在惊喜来的时候认不出它）。每一种写到看得见。 |
| 路标 | 出现什么大局面，就换方案，或者说明这份推法错了。要粗：一眼看得见、不来回跳、出现了大家不争；要具体：不能写“情况有变就调整”。 |

填写的几点提醒。第一，右端的“猜”与“许”要分开，这是最常被混在一起的地方：把“小满大概不会介意”写成了“小满不介意”，猜就悄悄变成了事实。第二，机制一栏写得越实，越容易看出哪一步会卡住；写不实的地方，用问号占着，不要用“随着事情发展”之类的话糊过去。第三，左端三种显露里，“最意外”最容易被省掉，省掉以后，惊喜或惊吓来的时候没有人认得出。第四，路标一栏至少写一个“该换方案”的和一个“我推错了”的，两个不是一回事：前者是现实走到了另一个路口，后者是这份卡的前提本身有问题。还有一条本书新增的要求：路标尽量立在对方难伪装、要花一点真实代价的动作上，不要只立在“对方说了什么”上。

**周家示例：桌上的一碟腌菜**

这是一个设想的场景。小满爱吃腌的，外婆周桂芳按医生的叮嘱要少盐。这一桌饭，腌菜放在哪里，是一个小小的接缝。

| 栏目 | 内容 |
|---|---|
| 右端假设 | 猜的：外婆不会主动去夹腌菜（来处：她一向守医生的话，但尚未问过她自己怎么想）；小满想吃时不会被人说（来处：他平时吃得自在，但周末有亲戚来时没有过）。许的：腌菜用一只小碟，放在小满手边，不放桌子中间；开饭前问外婆一句“放在这儿您看行吗”。旋钮：外婆的态度。默认：外婆的饮食按医嘱，由她和医生定，这张卡不替她定，也不写量。 |
| 发明机制 | 对象层。小满的“爱吃腌的”（显露）与外婆的“少盐”（医嘱，属于纠缠里的约束）碰在同一张桌上，推出一种新的摆法（做法）。路径取先看约束再定摆法：E→S→D，先问外婆的约束到哪里为止，再看腌菜怎么摆，最后让两人各自显露出自己的那一份。备选路径 D→E→S：先试一种摆法，再看外婆的反应。 |
| 左端显露 | 最可能：腌菜在小满手边，外婆的筷子不去那里，大家无事。最不想要：外婆觉得腌菜被“藏”起来是嫌她，或者小满觉得被嫌“吃得咸”，两个人都不吭声。最意外：阿乐也爱，那只小碟变成两个人的碟，外婆反倒笑着说“你们俩一个味”。 |
| 路标 | 该换方案：外婆连续两次盯着那只小碟看，或把小碟往自己这边挪，则开口问她，不翻页，也不拦。我推错了：如果外婆根本没在意腌菜放在哪里，而在意的是“小满总吃腌的”这件事本身，那么问题不在摆法，格子选错了，要重新问她。涉及她吃什么、吃多少，一律回到医嘱，听医生的。 |

这张卡没有写“外婆应该放宽心”，也没有写“小满应该少吃点”，两句都是劝诫。卡的主语只有写卡的人自己：我把小碟放在这里，我问一句。

### ◆二、八栏版

**空白模板**

| 栏目 | 填什么 |
|---|---|
| 假设 | 本次预案押在哪个右端上；猜的写来处，许的写做得到。 |
| 显露 | 左端的一束：最可能、最不想要、最意外，各写到看得见。 |
| 起手 | 第一步做什么，从对原料或流程侵入最小的做起；写明是不是公开的小试，先说什么，请谁认。 |
| 信号 | 看什么动作判断进展；尽量是对方难伪装、要花真实代价的动作，而不只是一句话。 |
| 换案点 | 信号出现到什么程度，换哪一页，或承认这一页错了；至少写一个“换方案”的和一个“我推错了”的。 |
| 带走的话 | 两三句，写完以后别人能凭这几句复述这张卡。 |
| 小账 | 用了哪个方程、哪个原理、哪条路径；用了第 8 章的哪类技术；这张卡入哪一库，签收人栏是否留空。 |
| 小预言 | 一条或两条可检验的话，带推翻条件。 |

八栏版用法的几点提醒。第一，“起手”一栏逼着人把第一步写出来，这是写预案的人最容易含糊的地方，宁可写小，不要写大。第二，“信号”和“换案点”是配对的：有信号没有换案点，信号只是观察；有换案点没有信号，换案点永远没人知道什么时候该触发。第三，“小账”不是装饰，它让别人能顺着你的账查到你用了什么、没用什么，也是以后合并、互校的依据。第四，“小预言”要能被事实反驳，写“效果会不错”之类的话没有意义，要写“若在某段时间内出现某事，则这张卡错了”。第五，涉及健康、安全的卡，在“带走的话”或“小账”里写明“听医生的”，并注明哪些条目属于底线、不许当场生成，见第 20 章。

**周家示例：周六的火锅**

这是一个设想的场景。周六晚上，周家想吃火锅：阿乐嗜辣，小满不吃辣，外婆周桂芳按医生的叮嘱少盐，林岚这晚不上夜班。

| 栏目 | 内容 |
|---|---|
| 假设 | 猜的：一口鸳鸯锅（一半清汤、一半红汤）能让三个人各取所需，来处是周家以前涮过锅，但没有分过汤（待问）。外婆的汤和蘸料怎么吃，由她和医生定，不在此卡讨论。小满不吃红汤里煮过的东西，这一点是猜的（待问）。许的：周五晚上问小满一次；锅底只备一小份试；清汤锅由外婆定咸淡，卡里不写数。 |
| 显露 | 最可能：清汤那半边小满和外婆用，红汤那半边阿乐用，大家各涮各的，偶尔互相夹一筷。最不想要：红汤飞溅到清汤，小满吃出辣味，从此对涮锅设防。最意外：小满想在清汤里试一点点阿乐的蘸料，自己提出来。 |
| 起手 | 周五先问，不替人定。周六开饭前说一句：今天是试一种分锅的涮法，吃完请你们各说认不认。先用对流程侵入最小的办法：同一口锅里放隔板，各用各的漏勺，红汤那边的东西，红汤一侧的人自己夹。若小满说“有一点辣味我就不吃”，则改成两只小锅。 |
| 信号 | 小满是否敢把筷子伸进清汤锅的公共区域；红汤一侧有没有东西被误夹到清汤里，被谁发现、谁来处理；阿乐是否还要另外加辣油；外婆有没有悄悄往自己的碗里另加调味。看动作，不只听“还行”。 |
| 换案点 | 小满吃出辣味，或明说“锅里有辣味”：下次改用两只小锅，不用隔板。阿乐说“这不是火锅的味”：先问他要的是辣、麻还是烫，再决定是加大红汤一侧的料，还是换一种调法。连续两次试做，两人都没有签收：这张卡的假设有问题，回到“问”。 |
| 带走的话 | 同一张桌，两口汤；分锅放在出锅之前，不放在入口之后。先问再做，先小后大。认不认，由吃的人自己说。 |
| 小账 | D = F（对方的 S，我的 E）：阿乐的辣（S）与小满的舌头（E）矛盾推出分锅的做法；123 原理：第三维是新的涮法，回写后可能改写小满对涮锅的看法；路径 E→S→D。技术：拆分（分锅，同锅放隔板是其中较轻的一种，归类见附录 B 末的说明），转移（蘸料自取）。入周家我库，出处写“预生成”，签收人栏留空，标待验证；辣与不辣各设一条，由阿乐与小满各自签收。 |
| 小预言 | 若这张卡有效，两次试做之内，阿乐与小满各自能说出“这口锅里有我要的东西”。若连续三次试做仍不能让两人同时签收，或者有一人事后说“其实我只是不想扫兴”，则这张卡的假设需要重写。 |

### ◆三、写完以后：四问自查

写完一张卡，拿下面四问过一遍，也可以请别人来问。这四问来自 267 附录三，判的是值不值得押，不是会不会赢。第一问，假设有无根据：每一个右端假设，现在有没有一点痕迹撑着，是有来处的假设，还是随口的愿望。第二问，机制走不走得通：从右端到左端，每一步之间有没有一个能想象的机制，有没有哪一步是跳过去的。第三问，显露推不推得出：推出来的东西是不是写到了看得见，有没有好有坏，还是只有愿望。第四问，路标清不清楚：出现什么大局面就换方案或认错，说得出吗；说不出路标的卡，直接出局。

另外有三种常见的坏样子，对着照一照：写成劝诫，主语都是别人；写成剧本，每一步写到分钟和句子，通篇是“必须”；没有换案点，只写怎么开始，不写什么时候承认这一页错了。好的卡的结尾留的不是“一定”，而是路标：走到哪里，说明我推对了；走到哪里，说明我该改了。

## 附录 B　技术库示例卡

这个附录给第 8 章的五类技术各配两三张示例卡，共十二张。每张卡七栏：名称、机制、做法、验证办法、适用与不适用、边界与风险、依据与待验。“依据”指卡里用到的外部常识，只取常识层面，没有常识可依的栏里写明；“待验”指做法的效果还没有人试过。验证办法都以第 6 章的三个检验为骨架：在场、有差、认得。所有卡都是待验证的，请当作起点，不要当作结论。涉及饮食的卡，凡有医嘱忌口的，一律听医生的，卡里不给量；涉及身体的，一律听医生或教练的，不给处方。人物与场景是设想，康婷、鲍嘉树、蒲永安是本书的设想人物，阿乐嗜辣、小满不吃辣是本书新增的设想。

### ◆一、拆分

**卡 B-1　去筋去籽（辣椒炒肉）**

| 栏目 | 内容 |
|---|---|
| 机制 | 辣这个方面主要附在椒的某些部位上，把这些部位分开，辣降下来，皮的脆和果香留下。 |
| 做法 | 把椒剖开，先去掉白筋（辣主要集中在这里），再去籽，再切；去下来的筋籽单独放，有人要辣，可以加回他那一盘。切的时候别把椒肉刮烂，否则口感的方面也跟着没了。 |
| 验证办法 | 小满先尝，辣是否降到他能接受；外婆看颜色与脆度，香是否还在；阿乐尝，认不认这是他那盘辣椒炒肉。三问缺一不可。 |
| 适用与不适用 | 适用：小满的约束是“别太辣”。不适用：约束是“沾了辣的锅也不吃”，这时要从最前面分锅，叠用办法见本附录末。 |
| 边界与风险 | 去得多了，椒的鲜甜也一起淡了；降得不够，小满吃出辣，会对这道菜设防。若有人因医嘱忌辛辣，听医生的，这张卡不替他定。 |
| 依据与待验 | 常识层面：辣主要集中在靠蒂的白色胎座和白筋上，籽本身并不最辣，只去籽不去筋降辣有限；不同品种差别很大。待验：实际降到什么程度，要在自家的椒上试。 |

**卡 B-2　必做栏与选做栏（作业）**

| 栏目 | 内容 |
|---|---|
| 机制 | 作业里“最低要掌握的”和“想走远一点的”是两个方面，本来就附在不同的题上，把题分成两栏，两种学生各取所需。 |
| 做法 | 设想康婷，42 岁，城区一所初中的数学老师，班里 40 来人，与周家无关。每份作业分必做栏和选做栏；必做栏全班统一，选做栏不计入统一评分，只在自己的小本子上记谁做了、写了什么路数。 |
| 验证办法 | 必做栏是否人人能完成（在场）；选做栏做出来的路数是否各不相同（有差）；爱难题的学生认不认选做栏是自己的地方，而不是一道加班题（认得）。 |
| 适用与不适用 | 适用：同一班里完成速度和兴趣差别大。不适用：必做栏本身就太难，或者老师没有时间看选做栏，那样选做栏只是装饰。 |
| 边界与风险 | 选做栏一旦变成“不做就落后”，就是假出现，假出现的样子见第 13 章（创意分的例子）。要防止选做栏悄悄变成排名依据。 |
| 依据与待验 | 待验：此做法在不同年级、不同班额下的实际效果，需要在真实班级里小试后再下结论。 |

**卡 B-3　通报与讨论分开（会议）**

| 栏目 | 内容 |
|---|---|
| 机制 | 一场会里“让大家知道”和“一起商量”是两个方面，拆开以后各用各的方式，各自的人各取所需。 |
| 做法 | 设想鲍嘉树，34 岁，软件公司后端工程师。每周例会拆成两部分：进度通报改为会前发文字，会上只留讨论。先试一个月，并公开说明是试，请老员工与新人各说认不认。 |
| 验证办法 | 通报文字是否有人读（在场）；会上的讨论是否比以前更实（有差）；习惯听口头通报的人认不认文字也算通报（认得）。 |
| 适用与不适用 | 适用：会议时间被通报占去大半。不适用：团队正处在要靠面对面同步情绪的阶段，比如刚经历大变动，这时通报本身就是讨论的一部分。 |
| 边界与风险 | 文字通报没人读，会变成“通报了但没人知道”；要有一个最低限度的确认办法，比如会上抽一两条问问。 |
| 依据与待验 | 待验：会议的长度与频率因团队而异，此卡不给数字。 |

### ◆二、换种

**卡 B-4　换椒（辣椒炒肉）**

| 栏目 | 内容 |
|---|---|
| 机制 | 同一类原料里，不同品种带有不同量的辣；换一个更不辣的品种，菜的其余方面不动。 |
| 做法 | 把一部分尖椒换成螺丝椒或甜椒，其余做法不变。换之前请吃的人先尝一小口，不单凭名字，因为同名的椒每一批辣度未必一样。 |
| 验证办法 | 小满尝辣度；外婆看香与鲜甜；阿乐尝，嫌不嫌太甜、太淡。换种带来的新毛病，也要问。 |
| 适用与不适用 | 适用：约束是程度上的，有梯度可走。不适用：约束是有无上的，如过敏、医嘱忌口，此时没有“轻一点的品种”可换，听医生的。 |
| 边界与风险 | 换成甜椒以后鲜甜多了，可能有人觉得腻；换过头就成了换菜，越过了换种的边界。 |
| 依据与待验 | 常识层面：甜椒基本不含辣椒素。各地对椒类的称呼与辣度排序不一致，换之前以亲口尝为准，不以名字为准。 |

**卡 B-5　换题材（同一个知识点）**

| 栏目 | 内容 |
|---|---|
| 机制 | 一个知识点可以挂在不同的情境上；学生被某个情境挡住时，换一个他熟悉的情境，知识点不动。 |
| 做法 | 康婷讲比例，原来用水池放水的题，另配一组用球赛比分的题。两组题考的是同一个知识点，并保留一道不换题材的题作对照。 |
| 验证办法 | 学生做对的是不是同一个知识点（在场）；换了题材的学生是不是用了自己的想法做（有差）；学生认不认这就是“那一课”，不是另一堂课（认得）。 |
| 适用与不适用 | 适用：学生卡在情境而不是知识点上。不适用：卡在知识点上，换十个情境也没用。 |
| 边界与风险 | 只会做球赛题，换回水池题就不会，说明学到的是情境，不是知识点；留一道不换题材的对照题，就是防这个。 |
| 依据与待验 | 待验：不同年龄段学生对情境的敏感程度不同，需要小试。 |

### ◆三、后置

**卡 B-6　起锅后分盘（辣椒炒肉）**

| 栏目 | 内容 |
|---|---|
| 机制 | 流程的大部分共用，分叉推到最靠近食客的那一步，让共用的部分里没有冲突的成分。 |
| 做法 | 整锅按不辣的做，起锅后分成两盘，给阿乐的那盘淋辣油或撒辣椒面；共用的那一锅，先请小满尝过，通过了再分。 |
| 验证办法 | 共用的一锅由受约束的人先验，这是后置特有的一条；再看阿乐那盘他认不认。 |
| 适用与不适用 | 适用：约束是“别太辣”，共用的部分不带辣味。不适用：约束是“沾了辣的锅也不吃”，此时共用的锅已被污染，要退回拆分，从最前面分锅。 |
| 边界与风险 | 分盘时的勺子、案板别混用；若有人对某种食物过敏，这张卡不适用，也不许当场生成，见第 20 章。若有医嘱忌口，听医生的。 |
| 依据与待验 | 常识层面：辣椒素是脂溶性的（疏水，在油和酒精里溶得多，在水里溶得很少），辣味会随油扩散，所以辣油能带出辣，也会把辣带进整锅；分盘前别让辣油进共用的那一锅。 |

**卡 B-7　灰度发布（事业）**

| 栏目 | 内容 |
|---|---|
| 机制 | 新旧版本共用同一套基础，分叉后移到“放给谁、放多少”，出了问题可以退回；稳与快因此在同一次发布里并存。 |
| 做法 | 设想鲍嘉树的团队上线新功能：先对内部人员开放，再对一小部分愿意尝新的用户开放，观察关键的出错情况，没有问题再逐步放大。每一步都事先写明退回的办法。 |
| 验证办法 | 出错指标是否明显变坏（稳在场）；尝新的用户有没有得到不同的体验（有差）；用户反馈里有没有“这不是我要的”（认得）。 |
| 适用与不适用 | 适用：新旧版本可以并存，且退回的代价小。不适用：一次性迁移、不可退回的变更，或者涉及安全与账务底线的改动。 |
| 边界与风险 | 样本不典型，会得出误导的结论；放量的节奏如果事先没写，容易在压力下加速。第 16 章有更完整的展开。 |
| 依据与待验 | 待验：放量的比例、观察的时间与指标，因系统而异，此卡不给数字；灰度发布本身是软件行业的通行做法，这里只取思路。 |

**卡 B-8　同一份底稿，最后一稿分版（汇报）**

| 栏目 | 内容 |
|---|---|
| 机制 | 材料与结论共用一份底稿，分叉推迟到“给谁看”这一步，两类读者各取一版。 |
| 做法 | 一份项目汇报，前面的数据、过程、结论共用；最后一步再出两版：一版给要决策的人，只留结论与风险；一版给要执行的人，留细节与步骤。两版都标明出自同一底稿。 |
| 验证办法 | 两版的数据是否一致（在场）；两类读者拿到的是否各自有用（有差）；两类读者是否认这就是同一份汇报，而不是两份说法（认得）。 |
| 适用与不适用 | 适用：同一件事对不同的人用途不同。不适用：两类读者对事实本身有分歧，此时分版会掩盖分歧。 |
| 边界与风险 | 容易被用来对不同的人说不同的话；每一版都要保留回到底稿的路径，别人想核对时能查到。 |
| 依据与待验 | 待验：此做法在不同行业、不同汇报制度下的效果，需要小试。 |

### ◆四、转移

**卡 B-9　蘸碟与桌上调味**

| 栏目 | 内容 |
|---|---|
| 机制 | 把某个方面的“量”从供给的一头转到使用的一头，每个人自己调。后置的分叉在做菜的人手里，转移的分叉在吃菜的人手里。 |
| 做法 | 菜按基础口味做，辣油、辣椒面、醋、酱放在桌上的小瓶小碟里。设想蒲永安（五十五岁，社区老年食堂的主厨）的食堂在每张桌上放小瓶，想重一点的自己加。不监督，不替人决定，也别把某一样刻意摆在某个人够不着的地方。 |
| 验证办法 | 想调的人有没有真的调、调得下口；供给的人有没有暗中施压（在场与有差）；调的人认不认这是自己的口味（认得）。 |
| 适用与不适用 | 适用：成年人，了解自己的约束。不适用：孩子，或不了解自己情况的人；凡有医嘱忌口的，请先告诉服务的人，由医生定，听医生的，食堂另备一份。 |
| 边界与风险 | 转移也把责任转走了，调多了是自己的事，因此对没有判断能力的人不能用；桌上的小瓶不是用来“冲破”医嘱的。 |
| 依据与待验 | 不同调味品的保质与卫生要求，按当地食品卫生规定执行，本卡不写具体要求。 |

**卡 B-10　功能开关（事业）**

| 栏目 | 内容 |
|---|---|
| 机制 | 新功能默认关着，想用的用户自己在设置里打开，量和时机由使用者定。 |
| 做法 | 设想鲍嘉树把一个改版做成可选：老界面保留，新界面是一个开关；开关旁写清楚“这是什么，开了会怎样，随时可以关”；关掉之后原有的数据不丢。 |
| 验证办法 | 开的人有没有真的用起来、关的人是否没有被打扰（在场）；用户是否各自找到了适合自己的用法（有差）；用户认不认这个开关是自己的权利，而不是变相的强制迁移（认得）。 |
| 适用与不适用 | 适用：新旧能并存，成本可承受。不适用：新旧不能并存，或者维护两套的成本压垮团队。 |
| 边界与风险 | 开关多了，设置页成迷宫；默认值如果悄悄偏向新版，就是假转移。要定一个期限，期限到了再商量是否收拢，并公开说明。 |
| 依据与待验 | 待验：维护两套并行版本的成本，取决于具体系统。 |

### ◆五、替代

**卡 B-11　花椒的麻顶辣的劲（慎用）**

| 栏目 | 内容 |
|---|---|
| 机制 | 辣这个方面被挡住时，用另一类刺激感来担“嘴里有劲”这个角色。它和换种不同：换种换同类里的另一个品种，替代换的是另一类东西。 |
| 做法 | 先问阿乐：要的是辣椒素的烧，还是“一口下去有劲、微微出汗”。若是后者，在不辣的那一盘里加花椒，请他尝。若是前者，这张卡不用。 |
| 验证办法 | 在场：有没有刺激感；有差：是不是比原来的辣另有味道；认得：阿乐说“这是我的菜”。替代最容易倒在最后一问上。 |
| 适用与不适用 | 适用：对方要的是一类感受，不是某种具体物质。不适用：对方要的恰好是具体物质，花椒的麻再好，他也不认。 |
| 边界与风险 | 最容易滑向假出现；也不要用“成分上也算刺激”去说服原主。若有人因医嘱忌口，听医生的。 |
| 依据与待验 | 常识层面：花椒的麻感来自另一类成分，作用的感受器与辣椒素不同，麻与辣在感受上是两回事，麻感还可能在辣退后持续一阵。待验：两者能否相互顶替因人而异。 |

**卡 B-12　口头复述代替默写（教学）**

| 栏目 | 内容 |
|---|---|
| 机制 | 默写是为了检验“记住了没有”；对写字有困难的孩子，写字这个动作挡住了检验本身，用另一种载体来担同一个检验。 |
| 做法 | 康婷让写字困难的学生口头复述一遍，再由老师在小本子上记下他说对了哪几条。检验的内容不变，载体换了；其他同学仍然默写，不特别标出谁是谁。 |
| 验证办法 | 复述里该有的内容是不是都有（在场）；学生用自己的话说出来（有差）；学生认不认这就是“过了关”，不是“照顾”（认得）。 |
| 适用与不适用 | 适用：检验的目的是理解与记忆。不适用：目的恰好是练字，此时替代等于放弃。 |
| 边界与风险 | 标准要保持一致，别因为是口头的就放松；孩子的书写困难是否需要进一步支持，听专业人员的意见，这张卡不下判断。 |
| 依据与待验 | 待验：口头复述与书面默写在检验效果上是否等价，视内容而定，需要在真实班级里小试。 |

### ◆六、叠用一例，和卡怎样进谱系条

实际用的时候，卡常常叠着用。以周家那盘辣椒炒肉为例，设想的叠法有两种，对应小满两种不同的约束。

第一种叠法，小满的约束是“别太辣”：先用卡 B-1 去筋去籽，降低整锅的辣度；再用卡 B-6 在起锅后分盘；最后用卡 B-9 把辣油放在桌上，由阿乐自取。三张卡叠在一起，顺序是先动原料，再动流程，最后把量转给吃的人。这个顺序遵守的是第 8 章的那条设想：先用对原料侵入最小的，再用对流程改动最小的，最后才动方面本身。

第二种叠法，小满的约束是“沾了辣的锅也不吃”：先用卡 B-1 或卡 B-4 做出一锅不辣的，单独盛出；再另开一只锅，做阿乐那一份；两锅用不同的锅铲和盘子；桌上仍可放卡 B-9 的辣油，但放在阿乐一侧。这一种叠法最重，用的人也最累，所以只在小满明确说出这条约束之后才用，不要一上来就这样做，那是替他预设了一个比他实际更强的约束。

每张卡用过以后，都要在谱系条上留一笔。出处写“技术库·卡号”，分叉点写它是从周家哪一条做法上分出来的，分叉理由写具体处境（阿乐嗜辣、小满不吃辣），留底标记写原来的做法留了一份，签收人由原主签（辣的在场由阿乐签，不辣的盘子由小满签），版本加一。没有签收人的，是待验的说法；这是 402 第 19 章定的规矩，本书的设想是预生成的卡先落在我库，签收人栏留空，用过、认过以后才填，详见第 9 章第八节。

### ◆七、用卡的几句话

这十二张卡有一个共同的要求：先问哪一维硬，再挑卡。同样是“辣”，小满的约束是“别太辣”，就从后置与转移里取；是“沾了辣的锅也不吃”，就从拆分里取，并从最前面分锅。同样一张卡，换一户人家、换一个班级，哪一栏要改，请照着自己的 E 改，并在谱系条上写明改了什么、为什么改。

卡用多了会长出新卡，这是好事。读者发现一个好办法不属于任何一类，或者同时跨了两类，请记下来，并写明它在哪一类里最不合身。这张清单是一个起点，不是边界；它自己也要接受“拿掉测试”：拿掉这份清单，使用的人还能把一盘菜分成两个盘子吗？能，它就是一个工具；不能，它已经成了指挥。

最后交代两处归类上的不确定。其一，“分锅”一词，有时指同一口锅里加隔板，有时指两口锅，前者更像后置，后者更像拆分，卡里没有强行归并，读者可以按自己的做法归。其二，卡 B-8 的“分版”和卡 B-3 的“分开”，边界并不清楚，一个在流程的末端，一个在内容的中间，若读者觉得该合并，可以合并，只要在谱系条上写明理由。各卡里的外部常识（辣椒素的分布与溶油、甜椒、花椒的麻）只取常识层面，其余都是待验的做法，请当作起点；凡涉及医嘱、过敏、用药和身体的，听医生的，这个附录不替任何人做决定。

## 附录 C　路标索引：全书可检验的小预言

用法：每条预言在正文里有完整的写法（谁来试、试多久、读数、推翻条件）。这里只给索引，方便读者挑一条去试，也方便把试的结果写回。预言一律是设想中的检验，不是已做完的实验。表后有三条使用说明。

| 章 | 想验的话 | 主要读数 | 什么情况算这句话错了 |
|---|---|---|---|
| 导论 | 居中翻译的始终是同一个人（做饭的，或最忙的那位），则此人缺席的几顿饭里，桌上当面的争执或默默的“不吃”比他在场的几顿更多 | 缺席与在场两种饭里争执和不吃的次数 | 两种饭里次数没有差别 |

## 附录 D　接续线与并立线：与尼采、福柯一路谱系学的关系

这篇附录回答一个读者可能会问的问题：本书反复说“谱系”，这个词在尼采和福柯那里已经有一个很有分量的用法，两边是什么关系。先交代用词。本书起初想用“纵线”和“横线”区分历时与共时，核对 402 以后改了：402 里没有“纵线”这个词，而“横线”已经有了固定的意思，指在第 19 章里新增的学派库、行业库两条检索线。为避免读者混淆，本附录改用“接续线”和“并立线”：前者是时间上前后相续的那一条，后者是同一时刻几样东西并排站着的那一条，下面分开讲。正文各章只讲具体的事，没有用这两个词，需要时到这里来查。

### 一、402 对尼采福柯一路的态度

本附录的口径以 402 第 8 章为准，不另立新说。402 第 8 章在讲家谱这一义时，专门谈到来路的两股力量。统一端嫌来路累赘，因为教材把来路拿掉最好用；多元端用来路拆台。后一路就是尼采与福柯一路的谱系学：一个看上去永恒而崇高的东西，追到它的来路上，往往发现是偶然的，是某些利害缠在一起的结果。来路在这里是一把刀，让“本来如此”露出“其实是这样做出来的”。本附录只采用 402 的概述，并对照了福柯《尼采、谱系学、历史》一文的通行提要：他把谱系学描述为追踪来源（Herkunft）与出现（Entstehung），留意偶然与力量的争夺，并拒绝“奇迹般的起源”；尼采《论道德的谱系》（1887）是这一路的出处。402 的概述与这些提要相合。两位各自的具体论证，本附录不展开。

402 的态度有两半。前一半是全盘接住：一个带着来路的同一，首先要经得起来路的拆台，拆完还能站着，才有资格叫同一。后一半是一个具体的不同意：拆台只是一半，拆的手艺极细，装的手艺几乎空白，来路如果只用来拆，拆完就没有下文。402 的说法是：同一件东西，来路向后看是拆，向前看是撑。本书沿用这句话，没有改动，也没有想比 402 走得更远。

### 二、接续线：一个时期的 E 影响下一个时期的 E

接续线是历时的。设想一个时期里，人们的特征纠缠网络，也就是他们的处境、习惯、利害和说法缠在一起的方式，叫它这一期的 E。这一期的 E 会通过人们的做法留下痕迹，影响下一期的 E 长成什么样。由此产生的是 D 与 S 的谱系：差异序列怎样一代代分出去，显露的样子怎样一代代变。这条线向后看，就是尼采福柯一路的工作：从今天的“本来如此”追回去，找到每一次分叉里的偶然与利害。向前看，同一条线说的是：今天做的这些事，会成为明天的来路，所以怎样记、记在谁手里，是要紧的。402 的家谱、谱系条的出处与分叉点、分叉理由，都是接续线上的东西。

用周家的话说：外婆的酱萝卜边上有三行字，每一行是不同的人、不同的年份写的，“第一回放多了，齁”，这条线一路追上去，是谁在什么时候改了盐。这是接续线。402 里的这一段，既拆掉了“盐一把”的天经地义，又撑起了后来每一次减盐的底气。同一桌饭上，外婆低盐、阿乐嗜辣（本书新增的设想）、小满不吃辣（同上）并立，各有来路，各自认出别人碗里的东西，这是并立线。两条线在一顿饭里同时在场：一个在追为什么这样做，一个在安排现在怎么同桌。

### 三、并立线：同一时期的 E 本身谱系化

并立线是共时的，这是本书加的东西。402 的核心判断是同一性不必是一个点，可以按方面逐项调成梯度。本书接着说：同一个时期里，E 本身就可以是谱系化的，也就是说，同时存在高同一的方面（比如安全线，不许谱系化）、中同一的方面和低同一的方面（口味、路线、形式，尽量放开）。由此带来的是同一时期里 D 与 S 的谱系化：同一桌饭、同一间课堂、同一个团队里，几条做法并立，各有来路，彼此看得见。第 1 章写的接缝，就是并立线上不同梯度位置相遇的地方；第 6 章的跨谱再现，则是并立线上的和谐：对方的东西在我这里出现，做法不同，原主认得。

两条线的分工可以用一句话说：接续线回答“这个东西是怎么来到今天的”，并立线回答“今天这几样东西怎样同在一处而不打架”。前者向后看，后者向旁边看。

### 四、两条线怎样互相牵着

两条线不是两件互不相干的事，三大方程和 123 原理在两条线上同时转，所以可以说出它们怎样互相牵着，而不用另做一张对应表。并立线上的一次跨谱再现，就是一次新的分叉：它产生新的做法，新做法按谱系条入库，成为下一期的来路，也就是接续线上的一个点。反过来，接续线上留下的来路，决定了今天并立的几条谱系在哪里分叉、为什么分叉，使并立线上的“认得”有处可查。若只有接续线，会像只拆不装：来路讲得很清楚，今天的人怎样共处却没有答案。若只有并立线，会像没有来路的拼盘：几样东西摆在一起，却不知道各自从哪里来，也就无从互相查错。两条线缺一条，都容易退成 402 所说的三种熄火之一。

### 五、与尼采福柯一路的关系，只落在哪里

可以把本书与这一路的关系说成三句。第一，接住：来路是拆台的刀，本书接受它，并且要求任何同一都先经得起这一刀。第二，不同意只拆不装：来路向前看是撑，所以谱系条里有留底标记、签收人、版本这些装的东西。第三，补一条共时的线：这一路的工作主要沿着时间向后追，本书补上同一时期里几条谱系怎样并立、怎样互相认得，这是并立线。第三句是本书自己的增补，不是对这一路的批评；他们没有处理这个问题，不等于处理错了。这一路是否处理过共时的多元并立问题，本附录不作断言，留给熟悉原著的读者判断。

### 六、一条使用上的提醒

读者若想用这两个词去解构别的思想，需要记住 402 的要求：推演要从三大方程、六路径、123 原理三者出发并同时满足这三重关系，不可以把接续线、并立线当成两栏静态的分类，把材料往栏里一放就算完事。问法应当是动的：这一处来路，追回去看见了什么偶然，往前撑得起什么；这一处并立，哪些方面该高同一，哪些该放开，并立之后原主认不认得。
