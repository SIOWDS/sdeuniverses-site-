# 第31章 本书怎样算错：证据责任与作废条件

假设有一位做了二十年工程的朋友，从头翻到这一编，在页边写了一行字：你说了这么多，什么结果出来你会认错？这个问题问得很对，也问到了一本书最难回答的地方。一本讲"AI加速你的落地"的书，如果任何结果出来都能说"这正好印证了我的看法"，那它说的就不是世界上的事，而是一套永远不会输的话。

前面三章把三方程、六路径、123原理拆开来看，用了不少新词。词多了，最容易发生的事，是读者被气势说服，而不是被证据说服。所以这一章不再添新东西，只做一件事：把这本书哪些话是什么性质、各自靠什么站住、什么情形出现要认错，一条一条写在明处。写在明处的东西可以被人拿去核对，写不出来的，就老老实实写"这里没有办法检验"。

## 五类主张，各有各的账

一本书里的话，性质并不相同。有的是在规定一个词的意思，有的是在做哲学解释，有的是数学上可以证明的命题，有的是关于世界的经验判断，有的是给人的实践建议。这五类话，证明的责任各不相同，不能互相豁免。哲学上的气势不能顶替经验上的证据，形式上的整齐不能顶替实际的验证，一个人的成功案例也不能自动证明一条普遍的道理。把这五类分开，是诚实的第一步。

下面这张表，把本书最重要的几个主张各自归了类。

| 本书的主张 | 主要性质 | 本书怎样对待 |
|---|---|---|
| AI是加速你的落地，不是代替你落地 | 概念规定加经验判断 | "地"的含义是规定；"加速"的部分是经验判断，要查 |
| 人与AI可以形成复合思考体 | 概念规定加经验判断 | 判据与减法检验可查，不能靠宣布 |
| 千倍万倍的思维力 | 经验判断，分三本账 | 量的账与轮的账可到几百倍的量级，判断的账不乘倍数 |
| 竞争搬家到新思想与一轮的快慢 | 经验判断，带预测 | 全部待验 |
| 三方程、六路径、123原理 | 哲学解释与概念工具 | 概念层的用法，不是公式，不是定律 |
| 第七编的各条做法 | 实践建议 | 建议可以试，可以退，不保证有效 |

拿一句话来演示怎样拆。"AI让你的落地更快"，听上去是一句话，其实里面至少裹着三层。"落地"指什么，是一个概念规定，本书规定为想法进入现实并被接住，可以争论定义是否合用，却不能用事实去驳。"更快"比什么快，快多少，是经验判断，要有比较的对象、测量的办法。"所以你应该现在就用"，是实践建议，对不对取决于听的人处在什么境地。三层混在一句话里，听的人就会拿经验的证据去撑规定，拿规定的清晰去顶经验，拿一个人的成功去推荐所有人。把它们拆开写，每层各自负责各自的账，是这一章的基本功。

表里没有数学命题这一栏的实质内容，因为本书没有数学命题。这需要明说，因为三方程写成了带字母的式子，容易给人一种它可以计算的错觉。F、G、H是生成关系的占位记号，没有变量，没有函数形式，没有时间尺度，没有对解的存在和稳定性的任何证明。本书不用它们算任何东西，这个界线不能模糊。

另一种分法，是按依据的来源。本书里的话，有的是对作者自己理论的阐释，有的是写作过程中新做的解释性展开，有的是对外部材料所作的事实判断。三种依据的分量不同。作者理论的阐释，可信度取决于这套理论本身是否经得起检验，写得再通顺也不增加它的证据。解释性的展开，是对着具体案例做的，只在案例范围内有说明力。外部材料的事实判断，只能用到材料所说的范围，不能越出一步。三类依据混在一起，读者就分不清哪句话是靠证据站着的，哪句是靠说得顺站着的。

还有四条论证的边界，一并在这里立下。科学假说保留它假说的地位，不因为讲得动听而升格；数学论证服从明确的定义与条件，条件没写明的地方不借用数学的口气；构造案例只作说明，不当作调查结果；跨领域的相似，只用来帮助提问，成立到哪里要分别去说。整体的视角在这里不能减轻证据责任，只能增加它：如果一个解释在任何结果出现之后，都能把三个维度的位置随意调换，让故事重新讲圆，它就没有经受过检验。

## 案例和数字的身份

本书用到的材料，大致有三种身份，这里分开交代。

第一种是设想的日常案例：小面馆的老板，医院的药师，工厂里用旧表格的员工，等等。它们都是为说明某个机制设想出来的，没有现实中的人名，没有现实中的机构，也没有被调查过。它们的用处，是让一个抽象的关系变得看得见。读者不应该把它们当成发生过的事，更不应该把"书里的小老板最后成功了"当作"这种做法有效"的证据。设想的案例里，作者想让它怎样走，它就怎样走，这本身就取消了它做证据的资格。

第二种是第一人称的经历。书中所说的"我"，涉及的只有作者自己的几条陈述：上午有了一个想法，经过逻辑验证和数值实验，下午合作的实验室就能从十个方案里挑出最可能的去做，从前这样的过程可能要半年到一年；有了灵感，可以马上和AI合作做理念实验，很快成书，从前要半年或几年。这些是作者的陈述，书里没有补任何细节，也没有对它做独立的核实。它们可以说明作者为什么这样想，不能替代对它们的检验。一个人的落地是一个例子，个案的成功不自动证成普遍的道理。

第三种是外部的研究，书里用到的有若干项。它们只在各自所说的范围里站得住。比如，2025年一项随机对照试验里，有经验的开发者在自己熟悉的项目上用AI工具，完成时间反而变长，而他们自己事前和事后都觉得变快了。研究者本人提醒过，结果只针对那一时期的早期工具和那类情境，不能外推到所有人。该机构后来在2026年2月表示，2025年的这个结果已不反映现状，并做了新一轮：57名开发者、八百多个任务，回访的开发者用AI后所需时间约缩短18%，新参与者约缩短4%，两个区间都很宽，都跨过了零，参与者的选择偏差又很严重，所以只是很弱的证据。这件事本身就是一个例子：一项被广泛引用的结果，过了一年，由做它的人自己说明不再代表现状。引用任何研究，都要多问一句，它现在还代表什么。反过来，另一项对咨询顾问的大型实验发现，在AI能力范围之内的任务上，用AI的人完成得更多更快质量更高，在能力范围之外的任务上，反而更容易答错。两项研究放在一起，并没有互相抵消，它们一起说明：加速是有条件的，条件是什么，本身就是要继续研究的东西。至于有一篇很受欢迎的材料科学预印本，后来被所在机构公开表示对数据没有信心，它的教训同样直接：越是我们爱听的结论，越要多查一遍。

"半年缩到半天"这类说法，要拿去测，先得把起点和终点定下来。一轮从哪里算起，是从有想法的那一刻，还是从想法被写成可检验的形式那一刻？到哪里算止，是方案出来，还是现实给出回答？同样一件事，起止点定得不同，倍数可以差出几倍。所以我说的这个量级，本书把它当作一个有待被定义清楚再去测的强判断，既不写成已经测定的数字，也不因为尚未测定就把它写没。

书里所有关于将来的话，全部是待验的预测。这本书没有做过本章后面列出的任何一项对照实验，没有测过任何一组倍数，没有给出任何本书自己得到的实测数字。凡是看上去像数字的东西，不是来自上面所说的外部材料，就是我提出的量级，二者之外没有第三个来源。

## 三个主张，各自怎样算错

这一节是本章的重心。全书的核心主张可以收成三个：加速论，说的是AI加速你的落地；复合思考体论，说的是人与AI可以形成一个有自己产出的思考体；竞争搬家论，说的是方案变便宜之后，差距搬到新思想与一轮的快慢。每个主张要写明：什么结果出现，它就算错，或者要大幅收缩。

先说加速论。这个主张的准确含义，是在AI能力范围之内、有自己的地的人身上，从新思想走到现实回答的一轮，时间会缩短，而且缩短主要发生在想法走到实验台、走到发布之前的那一段。下面几种结果，任何一种出现，加速论就要修改。其一，在满足这些条件的人群和任务里，做一个匹配了经验和任务难度的对照，用AI的一组与不用AI的一组，走完一轮的时间，中位数没有缩短。其二，缩短只出现在"做出来"，也就是方案、原型、稿子的产出，而"落下去"的时间，也就是客户接受、产线跑通、读者实践的时间，被下游的等待和返工原样吞掉，总的一轮没有变短。这种情形，加速论就要降为"加速做出来"，这是一个小得多的主张。其三，在多个领域、多种工具、不同熟练程度的人身上，反复看到用AI的一组整体更慢，并且不能用初学阶段的磨合来解释。前面提到的那项2025年开发者实验，作用是提醒这个主张必须带着条件，它已被该机构自己说明不再反映现状，不能拿来当加速论的反证；新一轮的结果也只是很弱的证据，同样不能反过来当证明。但如果用AI的一组整体更慢的结果，在更新的工具、更多的情境里持续出现，加速论就应该收缩到一个小得多的范围，甚至收回。

千倍万倍是加速论里最强的一句，它的账要分开算。量的账，是同样的时间里能生成和筛掉多少方案；轮的账，是一段人生能走多少轮；判断的账，是选得准不准、问得对不对，这一本账不能直接乘倍数。我的例子里，半年缩到半天，是几百倍的量级，这是轮的账；单轮之内的方案筛选，量的账可能更高。如果有多次独立的测量，在可比的场景下，显示这两本账的倍数远低于文中所说的量级，那么对应的说法要相应收回。如果有人能证明判断的账也能照倍数相乘，本书要改的是另一个方向：那说明本书对判断的谨慎过头了。

再说复合思考体论。这个主张是说，人和AI可以形成一个新的思考体，它做出来的东西，任何一方单独做不出来，而且这个思考体的连续性在人这一边。下面几种结果出现，它要修改。其一，减法检验显示，把AI撤掉以后，同一个人在同一个问题上的后续工作和有AI时没有差别，也就是AI只是帮他省了时间，并没有介入问题的形成，那么"复合"就是一个夸大的说法，准确的名字是工具。其二，换人检验显示，同一个AI换给不同的人，工作轨迹和产出看不出可以区分的差别，也就是所谓"这个思考体的连续性在人这边"，找不到任何痕迹，那么第8章的判断要撤。其三，把"复合"与"只是调用"的两组放到现实面前，比如让客户、读者、实验台来回答，二者没有差别，那么复合的价值论就站不住，只剩下一个概念上的区分。其四，用本书给出的判据去判断，几位彼此不知情的评判者给出的结论差异很大，没有一致性，那么这些判据就没有可操作性。

最后是竞争搬家论。它说的是，方案便宜以后，能不能落地不再是分水岭，差距搬到两处：有没有新思想，以及新思想变成方案并拿到现实回答的一轮有多快。以下结果出现，它要修改。其一，在AI普及之后的某些行业，方案的成本明显降下来了，但竞争的结果仍然主要由能否做出方案、产能、资金这类东西决定，那么搬家没有发生，至少在这些行业里没有。其二，新思想并没有变得稀缺，相反，AI能廉价地大量生成新思想，而且这些新思想也被现实接住了，那么搬家的第一处就错了。其三，一轮的快慢与竞争结果之间没有关系，竞争由渠道、监管、资本这些别的东西锁定，那么第二处就错了。瓶颈搬家本来就是书里讲过的现象，一条流程的产出由最慢的环节决定，在非瓶颈处提速不增加总产出；如果这一条在大量行业里把"快"的优势全部抵消，竞争搬家论就要缩到很窄的范围里。

还要交代一下"算错"的几种程度，免得读者以为只有生与死两种结局。一个主张遇到不利的结果，可以有三种处理：收缩，把适用的范围缩小到结果仍然支持的那一块；降级，把一个强主张换成一个弱得多的说法，比如从"加速落地"降到"加速做出来"；撤回，整条收回，不再主张。哪一种取决于不利结果的范围和稳定程度：只在个别领域出现的，收缩；在多处稳定出现的，降级；在满足全部前提条件的地方依然出现的，撤回。预先把这三档写下来，是为了在结果出现的时候，不临时去找一种最体面的说法。

三个主张之间并非互不相干。若加速论的第二种情形普遍成立，竞争搬家论的第二处就跟着塌；若复合思考体论的第一种情形成立，那么本书所说的"千倍万倍的思维力"就只剩下工具的省时，前面三编大半要重写。所以这三条作废条件不是各自独立的免责声明，是一张互相牵连的账。

## 本书自己的出身

最后要说的，是这本书自己。这本书由我与AI合作写成，各章由同一底座的多个AI智能体分头起稿。有人可能会觉得，这本身就是对书里主张的一种证明：看，人与AI合作，写出了一本二十万字的书。这个推论不成立，必须明说。

过程复杂，不证明命题正确。一本书是否由人和AI合作写成，与它说的话对不对，是两件事。合作写成的东西，可以是一本好书，也可以是一本把话说圆了的错书。大模型会编造，会迎合，会把一个错误的论断说得头头是道，一群同样底座的智能体把话说得彼此呼应，只能说明它们是同一个底座，不能说明话是对的。同一底座的多个智能体不能互作独立证据，多个窗口也不等于多份证据，各章之间读起来的一致，最多只是内部整齐，距离经受检验还很远。如果评审也由同一底座的模型来做，同样不算独立。

还有作者自己的位置要交代。作者有一个想让它成立的结论，这本身会影响取材和措辞。作者的专著落地，是一个案例，也只是一个案例。这本书作为人与AI合作的产物，既可能成为支持这些主张的材料，也可能成为反例，这要由读者和现实来裁定，不能由书自己宣布。

读者读这本书的时候，也有一个防备的办法。大模型参与写作的文字，容易写得流畅、对称、前后呼应，读起来格外顺。顺本身不是错，只是读者不应该把顺当成对。可以在每一个关键判断后面问两句：这句话说清楚了什么情形下它会错吗？它依据的是作者的理论、设想的案例，还是外部的研究？答不出来的地方，就是这本书最该被你划掉或者追问的地方。

什么样的东西才算独立的证据？大致有这么几种。读者在自己的地上走过一轮之后留下的记录，里面有哪些做了、哪些没做、现实怎么回答。换了不同的人、不同的底座，在同样的任务上重复，看结果是否相同。实际做出来的对照，比如匹配过经验的两组，一组用一组不用。以及失败的案例，被公开的失败，比成功更值钱。这些东西，本书都还没有，要靠读者和后来的人去积累。

## 读者的账本

最后，这一章可以变成读者手里的一张小表。在读完这本书之后，不妨拿出一页纸，写下三件事：你准备用这本书的哪一个判断去做哪一件具体的事；你预期它会带来什么，写成一句可以被事实否定的话；到什么日子回来对一遍。比如一位开小店的读者可以这样写：我准备用第29章的办法，先读出任务的形状再向AI提要求；我预期这个月里，我为同一件事被现实退回的次数，会比上个月少；三十天以后，我对一对退回的记录。这句话可以被事实否定，也可以被别人重复检查。写成"我希望自己变得更高效"，就没有人能说它错，也就没有人能说它对。到期以后，对着现实看，对了，记一笔，错了，记两笔，哪怕这意味着书里的某个说法应当被你划掉。一个主张是否有价值，不在它听起来多有道理，在它面对现实的时候肯不肯输。这本书希望自己是肯输的那一种，也欢迎读者把输的记录寄回来，因为一本书最好的修订，往往来自一个它没有想到的失败。

## 本章怎样会错

如果读者发现，本章列出的作废条件在实际中无法操作，比如"匹配了经验的对照""独立的测量"根本找不到可行的做法，那么这些条件就只是一种姿态，等于没有立。如果有人指出，本书某个核心主张在上面的作废条件下任何结果都不会被判错，那么这个主张就需要重新写，写到有可能被判错为止。如果本书关于五类主张的归类被证明混乱，比如把应当属于经验判断的话放在了概念规定里躲过检验，那么表里的相应一行要改。

## 带走一句话

一本书说得再圆，也要写明什么结果出来就算它错，而它由人和AI合作写成这件事，不能替它作证。
