## 三、整理规则
1. **段落**：原稿常把一句话拆成一行。连续几行若合起来是一段话，并成一段（一段一件事，通常 2–6 句，过 150 字拆开）。判断句、结论句可单独成段。真正的并列清单（如「1. 差异条件……2. 稳定条件……」）保留为列表，写作 `1. ` / `- `。
2. **标题层级**（严格用下面的记号，我会程序化组装；章号、篇号**不要自己写**）：
   - `# [篇] 篇题`（只有你这一段里出现篇的起头时才写；篇题去掉「第一篇：」前缀。紧接一行 `副题：……` 若原稿有「副标题」）。
   - `## [摘要]`、`## [引言] 引言题`（无题则 `## [引言]`）、`## [编] 第一编　编题`（篇内的「第一编、第二编」分组，只写分组标题，下面接章）、`## [章] 章题`（章题原文，不含「第一章」前缀；若原题有「（约5000字）」类尾巴去掉；章题被 PDF 折成两行的合成一行）、`## [结论] 题`（章题可保留，如「结论：时间不是先天形式……」这类**小节内的结论句**不是章，别升级）、`## [后记] 题`、`## [附论] 题`（附录 / 前奏 / 预告 等篇后附件，题去掉「附录 N：」前缀）。
   - 章内小节：`### ◆ 一、小节题`（保留「一、二、」序号；原稿「1.1」「（一）」类二级小节用 `#### 小标题`，去掉数字前缀；1. 2. 3. 标签式短行如「1. 常识的答案」若后面跟着解释段落，用 `#### 常识的答案`）。
   - **不要**用 `---`、`◆` 独行或表格以外的其他标记。
3. **引号**：中文引号用「」，内层用『』。原稿的 “ ” ‘ ’ 一律换掉。书名号《》。破折号用「——」，区间用「—」（1901—1926）。省略号用「……」。
4. **术语统一**（不得改义，只统一写法）：特征律（原稿偶写 WDS特征律，保留首次出现的「WDS 特征律」亦可，其后写特征律）；SIO（主体—互动—客体整体）；ΔSIO；差异稳定性；意识同一性；混沌—自组织—涌现（正文用此写法；流程式里可用 `混沌 → 自组织 → 涌现`）；自由律、幸福律、三律；发现学／发生学；必然学；屠龙刀；三界意义的死亡。S、I、O 三大意识。
5. **公式**：单独成行的公式写成 `$$ ΔSIO ≠ 0 $$`；行内的公式照写，不加记号。保留 ΔSIO、|d(ΔSIO)/dt| < ε、⇒ → 等符号。
6. **👉 标记行**：去掉 emoji。若是一节的收束判断，且不超过 40 字，写成单行引用块 `> **判断句**`；其余并入上下文段落。**每 3000 字至多 3 个引用块。**
7. **加粗**：只用于真正承重的判断句，每 3000 字不超过 3 处；成对写 `**…**`，不要出现单个 `**`。
8. **并列对照**：「常识说……／特征律说……」三组以上平行的，可改成两列表（`| 常识 | 特征律 |`）；少于三组不要改表。
9. **语气**：这是作者的论战文体，保持其锋芒与节奏。但原稿有大量「不可思议、美妙、伟大、革命性、奇迹」之类的重复赞叹——同一段里连续出现的，保留最有力的一处，其余删掉或改平；不加感叹号。句末不用「！」。
10. 句子过长（60 字以上）而又明显是几个意思连在一起的，拆开。不要使用「首先……其次」「综上所述」「值得注意的是」。
11. 每个章节开头一句不得是工序话（「本章将……」可保留为作者原有的路线说明，但去掉「约 N 字」）。
