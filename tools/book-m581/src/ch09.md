# 第9章 谱、主通道与支配的数学判据

## 一、七百格的压缩问题

上一章结束时，权力已经躺在一张 27×27 的表里。诚实带来了新的困难：七百多个格子，逐格盯视超出任何分析者的工作记忆。汇总吗？范数的三道警戒刚刚立过——粗暴求和会把要命的格子淹死在平庸的格子里。需要的是一种不失真的压缩：既把表收拢成少数几个可把握的量，又保住表里最要紧的方向信息。线性代数为这件事准备了现成的刀，刀的名字叫谱。

## 二、奇异值分解：权力的主通道

任何矩阵都可以做奇异值分解：

J^(A→B) = U Σ Vᵀ。

不必被记号吓住，它说的是一件极具体的事：任何一张影响表，都可以拆成若干条互相独立的“输入方向→输出方向”通道，每条通道带一个放大倍数。Σ 对角线上从大到小排着放大倍数 σ₁ ≥ σ₂ ≥ …（奇异值）；V 的第一列 v₁ 是 A 侧的最优发力方向——A 把单位力气按 v₁ 的配比分配到自己的各角度上，对 B 造成的总改变最大；U 的第一列 u₁ 是 B 侧相应的主变形方向——B 被改变时，变化主要沿这个角度组合发生；σ₁ 就是这条主通道的增益。

主通道回答的正是实践者最想问的问题。对强侧，v₁ 是省力学：想改变对方，劲往哪组角度使最划算。对弱侧，u₁ 是自我诊断学：我被改变时，究竟是哪一组角度在联动变形——很多人只感到“被拿捏”，却说不出被拿捏在何处，u₁ 把这份弥散的受制感定位成具体的角度配比。次通道 (σ₂, v₂, u₂) 以下依次减弱，通常头两三条通道已携带矩阵的绝大部分能量。

方向性权力也随之升级为矩阵版。以主增益之比定义

P_spec = ln[ σ₁(J^(A→B)) / σ₁(J^(B→A)) ]，

它比较的是双方各自最强通道的悬殊。要紧的提醒：不同范数、不同奇异值截断给出的汇总各有偏重，报告时必须写明所用口径——口径本身没有中立的选法，这一点将在本章第六节升级成一个理论命题。

## 三、各向异性：权力长成什么形状

奇异值的衰减速度刻画权力的形状。定义条件数

κ = σ₁ / σ_r

（最大与最小有效奇异值之比）。κ 很大，说明改变能力高度集中在一两条通道上——这样的权力有“七寸”：打蛇打七寸，谈判找主通道，监管掐主阀门。κ 接近一，说明改变能力在诸角度上近乎均匀铺开——这样的权力没有七寸，它弥散、冗余、切一刀换一处。上一章“集中与弥散”的定性讨论，在此获得刻度：现代平台权力之难治理，谱语言的说法是它的 σ₁ 与 σ₅ 相差无几——你封掉主通道，次通道的增益几乎不减。

## 四、回路矩阵与谱半径：支配的数学判据

现在处理上一章留下的回路问题。A 改变 B，B 也改变 A，扰动便在两者之间来回反射。从 B 侧看，一圈往返的合成矩阵是

L_B = J^(A→B) · J^(B→A)：

B 的一个扰动先经 J^(B→A) 传给 A，A 的响应再经 J^(A→B) 打回 B。这张回路矩阵的谱半径 ρ(L_B)——其特征值的最大模——裁决这段关系的整体性格。ρ < 1：来回反射逐圈衰减，扰动被关系吸收，格局可自我恢复；ρ > 1：存在某个扰动模式，每转一圈被放大一次，微小差异被回路指数化——直到非线性饱和或关系本身重构为止。

这里藏着一条值得单独镌刻的数学事实：矩阵乘积 PQ 与 QP 的非零谱相同，所以

ρ( J^(A→B) J^(B→A) ) = ρ( J^(B→A) J^(A→B) )。

翻译成权力语言：回路增益属于关系本身，由双方共享；不对称并不住在回路里，而住在单程增益里。“这段关系是自我放大的”是关于关系的判断；“放大偏向谁”要另看 σ₁(A→B) 与 σ₁(B→A) 之比。两问分开，许多混战自动散场。

回路矩阵还解释一桩人人经历却少被解释的现象：为什么长久的关系总沿同一条沟渠反复冲突。线性代数里有一条朴素定理：把同一个矩阵反复作用于几乎任意的初始向量，向量的方向会收敛到该矩阵的主特征方向——此即幂迭代。一段关系年复一年地转着同一个回路 L，等于在对彼此的扰动做幂迭代：无论这一回的争执由什么鸡毛蒜皮起头，来回反射几轮之后，它的方向总被拧回 L 的主特征方向上——那对夫妻永远吵回“你根本不尊重我的工作”，那对母女永远吵回“你从来不相信我”。主特征方向，就是这段关系被回路选中的裂缝。定理顺手交出干预的靶点：调解若只处理本次争执的内容（那只是初始向量），下一轮迭代照旧收敛回老地方；有效的干预必须改动 L 本身——改动的不是这次吵什么，是双方互相改变彼此的方式。

于是支配第一次获得完整的数学判据，三个条件缺一不可：其一，回路自增强——ρ(L) > 1，差异被关系放大而非阻尼；其二，增益偏向——单程主增益显著不对称，放大出来的差额持续落向同一侧；其三，沉淀锁定——每轮放大的所得被写进规则、身份与基础设施（E），使矩阵本身逐轮变得更不对称。第三条已经越出静态谱的地界，它是下一章的正题；但判据必须现在就完整立起，因为只有三条合璧，才配得上序言埋下的那个词：持续、稳定、可复制的不对称性改变。

## 五、反馈时代的总效应：尼曼级数

回路不止改变性格，还改变账目。给 B 施加一份外部扰动 δ，若无反馈，B 的改变就是 δ；有反馈，δ 经回路一圈变成 L_Bδ，两圈变成 L_B²δ……全部圈数加总：

总效应 = (I + L_B + L_B² + …)δ = (I − L_B)⁻¹ δ，

级数收敛当且仅当 ρ(L_B) < 1。这枚公式两头都锋利。收敛侧，它说任何一次干预的真实效果都不等于其直接效果——评估政策、审计算法、衡量一句话的分量，都必须乘上 (I − L)⁻¹ 这枚反馈放大镜；直接效应微弱而回路增益接近一的干预，总效应可以大得惊人，这是“四两拨千斤”的线性代数。发散侧，它说当 ρ ≥ 1，这段关系不存在线性意义上的均衡——总效应没有有限值可收敛，关系不会停在原地，它必然走向重构：或者非线性机制出面封顶，或者结构断裂。谱半径穿过一的那一刻，就是第十章将要讨论的相变临界。

## 六、加权矩阵与元权力

最后补上被一路悬置的伦理维度。以上全部谱量默认各角度等权，而第八章早已声明：角度的伦理分量不可通约。补救的形式手段是加权——选权重矩阵 W，对加权矩阵

W_B^{1/2} J W_A^{-1/2}

做同样的谱分析，让“改变一个人的自我价值”在账面上重于“改变一个人的片单”。但这一补救立刻暴露一个更深的事实：W 没有中立解。谁来决定幸福折多少分、尊严折多少分？谁的角度被计入、谁的被省略？定 W 的那只手，行使的是对权力测量本身的权力——本书称之为元权力。它不是形式化的瑕疵，而是形式化替我们揪出的真问题：一切排名、指数、评估体系，都内嵌着一位不署名的 W 制定者。这条线索在第十二章（测量）与第六卷（计算权作为三大主权之一）两度回收。

## 七、案例：平台—创作者关系的谱解剖

给全章工具做一次连贯演练。设 A 为内容平台，B 为百万创作者构成的群体系统。估计 J^(A→B)：平台侧微调推荐权重、分成比例、限流规则（其 v₁ 大致落在“数学、节奏、分布”的角度配比上），创作者侧的联动变形 u₁ 横跨收入、选题、发布节律、情绪与自我认同——σ₁ 巨大。反向 J^(B→A)：单个创作者的抗议、迁移、内容创新对平台参数的改变率微弱，σ₁(B→A) 很小；P_spec 显著为正。回路 L：创作者行为生成数据，数据回灌推荐模型，模型再改写创作者行为——回路增益在若干内容品类上明显大于一（同质化的指数繁殖即其表征），且每轮所得沉淀为平台侧的数据资产与规则修订权：支配三判据全部点亮。条件数 κ 则解释了监管的疲惫——限流、分成、算法透明度各管一条通道，而平台的次通道增益紧咬主通道，掐住一处，支配从旁边流过。这份谱报告同时给出弱侧的行动坐标：单点抗议打不动 σ₁(B→A)，能打动它的是改变回路结构本身——集体议价（把万千小 J 并联成一个大 J）、数据可携带（削平台的 E 沉淀）、多宿主经营（给自己的 u₁ 减耦合）。工具第一次显出它的双刃：谱既是强者的省力学，也是弱者的战术图。

## 八、快照的极限

谱分析把一张表压缩成几条通道、一个回路增益、一枚方向指针，静态解剖至此完备。但“静态”二字本身就是罪状：矩阵是切面，权力是历史。σ 与 ρ 都是此刻的读数，而昨天的强者今天崩塌、三十年的支配一夜清零、微弱的萌芽七年后长成新的中心——这些才是权力最需要解释的现象。J 如何随时间漂移？ρ 何时穿过一？不对称如何建立、靠什么惯性维持、在哪种信号之后反转、以哪几种方式死亡？下一章，给权力装上时间。
