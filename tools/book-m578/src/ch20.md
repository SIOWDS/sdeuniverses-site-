# 第20章　表面五花八门，下一步只有一个

## 回转寿司的传送带

你吃过回转寿司吧。一条传送带在桌边慢悠悠地转，一盘一盘过来：三文鱼，玉子烧，炸虾，小蛋糕，没有一盘重样。你本来只想吃两盘，可是传送带不停，你的手就不停，盘子叠起来，一抬头发现已经吃了十二盘。你并不是特别爱吃哪一样，你吃的是“下一盘”。

内容永远在换，手上的动作永远是同一个：伸手，拿，吃，再伸手。如果你问这个人今天吃了什么，他能说出十二样不同的东西。如果你问他今天下一步往哪儿去，他会说：下一盘。

苏晴戒烟满六个月以后，夜里常常是这个样子。她的工作到十一点多收个尾，人坐在沙发上，手机握在手里。她先看一会儿新闻，一条一条往下滑，滑到一个好笑的短片，笑了一下，接着又滑；中间跳出一条同事发来的消息，她回了；回完发现旁边弹出一个她收藏过的商品降价；她点进去，看了看，退出来；又回到那条滑动的流里。一个钟头过去，她看了上百条东西，没有两条是一样的。可是她若被人问一句“你这一个钟头在干什么”，答案只有一个：我在等这一晚上结束。

这就是这一章想说的：**从内容看，每一次都不一样；从下一步的去向看，每一次都回到同一个地方。**表面五花八门，下一步只有一个。有的平台把这件事做成了设计，一个内容的结尾，被安排成下一个内容的入口，结束就是开始，满足就是继续。没有人是在被强迫，每一下都是自己的手滑的，只是在这样一条传送带上，很难有一个自然的“离场时刻”。这一点不能怪到苏晴一个人头上，她面对的是一整套为了让人留下来而精心安排的东西，可她也不能因此什么都不做，因为留下来的毕竟是她的夜晚。

还有一层更隐蔽。每滑完一阵，苏晴那种空落落的感觉确实缓了一点，所以她觉得这个晚上被打发过去了。可是第二天晚上，那种空落落来得更快，她忍受它的时间更短，手机伸得更早。这就是后面要讲的“做完不销账”：这一次的缓解，没有把账销掉，反倒成了下一次的开头。结束是个伪结束，它结束了眼前这一刻的不适，却没有恢复她面对不适的别的办法，下一次空白还没来，她就已经不太敢让它空着了。

艺术和平台的差别，还有一个很容易看出来的地方：一部好电影放完，片尾字幕会走，灯会亮，你要起身，整理外套，想一想刚才看到的东西，这个“起身”是形式自己给你的出口。传送带式的设计偏偏把这个出口拆了，让人没有一个可以自然站起来的时刻。苏晴有一次想看完最后一条就睡，可是“最后一条”没有定义，每一条看完，下一条都已经在那里，等着当“最后一条”。

## 先把那些高频的人接住

读到这里，会有人感到紧张：这样看，岂不是所有重复的、沉浸的、固定顺序的事情都可疑了？一个人天天练琴，一个人几年磕一个数学猜想，一个母亲日复一日照顾老人，一个人每天按时做早课，都是高频，都是固定顺序，都能让人暂时忘了自己。

先把话说在前头：这本书不这样看，而且必须不这样看。艺术给这个问题带来了一个特别硬的反例。一首诗，词序不能打乱；一部交响乐，要从头到尾经历；一段舞蹈，要把动作练到身体自己会，一个读者可以连着几个小时待在一部小说里出不来。它们严格，反复，沉浸，却没有人说它们是病。那篇长文里有一条朴素的话，值得抄在本子上：强度本身不是罪名。

那么，这些高频的人和被预占的人，差在哪里？差在事情做完以后。练完琴的人会去买菜、接孙子、给学生回信，琴房漏水了，他换去散步。他做的事严格，但他做完以后，未来是还给生活的。读完一首诗的人常常合上书，看着窗外，对爱情、对失败、对死亡有了一点不同的想法。这些活动会把你关在里面一小会儿，出来的时候，世界反而宽了。被预占的位置相反，一次做完，下一次更窄地往同一处收，别的事只剩下“间歇”的身份，是两次回到这件事之间的空档。

做早课的人也是一个好例子。一位老太太几十年每天清晨念同一段经文，次序一字不差，从来不换。可是念完以后，她去给邻居送一碗粥，和老姐妹聊聊天，下午带着孙子去公园。经文的次序是固定的，她的下一步是散开的。固定和封闭，是两回事。

为了防止这套说法被用得太宽，这本书依据的那篇长文给了四条必须同时具备的特征，缺一条，就不该拿它来叫某个人。对象不在了，行动的方向仍然没有放开；占位的东西在身体、一句话、一个动作之间换手，却总接到同一个终点；做完一次并没有把账清掉，反而成了下一次的开头；别的方面的代价已经出现了，健康、家庭、钱、脸面，那个方向仍然保持着优先。用大白话说，就是东西走了位置还空着，换了人还是那件事，做完不销账，赔了也不退场。四条合起来，才是我们说的预占。

## 苏晴的“工作到凌晨”，算不算

现在可以回过头看苏晴最让人拿不准的一件事了。她戒烟以后，睡得更晚，工作到一点是常事。有人说，这是用工作代替了烟，是换了一副面孔。有人说，这是她事业心强，是好事。这本书的立场是，两边都不要急着说。

我们用上面的四条和上一章的办法来问她。第一，对象不在以后，行动的方向有没有放开？有一半，她下午四点的空还没填上，这一条她部分符合。第二，换手没有？有的，从烟到手机到购物页面到加班，几棒接力都看到了。第三，做完清不清账？这一条最要紧：一个晚上工作到一点，做完以后，她第二天的未来是更宽了，还是更窄了？她的回答让人稍微松一口气：周末她会去爬山，约朋友，睡到自然醒，周一的会开完，她也不是每次都往那个方向去。第四，代价到了，退不退场？她的体检单上睡眠的项目亮了灯，她已经把周三晚上定成了无工作日，坚持了五周，只破过一次。

这里面有一个细节值得讲。那个周三晚上的“无工作日”，是小周提议的，起因是有一天小周发现她半夜一点还在线，问了一句，你这是在忙，还是在躲？苏晴愣了一会儿，说，两样都有吧。这个回答她自己都没想到，说出口以后，她反而轻松了一点：承认两样都有，比硬说一样要好受。以后每到周三，小周会下班时喊她一声，两人去吃一碗面，说的都是些无关紧要的话。苏晴说，那碗面是她一周里最没用的一件事，也是她最舍不得丢的一件事。

所以这本书不叫她成瘾。她这一格，介于“正常的高投入”和“被占着的下一步”之间，边界是模糊的，不是我们不敢判，是这个模糊本身就是事实。能做的，是继续数。数她会后的第一件事，数她做完一晚上以后第二天的日子是不是还有别的方向，数她定下的那个周三。这些东西如果两个月后还在，她大概站在开放的一边；如果一个一个消失，位置就是在收拢。

同样的四条，放到老何身上，要格外小心。他吃的药是治疗的一部分，由医生管着，疼是实在的，不能因为他每天都吃、到点就吃，就说他被预占了。这四条拿来问的不是那几片药，是药旁边那个下午：他的药安排得再规范，如果一天里别的去处都慢慢消失，下午只剩下“等到点”，这个位置依然值得有人去看。唐医生看的就是这个，她没有拿它去怀疑老何，只是一直在问，药管完身体之后，剩下的时间是谁在管。

这里也要说，那篇长文自己做了两次让步，这两次让步很重要，我们照实带过来。第一次，对象不是无所谓的。不同的东西药理不同，毒性不同，戒断的风险不同，有的会危及生命，有的停了以后再用会更危险。所以“位置比东西重要”绝不意味着“东西不重要”，医学对身体的那一本账，没有任何抽象的说法可以替代。第二次，选择多不等于自由。一个人手上有一百个应用可选，未必有一百种未来；一个人只有一件事，可能在其中过得很宽。去处要数的是通向不同终点的那种，不是数量。

## 老何的下午，和这本书自己的账

老何后来的事，我们不敢说成一个圆满的结局。修理摊他去了两个多月，有几周因为腰疼和下雨断了，断的那几周下午就难过，难过的时候他也说过“还是想早点躺下”。唐医生一直在管他的药，药的安排始终是他和她商量着办，没有一次是靠他自己拿主意。那个钟点，有时是修理摊撑着，有时是老伴陪着，有时是药和理疗在撑着，有时他仍然盯着墙上的钟。唐医生在病历上写的一句是：下午的下一步，现在是三个，比去年多了一个，但最不稳的还是最后那个。她没有把这一行字说给老何听，怕他听成一张成绩单。她只在复诊的末了问了一句：这几个下午，您自己觉得，哪个钟点最长？老何想了一会儿，说，三点半。唐医生点点头，说，那咱们先从三点半想起。

这样写，不太好看，却老实。这本书要提的是一件很小的事：康复最低的标志也许就是，下一步终于可以不再属于它。它不是要求一个人永远没有渴求，也不是把所有线索洗成中性，更不是找一个更猛的活动去盖住那个空位。它只是在东西走了、线索淡了、节奏乱了的那一刻，下一步没有马上往原来的地方去，有别的地方可去，而且去了以后，未来又被还回来了一点。

那篇长文也押了注。比如它预测，替身应当在复发之前就先露头，如果替身总是复发之后才出现，这个说法就垮了。这些预测目前都是待检验的，没有哪一条已经被证实，这一编末尾还会说到它们。

最后要让这本书对自己也用同样的标准。如果这套说法被接受了，有人会开始在每一样重复的事里找预占，在每一个高投入的人身上找隐患，把所有反例都说成伪装。那时候它自己就成了它所描述的东西：占着解释的下一步，别的解释进不来，说完一次也不归还什么。要防这一点，有一个很简单的办法：撤掉“预占”这个名称，看看用习惯、线索、戒断、注意、情绪这些老说法，能不能把同样的事说得更好。能的话，这个新名字就该放弃。那篇长文还给自己押了一个有日期的赌注：到2030年底，至少有一项事先登记过方案的大研究，控制了严重度、戒断、情绪、已知线索反应和自控能力之后，仍发现“下一步会不会收拢到同一个终点”能预测一年内的复发或功能受损；没有，这个说法的强版本就该撤回，只留一个比喻。这是写在纸上的赌注，它到期那天，这一编的判断也跟着一起过堂。哪怕是在今天，这一编里的每一个数、每一个办法，也都应当被当成待检验的东西来读，而不是当成已经落地的结论。你不妨也替身边的人，替自己，留一个问题：东西走了以后，他的下一步，是往不同的地方散开了，还是只是换了一盘新的在转？

## 回头看这一编

先看三样东西怎样互相生出来。看得见的，是东西撤走以后，第一件稳定的事落在哪里，苏晴那条购物页面，老何那一杯酒，都是这样露出来的。一步一步的次序，是身体发紧，一句话，一个动作，一个页面，一棒接一棒。缠在一起的土壤，是被改写过的身体，会自己长出来的线索，一天的钟点，周围的人，还有那个没人写在病历上的空下午。三样互相喂养：土壤决定哪一棒顺手，次序把一次次落点练熟，落点又回过头去改写土壤。所以只动最上面那一样，比如把东西拿走，其余两样很快又把它生出来。

再看从哪里起手才对得上。这一道手续最吃紧的起手，是先看落点，再数次序，最后才翻土壤。先看落点，因为不看第一件稳定的事去了哪里，你分不清这个位置是空了，还是被换了人坐。接着数那几棒是怎么递的，最后才去翻身体、线索和钟点这些不好动的底子，那一层需要医生陪着，也需要时间。

最后看张力和回写。东西走了，位置却空着，这就是矛盾在顶撞；顶出来的新显露，是一个替身坐了上去。替身每坐一回，就更熟练一点，别的去处就少一次练习，下一轮更难。反过来，如果是修理摊、是人、是长出来的本事坐上去，同样一回一回地写回，下一轮反而更容易。

这一编怎样算错？如果东西撤走以后，第一件稳定的事散得很开，这样的人仍然多半复发，说明这个位置不是要害。如果替身都只在复发之后才出现，不能提前露头，说明接力的说法站不住。如果有人拿着这套尺子，把练琴的、做研究的、守着早课的人也算进去，说明我们已经把它用坏了。
