# 结语　开票这件事，能不能先教给小工

老板娘问完那句话，老孙愣了一会儿。他说教是能教，就是小工手慢，头几天肯定要出错。老板娘说出错就出错。

小工学开票，第一个星期错了三张，有一张开错了抬头，客户打电话来骂。老板娘接了电话，赔了不是，晚上回家又想把这事交还给老孙算了，反正他开得又快又准。她想了一晚上，第二天还是让小工开。这样过了一个多月，小工开票还是比老孙慢，可是有一天老孙请假没来，货到了有人签收，发票也开出去了。那天店里还是乱，账对不上，工资的事也没人懂。但是门开了。

故事讲到这里，我们不打算给它安一个圆满的结尾。老孙后来有没有走，店后来有没有好起来，我们不知道。我们知道的只是，那天早上老板娘站在柜台后面，第一次没有因为老孙不在而慌得不知道该找谁。

老周的事也差不多。写到这本书的结尾，他还在老高的小组里，还在吃唐医生开的药，还在凌晨四点的楼梯间里喝那杯温水。有的星期他做到了，有的星期他没有。有一回老高感冒没来，他当晚又喝了，第二天自己走上二楼说了这件事。这和前七次有点不一样，也可能并没有什么不一样，也许他到第九次的时候，我们会发现这本书又说错了。陈姐还在还债。老何的下午还长，药还在医生手里调着。苏晴到底算不算成瘾，我们到现在也说不准。阿宁有了一个晚上回她消息的朋友，那个朋友常常回得很晚。老方前些天又停了，他自己也不知道这回能停多久，也不知道为什么。

我们写下这些，并不是说他们都快好了。这本书承诺不了这个。戒断、复发、欠下的债、伤过的人，这些都是实在的苦，一本书帮不了多少。它能做的事很小：把问题换一换。从“你为什么这么没出息”，换成“这一轮谁来办”。前一个问题问得再狠，也只能往回算账。后一个问题问得再笨，也能指向明天早上的某一件具体的事。

这本书里，开头那句话其实不是我们最想守住的。那句话也许会被以后的研究削得更小，也许有一天《续燃》赢了，我们要把九道改成八道，要把“岗位”这个比方收回来。我们更想守住的，是老板娘拿出那张纸时发生的变化。这只是一个比方里的变化，要不要信，请你拿自己的日子去对。她没有变得更坚强，老孙也没有变得更好，只是一件原来看不见的事，现在写在纸上了。写下来以后，骂自己就显得不那么要紧了，开票这件事却变得要紧了。

如果你正在这件事情里，请先照看好身体，该找医生的时候去找医生，有伤害自己的念头时，马上告诉身边的人，联系医疗机构，也可以拨打全国统一心理援助热线 12356，紧急时拨打 120。然后，在哪一天你缓过来一点的时候，拿一张纸，写下最近的一轮生活，从有事开始，到这事算过去。写完你也许会看到一列相同的名字。那不一定说明你没用，它可能只是说明，这些年你的身边，能办事的越来越少了。

撤走的是办事的人，岗位还空着。那就先找一个人，教他开一张票。这张票开错了，明天再教一遍。
