# 第32章　几笔债同一天到期

## 一张本周到期单

陈姐把手机里那个页面删掉的第一个星期，是她这几年里最难熬的一个星期，难熬到她又拿出那个硬皮本，一天一天记了下来。她不是没有料到会难受，她料到的是想去点开的那阵冲动。可实际上来的东西，比她料到的杂得多，杂得像是几个不相干的债主，约好了在同一个星期登门。

第一晚，睡不着。老邓又出车了，屋里静得出奇，她躺着，眼睛睁着，往常这个钟点手里有一块亮着的屏幕，如今只剩天花板。这是身体的账。第二天上班，小李递给她一份表格，她接过来，才发现自己一上午都在躲小李的目光。从前这种躲，到了晚上点开页面就盖过去了，现在没处可盖。这是位置的账。第三天中午，她吃什么都没味道，胃里空着又什么都不想吃，下午四点心慌得厉害，分不清是缺了什么引起的反应，还是单纯饿过了头。这是肚子里的账。到第四天，催款的短信来了，一笔钱到了该还的日子，这笔钱过去一段时间里，她一直靠“再来一把”在心里往后推。这是有数字、有日期的那一本，是最硬的一本。

她把这几样写在一页纸上，标题起得很会计：本周到期。睡眠，脸面，肚子里的空，空出来的夜晚，欠款。五行字摆在一起，她看了很久，说了一句话，说得很准：我以前以为我离不开的是那个页面，原来我离不开的，是那个能把这五样同时先挂起来的办法。

这就是这一章要讲的事：撤走一个快办法，不是拿掉一件东西，是同时撤掉一个替好几本账垫付的人。使用的时候，一笔一笔的缺口，被它轮流盖住了，各自往后推了一段。它走了以后，这些往后推的账有可能在同一个星期里挤过来。当事人感觉到的不是“我想要那个东西”，而是睡不着、没脸见人、心慌、屋里空、钱压人，一股脑合在一起，说不清谁是谁。这时候冒出一个判断，是再自然不过的：没有它，我没法过日子。这句话不能当作一个永久的事实，它很可能只是在如实报告：这个星期，账都到期了。

读到这里，要把一个容易误会的地方说清。难受的程度，不等于那个办法对人有益。有人把“停下来更难受”当成“它原来是帮我的”，然后回头。它确实替人垫付过，垫付的方式却是转账，欠的数目只增不减。停下来以后的难受，是把原来挂着的账看见了，不是那个办法忽然变好了。当然，也要老实说，这个解释现在还是一种理论提法，没有大规模的记录去验证。陈姐的一个星期，只能说明她这一个星期。

赌博和酒不同，停下来时身体上的反应没有那么直接危险，但这不等于它不需要专业的人。赌博问题本身就是医学上可以求助的问题，精神科和心理门诊都能看。长期的失眠、持续的情绪低落、焦虑发作，都可能在停下来的那几周里加重，这时候社区医生、心理门诊都是可以去的地方。陈姐后来想明白了这一点：她那一周的难熬，不是她“没出息”，是几本账同时到期，而她手边除了一个硬皮本，没有第二个人在场。

另外也请记住：如果债压得人喘不过气，心里冒出伤害自己的念头，那不是靠记账、靠忍能处理的，要马上告诉身边的人，去找医疗机构，也可以拨打全国统一心理援助热线 12356，紧急时拨打 120，不要自己扛着。赌债压着、又瞒着家人，这是风险偏高的情形，身边的人也要留心。

## 医学先接最危险的那一本

几本账里，有一本是最不能等的，就是身体那一本，尤其是当那个快办法是酒，或者是镇静类、阿片类的药物的时候。这一点，这本书必须写得明白，因为全书讲了这么多“手续”，最容易被人听走样的就是这里。

先说酒。长期大量喝酒的人，如果突然一下子不喝了，身体可能出现很严重的反应，有的人需要在医疗监测下度过这一段，严重的时候会危及生命。如果停酒以后出现手抖、大汗、胡言乱语、看见不存在的东西或者抽搐，要马上去医院，不能等。镇静类的药，就是平常说的安眠药、安定类、抗焦虑药，情形类似：长期吃的人，不应该自己突然停，应该由医生安排，一步一步减下来。这些话，美国成瘾医学会等机构关于酒精戒断和镇静类药物减量的诊疗指南里都有写，那篇长文也特意引了。至于阿片类，有一个反直觉的地方：停用一段时间以后，身体的耐受会降低，这时候如果再用，发生过量的风险反而更大，严重的会致命。成瘾医学关于阿片类的指南也不赞成把单纯的突然停用当成完整的治疗，因为它可能带来更强的渴求、复发，和过量的风险。这些话，如果只记一句，就记：这几类东西，不要自己突然停。

老周第八次登记的时候，唐医生没有问他打算怎么戒，也没有鼓励他回去之后咬牙硬撑。她先问的是：这些年平均每天喝多少、有没有哪一回停下来之后手抖出汗或者睡不着、肝和血压最近查没查。她要先弄清的，是老周的身体在“停下来”这件事上有多少风险，需不需要在监测下进行，需不需要用药物帮他度过最难的那几天。这一次的安排，是先把身体这一关交给医生，决心这件事，放在后面再谈。

老何那边也一样。他腰伤手术以后长期吃止痛药，医生唐敏一直在帮他。他的药，不由他自己加减，这件事只在唐医生手里，同他商量着办。唐医生要弄清楚，他的疼到底处在什么状况，药在他身上起什么作用，下一步怎么调才安全，以后疼了怎么办。这里还要分清一件事：按医嘱长期吃这类药，身体会产生耐受和依赖，这本身不等于成瘾，老何算哪一种，要由医生来看，家里人和这本书都不替他下这个判断。他的情形需要医生持续陪着，不能靠他自己的决心去办。

这里面有一个更深的道理，也是这一编想说透的。医学治疗接管的，是最危险的那一本身体账。它不是在跟这本书抢位置，是这本书得以讲下去的前提。一个人如果在生死线边上，谁跟他讲“慢办法”都没用。医学先把这条线稳住，别的账才有了展开的条件。药物治疗、替代治疗、减少伤害的办法，也要放在这个意思上去看。有的治疗，即使用的药和原来那样东西有某些相似，也可能降低来路不明的风险，减少忽高忽低的波动，降低过量和伤害，让其他生活的账重新有力气运转。比如阿片类依赖的维持治疗，是在医生管理下用药，医学上证据很强，能降低过量死亡的风险，它不算“换了一样东西上瘾”。判断一种治疗好不好，不看它的分子像不像，看它的功能和风险有没有变好。这本书不替任何人决定要不要用药，也不让任何人以“手续”为由放弃治疗。

有人读到这里，会担心这是在说“医生管身体，剩下的不用医生”。恰恰不是。下面要讲的康复四层，每一层都可能需要医生、护士、心理工作者在场，只是最先、最急的一层必须是他们。老周的女儿周玥在医院当护士，她比家里别人更清楚这一点。她对父亲说的话不多，但有一句很实在：爸，这一次别自己停，也别听别人说“硬扛过去就好了”，先去把检查做了。这句话没有道理可讲，也不是在管他，是一个懂行的人，替他守住了最要紧的一道门。

所以，凡是有人拿这本书的话去劝家人“不用吃药了，把生活重新安排好就行”，请把这样的用法记作误用。这本书讲的是医学接管身体账之后还剩什么，不是用“手续”去代替治疗。反过来也要警惕另一种误用：医生把药开了，家里人就觉得事情办完了，从此不再过问睡眠、脸面、夜里那口气。前一种会把人推到危险里，后一种会让人在安全里空着。

医学接住了身体里最危险的那一本，下一个问题才轮到这本书：接住以后，这一轮其余的手续由谁来办？那篇长文给康复画了四层，我们换成大白话。第一层，把停下来这件事安全地办完，包括处理可能出现的戒断，这靠医生。第二层，把身体慢慢恢复的本事找回来，睡眠、疼痛、体力、疾病，一样一样地处理，这靠医生，也靠时间和日常的安排。关于运动，那篇长文引过一个汇总研究，说合适的运动可能帮助一部分正在戒除成瘾的人改善自控和注意，可是研究数量有限，多数缺乏长期追踪，所以也不能说多运动就会好，更不能说有过强迫性运动的人从此碰不得运动。第三层，降低停下来要付的位置代价：不喝酒会不会失去饭局上的位置，不加班会不会被当成不投入，不下注会不会等于承认亏损已经落定。这一层，靠的不是一个人更用力，是周围的环境、评价、圈子有没有给他一个下得来的台阶。第四层，让肚子里的信号重新变得可读，吃得有个稳当的节奏，少一点来回折腾。

医学接住身体账以后，这一轮其余的手续仍然悬着，所以才有了上面这四层。拿老周来说，唐医生把前两层的安排接下来，第三层靠老高的小组和家里人的态度，第四层靠他自己一天一天地吃饭睡觉，没有哪一层可以跳过去。

这四层的次序，也有道理：第一层没有稳住，后面三层谈不上；第一层稳住了，如果只有它，一个人出了门诊，仍然要回到那间只有一个办法的屋子里。所以老周从唐医生那里出来，手里有一份医学上的安排，同时还要走到老高的小组里去，还要想一想四点钟的那口气，除了酒，能走到谁那里去。两样加在一起，才是一整轮。

## 一次排一道，一次分一笔

陈姐和苏晴，后来各自做了一件相似的事：不再想一口气全部还清，而是先排一个次序。陈姐的单子上，欠款是最硬的，也是她最怕碰的。她用了几天才下定决心，不是去赌回来，也不是继续自己扛，而是找了懂得处理债务的正规机构去问：怎么摆，怎么谈，先后怎么排。同时，她把夜里的空白也当成一笔要认真对待的账，不再想着“忍过去”，而是在晚饭后安排了一件固定的小事，煮一壶水，给在外面跑车的老邓打个短电话。她还没有对老邓讲出全部，这件事她知道早晚要面对，可是她决定不在最累的那个星期里，把所有的话一口气说出来。她把“说”这件事，也排进了次序里。

苏晴戒烟的头一个月，找了医生商量，没有把它当成一个靠硬撑去打赢的仗。医生跟她一起看，她什么时候最难，有没有可以用上的医学帮助。她同时做了几件小事：把这一周里并不要紧的一个会议往后推，让位置账少一点压力；把睡眠固定下来，让身体账先稳；每天一顿正经的饭，让肚子里的账有个节奏。她还发现一件没想到的事：戒烟以后，她不再去侧门那块背风的地方了，而那里是公司里消息最灵通的地方，同事们抽烟的时候，什么项目要调整、哪位领导要换，都在那几分钟里流出来。她失去的不是一个习惯，是一个信息渠道，一个有点小小分量的位置。这一笔，如果没有想到，会在第二周变成一个她说不清来由的失落。所以她主动找了另一个办法，每周跟那几位同事约一次午饭。

生活里也有这样的场景。一家人搬新家，头一天，搬家公司、水电煤气、孩子转学、旧房子退租，几件事撞在一起，谁都想一口气全办完，结果谁也办不好。有经验的人会先问一句：哪件事一旦错过就无法挽回，哪件事可以让别人代办，哪件事晚两天也没关系？先把要命的办掉，再把能托付的托出去，剩下的才轮到自己慢慢来。成瘾这一轮的账也是这样，要命的在前，一般是身体，能托付的在中间，剩下的可以慢慢磨。老周去老高的小组，也是在托付一笔账：夜里四点钟的那口气，让它在认识老高的人手里多一个落点。

她们两个人的办法，都不是什么高明的设计。她们做的，是把“同一天到期”的几笔账，尽量错开；能请别人帮一把的，分出去一笔；每一笔到期的时候，先问一句：这笔账属于哪一本，现在有没有除了那个快办法之外的人或事，可以接。这样做不保证成功。那篇长文也说得很清楚，康复的标志，不是以后再也不欠账，生活里总会产生新的恢复需要，累了要歇，输了要缓，吃了要消化。标志是某一轮里，一笔缺口出现了，没有立刻转成旧办法，也没有被推到另一本账上，而是留在原处，被一条慢一点、却不再滚存的路接住了。

你可以想一想：如果明天就把你身边那个“快办法”撤走，今晚到期的会是哪几笔？其中哪一笔是需要医生先接手的，哪一笔可以先分给一个具体的人？

## 回头看这一编

先看这一编的三件事怎样互相咬着。看得见的，是那一口气松下来，缓解是实在的，所以人会说“它帮了我”。可这个样子是由次序和土壤生出来的：次序里，哪一本账先出毛病，每一轮不一样；土壤里，身体、脸面、肚子里的感觉，三本账彼此牵连，慢办法又常常没有备下。只动看得见的那一口气，等于只管撤对象，另外两样没动，它们很快又会生出同样的样子。

再看从哪里起手。这一道手续最吃紧的，是先稳住土壤里最危险的那一块，也就是身体账，由医学接手；再数次序，看每一轮哪本账先动；最后才轮到去碰那个样子本身。起手的次序错了，比如一上来就劝人“意志坚强”，只会让他在最危险的一块上硬扛。

最后看张力和回写。身体、脸面、肚子，三本账同时被顶起来，逼出一个快办法替它们一起垫付，这个新的样子写回土壤里：每垫付一次，慢办法少一次出场，欠账多挪一次，下一轮就更难。反过来，如果有一轮，缺口留在原账、被慢办法接住，写回的方向就变了，下一轮会容易一点点。

这一编怎样算错：如果长期记录显示，每一轮总是同一本账先动，而且另外两本毫无独立的动静；如果欠账的滚存和先动的换手，在控制了戒断、情绪和线索之后，仍然预测不了复发；如果同时处理几本账的办法，并不比只处理一本的办法好；如果不同的人看同一份记录，对“哪本账先动”总是吵不出一致，那么这一编的判断就站不住。不妨也想想，你身边那个人的最近几次，是不是这样。
