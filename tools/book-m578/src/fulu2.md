# 附录二　这本书核对了什么、没有核对什么

**做过的核对。** 全书写完后，我们抽查了十五条最承重的外部事实，核对渠道是公开网页，部分医学数据库的页面打不开，有几条只核到题目、刊物和年份，没有读到摘要。结果是十二条属实，两条有出入并已改正，一条查不到原始出处。查不到的是九篇长文里引的一项线索命名研究，第 18 章已把它删去。另外，人物事实、章节互指和安全提醒做过一轮通查。

**只核到一部分的。** 第 17 章的两项动物研究核到了题目和刊物，正文的细节按那篇长文转述。第 32 章关于酒精戒断的指南要点核到了，关于阿片类的两句没有取到指南原文。第 33 章的美国全国调查分析核到了出处，“多数没有经过治疗”一句没有回到原文。第 38 章奥尔巴赫画室的做法，核到美术馆的说明，“最后一次画成”一句据访谈与评传的说法，没有逐字核对。

**没有做的。** 全书提到的其余研究没有逐一回到原始文献。九道手续的所有数字，都没有在成瘾人群中做过检验，也没有常模。这本书没有经过独立的学术评审，也没有经过成瘾科医生审读，涉及医疗的句子请以医生的意见为准。
