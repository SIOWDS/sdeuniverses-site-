# 第30章　快的打败了慢的

## 那天晚上她试过慢的

陈姐的本子记到第三个月，有一晚她决定认认真真试一次慢办法。那是个周四，白天又是盘点，一个数字对了一下午对不上。她下班回家，吃了点东西，洗完澡，对自己说：今天不点开，先睡觉。这话没有毛病，医生会这么讲，家里的长辈也会这么讲。她躺下去，关了灯，十一点，十一点半，脑子里还在转那个数字。睡觉这件事，有个很讨厌的地方，它不是想睡就能立刻睡的，它得等。她盯着天花板等了一个多钟头，最后拿起手机。那一晚她没有输赢，只是点开了。

她后来把慢办法一条一条列出来看。睡觉，要等，而且越着急越等不来。跟人说，她第一个想到老邓，可老邓这周在外省，更要紧的是，她要说这个晚上为什么睡不着，就得从那笔欠着的钱说起，那是她瞒着丈夫的一件大事，这一说，说出去的就不是一个晚上的心烦，是整本账。第二个想到的是同组的小李，可小李恰好是升了组长的那个人。想去楼下走一走，十一点多了，小区里黑着，她一个人，走不出什么名堂。再往远处想，那些能把问题解决掉的路，比如把欠的钱一笔一笔摆出来找个人商量怎么还，比如去找专业的人谈，每一条都要先难受一阵，才可能慢慢好起来。

这几条路有一个共同的样子，让人沮丧：慢，贵，要别人配合，短期看不出效果，有时还要先添一层痛。而那个页面呢，就在手边，不用等任何人，三十秒就能让这间屋子里的东西换个样子。她说，不是我不知道哪条路对，是对的那几条路，那天晚上我一条也走不动，也走不进去。这句话她说得很轻，听的人却很难不想起，自己有多少次也是这样，路明明摆在那儿，人就是上不去。

苏晴那边，慢办法碰到的是另一堵墙。她知道自己该睡够，可是这一周版本要上线，她要是准点下班，几个同事就得替她扛夜里的故障。她也知道该跟总监谈一谈需求排得太满，可她在公司的位置并不稳，上一轮调整里有个同级的人被换去了边缘项目，大家嘴上不说，心里都有数。对她来说，退一步不只是少干点活，是要付出一个她不确定付不付得起的价：别人会怎么看她，下一次分活的时候她会排在哪里。内卷这个词听起来像是个玩笑，落在一个具体的人身上，是一笔每天都在记的相对位置账。她说，我不是不想歇，我是怕歇一歇，回来发现桌子被人换了。

三本账各有各的慢办法，值得分开说一下。身体的账，慢办法是睡眠、休息、看病、疼痛的处理和体力一点点地回来，它们靠时间，也靠医生。位置的账，慢办法往往不在个人，而在周围：评价的方式能不能松一点，退出一件事能不能不丢掉饭碗和面子，身边有没有一个参照的圈子不是天天在比。肚子和身体感觉的账，慢办法是吃饭有个稳当的节奏，不在饿过头和吃过头之间来回折腾，让饿和饱的信号有机会重新变得读得懂，这是个以月计的功夫，不是哪一顿饭能办成的。三条路都慢，三条路都需要环境配合，一个人撑着去走，很容易走到一半就撑不住。

## 一个办法能接多少种活

上一章说过，陈姐的五个夜晚，先喊疼的账本各不相同。这一章要问的是：既然各不相同，为什么最后全收拢到了同一个办法？答案之一是，这个办法有一种很特别的本事，它能把各种各样的难受翻译成同一个动作。输了，翻成“再来一把”。太静了，翻成“再来一把”。比不过人，翻成“再来一把”。胃里发空，还是“再来一把”。苏晴戒烟之前也是这样：疲劳，翻成“再抽一根”；怕失去位置，翻成“再改一版”；说不清哪里不对，翻成“再点一个外卖，再刷一下手机”。一个动作能接受的来路越杂，它越容易成为各种难受的共同出口。

我们不妨拿开着的饭馆来想。一家小饭馆里，有一个会炒菜、会收银、会采购、会招呼客人、还会修水管的师傅，那这家店就几乎离不开他，因为他一个人顶好几个岗位。他未必是最好的厨子，也未必是最好的收银员，但他永远在，永远快，别人一时顶不上去。那个快办法也是这样的师傅。它在一个晚上接了三个岗位的活，所以哪个岗位出事，大家第一个想到的都是它。

要把这种“能接多少活”讲得再具体一点，可以问四件事。这个办法多快见效？从想到它到松下一口气，隔了几分钟还是几天。要等不等别人？是一个人就能办，还是得有人在场、有人配合。要付多大代价？是顺手就有，还是要先花钱、花力气、花脸面。停下来要付什么价？不做的时候，失去的是一点快乐，还是一个位置、一个圈子、一个一直在用的出口。快、不等人、代价小、退出的价又高，这四样凑到一起，一个办法就占了很大的便宜。那篇长文把这个叫“结算密度”，意思是单位时间里它能办掉多少难受。密度高，只说明它好用，不说明它有病。要等到它同时带来越滚越大的欠账、一轮一轮换着人发动，才轮到我们认真起来。

这里需要慢一点，立一道护栏：一个办法接的活多、做得快，并不等于它就是成瘾。那篇长文自己用体育学的材料提醒过这一点。运动是个典型的例子，有人练到身体出问题、停不下来，也有研究汇总发现，合适的运动可能帮助一些正在戒除成瘾的人改善注意和自控一类的能力，只是这类研究不算多，多数没有长期追踪，不能当成定论。同一个跑步，对一个人是恢复，对另一个人是债务。差别不在练得多还是练得少，而在跑完以后，身体、心思和日子有没有重新开放。一个马拉松爱好者，一个月练许多次，跑完吃饭睡觉照常，下周照常上班，那是一个高频的好习惯。另一个人跑得不比他多，却是被比较和对自己身体的不满赶着跑，跑完更疼更累，下一次还得跑，那是另一回事。是不是成瘾，还要看有没有失去控制，有没有明知有伤害还继续，是不是在挤占别的生活。

苏晴听到这里，立刻问了一句，那她的工作到凌晨怎么算？这本书没法替她下判断。她加班多，可她有时也能按时下班，周末能关掉电脑，能因为一场朋友的饭局推掉一个会，这些情形说明她手里还握着别的岗位。她身上值得看的，不是加了多少班，而是有没有哪一晚，工作成了唯一能让她心里踏实下来的办法，别的办法全都排不上号。有的话，那几个钟头就不只是勤奋，是在替好几本账结账。

慢办法输，输在它们没有赶上今晚，倒不是它们本身不行。这一点对陈姐很要紧，她有个习惯，一件事做不成，就怪自己废物。可是回头想想，一个办法要赶上今晚，得提前备下东西：有一个愿意在夜里十一点接电话的人，有一个提前讲好的安排，有一条走得进去的路，有一块不会立刻被占掉的时间。这些东西，在那个周四之前没有人替她备，她自己也不知道要备。慢办法不是天生就慢，很多时候是因为它们的前期工程没有做，每一次要用，都得从零开始搭。快办法的前期工程，早在过去几年里一次一次用的时候就做完了。

日子里到处都是快办法打败慢办法的小例子，多数无伤大雅。下班晚了，冰箱里有剩菜和一把青菜，煮一锅热汤要四十分钟，一碗泡面三分钟，大多数人都会选后者。偶尔这样没什么，问题只在于，如果一个人连着几年每个晚上都是三分钟的那一个，他慢慢就忘了汤是怎么煮的，厨房里的东西也不再备了，等哪天想煮的时候，发现什么都得从头买。快办法不必比慢办法好吃，它只要每次都先到，慢办法就慢慢退出了这个人的生活。

## 好处记在眼前，账单寄到别处

快办法还有一个更要紧的优势，是它的好处立刻到账，它造成的麻烦却不在当场出现。陈姐点开页面，当晚就觉得心里松动了，这是记在“点开”这个动作名下的好处。可她第二天早上起来，眼皮沉，人没劲，上午对账错了一笔小的，下午躲着小李的目光。这些事，没有一件写着“昨晚点开了”。它们被记成“最近太累了”“更年期是不是要到了”“这个月事情太多”“我这个人就是不行”。好处有归属，坏处没有归属。

这是一种很普通的记账方式，生活里到处可见。大考前一晚熬夜背书，第二天考得还不错，这个好处立刻记在“熬夜”名下：看，通宵管用。可考完以后三四天，人都是恍恍惚惚的，没劲儿，该做的事做不动，这些事没有人记到“熬夜”头上，大家只会说，考试把人累垮了。下次再考，他还是会熬夜，因为他的账上，熬夜只有进项。

放到更大的一轮里就是这个样子。每一次，快办法都领走一份实在的回报，它的“收入”一笔不漏，而它欠下的东西，分散成睡眠差一点、心情糙一点、脸色黯一点、对人没耐心一点、吃饭乱一点，每一条都小到不值得单独拿出来怪谁。它们一点点积起来，积到一定程度，才变成一个叫不出名字的“最近状态不好”。那时候人想找一个让自己好受点的办法，第一个想到的，当然还是那个快的。所以快的越用，慢的越没有机会证明自己，因为慢的办法等到见效的时候，常常已经被快的抢先办完了一轮。

这和第六道手续是连着的。上一编讲过，好转的功劳总被记到最后碰到的那只手上。这里的道理差不多：功劳立刻记在快办法头上，欠账晚几天才露头，而且换了名字。于是在当事人自己的账本里，快办法的收益表一栏比一栏好看，而它的欠账表是空白的。一本这样的账，谁来审，都会得出“这个办法值得继续用”的结论，这并不是他糊涂，是他手里的账本天生缺了那一页。想让账本补上这一页，也不用靠谁去说教，一个很笨的法子就够：每次用完以后的第二天、第三天，各留一行字，写今天的状态，睡得怎么样，身上哪里不对劲。陈姐的硬皮本，后来多了一栏叫“第二天”，就是干这个的。

有人会觉得，这样说来，快办法简直成了坏人。也不是。它帮人度过了很多个撑不下去的夜晚，这一点有价值，没有谁该为此被嘲笑。需要问的只是，它在帮人的同时，有没有把别的办法挤到了没有机会出场的地步，它给的缓解，有没有被记成了全部的功劳，它转走的那些债，有没有人在看。

## 知道有害，为什么还是停不下来

家里人最想不通的就是这一点：他自己明明都知道。陈姐知道赌是一个洞，知道只会越陷越深，知道那笔钱是怎么一点点变成这个数字的，她比谁都清楚，毕竟她是做账的。老周知道酒伤肝，苏晴知道抽烟不好，这些话没有人需要再讲一遍。

那篇长文里有一个旁证，可以帮助理解这件事。它引了一项关于职场的调查，发现一种相当常见的组合：很多人对“内卷”的环境怨气不小，觉得不值得，觉得累，嘴上骂得很凶，可是该加的班还是加，该跟的风还是跟。抱怨归抱怨，退出归退出，这是两件事。一个人觉得这条路不值得，和他敢不敢从这条路上下来，并不在同一个账本上。成瘾里的“明知故犯”，有很大一部分像这种情形。“知道有害”改变的是对很久以后的判断，“再来一次”处理的是今晚最先到期的那一笔。长远的道理，付不了今晚的账。

更麻烦的是，当慢办法还没有长出来的时候，把危害讲得越透，有时反而会把人推向快办法。陈姐每想一遍“我这么多年的账就这么白做了”，位置的那本账就更疼一分，而这一分疼，正好是那个页面最拿手的活。羞耻一多，躲得就越深，躲的办法又是同一个。所以讲道理、看警示、翻后果，都很要紧，可它们本身不能替代另一套办理手续的办法。它们告诉人那个办法在欠债，却没有告诉人，今晚这口气该找谁来收。

还有一个小细节。陈姐在本子里有一次写了句气话：“我连个能说话的人都没有，才点的。”过了几天她又自己划掉，改成：“有，但那天我没法开口。”这两句话都对，也都在提醒一件事：有没有人，和那个人此刻够不够得着，是两回事。慢办法常常输在最后这半步上。

苏晴戒烟之前，有一回在体检报告上看到睡眠和心率那几行提示，当天晚上她认真地把电脑合上了，十一点上床。第二天开会，一个她本来准备好的论点没来得及说，被同事抢了先，她回到座位，胸口那股憋闷又上来。道理她全懂，那天晚上她还是走去了楼下侧门那块背风的地方。她没有变笨，她只是发现，认真的一天，没有给她的位置账添一分，倒让它欠了一笔。

读到这里，像李红那句“你要是真心想戒，早就戒了”的声音也许又要响起来：这么说他就没有责任了？不是的。陈姐的债是实打实的，欠的钱要还，瞒着丈夫的事要面对，这些都是她自己的账，别人替不了。这本书只是认为，把力气只花在“你为什么明知故犯”上，等于对着一个没人办的岗位喊话。责任是往回算的，慢办法是往前建的，两样都要，缺了哪一样，这一晚都难熬。你可以先问问自己，或者问问你担心的那个人：上一次想松一口气的时候，摆在手边的办法，有几个是不用等人的，有几个是不用先难受的，那几个，在不在那里？
