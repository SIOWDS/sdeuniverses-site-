# 第45章　这本书怎样算错

## 先把靶子立起来，再看每一道怎样算错

一本书如果只告诉你它哪里对，读者没法判断它值不值得信。所以最后一章，我们把靶子立起来，请你来打。

全书的母题是一句话：成瘾不是那样东西太诱人，而是一轮生活的手续只剩它会办；把它撤走，那个岗位还空着。这句话里其实藏着三个断言，每一个都可以单独错。第一个断言是，决定一个人离不离得开的，常常不是东西的强度，而是它在多少道手续上是独家。第二个断言是，撤走对象和交接手续是两件事，前者快，后者慢，两者之间的落差解释了许多出院即复发的情形。第三个断言是，这件事在账本上看不见，没有一张表记“这一轮是谁办的”。

第一个断言错在哪里？如果一批人，东西的强度和渴求的强度都量准以后，手续的集中程度对他们后来的复发毫无额外的预测力，那它就站不住。第二个断言错在哪里？如果撤走对象的同时，生活会自然长出别的办法，岗位很快有人接，落差从来没有出现过，那它也站不住。第三个断言错在哪里？如果翻开大量病历、机构记录和平台报表，发现其实早就有人在认真记“这一轮怎么结束”“上一次怎么停”，那么我们说的“看不见”就是我们自己没找到。这三种情形，任何一种出现，都应该让这本书退一步。

还要说一个细节：这句母题不是九篇原文里的任何一篇说的，是这本书把九篇合起来以后自己得出的判断。它比每一篇原文的说法都要宽，所以也更容易错。九篇原文里有几篇对自己的理论作了严格的限制，这本书的母题却是一个更概括的版本。概括的代价，是有可能把各篇自己都不敢说的话说出来了。

九道手续各有各的错法。下面一张表，把每一道最容易出现的“错的样子”写出来。这些写法来自九篇原文各自的证伪条款，我们改写成了大白话，并没有加码。

| 手续 | 如果出现下面这样的观察，这一道就站不住 |
|---|---|
| 生下一步 | 渴求、戒断、抑郁、生活资源、既往使用量都控制以后，高风险那一刻“别的下一步生出了几个”仍然预测不了接下来一到四周的复发 |
| 开工 | 同样控制以后，“谁先动起来”和“下一拍有没有转手”没有任何额外的预测力 |
| 收件 | 驱动在换，收件的“我”是否也换，对复发没有预测力 |
| 收尾 | 控制以后，“能不能靠别的办法把一轮结束”预测不了接下来的复发 |
| 接班 | 撤走对象之后，行为的收敛完全消失，也没有任何替身出现 |
| 记功 | 控制了主观渴求和实际的情绪变化，功劳记给谁预测不了下一次使用 |
| 结账 | 控制了线索反应以后，“最先暴露的缺口换了手”预测不了复发 |
| 重开 | 自行熄灭的那类重启，其危险率随着间隔拉长而稳定上升，旧有的自发恢复解释完全够用 |
| 改起点 | 控制了使用总量与依赖严重度，“改动之后起点少了几项”与一年内的复发没有剂量关系 |

读这张表要留一个心眼。每一行都比一般人愿意说的“还要看具体情况”更严格，它们划定了自己什么时候输。九篇原文还各自押了一个写死日期的赌注，日期落在二〇二九年到二〇三四年之间。多数要求至少有一项预先注册、样本不少于一百五十到三百人的研究支持它；《续燃》要的是有人在个人层面清点“上一次怎么结束”，《养面》要的是国家级或省级的治疗规范里出现一个强制填写的栏目。若到期没有，原文自己的说法大意是，这不能证明理论永远错，但它声称的“独立机制”地位就应当降级，降成一种帮助看清的说法。这本书同意这个降级条款。

## 最强的对手，和目前的证据

接下来该请对手上台了。我们挑了四位，各自最强的一版。第一位是功能说，也就是皮卡德那一路。它说长期成瘾往往是有目的的行为，当事人拿它来对付严重的心理痛苦。这一路和手续说离得最近，因为很多手续本来就是为了对付痛苦才交出去的。它们分开的地方在于：痛苦的强度如果能把手续归拢解释干净，也就是说，只要把一个人的痛苦量准，他的手续集中度就不再提供任何新信息，那么这本书多出来的那一层就是多余的。更直白地说，如果我们发现，痛苦退下去的人手续也跟着退回来，痛苦没退的人手续就没退，从来没有出现过“痛苦退了而手续还在”的人，那么皮卡德更对。老周的故事里有一个线索，指向这本书：那七个月里他睡得沉了，胃也不疼了，但发薪日四点钟的那口气仍然只有酒能收。可是这是一个人的故事，不是证据。

第二位是替代强化物不足。它说，生活里只有一样东西有奖励，当然离不开。这一路有着很丰富的研究基础，也解释了为什么经济条件、住房、工作、社区会影响康复。它与第一道手续最近。如果社区资源丰富、客观的替代奖励都摆在那里，个体仍然在高风险那一刻生不出别的下一步，并且这能预测复发，那么这本书加的是一个生成层。反过来，如果把客观可得的替代奖励量准，这一层的预测就全部被吃掉，那就应当并回这位对手。

第三位是诱因敏化，加上它旁边的习惯理论。罗宾逊和贝里奇三十年的回顾，把想要和喜欢的分离说得很透。它与手续说的区别，是预测的重点不同：诱因敏化预测的是对象及其线索的吸力，手续说预测的是，即使线索不变甚至被削弱，不同的缺口仍可能轮流成为发起处，换手了，而办事的方式不变。如果控制了线索反应和想要之后，发起处换手率不再预测复发，那就是诱因敏化够用，我们这边的机制没有独立的位置。

关于第九道，还有一位对手要点名：神经适应一路的说法，比如科布（George Koob）和勒莫尔（Michel Le Moal）二〇〇一年提出的异稳态。它说反复使用把奖赏系统的调定点推离了原位，所以停用很久以后脆弱性仍在。这位对手对同一份材料给出另一种读法：一个人每次都掉回原处，是因为体内的调定点，不是体外选项没有少。九篇原文自己把它列为对第九道最硬的一个反驳。如果将来的数据显示，控制了使用总量和依赖程度以后，“起点少了几项”并没有独立的效应，那么改善结局的杠杆就主要在体内，体外选项的安排至多是缓冲，这对我们是一个明确的坏消息，也比现在两头都试一点的状态更有用。

第四位，是九篇里的一个自家人。《续燃》那一篇讲的是，一个人半年没碰，没有任何诱因，中间也没人持有着什么，他又开始了。如果持续根本不需要谁持有，“岗位”这个说法就有裂缝，因为岗位意味着有一个位置，在等着被某个办事人占着。这位对手在第九编里已经当面反对过这本书，我们没有办法驳倒它，只是承认：手续说也许适用于有人持有的那一大类，而无人持有的那一类，需要另外的说法。

现在把证据的账摊开，不修饰。第一，九篇原文里的绝大多数可以数的数，目前都是理论上的提法，没有经过检验，没有常模，没有信度和效度的数据，更没有在任何临床标准里被采用过。书里每一处“数一数”，都只是看清楚的办法。

第二，九篇里只有一篇的两条检验被实际跑过，就是《养面》。它取了一个公开组织下的八个代码仓库，有一万五千多次提交，在计算任何数字之前，先把分组口径和检验方法写死。结果是：最被看好的“先后顺序”那一条没有通过，不作控制时方向与预测相反，控制了改动规模以后差异消失；最便宜的“重构频次”检验也没有通过；原文预言的“两个数近乎无关”也被推翻，实测是弱相关。另有一个麻烦被坐实：对“删除”怎样计，两种同样合理的编码给出的比率相差七倍，在口径统一之前，这个率不是一个数，是一族数。要补一句，这次实跑用的是软件仓库，不是成瘾的人，三处代理都很粗，所以它只能说明“按现有写法去跑，跑出来是这个”，不足以宣告整套说法为伪。但也不能当作什么都没发生：第九道手续的前两层主张，因此被作者自己削弱了。

这本书自己还有一个毛病，要如实交代：它是一个解释力很强的说法，什么事都能装进“手续”两个字里。统一能力越强，越要小心，一个说法如果能把诱因敏化、戒断、习惯、负性强化、复发全部重新叙述一遍，它很可能只是换了一套话，没有多告诉我们什么。读者读到任何一处觉得“这也太能解释了”，请把这一点记在心里。判断这本书有没有多说一步的办法，只有那些能让它输的检验。

第三，全书没有做过一项成瘾人群的实证研究。没有访谈，没有问卷，没有临床数据。老周、阿宁、陈姐、苏晴、老何、老方都是虚构的人物，他们的故事是为了讲清道理，不是证据。

第四，其余几篇提出的数，在原文中是写成“待检验的预测”和“写死日期的赌注”的，到期之前谁也不知道会怎样。其中《续燃》那一篇收回了三个自己原本想说的更强的主张，其余几篇也各自在三个行当面前收回过过强的主张。所以读者在这本书里读到的，是一组经过自我削弱的提议，不是一套成熟的理论。

## 一个可以分清“手续归拢”和“渴求强度”的研究，还没有做

最后，我们写下一个设计。这个设计我们没有做过，据我们所知也没有人按它做过；写下来，是为了让别人可以拿去打。

要回答的问题只有一个：手续的集中，与渴求的强弱，是不是两件事？如果它们总是一起变，那这本书多出来的这一层，就不需要。

设计大意是这样。找至少六个条件相近的治疗单元，比如同一地区、同一治疗规范下的几家社区门诊，招募不少于三百名正在接受物质使用障碍治疗的人，做预先注册，把怎样记、怎样分析在看数据之前写死。让参与者在日常生活中，每当遇到自己的高风险时刻，就用手机在短时间内记几项：此刻渴求有多强，身体有没有不适，心里的痛苦有多重，睡得怎么样；同时记手续的几个数：别的下一步想到了几个，谁先动的，这一轮是靠几样东西结束的，事后功劳记给了谁。每个人记几周到几个月，再随访三个月以上，看接下来七天到三十天里有没有复发或者有害使用。分析时有一个简单的办法：把所有高风险时刻分成四类，渴求高手续窄、渴求高手续宽、渴求低手续窄、渴求低手续宽，比较各类的后续。如果“渴求低而手续窄”的人，复发的风险仍然明显高于“渴求低而手续宽”的人，说明手续是一个独立的因素。如果差异完全消失，被渴求和痛苦吃掉，这本书的核心一层便站不住。顺序也要查：手续变窄是否出现在复发之前，如果总是复发之后才变窄，那它只是后果。

设计里还要装一个专门给功能说的检验：在同一批数据里，把痛苦的强度也测准，看手续的集中在控制了痛苦之后，是否还有额外的预测力。再往后，如果以上都通过，才值得做第二步：在不撤走任何常规治疗的前提下，随机让一部分人多得到一份“交接支持”，让另一部分人只接受常规治疗，比较后续。这一步必须有伦理审查，不能为了证明手续而去制造任何一个人的债务或风险。一个更便宜的前置版本是：在医院现有的治疗日志里，加上前一章提到的几个字段，连续记八到十二周，看变化的顺序。

这个设计什么时候算失败？一是手续的这些数对复发没有任何额外预测力，二是顺序不对，三是交接支持不比常规治疗好。三者中任何一个出现，都应当如实写出来，并让这本书的相应部分降级或撤回。

## 回头看这一编

这一编围绕一个问题展开：手续看清了，怎么分出去。回头看，三样东西仍然互相咬着。看得见的样子，是当事人手里的一张纸、家人手里的一个问题、病历上多出来的一栏。生出这些样子的次序，是先稳住身体，再选最窄的一小块，找两家去接，记下接住了没有，没接住就补人。托着这一切的土壤，是老高有没有空，李红有没有姐妹，唐医生有没有那一分钟，平台的指标要求什么。只动其中一样，比如只给当事人一张清单，而家人和机构不变，清单很快就会落灰。

这一编的起手，选的是最吃紧的一条：从次序入手，先分最窄、最小、有人愿意接的那一块。张力出在两处。一处是分出去的手续要落到别人身上，别人也会累，于是家人可能变成什么都得扛的人。另一处是栏目一旦进考核，可能被做坏。这两处顶出来的新显露，是抽查、公开编码规则、互相留一个说“今天不行”的口子，它们又反过来写回到次序和土壤里，让下一轮更容易或更难。

这一编怎样算错？如果把手续分出去，复发并不比常规治疗好，或者家人和接手的人负担明显加重，或者栏目一进考核就被普遍做坏，那么这一编的建议就站不住。这些都是可以观察到的事，我们盼着有人去看，看了以后告诉我们哪里错了。

如果要把整本书留给你一个问题，不是“这个说法对不对”，我们倒希望你问：在我身边那个让我担心的人，或者在我自己身上，哪一道手续最窄？我可以先从哪一小块开始，让它多一个人来办？这是这本书能留下的、最小也最实在的东西。
