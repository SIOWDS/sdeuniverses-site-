# 第8章　东西停了，未来没有分叉

## 七个月，算好了吗

回到老周的第七次。那七个月，他一口酒没碰，每周去两回老高的小组，药一直在吃，表格填得齐整，唐医生在档案上写过“依从性良好”。从任何一张表格看，这是他最好的一段日子。可是到了第七个月的那个发薪日，四点钟一过，他的手里仍然只有一个办法。酒停了七个月，这一轮里需要办的事，还是只有一家会办。

那七个月也不是白过的。老周睡得比以前沉了，胃不再疼，血压降了一点，他开始会在小组散场后给老高打电话，说上几句。这些都是长出来的东西，每一样都算数。只是它们长在固定的日子和固定的地方：小组那两天，他想得起老高，别的日子，号码就沉下去了。长出来的苗，还没长到凌晨四点的那一格里。

九篇长文里的第一篇，为这种情形画了一张很简单的图。它用两条线分开：一条看的是旧办法能不能被打断，另一条看的是别的下一步有没有出生。两条线交出四个格子，我们把它放成一张表，一章只用这一张。

| | 旧办法能被打断 | 旧办法难以打断 |
|---|---|---|
| 别的下一步已经出生 | 第一格：路是分叉的，想要得厉害，但还有别的路 | 第二格：路有了，身体或情绪压着，动不起来 |
| 别的下一步没有出生 | 第三格：外面把它停了，里面是空的 | 第四格：旧办法占满了所有出口 |

这张图有一个好处：它不问谁更努力，只问此刻里面有什么、缺什么。同样是“没做”，落在不同的格子里，要补的东西完全两样，补错了，力气就白花了。

第一格最好理解。三十多岁的老周下夜班，吵吵嚷嚷地和工友去吃早点，有时候也想喝，想得厉害，可是他还有别的去处，有时候就跟着走了，有时候没走。他想要的力气不小，但生活是有分叉的。这一格里的人，可能仍然需要认真对待，但他们的路没有被一家垄断。

第二格容易被误会。有人已经想到了几个办法，该给谁打电话，该去哪里，可是严重的戒断反应、惊恐、冲动让他一个也做不起来。这时候对他说“你不是有办法吗”，是不公平的，他需要的是医生的帮助，把身体先稳住，让办法有力气变成动作。这一格要特别记牢：它看起来和第四格很像，都是“没做”，要补的东西却完全不同。

第三格就是我们这一章要重点看的。旧办法被外面的力量停住了，里面的路却一条没长出来。老周第三次戒酒时换了一条绕远的路下班，每天多骑二十分钟，便利店从他的路线上消失了。这一招有用，挡过他一阵子。可是那二十分钟的路上，什么也没有生出来，他只是不再经过那个地方。哪天路线被改回来，或者新开了一家店，他还是站在原来的位置，手里是同样的东西。

第四格不用多说，那就是上一章描述的、几样东西互相锁死的样子。旧办法容易启动，难以打断，别的办法一个都不出生，它同时占据了想象、身体和现实的路。这一格最需要的不是某一样东西，而是好几样东西一起来：医生，人，地方，一步一步补回去的那些小动作。

有一点请不要弄错：这四个格子是用来看某一个时刻的，不是用来给人贴标签的。老周在白天坐在活动室里，可能是第一格，路很多，想得也清楚；到了凌晨四点，他可能掉进第三格甚至第四格。同一个人，不同的晚上，也可能落在不同的格子里。唐医生后来在自己的本子上写过，她看老周，大多数夜晚是第三格，偶尔夜里最难的时候是第四格。她这样写，是为了知道下一步该补什么，不是为了给他下个结论。

## 只看有没有碰，会漏掉哪一格

这四个格子里，最容易被忽略的是第三格，原因很简单：它在所有常见的表格上都是“好”的。阿宁有一次手机屏幕摔裂了，送去修，要三天。那三天里她没有刷任何东西，也没有玩游戏，按理说是“戒”了三天。她后来回忆，那三天夜里她坐在屋里，把可以做的事都看了一遍，发现没有什么想做的。她洗了两次澡，翻了翻书架，躺着看天花板，还给妈妈打了一次电话，说了五分钟就没话了。第四天下午，她拿到修好的手机，在地铁上就把它点亮了。三天里她的行为归零，三天后她和原来一模一样。她自己想了想，说，不是我想它想得厉害，是我手里没有别的东西，一拿到手，那个空就有地方去了。

医院、监管、药物阻断、环境隔离，这些外面的办法都是重要的，有的还是救命的。长期大量饮酒的人，在医生那里把身体稳住，是整个事情的基础，不应该被贬低。我们要说的只是，这些办法能保证“没有用”，保证不了“有别的”。一个人尿检阴性，出了院，没有再进某个场所，手机被收走，一段时间里没有复发，所有形式上的检查都能通过，而他在高风险的那一分钟里，仍然没有一个能自己发动的办法。

这一格有三个让人不放心的地方。第一，短期指标看上去都在变好，没有人会为一个指标全绿的人担心。第二，失败来得没有预兆，一直到旧环境回来，记录里才出现“复发”两个字，那时候再回头看，前面一点预警也没有。第三，它自己会加固。一个机构如果把“没有再用”当成全部成果，它就越来越少去问高风险的那一刻里有没有新的东西出生，因为账本上根本没有这一栏。看不见，就不会有人去补。

家人在这时候也很容易松一口气。老周停酒的头两个月，李红说话的口气都变软了，她说，好了就好。这口气松得很自然，也很应该，谁不盼着他好呢。只是松了这口气以后，家里人的注意力就从“他会不会喝”挪到了别处，没有人再去问四点钟那口气交给了谁。看不见的东西，家里人看不见，医生的表格上也没有，他自己更不会主动说，因为说出来像是在找麻烦。

所以老周的第七次让唐医生觉得，“依从性良好”四个字写下去之后，心里反而更沉。他按时来，按时吃，按时去，所有该做的都做了，每一项都是对的，可是“四点钟那口气交给谁”这件事，没有一项在处理它。这不是他的错，也不是医生的错，是账本上没有这一栏。

## 三个都看，才算走了一半

那么该怎样看恢复呢？九篇长文给了一个很朴素的建议：同时看三件事。**一，旧办法有没有减少。二，新办法有没有增加。三，在最险的那一刻，能不能当场生出不止一条路。**

三样的缺法各不相同。只有第二样，没有第一样，说明新的事做起来了，旧的伤害还在继续，家里人看到他又学了点什么，又去了哪里，也许会放心，其实危险没有退。只有第一样，没有第二样，那是空白的戒断，日子被清空了，没有往里放东西，老周的第三次就是这样。前两样都有，第三样没有，这个人的日常生活变好了，做了不少事，睡得好些，可一到关键的那一刻，窗口里还是只剩一条路，容易在那一刻重新塌下来。

拿老周来试试，唐医生后来在本子上画了三栏。第一栏，旧办法：夜班那几天里，经过便利店的次数少了，但还没有归零。第二栏，新办法：有了发给老高的那个字，有了下楼走货场的一圈，这两样是新长出来的。第三栏，最险的那一刻：四点钟之后，他手里有时候有两条，有时候还是只有一条。三栏摆在一起，她知道下一阶段不用劝他多忍，要做的是把第二栏里的东西演习得更熟，直到第三栏里“两条”变成常态。这样画不是为了打分，是为了知道劲儿该往哪里使。

要用好这三样，还有三个地方得小心，这也是那篇长文作者自己收回来的几句话。第一，想法多，不等于恢复。有人在情绪很高的时候脑子里想法飞快，那不是我们说的下一步，下一步要能动、要能持续。第二，选项多，不等于好。一项 2025 年的动物研究提示，不同的非药物替代物，以及它们的组合，对原来那个需要的影响可能不同，甚至相反。这是动物实验，不能直接搬到人身上，但它提醒我们：不是什么都往里放就行，放进去的东西得安全，得够得着，还得确实能承担原来那件事办的功能。第三，想象出来的未来不算数，没有地方住、没有路费、没有人接电话的未来，只是一个想象。这个人必须有住处，有交通，有工作的入口，有可以相信的人。

阿宁手机里有一份她自己列的清单，叫“变好计划”：冥想，健身，学英语，画画，早起，读书，一共十几条。她说每一条她都很认真地列过，每一条她都没有做满三天。这份清单不能算她的替代未来出生了，它们是愿望的集合，没有第一个动作，也没有第二步，更没有哪一条在晚上九点半那个具体的屋子里有人接应。清单越长，她越觉得自己没用。与其列十几条，不如先有一件在那个屋子里做得起来的，哪怕是收拾明天的包。

有人会问，那吃药算不算？药物治疗和替代治疗是医学里很了不起的成果，这一点我们没有半点含糊。它们做的事，是在身体上把那个被压得很短的时间重新拉长，让人睡得着，疼得不那么厉害，渴求不那么逼人。这本书讲的手续，是医学把时间拉长之后，还要往里放进去的东西，它们可以并排放，不可以互相替换。把“手续”当成不吃药的理由，那就把这本书读反了。

这里要把话说得再坦率一点。这一编的核心提法，叫“替代未来失生”，是九篇里的第一篇，作者自己的定位是一个理论建构，没有做过大样本的验证，那些数目都不是量表，也不能当诊断。他还自己写下了几种会让它站不住的情形，其中有一条写得很死：到 2029 年年底，如果没有一项事先登记、持续跟踪、样本不少于三百人、经过同行评议的研究，在控制了渴求、戒断、抑郁、手边的替代资源这些因素之后，还发现“那一刻别的下一步出生了几个”能独立预测接下来七到三十天的复发，那么它就得降一级，只能当一种描述方式。我们照着这段意思放在这里，是因为这本书的判断站在它的肩膀上，它现在站多稳，我们现在就站多稳。

还有一处，和这本书的母题之间有一点拉扯，我们不打算绕过去。导论里说，酒之所以几年下来越来越包办，是因为它快，别的慢办法没来得及起作用，这是在讲一场竞争，旧办法赢了。而这一篇长文的说法是：在那一分钟里，竞争根本没有发生，旧办法是在没有对手的时候独占了未来。这两种说法能不能接起来，我们的想法是接得起来：前者说的是几年的历史，后者说的是某个具体的当下，历史上赢了很多回，所以当下就没有对手来。但这个接法是我们做的，那篇长文并没有这样说，读者可以有自己的判断。那篇长文也特意承认，有些复发主要是严重的戒断和身体危机推的，有些人是在选项很多的时候主动选了这条路，这些都不适合归到“下一步没出生”里去。

最后一个警告，那篇长文把它放在伦理那一节，我们照着放。一个东西一旦能被数，就可能被拿去考核。老周如果有一天被要求每次来登记都说出两条办法，他很快会学会，说得又快又好听，数据变漂亮了，凌晨四点的窗口还是空的。这就是为什么我们一直强调，数是用来看的，不是用来评的，更不能拿来给谁定什么待遇，或者拒绝谁的什么权利。

到这里，第一道手续就讲完了。它问的只有一件事：别的下一步生出来了吗。可就算生出来了，还有一道关等着它：它能不能比旧办法先动起来。生出来而来不及动的办法，同样等于没有。下一编，我们就去看这一拍，是谁先抢到的。

## 回头看这一编

这一编走完，我们拿老周那个早晨，再用另一种眼光看一遍。先说看得见的样子：他站在便利店门口，手搭在车把上，仅此而已。这个样子是从两样东西里长出来的。一样是一步一步的次序：四点十分的电话，四点半的堵，五点以后只剩熟悉的办法，每一步都把下一步的余地缩小一点。另一样是缠在一起的土壤：把时间压短的身体，跑熟了的老路，撤走了“我”的句子，没有人接应的现实。次序在改写土壤，土壤又决定次序怎么走，门口的样子再写回前面两样。所以光动一样为什么不够？只把酒拿走，样子变了，次序和土壤依旧空着，下一回的样子还是原样。只劝他意志，等于盯着样子，不碰下面的东西。只换环境，窗口若还在，新环境里也会长出同一个窗口。

这一道手续该从哪里起手？眼下最吃紧的是先数次序，把第一个信号到旧办法启动之间的那一小段一步一步摊开，看哪里空着。随后翻土壤，补上人、地方和电话。样子留在最后再碰。对喝了多年酒的人，在这之前还有医生的一步，先把身体稳住，次序才有地方摆。

张力从哪里顶起来？一头是那口气要散，另一头是没有地方可散。两头一顶，逼出两种显露：旧办法，或者一个新的下一步。新的下一步每被生出来又被人接住一回，下一回就更容易；每没生出来一回，旧办法就多一次证明，下一回更难。

这一编怎样算错？如果在背景相近的人里，高风险那一小段中别的下一步出生了几个，对接下来七到三十天的复发没有任何增量预测；或者它只在复发之后才降下去；或者它只是日常生活丰不丰富的另一种量法，那么这一编的判断就站不住了。
