# 第三编　表达：三部分的实现

这一编回答：同一份基因，怎样在平台三个地方同时表达出来。第12章讲一卷三层，正文层给人读，条文层进检索，做法层成技能，三层要对得上。第13章是浏览，侧重显露，第14章到第16章是 ChatSDE 的三章，问对引擎，条文层进 RAG，做法层进 Skill，侧重差异序列。第17章是 SDE 社区，侧重特征纠缠，几位老师共建部落本，一家店调用另一家。第18章讲三部分怎样按三大方程互相回写，缺一部分是什么病。读这一编，不必把三部分当成三个模块去记，要看的是一份基因怎样在三个地方同时被读出来：一个人在书架上翻到一页，在追问器里被问到同一页，在社区里发现别人的一页与它相撞，三次是同一件事。这一编是第二步，子本怎样表达成平台。

## 第 12 章　一卷三层

> **这一章的问题**：同一节书，哪些话给人读，哪些话进检索，哪些话成了照着做的步骤？

### ◆ 一、一页稿子，三种读法

周六下午，作坊散了，孩子们的书包一个个从门口挤出去，罗青禾把椅子摞到墙边，坐下来，把一页打印稿推到林可面前。稿子是她那本《我的作文课》里的一节，章题叫《没什么可写》（新大纲的第3章），节题叫《先别让他写，先让他说》。她说这一节自己读了三遍，顺，也像她说话，下一步就该交给林可去做库了。林可没有接，先问了一句：这一页，将来是谁在读？

“这一页，将来谁读？”林可又问了一遍。“我呀，哪天我忘了，翻出来看。”“还有呢？”林可抽出一支笔，在稿子背面画了三栏，只在第一栏写了个“人”。罗青禾想了想，说店里的智能体，答家长之前要先翻书，把这页切成几小块，挑最像的两块读。林可在第二栏写下“切块”，又问：“再有一种？”罗青禾没答上来。林可在第三栏写“照着做”，说你自己，或者新来的老师，一步一步照着它做。

林可没有解释，拿剪刀把稿子剪成四块，推出其中一块。“有家长问，孩子不愿意写怎么办，智能体拿到的，很可能就是这一块。”那一块的第一句是“先让他说一件今天的事”。罗青禾点头，说对啊。林可翻出另一块：“可是这句在这里。”那是罗青禾自己写的，“这个办法对不愿写的孩子不灵”。两块没有一起被取出来，答案就只剩了前半。罗青禾把笔放下，说那个女孩的妈妈要是来问我，我会先看她脸上的神色，再决定说哪半句。林可说：“机器没有脸可看。”

罗青禾又指着稿子中间一行：“让他说个三句吧。”她说我写的时候心里有数。林可说照着做的人要问，三句还是五句，说了两句算不算。

罗青禾拿过笔，在“切块”那一栏下面写了“条件”两个字，在“照着做”下面写了“几句”。她说，我一直把一节书当成一样东西，原来是三样东西挤在一页纸上。林可摇了摇头，说不是三样，是同一件东西的三种出路。本章要讲的，就是这三种出路在一卷书里怎样分开放，又怎样对得上。

### ◆ 二、正文层：给人读的那一层

先从最熟的一层讲起。正文层就是一本书平常的样子：章、节、段落，有起承转合，有比方，有人物，读的人顺着往下走。第491号第33章讲一本书三份差事时，说过一个家常的意思：一页菜谱，有时照着做，有时翻着查，有时是想自己改，要看当年怎么试出来的。这三种用法里，“看当年怎么试出来的”那一份，靠的就是正文里那些走错又回来的地方。所以正文层不能只留结论，罗青禾那一节里，下面这一段是不能删的：

> 孩子说“没什么可写”，我以前的第一反应是给他一个题目。题目给得越具体，交上来的越像别人的。这一学期我换了一个动作：先不让他写，让他说一件今天的事，哪怕是食堂的饭凉了。他说三句，我听着，数一数里面哪一句是“我看见”的。第一句话，十有八九就在这三句里。可是去年十一月，一个不愿写的女孩，我也这样请她说，她说了三句“不知道”，之后三周没有再来作坊。

这一段是给人读的。它有她的口气，有一个孩子，有一次她不愿多提的失败。读它的人不需要知道“八到十二岁”“小桌”“三人以内”这些条件的精确写法，他从那个女孩的三句“不知道”里，已经读出这个办法有边。正文层的好处是顺，是让人愿意往下读，也让人把自己的孩子放进去。第296号第14章有一句话，说检索把根据带进来，发生要求根据继续面对新问题，正文层干的正是后半句：让一个读者带着自己的新问题，在这一页上站一会儿。

还有一层，是这一节为什么存在。母本第409号里没有一章叫《没什么可写》，这一章是从罗青禾自己的“问”里长出来的。她在画像里留下的原话是：“孩子说'没什么可写'的时候，我到底该先动哪一处？”子本重出大纲时，这句话成了一章的脊梁，所以正文层的写法也跟着变：它不是把母本的一般说法换成作文课的例子，它从她周一课堂上的沉默和周六作坊里的三句话写起。换成另一位老师，这一章要么不存在，要么整段重写。这是第457号所说“母本给的是字，子本给的是话”在正文层的样子，也是第10章的验收闸要去查的东西。

但是顺有代价。一段顺的话，条件常常藏在语气里：“这个办法”指哪个，“十有八九”是几成，“不愿写的孩子”和“没想到可写的孩子”怎么分，作者写的时候心里清楚，页面上没有。第109号第13章讲只给机器读的文本，把这笔账算得很清：为人写作的技艺，有很大一部分是在对付人的局限，其中就有一条，前面说过的不必重说，因为读者记得住。机器按片段取，记不住，那一条就成了陷阱。所以本卷对正文层只提三条要求。其一，每一个会被人拿去用的断言，在条文层里有一个编号，读者在屏幕上点一下，能看到它的七件；纸上则用页脚小标号。其二，走错的路写进正文，不许只留成功的那一遍。其三，正文层不替条文层做主：一句话好不好听，是正文层的事，成不成立，是条文层的事。还有一点，本卷把正文层当作本人认领的主要对象。规格八里认领的三件事，确认大纲、改过正文、写下第一页失效页，其中一件就是改正文。机器起草的正文再顺，没有经过她的手，就仍是胚胎；罗青禾那一节里，“我插话的时候他把嘴闭上了”这样的句子，只有她自己能写，写进去，这一节才开始是她的。

### ◆ 三、条文层：给检索和给本人对账的那一层

条文层把同一节书里能成立或不能成立的话，一条一条拆出来，每条按七件写：主张、成立条件、来源事件、失败记录、归属、保质期、牵连。这七件承第109号第1章，那里讲的是一条个人知识要齐哪几件才算完整；第414号第24章拿一位掌勺的师傅演示过，老赵那句“这道菜用中火”，条件长在话里，来源是去年的一回做糊，保质期是“换成电磁灶，我这一套就不作数了”。本卷把这张自查清单改成了可存、可检索、可对账的条目，另加两样东西：来路标和分层。下面是罗青禾这一节拆出来的第一条。

| 件 | 内容（本书为说明而拟的示例） |
|---|---|
| 编号 | T-009 |
| 主张 | 孩子说“没什么可写”，先请他口头说一件今天的事，三句，再动笔 |
| 成立条件 | 八到十二岁；他是没想到可写，不是不愿写；孩子写了但不愿让人看时，先问他想不想让你看；小桌，三人以内；老师三分钟内不插话 |
| 来源事件 | 二月，周六作坊，一个五年级男孩说食堂的饭凉了，三句里的第二句后来成了他作文的开头 |
| 失败记录 | 上一年十一月，对一个不愿写的女孩用同一办法，她答了三句“不知道”，此后三周没来 |
| 归属 | 罗青禾；错了算她的 |
| 保质期 | 满一学期复检；孩子升入初中，作废重试 |
| 牵连 | 连 T-010、T-011，连做法卡 K-009 |
| 来路标 | 说的 |
| 分层 | 主张与判据段可出库；成立条件原文、来源事件、失败记录永不出门 |
| 状态 / 所属代 | 已兑现 / 第二代 |

这一条里，凡是“何时会错”的话都落在条件和失败里，凡是别人调用时需要的话都落在主张与判据段里，两部分分开放，是承第109号那把刀：“撤回权私有，推翻权公有。”主张层可以被别家的智能体取用并当面反驳，条件层却是罗青禾自己的日子，只在她的库里。分层写在每一条上，而不是写在整卷上，因为同一卷里，有的条文她愿意让别人用，有的不愿意，开门的粒度要和判断的粒度一样细。

成立条件里“孩子写了但不愿让人看时，先问他想不想让你看”这一句，不是第一天就有的。它是二月认领那天，豆豆一页日记撞出来的：他说“我写了，可是你会看”。罗青禾把这件事写成了这一卷的第一页失效页 F-001，又回头加进这一条的成立条件。条文随失效页多长一句，旧的不擦，加在后面，这是第20章要讲的事，这里只借它说明一件事：条文的条件栏，是被日子一句一句撞出来的，不是坐下来想全的。

来路标是本卷加的第二样东西，承第414号第18章的料单：补维问出来的东西，要分开记，哪条是用户亲口说的，哪条是从现场或记录里取来的，哪条是机器自己推出来、还没被核对的。罗青禾这一节还有两条，正好是另外两种来路。T-010 的主张是“卡住有价值，可卡住不等于学：先卡住，再给场”，来路标“取的”，取自第409号导读四第六条，对应母本不变量清单里的 I-04。它的成立条件只有母本抄来的一般条件，落差刚好、有人在、孩子还有力气；来源事件、失败记录两栏空着，标“待本人给”：母本给的是一般的话，“在我的孩子身上何时成立”只有她能填。T-011 来路标“推的”：机器翻她三年教案笔记，数出“没什么可写”多出现在周一作文课，周六作坊里很少，于是起草了一句“这多半是课堂场合的反应，不是孩子的毛病”。这一句机器能起草，它的来源事件却写不出来，因为没有哪一次具体的事可以指给人看，所以那一栏也空着，状态是待验，在她认领之前不出库。

三条放在一起，罗青禾第一次看清自己这一节里哪句是自己的、哪句是借来的、哪句是机器的猜测。这件事在正文里看不出来：三种来路的话在正文里一样顺。第109号第13章里有一条分工线，允许AI代笔，不允许AI代经历、代判负、代承接，条文层的空栏就是这条线画在页面上的样子。它也是第414号“缺维时宁可停下来问，也不许补编”的落点，空栏不许机器补上一个看着合理的来源，只能留着，等她哪一天想起那件事，亲口填进去。

七件里有两件平时最不起眼，到了出事的时候最有用，一是保质期，一是牵连。保质期是给一条判断写好它到期的日子：T-009 写的是“满一学期复检”，到了日子，系统只做一件事，把这条的状态从“已兑现”提醒成“待复检”，由她决定续、改还是撤。牵连是给一条判断写好它撑着谁、被谁撑着。哪一天 T-009 被一个孩子推翻，系统顺着牵连一查，立刻知道正文里有两处引用它、有一张卡依据它、有一条机器的猜测和它互相呼应，这几处都要回头看一眼。没有牵连一栏，推翻一条判断就只能靠记性去找它的影响，记性是最靠不住的索引。

一节书拆出多少条，没有固定数。罗青禾这一节拆出了七条，其中三条她一眼就认为重要，两条是母本抄来的，两条是机器猜的。拆得太粗，一条里塞进三个主张，保质期没法写；拆得太细，成了一句一条，牵连的线乱得没法看。本卷给的经验口径是：一条一个主张，一个主张至少能写出一个“何时会错”，写不出来的，先留在正文里，不立条〔待验〕。

要说清条文层和第109号第13章的关系。那一章讲的机读文本，有三条判据，头一条是预期读者为零个人，写的时候就不打算给人读。条文层不满足这一条：罗青禾要认领它，要在每次季度收口时逐条看，林可建库时也要核对，它至少有三种人读。所以本卷只借了机读文本的几条写法：每条自足，不靠上下文；失效优先，先写何时不成立；可检索，先写大家会搜的说法，再给自己的精确词。没有借“没人读”这个前提，因为有人读，空栏才会被人看见。

### ◆ 四、做法层：给人和智能体照着做的那一层

条文回答“什么时候成立”，做法层回答“怎么做、做到哪儿停”。做法层的单位是工序卡，承第492号第25章书房的卡：工序名称、做法、这一步你是怎么知道的、在什么条件下要换做法、徒弟复现情况。本卷把它改成六栏加一个依据：名称、适用条件、步骤、检查点、跟做记录、状态，另有“依据条文编号”，一张卡必须指回至少一条条文，指不回去的卡不收，这样一张卡为什么这样做、什么时候不该这样做，总有地方可查。罗青禾这一节拆出两张卡，第一张如下。

| 栏 | 内容（示例） |
|---|---|
| 名称 | K-009　先说一件今天的事 |
| 适用条件 | 同 T-009：八到十二岁、没想到可写、小桌三人以内 |
| 步骤 | ①问“今天有什么小事”，不问“为什么”；②孩子说，数到三句，期间不插话；③圈出其中一句“我看见”的；④原话念回去，问“这句要不要当第一句”；⑤孩子点头才写，摇头回②，最多两遍 |
| 检查点 | 第④步孩子是否自己改了一个词（改词，说明认了这句）；连续三次说“不知道”，当天停，不再追问 |
| 跟做记录 | 3月14日　罗青禾　男孩B：第一句写出。4月11日　罗青禾　女孩C：改词后写出。5月9日　罗青禾　男孩D：三次“不知道”，停，未写出（我中途插了话）；卡上第⑤步与实际不符，已改。5月23日　罗青禾　男孩E：按改后的第⑤步照做，写出 |
| 状态 | 已跟做 |
| 依据条文编号 | T-009 |

这张卡的跟做记录有四行，四行里有一行是失败，还有一行写着“卡上第⑤步与实际不符，已改”，改完之后又照做了一回，才算数。罗青禾是隔了两周才照卡做的，一步一步照，不凭记忆。她说头一回照做，发现自己口述时漏了“圈出一句再念回去”，机器排卡时也不会知道这一步该有。第492号讲徒弟照卡做的十块板，三处差异要先查卡、不先查徒弟，这里是同一个道理，只是徒弟换成了第二天的自己。

第二张卡 K-010，名称是“提纲放到第二步”，依据是 T-010，也就是那条取自母本的话，正好是“先卡住，再给场”的做法版：先让孩子卡一会儿，提纲放到第二步再给。它的适用条件机器写了，步骤也写了，罗青禾还一次都没有照着做过，所以状态只能是“待跟做”。待跟做的卡不进 Skill，跟做闸的规矩见第16章。留在做法层里的这张卡，可以看，可以提醒她去试，店里的智能体却不能把它当作照着走的步骤；它挡掉的是一种很顺的错误：机器把母本里一句漂亮的话排成五步，看起来像做法，其实没有人在任何孩子身上走过。

做法层还有一个状态叫“已退役”。条文的保质期到了，或者失效页里写明那个读法不再成立，依据它的卡就要被复核，复核不过就退役。退役的卡不删，夹在新卡后面，像第492号何师傅的卡片，旧版用夹子夹在新版后面。

工序卡和提示词很容易被混为一谈，因为两者都是“告诉智能体怎么做”。第109号第13章在这里画过一条线：提示词是指令，规定行为；知识提供判断依据，告诉系统在什么情形下什么成立。工序卡站在两者之间，所以它必须带着依据：每一步旁边写明“这一步你是怎么知道的”，卡头写明适用条件，卡尾指回条文。没有这些，它就退化成一段提示词，换一个孩子、换一个年龄、换一间教室，它照走不误，没人知道它什么时候该停。卡的版本怎样管，被别家调用时守什么规矩，是第16章的事，这里只立一个前提：卡的依据在条文层，条文变，卡要跟着复核。

### ◆ 五、三层怎样对得上

这个分法并不孤单。Karpathy 的 LLM Wiki（2026）把原始资料、由模型维护的 wiki、配置文档分作三层；Anthropic 的 Agent Skills（2025年10月）把做法写成带 SKILL.md 的文件夹；Notion 3.0（2025年9月）让一页可编辑的说明充当智能体的记忆。它们说对了一件事：做法可以写成人和机器共读的文件，知识可以分层存放。本卷多走的一步在别处：三层从同一条判断拆出，每条带来路标和失败记录，状态随跟做和失效页变，归本人。多走的这一步，要靠下面的对账才站得住。

三层放在一卷里，最容易出的事不是缺哪一层，是三层各说各话。正文里有一句“这个办法对大多数孩子都灵”，条文层里找不到对应的条目，这句话就是口号；条文层里有一条写着“对不愿写的孩子不灵”，正文里从来没提过，读的人在屏幕上点开才看见，这是暗账；一张卡指不回条文，是没有根的做法。林可给罗青禾画的对账表就是查这三种病，一栏正文里的断言，一栏对应的条文编号，一栏依据它的卡，三栏之间连不上线的，就是要补的地方。第491号讲三层之间打架听谁的，规矩是判断卡是正文的压缩，不是正文的替身，卡上写的每一句要在正文里找到出处，找不到，改卡不改正文。本卷把这条规矩往前挪了一步：条文层和做法层不是正文的压缩，它们各有自己的来路标和状态，所以对账时谁错了不一定改谁，要看缺的是哪一件。

三层之间还有一种互相规定的关系，不是谁管谁。正文怎样显出来，取决于条文里写了哪些条件、做法里走过哪些路；做法里的步骤会因为条文的边界改变，条文的保质期到了，做法就要复核；做法层的跟做记录里撞出了一个新情形，条文层要长出一条新的失败记录，正文也要跟着改一段。三大方程在这里不是三个标签，是三层改动的传导：改了一层，另外两层受牵连，而且常常是两层先撞出分歧，第三层才动起来。罗青禾跟做 K-009 时，是做法层（她的步骤）和条文层（T-009 的条件“老师三分钟内不插话”）先对不上，因为她在男孩D那里插了话，然后才轮到正文，她把那一段加了一句“我插话的时候，他把嘴闭上了”。这一节书的起手次序也值得记下，用六路径的话说，它不是从形状起手：先有她做过的那一遍，也就是路，再浮出正文的样子，最后才追到条件那块土。每一卷、每一节的起手可以不同，只要记下它是怎么起的，将来对账时才知道先查哪一层。

对账什么时候做，由谁做，也要说清。本卷把它放在两个时点：一是认领，本人确认大纲、改过正文、写下第一页失效页的那一回，对一遍；二是每季度收口，合并重复、清掉过时、集中列分歧的那一回，再对一遍。前一类，“正文断言有无条文”“卡有无条文”两问机器可以跑，只数不判；“条文空栏该不该补”“这条主张是不是被正文讲歪了”，必须本人看。罗青禾头一回对账，机器列出十一处对不上，其中六处是正文里的口气词，如“大多数”“通常”，她逐处判：三处补成条件，两处删掉，一处承认自己其实不知道，改成“我只见过这几个”。对不上的地方，不一定补，诚实的做法有时是把正文那句话降下来。

失效页不在三层里，但三层都要对着它。条文层第四件“失败记录”是一条判断自己挨过的打，随条文走；失效页记的是整卷读法的突变，“我上次以为是什么，后来发现不对”，独立成页，只加不改，第20章专门讲。两者互相指：一条失败记录如果撞开了一个读法，就要指向一页失效页，一页失效页如果推翻了一条条文，就要把那条条文的状态改成已失效，并让依据它的卡进入复核。

WDS博士在2026年10月27日说过：“子本是用来发生的，是个人知识平台的发生基因RAG 和Skill 的生成基因”。这句话在一卷三层里落成很具体的两条通道：条文层切块、按七件进库，是RAG的来源；做法层经过跟做闸，是Skill的来源；正文层不进这两条通道，它留给人读，也留给本人认领时改写。本书把“基因”当作借喻，归入符号遗传一类，借的只有一个意思：同一条东西，在三个地方被读出来，三处读出来的要对得上，对不上就是变异，变异要有记录。借喻不当证据，本卷不拿它证明什么，只拿它说明为什么要对账。

## 第 13 章　浏览：侧重显露

> **这一章的问题**：一个人的书架上能看到什么，由什么定？

### ◆ 一、周叔的书架

周叔的手机字号调到了最大一档，一行只放得下九个字。他把手机立在老花镜旁边的书架上，对着它说了一句“读一下”，手机里一个平缓的声音念起来：“第一格，一本。母本，公开。第二格，一本。慧店专著，署名周建国，二十来位口述人入来处登记，由周建国定价。第三格，一本，只有三页。部落本，三位邻居各自认出来的，对本楼开放。第四格，一本。子本，署名周建国，只有本人能看。”

念完，他半天没说话。林可平日在长沙读书，那个周末她来了佛山，此刻坐在旁边的小凳子上，面前摊着她画的格子表，也不催。过了一会儿，周叔说，这个报法，我听得懂。我年纪大了，最怕的是拿起一本，不知道是书上写的，还是谁随口说的，还是我自己写的。药剂科干了一辈子，一瓶药没有标签，我是不敢发的。林可说，书架上每一本都有标签，先念标签，再念书名。

他又问，这第四格，别人看得见吗？林可说，现在看不见，您不打开，谁也看不见。周叔点点头，伸手在屏幕上点了一下，一个小锁的图案亮着。他说，我不是怕人看，是我还没想好，里面有几句我自己都不太想承认的话。林可没有劝，在表上第四格那一行写下“默认关门”四个字，旁边画了一把小锁。

林可问他，要是邻居来串门，想看这四本，您想让他看哪几本？周叔掰着手指头数：第一本，谁都能看；第二本，我写的，二十来个老街坊都有份，邻居看得；第三本，三页，是我们几个一起认下来的，本楼的看；第四本不给看。数完他自己愣了一下，说原来这四本，就是四种“给谁看”。林可点头，在表格最左边加了一列，写“谁能看”。

周叔让手机把第四格再念一遍，这回他闭上眼睛听。念到“子本，署名周建国”，他笑了一下，说，这个署名念出来，跟印在书上不一样，像有人在叫我名字。林可没有记这一句，可是她后来在设计稿的边上写了一行小字：浏览不只是看，还要能听，念出来的第一句话必须是标签。这一章就从这一格书架讲起。

### ◆ 二、书架住在一个地址里，按“问”分格

先说书架放在哪里。第439号第10章讲个人平台的时候，有一节叫“每人一个自己的地址”，那里的意思很清楚：账号是别人家里的一间客房，地址是自己的门牌。书架就挂在这个地址上，门里的东西怎么摆、谁能进来、进来看什么，由本人定。浏览是个人知识发生平台三部分里侧重显露的那一部分，显露在这里的意思很朴素：一个人手上的知识，要被他自己看见，被他同意的人看见。看不见的东西谈不上读，更谈不上发生。

再说书架上放什么。一个人的书架上，同时会有四种书：母本，是经 SDE 方法抽出不变量的通用专著，公开；慧店专著，是某个店主为自己的部落写的书，由店主定价租调；部落本，是几本子本相撞之后长出来的，一页要几个人各自认出来，才算大家共有，经贡献者同意才共用；子本，是母本与一个人的画像相遇之后重新打造的整本书，默认关门，本人打开才可租、调、挂。这四种东西，来路不同，归属不同，能给谁看也不同。

最容易想到的摆法，是按类型分层：最上面放母本，往下是部落本，最下面是子本。第439号第8章专门提醒过，把母本、部落本、子本当成自上而下的三级，就退回了“应用”式的单向套用：上面是定好的，下面是被套的，没有一处能回头。所以本卷的书架不按类型分层，按“问”分格。周叔在画像里留下的“问”，是他自己的原话：“楼里这些老人的药盒，哪些该照书上来，哪些是书上管不到的？”书架上第一块格板就是这一问，和这个问题有关的四种书都放在这一格里，母本、慧店专著、部落本、子本并排，每一本的书脊上有同一套标签。下表是这一格念出来的内容。

| 格内顺序 | 书名（示例） | 类型 | 署名 | 谁能看 | 流法状态 |
|---|---|---|---|---|---|
| 1 | 他选的那本母本（示意） | 母本 | 示意母本（站上无此书，署名从略） | 公开 | 七种皆可 |
| 2 | 《我们楼的药盒》 | 慧店专著 | 周建国；二十来位口述人入来处登记 | 对外，周建国定价 | 已挂于邻小区一家店 |
| 3 | 《我们楼的提醒》 | 部落本，三页 | 三位邻居（本楼内署名，出楼脱名） | 本楼 | 部落内可挂、调 |
| 4 | 《我的药盒》 | 子本，第二版 | 周建国 | 仅本人 | 关门 |

第3行的部落本是本章为说明而设的示例，不是前面章节里已经出现过的东西。它只有三页，是因为有三页是三位邻居各自在自己的子本里写下、又各自同意拿出来的。其余只有一个人认的页，按第439号的规矩，留在他自己的子本里。周叔每次让手机念这一格，念的顺序是固定的：类型，署名，谁能看，然后才是书名。固定顺序对他很要紧，他说，药剂科取药，也是先核对标签、再看药名，顺序一变就容易出错。

大字和语音不是附加功能，是这一层的底。本卷对浏览层给周叔这样的读者定了几条做法，都是本书的设计，要在老人手上试过才算数〔待验〕：字号分三档，最大一档一行不超过九个字；朗读可以随时停、随时退一句，语速由读者调；表格不念竖线，念成“第几格，书名，类型，署名，谁能看”；每次只念一个层次，念完这一格问一句“要不要往下”，不一口气念完整座书架。周叔试了半个下午（场景为示意，不算试用结果），提了一条林可没想到的：念到“关门”两个字时，他希望有一声很轻的响动，像柜门合上。林可记下来了。听觉上的锁，比一个看不清的小图标可靠。

按问分格有一个明显的危险，就是越用越顺，越顺越窄。第296号第21章谈过，读者的个性化服务不应变成认知舒适区的自动扩张。本卷的办法是在每一格的末尾放一个抽屉，叫“没排进你书里的”，里面是母本中没有被他的问接上的章节，也就是第8章缝隙单里“贴不上的”那一部分。抽屉默认是合着的，书架每周念一次抽屉里有几章，不替他打开。它做的事很小：让他知道，他的书是从母本里挑出一条路走过来的，路外边还有别的东西。

### ◆ 三、能看见什么，由问对和部落定

浏览的设计有一个最容易犯的错，是把“能看见什么”交给点击量，谁读得多就排在前面。一个人的书架上，这样的排法会很快变成另一个人的书架，因为大家点的差不多。本卷换一个依据：用 S＝F(D,E) 的话说，书架此刻显出哪一格、每一格里谁能看见谁，由他问出来的路和他与这座楼里的人缠在一起的方式一起定，不由别人的点击定。

先看问。周叔的第一块格板是“哪些该照书上来，哪些是书上管不到的”，这个问不是系统猜出来的，是他在语音里一字一字说、林可陪着记下来的原话，写在画像的“问”里。有了这个问，这一格才有四种书可放。要是他换了问，比如“药盒到底该按时间摆，还是按药名摆”，同一本母本会被挪到另一格，翻开时头一页也不同，因为重出大纲时被他的问接上的章节变了。同一本母本，在罗青禾的书架上是另一个样子，那里的格板是“孩子说没什么可写”。这就是第8章所说，画像改写的是路径，书架只是把改写后的路径显出来。

再看部落。第3行那本部落本为什么只有三页，不是因为系统筛选，是因为按规矩，一页要几个人各自认出来才进部落本，一个人认的页留在他自己的子本里。第2行那本《我们楼的药盒》被邻小区挂着，是因为周叔点了头，来处登记里的二十来位口述人也同意。这一格里谁能看见谁，不是算法排出来的，是一次一次同意累积出来的。同一格书，换一个读者站在门口，看到的行数会不一样：邻居看到第2、3行，邻小区的店主看到第2行，外人只看到第1行。

书架上看见的东西，反过来又会改他下一步问什么。有一天周叔让手机念第3行，念到一页邻居写的话：“晚饭后吃的药最容易漏。”他停下来，说这一条我从来没往这里想过，我一直以为早上最容易漏。他在语音里问追问器为什么，追问器没有给答案，问他哪一天漏过，这是下一章的事，起点却是书架上的一行字。那一刻书架重新排了一次，第3行升到第2行上面，因为他的“书上写的”和邻居的“晚饭后”先撞上了。这个排法是本书的设计，要在实际用起来的书架上试，试出来写进以后的版次〔待验〕。能确定的只有一点：排法的依据，是本人的问和同意过的纠缠，不是别人的点击和停留时间。书架没有排名，没有点赞，也不默认公开，这三条第439号第10章已经立下，本卷的浏览层照做。另外两条方程在一周里怎样转起来，留到第18章看。

有人会说，按点击排，至少省事。省事，这一点不假，代价是书架会逐渐变成一块广告牌。一个人今天点了三次“错药”，明天书架就铺满了错药，后天他连自己为什么点都忘了。按问分格要多做一件事：每隔一段时间，由追问器问他一句，“这一格的问，还是你现在的问吗”。他说还是，格板留着；他说不是了，格板换成新的问，旧的问连同它的格子一起收进版本页，不删。格板跟着他的问走，书架才不会自己走。

### ◆ 四、版本、差异与失效页

书架上不只有书，还有书的历史。每一卷子本每重出一次大纲、每经一次认领、每完成一轮回写，就长出一个新的版次。旧版不删，并排保存。周叔那本《我的药盒》现在是第二版，第一版是第10章里被换名测试拦下来的那份稿子，它没有被销毁，标着“退回”，躺在书架的版本页里。他问，留着那份不对的做什么？林可说，您后来改了哪里，要对得上它才看得出来。

系列总目是书架的脊柱。第19章会讲，一个人的子本一卷卷长成一个系列，总目里每卷一行：卷号、卷名、类型、所出母本、当前代、创新层级、释放状态、上次收口日期。周叔目前只有一行，类型是专题卷，当前代是第二代，创新层级是对自己新，释放状态是关门。这一行念出来只有一句话，可是一个人的系列长到五卷十卷以后，总目就是他自己的本体论的目录，哪几卷走在前面，哪几卷停在胚胎，一眼看得见。

版本旁边是差异对照，本卷定了两种。一种是版与版：这一章换了、那一章新增、这一章没动，每一处差异后面写明原因，指回哪一次认领或哪一页失效页。另一种是子本与母本：第10章验收闸里的 G3 大纲对照，在书架上显成“母本各章的去向”，取、压、弃，三种去向列成表。第489号的 v4.0 附过这样一张去向表，交代母本哪些章被压缩、哪些没有单列成章，本卷把它从附录挪到了每一卷都带着的位置。语音念差异，念得很短：“第三章，换了，原先讲药名排序，现在讲时间排序，见失效页 F-001。第六章，新增。其余没动。”

差异对照这件事，前人做过不少。Ted Nelson 的 Xanadu 在1960年代就提出过对不同版本做对比的设想；2025年4月有一篇推广文章主张书应当像软件仓库一样可以编辑、更新、分叉，附变更日志。它们说对的是版本可以并排看，变化可以逐处列。本卷多走的一步很具体：每一处差异记下是谁改的，本人的、机器起草的、还是由哪页失效页引起的，三种改动在书架上标法不同。因为机器起草的改动没有经过本人认领，就不能和本人的改动并排放在一个“已更新”里。

周叔的第二版里就有这样一处。机器根据他新说的几句话，起草了第五章的改动，把“早晚各一次”改成了“按餐前餐后”。差异对照里这一处灰着，标“机器起草，待认”，语音念到这里，会多念一句：“这一处你还没有看过。”周叔听完，说这个我要看，看完说不对，药剂科的“餐前”和老人说的“饭前”差着半小时。他把这一处退回，差异里改标“已退回”，机器起草的那一版仍留着，将来对得上。一处改动从起草到认领或退回，状态是看得见的，这比一句“已更新”诚实。

失效页在书架上单独占一页，按时间排。第439号第10章的那句话是：“第五样是失效页，单独一页，按时间排。”它不混在正文里，因为正文只显示现在的读法，旧读法一旦被覆盖，这个人就再也找不到自己上次怎么读错的。失效页的每一条按规格六的字段念：记于哪天，上次的读法，当时凭什么这样读，后来是什么撞开的，现在的读法，还没读透的地方，谁在场。语音读到“现在的读法”之前，会先停半拍，因为第一次听的人容易把旧读法当成现在的结论。周叔第一页失效页是 F-001，记的就是他那句“书上写的”，旧版指向《我们楼的药盒》第一稿序言的第2页，点一下就跳过去。第20章专讲这页怎样长出来，这里只看它的位置：书架最下一格，默认从最近的往前翻，“再早一页”一句话就能退回去。

这一页有三个限制。只加不改，旧的不能被擦掉；每一页必须指得回旧版的位置，点一下就能跳到那一版的原话；它永不出门，不管后面的书开到哪一级，失效页入口只对本人显示，别人的书架上这一格是空的。它也没有点赞和排名，第439号第10章说，失效页不是展示柜，没有人给你鼓掌。

### ◆ 五、租读与挂：书架上的交易

第491号第35章把专著流进慧店的走法理成七个字：买、租、调、挂、授、定、分。这七种里，进到浏览层、由人来读的，主要是租和挂。租是按期使用，到期收回；挂是把一本书挂在自己店里，供部落里的人翻。调不一样，那一章说得清楚：挂和调的区别在于，调是机器去翻，挂是人去翻。调走的是智能体的检索，是下一章起的事；买、授、定、分，一个是整本过户，三个是创作和结账，都不在书架上发生。

周叔的《我们楼的药盒》在第2行，书脊上多了一块小牌子：“挂于邻小区一家店，范围：该部落内，至11月30日，署名：周建国，口述人入来处登记。”这块牌子念出来是一整句，三个信息一样不少：挂在哪里，到哪天，署的是谁。第491号那句话在这里落成了字段：不管调还是挂，书的署名和出处必须跟着走。读的那一头也一样，邻小区的人读这本书，要有名分，不是任何路过的人都能翻，读一次，记一次来路，谁读的、读了哪一章、何时，这是第26章要结账的依据。

名分这件事有两头。读的人要有名分，是附录一规格十二里的一条；部落本的贡献者则要脱名，并且可以撤回。两者合起来，书架上才有了一个比较细的规矩：本楼的人读《我们楼的提醒》，看得见每一页是哪位邻居写的；这本部落本若被挂到别的小区，署名换成“本楼邻居”，原来的名字不出楼。哪位邻居哪天想撤回自己那一页，点一下，那一页在所有挂着它的书架上同时摘下，读者端不再留存那一页，已经被人抄走的防不住，来路链里记着谁读过。这个动作在设计稿里叫“摘页”，周叔起的名字，他说药房退药也是这样，单子上画一道，不是擦掉。

子本能不能租，要看规格九。规格十给子本留了租（只租读）、调、挂和分，不可买，不可授，也不可定；可是周叔这本《我的药盒》现在是第二代，对自己新，第三代以前一律不出门，到了第三代而仍是对自己新，也只记发生，不进市场。所以眼下，楼里那位老药师只能以陪读人的身份，由周叔请来，坐在他旁边看，书架上不会出现任何一条租读的状态。等这一卷长到第三代，又有三位邻居各自回写“在我们这儿灵”，认定为对部落新，门才可以由周叔来开。

到那一天，他要一页一页过目：哪几页可读，哪几页不可读，条件层的原文无论如何不出门，租读者能看到的是正文层里他同意开放的页，以及条文的主张与判据段，每一段后面带着来路标。到期那一天，租读者端的访问收回，他手里留下的是自己的读后笔记，不是整本书的副本。用而不过户，是这里的意思。租读者读到的页脚会有两行小字：“本页由周建国开放，来路：说的”“条件层未开放”。读的人因此知道，他读到的是一本书的一部分，没读到的部分不是不存在，是主人没有给。老药师读完可能会说“你这里漏了配伍禁忌”，漏没漏，要先看那一页开放了没有。

周叔当场就问，要是哪天我借出去了，人家会不会抄走？林可说，抄是防不住的，防得住的是账：每一次读都有记录，来路一丢，系统不计费，也不允许继续用。周叔想了想说，这跟药房一样，药可以拿走，发药的单子要留底。这句话其实说中了本卷的态度：浏览层没有办法让一本书不被记住，它能做的是让每一次被读都留下一个能追的底。

书架上的这些状态，念出来都是一句话：“未开放”“租读中，至某日，读者某某”“挂于某店，范围某某，至某日”。这些状态在书架上和第三节说的那些标签是同一套，周叔不用学新的东西。他唯一多问的一句是：我要是忘了关呢？林可答，租期到了自己收回，关门是默认，开门才要您点头。

## 第 14 章　ChatSDE（上）：问对引擎

> **这一章的问题**：机器怎样问，才算把一个人的缝隙问出来，而不是把他说过的话存起来？

### ◆ 一、夜里十一点，卷帘门拉下一半

佛山这一带，夜里十一点才是外卖骑手最后一拨人下线的时候。阿乐把卷帘门拉到齐腰，蹲在门里收工具，手机斜靠在扳手盒上，屏幕亮着。他手上全是黑油，没法打字，就对着手机说话：“今晚最后一个，是老刘的车。”手机里的声音很平，不像客服，也不像朋友：“老刘是谁？”“送夜宵的，跑这一片，在我这儿修过三回了。”“这一回他来，是为了什么？”阿乐想了想，说电池掉电快，其实没大毛病，他拆开看了，半个钟的事，可老刘说，你们修车的就爱拆。老刘前两回来，一回是刹车线，一回是充电口，每回都是修完付钱、扫码就走，一句话不多留，走的时候还低着头划手机。阿乐一直觉得这个人难搞，疑心重，今晚是头一回把这几次的事连起来说：同一个人，一回又一回回来，每回修的还不是同一处。

“他说这句话的时候，你手上在做什么？”这一问把阿乐问住了。他本来想说“我在给他解释”，话到嘴边换成了另一句：“我拿着螺丝刀，对着他的电池仓。他站在我旁边，看着手机。”“他看手机的时候，你看见了什么？”阿乐把扳手放下，半晌才说：“……看见他在看单。屏幕上有个倒计时。”手机没有接话。铺子里只剩冰箱压缩机嗡嗡的声音，隔壁烧烤摊的烟顺着门缝飘进来。过了几秒，那个声音才问：“你想接着往下说吗？”他说：“说吧。”这一问他后来想了好几回：它问的不是“你还有什么要补充”，而是问他愿不愿意，答案里留着一个“不”字的位置。

这是阿乐第三次和追问器聊。它不像他用过的那些软件，一上来先夸一句“你做得很好”，也不给建议。每一次它只问一句，等他答完才问下一句，而且一句比一句小，像拿万用表量电压，一次只搭一根表笔。有一回他忍不住问它：你怎么不告诉我该怎么办？它答得很直：我手上还没有你的日子，先要你说。

他的子本叫《我的入口》，画像“问”那一栏里登着他自己的两句原话。主问是：“我修好的车，为什么总有一部分会回来？”第二问是：“怎么让骑手别老觉得我乱收费。”老刘就是回来的那一部分里的一个。今晚阿乐开口先说的是第二问，追问器就从它问起，问了二十分钟，没有得到一句回答。可是阿乐发现，自己说出了一件这几年从没说出口的事：老刘盯着的是倒计时，不是他的价钱。他把这一点记在心里，想明天再捋一捋，手机里的声音却先开了口，问他今晚还想不想再往下走一步。本章要讲的，就是这样一台机器的问法：它为什么这样问，它问出来的东西为什么不同于“记得你说过什么”。

### ◆ 二、五条问法：一次一问，不带答案，允许空着

第439号《未来的知识经济主流产业：从母本到「我的……」》第10章给追问器立过几条问法的讲究。本书照收，并改成能写进程序、能事后检查的规则，前四条管怎样开口，第五条管问到别人。

第一条，一次只问一句。第439号写得干脆：「一次问一个，别问一张表」。阿乐的铺子就有现成的证据：开张头一年，他印过一张登记表，十四栏，车号、电话、购车年份、常跑路线、充电习惯，一栏不少。骑手们站在柜台边，手机里的单还在响，一栏都懒得填，电话号码一律写成一串零。表不是没用，是印表的人没算过对方此刻有几分钟。机器也一样，追问器每次只递一句，那一句小到可以顺口答，答完才轮到下一句。

第二条，不带答案去问。如果追问器开口就说“他嫌贵，所以你怕被投诉，是吗”，阿乐多半会说“对，就是这样”，因为这话听着有理，而且他困了。问句里已经塞进了答案，人只剩点头和摇头，他自己的那一块就没有地方放。所以追问器问的是“他说那句话的时候，你手上在做什么”，这样的问句没有现成答案可抄，只能从那个晚上里取。第439号的说法是「别带答案去问」，落成规则就是：追问器的问句里，不得出现本人还没说过的判断、原因和情绪词；它可以引用本人说过的话，不可以替他先说。

第三条，允许说“没有”，允许说“不想答”。同一章的原话是：「允许说「没有」，允许说「不想答」」。一个必须每天都有答案的平台，会逼着人编答案，编出来的话一旦进了库，比空着更糟，后面所有的撞都会建在它上面。所以“没有”“不想答”“现在答不上”都是正式的回答，都要记下来，记作“这里先别碰”。比方追问器问起上个月赔掉两百块的那一单，阿乐说不想答，系统就在那一问旁边标上日期和“本人未答”，当天不再问，也不换个说法绕回来。隔多久可以再问一次，由本人在设置里定；默认是不主动再问。这是本书的设计，尚未试过〔待验〕。

第四条，允许用嘴答。阿乐手上有油，手机在扳手盒上，他不想为了打字去洗手。语音进来的话转成文字时原样保留，不改成书面语：他说“冇得”，库里就写“冇得”。第439号对余桂芝那句夹着方言词的话说过同样的意思，方言词常常正是那个字最本地的读法。要是转写时顺手改成“没有”，库里存下的就是一个标准化了的阿乐，下一次撞的时候，撞到的是转写员，不是他。

第五条，问到别人要小心。老刘的话、老刘盯着倒计时的样子，进了阿乐的库，只算阿乐眼里的老刘，不算老刘的档案。追问器不替阿乐去查老刘的单量，也不拿老刘的名字去别处问；哪一天要把这些做成部落本，得先问过老刘。

这五条看上去像礼貌，其实是在守同一件事：进库的每一句，必须是本人那个晚上实有的东西。拿三大方程里的 D＝G(S,E) 来看，第四条的道理最容易说清。问对的路径是 D，它由已经显露的东西 S 和缠在身边的东西 E 共同规定；阿乐手上的油、夜里十一点的疲倦、手机里还在跳的骑手群，都属于 E。问法要是无视 E，下一句问什么就成了追问器一个人的独白，库里存下的只是它想听的话。

### ◆ 三、拆题与补维：缺了的那一维，宁可停下来问

阿乐的第二问，追问器没有去答它，而是先看它。这是第414号《SDE智能体到底能做什么？》第17章的第一个动作：「问题不是合同」，而是第一个要察看预设的对象。“怎么让骑手别老觉得我乱收费”这句话里，有一个没说出口的前提：他们觉得被乱收费，是因为钱。追问器把这个前提摊在桌面上：“如果不是因为钱，这个问题还剩下什么？”阿乐半天没出声。它接着提议：“我想先把问题改成：骑手说你乱收费的时候，他们指的是哪一项。你同意改，我就照新的问；不同意，我照原来的。”

这里有两处要紧的分寸，都是第414号定下的。其一，改切要明写，不许静默替换：原问题是什么，改成什么，为什么改，都说在阿乐耳朵里，由他点头。其二，改切的理由只认四类，单位太粗或太细、预设了不存在的东西、问的是果不是因、范围和机制不匹配，因为这四类都能当场核对。追问器此处用的是第二类，预设了“是因为钱”。它的看法可能是错的，所以改切只是交回本人核对的提议，不是裁定；阿乐要是说“不改”，问对就照原题往下走，并把这一句记下。

问对该从哪一维起手，也是在这时候读出来的。阿乐要处理的是一件正在进行的事，骑手一回又一回地来，信与不信一天天在变，第414号的起手表把这一类任务排在从过程起手：先看卡在哪一步，再看周围的条件，最后才谈新的做法。如果反过来，一上来就问“你理想的报价制度是什么样”，得到的会是一份漂亮的价目表，站在过程外面写成，老刘盯着倒计时的那一眼不在里面。追问器没有读准的时候，规矩也是第414号的：宁可多问一步，不可硬选。

拆题之后是补维：被忽视的那一维，料要从哪里来。追问器问：“老刘停一个钟头，会少跑几单？”阿乐说：“冇得，我没问过。听别人讲，一天三四十单吧。”追问器没有替他算。它把这一格记成“阿乐说：一天三四十单，听来的，未核”，把“停一个钟头少几单”那一格留空，旁边写一行：这一维要去老刘那里拿，明天见了他可以问。第414号第18章对此说得明白：答不上本身就是一个料，它说明关键处境不在本人手里，补维的本分是把空缺明写出来、告诉他去哪里取，而不是转身去编一个。

来路在这一刻分开，说的、取的、推的三种怎么分，见第9章。本章只补一点：追问器自己猜的，比如“可能是时间焦虑”，不进画像，只能放进规格二的“推断·待本人认”一栏，等阿乐哪天说“对，就是这个词”才算数；他母本第52号《六路径方法论入门》教的那副问法，则记作取的。

还有一道闸挡在前头。设想追问器很会写，它把阿乐画像的“问”一栏润色成“如何在高压计时场景中建立服务信任”，读起来比他的原话体面得多。可画像的“问”必须是本人原话，第414号第28章的可引原句闸讲的就是这个：「凡是承重的核心判断句，必须能引到原文；禁止代拟」。润色过的句子满格满栏，格子是满的，线是空的，第414号把这种样子叫作「格子满了，线是空的」。所以追问器宁可让土、路、形、问里的某一格空着，也不代填一句漂亮话。缺维不补编，是因为假地基上长出来的东西，每一步都合规，整座楼都是歪的：要是它替阿乐填上“每小时三单”，后面关于报价的所有判断，都会压在一个没人量过的数字上。

### ◆ 四、三种撞，和一句话怎样从两句话之间长出来

追问器的每一句问话，都不是凭空来的。把问对看作一串差异，也就是三大方程里的 D，那么按 D＝G(S,E)，这串差异由两样东西规定：已经显出来的 S，和缠着他的 E。在阿乐这里，S 是他已经说过的话、母本的问型、库里已有的失效页；E 是旺季里每天涌进来的三十来个骑手、骑手群里转着的“别信修车的”、房东周叔那句“写在纸上才有人信”。同一句“上次你怎么处理的”，在旺季的深夜问和在周日下午问，路径完全不同。只读 S，追问器就退成一台复读机；只读 E，它就成了闲聊。第2章讲过的123原理在这里落成一个动作：S 和 E 先撞，第三样，也就是下一句问话，才动起来。

撞有三种，第439号第10章分得清楚：母本撞日子，今天撞过去，我撞别人。追问器每天都在用，但一次只用一种，三种一起上，人会被问晕。第一种，是拿母本里的问法去问他的日子，比如六路径讲起手：你对骑手解释的时候，是先说机器的毛病，还是先问他这一周怎么用的？阿乐想了想，说自己总是先说毛病，因为那是他最有把握的部分。这一句本身没有什么，可它为后面留了一个缺口：老刘盯着倒计时，在他的解释顺序里没有位置。

阿乐那晚用的是第二种。追问器翻出他十月十二号的一条语音，那是他做画像那天随口录的：“骑手就是舍不得花钱，能拖就拖。”然后它把今晚的话放在旁边：“十月十二号你说他们舍不得花钱。今晚你说老刘看的是倒计时。这是同一个意思吗？”阿乐愣了一会儿，说：“不是一回事。哎，不是一回事。”两句话单独看都没毛病，都存得好好的；摆在一起，缝就出来了。第三种，是把别人眼里的他摆出来：周叔说过“写在纸上才有人信”，老刘说“就爱拆”，两句话里，阿乐是同一个人吗？这一种最难收，因为“我的字”从来不是一个人关在屋里想出来的，总有一半是别人看见的那个我；它也最容易伤人，所以追问器只在阿乐自己提到旁人的时候才用，而且留到下一次问对再用。别人的话进了他的库，仍然只算他听到的、他转述的。

这就是它和市面上记忆功能的区别，要先把对方说对。ChatGPT 的记忆功能从2024年起逐步放开，2025年4月起可以引用过往全部对话；Anthropic 的 Claude 在2025年给项目建立了可审阅、可编辑的记忆摘要；Mem 在2025年10月推出的 Mem 2.0，会在会前提示相关旧笔记；Personal.ai 把一个人上传的内容存成属于他的记忆栈。有了这些，阿乐不会再说“我忘了半个月前说过什么”，这是实打实的帮助。它们共同的目标是召回，把说过的找回来再用。按这几家公开的说明，没有看到它们把前后两句话并排摆出来、当作一个问题抛回给本人；这只说明没查到，不是证明没有〔待核〕。

好比理发店。老师傅记得你上回留的是寸头，这是记性；可你这回坐下来说想留长一点，他要是只顺着说“好嘞，留长”，两次都记得，两次从没碰过面。另一种师傅会停下剪刀问一句：上回你说怕打理，这回怎么想留长了？第二种师傅记性未必更好，他做的是把两句话摆到一起。召回的产品很自然地说“你以前提到过骑手舍不得花钱”，然后顺着今晚的话再附和一句。追问器做的是前一句和后一句并排，然后停下，等人答。这件事机器做起来比人容易：人对自己半个月前说过的话，常常愿意看的看得清，不愿意看的就漏掉，机器翻出几百条记录一对一对地比，不偏心，也不累。可它只负责摆，不负责判；两句话是不是一回事，只有阿乐说了算。

### ◆ 五、新思想与失效页，是问出来的

那一晚接着是这样的。阿乐说：“那我报价的时候，是不是该先说多久，再说多少钱。”追问器没有夸他，它问：“你这句话，在什么情形下会错？”阿乐想了一会儿：“要是我说了三十分钟，他们还是说贵，而且这车确实没修慢。”追问器把这一段记成一条条文候选：主张是报价先报时间；成立条件是骑手在接单时段；怎样算错，就是阿乐刚说的那种情形。来路：本人说的。状态：待验。它是对阿乐自己新的东西，按第492号的尺子，对自己新只记发生，不打分。

新思想没有被机器想出来，它是从两句话之间的缝里被问出来的，机器做的是把两句话放到一起，然后闭嘴等。这也提醒了一件事：这样长出来的东西，要拿第457号的五项测试里的“追问”再顶一顶，看它是不是只是十月十二号那句话换了个说法。追问器接下来问的是失效页。“你十月十二号说骑手舍不得花钱，在那之前你做过什么？”“搞了个免费检测，想着不要钱他们就敢来。”“后来呢？”“来是来了，没几个往下修。”“你上一次以为这是怎么回事，后来发现不对的是哪一处？”这是第439号第10章放在“路”这一层末尾、要问得慢的问法里的最后一问。阿乐想了很久，把十月十二号那条语音的第二段指了出来，说：“我以前读它是骑手抠钱，现在不是了，是他们舍不得停那一段。”

失效页就这样有了形状。它还只是一页候选，等阿乐第二天确认了，才按卷内顺序领一个F号，不在这里抢号：上次的读法，指回十月十二号语音第二段；当时凭什么这样读，是他看到的几个讨价还价的客人；后来是什么撞开的，是今晚老刘看着倒计时的那一眼；现在的读法，写着“现在”二字；还没读透的地方，是免费检测为什么也没人来，会不会是怕被拆开。这些栏目是追问器一栏一栏读回给阿乐听、请他确认的，没有一栏是它替他写的。第439号第9章说过，机器可以一秒钟写出一千页动人的“我曾经以为”，可那是一页关于失效的文字，不是一页失效；能称作失效页的，必定指得回旧版，有日期，有那个撞开它的人。所以那一章的结论是：「追问是平台的，答案是人的」。

这个设计有人走在前面，应当认。Engelbart 在1962年的《Augmenting Human Intellect》里就说过，现有的增强手段是为大批人群演化出来的，没有一套为个人的特点去适配；他也说每个人会长出自己的变体，并设想用增强后的能力去做下一轮增强。在“通用的方法要贴着个人长”这一条上，本书是他的后来者。Luhmann 把卡片盒称作交流的伙伴，价值在于它能让使用者意外。本书多走的一步，在他们手上没有读到：适配的对象是问句本身，每一次适配都留一页有日期、指得回旧版的记录。Engelbart 的报告只读到前十万字符，Luhmann 读的是英译转载和二手摘要，所以这只是已读范围内的判断〔待核〕。

第二天早上，追问器先开口了：“老刘那一问，你问了吗？停一个钟头，他少几单？”这是智能体比库多出来的第三样本事，先开口。阿乐回了一句语音：“问了。他说三单。”追问器把“三单”记进那一格，来路改成“老刘说，阿乐转述”，再问最后一句：“昨天你给他报价，先说了多久。他听完，有什么不同？”问对到这里才做完一半，另一半要等老刘的反应回到库里：他听完是松了一点，还是照样低头划手机，这一条是机器自己拿不到、只能由阿乐带回来的。要是老刘什么反应也没有，也要如实记一条“我说了，他没有动”，它告诉库，上一次的读解也许还差一点什么。

### ◆ 规格卡　追问器的问法规则，与一次问对的记录字段

|---|---|---|

> **小账**
> 承接：第439号第10章的追问器、三种撞和五条问法，第414号第17、18、28章的拆题、补维、料单来路和可引原句闸。往前走了一步：把问法写成可检查的规则 Q1—Q8，用 D＝G(S,E) 说明下一句问话为什么由已显露的和身边缠着的共同规定，并让问对的出口直接接上画像、条文和失效页三本账。
> 对手：最可能被说成“早就有了”的，是 AI 记忆产品（召回你说过的话）和 Engelbart 的个人适配与自举。本书的回答：先认它们已经做到的，再说多走的一步，即两句话被摆在一起作为问题抛回本人，每一次适配留下指得回旧版的记录。
> 会错：同一批本人，用“撞”的问法与只召回不撞的问法各问一段时间，若前者产出的失效页与条文候选并不更多，或本人在前几次问对里大量选“不想答”并关停，说明撞的问法没有多出东西，或者太重，本章应收回〔待验〕。

## 第 15 章　ChatSDE（中）：条文层进 RAG

> **这一章的问题**：一本子本的条文怎样进库，才不会变成一堆搜得到、却没人负责的句子？

### ◆ 一、周六晚上，三块搜出来的东西

周六作坊散了，孩子们被家长一个个领走，罗青禾在收桌子，把椅子一把一把倒扣上去。林可留到了最后。她把笔记本电脑支在讲台上，屏幕转向罗青禾：“第一版库搭好了，你的子本《我的作文课》一共三百多条条文，都在里面。你问一句试试。”罗青禾擦着手走过来，想了想，打了一行字：豆豆这周的作文，为什么又只写了两行？

屏幕上跳出一段回答，下面挂着三块来源。回答写的是：“按你的经验，写不长往往不是词不够，而是不知道写给谁看。”罗青禾读完，眉头先皱了起来。“这句话我没说过。”她点开第一块，是一段被拦腰截断的文字，开头半句是“……写不长往往不是词不够，当孩子口头能讲满三分钟却”，后半截不见了。林可说，她是按每四百字一刀切的，刀口刚好落在句子中间。罗青禾又点开第二块：“这是母本里的句子，不是我的。它怎么成了我的经验？”

第三块更荒唐。那是一句关于老人吃药的话：“记不住药，常常是因为说明书从来没写给谁看。”罗青禾愣了一下：“这不是周叔药盒群里的吗？”林可低头认了：“昨天赶工，我把阿乐、周叔和你三个人的试验数据先放在了同一个池子里，只为把流程跑通。三个人都点过头的。”罗青禾把抹布往桌上一放：“点过头也拆开。今晚就拆。”

罗青禾说话向来直，教了十二年书，批评学生也是这个口气，不绕。她又补了一句：“我最怕的不是搜错，是搜错了还写得头头是道。别的家长看到这个，会信的。”林可听出这不是冲着她，是冲着屏幕上那段通顺的话。那段话每个字都对，连起来是错的，错得还很体面。

林可没有争辩。她话少，抽了一张作业纸，翻到背面，画了一个三行的表：第一行写“被切断”，第二行写“串了库”，第三行写“冒认来路”，每一行后面留了一格，要写这一章的哪一节管它。罗青禾凑过来看了一眼，说：“你画表的时候，比说话的时候清楚。”林可嗯了一声，把笔帽扣上。罗青禾又问：“那我这些东西，别人想用呢？”林可说：“能不能出门，是另一道门管的，等拆干净了再谈。”罗青禾点点头，把最后一把椅子倒扣上去，说：“那就先拆。”场景里的几句检索结果，是本书为说明而拟的，不代表第409号原文。这张表就是本章的骨架，再加两件事：库里的东西哪些能送出门，以及搜到了不等于懂了。

### ◆ 二、按七件切块：一条条文是一整块，不是四百个字

林可那一刀切坏了东西，错不在刀不快，在于切法。第296号《出版是知识发生的开始》第14章把这个毛病说得很平：分块是为了便于定位，可论证关系未必服从块的边界，一个结论在本段，关键限定却在前一段，取回孤立的片段，限制它的那部分就丢了。罗青禾那条“写不长”的主张，成立靠一个条件：孩子口头能讲满三分钟。被切断的块只留下了结论，要是拿这个结论去回答另一个口头也讲不满的孩子，这句话放在他身上恰恰是错的。

超市理货员都懂这个道理：一箱牛奶，箱子外面贴着产地、生产日期和保质期，理货时整箱上架，没人把一箱拆开，把标签和牛奶分到两个货架上。分开了，标签留在这头，牛奶摆在那头，顾客拿到一盒不知道哪天产的奶，出了事谁也找不到人。条文的七件，就是这张贴在箱子上的标签。

条文层的切法因此不看字数，只看七件。条文七件，承第109号《AI时代的个人知识》第1章与第414号第24章：主张、成立条件、来源事件、失败记录、归属、保质期、牵连。一条条文就是一块，七件在块内分七格，不拆开。拿罗青禾那一条来说：主张是“豆豆写不长，不是词不够，是他不知道写给谁看”；成立条件是“他口头能讲满三分钟同一件事，落到纸上只有两行”；来源事件是十一月那周的周记，他把小区里流浪猫的事讲了三分钟，写出来只有两行；失败记录里有两笔，一次给奶奶写信写了半页，另一次给奶奶写信又只有两行，所以这条在她这里站得住的范围，是写给不熟悉的读者的时候；归属是罗青禾本人；保质期写到他三年级下学期前复查；牵连指向另一条“口述先于书写”，两条互相拉扯。七格里，来源事件、失败记录、归属是机器给不了的。第109号第13章的原话是：「允许 AI 代笔，不允许 AI 代经历、代判负、代承接」。

块有了，索引怎么建，是本书的设计，尚未跑过〔待验〕：按件建索引，不按块建。问“什么时候不灵”，落在成立条件和失败记录上；问“你凭什么这样说”，落在来源事件上；问“该怎么办”，落在主张上。不管命中哪一件，返回的都是整条，七件一起走，并且把边界放在前头，成立条件和失败记录先于主张。这是借第109号对机读文本的一条写法：失效优先，先写它什么时候不成立。第296号第14章谈检索粒度时也说，检索到一句话以后，系统应当有能力进入它所属的段落，不能为了短，把必要条件永久切掉。

缺了哪几件，就在那几格里明标“空”，不补。缺来源事件和失败记录的条文，只有主张和成立条件两件，第109号管它叫半条。半条可以进库，可以被使用，可以被反例修正，回答时必须说“这一条还没有履历”。第414号第24章里有一句话，正好是这一格的纪律：凡是老刘没说的，不替他补。

这里要认一笔账：条文层不满足机读文本“预期读者为零个人”这一条，所以只借自足、失效优先、可检索三条写法，细说见第12章。

### ◆ 三、串了库：按人隔离；冒认来路：每块带来路

第二行“串了库”，管它的是隔离。规矩很短：一个人一个库，查询时只打开本人的那一个，不入公共池。道理有两层。其一是向量检索只认相似，不认主人，“写给谁看”这几个字在周叔的药盒里和在罗青禾的作文里，排名可以相邻，池子里有谁，它就取谁。其二是第457号《AI对科研的冲击为何首先表现在数学上？》第32章划过的线：「任何把子本汇集起来的做法，都得先问写的人愿不愿意」。第109号讲账也是同一个意思，账的所有者必须是使用它的人本人。所以不是“三个人点过头，就可以放在一起”，而是各人的库各有各的钥匙，要进别人的库，只能走出库口径开出来的那扇门。

好比一栋楼里每户一块水表。楼里有总表，物业按总表跟水厂结算，可没人会说，既然水都是一根管子来的，各家的表就可以拆掉。拆掉以后，谁家多用了、谁家漏了，全成了公摊。条文也是这样：罗青禾库里“失败记录”那一格，写的是豆豆给奶奶写信只有两行，这是她一家的事。若是放进公共池，别人问“孩子为什么写不长”，这一笔就可能出现在别人的回答里，名字或许被抹掉了，那种具体的、只有她才有的细节，一样漏了出去。

母本不在这条规矩里。第409号这类母本是公开的，另放一个只读的母本库，查询时两个库同时问，但结果分栏摆：这一栏是“你的”，那一栏是“母本里的”，不混在一个排名里。班上孩子的作文也一样，不进罗青禾的条文库，要存另开一库，归孩子的监护人。

第三行“冒认来路”，管它的是来路标。每一块带说的、取的、推的三种来路中的一种，三种怎么分，第9章已经讲过，这里只说它在检索时的三个用处。一是回答的口气跟着来路走：说的，可以写“你记过”；取的，必须写“母本里说”；推的，必须写“机器推的，等你认”。罗青禾那句“按你的经验”之所以是错的，因为它把一条取的说成了说的。二是推的不当证据。第296号第14章讲得清楚，转述不增加独立证据，系统不能把自己先前的输出重新检索出来，当作独立的支持。三是来路随块走，出库时一并带出，下一章会看到它怎样接上来路链。

没有来路标的块，入库时就被拦下。这对应规格四的第六道闸，来路标注率：条文层每条都要有来路标，是机器能跑的一道。拦的不是内容，是“说不清从哪来”这件事本身。就像菜市场卖肉，哪头猪、哪天宰的、谁家养的，写不出来的，不让上摊。罗青禾翻回头看那三百多条，才发觉她自己那一半，也有二十来条是不记得从哪里来的：是她读了母本以后顺口说出来、被记下的话，到底算她说的，还是母本的，当时没分。林可把这二十来条先标成“待认”，放在一边，等她一条一条说“对”或“不对”。

来路标不由机器事后改。子本生成时，哪条是本人说的，哪条是母本取的，由那道工序当场打上；问对里长出的条文，由问对的记录打上。本人可以改：机器推过一句“豆豆怕被同学笑”，挂着“推的”，罗青禾哪天说“对，就是这样”，这一条就新立一个版本，改标“说的”，注上日期，旧版保留，不覆盖。

### ◆ 四、出库口径：门外只有主张与判据

第三个问题是，库里的东西能不能送出门。做家长课堂的另一家慧店，想调用罗青禾库里的“写不长”，这是慧店之间调用的常事，第17章会专讲。本书的口径承第109号第11章的出库口径：被别家调用时，默认只送主张与判据段，附来路，限次，不送全文。第109号第5章与第11章写得更具体，完整推演链、原始数据、失败记录都不出库。

判据段是本书补出来的一个概念，要说清。它不是条件层的原文，而是罗青禾把成立条件改写成的一两句话，写成“当……时，先……”的样子，不带个人信息，由她逐条确认：“当孩子口头能讲满三分钟同一件事、落笔只有两行时，先查他的写作对象。”这一句里没有豆豆，没有十一月，没有奶奶，是她愿意让别人拿去试的话。没有确认的条文，没有判据段，也就没有出库资格，宁缺。判据段在附录一规格五的条文层里是独立的一个字段，不混在成立条件那一格里，这样门库取它的时候，取不到条件层原文。主张句也一样：内库里那一句写着豆豆，出库的是她改写并确认过的一句，“孩子口头能讲、落笔很短，多半是不知道写给谁看”，没确认的，主张句也不出门。

实现上不是在回答时再删，而是门外根本没有。内库存七件整条，只有本人的智能体能开；门库另建，只收满足五个条件的条文：分层为主张层，主张句与判据段都已由本人确认，状态是已兑现，所属子本已到第三代以上而且创新层级经规格九认定为对部落新或对世界新，本人打开了门。子本默认关门，第三代以前一律不出，这是规格九定的；到了第三代也要看创新层级，对自己新的卷，哪怕到了第三代，门库也不收，开放范围随层级走：对部落新只向部落内和相邻慧店开，对世界新才进全社区，谁来认定，第24章讲。慧店专著的条文则由店主决定上不上门库。门库里每一条对外只有三样：主张、判据段、来路。画像、失效页、条文的条件层原文，永不出门，不是被过滤掉，而是从没进过门库。就算有人对门库用尽办法套话，套得出来的也只有罗青禾愿意给的那几句。

每一次调用都要留一条来路链记录，字段承规格十一：调用方、被调对象（卷、章、条文编号）、时间、用途、回答中引用的片段、分账依据。细的都记在这里：拿“写不长”被调一次来说，来路链里记的是罗青禾的店、《我的作文课》第三代、条文 T-017、说的，外加调用方和时间，这些不进回答。来路一丢，不计费也不得使用。失败记录不出库，有两个理由：它是整条条文里最带着个人细节的一格，也是本人最不愿意给人看的一格；而且别家的智能体拿到一次失败，没有那个晚上的前后文，很容易读歪。每个调用方在一个时间窗里能调几次，由店主设，本章不定数；防着有人批量调用把库萃干，是第27章的事。

拿“写不长”走一遍。做家长课堂的慧店问：“孩子嘴上能讲，一写就短，怎么办？”门库返回三样：主张（孩子口头能讲、落笔很短，多半是不知道写给谁看）、判据段（上面那一句）、来路（罗青禾的店、《我的作文课》、说的）。这一条能被调，是因为罗青禾这一卷已有长沙三位老师各自回写“在我们这儿灵”，认定为对部落新，邻店才够得着。回答里带的就是这主张句、判据句和粗来路三样，条文编号和第几代不在回答里，只记在上一段说的来路链上。调用方的智能体拿到这三样，写进自己的答案，答案里必须带着来路那一行。它看不到豆豆，看不到十一月的周记，也看不到那两次给奶奶写信的结果，看不到的东西，不会因为它问得巧就变成看得到。第109号讲的第三载体，说的就是这个：出租出去的是解答，不是底本，书始终留在主人那里。

门是可以随时关的。罗青禾哪天读到新东西，觉得“写不长”这一条站不住，把状态改成已失效，门库里的那一条当时就撤下，下一次调用不再出现。已经发生的调用留在来路链里，不改，不删。第109号第1章有一句话，管的是这个动作：「撤回权私有，推翻权公有」。撤回是她一个人的事，推翻却可以由任何调用方带着反例回来。她为此多付一份代价：内库、门库两边要同步，改一处，两处都要看。林可估过，这笔维护的成本，比把东西存在一个库里贵，但换来的是出库口径不靠“回答时记得删”，而靠“根本没放进去”〔待验〕。

### ◆ 五、命中不等于理解，RAG也不等于平台

林可还剩最后一个测试。罗青禾问：豆豆每天写日记，能不能写长？库里命中两条：一条是母本的主张，日记让孩子有话写；另一条是罗青禾自己的失败记录，豆豆的日记只写“今天很开心”。如果只拿第一条回答，会得出“能”；两条一起，才看得出日记对对象是自己的写作未必管用。林可的办法是让回答把接缝显出来：母本说什么，你自己试过什么，这一次是机器推的什么，三段分开。没找到时，只能说“在你这个库里没有找到”，不能说“你没有记过”：可能是她没写，可能是写在了母本库，也可能是哪一块的索引还没更新。比方罗青禾问豆豆为什么抗拒默写，库里没有对应的条文，回答该是“这个库里目前没有关于默写的条文，母本里有一条相邻的，是取的，你要不要先看”，而不是编一段听上去合理的话。这几条都来自第296号第14章：相关不等于支持，缺席也是需要解释的结果，答案里要看得见推论的接缝。第296号那一章的头一句话是：「检索把根据带进来，发生要求根据继续面对新问题」。

林可是学统计的，她补了一句：“命中率我能量，你问到了没有。理解我量不了。”所以检验不放在检索这一头，放在回头。罗青禾照着回答对豆豆试了一个星期，结果怎样，写成这一条的兑现记录，状态由待验改已兑现或已失效。库的好坏，最终看这条记录有没有被写回来。

这也是为什么WDS博士在2026年10月27日的口述里说：「子本是用来发生的，是个人知识平台的发生基因RAG 和Skill 的生成基因」（登入附录六）。这句话可以读成两层：子本既是平台发生的基因，又是 RAG 与 Skill 的生成基因。库里的条文不是另外喂进去的材料，是子本生成和回写时长出来的；库是子本的表达，不是子本的替身。第109号第7章有一句分界的话：「一个生态几乎必然用到 RAG，但 RAG 不构成生态」。本卷的 RAG 只是条文层的技术形态，用到是必然的，可构成这个平台的东西不在检索里：来源事件和失败记录只能由本人给，失效页、回写和认领也不是检索做得出来的。第109号把这个分界讲到了根上：RAG 的目标是让输出更准，而它判一个生态的三条判据，账、史、承接，没有一条问输出准不准。一个库可以检索得很准，答得头头是道，却没有人对其中任何一句负责，也没有一页记着它哪天错过，这样的库是仓库，不是平台。罗青禾的库里，每一块背后都站着一个人，来源事件写着是哪一周的事，失败记录写着哪一次没灵，保质期写着哪天复查，这才是她的库不同于一个好用的笔记检索的地方。

这个领域已经有人做了很多，应当先认，先说他们做对了什么。Khoj、Reor、Obsidian 的 Smart Connections 一类工具，让人把自己的笔记放在本地做语义检索，保住了私有；2023年的 LaMP 基准把“从用户档案里检索个人条目增强提示”做成了标准做法；Reor 在2026年3月被作者归档，只说明单靠笔记加检索的工具，维护并不稳固。MemGPT 与 Generative Agents 在2023年做了多层记忆与反思；同一条线上的 Mem0〔待核：本书只核到题名与编号，功能未核〕。最近的一家是 Karpathy 在2026年4月〔日期据二手报道，待核〕写的 LLM Wiki：原始来源不动，由 LLM 写并维护一个会累积的 wiki，查询的好答案可以回存，定期检查矛盾和过时的断言。它把“回写”和“查过时”说得很透，本书接受。

本书多走的是三处。第一，条文是子本生成时带着七件长出来的，不是对既有笔记做的索引；第二，七件里有三件只能由本人给，不是 LLM 全权维护；第三，每块带着说的、取的、推的三种来路，并按人隔离、按口径出库。至于谁来判定一条条文已经过时，2026年的 STALE 测试说，最好的模型对隐式失效的识别也只有约一半，所以本书把判定留给本人，第20章再细说。第109号第13章的机读文本是最近的前作，条文层沿着它的写法走，又加上了隔离、来路和出库这三道。

还有一处张力要说在前面。第109号给一个人的库定过上限，成熟的库不该继续变大，一个人的库大致在一百到三百条。罗青禾的库已经三百多条，站在这条线边上。本书的办法不是封顶，而是让每条带保质期，到期复查，查不过的撤下或并入别条，具体怎么收，第21章的季度收口再讲。库要增长，但进来的速度要有节制，出去的路也要留着。

### ◆ 规格卡　规格五条文层，及切块、索引、隔离、出库四项技术约定

**条文层条目**（规格五；本书的设计）

| 字段 | 内容 |
|---|---|
| 编号 | 条文编号，如 T-017 |
| 七件 | 主张｜成立条件｜来源事件｜失败记录｜归属｜保质期｜牵连 |
| 来路标 | 说的／取的／推的 |
| 分层 | 主张层（可出库）／条件层（永不出门） |
| 状态 | 待验／已兑现／已失效 |
| 所属代 | 第几代 |
| 创新层级 | 对自己新／对部落新／对世界新（规格九认定） |
| 判据段 | 独立字段：本人逐条确认、不带个人信息、写成“当……时，先……”的一两句；未确认则空 |
| 出库状态 | 未入门库／已入门库／已撤下 |

**示例行**（罗青禾的子本）：T-017｜主张：豆豆写不长，是不知道写给谁看｜成立条件：口头能讲满三分钟、落笔只有两行｜来源事件：十一月周记，流浪猫｜失败记录：给奶奶写信，一次半页、一次两行｜归属：罗青禾｜保质期：三年级下学期前复查｜牵连：T-009（口述先于书写）｜来路标：说的｜分层：主张层（判据段已确认）与条件层（永不出门）分设｜状态：已兑现｜所属代：三｜创新层级：对部落新｜主张（出库版）：孩子口头能讲、落笔很短，多半是不知道写给谁看｜判据段：当孩子口头能讲满三分钟同一件事、落笔只有两行时，先查他的写作对象｜出库状态：已入门库（本人已开门）。

**四项技术约定**（均为本书的设计〔待验〕）

| 项 | 约定 |
|---|---|
| 切块 | 一条条文一块，七件不拆；缺件明标“空”；缺来源事件与失败记录者标“半条”；不按字数切 |
| 索引 | 按件建索引，命中任一件返回整条；返回顺序成立条件、失败记录在前，主张在后 |
| 隔离 | 一人一库一钥；查询只开本人库；母本库只读并分栏；他人只能经门库访问 |
| 出库 | 门库另建，只收主张层、主张句与判据段已确认、状态已兑现、所属子本第三代以上且对部落新以上、本人已开门的条文（对自己新的不收）；只送主张、判据段、来路；限次；每次写来路链（规格十一） |

> **带走的话**
> 条文进库的规矩只有一句：每一块都带着它的边界和它的来路，搜出来的东西才有人负责。

> **小账**
> 承接：第109号第1、7、11、13章的条目七件、RAG分界、出库口径与机读文本，第296号第14章的“检索命中不等于理解”，第414号第18、24章的来路与七件。往前走一步：把这些落成条文层的切块、索引、隔离和出库四项约定，并让库里的条文来自子本的生长而不是另外喂进去。
> 对手：个人 RAG、Mem0、Karpathy 的 LLM Wiki，以及第109号的机读文本，都可能被说成“早就有了”。本书的回答：它们说对的部分（私有检索、会累积的库、回写与查过时、条件层的写法）本书承认并使用；多走的是条文带着只能由本人给的三件、来路分三种、按人隔离和按口径出库。
> 会错：若在同一批问题上，整条返回与只返回主张句两种配置下，回答漏说成立条件的比例没有差别，七件切块的额外成本就不值得；门库里只要查到一次条件层原文或失效页，则出库口径视为失败，直接作废重做〔待验〕。

## 第 16 章　ChatSDE（下）：做法层进 Skill

> **这一章的问题**：一张工序卡凭什么能进 Skill，进了以后怎样改、怎样退、怎样借给别人？

### ◆ 一、灰色的标签，一直没变

十一月中旬的一个周一，铺子还没开门，一个叫阿杰的骑手已经把车推到了卷帘门外，说接头又烧了，上周才换过。阿乐认得这个声音，这个月已经是第三次了，前两次他都以为是接头质量差，换了更贵的。阿乐把车推进来，手机靠在扳手盒上，屏幕上是他的子本《我的入口》里的一张卡：换接头前三查，v1，标签是灰色的，写着“待跟做”。这张卡是十一月初起草的。他那一页失效页（F-003，往上一页是F-002，先怪电池、后来才怪到接头）写着：以前以为接头烧了，换接头就好；后来发现三次回头的车里，有两次是电池仓里的座烧变了形。他对着手机把自己平时怎么做讲了一遍，系统排成五步：一查线，二查座，三查人，四按查出的毛病换，五试骑后摸温。他读过一遍，说，行，就是这样。有一步机器自己是加不出来的：他平时讲做法的时候，从没提过座，是那页失效页逼着第二步写进去的。可是那个灰标签一直没动，因为读过、说行，都不算。

阿乐的手想走老路：拔掉烧黑的接头，量一量，换新的，二十分钟收工。他干这行六年，手比脑子快。但今天他把手收了回来。他嘴快，爱打比方，对阿杰说：“这是我师傅坐副驾，我得先听他的。”阿杰靠着门框，笑他：“你今天怎么这么慢。”阿乐没理他，念出第一步：“查线。看线皮有没有发硬变色，线径有没有细过接头的额定。”他一边看，一边对手机说“线皮发硬，有一小段变色”，系统把这句话记进了检查点。

第二步是查座。阿乐从来没有在换接头之前拆开过电池仓里的母座，因为接头烧了，眼睛就盯着接头。他拿小手电侧着照进去，座壁上有一道细细的纹，触片边缘一圈发黑。“哎。”他说了一声，后面的话没出口。这是他换了二十多次接头都没看过的地方。他蹲在那里没有动，手电的光落在那道纹上，纹的边缘有一点点油亮的黑，是烧过的痕迹。要是照老办法，他此刻已经把新接头插进这个座里了，插得牢牢的，过三五天，阿杰还会推着车回来。第三步，查人，要问骑手。他问阿杰：“最近换过电池吗？”阿杰说：“上周在网上买了块大容量的，便宜两百。”

手机问他：“要不要把这一次记下来？”阿乐说：“记。”灰色的标签没有变，因为卡才做到第三步，后面还要换座、试骑、摸温。它要等这一遍做完，每一项检查点都有他自己的话，才可能由灰变绿。本章讲的，就是这个标签为什么要灰那么久，变绿以后又会发生什么。

### ◆ 二、做法层是什么，Skill为什么不是摘要

上一章讲了 RAG 这一半，这一章是 Skill 这一半：做法层的卡不是另外写的说明书，它们是从子本的条文和失效页里长出来的。条文说“在什么条件下什么成立”，卡说“成立的时候，一步一步怎么做”。

卡的字段承规格五：名称、适用条件、步骤、检查点、跟做记录、状态、依据条文编号。阿乐这一张，依据的是一条条文，主张是“接头烧了，先查座，不要先换接头”，条件是电动车、骑手高强度使用的情形；卡上的第二步“查座”之所以存在，是因为他的失效页写过：上次我以为是接头，后来发现是座。卡的步骤挂在失效页上，这是本章与别处最不同的地方，后面的对手一节会回来。

一张卡因此有三处根：条文告诉它在什么条件下才该上场，失效页告诉它每一步为什么在那里，跟做记录告诉它有没有没有人做过。机器能起草的是步骤的排序和措辞，起草不了“为什么”和“什么时候不这样做”：第492号第25章讲装配成书时说得明白，这两样只能从撞痕里取，不能从别处借。阿乐的卡上，“若座壁有纹，停，不换接头”这一句的底气，来自他自己那页失效页，不是来自一本维修手册。

Skill 不是摘要，第296号《出版是知识发生的开始》第16章用两句话摆出了差别。一句是摘要，大意是知识在社会互动中持续形成，出版不该被当作生产的终点。另一句是 Skill，大意是：当用户提出问题时，先确定任务与来源版本，区分原文主张和新增推断，检查情境差异，再决定是否形成候选修订（第296号第16章的举例）。两句都不长，前一句让人知道说了什么，后一句组织系统接下来做什么。放到阿乐的铺子里，摘要是：“电动车接头发热，多半是接触不良，更换接头通常可以解决。”这话没有错，写给任何一个修车的人都不会错，也因此帮不了任何人。Skill 是：“第一步，查线；若线皮发硬变色，记录位置，继续；第二步，查座，用手电侧照；若座壁有纹或触片发黑，停，不换接头，转换座卡。”它有入口，有分支，有停止条件，有每一步的检查点。

第296号第16章的那句话是：「程序化的不是全部思想，而是可以明确承担的工作关系」。哪些步骤可以由机器记录，哪些必须是手去摸，哪些要问骑手，每一步由谁来判断，都写在卡上，不让机器一句“我觉得可以”悄悄滑过去。阿乐这张卡的检查点，一部分是“看”（线皮、座壁），一部分是“问”（电池是不是换过），一部分是“量”（试骑十分钟后手背贴一贴，看烫不烫）。写进检查点的每一项，都是做完以后可以回头核对的，不是“注意安全”一类的话。第296号第16章还有一条提醒，字段可以写“本次未执行”“证据不足”，不必为了格式完整让模型补一个值。卡上也是这样：第五步试骑，若当天没有条件，就写“未试骑”，状态不转，不允许写一句“应无异常”顶替。

这也说明为什么角色扮演不是 Skill。如果卡上只写一句“你是一位有二十年经验的电动车修理师傅，请谨慎判断”，模型会说出老师傅的口气，可是第二步该拆哪里、什么情形停，它一个字也没有。Skill 的可信来自它怎样处理知识，不来自它听起来像谁。

### ◆ 三、跟做闸：没在本人身上做过的卡，不进 Skill

第492号《一店三门》第25章，给书房定了一条硬规矩：没有经过第四站跟做验证的卡，不进 Skill。本书沿用，并把“谁来做”落到本人身上：一张做法卡，必须有人照着卡做一遍，不凭记忆补，做完留下记录，才算跟做。本人照做，是起点；他人照做，是旁证，记在跟做记录里，但不能代替本人那一遍。这是本书的设计，尚未长期试跑〔待验〕。

为什么非要阿乐自己做，读过、同意还不够？第492号第22章说过两层缘故。一是回忆会美化：人讲自己做过的事，会不自觉地讲得比实际做的时候更利落，犹豫的、走错又退回来的那几步最容易被省掉，可恰恰是那几步藏着最要紧的东西。阿乐对手机讲“我一般先看线”的时候，没有提到手电，而侧着照进去看座壁，恰恰是他第一次做才发现的。二是回写不一定往好的方向写：一张写错的卡被照着做几百遍，错会写进手里，而且比原来的错更难改，因为从此有了“卡上就是这么写的”这张护身符。驾校里新手上路，教练坐副驾，不是因为新手笨，是因为方向盘上的错，只有转过才知道。卡在没有人跟做过以前，就是一个还没上过路的学员。

这和第492号并不冲突。第492号写的是手艺人的专著，卡要交给徒弟或同行去撞，因为师傅自己的手太快，卡上没写的步骤他会自己补。本卷多了一层：子本归本人，卡也归本人，所以先要本人这一遍，旁证的人扮的是徒弟的角色，补上本人那一遍看不出的缺口。两遍不能互相替代。

跟做时机器做什么，也要说清。它只念步骤，等检查点的回答，记下来，不评论，不说“你做得很好”，也不在阿乐没做完的时候抢先写“已完成”。做错的几次，和做对的几次一样记下，不许删，这是第492号第22章的规矩。

状态因此只有三种，规格五定好的：待跟做、已跟做、已退役。待跟做的卡可以看，智能体拿出来时必须先说“这张卡还待跟做”，不替本人执行，也不放进 Skill 包。已跟做的卡才进 Skill，智能体可以一步一步带着做。已退役的卡留着，不进。

阿乐这张卡的路走了三个星期。第一遍，十一月中旬，他本人照 v1 做，发现“目视查座”看不清，要用手电侧照；卡改成 v2，回到待跟做。v1 也只做到第三步，从没转过已跟做，所以此刻 Skill 包里还没有这张卡，直到 v2 被完整跟做一遍。往后 v2 转绿、v3 出来时，才有旧版当值、新版待验的并行，哪一版好，比过才知道。第二遍，一周后，他本人照 v2 做完，五步的检查点逐项有记录，结果没有推翻依据条文，v2 由灰变绿。第三遍，又过一周，隔壁档口的师傅只看卡、没问阿乐，照着做了一台，他在第三步卡住：“最近换过电池吗”这一句，骑手听不懂他问的是哪种电池。阿乐把这句话改成“最近有没有换过或加装别的电池、充电器”，卡升到 v3，这一遍记作旁证。v3 因此回到待跟做，当值的仍是跟做过的 v2。同一个月里还有一台车让卡吃了一惊：那台车的母座是铆死的，拆不下来，第二步根本做不下去。阿乐在记录里如实写了“做不下去”，卡的适用条件里多了一句“电池仓母座可拆”。这一条不是失败，是卡第一次知道了自己的边界。

已跟做不是终身的。每一次真实使用，卡都要追加一条记录：日期、谁做、结果。后来某次结果不对，卡就退回待跟做，从 Skill 包里撤下，重新跟做。第109号《AI时代的个人知识》第12章警告过，直通车造的是使用者，不是持有者：一张卡被反复调用，用的人越用越顺手，却不知道它哪一步已经不灵了。每次使用都要记，就是在这条路上加的一道回流。第492号说书房的“稳”是三件可查的事：照着做能复现，改了什么查得到来路，改坏了退得回去。阿乐这张卡的三个版本，正好各对一件：每一遍跟做对应复现，每个版本附一句变化说明对应追溯，旧版并排保存对应退回。

### ◆ 四、版本、退役，和被别家调用

先看这套东西在阿乐的铺子里怎样一起转。阿杰这样的骑手一来，智能体先去条文库里取条文，也就是上一章那一层，问的是“接头烧了，什么情形下先查座”，取回T-031的成立条件和失败记录，回答带着来路；再去做法层里看有没有已跟做的卡，有，就把卡的第一步递出来，一步一步带着做。条文回答“该不该这样”，卡回答“怎么做”。条文是翻着查的，卡是照着做的，两样出自同一页失效页，这是第491号《SDE平台：慧店的诞生》第33章讲的“一本书三份差事”，落到一个人身上的样子。Skill 包由已跟做的卡自动生成，一张卡转已跟做或已退役，包就重新生成一次，旧包存档。

卡每改一次就是一个新版本。版本怎么编号可以由各家定，变化说明不能省，这是第296号第17章身份模块的要求：说清为什么改、因为哪一次跟做改。阿乐的 v2 写着“原因：十一月第二周本人跟做，目视看不清座壁”，v3 写着“原因：旁证者反映第三步措辞不清”。旧版不删，并排保存，和失效页只加不改是同一个道理。新版在跟做完成以前，当值的仍是跟做过的旧版；旧版若也没跟做过，就还没有当值的版本。

退役有四种由头：依据条文被判已失效；适用条件不再出现；保质期到了复查不过；同一张卡本人连续两次跟做都不通过。这四条是本书的设计〔待验〕。比方明年骑手们大都换了不需要接头的新款电池，阿乐这张卡的适用条件不再出现，它就退役，写明“适用条件消失”，仍留在做法层里，Skill 包重新生成，不含它。退役不是删除，原因要指回一页失效页：这张卡当初为什么存在，现在为什么不再需要，都有据可查。失效页分三种，范围失效与读法失效都会牵出卡来：范围失效，是卡在一种车型上管用、换一种车型就不灵，该改的是适用条件；读法失效，是卡背后那条条文本身错了，卡要整张退。一张卡退不退，先看是哪一种。

最后一个问题，是别家来调用。第17章会专讲慧店之间的调用，这里只立 Skill 一侧的规矩，共五条，都是本书的设计。第一条，门是本人开的。子本里的卡默认关门，第三代以前一律不出，到了第三代也要看创新层级：对自己新的不出，对部落新向部落内和相邻慧店开，对世界新才进全社区；慧店专著里的卡由店主决定。第二条，按步送。出库口径放到做法层，写成：被调用时每次只送当前一步的步骤和检查点，附来路和状态，不一次送整卡，不送依据条文的条件层原文、跟做记录里的人和车、失效页。调用方看得到“这张卡已有几条跟做记录”这个数，看不到是谁的车、哪一天。第三条，先核适用条件，不符就回“不适用”，不硬跑。比方对方问的是三轮货车，适用条件里写着电动车、母座可拆，智能体要先问清车型，不对就如实说“这张卡不适合你这台车”，不会因为想帮忙就拿去硬套。

第四条，借来的卡，在借的人手里是待跟做。阿乐的卡已按完整一遍跟做过，之后又追加了两条记录，那都是在阿乐的铺子、阿乐的手里。等阿乐这一卷到了第三代、认定为对部落新，隔壁区一家修快递三轮车的慧店才够得着，调用它时，它在对方那里仍须再跟做一遍，记在对方自己的跟做记录里，这是第492号第28章那句话的技术版：三扇门之间流的是土，不是货，进了另一边，要在那边重新发生一次。第五条，反例回流，由出方判定。借方跟做失败，可以脱名写一段话回给出方，但出方本人看了才决定写不写进自己的失效页，借方不能替他写；每一次调用，来路都记进来路链，署名不剥夺。借来的卡在对方那里的来路标是“取的”，取自阿乐的店；对方想改，只能另写一张自己的，状态从待跟做起，不能改阿乐的原卡。按规格十，子本只可租、调、挂和分，卡属于子本，所以这里发生的是“调”：用，不过户，也不能买卖。

### ◆ 五、它们说对了什么，本书多走的那一步

从失败里蒸馏做法、固化成技能，这条路已经被走得很远，必须先认。Reflexion（2023）让智能体对任务反馈作语言反思，存进情景记忆缓冲区，供下一次尝试用；Voyager（2023）让智能体在环境里积累一个不断变长的可执行技能库；ReasoningBank（2025）从智能体自己判定的成功与失败经验里，提炼可迁移的推理策略，测试时检索并写回；ACE（2025）把上下文做成不断演化的手册，经生成、反思、整理更新，并指出反复重写会逐步侵蚀信息。Anthropic 在2025年10月推出的 Agent Skills，是一个含 SKILL.md 的文件夹，分层加载；文中说可以让 Claude 把成功的做法和常见的错误记进 Skill，也表示希望将来智能体能自己创建、编辑和评估 Skill。这几家说明了一件事：做法可以从经验里长出来，并且可以被反复调用。它们各有自己的实验，本书没有逐项复核，也不拿它们的结果为自己背书。本书不争这条回路本身，还借用了其中一样东西：Agent Skills 的文件夹格式与分层加载，本书的 Skill 包导出时就用这样的结构，一张已跟做的卡一个文件夹，换一个平台也能读〔设计，待验〕。

本书多走的一步，是五处不同。第一，对象不同。它们处理的是智能体的任务策略，本书处理的是一个人在自己日子里的做法。第二，谁判成败不同。ReasoningBank 里是智能体自评，本书里是本人的跟做记录，阿乐的卡变绿，靠的是他手上的一遍，不是模型觉得对。第三，挂在哪里不同。别家的策略条目挂在任务轨迹上，本书的卡挂在本人的失效页和条文上，每一步为什么存在，指得回他哪次错过。第四，归谁不同。卡归阿乐，可带走，可删除，不入模型，借出去也不过户。第五，怎样防侵蚀不同。ACE 警告反复重写会损失信息，本书的办法是只加不改：旧版不删，新版要先跟做，退役留痕，每季度收口一次，第21章再讲。

工序卡听上去像工厂里的作业指导书，这个相似应当认下。不同在于写卡的人：作业指导书多半是管理者写给操作者的，卡是做事的人自己的话，由机器排版，每一步后面还要写“这一步我是怎么知道的”。管理者写的规程出了错，操作者往往只能照做；这里卡出了错，写它的人、跟做它的人是同一只手，错得到修的地方也就在这只手上。

举个例子就清楚了。同样是“接头烧了”这件事，策略库里记下的可能是一条从很多次任务里蒸馏出的经验：“发热类故障先排查接触不良。”这没有错，可它不知道是谁的手、哪一台车、哪一次错过。阿乐的卡记着的是：十月底，三次回头；两次是座；他是在哪一天、被谁的一句话撞开的；这张卡又被谁照着做了几遍。前者可以服务很多智能体，后者只服务一个人，但只有后者能回答“你凭什么这样说”。

说这些，不是说本书的办法更好用。第296号的结语写得老实：「Skill 是接口，不是魔法」。一张卡的步骤可能写错，一次跟做可能碰巧成功，旁证者可能照着做偏。本书这条路没有跑过，下面这些都要看结果才算数。

> 灰色的标签不是慢，是诚实：一张卡只有被本人的手做过一遍，才有资格告诉别人怎么做。

> **小账**

## 第 17 章　SDE社区：侧重特征纠缠

> **这一章的问题**：一页要几个人认出来才算共有？别家调用我的书，知识怎样不被搬走？

### ◆ 一、十一张纸，红圈和蓝圈

九月下旬的一个周六，下午四点，社区活动室的长桌上摊着十一张打印纸。每张纸的右上角只有一个号码，没有名字。罗青禾把纸按号码排开，又给在座的四个人各发一支红笔、一支蓝笔，笔是她从豆豆的笔筒里一把抓来的：彭春梅教初三，谭素芬教了三十年书、今年带最后一届，余晓棠教初一，蒋明工作第三年。五个人都是长沙的中学语文老师：谭老师和罗青禾在同一所学校，彭春梅在城东一所中学，余晓棠和蒋明各在另外两所。她们各有一本以第409号为母本长出来的子本，这十一张纸，是每个人从自己的子本里挑出一两页、改写成能拿出门的样子之后交上来的，其中一张是罗青禾自己的。

规矩她前一晚在群里讲过，现在又讲了一遍：先不看别人的圈，也不要商量，圈错了没有人会翻出来说。每页读完，先写一行自己班上的事，再圈。红圈是“我也有”，蓝圈是“不是这样”，画半个圈的意思是“有一点，但不全是”。轮到她自己那一页，由余晓棠收圈，她背过身去倒水。编的人也投页，投了就不能自己收自己的票，这是她给自己立的第一条规矩。

P-04是谭老师投的，说的是孩子们的作文结尾总爱写“我明白了一个道理”，原因不是不会收尾，是怕留白被扣分。彭春梅读完，先画了红圈，旁边写：“我班二十个，十六个这样。”罗青禾画了红圈。余晓棠画了红圈。蒋明盯着纸看了很久，画了蓝圈，在旁边写了半行很小的字：“我班的孩子不怕扣分，他们觉得结尾就该有道理，班级公众号上登出来的好作文都这么结。”

收完圈，余晓棠把P-04放到桌子中间，说：“三个红圈，一个蓝圈。”谭老师笑了一下，没有出声。彭春梅把笔往桌上一放，说话一向直：“三个红圈，是不是因为我们三个读的是同一本教参？我班十六个，是不是也是我自己教出来的？”

没有人接话。罗青禾没有急着答，她把蒋明那半行字原样抄到P-04的页尾，抄完才说：“这个问题比这一页重要。”这一章要讲的，就是部落本怎样共建、共建出来的东西凭什么不是一群人的回声，以及另一件事：一家慧店的书被另一家调用的时候，知识在那边是怎样重新发生一次的。社区是平台三部分里侧重特征纠缠的一部分，彭春梅那一问，正好问在纠缠的根上。

### ◆ 二、先认对手：阐释共同体怎么说

彭春梅的怀疑不是她的发明，文学理论里有一整套说法在等着她。费什（Fish）的社会性读者反应论，本书是按转述读到的〔所据为1980年的文章页面，篇名待核〕：阐释者不是把意思从文本里解出来，而是在读的时候把它制造出来；制造的办法不是个人的，是他所属的阐释共同体共有的读法，同一个共同体里的人，读出来才会一样。照这个说法，五位长沙老师圈出同一个红圈，很可能说明的只是她们受过同一种训练、读过同一类教参、批过同一类作文，红圈量出来的是读法，不是教室。

这个说法的好处，本书先认下来。第一，它提醒“认出来”不是一个中性的量尺，认的人带着自己的读法进来，读法会替他把页上没写的东西补齐。第二，它把一致和一致的原因分开：一个共同体内部越一致，越不能直接拿来当作外面世界一致的证据。第三，它说到了一个让人不舒服的事实，没有人能站到自己所属的共同体外面去读，包括编部落本的人。罗青禾自己教了十二年书，她画红圈的那一下，有多少是她的日子，有多少是她十二年里读惯了的读法，她分不清。

同一条路上还有更贴近的前人。霍兰（Norman Holland）讲每个读者把自己的同一性主题带进文本；布莱希（Bleich）认为客观的阅读不可能，所以让学生把各自的反应记下来、拿到班上互相比较，由此弄清一个班怎样共同地再造一个文本。这几乎就是长桌上正在发生的事：十一张纸，一人一支笔，把各自的反应摆出来比。本书的部落本在做法上没有离开他们多远，这一点要说在前面。

在“多人收敛到同一处”这件事上，还有一种不同的解释。克莱迪埃、斯科特-菲利普斯与斯珀伯（Claidière、Scott-Phillips、Sperber，2014）的文化吸引一路主张，许多人想到同一处，不一定是某个东西被忠实复制了，也可能是人的认知本来就往那里倾斜；这是他们的论点。蒋明那半行字补了另一种可能：大家读过同一个外来样板，班级公众号上登的好作文让孩子们学会把结尾写成道理，谭老师以为的“怕扣分”，可能只是样板的影子。这是本书对这一页的读法，不是该文的论点。

本书在这里多走的，是工程层的几步，不是原理层的。原理上，费什那一问本书无法绕开，也不宣称绕开了。本书能做的是三件事。其一，把“认出来”拆成可以复查的动作：每个认出者在盲认时必须写下自己的一行日子，以及这个读法是从哪里学来的，认出的人如果说不出读法的来路，这一票只算半票。其二，不合的声音原样留在页尾，不平均、不改写，编者无权删。其三，请读法不同的人来认：邻座的数学老师、一位家长、一个初三的学生，他们的红圈和蓝圈，比三位语文老师再多画三个都值钱。第491号第29章里，邹老师读报告先看“没验到的是什么”，罗青禾后来请隔壁班一位不太熟的老师来排作文先后，也是同一个办法：借一双不是自己的眼睛。

费什会说，这样做仍然站在共同体里面，因为你请来的家长也带着家长的读法。这话对，本书接着认：部落本做不到摆脱读法，只做得到把读法摊在桌面上，让它能被对账、被反驳、被写进失效页里。摊开的读法比隐藏的读法更容易坏，坏了才能改，这是本书对阐释共同体多走的那一步。它能不能走得通，下面的“会错”里写了看什么。

### ◆ 三、一页怎样进入部落本

回到那张长桌。第439号第8章把部落本编者的规矩写成四句：一页要有几个人各自认出来才算共有，只有一个人认的页留在他自己的子本里，不合的声音哪怕半行也要留下，每页署原来写它的人，并且只收本人同意拿出来的。那一章也说，编者不必是专家，她只需要把页摆在桌上，一页一页问“这一句，你们谁也有”。本书要把这四句落成能操作的步骤，下面按罗青禾那个下午实际走的次序来讲。

第一步是投页。一页不是子本里随手剪下来的一段，而是投页者自己从子本里改写出来的、专为出门准备的东西：一句主张，三行她自己班上的日子，一个来路标，说明这句话是她自己说的、取自母本的，还是机器推的。出门的只有这一层。她子本里的失效页原文、条文的条件层原文、她的画像，一个字都不出门，这是本书开头就立下的“永不出门”三样。谭老师投P-04时，她的条件层里写着哪一年、哪个班、哪个孩子，那些都留在家里，页上只有一句“结尾总爱写道理”和三行不带人名的日子。

第二步是盲认。长桌上每个人先写一行自己的日子再圈，不看邻座，这一步在线上由ChatSDE的追问器代劳：它把页发给每个认出者，逐个问“你班上有没有这一句？有，请说一件；没有，也请说”，并且允许回答“不想答”。投页者本人不计票，所以门槛按投页者以外的人数算。本书的设计是：三人各自盲认为“认”，而且这三人里至少有一人与投页者不在同一所学校，或不在同一个年级组，页才成为正页；两人，页是候选页，挂在部落本的边上等第三个人；只有一人认，或者无人认，页回到投页者自己的子本里，不进部落本。凑不齐这一条的，页尾标“同读法正页”，不作为第24章认定对部落新的材料。两个半票折一票，折后不足三票的是候选页。这个三是照第三代出门资格里“至少三人各自独立”的结构取的，不是测出来的最佳值〔待验〕。要分清的是，这里的三是对一页的盲认，量的是有没有这回事；第24章的三是对一条条文的回写认定，量的是用过之后灵不灵。两道门，凑巧同数，同一个人可以在两处各算一票，但一页被认出不等于一条条文被认定。

第三步是对账。机器在这一步最能帮上忙：它能在几秒内列出哪几页被哪几个人认出，哪几页的认出者重叠，哪几页的文字跟某篇公开文章高度相似，后一项就是蒋明那半行字所指的“外灌”嫌疑。第439号说过机器的位置是撞的速度，不是撞的内容。外灌嫌疑页并不被删，只是页尾多一行：“认出者中有人指出，这一读法可能来自班级公众号样板”。P-04后来就带着这一行进了部落本。

第四步是留下不合的声音。蓝圈和半个圈的旁注，原话抄在页尾，署代号。有一页五个人里两红、两半、一蓝，罗青禾没有把它降为“多数认同”，而是把它标成分歧页，三种声音并排摆着，因为这一页的价值就在它的不齐。部落本因此不是平均数，而是第439号说过的那张家族近似的网：P-04被彭、罗、余三人认出，P-07被谭、蒋认出，彭和罗只认一半，两页的认出者各不相同，没有哪一页是全体的标准。

第五步是脱名与撤回。页上署代号，号码和姓名的对照表由编者封存，部落以外的人看不到。这里要老实说一个限度：五个人的小部落，脱名挡得住外人，挡不住屋里的熟人，彭春梅读P-04就猜到了是谭老师。所以脱名之外还要两道保险，一是每页由本人逐页同意才入册，二是任何时候可撤回，撤回后原处留一个空位，写着“此处原有一页，已撤回”。撤回还要连带标记已有的引用，不然撤回只是名义上的。

整个过程里，有一条是罗青禾从第491号第28章搬来的自查。那一章给出平台越级的三个信号：开始用“应该”，开始用“大家”，开始不让验。编者审稿时拿这三个信号过一遍部落本的文字。彭春梅起草的一段话里有一句“大家都知道结尾要留白”，蒋明立刻指出来，那句话的“大家”正好把他那个班压没了。改成“我们五人中有三人的班上有这种情况”，字多了，却是实话。

### ◆ 四、碰撞：纠缠由读出来、问出来的东西长成

现在可以回答，社区侧重的那个E，在这个下午到底长在哪里。这是 E＝H(S,D) 在社区一端的一个用例（方程见第2章）。放到这张长桌上，S是十一张摆在桌面上、能被读的页；D是读完之后每个人对不上的地方，谁圈红、谁圈蓝、谁画半个圈、谁说不出读法的来路，这些差异不是别人替她们采集的，是被一支笔、一句追问逼出来的。纠缠不是五个人在同一个群里，不是互相点过多少次赞，是P-04上的红圈、蓝圈和那半行字，彼此有了对得上或对不上的关系。

这样看，社区的E有两个来源，摆出来的页和被问出来的差异，缺一个就缩成别的东西；缺了会变成什么，第2章和第18章已经讲过，这里不重复。

会前一周，罗青禾还做了一件对应第二节的事：她请同校的邹老师，也就是第491号里那位教数学的邹老师，把P-04盲读一遍。邹老师没有画红圈，他画了半个圈，旁边写：“怕扣分是评分表的事，不是学生的事。评分表在谁手里，结尾就往哪边靠。”他不教语文，不计票，但这半行字抄进了页尾，标明“异科读者”。谭老师读到，说：“我三十年没这样想过。”一页上多了一个读法不同的人的声音，比再多一个语文老师的红圈，更能分出这页说的是教室里的事，还是语文老师们共有的看法。

再用六路径和123原理看一下共建的次序。次序上，部落本不是先定一个题目、再去收集材料，而是从页起手：先有每个人手里的页，再有盲认，再有对账，最后才有书名。起手错了，比如先定题为《初中作文的二十个误区》再去找页配，编出来的就是第439号说的调查报告，站在群体外面看一群人。动力上，是123原理里“两个先撞、推动第三个”：页和差异先撞，撞出一个任何人的子本里都没有的东西。

这个东西那天下午出现了。蒋明的蓝圈和谭老师的红圈撞在P-04上，没有人能说服谁。ChatSDE的追问器把两边的话并排放着，问了两个问题。给谭老师的是：“你班上写‘我明白了一个道理’的孩子，最近一次读过的好作文，是谁推荐的？”给蒋明的是：“你班公众号上登的作文，是谁挑的，挑的时候看什么？”答案回来，谭老师说是年级组每月发的范文集，蒋明说是他们自己班排版的小编，一个初二的女孩，她挑的都是老师在课上念过的。两条线接上了：结尾的道理，来自范文，范文来自老师念过的，老师念过的，是被扣分的结果。

于是桌上多了P-12，是五个人谁也没投过的一页：“结尾点题，多半不是学生怕扣分，是学生学来的样板，样板的来路在老师自己念过的范文里。”它标成部落新页，来路标是“推的”，等三个人各自盲认，认了才算数。这就是第439号第8章里王德生所说的“部落共同知识的新发生”：一个部落自己撞出来的知识，不是从上面分下来的，也不是谁的子本里本来就有的。第14章要讲的三种撞里，这一种叫“我撞别人”，它跟前两种的不同在于，撞的另一方不是母本，也不是过去的自己，而是一个同样要回家过日子的人。

这里要把三层的关系说清，因为部落既是土，也是市场。第491号第27章说，部落是知识长的土、验的市场、讨生活的饭碗，三样挤在一处，所以路短、验得准。这一页的验就是这样发生的：验P-12的，是用它的老师本人，改天回班上看看，范文集换一换，结尾会不会变。至于页将来能不能租读、调用、分账，那是第24到27章的事，这里只记一句：交易以认出为前提，没有三个各自的红圈，这一页进不了市场。第491号第28章把平台不越级写成铁律，这条规矩在这里变成一条编辑纪律：平台可以提供对账的工具和边界，不能替部落决定哪一页是共有的。“平台只统一方法与信任，不统一结论。”部落本的结论只能由认出它的人给。

### ◆ 五、慧店调用慧店：知识在另一家重新发生一次

长桌散了以后，罗青禾的店里发生了另一件事，来自佛山。阿乐在给骑手准备一次小课，主题是怎样把出险经过写在理赔单上。他发现一件怪事：骑手们在群里语音说起自己怎么摔的、怎么赔的，头头是道，写到单子上只剩一句“车坏了”，保险那边退回来三次。他的ChatSDE追问器停在“缺维”上，不补编，建议他去调一家做“写”的店的书。他想起表姐罗青禾，也想起她那本《不再是同一篇》，就在平台上发起了一次调用。

调用的规矩，本书的设计是这样。被调的是罗青禾的慧店专著，不是她的子本，子本默认关门；慧店专著由店主定价，可租可调可挂。调用时阿乐的智能体拿到的不是书，是出库口径规定的那一份：与他问题相关的一两条主张句，每条带一句判据句，附上粗来路（店、卷名、来路类别：说的、取的还是推的），限次，不送全文；条文编号、章位置、被引片段只记在来路链上，不进回答。罗青禾书里有一条主张是：“孩子写不出来，多半不是没东西可写，是不知道先说哪一件。”判据段是她把成立条件改写之后、逐条确认过的一两句不带个人信息的话，写成“当……时，先……”的样子：“当对方写出来的和说出来的不像一回事时，先让他口头说一遍，看他先说的是哪一件；如果和笔下先写的不是同一件，问题多半在次序，不在材料。”它不等于留在家里的条件层原文，哪一年哪个班哪个孩子，一个字也不在里面。第15章讲条文层进RAG时会详细说这个切法，这里要看的是调过去之后发生了什么。

阿乐没有把判据照搬。他请三位骑手先口头讲一遍再写，结果有一半对上了：他们口头先说的，确实和笔下先写的不是同一件。可是再往下问，原因和罗青禾班上的孩子完全不同。孩子是不知道先说哪一件，骑手是知道，他们先说的是“不怪我”。一次摔车，脑子里装着的第一件事是怕保险说责任在自己，所以单子上要么空着，要么只写一句不会被挑错的话。阿乐在自己的店里记下一条新条文：“骑手写出险经过，先写的是自保，不是经过。”来路标是“说的”，来源事件是三位骑手那天说的话，同时标明“取自罗青禾店，调用号某某”，判据借来，原因是自己长出来的。

这就是第491号第16章讲的“每迁一格，都要重新发生一次”在两家店之间的样子。罗青禾的判据到了阿乐那里，成立的部分，次序问题，被借用了；不成立的部分，原因，被重新长了一遍。如果阿乐只是把她的主张贴进自己的书，那是搬运，下一次骑手的情形一变就失灵；他把判据当一把尺子去量自己的土，量出了尺子够不到的那一截，才有了自己的条文。第491号第35章对买来的书也是这个态度：别家流进来的专著，先要拿到自己的土里撞一撞，才算用上。

调用的另一头也没有结束。阿乐在自己店里验过之后，把“判据在这儿灵了一半、原因不同”写成一条回写，投到罗青禾店的待回写箱里。这条回写不是结论，是调用方的不合声音，与部落本页尾那半行字是同一类东西。罗青禾读到，没有立刻改书，她在自己的追问队列里多了一道题：“你班上写打架那一篇，开头第一句，是在讲经过，还是在讲谁的错？”一个孩子的作文，一个骑手的单子，在两家店之间互相照出了对方没看见的一截。所以一次调用在被调用的那一家也让知识多发生一次，只是发生的是追问，不是答案。

每次调用都留在来路链里：谁调的、调了哪卷哪章哪条（编号在这里记，回答里不带）、什么时候、用来做什么、回答里引用了哪一段。来路一丢，这次调用不计费，也不得使用。怎样计价、怎样分账、怎样防有人批量调用来萃取，是第26、27章的事。这里要守的只有一条界线，也是第491号第28章的界线：平台只记账、只提供工具，不替阿乐判断判据对不对，也不替罗青禾判断阿乐的回写该不该采纳，两家店的复合体各自对自己的部落负责。

### ◆ 规格卡　部落本共建字段

最小字段如下，完整字段与示例详见附录一附表一。部落本可租（只租读）、调、挂、分，须经贡献者同意（规格十）；门槛数字为本书的设计〔待验〕。

| 字段 | 内容 | 规则 |
|---|---|---|
| 页 | P-nn｜一句主张｜三行日子｜来路标｜状态（候选／正页／分歧页／已撤） | 只含可出门的一层；失效页原文、条件层原文、画像永不入页 |
| 认出者 | N1…｜认／不认／半认｜一行自己的日子｜读法来路｜是否盲认 | 投页者以外三人盲认为“认”成正页，其中至少一人异校或异年级组，否则页尾标“同读法正页”；两人为候选页；两个半票折一票；异科读者不计票，话抄页尾 |

## 第 18 章　三部分互相回写

> **这一章的问题**：浏览、ChatSDE、社区在一个人的一周里怎样互相改写？缺了哪一块会变成什么？

### ◆ 一、周日夜：同一条文，三处亮灯

九月最后一个周日的夜里十点，豆豆睡下了，罗青禾把笔记本搬到客厅的饭桌上，打开平台。首页没有推荐栏，只有林可上个月帮她调出来的一张“本周动静”，三行字。第一行在书架：《我的作文课》第七章第三节，被部落本里的P-04标了“待改”。第二行在ChatSDE：追问器昨晚排好了一道题，等她回答。第三行在社区：周六长桌上长出来的P-12，三位认出者里，她排第一个。

三行说的是同一件事。她子本里有一条条文，编号T-022，主张是“孩子结尾总写‘我明白了一个道理’，是怕被扣分”，来路标是“说的”，状态“待验”，从二月认领起已经放了大半年。它在书架上是第七章第三节的一段话；在ChatSDE里是条文层的一块，追问器和别家来调用的智能体翻到的就是它；在社区里，它是周六她给谭老师那一页画下的红圈。一条条文，三处同时在场，而这一周里它每一处的样子，都将被另外两处改动。

这一周她有二十二节课，一场家长会，周六下午还要去社区活动室，能分给平台的时间，大约是每天午休的半小时和孩子睡下之后的一小时。她想知道的是，在这么挤的时间里，平台是在替她多做事，还是在多给她添事。判断的办法很朴素，看一周下来，三部分有没有互相改过对方，改的时候是谁点了头。

她没有急着点哪一行。平台对每一行只做一件事：提议。书架上的“待改”只是一个标记，不会自己动正文；追问器的题可以跳过，跳过不记过；P-12要不要认，由她盲认，平台连别人已经认了几个都不给她看。凡是推断出来的东西，比如平台从她这周的停顿推出“她对结尾的读法有些动摇”，只能写进“推断·待本人认”那一栏，没有她点头，不进画像，也不改任何一页。机器的位置是把线头递到她手里，线怎么接，是她的事。

她把这个念头发给了林可。林可回得很短：“一周下来，你会碰到每一部分三次以上，但每次是谁先动，每周不同。”罗青禾把笔记本合上了一半，想起第2章讲过的那张三乘三的表，那是一张静着的图。这一周要看的是图动起来：同一条文怎样在三个地方被改，三个地方又怎样互相规定，缺了其中一个，会掉到什么里去。

### ◆ 二、周一周二：追问被书页和邻座改写

周一午休，罗青禾先去了书架。浏览这一部分最朴素的本事是并排：她把第七章第三节和部落本P-04放在同一个屏上，左边是她自己写的“怕扣分”，右边是谭老师那一页，页尾抄着蒋明的半行字。读到自己那句时，她停了一下，在句子旁边点了一个“存疑”。这个动作很小，它不改正文，只是一个读者在书页上留下的痕迹，平台把它记作：读，不改。

接着追问器动了。这是 D＝G(S,E) 的一例（方程见第2章）。放到这个午休，D是追问器这次问什么、怎么问；S是她刚留下“存疑”的那一句书页；E是部落本里蒋明的蓝圈和P-12还没认完的那些票。上周的题原本是常规的保质期提醒：“T-022已经放了大半年，这学期验过吗？”现在这道题被改写了，改写它的，既有书页上的一个记号，又有社区里一个对不上的声音。新题是：“上周收上来的四十三篇作文，结尾不写道理的有几篇？是谁？”

这道题的写法有讲究。第14章讲问对引擎时会说，追问器一次一问，不带答案去问，允许说“没有”，允许说“不想答”，允许用嘴答。罗青禾在办公室的窗边按了语音键。她答：“三篇。”追问器问：“这三篇的结尾各是什么？”她答：“一篇是一句问话，一篇是一个动作，还有一篇……我想不起来了。”追问器没有替她补，只是把“想不起来了”记下，挂在那一篇上，写着“待回看作业本”。再下一问是：“这三个孩子，平时读的范文是谁挑的？”她停了半分钟，说：“没有，我不知道。”

当天放学前，她在走廊里拦住了H，三篇里那个结尾是问句的孩子。她没有问“你为什么不写道理”，那样问，孩子只会交出一个听着得体的答案。她问的是：“上次你最后写了一句‘它到底去哪了’，怎么想起来这么写的？”H挠了挠头，说：“写道理好无聊，我就问问。”她又问：“那别人都写道理，你不怕吗？”H想了想：“没人说不能问啊。”整段对话不到一分钟，她回办公室，用嘴把它说给了追问器，追问器把它记在T-022下面，来路标是“说的”，来源是一个孩子在走廊里的两句话。

周二晚上，她把三本作业本翻了出来，补上了周一想不起来的那一篇：结尾只有一句“天黑了，我们回家”。追问器把“待回看作业本”那一条销掉，记成“说的”，又问了一句：“这三个孩子，有什么共同点？”她想了想，答：“都不是班上最会写的。”追问器没有顺着这句往下推，只把它存着，留作下周的一题。会写与不会写，是不是和学不学样板有关，她现在不知道，也不该由机器替她知道。

“没有”这两个字被原样存进去，没有被改成一个听着合理的答案。缺维宁可停下来问，也不补编，这是第9章里从第414号接过来的纪律，在这一周里第一次派上用场。那个空，后来成了周三书页上最诚实的一句话。如果追问器当时替她补了一句“可能是教参推荐”，她很可能就点头了，因为这个答案听起来太像她十二年里读惯了的读法，补上去的东西会把一条原本通向外面的线封死。

这里能看到“回写”和“反馈”的差别。第439号第8章把二者分过：反馈是把结果送回去给原来的东西看一看，原来的东西不一定变；回写是原来的东西因此变了。周一周二这个过程里，书架上的记号让追问器的问法变了，社区里的蓝圈也让它变了，被改写的是下一次问什么，而不是已经问完的答案。问法一换，同一个罗青禾答出来的东西就换了一批。

这一次的路径类型，本书记作两条：书架到ChatSDE（读者在书页上存疑，触发追问）、社区到ChatSDE（他人的不合声音，触发追问）。两条的共同特点是，平台提议，本人可以跳过，而且都不写入画像。

### ◆ 三、周三周四：书页被问出来的和认出来的改写

周三晚上，她回到书架，要处理那个“待改”。这是 S＝F(D,E) 的一例。这里的S是第七章第三节要变成什么样子；D是周一周二问出来的东西，三篇作文，一个问句，一个动作，一个不知道，以及她说的“没有”；E是部落本里P-04、P-12，加上蒋明的半行字，三位老师的红圈。书页怎么写，既不由她一个人的感觉定，也不由社区平均一个答案，而是由她被问出来的和被认出来的东西一起规定。

先写的不是正文，而是失效页。ChatSDE在这里只做两件事：把旧版指给她，把“你上次说过”的那句原话摆出来。其余各栏要她自己落笔：上次的读法，“结尾写道理，是怕扣分”，指回第七章第三节旧版；当时凭什么这样读，十二年的班，以及这大半年孩子们交上来的作文；后来是什么撞开的，周六长桌上蒋明的蓝圈，周二她自己说出的“没有”；现在的读法，现在她读成“结尾的道理，多半学自老师念过的范文，怕扣分只是其中一部分孩子”；还没读透的地方，那三个不写道理的孩子为什么不写；谁在场，班上一个孩子，页上记作H。类型：读法失效。编号F-004，只加不改。

这页失效页机器写不了。第20章会讲，机器补写的失效是装饰，它写得出一页格式漂亮的东西，可是“我上次以为什么”只有上次以为的那个人才记得，“后来是什么撞开的”也只有被撞到的人才指得出来。平台可以提醒、可以排版、可以把F-004和T-022连起来，不能代笔。

失效页落了笔，正文才动。新的第三节不再叫“怕扣分”，改叫“道理从哪里学来”。旧段落留着，在版本里用一条线连到新版，读者可以在浏览部分把两版并排看。新节里有三个变化：一是结论换了位置，从“学生怕扣分”退到“学生学样板”；二是多了一个小例子，H的那个问句结尾，被她写成“有人不这样”；三是末尾有一句：“这一节，我暂时还看不见：为什么班上有三个孩子，不学样板。”第439号第8章里，程卫东的子本留空了一章，写的是“这一章，我暂时还看不见”，书里称它是子本里最诚实的一句；伪子本没有这样的句子，因为它什么都写得满。

同一个晚上，T-022在条文层也变了：旧条文状态改为“已失效”，指向F-004；新条文T-022 v2写下，状态“待验”，来路标“说的”，牵连栏挂着P-04、P-12。做法层同时多出一张工序卡《批作文时问结尾三问》，三问是：这个结尾是孩子自己的话，还是某篇范文的话；去掉最后一句，文章还完整吗；他是在哪里读到这样收尾的。检查点是每问都在作业本上留一行记录。这张卡的状态是“待跟做”。跟做闸在这里起作用：这张卡没有在她身上跟做验证过，只标待跟做，不进ChatSDE的Skill。周四早上，她做了第一件跟做的事：把周五要念的范文换成班上一个孩子的作文，一篇结尾不写道理的。结果会不会变，下周才知道，到时候记入跟做记录。

这一段的事件有两条类型值得记下：ChatSDE到浏览（本人答出新说法，触发失效页、条文与正文的修订），以及社区到浏览（部落本正页成立，触发“待改”标记）。前一条必须本人落笔，后一条只是标记。浏览这一部分在这里的用处，是让这次改动留在明处。周三夜里她点开版本对照，左边是v1的第三节，右边是v2，改了什么、删了什么、新增了什么，用颜色标着；失效页F-004单独排在“按时间的失效页”那一栏，挨着前面几页旧的，一翻就能看出这半年她改过几回口。读者不必信她改得对，只需要看得见她改了。看得见是后面所有核对的前提。书页能不能动、动成什么样，权力始终在她手里，三部分互相规定，规定的是可能性，没有任何一部分能替她写下“我错了”。

### ◆ 四、周五周六：社区由读出来、问出来的长成

周五夜里，她做了一件周日夜里还没想到的事：把这一周的东西，拣一页出来，准备拿给部落。出门的只能是改写过的一层。她没有再投一页“结尾的道理学自范文”，那一句已经是P-12，她投的是失效页里“还没读透的地方”：一句主张“也有孩子不学样板：三个里有一个用问句收尾”，三行不带人名的日子，其中一行是那个孩子的原话“没人说不能问啊”，来路标“说的”。F-004的原文、T-022的条件层原文，她班上的名字，一个字也不出门。ChatSDE问了她一句：“这一页，你愿意署代号放进部落本吗？”她点了“是”。逐页同意，是规格十二里谁也不能代点的一步，平台提议，她点头。

周六的长桌上，这一页是P-13。三位认出者盲认，彭春梅在旁边写：“我班也有一个，最后写了个问号。”余晓棠画了红圈，蒋明画了红圈，写的是“我班有两个”；谭素芬画了半个圈：“有。三十年里见过几个，很少。”它成了正页，带着谭老师那半行字。同一个下午，上周六长出来的P-12也凑齐了三个红圈。这一周下来，部落本里的页变了，页和页之间也变了：P-04、P-12、P-13被编者连成一族，标着“同属范文来路”，P-13是这一族里“不学样板”的那一面。

谭老师那半行字，罗青禾照第17章的规矩原样抄在P-13的页尾，没有把它并进“多数认同”。三十年里只见过几个，这个数字对一个五人的部落是有用的：它提醒不学样板的孩子不是常态，这一族页要写的不是“学样板是错的”，而是样板的来路在哪里，以及不走这条路的人也在。她是这一页的投页者，也是编者，这一次收圈的人是余晓棠。

这是 E＝H(S,D) 的一例。社区的纠缠不是这间屋子里多了几个人，而是P-13这样的页，由一页失效页写出来，却只带着三行日子出门，摆在桌面上；加上谁认、谁不认、谁说“有一点”这样的差异，被一支笔和一道追问逼出来。如果罗青禾只发一句“我觉得结尾是学来的”，在群里得到三个赞，纠缠是不会长的，没有页可读，也没有差异可对。

纠缠长出来，又立刻回过头去改别人。周六散会前，彭春梅说：“我那十六个，我得回去查他们读过什么，也查查里面有没有不学样板的。”她的追问器因此在下周一多出一道题：“你班十六个孩子的结尾，各自对应哪一篇你念过的范文？”这是社区到ChatSDE那一条线，另一个人身上的。一页脱了名的页，在罗青禾的子本里是出门版，到了彭春梅那里是一道要回答的题，在谭老师那里则是P-04旁边多出的一个链接。同一个基因，在别人身上又表达了一次。

这里要补一句边界，别让人以为社区会一直吞下去。社区长出来的东西，不会自己回灌到谁的书里。P-13进了部落本，罗青禾的第七章没有因此自动改一个字；它只在她那里留下一条提议，等她季度收口时与总纲卷对账（第21章）。部落本里反复出现的东西，要不要回写给母本，也要经每位贡献者逐页同意，且只送脱名的失效摘要，不送子本本身（第23章）。社区的纠缠是一种拉力，不是一只手。

这一周她的店被别家调用了两次。其中一次来自佛山，阿乐店里的智能体取走了她《不再是同一篇》里的一条判据，用在骑手小课的另一个环节上。来路链上多了一行：谁调的、调了哪卷哪章哪条、什么时候、用来做什么，她没有收到任何要她处理的事（这是另一次调用，调用方没有回写）。这是R-07：它不改她的任何一页，只记账。可是账记在那里，对她有一个间接的用处，她能看到自己的书里哪几条正在被别人当尺子，哪几条从来没人碰。被碰得多的，往往是她下一轮最该核对条件的地方。

周日夜里，罗青禾再打开“本周动静”。三行字换了：书架上，第七章第三节的“待改”变成“已改，新版v2”；ChatSDE里，有两道新题，一道是回看那三个孩子的作业本，另一道是她要不要给F-004补一笔“还没读透的地方”；社区里，P-12、P-13已成正页，下周还有三页等她盲认。屏幕下方多出一行小字：本周您的店被别家调用两次，内容未变。

### ◆ 五、两部分先撞，第三部分才动

第2章讲了规定和动力，这一周是它的演示：周一，社区的蓝圈先撞书架上的“存疑”，追问器的问法被改写；周三，问出来的与认出来的先撞，书页被改写；周五到周六，书页与失效页一起摆上桌面，社区的纠缠随之变厚。每一次都是两个部分先撞，第三个部分才动，起手的部分每周不同，这一周从社区起手，下一周也许从书架，也许从追问器。三部分与S、D、E是侧重关系，不是等号，这一点也在第2章立过，这里不再申明。

林可后来把这一周画成了一张表，画在一张外卖单的背面。她话少，表上没有一个形容词：七条线，每条线只填三样东西，谁触发、送到哪、要不要本人点头，页边另有一行小字：点错了怎么退。罗青禾看了一会儿，指着“点错了怎么退”那一栏说：“这一栏最要紧。”林可点头，在后面加了一行小字：失效页只加不改，退回的办法是再写一页，不是擦掉那一页。下面规格卡里的七条线，就是从这张表整理出来的。

先认对手。卡帕西（Karpathy）2026年4月的LLM Wiki〔日期据二手报道，待核〕，用三个操作把个人知识养起来：新来源进来，更新多页；问出来的好答案，归档回库；定期检查矛盾和过时的断言。这三个操作和这一周几乎同构，尤其是查询结果回写和查过时，本书不能把它们当作自己的发明。卢曼把自己的卡片盒看作一个能让他意外的对话者，盒子自己长出结构，有了自己的生命。马图沙克的常青笔记同样主张笔记为自己写、随时间演化累积。它们说对了一件事：个人知识应该是持续生长的产物，不是每次检索的一次性结果。

本书多走的是两步。第一步在第三端：那些回路里，只有一个人和一个库，没有别人的页和不合的声音这一端。T-022一周之内被改动，起点是蒋明那半行字，如果没有社区，罗青禾的追问器永远问的是保质期。第二步在谁写：LLM Wiki的设想里，库的写与维护主要由模型承担，人负责选来源、提好问题；本书反过来，机器提议，本人确认，失效页只能本人写下。这两步是工程与制度层的，本书不宣称它改变了回路的原理。

最后是缺一部分会怎样，只看这一周特有的症状。抽掉ChatSDE：周一的“存疑”只剩书页上的一个记号，没有人问她“几篇、是谁”，书页和部落页并排躺着，T-022还是那条放了大半年的条文。抽掉浏览：追问器照样问，她照样答，可是答完的话散进对话流水，周三要写F-004时，“上次的读法”没有旧版可以指回去，失效页缺了最要紧的一栏。抽掉社区：蒋明的蓝圈不存在，P-12不存在，追问器问得再细，红圈也都是她自己的回声；一个只和自己对质的人，十二年的读法恰恰最难被自己撞开。

三种症状各有一个迷惑性：单看都像是健康的。书都在，对话很聪明，群里很热闹，没有一个看上去出了毛病。可是放回这一周，缺的是同一种东西，即另外两部分无法自己提供的那一种力：逼着书页动起来的差异，能被指回去的旧版，各人手里那一页。三部分因此不能拆开卖，也不能拆开读。

### ◆ 规格卡　三部分之间的回写事件

七类路径如下，事件号、动作与收口清单详见附录一附表二。平台只提议，写入书页、条文、失效页、画像须本人确认；推断只进“推断·待本人认”。点错了一律再加一笔，不擦旧的。

> **带走的话**
> 三部分不是三个栏目，而是一条条文在三个地方被不同的方式碰到：书页让它被读，追问让它被问，社区让它被认或被驳；任两样先撞，第三样才动。

> **小账**
> 承接：接第439号第8章的回写四动作和“回写不是反馈”，把它们放进一个人的一周，写成七类事件的类型、触发、去向与确认；接第491号第28章三层不越级，平台只提议、本人确认。
