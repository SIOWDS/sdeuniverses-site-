# 结语　德在账上

这本书从一台冰箱开始，也回到这台冰箱。

前言里那张家务积分榜，贴到第三周就出了事：老大抢着拖地，老二说她“刷分”，弟弟把一袋垃圾分成三袋倒了三趟；那个周四傍晚，奶奶在阳台扭了腰，喊人扶一把，三个孩子都听见了，谁也没动。那天晚上妈妈看着冰箱门，第一次觉得这张榜不是在帮她，是在跟她作对。

她没有把榜撕掉。撕掉一张榜容易，换一张新榜也容易，难的是在旧榜旁边留出一块空白。孩子们确实比以前多干了活，碗有人洗，地有人拖，这一页账是有用的。她做的事很小：拿一支笔，在榜的右边画了一道竖线，把一张纸分成两栏。左栏照旧，洗碗三分，拖地五分，倒垃圾一分，周末谁积分第一谁选去哪儿玩。右栏的栏头，她写的是：“这周我帮了谁，谁帮了我。”下面又加了一行小字：右栏不打分，不排名，谁都可以写，每月最后一个星期天，全家一起改一次记法。

第一个月，右栏很空。老大写了一条“帮弟弟找到了鞋”，老二写了一条“姐姐借我橡皮”，弟弟画了一个歪歪扭扭的笑脸，说是“我帮奶奶拿遥控器”。四个星期加起来，不到十行。左栏照旧挤得满满的，数字一格一格往上加。

有一件小事，妈妈后来常提。第二周的某天晚上，弟弟站在冰箱前，一条一条地数右栏，数完大声宣布：“我写了三条，比哥哥多！”老二当场不干了，说右栏不是比这个的。两个人吵到妈妈出来。她没判谁对，只说：月底开家庭会，你们俩谁有意见，那天提。

月底的家庭会上，老二真的提了。他说右栏应该加一条规矩：不许数谁写了几条。老大补了一句：也不能只写自己帮了别人，别人帮了你也要写。妈妈把这两条写在了右栏的最上面，旁边用小字注明：“第一个月家庭会，老二、老大提议加。”弟弟有点委屈，可他也提了一条：奶奶也要能写。全家都愣了一下——那张榜从贴上去那天起，就没有奶奶的位置。妈妈把这一条也写上了，注明“弟弟提议”。

第二个月，右栏写满了。

写满的不是因为大家突然变好了。左栏还在，周末去哪儿玩还是积分第一的人说了算，老大还是常常抢着拖地。变的是右栏里写的东西。老二写：“姐姐教我做那道分数应用题，讲了两遍。”老大写：“弟弟晚上帮我把校服叠了，虽然叠得不好。”弟弟写：“哥哥陪我走到小区门口，因为那只狗在。”有一条是老大和老二一起写的：“周三扶奶奶下楼去菜市场，一人扶一边。”

最下面一行，字迹和孩子们的都不一样，写得很慢，一笔一画。那是奶奶写的：

“老二扶我下楼。我教老大擀了饺子皮。”

妈妈后来说，她看到这一行时站在冰箱前好一会儿。这张榜贴了两个多月，奶奶头一回在上面出现，不是作为一件没人做的家务，而是作为一个写账的人。她被扶了一次，也教会了别人一样东西；她写下的没有分数，只有一来一回。第一个月那个没人扶的奶奶，在第二个月的账上，成了这个家里的一个“之间”。

第二个月的家庭会，也不是一团和气。老大提了一个很精明的主意：右栏写得多的人，能不能换一点左栏的分？她算得很清楚，扶奶奶一次，抵得上拖一回地。妈妈险些答应——这听起来是在“奖励善良”。可她想起两个月前那个晚上，自己拿起笔差一点就写下的那一格“扶奶奶，十分”，又想起第一个月弟弟数条数的那一晚，摇了摇头。老大的提议，正是她自己当初放下的那个念头，换了一个更精明的说法。她说：右栏一换成分，大家就会去抢着扶奶奶，奶奶不疼的时候也要被扶；那样右栏就成了第二个左栏。老大不太服气，但这条提议没有写上去，妈妈在家庭会的小本子上记了一句“老大提议右栏换分，没通过，因为一换就又比了”。没通过的提议，也留了一行。

第二个月里还有三天，妈妈出差去了外地。她走之前有点担心，回来一看，右栏多了五行，其中一行是弟弟写的：“奶奶说腰疼，我去叫了哥哥。”没有人盯着，那一栏照样有人写。本书说一条制度的美，就是没人看着的时候大家还愿意守它；这个家里的美，那三天露了一下脸。

左栏为什么不撤？妈妈想过。撤了左栏，碗可能就真没人洗了；而且孩子们比积分时那股劲头，也不全是坏事，老二为了拿第一学会了把灶台擦干净。名次是一种真，它让人看清楚谁干了多少，这一页账不必撕掉。毛病从来不在左栏，在于冰箱门上原来只有左栏，而且只有妈妈一个人能决定左栏怎么记。

这就是本书花了二十三章想讲的事。

换成本书的话，这台冰箱是这样的。左栏是一号位的账，记对比，把每个孩子显成一颗粒子，谁多谁少一目了然。右栏是给二号位留的一页，记的是一来一回，扶一下、教一下、陪一段路，只有在两个人之间走完才看得见。每月那次家庭会，和右栏顶上那几行写着“谁提议加”的小字，是这个家慢慢长出来的三号位：一个大家愿意守、也知道能改的场。次序也是本书说的那一条：妈妈先改了记法，家里人之间的往来跟着变了，奶奶那一行字才显露出来。她没有先开一次“我们要互相关心”的家庭会，也没有先给三个孩子讲孝顺的道理。

那几行小字还有一个用处。暑假里表哥要来住一个月，他头一天站在冰箱前看了半天，指着“老二、老大提议加”那一行问：“这个是你们自己定的？”老二说是，表哥就问，那我能不能也提一条。这个家里的规矩可以改，不用谁去讲，写在纸边上的那一行字已经告诉了后来的人。

那三个孩子，在第三周和第二个月之间，并没有被上过一堂思想品德课，也没有人对他们说“你们要孝顺奶奶”。他们心里的那点好，在第三周就有，在第二个月也还是那么多。变的只是冰箱上那张纸：它多了一页给“之间”的账，这一页不打分、不排名；而且记法不只握在妈妈手里，老二能提议，弟弟能提议，连奶奶也能拿起笔。善没有被挤掉，也没有被压住，它在第三周只是没有地方显露；等账上给它留了一页，又允许被记的人改账法，它就显露出来了。

把冰箱换成教室，把妈妈换成苏老师，把家务榜换成周一早上推送的那张周榜，故事是同一个。林可有空却没给周远讲题，阿杰修好了投影仪没人看见，小敏读到班规旁那一行小字才敢举手。七班这一学年改的，也不过是几页账：撤掉了周榜排名，加了一个本子，在班规旁边写上它的来历和改过的痕迹，让学生在班会上能改一条记法。

所以本书最后，把开头那句话再说一遍：

学校的道德不发生在课上，也不发生在心里，而发生在账上。善只在人与人之间显露；只有当学校的记账制度给“之间”留出账页，并且允许被记的人改写账法时，善才显露为善。否则善被折成名次，冷漠与作弊就是这本账的利息。

这句话有可能是错的。第 23 章把它会怎样错，写得清清楚楚：账页与账法之间如果没有交互，它就退回两篇旧论文的加法；先改账与先改组如果没有分别，它说的那条路就不成立。一本讲账的书，该把自己的账也摊开来，让人能改。

在被证明错之前，它至少给读这本书的老师、家长、校长留了三个随身带着的问题：这里的好，记在哪本账上？是谁拿的笔？被记的人能不能改账法？

问一问自己家冰箱门上贴着什么，问一问班级群里每天推送的是什么，问一问学校的评估表上，有没有一栏是留给“之间”的。不同的读者，带走的可能是不同的一页。做班主任的，也许只需要在班级日志里留出一栏，让学生自己写“这周谁教会了我什么”，并且在下一次班会上，问问大家这一栏该怎么记。做家长的，也许只需要在晚饭桌上，把“今天考了多少”换成“今天谁帮了你，你帮了谁”，再找一条家规，和孩子一起改一次，把为什么改写在旁边。做校长的，也许只需要在评估表上，把“德育活动开展了几次”换成“学生提议改过几条规矩、改动有没有留痕”，而且不给这一栏打分。

也会有一天，冰箱门上的那张纸变成手机里的一个应用，教室后墙的班规变成屏幕上的一行字。那时候，第 22 章的三条底线就是这三个问题的另一种问法：本人读不读得到？本人改不改得了？会不会被拿去排名？记账的工具会变，问法不变。机器记得再快，也替不了奶奶写下那一行字。

问完了，也许会发现，我们一直以为孩子不够好，其实是我们的账不够宽。

善不缺，缺的是一页账，和一支被记的人也能拿起来的笔。
