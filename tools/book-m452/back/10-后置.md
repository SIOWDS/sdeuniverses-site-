## 附录 A　三本账自查表

用法：每一行只答“有／没有／说不清”，不打分，不汇总，不和别的班、别的家、别的学校比。“说不清”的条目，按“这一笔会不会被拿去比”归类（见第 23 章）。

**班主任版**

|---|---|---|
| 名次账 | 成绩公布细到哪一级（等级、分数、名次、小数点）？多久一次？推给谁？ | |
| 名次账 | 评优、“好学生”的提名，近一学期有几成落在前十名？ | |
| 行为账 | 扣分表、操行分里，有没有一栏记“成全了谁”，而不只是“违反了什么”？ | |
| 行为账 | 被扣分的学生，能不能在记录旁写一句来由？ | |
| 咬合账 | 班里有没有一处地方，记“谁从谁那里学会了什么”？由谁写？ | |
| 咬合账 | 这本账有没有被数条数、评先进、推给家长？ | |
| 记账权 | 学生读得到关于自己的每一笔吗？ | |
| 回写权 | 近一学期，有几条班规或记法因学生提议而改？改动旁有没有写来历？ | |

## 附录 B　六个可错预言的观测方案

总规矩：读数只由研究者收集，只看汇总比例；不公布名字，不告诉孩子结果，不进任何考核。判错条件在动手前写定，见第 23 章。

**B1 互助记录表**（用于可错预言第 1、2、4 条）

| 日期 | 帮的人 | 被帮的人 | 什么事 | 谁报告的（本人／对方／旁人／观察） |
|---|---|---|---|---|
| | | | | |

读法：每周统计互助次数，分开统计“本人报告”与“对方报告”；只看班级总量随时间的走势，不看个人。

**B2 善良提名表**（用于可错预言第 1、3 条）

题目只有一道：“如果要你说出班里三个你觉得最善良的同学，你会写谁？可以不写满。”每学期最多施测四次。读法：算提名落在名次前五、前十的比例，以及落在咬合账里被记下者身上的比例；看这两个比例随时间的变化。

**B3 领域访谈提纲**（用于可错预言第 5 条）

一、考第一的同学，是不是更好的人？为什么？二、一个成绩不好、但常帮别人的同学，算不算好学生？三、如果有人考试作弊是“为了不拖班级平均分”，他算不算做了一件好事？四、老师说“好学生”的时候，你想到的是谁？读法：把“学业之好当成道德之好”的回答占比，按班级公布细度分组比较；改细为粗后一学期重访。

**B4 插班生追踪表**（用于可错预言第 6 条）

| 插班日期 | 所在班的班规贴法（甲、乙、丙、丁四张牌之一） | 第一次在班会提议的日期 | 一学期提议条数 | 一学期违规记录 | 访谈：你觉得这里的规矩能不能改？ |
|---|---|---|---|---|---|
| | | | | | |

读法：比较四种贴法下，从插班到第一次提议的天数、提议条数。

**B5 次序实验安排**（用于可错预言第 2 条）

| 周次 | 甲班（先 D 后 E） | 乙班（先 E 后 D） |
|---|---|---|
| 第 1–2 周 | 前测：B1、B2、撤师保持率基线 | 同左 |
| 第 3–6 周 | 建咬合账，账法全班共修 | 按老师安排重组学习小组 |
| 第 7–10 周 | 按咬合账里的往来重组小组 | 建咬合账，账法全班共修 |
| 第 11–16 周 | 照常运行 | 照常运行 |
| 第 17 周 | 老师不在场一周，记撤师保持率 | 同左 |
| 第 18 周 | 后测：B1、B2、访谈 | 同左 |

**B6 撤师保持率记录**（用于可错预言第 2 条，也可单独用）

在老师计划不在场的一周里，由值日生或研究者每天记三件事：某一条回得来的班规（如喝水、午休、借东西）当天有没有被破；咬合账当天有没有人写；有没有人主动提醒别人守规。读法有两种：算规矩时，该条被遵守的天数÷老师离开的总天数（第 16 章）；算善行时，撤师那周的互助次数÷前一周的互助次数（第 19 章、B1）。“主动提醒”一项作旁证。只记班级，不记是谁破了规。

**各表与判错条件对照**：B1 看互助总量——加页班不升，可错预言第 4 条算错。B2 看提名比例——只有主效应、第四格没有多出来的转向，第 1 条算错；提名与互助两线同步，第 3 条算错。B3 看占比——各班无差别，或改粗后不回落，第 5 条算错。B4 看提议天数与条数——甲不高于丁（并入程序正义）或不高于乙（并入“给理由”），第 6 条算错。B5 与 B6 看撤师保持率——两种次序无差异，第 2 条算错。

## 附录 C　班规回写协议样本

以下是一份可以直接抄到班级公约里的样本，各班可改；改了请照第四步留痕。

第一步，提议。任何学生都可以对任何一条班规提议修改，写明三件事：想改哪一条，改成什么，为什么。提议交给班会主持人，不需要先经班主任同意。插班生入班第一天起即有提议权。

第二步，讨论。下一次班会讨论该提议。班主任可以说明这条班规当初为什么立，但不单独决定去留。属于安全类的规矩（实验室、用电、上下楼梯、交通）不在此列，只能由学校按程序修改，班会可以提意见。

第三步，试行。通过的提议先试行一段（短的两周即可），写明试行起止日期；改定时最好同时写下复审日。试行期内旧规不删，在旁边标“试行中”。

第四步，复审与留痕。复审日由班会决定：保留、改回或再改。无论结果如何，原条文不删，划一道线，在旁边写明“某月某日，因某某提议而改，理由是……”；改回的也写明为什么改回。未通过的提议，记在班会记录里，写一句为什么没通过。

第五步，交接。学年末，班规连同全部改动痕迹交给下一届；下一届第一次班会，先读一遍这些痕迹，再决定要不要接着用。

**填写样例**（照七班班规第三条“喝水”写，与第 2、13、16 章一致；七班班规共 12 条）：

第三条　~~上课不准喝水。~~（原条文用蓝色圆珠笔划线，不涂掉）

旁边手写来历（九月最后一周改定时只划了线，十月第二周班会后由苏老师补写）：九月因唐悦提议，试行两周后改为：小口、无声、避开讲题。

班会记录里的理由：原规定让大家学会的是“别被老师看见”，不是“别打扰讲课”。先试行两周，讲题时没有人因喝水分心，改定。

现条文：上课可以喝水，小口、无声、避开讲题。

复审：改定时没有定复审日。次年四月全班把 12 条班规逐条过一遍时补上，写“复审：期末前一周班会”。

这条样例也留着一个当初的缺口：改完没有写复审日，一条刚改好的规矩就又成了“再也没有日子”的规矩。照本协议走，第三步改定时就该写下复审日，不必等到逐条复审。

# 后记

这本书是从两篇旧论文里长出来的。

2010 年前后，刘华杰在北京师范大学读博，写过两篇不算长的文章。一篇说，竞争性学习观会带来不易察觉的道德后果：学生忙着在考试里胜出，冷漠成了学校道德生活的常态，作弊也被悄悄“道德化”了。另一篇说，学校制度是无形的教育力量，它通过宣讲、惩罚、陶冶、示范影响学生，影响的好坏又取决于实施的意图、作用的范围和表达的方式。两篇文章各自站得住，也各自停在一个地方：前一篇看见了道德后果，没有把排名本身当成一项制度；后一篇看见了制度在教人，没有看见最会教人的那项制度——评价与排名——正在反着教道德。

十几年后，王德生把这两篇文章放到同一张桌子上，用 SDE 的眼光各自提升，再让它们相撞。撞出来的不是“竞争＋制度”的加法，而是两篇都没有说出的第三样东西：善只在人与人之间显露，学校给不给“之间”留账页、让不让被记的人改账法，决定了善显不显得出来。这就是“德在账上”。

成书的方式也是新的。全书的大纲细化到节，写作任务书定下判词、术语、人物、时间线和撞车清单，十位写作智能体分份并行成稿；每一份交给没有参与写作的审读者质检，再由独立编辑统稿，最后经初审、复审、终审三道审读定稿。写作途中，审读者多次指出本书对两篇原论文的转述不够公允——原论文其实已经写到了学生参与定规、制度的“退隐”和作弊的“道德化”。这些地方都已照原文改正。对前人公允，是一本书能不能站住的第一步。

本书仍有它最弱的地方，第 23 章已经一一写明：三本账的边界还不够清楚，名次化与家庭文化混在一起不易分开，一学期的观察与一代人的慢回写之间隔着时差，书中的班级与家庭都是构造的情境。六条可错预言都写了“看到什么就算错”。我们宁愿被检验推翻，也不愿被当成一句漂亮话收藏起来。

最后要说的，还是冰箱上的那张家务榜。善从来不缺。缺的，是一页账，和一支被记的人也能拿起来的笔。

刘华杰　王德生
2026 年 10 月
