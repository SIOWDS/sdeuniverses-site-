## 读书建议

这本书有两种读法。想先弄清它主张什么、凭什么，可以先读导论，再读第15章（怎样算错）和第45至47章，最后读结语，这几处合起来是全书的骨架；然后回头看附录三，把每条主张的失败条件对着自己熟悉的事例一条条试一遍。想按自己的行当读，可以先读第一、二编弄清统一性知识怎样成了元件，再读第三编立起“发生”这个本业，然后只读与自己相关的一编：自然科学读第四编，社会科学读第五编，人文读第六编，医学、工程、农学、法学、管理、教育读第七编，关心大学怎样开门的读第八编。读的时候有三点值得留意：书里的 S、D、E 是三种互相生成的关系，不是三栏对照表，不要拿它去给学科或事例贴标签；书里的案例凡带“设想”二字的，都是用来说明机制的假设情形，不是实地调查；读到“怎样算错”，请把它当作邀请，而不是装饰。引用书中涉及他人研究的说法之前，请先翻附录四，那里列了尚未逐条核到原始来源的地方。

## 附录一　王德生的口述命题（2026年10月28日）

下列五条是王德生于2026年10月28日的口述，原文照录，未作改动。每条之后写明它主要在哪些章展开，章号依本书目录。

> **K1**　大学的重生与知识生产典范转移：从统一性到同一性谱系的诞生。统一性知识的生产将转移到大厂（大模型公司＋顶级科学家加入），大学变革为“同一性谱系知识的生产”，而“统一性知识”则是基本资料和基础元件。

K1 主要在导论、第5至8章（统一性生产转向大厂、元件化及其边界）和第45章（知识生产的典范史）展开，结语第二节从 universitas 的原义再回到它。

> **K2**　同一性谱系知识和应用是直接挂钩的，即“部落群体，即E的谱系性”为基础的，大学不再是“知行分离”，而是“知行一体”。

K2 主要在第3章（知行分离）、第10章（发现的谱系与发生的谱系）、第11章（部落群体）和第12章（知行一体）展开，第39章（科研）与第44章（治理与财政）把它落到立项单位和经费上。

> **K3**　大学教授和学生将来是：深入E，发明D，涌现S。

K3 主要在第13章展开；第18至20章、第24至26章、第30至32章分别在自然科学、社会科学、人文学科里把三个动作各讲一遍，第38至40章落到教学、科研与学位。

> **K4**　大学的典范革命：从统一性到谱系发生，谱系必须是发生的，不是发现的。

K4 主要在第9章（大厂发现谱系）、第10章、第15章（怎样算错）、第45章（典范史）和第46章（三种失败）展开，导论第三节也先把它立了起来。

> **K5**　自然科学侧重知识生产的客体属性发生；社会科学侧重在互动属性发生；人文则是主体属性发生。

K5 主要在第14章（三种属性）展开，第四至六编分领域讲，第七编（第34至37章）讲三种属性纠缠最紧的交叉之地，结语第四节再作收束。

## 附录二　本书的词

下表按词义的远近排列，不按笔画。“首见”一栏给出该词在正文里最先出现的位置，括注处为详论的章。释义只照书中的实际用法，不另作引申。

| 词 | 释义 | 首见 |
|---|---|---|
| 统一性知识 | 追求放之四海而皆准、不因提问的人是谁、身在何处而改变答案的知识，即定义、定律、标准解释、通用模型。它要先从任何具体的E里剥离出来才能成立。 | 导论 |
| 元件化 | 统一性知识重要到被一切预设、以致不再被单独看见的状态，书中称它成了“基本资料和基础元件”，比喻是插座里的电。元件可随取随用、可拼接，不再属于某一个生产者；这不是贬值，而是公共化。 | 导论（第7章详论） |
| 大厂 | 对拥有算力、数据并吸纳了顶级科学家的机构的简称。统一性知识的前沿生产转到这里；它们所做的“谱系”是发现型的。 | 导论 |
| 去E化 | 控制变量、去语境、教科书化等工序的统称，目的是把结论从得出它的地方摘下来，使它对所有人成立。知行分离是它的代价。 | 导论（第3章详论） |
| 知行分离 | 统一性的代价：知识先在象牙塔里完成，再由别人拿出去用；成果转化与产学研是在分离之上修桥。 | 导论（第3章） |
| 知行一体 | 谱系知识只在E中发生，知与行是同一个事件，所以不需要桥。它与王阳明的知行合一、与应用研究、与咨询公司的区别，在第12章专门划界。 | 导论（第12章） |
| 谱系 | 同一时期里E本身同一性高低的梯度，书中叫“浓淡之图”：哪里相同、哪里不同、相同之处何处浓何处淡。本书的谱系是横向的，不同于尼采、福柯那种沿时间向后考掘的谱系学。 | 导论（第10章） |
| 同一性的梯度 | E的各部分同一性有高有低，最稀薄处几乎没有同一性。书中用一家人吃辣椒说明：人人吃饭怕烫是高处，爱辣与爱香之别使它降低，只闻不吃的小孙子处已近稀薄，但他仍坐在桌边。 | 导论（第10章） |
| 发现型谱系 | 差异在编目之前已经在那里，编目者站在所有部落之外把它找出来、排整齐，统一的对象从规律换成了差异。林奈的分类、用户画像与聚类属此类，尼采、福柯的谱系考掘也被归入此类。 | 导论（第9、10章） |
| 发生型谱系 | 事先不在任何数据库里，只在一群人做事的过程中被做出来，做出来之前挖遍数据也挖不到。一句话：大厂发现谱系，大学发生谱系；族谱是发现，家风是发生。 | 导论 |
| 部落群体（部落） | 在E上有一定同一性、可以被进入的人群，是知识生产的新单位。“部落”是中性的分析用语，不含封闭、排外之意。 | 导论（第11章） |
| 单一性群体 | 部落把自己做出来的差异当成“发现的真理”，不再让它发生、只剩守护，谱系就冻结成单一性群体，严重时是原教旨式的封闭。它是冻结后的状态，不是“部落”一词的定义。 | 导论 |
| 部落固化 | 上述冻结的过程，被列为谱系大学的三种失败之一。书中给出三种症状：差异的来历讲不出，守护边界强于推进内容，外来的差异一律当威胁。 | 导论（第11、46章） |
| 稀薄的根 | 文明之根变稀薄：原来大块的统一性缩小，须根四处伸。书中强调稀薄的是根，不是生活，许多统一性还在，只是被缩小了；本书主张既不复原、也不放任，而让根在新的E中重新发生。 | 导论（第32、43章） |
| 根的发生地 | 与“根的博物馆”相对。博物馆把东西取出E来保存，被保存的东西不再发生；发生地待在E里，让根继续长出新须。保存是必要条件，发生是本业。 | 导论（第43章） |

## 附录三　本书怎样算错

下面把全书各编各章写下的失败条件集中在一处，按编排列，括号里是出处章号。措辞从简，要看原条件的完整说法请回到该章。这些条件都落在可以观察的事情上；它们不是已经做过的检验，而是可以去做的检验。

**导论**

- 若站在群体之外的系统，能凭外部数据独立推出、在部落做出新区分之前事前说中，则“发生型谱系挖不出来”错，大学在谱系上就没有大厂不能替代的位置。（导论）
- 若“东坡晚采三天”这类区分，能在不进入现场的情况下由遥感数据和通用模型事先推出，而进入现场的师生没有做出外部推不出的东西，则知行一体不是知识生产的必要条件。（导论）
- 若自称做谱系知识的大学，十年下来只在一两个部落里打转、没有织出跨部落的谱系，它做成的是咨询公司。（导论）
- 若自然科学里随环境而异的客体性质，最终都能被一个更完整的统一性模型预先算出，或把三个领域的工作对调并不改变能做出的新区分，则“侧重”之说没有区分力，应当删去。（导论）

**第一编　统一性大学的兴衰**

- 若在多元巨型大学里，以部落现场中生出、留在现场的知识为核心的研究，已在评价、资助、晋升中与普遍性研究享有同等地位，则“范式未变”的判断要修正。（第4章）
- 若在一项知识高度去E化的同时，无需任何再E化就在各种现场直接被行用、且不产生新的现场区分，则“知行分离是统一性的代价”要被削弱。（第3章）
- 若以大学为主体的团队，在需要大规模算力与数据的统一性前沿上持续、普遍地领先，且不依赖大厂的模型与算力，则“统一性生产主场转向大厂”错；若大学算力已与大厂大体对等而前沿仍向大厂集中，则解释需要补充。（第5章）

**第二编　统一性的去向：从学问到元件**

- 若前沿统一性的生产仍主要在大学完成，或大学内部以统一性为核心的研究其相对地位并未下降、甚至上升，则“统一性转向大厂”在那个领域错。（第8章）
- 若大厂能在不进入部落的情况下，大规模生成只在某个E中成立、且被那个部落采用的新区分，则第三层的说法被推翻，全书根基动摇。（第8章）
- 若某个系统不进入任何部落、不与部落一起做事，却持续生成此前在数据中毫无痕迹、又被部落采用并改变了做法的新区分，则“大厂只能发现谱系”被推翻。（第9章）

**第三编　谱系发生：大学的新本业**

- 若自然科学的重要谱系知识主要发生在互动属性上且是常态，则“自然科学侧重客体属性”要修正；若人文学科的谱系工作普遍表现为客体属性的发生，则“人文侧重主体属性”要修正；若三种属性在实际工作中根本无法分辨，则三分法应当放弃。（第14章）
- 若连续数年里，大学在前沿统一性产出上重新拉开了与大厂的距离，且靠的是制度性优势而非个别天才；或大厂的统一性产出被长期锁在付费墙和专有系统后、没有成为随取随用的元件，则本书的出发点要修正。（第15章）
- 若一种站在部落之外的数据驱动方法，持续、事先地给出了部落后来才发明出来的区分，且部落拿到就能直接采用、无需在行中再修正，则“发生型谱系挖不出来”错。事后拟合不算；给出候选再由部落去试出来的，算作部落在发生。（第15章）
- 若谱系知识可以先在别处完成、再原样搬进部落，效果与在行中发生的知识没有稳定差别，则知行一体只是一种说法。（第15章）
- 若大学进入多个部落后织出的跨部落谱系，对任何一个部落、对下一次进入新部落都没有可见的用处，则“两层都在才是大学”落空。（第15章）
- 若三个领域的谱系工作里，矛盾的落点、回写的对象、成果被谁认出，看不出客体、互动、主体的侧重之别，或侧重的方向普遍相反，则三分法要修正或放弃。（第15章）
- 若有部落长期只守护、不发生，却仍持续产出被他人采用的新知识，则“还在不在发生”作为判据不够用；但“不发生”须独立判定，看矛盾来临时有没有长出新的区分、有没有回写，不能看后来有没有产出。（第15章）

**第四编　自然科学：客体属性的谱系发生**

- 若在与人的生活相关的主要客体领域里，随着测量维度增加，基因—环境交互或性能—环境交互普遍可被一个事先给定的有限维度函数完整预测，到新的E中无需就地试探、比较、修正就能可靠预言客体的关键属性，则“客体属性在纠缠中发生”多余。（第17章）
- 若长期实践中人的做法对客体关键属性的影响可以忽略，或做法与属性之间不存在相互改写的循环，则“E包括人的做法”站不住。（第17章）
- 若同一性梯度在经验上不存在，即几乎所有客体属性都高度同一、或几乎都不同一，则“谱系”这个说法没有提供新的区分。（第17章）
- 若在部落做出某条区分之前，模型仅凭已有数据就能稳定、事先地给出同样的切口、尺度与用途，则“D只能在行中发明”在这一领域错，至少被高估。（第19章）
- 若合作做了五年，部落里既没有可识别的新东西、也没有能离开项目而维持的做法、更没有新的说法流传，就应承认这次没有等到，并回头查条件。（第20章）
- 若项目撤走、补贴停止一两年后，那套做法已原样消失或被原样供起来，那就不是涌现，而是被交付的S。（第20章）
- 若模型能在部落发明之前事先给出区分，且封存预测、事后对照时模型一再先到，则“大厂能事先给出区分”成立，本编应当认输。（第21章）
- 若长期运行的谱系实验室只能报告一堆互不相干的地方经验，说不出任何跨部落的同一性判断，或说出的判断与元件层早有的统一性知识完全重合，则第二层是空的。（第21章）
- 若在给足时间、保留变异、连续记录的条件下，部落普遍没有出现满足三个可的新工艺、新品种或新常识，而同期常规推广方式反而稳定地显露了，则“S只能在部落里等到”在这类客体上错。（第21章）
- 若随着测量和建模手段的进步，“进入部落才知道”的那部分在各类客体上持续、显著地收缩到可以忽略，则客体属性的哲学解释失去支撑。（第21章）
- 若谱系实验室退出若干年后部落的做法与大学进入之前没有可辨别的差别，或部落成员普遍认为大学的参与毫无用处、只增加负担，则知行一体在这里只是大学的自我描述。（第21章）

**第五编　社会科学：互动属性的谱系发生**

- 若平台的行为数据与仿真，能在一种新的互动规则于某个部落出现之前，就准确给出它的样子，则“互动属性在行中发生”要大打折扣；若平台只能在新做法出现之后识别并复制它，则它做的是发现。（第22章）
- 若后续研究发现奥斯特罗姆所研究的那些制度，主要由外部权威设计好再交给社区执行，则“互动属性发生”的解释不成立。（第23章）
- 若知道资源的物理性质和使用者的个人特征，就能可靠推出社区会长出哪一种具体规则，则互动是可以消去的中间变量，第三种属性之说多余。（第23章）
- 若一种研究在问题从不改写、部落里什么也没留下、研究者也没被改变、成果无法进入跨部落比较这四点上都做不到却自称深入E，它就是被说错了的投放；若严格按问卷、抽样、远距离分析做出的研究，同样能在部落里促成新区分的发生，则“必须进入互动场”要大幅修正。（第24章）
- 若大厂仅凭行为数据和仿真，就能事先生成在部落里站得住、并被部落自己维持下去的新规则（以撤掉看守后能否维持、新人怎样学会、住户能否说出理由为判据），则“社会领域的D只能在行中发明”错。（第27章）
- 若有指挥的秩序在指挥者离开后仍持续自我更新，且新规则的发生不少于自主议事的社区，则“复调而非有指挥的交响”要修正。（第27章）
- 若“对方的东西在我这里也出现了，但做法有差异”这一判据，在实际观察中无法与同化、隔离区分开，或让几位独立观察者的判断彼此高度不一致，则和谐判据是空的。（第27章）
- 若互动实验场长期运行产出的谱系知识，不比传统学科分工下的研究更多地被部落采用、更多地沉淀为可跨部落使用的新元件，则制度主张错。（第27章）
- 若互动实验场普遍退化为咨询化（只服务一个部落）或采集化（只取数据、出论文、部落的行没有改变），则两层结构没有成立。（第27章）
- 若被研究的部落在长期参与后，普遍把实验场里共同发明的规则当成不可更改的真理，则实验场是在制造固化。（第27章）

**第六编　人文学科：主体属性的谱系发生**

- 若工坊协助发明的意义区分几乎都不被部落成员采用，部落成员普遍认为“这是学者们的话，跟我们没关系”，则“人文学者可以在行中参与发明D”这一判断站不住。（第33章）
- 若大模型仅凭一个部落公开留下的材料，就能事先生成与工坊同样的意义区分，且部落成员在不知来源时也认作自己的、照着做了，则“意义区分只能在行中发生”被削弱。（第33章）
- 若长期对照下，以工坊方式学习的学生身上并不比传统方式的学生更常出现新主体的三种信号，则“工坊更有利于主体属性发生”错。（第33章）
- 若人文工坊比文本研究体制更容易制造冻结的单一性群体，或普遍滑向只服务一个部落、做完就走，或让考据纪律冲淡、共同记忆的发生开始容忍编造，或让哲学的方法共同体变成发放三字母对应表的机构，则本章的制度建议有害。（第33章）
- 若用 S、D、E 去读一个又一个部落里的意义变化，只能给出事后的、换个说法的复述，不能比不用它们多看出任何可检验的区分，则这套哲学解释应当放弃或重写。（第33章）
- 工坊在某个部落里三年没有出现新主体的信号，一条区分后来被修正甚至推翻，个别部落不愿合作，这三种情况本身不算错；只有在大量部落、长时间里系统性地如此，才构成反证。（第33章）

**第七编　交叉之地：三种属性的纠缠**

- 若把研究组从深入某个照护者部落换成只在门诊发一份问卷，所得区分与前者没有实质差别，则医学一章的主张站不住；若深入所得的区分部落自己并不采用、过一阵就被丢掉，则它至多是研究者带回城的一份记录，不是在这群人的行中发生的知识。（第34章）
- 替换检验：若把一种属性上的做法换掉（医学里把深入换成问卷，工程里把与住户一起改方案换成先定方案再做工作，教育里把从学生自己的土壤起手换成统一的导入环节），其他两种属性上的结果并未随之改变，则三者可以拆开相加，“纠缠”不成立。（第37章）
- 增益检验：若多个部落里长期深入所得的区分，与外部团队用大规模数据做聚类所得的分群在内容上基本重合，则“发生型谱系”没有超出发现型谱系。（第37章）
- 回写检验：若部落采用新区分之后，其后的做法与理解并未发生可观察的改变，则“回写”只是修辞；若观察到的改变只是一次性的、过一阵就退回原样，那只是反馈，不是回写。（第37章）
- 教育上的专门检验：若在同样条件下，由AI代走D的学生与自己走过D的学生，在面对需要把所学接上一块新土壤的新情境时表现没有差别，则“让S在他身上重新发生”这一定义没有可检验的内容。（第37章）

**第八编　重生的大学：制度设计**

- 若认真实施几年之后，参加发生现场课程的学生独立面对陌生问题时，并不比只上传统课程的学生更能做出合用的区分，或合作部落普遍反映课堂的介入没有带来可用的改变、甚至带来了负担，则教学一章的主张需要修正；不能用“发生需要时间”无限期地搪塞。（第38章）
- 若谱系实验室运转几年后，它在部落中做出的区分普遍没有被采用或很快被放弃；或跨部落对照会给出的谱系层判断，在加入新部落后几乎总被推翻；或合作部落普遍认为与大学合作不如雇咨询公司，则科研一章的设计需要修正。（第39章）
- 若大厂单凭数据和模型，不进入部落就能稳定预测出部落将要做出的那些区分，则“发生型谱系只能在行中出来”站不住。（第39章）
- 若持有发生履历学位的人，在面对新部落、新问题时并不比持有传统学位的人更能做出合用的区分，则“认证生成过什么知”不比“认证掌握了什么”更有效。（第40章）
- 若发生履历大面积出现伪造深入、伪造区分，而追问与部落确认机制无法识别，则这套认证已被做出了样子，需要推倒重来。（第40章）
- 若统计发现获得高质量部落机会的学生仍高度集中在少数家庭背景优越的群体，补偿安排没有起作用，则谱系大学只是换了一种方式复制旧的不平等。（第40章）
- 若部落普遍认为接待学生是负担、越来越多的部落拒绝合作，则这种学位的根基就不存在了。（第40章）
- 若认真试行后发现部落并不在乎自己的E被平台平均掉，平台的回写并没有让部落的发生减少，或部落在托管约定下反而因程序繁琐而失去了发生的活力，则契约一章的主张需大幅修正。（第42章）
- 若在有谱系站长期在地的社区里，与相似而没有谱系站的社区相比，看不出本地发生的新做法和新说法更多出现，看不出居民面对通用元件时更有能力保留或改写自己的东西，则“大学是根的发生地”在这些地方没有成立；若谱系站促成的新做法很快被通用元件吸收、平均掉，主张同样要修正。（第43章）
- 若使用者分享一开，谱系单元普遍向有钱的部落迁移、跨部落谱系日益萎缩，而几道财政闸都拦不住；或三方治理在多数地方空转；或公共财政无论怎样设计，都无法在不把谱系发生变成新的计量竞赛的前提下分配下去，则财政与治理的设计失败。（第44章）

**第九编　典范革命的全景，及结语**

- 若往后十年里，部落现场发生的区分几乎从不改变通用模型和标准知识的适用范围，元件层照旧以不分场合的口吻给出答案、且这样做并没有在任何部落里引起可观察的失效，则“回写”不成立，谱系发生只是元件层下游的一个应用环节，不是一场典范革命。（第45章）
- 部落多年里没有任何区分被修改、而它的E（气候、价格、人口、技术）确实变了，则它很可能已经固化；元件只扩张不收缩、回写通道形同虚设，就该警惕垄断；一个院系五年的成果全部能按甲方归档、没有一项是站在部落之间说话的，它多半已沦为乙方。（第46章）
- “它还在不在发生”这一判据本身也有两种错法：把变化误当发生，把稳定误当固化；区别在有没有检验，守护拒绝检验，稳定经得起检验。（第46章）
- 若大学所谓的“预案”只是坐在会议室里写的对策报告、从未在任何部落的行中试过；或一所大学多年拿不出在真实部落里显露过、维持过一段时间并留有发生记录的“未来知识”，则它还没有成为发生器。（第47章）
- 若统一性的元件化在相当长时间里并没有发生，大学仍是统一性知识不可替代的生产者；或大厂通过长期驻扎、与部落共同行动，真能在部落的行中发明新区分；或走上谱系道路的大学普遍沦为乙方，不再有跨部落的谱系；或部落在与大学的合作中，E被系统地抽走而没有得到回写，则全书的论证要被修改，严重的要被推翻。（结语）
- 若谱系大学在实践中一再成为“部落E的中转站”，把在地的纠缠一车车运给统一性工厂，则“大学深入、大厂投放”的区分算是错了。（结语）
- 若若干年后谱系大学里出现一个新的“谱系精英”阶层，它对部落的态度与过去统一性精英对“外行”的态度没有两样，则“师生同排”失败。（结语）

# 后记

这本书的问题，来自2026年10月28日上午的一个判断。那天上午我读到“博士一夜清零”一类的说法，觉得它认错了对象：被模型冲击的不是博士这个人，而是博士手里那批统一性知识的稀缺性。随后我连续口述了几轮，把这个判断从博士推到大学，推到知识生产的方式上，这些口述的原文，我原样登记在附录一里，全书的五条主线都由它们而来。

成书有两项要求：全书约三十万字，九编四十七章；自然科学、社会科学、人文学科三个领域要分开来写。分开写有讲解上的方便，也有代价，就是容易让人以为三种属性各管一摊。所以第七编专门写三种属性缠在一起的交叉之地，结语里又说了一遍：书里说的是“侧重”，不是“独占”。

从提纲到成书，用了一天。做法是这样的：依据同一份写作指南，十五位AI写作者分头并行起草，各写各的编、各的章；起草之后，七位编辑分块统稿与初审，三位编辑分头复审，分别查术语、查跨章的一致、查事实；最后是一次终审。全书由AI（Claude）协作起草，我审定。我把过程写在这里，是因为它决定了这本书应当怎样被读。

这条流水线有一个摆在明处的限制：写作者和编辑者出自同一个基础模型，它们互相核对，并不构成彼此独立的证据。几处一致，可能只说明它们有同样的偏好，不说明事情就是那样。所以书中的判断，不能靠写作者与编辑者的互相认可来成立，只能交给读者，也交给现实去检验。

为此我做了两件事。一是把每条主要主张怎样算错写了出来，集中在附录三，请读者按条去对。二是把事实核查里没能核到原始来源的说法逐条列在附录四，它们仍留在正文里，请在引用之前自己核对；核查是在联网受限的条件下做的，不少说法只有专业常识、没有出处，这一点也应当让读者知道。参考书目只列正文实际提到的人物、著作与研究，没有提到的不在其内。

书里说，知识必须是发生的，不是发现的。这本书自己也一样：它此刻只是一个被提出来的说法，站不站得住，要看有没有人带着它走进某一个具体的部落，在那里被采用、被修改，或者被推翻。如果有人这样做了，无论结果如何，我都希望他把过程如实记下来。我对这本书的态度，和对一份可能出错的实验记录一样：把过程交代清楚，把没核的地方标出来，把错法写在前面。
