# 第七编　三号位之力的文明

这一编四章，问三号位回到力里来以后，日子和账本会变成什么样。第 36 章把同一个 token 分成两面看：一号位那一面是地板，三号位亮起来的那一面才有价。第 37 章是全书篇幅最长的一章，专讲一个 token 有几个价，三属性纠缠给经济学出了哪几道难题。第 38 章问谁拥有哪一角：芯片、算力中心、基础模型这些大装置管得住哪几格，个人的发生器又落在哪几格。第 39 章落到手上，讲个人、学校、企业怎样养出自己那份力。

这一编的陪读，是两张单子并排放：周敏米粉店的电费单，杜禾手机里的 token 账单。电费单上每一度电都一样，米粉的好坏在电外面。token 账单上每一个 token 也印得一样，可是那几百块里，有一部分换来了论文里最要紧的一节，有一部分只换来了格式整理。

这一编要你看见一个反差：两百年里，力越来越便宜、越来越一样，三号位一直待在力的外面，待在米粉里、手艺里、人身上；现在力还在变便宜，三号位却回到了力的里面，价目表上却还没有它的那一栏。

## 第 36 章　地板 token 与纠缠 token

这一章交给你的判断是：同一个 token，一号位那一面是地板，价钱贴着算力成本往下沉；三号位亮起来的那一面才有价，可这份价不在价目表上，在它落下去的那片场里兑现。

### ◆ 一、收银台下面的两张单子

十月底一个晚上，九点多，湘潭大学后门那条街上的米粉店收了最后一桌。

周敏把卷帘门拉下一半，从收银台的抽屉里抽出一张单子。是这个月的电费单，供电公司打印的，一行一行很规整：本月用电多少度，峰时多少，谷时多少，每度多少钱，合计多少。

她拿计算器按了两遍，叹了口气：「比上个月多了一百多。熬汤那口锅太费电了。」

杜禾坐在店里最里面那张桌子上，捧着手机，也在看一张单子。是她这个月用 AI 的账单：输入多少 token，输出多少 token，合计多少钱。

周敏凑过来看了一眼：「你这个也是按量算的？」

「按 token 算。一个 token 差不多是一个字，一小截词。」

「那跟电一样嘛。一度电就是一度电，你那一个也就是一个。」

杜禾想了想，没有马上答。她这个月的账单是三百多块。她记得很清楚，其中有一个周末，她和那个装了 SDE 方法的 Claude 来回磨了两个晚上，磨出了论文第三章最要紧的那一节。剩下的大半，是让它整理参考文献格式、翻译摘要、改错别字。

账单上，这两种 token 是同一个价，印在同一栏里。

「一样，又不太一样。」她说。

这一章，就从这句「一样，又不太一样」讲起。

### ◆ 二、地板是什么：第 347 号的说法

先把一个现成的词借过来。

第 347 号《我的面条》讲过「地板价」。那本书说得很具体：地板价不是「很便宜」，是「便宜到只剩复制一份的成本」。一碗面再便宜，底下也垫着面粉、汤、燃气、人工；一份标准说明书的译文，生成出来以后再复制一千份几乎不花钱，要时现做，花的只是一点算力。价格掉到算力成本那一层，就贴住了。

那本书还说了两件要紧的事。

第一，地板本身在往下沉。面粉、电的价钱有涨有落，大体稳着；公共知识底下垫的是算力，算力这些年一直在变便宜，所以价格是贴着一块还在下沉的地板一起往下走。

第二，地板压的是「生产」，压不到「发生」。可重复的那部分会被工具接管；一次性的、只对这个人这一天有效的那部分，不会一下子掉到地板上。

### ◆ 三、先说地板对在哪儿

这两件事，本书全都认。

地板不是坏事。第 347 号自己就说过，地板很有用，人人每天踩在上面。一家网店用模型回客服消息，一天几千条，问的都是「几天发货」「能不能换尺码」，答案大同小异。对这家网店来说，token 便宜到地板，是福气。它不需要这份力懂它，只需要这份力又快又稳又便宜。

杜禾让模型整理参考文献格式，也是这样。格式有标准，谁来整理都该整理成一样。这时候她要的就是「谁来都一样」，越一样越好。

所以把地板说完整：**只要一件事要的是可复现的读数，另两个号位最好被钉住，地板 token 就是对的力，而且越便宜越好。**

工业文明两百年，在电、油、煤上做成的，正是这件事。第三编讲过，这是了不起的成就。token 在一号位上走的，是同一条路，只是走得更快。

### ◆ 四、地板压住的是哪几格

用九格把地板量一量。

一号位上，三格都被压住了。对比：账单上只有一个读数，token 数。粒子：一个 token 就是一份，可以数、可以加、可以按百万打包卖。真：同样的问题，在同样的设置下，回答大体能复现；格式整理整理一百次，该是一样的一百次。

二号位上，也有几格被钉住。一次推理的变化，被写成一套固定的流程；批量处理的时候，往返的波被压成一次性提交；善，被读成单位成本里的效率。

三号位上，三格都缺。落给谁，账单不问；围着谁的语料和方法成形，账单不记；被谁选中、离不开，账单也没有地方写。

这就是地板 token 在九格上的样子：**一号位满格，二号位被钉住，三号位被逐出。**

它和一度电在九格上的样子，几乎一模一样。周敏说「跟电一样」，在这一层上，她说对了。

### ◆ 五、本书的说法：地板 token 与纠缠 token

把这一章的两个词写准。

地板 token：三号位侧重显影缺席的 token。它的力只在一号位和被钉住的二号位上显出来，读数就是计数，价钱贴着算力成本。

纠缠 token：三号位侧重显影亮着的 token。它的场、分布、美，和一号位的计数、二号位的往返缠在一起；同一个计数，因为落在哪片场里、落在什么事上、被怎样选中，是不同的力。

请注意：这不是两种 token。机房里算出来的，是同一种东西；账单上印的，是同一个价。分开的是号位的侧重，不是 token 的种类。

拿杜禾那一个周末，从头走一遍。

周六下午，她先让模型把四十条参考文献统一成学院要求的格式。这时候三号位没有亮。换一个同学来做，换一个模型来做，结果应该一样。这一段，是地板 token。

傍晚，她打开自己写的那份 SDE 方法文件，把导师上周的批注、自己三个月的笔记一起放进去，问了一个问题：她的论文说「平台两头都坐」，那么一个 AI 助手坐在哪一头？

模型回了一大段。她不满意，指出它把交换价值论和效用价值论搅在一起了。模型改了一版，她又追问一句。来回十几轮，到晚上十点多，一个说法冒出来：助手坐的不是哪一头，是三号位上「替人想要」的那一格。

她愣了一会儿，把这句话抄进了本子。

这一段，三号位亮了。场是那份方法文件、那堆笔记和导师的批注；分布是落在论文第三章这件事上；美是她最后「就是这个」的那一选。这一段，是纠缠 token。

两段加起来，账单上是一个数。

### ◆ 六、电费单为什么没有这一栏

回到周敏的电费单。

她的店在这条街上开了九年。熟客来了，说一句「老样子」，周敏就知道是二两扁粉、多放酸豆角、不要葱。有个在附近读博的老客，回老家以后还托人带过两次她熬的汤底。

这些都是三号位。可它们在哪里？在米粉里，在周敏的手上，在店里那片熟客的联系里。不在电里。

熬汤那口锅里的一度电，和隔壁奶茶店封口机里的一度电，和实验楼里离心机的一度电，没有分别。电把三号位留在了力的外面。米粉好不好吃，是周敏的事；电只管有没有、够不够、稳不稳。

这是工业钉住史留下的格局，第 17 章讲过：插座不问你是谁，电表只记一号位。三号位没有消失，它搬了家，搬到了产品里、手艺里、品牌里。

token 不一样的地方，就在这里。

杜禾那个周末晚上，三号位不在论文里等着，也不在她身上揣着。它是在那十几轮来回里，和方法文件、笔记、模型一起显影出来的。它进到了力的里面。

电费单没有这一栏，是因为电里本来就不需要这一栏。token 账单没有这一栏，是因为价目表还没学会写。

### ◆ 七、那片场是怎样养出来的

纠缠 token 亮起来，靠的是那片场。场不是一天有的。

杜禾那份方法文件，第一版只有两页，是她照着导师给的提纲抄的。用了一个月，她发现模型老把「层断裂」讲成「价格下跌」，就在文件里加了一段，写明这个词在第 391 号《价值是谁创造的？》里指什么。又过两周，她把自己被导师打回来的三段文字和导师的批注一起放进去，标上「这样写不行，原因在这里」。

三个月下来，文件长到十几页。

用第 396 号《属性纠缠论》第 21 章的两本账来记，这是两次回写。

第一本账，所得进土。每一次被打回、每一次改，都往那片场里多缠了一层：方法文件里多了一条判准，笔记里多了一个反例，模型下一次接到的上下文就不一样了。这一次回写慢，看不见，也不要「我」。

第二本账，名字进号位。到了那个周末晚上，「我的论文那一节」「懂我的那个 Claude」这两句话，才挂了上去。挂得很快，一句话就完成。

这两本账，在电上从来不用记。周敏用了九年电，电网没有因为她多懂一点电。电网对用电者，是零写。

杜禾和那个装了 SDE 方法的 Claude，是在往双写那一头走：她改了文件，模型下一次的回答变了；模型的回答又逼着她改了论文和文件。场是在这一来一回里，一层一层缠出来的。

所以纠缠 token 的价，有一半早在那个周末之前就付过了，付在三个月的改与被改里。

### ◆ 八、和第 347 号对账

第 347 号把算力放在地板下面，当地基。公共知识的价格贴着算力往下沉，「我的」那部分留在上面，靠社区定价才有跳跃。

本书全认它的前半句：一号位那一面，确实是地板，而且在下沉。

本书在后半句上多走半步。第 347 号说，不在地板上的，是「我的知识」，是只对这个人这一天有效的那一次发生。它没有说错。本书要补的是位置：这份「我的」，不是一个先在的人揣在身上、再拿去用算力兑现的东西。它是三号位侧重显影的结果，是在使用里回写挂上去的。

所以，「我的」不只在地板上面，也在力的里面。同一个 token，一面贴着地板，一面亮着三号位。

两本书在这里的分别，用一句话说：第 347 号说，算力是地板，「我的」在地板之上；本书说，算力的一号位是地板，三号位回到了算力里。

这半步是本书的推断〔待验〕。要验它，就得在同一批使用者、同一个模型、不同任务上，看含使用者的那一份搭配有多大。第 41 章会把这件事写成判错条款。

### ◆ 九、纠缠 token 的价在哪里兑现

纠缠 token 既然有价，价在哪里？

不在价目表上。价目表按计数收钱，纠缠 token 和地板 token 收的是同一个价。

它在别处兑现。杜禾那个周末的几十块钱，换来的是论文第三章的一个说法；这个说法会写进论文，被导师认，也许会在答辩时被追问，也许会在以后的文章里接着长。它的价，要到那些地方去找。

第 198 号《知识经济的诞生》给过一张价格构成表：一次知识服务的价格，可以拆成基底成本、平台费用、知识租、责任溢价四块。基底成本就是那块地板，会持续下降；知识租来自持有者的方法与判断，可以长期维持。

借这张表看，纠缠 token 的价，大部分不在基底成本那一行。

这里只先指出一件事：**价格贴着地板，价值却散在三号位上。**两层怎样断开、怎样回写，经济学的老工具在这里卡在哪里，下一章专门讲。

### ◆ 十、两个容易起的误会

第一个误会：地板 token 低贱，纠缠 token 高贵。

不是。网店的客服消息，杜禾的格式整理，用地板 token 正合适。地板是地基，一栋楼离不开它。一个人一天里用的 token，多半本来就该是地板。导读里说过，本书不说 token 比电高贵，这里也不说纠缠 token 比地板 token 高贵。

第二个误会：纠缠 token 是杜禾的，因为杜禾厉害。

也不是。那个周末晚上亮起来的三号位，不是杜禾先揣着、再发动出来的。方法文件是她三个月里一次次改出来的，导师的批注是导师的，模型的本事里封装着别人的三角（第 23 章），那句「替人想要的那一格」是在第十几轮来回里冒出来的。「我的论文那一节」是回写挂上去的名字，挂上去以前，它是一场缠在一起的发生。

### ◆ 十一、今天与机器

今天的市场，正在用力把 token 往地板上压。

第 198 号记过一件事：2024 年 5 月，国内多家大模型厂商在几周之内相继大幅下调接口价格，被媒体称为「价格战」〔待核〕。各家价目表此后也一直在调〔待核〕。

压地板这件事，本书不反对。地板越低，网店、学生、小作坊用得越起。

可是请注意它带来的一个副作用。价格越往一号位上压，大家越习惯只看一个数：每百万 token 多少钱。纠缠 token 也被这个数读着。读惯了，三号位就又被逐出去一次，这一次不是被电网的钉子，是被价目表上那一栏。

杜禾的同学里，已经有人每月比价、换最便宜的那一家。对地板任务，这是精明。对论文那一节，换走的可能是三个月养起来的那片场。

### ◆ 十二、放回日子里

那天晚上，周敏锁了店门，母女俩往家走。

杜禾跟妈妈说：「你那锅汤，电是电，汤是你的。我这个不一样，有一部分汤是在电里面熬出来的。」

周敏没太听懂，说：「那你月底那三百块，到底花得值不值？」

杜禾说：「我回去分一分。」

回到宿舍，她把这个月的使用记录导出来，按事情分成两栏。一栏写格式、翻译、改错字；一栏写论文第三章那两个晚上。她发现，第二栏的钱不到总数的五分之一。

一个小办法，你明天就能试：把你上个月用 AI 的记录翻一遍，分成两栏。一栏是「换谁来都该一样」的事；一栏是「换了我的材料、换了这件事，就不是这个结果」的事。第一栏，可以放心去找最便宜的；第二栏，先别急着换。

> **九格卡**
> 一号位（对比·粒子·真）：token 计数、按份计价、同一设置下回答可复现；地板 token 在这三格上满格。
> 二号位（变化·波·善）：一次推理、对话往返、被接住的那部分；地板任务里被流程和批处理钉住。
> 三号位（分布·场·美）：落在论文那一节、围着方法文件和笔记成形、「就是这个」的那一选；只在纠缠 token 上亮。
> 钉住的是一号位三格和二号位的流程；被逐出的是三号位三格，在地板 token 上缺，在纠缠 token 上回来，账单上却仍是同一栏。

> **带走的话**
> 同一个 token，一面贴着地板，一面亮着三号位；地板上的价钱一路往下沉，三号位上的价，要到它落下去的那片场里去找。

> **本章判错句**
> 如果同一批使用者在同一个模型上做思想创新与格式整理两类任务，产出质量里含使用者的那一份搭配并无差别，本章「纠缠 token」的区分算错，三号位回到力里的说法收窄为「三号位仍只在产品里」。

> **想一想**
> 1. 你上个月用 AI 的钱，有几成换来的是「换谁来都一样」的东西？
> 2. 你家里的哪一样东西，三号位在力的外面，比如一锅汤、一块地、一门手艺？

## 第 37 章　一个 token 有几个价？——三属性纠缠给经济学出的难题

这一章交给你的判断是：价目表上一个 token 只有一个价，那是一号位的读数；三号位亮起来以后，同一个 token 换来的价值散成好几份，价格却纹丝不动。价格与价值在这里断成两层，经济学最结实的几样工具，正好立在一号位那一层上。

### ◆ 一、两张发票

十一月初，杜禾在电脑上下载了上个月的发票。

同一家服务商，同一个模型，这个月她用了一百万 token 出头。发票上一行字：模型名称，用量，单价，金额。

同一天，米粉店隔壁那家卖湘潭腊肉的网店老板，也下载了一张发票。他用的是同一家、同一个模型，帮他回买家的消息：「几天发货」「真空包装能放多久」「可以开发票吗」。一个月下来，也是一百万 token 出头。

两张发票摆在一起，几乎是同一张。单价一样，用量相近，金额相近。

可是你问两个人，这一百万 token 值多少。

网店老板会说：值一个客服半个月的工资，也许还不到。他算得出来，因为他知道请一个人要多少钱。

杜禾说不出来。那一百万里，有一小截换来了论文第三章的一个说法。这个说法值多少？值导师那一句「这个点站得住」，值答辩时少挨的一次追问，值她以后也许会接着写下去的一篇文章。她找不到一个数。

同一个价，买到的却不像同一种东西。

你也许觉得这不稀奇。同一本书，一个人读了改了一辈子，一个人拿来垫桌脚，书价也是一样的。可是请看清楚差在哪里：书是先印好的，读法在书外面；那一百万 token，是在杜禾一来一回的使用里才算出来的，她的方法文件、她的追问，都进到了这一次「生产」里去。书的三号位在读者身上，token 的三号位在力的里面。

这一章要问的就是：经济学的哪几样工具，能把这件事说清楚，说到哪一步停下。


### ◆ 二、经济学脚下的那块地：同一种商品

经济学讲价格，脚下踩着一块地：先得有「同一种商品」。

最朴素的一条叫一价定律。它说的是：同一种商品，在一个能自由买卖、运费可以不计的市场里，只该有一个价。哪里便宜，就有人从那里买、到贵的地方卖，差价很快被抹平。这条定律不靠谁的好心，靠的是套利。

再往深里走，是阿罗和德布鲁。德布鲁在《价值理论》（1959）里把「商品」定义得非常干净：一样商品由它的物理特征、交付的地点、交付的时间一起确定；后来又加上「在哪一种世界状态下交付」〔待核：章节以原书为准〕。同样是小麦，今天在湘潭交和明年在长沙交，是两种商品。定义下得这样细，整套一般均衡的证明才站得住。

先把公道说足。

这样细的定义，不是书斋里的讲究。期货市场能开起来，靠的就是它。郑州的棉花合约、上海的原油合约，合约上写明品级、交割地点、交割月份；写明了，天南地北素不相识的人才敢买卖。杜卫东跑长途，加油站的牌子上写着「0 号柴油」，他不用每次闻一闻、试一试，就知道这一升和上一升是同一种东西。这份放心，是「同一种商品」这块地给的。


这块地是经济学最了不起的工程之一。一吨小麦、一桶原油、一度电，都能放进这套定义。第 391 号《价值是谁创造的？》第 5 章也先还过这份公道：偏好、技术、禀赋写进同一套证明，是数学上最漂亮的一次。

用九格看，这块地铺在哪里，也很清楚。物理特征是对比和粒子，时间和地点是把分布钉成一个坐标，「交付了就是交付了」是真。整块地，铺在一号位上，再加上一颗把分布钉死的钉子。

在电上，这块地铺得严丝合缝。第三编讲过，电网把另两个号位钉住了，一度电在哪里都是一度电。

它完全成立的条件是：**商品的另两个号位被钉住，换谁来用都是同一种东西。**

### ◆ 三、一号位的价：按粒子计价，地板在下沉

token 的价目表，是照这块地写的。

一个 token 是一份粒子。价目表按百万份打包标价，输入一个价、输出一个价。哪个模型、什么时候、在哪个区域调用，写得清清楚楚。物理特征、时间、地点，一样不少。

这是一号位的价，而且是很纯的一号位的价。

第 36 章说过，这个价贴着一块还在下沉的地板。第 198 号《知识经济的诞生》记过一个例子：2023 年 3 月，一家主要服务商给当时最强的模型定了一个价；一年多以后，同档能力的模型价格已经降到原来的十分之一以下〔待核〕。第 347 号把这叫作地板在往下沉。

第 198 号还有一句话，说得很准：词元衡量的是生成了多长，不是值多少；它是发动机烧了多少油，不是车把人送到了哪里。

一号位的价，答的是「烧了多少油」。

杜卫东对这句话最有体会。他跑一趟长沙到广州，柴油钱多少，他算得一分不差；这一趟货值多少，是货主的事，跟油价没有关系。油价只管油。他从没想过油价该替货值多少操心。

token 的价目表也只管油。这不是它的毛病，是它的本分。一号位的价，本来就该只读一号位：计数清楚，单价公开，谁来买都一样，这是买卖公平的底子。第 198 号说，价格可以事先标明、质量可以试用判断、交易可以反复进行，知识才第一次像普通商品一样进了市场。这份功劳，要记在一号位的价上。

难处不在这个价写错了，在它写全了一号位，就被当成写全了这份力。


### ◆ 四、二号位让价格变起来

价目表并不是一个数到底。这几年，它在二号位上长出了好几道褶子。

第一道是缓存。同一段很长的材料，你反复拿来问，服务商可以把它存着，第二次起这一段按更低的价算，具体折扣据各家公开价目表〔待核〕。同样一个 token，因为是「又来一次」，价钱不同。这是波：往返的节律进了价格。

第二道是批处理。你不着急要，把一大批请求一起交上去，等它在空闲时慢慢算，价钱便宜一截〔待核〕。这是变化：转化的时机进了价格。

第三道是思考型 token。有的模型在回答之前先在内部推一遍，这一遍也要算 token，通常按输出计费〔待核〕。同一个问题，想得深、想得浅，账单不一样。这也是变化：推理这一次转化本身被计了量。

第四道是长上下文。一次塞进去的材料超过某个长度，有的服务商按另一档收费〔待核〕。

四道褶子，有一个共同处：都是二号位。它们读的是「正在」怎样转、怎样往返、怎样被接住，没有一道在问落给谁、围着谁、被谁选中。

请注意，这几道褶子是真本事，不是花样。缓存让反复问同一份材料的人少花钱，批处理让不赶时间的人少花钱，它们都在把二号位上的浪费挤出去。按九格的读法，这是在善那一格上下功夫：被接住的多一点，漏掉的少一点。

杜禾自己就沾过光。她把那份十几页的方法文件每次都放在最前面，后来发现这一段走的是缓存价。场越厚，这一段越长，缓存省下的钱也越多。可是省下的是二号位上的钱。那份文件为什么值得每次都放进去，价目表不问。


所以价格确实变起来了，可它是在二号位上变。

### ◆ 五、三号位让价值散开，价格却不动

现在看三号位。

场：杜禾那份十几页的方法文件、三个月的笔记、导师的批注。网店老板没有这些，他也不需要。

分布：杜禾的 token 落在论文第三章，网店老板的 token 落在「几天发货」。

美：杜禾最后那一句「就是这个」，是在十几版里选出来的；网店老板的回复，只要不出错就行，谈不上被选中。

这三格，一格也没进价目表。

可是三格一变，同一个 token 换来的价值就散开了。在网店老板那里，它值半个客服的一小时；在杜禾那里，它的一小截值一个站得住的论点；同样在杜禾那里，另一大截只值一次格式整理。

第 391 号把一件经济的事分成几层看，其中两层是价格层和价值层。那本书说，价格不是价值的现象，两层并列、互相纠缠；它把「价格在涨，价值在退」叫作层断裂。

token 上出的是另一种断：**价格一层不动，价值一层散开。**

价格层只读一号位，外加二号位的几道褶子。价值层却在三号位上分了家。两层之间，没有一根管子通着。

这和米粉店不一样。周敏的粉，价值也在三号位上：熟客的「老样子」、那锅汤、九年的口碑。可是这份价值有一个出口，就是墙上那块价目牌。粉好吃，回头客多，她可以多卖几碗，也可以过两年涨一块钱。三号位的价值，经过一碗一碗的粉，慢慢写回了价格。

token 没有这个出口。杜禾那片场养得再厚，她付的单价也和网店老板一样；那片场换来的东西，落在论文里、导师那里，落不回发票上。


### ◆ 六、九格纠缠给经济学出的五道难题

三号位一回来，经济学手边几样最好用的工具，都碰上了难处。一道一道看。

第一道，一价定律失效。不是价格不一，价格恰恰只有一个；是「同一种商品」这块地松了。按德布鲁的定义，杜禾和网店老板买的是同一种商品：同一个模型、同一个月、同一个区域。可按力来分，它们不是同一种力。一价定律守住的是一号位，它说不出「这一个价买的是不是同一样东西」。

你也许会说：那就把定义再写细一点，「用在论文上的 token」和「用在客服上的 token」算两种商品。德布鲁的办法确实能这样往下分。难处在于，分的依据不在 token 身上，在三号位上：落给谁、围着哪片场、被怎样选中。这些东西卖方看不见，买方自己事先也说不准。一个按交付前就能写清的特征来分商品的框架，碰上一种要在使用里才显出是哪一种的力，就分不下去了。


第二道，需求曲线画不出。需求曲线要先有一样确定的东西，再问价格多少时人们要多少。token 的需求曲线，横轴是计数。可是杜禾愿意为论文那一节付多少，取决于那片场养了多久，不取决于这一节用了多少 token。把地板 token 和纠缠 token 画进同一条曲线，等于把两种东西叠成一种。

还有一层更麻烦。需求曲线默认想要是先给定的，价格一变，人沿着曲线挪一挪。可杜禾的想要，是在用的过程里长出来的：没用之前，她不知道自己要的是「替人想要的那一格」这句话；磨出来以后，她才知道值。曲线还没画，曲线本身已经被那一次使用改了。第 391 号第 28 章说的成交回写，在这里落到了一份力上。


第三道，边际成本定价失灵。经济学有一条老道理：价格等于边际成本，最有效率。信息产品早就在这里碰过壁，固定成本大、多服务一次几乎不花钱，按边际成本卖就收不回本。token 上还多一层：三号位那片场的成本，很大一部分不是卖方付的，是杜禾三个月里一次次改文件付的。买方在替这一次「生产」出力。边际成本该算谁的？

网店老板那里不存在这个问题。他的场几乎是空的，一个 token 的成本就是卖方那一份算力。杜禾这里，一个纠缠 token 背后站着两笔成本，一笔在机房里，一笔在她的书桌上。价目表只认机房那一笔。


第四道，剩余与 GDP 计不进。消费者剩余，是人们愿意付的和实际付的之间那一块。打个比方：你愿意花二十块吃一碗周敏的粉，墙上标十二块，多出来的八块就是你的剩余。GDP 记的是成交的价格乘数量。地板在下沉，token 越来越便宜，记进 GDP 的数就可能越来越小；杜禾那一节的价值，却大半落在剩余里，落在一个画不出来的需求曲线下面。第 347 号说过「份额让出，产量不缩」；放到 token 上，可能是计进账的越来越少，没计进账的越来越多〔待验〕。

GDP 本来就不记家里做的饭、自己带的孩子，这是统计学家早就承认的老边界，不是谁的疏忽。token 让这条边界挪了位置：一大块三号位的价值，是在家里、在宿舍、在一个人的书桌上，和一份买来的力缠出来的。买的那部分记进去了，缠出来的那部分照旧在门外。


第五道，杰文斯悖论重演。1865 年，杰文斯在《煤炭问题》里指出，蒸汽机烧煤越省，英国用的煤反而越多〔待核〕。第 14 章把这个悖论埋下，这里收。token 越便宜，用的 token 多半越多，这一条大概率会重演。本书要多问的是：多出来的是哪个号位上的 token？一号位上的计数，跟着价格一起涨；三号位不是堆出来的（第 31 章），它不会因为便宜就自动多起来。杰文斯悖论在一号位上重演，在三号位上未必〔待验〕。

### ◆ 七、三家价值论各押一个号位

这五道难题，经济学史上三家价值论各自碰到过一半。

第 391 号拆过三家：劳动价值论押「东西」那一头，效用价值论押「人」那一头，交换价值论押「来往」那一头。放到力的九格上：

劳动价值论押一号位。价值在做出来的那样东西里，量它要看耗费了多少。放到 token 上，它最好解释价目表：算力、电、芯片，都是耗费，价格贴着耗费走。它说不清的，是同样的耗费为什么在杜禾那里值一个论点。

交换价值论押二号位。价值在成交那一下才有，马歇尔的剪刀，供给需求两片刃一合。放到 token 上，它最好解释那四道褶子：缓存、批处理、思考、长上下文，都是来往的样子进了价格。它说不清的，是同一下成交，为什么在两张桌子上剪出两种东西。

效用价值论押三号位。价值在人想要的那一头。放到 token 上，它最接近杜禾的「就是这个」。可是它把想要当成人先揣着的偏好，先给定、再去满足。第 391 号第 28 章说过，怎么买的，会回头改人有多想要。杜禾那份「想要」，是三个月里和模型一来一回改出来的，不是先在那里等着。

三家各看对了一个号位。按第 391 号的说法，每一家都在另外两头留着欠条。

请注意，这里说的是三家在力的九格上「各押一个号位」，是借第 391 号的三头往力上对，不是说三家学说本来就是在讲号位。这个对法，是本书接着第 391 号往下走的一步。

三家放在一起，正好照出 token 的三张脸：劳动价值论照见价目表，交换价值论照见褶子，效用价值论照见「就是这个」。三张脸都是真的，谁也不能单独代表那一百万 token。


### ◆ 八、市场已经在试的出路各钉哪一格

市场没有等经济学。服务商已经在试好几种卖法。先把它们背后的经济学还个公道，再看各钉哪一格。

价格歧视，是同一样东西卖给不同的人不同的价。庇古把它分成三级〔待核〕：一级是对每个人收他愿付的最高价，二级是按买多少、买哪一档分价，三级是按人群分价。经济学家早就说过，价格歧视在一定条件下能让更多的人买得起。

两部收费，是先收一笔入门费，再按用量收钱，像游乐园门票加每个项目的票〔待核：常引的文献是 1971 年奥伊的《迪士尼乐园的两难》〕。捆绑，是几样东西放在一起卖，让估价各不相同的人都愿意掏钱。夏皮罗与瓦里安在《信息规则》（1998）里讲得最透：信息产品要按价值定价，不按成本定价；办法之一是做出几个版本，让人自己挑，挑的时候就透露了自己的估价。

这几样办法有一个共同的长处：卖方不必知道每一个买方心里的价，也能让估价高的多付、估价低的少付。在信息产品上，它们几十年来一直管用。软件有个人版和企业版，数据有延时版和实时版，都是这个道理。它们之所以管用，是因为版本是卖方能事先做出来的东西。


这些都是真本事。现在看市场上的几种卖法。

分档：同一家出几档模型，贵的跑分高，便宜的跑分低。钉的是一号位的对比。

订阅：按月交一笔钱，额度内随便用。这是两部收费和捆绑的样子，钉的是粒子：把一份一份的计数，钉成一段时间里的一整块。

按席位：一个人一个账号，按人头收钱。它碰到了分布，落给谁。可它只记「几个人」，不记落在什么事上，场更不在里面。

网店老板和杜禾，在按席位的卖法里是一模一样的两个人头。


按结果计费：第 198 号记过一个例子，一家客服软件公司按「成功解决一个客户问题」收费。钉的是二号位的善：只为被接住的那一部分付钱。它离价值最近，可第 198 号自己也说了难处：结果难以界定，也受许多别的因素影响。

发生器按场计价：第 198 号说，一个人把方法文件、私有语料、评价标准装进基底模型，就成了一个发生器；基底的价格会被竞争压到接近算力成本，持有者的方法与判断带来的那一份，可以长期维持，那本书叫它知识租。这是唯一一种直接给场标价的卖法。

五种卖法，前四种都还在一号位和二号位上转。第五种碰到了场，可它给的是卖方那片场的价。杜禾这种情形，场是她自己一边用一边养出来的，她付了 token 钱，又付了三个月；这一片场，现有的卖法里没有一栏。

第 198 号还提醒过一件事：服务商在对话里知道的越来越多，最容易走向「杀熟」。按场定价，要是按的是从你的场里读出来的估价，就是把三号位又挂到了别人的价目表上。

### ◆ 九、本书的说法

把这一章的说法写准。

**价格是一号位的读数；价值是三号位的纠缠；两层并列，互相回写。**

价格：一份力在一号位上被计数、被比、被复现以后留下的那个数，外加二号位上被计了量的几道褶子。它是真的，也是做出来的：标准化把另两个号位钉住，它才能一个价走遍天下。

价值：同一份力在三号位上和场、分布、美缠在一起时显出来的那一份。它不在价目表上，在力落下去的那片场里兑现。

两层并列：价格不是价值的影子，价值也不是价格背后的本体。第 391 号拆过「价格是价值的表现」那套二元论，本书照用。

互相回写：用杜禾那个周末从头走一遍。

价格往价值里写。token 便宜，她才敢来回十几轮，一版一版地磨；要是每一轮都很贵，她多半磨到第三轮就收手，那个说法冒不出来。地板低，给三号位腾出了往返的余地。

价值往价格里写。那一节磨出来以后，她下个月换成了更贵的一档，又把方法文件整理得更细。三号位亮过一次，回头改了她在一号位上怎样买。

两层都在动，谁也不是谁的原因。网店老板那里，价值层几乎是平的，价格层就是全部；杜禾这里，价值层起伏很大，价格层只是一块垫在下面的地板。

这个说法有三处要守住。

第一，它不说价格是假的。一号位的读数是真的，是标准化做出来的真，第 18 章讲过。

第二，它不说价值是杜禾的。价值层里的那一份，是场、分布、美和一号位、二号位缠出来的，「我的论文那一节」是回写挂上去的名字。

第三，它不给价值层一个数。三号位上散开的那几份，本书不把它们加成一个总分。第 391 号把真、善、美三个读数并排、不加总，本书在这里也照办。


### ◆ 十、预言与判错

先用一句话把这一章出的难题收拢：经济学的工具，大多要求在成交之前就知道买的是什么；三号位回来以后，买的是什么，要到用完才知道。


这一章的说法，要能被事实打败。先写三条，都是本书的推断〔待验〕，第 41 章会把检验办法写全。

第一条，价值散开。同一个模型、同一个价，让一批人估「这次用掉的 token 值多少」。思想创新这类任务上，估价的离散程度明显大于格式整理这类任务。

第二条，场越厚，越不看价。手里攒下的方法文件、记忆、语料越多的人，面对别家更低的价，换家的比例越低。

第三条，杰文斯在一号位重演。token 单价往下走，总用量往上走；纠缠 token 在总用量里的比例，不跟着自动往上走。

判错写在这里：如果场厚的人和场薄的人，对价格变动的反应一样，第二条落空，本章「价格不动、价值散开」收窄为「价值散开，但不比价格散得更开」。如果思想创新任务的估价离散程度不大于格式整理，第一条落空，本章的五道难题退回成「经济学的老难题，换了一个新例子」。

### ◆ 十一、放回日子里

十一月第一个周日晚上，杜禾坐在米粉店最里面那张桌子，把发票和使用记录摊开。

周敏在旁边对电费单，问她：「我这单子一度一度清清楚楚。你那个，到底哪几百块是值的？」

杜禾一条一条往下翻，找到了那个周末的两个晚上。她算了一下，那两晚的 token 钱，加起来大约六十块。剩下的两百多块，是格式、翻译、改错字。

「就六十块？」周敏有点意外，「那一节你不是磨了好久？」

「token 钱是六十块。」杜禾说，「可是没有那份方法文件，六十块磨不出来。那份文件我改了三个月。」

她在本子上写了三行。

价格层：那两晚，约六十元。

价值层：论文第三章一个站得住的说法，导师认了。

两层之间：便宜，让我敢磨十几轮；磨出来了，我下个月换了一档。

写完，她看了看妈妈手里的电费单。周敏那锅汤的价值，是靠一碗粉一碗粉卖出去兑现的，粉的价钱写在墙上的价目牌上。她的这份价值，没有一块价目牌。

一个小办法，你明天就能试：用 AI 做事的时候，每做完一件，在记录旁边写一个字，「地」或者「缠」。月底只算「缠」那一栏的钱，再写一句它换来了什么。写不出来的那一笔，多半是地板，下个月就去找便宜的；写得出来的那一笔，它的价从来不在发票上。

> **九格卡**
> 一号位（对比·粒子·真）：价目表上的单价、按百万份计数、同一设置下的复现；价格层几乎全在这里。
> 二号位（变化·波·善）：缓存、批处理、思考型 token、长上下文四道褶子，按结果计费读的善；价格在这里起了变化。
> 三号位（分布·场·美）：落在论文第三章、围着三个月的方法文件、「就是这个」的那一选；价值在这里散开，一格也没进价目表。
> 钉住的是一号位三格与二号位的几道褶子；缺的是三号位三格的价，发生器按场计价只给卖方那片场开了一栏。

> **带走的话**
> 价目表上一个 token 只有一个价，那是一号位的读数；价值在三号位上散成好几份，两层并列，互相回写，谁也不是谁的影子。

> **本章判错句**
> 如果同一个模型、同一个价下，思想创新任务的价值估价离散程度不大于格式整理任务，且场厚与场薄的使用者对价格变动反应一样，本章「价格不动、价值散开」的判断收窄为经济学老难题的一个新例子。

> **想一想**
> 1. 你买过的东西里，有没有哪一样，同一个价，在你手里和在别人手里值得完全不一样？
> 2. 你为一份力付过「两次钱」吗：一次付给卖方，一次付在自己一点一点养出来的那片场里？

## 第 38 章　大装置与发生器：谁拥有哪一角

这一章交给你的判断是：芯片、算力中心、基础模型是一号位的大装置，管得住有没有、够不够、稳不稳；个人的发生器落在三号位，那片场是在使用里回写出来的，谁也不能像拥有一台机器那样拥有它。算力主权，只能管住一号位。

### ◆ 一、停电的晚上，断线的晚上

十一月中旬一个周四，晚上七点多，米粉店那条街停了电。

周敏正在下粉，锅里的水一下子不滚了。她骂了一句，从后厨拖出那台备用的煤气灶，接上罐子，继续煮。店里点起两盏充电灯，熟客们端着碗，在半明半暗里照样吃。

同一个晚上，杜禾在宿舍里，也碰上了断。她用的那家服务出了故障，页面上一行字：服务暂时不可用，请稍后再试。她正和模型磨论文第四章的一个提法，磨到一半。

两个小时后，电来了，服务也恢复了。

周敏的汤没耽误，煤气灶顶上了。杜禾的那一晚却续不上。服务恢复以后，她把同样的材料又放进去，模型的回答和两个小时前的思路接不上了，她自己的劲头也散了。

回家吃饭的时候，杜长林听她说完，慢慢讲了一句：「过去点煤油灯，没电也能过。现在离了电，一条街都停。你们那个，也是一条街吧。」

### ◆ 二、三样最重的东西

先看那条「街」底下是什么。

第 338 号《万灯》讲过技术世界里最重的三样东西：芯片，算力，基础模型。芯片是计算的肉身；算力是成千上万块芯片连起来日夜不停算出来的力气；基础模型是在海量文本上训练出来的底座，许多应用在它上面做一层薄薄的东西。那本书说，这三样都是大装置：个人和小团体背不动、所有人又都需要的东西。

第 338 号还说过，巨型组织蹲下来以后，要守的东西大致是四样：守原典，守标准，提供大装置，兜底公共服务。它管这样的组织叫基础组织。

杜禾那一晚断的，就是这一层。她的方法文件、她的笔记都在，可是让它们动起来的那台大装置，暂时不在了。

### ◆ 三、先说大装置对在哪儿

大装置不是坏东西，而且非有不可。

杜长林在供电所干了三十年，最懂这个。一个县的电网，变电站、线路、配电房，没有哪一户人家建得起；可是有了它，周敏的店、学校的实验楼、乡下的抽水机，都能用上同一种电。第 17 章讲过，插座不问你是谁。这句话的另一面是：插座对谁都一样好。

芯片和算力也是这样。一块先进芯片要几百道工序、几十年的工艺积累，全世界能造的地方屈指可数〔待核〕。一个顶尖的基础模型，训练一次的投入，个人想都不用想。杜禾一个月三百块，能用上这样一台装置，是大装置摊薄了成本的功劳。

把大装置完全成立的条件说清楚：**它管的是一号位，只要你要的是有没有、够不够、稳不稳，它就是最好的办法，而且只能由大的组织来造、来养、来开。**

### ◆ 四、大装置管的是哪几格

用九格量一量这三样东西。

芯片和算力中心，几乎全在一号位。对比：算力多少、跑分多少；粒子：一块卡、一个机柜、一个 token；真：稳定供应，同一个请求得到可复现的服务。它们也钉住了二号位的几格：接口的规矩、调用的流程、响应的快慢，像交流电的频率一样被钉成标准。

基础模型要多看一眼。第 23 章讲过，模型的能力，是别人的三角被封装成了一个看上去像客体的东西。训练用的是无数人写下的文字和代码，里面沉着无数次人和任务的往来；训练把这些往来的所得压进参数，让它能被整体调用。

所以基础模型站在一号位上，可它肚子里装着封存了的别人的三号位。封存以后，那些三号位不再亮了，只剩一号位上的读数：这个模型强不强，跑分多少。

三样大装置合起来，在九格上是这个样子：**一号位满格，二号位被钉住，三号位封在参数里，不亮。**

### ◆ 五、发生器：装在大装置上的那一层

再看杜禾那份方法文件。

第 198 号《知识经济的诞生》给这类东西起了个名字，叫发生器。那本书说，一个发生器由两部分组成：一部分是公共可得的基底模型，另一部分是持有者自己加上去的东西，至少有五类：方法文件，私有语料，微调得到的权重，工作流程与智能体的配置，评价标准。

那本书还打了一个比方：用户得到的每一个回答，都带着这五类东西的印记，却不包含它们本身，像盐溶进了汤；用户拿得走汤，拿不走配方。

杜禾这三个月，正是在养一个小小的发生器：十几页方法文件，一堆笔记，几段被导师打回来的反例和批注，一套「先让它复述我的判准、再让它反驳我」的固定问法。

放到九格上，这五类东西落在三号位。场：方法文件、语料、评价标准，是围着显影成形的那片联系。分布：它们让这份力落在思想创新这件事上，不落在客服上。美：评价标准写着什么样的回答算好，就是在给「被选中」立规矩。

这就是作者本人的话里那一句「必须是懂 SDE 的 Claude」所在的位置：三号位·场。大装置给了「Claude 的算力最好」那一格，一号位·对比；场这一格，在大装置上面那一层。

把作者本人的话放回来看：「对于我来说，Claude 的算力最好，但是随便一个 Claude 不行，必须是懂 SDE 的 Claude；而且懂 SDE 的 Claude 最合适我的事情是做思想创新，而不是普通的服务和软件写作。」

这句话里，「Claude 的算力最好」，是大装置那一层，一号位·对比，谁拥有芯片和模型，谁就管得住这一格。「必须懂 SDE」，是三号位·场。「最合适做思想创新」，是二号位·变化与善：一次推理被接住多少，要看落在什么事上。「对于我来说」，是三号位·分布。「最好」「最合适」那一选，是三号位·美。

一句话五个位置，只有第一个在大装置上。其余四个，都在装置上面那一层、在用的那一来一回里。这里的「我」，也是三号位侧重显影出来的，不是先站在那里发动这一切的人。


### ◆ 六、本书的说法：谁拥有哪一角

把这一章的说法写准。

大装置：个人背不动、所有人需要的芯片、算力中心、基础模型。它的力侧重显影在一号位，并钉住二号位的流程；它能被拥有，像一座电站能被拥有。

发生器：装在大装置上、使三号位侧重显影的那一层。它的力在场、分布、美上显出来。

谁拥有哪一角：大装置的所有者，拥有一号位那一角，可以计量、可以卖、可以停；发生器那一角，只能说「挂在谁的名下」，不能说「谁拥有它」。

为什么不能说拥有？第 15 章立过一条：承载者不是主人。杜禾那片场，不是她先揣着、再装进去的。方法文件是她改出来的，可改的理由来自导师的批注、模型的错、第 391 号那本书；那句「替人想要的那一格」，是在十几轮来回里冒出来的。所得先进土，名字后进号位。「我的发生器」是回写挂上去的名字，挂上去以前，它是一场缠在一起的发生。

从头走一遍。

九月，杜禾第一次用。只有大装置在场，她问什么，模型答什么，答得像对谁都一样。一号位满格，三号位不亮。

十月，方法文件长到十几页。同一台大装置，回答开始带上她那片场的样子：先复述判准，再找反例，词用得和第 391 号对得上。三号位亮了，场在大装置上面一层。

十一月，那晚断线。场还在她的硬盘上，大装置不在了，三号位亮不起来。服务恢复以后，场还在，可那十几轮来回里缠出来的、还没写进文件的那一截，散了。

三个月看下来：一号位那一角，在服务商那里；场有一半在她的文件里，有一半只在一次次来回里活着，断一下就没了。

那片场的两本账，也要在这里记一下。

所得进土：三个月里，每一次被打回、每一次改，都缠进了方法文件、笔记和她自己的判断习惯。这一本账慢，不要「我」，存在硬盘上的那一半，搬到哪家都在。

名字进号位：「懂我的那个 Claude」「我的发生器」，这些话挂上去很快，一句就够。可是请注意，这个名字挂在一台具体的大装置上。换一家，进土的那一半还在，名字要重挂一次，挂上之前，她会有好几天觉得「它不懂我」。

两本账对不齐的地方，正是搬家最疼的地方。


### ◆ 七、算力主权只能管住一号位

这几年，「算力主权」这个词常被提起：一个国家、一家企业，要有自己的芯片、自己的算力中心、自己的基础模型〔待核：各国政策表述不一〕。

这件事本书全认。大装置握在别人手里，人家断供、涨价、改规矩，你只能挨着。杜长林年轻时经历过拉闸限电，最知道一条街的电握在谁手里有多要紧。第 338 号也说过，一个底座只要能单方面改规矩，长在它上面的小项目就只能被动地挨着。

可是请看清楚，主权管住的是哪几格。

有没有、够不够、稳不稳、贵不贵，一号位四件事，主权都管得住。接口规矩、调用流程，二号位上的钉子，也管得住。

场管不住。场不是造出来、存起来的，是在使用里一次次回写出来的。一个国家可以有全世界最多的算力中心，它的学生、工程师、研究者手里的场，照样要一次次改、一次次被打回才长得出来。分布也管不住：同一份算力落在什么事上，要看那片场把它引到哪里。美更管不住。

所以算力主权只是一半的事。另一半，是让场能长起来、能搬得动。

### ◆ 八、三号位被挂到大装置名下的那条路

还有一种情形，要专门说。

大装置上面那一层，越来越多地由大装置自己来做：记忆功能、个性化设置、对话历史，都存在服务商那里。用得越久，模型越「懂你」。这本来可以是一条好路。

可是请注意它挂在谁的名下。场的一半，存在了别人的机器上。你想搬到另一家，记忆带不走，历史导不全，那片场就要从头养。

第 338 号管这件事叫「回流变成抽水」：用户的提问、修改、点的每一个「这个回答不好」，回到底座，让下一代模型更好；如果送的人什么也没拿回来，那就不是回流，是抽水。

用本书的话说：这是三号位被挂到了大装置名下。挂上以后，回写的对称度就变了。杜禾自己改文件、自己存着，是在往双写那一头走；场存在服务商那里、由它的系统替她整理，就退向单写：系统在改她，她改不动系统。

第 396 号第 100 章讲过算法画像：一张越来越准的画像，会把三种属性一起冻住。三号位被挂到大装置名下，最坏的样子，就是那片场被冻成一张画像。

### ◆ 九、杜长林讲电网的规矩

那天晚饭，杜长林又说了一段。

他说，供电所再大，也有几条规矩：电价要公布，峰谷几点到几点写在单子上；要拉闸，得提前通知；电表是公家装的，可是你家里装几盏灯、买什么电器，供电所不管。

杜禾听着，觉得这几条正好对得上。

电价公布，是大装置把一号位的价写在明处。提前通知，是大装置守稳定。不管你家里装什么，是大装置不伸手到三号位里去。

电网是最典型的大装置，它对用电的人是零写：不认识你，也不改你。正因为零写，周敏的汤才是她自己的，没有一碗挂在供电所名下。

token 的大装置做不到零写，它必须读你的材料才能算。可是电网那几条规矩，还是可以照着学：价写在明处，改规矩提前说，三号位那片场让人带得走。

### ◆ 十、今天与机器

今天已经有几件事，在往这个方向走。

第 338 号记过：有的机构把训练好的基础模型权重公开发布，别人可以下载、在自己的机器上跑、在上面接着训练〔待核〕；不同平台之间的接口规矩，有一些在往公开、多方维护的方向走。

这些事的意思，用九格说就是：一号位的大装置不止一家，二号位的钉子是公共的，三号位的场就有了搬家的路。

杜禾自己也学了一手。那晚以后，她把方法文件、笔记、每次磨出来的要紧结论，都存进自己电脑里的一个文件夹，按日期记好。换一家服务，文件夹拿过去，场的大半还在。

### ◆ 十一、放回日子里

周末，周敏问女儿：「你那个文件夹，跟我那台煤气灶，是一回事吧？」

杜禾想了想，说：「有一点像。煤气灶是另一个大装置，停了电还有气。我那个文件夹不是大装置，是我养的那片场。大装置可以换，场要自己带着走。」

一个小办法，你明天就能试：列一张单子，写下你用 AI 时那片场都放在哪里。方法、笔记、例子、你认的好标准，哪些在你自己手里，哪些只存在服务商那里。只在别人那里的，挑最要紧的一样，今晚就导出来存一份。

> **九格卡**
> 一号位（对比·粒子·真）：芯片、算力中心、基础模型的算力与跑分、按份供应、稳定可复现；大装置满格。
> 二号位（变化·波·善）：接口规矩、调用流程、响应快慢；被大装置钉成标准。
> 三号位（分布·场·美）：方法文件、语料、评价标准，落在思想创新上、给「好」立规矩；在发生器那一层亮，基础模型里封存的别人的三号位不亮。
> 钉住的是一号位与二号位的流程；三号位在大装置上缺，挂在服务商名下时有被冻成画像的危险。

> **带走的话**
> 大装置能被拥有，管住的是有没有、够不够、稳不稳；发生器那一角只能说挂在谁的名下，它是在使用里回写出来的，要自己带着走。

> **本章判错句**
> 如果一个人把方法文件、语料和评价标准原样搬到另一家同档的大装置上，思想创新任务的产出质量明显掉回到没有这片场时的水平，本章「场在大装置上面一层、可以带着走」的说法收窄为「场与某一家大装置焊在一起」。

> **想一想**
> 1. 你用的哪一样东西，大装置是别人的，那片场是你一点一点养出来的？
> 2. 要是明天那台大装置换了一家，你手里还剩下什么？

## 第 39 章　养出自己那份力

这一章交给你的判断是：三号位那份力不是买来的，是养出来的；养的办法，是先用九格卡认清这份力缺哪一格，再用选起点三问挑一条路，然后去追回写。个人、学校、企业都一样：养土，而不圈土。

### ◆ 一、米粉店的菜单

十二月初，周敏想做一件事。

店门口那块菜单板用了好几年，字褪了色。她想重写一份，再在手机上发几条介绍，让附近新来的学生知道这家店。杜禾说：「让 AI 写嘛，几秒钟的事。」

周敏试了。她打了一句：「帮我写一份米粉店的菜单介绍。」

几秒钟，一份出来了：「精选优质米粉，秘制汤底，鲜香可口，欢迎品尝。」

她看了半天，说：「这哪家店都能用。」

杜禾说：「你得告诉它你的店是什么样。」

周敏就一句一句地说：汤底是筒骨加黄豆熬的，每天早上四点起来熬；扁粉是湘潭本地一家老作坊的；熟客最爱点的是酸豆角肉末，不要葱的人多；有个博士回老家以后还托人带过汤底。

第二版出来，像她的店了。

她又改了两处：「秘制」两个字删掉，她不喜欢；「欢迎品尝」改成「来了说一声老样子」。

第三版，她看了，笑了：「这个是我家的。」

### ◆ 二、九格卡先认这份力缺哪一格

周敏那三版，正好是一张九格卡从空到满。

第一版，一号位满格：字数够，句子通，谁来问都能得到差不多的一份。二号位有一点：一次推理，一次回答。三号位全缺：没有场，不知道是哪家店；分布落在「米粉店」这个类上，没落在「这一家」上；没有被选中，周敏一眼就嫌它。

第二版，场进来了。筒骨、黄豆、四点、老作坊、酸豆角、那个博士，这些是九年里围着这家店长出来的联系。分布也挪了，从一类店落到了一家店。

第三版，美亮了。删掉「秘制」、换成「老样子」，是在几版里选出「就是这个」。

用九格卡认一份力，先问的不是「这个模型强不强」，是「这一次缺的是哪一格」。缺一号位，换大装置；缺二号位，换问法、多来回几轮；缺三号位，就要去养。

第 36 章说过，多数时候缺三号位不要紧，地板正合适。可是周敏要的恰恰是「这一家」，三号位一缺，力再足也是别人家的菜单。

### ◆ 三、先说「买更好的」对在哪儿

很多人碰到第一版那种回答，第一个念头是：换个更贵、更强的模型。

这个念头不错。第 31 章讲过，规模长的是一号位，对比、粒子都会跟着长。更强的模型，句子更顺，常识更全，错得更少。在缺一号位的时候，买更好的，就是最快的路。

它完全成立的条件是：**缺的确实是一号位。**

杜卫东算油耗就是这样。他要的是一个准数，路线、载重、车况都给定了，换哪家来算都该是同一个答案。答得不准，换一个更强的模型，正对路子。


周敏那一次缺的不是。换一个再贵的模型，没有她那几句话，它写出来的照样是「精选优质米粉」，只是写得更漂亮。三号位不是堆出来的，是回写出来的，这句话第 31 章说过。

### ◆ 四、六条路，三个起点

第 396 号《属性纠缠论》第 57 至 59 章讲过六路径：三种属性轮流作起点，每个起点后面有两种排法，一共六种。那本书用的是主体、客体、互动三种属性；放到力上，就是三号位、一号位、二号位轮流起手。

从一号位起手：先动那台大装置，换模型、换档位。

从二号位起手：先动用法，换问法、加轮次、改流程。

从三号位起手：先动那片场，写方法文件、整理语料、立评价标准。

每个起点后面再排两种先后，比如「二号位→三号位→一号位」，就是先换问法，再看场长出来没有，最后才考虑换不换模型。

第 396 号说，六条路不分高下，是同一个三角的六个入口。起点不由习惯定，由这件事自己带着的样子定。

### ◆ 五、选起点三问

那本书第 60 章给了选起点的三问：哪一角最松？哪一角被先在化得最深？哪一角回写最快被看见？

拿周敏的菜单问一遍。

哪一角最松？用法。多说几句、多改两版，马上就能做，不花钱，不行就退回。

哪一角被先在化得最深？三号位。「这是我家的店」，周敏觉得这是天生就有的，用不着跟机器讲；可恰恰是这一角，机器那边一点也没有。

哪一角回写最快被看见？还是用法。每改一句，下一版当场就变。

还可以问反过来的一句：要是周敏一上来先从三号位起手呢？比如先坐下来，把九年的店史写成一篇长文，再交给机器。这条路也走得通，只是慢；她那天下午只想要一份菜单。起点没有对错，只有合不合这件事此刻的样子。

三问排下来：第一位放最松、回写最快的二号位；被先在化最深的三号位不放第一位，放在第二位让它慢慢长；一号位放最后。二号位→三号位→一号位。周敏那天下午走的，正是这一条。

请注意，第 396 号也提醒过：在 AI 已经进来的事情里，互动那一角常常最松，这是倾向，不是规定。三问每一次都要重问。

### ◆ 六、本书的说法：养出自己那份力

把这一章的说法写准。

养出那份力：让三号位在一份力上反复侧重显影，并把每一次的所得回写进场，使同一台大装置在这件事上成为不同的力。

它有四步，照第 396 号第 61 章那张三角卡的四栏走：诊断，用九格卡认缺哪一格；选路，用三问挑起点；推进，看哪两个号位在撞；追回写，写下看什么读数、多久看一次、怎样算失败。

用杜禾从九月到十二月，从头走到尾。

诊断：九月，一号位满格，二号位有，三号位缺。被先在化的是三号位：她以为「懂我」是模型自己该有的。

选路：二号位→三号位→一号位。理由：问法最松，当天能改；三号位先在化最深，放第二位；一号位放最后，换模型最贵也最没必要。

推进：模型回答里的老毛病（一号位，把层断裂讲成价格下跌）和她的追问（二号位）一撞，推着三号位长：她把那条判准写进了方法文件。

追回写：每周看一次三件事，模型复述她的判准还错不错，导师批注里「概念混淆」少了没有，方法文件长了几条。失败条件写在本子上：三个月后，换一个同档模型，产出掉回九月的样子，就说明场没养进文件，只养在了一家服务的记忆里。

十二月，她真换了一次试。掉了一点，没掉回九月。

这四步里，有一句话要读准。「杜禾养出了她的那份力」，在日常里可以这么说；到下判断的时候，要换一种说法：九月到十二月，三号位在这份力上一次比一次亮得稳，「我的」这个名字，是在这一次次回写里挂上去的。杜禾每天改文件、追问、存档，这些事照常是她在做；可是那份力为什么成了「她的」，答案不在她一个人身上，在那三个月的来回里。


### ◆ 七、学校：统一账号，还是让学生养场

杜禾的学院也碰到了这件事。

学期初，学院讨论给研究生统一买 AI 账号。有老师主张选最便宜的一家，人人一样，公平，好管。

这个主张对在哪儿，要先说足：一号位上，统一采购确实省钱、确实公平；格式整理、文献检索这类地板任务，谁用都一样，统一账号正合适。

可是杜禾在会上说了一句：统一账号可以，方法文件和笔记得让学生自己存、自己带走。

她的导师接着说了一个办法：账号统一买，地板任务走统一账号；每个学生另建一个自己的文件夹，放方法、反例、评价标准，学期末交一份「我的场长了什么」的两页小结，不打分，只看长没长。

用九格看，这是一号位统一、三号位各养。学校管大装置那一角，不伸手去收学生的场。

会上也有人担心：学生各养各的场，会不会养歪？有人只喂模型自己爱听的，越养越偏。

导师的回答是，那两页小结里有一栏专门写「这学期我的场被谁打回过」。被导师打回、被同门反驳、被模型自己挑出的错，都记进去。一片场要是一学期没被打回过一次，多半不是长得好，是圈住了。

这个办法管不管用，学院还没有看到结果〔待验〕。可它的方向是对的：学校守大装置和标准，学生养场，场的长法要摊在明处，让别人能来反对。第 338 号说基础组织守原典、守标准、提供大装置；学校在这件事上，正好是一个小小的基础组织。


### ◆ 八、企业：米粉店也是一家企业

回到周敏。

菜单写好以后，她又试着让 AI 帮她回外卖平台上的差评。第一次回出来，礼貌周到，像一家连锁店的客服。她不满意。

这一回她自己知道该怎么做了。她在手机备忘录里建了一页，写了五条：差评先认，不辩；说清哪天、哪碗、出了什么事；不写「亲」；要是汤淡了，就说那天骨头少放了；最后一句写「下次来，说一声，我多给你加一勺汤」。

这一页，就是米粉店的场的一小块。九年里攒在她嘴上和手上的东西，第一次被写成了几行字。

大一点的企业也是这个道理。公司可以统一买大装置，这是一号位；可是一个部门、一个老师傅、一个客服组攒下的那些「我们这里不这么说」「这种客户要先问一句」，要有地方写下来、让人接着改。

第 396 号第 96 章讲过一张三栏绩效表：个人栏、任务栏、协作栏，三栏不加总。放到力上也可以照这个样子记一本账。一栏记大装置花了多少，一号位；一栏记用法改了什么，二号位；一栏记场长了几条，三号位。三栏也不加总。只看第一栏的公司，会以为换最便宜的模型就是省钱；三栏都看，才看得出哪一次省钱，其实是把一个客服组三年攒下的规矩扔了。

周敏那五条规矩，按这本账，就记在第三栏里。它一分钱没花，却是店里最难重来的东西。


### ◆ 九、养土，而不圈土

这里有一条线，个人、学校、企业都要守：养土，而不圈土。

养土，是让场一次次回写，越缠越厚：方法文件越改越准，反例越攒越多，评价标准越来越说得清。

圈土，是把场锁起来，只许在一处长。有三种常见的样子。

第一种，场被锁在一家服务里。记忆、历史、设置都在别人那里，带不走。第 38 章讲过，这是三号位被挂到了大装置名下。

第二种，组织把个人的场收归自己。一家公司规定员工的方法文件只能存在公司系统里、离职一律清空。公司有它的理由，商业秘密要保护〔待核：各地法规不一，本书不作法律建议〕。可是一片场一旦只许在一处长，它就开始变窄、变老。

第三种，自己把场圈起来。只喂模型自己爱听的，只留赞同自己的例子，评价标准越写越像自己。第 338 号把这叫作「只说我爱听的」那面镜子。场是越来越厚了，可它只围着一个点长，三号位亮成了一盏只照自己的灯。

三种圈法，有一个共同处：回写只往一个方向走。养土要的是双写：你改它，它也改你；你的场长进力里，力里冒出来的东西，也回头改你的场。

### ◆ 十、今天与机器

今天的工具，往两个方向都在推。

一个方向是方便圈土。记忆功能越做越顺手，什么都不用自己存，用得越久越「懂你」，也越难搬走。

另一个方向是方便养土。很多工具允许你写自己的说明文件、上传自己的资料、导出对话记录〔待核：各家功能不一〕。这些功能让场能落在你自己手里。

本书不劝你不用记忆功能，那是二号位上的好帮手。只提醒一句：用之前，先想好这片场有几成要在自己手里。

### ◆ 十一、放回日子里

一年快到头的一个晚上，一家四口在米粉店里吃饭。

杜长林看着墙上的新菜单，念了一遍：「来了说一声老样子。」他笑了：「这句话你说了九年，现在写上墙了。」

杜卫东说他也想试试，让 AI 帮他算一趟长沙到广州的油耗。杜禾说：「那个是一号位的事，用最便宜的就行。」

周敏说：「我那五条回差评的规矩，你帮我也存一份到你那个文件夹里。」

杜禾说：「存你自己手机里。那是你的店的场，你带着。」

一个小办法，你明天就能试：挑一件你常用 AI 做、又总觉得「不像我」的事，拿一张纸，写下五条「我们这里是这样」的规矩。写完，下一次用的时候放进去。一个月后，再看这五条改了几条、多了几条。改过的那几条，就是那片场在长。

> **九格卡**
> 一号位（对比·粒子·真）：模型的强弱、按量计费、可复现的地板任务；统一采购最省，规模能让它长。
> 二号位（变化·波·善）：多说几句、多改几版、追问几轮；常常最松、回写最快，适合先起手。
> 三号位（分布·场·美）：店的筒骨汤和「老样子」、学生的方法文件、评价标准；要养，要回写，要自己带着。
> 钉住的是一号位，交给大装置与统一采购；缺的是三号位，靠养土补，圈土会让它变窄、变老。

> **带走的话**
> 三号位那份力是养出来的，不是买来的：先认缺哪一格，再挑最松的一角起手，然后追回写；养土，而不圈土。

> **本章判错句**
> 如果按选起点三问挑起点的人，在思想创新这类任务上，并不比只换更贵模型的人更快见到稳定的回写，本章的养法收回，退为「三号位主要随大装置一起长」。

> **想一想**
> 1. 你手里有没有一份「我们这里是这样」的规矩，从来没写下来过？
> 2. 你养的那片场，有几成在你自己手里，有几成在别人的机器上？

### ◆ 本编总账

第七编四章，问三号位回到力里来以后，日子和账本怎样变。第 36 章把同一个 token 分成地板与纠缠两面；第 37 章看价格与价值怎样在 token 上断成两层，经济学的工具停在哪里；第 38 章分清大装置与发生器各占哪一角；本章落到个人、学校、企业怎样养出自己那份力。

| 章 | 看见了什么 | 一号位 | 三号位 |
|---|---|---|---|
| 第 36 章 | 同一个 token 有两面 | 地板，贴着算力往下沉 | 纠缠，在落下去的场里兑现 |
| 第 37 章 | 一个 token 有几个价 | 价格层，一个价走遍天下 | 价值层，散成好几份 |
| 第 38 章 | 谁拥有哪一角 | 大装置，能被拥有、能被主权管住 | 发生器，只能说挂在谁名下 |
| 第 39 章 | 怎样养出那份力 | 统一采购，交给规模 | 养土，不圈土 |

看见清单：地板是真的，也是好的；价格是一号位的真读数；大装置非有不可；三号位回到了力的里面。

收回清单：价目表不等于这份力的全部；「同一种商品」这块地在三号位上松了；算力主权只管住一号位；「我的力」不是先揣着的，是回写挂上去的名字。

**三号位之力的文明，是一号位越来越便宜、越来越一样，三号位却回到了力里：价格还在一号位上，价值散在三号位上，那份力要靠养，不能靠买，也不能靠圈。**
