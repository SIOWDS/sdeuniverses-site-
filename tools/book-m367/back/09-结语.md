# 结语　从「有多少度」到「是谁的力」

### ◆ 一、两张单子摆在一张桌上

月底那天晚上，杜家的饭桌上摆着两张单子。

一张是米粉店的电费单。周敏用红笔在度数那一栏画了个圈，比上个月多了一点，因为天冷了，骨头汤熬得久。

一张是杜禾手机里的 token 账单。她把屏幕转过来给爷爷看，数字也比上个月多了一点，因为论文写到了要命的那一节。

杜长林戴上老花镜，两张都看了一遍。他抄了三十年电表，看单子是老本行。

他说：「电费这张，我看得懂。多一度，就是多烧了一度。你这张，我看不懂。数字我认得，可它多出来的那一截，到底是多干了活，还是白转了圈，单子上看不出来。」

这本书四十一章，说到底就是在讲老人这句话。

### ◆ 二、两百年，力被钉成了「谁来都一样」

先把走过的路收一收。

前工业的力，三号位都在。一个好劳力，是这一个人；一头只听主人的牛，是这一头牛；一架水碓，是这一条溪边的水碓。力和它落在谁身上、围着谁长出一片场、被谁抢着请，缠在一起。三号位亮得很，可是一号位立不起来：没有「一度人力」，没有「一斤牛劲」，力算不出来，也卖不开。

工业文明做的事，是把一号位立起来。马力把马拿来比，再把马的脾气钉掉；标准煤和热值把一吨一吨的力做成「这一类」；一只桶、一个品级、一个基准价，让每一桶都一样；电压和频率钉住了二号位的变化与波；插座与电表把分布钉成人人一样。到了千瓦时，力成了「谁来都一样」。

这是成就，不是罪过。本书第三编一直在说这件事：一度电在谁手里都是一度电，所以医院和米粉店用得上同一张网，所以杜长林抄表时不必问用电的人是谁。稳定是真的，是公共成立；只是这个「谁来都一样」，是钉出来的。钉住的地方，三号位被逐出了。

所以全书的判词这样说：

**能源史是三号位被逐出的历史：人类用两百年，把力从「这一个」做成「谁来都一样」。Token 是第一种让三号位回到可计量之力里的力：它的场在使用中回写进去，它的分布落给谁、它的美被谁选中，都改变它是哪一种力。**

### ◆ 三、计算力开了一道门，token 走了进来

计算力放开了二号位。同样的芯片，跑不同的程序就是不同的力，一次运算不再是一次运算。可是三号位仍然缺着：你在电脑上写什么，电脑不会因此变成「你的」电脑。

token 走进来的那一步，在作者本人的一句话里看得最清楚：「对于我来说，Claude 的算力最好，但是随便一个 Claude 不行，必须是懂 SDE 的 Claude；而且懂 SDE 的 Claude 最合适我的事情是做思想创新，而不是普通的服务和软件写作。」

这句话里，「Claude 的算力最好」是一号位的对比；「必须懂 SDE」是三号位的场；「对于我来说」是三号位的分布；「最合适做思想创新」是二号位的变化与善；「最好」「最合适」那一选，是三号位的美。九格里有六格，在一句话里一起亮了。

这里的「我」，不是一个先在的人拿起一份力去用。是力落在了这一处，这一处亮成了「我」；「懂 SDE」是语料、Skill、记忆一次次回写进去，在使用中长出来的一片场。所得先进土，名字后进号位。

### ◆ 四、三张脸

「第一次」这三个字，本书小心地用。手艺人、好劳力、人和工具的复合体，三号位从来都在；第一次的是，三号位回到了一种按份额计量、按价目表出售的力里。

这个第一次有三张脸。

第一张脸是钉不住。电的另两角被电压、频率、插座、电表钉死了，token 的场在使用中回写进去，价目表钉不进去。

第二张脸是换了界。煤、油、电都落在现实界，那里的尺子最硬，所以「一度电」像石头一样客观；token 做思想创新时落进理念界，那里的尺子最软。

第三张脸是换了族。以往的力是一股劲，管维持、管激发；token 在思想创新里的力是一条路，是能不能走出新路的那份本事。

三张脸连成一件事：力第一次从「有多少」走到「是谁的」，而且这个「谁」，是发生出来的，不是事先摆在那里的。

### ◆ 五、经济学接下来要回答的

第 37 章写了五道难题。这里只说它们共同的根。

经济学两百年站在一块地上：同一种商品，同一个价。这块地是一号位铺的。煤、油、电正是因为一号位立得住，价格才能大体读出价值。

token 的价格只读到一号位，价值却在九格的纠缠里。同价不同值，同值不同价；需求曲线的横轴上，「一单位」不再同质；成本在一号位，价值在三号位，两者不在一处。价目表越拉越长，是二号位挤进了定价；三号位一格也没进价目表，价格层和价值层就在这里断开。

本书没有替经济学给出答案。本书只说：这不是市场还不成熟，是三属性纠缠在价目表上露面了。谁能第一个按场计价而不把场冻死，谁就碰到了这道题的门把手。

### ◆ 六、对个人，一句老实话

如果判词是对的，那么每个人手里那份算力，值多少，不由价目表定，由它落在哪片场上定。

这不是说人人都要去做思想创新。杜禾的大半个月，token 都花在整理文献上，那是地板 token，不丢人，也离不开。要紧的是知道：哪几百块换来了论文里那一节，哪几百块只是在原地重写开头。前一种是纠缠 token，它会回写进你的场；后一种是地板 token，它用完就走。

养出自己那份力，靠的不是多买，是养土：让一片场在一次次使用里长厚、长宽，而不是越用越窄、越用越像别人。

### ◆ 七、本书最可能先倒在哪里

一本讲回写的书，要允许世界回写它。

第 41 章立了一条致命条款：同一批使用者、模型与任务交叉之下，若思想创新任务上含使用者的搭配份额不高于标准编程任务，第五编收窄；两类任务都低于登记下限并复现，判词的后一半就要划掉。另有六条按号位排的预注册预言，阈值都标了〔待验〕，须在开跑前登记，由不知道假设的人记录，结果出来后不许改。

本书自己押的是：最可能先倒的是「美」和「回写对称度」两条。美的读数最难和营销分开，双写最难和单写分开。倒了，就照第 41 章写好的退法退。

写作时，这些检验一条都还没有真跑。这一句照实写在这里。

### ◆ 八、放回日子里

那天晚上，杜禾收起手机，在那张 token 账单的截图上做了两个记号：一个画圈，一个画叉。画圈的是那两个写出新东西的晚上，画叉的是反复重写开头的那一周。

杜长林看她画完，说：「你这是在抄表。」

杜禾笑了：「抄的不是度数。」

「抄的是什么？」

她想了想：「抄的是这份力落在哪儿了。」

老人点点头。他抄了三十年表，从来只问有多少度。他孙女这一代，要开始问另一句：这是谁的力，它在谁那里长成了什么。

> **带走的话**
> 一度电问的是「有多少」，一个 token 还要问「是谁的」；这个「谁」，是在使用里发生出来的。
