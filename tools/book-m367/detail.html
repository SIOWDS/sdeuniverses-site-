从马力到 Token

力的属性纠缠文明史 · 「普通人都能懂」系列 · 《属性纠缠论》（第 396 号）应用卷

能源史是三号位被逐出的历史；Token 是第一种让三号位回到可计量之力里的力。

一度电，谁来用都是一度电；一个 token，却不是。同一个月、同一个模型、同样一百万 token，一张桌上写出了一节思想创新的论文，另一张桌上回了几千条客服消息。账单一样，力不是同一种力。作者说：对我来说 Claude 的算力最好，但必须是懂 SDE 的 Claude，而且最合适做思想创新。这句话里，一种力第一次同时有了主体、客体、互动三种属性，而且缠在一起。

本书用「力的九格」读两百年的能源史：客体性是一号位（对比·粒子·真），互动性是二号位（变化·波·善），主体性是三号位（分布·场·美）。人力畜力三号位都在，只是算不出来；马力、标准煤、原油、电网与千瓦时，把力钉成「谁来都一样」；计算力放开了二号位；token 让三号位回到一种按份额出售的力里——也给经济学出了一道「同价不同值」的难题。

八个要点

一个 token 的两张桌子（导言）同样一百万 token，一张桌上是一节论文，一张桌上是几千条客服回复：账单一样，力不同。
力的九格（第一编）一号位对比·粒子·真，二号位变化·波·善，三号位分布·场·美；号位的真善美不是三股劲。
三号位尚在（第二编）好劳力、只听主人的牛：前工业的力三号位都在，只是算不出来。
钉住史（第三编）马力、标准煤、原油、电压频率、插座电表：力被钉成「谁来都一样」，这是成就，不是罪过。
二号位放开（第四编）一次运算不是一次运算：程序让变化回到力里。
三号位回来（第五编）「懂 SDE」是一片场，不是一项功能；规模只长一号位。
一个 token 有几个价（第37章）价格只读到一号位，价值在九格的纠缠里：一价定律、需求曲线、边际定价同时吃紧。
本书怎样才算错（第八编）致命条款与六条预注册预言，按号位排列，写在开跑之前。

可被推翻

第八编写明本书怎样才算错：同一批使用者、模型与任务交叉之下，若思想创新任务上含使用者的搭配份额不高于标准编程任务，第五编收窄；另列按号位排列的六条预注册预言与本书自认最弱处。书中凡标〔待核〕的史实与数字尚未逐条核对，凡标〔待验〕的是本书的初步解释。本书讲的「力」是被显影、被挂名、被计价的属性，不改写任何物理定律；陪读人物与场景均为构想。
