# 版面"装置"写作说明（《被清零的不是博士》PDF 美化）

为了让每一页有呼吸、有节奏，每一章在排版时会加四种装置（照德麦国际第 220、302 号的版式）：

1. **这一章的问题**（章首，蓝边框）：一句话，问出本章要回答的那个问题。18—45 个汉字，以"？"结尾。用书里的说法，不用新术语。
2. **金线引语**（章中，上下金线、加粗居中）：从本章正文里**原样摘出** 3 句（导论和结语 2 句），每句 18—48 个汉字。必须是正文中某一段里连续出现的原文，一字不改（标点、引号也照抄源文件），以句号、问号或叹号结尾的完整句子，不要截半句。三句要分散在本章前、中、后三段位置，挑判断最锋利、离开上下文也能读懂的句子。
3. **带走的话**（章末，米底金边）：一句判断，本章最该带走的话，25—60 个汉字。可以用自己的话凝练，但不得超出本章正文的意思。
4. **小账**（章末，紧跟带走的话）：两行，每行格式是"一个问读者的短问题？——一句提示"，问题 6—20 字以"？"结尾，提示 15—40 字。第一行问"这一章的判断落在你身上是哪一处"，第二行问"你下一步可以做的一件小事"，都要贴本章内容、具体，不空泛。

纪律：不编造数据、语录、研究；不出现 E、D、S 字母和"SDE"字样；中文全角标点；人物只用书中已有的。

输出 JSON（UTF-8，合法 JSON，写完用 python3 -c "import json;json.load(open(路径))" 校验），键为源文件名去掉 .md：
{
  "ch01": {
    "question": "……？",
    "pulls": ["原文句子一。", "原文句子二。", "原文句子三。"],
    "takeaway": "……。",
    "ledger": ["……？——……。", "……？——……。"]
  },
  ...
}
写完后自检：对每句 pulls，用 python 确认它是源文件全文的子串（`s in open(源文件).read()`），不是就改到是为止。
