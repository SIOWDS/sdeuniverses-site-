# 术语表

**AEI**：AI 时代的新生产单位，“人-AI 复合体”的财富机器。以意义为方向、以 AI 为工程速度、以反馈为校正机制，持续发生智慧新思想，并封装为可复制的产品线，形成复利。

**E（Ego，“我”）**：AEI 这三个字母里的 E，是 AEI 的决定性锚点；不是技术修饰词，而是本体性位置。E 对应三号位的三把手：分布、场、美。

**三号位（分布/场/美）**：财富命运“默认值”的操作杆。分布是关系与资源网络里的位置；场是互动规则与次序；美是吸引力与和谐度，也就是复利的自然性。

**思想寡头**：本书的一个两层概念。第一层是结构位置：少数人和少数组织开出新路，并占住“发生—封装—扩散”的控制权，资源、注意力与合法性于是倾向于向他们集中。这是诊断，也是风险，因为位置固定之后可能变成压住别人的盖子。第二层是对照：普通人的目标不是当思想寡头，而是成为发生中心。

**发生中心**：一个人、一个家庭、一个小团队，能提出自己的问题，建立自己的坐标，并在现实反馈里改写自己的题库。它不要求规模，也不要求别人承认；要求的是你那块地上的事情是你自己在想、在试、在改。每户都能决定自家种什么，不等于每户都是第一个开路的人。

**发生—封装—扩散**：本书的“思想生产三动作”。发生是提出新问题、新结构；封装是把思想变成可执行的结构；扩散是把结构变成产品线与闭环的组织能力。

**抄得走与抄不走**：抄得走的是结果，包括概念表、模型图、工具箱、框架的名字，乃至一个模型的行为，它们会越来越便宜；抄不走的是发生，即现实变了、旧框架失灵的时候，还能不能提出下一题、做出新一轮结构。封装带来的只是一段时间的领先，能领先多久，看背后是否还在持续发生。

**出题权**：方向权。不是更快解题，而是能提出新问题、重写旧问题。可用三个信号判断：把“怎么更快”改写成“该不该做”，把“如何达标”改写成“什么算值得”，把“别人都在做什么”改写成“我要创造什么”。

**意义权重**：在创造、自由、幸福之间换挡的能力，保证长期运转；意义权重一旦外包给外部指标，就会被跑步机拖走。

**反馈闭环**：AEI 的仪表盘。用“最小试验、从失败读结构、每周每月把经验封装成工具”，把不确定变成信息，再用信息迭代路径，长出复利的结构。

**产品线**：把同一套智慧新思想封装成可复制的交付物，形成可迭代、可扩散、可复利的“产品森林”。

**产品森林与产品烟花**：烟花是一次性的爆款；森林是可持续生长的产品线体系。

**七种形态分裂树**：同一思想可以分裂为七种产品形态：书、课、工具箱、训练营、咨询、软件、API，从语言到理解，到行动，到习惯，到系统，到订阅资产。

**突变时代**：规则改变的频率与幅度超过传统适应机制所能承受的时代；“稳定很短，变化很快，旧的稳定迅速失效”成为常态。

**价值寿命**：一项产品、技能、方法或路径保持有效与溢价的时间长度。AI 加速使价值寿命进一步缩短，迫使系统从“守住存量”转向“持续生成”。

**意义经济学**：价值失稳之后，财富的稳定性必须向上游迁移，迁到“持续生成真善美的能力”；其核心资源是能运行意义三律的智慧。

**意义三律（创造/自由/幸福）**：创造是生成新结构与新价值；自由是打开可行路径与选择空间；幸福是把张力转为可持续的动力，保证系统不断运转而不崩溃。

**SIO（主体—互动—客体整体）**：本书的存在结构底座；内卷与原创等问题，需要回到 SIO 整体才能解构与重建。

**ΔSIO（差异火花）**：原创发生的第一粒火花；差异被点燃并稳定化、再纠缠扩散，特征与结构才会形成。

**生题与终题**：生题是提出新问题；终题是结束旧循环；二者加上“建立新结构”（可复制的发生机制），构成原创的三大难题。

**题库**：命运运行的题型集合；“命运像命运”，是因为它以默认运行的方式反复出题。

**题库可编辑**：AI 时代改写财富命运的目标不是“没有问题”，而是旧题能死、新题能生、三律复活、新默认值下沉。

**默认值（默认流程）**：人在不刻意思考时也会自动运行的行动与反应；改命就是把新默认值写入系统。

**锁化态（锁芯—棘轮—锁壳）**：题库不可编辑的结构性原因。锁芯偏向连接固化，棘轮偏向次序死亡，锁壳偏向结构单一，最后只能在旧题库里加码或断电。

**三钥匙开锁（三公理归位）**：本体归位是连接松动；路径归位是次序复活；动力归位是意义点火。归位发生，题库就从不可编辑变得可编辑。

**三界（现实/理念/自我）**：命运运行的三个后台；只改一界通常会回滚，三界同改才容易形成新默认值。

**三界同改**：改命的最低条件。现实只努力会回滚，理念只想明白会空转，自我只立志会燃尽。

**九宫格（重编码操作系统）**：把“三界同改”落到九个写入点：三界乘以三规范。

**三规范（改名/改路/改评）**：改名是重命名问题与身份；改路是重排路径与次序；改评是重写评价函数与指标体系，让真善美回到护持的位置。

**四铁指标**：验收你是否改写成功的四条：旧题能死、新题能生、三律复活、新默认值下沉。

**三类反扑**：影子反扑（连接回滚）、流程反扑（次序回滚）、价值反扑（结构回滚）；意识到反扑，就可以启动复位周期。

**复位周期**：系统维护计划（每日、每周、每月、每季），把改命从一次冲刺变成长期运转的机器。

**最小试验**：把新路径写成现实动作，用反馈校正；是反馈闭环的最小单元。

**跑步机（资格化跑步机）**：资格成为门槛，更多人追，稀缺性下降，系统再抬高门槛，人投入更多时间成本；努力变成无效加码，内卷成为常态。

**KPI 工厂与发生平台**：两种组织结构位。前者制造文明病与内卷，后者制造复利与可持续的发生。
