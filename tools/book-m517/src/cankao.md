# 参考书目

本书只列修订时实际核查、正文用到的材料。这一版沿用原书不用引文的写法，案例的出处集中在这里。每条末尾的标记说明读到什么程度：〔原文〕指读到文献原文或原页面；〔部分〕指读了相关部分；〔摘要〕指只读摘要、书目页或书评；〔二手〕指据新闻、词条或他人转述。网页内容多经工具转述，凡不能确认读到全篇的，都降一档标注。书中的人物言论都是短句转述。
