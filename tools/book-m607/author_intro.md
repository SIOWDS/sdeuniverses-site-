# 作者介绍
王德生，博士，SIO 本体论与 SDE 发生学的创立者，德麦国际创始人，SDE Universes 平台的主持人。

他出身计算数学：湘潭大学数学系本科与硕士，中国科学院数学研究所博士；先后在英国威尔士大学斯旺西分校、新加坡南洋理工大学数学系任教与研究，是博士生导师，发表计算数学与图形学国际期刊论文四十余篇。

2015 年起，他回国推广多视角看世界的方法，各地高校讲学数百场。2024 年提出 SIO 本体论与意义三律，后来凝练为 SDE 发生学。他主持的德麦国际出版体系与 SDE Universes 平台，已出版数百部专著，并为每部专著配有智能体与学习包。

他的口号是：让每个人都有自己的思想和知识工厂。
