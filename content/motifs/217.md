# 第217号《价值发生论》
- 副题：真善美，不是评价，而是生成的三种力
- 作者：王德生、付自文著
- 题域：哲学·价值论
- 题型：Why
- 母题：真善美不是评价标准，而是意义三律运行结出的三种力之果；价值是意义的局部定型。

## 一、它推翻的默认看法

默认看法是把真善美当作早就在那里、等人去发现的标准：真是陈述符合现实，善是行为符合道德，美是形式令人愉悦；"价值"是判断的尺子，"有价值"是评价的结果。本书从 value 的拉丁词根 val-（力量，有效性）出发，说 value 原初不是评价（Value ≠ Evaluation），而是一个结构是否"有力"。因此错在两步：第一，把价值当作静态标准，其实价值是动态生成；第二，把价值与意义混为一谈，其实价值是意义的局部定型，意义才是源头。由此，所谓"价值标准"其实是结构运行时满足的三种约束，传统的性善性恶之争、真理中立的神话、达标人生的空洞，都出自把价值果当成意义果。

## 二、母题怎样立起来

起点是2024年8月的主客互动价值论：价值的主人不是单独的主体或客体，而是主体、互动、客体合成的 SIO，真善美相应分成三个子论。第一步，同年9月从词根 val- 把真善美写成维持、促进、吸引三种力量，价值从"属性"变成"力量"。第二步，价值与意义分开：价值稳定一个已存在的 SIO，意义孕育新 SIO 的诞生与流动。单一稳定系统内部两者重合，故被混淆；进入 SIO 爆炸涌现的文明阶段，混淆成为致命障碍。第三步，母命题：意义三律（特征律、自由律、幸福律）是价值之母，真善美是结构之子。圣经里公义与怜悯、真理与爱等20组价值冲突，不被视为系统失效，而是 SIO 尚未闭环时三律运行的合法差异。第四步，连成"律→力→果"：特征律生真力（维持结构轨道），自由律生善力（路径协同加速），幸福律生美力（使人愿留下）；三力结出的果叫真善美。第五步，用它回看：真理里含不可消去的主体（视角设定、路径偏向、情感张力），道德起于幸福律社会化，伊甸园的起点是把价值果当作意义果的"结构错认"。第六步，转向：文明动力学从价值动力学转向意义动力学，推动文明的是三律的运行，真善美只是对结构压缩之后的标签。落到母题。这条链的实际用法是改变评价：评价不再是批判，而是扫描三力是否协同，稳定一个系统是在种真，激发他人成长路径是在种善，让互动节奏动人是在涌现美；出路也相应从"价值消费者"变为"意义农夫"，在家庭、教育、组织里重新种树，而不是只摘果子。

## 三、核心构念

- **律→力→果**：意义三律运行生三力，三力结真善美之果。全书脊梁。
- **意义三律**：特征律、自由律、幸福律。价值之母，对应创造、自由、幸福的意义三位。
- **真力 / 善力 / 美力**：结构轨道的维持力、路径的协同与加速力、节奏在场的吸附力。
- **ΔSIO**：主体、互动、客体合成的结构及其差异运动。价值与意义都落在它上面。
- **价值标准＝三种本体约束**：结构稳定性、生成效率、节奏吸附性；评价由批判变为扫描三力是否协同。
- **结构错认 / 价值幻觉**：把价值果当作意义果，分真理、道德、审美三重幻觉。
- **意义内卷**：达标而空洞的人生，被异化的真善美拿来当模板所致。

## 四、全书骨架

编定说明与总序之后分五编十八章，另有结语和四件附录。第一编（第1—4章）为前史：真善美的四次定义，2024至2025年。第二编（第5—8章）为律：意义三律是价值之母，含道德的三律起源。第三编（第9—11章）为力与果：三力模型、真理的主体性成分、价值与意义。第四编（第12—15章）为回看：西方价值神坛的倒塌、三大文明、生命树与善恶果、达标人生为何空。第五编（第16—18章）为转向：从价值动力学到意义动力学。附录收"价值标准"、词根演化、真善美的六个说法与篇目出处。

## 五、关键案例与证据

全书由2024年8月至2025年7月的二十篇长文编成，保留当年的说法。
- 真善美六个说法的演变表：从可重复、去晕除痛减苦、吸引，到三力，称"同一个判断长了一年"。
- 圣经20组价值冲突（公义与怜悯、真理与爱、律法与恩典等）作为试验。
- "疯人"在医学话语、观察者视角、医院制度下显现为不同的真理位形。
- 三大文明：西方 Being（真善美）、中华 Becoming（诚中和）、佛教 Leaving（空无离），共享三律而方向不同。
- 学者讲台下的机械感、道德楷模无人处的情绪溃散、成功者深夜的"我没有意义"。
- 伊甸园两棵树：善恶树结价值果，生命树象征生成性互动。

## 六、碰撞接口

- **可抽出的命题**：（1）凡把价值当作评判标准者，皆把价值果当成意义果，因而达标而空洞；（2）若价值是意义的局部定型，则单一稳定系统内两者重合，系统多元化后混淆即成障碍；（3）真善美不是评价，而是律所结之果：不拜果子，要走结构。
- **可相撞的方向**：与规范伦理学、元伦理学、美学的"标准论"相撞；与以KPI、价值观清单治理组织的做法相撞；与三大文明比较中的"统一价值"主张相撞，可撞点在共享结构还是统一价值。也可与第214号对读：同样用真善美三股力，该书用于管理。

## 七、边界：什么情况下算错

本书停在2025年，用的是当时的口径（SIO、ΔSIO、意义三律），后来 SIO 已长成 SDE，编定时未改写。书中明言同一判断改过六次，早期说法（如意义因价值的变化性而产生）与第6章相反，以后者为准。三律的定义在多章重复出现，各章原为独立长文。论证依赖的前提是价值可还原为 ΔSIO 的三种约束；若有价值不对应任何结构运行条件，三力说即不成立。批评传统道德时，针对的是异化的真善美，三力所结之果不在批判之列。
