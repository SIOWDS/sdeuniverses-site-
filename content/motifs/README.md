# 专著母题卡 · 源稿目录

本目录每个 `{号}.md` 是一部专著的母题卡源稿，由 `tools/build_motifs.py` 生成 `public/motifs/` 栏目（总表、单书页、motifs.json、all.md）。新书上站后照下面的规程写一张卡，再跑脚本。

---

## 写作规程

你在为德麦国际 SDE Universes 网站的新栏目「专著母题」写母题卡。每本专著一张卡，约 2000 字（1800—2200 字，以汉字计）。

## 这张卡是给谁用的

主要读者是做「SDE 二阶碰撞」和「形式逻辑归纳总结」的研究者与智能体。他们要靠这张卡，不读全书就能：
- 一眼抓住这本书的母题（全书脊梁那一句反直觉判断）；
- 知道它推翻了什么默认看法、靠什么立住；
- 拿到它的核心构念和可以抽出来的命题，用来和别的书相撞，或者和别的书一起归纳；
- 知道这本书的判断在什么情况下不成立。

所以写法是"研究底册"，不是书评，不是宣传文案，不写"本书深刻地……""令人耳目一新"这类评价。

## 材料与忠实

每本书的材料包（source pack）里有：目录信息与简介、要点（keypoints，常含作者原话）、章节标题、开头与结尾的正文摘录、站内相关书目。

铁律：
1. **只写材料里有的。** 不编造书里没有的论点、案例、数据、人物、引文。材料不够的地方宁可写短，也不补想象。
2. **母题是这本书自己的判断**，用这本书自己的话立住；不要替它发明一个新判断，也不要拿 SDE 的通用说法顶替它的具体判断。
3. 作者原话（材料中标为原话或口述的）可以短引，单处不超过 40 字，用「」。
4. 构念名、术语照书里的写法，不改名。

## 术语纪律

- 泛指大模型一律写"基底"（厂商专名照原名）。
- S 是"显露"（Show），不是"结构"。
- 不用"真"作强调修饰（如"真正的""真问题"），不用"本体论级"作修饰语。
- 出版社写"德麦国际出版社"。

## 卡片格式（严格照此，Markdown）

```
# 第{号}号《{书名}》
- 副题：{副题，没有就写"无"}
- 作者：{作者；有指导老师写"某某著，某某指导"}
- 题域：{一到三个词，如 教育·学习}
- 题型：{What / How / Why 选一个主型：这本书主要回答"是什么"、"怎样发生/怎么做"、还是"为什么"}
- 母题：{一句话，不超过 60 字，必须是一个判断，读起来有反直觉之处}

## 一、它推翻的默认看法
（约 250 字）这本书针对的常见看法是什么，错在哪一步。

## 二、母题怎样立起来
（约 500 字）论证主线：从哪个起点出发，经过哪几步，落到母题。写出推理链，不罗列章节。

## 三、核心构念
（约 350 字）3—6 个本书自创或重新定义的构念，每个一行：**构念名**：一句定义＋它在全书里干什么用。

## 四、全书骨架
（约 250 字）几编几章、各编分别做什么，一段话写完。

## 五、关键案例与证据
（约 250 字）书里用来立论的主要案例、母事、数据或文本，各一两句。

## 六、碰撞接口
（约 300 字）分三小项：
- **可抽出的命题**：2—3 条，写成"若……则……"或"凡……皆……"或"……不是……而是……"的形式，供形式归纳用；
- **可相撞的方向**：这本书的判断最适合和哪类问题、哪类学科相撞，可撞点在哪里；
- **站内邻书**：从材料里的相关书目中挑 2—4 本，写书号与书名，并用半句说明是同向还是可对撞。

## 七、边界：什么情况下算错
（约 150 字）这本书的判断在什么条件下不成立、作者自己划了哪些界；材料里没有就根据论证写出它依赖的前提。
```

正文用段落写满，不要一行一段（第三节、第六节的条目除外）。

## 交付

把每张卡写成独立文件：`{输出目录}/{号}.md`，文件里只放卡片本身。写完一本再写下一本。全部写完后，回复一行：已完成的书号列表，以及因材料严重不足而写得偏短的书号（如有）。

## 补充说明

- 材料包没有给站内相关书目时，「站内邻书」只写正文里明确提到的本站前作（有书号才写书号，没有就只写书名），不要编书号；一本也确认不了就写"材料未列出"。
- 读材料包要读完再写，不要只读开头。
- 每张卡写完立刻用 Write 存盘，再读下一本的材料包。

---

## 用法：四层读法（做二阶碰撞、类比、演绎、归纳出大纲时）

1. 第一层 · 母题总表（/motifs/ 或 motifs.json 里的 motif 字段）：选书。
2. 第二层 · 母题卡（/motifs/{号}/）：定大纲骨架。
3. 第三层 · 选中专著的要点、章节与碰撞关联（/books/m/{号}/ 的 keypoints.json、rag.json）：定位章节。
4. 第四层 · 原书章节：只读定位到的那几章。

下沉条件（满足其一才往下一层）：承重前提；要直接引证原话或案例；卡上注明材料不足或据要点还原；两张卡说法冲突。不满足就停在上一层。
