# 发布事故复盘：最新作品已上线，但未在学员页正确置顶

日期：2026-07-24

## 事故

投稿箱新论文已经生成网页长文、在线 PDF 和下载 PDF，文章直达页也能访问，但学员主页与作品列表没有同步呈现正确的“最近发表”状态。

典型表现：

- 胡敏《无向的发生》直达页在线，但学员主页首屏没有题目，用户因此合理判断为“没有出现在线上”。
- 胡敏新作沿用了“之五、之四”等旧局部编号，没有使用其当前44篇作品中的最高序号。
- 学员主页的静态简介、动态作品列单、作品列表、论文书目之间更新不同步。
- 只验证直达页返回200和PDF入口存在，就错误地宣布“学员页已经更新”。

## 根因

1. 把“文章可访问”误当成“文章已经在学员页完成发表”。
2. 新卡片沿用旧模板编号，没有依据作者当前作品总量重新排序和编号。
3. 只检查动态加载完成后的作品列单，忽略用户打开主页时首先看到的静态展示区。
4. 发布验收缺少“从学员主页进入文章”的完整用户路径。

## 正确规则

1. 最近发表的作品必须置于作者作品列表最上方。
2. 最新一篇必须使用作者当前最高序号，后续新作依次递减。
3. 同一批多篇作品按确定的发表顺序排列；不得沿用模板中的局部序号。
4. 学员主页静态展示区必须出现本批新作，不能只依赖延迟加载的 JavaScript 列单。
5. 作品总数、卡片序号、论文书目条目数必须一致。
6. 验收必须从正式站点依次检查：学员主页 → 最新作品卡片 → 文章页 → 在线PDF → 下载PDF。
7. 不能只用直达URL返回200作为“已上线”的完成证据。

## 以后发布前的强制检查

```text
[ ] 新作是否位于作品列表第一位
[ ] 最新序号是否等于该作者作品总数
[ ] 同批后续作品是否按最高序号递减
[ ] 学员主页不等待脚本也能看到本批新作
[ ] 作品列表、roster.json、publications.json 数量一致
[ ] 正式站点按“主页→作品→三种阅读方式”实测通过
```

这不是排版小错，而是发布完成标准判断错误。以后必须把“用户从学员主页能找到文章”作为发表成立的必要条件。
