# ChatPrimary 1.0

独立入口：`https://sdeuniverses.com/education/chatprimary/`。母站教育栏目和教育子站首页均提供链接。本智能体独立于 ChatPrim，使用独立页面、服务端策略、API 路由和学习记录；保留已有 ChatPrim。

范围：四、五、六年级，语文、数学、英语；文字自学，课题输入、教材版本及原文粘贴、节奏和情境偏好、基于回答调整引导。27 个课题起点不是完整教材目录。未提供原文时不声称读过指定课文。

教学设计依据王德生博士的 SDE 知识发生学：理解显露 S、尝试的差异序列 D、材料与学习条件 E 相互改变。界面呈现“先试一试／找找差异／自己说懂／换题试试／收获回看”。推进依据学生表达的证据，不按轮数加分，不声称提示后答对即掌握。每轮原则上只邀请学生完成一个动作。

实现：独立 `src/chatprimary.js` 模块，由 Worker `/api/chatprimary` 路由调用，固定服务端策略、严格年级学科/历史校验、JSON 输出校验、超时、同源限制、限流。只支持 DeepSeek、通义千问和智谱，复用站点厂商地址与模型默认值；智谱使用站点轻量模型。没有密钥时不调用模型、不读取 CONFIG_VAULT、不退回平台付费账户，不改全站 BYOK 规则。

家长/老师在设置里填入其模型账户密钥，费用由该账户承担。本页密钥只驻留内存；仅在网站已有 `sde_wds_key` 与可识别国内厂商 `sde_wds_vendor` 同时存在时沿用，不回显，不写入学习存档。断开仅影响本页。

学习正文默认只存在页面内存。可明确勾选保留到本机浏览器，7 天后不恢复，清空会移除该存档。本服务不写学习正文或密钥日志/数据库；调用所选模型时仍需向模型服务发送题目和对话，厂商按自身规则处理。上游错误正文不传给孩子。界面不要求姓名、学校或联系方式。

每课最多 20 轮。每轮成功后才落入历史；失败保留待重试请求，不重复追加。切换新课清除历史、材料可重新编辑，未完成的旧请求通过序号与中止控制避免写入新课。页面纯文本呈现模型输出，无 HTML 注入。

验证：`node tools/test_chatprimary.mjs`（受控上游夹具）、Node 语法检查、Git 差异检查。当前工作环境没有可用的用户国内模型密钥，不能据此宣称完成真实模型教学质量验收；上线后需由家长填入有效密钥，完成实际三科学习试用。

接口格式依据：[DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)。本次没有改变既有模型全站默认值、部署配置或 Durable Object 迁移。
